## Objective

Verify on production that a suspended sandbox accrues storage and an ended one stops, and that the metered bytes match the registry.

## Context

- The hourly roll-up means accrual is visible after the next rollup; plan for at least one full hour.
- Follow the production-check pattern of w32/m297 t004 (isolation-matrix probe).

## Steps

1. Create a sandbox, write a known amount of data, let it suspend (or suspend it), wait for the roll-up.
2. Read `GET /v1/usage` and the invoice preview; compare the bytes with the Zot repository size.
3. Resume and terminate; confirm accrual ends and the image is removed.

## Files

- Evidence summary in the task file (no raw dumps)

## Acceptance criteria

- [ ] Metered bytes within the documented tolerance of the registry's size
- [ ] Accrual stops on terminate
- [ ] The usage preview shows storage and no compute while suspended

## Out of scope

- Memory and CPU billing
