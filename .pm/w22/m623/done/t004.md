## Objective

The three documents a reader would check say the same thing: how many sandbox execs and transfers one user can run at once on bex, why, how a refusal answers, and whether that differs from Render.

## Context

- `docs/ADR104-sandbox-render-parity.md` D7 § API rate limits (w22/m443) and its production check, which ends "A user cannot reach this class's 1,000 a minute until w22/029 lifts that cap for sandbox streams".
