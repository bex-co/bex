## Objective

## Steps

1. For each failing test, find the first refused or mismatched request and the matching interaction in Render's cassette.
2. Class it; for a new bex-side class, write what Render answers, what bex answers, and the bex code path.
3. A test that fails on a known class number means a fix regressed: record it as such.
