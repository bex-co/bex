## Objective

`POST` and `DELETE /v1/environments/{id}/resources` accept `sbg-` ids, with the semantics the clients rely on: adding a group that is in another environment moves it, removing it leaves it in no environment, and a mixed request is all-or-nothing as it is today.

## Context

- `lego/backend/internal/environments/resources.go`: `classifyResources` (lines 59–79) refuses `sbg-` with 400; `ChangeResources` applies each `memberKind` in turn and reverses the applied kinds on failure (`reverseKind`).
- Routes: `lego/backend/internal/environments/rest.go:225-240` (POST answers 201, DELETE 204).
- The group's placement: `sandbox_groups.environment_id` (migration 0270, `ON DELETE SET NULL`), set at create by `placeGroup` (`lego/backend/internal/sandbox/groups.go:320`, which calls `core.ResolveEnvironmentForCreate`). The `id` package already has `ids.SandboxGroup` (`sbg`).
- The import DAG: `environments` must not import `sandbox` if that creates a cycle; follow how the other label-backed kinds reach their stores (`resourceIndex`), or add a narrow interface the sandbox package satisfies.
- Render's clients: add relies on the API "to move the group out of any environment it was in" (CLI `repo.go`); clear reads the group, then removes it from the environment it reads.

## Steps

1. Add a sandbox-group kind to `resourceKinds`/`classifyResources` and the 400 message.
2. Add the group's `memberKind`: change sets or clears `environment_id` for the named groups only, recording where each was (`memberChange.from`) so `reverseKind` can return it.
3. A group id that does not exist, or belongs to another workspace, answers 404 like the other kinds, before anything changes.
4. Removing a group that is not in this environment: match what the other kinds answer, and record it.
5. Keep the environment's REST shape unchanged (Render's environment object lists no groups); `EnvironmentOccupied` and the delete cascade keep m412's behavior (the group survives with `environmentId: null`).
6. Unit tests on the fake store and a real-Postgres test in `resources_pg_test.go`.
