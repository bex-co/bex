# Watch the operations Render's generated clients reach before its public OpenAPI does

Why: Render's own clients run ahead of its public OpenAPI, and the scheduled drift job reads only the public spec, so an operation that Render's CLI or SDK can call (and that a bex user's code may call next) reaches bex unseen.

Found by `/pm-brainstorm one aspect of render parity for w22` (2026-11-23), item 4, filed by `/pmx them all to w22`; verified at `origin/main` `cb469e7cfd`.

- **Evidence (read 2026-11-23).**
  - Render SDK v1.10.0's generated Go client (`go/pkg/render/internal/client/client_gen.go` at `typescript/v1.10.0`) has 178 operation paths, against 174 at v1.9.0. New: `/hosted-repos` (list, create), `/hosted-repos/{id}` (retrieve, delete), `POST /hosted-repos/{id}/git-credentials`, and `/flow-runs/{id}/steps/{id}/attempts/{id}`. The types describe Render Hosted Git: `HostedRepo` (`hrp-` ids, `remoteUrl` on `code.render.com`, `serviceIds`, `state`, `deleteAt`) and short-lived `GitCredentials`.
  - Render CLI v2.38.0's `pkg/client/client_gen.go` (and v2.37.0's, `docs/cli-compatibility-checklist.md:41`) already carries `CreateHostedRepoGitCredentials` and `get-flow-run-step-attempt`, reached by no served command.
  - None of it is in Render's live public OpenAPI (265 operations, no `hosted` path), `render.com/llms.txt` or the changelog, and `render.com/docs/hosted-git` answers 404.
  - `scripts/render-schema-drift.sh` downloads only `render-public-api-1.json` and the CLI's latest release tag. The hand-kept `renderCLIOperationsOutsideSpec` (`lego/backend/internal/api/render_openapi.go:1072`, w32/100) lists the CLI operations bex serves outside the spec, checked by hand against the pinned `client_gen.go`; nothing re-checks it when the pin moves.
- **Do.**
  1. In the drift script (or a sibling job step), extract method plus path from the pinned CLI's `pkg/client/client_gen.go` and from the latest SDK release's `go/pkg/render/internal/client/client_gen.go`.
  2. Compare them with the pinned OpenAPI's operations plus a small checked-in list of client-only operations, each with its disposition: served (and in `renderCLIOperationsOutsideSpec`), omitted with ADR018's reason, or a non-goal (`/flow-runs/…` is the Workflows non-goal in `.pm/DO_NOT_DO.md`). An operation in neither fails the job with the client and version that carries it.
  3. Fail too when an entry of `renderCLIOperationsOutsideSpec` is no longer in the pinned CLI's client.
  4. Record Render Hosted Git in ADR018 § Render operation omissions as unannounced: present only in Render's generated clients, no public docs; nothing is built until Render publishes it, when it becomes a parity decision of its own.
- **Done when:** the drift job's run log lists the client-only operations it found with their dispositions, a test feeds it a client with an unknown path and it fails, and ADR018 has the Hosted Git row.
- Size: about an hour (one script step, a small list, a test, a ledger row), so a note, not a milestone.
