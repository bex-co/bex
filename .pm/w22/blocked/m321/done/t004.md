## Objective

Give bex-api the registry URL and both credentials so sizing and reaping start without a hand-set variable.

## Context

- `BEX_SANDBOX_SNAPSHOT_REGISTRY_URL`/`_USER`/`_PASSWORD` and `BEX_SANDBOX_SNAPSHOT_REGISTRY_GC_USER`/`_GC_PASSWORD` (`lego/backend/cmd/api/config.go`, w22/m313); `lego/operator/config/api/deployment.yaml` is bex-api's manifest.
- The network policy admits `bex-system` into `bex-registry:5000` (`deploy/gitops/base/network-policies.yaml`); confirm bex-api's own egress policy does too.

## Steps

1. Add the five variables to `deployment.yaml` with `secretKeyRef` entries marked `optional: true`, so a cluster without the Secret behaves as today (nothing sized, nothing billed).
2. Confirm the repository prefix and container name (`snapshots`, `sandbox`) against a live sandbox's snapshot repository and set the two variables if they differ.
3. Update `.env.example` and `lego/backend/AGENTS.md` if anything changed.

## Files

- `lego/operator/config/api/deployment.yaml`, `deploy/gitops/base/network-policies.yaml` (if needed)

## Acceptance criteria

- [ ] bex-api starts with and without the Secret
- [ ] `SandboxStorageUnsized` has the credentials it needs to clear once a sandbox is suspended

## Result — 2026-11-10

bex-api reads the Secret (`cmd/api/registry_credentials.go`: cached for five minutes, rotation picked up, the last good value served through an API outage, a Secret with no password refused, never an empty credential); `RegistryConfig.Credentials` supplies the auth per call. `BEX_SANDBOX_SNAPSHOT_REGISTRY_SECRET` wins over the plain variables, and deleting is a **separate switch**, `BEX_SANDBOX_SNAPSHOT_REAP` (off in `deployment.yaml`), because it is the first registry write bex-api makes: sizing is verified first (t005), then it is turned on. `deployment.yaml` sets the Zot URL and the Secret. Not confirmed without a cluster: that bex-api's own egress policy admits `bex-registry:5000` (the registry's ingress policy admits `bex-system`), and the repository prefix and container name (`snapshots`, `sandbox`) against a live snapshot repository; both are in t005.
