## Objective

Make the queue and the interrupt usable on the session page, matching what Devin offers: send while it works, see and manage what is queued, send one now, stop the turn.

## Context

- The composer is `dashboard/src/features/agent-sessions/components/steering-composer.tsx` (disabled while a turn is live, ~lines 60–76); the page is `session-chat-column.tsx` / `session-conversation*.tsx`; the header with Cancel is `session-detail-header.tsx`; spend banners are `composer-spend-banner.tsx`. Locales: `dashboard/src/features/agent-sessions/locales/` (en and zh).
- Devin: queued messages are editable, removable and reorderable (2026-10-16), Cmd/Ctrl+Enter while editing a queued message sends it immediately (2026-08-26), Cmd/Ctrl+Shift+Backspace stops Devin while it works (2026-08-21).
- Dashboard rules (AGENTS.md, `dashboard/AGENTS.md`): skeletons match the ready state's geometry at desktop and narrow widths; strings in the locale files; the dashboard only calls the GraphQL API.
- "Send now" is interrupt, then move that message to the front (t003 dispatches it when the turn settles).

## Steps

1. GraphQL documents and generated types for the queued-messages field and the edit, delete, move and interrupt mutations; run the repo's codegen.
2. The composer stays enabled while a turn runs: a send enqueues and shows the message as a chip above the composer; a full queue shows the coded error's message.
3. Queued-message chips: edit in place, remove, move up or down, and "send now" (with the Cmd/Ctrl+Enter shortcut while editing); each states a blocked reason when the dispatcher reports one (spend cap, live-sandbox limit).
4. "Stop turn" beside Cancel while a turn runs, with a shortcut, a distinct label from Cancel, and a confirmation only for Cancel (Stop turn is cheap and reversible). Cancel keeps its current copy and behavior.
5. The turn list shows an interrupted turn as interrupted, not failed.
6. Tests for each control and error state; skeleton and ready states compared side by side at desktop and narrow-mobile widths (Playwright MCP, bare filenames, no images committed). `cd dashboard && yarn lint && yarn test`.
7. Live run on `dev-N` (`scripts/dev-env.sh <N> up`, pre-approved): start a long turn, send two messages (both queue), reorder them, remove one, edit the other, "send now" it, watch the turn stop and the message run, send another and let it run in order, then press "Stop turn" on a running turn. Record the observed codes, timings and the dashboard states as text in the milestone README under "Live run" (no images committed). Tear the environment down.
