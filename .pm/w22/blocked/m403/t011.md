## Objective

Prove the milestone's observable end state on a running stack: a message sent to a running agent session is queued and runs in order, and Stop turn ends only the running turn on a real sandbox. This moves the live steps out of t004 (step 5) and t005 (step 7), whose code and tests are done, because the stack they need could not be brought up when they were worked.

## Context

- `scripts/dev-env.sh <N> up` and `agent-up` (pre-approved, AGENTS.md 2026-09-09) need the shared kind/CAPD cluster from `bash scripts/mock-cluster.sh`.
- The scenario and what only a live stack can show are in the milestone README under "Gate: t011". The design is ADR047 D12 and its "As built" notes.
- Record text and numbers only; no screenshots or raw logs in git (`#NO-ARTIFACTS-IN-GIT`).

## Steps

1. Bring up `dev-N` with the agent leg and a workspace with a model key.
2. Run the scenario in the milestone README: two queued messages with positions, reorder, edit, remove, send now, a third message after the turn, Stop turn on a running turn, a follow-up after Stop turn, and a bex-api restart with messages queued.
3. For Stop turn read the status file and the sentinel inside the sandbox (`/var/run/bex-agent/`), the time from the click to the `interrupted` state, and the delivery note's text for unpushed work; repeat once per engine profile that has a key (claude, codex, gemini, muse).
4. Write the observed codes, timings and the state of each queue row under a "Live check" heading in the milestone README. Fix any defect found with a test first. Tear the environment down.
