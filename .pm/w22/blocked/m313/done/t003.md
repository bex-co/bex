## Objective

Accrue storage for a suspended sandbox's retained rootfs image from commit success to deletion, durably and idempotently, and expose the same start/end API for w32/m285 to call for snapshots.

## Context

- The suspend path commits the rootfs to a per-tenant Zot image (ADR042 D5; w2/m278): `sandbox/service.go` and `idle.go`.
- Durable cursor precedent: `store/sandbox_meter.go`; storage precedent: `storage_gb_seconds` for datastores (ADR023) and ADR082's provisioned-GB seconds.
- w32/m285 (blocked) will create snapshots; it should call this API rather than add a second meter.

## Steps

1. Add the migration for storage objects (workspace, object id, kind, bytes, started_at, ended_at) and the `sandbox_snapshot_gb_seconds` usage kind.
2. Call `start` when the suspend commit succeeds (bytes from t001's source) and `end` on terminate, GC and expiry.
3. Accrue in the same hourly rollup shape as other storage kinds; make `start` and `end` idempotent.
4. Document the API in the package comment and in ADR104 D4 so m285's tasks consume it.

## Acceptance criteria

- [ ] A 10 GB image kept 24 h records 240 GB-hours; ending it stops accrual
- [ ] Replaying a start or end event changes nothing
- [ ] A crash between commit and `start` is repaired by the next poll without losing or inventing seconds

## Out of scope

- Snapshot objects (w32/m285 calls the API)

## Result — 2026-11-10

Migration 0228 (`sandbox_storage_objects`), `store/sandbox_storage.go` (`StartSandboxStorage`, `SetSandboxStorageBytes`, `EndSandboxStorage`, `AccrueSandboxStorage`, all idempotent) and the phase-cursor hook. **Deviation from the task text:** there is no hook in `service.go`/`idle.go`. `lifecycle()` records phase `suspended` when a pause is only accepted, before its image commit has succeeded, so the object opens only from a *polled* `Paused` observation (`SandboxMeterObservation.Polled`), and the size is read only then. A 10 GB image kept 24 h records 240 GB-hours and closing it stops accrual; replays change nothing; a registry outage delays a charge and covers the whole retained interval once the image is sized; a size read for an earlier period is refused after a reopen (`TestSandboxStorageMeterPG`). `RegistrySizer` reads the manifest (tested against a fake registry and, once, against a real local Zot). API for w32/m285 documented in ADR104 D4.
