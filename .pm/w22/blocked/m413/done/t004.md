## Objective

Tell the user what happened to the interrupted turn's unpushed work: kept until a time, or lost.

## Context

- The interrupted note is `dashboard/src/features/agent-sessions/components/turn-interrupted-note.tsx` (rendered in `session-conversation-impl.tsx` ~1023-1042); the delivery-note callout is `delivery-note-callout.tsx`. A turn's `interrupted` flag is on `agentSessionTranscript.turns` (`lego/backend/internal/agentsessions/graphql.go` ~530, `models.go` ~537-539). Unpushed facts reach the UI only as the delivery-note string today.
- `AGENTS.md`: a loading skeleton must match its ready state; generated GraphQL files are regenerated, never hand-edited or prettier'd.

## Steps

1. Tests first (service, GraphQL, MCP, REST parity; a dashboard component test): an interrupted turn reads `retention` as kept with `retainedUntil`, as lost (expired, or the cap was full) or as none (nothing to keep); the note shows 'your changes are kept until <time>' or 'your unpushed changes were lost when the sandbox expired'.
2. Add the field to the turn on REST, GraphQL and MCP (golden JSON regenerated), the dashboard note with the strings in every locale of the feature, and `bex agent` output (`lego/cli/internal/agent`).
3. `cd dashboard && yarn lint && yarn test`; check the note at desktop and narrow width.
