## Objective

Establish whether the in-sandbox capabilities Docker needs can coexist with the Pod Security Standard and admission policy on `<ws>-sandbox` namespaces.

## Context

- `<ws>-sandbox` namespaces enforce PSS baseline (ADR042); `deploy/gitops/base/sandbox-pod-admission.yaml` is a ValidatingAdmissionPolicy over sandbox pods; `deploy/opensandbox/batchsandbox-template.yaml` is the pod template.
- ADR104 D6 says this "has not been checked against the sandbox Pod template".

## Steps

1. Read the three files above and list each rule that would reject or strip the capabilities.
2. Try admitting the spike pod into a scratch `<ws>-sandbox`-shaped namespace on the throwaway cluster and record which control blocks it.
