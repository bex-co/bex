## Objective

Turn the functional and isolation checks into one script with pass/fail output so the spike can be re-run on a runsc, Docker or pin bump.

## Context

- `scripts/` holds the cluster helpers (`mock-cluster.sh`, `deploy-sample.sh`); script validation conventions live in `scripts/*-validate.sh` and `scripts/ship-gates.sh`.
- The script must refuse to run against a node labelled `bex.co/pool=sandbox` unless an explicit override is passed.

## Steps

1. Write the script from the t003 and t005 commands with one line of output per check.
2. Add the production-pool guard and a `--dry-run` that prints the plan.
3. Run it end to end on the throwaway node and attach the output summary to t007.
