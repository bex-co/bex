## Objective

In every situation t002 marked "different spelling" or "generic error", bex answers the code the SDK maps.

## Context

- The work list is the "Code comparison" table in the milestone README.
- A group can be suspended on Render (`SandboxGroupSuspendedError`). On bex the nearest states are a workspace suspended by billing (w6/m319's `billing` suspender) and the payment gate (`lego/backend/internal/sandbox/payment_gate_test.go`). Map only where the situation is the same; do not relabel a different refusal to make a row green.
- The unmodified Render CLI parses some of the same codes; `lego/backend/internal/sandbox/cli_flags_test.go` and `groups_contract_test.go` pin what it reads.

## Steps

1. Add or rename the constants, one per code, each with a comment naming the SDK class and the fixture.
2. Where a bex-named code is replaced by Render's, check who reads the old one: the dashboard, the `bex` launcher's messages, MCP tool descriptions, ADR018 and the checklist. Update them in the same change.
3. Return the same code on GraphQL (error extension) and MCP (tool error) as on REST.
4. Keep bex-only refusals (snapshots and credentials not offered) under their existing names, and record them in the fixture's "cannot occur" list.
