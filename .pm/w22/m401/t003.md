## Objective

Give both new alerts the panel ADR088 §6 requires ("an alert only says broken; the panel answers how bad and since when"), record them in the §6 coverage table, and remove the comment that tells the next reader the registry is empty.

## Context

- `scripts/obs-coverage-check.sh` fails unless every alert in `alerting_rules.yml` has at least one backing series drawn on a committed dashboard (`deploy/gitops/base/values/grafana.values.yaml`), and context series (`up`, enable flags, joins) never count on their own. It prints the alert → dashboard map on every run.
- The Cluster capacity dashboard already holds the Zot PVC and GC panels (`docs/ADR088-platform-observability-ui.md` line ~85 and the "Registry GC recurrence (w7/m163)" section at ~101).
- The §6 coverage table is where the "Deploy email" waiver row lives (`docs/ADR088-platform-observability-ui.md` ~line 143).
- The comment above `StrandedNodeLocalImages` (`alerting_rules.yml`, ~line 1633) says "App images are node-local ctr imports (no registry — zot is empty)". Tenant images are served from Zot since the registry-backed pull path (ADR022 § Node image cache), so the comment is wrong for Git-built services. The rule itself stays: it still describes the `/deploy-app-from-local` image-import path.

## Steps

1. Add to the Cluster capacity dashboard in `grafana.values.yaml`: a "Zot replicas ready vs desired" panel (`kube_statefulset_status_replicas_ready` and `kube_statefulset_replicas` for `bex-registry/zot`) and a "Tenant pods failing to pull from the platform registry" panel (the same expression as `TenantRegistryImagePullFailing`, as a count over time).
2. Run `bash scripts/obs-coverage-check.sh` and confirm both alerts map to the new panels.
3. Add the "Registry pull path" row to the §6 coverage table in `docs/ADR088-platform-observability-ui.md`, naming both alerts, both panels and the `ZotRegistry*` alerts they sit beside. Add one sentence to the Cluster capacity row.
4. Correct the `StrandedNodeLocalImages` comment: say what the rule still covers (node-local imports) and point at `TenantRegistryImagePullFailing` for registry-served images and at its `namespace="default"` scope.
5. Run `scripts/gitops-validate.sh` for the dashboard JSON and rule checks it performs.
