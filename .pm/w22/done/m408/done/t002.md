## Objective

Stop the sandbox's own status file from deciding that a turn was interrupted: bex-api stamps the stop request on the turn, and the Completer honors the `interrupted` status only for a stamped turn.

## Context

- `Completer.interrupted` (`lego/backend/internal/agentsessions/completion.go`) finalizes a turn as completed when the status file says `interrupted`, and bex-api records no request, so an untrusted agent that can write the status file can end its turn that way to skip the missing-structured-result failure `complete()` raises.
- `Service.Interrupt` (`agentsessions/queue.go`) writes the sentinel through `InterruptSessionTurn` (`lego/backend/internal/sandbox/service.go`); the driver writes status `interrupted` (`lego/agent-image/driver/src/interrupt.ts`, `session.ts`). `MarkAgentSessionTurnInterrupted` flags the turn.

## Steps

1. Write failing tests first: a status `interrupted` with no recorded request is NOT finalized as interrupted (it takes the normal completion path, so a turn owing a structured result fails as before); with a recorded request it finalizes completed with the turn flagged `interrupted`; a request recorded for turn N does not cover turn N+1.
2. Add a nullable `interrupt_requested_at` to `agent_session_turns` (migration), stamped by `Service.Interrupt` before the sentinel is written (idempotent), and read by the Completer.
3. In the Completer, honor `interrupted` only for a stamped turn; otherwise run `complete()`'s checks.
4. Update ADR047 D12 "As built".
