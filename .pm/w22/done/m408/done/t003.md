## Objective

Exclude a message the dispatcher holds a lease on from reordering, and have the begin-turn transaction use the row as it is now instead of the claim-time copy.

## Context

- `MoveQueuedAgentMessage` (`lego/backend/internal/store/agentsession_queue.go`) requires the target to be unleased, but the leased head still takes part in the position trade, so "send now" can show message M first while the leased message H starts first.
- An edit after a lapsed 2-minute lease is lost, because `BeginQueuedAgentSessionTurn` uses the prompt and author from the claim.

## Steps

1. Write failing real-Postgres tests first: moving a message ahead of a leased head answers a coded 409 `AGENT_QUEUED_MESSAGE_DISPATCHED` and changes no position; moving the leased head itself is refused the same way; an edit that lands between claim and begin-turn is what the turn runs (or the begin-turn is refused so the dispatcher re-claims).
2. Make the move skip or refuse leased rows; re-read prompt and author under the row lock in `BeginQueuedAgentSessionTurn`.
3. Update ADR047 D12 "As built".
