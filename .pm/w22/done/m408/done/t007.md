## Objective

## Steps

1. Check each task's failing-then-passing tests against its failure modes, and add what is missing (a key reused across two sessions, an interrupt request for turn N and a status for N+1, a lease lapsing mid-edit, a backoff boundary).

## Acceptance criteria
