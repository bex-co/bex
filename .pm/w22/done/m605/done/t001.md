## Objective

One run of the whole suite against one bex commit that production runs.

## Context

- Production's pin: the newest `chore(deploy): pin platform images to <sha>` on `origin/main` (`9fdf7e0a1171` at filing, `cded300699`). Build bex-api and the operator from that source (or a later main the next pin carries, recorded as such).
- `docs/terraform-compatibility-checklist.md` § Pins and harness and § Runs; Run A's production shape: `BEX_REGION=fsn1` (resources read back `frankfurt`), OpenFGA enforced, a Scale workspace, the Admin's API key used as minted (since w9/m481 it acts with its creator's role).
- `scripts/dev-env.sh <N> up` plus `agent-up` for OpenBao; `mock-cluster.sh operator` so the operator matches the tree. Local dev environments are pre-approved.

## Steps

1. Bring up a free `dev-N` from the pin's source; record the commit, region, authorization mode and plan.
2. `scripts/terraform-provider-verify.sh all` with a fresh Scale workspace's Admin key; re-run tests that hit GitHub's anonymous rate limit after the reset, recording which.
3. Keep cassettes and logs outside the repository; record the recordings tarball's sha256 and the per-test result table.
