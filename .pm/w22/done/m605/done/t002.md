## Objective

Each failure has a stated cause, compared with Render's own cassette for the same test.

## Context

- Known omissions and non-goals: `log_stream_override` (external log drains), `previews.generation: automatic` and preview notifications `true` (PR previews), dedicated outbound IPs, Postgres `parameterOverrides`, `logstreams`/`metricstream` (ADR018 § Render operation omissions, `.pm/DO_NOT_DO.md`).
- Classes 1–12: `docs/terraform-compatibility-checklist.md` § Failure classes.
- `git -C <work>/terraform-provider-render diff` compares bex's answers with Render's recordings.

## Steps

1. For each failing test, find the first refused or mismatched request and the matching interaction in Render's cassette.
2. Class it; for a new bex-side class, write what Render answers, what bex answers, and the bex code path.
3. A test that fails on a known class number means a fix regressed: record it as such.

## Acceptance criteria

- [x] No failing test is left unclassified.
