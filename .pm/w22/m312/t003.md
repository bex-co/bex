## Objective

Record what works and what fails of Docker and Compose inside the sandbox, against Render's "Docker and Docker Compose supported".

## Context

- Render's page does not say how far "supported" goes: whether `docker build` works, whether published ports work, how Compose networking behaves (ADR104 D6).
- gVisor's FAQ: with iptables off, `docker run -p` and `--expose` do not publish ports (use `--network=host`), and DNS on user-defined bridge networks does not resolve.

## Steps

1. Run `docker run hello-world`.
2. Run `docker build` of a small multi-layer image.
3. Run a Compose file with two services, an internal call between them by service name, and a published port; record each failure verbatim.
4. Repeat on Docker v28 and v29 where the node image allows.
