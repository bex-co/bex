## Objective

Add meaningful tests for the behavior this milestone shipped. Tests assert real behavior and failure modes; no trivial or tautological tests.

## Steps

1. A test that the configured default image is pinned by digest and is the one ADR104 names (so a silent change of the default fails).
2. If bex builds the image: a build-time check that runs in its workflow and asserts each tool in ADR104's contents list is present and that a glibc binary starts (when glibc was the choice).
3. The resume test from t005 and the file round-trip tests on the new image.
4. Mutation spot-check: remove `curl` from the image, unpin the digest, and make resume read the current default; each must fail a check.

## Acceptance criteria

- [ ] Each mutation above is caught, and the results are recorded in the milestone README.
- [ ] The backend suite is green against the real database.
