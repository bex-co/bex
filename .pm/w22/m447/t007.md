## Objective

Check that the default image is the same on every surface that creates a sandbox, and compare what it provides with what Render's pages and templates assume; record drift as follow-up work instead of diverging silently.

## Context

- Surfaces: REST `POST /v1/sandboxes`, GraphQL and MCP sandbox create, and the CLI through the launcher. The dashboard's sandbox pages show the image if they show one.
- Render: the three integration pages, render.com/docs/sandboxes-executing ("each command starts a new shell in the home directory") and sandboxes-files (relative paths resolve from the home directory).

## Steps

1. Create a sandbox with no image on each surface and confirm the same digest.
2. Re-read Render's executing and files pages against the new image: home directory, working directory, relative upload paths.
3. Update ADR018's sandbox rows and ADR104 D2; list anything a template needs that bex still lacks, and anything bex ships that is its own choice.
4. File each drift as an inbox note (`/pm add`).
