# Key Value's external host: Render's regional `<region>-keyvalue.` endpoint, or the user's sign-off on bex's per-store SNI host

Why: a Key Value's external connection string and CLI command name Render's regional shared endpoint on Render (`oregon-keyvalue.<domain>:6377`, routed by username) and a per-store host on bex (`red-….kv.bex.co`, routed by SNI), so Render's own Terraform data source checks fail on bex. That is the last non-omission failure in the [Terraform checklist](../../docs/terraform-compatibility-checklist.md) besides class 13 (w22/037), and ADR018 records the difference without the user's sign-off, which a divergence needs (`AGENTS.md`, Render parity).

From w22/m605 (Run K, 2026-11-24, dev-10 at production's pin `ff5de0a130e6`), as in run I (w9/m521, 2026-11-19):

- **The checks.** `TestAccKeyvalueDataSource` and `TestAccRedisDataSource` pass checks 1–10 and 12 and fail checks 11 and 13 (`keyvalue/datasource/datasource_test.go:41` and `:57`): `^rediss://red-.*:.{32}@oregon-keyvalue\..*:637[7,9]$` and `^ REDISCLI_AUTH=.{32} valkey-cli --user red-.* -h oregon-keyvalue\..* -p 637[7,9] --tls$`. With bex's host swapped for `oregon-keyvalue.` both of bex's strings match, `--sni` included; nothing else differs.
- **Render.** Its cassettes answer `rediss://red-…:<password>@oregon-keyvalue.localhost.render.com:6377` and ` REDISCLI_AUTH=<password> valkey-cli --user red-… -h oregon-keyvalue.localhost.render.com -p 6377 --tls` (recorded against Render's test environment): one regional host and port for every store, routed by the username after TLS.
- **bex.** `rediss://red-…:<password>@red-….<BEX_KV_DOMAIN>:6379` and the same command with `--sni red-….<BEX_KV_DOMAIN>`: the shared edge (`bex-kv-sni-proxy`) selects the store by the TLS server name and passes TLS through to it ([ADR021 §3](../../docs/ADR021-keyvalue-management.md#3-end-to-end-public-tls)). Routing by username would mean terminating TLS at the edge and reading the client's `AUTH` or `HELLO` before choosing a backend.
- **The choice.** Either (a) serve Render's shape, a regional `<region>-keyvalue.<BEX_KV_DOMAIN>` host routed by username, as a milestone of its own that reworks the edge and keeps the per-store host working for existing clients; or (b) record the per-store SNI host as a divergence in ADR018's Key Value row, with the user's sign-off and the reason.
- **Done when:** the user's decision is recorded here and in ADR018's Key Value row; for (a), a milestone is filed, and when it ships both data source tests pass all 13 checks on a `dev-N` stack (`scripts/terraform-provider-verify.sh keyvalue redis`); for (b), the checklist's test assumption names the signed divergence.
