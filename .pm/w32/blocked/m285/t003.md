## Objective

Accept `snapshotId` and `snapshotName` (`--snapshot-id`, `--from`) on sandbox create: start the new sandbox from the snapshot image, inherit plan, network policy and timeouts unless overridden, do not carry env, and resolve a reused name to the most recent available snapshot.

## Context

- Today create refuses these by name with `SANDBOX_SNAPSHOTS_UNSUPPORTED` (`refuseUnsupportedCreateOptions`, `lego/backend/internal/sandbox/service.go`)
- Templates path ADR014 D2

## Steps

1. Remove the refusal for available snapshots; answer named 404/409 for missing, foreign, failed, creating or expired ones.
2. Start from the snapshot image with inherited settings.
3. Keep the snapshot for reuse.

## Acceptance criteria

- [ ] A file written before capture exists in a sandbox created `--from base`
- [ ] Two restores from one snapshot both work and the snapshot remains
- [ ] A foreign or expired snapshot answers a named error

## Out of scope

- Restoring running processes
