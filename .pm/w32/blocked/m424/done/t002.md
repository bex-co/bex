## Objective

A native Python service's default `GUNICORN_CMD_ARGS` becomes Render's `--preload --access-logfile - --bind=0.0.0.0:10000` in the image, and at runtime on a web or private service binds the serving port, unless the service or a linked group sets its own value.

## Context

- Render's Python default (render.com/docs/environment-variables, read 2026-11-16): `GUNICORN_CMD_ARGS=--preload --access-logfile - --bind=0.0.0.0:10000`. bex sets `--preload --access-logfile -` only (`lego/operator/internal/build/native.go:463`, w8/113).
- Gunicorn source (read 2026-11-16): the `Bind` default is `0.0.0.0:$PORT` when `PORT` is set, else `127.0.0.1:8000` (`gunicorn/config.py`); `Application.load_config` applies the config file, then `GUNICORN_CMD_ARGS`, then the command line (`gunicorn/app/base.py`). So on Render the env `--bind` overrides a `gunicorn.conf.py` bind, while a `-b` on the start command still wins. Without it, bex lets a config-file bind win and the service is then found only by port detection.
- Same precedent and yield rule as t001 (`ROCKET_PORT`, `web_concurrency.go:118-150`). A service's own value, including an explicit empty one, already wins over the image default (w8/113 sweep390).

## Steps

1. Change the Python image default to Render's literal value.
2. Add a runtime default for `runtime: python` web and private services that replaces the bind port with the serving port, only when `configuredEnv` finds no value.
3. Update the `native.go` comment.

**Done 2026-11-17:** the Python image default is Render's literal `GUNICORN_CMD_ARGS="--preload --access-logfile - --bind=0.0.0.0:10000"`, and a `runtime: python` web or private service's pod gets the same flags bound to its serving port (`servingPortDefault`), yielding to any service or group value, empty included. A real Gunicorn 23 with `gunicorn.conf.py` binding `0.0.0.0:8000` and a bare `gunicorn app:app` listens on 10000 by default, on the operator's serving-port value, on 8000 with the variable explicitly empty, and on a start command's `-b 0.0.0.0:7000` (`TestNativePythonImageGunicornBindsRendersPort`; 8000 before the change). The w8/113 access-log and w8/116 scheme gates still pass.
