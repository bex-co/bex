## Objective

Make sure the tests pin what this milestone shipped and fail when it regresses:

- each of Render's seven forms, byte for byte, at the writer that produces it;
- every line bex writes carries a form, and its visible text equals its plain words (one table-driven test per writer);
- the operator's readers of the build's output and the backend's `unmarked` work with the codes;
- each reader returns the codes, and the `text` filter behaves in both modes.

Prove the key tests are real: drop the styling and watch them fail.

## Acceptance criteria

- [ ] The tests above exist and pass, and each fails with the styling removed.

## Outcome

Done 2026-11-22. Each form is pinned byte for byte where it is written: `renderlog`'s `TestEachFormWritesRendersCapturedBytes` and `TestShellSpellingPrintsTheSameBytes` against the captures; the control plane's `TestEveryPlatformLineCarriesItsForm` (every line the narration writes across a deploy of each kind, with its form and unchanged words) and `TestRendersPlatformLinesByteForByte`; the build pod's `TestShellLinePrintsRendersBytes`, `TestAwkStringPrintsRendersBytes` and `TestOnlyNodesVersionLinesCarryRendersForm` plus the display, cache and push tests that now expect the bytes; native-init's tests through `running`; `TestUnmarkedReadsAColouredLineByItsWords`; the CLI's `TestLogsJSONAndYAMLCarryRendersCodes` and `TestLogsTextShowsRendersColours`; the text filter in `TestColouredLinesShowTheirWordsInEveryRead` and `TestRESTTextSearchFindsAColouredLineByItsWords`; the dashboard's forms, pane and copy tests. Mutations, each reverted after: `styled` returning the plain line failed 38 backend tests; dropping `unmarked`'s display read failed its test; plain `shellLine`/`awkString` and a plain native-init line failed 39 operator tests; a plain Node form failed 5; `ansi.ts` reading `ESC ( B` as two bytes failed 6 dashboard tests.
