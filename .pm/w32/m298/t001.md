## Objective

Add a Postgres `sandbox_executions` table (migration), and record a row at every run and file connect-token mint with the minted `exe-…` id: `sandboxId`, `type` (`runs`|`files`), `operation` (`sync`|`stream`|`upload`|`download`), `userId`, `startedAt`, and `command` (truncated) or the file path.

## Context

- Render schema: required `id, sandboxId, type, operation, userId, startedAt`; optional `command, stoppedAt, exitCode`; `startedAt` is the token provisioning time

## Files

- `lego/backend/internal/store/` (migration and queries)
- `lego/backend/internal/sandbox/service.go`

## Acceptance criteria

- [ ] A mint writes exactly one row with Render's required fields
- [ ] A failed mint writes none
