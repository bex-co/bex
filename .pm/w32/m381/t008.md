## Objective

Add meaningful tests for the shipped behavior:

- A disconnected command holds the sandbox awake until it ends, and the idle window then runs from its end.
- A finished command's background process does not hold it.
- The history record stays open, then carries the real exit code.
- The connected path, MCP buffered exec and the w32/m348 exec contract (`bash -c` in `$HOME`, exit code, stdout/stderr split) are unchanged.

Tests must assert real behavior and failure modes, not snapshot everything.

## Acceptance criteria

- [ ] Each behavior above has a test that fails if it regresses.
