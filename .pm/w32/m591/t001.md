## Objective

Extend `status.releaseRollout` so the operator records the earliest non-OOM exit (`finishedAt` and `exitCode`) of the release's app container while the rollout is running, giving bex-api the moment and status of run 1's exit without breaking the operator's database-free boundary.

## Context

- `ReleaseRolloutStatus` lives in `lego/types/v1alpha1/app_types.go:1887`. It already holds `Generation`, `StartedAt`, `AppStarts`, `Command`, `WebConcurrency` and `InstanceAnnounces`.
- `recordReleaseRollout` and `withAppStarts` live in `lego/operator/internal/controller/release_rollout.go:51-159`. `withAppStarts` already iterates current-revision, non-deleting pods and reads `appContainerName`'s `LastTerminationState.Terminated` and `State.Terminated`.
- OOM detection already exists in the operator (check `isOOMTerminated` / `OOMKilled` in `lego/operator/internal/controller/instance_exits.go` or `app_controller.go`) so an out-of-memory kill is excluded just as `rendersVerdict` excludes `OOMKilled`.
- `releaseRolloutRunning` (`release_rollout.go:101`) already gates collection so nothing is recorded once the release serves, fails, is canceled, or is replaced.

## Steps

1. Add a first-exit field to `ReleaseRolloutStatus` in `lego/types/v1alpha1/app_types.go` (e.g., `FirstExit *ReleaseRolloutExitStatus` with `FinishedAt metav1.Time` and `ExitCode int32`). Document its semantics (earliest non-OOM termination while the rollout ran; whole seconds as the kubelet reports; not overwritten by later restarts; replaced only with a newer release generation). Run `make manifests generate` in `lego/operator/`.
2. Add a pure helper beside `withAppStarts` in `lego/operator/internal/controller/release_rollout.go` (e.g., `withFirstAppExit`) and call it from `recordReleaseRollout` while `releaseRolloutRunning` is true.
   - Inspect `LastTerminationState.Terminated` and `State.Terminated` on `appContainerName` of current-revision, non-deleting pods.
   - Skip zero `FinishedAt` and skip OOM-killed terminations (`Reason == "OOMKilled"` / existing operator OOM helper).
   - Pick the earliest `FinishedAt` (if `recorded` is nil, or a pod reports an even earlier non-zero `FinishedAt`, take the earlier one; if `recorded` is already earlier or equal, return `recorded` unchanged so status is not rewritten needlessly).
3. Add unit tests in `lego/operator/internal/controller/release_rollout_test.go` and extend the rollout envtest.

## Acceptance criteria

- [ ] Unit tests cover: first non-OOM exit is recorded (both `LastTerminationState.Terminated` and `State.Terminated`), a later restart's exit does not overwrite it, an earlier termination seen out-of-order across pods wins, `OOMKilled` is ignored, pods of another revision or being deleted are ignored, and exit code `0` is preserved (not treated as absent).
- [ ] Envtest verifies that `status.releaseRollout.firstExit` is populated on a crashing rollout, stops updating once the rollout settles, and is cleared/replaced on a newer release generation.
- [ ] `make test` (from `lego/operator/`, with `-timeout 30m`) and `make lint` pass.
