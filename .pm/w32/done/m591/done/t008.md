## Objective

Verify that meaningful tests cover every new behavior and failure mode introduced by this milestone, with no gaps between operator, store/reconciler, narration and live tail.

## Steps

1. Audit coverage across:
   - Operator (`release_rollout_test.go` + envtest): first non-OOM exit capture, exit code `0`, OOM exclusion, earliest-wins, stop after settle, reset on new generation, non-matching revision / deleting pods ignored.
   - Store & reconciler (`deploy_rollout_test.go`, `deploy_rollout_pg_test.go`): real-Postgres persistence, earliest-wins while open, terminal immutability, exit code `0`, fast crash settling on the same pass.
   - Logs & live tail (`progress_test.go` and tail tests): legacy native (`InstanceAnnounces: false`) with 3 starts, new native (`InstanceAnnounces: true`), Dockerfile, prebuilt image, different exit code on run 1 vs run 3, nanosecond app output in same second, run 2 in same or next second, `update_in_progress` suppression, eventually-`live` deploy suppression, legacy row fallback, `OOMKilled` / `TimedOut` / `build_failed` / `pre_deploy_failed` / `canceled`, ANSI forms, live tail emission and `holdClosing`.
2. Add any missing behavioral test and verify it fails when the corresponding behavior is reverted.
3. Run `make test` (from `lego/operator/`), `cd lego/backend && go test ./...` (with real deps), and `make lint`.

## Acceptance criteria

- [ ] Every behavior and failure mode above has a passing behavioral test, and all affected suites + lint pass.

## Out of scope

- Snapshot-everything or tautological tests.
