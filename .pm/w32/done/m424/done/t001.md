## Objective

A native Ruby service gets Render's `PASSENGER_PORT`: `10000` in its image (build and any non-routed workload, as on Render), and at runtime on a web or private service the port the service is routed on, unless the service or a linked group sets its own value.

## Context

- Render's Ruby defaults (render.com/docs/environment-variables, read 2026-11-16) include `PASSENGER_PORT=10000`, build and runtime alike (w5/162 re-fetch).
- Passenger Standalone's `port` option: environment variable `PASSENGER_PORT`, default `3000` (phusionpassenger.com config reference for Standalone, read 2026-11-16); the reference does not say it reads `PORT`. Without the variable a Passenger app binds 3000, not the routed port.
- Precedent: `ROCKET_PORT` (w8/273), `lego/operator/internal/controller/web_concurrency.go:118-150`: the default follows the serving port, is added only when `configuredEnv` finds no service or group value (a container `env` entry beats every `envFrom` key), and is inserted just before `PORT` (`deployment_projection.go:181`, `:336`).
- The Ruby image defaults live in `nativeRuntimeDefaults`/`nativeBuildDefaults`, `lego/operator/internal/build/native.go:468-481`, whose comment records why `PASSENGER_PORT` was left out.

## Steps

1. Add `PASSENGER_PORT=10000` to the Ruby image defaults.
2. Add a `passengerPortDefault` beside `rocketPortDefault` for `runtime: ruby` web and private services, valued at the serving port.
3. Replace the `native.go` comment's reason with the shipped rule.

**Done 2026-11-17:** `nativeBuildDefaults` gives a native Ruby image `ENV PASSENGER_PORT="10000"` before the build `RUN` (build, worker, cron and pre-deploy see Render's value), from `build.NativeServingPortEnv`. The operator's `rocketPortDefault` became `servingPortDefault`/`withServingPortDefault` (`web_concurrency.go`): a `runtime: ruby` web or private service's pod gets `PASSENGER_PORT=<serving port>` just before `PORT`, unless a literal, its own secret-backed set or a linked group sets the name (an explicit empty value included). A real Passenger 6.1 `bundle exec passenger start` app listens on 10000 by default and on its own `PASSENGER_PORT` (`TestNativeRubyImagePassengerPort`; 3000 before the change). Focused envtest and unit tests pass; the full `make test`/`make lint` ran in t006.
