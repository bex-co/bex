## Result — 2026-11-17 (done)

- REST, GraphQL and MCP share `listFiltered`, `Get` and `Create`. `region`, `createdAt`, `name` and `terminatedAt` are on every surface, and so are the `status`, `name` and `sandboxGroupId` filters.
- Paging is REST-only by w10/m377's recorded choice: REST answers Render's first page of 20, and GraphQL and MCP return the whole list.
- `file_not_found` and the SSE keep-alive live on the REST connect path and its gateways. GraphQL has no file transfer, and MCP `sandbox_exec` collects its output.
- The behavior matches Render's pinned OpenAPI (the `sandbox` schema, `409SandboxConnectConflict`) and the SDK sources. ADR018 needed no change, and ADR104's D9 and gap 5 record the walk. Dashboard N/A.
