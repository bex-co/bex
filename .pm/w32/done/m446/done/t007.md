## Objective

Add tests that pin the behavior this milestone shipped, through the real auth middleware and, where it applies, real Postgres and OpenFGA.

## Context

- `lego/backend/internal/api/auth_test.go` and `tenancy_test.go` already fake the onboarder and the tenant store.
- The real-DB suite runs under `BEX_TEST_REQUIRE_DEPS=1` (`scripts/ship-gates.sh`).

## Steps

1. Test a `Check` error followed by success: the request is served and no write is sent.
2. Test an "already exists" grant answer: the request is served.
3. Test a transient cache-miss store fault for a returning caller (served) and for a first-ever caller (503 with a logged cause).
4. Test that a tombstoned account is refused while a stale tenant is held.

## Files

- `lego/backend/internal/api/tenancy_test.go`
- `lego/backend/internal/api/auth_test.go`

## Acceptance criteria

## Out of scope

## Result (2026-11-17, `/loopx w32`)

Each test was checked by reverting the code it pins, and each fails then:

1. **A Check error followed by success:** `TestOnboardingSendsNoWriteWhenAResetCheckIsResent` uses the production OpenFGA checker over a fake whose second Check resets its keep-alive connection. It sees 3 checks, 0 writes, and both requests served. Without the Check resend (`a77d36c92`) it sees 2 checks and 1 write.
2. **An "already exists" grant answer:** `TestOnboardingServesAnAdminWhoseCheckErrorsE2E` (real Postgres and OpenFGA) serves an admin whose Check errors. Without `on_duplicate` (`ef7e65cd3`) it fails with `workspace admin grant failed (authorization service): POST …/write returned 400`. The fake-granter version is `TestEnsureTenantServesAnAdminWhoseCheckErrors`.
3. **A cache-miss store fault:** `TestEnsureTenantServesARecentWorkspaceThroughAStoreFault` and `…ThroughAnOpenFGAFault` serve a returning caller. A first-ever caller gets `503 … personal workspace lookup failed (workspace store)`. With the fallback disabled, both serve tests fail. The logged cause is pinned at the gate: `TestGateNamesAndLogsAnOnboardingFault` (it fails without the log line or the named message) and `TestGateLogsAnAuthUpstreamFault`.
4. **A tombstone while a stale workspace is held:** `TestEnsureTenantTombstoneWinsOverARecentWorkspace`. `TestEnsureTenantDoesNotServeARecentWorkspaceThroughEveryFault` adds three cases: a failed re-read after a grant, an unreadable tombstone and `InvalidateTenant`.
5. **Introspection resent on a reset connection:** `TestIntrospectionSurvivesAResetReusedConnection` fails without `core.MarkReplayable` in `introspectUpstream`.
