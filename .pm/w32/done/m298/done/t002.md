## Objective

Set `stoppedAt`/`exitCode` when an exec stream ends (the exec gateway's `exit` event) and when a file transfer finishes. When the sandbox terminates, stop any execution still open.

## Files

- `lego/backend/internal/sshgateway/sandboxsse/`
- `lego/backend/internal/sshgateway/sandboxfiles/`
- `lego/backend/internal/sandbox/service.go`

## Acceptance criteria

- [ ] An exec that exits 3 records `exitCode: 3`
- [ ] A terminated sandbox has no open executions
