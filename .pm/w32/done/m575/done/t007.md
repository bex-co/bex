## Objective

Check that every surface that reads a service's log, or a deploy's, shows the instance's `==> Running '<command>'` the same way, once per start:

- REST `GET /v1/logs` (with and without `type=app`, and with `type=build`) and `GET /v1/logs/subscribe`;
- the GraphQL logs query;
- MCP `list_logs`;
- the dashboard's service Logs page and the deploy page's log pane (`dashboard/src/features/deploys/hooks/use-deploy-logs.ts`);

Compare each with Render's logs in the milestone README.
