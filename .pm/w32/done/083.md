# A web service's deploy log ends at `==> Your service is live 🎉`, where Render's follows it with the primary URL block

Why: Render parity in the deploy log. Render's live line is followed by the URL the service is reachable at, so a user reads where the deploy went live without leaving the log.

- **Severity / estimate:** minor, ~45m: one narration change in `closingLines` plus tests and the contract rows.
- **Seen:** w32/m560 t009, 2026-11-22. bex's `type=build` narration closes a live web service's deploy with `==> Your service is live 🎉` and nothing after it (`terminalLine`, `lego/backend/internal/logs/progress.go`).
- **Render reference (public issue logs):** after `==> Your service is live 🎉`, Render writes a block that frames the primary URL. It is a `==> ` line, a `==> ///…///` rule, a `==> ` line, `==> Available at your primary URL https://<service>.onrender.com`, a `==> ` line and the rule again (lelewithheart/Pixel-Breach#10, and about 20 more logs found by searching for `Available at your primary URL`). Copy the exact rule length and the blank lines from those issues before writing the lines.
- **Scope check:**
  - Decide which types get the block. Web services do. Check whether a private service, a background worker or a static site get it: a static site reads `==> Your site is live 🎉` (w32/081).
  - The URL is the service's primary one, `https://<slug>.onbex.co` on bex, or its primary custom domain if Render uses that (check).
  - It must be the deploy's own URL, recorded on the row, so an old deploy's log does not change when the service is renamed or gets a domain later.
- **Done when:** a live web deploy's log carries the block with the service's URL on REST, the subscribe stream, GraphQL and MCP. `docs/render-artifacts/live-deploy-following.md` § Platform progress-line contract and ADR018 § Logs, Build logs record the Render logs it comes from.

## Promoted to w32/m567 (2026-11-22)

Its scope check requires the deploy's own URL to be recorded on its row, which means a migration, the reconciler's live close and the store read, besides the narration. That is about 2h20m across three implementation tasks, plus the production walk and the closing tasks. Eighteen Render logs in public issues settled the open questions, and the milestone README records them:

- The block is six lines, with a rule of 59 slashes.
- The URL carries no trailing slash in API reads.
- A custom domain is the primary URL, with ` + N more domain(s)`.
- A static site's log has no block.
