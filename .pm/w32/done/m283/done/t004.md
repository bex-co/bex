## Objective

Prove the enforcement end to end with the pinned bex CLI, first on the local mock cluster and then on production after deploy.

## Context

- `scripts/mock-cluster.sh` and `scripts/dev-env.sh` are pre-approved (AGENTS.md)
- Sandbox routes need `BEX_OPENSANDBOX_URL` (dev-9 runs without it; see w9/067)

## Steps

1. Create one sandbox per policy and exec probes: public HTTPS, public non-HTTPS, a listed and an unlisted host, a subdomain against an exact rule, cluster DNS/service IP, node metadata, a private range.
2. Suspend and resume the allow-list sandbox and re-probe.
3. Record the results (no raw logs in git) in this task.
