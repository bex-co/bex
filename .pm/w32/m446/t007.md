## Objective

## Steps

1. Test a `Check` error followed by success: the request is served and no write is sent.
2. Test an "already exists" grant answer: the request is served.
3. Test a transient cache-miss store fault for a returning caller (served) and for a first-ever caller (503 with a logged cause).
4. Test that a tombstoned account is refused while a stale tenant is held.
