## Objective

Once a production pin carries t001–t003, walk the definition of done with the released `bex` CLI and a human device login against a new sandbox in `bex-canary`, then stop that sandbox.

## Steps

1. Upload `./src`, which holds a relative, an absolute, a dangling and a directory symlink, plus a plain file. Also upload a `python3 -m venv --without-pip` tree. Check with `bex sandboxes exec <sbx> -- ls -la`.
2. In the sandbox, build `dl/` with `top.txt`, `rel-link`, `abs-link -> /etc/hostname`, `dirlink -> sub` and a hard link `hard.txt`. Download it, then check `readlink` and the file contents locally.
3. Re-run the plain-tree control from 2026-11-13: spaces, CJK and emoji names, a hidden file, an empty directory, `0755` and `0444` files.
4. Mint one download ticket for a path the gateway must refuse before streaming, and fetch it once over HTTP/1.1 and once over HTTP/2. The cause must read the same in both, with no `409 file ticket already used`.
5. If w32/022 has shipped, also check `bex sandboxes cp <sbx>:. ./sandbox-home`.

## Acceptance criteria

- [ ] Every DoD bullet observed and recorded in the milestone README with the date, pin and sandbox ID.
- [ ] The sandbox is stopped and reads `terminated`.
