## Objective

Every new behavior and every remaining refusal has a test that fails without the change.

Cover these:

- symlink and hard-link entries in both directions;
- a skipped FIFO;
- a child under a symlink entry, and a hard link to an unseen or outside name, both refused;
- the pre-first-byte error answer;
- the non-replayed gateway hop.

Also run the backend suite and the CLI contract tests (`lego/cli` `TestPinnedSandbox*`).

## Acceptance criteria

- [ ] Each case above has a test, and a mutation spot-check shows at least the link and replay tests fail without the change.
- [ ] `cd lego/backend && go test ./...` and `cd lego/cli && go test ./...` pass.
