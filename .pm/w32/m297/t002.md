## Objective

Remove the env refusal. Accept `env` on REST `POST /v1/sandboxes`, as a GraphQL create input and as an MCP `spawn_sandbox` argument. An invalid name, a reserved name or an exceeded limit answers `400 SANDBOX_ENV_INVALID` naming the variable, never its value.

## Files

- `lego/backend/internal/sandbox/{rest,graphql,mcp,service}.go`

## Acceptance criteria

- [ ] `--env-var A=1 --env-var B=2` creates a sandbox
- [ ] A reserved name and an invalid name each return a named 400
- [ ] The snapshot refusal is unchanged
