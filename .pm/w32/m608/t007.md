## Objective

Ensure meaningful, non-tautological tests cover every behavior and failure mode in the definition of done, and prove the tests catch regressions by spot-checking reverts.

## Steps

1. Check every case in the milestone README's Definition of done against tests from t001 and t002, filling any gap:
   - repo A → repo B switch (unchanged message + `id`);
   - branch A → branch B switch with unresolved commit (unchanged message + `id`);
   - Git → prebuilt image switch (keeps `==> Build queued`, `==> Building from …`, `==> Deploying...`, and `id`s);
   - prebuilt image → Git switch (keeps `==> Deploy queued` / `==> Deploying image …`);
   - pre-migration fallback (`Repo == ""`, `Image == ""`);
   - image-override deploy on a repo-backed service;
   - real-Postgres persistence across `CreateApp`, `CreateDeploy`, `EnsureCheckedDeploy`, `promoteDeferredDeploy`, and `SetAppSource`;
   - REST, GraphQL, MCP, and subscribe-stream agreement;
   - public deploy JSON omits `repo`/`branch`.
2. Temporarily revert the store write and the `buildProgressLines` per-deploy lookup in turn and verify the corresponding tests fail, then restore.
3. Run `cd lego/backend && go test ./...` (with real deps) and `make lint`.
