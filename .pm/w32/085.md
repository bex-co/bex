# Capture Render's rollout lines for the deploys no public log shows: a worker, a private service, a prebuilt image, a rollback and a pre-deploy command

Why: w32/m560 had to assume what Render's deploy log says for these deploys. A capture settles each assumption, or turns it into a parity fix.

- **Severity / estimate:** minor, ~45m with a Render account: five free or cheap deploys and their logs.
- **Seen:** w32/m560, 2026-11-22. Thirty public Render logs fix the rollout lines for built web services, native and Docker, and none shows the cases below. bex's choice for each is recorded in `docs/render-artifacts/live-deploy-following.md` § The rollout and in ADR018 § Logs, Build logs.
- **What to capture on Render:**
  - **A background worker and a private service, both native.** bex assumes they read like a web service: `==> Deploying...`, then the `WEB_CONCURRENCY` line (private only, since Render gives a worker no default), then `==> Running '<command>'`, with no port scan.
  - **A prebuilt image** (Deploy an existing image). bex keeps `==> Deploying image <image>`, then the `WEB_CONCURRENCY` line. Qxad/openlist-for-PaaS#2 shows `==> Starting service...` before that line, but it may be a restart.
  - **A rollback, and a "Save and deploy" that reuses the build.** bex keeps `==> Deploying image <image>` and `==> Rolling out the current release`.
  - **A service with a pre-deploy command.** Where does its output sit against `==> Deploying...`? bex prints `==> Deploying...` after it, because the template is written once the step passes.
  - **The log `type` of each rollout line** in Render's API (`GET /v1/logs?type=build` against `type=app`), and whether Render's deploy log copies the instance's output (w32/084).
- **Gate:** a Render account. No Render credential exists in this checkout (checked for w32/039 on 2026-11-17). Like w32/039, this needs a `RENDER_API_KEY` in `.env`, or the user pastes the logs.
- **Done when:** each case's Render log is recorded in ADR018 § Logs, Build logs. Any line bex writes differently is fixed, or filed as its own item.
