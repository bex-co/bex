## Objective

Ship t002–t005 through `/ship`, then, once the production pin carries them, walk the definition of done in `bex-canary` with the released `bex`.

## Steps

1. Ship. Park the milestone with ``pin must carry `<sha>` `` until the pin carries the commits.
2. In `bex-canary`, create these free services, each built after the pin:
   - a native Node web service from `examples/hello-node` (start command `node main.js`);
   - a second one whose start command exits after the service went live, for example `timeout 90 node main.js`;
   - a Dockerfile web service;
   - a prebuilt-image web service (`docker.io/library/nginx:1.27-alpine`).
3. On the first service, read `bex logs -r <srv> -o json` and find `==> Running 'node main.js'` once per start, with `type=app`, the pod as `instance`, and a level. Check that the dashboard's deploy page and the CLI's type-less deploy tail show it once.
4. Leave the first service idle until it spins down. Wake it with a request, and find the line at the woken instance's start, on a live `bex logs -r <srv> --tail` and in the history. Restart it, and find the line again.
5. On the second service, find the line at each restart after the command exits.
6. On the Dockerfile and image services, find no `Running` line at any start.
7. Deploy a native service in `bex-canary` whose release runs a build from before the pin: one built while t002 waited for the pin, then redeployed with "Save and deploy" or rolled back to that build after it. Check that its deploy log keeps the narrated line, once. If no such build exists, record that, since t004's unit tests cover the case.
8. Delete every fixture by ID and confirm each with a 404.

## Acceptance criteria

- [ ] Every check above passes, and its evidence is written into this task: commands, service ids of the disposable fixtures, timestamps.
- [ ] Every fixture is deleted and returns 404.

## Out of scope

- A paid native background worker or private service: the web service covers native-init's line, and the worker's narration is w32/085's.
