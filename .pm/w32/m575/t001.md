## Objective

Decide, from Render's own logs, which commands a native instance names with `==> Running '<command>'` when it starts them, and whether a start writes anything else. The milestone README's evidence settles the start command (at a deploy, a crash, a free spin-up) and a pre-deploy step. A cron job run and a one-off job are still open, and so is the runtime version line Bun writes at each start.

## Context

- The README's § Render's line: tretta's capture, DerekSopok/EMS-Kahoot#3, Sherbivs/SensaiOS#2, Bubba898/luchadores-web#5, and w32/m572's pre-deploy logs.
- native-init runs a service's start command, a cron run and a one-off run as `bash -c`, and a pre-deploy step as `sh -c` (README § bex today).
- w32/085 holds the questions only a Render account can answer. Do not wait on it.

## Steps

1. Search public issues, PRs and committed log captures (`gh search issues`, `gh search code`) for a Render cron job run's log and a one-off job's log on a native runtime. Read each runtime from the repository's `render.yaml` at the commit, as w32/m572's t003 did.
2. Search for a start-time version line on Node, Python, Ruby, Go, Rust and Elixir instances, like Bun's `==> Using Bun version 1.3.4 (default)` and its docs line (luchadores-web#5).
3. Write the findings into the milestone README under § Render's line, each with its log.
4. Pick, for each launch (start command, pre-deploy step, cron run, one-off job), whether native-init writes the line:
   - Where a log settles it, follow the log.
   - Where none does, follow the pre-deploy evidence: Render's native launcher names whatever command it runs, so the launch announces.
   - The pre-deploy step's line is already written by w32/m572's narration. Choose which side writes it so it appears once. Keeping the narration's copy and having native-init stay quiet in the step's pod avoids depending on w32/092, since the CLI's live tail does not carry the step's own output yet.
5. File each version line that no runtime of bex writes at start as its own note with `/pm add w32`, unless it fits t002's hour.
