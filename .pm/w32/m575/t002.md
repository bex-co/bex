## Objective

native-init writes `==> Running '<command>'` and a newline to the container's stdout every time it starts a command that t001 settled as announced, after it links the secret files and before it starts the command. The command is quoted as configured. The line then reaches the service's log with the pod's own labels, because it is the container's own output.

## Context

- `lego/operator/cmd/native-init/main.go` (`run`, `start`); tests in `main_test.go`.
- Its arguments are `["/bin/bash", "-c", <command>]` for a start command, a cron run and a one-off run, and `["/bin/sh", "-c", <command>]` for a pre-deploy step. The third argument is the command as configured (README § bex today).
- A native image carries the native-init of the build that made it (`nativeEntrypoint`, `lego/operator/internal/build/nativeinit.go`), so the line reaches a service at its next build. t003 handles the images built before.
- Render writes the line before the command's own output, also when bash then fails to find the program (Unwrenchable/ATOMIC-FIZZ-CAPS-VAULT-77-WASTELAND-GPS#82: `Running 'Node.js'`, then bash's `command not found`).

## Steps

1. Read the command from the `<shell> -c <command>` argument shape. Write nothing for any other shape.
2. Write the line before `start`, as a single write so that it cannot interleave with the command's output.
3. For a launch t001 settles as quiet, pick a signal that native-init reads and the command never sees.
   - An environment variable on that launch's pod only, which native-init removes from the environment it passes on.
   - The signal must not change any service's Deployment template, so the operator upgrade rolls no service, and it must not appear in the user's `env` (w32/m425's default-environment capture).
   - The `bash`/`sh` difference between the launches is incidental: do not key on it.
4. Keep the line plain. w32/089 owns the colours, and its instance form (green `==>`, `tput sgr0` resets) applies to this line when it lands.
5. Run `cd lego/operator && make test` (`-timeout 30m`; the controller envtest takes 630–730 s on this host) and `make lint`, through Docker.

## Files

- `lego/operator/cmd/native-init/main.go`, `main_test.go`
- the launch site that carries the quiet signal (`lego/operator/internal/controller/app_controller.go`), if t001 makes one quiet

## Acceptance criteria

- [ ] A test runs native-init on a command that prints, and reads `==> Running '<command>'` first, exactly once, then the command's output.
- [ ] `$PORT` and other variables in the command appear unexpanded in the line.
- [ ] A launch t001 settles as quiet writes no line, and its command's environment has no extra variable.
- [ ] native-init's exit status, signal forwarding and secret-file links are unchanged (the existing tests pass).
