## Objective

A native Ruby service gets Render's `GEM_PATH=/opt/render/project/.gems` without losing the gems its Ruby ships.

## Context

- Render's Ruby default: `GEM_PATH=/opt/render/project/.gems` (render.com/docs/environment-variables, read 2026-11-16). bex leaves it out because "setting it drops RubyGems' default directory, hiding the gems Ruby ships (rake, minitest)" (`native.go:473-475`).
- Verified 2026-11-16: RubyGems' `Gem::PathSupport` sets `@home = GEM_HOME || Gem.default_dir` and, with `GEM_PATH` set, uses its entries plus home; a trailing separator appends the default paths. bex's Ruby bases are the docker-library `ruby:*-bookworm` images (`native.go:129-134`), which set `GEM_HOME=/usr/local/bundle`, so `GEM_PATH` alone drops Ruby's default dir there. Render's own Ruby has no such `GEM_HOME`, so on Render home is the default dir.
- Bundler installs under `BUNDLE_PATH=/opt/render/project/.gems` (`.../ruby/<abi>/`), so `bundle exec` is largely independent of `GEM_PATH`.

## Steps

1. In a native Ruby image, measure `Gem.path` and `require "rake"` / `require "minitest"` with and without `bundle exec`, and `gem install`, under: (a) Render's literal `GEM_PATH` alone; (b) Render's literal with `GEM_HOME` set to Ruby's `Gem.default_dir`, as Render's own Ruby has it; (c) `GEM_PATH=/opt/render/project/.gems:` (trailing separator).
2. Ship (a) if nothing breaks, else (b). Ship (c) only if both break, and record its one-character value difference in ADR018 as a divergence awaiting the user's sign-off.
3. Update the `native.go` comment with the measured result.
