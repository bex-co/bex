## Objective

The control plane copies t001's record onto the deploy row whose generation it names, and `logs.DeployProgress` carries it. The deploy log can then narrate a deploy's step long after the App's status has moved on to a newer release.

## Context

- The next migration after `0329_deploy_live_urls` (`0330` on `origin/main` at `c01e2f55c3`). Re-check `git ls-tree origin/main lego/backend/internal/store/migrations` after every rebase, since workers often pick the same number. It adds columns such as `pre_deploy_started_at`, `pre_deploy_container_started_at`, `pre_deploy_finished_at`, `pre_deploy_command`, `pre_deploy_native` and `pre_deploy_exit_code`.
- `store.Deploy`, `deployColumns` and the scan (`lego/backend/internal/store/store.go:3579`). The precedents are w32/m560's rollout columns (`SetDeployRollout`, migration `0327_deploy_rollout`) and `DeployEnd` (w8/m146).
- The reconciler already reads the step for the row's `pre_deploy_status` (`preDeployStatusAt`) and its facts (`preDeployLifecycleFacts`, `lego/backend/internal/store/reconciler.go:1579`). Copy the record only when its generation is the row's, and only while the row is open.
- The adapter: `lego/backend/internal/api/server.go:1023` builds `logs.DeployProgress`. Add fields such as `PreDeployStartedAt`, `PreDeployContainerStartedAt`, `PreDeployFinishedAt`, `PreDeployCommand`, `PreDeployNative` and `PreDeployExitCode`.

## Steps

1. Write the migration, the `Deploy` fields and the scan.
2. In the reconciler, stamp the row from `status.preDeploy` when the record's generation is the row's. Stamp the command, the launch and the start once. Stamp the container's start, the end and the exit code when they arrive.
3. Extend the adapter.

## Acceptance criteria

- [x] A real-database store test (`bash scripts/backend-test-deps.sh up && eval "$(bash scripts/backend-test-deps.sh env)"`) shows that:
  - a row is stamped once;
  - a stale generation's record never stamps a newer row;
  - a closed row is not stamped again;
  - a row with no step keeps NULLs.
- [x] `cd lego/backend && GOWORK=off go test -p 1 ./...` passes.

## Out of scope

- Any Render deploy field: the columns are `json:"-"`, like the rollout ones.
