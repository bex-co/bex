## Objective

A mint against a suspended sandbox currently waits for the resume, longer than the Python SDK's 5 s HTTP timeout. Start the resume and answer the mint at once; the gateway stream/transfer waits for the sandbox to be running (the 15 s SSE keep-alive covers an exec's wait).

## Files

- `lego/backend/internal/sandbox/service.go`
- `lego/backend/internal/sshgateway/sandboxsse/`
- `lego/backend/internal/sshgateway/sandboxfiles/`

## Acceptance criteria

- [ ] A mint against a suspended sandbox returns in under 1 s
- [ ] The exec or transfer that follows succeeds after the resume
