## Objective

Make a dead Web Shell edge loud: add a ticketless WebSocket handshake-shape probe for `wss://ssh.bex.co/shell` to the existing SSH-edge liveness synthetic, so the WS edge gets the same protection w6/m132 gave the TCP/22 edge.

## Context

- Carrier: `.github/workflows/ssh-edge-liveness.yml` runs `scripts/ssh-kexinit-probe.sh` on schedule (w6/m132 t004; shared with w6/m131/t004).
- The probe must distinguish **alive-but-refusing** (an unauthenticated upgrade gets the deterministic 401-shaped refusal — healthy) from **dead** (timeout, connection refused, TLS error, wrong route — alert). This is the m132 lesson: the banner looked alive while the protocol was dead.
- No ticket, no credentials: the probe stays unauthenticated and content-free.

## Steps

1. Add a WS probe (either a new `scripts/shell-ws-probe.sh` or an extension of the existing probe script) that performs the TLS + WS upgrade to `/shell` and classifies refusal-shape vs dead.
2. Wire it into `ssh-edge-liveness.yml` beside the KEXINIT probe; failure of either fails the run.
3. Prove it red once against a dead/absent edge (e.g. a wrong host/port), then green against production.

## Files

- `.github/workflows/ssh-edge-liveness.yml`
- `scripts/shell-ws-probe.sh` (new) or `scripts/ssh-kexinit-probe.sh` (extend)
