## Objective

Install (or verify) the shared `bex-shell-ticket` Secret for both the ssh-gateway and bex-api in production so the gateway's WebSocket shell listener starts, and confirm the checked-in `ssh-shell` IngressRoute + `bex-ssh-shell-tls` certificate serve `wss://ssh.bex.co/shell` from the public internet.

## Context

- The gateway's WS listener starts only when `BEX_SHELL_TICKET_SECRET` is present — sourced from Secret `bex-shell-ticket` (`lego/operator/config/ssh/deployment.yaml:93-101`; `BEX_SHELL_WS_ADDR` at :96).
- bex-api reads the **same** Secret (`lego/operator/config/api/deployment.yaml:437`) to mint tickets via `POST /v1/services/{id}/shell-ticket` — and also signs the 24h agent-session snapshotKey with it (`:489`), so if the Secret already exists, do **not** rotate it; only create it if absent.
- `lego/operator/config/ssh/ingress-shell.yaml` — IngressRoute `ssh-shell` routes `wss://ssh.bex.co/shell` → gateway Service port 8080, TLS from `bex-ssh-shell-tls`.
- `scripts/shell-ticket-secret.sh` — the install path for the Secret.
- m55 closeout (`.pm/w2/done/m55/README.md`) records exactly what production was missing.

## Steps

1. Check whether Secret `bex-shell-ticket` exists in prod (both namespaces/consumers as the manifests expect). If absent, run `scripts/shell-ticket-secret.sh`; if present, leave it (snapshotKey coupling above).
2. Confirm the gateway and bex-api pods see the env (roll them if the Secret is newly created) and the gateway log/metrics show the shell WS listener active.
3. Verify the IngressRoute and certificate: a public TLS connection to `ssh.bex.co` on the shell route completes with a valid cert, and an unauthenticated WS upgrade to `/shell` gets the deterministic refusal (401-shaped), not connection-refused/timeout.

## Files

- `scripts/shell-ticket-secret.sh` (run, not edit)
- `lego/operator/config/ssh/ingress-shell.yaml`, `lego/operator/config/ssh/deployment.yaml`, `lego/operator/config/api/deployment.yaml` (read/verify; edit only if a live-vs-manifest gap is found — record it)

## Acceptance criteria

- [ ] `wss://ssh.bex.co/shell` is reachable from the public internet with valid TLS; unauthenticated upgrade gets the refusal shape, not a dead connection
- [ ] Gateway shows the shell listener active; bex-api mints a ticket without error
- [ ] No secret value printed or committed anywhere
