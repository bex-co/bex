# Postgres REST `connectionPool` enum vs bex `pooler` bool

From **w2/m79**. Render OpenAPI create/PATCH/read expose `connectionPool: pgbouncer | none` (changelog 2026-07-01). bex already provisions PgBouncer via CRD/`CreateRequest` `pooler` bool + Blueprint `connectionPool`, and returns pooled connection strings when enabled (ADR018 Access-control/pooler row stays ✅ on mechanism). Gaps: REST responses omit the `connectionPool` string (conformance allowlist), and create/PATCH do not accept Render's enum. Align wire shape without changing the CNPG Pooler mechanism.
