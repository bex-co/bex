## Objective

Implement the t001 scheme in the operator's registry plane: an App carrying the `app.bex.co/workspace` label builds/pushes to the workspace-scoped Zot repository, gets a workspace-scoped htpasswd user + repo ACL + `reg-pull-*` Secret, and its Deployments reference the workspace-scoped image ref. An App without the label (legacy/hand-applied) keeps the bare-name path byte-identically, and running legacy Deployments keep pulling their old refs (dual-read: no re-keying of existing artifacts).

## Context

- `lego/operator/internal/build/build.go:394-406` — `Options.ImageRef()` / `KpackImageRef()` compute `<Registry>/<o.Name>:gen-N`; `Options` is populated in `lego/operator/internal/controller/app_controller.go` (which also holds `labelWorkspace = "app.bex.co/workspace"` at line 137).
- `lego/operator/internal/registry/creds.go` — `PullSecretName` ("reg-pull-"+appName, line 101), `ZotUsername` ("app-"+appName, line 104), `EnsureCreds`/`RevokeCreds`/`RotateCreds` all take `appName`; `ensureZotConfigEntry` writes the per-repo ACL into the `zot-config` Secret (`BEX_REGISTRY_NS`, `BEX_ZOT_CONFIG_SECRET`/`BEX_ZOT_HTPASSWD_SECRET`, wired in `lego/operator/cmd/manager/main.go`).
- `lego/operator/internal/registry/snapshot_creds.go` — snapshot-credential variant; check for the same name-keying.
- `lego/operator/internal/controller/build_registry_secret.go` — the `bld-<name>-registry-auth` build-ns mirror + `checkOwnedArtifact` guard (line 129); mirror naming should follow the new scheme for labeled Apps.
- Existing test surface to extend: `lego/operator/internal/registry/creds_test.go`, `lego/operator/internal/controller/registry_auth_test.go`, `per_app_registry_envtest_test.go`, `predeploy_pull_secret_test.go`, `publish_pull_secret_test.go`.
- `scripts/registry-secrets.sh` documents/refreshes the `bex-builder` + `app-<name>` htpasswd users — its preserve-operator-managed-users logic must recognize the new user format.

## Steps

1. Thread workspace identity (from the App's `app.bex.co/workspace` label) into `build.Options` and `registry.Creds` call sites; add scheme helpers (repo/user/secret names) in one place per t001.
2. Mint workspace-scoped repo/user/ACL/Secret for labeled Apps; keep the bare-name path for unlabeled Apps.
3. Keep `RevokeCreds`/finalizer purge working for both schemes (delete whichever the App actually used; full purge/retention alignment is t005).
4. Update `scripts/registry-secrets.sh`'s operator-managed-user preservation to match both user formats.
5. `make test` + `make lint` from `lego/operator/`.
