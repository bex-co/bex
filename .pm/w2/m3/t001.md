## Objective

Expose the opensandbox runtime's lifecycle as a first-class API: create / pause / resume / kill a sandbox, so agents get hosted execution environments.

## Context

- The opensandbox runtime already backs `BEX_RUNTIME=opensandbox` and has real pause/resume; endpoint at `BEX_OPENSANDBOX_URL` (`CLAUDE.md`).
- Keep the same one-Core discipline: a `Core`-style sandbox service so REST/MCP share one impl.

## Steps

1. Add a sandbox service wrapping the opensandbox client: `Create`/`Pause`/`Resume`/`Kill`/`Get`.
2. Expose a minimal REST surface (`/v1/sandboxes...`) returning sandbox id + state.

## Files

- `operator/internal/api/` (sandbox service) · `operator/internal/api/rest.go`

## Acceptance criteria

- [ ] Create a sandbox, pause it, resume it, kill it via the API; state transitions reflect the opensandbox runtime.

## Out of scope

- E2B-compatible shapes (t002), idle-hibernate (t003), MCP verb (t004).
