## Objective

Make `sleep = free` real for sandboxes: pause an idle sandbox so it occupies nothing (enabling overcommit), and resume it transparently on the next connection.

## Context

- Pillar 5: "idle sandboxes hibernated (sleep = free)" — same economic model as free-tier app scale-to-zero (w1/m4), applied to sandboxes via opensandbox's real pause.
- Idle = no active connection / no activity for a configurable window.

## Steps

1. Track per-sandbox last-activity; after the idle window, call `Pause`.
2. On a new connect to a paused sandbox, `Resume` first (wake-on-connect), then proceed.

## Files

- `operator/internal/api/` (sandbox service — idle tracker + wake path)

## Acceptance criteria

- [ ] An idle sandbox auto-pauses within the window (occupies nothing); the next connect resumes it transparently.

## Out of scope

- Cross-node rescheduling of resumed sandboxes; billing/usage metering.
