## Objective

GitHub #112 lists the hourly heartbeat and the deploy-latency and edge probes as late almost every day. Since the 2026-11-09 move to GitHub-hosted runners, GitHub creates far fewer scheduled runs than requested. Set each window from the measured gaps, so #112 again means "this watcher really stopped".

## Context

- `scripts/ci-schedule-drift.sh:61-65`: `ssh-edge-liveness.yml 12`, `alerting-heartbeat.yml 6` (comment: "no history yet"), `deploy-latency.yml 9`.
- Measured (scheduled runs that reached a verdict):

  - `deploy-latency`: every 3h, max 10.5h.
  - `ssh-edge-liveness`: every 6h, max 15.5h, 7 of 186 gaps over 12h.
- Runs start as soon as GitHub creates them and nearly all succeed: the probes are not failing or queued.
- `runner-link.yml` was deleted in `4630a48a7`, but #112 still lists it.
