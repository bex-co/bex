## Objective

Conduct a focused adversarial security review of all sandbox-group-credential code shipped in `w2/m532`–`m535` (control plane, OpenBao custody, internal `:8091` lookup, `ssh-gateway` TLS broker, Pod CA/proxy wiring, Cilium policies), record it in the next free security-review ADR (e.g. `docs/ADR<next>-security-review-sandbox-credentials.md`), and fix every exploitable finding inline with regression tests.

## Context

- Follow the format and rigor of `docs/ADR103-security-review-static-rewrite-proxy.md`, `docs/ADR117-security-review-api-key-roles.md`, and `docs/ADR118-security-review-scoped-api-keys.md`.
- Attack classes that MUST be audited and tested:
  1. Cross-sandbox-group and cross-workspace credential theft via Pod IP spoofing, Pod label tampering, or agent-session Pod calling the sandbox broker;
  2. SSRF and DNS rebinding via credential `domain` or `CONNECT` target (loopback, RFC1918, CGNAT, link-local/Hetzner metadata `169.254.169.254`, IPv6 ULA, cluster Pod/Service CIDRs);
  3. Cross-host HTTP 3xx redirect secret leakage;
  4. `Host`/SNI mismatch smuggling and HTTP request smuggling (`CL.TE` / `TE.CL` / multiple `Content-Length` / absolute-URI requests);
  5. Forbidden header injection (`Host`, `Transfer-Encoding`, `Content-Length`, `Proxy-Authorization`, hop-by-hop headers) and CRLF/header-injection through `${SECRET}` or `name`;
  6. `allow-list` bypass via brokered domain and `deny-all` bypass via broker port;
  7. OpenBao secret leakage via API/GraphQL/MCP responses, error messages, Postgres tables, audit logs, gateway logs, Prometheus labels, or sandbox snapshots;
  8. Privilege escalation: Developer attempting `domain`/`value` PATCH, create, delete, or restore; scoped API key with `KeySandboxesHistory` only attempting writes; revoked/narrowed API key or demoted Admin.
