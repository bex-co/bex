## Objective

Fix the contract bex will serve for Render's sandbox images and record the design, so t002–t005 build one agreed shape. Amend the ADRs that today forbid caller images.

## Context

- Render contract: `lego/backend/internal/api/openapi/render-public-api-1.json` paths `/sandbox-groups/{sandboxGroupId}/builds` (POST, GET) and `/sandbox-groups/{sandboxGroupId}/builds/{buildId}` (GET). Create takes `name`, `sourceImage` and an optional `registryCredential {username, password}`; it returns without waiting; a known name+digest returns the existing build; 400 `invalid_sandbox_group_id`; 409 `sandbox_group_suspended`; 429 at the pending-build limit.
- CLI v2.36: `render-oss/cli` `cmd/sandboximagesimport.go` (`--name`, `--wait`, `--group`, status `running` → `succeeded`/`failed`, failure reason), `cmd/sandboximagesget.go` (another group's image is not found), `cmd/sandboxcreate.go:207` (`--image` by id or name; a name is the group's newest succeeded image; `--build` alias). Module dir: `go list -m -f '{{.Dir}}' github.com/render-oss/cli` from `lego/cli`.
- bex: ADR014 D2 ("spawn from pre-registered templates"), ADR104 gap 13, `lego/backend/internal/sandbox/client.go:305` (`Client.Create` already takes an image URI), the sandbox snapshot registry (`SandboxSnapshotRegistryURL` / `SandboxSnapshotRegistrySecret` in `lego/backend/cmd/api/config.go`).
- Sandbox nodes are x86 (ADR042 D3), so only `linux/amd64` images can run.

## Steps

1. Read the response schema (fields, status enum, timestamps, failure reason) from the pinned OpenAPI and the CLI's client types. Record it in `docs/render-artifacts/sandbox-images.md`.
2. Decide and write down in ADR104: the `sbb-` id (minted with `id.New`), the image's home (a per-group repository under the snapshot registry), the platform rule, the size cap, the pending-build limit per group, and storage accounting (recommendation: no separate charge; count in the workspace sandbox-storage gauge; cap images per group).
3. Amend ADR014 D2: sandboxes start from a registered template or from an image imported into the caller's group. Mark ADR104 gap 13 as scheduled by w2/m358.
4. Note what bex answers for `sandbox_group_suspended` when bex has no suspended groups (never emitted, documented).
