## Objective

Ensure deleting an account also deletes every durable way that account can continue acting.

## Steps

1. Delete Hydra API-key clients stamped with the subject and unbind their `tenant_members`/OpenFGA tuples; revoke subject OAuth consent/session chains and invalidate bex auth caches.
2. Revoke SSH keys, active attach/shell access, device/web-push subscriptions, and pending GitHub connect transactions.
3. Extend the Kratos admin client with bounded delete-sessions and delete-identity methods.
4. Execute identity/session deletion only after the recoverable control-plane work is complete; define idempotent handling for already-absent external objects.
5. Scrub secrets from errors, logs, and audit metadata.

## Files

- `lego/backend/internal/accounts/`
- `lego/backend/internal/{apikeys,cliauth,sshkeys,sshgateway,notifications,workspaces}/`
- `lego/backend/internal/workspaces/kratos.go` or a shared Kratos admin client

## Acceptance criteria

- [ ] Subject-created Hydra API keys stop authenticating and lose workspace bindings.
- [ ] Ory browser sessions and the Kratos identity are gone at terminal success.
- [ ] Active/future SSH and push access cannot survive deletion.
- [ ] Missing/already-revoked external objects are idempotent success; real upstream failures remain retryable.
- [ ] No credential or identity trait is logged.

## Out of scope

- Deleting audit events whose retention policy says to keep them.
