## Objective

Prove the destructive workflow is fail-closed, retry-safe, and complete across stores.

## Steps

1. Add real-Postgres coverage for subject cleanup, retained rows, personal-workspace cascades, and shared/last-admin/owner blockers.
2. Inject failure at each OpenFGA/Hydra/Kratos/purger boundary, retry, and prove convergence without double deletion or orphaning.
3. Assert human-only mutation authorization and zero side effects for machine/delegated callers.
4. Test the Settings dialog, blockers, exact confirmation, duplicate submit, error retry, success logout, and both responsive skeleton geometries.
5. Run backend tests/lint and dashboard typecheck/lint/tests.

## Acceptance criteria

- [ ] Every external boundary has a failure-and-retry test.
- [ ] Last-admin and owner-anchor race cases fail before mutation.
- [ ] Deleted credentials cannot authenticate in an end-to-end auth test.
- [ ] UI tests cover blockers, success cleanup, and pending/ready shape.
- [ ] All affected CI gates pass.

## Out of scope

- Production deletion of a real user during automated tests.
