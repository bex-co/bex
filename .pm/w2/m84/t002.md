## Objective

Implement the control-plane half of account deletion so retries converge and no workspace is silently orphaned.

## Steps

1. Add an account-lifecycle service rather than hiding cross-domain deletion inside `workspaces` or the GraphQL resolver.
2. Preflight every blocker before the first destructive write and return stable typed blocker details.
3. Reuse `workspaces.Service.Delete` for an eligible sole-user personal workspace; remove the subject from safe shared memberships while revoking the matching OpenFGA role tuples.
4. Clean subject-scoped store rows according to t001, preserving explicitly retained audit/history rows.
5. Make each step idempotent and choose/persist enough progress for an interrupted request to converge without an authenticated subject having to reconstruct lost state.

## Files

- `lego/backend/internal/accounts/` (new)
- `lego/backend/internal/store/`
- `lego/backend/internal/{workspaces,members}/`
- `lego/backend/cmd/api/main.go`

## Acceptance criteria

- [ ] Preflight makes no changes when any workspace blocker exists.
- [ ] Safe membership removal revokes store and OpenFGA state without a last-admin race.
- [ ] Sole-user personal workspace cleanup rides the established resource/Stripe/purger path.
- [ ] Repeating after failure is safe and converges to the same result.
- [ ] A surviving tenant never retains a deleted `owner_identity_id` anchor.
