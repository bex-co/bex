# Build Sources follow-ups from the w2/m254 parity pass

Why: m254 serves Render's Build Sources on every surface; these are the small gaps its reviews and the parity pass left, each well under an hour.

- **dryRun on linking:** GraphQL `linkBuildSource` and MCP `link_service_to_build_source` hardcode `dryRun: false`, while REST PATCH accepts `?dryRun` (`lego/backend/internal/apps/build_sources_graphql.go`).
- **Picker cap:** the dashboard's Update Source picker lists the first 100 build sources (`dashboard/src/features/services/api/build-sources.graphql`); add paging or search for larger workspaces.
- **Deploy card:** a service linked to a native build source shows the image Deploy card in Settings, because its own repo is empty (`routes/services.$serviceId.settings.tsx`).
- **Linked cron jobs:** a cron job linked to a native build source runs its command through the explicit-command shell path (`cronPodSpec`), not native-init plus bash like a linked web service (t017).
- **Fan-out provenance:** fan-out deploy rows carry `buildId` but no commit message or image. Render's deploy object for a build-source deploy shows the build's commit.
- **Dashboard create page:** build sources are created over the API or MCP only. Check whether Render's dashboard has a create page, and match it.
