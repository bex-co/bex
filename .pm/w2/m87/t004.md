## Objective

Wire detection into the New Service wizard: when the user picks a repo (or changes branch/Root Directory), fire the detection query and pre-select the returned runtime — unless the user has already made an explicit runtime choice, which is never overwritten. Detection failure or `null` leaves the selection exactly as it is today.

## Context

- Form/state: `dashboard/src/features/services/hooks/use-new-service-form.ts`; page `dashboard/src/routes/services.new.tsx`; picker `service-source-picker.tsx` (avoid editing the picker itself — open `w8/m31` is working in it; consume its selection from the form layer).
- Track "user explicitly chose" as dirty-state on the runtime field (set on user interaction, not on programmatic pre-select).
- Debounce Root Directory keystrokes before querying; cancel stale in-flight results (Apollo `fetchPolicy`/abort idioms already used in the codebase).
- i18n: any new visible copy (e.g. a subtle "detected from go.mod" hint, if added) goes through `locales/en.ts` + `zh.ts`. A hint is optional — silent pre-select is the Render-shaped baseline.

## Steps

1. Add the detection query hook (codegen) and call it on repo/branch/rootDir changes.
2. Apply the result to the runtime field only while the field is pristine.
3. Handle loading/failed as no-ops; never block or flash the wizard.
4. Component tests: pre-select on pick, re-infer on rootDir change, no clobber after manual choice, silent failure.
