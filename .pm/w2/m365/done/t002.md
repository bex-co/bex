## Objective

Delete-then-create answers 201 at once whatever the old teardown takes.

## Done

- `appObjectName` (no I/O): `CRName(tenant, name)`, or, while a deleting App holds it, `CRName-<4 chars>` (`store.NewNameSuffix`, shared with Blueprint resource suffixes). Create reuses the one name probe it already makes; the Blueprint stack write probes the holder itself.
- Storage meeting a just-deleted name (a race with the probe) retries once under a fresh object name (`errNameReleasing`), else the ordinary `CONFLICT "already in use"`.
- A live holder still refuses: two live services never share a name. `nameHolder` yields a deleting holder to its live suffixed successor, so a second create beside the teardown is refused too, store off included (`TestASecondCreateBesideTheTeardownIsNameInUse`).
- Unbound (store off), a suffixed App carries `LabelServiceName` so it still answers to its public name.
