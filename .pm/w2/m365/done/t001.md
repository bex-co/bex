## Objective

Every reader of a service's App object name reads the recorded name, falling back to `CRName(tenant, name)` for rows written before the column existed.

## Done

- `store.App.ObjectName` + `AppObjectName()`; migration `0244_apps_object_name` (nullable `text`); `appColumns`/`scanApp`/`ListDesiredApps` scan it; `CreateApp` writes it only for a suffixed App (NULL means CRName).
- Callers moved to `AppObjectName()`: the projector's App name and pull-secret name (`store/reconciler.go`), the build-source fan-out (`deploys/build_sources.go`), the usage pod fallback (`usage/service.go`).
