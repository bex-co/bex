## Objective

The re-created service never races its predecessor's Ingress host or `<slug>` Service.

## Done

- `CreateApp`: a row with an `ObjectName` (a suffixed App) mints `<name>-<4 chars>` as its slug (Render never reuses an `onrender.com` subdomain either), so the old App's Ingress and slug Service keep theirs until collected.
- Registry repo, static S3 prefix (`PurgePrefixes` end in `/`), Zot user and build artifacts follow the App object name and are UID-gated on deletion, so the two never share or purge each other's.
