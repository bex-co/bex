## Objective

Make the issuer reachable on the public internet at `https://oidc.bex.co`, with the base URL configurable for self-hosted installations.

## Context

- Existing public hosts (`api.bex.co`, `dashboard.bex.co`, `oauth.bex.co`) are routed by Traefik in `deploy/gitops/`.
- Never touch `BEX_BASE_DOMAIN` (`.pm/DO_NOT_DO.md` #PSL).

## Steps

1. Add the DNS record, certificate and Traefik route.
2. Add `BEX_OIDC_ISSUER_BASE_URL` (or the ADR's name) to bex-api config, `lego/backend/AGENTS.md`, and the gitops values; keep the feature off when it is unset.
3. Run `scripts/gitops-validate.sh`.

## Files

- `deploy/gitops/` (route, certificate, bex-api env)
- `lego/backend/AGENTS.md`
- DNS (Terraform or the documented provider path)

## Progress (2026-11-18)

Implemented and shipped in `68b45459b`; only the live acceptance waits for the production pin.

- **DNS:** nothing to add. The proxied `*.bex.co` wildcard already sends `oidc.bex.co` through Cloudflare to Traefik (2026-11-18: `oidc.bex.co` resolved to Cloudflare and answered Traefik's `404 page not found`, as `api.bex.co`'s unknown paths do).
- **TLS and route:** `lego/operator/config/api/ingress-oidc.yaml` (Ingress `bex-api-oidc`, cert-manager `letsencrypt-prod`, Secret `bex-oidc-tls`, host `oidc.bex.co` to bex-api's port 80), in `config/api/kustomization.yaml`.
- **Config:** `BEX_OIDC_ISSUER_URL=https://oidc.bex.co` in `config/api/deployment.yaml`; `http://oidc.localhost:<port>` on dev-N (`scripts/dev-env.sh`); documented in `lego/backend/AGENTS.md`. Unset, the issuer is off. Startup refuses an origin with a path, the API's own host, or no `BEX_CP_DB_URI`.
- `bash scripts/gitops-validate.sh` passes (`PASS: gitops tree renders`).
- **Left:** `curl https://oidc.bex.co/<tea>/.well-known/openid-configuration` answering 200 with a valid public certificate, once a production pin carries `68b45459b`.
