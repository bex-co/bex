## Objective

Prove on production that a bex-minted token verifies with an independent OIDC library given only the issuer URL, and that the discovery shape matches Render's live document.

## Context

- Render's live document: `https://oidc.render.com/tea-c0000000000000000000/.well-known/openid-configuration`.

## Steps

1. Add `scripts/oidc-issuer-verify.sh`: mint a token for a QA workspace (a test-only path or a one-off command, never a public mint endpoint), verify it through `https://oidc.bex.co/<tea>` discovery with an independent library, and diff discovery keys against Render's live document.
2. Record the run (command, pin, result) in this milestone's README.

## Files

- `scripts/oidc-issuer-verify.sh` (new)

## Progress (2026-11-18)

`scripts/oidc-issuer-verify.sh` (+ `scripts/oidc-issuer-verify.test.sh` in `scripts (test)`) and the verifier `lego/backend/cmd/oidc-verify` (go-oidc v3.17.0 + go-jose v4.1.4) shipped in `68b45459b`. The token comes from `/api oidc-test-token`, an operator command inside the bex-api pod with the fixed audience `bex-oidc-verify`, never a public mint endpoint.

**Rehearsed on dev-2, 2026-11-18 02:00 PST:** with a `kubectl` stand-in that runs the same command on dev-2's bex-api binary, `OIDC_ISSUER_BASE=http://oidc.localhost:54020 bash scripts/oidc-issuer-verify.sh tea-daif693dqjvc73e7as3g srv-dbkq3hdhhjfs73eiahe0` passed all nine checks against Render's live documents: the token verified through its workspace's issuer alone (two published keys, RFC 7638 kids), `tea-c0000000000000000000`'s issuer refused it ("id token issued by a different provider"), status, `Content-Type` and `Cache-Control` equal Render's, discovery has Render's fields in Render's order, the JWKS has Render's members, and the four refusal paths answer Go's 404.
