## Objective

The Charges tree shows a deleted resource by its retained name with a translated "(deleted)" marker, and shows a bare id only when no name was ever recorded.

## Context

- The usage GraphQL fragment in `dashboard/src/features/usage/` must add the `deleted` field from t002; regenerate codegen per `dashboard/CLAUDE.md`.
- Plural/locale rules: add `en` and `zh` keys together.

## Steps

1. Extend the usage query/fragment with the new field and run codegen.
2. Render `<name>` plus a muted `(deleted)` suffix when `deleted` is true; keep the id available on hover/copy.
3. Keep the id fallback for rows with empty `serviceName`.
4. Component test: a deleted row shows the name and marker; a live row shows the name only; a nameless row shows the id.
