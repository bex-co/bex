## Objective

`--group`/`--sandbox-group` (`sandboxGroupId`) and `--image` (`buildId`/`buildName`) get a generic `unknown field` 400 on create; `sandboxGroupId` on list is silently ignored; `sandbox-groups create` and `images import|get` 404 generically. Sandbox groups are an ADR018 omission, so each should name it.

## Acceptance criteria

- [ ] Each case answers a 400/404 naming sandbox groups or images as unsupported; a list with `sandboxGroupId` never returns unfiltered results.
