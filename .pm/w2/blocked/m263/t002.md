## Objective

Since CLI v2.34.0, `--timeout=0` means no timeout (omitting it means 24 h). bex maps 0 to the 86400 s cap (w5/m99), which ADR018 does not record. Match Render, or record the divergence with sign-off if a no-timeout sandbox conflicts with a resource guard.

## Acceptance criteria

- [ ] A sandbox created with timeout 0 has no expiry (or ADR018 records the signed-off divergence); omitting the timeout still gives 24 h.
