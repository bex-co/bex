## Objective

Every forum hostname is a verified bex custom domain on the App t003 assigned, served by bex-created routing and certificates; the hand-made objects are then removed with no gap in service.

## Context

- t003's hostname → App table; bex custom domains (`docs/ADR005-custom-domain.md`, Render-identical setup since `w5/m137`).

## Steps

1. Add each hostname as a custom domain through the dashboard/API/CLI as a tenant; complete the DNS verification bex asks for.
2. Wait for bex's certificate and route; verify each host serves the forum (HTTP 200 on `/forum`, 301 on `/`).
3. Delete the hand-made Ingresses and Middleware; re-verify every host.
4. Anything bex cannot express → file a gap, do not patch around it.
