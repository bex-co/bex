## Objective

Provide cert-manager a production DNS token without putting it in Git or widening its Cloudflare authority.

## Steps

1. Define `BEX_ONBEX_DNS_API_TOKEN` in `.env.example` and `scripts/gh-secrets.sh` using the existing secret inventory pattern.
2. Require a Cloudflare API token restricted to DNS edit/read for the `onbex.co` zone only.
3. In the protected deploy job, create/update the namespaced cert-manager Secret by stdin after kubeconfig is available; never echo the value.
4. Make absence fail before Argo applies a permanently unready Certificate and document rotation.

## Acceptance criteria

- [ ] Token value is absent from Git, command arguments, and logs.
- [ ] `.env.example`, `.env`, secret uploader, and workflow names stay in sync.
- [ ] Secret is limited to the issuer namespace and token authority is zone-scoped.
- [ ] Missing token fails with an actionable message before rollout.

## Out of scope

- Replacing existing operator-managed Cloudflare DNS credentials.
