## Objective

Issue and renew a publicly trusted wildcard certificate using ACME DNS-01.

## Steps

1. Add a production-only namespaced ACME Issuer using Cloudflare DNS-01 and the t001 Secret.
2. Add a Certificate for `*.onbex.co` (and apex only if an explicit consumer needs it) with its private-key Secret in `traefik`.
3. Order the Argo application after cert-manager CRDs/controller and before relying on the TLSStore.
4. Preserve existing HTTP-01 issuers for per-App/custom-domain certificates.

## Files

- `deploy/gitops/charts/onbex-default-tls/` (new)
- `deploy/gitops/overlays/prod/`

## Acceptance criteria

- [ ] Certificate reaches Ready and covers `*.onbex.co`.
- [ ] Renewal is cert-manager-owned and existing alerts select it.
- [ ] Existing HTTP-01 issuers/certificates are unchanged.
- [ ] Local/mock overlays do not require production DNS credentials.

## Out of scope

- A wildcard for arbitrary custom domains.
