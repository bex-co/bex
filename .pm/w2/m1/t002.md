## Objective

Belt-and-suspenders for config propagation: when the operator starts (or its config changes), requeue every App so controller-level settings (base domain, default tier, cluster issuer) reconcile without waiting for a spec bump.

## Context

- `operator/internal/controller/app_controller.go` + `SetupWithManager`.
- Options: an initial full-list requeue on startup, or watch the manager config / diff actual-vs-desired Ingress annotations and act on drift.

## Steps

1. On manager start, list all Apps and enqueue them.
2. (Optional) detect drift between desired and live Ingress annotations and requeue on change.

## Files

- `operator/internal/controller/app_controller.go`

## Acceptance criteria

- [ ] Restarting the operator visibly re-reconciles all Apps (logs/events), not only changed ones.

## Out of scope

- The idempotent-apply fix itself (t001).
