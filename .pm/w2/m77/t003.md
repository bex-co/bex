## Objective

A real prod agent session, left idle after completion, transitions to phase `hibernated` with its snapshot object present under the workspace prefix and its sandbox pod reclaimed.

## Context

The m68 Completer reclaim seam turns idle (per ADR059 D2: `idle = now − max(last turn end, last editor SSH disconnect)`, open Zed pins idle at zero) into snapshot → `hibernated`, falling back to Terminate on any failure — so a failed hibernate looks like the old behavior and must be distinguished by logs. Default idle grace is `BEX_AGENT_SANDBOX_IDLE_TTL=30m`; for a faster walk, lower it on a canary rather than waiting, then restore.

## Steps

1. Run a small agent session to completion in prod (any workspace you control).
2. Either wait out the 30m grace or temporarily lower `BEX_AGENT_SANDBOX_IDLE_TTL` (env change + rollout) for the walk; note whichever was done for the evidence file. Ensure no editor SSH session is open (it pins idle at zero).
3. After the grace elapses, verify: session phase is `hibernated` (REST/GraphQL/dashboard chip), the snapshot object exists at `agent-snapshots/<ws>/…` in the bucket (scoped-credential list, or provider console), and the `<ws>-sandbox` pod is gone (`kubectl get pods -n <ws>-sandbox`).
4. Capture the Completer's hibernate log lines and the object key/size/timestamp; confirm the object is SSE-encrypted (provider metadata).
5. If the Completer fell back to Terminate instead, capture the failure log — that is a t007 regression-test input, and the walk repeats after the fix.
6. If the TTL was lowered, restore it.

## Files

- No repo files expected; raw captures staged for `.pm/w2/m77/evidence/` (t005).
- Possibly `lego/operator/config/api/deployment.yaml` (temporary TTL, restored).

## Acceptance criteria

- Phase `hibernated` observed on the API surface; snapshot object present under the workspace prefix; pod reclaimed.
- Hibernate logs + object metadata captured; SSE confirmed on the object.
- Any fallback-to-Terminate failure is captured and routed to t007, not papered over.

## Out of scope

Rehydrate (t004); retention-sweep observation (7-day horizon — noted for a later check, not blocking); pin/unpin exercise (shipped + tested in m68).
