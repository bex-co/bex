## Objective

Production bex-api starts with the full `BEX_AGENT_SNAPSHOT_S3_*` contract and logs `bex-api: agent-session hibernation enabled (object store <bucket>)`; the retention + pin-quota defaults are reviewed and either kept or explicitly set.

## Context

The composition root (`lego/backend/cmd/api/main.go` ~1047–1060) enables the tier only when endpoint+bucket+access+secret are all set; any unset ⇒ silent Terminate-only (byte-identical to w2/m67). **Repo fact:** bex-api's env lives in `lego/operator/config/api/deployment.yaml` — not `deploy/gitops/` (that tree has only bex-api RBAC/admission). Secret material stays out of git: follow the `bex-stripe` pattern — an out-of-band secret script (cf. `scripts/stripe-billing-secret.sh`) creating a `bex-agent-snapshot` Secret, referenced via `secretKeyRef` with `optional: true` so clusters without the contract keep the tier off.

## Steps

1. Add the six env entries to `lego/operator/config/api/deployment.yaml`: non-secret values (endpoint/bucket/region/prefix) inline or from the Secret; access/secret keys via `secretKeyRef` (`optional: true`), with a comment naming ADR059 D3 and the unset⇒off semantics.
2. Add an out-of-band secret script (e.g. `scripts/agent-snapshot-secret.sh`, modeled on `stripe-billing-secret.sh`) that materializes the Secret from `.env`; run it against prod (kubectl context `hetzner-prod`).
3. Review `BEX_AGENT_SNAPSHOT_RETENTION` (default 168h, dirty-git doubling) and `BEX_AGENT_MAX_PINNED_SANDBOXES_PER_WORKSPACE` (default 10) — keep defaults unless there is a reason; record the decision.
4. Deploy (normal image/deploy flow), then confirm the arm log line in the bex-api pod logs and that startup is otherwise clean.
5. Document rollback inline in the manifest comment: delete/unset the Secret keys ⇒ reclaim reverts to Terminate.

## Files

- `lego/operator/config/api/deployment.yaml`
- `scripts/agent-snapshot-secret.sh` (new, out-of-band; no secret material in git)

## Acceptance criteria

- Prod bex-api logs `agent-session hibernation enabled (object store <bucket>)` on startup.
- Secret exists in prod, never committed or printed; manifest references it `optional: true`.
- Retention/pin-quota decision recorded (defaults kept or values set + why).
- Rollback path documented.

The live hibernate/rehydrate walks (t003/t004); Completer semantics changes; partial-config validation hardening (t007).
