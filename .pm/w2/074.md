# 074 — Blueprint Sync History repeats the reconnection note on every row

Why: on production (2026-11-08) one Blueprint's Sync History showed "re-established a previously disconnected connection… earlier sync history below belongs to that connection" on several rows, including 7-day-old ones, so a customer cannot tell where the reconnection happened. w2/m256 t013 meant it to mark the boundary once.

- **Fix:** show the note only on the first sync row of each reconnection, the boundary between connections. Check whether the API stamps the note on every later row or the dashboard repeats it.
- **Acceptance:** a Blueprint reconnected twice shows exactly two boundary notes; dashboard test (and an API test if the note is stored per row).
- **Render parity:** UI.
