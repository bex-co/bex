## Objective

Register 7 bex-extension MCP tools for sandbox group credentials on `/mcp` with accurate read-only/destructive hints, per-call `workspaceId`, write-only secret handling, scoped-key registration, and updated `TestMCPParityInventory` and `ADR018` MCP tool counts.

## Context

- Render's official MCP server (`render-oss/render-mcp-server`) ships no sandbox-group-credential tools, matching how sandbox groups (`w22/m311`, `w2/m359`) and sandbox snapshots (`w32/m285`) are registered as `Extension` tools in `lego/backend/internal/sandbox/mcp.go` and pinned in `TestMCPParityInventory`.
- `TestMCPToolsNeverCallBexRender` enforces that tool descriptions never mislabel the caller's workspace/resources as Render's.

## Steps

1. Add the 7 tools in `lego/backend/internal/sandbox/credentials_surfaces.go` / `mcp.go`: `list_sandbox_group_credentials`, `get_sandbox_group_credential`, `list_sandbox_group_credential_versions`, `create_sandbox_group_credential`, `update_sandbox_group_credential`, `delete_sandbox_group_credential`, and `restore_sandbox_group_credential`.
2. Annotate read-only vs write/destructive tool hints, wire per-call `workspaceId`, and register all 7 MCP tools in `lego/backend/internal/api/key_permission_ops.go` (`KeySandboxesHistory` / `KeySandboxesCredentials`) and OAuth scope maps.
3. Update `TestMCPParityInventory` and `docs/ADR018-render-parity.md`'s MCP extension tool count.
