## Objective

Make successful Environment Group mutations converge visibly and truthfully: a deleted group must disappear from list/cache before the detail route finishes navigating, and rollout notices must only claim redeploys when linked services were affected.

## Context

- `env-groups_.$groupId.tsx` passes `skipDeleteRefetch: true`; live testing twice left the deleted card visible for more than seven seconds/until reload.
- A generated value saved on an unlinked group showed “Linked services are redeploying,” even though `serviceLinks` was empty.
- Refetch failure is currently best-effort, so a successful mutation must not be relabeled as failed; deterministic Apollo eviction/update is the primary path.

## Steps

1. Remove the skip-delete stale-state path and update/evict the group from every relevant Apollo list/detail entry on mutation success.
2. Sequence cache convergence and navigation so Back cannot resurrect the deleted card or deleted detail object.
3. Preserve correct success semantics if a follow-up network refetch fails after server deletion.
4. Centralize mutation notice construction around the returned/current linked-service count; omit deployment copy for unlinked writes and preserve it for linked content/link changes.
5. Add fake-timer/router/cache regressions for delete from detail, delete from list, Back navigation, and linked/unlinked notices.

## Acceptance criteria

- [ ] After a successful delete, the list has no matching card/row immediately and a reload agrees.
- [ ] Browser Back cannot render the deleted detail from normalized cache.
- [ ] A failed best-effort refetch does not show a false delete failure or restore stale data.
- [ ] Unlinked content changes have no “services are redeploying” description; linked writes report rollout only when the server accepted an operation that affects links.
- [ ] The exact `skipDeleteRefetch` regression is locked by a route-level test.

## Out of scope

- Redesigning global toast infrastructure.
- Optimistic deletion before the server confirms success.
