## Objective

Make the populated Environment Groups index as operable as Render's: live name search, a clear no-match/reset state, and responsive columns for name, Environment, env-var count, secret-file count, and updated time.

## Context

- Bex currently renders unfiltered cards and omits Environment scope.
- The authenticated Render list exposes search plus `Env Group Name`, `Environment`, `Env Vars`, `Secret Files`, and `Updated` columns.
- The existing backend list is paged/filterable; the UI must not pretend it searched unloaded pages.

## Steps

1. Rebuild the populated state on the shared table/list primitives with the observed columns, preserving create and row navigation.
2. Add debounced accessible search using the server's name filter (or a complete loaded set only when proven complete), stable pagination, URL/state behavior, and Reset search.
3. Distinguish workspace empty, no matching results, loading, error, and unknown Environment labels.
4. Preserve useful Bex metadata without crowding Render's primary columns, and supply a responsive small-screen representation with no horizontal page overflow.
5. Test keyboard search/reset, workspace switch, pagination/filter composition, and locale formatting.

## Acceptance criteria

- [ ] Populated list has the five observed primary columns and correct values/labels.
- [ ] Search finds matching names across the result set, has an accessible no-match state, and Reset restores the list.
- [ ] Search composes with workspace and pagination without stale prior-workspace rows.
- [ ] Empty workspace and no-match are distinct; loading/error do not flash as empty.
- [ ] Desktop and 390px mobile have no page-level overflow and retain actionable row navigation.

## Out of scope

- Full-text search inside secret keys or values.
- Changing backend list limits unrelated to correct filtered pagination.
