## Objective

Verify m73's Definition of done from code, tests, and live evidence; record the final contract and any narrowly scoped follow-ups; then close the milestone in the PM board.

## Steps

1. Check every task and milestone acceptance criterion against committed implementation/evidence; do not close on intended behavior alone.
2. Add concise completion notes with shipped semantics, live audit result, test/gate commands, cleanup status, and deliberate divergences.
3. File only genuine residual work as deduplicated `.pm/w2` inbox notes with provenance; do not hide an unmet DoD item in closeout prose.
4. Mark all tasks done, move task files under `done/`, move `m73` to `.pm/w2/done/m73/`, and update the w2 milestone index/count/status.
5. Run Markdown Prettier and validate board ids/dependencies after the move.

## Acceptance criteria

- [ ] Every m73 task and Definition-of-done bullet has verifiable implementation, test, or live-evidence support.
- [ ] Completion notes state the exact final generated-value, uniqueness, staged patch/save-mode, scope/move/link, import/export/clone/search, and delete-cache contracts.
- [ ] No synthetic audit resource or secret-bearing artifact remains.
- [ ] Any follow-up is concrete, deduplicated, sourced, and honestly outside m73; otherwise none is created.
- [ ] Milestone and tasks are in the correct `done/` hierarchy and `.pm/w2/README.md` is synchronized.

## Out of scope

- Implementing new work discovered during closeout.
- Marking the milestone done while an acceptance gate is skipped or blocked.
