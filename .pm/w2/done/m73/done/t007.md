## Objective

Replace immediate per-row Environment Group editing with Render's masked read-only view and one discardable draft for env vars and secret files, committed through t006's sparse patch and explicit save chooser.

## Context

- The service Environment editor from `w5/m44` already has the intended state machine, masked values, dirty-navigation guard, patch construction, generation preview, and save chooser.
- Group editors currently reuse low-level row components whose callbacks persist immediately; key rename is modeled as delete+add across separate requests.
- Draft initialization must not reveal every group secret.

## Steps

1. Extract/reuse the service editor's neutral draft/diff/save primitives while keeping service and group orchestration typed separately.
2. Render view mode masked by default; Edit creates one in-memory env+file draft from names/revision only.
3. Support add/update/delete and atomic key/file rename, generated-value intent, Cancel, dirty navigation confirmation, and retry after rollout-only partial failure.
4. Submit exactly one sparse patch with the selected save mode and replace the draft from the returned names/revision.
5. Preserve responsive, keyboard, focus, screen-reader, English, and Chinese behavior.

## Acceptance criteria

- [ ] Opening detail or Edit performs no bulk secret reveal; values/files remain opaque until explicitly revealed or replaced.
- [ ] Multiple var/file changes and renames remain local until Save; Cancel and navigation discard/guard produce zero writes.
- [ ] One Save emits one patch and the selected rollout mode; no per-row mutation or deployment occurs.
- [ ] Generated rows retain intent/value correctly and unchanged masked rows survive byte-for-byte.
- [ ] Partial rollout failure preserves the committed revision and offers rollout-only retry.
- [ ] Desktop and 390px mobile flows are keyboard/a11y/i18n clean.

## Out of scope

- Dotenv import and export affordances (t008).
- Editing service-local values from the group page.
