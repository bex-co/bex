## Objective

Implement the shared domain methods on `sandbox.Service` for all 7 credential operations, enforcing every pinned Render OpenAPI validation rule, split Admin vs Developer authorization, scoped API key permissions, and audit-log recording.

## Context

- Exact Render OpenAPI rules (`lego/backend/internal/api/openapi/render-public-api-1.json`):
  - `id`: `^[A-Za-z0-9._~-]+$`, minLength 1, case-sensitive, unique per group; `.`, `..`, and `rnd-*` reserved.
  - `domain`: public DNS hostname, normalized lowercase, exact match; reject IPs, ports, wildcards, local/private/cluster hostnames (reuse `sessionegress.PrivateOrClusterHost`).
  - `value`: UTF-8 string up to 5120 bytes (5 KiB).
  - `enabled`: bool, default `true` on create.
  - `methods`: subset of `GET`, `HEAD`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`, normalized uppercase, deduplicated; omitted or `[]` matches any method.
  - `paths`: absolute path patterns starting with `/`, `*` = one nonempty segment, `**` = one or more segments, wildcards occupy whole segments only, no `?`, `#`, or escaping; omitted or `[]` matches any path.
  - `injection`: `type` in `header | basic | cookie | query`; `name` required for `header`/`cookie`/`query` and forbidden for `basic`; forbid routing/connection headers (`Host`, `Connection`, `Keep-Alive`, `Proxy-Authenticate`, `Proxy-Authorization`, `TE`, `Trailer`, `Transfer-Encoding`, `Upgrade`, `Content-Length`, `X-Forwarded-*`, `Forwarded`, etc.); `template` optional (default `${SECRET}`), must contain 1–5 `${SECRET}` occurrences; for `basic`, rendered value must contain `username:password`.
  - PATCH semantics: omitted top-level fields keep current values; providing `injection` replaces the entire `injection` object (`template` defaults to `${SECRET}` if omitted); empty `methods` or `paths` clears the filter; setting `value` creates a new version even if unchanged; changes to routing/injection/`enabled` create a new version.
  - Split RBAC: `list`/`get`/`versions` require workspace view (`can_view`); `create`, `delete`, `restore`, and `update` touching `domain` or `value` require Admin (`can_manage`); `update` touching only `injection`/`methods`/`paths`/`enabled` requires Developer (`can_create`).
  - Scoped API keys: `KeySandboxesHistory` for reads and `KeySandboxesCredentials` for writes (already declared in `lego/backend/internal/core/keygrant.go`).

## Steps

1. Implement strict validation helpers for credential ID, domain, value size, methods, path patterns, and injection specs (including header denylist and `${SECRET}` template checks), returning Render-compatible coded 400 errors that never echo secret values.
2. Implement `ListGroupCredentials`, `GetGroupCredential`, `CreateGroupCredential`, `UpdateGroupCredential`, `DeleteGroupCredential`, `ListGroupCredentialVersions`, and `RestoreGroupCredential` on `sandbox.Service` with exact split RBAC (`can_view` / `can_create` / `can_manage`), sandbox-group existence & workspace-ownership checks (foreign group → 404), and version fingerprinting.
3. Record workspace audit events (never containing secret values) on create, update, delete, and restore.

## Acceptance criteria

- [x] Every Render validation edge case (reserved IDs, private/wildcard/IP domains, >5 KiB value, invalid methods, non-whole-segment wildcards, query/fragment in path, forbidden headers, 0 or >5 `${SECRET}`, invalid `basic` format, `name` on `basic`) returns a clear 400 error without leaking secrets.
- [x] Split RBAC allows Developers to PATCH `injection`/`methods`/`paths`/`enabled` while returning 403 when a Developer tries to create, delete, restore, or PATCH `domain` or `value`.
- [x] Foreign workspace `sandboxGroupId` answers 404; repeated delete of an absent credential succeeds idempotently.
