## Objective

Wire the sandbox credential broker listener into `lego/backend/cmd/ssh-gateway` with bounded concurrency/timeouts, clean shutdown/drain, secret-free logging, Prometheus metrics, and a Grafana panel on `bex-api + gateways`.

## Context

- `lego/backend/cmd/ssh-gateway/main.go` already hosts the SSH, Web Shell, agentcred, modelproxy, and egressproxy listeners with shared `SessionLimiter`, `Metrics`, and graceful drain (`drain.go`).
- Every new env var must be documented in `lego/backend/AGENTS.md` and `.env.example` (if applicable).

## Steps

1. Add configuration flags/env vars in `lego/backend/cmd/ssh-gateway/main.go` for the sandbox broker bind address (e.g. `:8085`), Broker CA cert/key paths, and `bex-api` internal lookup URL/auth; start the listener only when configured (fail closed when partially configured).
2. Wire `SessionLimiter` (global + per-Pod caps), idle/total tunnel timeouts, and graceful drain on shutdown.
3. Add Prometheus metrics in `lego/backend/internal/sshgateway/metrics.go` (requests by outcome `injected`/`passthrough`/`denied`/`error`, overlaps, lookup latency, cache hits/misses — closed label sets, zero secret/URL/path cardinality) and add a panel to the `bex-api + gateways` Grafana dashboard (`deploy/gitops/`).
4. Update `lego/backend/AGENTS.md` with the new env vars.

## Files

- `lego/backend/cmd/ssh-gateway/main.go`
- `lego/backend/internal/sshgateway/metrics.go`
- `lego/backend/AGENTS.md`
- `deploy/gitops/base/grafana-dashboards/*` (or existing gateway dashboard manifest)

## Acceptance criteria

- [x] `cmd/ssh-gateway` starts the broker listener cleanly when configured, skips it when unconfigured, fails closed on partial config, and drains gracefully on SIGTERM.
- [x] Prometheus metrics use closed labels with zero secret or high-cardinality values, and `scripts/gitops-validate.sh` passes.

## Out of scope

- Kubernetes Service port / Cilium policy / Pod env wiring (`w2/m535`).
