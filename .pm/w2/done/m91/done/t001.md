## Objective

Make `create_postgres` accept Render's `diskSizeGb` spelling (bex currently only accepts `diskSizeGB`), and decide once — for all three tools in this milestone — how legacy bex spellings are handled (kept as documented compat aliases with a precedence rule, or removed), so t003 applies the same policy.

## Alias policy (milestone-wide)

**Keep legacy bex spellings as documented compat aliases.** Each renamed upstream argument is a second optional JSON field on the MCP args struct; merge via `mcputil.Prefer*` / `ResourceIDs`. **When both spellings are set, the Render spelling wins.** Removal of legacy spellings is out of scope — agents already calling bex keep working. Applies to: `diskSizeGb`/`diskSizeGB`, `resourceId`/`resource`, `resolution`/`resolutionSeconds`, `httpLatencyQuantile`/`quantile`, and the host/path Render names vs bex `host`/`path`.
