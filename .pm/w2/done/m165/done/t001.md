## Objective

Make newly discovered environment IDs usable by the unmodified pinned Render CLI, including environments persisted with legacy env-* IDs.

## Context

- [Researched finding](../finding.md), reproduced against production with the installed Bex binary and unmodified pinned Render CLI.
- [Milestone definition of done](../README.md).

## Steps

1. Read finding.md and ADR020. Settle one canonical outward ID and bounded legacy normalization/alias contract before changing mints.
2. Implement the shared producer/read/input behavior across all three creation families and discovery/reference serializers. Preserve durable identity and placement; do not rewrite CLI requests or reinterpret name filters.
3. Cover new/legacy inputs, invalid aliases, collision behavior, project binding, and access checks. Record the exact internal/public boundary.
