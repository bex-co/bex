## Objective

The missing core page: a `/blueprints/new` flow mirroring Render's `/select-repo?type=blueprint`. Step 1: pick a GitHub-App-connected repo (reuse the existing repo-listing surface from w2/m8) or paste a public GitHub URL; choose branch + blueprint file path (default `bex.yml`) + instance name. Step 2: fetch + validate, show the change review — the parsed plan (services/databases/keyValue/envGroups from `BlueprintValidationPlan`) with per-entry errors on failure. Step 3: prompt for each `sync: false` env var declared in the manifest (masked inputs, names from the validation plan). Step 4: Deploy Blueprint → `createBlueprint` mutation → land on `/blueprints/{id}` in its syncing state. A "New Blueprint" button on the `/blueprints` list (and empty state) links here.
