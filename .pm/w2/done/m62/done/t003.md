## Objective

A first-class create verb: given `(repo, branch, path, name?)`, fetch the manifest from Git (t002), validate it, apply the stack (existing `deployStack` path), and register the blueprint row with the Git-connection fields — replacing "blueprints only appear as a side effect of an MCP/CLI deploy". Accept a `envVarValues` map supplying values for `sync: false` env vars declared in the manifest (Render prompts for these at create; bex's SEED-ONCE w1/m35 semantics apply them on first create only).

## Context

- Core: `lego/backend/internal/apps/blueprint.go` (`upsertBlueprint`, `SyncBlueprint`) + the shared `parseStack` in `deploy.go`.
- Render has **no public REST create-blueprint endpoint** (dashboard-only) — so REST create is a documented bex extension or omitted; GraphQL mutation (dashboard's client) + MCP tool are the primary adapters. Follow the ADR006 one-core/thin-adapters pattern and note the extension status in the ADR018 row (t010).
- Protected-environment confirm (`confirm` phrase, w5/m31) must ride through create as it does through sync.
- Payment gate (ADR046): non-free plans in the manifest hit the existing `PaymentGate` — do not bypass.

## Steps

1. `CreateBlueprint(ctx, ownerID, req{repo, branch, path, name?, envVarValues?, confirm?})` in core: fetch → validate → apply → upsert row (status `created` → `in_sync` on success, `error` on failure) and record the initial sync run (t001 table).
2. GraphQL `createBlueprint(...)` mutation + MCP `create_blueprint` tool; decide + document the REST stance (extension vs omitted).
3. Thread `envVarValues` into the stack apply for `sync: false` vars only (reject values for undeclared keys with a named 400); `generateValue` vars keep minting.
4. Tests: create from stubbed fetch, sync:false values land in the created service env, undeclared-key rejection, failure marks `error` status + errored sync row.

## Acceptance criteria

- [ ] One call creates resources + a Git-connected blueprint row + an initial recorded sync.
- [ ] `sync: false` values supplied at create are applied once; omitted ones leave the var unset (never a placeholder).
- [ ] Cross-workspace deny (w7/m55 matrix idiom) covered by a test.
