## Objective

Add deterministic local tests for the automation behaviors that the live happy-path evidence cannot safely or cheaply repeat: PTY completion and timeout, output mismatch, secret redaction, preflight-before-create, and exact cleanup after failures.

## Context

- The gated live verifier proves the real external path but should not be required by normal CI.
- Tests must exercise behavior, not snapshots: a hanging child must be reaped, a wrong Valkey result must fail, a URI/token in a synthetic transcript must be redacted, and a created fixture must be deleted when a later leg fails.
- Shell tests may use local command/API fakes, but must assert the invoked target/method and cleanup ordering; a fake that merely exits zero would not protect the verifier.

## Steps

1. Add focused Go tests around the PTY runner using harmless child fixtures for expected output, nonzero exit, premature EOF, and deadline termination; assert no child remains.
2. Feed synthetic bearer and password-bearing URI strings through the diagnostic path and assert the sensitive substrings are absent while actionable context remains.
3. Add a shell-level verifier test with strict API/CLI fakes that records create, readiness, id/name probe, and delete calls; cover preflight failure before create and probe failure followed by exact-id cleanup.
4. Run the focused script tests and `cd lego/backend && go test ./internal/keyvalue`; then run `cd lego/backend && go test ./...` in proportion to any shared helper/dependency change.

## Acceptance criteria

- [x] Tests fail if the PTY child hangs/leaks, expected output is absent, a secret survives sanitization, resource creation happens before preflight, or failure skips exact-id deletion.
- [x] Tests cover both opaque-id and display-name argument construction including `--output interactive` and the post-`--` Redis arguments.
- [x] Focused Key Value tests, script tests, and the backend suite are green without a live cluster or public DNS.
- [x] No tautological assertion, broad snapshot, or credential-shaped real value is used to inflate coverage.
