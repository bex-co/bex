## Objective

- `lego/backend/internal/apps/mcp.go`, `lego/backend/internal/postgres/mcp.go`, `lego/backend/internal/keyvalue/mcp.go`.

## Steps

1. Add an optional `dry_run` bool arg to each tool listed above.
2. Route through `core.WithDryRun(ctx)` (t001) and return a preview payload matching `validate_bex_yml`'s established shape.
