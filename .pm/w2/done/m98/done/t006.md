## Objective

Meaningful tests for what m98 shipped. A suspended web service's public host must reach the bex responder and never wake the App; the sibling paths must be unchanged.

## Steps

1. **Operator (envtest):** a suspended web App's Ingress backend is the activator alias; with maintenance mode also on it is the maintenance alias; clearing `Spec.Suspended` returns it to the own Service. Controls: a suspended static site keeps the `w3/m46` backend; a sleep-eligible free service keeps the `w6/m94` backend; a private service has no Ingress.
2. **Activator:** for a suspended App, `Accept: text/html`, `Accept: application/json` and no `Accept` each get `503`, the matching content type, a bex body and `Retry-After`; the fake client records no replica patch and no `last-active` annotation write. Controls: the sleeping path still wakes, the maintenance path still answers without waking.
3. Each new test is shown failing on the pre-fix code.

## Acceptance criteria

- [ ] The operator and activator cases above exist and pass.
- [ ] `make test` in `lego/operator/` is green.
