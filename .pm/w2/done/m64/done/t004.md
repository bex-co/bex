## Objective

Ride the fast create: the composer navigates to `/agents/$agentSessionId` as soon as the accept response returns, and the chat page becomes the home of provisioning state — a visible "starting the sandbox…" treatment while `pending/creating`, live progression to `running` (existing phase polling/stream), and a `failed` + recorded-reason state with a retry affordance.

## Context

- `dashboard/src/features/agent-sessions/components/new-session-composer.tsx:298-311` — `await create(...)` then `navigate`; after the backend split this is already fast, but verify no client code still expects an attach ticket on the create response (t002) — the conversation view should mint lazily via the attach-ticket verb once `running`.
- `dashboard/src/routes/agents_.$agentSessionId.tsx` + `features/agent-sessions/components/{session-detail-header,session-conversation,session-conversation-impl}.tsx` — phase-driven rendering already exists (`AgentSessionPhaseChip`, `isCanceling`); extend for the pre-sandbox phases rather than bolting on a new mechanism.
- Field-anchored validation errors still happen pre-navigation (backend keeps them sync) — composer error handling (`ERROR_FIELDS`, `failInConfig`) is unchanged.
- Retry on `failed`: decide the verb (re-`create` with the same config vs a dedicated retry) — simplest honest MVP is a "Start a new session with the same prompt" affordance; note anything bigger as follow-up.
- Every new user-visible string goes through `useTranslations()` with `agentSessions.*` keys in `locales/{en,zh}.ts`.

## Steps

1. Verify/adjust the composer flow for the ticketless fast response; navigate on accept.
2. Add the `pending/creating` provisioning treatment to the chat page (skeleton/spinner + phase copy), driven by the existing phase refresh.
3. Render `failed` + the row's recorded reason with the retry affordance.
4. Make the conversation view tolerate "no attach ticket yet" (mint lazily when `running`; retry the named not-ready error from t002).
5. Component tests in `components/__tests__/` for the three states.
