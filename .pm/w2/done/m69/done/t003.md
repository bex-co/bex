## Objective

Flip the dispatch path: when the proxy is configured, the sandbox create request carries a per-session **placeholder** instead of the real key, the driver env gains the proxy base URL, and the rendered per-session Cilium policy drops the vendor model host in favor of a proxy-service carve-out beside `credentialGatewayHost`. Unset ⇒ today's behavior, byte-identical.

## Context

- Real-key injection today: `lego/backend/internal/sandbox/service.go` `CreateAgentSessionSandbox` (`ModelAPIKeyEnvVar`); key fetched in `internal/agentsessions/service.go` at dispatch.
- Egress rendering: `lego/backend/internal/sessionegress/policy.go` — `ModelEndpointHost` admits the vendor host; its forward note already specifies this narrowing ("the provider resolver must return only that single in-cluster proxy endpoint"). The proxy joins as a second cluster-internal carve-out beside `credentialGatewayHost:8082`.
- The placeholder must be visibly fake (e.g. carries the session id, no `sk-` shape collision) so accidental direct use fails loudly; the proxy trusts pod identity, not the placeholder value.
- Feature gate: one bex-api env (the proxy's browser-invisible internal URL, e.g. `BEX_AGENT_MODEL_PROXY_URL`) selects the new path; document in CLAUDE.md env table + `.env.example`.

## Steps

1. In dispatch: when gated on, stop fetching/injecting the real key into pod env; inject placeholder + proxy base URL into driver env instead (real-key fetch moves entirely to t001's resolve path).
2. In `sessionegress`: render the proxy carve-out and omit the vendor host from tenant-pod egress when gated on; `EnterAgentSessionPhase` keeps the same narrowing.
3. Keep hibernation/rehydration (ADR059, m68) credential-free: rehydrate re-binds pod identity; assert no snapshot/rehydrate step needs the key.
4. Update the ADR062 status line (Proposed → Accepted) and CLAUDE.md env rows once the path is live-verifiable.
