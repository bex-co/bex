## Objective

Add the credential-injecting model proxy to `cmd/ssh-gateway`: a cluster-internal plain-HTTP listener (no edge route) that authenticates the **direct source Pod** against the session's sandbox binding, resolves the credential via t001 (short-TTL in-memory cache), injects the provider auth header on the upstream hop, and streams the response byte-transparently to the session's registered endpoint — and only that endpoint.

## Context

- Pattern and trust model: the agentcred Git smart-HTTP proxy (`internal/sshgateway/agentcred`, `BEX_AGENT_CREDENTIAL_ADDR` :8082) — source-pod authentication, no edge exposure, listener disabled when its config is unset (byte-identical default).
- Injection shapes: `x-api-key` (Anthropic API keys), `Authorization: Bearer` (`sk-ant-oat` OAuth tokens — see the shape-routing in `lego/agent-image/driver/src/config.ts`), OpenAI-style `Authorization: Bearer`. Strip any client-supplied auth header before injecting.
- Upstream target: exactly the t001-returned `ModelEndpointHost` (already rejects IP literals and private/cluster-local names — the SSRF guard). HTTPS :443 upstream; streaming (SSE) responses must flow unbuffered.
- Follow env-var conventions: a `BEX_MODEL_PROXY_ADDR`-style listen knob plus reuse of the existing internal credential-API base URL; document both in the CLAUDE.md env table and `.env.example`.

## Steps

1. New `internal/sshgateway/modelproxy` package: listener, source-pod → session-binding resolver (reuse the shared gateway kernel), credential fetch with a short-TTL memory cache keyed by session, header injection, transparent streaming reverse proxy.
2. Wire into `cmd/ssh-gateway` behind its env gate; share the process-wide limiter conventions.
3. Refuse: unbound source pods, sessions in a non-live phase (re-check at request time), upstream hosts differing from the pinned endpoint.
4. Metrics: requests, refusals by reason, upstream latency (existing gateway Prometheus registry).

## Acceptance criteria

- [ ] A request from the bound sandbox pod is proxied to the pinned endpoint with the injected header; SSE streams end to end.
- [ ] A request from any other pod, or for a non-live session, is refused with a coded status; the credential never appears in logs/errors.
- [ ] Env gate unset ⇒ listener not started; gateway behavior byte-identical.
- [ ] Client-supplied `Authorization`/`x-api-key` headers are stripped, never forwarded.
