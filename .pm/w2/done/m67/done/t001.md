## Objective

Replace "tear down as soon as the turn finalizes (unless SSH is open this instant)" with ADR059 D2's Active-tier rule: reap only when `idle > graceTTL`, where `idle = now − max(last turn end, last SSH session end)` and an **open** SSH session pins idle at zero.

## Context

- Today: `agentsessions/completion.go` finalizes then `teardown`s; ADR054 D6 defers only while an `ssh_sessions` row is open, and `reapDeferredSandboxes` retries each tick. m65 already added `HasOpenSSHSession` + `ListTerminalAgentSessionsWithSandbox` + `ClearAgentSessionSandbox` on the store.
- New inputs for the idle max: the session row's terminal `updated_at` (last turn end) and the most recent `ssh_sessions.ended_at` for the `ags-…` id (new store read, gateway already writes these rows).
- Env: `BEX_AGENT_SANDBOX_IDLE_TTL` (Go duration; default `30m`; `0` ⇒ legacy immediate-reap). Plumb via `cmd/api` → Completer field, mirroring `SSHGraceTTL`.
- Keep the terminal action behind a seam (`reap(record)`) — m68 swaps Terminate → hibernate at this exact point.
- Mirror the env var in root `CLAUDE.md`'s table and `.env.example` (name + comment only).

## Steps

1. Add a store read for "latest ended ssh session for resource id" and thread it plus terminal `updated_at` into an `idleSince(record)` helper on the Completer.
2. Gate teardown on `now − idleSince > IdleTTL` (open SSH session ⇒ never); keep the stale-row guard and Cancel's immediate path.
3. Env plumbing + docs (`CLAUDE.md`, `.env.example`).
