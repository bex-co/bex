## Objective

Fix the upgrade-transition bug that stamps `status.staticPrefix` on a skip-publish reconcile (pointing a labeled already-published site at an empty `W/A/<rev>/`), add the missing transition coverage, and land the four review follow-ups (tombstone-key match, ETag runbook caveat, ownership-gated legacy pull-Secret cleanup, ADR074 username-join residual). ## Context

- Finding 1: `reconcileStaticSite` wrote `appIdentity(app).StaticPrefix(rev)` even when `ActiveRevision` already matched and no publish ran. After operator upgrade, labeled sites still live at `A/<rev>/`; an invented prefix 404s.
- Finding 2: closeout ran while the DoD's first clause (mock-cluster e2e) was substituted with envtest; that substitution skipped the transition class Finding 1 is.
- Minors: `BuildPlan` skipped any key ending `.bex-tombstone`; multipart ETags; leftover `reg-pull-<name>` on labeled Apps; `app-W-A` username join.

## Steps

3. Exact prefix-root tombstone key only; ownership-gated legacy Secret delete; runbook ETag caveat; ADR074 username residual.
4. Amend the milestone DoD to envtest coexistence + this transition test; live operator-image upgrade stays runbook-gated.
