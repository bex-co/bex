## Objective

Decide the workspace-scoped identity formats for the two shared sinks before any code changes: the Zot repository name, the per-App Zot htpasswd user + ACL entry name, the `reg-pull-*` Secret name, and the static-site S3 object-key prefix — all keyed on stable workspace identity (the `tea-<xid>` workspace id per docs/ADR020-identifiers.md, carried on App CRs as the `app.bex.co/workspace` label). Define the legacy→new mapping and the dual-read precedence (new scheme first, legacy fallback), and write it down as a design section so t002–t005 implement one agreed scheme.

## Context

- Today's legacy identities, all keyed on bare `App.Name`:
  - OCI repo + tag: `ImageRef()` returns `<Registry>/<o.Name>:<rev>` — `lego/operator/internal/build/build.go:394-399` (tag `gen-N`, line 249); kpack alias `KpackImageRef()` same file.
  - Zot user `app-<name>` + pull Secret `reg-pull-<name>`: `ZotUsername`/`PullSecretName` in `lego/operator/internal/registry/creds.go:101-104`; ACL entries per repo via `setZotRepoPolicy` in `lego/operator/internal/registry/zotconfig.go:162`.
  - Static publish prefix `<appID>/<revision>/`: `Options.Prefix()` in `lego/operator/internal/publish/publish.go:144`; purge prefix `appName + "/"` at line 487; serve-side key `Site.AppID + "/" + Revision + "/"` in `lego/operator/internal/staticserver/staticserver.go:96`.
- Workspace identity: `labelWorkspace = "app.bex.co/workspace"` (`lego/operator/internal/controller/app_controller.go:137`); workspace ids are `tea-<xid>` (`lego/backend/internal/id/id.go:61`). Legacy/hand-applied Apps may lack the label (app_controller.go:270).
- ADR067 finding 1 (docs/ADR067-security-review-round12.md:26-33) notes bex-api's store path already tenant-prefixes CR names (`<ws>-<name>`), so collisions require legacy or hand-applied CRs — the scheme must still be UID/workspace-keyed per ADR055's F2/F3 remediation sketch (docs/ADR055-security-review-round4.md:44).
- Zot repo names must stay valid OCI repository path components; `tea-<xid>` is DNS-safe by ADR020 design.
