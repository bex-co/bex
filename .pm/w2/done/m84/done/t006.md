## Objective

Give `/settings` a clear, accessible, localized deletion flow whose warning is generated from the backend's real workspace disposition.

## Context

- `settings-page/index.tsx` currently has four sections and `SettingsNavigation` has four items. `AccountSettingsPageSkeleton` mirrors those four regions/counts and must move with the ready state.
- Existing `ConfirmDialog`/`SudoCommandField` and workspace/resource danger-zone cards provide the repository's destructive confirmation/accessibility patterns.
- The user must see what will be deleted, what will survive, and why a workspace blocks deletion before entering the confirmation.

## Steps

1. Add a self-contained account-deletion feature hook/card/dialog that reads the GraphQL preview and invokes the mutation; do not call Kratos admin APIs from dashboard SSR/client code.
2. Add a fifth `danger-zone` settings section and navigation item after Security & Compliance, with exact localized delete/leave/block lists and irreversible/credential/session consequences.
3. Disable confirmation while blockers exist and link each blocker to `/workspace/settings` so the user can promote another admin or delete the workspace.
4. Require the exact ADR confirmation phrase, handle accepted/retry/pending errors without leaking raw error details, clear Apollo/session-sensitive client state, and land on a public terminal success page after acceptance.
5. Update English/Chinese strings, route validation, and `AccountSettingsPageSkeleton` to five navigation items and a matching one-card danger zone at desktop and narrow-mobile.

## Acceptance criteria

- [ ] The fifth navigation item and fifth ready/skeleton section agree at both required breakpoints.
- [ ] Delete/leave/block workspace lists render from the backend preview; no destructive consequence is guessed client-side.
- [ ] A blocker cannot be bypassed by DOM state or a stale preview; the server rechecks it.
- [ ] The exact confirmation arms one destructive action, double-submit is impossible, and accepted deletion lands on a clear signed-out terminal page.
- [ ] All user-visible strings exist in English and Chinese and the dialog is keyboard/screen-reader usable.

## Out of scope

- Personal-data export UI.
- Account-deletion grace period or undo.
