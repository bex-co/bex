## Objective

Lay the data foundation for ADR065: the `archived_at` column, store-level archive/unarchive/delete operations, and a filtered + keyset-paginated `ListAgentSessions`.

## Context

- ADR065 D1 (flag, never a phase), D3 (filters + pagination), D4 (delete ordering).
- Migrations live in `lego/backend/internal/store/migrations/`; next free number after the current max (0073 was hibernation — scan for the actual max first).
- Current list: `SELECT … WHERE workspace_id=$1 ORDER BY created_at DESC, id DESC`, no LIMIT (`lego/backend/internal/store/agentsessions.go:120-136`).
- `DeleteAgentSession` exists as create-path compensation (`store/agentsessions.go:615-627`) — reuse/extend for D4, keeping the blob-before-row ordering owned by the service layer (t003).

## Steps

1. Migration: `ALTER TABLE agent_sessions ADD COLUMN archived_at timestamptz` (+ down). No CHECK/phase change.
2. Store: `ArchiveAgentSession` / `UnarchiveAgentSession` (idempotent, stamp/clear `archived_at`), add `ArchivedAt` to the row struct and scans.
3. Store: extend `ListAgentSessions` with a filter struct — `Archived` (false default / true / all), `Phases []string`, `Repo`, `CreatedBefore/After`, `Limit` (default 50, max 200), opaque keyset cursor over `(created_at DESC, id DESC)`.
4. Store: hard-delete path suitable for the public verb (row delete; transcripts cascade via existing FK).
