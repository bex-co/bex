## Objective

Implement the **Settings** tab (`/build-sources/$buildSourceId/settings`) supporting editing Build Source configuration via `updateBuildSource` (save without building) and safe deletion via `deleteBuildSource` with clear linked-service refusal handling.

## Context

- `updateBuildSource` (`lego/backend/internal/apps/build_sources_graphql.go:209`) patches `name`, `git` (`repoUrl`, `branch`, `runtime`, `buildCommand`, `rootDir`, `dockerfilePath`, `dockerContext`, `buildFilter`, `registryCredentialId`), or `image` (`imageUrl`, `registryCredentialId`). Like Render, edits are saved without rebuilding (`ADR097`).
- `deleteBuildSource` refuses deletion while any service remains linked (`serviceLinks.length > 0`).

## Steps

1. Create `dashboard/src/routes/build-sources.$buildSourceId.settings.tsx` and `BuildSourceSettingsTab`:
   - Editable sections matching the source kind (Git: name, repo URL, branch, runtime, buildCommand / dockerfilePath + dockerContext, rootDir, buildFilter `paths`/`ignoredPaths`, registry credential; Image: name, imageUrl, registry credential), with read-only display of immutable fields (ID `bds-…`, region, project).
   - Viewer read-only gating (`can_create` required to edit/delete).
   - Clear inline note that saving Settings does not automatically start a build.
2. Add **Danger Zone — Delete Build Source** card:
   - If `serviceLinks.length > 0`, clearly list the linked services with links to unlink them and disable/explain why delete is blocked (and still handle backend conflict cleanly if raced).
   - When unlinked, open a confirmation dialog requiring the Build Source name, call `deleteBuildSource`, evict cache, and navigate back to `/build-sources`.
3. Add breakpoint-matched pending skeleton (`1440px` and `390px`).
