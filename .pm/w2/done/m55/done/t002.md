## Objective

Add a bex-api endpoint that, for a caller authenticated by a Kratos session, authorizes `can_operate` on the target service and mints a **short-lived, single-use, service-scoped exec ticket**. The gateway (t003) validates this ticket to open a browser exec stream. bex-api gains **no** `pods/exec` RBAC — it only authorizes and mints a signed ticket.

## Context

- Auth model settled in t001: the browser never holds an SSH private key; the Kratos session is the browser's credential, and the ticket is the capability handed to the gateway.
- Existing authz seam: `apps.Service.AuthorizeApp(ctx, core.RelCanOperate, lookup)` (`lego/backend/internal/apps/service.go`) already targets the App's workspace — reuse it, do not reinvent.
- Existing identity plumbing: bex-api already resolves Kratos sessions to a `core.Identity` (see the auth middleware used by REST/GraphQL). The ticket must bind subject + service id + workspace + short TTL.
- The gateway and bex-api share the control-plane Postgres and OpenFGA; the ticket can be either a signed token (HMAC/JWT with a shared secret) or a DB-backed single-use row. Pick per the t001 design (favor the mechanism that is content-free and single-use).

## Steps

1. Define the ticket shape: subject, service id, workspace id, issued-at, short TTL (seconds), single-use nonce. Bind it so the gateway can verify integrity and scope without a second OpenFGA round-trip (or with one, if t001 chose DB-backed).
2. Add the mint endpoint (e.g. `POST /v1/services/{id}/shell-ticket` or GraphQL mutation, per t001/parity): session-authenticated → `AuthorizeApp(can_operate)` → return the ticket + the gateway WS URL. Fail closed on free/suspended/unsupported-type/foreign exactly like `sshEligible`/`ResolveSSHSession`.
3. Add the signing/validation helper in a package importable by both bex-api and the gateway (or a shared secret + verify func the gateway reuses).
4. Ensure **no** `pods/exec` rule is added to bex-api's Role; add a guard/assertion if the RBAC test harness supports it.
5. Unit tests: authorized mint succeeds; unauthorized/free/suspended/foreign denied; ticket TTL + single-use enforced.

## Files

- `lego/backend/internal/apps/` (or a new `internal/shell/` package) — ticket mint + endpoint
- `lego/backend/internal/apps/service.go` — reuse `AuthorizeApp` / eligibility
- shared ticket sign/verify helper importable by `lego/backend/internal/sshgateway/`
- RBAC manifests/tests confirming bex-api still lacks `pods/exec`

## Acceptance criteria

- [ ] A Kratos-session caller with `can_operate` receives a scoped, short-TTL, single-use ticket + gateway WS URL for an eligible service.
- [ ] Free/suspended/unsupported-type/foreign-workspace/unauthorized callers are denied with a useful error and no ticket.
- [ ] bex-api RBAC still has no `pods/exec` rule (guard/test).
- [ ] Ticket TTL and single-use are enforced and unit-tested.
