## Objective

Standing closing task: a meaningful negative-path test matrix proving least-privilege enforcement and — equally important — proving the four legitimate ADR069 caller shapes are byte-identically unaffected.

## Context

The DoD's riskiest clause is back-compat: `bex.api` umbrella tokens, `client_credentials` API keys, `bex.co/platform-client`-marked clients, and audience-less device-flow tokens must behave exactly as before t003. `r14_scope_test.go` (which must remain green unmodified) covers the round-14 introspection layer; this task covers the new class layer on top. Follow the repo's existing cross-surface matrix precedent (`crossworkspace_matrix_test.go`, `crossworkspace_gqlmcp_test.go`) rather than one-off tests per surface.

## Steps

1. Backend matrix test (new `lego/backend/internal/api/scope_matrix_enforcement_test.go` or similar): for each scope shape (read-only, write, mint, umbrella) × each surface (REST/GraphQL/MCP) × representative operations from each class, assert allow/deny per the t002 table and the exact refusal code/shape on deny.
2. Exemption tests: API key, platform-marked client, and audience-less device-flow token each perform a write and a mint operation successfully with no scope check engaged.
3. Regression: assert `r14_scope_test.go` passes unmodified; a capability-scope-less API-audience human token still gets 401 (not the new 403).
4. Audit assertions: each refusal in the matrix produced the t005 record with correct fields and no token material.
5. Dashboard: extend `__tests__/hydra-consent.test.ts` — granular-scope consent succeeds (GET+POST), identity-only-with-audience still refused, unrecognized scopes still dropped by the intersection.
6. Run `cd lego/backend && go test ./...` and `cd dashboard && yarn test`.
