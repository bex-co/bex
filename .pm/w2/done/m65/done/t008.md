## Objective

Implement ADR054 D5's machine half: the agent-session `View` gains `sshAddress: "ags-<xid>@<BEX_SSH_HOST>"`, present only when `BEX_SSH_HOST` is set and the sandbox is live, projected identically on REST, GraphQL, and MCP.

## Context

- Pattern to copy: `apps/service.go` `view()` — lowercase/trim host, DNS-subdomain validation, eligibility gate, `v.ID + "@" + host`. Same activation gates as ADR035 (`scripts/ssh-activate.sh --check` before `BEX_SSH_HOST`).
- Shape: `lego/backend/internal/agentsessions/models.go` `View` (next to `SandboxID`), populated in `viewOf`/presenter; GraphQL field on `agentSessionGQLType` (`graphql.go`); MCP inherits the View.
- Liveness gate identical to t004's resolver: phase ∈ {creating, running, resuming, redispatching} and `sandbox_id != ''`. Terminal sessions omit the field (never invent an address).
- bex-api needs `BEX_SSH_HOST` plumbed to the agentsessions service (`cmd/api/main.go` already reads it for apps).

## Steps

1. Add the field + presenter assembly + host plumbing.
2. GraphQL type field; confirm MCP tool output carries it via the shared View.
3. Document the field in the ADR054-referenced env row for `BEX_SSH_HOST` in `CLAUDE.md` (bex-api row: mention agent sessions).
4. Tests: present on a live-phase session with host set; absent on terminal phase, absent with host unset, absent with malformed host.
