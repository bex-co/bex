## Objective

Implement ADR054 D5's UI half: a Connect-style control on the agent-session detail header with an **Open in Zed** anchor (`zed://ssh/<sshAddress>/workspace`) and a copyable `ssh <sshAddress>` row, shown only while the address exists.

## Context

- Pattern to clone: `ServiceConnectButton` + `ConnectCodeRow` (`dashboard/src/features/services/components/service-detail-header.tsx`) — DropdownMenu, section label, `bg-muted` code row + `CopyButton`.
- Placement: `session-detail-header.tsx`, next to the evidence toggle or in the overflow menu.
- Data: add `sshAddress` to the `AgentSessionFields` fragment (`features/agent-sessions/api/agent-sessions.graphql`) + regenerate types; the view already polls, so appearance/disappearance tracks phase.
- This is the dashboard's first custom-scheme `href` — a plain anchor; `safe-next.ts`-style http(s) guards apply to navigation targets, not this intentional external-protocol link. Unavailable state mirrors the service Shell page convention (explain, don't invent).
- i18n: en + zh strings like the rest of the header.

## Steps

1. Fragment + codegen; header component + dropdown with the two rows; phase-gated render.
2. Component tests: visible with address, hidden without; anchor href exact; copy row content exact.
3. `yarn test` + lint + typecheck.
