## Objective

Make App finalization idempotently delete every copied build credential and kpack/build object in the shared execution namespace.

## Context

- `build.DeleteAppArtifacts` currently deletes Jobs, Pods, and kpack Images only.
- Copied Secrets, derived private-registry configs, kpack credentials, Builds, and per-App ServiceAccounts need explicit cleanup.

## Steps

1. List artifacts by the standardized App identity from t001.
2. Delete all matching Secrets, ServiceAccounts, Jobs/Pods, kpack Images/Builds, and derived configs idempotently.
3. Handle NotFound as success and preserve/retry other errors.
4. Verify delete/recreate does not adopt old-UID credentials or build objects.

## Files

- `lego/operator/internal/build/build.go`
- `lego/operator/internal/build/kpack.go`
- `lego/operator/internal/build/*_test.go`
- `lego/operator/internal/controller/app_controller.go`

## Acceptance criteria

- [x] App deletion leaves zero inventory-matched build/kpack artifacts.
- [x] A transient deletion error keeps finalization retryable.
- [x] Same-name App recreation cannot consume the deleted App's credentials or build result.

## Out of scope

- Registry manifests and static/backup/TLS cleanup, owned by t003.
