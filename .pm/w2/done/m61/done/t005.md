## Objective

Prevent registry and Prometheus stalls from indefinitely holding App/Database reconcile workers.

## Context

- Registry manifest resolution/cleanup and autoscaling queries use `http.DefaultClient` or otherwise lack complete deadlines.
- The App controller currently has a small worker pool and source builds are synchronous.

## Steps

1. Introduce shared clients/transports with connect, TLS, response-header, idle, and total request bounds appropriate to each dependency.
2. Propagate reconcile contexts through every call.
3. Bound response-body reads and always close bodies.
4. Add stalled-connect/header/body and cancellation tests.

## Acceptance criteria

- [x] No audited registry/Prometheus path uses an unbounded default client.
- [x] Stalled endpoints return within the configured deadline and release the reconcile worker.
- [x] Context cancellation is distinguishable from upstream HTTP/protocol failure in conditions/logs.

## Out of scope

- Changing retry/backoff policy beyond what is needed to avoid hot loops after timeout.
