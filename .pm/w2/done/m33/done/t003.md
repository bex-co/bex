## Objective

Let an authorized caller regenerate an App's deploy-hook token (immediately invalidating the old one) and read the current hook URL, across REST, GraphQL, and MCP.

## Steps

1. Add a `RegenerateDeployHookToken` verb, authorized via the existing `AuthorizeApp` chokepoint.
2. Expose the current hook URL (not the raw token unless intentional — decide whether the full URL or just a reveal-on-demand token, mirroring the env-var "Show secret" pattern) and the regenerate action on REST/GraphQL/MCP.

## Files

- `lego/backend/internal/apps/service.go`
- `lego/backend/internal/apps/rest.go`, `graphql.go`, `mcp.go`

## Acceptance criteria

- [x] Regenerating invalidates the old token immediately (old URL 404s).
- [x] New token/URL is retrievable across all three surfaces.
