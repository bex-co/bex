## Objective

Standing closing task. Lock the milestone's guarantee in as tests that assert real behavior: the starvation scenario itself (rapid generations during a slow build ⇒ forward progress + convergence), every state-machine edge (admit/adopt/advance/supersede/cancel/fail/timeout/restart), and the SLI labels. No tautological or snapshot tests.

## Context

- The DoD's canonical scenario: generation bumps faster than build completion ⇒ exactly one running Job at all times, one coalesced dispatch afterward, final deployed generation = latest.
- envtest can't run real BuildKit; drive Job terminal conditions directly (the watch path doesn't care who set them).
- Restart coverage: t003's adopt-on-restart with budget continuity.

## Steps

1. Starvation regression: N rapid spec generations against an artificially-held Job; assert run-to-completion, single pending slot, convergence, and that intermediate generations produce `superseded` outcomes (not `canceled`).
2. Edge matrix: Cancel-verb preemption releases the slot; failed/timeout builds release the slot; slot equal to just-built generation clears without redispatch.
3. Restart: kill/restart the manager mid-build; assert adopted budget from status timestamps.
4. Confirm CI (`operator-test.yml`) runs all of it via `make test`.
