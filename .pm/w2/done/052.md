# 052 — Delete bare-name Zot repos that no live App owns

Why: after w2/035 deleted the migrated Apps' legacy repos, Zot still holds about 25 bare-name repos from Apps that were deleted or never migrated (`tea-d98210cbbpdc73dcrkvg-hello-go`, `…-static-site-v2…v6`, `…-m92-scratch`, `agentmarketcap`, `beancount-cms`, …). They waste the 100 Gi `zot-pvc-zot-0` volume. A bare name is also exactly the cross-tenant key ADR055 F3 removed, so stale ones should not linger.

## Do

1. List the bare repos (`/v2/_catalog`, names without `/`). For each, prove that no App CR, Deployment, CronJob, Job or ReplicaSet references it, and that it is not a platform image (`bex-cnb-builder`, `opensandbox-server` are platform images and must be kept).
2. Back them up as w2/035 did (`skopeo copy --all --preserve-digests` to an OCI layout, verify digests), then delete by digest and record the list.
3. Consider making App deletion remove its own repo (scoped or bare), so orphans stop accumulating. File that separately if it is more than an hour of work.

## Acceptance

- [ ] Every remaining bare repo is either a platform image or owned by a live App; the deleted list and backup location are recorded here.

## Done 2026-10-30

- **Inventory (read-only, production Zot):** 27 bare-name repos. `bex-cnb-builder` and `opensandbox-server` are platform images and were kept. The other 25 had no live App and no reference from any Pod, Deployment, ReplicaSet, StatefulSet, DaemonSet, CronJob or Job.
