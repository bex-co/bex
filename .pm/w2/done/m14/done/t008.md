## Objective

Prove the whole path works end to end: create a credential for a real private registry, deploy an existing-image service referencing an image there, and confirm it pulls successfully.

## Context

- Use a real free-tier private registry account (e.g. a private Docker Hub repo, or a private GHCR package) for the drill — not a mock.

## Steps

1. Push a small test image to a private registry under a real account.
2. Create the matching registry credential via the dashboard or REST.
3. Deploy an existing-image service referencing that image.
4. Confirm the pod pulls successfully (no `ImagePullBackOff`) and the credential doesn't leak to unrelated pulls.

## Files

- none (live verification only)

## Acceptance criteria

- [ ] A real private-registry pull succeeds end to end.

## Out of scope

- Testing every supported registry provider (Docker Hub/GHCR/GitLab/ECR) — one representative provider is sufficient for live verification; the mechanism is provider-agnostic (standard `dockerconfigjson`).
