## Objective

Give workspace admins a dashboard UI to add, list, and delete registry credentials, modeled on Render's "Container Registry Credentials" settings page, reusing the Integrations section pattern `w3/m11`'s webhooks work establishes.

## Context

- Follow `dashboard/CLAUDE.md` conventions (TanStack Start + Apollo + shadcn).
- Precedent for "reveal-once" secrets: the API-key mint flow (`w4/m8`), the webhook signing-secret flow (`w3/m11`).

## Steps

1. Add a registry-credentials section under Settings → Integrations (alongside webhooks): list of stored credentials (host, username, expiry if set, masked secret).
2. Create form: host + username + secret (+ optional expiry); on submit, confirm creation (secret is not re-shown after).
3. Delete action per credential.
4. Surface expiry status (t007's data) inline — a visual flag for near/past-expiry credentials.

## Files

- `dashboard/src/features/` (new `registry-credentials` feature directory, or extend the `webhooks`/`integrations` feature area if one exists by then)

## Acceptance criteria

- [ ] Creating a credential works and the secret isn't re-displayed after.
- [ ] `yarn test`/`yarn lint` green.

## Out of scope

- Auto-rotation UI — bex doesn't rotate credentials on the tenant's behalf.
