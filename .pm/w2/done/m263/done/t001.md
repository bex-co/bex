## Objective

Render (CLI v2.31.0) sends `idleTimeoutSeconds` (300–86400, 0 disables idle suspension) on create and shows it in detail. bex 400s it as an unknown field and returns none, so the CLI always prints "Idle timeout: disabled". Honor it if the OpenSandbox substrate can suspend on idle; otherwise refuse it by name and record the gap in ADR018.

## Acceptance criteria

- [ ] Create with `--idle-timeout 600` works as on Render (or answers a named 400), and detail reports the actual value.

**Closed 2026-11-07 (D2=A):** the named refusal and `idleTimeoutSeconds: 0` reporting shipped in `21175a4d2`. Honoring a positive idle timeout (Render parity) moved to **w2/m278**.
