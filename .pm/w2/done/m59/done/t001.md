## Objective

Turn ADR039 O-01/O-02 into executable manifest and live-test expectations before changing placement or credentials.

## Context

- Production sets `BEX_BUILD_NAMESPACE=bex-system` in `lego/operator/config/manager/manager.yaml`.
- `deploy/gitops/base/tenant-node-egress.yaml` protects tenant Pods, not the current build namespace.
- `scripts/verify-tenant-isolation.sh` is the existing reachability-test pattern.

## Steps

1. Add cluster-less assertions for Pod labels, token mounting, namespace placement, PSS, webhook selectors, and failure policy.
2. Extend or add a live adversarial script covering metadata, kubelet, Kubernetes API, platform services, cross-tenant endpoints, and registry repositories.
3. Make each expected build dependency explicit so later policy changes do not silently break valid builds.
