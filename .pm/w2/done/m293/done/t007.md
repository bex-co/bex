## Objective

The CAPD mock's nodes are arm64 (Apple Silicon / linuxkit), so BuildKit builds arm64 images. The operator only accepts linux/amd64 (`lego/operator/internal/registry/image_config.go:376,403`, ADR004 "Which digest"). A repo-built service on dev-N therefore fails with `ImageMetadataUnavailable "image config is not Linux/amd64"` even after it builds and pushes.

Add an operator setting for the hosting platform (e.g. `BEX_IMAGE_PLATFORM`, default `linux/amd64`) used by digest/index selection and the config check. Set it to the nodes' architecture only in the mock's `mock-cluster.sh operator` deploy. Production is unchanged.

## Acceptance criteria

- [ ] With the setting unset, every existing operator test passes unchanged (amd64 contract).
- [ ] With `linux/arm64`, an arm64 single-platform image and an index's arm64 entry are accepted; amd64-only images are refused with a message naming the expected platform.
- [ ] On dev-2, the m293 web-service walk goes Live and serves 200 through Traefik.
