## Objective

Turn `SidebarRail` from a click-only toggle into a Devin-style drag handle: pointer-drag resizes the sidebar continuously within a bounded range by writing `--sidebar-width`; dragging below a snap threshold collapses to the icon rail; dragging outward from the rail re-expands; double-click toggles; the handle carries WAI-ARIA window-splitter semantics.

## Context

- `SidebarRail` (`dashboard/src/common/components/ui/sidebar.tsx:299-322`) already shows resize cursors but `onClick` only calls `toggleSidebar()`.
- Width flows entirely through `--sidebar-width` set on the provider wrapper (`sidebar.tsx:145-146`) and consumed as `w-(--sidebar-width)` — no other component hardcodes offsets, so live resize is just updating that one var.
- Devin's measured model (2026-08-04): expanded band 300–400px (drags outside clamp back); below ~50% of min width it snaps to the 52px rail; from the rail an outward drag snaps to min expanded width; dblclick toggles; the 1px handle widens to 3px + accent color while hovered/dragging (`data-separator` states) without shifting layout; `touch-action: none` on the handle; scrollbars in the group get `pointer-events: none` during drag.
- ARIA per Devin: `role="separator"`, `aria-orientation="vertical"`, `tabindex=0`, `aria-controls` on the sidebar, `aria-valuemin/max/now`.
- Perf: write the CSS var directly on the wrapper element during `pointermove` (no React re-render per frame); commit to state on `pointerup`.
- Suggested bounds for bex: min 12rem, default 16rem (`SIDEBAR_WIDTH`), max 24rem; snap-to-collapse below ~8rem of drag position.

## Steps

1. Add pointer handlers (`pointerdown`/`setPointerCapture`/`pointermove`/`pointerup`) to `SidebarRail` updating `--sidebar-width` on the provider wrapper, clamped to the band.
2. Implement snap: drag position below threshold ⇒ `setOpen(false)` (rail); drag outward while collapsed ⇒ `setOpen(true)` at min width.
3. Add dblclick ⇒ `toggleSidebar()`; keep plain click-toggle only if it doesn't fight drag (use a small movement threshold to distinguish).
4. Add the ARIA splitter attributes + a `data-dragging` visual state (accent color, widened hit line).
5. Expose the committed width through `SidebarProvider` context so t003 can persist it.
6. Respect `prefers-reduced-motion` / disable width transition during drag so it tracks the pointer 1:1.
