## Objective

Open the narrowest possible Cilium egress path from `allow-all` and `allow-list` `/v1/sandboxes` Pods to `bex-ssh-gateway`'s dedicated broker port (plus DNS lookup of `bex-ssh-gateway.bex-system.svc.cluster.local`), while keeping `deny-all` completely sealed and preserving every platform isolation deny.

## Context

- `deploy/gitops/base/tenant-node-egress.yaml` defines `sandbox-egress-default-deny` (structural denies: host, remote-node, kube-apiserver, 169.254.0.0/16, private CIDRs on port 443) and `sandbox-egress-allow-all`.
- `lego/backend/internal/sessionegress/sandbox.go` renders per-sandbox `CiliumNetworkPolicy` objects for `allow-list` sandboxes, guarded by `bex-api-sandbox-egress` ValidatingAdmissionPolicy in `deploy/gitops/base/bex-api-namespace-admission.yaml`.
- Note: `sandbox-egress-default-deny` denies private CIDRs on port `443` only, so a non-443 broker port (e.g. `8085`) targeting the exact `bex-ssh-gateway` Cilium endpoint identity (`k8s:io.kubernetes.pod.namespace: bex-system`, `k8s:io.cilium.k8s.policy.serviceaccount: bex-ssh-gateway`, `k8s:app.kubernetes.io/name: bex-ssh-gateway`) mirrors the existing `port: "8082"` gateway pattern without loosening any private-CIDR or port-443 deny.

## Steps

1. Update `sandbox-egress-allow-all` (or add a dedicated `CiliumClusterwideNetworkPolicy` selecting `app.bex.co/regime=sandbox`, `bex.co/egress` in `{allow-all, allow-list}`, `bex.co/agent-session` `DoesNotExist`) allowing DNS for `bex-ssh-gateway.bex-system.svc.cluster.local` and TCP to the `bex-ssh-gateway` ServiceAccount endpoint on the single broker port only.
2. Update `lego/backend/internal/sessionegress/sandbox.go` and `deploy/gitops/base/bex-api-namespace-admission.yaml` (if per-sandbox allow-list DNS rules need `bex-ssh-gateway.bex-system.svc.cluster.local`), keeping `bex-api-sandbox-egress` strictly fail-closed.
3. Update `deploy/gitops/base/network-policies.yaml` ingress on `bex-ssh-gateway` to admit the broker port from `app.bex.co/regime=sandbox` pods only, and run `scripts/gitops-validate.sh` + `sessionegress` tests.
