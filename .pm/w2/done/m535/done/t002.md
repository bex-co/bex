## Objective

Stamp `bex.co/sandbox-group: <sbg-id>` on every `/v1/sandboxes` Pod created, resumed from idle suspension, or restored from a filesystem snapshot so `bex-ssh-gateway`'s Pod resolver can bind every source IP directly to its immutable sandbox group.

## Context

- `lego/backend/internal/sandbox/service.go` already stamps `app.bex.co/regime=sandbox`, `bex.co/sandbox-id`, and `bex.co/egress` in OpenSandbox creation metadata (`metadataEgress` etc.); `idle.go` and `snapshots.go` recreate/restore Pods.
- `deploy/gitops/base/sandbox-pod-admission.yaml` validates sandbox Pod invariants; check whether any ValidatingAdmissionPolicy expression needs updating or should enforce `bex.co/sandbox-group` shape.

## Steps

1. Define `SandboxGroupLabel = "bex.co/sandbox-group"` in `lego/backend/internal/sessionegress/sandbox.go` (or `sandbox` shared constants) and stamp it on every `/v1/sandboxes` create, idle resume, and snapshot restore (never on agent-session pods).
2. Verify `deploy/gitops/base/sandbox-pod-admission.yaml` admits pods carrying `bex.co/sandbox-group` and keeps all existing Pod security/runtime/nodeSelector invariants intact.
3. Add unit tests in `lego/backend/internal/sandbox/` asserting `bex.co/sandbox-group` is present and matches the resolved group ID on create (explicit group and default group), idle resume, and snapshot restore.
