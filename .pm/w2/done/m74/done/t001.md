## Objective

Prevent a definitively unauthorized user from entering or mutating the shared staged environment draft, with one localized reason covering both service and environment-group writes.

## Context

- w2/m73 made `EnvironmentEditor` the current variables/secret-files editor for both resource families; its write path is `can_create` while reveal/export remains independently sensitive.
- w9/m84's capability hook is permissive until a definitive projection loads. Preserve that loading/unknown contract.

## Steps

1. Thread `useCapabilities` into the shared editor boundary and compose `loaded && !canCreate` with existing busy/read-only states.
2. Disable Edit, draft add/remove/rename/generate/import/file mutations, and save/deploy/rebuild entry points with `PermissionTooltip` and the localized `reasonCanCreate`.
3. Audit any reachable legacy environment-variable editor so it cannot provide an alternate unauthorized write path; remove stale plumbing or apply the same boundary without duplicating policy.
