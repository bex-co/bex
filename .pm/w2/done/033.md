# Disk-snapshot Secrets don't reach new tenant namespaces (no projection) nor the bootstrap apps namespace

Why: `scripts/disk-snapshot-secret.sh install` copies `bex-disk-snapshot` + `bex-disk-snapshot-age` into namespaces matching `tea-*` **at run time** — a workspace namespace created afterwards gets neither, so its first disk-bearing App's backup Job dies in `CreateContainerConfigError` and restore is impossible until an operator re-runs the script; the bootstrap apps namespace (`default`, where hand-applied Apps land) is never covered at all (w2/m86 hand-copied them there).

- The KeyValue pipeline solved this with `BackupSourceNamespace` projection; disks deliberately have none (recorded in the script's comments). Options: operator-side projection of the two Secrets into workspace namespaces at namespace-provision time (the ADR043 `quotaForPlan` seam already touches every new namespace), or fold the copy into bex-api's workspace-namespace creation.
- Until fixed, the runbook should at least say "re-run install after new workspaces appear".

← filed from the w2/m86 drill session, 2026-09-02.

**Resolved 2026-09-08** — operator-side projection implemented (the note's first option, the ADR043/D8.4 `BackupSourceNamespace` pattern): `DiskSnapshotStore.SourceNamespace` (wired to the apps namespace) makes `reconcileDiskBackup` project `bex-disk-snapshot` + `bex-disk-snapshot-age` into each disk-bearing App's own namespace at reconcile time via the shared `projectBackupCredential` (protected-from-tenant-mount label, drift-refreshing) — new workspace namespaces and the bootstrap apps namespace are both covered with no script re-run. A missing canonical pair sets the named `SnapshotCredentialUnavailable` condition instead of scheduling a CronJob doomed to `CreateContainerConfigError`. `scripts/disk-snapshot-secret.sh` now seeds the apps namespace as the projection source (self-test updated, mutation-checked). Envtest pins projection + drift refresh + label + fail-closed branch; full operator `make test`/`make lint`/gitops-validate green. Runbook, operator CLAUDE.md, ADR082, and the apps-RBAC comment updated. Operational step on prod: re-run `scripts/disk-snapshot-secret.sh install` once so the apps namespace holds the canonical pair (the m86 hand-copy already put it there).
