## Objective

Prove the definition of done on production with the unmodified pinned Render CLI v2.36.

## Steps

1. Create group B and a sandbox in it; suspend a second one there (short `--idle-timeout`).
2. `bex sandbox-groups delete <B>` (preview, nothing changes), then `--confirm`: B leaves the list and both sandboxes leave `sandboxes list`; their rootfs images are gone from the registry.
3. `bex sandbox-groups delete <default> --confirm` → the CLI's default-group sentence.
4. `bex sandbox-groups default set <C>`; a create without `--group` lands in C; set the original default back.
5. Delete every fixture.

## Acceptance criteria

- [ ] Steps 2–4 pass on production, recorded with ids and times in this file.
