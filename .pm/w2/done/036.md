# w2/036 — Three dashboard env components are dead in the product, kept alive only by their own tests

Found while tracing every env value-field site for `w2/m95` t002.

`src/features/services/components/env-var-row.tsx`, `env-vars-panel.tsx` and `secret-files-panel.tsx` are imported by **no** route and by no other component. The service Environment tab (`routes/services.$serviceId.env.tsx`) renders `ServiceEnvironmentEditor` + `EnvGroupsPanel` instead; `EnvVarsPanel` and `SecretFilesPanel` have no caller at all, and `EnvVarRow` is used only by `EnvVarsPanel`.

`yarn lint:unused` (knip) does not flag them because knip treats `**/*.test.tsx` as entry points, and each has its own test file (`__tests__/env-vars-panel.test.tsx`, `__tests__/secret-files-panel.test.tsx`) that imports it. So the tests are the only thing keeping them reachable.

`w2/m95` deliberately did **not** convert their value fields to the auto-growing textarea, since converting unreachable code would be churn — the three live sites were swapped instead. That leaves them as the only env value fields still on a single-line `<Input>`, which is a drift trap if one is ever revived.

**What to do:** confirm the reachability claim (grep for each component name across `src/`, including dynamic imports), then delete the three components together with their test files; or, if one is genuinely wanted, wire it to a route and give it the `AutoTextarea` treatment. Good candidate for the `routine-dead-code` sweep rather than a milestone.

Filed 2026-09-15 by `w2/m95` t002.

## Resolved 2026-09-15 (same run that filed it)

Reachability re-confirmed by grepping every component name across `dashboard/src`: `EnvVarsPanel` and `SecretFilesPanel` had no caller at all, and `EnvVarRow` was used only by `EnvVarsPanel`. Deleted, with their two test files:

- `features/services/components/env-var-row.tsx`
- `features/services/components/env-vars-panel.tsx`
- `features/services/components/secret-files-panel.tsx`
- `components/__tests__/env-vars-panel.test.tsx`
- `components/__tests__/secret-files-panel.test.tsx`

Removing them let `knip` finally see a **fourth** dead file it had been unable to reach past the test-entry-point chain — `features/services/components/secret-file-row.tsx`, whose only consumer was the deleted `secret-files-panel.tsx`. Deleted too. That is the mechanism this note predicted: a test keeping a component alive also keeps that component's own dependencies alive.

Also removed the now-dangling `env-vars-panel.tsx` row from `common/lib/__tests__/mutation-error-toast-invariant.test.ts`'s census.

Gates after deletion: `yarn typecheck`, `yarn lint` (knip reports no unused files) and 3,345 dashboard tests green.
