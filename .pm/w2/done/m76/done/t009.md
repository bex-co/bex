## Steps

2. Policy tests (with t004): suppressed event ⇒ no deliveries either transport; quiet-hours deferral applies to webpush; per-service override honored.
3. Prune tests: fake push service returns 404 then 410 ⇒ each response revokes exactly the targeted subscription, other subscriptions and the Expo installation unaffected; retryable 429/5xx does not prune.
