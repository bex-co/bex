## Objective

Cover every git-push Build Source webhook path with deterministic unit and real-Postgres integration tests so regressions cannot silently disable Build Source auto-builds again.

## Context

- Existing webhook tests live in `lego/backend/internal/apps/webhook_test.go` and Build Source tests in `lego/backend/internal/apps/build_sources_test.go` and `lego/backend/internal/deploys/build_sources_test.go`.

## Steps

1. Add tests asserting a signed GitHub push to a git-backed Build Source's branch triggers a carrier build (`bld-…`) with commit metadata, and verify both URL matching and GitHub repo ID matching (`followRepository` on repo rename).
2. Add negative/filter tests: wrong branch, `buildFilter.paths` miss, `buildFilter.ignoredPaths` hit, `[skip render]` commit message, billing-enforced workspace, and image-backed Build Source.
3. Add an end-to-end carrier-build-to-fan-out test proving linked `autoDeploy: true` services deploy the resulting `bld-…` while linked `autoDeploy: false` and suspended services are skipped, and no service-only `commit_ignored`/`branch_deleted` facts leak.
