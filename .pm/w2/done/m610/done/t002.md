## Objective

Allow signed push webhooks in `GitWebhook.repoCandidates` to match git-backed Build Source carriers alongside ordinary services, while keeping image-backed Build Sources excluded and honoring branch matching, `buildFilter` (`paths`/`ignoredPaths`), `rootDir`, and commit skip phrases.

## Context

- `lego/backend/internal/apps/webhook.go:972-991` strips all build sources via `core.ServiceApps(list.Items)`.
- `lego/backend/internal/apps/webhook.go:1085-1165` evaluates `branchMatches`, `commitIgnoredReason` (`commitHasSkipPhrase` + `pathsIgnoredReason(spec.RootDir, spec.BuildFilter, paths)`), and billing mutation gates.
- `lego/backend/internal/core/build_source_guard_test.go` requires every `AppList` read to explicitly declare how it handles build sources.

## Steps

1. Update `repoCandidates` in `lego/backend/internal/apps/webhook.go` to keep both ordinary services and git-backed Build Source carriers (`core.IsBuildSource(a)` with `a.Spec.Repo != ""` and `a.Spec.Image == ""`), with a clear comment satisfying `TestEveryAppEnumerationDeclaresBuildSources`.
2. Ensure `followRepository` updates renamed/moved GitHub repo URLs on git-backed Build Source carriers just like services.
3. Ensure `redeployCandidates` evaluates `branchMatches`, `commitIgnoredReason` (`buildFilter` + `rootDir` + skip phrases), and `RequireBillingMutation` identically for git-backed carriers.

## Files

- `lego/backend/internal/apps/webhook.go`
- `lego/backend/internal/core/build_source_guard_test.go` (if allowlist/comment check needs updating)

## Acceptance criteria

- [x] A signed push matching a git-backed Build Source's repo + branch + `buildFilter` selects the carrier in `repoCandidates` and `redeployCandidates`.
- [x] A push outside `buildFilter.paths`, matching `buildFilter.ignoredPaths`, carrying `[skip render]`, targeting another branch, or hitting an image-backed Build Source does not trigger a build.
- [x] `TestEveryAppEnumerationDeclaresBuildSources` passes.
