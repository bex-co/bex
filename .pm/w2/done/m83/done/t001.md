## Objective

Leave one obvious way to attach a repository to a session.

## Context

- The composer renders both `Add repository` and `Mention a repository or session`, and the helper line also advertises `@ for a repo`. All three reach the same outcome.
- The mention path is the richer one: `w4/m36` made typing `@be` surface `bex-co/bex` directly, and it can also attach **prior sessions**, which the button cannot.
- So this is not "delete one button" — the merged control has to keep the mention picker's session-attach capability, or `w4/m36` regresses.
- Relevant components: `new-session-composer.tsx` (~388 lines), `mention-picker.tsx` (~210), `inline-mention-editor.tsx` (~455), `lazy-mention-editor.tsx`.

## Steps

1. Decide the single affordance and record the reasoning in the milestone README. Default: keep the mention picker as the mechanism and let one visible control open it.
2. Remove the redundant control, keeping one discoverable entry point for people who will not guess `@`.
3. Ensure repo **and** session attachment both remain reachable.
4. Reword the helper line to describe only what exists afterwards.
