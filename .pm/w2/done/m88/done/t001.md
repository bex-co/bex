## Objective

Decide the label scheme (proposed: keep `[self-hosted, Linux, ARM64]` and add `ci` or `production` as a fourth label) and classify every workflow under `.github/workflows/` + `lego/operator/.github/workflows/` into its trust pool by what secrets/environments it can touch. Write the operator runbook for re-labeling the physical fleet (which hosts join which pool, in what order, so queues never strand).

## Context

- Fleet: the operator's ARM64 self-hosted runners (ADR083, ADR019 §Decision 5). Runner labels are set host-side at runner registration — an operator step outside the repo, mirroring m85's protected-env pattern: repo work lands fail-safe, operator step documented.
- Classification signal: workflows using `environment:` gates, infra credentials, or kubeconfigs (`deploy.yml`, `app-cluster.yml`, `infra.yml`, `openbao-restore-drill.yml`, `keyvalue-restore-drill.yml`, `snapshot.yml`, `egress-meter-live.yml`, `ssh-edge-liveness.yml`…) vs pure test/lint (`backend-test.yml`, `dashboard-test.yml`, `operator-test.yml`, `go-lint.yml`, `cli-test.yml`, `scripts.yml`, `docs.yml`…). Verify each by reading its secrets usage, not by name.
- Jobs targeting a not-yet-existing label simply queue — that is the fail-safe if repo changes land before the fleet re-label.

## Steps

1. Inventory every workflow's secrets/environment usage; produce the classification table (goes in the runbook + t004's ADR update).
2. Choose the label names; document the re-label sequence (add `production` label to N hosts first, then flip workflows, then add `ci` to the rest).
3. Write the runbook under `docs/runbooks/` (no secrets in it).

## Files

- `docs/runbooks/` (new: runner-pool re-label runbook)
- classification table (feeds t002/t004)

## Acceptance criteria

- [ ] Every workflow appears exactly once in the classification table with its evidence (secret/environment usage); the runbook's ordering leaves no window where deploys can run on a `ci` host.

## Out of scope

- Executing the host re-label (operator step; verified in t004), ephemeral runners.
