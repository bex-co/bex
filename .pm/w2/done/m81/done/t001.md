## Objective

Deploy a kubelet-serving CSR approver (e.g. `postfinance/kubelet-csr-approver`) as a digest-pinned Argo CD Application so `kubernetes.io/kubelet-serving` CSRs from cluster nodes are approved automatically. Today **no approver exists anywhere in the repo** (grep confirms), and kube-controller-manager never auto-approves serving CSRs, so kubelets fall back to self-signed serving certs.

## Context

- ADR072 finding 5 (deferred; re-reported ADR061 #11, ADR063 #9) records the plan: approver → `--kubelet-certificate-authority` → drop the insecure flag. ADR036 §92 already *claims* all kubelet server certs are `bex-ca`-signed — aspirational until this lands.
- The GitOps base only admits immutable sources: every chart must come from the reviewed mirror `oci://ghcr.io/bex-co/bex-charts/<chart>` with a `sha256:` targetRevision, `project: bex-platform`, and a matching row in `deploy/helm-artifacts.lock` (`scripts/gitops-validate.sh` enforces all of this; mirror via `bash scripts/helm-artifact.sh mirror`).
- Model Application: `deploy/gitops/base/metrics-server.yaml` (sync-wave, platform-pool nodeSelector/toleration, kube-system destination — already in `appproject.yaml`'s destinations).

## Steps

1. Pick the approver (postfinance/kubelet-csr-approver Helm chart is the default candidate); review the chart, then mirror it with `scripts/helm-artifact.sh mirror` and add the `deploy/helm-artifacts.lock` row.
2. Add `deploy/gitops/base/kubelet-csr-approver.yaml` Application + register it in `deploy/gitops/base/kustomization.yaml`. Pin to the platform pool like metrics-server.
3. Configure tight matching values: provider regex for node names (CAPD `bex-*` and CAPH machine names), require IP SANs inside the node's addresses, restrict DNS SANs to the node name, and cap SAN counts. No bypass mode.
4. Render-check with `bash scripts/gitops-validate.sh`; apply to the mock cluster and confirm the deployment is healthy.

## Files

- `deploy/gitops/base/kubelet-csr-approver.yaml` (new)
- `deploy/gitops/base/kustomization.yaml`
- `deploy/helm-artifacts.lock`
- `deploy/gitops/overlays/local/kustomization.yaml` (only if a local-scale patch is needed)

## Acceptance criteria

- `scripts/gitops-validate.sh` passes (mirror + lock + bex-platform project checks green).
- Approver pod runs on the mock cluster; its logs show it watching CSRs; no CSR is approved that fails the matching rules.

## Out of scope
