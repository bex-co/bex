## Objective

Expose a gateway-authenticated internal endpoint on `bex-api`'s control-plane listener (`:8091`) that resolves a verified `/v1/sandboxes` Pod's `networkPolicy` and its sandbox group's active enabled credentials (including OpenBao-resolved secret values) for `bex-ssh-gateway` alone.

## Context

- `bex-ssh-gateway` already calls `bex-api` on the internal control-plane port (`:8091`, allowed by `allow-ssh-gateway-to-cp-api` in `deploy/gitops/base/network-policies.yaml`) for agent-session credential and egress grants (`lego/backend/internal/agentsession/`).
- This endpoint must reject agent-session Pods (`bex.co/agent-session` present), verify `(workspaceID, sandboxID, sandboxGroupID)` consistency against `sandbox_records`/`sandbox_group_members`, and never be mounted on the public `:8090` mux.
- Include a monotonic group-credential version/etag or short cache TTL (≤ 5 s) so disable/delete/update/restore cuts off promptly.

## Steps

1. Define the internal broker grant request/response contract in `lego/backend/internal/sandbox/broker_cp.go` carrying the sandbox's verified `networkPolicy` (`allow-all`, `deny-all`, `allow-list` rules), active enabled credentials (`id`, `domain`, `methods`, `paths`, `injection`, resolved secret value from OpenBao), and a group version stamp.
2. Mount the handler on `bex-api`'s internal `:8091` control-plane mux with the same gateway shared-secret/mTLS auth used by `agentsession` internal mint routes, and ensure any OpenBao failure fails closed (503, never silent allow).
3. Add a typed Go client for `bex-ssh-gateway` to call this internal endpoint with bounded timeouts and short-TTL in-memory caching (≤ 5 s; zero disk persistence).

## Acceptance criteria

- [ ] Internal `:8091` endpoint authenticates only `bex-ssh-gateway`, verifies `(workspace, sandbox, group)` ownership, rejects agent-session pods and ended/foreign sandboxes, and returns `networkPolicy` + enabled group credentials with OpenBao secrets.
- [ ] Endpoint is unreachable on `:8090` public API and never logs secret values.
