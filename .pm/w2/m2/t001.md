## Objective

Add the deploy verb: a single call takes `{repo, bex.yml}` and writes a build-from-git `App` CR (create or patch), so the platform builds and runs it to a live URL.

## Context

- The control plane owns app creation (tenants/apps/domains) — `docs/control-plane.md`; the create-app API lands in w1/m2 (t006). Deploy builds on that row → `App` CR projection.
- Build-from-git (`App.spec.repo`) must work in-cluster — that's w1/m5. Until then deploy can target prebuilt images only.
- Keep it a `Core.Deploy` method so REST, GraphQL, and MCP all share one impl.

## Steps

1. Add `Core.Deploy(repo, bexYml)` → construct/patch the `App` CR (map `bex.yml` fields to `App.spec`).
2. Expose `POST /v1/deploy` in the REST adapter returning the service object.
