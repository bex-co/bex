## Objective

Have `StartConnect` mint a short-lived, HMAC-signed `state` token encoding the caller's resolved `workspaceID` and an expiry, appended as a `state=` query param on the returned `installUrl`.

## Context

- `lego/backend/internal/github/service.go` `StartConnect` (~line 97-112) currently builds the install URL purely from `s.GitHub.InstallURL()` with no per-request/session-bound token.
- GitHub's Setup URL preserves a `state` param automatically as a documented passthrough on the manifest/install flow — it comes back unmodified on the redirect to the callback.
- Needs a signing secret: reuse `BEX_GITHUB_APP_PRIVATE_KEY` or add a small dedicated `BEX_GITHUB_STATE_SECRET` (HMAC-SHA256, out-of-band like other platform secrets per `docs/ADR012-auth.md`'s custody pattern).

## Steps

1. Add HMAC-SHA256 state-token minting: `base64(workspaceID|expiry|hmac)`.
2. If a new env var is needed, add it to root `CLAUDE.md`'s env table and `.env.example`/`.env.template`.
3. Append `state=<token>` to the `installUrl` `StartConnect` returns.

## Files

- `lego/backend/internal/github/service.go`
- `CLAUDE.md`, `.env.example`, `.env.template` (if a new secret is added)

## Acceptance criteria

- [ ] `StartConnect`'s returned URL includes a `state` param.
- [ ] The token is opaque and tamper-evident (HMAC-signed).
