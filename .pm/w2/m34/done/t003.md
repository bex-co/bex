## Objective

Have the callback handler verify the `state` query param (HMAC + expiry + tamper check) and reject the request with a clear error if it's missing, invalid, or expired.

## Context

- `lego/backend/internal/github/rest.go` callback handler (~line 43-59) currently reads only `installation_id` off the query string.
- This is the actual authentication mechanism for the now-auth-gate-exempted route (t002) — the state token IS the credential.

## Steps

1. Parse and verify `state` (HMAC signature, expiry) using the same secret minted in t001.
2. On failure, return a clear error (400/401) rather than silently proceeding.
3. On success, extract the encoded `workspaceID` for use in t004.

## Files

- `lego/backend/internal/github/rest.go`

## Acceptance criteria

- [ ] Missing/tampered/expired `state` is rejected with a clear error.
- [ ] Valid `state` yields the correct `workspaceID`.

## Out of scope

- Using the resolved `workspaceID` to complete the connection (t004).
