## Objective

Let `GET /v1/git/callback` reach its handler without a session/Bearer credential, since GitHub's redirect carries neither — while keeping every other route on the existing blanket auth gate.

## Context

- `lego/backend/internal/api/auth.go` `middleware` currently requires `Authorization: Bearer` or a Kratos session credential for every route; GitHub's post-install redirect has neither, so it 401s before the `Connect` handler in `github/rest.go` ever runs.
- This is a deliberate, narrow exception — the file's own doc comment states "every route sits behind the same gate" today; that invariant needs an explicit, well-justified carve-out for exactly this one route, not a general bypass mechanism.
- The state-token verification (t003) is what actually authenticates the request once it reaches the handler — this task only lets it reach the handler.

## Steps

1. Add a narrow, explicit route-level exception in the auth middleware (e.g. a small allowlist of paths matched by exact string, not a pattern) for `GET /v1/git/callback` only.
2. Comment clearly: state-token-is-the-credential for this route, not "no auth."
