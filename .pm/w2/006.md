# GraphQL `triggerDeploy` mutation — unblocks the dashboard Manual Deploy button

`w2/m5` deliberately shipped deploy-trigger REST-only (`lego/backend/internal/deploys/graphql.go`: "No mutation: triggering a deploy is REST-only for now"). The dashboard is a GraphQL client, so Render's **Manual Deploy** header action (deploy latest commit) has nothing to call — the parity ledger's "Trigger a deploy" row is UI ✖. Add a mutation delegating to the same core verb as REST `POST /v1/services/{id}/deploys` (one core, thin adapters), Render-consistent semantics/naming (check Render's captured dashboard operations for the operation name to mirror).

The UI half (the Manual Deploy button) rides `w5/007`'s Events/Deploys-tab milestone at promotion — 007 amended 2026-07-12 to include it.
