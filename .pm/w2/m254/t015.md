## Objective

Bill a build source's builds as Render bills Build Source build minutes. Carrier builds currently go unmetered because the usage rollups enumerate `ListApps`, which excludes carriers.

## Context

- `lego/backend/internal/usage/service.go` `rollup`/`catchUp` → `catchUpAppThrough` meters instance, egress and build seconds per service row; `queryBuildSeconds` sums build Jobs labelled `app.bex.co/build=<CR name>`.
- A carrier has build Jobs only: no instances, no egress.
- Usage rows, invoice lines and the dashboard usage view key on the service id; a carrier's id is `bds-…`.

## Steps

1. Enumerate carriers alongside services for the build meter only (`build_seconds`), keeping instance/egress off for them.
2. Make sure billing (Stripe/Metronome lines) and the usage surfaces attribute `bds-` rows to the build source by name.
3. Declare the enumeration in `TestEveryAppEnumerationDeclaresBuildSources`.

## Files

- lego/backend/internal/usage/
- lego/backend/internal/store/usage.go

## Acceptance criteria

- [ ] A carrier build's Job duration appears as `build_seconds` for the build source, and is billed like a service build.
- [ ] A carrier never records instance or egress usage.

## Out of scope

- Build retention.
