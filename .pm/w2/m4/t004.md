## Objective

Prove the whole loop on a real cluster: an MCP client calls `create_web_service` with a prebuilt image and gets a service that converges to a live `*.onbex.co` URL; `delete_service` removes it cleanly; the accepted-but-pending `repo` path is exercised and truthful.

- In-memory MCP client↔server round-trip tests already exist (`mcp_test.go` pattern from w2/m1) — extend for the new tools; the live check runs against the mock cluster.

## Steps

1. Extend the MCP round-trip test: `create_web_service` advertised, creates through the same write path as REST; `delete_service` removes.

3. Repo-body create: accepted, service visible with a truthful non-live state (until w1/m5).
