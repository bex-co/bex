## Objective

Periodically compare each service disk's used bytes to its spec size and detect crossings.

## Context

- Used bytes: `kubelet_volume_stats_used_bytes` query in `metrics/source.go`; size from `spec.disk.sizeGB` (not PVC capacity, see comments at `source.go:702`).
- Replica-safety: leader election or SKIP LOCKED pattern used by other bex-api workers.

## Steps

1. Add a sweep (bex-api worker) over Apps with disks.
2. Above at ≥80%, below at <75% (or ADR-recorded values); persist last state per disk.
