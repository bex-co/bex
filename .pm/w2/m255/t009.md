## Objective

dev-N has no Prometheus and no `BEX_PROM_URL`, so `newDiskUsage` never starts and the disk alert cannot be walked locally (D1=A, 2026-11-07). Add a minimal Prometheus to `scripts/dev-env.sh up` that scrapes kubelet volume stats, and point dev-N's bex-api at it.

## Acceptance criteria

- [ ] `dev-env.sh N up` brings up Prometheus, sets `BEX_PROM_URL`, and its status check shows it ready.
- [ ] A disk on local-path reports usage through the query the sweeper uses; if `kubelet_volume_stats_used_bytes` is absent for local-path, an equivalent source is chosen and documented.
- [ ] `scripts/dev-env.test.sh` covers the new stage.
