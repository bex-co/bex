## Objective

Ship an explicit, operator-invoked migration that moves every legacy `env-groups/<gid>/*` entry to its workspace prefix, verifies the copy, and tombstones the legacy path — idempotent and resumable so a partial run can simply be re-run.

## Context

ADR066's residual register (docs/ADR066-security-review-round11.md:51) calls for "explicit operator migration, same shape as w7/m70". Note the precedent nuance: m70 shipped **lazy first-read migrate-and-delete** (`readMap` in `lego/backend/internal/secrets/store.go`) rather than a standalone command; the closest command-shaped precedent is the env-gated maintenance mode `BEX_ENV_GROUP_NAME_CLAIM_AUDIT=dry-run|apply` (`lego/backend/cmd/api/main.go:416` → `envgroups.AuditNameClaims`, `nameclaims.go`). Mirror that: an env-gated startup migration with dry-run and apply modes.

## Steps

1. Add `envgroups.MigratePaths(ctx, store, dryRun)` walking `store.List(ctx, "env-groups")`: for each gid read meta, resolve `workspace` (empty workspace ⇒ report + skip, never guess), copy meta/env/files/revision to the workspace prefix, re-read and compare (verification), then tombstone the legacy path (delete, or an explicit marker if delete would break t001's fallback mid-run — pick one and document it).
2. Idempotency: a group already present at its workspace prefix (and absent/tombstoned at legacy) is a no-op; re-running after a crash resumes cleanly. Never overwrite a newer new-prefix copy with legacy data.
3. Migrate the name-claim entries only if the chosen scheme moved them (they are already workspace-digested, `service.go:1348`).
4. Wire an env-gated invocation (e.g. `BEX_ENV_GROUP_PATH_MIGRATION=dry-run|apply`) in `cmd/api/main.go`, mirroring the name-claim audit's report logging; document the new var in CLAUDE.md's env table only if the milestone owner approves — otherwise keep it runbook-only (t005).
5. `cd lego/backend && go test ./...` green.

## Files

## Acceptance criteria

- Dry-run reports moves without writing; apply moves + verifies + tombstones; both logged per group.
- Re-running apply after an injected mid-run failure completes with no loss or duplication (test-asserted).
- A group whose meta lacks a workspace is reported and left readable via the legacy fallback.

## Out of scope

- Running against prod (t005's authorization-gated runbook); retiring the legacy fallback read (post-cutover follow-up).
