## Objective

Lock the milestone's invariants in tests: prefix isolation (a workspace's reads cannot touch another's prefix), dual-read fallback correctness, and migration idempotency + verification.

## Context

Standing closing task. Model on w7/m70's shipped suite (`TestOpenBaoStore_TenantScopedPaths`, `TestReadMap_LazilyMigratesLegacyData`, cross-workspace isolation asserts) and the existing envgroups tests (`lego/backend/internal/envgroups/envgroups_test.go`, `nameclaims_test.go`, `patch_test.go`, `purger_test.go`, `seam_test.go`). A recording fake `core.SecretKV` that captures every path touched is the key instrument — isolation is proven by asserting the absence of foreign-prefix reads, not just correct results.

## Steps

1. Prefix isolation: seed groups in workspaces A and B; assert list/get-by-name/membership/reveal for A never issue a store operation under B's prefix (recorded-path assertion), and that results are disjoint.
2. Dual-read fallback: a legacy-path group is fully readable (get, reveal, links, revision) pre-migration; a same-named legacy group still blocks a name claim (t003 step 4).
3. Migration: dry-run writes nothing; apply copies + verifies + tombstones; re-run is a no-op; injected mid-run failure resumes without loss/duplication; workspace-less meta is skipped + reported (extend t002's tests if gaps remain).
4. Quota: `ENV_GROUP_LIMIT` refusal unchanged across REST/GraphQL/MCP (extend the existing quota tests to the new layout).
5. Purge/delete: deleting a migrated group leaves nothing at either prefix; deleting a legacy group during the dual-read window cleans both.
6. `cd lego/backend && go test ./...` green; confirm the integration-gated suites (`BEX_TEST_DB_URI`/`BEX_TEST_OPENFGA_URL`) still pass in CI.
