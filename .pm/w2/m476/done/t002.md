## Objective

Add `lego/backend/internal/oidcissuer`: load the key set, mint a signed JWT for (workspace, environment or `default`, service, audience) with the ADR's claims, and expose the public JWKS.

## Context

- Ids come from `lego/backend/internal/id` (never format ids by hand; AGENTS.md id rule).
- Use an existing JOSE library already in `lego/go.work` modules if one is present; otherwise pick one and justify it in the PR.

## Steps

1. Implement the claim builder and the signer.
2. Unit-test that a minted token verifies with an independent verifier through the JWKS alone, that `sub`/`iss`/`aud`/`exp` are exact, and that a token for workspace A fails a verifier configured with workspace B's issuer.

## Files

- `lego/backend/internal/oidcissuer/` (new)

## Acceptance criteria

- [x] `go test ./internal/oidcissuer/...` covers claims, verification, cross-workspace refusal and an expired token.

## Done (2026-11-18)

`lego/backend/internal/oidcissuer`: `keys.go` (P-256 key generation, PKCS#8, RFC 7638 thumbprint, the state function `Classify`), `keyset.go` (each replica's cached view, reloaded every minute), `issuer.go` (`Subject`, `Mint`). Signing uses `golang-jwt/jwt/v5`, already a backend dependency; the tests verify with `coreos/go-oidc/v3` + `go-jose/v4` (already pinned in the workspace by the CLI module), so the verifier shares no code with the signer. `id.Is(kind, s)` is the strict id check (the xid must decode, as Render's issuer requires). Tests: `TestMintCarriesRendersClaims` (exact header and five claims), `TestATokenVerifiesThroughItsWorkspacesDiscoveryOnly` (own issuer verifies; another workspace's issuer, another audience and an expired token fail), `TestSubjectIsRendersTemplate`, `TestSigningRefusesAStaleOrUnloadedKeySet`.
