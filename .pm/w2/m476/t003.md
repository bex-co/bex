## Objective

Make the key set durable and rotatable: bootstrap a key when none exists, publish the next key before it signs, retire the previous one only after its tokens have expired.

## Context

- Key custody per the ADR (D5 recommends a `bex-system` Secret).
- bex-api runs two replicas: bootstrap must not race (one writer).

## Steps

1. Implement bootstrap and the rotation states (next → current → previous → removed).
2. Add a rotation command or script plus a runbook under `docs/runbooks/`.
3. Exercise one rotation on dev-2.

## Files

- `lego/backend/internal/oidcissuer/`
- `docs/runbooks/oidc-key-rotation.md` (new)
- `lego/backend/AGENTS.md` (any new env var)

## Acceptance criteria

- [ ] On dev-2, a token signed before a rotation still verifies until it expires, and new tokens carry the new `kid`.
- [ ] Two replicas starting together create exactly one key.

## Out of scope

- Hardware-backed keys or OpenBao transit (record as a follow-up if the ADR prefers it later).
