## Objective

Add meaningful regression coverage for the SSH contract's real success, denial, lifecycle, and isolation behavior across core services, adapters, protocol handling, Kubernetes exec, manifests, and dashboard.

## Context

- Authentication success alone is insufficient: the highest-risk bugs are cross-tenant targeting and overly broad exec RBAC.
- Protocol tests need PTY resize, exit status, cancellation, and unsupported-channel behavior rather than snapshots.
- A real-cluster smoke test complements but does not replace deterministic unit/envtest coverage.

## Steps

1. Cover public-key parsing/fingerprints/dedup/ownership, key deletion races, and fingerprint lookup.
2. Cover service/instance eligibility, foreign-workspace authz, stale/non-Ready pods, shell-less images, session caps, timeouts, resize, exit status, disconnect, and pod deletion.
3. Add REST/GraphQL/MCP parity tests, dashboard interaction tests, and manifest/RBAC/network-policy guards.
4. Run backend `go test ./...`, operator `make test`, dashboard `yarn test`, lint/typecheck, and the redacting live smoke where the environment permits.

## Acceptance criteria

- [ ] Tests prove both a successful real session and the major failure modes without tautologies or blanket snapshots.
- [ ] A regression granting bex-api exec or gateway secret/platform access fails a structural test.
- [ ] Relevant Go and dashboard suites, lint, typecheck, and manifest validation pass.

## Out of scope

- Inflating coverage with trivial getters or testing third-party SSH/Kubernetes libraries themselves.
