## Objective

Register all 7 Render REST endpoints for sandbox group credentials on the public API mux, match Render's exact response shapes/status codes (`201`, `200`, `202` on delete, `429` with `RateLimit-*`/`Retry-After`), retire `sandbox/notoffered.go`, and remove the 7 entries from `renderOperationOmissions`.

## Context

- Routes currently return `404 SANDBOX_CREDENTIALS_UNSUPPORTED` via `sandbox.NotOfferedRoutes` (`lego/backend/internal/sandbox/notoffered.go`) mounted in `lego/backend/internal/api/server.go`.
- `lego/backend/internal/api/key_permission_ops.go` already declares all 7 REST patterns under `KeySandboxesHistory` and `KeySandboxesCredentials`.
- `lego/backend/internal/api/render_operation_coverage_test.go` lines 29–35 list the 7 operations in `renderOperationOmissions`; once mounted, those 7 entries must be removed so `TestEveryRenderOperationMountedOrDocumented` stays green.
- `DELETE /v1/sandbox-groups/{sandboxGroupId}/credentials/{credentialId}` returns **202 Accepted** (empty body) per Render's pinned spec, not 204.
- `GET /v1/sandbox-groups/{sandboxGroupId}/credentials` returns a bare JSON array (sorted by `id`, `[]` when empty); `GET .../versions` returns a bare JSON array (newest version ID first).

## Steps

1. Add `lego/backend/internal/sandbox/credentials_rest.go` registering all 7 routes in `Service.RegisterREST` with strict JSON decoding (`WithStrictJSONDecoding`) and exact status codes (`200`, `201`, `202`, `400`, `403`, `404`, `409`, `429` with `Retry-After` / `RateLimit-*`, `503`).
2. Remove `sandbox.NotOfferedRoutes` wiring from `lego/backend/internal/api/server.go` and remove `lego/backend/internal/sandbox/notoffered.go` (and update `lego/backend/internal/sandbox/cli_flags_test.go` where it asserted `404 SANDBOX_CREDENTIALS_UNSUPPORTED`).
3. Remove the 7 `*-sandbox-group-credential*` entries from `renderOperationOmissions` in `lego/backend/internal/api/render_operation_coverage_test.go` and verify the OpenAPI request validator accepts valid calls and rejects malformed bodies.
