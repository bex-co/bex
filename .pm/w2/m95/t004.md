## Objective

## Steps

3. **Compare with Render.** Check Render's env editor for multi-line values and its `.env` import escape rules (docs say only "valid `.env` syntax"); note what Render does, with the date. For `PORT`, Render honors it; bex refuses. Confirm the ADR018 row from t003 says so.
4. **Inventory.** List any production services or env groups that already hold a `PORT` key (read-only) in the README, so the operator can decide whether to clean them up.
5. **Record drift.** File any divergence found as `w2/NNN`.
