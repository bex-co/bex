## Objective

Every env value field in the dashboard is a single-line `<Input>`, so the browser flattens a pasted or filled line break into a space before the value ever reaches state. A pasted PEM key or JSON blob is saved changed, with no warning. Replace each value field with an auto-growing textarea that starts at one row, so multi-line values are kept and an imported multi-line draft is displayed truthfully instead of run together.

## Context

- Value field sites (w1/done/099):
  - `EnvDraftItem` in `dashboard/src/features/services/components/service-environment-editor.tsx:1159-1181`, shared by the service Environment page (`routes/services.$serviceId.env.tsx:47`) and the env-group detail editor (`features/env-groups/components/env-group-editors.tsx:30`).
  - `NewEnvGroupDialog` in `features/env-groups/components/new-env-group-dialog.tsx:248-251`, used by `routes/env-groups.tsx:119` and `env-groups-panel.tsx:153`.
  - `env-var-row.tsx:114` and `env-vars-panel.tsx:325`, `:337` (consumers not yet traced; trace them first, the create-service form's env rows are the likely one).
- Live evidence: pasting two lines into the value field read back `first second`; an imported four-line PEM draft displayed as one run-together line although state held the newlines.
- `w1/m153` just touched `service-environment-editor.tsx` (poll guards). Rebase on main before editing.
- shadcn has a `Textarea` component under `dashboard/src/components/ui/`. Check for an existing auto-resize helper before writing one.

## Steps

1. Trace the consumers of `env-var-row.tsx` and `env-vars-panel.tsx` and list every site in this task's Context when done.
2. Add (or reuse) a one-row auto-growing textarea component: `rows=1`, grows with content up to a sane max (for example 10 rows) then scrolls, no resize handle, same visual height as the neighboring key `<Input>` when single-line, Enter inserts a newline (does not submit the form), keyboard and reveal/masking behavior preserved where the field is a secret.
3. Swap each value `<Input>` for it. Keep every existing prop: `aria-label`, placeholder, disabled state, masking, `data-testid`s.
4. Verify pasting a three-line value keeps three lines in state and in the `PatchServiceEnvironment` payload, and that an imported multi-line draft renders on multiple lines.
5. Verify the Import dialog, Generate secret, and the reveal toggle still work on the swapped field.
