## Objective

Make the optional signature-verification webhook select real tenant Pods and reject unverifiable images when the feature is enabled.

## Context

- The webhook namespace selector expects `bex.co/workspace`.
- Production tenant namespaces do not carry that label; Pods carry `app.bex.co/workspace`.
- `failurePolicy: Ignore` makes configuration/readiness failures silent bypasses.

## Steps

1. Choose and implement an object/namespace selector that matches only intended tenant Pods.
2. Add readiness and rollout ordering that permits fail-closed activation safely.
3. Switch enabled-mode failure policy to Fail and keep disabled-mode behavior byte-identical.
4. Verify signed allow, unsigned deny, tampered deny, and platform-pod non-selection.

## Acceptance criteria

- [ ] Rendered selectors match actual tenant Pod labels and exclude platform Pods.
- [ ] Enabled verification fails closed without blocking webhook rollout itself.
- [ ] Live signed/unsigned/tampered controls produce the intended admission results.

## Out of scope

- Enabling signing by default for development clusters.
