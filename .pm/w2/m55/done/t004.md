## Steps

1. Add xterm.js (`@xterm/xterm`, fit addon) to the dashboard deps; create a terminal component (mount xterm, fit to container, theme to match the dashboard).
2. On open: call the t002 ticket endpoint for this service, then connect the gateway WS with the ticket; pipe WS data ↔ xterm; send resize (fit addon `onResize` → WS resize control message → gateway `window-change`).
3. Keep the copy-ready `ssh …` command block above the terminal; keep the "Manage SSH public keys" deep link.
