## Objective

Implement the Builds tab (`/build-sources/$buildSourceId` index route) listing all builds for a Build Source with status badges, commit link / image digest, start/finish duration, cursor pagination, live polling while a build is active, and a breakpoint-matched skeleton.

## Context

- Backend GraphQL `builds(buildSourceId, cursor, limit)` (`lego/backend/internal/deploys/build_sources.go:777`) returns `Build` objects with `id` (`bld-…`), `buildRun` (`id`, `status`, `buildStartedAt`, `buildFinishedAt`, `runtime`, `commitId`, `commitUrl`), `image` (`sha`, `ref`, `imageUrl`), `deploys`, `skippedServices`, `cursor`, `createdAt`, `updatedAt`.
- Reuse the dashboard's shared `Table`, status badge, commit-link, and duration helpers (matching `deploys-list-page.tsx`).

## Steps

1. Create `dashboard/src/routes/build-sources.$buildSourceId.index.tsx` and `BuildSourceBuildsTab` component.
2. Render each build row (`bld-…`) with status badge, commit SHA/link (or image ref/digest), duration/timestamp, fan-out deploy count badge, and click/row link to `/build-sources/$buildSourceId/builds/$buildId`.
3. Enable bounded polling while any build is in an active/non-terminal status; support cursor-based "Load more" pagination.
4. Provide clean empty state (with Trigger Build CTA for git sources if `can_create`), error state, and breakpoint-matched skeleton.
