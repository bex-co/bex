## Objective

Confirm production can actually run what t001 sells: two instances of each new tier on distinct nodes, plus room for read replicas and autoscaler growth.

## Context

- Node types and pools: [ADR053](../../../docs/ADR053-node-instance-types.md), `deploy/gitops/base/autoscaler.yaml`.
- Operator HA projection: `spec.highAvailability` raises CNPG instances to ≥2 with pod anti-affinity; `w7/done/m90` keeps CNPG's PDB only for multi-instance clusters.
- Storage: per-instance Hetzner volumes (grow-only, `w2/done/m60`); read replicas add instances (`w8/m50`, ADR009 Capacity admission).

## Steps

1. Compute per-instance requests/limits for each chosen tier and compare to allocatable on each node type.
2. Confirm anti-affinity can be satisfied (≥2 eligible nodes) and the autoscaler can add a node when it cannot.
3. Record any tier that does not fit, with the smallest change that would make it fit; feed back to t001 if the list must change.
