## Objective

Prove the shipped idle suspension on production, signed in as the QA user (`bash scripts/qa-login.sh`; log out after).

## Steps

1. Create a sandbox with `--idle-timeout 300` and write a marker file.
2. Wait about 5 minutes: the status goes `suspending` → `suspended`, and `sandbox_compute_seconds` stops.
3. Run `bex sandboxes exec`: it resumes (`resuming` → `running`), runs the command, and the marker file is there.
4. Delete the sandbox.

## Acceptance criteria

- [ ] Each status and the exec output are recorded with timestamps in the milestone README.
- [ ] The memory/process loss is expected (D1=A, 2026-11-11), not a failure.
