## Objective

Produce a single checked-in classification table assigning every registered REST route, GraphQL query/mutation, and MCP tool to a scope class (read / write / credential-mint), with a guard test that fails when a new operation is added unclassified.

## Context

Enforcement (t003) is only as good as its coverage. The API surface is assembled feature-by-feature: REST routes register onto the mux via each feature's `RegisterREST` (`lego/backend/internal/api/server.go`, `restRegistrar` ~line 800, `restHandler` ~line 1089), MCP tools live in per-feature `mcp.go` files (`lego/backend/internal/<feature>/mcp.go` — apikeys, deploys, metrics, secrets, workspaces, …), and GraphQL resolvers in per-feature `graphql.go` files. The repo already has guard-test precedent for exhaustive surface sweeps (`lego/backend/internal/api/alwayspublic_guard_test.go`, `conformance_*_test.go`) — follow that pattern so the table cannot silently rot.

## Steps

1. Enumerate the three surfaces mechanically (mux walk / MCP tool registry listing / GraphQL schema introspection) rather than by hand.
2. Define the table as code (a Go map or slice in a new file under `lego/backend/internal/api/`, e.g. `scope_matrix.go`) so t003 consumes it directly; mint verbs must agree with the `AuthorizeMintClass` call sites (`apikeys`, `sshkeys`, `deploys` deploy-hook verbs).
3. Classify every operation: reads (GET routes, GraphQL queries, list/get MCP tools) vs writes (mutating verbs) vs credential-mint (the round-7 class). Ambiguous cases (e.g. shell/exec tickets, log SSE) get an explicit decision recorded in a comment.
4. Write the guard test: enumerate each surface at test time, assert every operation appears in the table exactly once, and fail with the operation name when one is missing.
5. Confirm the guard passes on the current surface (`cd lego/backend && go test ./internal/api/...`).

## Files

- `lego/backend/internal/api/scope_matrix.go` (new — table)
- `lego/backend/internal/api/scope_matrix_guard_test.go` (new — guard)
- Read-only: `lego/backend/internal/api/server.go`, per-feature `mcp.go` / `graphql.go` files, `lego/backend/internal/api/alwayspublic_guard_test.go` (pattern)

## Acceptance criteria

- Table covers 100% of registered REST routes, GraphQL queries/mutations, and MCP tools; the guard test fails (with a useful name) on an unclassified addition.
- Mint-class rows exactly match the `AuthorizeMintClass`-gated verbs.
- No enforcement behavior change yet (table + guard only).

## Out of scope

- Wiring the table into the auth gate (t003); consent/discovery changes (t004); reclassifying any operation's underlying authorization relation.
