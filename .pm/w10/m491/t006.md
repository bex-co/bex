## Objective

Every turn whose undelivered work was kept, continued from or lost says so on every API surface, with what was at stake, and the next turn's agent is told where it starts.

## Context

- `turnRetention` (`lego/backend/internal/agentsessions/turn_retention.go:85`) answers `none` for a turn that was not interrupted; REST `TranscriptTurn`, GraphQL (`graphql.go:544`) and MCP (`get_agent_session_transcript`, `mcp.go:297`) carry `retention`, `retainedUntil`, `retentionLostReason`, `startNote`.
- `retainedFresh` (`retention.go:308`) speaks only of "the stopped turn".
- The continuity env (`continuity.go`) primes a fresh agent from the transcript; the driver leaves an existing checkout alone (`ensureRepo`).

## Steps

1. Read retention from the turn's record whatever ended it, and add the cause (`stopped`, `failed`, `replaced`, `idle_closed`) and the stake (`unpushedCommits`, `uncommittedChanges`) to the turn on all three surfaces, with matching descriptions.
2. Reword `retainedFresh` and add the lost case to the next turn's start note: "The N unpushed commits and uncommitted changes from turn K were lost (<reason>), so this turn started from a fresh checkout of the branch."
3. Tell the next turn's agent in its prompt preamble whether it starts from the restored checkout or from a fresh one that lost that work (env from bex-api, rendered by the driver).
