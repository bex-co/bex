## Objective

The `bex` CLI sets and shows each level with t001's flags. A session create and an automation save carry `agentConfig.githubCli`. `bex agent env set` writes the automations default and the mandatory flag. `bex agent env`, `bex agent get` and the automation reads print them.

## Context

- `sessionFlags` (`lego/cli/internal/agent/agent.go:535`) is shared. `createFlags` (`:565`) embeds it for `run`, `chat` (`chat.go:73`) and `handoff` (`handoff.go:42`), and the automation template flags embed it too (`automations_flags.go:290`). One flag there reaches all of them.
- `bex agent automations create`/`update` are in `lego/cli/internal/agent/automations.go:358` and `:420`. `apply`/`export` are in `automations_apply.go`. `bex agent get` is `agent.go:789`.
- `bex agent env set --github-cli on|off` is in `lego/cli/internal/agent/config.go:426`–`:510`. It shows a field missing from an older bex-api as on, and the new fields need the same tolerance (missing means inherit and not mandatory).
- The CLI imports no sibling module. It speaks REST.

## Steps

1. Add `--github-cli on|off` to `sessionFlags` and to the automation create and update flags. Leave the field out when the flag is not given, and treat any other value as a usage error.
2. Add t001's two `bex agent env set` flags, and print the fields in `bex agent env` (for example `GitHub CLI off (mandatory)` and `Automations GitHub CLI inherit`).
3. Print a session's and an automation's binding where their reads print the template and model.
4. Name the refusal codes in the help, the way `--github-cli` names `githubCliEnabled` today.

## Files

- `lego/cli/internal/agent/agent.go`, `automations.go`, `automations_flags.go`, `automations_apply.go`, `config.go`, and their tests

## Acceptance criteria

- [x] `bex agent run --github-cli off …` sends `agentConfig.githubCli: false`. Without the flag the field is absent. `--github-cli maybe` is a usage error.
- [x] `bex agent automations create`/`update --github-cli off` saves it, and `export` then `apply` round-trips it.
- [x] `bex agent env set --github-cli-mandatory on` and `--automations-github-cli off|inherit` send only their fields, and `bex agent env` prints them, reading a missing field as inherit and not mandatory.
- [x] `cd lego/cli && go test ./...` and `make lint` (from `lego/operator/`) pass.

## Out of scope
