## Objective

Make sure the shipped behavior is pinned by tests that assert real outcomes and failure modes: each level's precedence over the others in both directions, the mandatory floor, the refusals, and the older-component compatibility.

## Context

- t004's resolver table test, t003's surface tests, t005's overlay tests, t006's CLI tests and t007's component tests are the base.

## Steps

1. Check coverage against the Definition of done, items 1–4. Add what is missing:
   - A real-DB test: an automation edited to turn `gh` off makes the session's next mint refuse, naming the automation.
   - A mandatory flag saved while a session with `githubCli: true` runs makes its next mint refuse, naming the workspace.
   - A child of an automation's session.
   - A gateway that receives an unknown level.
2. Revert one precedence rule at a time to confirm the tests fail, then restore it.
