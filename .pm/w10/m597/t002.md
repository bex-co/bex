## Objective

Add the gateway-to-bex-api verb t001 designed: the gateway names the key's owner and the session, and bex-api runs `Service.Resume` as that owner, with every check a person's own `resume` gets, and answers the session's phase or the refusal.

## Context

- Siblings to copy: `lego/backend/internal/agentsession/two_factor.go` and `key_grant.go` (handler, client, `serveSignedMint` / `postSignedMint`, nonce replay guard, `BEX_SANDBOX_EXEC_SECRET`), mounted on the internal `:8091` root in `lego/backend/cmd/api/main.go:1453-1458`.
- `Service.Resume` (`lego/backend/internal/agentsessions/editor.go:54`) authorizes on the identity in `ctx` (`AuthorizeOn` `can_operate`, `AuthorizeFreshOn` `can_create`). The gateway's resolver builds that identity from the SSH key (`keyIdentity`, `nativessh/server.go:231`).
- A key enrolled by a bex API key is held to the key's grant on every request (w9/125, `sshgateway/keygrant.go`); the verb must not let such a key start what its grant does not cover.
- Rolling deploy: a gateway on the new release may ask a bex-api still on the old one (404 on the path). The gateway must then fall back to w10/043's banner, not fail the login differently.

## Steps

1. Add the path constant, request/response types, handler and client in `internal/agentsession/`, following `key_grant.go`.
2. In the handler, rebuild the caller's identity as t001 decided (subject, and the key re-read by fingerprint if so), check the key grant for an API-key owner, and call `Service.Resume`. Map its answer and refusals to the response t001 named.
3. Mount it in `cmd/api/main.go` beside the other two verbs; with no secret it is not mounted (fail closed), as they are not.
4. Tests on the real database and OpenFGA, as `key_grant_test.go` and `two_factor_test.go` do: a valid signature runs the wake; a bad signature, a replayed nonce and a stale timestamp are refused; a caller without `can_operate` or fresh `can_create`, an archived and a canceled session, and an admission refusal each answer their refusal; a session already `resuming` or running is returned unchanged and starts nothing.
