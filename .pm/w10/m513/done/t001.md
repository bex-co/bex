## Objective

Both agent templates (`agent`, `agent-4c-8g`) run one image, `lego/agent-image/Dockerfile`. Add Python 3.12 next to Debian's 3.11, `uv`/`uvx` and `gitleaks` to it, each pinned, so a session runs Python 3.12 projects, `uv` workflows and a secret scan with no download.

## Context

- The final stage is `node:22.23.4-bookworm-slim` plus bookworm's `python3` (3.11), `python3-pip`, `python3-venv`, Go and build tools. The sandbox runs as uid 10001, so a session cannot `apt-get` anything.
- The image already pins tools the way this task needs:
  - the `node-24` stage copies one binary out of a digest-pinned official image (ADR114);
  - the `native-binaries` stage downloads by URL and refuses a SHA-256 mismatch (`fetch-native-binaries.mjs`, ADR108).
- Candidate sources (pick, pin and say why in the Dockerfile comment):
  - **Python 3.12:** a digest-pinned `python:3.12.<n>-slim-bookworm` stage (same Debian release, so the same glibc and OpenSSL), copied without its `python3`/`python`/`pip3` names so `python3` stays 3.11. The official build links `python3.12` with an `$ORIGIN/../lib` rpath, so it can also live under `/opt/python3.12` with a `/usr/local/bin/python3.12` link. A uv-managed python-build-standalone install is another option.
  - **uv/uvx:** `COPY --from=ghcr.io/astral-sh/uv:<version>@sha256:… /uv /uvx /usr/local/bin/`, Astral's documented Docker install.
  - **gitleaks:** the release tarball per `TARGETARCH`, pinned by SHA-256, or a digest-pinned `ghcr.io/gitleaks/gitleaks` image.
- deploy.yml's Trivy gate fails the build on a fixed CRITICAL finding (HIGH only reports). `gitleaks` is a Go binary, so take a release built with a current Go.
- `uv` discovers a `python3.12` on `PATH` for `--python 3.12`. Downloads would fail on the registries tier until t002 lands, so the build check runs with `UV_PYTHON_DOWNLOADS=never`.

## Steps

1. Add the stages and copies with exact version and digest/SHA-256 pins. Keep them as linked layers (`COPY --link`) where they do not depend on the layers above, as `/opt/bex-go` is.
2. Add a build-time check in the final stage: `python3 --version` is 3.11, `python3.12 --version` matches the pin, `python3.12 -m venv` and `python3.12 -m pip --version` work, `uv --version`, `uvx --version` and `gitleaks version` match their pins, and `UV_PYTHON_DOWNLOADS=never uv venv --python 3.12 /tmp/v` succeeds. A mismatch fails the build.
3. Build the image locally (`docker build -f agent-image/Dockerfile -t bex-agent-sandbox:dev .` from `lego/`) and run the check as uid 10001. Run Trivy on it at CRITICAL with `--ignore-unfixed`, as deploy.yml does.
4. Document the tools and their pins in `lego/agent-image/README.md` (the opening paragraph lists the image's contents) and ADR047's sandbox image description.

## Result

Done 2026-11-19: `lego/agent-image/Dockerfile` adds a digest-pinned `python:3.12.16-slim-bookworm` stage (only `python3.12`, `pip3.12`, libpython and the stdlib are copied, so `python3` stays 3.11), a `cli-tools` stage that fetches `uv`/`uvx` 0.13.9 and `gh` 2.105.0 tarballs per `TARGETARCH` and refuses a SHA-256 mismatch, and a `gitleaks` stage that builds 8.30.1 from its module with the image's Go 1.27.4 after checking its go.sum hash: Trivy finds a fixed CRITICAL (CVE-2025-68121, Go 1.24.11 stdlib) in the release binary. The final-stage check fails the build unless every tool reports its pin, `python3` is 3.11, the 3.12 extension modules import, `pip` and `venv` work, and `UV_PYTHON_DOWNLOADS=never uv venv --python 3.12` finds the baked interpreter. Verified locally on arm64 (full build, check passes); as uid 10001 every tool reports its pin, `uv venv --python 3.12` works, `gitleaks git` finds a planted `ghp_` token (exit 1); a wrong `UV_VERSION` fails the SHA-256 check and a wrong `GITLEAKS_VERSION` the module-sum check; the amd64 download stages verify their pins. Trivy (`--severity CRITICAL --ignore-unfixed`, as deploy.yml) reports 0 on the image, including `gh`, `gitleaks`, `uv` and pip 25.0.1. The full amd64 image is built by deploy.yml (t006's gate). README and ADR047 D2 list the tools.
