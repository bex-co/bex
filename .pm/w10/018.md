# 018 — The agent sandbox template lacks the tools common repositories check with: Python 3.12, `uv`, `gitleaks`, `gh`

Why: agents skip the checks they cannot run and push work verified only by CI, so more PRs come back red and the agent cannot reproduce a CI failure. Severity: moderate. Surface: sandbox template `agent-4c-8g`.

## Evidence (production, 2026-11-16..18, bex-co/beancount-io automations)

- "this sandbox has only Python 3.11 … managed-Python downloads, Debian mirrors, and release-asset hosts are unreachable" — beancount-io#189, #208, #212 could not run `make check-all` / pytest (the CLI needs 3.12).
- `uv` missing: the skills CI leg (`scripts/skills/ci-check.py`) could not run its customer-`bea` leg (beancount-io#188).
- `gitleaks` missing in every run ("relying on the PR's secret-scan CI").
- `gh` is not installed, so routines that read CI history (`rt-flaky-test-fixer`) cannot use it.

## Direction

Add Python 3.12 (alongside 3.11), `uv`, `gitleaks` and `gh` to the agent templates, or let a workspace declare extra tools/versions per repository.
