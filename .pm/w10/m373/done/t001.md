## Objective

Make the handlers the rendertest suites validate carry the configuration production has, so the validator checks the shape production sends. Today 66 of the 109 `Allowlist` entries cite ADR018's "Resource metadata omitted when unknown" row: `owner`, `owner/email`, `ownerId`, `region`, `version`, `project`, `dashboardUrl` and `updatedAt` go missing because the suites' `Deps` set no `Region`, no `DashboardURL` and no resolved workspace. Production sets all three, so a regression that drops `region` or `owner` from a production read passes CI today.

## Context

- `lego/backend/internal/rendertest/allowlist.go:61-123` (the entries), `rendertest_test.go:40` (`allowlistSize = 109`), `rendertest/main.go:42` (a full run fails an entry nothing reproduces).
- `lego/backend/internal/api/server_test.go:197` `buildHandler` (the `internal/api` suite) and the `validated` muxes of `internal/apps`.
- Metadata seam: `lego/backend/internal/apps/render.go:391-412` (`metadata.PlatformRegion()`, `metadata.DashboardURL(...)`); `lego/backend/internal/api/resource_metadata_test.go:135-136` already builds a configured server (`Region: "fsn1"`, `DashboardURL`).
- ADR018 row "Resource metadata omitted when unknown" (`docs/ADR018-render-parity.md:295`) and § Allowlisted response-schema divergences (`:289`, which still says the size is pinned at 106; w3/m302 raised it to 112 and w3/m317 lowered it to 109).

## Steps

1. Give the default `Deps` of `buildHandler` and the apps `validated` muxes a region, a dashboard URL and a resolved workspace with a contact email, the values production sets. Keep the constructors' signatures; tests that need an unconfigured server opt out explicitly.
2. Keep the omit-when-unknown behavior pinned by targeted tests (an unset `BEX_REGION`/`BEX_DASHBOARD_URL` and an unresolved workspace omit the field, never guess it), in `resource_metadata_test.go`.
3. Run both suites with the test database (`BEX_TEST_REQUIRE_DEPS=1`, `scripts/backend-test-deps.sh`); delete every entry TestMain reports as unexercised and lower `allowlistSize` to the new count.
4. Any metadata entry that a production-shaped fixture still reproduces is a real production omission: fix it, or leave it for t006 with the evidence.
