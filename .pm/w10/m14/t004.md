## Objective

Price every platform-route request at upstream cost × `agentModel.markup` (1.30), record cost source, meter it as `agent_model_cost_microusd`, and bill it through one model-agnostic Stripe meter. Replaces the per-model token-price mechanism from `952b9e8fa` for billing.

## Context

- ADR091 D1–D3.
- Usage tee-parse: `lego/backend/internal/sshgateway/modelproxy/usage.go`; events: `lego/backend/internal/agentsession/modelusage.go`, `lego/backend/internal/store/agent_model_usage.go`.
- Pricing: `lego/backend/internal/pricing/pricing.go` + `pricing.yaml` `agentModel` (`models[]` ships empty today).
- Billing outbox: `lego/backend/internal/billing/stripe.go`; setup: `scripts/stripe-billing-setup.py`.

## Steps

1. Live probe: one platform-route request through OpenRouter `/api/v1/messages`; confirm whether `usage.cost` is returned and what request flag (usage accounting) is needed. Record the result in this task.
2. Gateway: parse `usage.cost`; send it with the usage report.
3. bex-api: fallback cost from a cached OpenRouter `/api/v1/models` table (hourly refresh, last good copy, time-of-day `overrides` at request start).
4. Migration: add `upstream_cost_microusd`, `cost_source`, `price_microusd` to `agent_model_usage_events`; meter `agent_model_cost_microusd` into `usage_hourly` (half-up per request).
5. `pricing.yaml`: `agentModel.markup: 1.30`; drop per-model price rows from billing (token meters stay for display).
6. Billing outbox + `stripe-billing-setup.py`: one meter at $0.000001/unit; run against test Stripe.
