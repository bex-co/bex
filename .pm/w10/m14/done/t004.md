## Objective

Price every platform-route request at upstream cost × `agentModel.markup` (1.30), record cost source, meter it as `agent_model_cost_microusd`, and bill it through one model-agnostic Stripe meter. Replaces the per-model token-price mechanism from `952b9e8fa` for billing.

## Context

- ADR091 D1–D3.
- Usage tee-parse: `lego/backend/internal/sshgateway/modelproxy/usage.go`; events: `lego/backend/internal/agentsession/modelusage.go`, `lego/backend/internal/store/agent_model_usage.go`.
- Pricing: `lego/backend/internal/pricing/pricing.go` + `pricing.yaml` `agentModel` (`models[]` ships empty today).
- Billing outbox: `lego/backend/internal/billing/stripe.go`; setup: `scripts/stripe-billing-setup.py`.

## Steps

1. Live probe: one platform-route request through OpenRouter `/api/v1/messages`; confirm whether `usage.cost` is returned and what request flag (usage accounting) is needed. Record the result in this task.
2. Gateway: parse `usage.cost`; send it with the usage report.
3. bex-api: fallback cost from a cached OpenRouter `/api/v1/models` table (hourly refresh, last good copy, time-of-day `overrides` at request start).
4. Migration: add `upstream_cost_microusd`, `cost_source`, `price_microusd` to `agent_model_usage_events`; meter `agent_model_cost_microusd` into `usage_hourly` (half-up per request).
5. `pricing.yaml`: `agentModel.markup: 1.30`; drop per-model price rows from billing (token meters stay for display).
6. Billing outbox + `stripe-billing-setup.py`: one meter at $0.000001/unit; run against test Stripe.
7. Report `agent_model_cost_microusd` to Stripe without the 48h seal (ADR091 D3, amended 2026-11-05): the cost row's hourly window is final once the hour ends (written only at record time, never rewritten by the rollup), so the outbox seals fast kinds at `window_start` + 65 min and a 5-minute pass exports them, with the existing deterministic row identifier. Chosen over one event per request because it reuses the outbox's durable attempt/stamp/quarantine machinery unchanged.

## Probe 2026-11-05

Live probe against OpenRouter `/api/v1/messages` with the pinned `deepseek/deepseek-v4.1-flash-1017`:

- **Cost is returned by default.** No request flag (usage accounting) is needed.
- **Non-streaming:** top-level `usage.cost` (float USD, e.g. `1.415e-05`), plus `usage.cost_details.upstream_inference_cost` and `usage.is_byok`.
- **Streaming:** the `message_delta` event's `usage.cost` carries it; `message_start` has none.
- **`/api/v1/models` pricing** for the pinned model: `pricing.prompt`, `pricing.completion`, `pricing.input_cache_read` as USD-per-token decimal strings, plus `pricing.overrides`, a list of `{utc_days: [lowercase weekday names], utc_start, utc_end, prompt, completion, input_cache_read}`. `utc_start`/`utc_end` are HHMM integers (`100` = 01:00); `utc_end` `0` means midnight; absent start/end means the whole day. The first override matching the request's UTC weekday and time wins, else the base price applies. Cache-write tokens use `input_cache_write` when listed, else `prompt`.
