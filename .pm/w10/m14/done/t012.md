## Objective

Let workspace admins set their own model provider key through a write-only mutation on REST, GraphQL and MCP and a Settings → Agents field; a workspace with a BYO key uses it and is not billed for tokens.

## Context

- ADR091 D7; original finding `w10/done/009.md`.
- `lego/backend/internal/agentsession/model.go` reads `ModelKeySecretPath` from OpenBao; nothing writes it.
- Settings card: `dashboard/src/features/agent-environment/`.

## Steps

1. Add an admin-only write-only mutation (set / clear) that stores the key at `ModelKeySecretPath`; reads expose only `modelKeySet: boolean` and model source.
2. Precedence in the mint: BYO key → provider direct, no cost meter; else platform route.
3. Dashboard Settings → Agents: model source + key field (masked, write-only, clear action).
4. Fix the composer copy that points at a non-existent settings field.

## Files

- `lego/backend/internal/agentsession/model.go`
- REST/GraphQL/MCP handlers + OpenFGA admin check
- `dashboard/src/features/agent-environment/`
- composer copy in `dashboard/src/features/agents/`

## Acceptance criteria

- [x] Real-DB test: admin sets a key; no read API (REST/GraphQL/MCP) returns it; audit event omits the value.
- [x] Test: non-admin write is refused.
- [x] Test: a BYO workspace session mints against its own key and records no `agent_model_cost_microusd`.
- [x] Dashboard test: the field is write-only and shows set/unset state.

## Out of scope

- Per-session key override.

## Done

2026-11-05. The write-only `modelApiKey` and `clearModelApiKey` fields are on the agent environment update (REST, GraphQL and MCP; admin-only, audit target `model-key`). Reads expose `modelKeySet` and `modelSource`. Migration 0196 adds `agent_environments.model_key_set_at`, and every route decision reads this flag: the mint, create and steer, the model pin, Capabilities and the trust count. A BYO key now wins over the platform route. Settings → Agents has a Model provider section. The composer links to `/workspace/settings#agents`, and the mobile copy is fixed. Tests: `agentsessions/modelkey_test.go`, `modelkey_pg_test.go`, `agentsession/platformroute_test.go`, the dashboard card and composer tests. Review fixes, 2026-11-05:

- **Model source on steer.** Steer re-resolves the model source. A session created on the platform route runs the workspace default model (or the profile default) against the provider once its workspace is BYO, and runs the pinned model on OpenRouter again once the key is cleared.
- **Consistent writes.** The OpenBao write and the flag share one transaction that locks the `agent_environments` row (`UpsertAgentEnvironmentLocked`). A first-time set whose flag write fails deletes the new key. A failed rotation leaves the new key active and returns an error.
- **The mint.** It reads the flag together with the spend position, through the t005 20-second cache (`AgentSpendInputs`). It fails closed without a spend store. A key write drops this replica's cache entry (`ForgetSpend`); other replicas follow within 20 seconds.
- **No key echoes.** GraphQL variable and argument value errors, and MCP argument-schema errors, no longer echo the offending value.
- **Hand-provisioned keys.** A one-shot startup reconcile flags them (`BackfillModelKeyFlags`, see t007).
- **Dashboard.** The key field keeps browsers and password managers out, and a key change refetches `AgentSessionCapabilities`.

Tests: `TestSteerFollowsTheModelSource`, `TestModelKeyFlagWriteFailure`, `TestBackfillModelKeyFlags`, `TestModelKeyPG` (row-lock serialization, rollback, marker), `TestMintKeyFlagLookup`, `TestGraphQLValueErrorsNeverEchoTheModelKey`, `TestMCPArgumentErrorsNeverEchoTheValue`, and `use-agent-environment.test.ts`. Resume wakes the existing sandbox, whose environment is fixed, so the model swap applies from the next steer.
