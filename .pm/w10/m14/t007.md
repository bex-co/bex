## Before widening: backfill BYO key flags (found in t012, 2026-11-05)

- Route decisions read `agent_environments.model_key_set_at`, which only the t012 write path sets.
- A key an operator put into OpenBao by hand earlier (`agent-sessions/<ws>/model-key`) has no flag. Once the route widens, that workspace would silently switch from its own key to the billed platform model.
- **Automated.** bex-api runs a one-shot reconcile at startup, in the background (`agentsessions.BackfillModelKeyFlags`). It lists `agent-sessions/` in OpenBao and sets `model_key_set_at` for every workspace whose `model-key` secret holds a key and has no flag. It never clears a flag.
- **Verify after the deploy, before removing the allowlist.** Check the bex-api startup log line `agent model key flag backfill: workspaces=… keys=… flags_set=… failed=…`. Expect `failed=0`. Expect `keys` to match the hand-provisioned keys you know of. A restart retries any failure.
