## Objective

Show agent model spend everywhere ADR091 D6 lists, consistently across REST/GraphQL/MCP and the dashboard.

## Context

- ADR091 D6.
- Usage page: `dashboard/src/features/usage/`; settings: `dashboard/src/features/agent-environment/`; composer and session detail: `dashboard/src/features/agents/`.
- **Retention gap (found in t004 review 2026-11-05):** `CompactUsage` (`lego/backend/internal/store/usage.go`) deletes `agent_model_usage_events` along with the hourly rows after about 48h. That loses the per-request cost, `cost_source` and `price_microusd` that per-turn cost (D6) and the ADR091 D2.3 invoice trace need. Keep these events for at least the invoice period plus dispute window (e.g. 13 months, or roll them up per session) before building the per-turn view.

## Steps

1. Usage/Billing: an "Agent model" line with month-to-date USD and an expandable breakdown by model and token kind; same data on REST/GraphQL/MCP usage reads.
2. Settings → Agents: model source, "billed at the model provider's cost + 30%", month-to-date spend vs cap, admin-editable cap.
3. Composer: warning banner at ≥80% of the effective cap; at 100% block with the typed error and an admin "increase cap" action.
4. Session detail: per-turn cost from the usage events.
5. Settings → Billing: current trust tier, next charge point, and what reaches the next tier (ADR091 D10.1).
6. Skeletons match ready states (AGENTS.md rule).

## Done (2026-11-05)

- **Retention.** `CompactUsage` keeps `agent_model_usage_events` past the hourly rows and deletes them 13 UTC calendar months past the compaction boundary (`store.AgentModelEventRetentionMonths`); migration 0199 adds `started_at` and indexes `(session_id, recorded_at)`. Real-DB test `TestAgentModelUsageIsIdempotentAndMetered` checks the retention edge.
- **Usage reads.** REST `GET /v1/usage`, GraphQL `usage.agentModel`, MCP `get_usage` carry `agentModel { monthToDateUsd, models[] { model, costUsd, input/output/cacheRead/cacheWriteTokens } }`, priced from `pricing.Estimate`'s agent-session cost meter lines (one rounding source, `pricing.FormatUSD`, now exported and sign-safe); the token fold stays in `summariseAgentModel`. `TestAgentModelLineMatchesTheUsageEvents` (real DB) checks the line against `SUM(price_microusd)` across a compaction.
- **Session cost.** REST `GET /v1/agent-sessions/{id}/model-cost`, GraphQL `agentSessionModelCost(id)`, MCP `get_agent_session_model_cost`: `modelSource` (the session's own route from its stored endpoint), `costUsd` as a cents string (the usage read's format), `requests` (GraphQL `Int`) and per-turn rows. A request belongs to the turn that was latest when it **started**: the recorder persists the gateway's `StartedAt` (clamped like pricing) as `started_at`, and one store query builds turn ranges with `lead()` and range-joins on `COALESCE(started_at, recorded_at)`, reading the session in the same statement (no separate `GetAgentSession`). Store test `TestAgentSessionModelUsageGroupsByTurn` (real DB: started in turn 1, recorded after turn 2 began ⇒ turn 1; a retried report counts once; foreign-workspace events excluded); recorder test pins the persisted start; parity test `TestModelCostIsTheSameOnEverySurface`.
