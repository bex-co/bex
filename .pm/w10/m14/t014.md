## Objective

Charge the card as soon as a workspace's unbilled `agent_model_cost_microusd` reaches its plan threshold, so non-payment exposure is bounded by the threshold rather than the month.

## Context

- ADR091 D10.1, D10 exposure bound.
- Usage reaches Stripe only after the 48h seal horizon (ADR040); the outbox is `lego/backend/internal/billing/`.

## Steps

1. `pricing.yaml`: `agentModel.billingThresholdUsd[]` per plan.
2. Pick the mechanism after reading the Stripe API: subscription `billing_thresholds.amount_gte` vs an early invoice of unbilled agent-model usage; write the choice in this task.
3. For the threshold path, push agent-model cost without waiting for the 48h seal (idempotent with the later sealed report).
4. A failed threshold charge enters the existing ADR040 §7 dunning path.

## Files

- `lego/backend/internal/billing/`
- `pricing.yaml`, `lego/backend/internal/pricing/`

## Acceptance criteria

- [ ] Test against Stripe test mode (or stripe-mock): crossing $10 on Hobby creates exactly one charge/invoice; replaying the same usage does not double-bill.
