## Objective

Generalize the dev-only OpenRouter route (agentsession/devroute.go) into a production-capable route scoped by BEX_AGENT_PLATFORM_MODEL_WORKSPACES, decided per workspace at mint/dispatch time so existing sessions switch on steer. Allowlisted claude sessions get the OpenRouter endpoint, the platform key (BEX_AGENT_PLATFORM_MODEL_KEY from Secret bex-agent-platform-model) and the pinned model; the gateway proxy refuses any other request model. Non-allowlisted workspaces are byte-identical to today (tests). ADR090 amended.
