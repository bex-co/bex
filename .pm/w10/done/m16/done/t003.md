## Objective

Tool items stay bounded, and the transcript never stores duplicate copies or the agent's internal notices.

## Context

- **Sample tool outputs:** 298 rows, median 1.2 KB, max 30 KB.
- **`data-acp-info`:** 1.02 MB (35% of the sample), mostly duplicated tool output plus internal notices such as "Async agent launched… never quote…".
- **Prior art:** Claude Code `BASH_MAX_OUTPUT_LENGTH` (30k chars) with large results spilled to files; OpenHands head+tail clip; Cursor's `truncated` flag.

## Steps

1. Cap tool output at ≈30k chars (head+tail, `… N chars clipped …`) with `truncated: true` and the original size.
2. Merge ACP tool updates into the tool item, keeping only the fields the UI renders (title, kind, status, diff/terminal content).
3. The dashboard shows the truncated marker.
