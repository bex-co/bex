# Billing charge tree shows raw meter names, a mangled model id and "Included" for unpriced agent-model lines

Why: on production `/billing`, agent-session usage reads as internal identifiers and claims an allowance that does not exist. Once ADR091 bills these lines, customers cannot tell what they are paying for.

Found 2026-11-04 on `dashboard.bex.co/billing`, QA user, workspace `bex`, period October 2026:

- The category renders as the raw `agent_session`. `CATEGORY_LABEL_KEYS` in `dashboard/src/features/usage/components/charges-card.tsx` has no entry for it (the existing `sandbox` entry covers only sandbox compute).
- Charge rows render as the raw `agent_model_input_tokens` / `agent_model_output_tokens` (and the cache kinds). `CHARGE_LABEL_KEYS` has no entries for them.
- The tier column applies CSS `capitalize` to the model id, so `deepseek/deepseek-v4.1-flash-1017` renders as `deepseek/Deepseek-V4.1-Flash-1017`. Plan tiers can stay capitalized; a model id must render verbatim.
- An unpriced line with a $0 rate shows "Included", which reads as a plan allowance. ADR091 D4 says no plan includes agent-model tokens. Show the rate as $0 or "Not billed yet" instead.
- Services show `disk_gb_seconds` raw. It also has no label key (ADR082 disks).

Fix:

1. Add label keys (en + zh locales) for `agent_session`, the four `agent_model_*` kinds and `disk_gb_seconds`.
2. Render the model-id tier verbatim.
3. Stop labelling zero-rate agent-model lines "Included".

Add component tests in `features/usage/components/__tests__/` that assert the labels, the verbatim model id and the absence of "Included" for an agent-model line. Then verify on production `/billing` (October period) at desktop and narrow-mobile widths.

Related: `w10/m14` t013 builds the full "Agent model" usage line on top of this; this note is the label fix only. It should ship before `m14` t007 widens billing to every workspace.

Done 2026-11-05 (`ee2441fc6`, deployed in pin `cc3c51e12952`). Production `/billing`, QA user, workspace `bex`, October 2026:

- **Category and lines:** the category reads "Agent sessions", and the lines read "Input tokens" and "Output tokens".
- **Model id:** `deepseek/deepseek-v4.1-flash-1017` renders verbatim.
- **Rate column:** "—". No "Included" appears, and no raw `agent_model_*` or `disk_gb_seconds` identifier remains.
- **Widths checked:** 1440px desktop and 390px mobile, with no horizontal overflow.
