## Objective

Store the list t001 named on the workspace agent environment, with the whole catalog on by default. REST, GraphQL and MCP read it, workspace admins write it, and the refusals t001 chose are in place.

## Context

- `lego/backend/internal/store/agent_environments.go`: the struct, the patch, `agentEnvironmentColumns`, `dest` and the upsert's column list. `disabled_agents` is the precedent for a text-array opt-out.
- `lego/backend/internal/agentsessions/environment.go`:
  - `Environment` (the read) and `EnvironmentInput` (the write). Its `jsonschema` descriptions are what MCP serves.
  - `validateEnvironmentInput` and `UpdateEnvironment`. `agentAvailabilityPatch` is the precedent for a whole-list replace validated against the current row.
- `graphql.go` holds the `AgentEnvironment` type (its `models` description) and `AgentEnvironmentInput` with its raw-input decoding. `mcp.go` holds the `get_agent_environment` and `update_agent_environment` descriptions, and `rest.go` holds `GET`/`PATCH /v1/agent-environment`.
- The next free migration number is above `0314`. Re-check `lego/backend/internal/store/migrations/` and `origin/main` before naming it.
- `lego/backend/internal/api/testdata/schema.graphql` is the checked-in schema snapshot. `dashboard/src/graphql/` holds the generated types.

## Steps

1. Add the migration (up and down).
2. Add the field to the store struct, the patch (a nil pointer keeps the value) and the upsert.
3. Serve the list on the read and accept it on the input, with t001's refusals. Describe it in the GraphQL field and input descriptions and the MCP tool descriptions: what off does, that the catalog default stays on, and when a change applies.
4. Write tests:
   - Store: the default row, a write and its read-back, and a patch that keeps the list.
   - REST, GraphQL and MCP: the read with no row offers the whole catalog, an admin's write reads back on all three, a member's write is refused as for the other fields, and each refusal from step 3.
5. Regenerate the schema snapshot and the dashboard's GraphQL types the way the repository keeps them in sync.
