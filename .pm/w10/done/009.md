# Customers have no way to set a BYO model key

Why: the composer tells users to "add a model provider key in workspace settings", but there is no write path anywhere (no REST/GraphQL/MCP mutation, no dashboard field). `agentsession/model.go` only reads `ModelKeySecretPath` from OpenBao, which an operator writes by hand. So no workspace outside the platform-route allowlist can run an agent session.

- This belongs with the platform-key rollout design (w10/m14 follow-up): decide the model source (bex-provided metered vs your own key), add a write-only key mutation on REST/GraphQL/MCP plus a Settings → Agents field, and fix the composer copy.
