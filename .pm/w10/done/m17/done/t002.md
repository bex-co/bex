## Objective

A per-session `agentConfig.model` can never make a platform-route session fail at the gateway's model pin.

## Context

- Platform route: `lego/backend/internal/agentsession/devroute.go` (allowlisted workspaces, `pinnedModel` in the mint).
- The gateway pin is in `sshgateway/modelproxy/modelproxy.go`. The session model reaches the agent through driver env / `ANTHROPIC_MODEL`.

## Steps

1. At session create/steer for a platform-route workspace, either reject a model that differs from the pinned model with a typed 400 (`AGENT_SESSION_MODEL_PINNED`), or ignore it and record the pinned model. Choose rejection for API callers.
2. Make sure driver env always carries the pinned model for that route.

## Files

- `lego/backend/internal/agentsessions/service.go`, `lego/backend/internal/agentsession/devroute.go`, tests

## Acceptance criteria

- [ ] Tests: an allowlisted workspace plus a different model gets a typed error or the pinned model; a non-allowlisted workspace is unchanged.
