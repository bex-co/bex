## Objective

One durable per-workspace agent environment, readable and writable over every API surface.

## Context

- The BYO model key and capabilities already live per workspace (`agentSessionCapabilities`, `ModelKeySecretPath`).
- Workspace settings authz: OpenFGA workspace admin relations (see existing workspace settings mutations).

## Steps

1. Store: `agent_environments` (workspace_id PK, network_tier enum `registries`|`full`|`custom`, custom_hosts text[] ≤32 validated like `sessionegress.ExtraDestinations`, default_model, updated_at/by), via the next-numbered migration.
2. Service plus REST (`GET/PATCH /v1/agent-environment?ownerId=`), GraphQL (`agentEnvironment` query + `updateAgentEnvironment` mutation) and MCP tools, with admin-only writes, audit events and typed validation errors.
3. Session create resolves the environment: the tier and custom hosts feed egress (t004), and `default_model` applies when the request has no model. An explicit API `egressAllowlist` is still honoured (merged with custom hosts, capped).

## Files

- `lego/backend/internal/store/` (migration + store), `lego/backend/internal/agentsessions/` (service, rest, graphql, mcp), authz model if a relation is needed

## Acceptance criteria

- [ ] Real-DB tests: defaults, round-trip, admin-only write, validation errors on every surface.
