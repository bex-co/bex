Add meaningful tests for the behavior this milestone shipped: the confirm page renders the code and posts same-origin with both hidden fields; the GET handler routes signed-in confirms to the React page and still bounces signed-out visitors with code+challenge preserved; pairing never happens on GET; document titles say "bex CLI" in en + zh. Assert real behavior and failure modes — no snapshot-everything.
