## Objective

An established `GET /v1/logs/subscribe` live-tail re-runs `can_view_logs` on a ~1-minute cadence, so revoking a member's access (or deleting their key) ends the tail within the interval instead of letting it run to disconnect — the last gap in the round-9 revalidation watchdog family.
