1. Make the model proxy mandatory in `config.ts`: refuse to start without `modelBaseUrl`, and reject a credential that is not a placeholder. Delete the standalone real-key path.
2. Delete the scrub, the Git-object scan and secret-form generation. Keep redaction only if t001/ADR090 decides the placeholder still warrants it; the default is to delete.
3. Delete `/snapshot/scrub`, the snapshot grant, `bex-pre-snapshot`, its Dockerfile install, and the lifecycle exec hop in `sandbox/service.go`. Suspend/hibernate snapshot directly.
4. Delete `credential-scrub-test.sh` and its CI step. Move `verify-sandbox-isolation.sh`'s model leg to the proxy path.
