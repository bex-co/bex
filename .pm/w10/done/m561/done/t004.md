## Objective

Replace the workspace-only check with one resolver that returns whether `gh` is on for a session and, when it is off, which level turned it off. Use it in both `gh` credential mints and in `driverEnv`. Carry the level to the gateway and the driver, so the route's 403 and the overlay name it.

## Context

- `Minter.githubCLIAllowed(ctx, workspace)` (`lego/backend/internal/agentsession/mint.go:259`) reads only the environment row. The mint already holds the session record (`mint.go:230`), so the session's own binding and its `AutomationID` are at hand.
- `driverEnv` (`lego/backend/internal/agentsessions/service.go:1865`) sets `BEX_AGENT_GITHUB_CLI=0` from `workspaceEnv.GitHubCLIDisabled` (`:1908`).
- The refusal wire: `RefusalGitHubCLIOff` and `ErrGitHubCLIOff` (`lego/backend/internal/agentsession/contract.go:61`, `:118`), mapped back in `agentsession/http.go:96` and `:207`. The gateway's text is `githubCLIOffRefusal` (`lego/backend/internal/sshgateway/agentcred/githubapi.go:79`), chosen at `:175`. It is counted as `authentications_total{result="github_cli_off"}`.
- The session's web Shell, SSH and Zed `gh` reach the same route (w10/027), so they follow the resolver with no change of their own.

## Steps

1. Write the resolver once, in the package both callers can import without breaking the DAG. Its inputs are the environment row, the session's `agentConfig.githubCli`, the automation's template binding for an automation's session (read as t001 decided) and the parent chain for a child. It returns on/off and the level.
2. Use it in `githubCLIAllowed` and in `driverEnv`. Both read live, so an automation edit or a mandatory flag applies from a running session's next `gh` call and its next dispatch.
3. Cross the internal hop with t001's level encoding. Keep `github-cli-off` meaning the workspace level, so an older gateway answers as today. Map each level to its error in `agentsession/http.go`.
4. Give the gateway one message per level, each saying how that level turns `gh` back on. Keep the metric's `result` label stable, or add the level as t001 decided.
5. Set the driver's level variable beside `BEX_AGENT_GITHUB_CLI=0`.
6. Audit the denied mint as today, with the level in the audit details if the audit row has a place for it.
