## Result

Done 2026-11-22: `/simplify` (reuse, quality and efficiency reviews) applied:

- **Backend.**
  - One `agentsession.ResolveGitHubCLI` serves the mint and the dispatch, and returns early under a mandatory off with no tree or automation read.
  - `Resolve` returns just the level, so the decision struct, which held redundant state, is gone.
  - A repo-less session resolves nothing.
  - The existing `optionalBoolField` is reused, and the single-use description constants are inlined.
  - The field-name constants are clearer, and `envGitHubCLILevel` now sits beside `envGitHubCLI`.
- **CLI.** One `parseOnOff` serves the four on/off(/inherit) flags.
- **Driver.** The level union is derived from one list, and a dead fallback is dropped.
- **Dashboard.** `ToggleSaveAlert` takes an `id`, the error wiring uses `describedBy`, the picker's two props and one span are gone, and an unreachable error-code entry is removed.
- **Not worth it:**
  - Collapsing the mint's up to six reads into one recursive query: two reads for a top-level session, small next to the GitHub token request.
  - Passing the environment row into `refuseGitHubCLIOn`, and reusing `resolveParent`'s parent row: one read on a rare path each.
  - Moving the automation pages' environment read into capabilities: one read per page mount.

The backend, CLI, driver and dashboard suites pass again, and `make lint` passes.
