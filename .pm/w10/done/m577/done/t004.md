## Objective

Expose the option in the `bex` MCP server's `merge_pull_request`, accept the armed or queued answer, and tell the agent when to use it. Also make the `github-api` route's refusal of `gh pr merge --auto` name the option.

## Context

- `lego/agent-image/driver/src/merge-pr.ts`:
  - `mergePullRequestToolDefinition`, its schema and description;
  - `validateMergeInput`, which mirrors the gateway's `Validate`;
  - `mergePullRequest`, which accepts only `merged === true`;
  - `recordMerge`, which writes `merged` and `headSha` into the PR record that `delivery-check.ts` reads (`readPrRecord`, `mergedHead`).
- The overlay's `readyOrMergeStep` (`lego/agent-image/driver/src/overlay.ts:170`) tells the agent to wait for the checks, with `gh pr checks --watch` dropped when `gh` is off. w10/042 tracks that command failing without the pull request's number.
- The gateway's `pullRequestStateRefusal` (`lego/backend/internal/sshgateway/agentcred/githubapi.go`) answers `gh pr ready` and `gh pr merge`, `--auto` included.

## Steps

1. Add the option to the tool's schema and description: arm GitHub auto-merge, or join the merge queue, and end the turn; GitHub merges once the required checks pass. Validate it as the gateway does.
2. Accept the armed or queued answer and return it to the agent as such. `recordMerge` runs only on a real merge, and the delivery check's `mergedHead` stays empty for an armed pull request.
3. Rewrite the overlay's merge step per DoD 7. When asked to merge once the checks pass, the agent marks the PR ready, calls the tool with the option, reports that auto-merge is armed or the pull request is queued, and ends its turn. A plain merge stays the path when it was asked to merge now. Keep the "only when asked" rule.
4. Make `pullRequestStateRefusal` name the option for `gh pr merge --auto`, and update its test.
5. Tests: `driver/test/merge-pr.test.ts` (the option validated and sent, an armed answer accepted, `recordMerge` not called for it), `driver/test/overlay.test.ts` (the new step, with `gh` on and off), and the gateway refusal test.
