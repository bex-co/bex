## Objective

Route `PullRequester.Merge` through t001's decision table, keeping every check it makes today. Those are the recorded pull request, a draft refused, the head pin before any call, the method rule and GitHub's message relayed. Carry the option and the new answer over both hops.

## Context

- `lego/backend/internal/agentsession/pullrequest_merge.go`:
  - `PullRequestMergeContent` and `Validate` run on both hops.
  - `Merge` refuses a draft and a head that is not the recorded one, then merges and calls `recordMerged`.
  - `mergeRefusal` and `NewPullRequestMergeError` map the codes and hints, and `PullRequestMergeResponse` is the answer.
  - `PullRequestMergeClient.Merge` accepts only `out.Merged && out.SHA != ""`.
- The gateway's `servePullRequestMerge` (`lego/backend/internal/sshgateway/agentcred/pullrequest.go:119`) strict-decodes the body. Its refusal text lists the three fields.
- If t001 disarms on a new head, the hook is where the Git proxy accepts a push or where `open_or_update_draft_pr` records `headSha`.

## Steps

1. Add the option to `PullRequestMergeContent` and its `Validate`. Update the gateway's strict-decode refusal and the `invalid_request` hint so they list it.
2. In `Merge`, take the direct, armed or queued path per t001. `recordMerged` runs only on a merge. An armed or queued answer leaves `prState` to the PR-state poller and the webhook.
3. Add the new codes and hints (for example `auto_merge_not_allowed`), and map GitHub's refusals of the new calls in `mergeRefusal`.
4. Extend `PullRequestMergeResponse` and the gateway client's acceptance so an armed or queued answer gets through, and a malformed one still fails.
5. Add the undo and the head-pin hook if t001 chose them.
6. Audit per t001.
7. Tests in `internal/agentsession` and `internal/sshgateway/agentcred` (`pullrequest_merge_test.go`, with the `prForge` fake extended):
   - the option armed, the queue, auto-merge off, an already-mergeable pull request, a draft and a moved head refused before any GitHub call;
   - an armed answer through the gateway end to end;
   - `prState` not recorded merged on an armed answer.
