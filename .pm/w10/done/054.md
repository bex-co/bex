# 054 — `docs/ADR018-render-parity.md` is 279 bytes under the 1 MiB blob limit, so the next sizeable parity amendment from any workstream fails ship-gates

Why: every workstream amends the parity ledger, and the file grows about 40–50 KB a day. Trimming sentences buys hours, so it needs splitting into smaller files that keep the links into it working. Filed by the `/loopx` CI-fix worker for the w10/053 incident, 2026-11-23. Severity: major (it blocks every ship that touches the ledger). Milestone-sized and touches every workstream, so promote it.

## The limit

- `scripts/repo-artifact-guard.sh` refuses any blob of 1 MiB (1,048,576 bytes) or more. Both run it: `scripts/ship-gates.sh` over `base..HEAD`, and `.github/workflows/repo-artifact-guard.yml` over HEAD's tree and over each push's `before..sha` (user decision 2026-11-04, w6/100 D10). Raising the limit or exempting the file would undo that decision, so neither is the fix.
- ADR018 is 1,048,297 bytes on `4609555136`, 279 bytes of headroom. Its size on main: 517,103 bytes on 2026-11-01, 706,326 on 11-16, 881,933 on 11-20, 1,041,681 on 11-23. 396 commits touched it in the week to 11-23, from w4, w32, w10, w5, w8, w6, w33, w21, w34 and w3 since 11-22 alone.

## Suggested split

- Keep `docs/ADR018-render-parity.md` as the index: the status, the legend, evidence sources, a short note on each surface, and links to the ledger files. Its path stays, because 2,467 references in 1,655 files point at it.
- Move each top-level section into its own ledger file, e.g. `docs/ADR018/services-lifecycle.md`, `deployment-sources-iac.md`, `logs.md`, `bex-ahead-of-render.md`. Each stays a few hundred KB at most, and Services & lifecycle may need splitting again (lifecycle vs scaling/disks/jobs).
- Keep every anchor in use working. Only 13 distinct `#…` anchors point into ADR018 (the most used is `#deployment-sources--iac`, 10 references; then `#render-operation-omissions`, `#bex-ahead-of-render`, `#other-datastores--storage`, `#environment--config`, `#deploys`, `#api-contract`, `#managed-postgres`, `#gap-backlog`, `#sandbox-create-flags-w2m263`, `#list-query-census-w4164-2026-09-27`, `#allowlisted-response-schema-divergences-w3m272`, and one stale `#L597`). Either leave each heading in the index with a one-line pointer to its new file, or rewrite those links. `bash scripts/docs-links-validate.sh` checks paths only, not anchors, so check them by hand or extend it.
- Move the code that reads the file along with it:
  - `lego/backend/internal/rendertest/rendertest_test.go` `adr018AllowlistRows` parses the "Allowlisted response-schema divergences" table out of this path, and `allowlist.go`'s `Divergence.ADR018` names it.
  - `scripts/ci_test_inputs.py` and the `backend-test.yml` `paths` list it as a test input.
  - `scripts/render-schema-drift.sh` tells the operator to run a drift round in it.
  - Twelve backend Go files and `lego/types/renderlog/renderlog.go` cite it in comments.
- Add a guard that fails any `docs/**/*.md` over a soft limit (e.g. 512 KB) in `scripts/ship-gates.sh`, so a growing ledger file is split well before the hard 1 MiB refusal.
- Update the pointers in AGENTS.md (root "Docs — where to look") and in `docs/AGENTS.md`'s catalog line.
