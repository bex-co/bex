# 055 — Below 640 px an agent session's Connect button has no accessible name, so a screen reader announces only "button"

Why: on a phone the session header's Connect trigger is an icon and a chevron with its label hidden (`hidden sm:inline`) and no `aria-label`, so assistive technology cannot tell it from the header's other icon buttons. Found by w10/m597 t006's live walk on production, 2026-11-23. Severity: minor (accessibility). Surface: `dashboard/src/features/agent-sessions/components/session-detail-header.tsx` (`OpenInZedButton`).

## Observed (2026-11-24, pin `f46c44d9ddb1`)

At 390 px on a `tian-personal` session (disposable, deleted afterwards), the header's menu triggers were "Files" (an `aria-label`), an unnamed 58 px button, and "More actions" (an `aria-label`). The unnamed one is Connect. At 1280 px it is named by its visible "Connect" text. The label has been hidden below `sm` since w2/m65 (`bbda156883`).

## End state

The Connect trigger carries `aria-label={t("agentSessions.connect")}` as the Files button beside it does (`session-files-sheet.tsx`), so it is named "Connect" at every width. A dashboard test finds it by role and name with the label hidden.
