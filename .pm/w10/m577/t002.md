## Objective

Give `lego/backend/internal/github` the calls t001 chose: enable auto-merge with `expectedHeadOid`, the queue call pinned to the head, the undo if t001 keeps it, and the read that tells a queue branch, an already-mergeable pull request and an armed or queued one apart.

## Context

- `MergePullRequest` (`lego/backend/internal/github/merge.go`) mints the merge token (`mergePermissions`, with the workflows fallback), picks the method (`allowedMergeMethods`) and sends the synchronous merge. `MarkPullRequestReady` is the GraphQL template: a GraphQL `errors` entry becomes an `*APIError` (FORBIDDEN 403, NOT_FOUND 404, otherwise 422), and `APIErrorMessage` relays GitHub's text.
- `GetPullRequest` returns `PullRequestDetail` with `NodeID` (`lego/backend/internal/github/pulls.go`).
- GraphQL inputs: `enablePullRequestAutoMerge(input: {pullRequestId, mergeMethod, commitHeadline, commitBody, expectedHeadOid})`, `enqueuePullRequest(input: {pullRequestId, expectedHeadOid})`, `disablePullRequestAutoMerge(input: {pullRequestId})`, `dequeuePullRequest(input: {id})`. The method enum is upper case (`MERGE`, `SQUASH`, `REBASE`).

## Steps

1. Add the calls t001 chose (for example `EnablePullRequestAutoMerge`, `EnqueuePullRequest`, `DisablePullRequestAutoMerge`), each minting the merge token for the one repository.
2. Add the read t001 chose, for example `isMergeQueueEnabled`, `isInMergeQueue`, `mergeStateStatus` and `autoMergeRequest` for the pull request's node, or the `merge_queue` branch rule.
3. Keep the method rule: a named method the repository does not allow is still a `*MergeMethodError` before any call, except where t001 says a queue ignores it.
4. Tests against an `httptest` GitHub: each call's exact body, `expectedHeadOid` carried, the method mapped to GraphQL's enum, GitHub's refusals for auto-merge off and an already-clean pull request kept as `*APIError` with GitHub's message, and the token's permissions.
