## Objective

Settle how `merge_pull_request` arms auto-merge and uses a merge queue, and amend the ADRs, so t002–t004 implement one written design. Record the decisions in the milestone README under `## Design record (t001)`, citing Devin's and GitHub's pages for each choice (the Devin rule: pick the option that matches Devin's observable behavior).

## Context

- Today's contract is ADR090 D3's w10/m538 amendment (`docs/ADR090-agent-owned-delivery.md`, "The merge call", "The head pin", "The method", "The tokens"), implemented in `lego/backend/internal/agentsession/pullrequest_merge.go` and `lego/backend/internal/github/merge.go`.
- What gh 2.105.0 sends for `gh pr merge --squash --auto` is recorded in `lego/backend/internal/sshgateway/agentcred/testdata/gh-2.105.0-requests.json`. It reads `mergeStateStatus`, `isInMergeQueue` and `isMergeQueueEnabled`, then sends `enablePullRequestAutoMerge`. gh's merge command (`pkg/cmd/pr/merge/merge.go` in `cli/cli`) is the reference for what `--auto` does on a queue branch and on a pull request that is already mergeable.
- GitHub's inputs and endpoints are listed in the milestone README (§ GitHub's calls).

## Steps

1. **The option.** Name it, for example `auto: true` after gh's `--auto`, or the note's `whenReady: true`. Say what it means with `method`, `commitTitle` and `commitMessage`. On a queue branch GitHub ignores all three, so decide whether naming one there is refused or ignored and said so in the answer.
2. **The decision table.** For each of these, record the GitHub call and the answer: no queue and not yet mergeable; no queue and already mergeable (`mergeStateStatus` `CLEAN`, where enabling auto-merge is refused); a queue branch, with or without the option; already armed; already queued.
   - Choose the queue call: `enqueuePullRequest` with `expectedHeadOid`, `merge-async` with `merge_action: merge_queue` and `sha`, or `enablePullRequestAutoMerge`, which GitHub's notes say works with a queue.
   - Choose how the queue is detected, for example GraphQL `isMergeQueueEnabled` (it covers rulesets and classic protection) or the `merge_queue` rule of `GET …/rules/branches/{base}`.
   - Decide whether the plain call (no option) on a queue branch enqueues, as Devin's `m` and GitHub's button do (DoD 2).
3. **The head pin after arming.** GitHub keeps auto-merge on after a push by someone with write access, and the session's push token has it. Choose one:
   - bex disarms auto-merge (`disablePullRequestAutoMerge`) when the Git proxy accepts a new push to the session branch, or when `open_or_update_draft_pr` records a new head;
   - or ADR090 D3 says that a later head is merged only after its own required checks pass, as with any writer's push.
   Record what Devin's behavior implies, and why the choice keeps "a commit pushed later is never merged unchecked" true or replaces it.
4. **The undo.** Decide whether a person's "don't merge it after all" goes through the tool, for example `auto: false`, or a separate verb. Calls: `disablePullRequestAutoMerge`, or `dequeuePullRequest` for a queued pull request. Devin Review can disable auto-merge. If the undo is left out, file it as a note.
5. **Refusals.** Name the code and hint for a repository with "Allow auto-merge" off (`allow_auto_merge` on `GET /repos/{owner}/{repo}`, or GitHub's own error), and for any new GitHub refusal. Every hint keeps `mergeNoOtherRoute`.
6. **The answer.** Choose the fields (for example `merged: false`, `autoMerge: true` or `enqueued: true`, `method`, `headSha`) and say what the gateway client (`PullRequestMergeClient.Merge`) and the driver accept. Decide whether the audit gets its own verb or a detail on `agentsessions.PullRequestMerge`.
7. **Tokens.** Confirm that the merge token (Contents, Pull requests and Workflows write, with the w10/014 fallback) is enough for the auto-merge and queue mutations. GitHub's [permissions for GitHub Apps](https://docs.github.com/en/rest/authentication/permissions-required-for-github-apps) and the mutations' docs are the source, and an installation token's `enablePullRequestAutoMerge` must be shown to work, for example from a public report or t005's run.
8. **Amend the docs.** ADR090 D3 (the m538 amendment's merge-call, head-pin and tokens bullets) and D4 (the refusal for the auto-merge mutations names the tool's option), ADR047's PR-delivery lines, and `lego/agent-image/README.md`.
