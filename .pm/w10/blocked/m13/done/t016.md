## Objective

Unblock the live legs (this milestone's t011 and `w10/blocked/m12/t006`) with the user-authorized `OPENROUTER_API_KEY`. The user authorized it on 2026-10-22, and it is present in `.env`. The route goes Claude profile → OpenRouter's Anthropic-compatible endpoint → the latest DeepSeek "flash" model. It is **dev only**: the release profiles in `agent-profiles.json` stay unchanged.

## Context

- `lego/backend/internal/agentsession/agent-profiles.json` pins claude → `https://api.anthropic.com/v1` (`ANTHROPIC_BASE_URL` / `ANTHROPIC_API_KEY`). `RegisteredModelEndpoint` (`agentsession/model.go:66-85`) rejects overrides.
- `ResolveAuthScheme` (`model.go:429-440`) already defaults non-Anthropic/Google hosts to Bearer, which is what OpenRouter expects.
- Egress: the model-endpoint host is derived via `sessionegress.ModelEndpointHost`. `openrouter.ai` must be the registered host for this route.
- OpenRouter documents Claude Code usage: base URL `https://openrouter.ai/api`, Bearer auth, model via `ANTHROPIC_MODEL` / `ANTHROPIC_DEFAULT_{OPUS,SONNET,HAIKU}_MODEL`. Non-Anthropic models are best effort through its Anthropic-format translation.
- The BYO key is per workspace in OpenBao (`ModelKeySecretPath`). Seed dev-10's workspace key from `.env` without printing it.
- `.env.example` lacks `OPENROUTER_API_KEY`; repo rule says it must mirror `.env` names.

## Steps

1. Resolve the exact model id from `GET https://openrouter.ai/api/v1/models` (latest `deepseek/*flash*`) and record it here. Don't guess.
2. Add an env-gated dev endpoint override, e.g. `BEX_AGENT_DEV_MODEL_ROUTE=openrouter`, off by default and refused when the environment is production. It swaps the claude profile's registered endpoint to `https://openrouter.ai/api` and injects `ANTHROPIC_MODEL` and the `ANTHROPIC_DEFAULT_*_MODEL` vars into the agent env. Keep the base-URL path consistent with how the model proxy composes paths (Claude Code appends `/v1/messages`).
3. Verify the gateway model proxy sends `Authorization: Bearer <key>` and strips Claude Code's `x-api-key` placeholder header on this route. Add a test.
4. Seed dev-10's workspace BYO model key from `.env` `OPENROUTER_API_KEY` (in `scripts/dev-env.sh` or a one-off helper; the value is never echoed). Add `OPENROUTER_API_KEY=` to `.env.example`, and the new env to `lego/backend/AGENTS.md`.
5. Smoke: one trivial headless turn on dev-10 reaches DeepSeek through the proxy and returns text.
