## Objective

Give the sandbox one narrowly-scoped, credential-free way to open or update its own draft PR. It is the PR-side twin of the Git proxy's exact-branch receive-pack rule.

## Context

- Gateway `:8082` mux: `lego/backend/cmd/ssh-gateway/main.go:371-380`. Git proxy `internal/sshgateway/agentcred/agentcred.go`:
  - `serveGit` 175-345: limiter → `KubeSessionPodResolver` source-IP → `agentsession.AuthorizePod` label digests → budgets → HMAC mint → audit;
  - `parseProxyPath` 433-471.
- The model proxy (`internal/sshgateway/modelproxy`, main.go:263) is the precedent for a second verb reusing `RemoteIP` + the resolver.
- bex-api internal listener `:8091`: `InternalMintPath` / `InternalModelMintPath` (`agentsession/contract.go:35`, `model.go:44+`, `cmd/api/main.go:948`). The mint re-checks the live generation + phase in `agentsession/mint.go` `currentSandboxCaller` 68-74.
- `internal/github/pulls.go` `OpenDraftPullRequest` 52-82: per-call token with `pull_requests:write, contents:read`; a 422 returns the existing open PR. It has no update path yet.
- Session store: `store/agentsessions.go` `FinalizeAgentSession` 880-895 writes `head_sha`/`pr_url`/`pr_number` only at finalize.

## Steps

1. Contract:
   - `POST /pr/<ns>/<sid>/<repo>/<branch>` on `:8082` with body `{title, body}`, JSON, ≤ 64 KiB;
   - title is a single line of ≤ 256 runes, and the body is ≤ 60,000 bytes (GitHub limit 65,536 minus footer headroom);
   - add the path constant next to the Git path in `agentsession/contract.go`.
2. Gateway handler: same Pod binding, `AuthorizePod`, limiter and budget as `serveGit`. Then the HMAC call to a new internal verb `/v1/agent-session-pull-requests`.
3. bex-api internal verb:
   - `currentSandboxCaller` check; resolve owner/repo/base from the session record (never from the request); head = the bound branch;
   - refuse with a typed error if the remote head is not ahead of base (`compare` API) or does not exist (`branch_not_pushed`);
   - else create the draft PR, or update title/body if an open PR for that head exists (add `UpdatePullRequest` to `github/pulls.go`);
   - never set `draft:false`.
4. Footer, appended server-side and replaced idempotently on update, never duplicated: a `---` separator, then a line like `🤖 Opened by a bex agent session (<engine profile>) · <dashboard session URL>`. Use the dashboard URL, not the API URL; add the config for it if absent.
5. Persist `pr_url` / `pr_number` / `head_sha` on the session immediately (new store method). REST/GraphQL/MCP then show the PR mid-turn.
6. Audit the event like the Git proxy does. Return `{url, number, created|updated, headSha}` or `{error:{code,message,hint}}`; hints must say not to try alternative routes.
