## Objective

A person watching a session sees that it is waiting for a machine instead of a bare spinner. A failed start shows its cause, in the dashboard and in the CLI.

## Context

- Dashboard session page and list: `dashboard/src/features/agent-sessions/`. Its locales are in all eight languages (`dashboard/AGENTS.md`).
- CLI: `lego/cli/internal/agent/render.go` and `chat.go` (`bex agent get`, `logs`, `run`).
- Devin's notice reads "waiting for machine capacity". The time it has waited is part of it.

## Steps

1. Dashboard: a "Waiting for a sandbox machine" status, with the time waited, on the session page header and the sessions list row. On failure, a cause line in place of "platform issue". No upgrade call to action unless the code is `SANDBOX_CAPACITY_LIMIT`.
2. Add the strings in all eight locales.
3. CLI: `bex agent get` and `logs` print the waiting line. `bex agent run` prints it once while it waits and keeps waiting. A failure prints the cause.
