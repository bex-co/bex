## Objective

For each of the 45 list operations in the pinned spec that carry `limit`, record whether bex serves it and what an unpaged call returns today (full set or 20), and list the in-repo REST clients that read an unpaged list and need every item.

## Context

- Pinned spec `lego/backend/internal/api/openapi/render-public-api-1.json`: `limitParam` default 20, max 100; `auditLogLimitParam` default 20, max 1000.
- `core.StablePage` (`lego/backend/internal/core/pagination.go:488-505`) returns the whole list when `requested` is false; REST callers differ: `GET /v1/services` already passes `requested=true` (`lego/backend/internal/apps/rest.go:888`), the sandbox list does not (`lego/backend/internal/sandbox/rest.go`, `TestListLimitIsClampedToOneHundredAndAnUnpagedListIsComplete`).
- Other `StablePage` callers: `apps/build_sources.go`, `apps/disks.go`, `envgroups/service.go`, `keyvalue/rest.go`, `postgres/rest.go`, `projects/rest.go`, `registrycreds/rest.go`; lists that page without `StablePage` must be checked too.

## Result (2026-11-14)

45 pinned operations take `limitParam` (or `auditLogLimitParam`). Most already answered Render's first page of 20 unpaged (`core.PageParams`, `PageLimitOrDefault`, `PageLimitOrAbsent` or the store's default page). Six served ones did not: `list-sandboxes` (`sandbox/rest.go`, full set), `list-routes` and `list-headers` (`apps/rest.go` `pageRules`, full set), `list-deploys` and `list-job` (newest 100 through `core.QueryLimit` and the store clamp), `list-logs-values` (`logs/rest.go`, full set; `limit` parsed and never applied). Not served: the operations in `renderOperationOmissions`; `subscribe-logs` is a stream and `listWorkflows` a stub. Their service functions are shared with GraphQL and MCP, so each switch sits in the REST adapter. In-repo clients that read one of the six whole: `scripts/verify-sandbox-isolation.sh` (four sandbox lists), `scripts/events-verify.sh` (deploys, reads the oldest), `scripts/logs-verify.sh` and `scripts/cli-logs-verify.sh` (log values). The official Render CLI already pages (`client.ListAll` with limit 100); the dashboard's lists are GraphQL; mobile reads `/v1/logs` with limit 100. Finding: `GET /v1/projects` already returned 20 (w8/191), so DoD 2's live check must use one of the six (e.g. `/v1/sandboxes` or a static site's `/routes`).
