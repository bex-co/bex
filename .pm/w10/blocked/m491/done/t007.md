## Objective

The dashboard's transcript and `bex agent logs`/`get` show the retention line for every turn that kept or lost undelivered work, not only under a stopped turn's note.

## Context

- `dashboard/src/features/agent-sessions/lib/mapper.ts` and the session transcript components render the m413 line under the interrupted note; strings live in all eight dashboard locales.
- `lego/cli/internal/agent/types.go` and the `logs`/`get` renderers print the stopped-turn sentence.

## Steps

1. Render the line for any turn with a retention state other than `none`, worded by cause and stake ("Your 2 unpushed commits and uncommitted changes are kept until {time}", "… were lost when the turn failed and its sandbox was gone").
2. Add the strings to every locale; keep the pending skeleton's geometry unchanged.
3. `bex agent logs` ends such a turn with the same sentence; `bex agent get` shows it for the latest turn.
