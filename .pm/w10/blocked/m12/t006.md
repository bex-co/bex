## Objective

Prove the bump in a real sandbox: the image builds with the install-profiles check passing, and a real Claude turn on `dev-10` emits the typed parts, cancels cleanly and resumes.

## Context

- `bash scripts/dev-env.sh 10 up` is pre-approved. The image build context is `lego/` (`lego/agent-image/Dockerfile`).
- A real turn needs a model key. Past live-verification attempts (w5/m66, w5/m98 t005) were blocked on that.

## Steps

1. Build the agent image and confirm the `node dist/install-profiles.js` step passes for all three profiles.
2. On `dev-10`, start a Claude session. Prompt for a turn that edits a file and runs a command.
3. Record the part types seen (tool, plan, diff, terminal). Then cancel mid-turn and confirm the process group is gone. Resume the session and confirm the transcript is restored.

## Acceptance criteria

- [ ] Image builds, and the install-profiles check passes.
- [ ] Live turn evidence is recorded here (part inventory, cancel, resume). If no model key is available, record that as the blocker; the milestone stays open.

## Out of scope

- Production rollout (the normal `deploy.yml` image pin).
