## Objective

Make sure the claude-agent-sdk 0.3.x transcript is fully flushed before the driver ends the process at the result boundary. The profile's `sessionState` paths must still capture everything that `loadSession` needs, and sessions that hibernated under 0.16.2 must either resume or fail with a typed, honest error.

## Context

- `profiles.test.ts:78` documents 0.2.44's 100ms batching and the `CLAUDE_CODE_EAGER_FLUSH=1` workaround.
- Hibernation and snapshot of HOME state are covered in ADR059 and `lego/agent-image/bex-pre-snapshot`. `sessionState` is validated in `driver/src/profiles.ts:143`. Continuity is in `driver/src/continuity.ts`.

## Steps

1. Confirm whether 0.3.x still needs, renamed or dropped the eager-flush flag. Update the profile env and the test comment and assertion to match.
2. Confirm where 0.3.x writes session state (`~/.claude/projects/...`, `.claude.json`, anything new), and update `sessionState` to match.
3. Decide how pre-bump sessions are handled: either 0.94 can `loadSession` a 0.16.2 transcript, or the driver surfaces a typed resume error. Record the decision here.

## Outcome (2026-10-22)

- **Flush:** `CLAUDE_CODE_EAGER_FLUSH` is still read by the Claude Code 2.1.303 binary, which awaits the transcript flush after `transcript_persist` when it is set. The profile env is unchanged, and the test comment was updated for 0.94.0 / 0.3.303.
- **State paths:** `$CLAUDE_CONFIG_DIR` or `~/.claude`, under `projects/<dir>/<id>.jsonl`. `sessionState` is unchanged.
- **Pre-bump resume decision:** resume natively, with the existing fallback ladder. Verified offline: a session written by the old image (`claude-code-acp` 0.16.2, session `7a3ce71d…`) was resumed by the new image with `resume: "loaded"`, `continuity: "session-load"`, and the prior history in the model request. A missing transcript makes the adapter throw `resourceNotFound` (-32002), which `canRebuildSession` already maps to a fresh process plus transcript re-prime (existing tests: corrupt/closed restart). No code change needed.
