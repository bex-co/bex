## Objective

While a custom range is active, the range trigger shows the window itself (for example "Nov 12, 3:39:00 PM – 3:39:20 PM", and in zh with Chinese date formatting) on service Logs, Postgres and Key Value Logs and Metrics; "Custom…" stays as the dropdown option, and the Edit button stays.

## Result (2026-11-14)

`RangeSelect` (service Logs, Postgres and Key Value Logs, Metrics: every caller shares it) shows the active custom window in its trigger through `formatTimeWindow` (`Intl.DateTimeFormat.formatRange`, shared parts said once): `Nov 12, 3:39:00 PM – 3:39:20 PM`, zh `11/12 下午3:39:00 – 下午3:39:20`, with the same text as the trigger's `title`. The window reads the viewer's clock, so it replaces "Custom…" only after hydration. "Custom…" stays the dropdown option and the Edit button stays. The trigger widens to fit (`min-w-40 max-w-80`, truncated with the title) instead of clipping (the w4/614 lesson). Tests: `range-select.test.tsx` (en window and title, preset label back, zh).
