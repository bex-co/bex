## Objective

Add meaningful automated coverage that fails if a future controller reintroduces a
cluster-wide Secret informer or if the namespace-safe KeyValue event path stops
reconciling its owner.

## Context

- Existing RBAC tests reject Secret verbs in the ClusterRole but did not catch a
  watch that nevertheless requires those verbs at runtime.
- The regression must cover manager/cache startup, not only static YAML content.
- App reconciliation is part of the failure mode because one blocked informer
  prevented every controller from starting.

## Steps

1. Add a production-shaped startup test with ClusterRole plus namespace Role
   permissions and assert controller caches synchronize.
2. Assert a KeyValue-owned Secret event in the apps namespace triggers owner
   reconciliation.
3. Assert App reconciliation proceeds under the same manager configuration.
4. Retain or strengthen static RBAC checks against cluster-wide Secret access.
5. Run `make test` from `lego/operator/`.

## Files

- `lego/operator/internal/controller/*_test.go`
- `lego/operator/internal/controller/rbac_test.go`
- `lego/operator/config/rbac/`

## Acceptance criteria

- [ ] Tests fail against the incident-causing watch configuration and pass with the fix.
- [ ] Both KeyValue Secret events and App controller startup are exercised.
- [ ] Cluster-wide Secret permission remains explicitly forbidden.
- [ ] `make test` passes from `lego/operator/`.

## Out of scope

- Coverage-only assertions that do not exercise real cache or reconciliation behavior.

## Completion evidence

- `secret_cache_test.go` starts a real envtest manager with a service account that
  is forbidden to list Secrets cluster-wide but allowed in the apps namespace.
- The test exercises informer replay through the real App reconciler and observes a
  KeyValue owner reconcile after an owned Secret resource-version change.
- A direct authorization assertion proves the incident-causing cluster-wide Secret
  list is forbidden while namespace-scoped access succeeds.
- `make test` passed from `lego/operator/`, including generation, formatting, vet,
  unit tests, and the controller envtest suite.
