# Mobile agent composer can't start repo sessions (sends the repo default branch)

Why: `mobile/src/features/agent-sessions/composer/compose.ts` sends the repo's default branch (e.g. `main`), and the backend rejects anything outside `bex-agent/*` with a 400. It predates w10/m17; found in the m17 closeout.

- Remove the mobile branch picker and derive `bex-agent/<slug>` like the dashboard, including the non-ASCII fallback `bex-agent/session-<base36 time>`.
- Add a mobile test plus a scope-policy test update if the operation shape changes.
