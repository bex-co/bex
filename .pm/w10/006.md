# Agent network tier "Full internet" is stored but not enforced

Why: Settings → Agents shows Full internet as "coming soon". The tier is stored and rendered as `registries`, because the `bex-api-session-egress` admission policy only admits exact FQDN rules. Cilium can't carve the model-provider hosts out of a world rule.

- Design an enforceable "any public host except model providers" posture, e.g. an egress HTTP CONNECT proxy in the gateway that denies the provider FQDNs, with the sandbox allowed only to that proxy.
- Then widen the VAP for that labelled posture and enable the option in the UI.
