# 052 — After a session's pull request is merged or closed, the next turn's overlay still says "there is never a second one", though `open_or_update_draft_pr` opens a new pull request

Why: the overlay tells the agent something false at the moment it decides how to deliver follow-up work, and the agent spends reasoning reconciling it with the user's "open a new pull request". Found by w10/m577 t005's live run on production, 2026-11-23. Severity: minor. Surface: `lego/agent-image/driver/src/overlay.ts` (`existingPrLine`), `lego/backend/internal/agentsessions/service.go` (the driver env for a steering turn).

## Observed (2026-11-23, pin `ac882b5f557f`)

Session `ags-dc22fn6hv52s73bqmme0` in `tian-personal` merged its pull request #1 in turn 1 (GitHub auto-merge). Turn 2's overlay still read "Earlier turns of this session already opened pull request #1 (…/pull/1). Calling `open_or_update_draft_pr` updates it; there is never a second one." The agent's reasoning stalled on it: "the platform says earlier turns already opened PR #1 … there is never a second one. But the user asks to 'open a new pull request'." It then called `open_or_update_draft_pr`, which answered `created: true` with #2, a new pull request on the same session branch.

## Current state

- `service.go` (around line 1804) sets `BEX_AGENT_PR_URL`/`BEX_AGENT_PR_NUMBER` from the session's recorded pull request whatever its `prState`.
- `existingPrLine` (`overlay.ts:127`) always says the call updates it and that there is never a second one.
- The PR verb opens a new pull request when the recorded one is merged or closed.

## End state

When the recorded pull request is merged or closed, the overlay says so, for example "Earlier turns opened pull request #1, which is merged; calling `open_or_update_draft_pr` after new pushes opens a new pull request". It keeps today's sentence only for an open one. The driver learns the state from bex-api, for example a `BEX_AGENT_PR_STATE` env beside the URL. A driver test covers open, merged and closed, and a backend test covers the env.
