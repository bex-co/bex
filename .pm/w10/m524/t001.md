## Objective

Decide the setting's shape and record it in ADR047 and ADR090 D4 before any code: its name on every surface, its default, its scope, the two enforcement points and when a change takes effect.

## Context

- The agent environment row: `lego/backend/internal/store/agent_environments.go` (`AgentEnvironment`, `AgentEnvironmentPatch`, `upsertAgentEnvironment`). The last migration that added a field to it is `0311_agent_environment_default_template`.
- The service's read and input: `lego/backend/internal/agentsessions/environment.go` (`Environment`, `EnvironmentInput`). REST is in `rest.go`, GraphQL in `graphql.go`, MCP in `mcp.go` (`get_agent_environment`, `update_agent_environment`).
- The driver's `gh`: `lego/agent-image/driver/src/github-cli.ts` and `githubCliLine` in `overlay.ts`. The dispatch env is built by `driverEnv` (`lego/backend/internal/agentsessions/service.go`).
- The gateway route: `serveGitHubAPI` (`lego/backend/internal/sshgateway/agentcred/githubapi.go`). The read and write mints: `Minter.MintGitHubRead` and `MintGitHubWrite` (`lego/backend/internal/agentsession/mint.go`). Named refusals on the internal hop: `RefusalHeader` (`lego/backend/internal/agentsession/contract.go`).
- Devin: a security profile removes the `gh` token, and sessions keep Git but lose direct GitHub API calls ([Security profiles](https://docs.devin.ai/product-guides/security-profiles)).

## Steps

1. Pick the names. The proposal is `githubCliEnabled` (REST, GraphQL, MCP), `agent_environments.github_cli_enabled boolean NOT NULL DEFAULT true`, the driver env `BEX_AGENT_GITHUB_CLI` (`0` turns it off; absent means on, so an older bex-api never turns `gh` off), `bex agent env set --github-cli on|off`, and the dashboard label "GitHub CLI (`gh`)". Keep them if nothing in the code argues otherwise.
2. Decide the enforcement points. bex-api's read and write mints refuse a session whose workspace has the setting off, with a new named refusal (for example `github-cli-off`) that the gateway maps to a 403 naming the setting. The driver skips `gh` at dispatch. The gateway check is the one that holds for running sessions, because the driver's configuration changes only at the next turn.
3. Write the refusal message: it says that `gh` is turned off for the workspace's agent sessions, how an admin turns it on (Settings → Agents, `bex agent env set --github-cli on`), and that pushes to the session branch and the `bex` tools still work.
4. Amend ADR047 (the agent environment and the `gh` route paragraphs) and ADR090 D4, each dated 2026-11-19 or later with this milestone's id, and run prettier on them.
