# 059 — On a cold load of a session's page, the Terminal button appears only after the capabilities query answers, so the header's action row reflows

Why: from 640 px up the session header first paints Files, Connect and "…", then inserts Terminal between Files and Connect once a separate client query answers, so the row a person is about to click moves under them on every first visit. Found by w10/m615 t007's Devin walk on production, 2026-11-24. Severity: minor (layout shift). Surface: `dashboard/src/features/agent-sessions/components/session-detail-header.tsx` (`useSessionTerminalOffered`, the `terminalOffered ? <SessionTerminalSheet …/> : null` beside `SessionFilesButton`).

## Observed (2026-11-24, pin `19638322178a`)

At 1280 px, an accessibility snapshot taken as `/agents/<id>` finished loading in a fresh browser listed `button "Files"`, `button "Connect"`, `button "More actions"`. The next snapshot on the same page listed `button "Files"`, `button "Terminal"`, `button "Connect"`, `button "More actions"`. The session was a disposable `tian-personal` session, deleted afterwards. The shift's size and duration were not measured.

## Cause

Connect renders from the session's own `sshAddress`, which the page already has (`OpenInZedButton`, `if (!session.sshAddress) return null`). The Terminal renders from `agentSessionCapabilities.terminalEnabled`, a client `useQuery` (`use-agent-session-capabilities.ts`, `cache-first`) that the route loader does not prime. Until it answers, `terminalOffered` is false and the button is absent.

## End state

On a cold load at 1280 px, the header's action row has the same buttons in the same places from first paint to ready. Options include priming the capabilities query in the route loader, or rendering the button from data the page already has and leaving `terminalEnabled: false` to the sheet's own refusal (`agentSessions.terminalUnavailable`). Below 640 px, the "…" menu item follows the same rule. A dashboard test renders the header with the capabilities query pending and finds the Terminal button, or the loader primes the query and a test asserts that.
