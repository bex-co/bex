# 043 — SSH into an agent session whose turn ended answers a bare `Permission denied (publickey)`, as if the key were wrong

Why: a member who copied a session's `ssh ags-…@ssh.bex.co` command and runs it after the turn ended gets the same refusal as an unregistered key, with no hint that the session only needs a message to run again, so they debug their key instead. Found by w10/032's live check, 2026-11-22. Severity: minor (Devin parity). Surface: `lego/backend/internal/agentsessions/ssh.go` (`ResolveSSHSession`, `liveSandboxPhase`), `lego/backend/internal/sshgateway/nativessh/server.go` (the public-key callback, `loginRefusal`).

## Evidence (production, pin `eaaa61506165`, 2026-11-22)

Repo-less session `ags-dc1kvrjr121s73eu0gcg` in `tian-personal`: once its first turn ended (`phase: completed`), `ssh` with the account's registered key printed only `Permission denied (publickey)`, while the sandbox Pod was still Running. After a steer started a new turn (`phase: running`), the same command opened a shell at once. The resolver authorizes `can_view_sensitive` first, then refuses `AGENT_SESSION_NOT_ATTACHABLE` for a phase outside `liveSandboxPhase` (`ssh.go:64-79`). The gateway sends a banner only for the login-requirement refusals `loginRefusal` knows (two-factor, Google sign-in), so this one reaches the client as a plain key rejection. The dashboard hides the SSH command while `sshAddress` is absent, so the CLI and a copied command are where this shows.

## End state

- An authorized member's SSH login into a session with no live sandbox gets an auth banner that says the session is not running and how to start it again (send it a message, then connect), in the same way the two-factor refusal's banner does. Check how Devin presents a sleeping session's machine before writing the wording, and cite it here.
- Someone who cannot view the session, or names a session that does not exist, still gets the bare refusal: the banner is sent only after authorization passes, so it never reveals that a session exists.
- A gateway test covers both cases.
