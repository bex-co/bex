## Objective

Make one offered-model set read the allowlist, so a catalog model added after a narrowing write is off everywhere a turned-off model is. Make the environment read name those models apart from the ones an admin turned off.

## Context

- `offeredModels` (`lego/backend/internal/agentsessions/environment.go:837`) and `leftOn` (`:853`) serve every check:
  - `sessionModel` (`:894`), for create, message, turn dispatch and automation save;
  - `agentModels` (`:970`), for the capabilities read;
  - `environmentView` (`:675`);
  - the `defaultModel` check in `modelOfferPatch` (`:585`);
  - `retiredTemplateModel` (`automation_scheduler.go:248`).
- `modelOfferPatch` writes the list (`:588-618`).
- The REST, GraphQL and MCP types are `Environment` and `EnvironmentInput` (`environment.go:73-186`), `graphql.go` and `mcp.go` (the `get_`/`update_agent_environment` descriptions at `:288`/`:293`).
- The fixtures are `lego/backend/internal/agentsessions/testdata/mcp_tools.golden.json` and `lego/backend/internal/api/testdata/schema.graphql`.
- The existing tests are `model_offer_test.go`, `model_offer_pg_test.go`, `TestEnabledModelsOnEverySurface` and `TestEnabledModelsRefusalsOnEverySurface`.

## Steps

1. Make `offeredModels`/`leftOn` read the allowlist. An allowlist offers `catalog ∩ allowlist`, plus `catalog[0]`. "Allow all" offers the catalog. A legacy row reads as t001's rollout rule says.
2. Make `modelOfferPatch` store "allow all" or the allowlist per t001's rule, and keep `disabled_models` as t001 decided.
3. Add the new-models field to `Environment`, GraphQL and MCP, with descriptions stating the two modes. Rewrite the `enabledModels` descriptions that say a later model starts on.
4. Update `lego/backend/AGENTS.md`'s `BEX_AGENT_PLATFORM_MODELS` row.
5. Add the tests. Add a catalog model after a narrowing write, through the test's platform-route setup. Check:
   - the capabilities `models` leave it out on REST, GraphQL and MCP;
   - a create naming it, a message naming it and an automation save naming it are refused with `AGENT_SESSION_MODEL_NOT_OFFERED`, with the "turned off in this workspace" message;
   - `defaultModel` naming it is refused with `AGENT_ENVIRONMENT_MODEL_NOT_OFFERED`;
   - the environment read lists it as new;
   - an un-narrowed workspace offers it;
   - turning it on offers it;
   - turning every model on allows all again.
