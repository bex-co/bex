## Objective

## Context

- `lego/cli/internal/agent/config.go` decodes `EnabledModels` (`:384`) and prints the "Models" and "Models off" rows (`:595-611`), where every off model reads "(turned off by an admin)". It sends `enabledModels` from `--models` (`:527`). It reads a field missing from an older bex-api as the whole catalog (`:577-580`).
- The contract fixture is `lego/cli/testdata/agent-cli-contract.json`, and the tests are in `lego/cli/internal/agent/lifecycle_test.go`.

## Steps

1. Decode the new field. A missing field (older bex-api) reads as no new models.
2. Print "Models off" with each model's reason: "(turned off by an admin)" or "(new in the catalog)".
3. If t001 added an explicit "allow all" mode, add its flag.
4. Update `--models`'s help.
5. Add tests for a read with both kinds of off model, and for an older bex-api's read.
