## Objective

Let the CLI set the workspace default template and show the templates bex-api serves, and stop hard-coding the template names and sizes in its help.

## Context

- `lego/cli/internal/agent/config.go`: `bex agent env` (`:368`), `env set` flags (`--default-model`, `:444`), `bex agent models` (`:506`).
- `lego/cli/internal/agent/agent.go:545`: the `--template` help names `agent` and `agent-4c-8g` with their sizes.
- `lego/cli/AGENTS.md` / `README.md` for the CLI's conventions and docs.

## Steps

1. `bex agent env set --default-template NAME` (`""` returns to `agent`); `bex agent env` prints the default template.
2. `bex agent models` (or a sibling the design picks) lists the templates with their sizes and marks the default.
3. The `--template` help points at that list instead of naming sizes.
4. Run `cd lego/cli && go test ./...` and `make lint`.

## Files

- `lego/cli/internal/agent/{config.go,agent.go}`, their tests, the CLI docs that list `bex agent env set` flags

## Acceptance criteria

- [ ] `bex agent env set --default-template agent-4c-8g` sends `defaultTemplate`, and `bex agent env` shows it.
- [ ] The templates printed come from the server's response (a test with a third, made-up template shows it).
- [ ] `cd lego/cli && go test ./...` and `make lint` pass.
