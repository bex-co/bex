## Objective

Give a dashboard user the template choice the API and CLI already have, read from bex-api's list: pick it when starting a session or saving an automation, set the workspace default, and see which template a session runs on.

## Steps

1. A Sandbox control in the new-session composer listing name and size, preselecting the workspace default; the create sends the picked one.
2. The same control in the automation form (create and edit), showing the stored template.

4. The session detail header shows the session's template and size.
5. Locales in every language; run `yarn lint` and `yarn test`; check desktop and narrow-mobile widths.
