## Objective

Make sure the shipped behavior has meaningful tests:

- the whole catalog for a workspace with no row;
- the admin-only write on each surface;
- the refusals for the catalog default, an unknown model and an empty list;
- `AGENT_SESSION_MODEL_NOT_OFFERED` at create, on a message and in an automation save;
- the narrowed capabilities `models`;
- the next turn's fallback and the queued message's fallback;
- the automation fire's note;
- a turned-off workspace default yielding the catalog default;
- a workspace on its own key unaffected;
- the CLI flag and table;
- the dashboard list and its pickers.

## Acceptance criteria

- [x] Each behavior above is covered by a test that fails when the behavior is removed. Spot-check at least the create refusal and the next-turn fallback by reverting them.
- [x] The backend, CLI and dashboard suites pass.

## Result

Done 2026-11-20. Each behavior has a test:

- **No row and the admin-only write:** `TestEnabledModelsOnEverySurface` (REST, GraphQL and MCP) and `TestAgentEnvironmentDisabledModelsRoundTrip` (real DB).
- **The refusals:** `TestEnabledModelsRefusalsOnEverySurface` covers the default off, the empty list, a non-catalog model and the own key. `TestOfferedModelsKeepTheCatalogDefault` covers the route off. `TestDefaultModelAndTheEnabledModels` covers a `defaultModel` that is off.
- **`AGENT_SESSION_MODEL_NOT_OFFERED`** at create, on a message, and on an automation create and update: `TestATurnedOffModelIsRefusedEverywhere`.
- **The narrowed capabilities:** `TestCapabilitiesShowEachAgentsModelOnEverySurface` on all three surfaces.
- **The fallbacks:** the next turn's in `TestASessionOnATurnedOffModelRunsTheDefaultFromItsNextTurn`, which covers both the workspace and the catalog default. The queued message's in `TestAQueuedMessageOnATurnedOffModelRunsTheDefault` (real DB).
- **The automation fire's note:** `TestAnAutomationOnATurnedOffModelRunsTheDefault`.
- **A turned-off workspace default** yielding the catalog default: `TestDefaultModelAndTheEnabledModels`.
- **The own key unaffected:** `TestTheModelListLeavesAnOwnKeyWorkspaceAlone`.
- **The CLI:** the `TestEnvSet` cases, `TestEnvShowsTheEnabledModels` and `TestModelsListsOnlyTheOfferedModels`.
- **The dashboard:** the card's "models members can choose" block, the lib, hook and automation-form tests.

Spot-checked by reverting:

- Making `leftOn` offer every catalog model fails every backend test above, the create refusal and the next-turn fallback included. Dropping its catalog-default rule fails `TestOfferedModelsKeepTheCatalogDefault`.
- In the dashboard, pointing the default-model select back at the whole catalog, or removing the one-model picker fix, fails three of the new tests.

The backend suite with real Postgres, OpenFGA and OpenBao, the CLI suite and the dashboard suite pass.
