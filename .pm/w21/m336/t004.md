## Objective

- Found 2026-11-08: 11 `billing_lifecycles` rows with `status='enforcing'`, `attempt_count` about 21,000, empty `last_error`, every tenant still existing; `billing lifecycle: no rows in result set` logged 1,147 times in 7 hours ([`finding.md`](finding.md)).
- `Enforce` has run for these rows on every lease, so their effective state is already enforced; once t001 ships, `Complete` flips the row to `enforced`. A row whose workspace should not be enforced (first-party, comped, excluded) must be corrected first, through the sanctioned override (`SetBillingException`, `ForceBillingRecovery`).
