# 073 — Operator proxy, job and logging hardening notes from the round-25 audit

Why: small gaps with no known path: a mistyped trusted-proxy CIDR is silently widened, the edge-cache sidecar has only a header read timeout, a cancelled fetch leader fails its waiters, an admin tool takes credentials in argv, the manager logs in development mode, and a disk whose snapshot stream passes about 78 GiB never snapshots.

- **Source:** w21/m394 round 25 audit, hardening (Proxies and jobs, Logging), 2026-11-14.
- **Size:** about 2h; split by component if one item grows.

## Items

- PROXY trust serves a trusted peer that sends no header as the peer's own IP, and `ParseTrustedProxyCIDRs` masks a mistyped `/24` (`lego/operator/internal/sniproxy/`).
- The edge-cache sidecar sets only `ReadHeaderTimeout` (`lego/operator/cmd/edge-cache/main.go`); add read, write and idle timeouts that keep streaming and long-poll responses working.
- A static-server fetch leader's cancellation answers its waiters 502 (`lego/operator/internal/staticserver/staticserver.go`, singleflight in `get`).
- `registry-migrate` takes `--src-creds user:pass` in argv with `--src-tls-verify=false` (`lego/operator/cmd/registry-migrate/main.go`).
- `zap` `Development: true` in the manager (`lego/operator/cmd/manager/main.go:161`) and static server enables DPanic, debug level and no sampling.
- A disk whose snapshot stream exceeds about 78 GiB never snapshots (the upload part cap, `lego/operator/internal/disksnapshot/store.go`); the restore-key prefix check does not reject `..` (not tenant-reachable); the comment at `disksnapshot.go:335` about `os.Root.Symlink` is wrong.
- Clone and context symlink containment (`pwd -P`) runs in one step only.

## Acceptance

- Each fixed with a test, or recorded as accepted with the reason; `make test` and `make lint` (operator) pass.
