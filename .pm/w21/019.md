# Several UI texts fall below WCAG AA contrast (4.5:1): log instance ids in both themes, and the 404 chip, project health line, Partial data label and success badge in the light theme

Why: the instance id in every log line is the click target for filtering by instance, and it is the dimmest text on the page in both themes (3.13:1 light, 3.84:1 dark).

**Severity:** minor (readability and WCAG 1.4.3, no functional loss). **Estimate:** 30m, dashboard only (five class edits plus a regression check). **Source:** live `/qa-find-bugs` pass 13 (contrast sweep), 2026-11-10, production `https://dashboard.bex.co`, workspace `bex`, filed to w21 per user direction. **Status:** inbox.

## Method (reproducible)

For each page, in the light and the dark theme (`localStorage['vite-ui-theme']` = `light` or `dark`, browser-local, then reload), walk every visible text node and compute the WCAG contrast ratio of its computed color against its effective background.

- Colors can be `oklch()`/`oklab()`, so each CSS color is converted through a 1x1 canvas (`fillStyle`, then `getImageData`).
- The background is composited from the root down through every ancestor's `background-color` alpha; the text color is composited with the cumulative opacity.
- Threshold 4.5:1, or 3:1 for text of at least 24px (or 18.66px and bold). Skip `disabled`/`aria-disabled`/`data-disabled` and hidden elements.
- Pages scanned (light and dark): Overview, a service's Deploys, Events, Logs, Metrics, Environment, Scaling, Plan and Settings tabs, Blueprints, Environment Groups, Webhooks, Webhooks/new, Notifications, Billing, Workspace Settings, New Web Service, Agents, Automations.
- Result: dark theme has 1 failing spot (the instance id). Light theme has the spots below; every other page had 0 failures (66 text nodes on Overview, 206 on a service's Deploys tab).

## Findings (live numbers, WCAG ratio)

1. **Log instance id `[b6f6e]`** (the "Filter logs by instance …" button; 12 on one Logs page): light 3.13:1, dark 3.84:1, 12px.
   - Root cause: `dashboard/src/features/logs/components/log-line-list.tsx:419` (button) and `:433` (the non-interactive variant): `text-muted-foreground/70`.
   - Control: the timestamp beside it uses `text-muted-foreground` (line 411) and passes the scan in both themes; the un-faded muted foreground measured 5.36:1 against the 404 chip's tinted background in the light theme, a harder case than the plain log background.
   - Fix: drop the `/70`.
2. **`404` status chip in the request log** (light): 4.12:1. `log-line-list.tsx:28` `bg-amber-500/15 text-amber-700`. Measured candidate `text-amber-800` on that background: 5.81:1. The 2xx (green-700), 3xx (blue-700) and 5xx (red-700) chips pass, so only the 4xx line moves.
3. **Overview project card "All resources running"** (light): 3.44:1, 14px. `dashboard/src/features/projects/components/project-card.tsx:47` `text-emerald-600 dark:text-emerald-400`. Measured `text-emerald-700`: 5.06:1. Dark passes.
4. **Billing "Partial data"** (light): 3.2:1, 12px. `dashboard/src/features/usage/components/charges-card.tsx:254` `text-amber-600 dark:text-amber-500`. Measured `text-amber-700`: 5.03:1.
5. **Success badge**, seen as "Verified" on a custom domain (light): 4.49:1 (just under 4.5). `dashboard/src/common/components/ui/badge.tsx:21` `success: "bg-emerald-600/15 text-emerald-700 …"` (the badge's measured background `217,240,232` is that tint over white). Measured `text-emerald-800` on that tint: 6.37:1. This is a shared variant: 5 non-test `variant="success"` usages (grep), plus any caller that picks the variant indirectly (not enumerated).
6. **At the limit, token level, not part of this fix:** the "bex extension" chip on Notifications, 4.49:1, `dashboard/src/features/notifications/components/push-notification-settings-panel.tsx:224` `text-primary` on `bg-primary/10`. Changing it means changing `--primary` or the chip pairing, which touches every `text-primary` use.

## Fix (target behavior)

Every text in the scanned pages meets 4.5:1 (3:1 for large text) in both themes, using the darker Tailwind step measured above for each spot (log ids: the un-faded `text-muted-foreground`), with no layout change and no change to dark-theme colors other than item 1. UI only.
