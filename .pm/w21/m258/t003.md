## Objective

Add `agent_sessions.idempotency_key` with a partial unique index on `(tenant_id, idempotency_key)` valid for 24 h. Same key + same normalized request returns the existing session with `created:false`; same key + different request returns `409 AGENT_SESSION_IDEMPOTENCY_KEY_REUSED` (ADR094 D4). `created` appears on every create response.

## Context

- Key: 1–128 printable ASCII.
- REST header `Idempotency-Key`, GraphQL argument `idempotencyKey`, MCP field `idempotencyKey`.
- Migrations live with the backend store; create path in `lego/backend/internal/agentsessions/service.go`.

## Steps

1. Write migration (column + partial unique index).
2. Normalize request for comparison; implement lookup-or-create in a transaction.
3. Wire three transports and the error code; add 24 h expiry handling.

- lego/backend/internal/agentsessions/service.go

- migration

## Acceptance criteria

- [ ] Retrying a create with the same key creates exactly one sandbox/session (`created:false` on retry).
- [ ] Different request, same key → 409 with the named code.
- [ ] Concurrent duplicate creates yield one session.

## Out of scope

- Batch create (rejected in ADR094 D3).
