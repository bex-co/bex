## Objective

Make `pub-<obk-xid>.<BEX_BASE_DOMAIN>` reach the gateway over TLS.

## Context

- `docs/ADR112-object-storage.md` D4: `pub-<obk-xid>` is a single label under `BEX_BASE_DOMAIN`, so the existing `*.onbex.co` certificate (`docs/ADR093-onbex-wildcard-tls.md`) covers it. Routing is an infrastructure task: a Traefik `HostRegexp` route or operator-managed Ingresses is unverified.
- `scripts/gitops-validate.sh` is domain-agnostic: it asserts a suffix is declared and never the literal `onbex.co`; DO_NOT_DO #PSL forbids unsetting `BEX_BASE_DOMAIN`. Keep the route domain-agnostic.
- Precedence: the `pub-` reservation (t001) means no service host can collide.

## Steps

1. Decide the routing form with a short check of how static-site and App hosts reach their backends today, and implement it.
2. Verify with `curl` that a `pub-` host serves over the wildcard certificate and that a service host is unaffected.
3. Run `scripts/gitops-validate.sh`.

## Files

- deploy/gitops/ or lego/operator/config/ (route)
- scripts/gitops-validate.sh (only if a check must learn the new host form)

## Acceptance criteria

- [ ] A `pub-` host reaches objectgw over TLS with no per-host certificate.
- [ ] `scripts/gitops-validate.sh` passes.

## Out of scope

- Custom domains.

## Result

Two Traefik IngressRoutes (a Kubernetes Ingress cannot match a `pub-*` prefix, and the operator may not write Ingresses outside tenant namespaces): `objectgw-public` on `websecure` with `tls: {}` (Traefik's default store certificate, the existing `*.onbex.co` wildcard, no per-host order) and `objectgw-public-http` on `web` through the platform-host fallback's redirect middleware, both matching `HostRegexp(^pub-[0-9a-v]{20}\.<suffix>$)` at priority 10000, above the activator fallback (1), wildcard custom domains (1) and every App route (rule length). The suffix is written in the manifest with a keep-in-sync comment, as the fallback Ingress does; `gitops-validate.sh` derives it from the prod `BEX_BASE_DOMAIN` and never names the literal. Kustomize's name prefix reaches the route's Service and Middleware through a `nameReference` configuration. `kubectl kustomize` renders `config/default` and `config/prod`; the repo's guards pass. **Not verified, needs production (t008):** a `curl` through Traefik (no cluster access here), that Traefik v3 matches `HostRegexp` against the whole host as documented, and the TLS answer.
