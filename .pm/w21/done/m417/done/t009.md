## Objective

Check public reads against Cloudflare R2's public bucket behavior and record where bex differs. Render offers no equivalent.

## Context

- Surface: the `dev-url` REST routes and the public `pub-` host. Reference: R2's `r2.dev` behavior (non-production, rate-limited) as read 2026-11-14 in ADR112 § Sources.
- GraphQL, MCP and the dashboard have no object surface.

## Steps

1. Compare `dev-url` shapes and public-read behavior (no listing, caching, CORS, rate limiting) with R2's documentation.
2. Record each difference in ADR018's Extension row.

## Files

- docs/ADR018-render-parity.md

## Acceptance criteria

- [ ] Every difference from R2 is written down with its reason.

## Out of scope

## Result

Dependency changed from t008 to t007 on 2026-11-15: the comparison reads Cloudflare's published documentation and runs the real wrangler against the handlers, and none of that needs production (t008 does, and stays open as the gate), as m415 and m416 did. Compared on 2026-11-15 with Cloudflare's public-buckets page (the r2.dev public development URL: non-production, rate-limited, no caching, WAF or access control without a custom domain, no listing at the root, enabled and disabled in the bucket settings) and its API schema for updating the managed domain (`PUT` with a boolean `enabled`, result `bucketId`, `domain`, `enabled`), which bex's route matches. Render has no public buckets. Every difference is in ADR018's extension entry with its reason, dated and unsigned: the host is a label under the shared platform suffix and not Cloudflare's own `r2.dev` (the same risk class as static sites, ADR103); publishing needs the workspace admin; turning it off reaches visitors within 30 seconds and an overwritten object within 60 (Cloudflare publishes neither); the caps are bex's own and per replica (Cloudflare publishes no r2.dev limit); `If-Range` serves the whole object; a non-preflight `OPTIONS` is 405; and Cloudflare's page says nothing about CORS on r2.dev, so there was nothing to compare. The one parity-driven change to ADR112 itself is the `pub-` reservation (t001). `docs/bex-cli.md` gains the public-bucket section with the same warnings.
