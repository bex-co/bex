## Result (2026-11-14)

`/simplify` ran over the ten fix commits' non-test source (reuse, quality, efficiency, three reviewers; each commit had also been reviewed once on its own). Applied:

- **Reuse:** `fetchGate`'s hand-rolled per-site counter (`mu`, `perSite`, `maxPerSite`, `releaseSite`, about 20 lines) is gone; the static server's per-client limiter became `keyedLimiter` and `fetchGate` holds one per site (`staticserver/fetchgate.go`, `clientkey.go`). `canonicalClient`, a one-line wrapper, is inlined. Three copies of a 5-second polling loop in the new tests (`staticserver`, `activator`, `controller`) became gomega `Eventually`.
- **Quality, one real defect:** a registry host's failure history outlived `registryHostMemory` until 512 hosts were held, so a host that failed four times last week and once today got the 5-minute breaker at once. `acquire` now forgets an idle host quiet past its window plus the memory (`TestRegistryReadGateForgetsAHostThatStayedQuiet`; the existing breaker test's interval became "window plus one second").
- **Quality:** an App's failure counter now resets on any outcome that is neither transient nor busy, so a registry refusal also starts it over (`imageRegistryWait`; the test covers success and a `RefusedError`). The edge cache charges `cap(body)` as the static server's cache does, since the body is a `bytes.Buffer`'s slice. The orphaned `maintenancePages` comment sits on its var again, `imageRegistryWaitMessage` moved into its const block, the design paragraph is on `registryReadGate` and no longer retells the incident, and "about 3000 entries" is on the `negativeBudget` field.

Declined, with the reason:

- **Compute the client key lazily** (efficiency): about 0.5 µs and four allocations per static-server request, an estimated 2 to 4% of a cached response, no measurement. The change touches five call sites, and `serveNotFound` holds only `r`, not a context, so it needs a wider signature change for no measurable gain.
- **Drop `registry.NewTransientError`** (quality: used only by a test): it is a legitimate constructor for a type whose only field is unexported, and the dead-code analysis counts tests as roots, so lint passes.
- **Key the backend's per-source caps on the /64** (reuse): a real gap of the same kind (`nativessh/server.go:343`, `cmd/ssh-gateway/main.go:646`, `api/authadmission.go:170`), but a behavior change in security code outside this milestone's diff; filed as w21/074.
- **A shared "decrement and delete at zero" package**, and making `sniproxy.decrementKey` generic: the lock scope differs at each of about ten places (the gate must check and increment its host and workspace counters under one lock), and `sniproxy` is code this milestone did not write.

Checked and left alone: `hostIndex` costs about 10 to 20 ms per rebuild at 5,000 Apps and rebuilds at most 4 times a second (`appwatch.Loop`), the negative-eviction scan is bounded by the 3,000-entry site share, and the 0260 triggers run only on user-initiated domain add and remove. Gates: `make lint` exit 0 and `GOWORK=off make test` exit 0 on the simplified tree.
