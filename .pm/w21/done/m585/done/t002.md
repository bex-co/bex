## Objective

The operator's allowlist and the image gate admit t001's list per major, and the gate proves each is created by the owner and that the closed list still closes.

## Steps

2. Replace the three refusals with owner creations plus one use each where cheap (`earth_distance`, a `moddatetime` trigger, a `dblink` connect with a password to the same instance).
3. Add the non-listed refusal and keep the owner-is-not-superuser check after every creation.
4. Rerun the gate in CI (the image does not change unless t001 asked for a script).
