## Objective

The owner creates and drops `vector` through the allowlist on every major.

## Context

- pgvector is not a trusted extension (ADR009 § pgvector: `CREATE EXTENSION vector` needed a superuser), so it needs the allowlist like the others.
- Admitted lists: `deploy/pg-operand/matrix.json` and the operator copy in `database_operand.go`, kept equal by `TestPGExtensionAllowlistMatchesTheImageGate`.
- The image already carries pgvector (CNPG's system image installs it).

## Steps

1. Add `vector` to every major's admitted list.
2. In `check.sh`, as the owner in a fresh database: `CREATE EXTENSION vector;` with `ON_ERROR_STOP`, a `vector(3)` table with an HNSW index and a nearest-neighbour query, then `DROP EXTENSION vector`.
3. Check the export and restore of a database using `vector`.
