## Objective

The new command surface is consistent with the other surfaces it exposes and with Render's conventions where Render has an equivalent.

## Context

- `bex s3` is a bex extension (ADR018's `Extension` row); the Render equivalent for objects is `render ea objects`, which is unchanged. Compare the flags and conventions the verbs share with `bex ea objects` and `bex agent` (`-o json`, exit codes, `--confirm` and non-interactive behavior, how a refusal prints), and the key and publish verbs with the REST and GraphQL routes they call and the dashboard's object-storage page, if there is one.
- Flag any drift as a follow-up note, never as a silent divergence.

## Result

Compared 2026-11-20: `bex s3` against `bex ea objects` (the Render equivalent for objects, unchanged), `bex agent` (the bex-native command conventions), the REST and GraphQL routes `keys`, `public` and `info` call (`/v1/object-storage/{ownerId}/access-keys` and `.../buckets/{bucket}[/public]`, GraphQL beside them, ADR018) and the dashboard (no object-storage page exists, as ADR112 D10 says). The surfaces agree on: `-o json|yaml|text` with the text fallback off a terminal, exit `1` for a failure and `2` for a wrong command line, the active workspace (`bex workspace set` or `BEX_WORKSPACE`) and no per-command `--workspace`, the key and bucket JSON fields that `keys` and `info` print being the REST answer's own.

Drift, each recorded in ADR018's `bex s3` row (dated 2026-11-20, sign-off awaiting the user) and the first filed as a follow-up:
- **Confirmation:** `bex ea objects delete` prompts in a terminal unless `--yes` or `--confirm`; `rm --recursive`, `rb --force` and `sync --delete` do not, and the root `--confirm` flag is accepted and ignored. Filed as w21/115 (parity-sufficient change: prompt in a terminal only, never in a pipe or CI).
- **JSON field names:** `bex s3 ls -o json` uses S3's (`size`, `lastModified`, `etag`) where `ea objects list` prints Render's (`sizeBytes`); the commands read different APIs, so this stays and is recorded.
- **`--region`:** optional here (default `oregon`), mandatory for `ea objects`.
