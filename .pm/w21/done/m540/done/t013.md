## Objective

The native `bex s3` reaches users: `bex-cli/v0.9.0` is published and verified on every channel.

## Context

- The user approved this plan on 2026-11-20 with its last step, "release v0.9.0 when done", so invoking `/release cli` here is authorized; follow `.claude/skills/release/SKILL.md` exactly (source from `origin/main`, a tag on the last commit whose required checks passed, `release (bex CLI)` to completion, the four archives, `checksums.txt` and its Sigstore bundle, the signature, the installer, the Homebrew formula, the update notice). The baseline is `bex-cli/v0.8.0`; the changes since are minor or patch by Conventional Commits, and an exact version is `0.9.0` if the rules agree.
- Verify the one thing this milestone is for: with the released binary installed through `scripts/install-bex.sh` into a temporary directory and a PATH with no other S3 tool, `bex s3 ls` runs.
