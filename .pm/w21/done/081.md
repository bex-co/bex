# 081 — Narrow the dashboard CSP's `connect-src` from `https: wss:` to the origins the app actually reaches, with a browser sweep

Why: the CSP's `connect-src 'self' https: wss:` (`dashboard/server/security-headers.ts`) lets an injected script send data to any https or wss origin. The w21/m394 audit asked for it narrower; w21/m410 t003 left it, because narrowing it silently breaks whichever origin a sweep misses (the API, Kratos, Stripe, the Browser Web Shell and the Cloudflare beacon are the ones named in `dashboard/AGENTS.md`).

- **Source:** w21/m410 t003, 2026-11-14.
- **Size:** about 1h30.

## Steps

1. List the origins at build time from `VITE_API_URL`, `VITE_KRATOS_PUBLIC_URL`, the web shell and attachments origins, Stripe and the beacon, the way `scriptOrigins` already builds the script list.
2. Sweep every flow in a browser against the real origins (sign in, a service, logs live tail, the web shell, billing, an agent session with an attachment) with the CSP in report-only mode first, and read the console for violations.
3. Switch to enforcing and update `security-headers.test.ts`, which should pin the directive.

## Done in part (2026-11-14)

The narrowing is built and reported, not yet enforced. `dashboard/server/security-headers.ts` builds the narrowed `connect-src` from the build env (`VITE_API_URL`, `VITE_KRATOS_PUBLIC_URL`, `VITE_AGENT_STREAM_URL`, `VITE_SHELL_WS_URL` defaulting to `wss://ssh.bex.co/shell`, the attachments origin) plus `https://api.stripe.com` and `https://cloudflareinsights.com`, and production sends it as `Content-Security-Policy-Report-Only` beside the unchanged enforced policy; the error-response plugin carries it too. Reading the code found every browser-side connection (Apollo, the Kratos client, `/api/*`, the agent stream, the live-log `EventSource`, the Web Shell `WebSocket`, the presigned attachment upload, Stripe.js, the Cloudflare beacon) but cannot prove a flow it never runs, and the Stripe Payment Element may add `link.com`, so enforcing waits for a sweep of the real flows: [w21/083](../083.md), due by 2026-12-14. Tests: `security-headers.test.ts` (exact origin set, only connect-src differs, absent without an API origin and outside production; red with Stripe dropped).
