## Objective

Stop the singleflight leader's cancellation (its client went away) from answering every waiter 502.

## Context

- `internal/staticserver/staticserver.go` `get` runs the origin fetch inside `h.group.Do` with the leader's own `ctx`; when that client disconnects, `origin.Get` returns `context.Canceled` and every coalesced waiter gets it as a 502 "origin error" (line 503).
- The fetch needs a bound of its own once it no longer follows its leader: nothing but the request context limits `S3Origin.Get` today.

## Steps

1. Red-first test in `concurrency_test.go`: two requests for one missing key, cancel the first while the origin blocks, release it, and the second must get 200 (and the origin is asked once).
2. Run the shared fetch on `context.WithoutCancel(ctx)` with a timeout, and wait per caller with `DoChan` and a `select` on the caller's own `ctx.Done()`, so a cancelled caller leaves and the fetch continues for the others.
3. Keep the admission slot and the per-client count tied to the fetch, released when it ends.

## Result (2026-11-14)

The origin fetch no longer belongs to the request that started it. `internal/staticserver/flight.go` replaces the singleflight group for origin fetches: the fetch runs under a context that keeps the request's values (the client key) but not its cancellation, with its own 30 s deadline (`originFetchTimeout`); each caller waits under its own context; the last caller out cancels the fetch and waits for it to unwind, which keeps the admission waiter's prompt exit (`TestAWaiterLeavesWhenItsRequestIsCancelled`). A panicking or `Goexit`-ing origin fails its requests instead of crashing the server or reading as an empty object. Tests (red before): a cancelled leader does not fail its waiter, a cancelled waiter returns at once, a fetch no one waits on is cancelled, a request after an abandoned fetch starts a fresh one, a silent origin ends at its deadline, a panicking origin is a 502; `go test -race -count=20` is stable. A review found one window (a joiner arriving between the last leaver's decrement and its cancel); the cancel now happens under the lock.
