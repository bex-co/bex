## Objective

Run the link gate and the board validator in CI on every change that can break them, including changes that touch only `.pm/**`, which `docs.yml` excludes.

## Context

- `.github/workflows/docs.yml` excludes `.pm/**` from its `paths` because prettier ignores `.pm`; a milestone closeout moves files in `.pm` and breaks inbound links without triggering it. A separate workflow avoids changing the prettier job's filter.
- Workflow rules: `scripts/github-actions-validate.sh` (GitHub-hosted runner labels, SHA-pinned actions; `#CI-RUNNERS` in `.pm/DO_NOT_DO.md`) and `scripts/ci_test_inputs.py`; copy the checkout pin and runner label from `docs.yml`.

## Steps

1. Add `.github/workflows/references.yml` that runs `scripts/docs-links-validate.sh` and `scripts/pm-board-validate.py` on pull requests and main pushes touching `**/*.md`, `.pm/**` or the scripts.
2. Run `bash scripts/github-actions-validate.sh` and `python3 scripts/ci_test_inputs.py`.

## Files

- .github/workflows/references.yml

## Acceptance criteria

- [x] A change that only moves a file under `.pm/` is in the new workflow's `paths`.
- [x] `scripts/github-actions-validate.sh` and `scripts/ci_test_inputs.py` pass.

## Out of scope

- Changing the prettier job.
