## Objective

## Context

## Steps

1. Create an every-5-minutes automation; confirm three consecutive fires each create one session.
2. Pause it: no fire. Resume: fires again.
3. Start a long session from it and let the next tick arrive: `skipped_overlap`.
4. Remove the QA user's `can_create` (or use a second QA member) and confirm `denied` plus auto-pause.
5. Compare pending and ready states side by side at desktop and at 375 px for `/automations`, `/automations/new` and an automation's detail page (the skeleton-parity check carried over from t007), and fix any mismatch.
6. Delete every fixture and verify it is gone; revoke QA sessions.
