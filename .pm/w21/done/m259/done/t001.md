## Completion note (2026-11-05)

- `outputSchema` (object; GraphQL: JSON text) and `outputRequired` (default true with a schema) are accepted by `create_agent_session` and `send_agent_session_message` on REST, GraphQL and MCP. `agentsessions/outputschema.go` compiles the schema as 2020-12 with a loader that refuses every reference leaving the document (external `$ref`, another `$schema` dialect, > 64 KiB, uncompilable, NUL) -> `400 AGENT_SESSION_OUTPUT_SCHEMA_INVALID`; `outputRequired` without a schema -> `AGENT_SESSION_INPUT_INVALID`.
- Migration 0200 adds `agent_session_turns.output_schema`, `.output_required`, `.result`, `.result_final` (the last two beyond the ADR's two columns: `result_final` separates a partial value from the answer). The contract is stored atomically with the turn (`CreateAgentSession`, `BeginAgentSessionTurn`) and is part of the idempotency digest.
