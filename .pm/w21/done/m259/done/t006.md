## Completion note (2026-11-05)

Parity check against Devin (`structured_output_schema` on create session, `structured_output` on the session): REST, GraphQL and MCP agree on every field and code below; no unexplained drift.

| Surface x field / error | REST | GraphQL | MCP | Dashboard | Devin |
| --- | --- | --- | --- | --- | --- |
| Schema input | `outputSchema` (JSON object) on create and on `/steer` | `outputSchema` (JSON text) on `createAgentSession`, `steerAgentSession` | `outputSchema` on `create_agent_session`, `send_agent_session_message` (+ aliases) | not sent (free-form composer) | `structured_output_schema` at session creation only |
| `outputRequired` | same name, default true with a schema | same | same | n/a | none (the agent may never fill it) |
| Bad schema | `400 AGENT_SESSION_OUTPUT_SCHEMA_INVALID` | `extensions.code` same | tool error text same | n/a | 400 with a free-text message |
| Final result | `outcome.result` | `outcome.result` (JSON text) | `outcome.result` | not rendered | `structured_output` (evolving value) |
| Partial result | transcript turn `result` + `resultFinal` | same | same | not rendered | same field as the final value |
| Missing result | `failureReasonCode: STRUCTURED_OUTPUT_MISSING`, state `failed`, PR kept | same | same | shows the failed state/reason | no equivalent (session just finishes) |
| Repo-less | supported | supported | supported | n/a | supported |

Divergences, all supersets or deliberate: per-turn schema (Devin: creation only); `outputRequired` + a bounded reminder + a named failure (Devin has none); `outcome.result` is final-only while Devin's `structured_output` mixes partial and final. Dashboard: no client-side re-derivation exists (it reads no result), and its generated GraphQL types are untouched. Gap filed as inbox note `w21/003` (render `outcome.result` and the partial value on `/agents`; optionally expose the in-flight partial next to `outcome.result`). No ADR018 divergence needs recording: Devin is the reference product, not Render.
