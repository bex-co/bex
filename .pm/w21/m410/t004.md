## Objective

Remove `http://localhost:5173` from the production Kratos configuration while keeping it for local development.

## Context

- It sits in production `allowed_return_urls` (the Kratos config under `deploy/gitops/`); a return URL on localhost sends a signed-in browser to whatever listens on the user's own port 5173.

## Steps

1. Find the production and local values (base against the prod overlay) and the test that pins them (`scripts/gitops-validate.sh`).
2. Move localhost to the local overlay only; add a check that fails if production lists it.

## Files

- deploy/gitops/ (Kratos values, base and overlays)
- scripts/gitops-validate.sh

## Acceptance criteria

- [ ] Production lists no localhost return URL, local development still works, and the validation script fails if it returns.

## Out of scope

- Other Kratos settings.
