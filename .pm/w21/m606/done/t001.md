## Objective

On CloudNativePG v1.30.1 (production's pinned operator), `reconcileExtensions` no longer drops a managed extension that has no parameter with its prefix but whose library the cluster lists in `spec.postgresql.shared_preload_libraries`. Creation stays as upstream has it. The patch is one reviewed file under `deploy/cnpg-operator/patches/` with upstream-style unit tests.

## Context

- Upstream v1.30.1 code:
  - `internal/management/controller/instance_controller.go` `reconcileDatabases` (:711-757) and `reconcileExtensions` (:785-846).
  - `pkg/postgres/configuration.go` `ManagedExtension` (:413-438) and `ManagedExtensions` (:459-483).
  - `api/v1/cluster_types.go:1615` `AdditionalLibraries` (`shared_preload_libraries`).
- Tests in the same style: `internal/management/controller/instance_controller_sql_test.go` (Ginkgo with `go-sqlmock`, `QueryMatcherEqual`).
- bex preloads `pgaudit` through `shared_preload_libraries` (`lego/operator/internal/controller/database_operand.go` `pgExtensionPreloadLibraries`) and sets no `pgaudit.*` parameter (ADR092 D1, D2). It sets `pg_stat_statements.track`, so `pg_stat_statements` is "used" and its creation must not change.
- Why upstream drops at all: an installed `pgaudit` whose library is not preloaded fails every DDL statement. Its event-trigger functions load `pgaudit.so`, whose `_PG_init` errors outside `shared_preload_libraries`. A library the cluster preloads itself does not have that problem.

## Steps

1. Record the upstream base in `deploy/cnpg-operator/UPSTREAM`: tag `v1.30.1` and its commit SHA. Clone it into a scratch directory, never into the repository.
2. In `reconcileExtensions`, drop only when `!extensionIsUsed && extensionIsInstalled && !preloadedByCluster`. `preloadedByCluster` means one of the extension's `SharedPreloadLibraries` is in `cluster.Spec.PostgresConfiguration.AdditionalLibraries`. Leave the create branch alone.
3. Make the status that triggers the check include `preloadedByCluster`, so removing the library from the cluster's own list runs `reconcileExtensions` again without waiting for a manager start. Without this, an extension whose preload was removed would stay installed while DDL fails.
4. Add Ginkgo/sqlmock cases:
   - not used, installed, preloaded by the cluster: no `DROP`
   - not used, installed, not preloaded: `DROP`, as upstream does
   - used, not installed: `CREATE`, as upstream does, whatever the preload
   - a change to the preload list sets the status-changed flag
5. Run the package's tests (`go test ./internal/management/controller/...` and `./pkg/postgres/...`) on the patched tree, and `go vet`. Export the change as `deploy/cnpg-operator/patches/0001-instance-keep-extensions-the-cluster-preloads.patch` (`git format-patch`, no sign-off line: the DCO is the user's, t005).

## Result (2026-11-23)

- `deploy/cnpg-operator/UPSTREAM`: `v1.30.1` is `2a35abb4628f209d149825ef3c38011e0701ff2f` (the tag is checked against it at every build), `BEX_REVISION=1`.
- `deploy/cnpg-operator/patches/0001-instance-keep-extensions-the-cluster-preloads.patch` (`git format-patch`, no sign-off): `reconcileExtensions` drops an unused, installed managed extension only when none of its `SharedPreloadLibraries` is in the cluster's `shared_preload_libraries` (`isPreloadedByCluster`). The status that triggers the check is now `{used, preloaded}` per extension (`getExtensionStatus`, compared with `maps.Equal`), so a change to the cluster's own preload list runs the check again. The create branch is unchanged. Three files: `instance_controller.go`, `manager.go` (the status map's type) and `instance_controller_sql_test.go`.
- Tests (Ginkgo + sqlmock, `QueryMatcherEqual`): not used + installed + preloaded → no `DROP`; not used + installed + not preloaded → `DROP EXTENSION pgaudit`; used + not installed → `SET LOCAL search_path` + `CREATE EXTENSION pgaudit` with and without the preload; dropping `pgaudit` from the preload list changes the status. The two existing create specs only gained the new `nil` argument; their expectations are unchanged.
- Verified on the patched tree: `go vet ./internal/management/controller/`, `go test ./internal/management/controller/... ./pkg/postgres/...` (CGO on and off) pass. Mutations: restoring the unpatched drop condition fails "does not drop an unused extension whose library the cluster preloads"; leaving `preloaded` out of the status fails "reports a status change when the cluster stops preloading the library".
