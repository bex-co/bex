## Objective

## Context

- The workflow publishes only an image that passed its gate (w6/109). It runs on push to the recipe paths.
- Evidence rules: no run output in git (AGENTS.md, `#NO-ARTIFACTS-IN-GIT`). Record digests, run ids and the per-extension verdict table in ADR092 § D3 result, not logs.

## Steps

1. Push t002 and t003; follow the run to the end.
2. For any failure that is not an extension verdict (build, registry, memory), fix it and rerun.
3. Record per major: the published digest, both architectures' verdicts, the admitted list, the anonymous memory peak.
