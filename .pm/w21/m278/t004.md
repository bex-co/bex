## Objective

Build `agentautomations.Service`: create, update, delete, pause, resume, take over, with template validation and authorization.

## Context

- Spec: ADR101 D4, D5, D7. Create needs `can_create`; only the creator edits; admins (`can_manage`) pause, resume, delete and take over.
- Template validation reuses `agentsessions` create validation (`validateCreate` in `internal/agentsessions/service.go`); export a shared entry point rather than copying it.
- A platform-metered model requires `maxSpendUSD`. Template fields `secretNames`, `skills` and `approvalMode` are accepted as each of w9/m174, w9/m175 and w9/m176 lands; none blocks this task.
- Write the audit log for create, update, pause, resume, take-over, delete and run-now with the actor.

## Steps

1. Add the service and its interfaces under `lego/backend/internal/agentautomations/`.
2. Export the create-validation entry point from `agentsessions` and call it on save.
3. Implement the pause reasons `repeated_failures`, `creator_lost_access`, `template_invalid`.
4. Tests against real Postgres and OpenFGA for authorization and for every refusal.

## Files

- lego/backend/internal/agentautomations/service.go
- lego/backend/internal/agentautomations/service_test.go
- lego/backend/internal/agentsessions/service.go (shared validation entry point)
- lego/backend/internal/audit/ (new event names)

## Acceptance criteria

- [ ] A non-creator cannot edit another member's automation; an admin can pause, resume, delete and take over.
- [ ] A template that fails session validation is refused at save time with the same error a manual create gives.
- [ ] A platform-metered template without `maxSpendUSD` is refused.

## Out of scope

- HTTP adapters and the scheduler.
