## Objective

Provision the fixed addresses and the CNI feature the policy needs.

## Context

- `infra/terraform/main.tf` already manages the edge load balancer (`hcloud_load_balancer.traefik`, `prevent_destroy`).
- Cilium's egress gateway needs the egress IP on the gateway node's interface and BPF masquerading.
- **Gate:** creating Floating IPs bills the user's Hetzner account monthly. Ask for the go-ahead before `terraform apply`; park this task with that gate if it has not been given.

## Steps

1. Add two `hcloud_floating_ip` (IPv4) in the tenant pool's location with `prevent_destroy`, outputs, and a label naming their role.
2. Turn on the egress gateway in the Cilium install found in t001, keeping every existing setting.
3. Configure the addresses on the chosen gateway nodes (the mechanism the ADR picked: a node label plus a small agent, or the failover controller of t004).
4. Extend `scripts/clusterapi-validate.sh` or `scripts/gitops-validate.sh` so the feature cannot be turned off silently.

## Files

- `infra/terraform/main.tf`
- the Cilium install's values (t001)
- `scripts/gitops-validate.sh` or `scripts/clusterapi-validate.sh`

## Acceptance criteria

- [ ] `terraform plan` shows two Floating IPv4s and nothing destroyed.
- [ ] Cilium reports the egress gateway enabled on the cluster.
- [ ] The validator fails if it is turned off.

## Out of scope

- IPv6 egress, unless the ADR decides otherwise.
