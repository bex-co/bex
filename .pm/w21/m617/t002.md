## Objective

Implement the rule ADR004 records.

## Context

- `lego/operator/internal/controller/deployment_projection.go` (`projectDeployment`, the `Recreate` branch for disk services).
- Free services are capped at one instance (ADR030 §6); disk-attached services roll with `Recreate`.

## Steps

1. Add the `topologySpreadConstraints` entry to the pod template for the services ADR004 names.
2. Make sure an operator upgrade does not change the template of any running Deployment that is not otherwise rolling.
3. Envtest: the constraint is present for a multi-instance service, absent for single, free and disk services, and the upgrade leaves an existing template unchanged.
