## Objective

Make a host the owner removed from a hibernated or suspended App stop being routed to it, and make a host claimed by two Apps resolve deterministically in favour of the spec.

## Context

- Finding R25-01 (Low). `lego/operator/internal/controller/app_controller.go:3488-3500` `hibernated()` sets only `Status.URL` (and only when hosts is non-empty); `Status.URLs` is written only by `setStatusURLs` (`:3423` Running, `:4826/:4841` static site) and the nil-ing branches (`:3426`, `:3736`, `:5113`); a spec edit while parked reconciles the Ingress (`:2855`) but not status. `lego/operator/cmd/activator/main.go:761-782` `appHosts` indexes `Spec.Host`, `Spec.Hosts`, `Status.URL`, `Status.URLs`; `refreshOnce` (`:829-831`) is last-listed-wins in informer-cache (map) order. A later claimant's non-HTML requests can be woken, held and proxied (Host, Cookie, Authorization, body) to the former holder's app until its first Running pass.
- The claimed bypass of per-App Ingress middlewares for a dropped custom host is REJECTED: a host with no Ingress gets Traefik's 404 (`config/activator/platform-host-fallback-ingress.yaml:30-31` matches `*.onbex.co` only).
- Other readers of `Status.URL(s)` (backend `service.go:1124`, logs `service.go:1143`, `domains.go:509`) only gain correct data from the refresh. Prototype from the validator: refresh in `hibernated()` plus spec-first claims in `refreshOnce` removed all stale hosts and all 200 misroutes; the activator package passed.

## Steps

1. Write the failing tests first: operator: a parked reconcile that drops a host leaves `Status.URLs` without it (use the existing lifecycle fixture; cases: hibernated with host dropped, suspended with host dropped, subdomain policy disabled); activator: a two-App `mapReader` test over 200 index rebuilds asserting the App whose spec claims the host always wins.
2. In `hibernated()` refresh status from `hosts`: `setStatusURLs` when hosts is non-empty, otherwise `URL = internalURL` for addressable types and `""` otherwise, `URLs = nil`.
3. In `refreshOnce` let spec-derived claims beat status-only ones and make duplicate resolution deterministic (stable order).
4. Run `make test` for the operator and `make lint`.
