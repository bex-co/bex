## Objective

Make the dashboard's link classifier see the same URL the browser will navigate to, so a raw-HTML link that resolves off-origin renders with the external affordance.

## Context

- Finding R25-09 (Low). `dashboard/src/common/lib/external-url.ts:21-39` `classifyHref` tests the scheme regex and `startsWith("//")` on the raw string after only replacing backslashes (`:28-30`); `dashboard/src/common/components/markdown-renderer.tsx:137` omits `target`, `rel` and the icon when it returns internal. WHATWG parsing strips leading and trailing C0 control or space and removes tab, LF and CR anywhere: `/\t/evil.example/x`, `  //evil.example/x`, `\t//evil.example/x`, `\u0001//evil.example/x`, `/\n/evil.example/x` all resolve to `https://evil.example/x`. rehype-raw + rehype-sanitize keep these colon-less values; markdown link syntax is not affected (micromark percent-encodes the destination).
- The markdown is agent text, reasoning and steering turns (`dashboard/src/features/agent-sessions/components/session-conversation-impl.tsx:957,1076,1117`; PR feedback is quoted with `> ` per line, which still renders raw HTML). No cross-tenant path.

## Steps

1. Write the failing tests first: in `dashboard/src/common/lib/__tests__/external-url.test.ts` assert `classifyHref` marks the five inputs above external; in `dashboard/src/common/components/__tests__/markdown-renderer.test.tsx` (or its existing test file) a raw `<a href="&#9;//evil.example/x">` renders `target="_blank"` with `rel="noopener noreferrer"` and the icon.
2. In `classifyHref` strip `/^[\u0000-\u0020]+|[\u0000-\u0020]+$/g` and `/[\t\n\r]/g` from `href` before classifying and return the cleaned value as `safeHref`.
3. Check that relative, anchor, `mailto:` and `https:` links are unchanged (existing tests); run `cd dashboard && yarn lint && yarn test`.
