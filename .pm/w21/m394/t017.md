## Objective

Land three one-to-five-line fixes with regression tests: an unbounded read in the pg SNI proxy, a server error on a malformed `lang` query, and per-source connection counting that a single IPv6 /64 can sidestep.

## Context

- R25-13 (hardening). `lego/operator/cmd/pg-sni-proxy/main.go:500` `io.ReadFull(back, resp[:])` has no deadline after the client deadline was cleared (`:471`); a backend that accepts TCP but never answers pins the global, source and route slots even after the client leaves (20 slots still pinned 22.5 s later). Only an infrastructure hang triggers it (a tenant cannot freeze the postmaster); kv has no equivalent window (`kv-sni-proxy/main.go:329-335`). Fix: `back.SetReadDeadline(time.Now().Add(dialTimeout))` before the read; the validator's prototype passed its test.
- R25-15 (informational bug). `dashboard/src/common/lib/search-params/server.ts:6` calls `decodeURIComponent` on a value `URLSearchParams.get` already decoded, so `?lang=%25`, `?lang=%` and `?locale=%25zz` throw `URIError` and the built server answers 500 on any route (not cached; no other effect). Fix: drop the redundant decode.
- R25-12 mitigation 1 (the residual itself is ADR066's and is recorded by t005). `lego/operator/internal/sniproxy/limiter.go:106` keys the per-source cap on the exact `addr.Unmap()`, so 1024 addresses of one IPv6 /64 all pass the per-source cap of 128. Fix: key IPv6 sources on their /64 in `AcquireSource` (about 5 lines).

## Steps

1. Write the failing tests first: pg-sni-proxy: a backend that accepts and never answers the SSLRequest releases its slots within the dial timeout after the client disconnects (port the validator's M1/M2 pair into `cmd/pg-sni-proxy/main_test.go`); dashboard: mock `getRequest` with `?lang=%25` and assert `getSearchParamOnServer("lang")` returns `"%"` instead of throwing; limiter: `TestLimiterPerSourceKeysIPv6OnSlash64` (1024 addresses of one /64 admit 128, today 1024).
2. Apply the three fixes.
3. Run `make test` and `make lint` for the operator and `cd dashboard && yarn lint && yarn test`.
