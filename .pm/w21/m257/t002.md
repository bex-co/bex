## Objective

Add a derived coarse `state` (`working|needs_input|succeeded|failed|canceled`) and `steerable: bool` to the session view, computed once in `agentsessions.toView` so all three adapters get it (ADR094 D7). This removes the Devin-style ambiguous 'running/finished'.

## Context

- Mapping: phases `creating|running|resuming|redispatching|canceling` → `working`; `completed` → `succeeded`; `failed` → `failed`; `canceled` → `canceled`; `needs_input` is never emitted until the w11/m7 t003 decision-request contract ships.
- `lego/backend/internal/agentsessions/models.go:133` `View`; GraphQL fields in `graphql.go`.

## Steps

1. Define the state enum and phase→state mapping beside `View`.
2. Compute `state`/`steerable` in `toView`; expose on REST JSON, GraphQL type, MCP outputs.
3. Update the golden test.
