## Objective

Give the package a Wasabi client for presigned URLs, head, delete, list and prefix purge, a fake S3 the tests share, and the wiring that turns the store off when the credential is absent.

## Context

- `lego/backend/internal/s3client/s3client.go:38` builds the path-style client Wasabi needs; `internal/postgres/export_signer.go` is the presign precedent.
- The attachments precedent: `internal/agentsessions/attachstore.go` (config `S3AttachmentConfig` at `:48`), `cmd/api/config.go:690-701` reads the variables, and `cmd/api/main.go` leaves the store nil when they are unset.
- `docs/ADR112-object-storage.md` D9: the only variables are credentials. This task reads `BEX_OBJECT_STORAGE_ACCESS_KEY` and `BEX_OBJECT_STORAGE_SECRET_KEY` (bex-api); endpoint, bucket and region come from t002's constants. objectgw's read pair is w21/m417.
- D2: a presigned PUT signs `Content-Length`; a presigned GET pins `response-content-disposition: attachment`, as `docs/ADR095-agent-attachments.md` D7 does.

## Steps

1. Add `client.go`: per-region client built from the constants; `PresignPut(key, size)` signing `Content-Length`, `PresignGet(key)`, `Head`, `Delete`, `List(prefix, startAfter, limit)` and `DeletePrefix` (batched).
2. Add `config.go`: a config struct whose endpoint tests can inject; both credentials empty gives a nil store; exactly one set is a startup error that names the missing variable.
3. Add `fakes3_test.go`, an `httptest` fake of the S3 subset used (PUT, GET, HEAD, DELETE, ListObjectsV2 with continuation), shared by later tasks.
4. Read the two variables in `cmd/api/config.go` and construct the service in `cmd/api/main.go`; leave it nil when unset.
