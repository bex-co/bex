## Objective

Serve Render's four `/v1/objects/{ownerId}/{region}` routes as the pinned CLI and SDKs call them, with presigned URLs so the bytes never pass bex-api.

## Context

- `lego/backend/internal/api/server.go:1749-1797`: `notOfferedRefusals` lists the four patterns, `mountNotOffered` answers them, `objectStorageNotOffered` is the message. Remove the four entries and the constant, and update the comment above the map.
- `docs/ADR112-object-storage.md` D2: list reads Wasabi under `<tea-id>/<obk-id of render-region>/` (limit default 20, up to 1000, cursor is the base64 of the last key fed to `StartAfter`); put mints a presigned PUT signing `Content-Length = sizeBytes` and returns `{url, expiresAt, maxSizeBytes}` with `maxSizeBytes = sizeBytes` (413 above the 5 GiB cap); get and delete `HEAD` first and answer 404 for a missing key; the GET URL pins `response-content-disposition: attachment`.
- Presigned lifetime 15 minutes (the architecture diagram's bound).
- Authorize through `Base.AuthorizeWorkspace` (`lego/backend/internal/core/base.go:1231`) on `ownerId`; t007 sets the relations.
- How the pinned-spec request gate treats a route: `internal/api/render_openapi.go:796` and the `render_openapi_*_test.go` files. The four routes must not stay in any not-offered set.

## Steps

1. Add `internal/api/objects_render.go` with the four handlers as a thin adapter over `objectstorage.Service`; mount them in `server.go`.
2. With no service configured the handlers answer today's named 404 so nothing changes before the credential exists.
3. Region path value: `oregon` or `frankfurt`, anything else is 400 `REGION_NOT_OFFERED`.
4. Resolve the workspace's system bucket with `EnsureSystemBucket` on first use.
5. Write handler tests against the fake S3: each route, each error, and the unconfigured 404.
