## Objective

Extend the hydration test helper so one test renders a node to a string under a server environment and hydrates the same markup under a different browser environment, and reports the recoverable errors React raised.

## Context

- `dashboard/src/test/hydration.ts` has `hydrateAcrossBoundary(node, { serverNow, clientNow })`: it mocks `Date.now`, calls `renderToString`, then `hydrateRoot`, and returns `{ html, recovered }`. It varies only the clock.
- The recurring mismatches vary the environment: time zone (w21/013, w6/049, w6/m107), language and its storage (w21/054), and the clock (w4/m152). Node applies a change to `process.env.TZ` at runtime, so the harness can set it between the two passes.
- `src/test/setup.ts` installs a no-op localStorage (use `memoryStorage()` for a real one) and mocks `useCapabilities` and `useRouterNavAvailable`.

## Steps

1. Add `hydrateAcrossEnvironments(node, { server, client })` beside `hydrateAcrossBoundary`, where each side is `{ timeZone, language, now, cookie, storage }`. Set and restore `process.env.TZ`, `navigator.language` (`languages`), `document.cookie`, `localStorage` and `Date.now` around each pass, restoring in `onTestFinished`.
2. Keep `hydrateAcrossBoundary` working (it can call the new function).
3. Self-tests in `src/test/__tests__/hydration.test.tsx` (or the existing hydration test file): a component that prints `new Date(...).toLocaleString()` mismatches across zones; one that prints a month label for a boundary instant mismatches; a hydration-safe version of each does not; and the language case from w21/054 is expressible (cookie missing, storage `zh`).
4. Reproduce the w6/049 and w21/013 mismatches against the pre-fix code shape in a self-test (a small component that mirrors the old bug), so the harness is proven to catch them.

## Files

- dashboard/src/test/hydration.ts
- dashboard/src/test/**tests**/ (the harness self-tests)

## Acceptance criteria

- [ ] The harness reports a recoverable error for a time-zone-dependent render and none for a hydration-safe one.
- [ ] Time zone, language, clock, cookie and storage are restored after each test (a following test in the same file sees the original values).
- [ ] The existing tests that use `hydrateAcrossBoundary` still pass.

## Out of scope

- Routing, Apollo and real server-rendered data (t003), and a real browser.
