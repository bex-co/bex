## Objective

Render each route that already has a test fixture through the cross-environment probe and assert zero recoverable hydration errors, so a mismatch anywhere on a page fails a test.

## Context

- `dashboard/src/routes/__tests__/` holds about 44 test files with mocked Apollo data, covering services, databases, billing, webhooks, env groups, blueprints, agents and settings.
- The pairs to run: (UTC, English, server clock) to (Asia/Shanghai, Chinese, clock one minute later), and the w21/054 case: the `i18nextLng` cookie missing while localStorage says `zh`.
- A jsdom probe of 054's inferred mechanism (`src/i18n/__tests__/hydration-language-sync.test.tsx`) hydrates cleanly, so a clean result for 054 is possible; record it either way.

## Steps

1. Add a shared helper that, given a route test's fixture setup, renders the route's component to a string in the server environment and hydrates it in the client environment (reuse the route tests' providers and mocks).
2. Add a sweep test (`src/routes/__tests__/route-hydration.test.tsx`) that iterates the fixtures and asserts `recovered` is empty for each pair; a failing route names itself in the test title.
3. List every route that fails; do not fix them here (t004).
