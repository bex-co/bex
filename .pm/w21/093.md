# 093 — Three more paths still record a closure's name as the audit verb

Why: w21/087 named the verb of every REST route, but the route sweep found one GraphQL field and production's audit log holds two background paths whose verbs are still a closure's name (`...func1`), which tells a reader nothing.

- **Source:** w21/087, 2026-11-16. Production `audit_events` (read-only query, rows since 2026-08-18) and `TestEveryGraphQLFieldRecordsANamedVerb`.
- **Cause:** `core.Base` derives a verb from the calling stack frame, and walks past an unexported method but not past a closure or a plain function. Each path below reaches an authorizing helper through one. 087 added `AuthorizeAs`, `AuthorizeTargetAs` and `AuthorizeWorkspaceAs` for exactly this.

| Verb recorded today | Rows | Path | Verb it should record |
| --- | --- | --- | --- |
| `secrets.graphQLQuery.func1` (a refused `envVars` query) | 0 so far | `secrets/graphql.go` calls `listEnvVarsPage` from the field's closure | `secrets.ListEnvVarsPage` |
| `agentsessions.RunOnce.func1` | 48 | the automation scheduler's goroutine reaches `AuthorizeWorkspace` through `fireAutomationRun` → `decideAutomationRun` (`agentsessions/automation_scheduler.go`) | one name for a scheduled run, such as `agentsessions.FireAgentAutomation` |
| `keyvalue.ClearProjectID.func1`, `keyvalue.ClearEnvironmentID.func1`, `postgres.ClearProjectID.func1`, `postgres.ClearEnvironmentID.func1` | 26 | `core.RetryPlacementClear` calls the fetch closure, which authorizes (`keyvalue/service.go`, `postgres/service.go`) | the method's own name, `keyvalue.ClearProjectID` and so on (the events vocabulary test already excuses those names) |

## Steps

1. Name each verb with `AuthorizeAs`-family entry points (a `...As` variant of `AuthorizeApp`, `AuthorizeDatabase` and `AuthorizeKeyValue` for the placement clears) and keep one name across surfaces.
2. Remove the `graphql envVars` entry from `closureVerbBacklog` in `lego/backend/internal/api/audit_verbs_test.go`; the test fails while the entry is stale.
3. Add a test that drives the scheduler's fire and a `ClearProjectID` and reads their verbs, since no HTTP route reaches them.
