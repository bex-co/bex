## Objective

Add `scripts/pm-board-validate.py` that fails when a change introduces a milestone number already used elsewhere in the tree, or an open task whose `id:` does not equal its path.

## Context

- Existing duplicates (16 since m250) and 58 old `id`-versus-path mismatches sit in `done/` or are historical re-homings; repairing them is churn, and the `wN/` prefix disambiguates. The gate is forward-looking.
- Detect new duplicates by milestone directories added in the change (`git diff --diff-filter=A --name-only <base>...HEAD -- .pm`) whose `mN` already exists under another workstream at the base.

## Steps

1. Write the script and a test (a fixture board with one added duplicate and one id/path mismatch).
2. Check open and blocked tasks only (outside `done/`) for `id:` equal to `wN/mN/tNNN` of the path.
3. Run it on the tree and fix any open-task mismatch it finds.

## Files

- scripts/pm-board-validate.py
- scripts/test_pm_board_validate.py

## Acceptance criteria

- [ ] The test shows a newly added duplicate `mN` and an open task with a wrong `id:` both fail, and a clean change passes.
- [ ] The script passes on the tree.

## Out of scope

- Repairing historical duplicates or `done/` ids.
