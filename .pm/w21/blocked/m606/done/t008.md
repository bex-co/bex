## Objective

Meaningful tests cover what this milestone shipped:

- the patch's four cases (t001)
- the restart step on a real CloudNativePG, which fails on stock 1.30.1 (t003)
- the validators refusing an upstream image while the patch is needed (t004)

Each test was shown to fail without its fix.

## Acceptance criteria

- [x] Each new or changed test is recorded with the mutation that made it fail.

## Result (2026-11-23)

Each new or changed test, with the mutation that made it fail:

- The patch's four cases (t001, Ginkgo + sqlmock in CloudNativePG's `instance_controller_sql_test.go`): restoring the unpatched drop condition fails "does not drop an unused extension whose library the cluster preloads"; leaving `preloaded` out of the status fails "reports a status change when the cluster stops preloading the library". The drop and create cases pin upstream's behaviour (they fail if the drop or the create branch is removed).
- The restart on a real CloudNativePG (t003): `TestOwnerPgauditAcrossRestartOnCNPG` (and the same step in `TestApplicationDatabaseExtensionsOnCNPG`) fails on the unpatched release, run 45293944381 on arm64 and amd64 (`pgaudit` gone after the restart), and passes on the build, run 45293927285.
- The validators refusing an upstream image while the patch is needed (t004): with `cnpg-operator.yaml` set back to the release's `tag: 1.30.1@sha256:923c267e…`, `TestQualificationCNPGImageIsProductionsPin` fails (`production pins ":1.30.1@sha256:923c…", the matrix qualifies "ghcr.io/bex-co/bex-operator:cnpg-1.30.1-bex.1-…"`), `gitops-validate.sh`'s CNPG block fails both checks (the Deployment image and `OPERATOR_IMAGE_NAME`), `dev-env.test.sh` fails its install checks, and `mock-cluster.test.sh` fails. Dropping the `--set image.*` arguments from `install_pinned_cnpg` or `install_cnpg` fails "it installs … with production's operator image" in `dev-env.test.sh` and "it runs production's operator image, not the chart's default" in `mock-cluster.test.sh`.
- Not covered by a test of its own: `scripts/cnpg-operator-qualify.sh`, which every `cnpg-operator-qualify.yml` run exercises end to end (both operators, both architectures).
