## Objective

Give cert-manager a second ACME issuer.

## Context

- `deploy/gitops/charts/cert-manager-issuers/clusterissuers.yaml`; directory `https://dv.acme-v02.api.pki.goog/directory`; cert-manager ACME `externalAccountBinding` (keyID + HMAC Secret).
- Secrets reach the cluster the way the other platform credentials do ([ADR019](../../../../docs/ADR019-infra-credentials.md)); never commit the value.
- **Gate:** the EAB key comes from the user's Google Cloud project. Park this task with that gate if it is not available.

## Steps

1. Add the `google-trust-services` ClusterIssuer with the HTTP-01 solver the Let's Encrypt one uses.
2. Wire the EAB Secret, add its name to `.env.example` if a new variable is needed, and guard the issuer in `scripts/gitops-validate.sh`.
