## Objective

Prove wrangler 4.162.0 works against production and settle the Wasabi and Traefik questions the design left open.

## Context

- `docs/ADR112-object-storage.md` t009 (Contract B part). Needs the credentials installed by w21/m415 t010.
- Evidence rule: conclusions and sha256 only, never raw logs (`.pm/AGENTS.md`).
- If a step needs something missing, park the task in `blocked/` naming exactly that.

## Steps

1. Set the three environment variables and run bucket create, list, info, delete and object put, get, delete with `--remote`.
2. Upload a 300 MiB file through Traefik and confirm it completes; try 300 MiB + 1.
3. Probe whether Wasabi accepts the streamed presigned PUT with a signed `Content-Length`; record the result and the fallback if not.
4. Put an object with `wrangler` into `render-oregon` and read it with `render ea objects` and the other way round.
5. Update ADR112's Not verified list.
