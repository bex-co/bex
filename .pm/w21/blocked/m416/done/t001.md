## Objective

Mount the surface stock wrangler calls and make every answer Cloudflare-shaped, so the later routes only supply results.

## Context

- `docs/ADR112-object-storage.md` D3: routes live under `/cloudflare/client/v4/accounts/{accountId}/r2`; the token is a bex API key sent as `Authorization: Bearer`; `accountId` is the workspace id (`tea-…`, valid under wrangler's `^[A-Za-z0-9_-]+$`).
- Envelope `{success, errors: [{code, message}], messages, result}`; every 2xx carries a body because wrangler fails on a bodiless one.
- Codes: 10002 (401), 10003 (403, also for a workspace the caller cannot see), 10005, 10006, 10007, 10008, 10009, 10020, 10033 (411), 10042 (403), 10058 (429), 10073 (409), 100100 (400).
- These routes are not in Render's OpenAPI, so ADR018's strict Render request gate does not cover them; bex validates its own input.

## Steps

1. Add `internal/api/cloudflare_r2.go`: mount, authentication through the existing bearer middleware, `accountId` to workspace authorization through `Base.AuthorizeWorkspace`, the envelope writer, and the code table.
2. Map the service's typed errors (t002 of m415 and the registry errors) to codes.
3. Answer `10042` for every route when the store is not configured; answer an unknown route under the prefix with a Cloudflare-shaped 404.
4. Test the envelope for success and for each code.

## Files

- lego/backend/internal/api/cloudflare_r2.go and tests
- lego/backend/internal/api/server.go

## Acceptance criteria

- [ ] Every answer is the envelope and every 2xx has a body.
- [ ] Each code in the table is produced by a test.
- [ ] An unconfigured store answers `10042`.

## Out of scope

- Bucket and object routes (t002 to t004).

## Result

`internal/api/cloudflare_r2.go` mounts the surface at `/cloudflare/client/v4/` on the root mux (`Server.CloudflareR2`, `cloudflareHandler`), behind the OAuth gate, the identity-keyed limiter and the scope-class gate, with neither the buffered body cap nor the REST request budget. Every answer is the envelope and every 2xx has a body. `cloudflareGate` rewrites the failures shared middleware writes before a route runs (the gate's 401 to `10002`, the limiter's 429 to `10058` with its Retry-After, a scope refusal to `10003`) into the envelope, keeping their headers and message; `cloudflareMux` answers an unknown route `7003` and a wrong method `7000`; an unconfigured store answers `10042` on every route; `cloudflareError` maps service and core errors to the table and answers anything unclassified as a logged `10001 internal error`. The account id is authorized through `Base.AuthorizeWorkspace`, and a workspace the caller cannot see answers `10003` with a generic message. Beyond the task text: codes outside ADR112's subset (`10001`, `10013`, `10043` from Cloudflare's published table; `7003`, `7000` Cloudflare's routing codes; `7400` bex's own) are recorded in ADR112 D3 and ADR018; object routes are exempt from gzip (`isCloudflareObjectPath` in `withGzip`) so the bytes keep their length. Tests: the envelope on every 2xx, every code of ADR112's table and bex's three extras produced by the situation that answers it, the unconfigured store on all routes, and the real handler chain for 401 and 429.
