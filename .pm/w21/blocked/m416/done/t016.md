## Objective

Add meaningful tests for the behavior this milestone shipped: real behavior and failure modes, never tautological or snapshot-everything tests.

## Context

- Changed code: lego/backend/internal/objectstorage/, lego/backend/internal/api/cloudflare_r2*.go, scripts/wrangler-r2-contract.sh
- Read each earlier task's acceptance criteria and check a test fails if the behavior is removed.

## Steps

1. List the behaviors and failure modes shipped by the milestone's tasks.
2. For each, find the test that fails when the behavior is removed (mutate it locally to confirm); add the missing ones.
3. Run the backend suite with the real Postgres the repo's CI uses.

## Files

- lego/backend/internal/objectstorage/, lego/backend/internal/api/cloudflare_r2*.go, scripts/wrangler-r2-contract.sh

## Acceptance criteria

- [ ] Every behavior and failure mode in the milestone has a test that fails without it.
- [ ] No test asserts only that a constant equals itself.

## Out of scope

- Raising coverage numbers with trivial tests.

## Result

Mutation-checked every behavior the milestone shipped, on both sides: 35 mutants of the Cloudflare adapter, the streaming service and client, the validators and the routing (a mutant is one line removed or inverted, run against the suites that should catch it) and 28 mutants of the sweep, lifecycle, purge and meters by the sub-agent (`go test -overlay`, so no shared file changed), each killed by a test except three equivalent ones: the adapter's early "store not configured" check (every handler's service call answers `10042` anyway), the seconds comparison in lifecycle expiry (once `Validate` caps `maxAge`, the `Duration` form cannot overflow) and an earlier duplicate `ValidateKey` that `ObjectKey` repeats. The mutation runs found gaps and real defects, all closed: a connection failure to Wasabi was reported as a short body (`10013`, 400) because the counter did not tell an early end of the caller's body from a failure before the body was read; the error of a failed put quoted the presigned URL, a 15-minute signature, into the log; closing an object twice metered its egress twice; an object stored with no `Content-Disposition` was not served as a download; the storage-class header on a put was untested; a stalled Wasabi holding a stream slot was untestable (the deadline is now a field, shortened by a test helper); a HEAD ran a full GET; and a bucket listing loaded every bucket's rules. Added tests: `TestPutStreamErrorsNeverCarryTheSignedURL`, `TestClosingAnObjectTwiceMetersItsBytesOnce`, `TestAStalledWasabiDoesNotHoldAStreamSlot`, `TestCloudflareHeadAsksWasabiForHeadersOnly`, `TestCloudflareTransferIsMeteredExactly`, `TestObjectBucketSummariesLeaveTheRulesOut`, `TestSetRulesValidateStoreAndMapAMissingBucket`, `TestValidateLifecycleRefusesWhatTheSweepWouldNotRun` and the `maxAge` bound cases. The suites for the touched packages pass with `-race`, `make lint`'s golangci-lint and `deadcode -test` are clean, and the full real-Postgres, OpenFGA and OpenBao backend suite runs in the ship gate (`scripts/ship-gates.sh`).
