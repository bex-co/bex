## Objective

Serve `wrangler r2 object get|delete --remote`.

## Context

- `docs/ADR112-object-storage.md` D3: a get `HEAD`s first (`10007` when missing) then streams the object back with its stored headers; deadlines extended as for put.
- Wrangler's own behavior for a missing key on delete is read from its source (`packages/wrangler/src/r2`); follow Cloudflare's answer and record the choice in the contract test.

## Steps

1. Add the get and delete handlers.
2. Return `Content-Type`, `Cache-Control`, `Content-Disposition`, `Content-Encoding`, `Content-Language`, `Expires`, `ETag` and `Content-Length`.
3. Test round trips, a missing key, a bucket that is not the caller's, and a key the validator rejects.

## Files

- lego/backend/internal/api/cloudflare_r2_objects.go and tests

## Acceptance criteria

- [ ] A put then get returns identical bytes and the stored headers.
- [ ] A missing key is `10007`; a key with `..` is `10020`.

## Out of scope

- Range reads on Contract B.

## Result

A get opens the object once with `GetObject` (headers and body together, `NoSuchKey` for a missing key) instead of a HEAD first: the same answer with one Wasabi round trip fewer and no window in which the headers and the bytes belong to different versions. It returns the stored `Content-Type`, `Cache-Control`, `Content-Disposition`, `Content-Encoding`, `Content-Language`, `Expires`, `ETag`, `Last-Modified` and `Content-Length` (a stored gzip is not decompressed on either hop), and adds `X-Content-Type-Options: nosniff`, `Content-Security-Policy: default-src 'none'; sandbox` and a default `Content-Disposition: attachment`, so a signed-in browser that followed a link never renders a tenant's HTML on bex's origin (ADR095 D7's rule). A HEAD, which the same pattern matches, is a HEAD to Wasabi (`StatObject`): the stored headers and length, no body, no stream slot, no egress. A delete of a missing key succeeds, as S3 and Cloudflare answer (Render's route answers 404); wrangler's own source treats a 404 there as success, and the contract test pins `object delete missing`. A key with a backslash or a control character is `10020`; a `..` segment never reaches the handler because ServeMux redirects the cleaned path. Egress is metered from the bytes actually read. All recorded in ADR112 D3 "As built".
