## Objective

Create the pure core of the package: everything that decides what a bucket name, a key, a region and a cap are, with no I/O and no environment variable.

## Context

- `docs/ADR112-object-storage.md` D1 (regions, names), D7 (keys), D8 (caps), D9 (constants, not environment variables).
- Regions: `oregon` is Wasabi `us-west-1`, `frankfurt` is `eu-central-2`; the Cloudflare hints `wnam` and the default map to `oregon`, `weur` and the jurisdiction `eu` to `frankfurt`; every other hint or Render region is a typed "region not offered" error (HTTP 400, code `REGION_NOT_OFFERED`).
- Endpoint `https://s3.<wasabi-region>.wasabisys.com`, bucket `bex-objects-<region>`, object key `<tea-id>/<obk-id>/<key>`.
- Bucket name rule `^[a-z0-9][a-z0-9-]{1,61}[a-z0-9]$` plus the reserved `render-` prefix.
- Key rule: reject an empty key, one over 1024 bytes, one starting with `/`, one with a `.` or `..` segment, one with a backslash or a control character. Cases to cover: `%2e%2e`, doubled slashes, Unicode look-alikes.
- Caps (constants): 100 GB and 1,000,000 objects per workspace per region, 1,000 buckets per workspace, 5 GiB per object on Contract A, 300 MiB on Contract B, 8 concurrent streams per workspace.

## Steps

1. Create `lego/backend/internal/objectstorage/` with `regions.go`, `limits.go`, `names.go` and `keys.go`.
2. `keys.go`: build `<tea-id>/<obk-id>/<key>` from validated parts and parse the second path segment back to an `obk-` id.
3. Write table-driven tests, including every adversarial key above and a name that starts with `render-`.
4. Add a test that fails if the package reads an environment variable (`os.Getenv`, `os.LookupEnv`).

## Acceptance criteria

- [ ] The package reads no environment variable.

## Out of scope

## Result

Package `internal/objectstorage` with regions.go (Render path and Cloudflare hint parsing, endpoint and bucket names), limits.go (every cap, the list page and presign lifetime as constants), names.go, keys.go (`ValidateKey`, `ObjectKey`, `ParseObjectKey` that also checks both ids' kinds) and tests. Beyond the task text: the CORS, lifecycle, list and presign constants that later tasks need live here too, and the environment-variable guard is an AST check (mutation-checked: a file calling os.Getenv fails it). Doubled slashes and look-alikes of .. are accepted keys by design (S3 keys are opaque; http.ServeMux cleans paths); a doubled slash before a .. segment is refused.
