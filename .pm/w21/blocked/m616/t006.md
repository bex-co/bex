## Objective

Prove the definition of done on production.

## Context

- Use a disposable QA service in a first-party workspace (`scripts/lib/first_party_workspaces.txt`), marked `(disposable)` in the record.
- The source address must be read from a bex-owned endpoint, never a third-party IP-echo service.

## Steps

1. Deploy a disposable service with two instances on two nodes; from each, read the source address at a bex-owned endpoint.
2. Scale the tenant pool so a new node joins, place an instance there, read again.
3. Run a cron job once and read its source address.
4. Fail the gateway over (cordon and delete its node, or the ADR's drill) and record the recovery time and the reset.
5. Compare with `outboundIps` on REST, GraphQL, MCP and the dashboard; delete the disposable resources.
