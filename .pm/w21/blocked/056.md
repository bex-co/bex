# Refuse a repo-backed static site's publish directory that leaves the checkout when it is saved (create and update on REST, GraphQL, MCP and Blueprint), a stricter-than-Render variant of w21/050

Why: [w21/050](done/050.md) shipped the parity-sufficient part (the failure reads as a plain build failure and the dashboard marks the path before Save) because Render accepts any publish directory and fails the build, so a 400 at save is stricter than Render and needs the user's sign-off in ADR018 before it ships.

**Severity:** minor. **Estimate:** 30m once decided. **Kind:** follow-up variant split from w21/050 (a). **Status:** inbox; needs a user decision.

## What 050 left as it was

- `validatePublishPath` (`lego/backend/internal/apps/service.go`) rejects only an empty value and `\r\n\x00` on update, and create calls neither it nor `checkPublishPath`, so `publishPath: "../../../x"` on a repo-backed static site answers 201 or 200 and fails the first deploy. The operator now closes that deploy `build_failed` with `the publish directory "../../../x" is outside the repository (…)` (`publish.Ensure`), and the Settings editor and the New Service form mark it before Save.

## The variant

- `checkPublishPath` (`apps/settings_check.go`) applies the operator's rule at save for a repo-backed static site: the joined `rootDir/publishPath` must stay inside the checkout. Create and update answer 400 on REST, GraphQL, MCP and Blueprint with a sentence naming the typed value. An image-backed static site keeps its absolute paths.
- Whether a `..` that stays inside the repository but leaves the Root Directory (`../static-site` under `examples/hello-node`, which publishes a sibling directory today) should also be refused is a further decision. Render's behavior for it is unverified.

## The decision

- Whether bex may answer 400 for a publish directory Render's API accepts. `AGENTS.md` lets a divergence stand only when [ADR018](../../docs/ADR018-render-parity.md) records it with the user's sign-off, so a "yes" is recorded there in the same change; a "no" closes this note.

## Blocked 2026-11-11 (worker, `/loopx w21`)

A "no" closes the note. The implementation is ready to describe: `checkPublishPath` in `lego/backend/internal/apps/settings_check.go` applies the operator's joined-path rule for a repo-backed static site, and the create path calls it too.
