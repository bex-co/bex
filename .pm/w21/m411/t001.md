## Objective

Make `ParseTrustedProxyCIDRs` refuse a prefix whose host bits are set (`10.10.0.7/24`), which `prefix.Masked()` silently turns into the whole `/24`, and record the behavior for a trusted peer that sends no header.

## Context

- `lego/types/proxyproto/proxyproto.go` `ParseTrustedProxyCIDRs` ends with `prefixes = append(prefixes, prefix.Masked())`: an operator who types the LB address with a `/24` mask trusts every host of that network to assert a client address (the PROXY trust that gates `IPAllowList`). Production is `10.10.0.7/32` in both daemonsets and `scripts/gitops-validate.sh` pins it, so refusing host bits breaks nothing deployed.
- `ReadProxySource` serves a trusted peer that sends no PROXY header as the peer's own address. That is deliberate (a header is trust-gated only when present; a connection straight to the proxy keeps working) and it forges nothing: record it as accepted with the existing test that pins it.

## Steps

1. Red-first test: `10.10.0.7/24` and `2001:db8::7/64` fail to parse with an error naming the masked form; `10.10.0.7/32`, `10.10.0.0/24` and the existing cases still parse.
2. Return the error from `ParseTrustedProxyCIDRs`; both proxies already exit on it.
3. State the rule where the variable is documented (`lego/operator/AGENTS.md`) and the headerless case as accepted.
