## Objective

Persist one immutable version per skill save, in the same transaction as the save.

## Context

- Spec: ADR099 (amended in t001). `agent_skill_versions(skill_id, version, content, message, created_by, created_at, short_id)`; the current content is version N and stays in `agent_skills`.
- Existing skills created before this milestone get a backfilled first version.
- Extends the `agent_skills` store from w9/m175 (`lego/backend/internal/store/agentskills.go`, migration 0204).

## Steps

1. Write the next free migration pair, including the backfill.
2. Write the version row inside the same transaction as create and update; message is `Add <path>` on create and `Update <path>` afterwards.
3. Apply the retention cap.
4. Real-Postgres tests: every save writes one version atomically; a failed save writes none.

## Acceptance criteria

- [x] Each save yields exactly one version; a rolled-back save yields none.
- [x] The backfill gives every existing skill a version 1.
