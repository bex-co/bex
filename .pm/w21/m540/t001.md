## Objective

`bex s3` builds an S3 client from the cached ephemeral key and talks to the endpoint with no other program involved.

## Context

- ADR112 D3 (The command: `bex s3`, a native client). The key mint, the 12-hour cache and its file lock, the endpoint resolution and the bucket and key routes already exist in `lego/cli/internal/s3` (`session.go`, `api.go`, `output.go`) and stay.
- Dependencies: `github.com/aws/aws-sdk-go-v2` with `service/s3` and the GA `feature/s3/manager` (Uploader and Downloader: multipart, concurrency, part size). Not `feature/s3/transfermanager`: it is a v0.x module without a compatibility guarantee; move to it only once it is GA (a later task, not this one). `lego/cli/go.mod` has no AWS SDK today (the backend does: `lego/backend/go.mod`).
- Build the `aws.Config` by hand (region, static credentials from the cached key, the endpoint as the base endpoint, `UsePathStyle`), never with `config.LoadDefaultConfig`: nothing may read a credential or configuration file or an `AWS_*` variable of the environment. The gateway takes `UNSIGNED-PAYLOAD`, an explicit SHA-256 and the `STREAMING-UNSIGNED-PAYLOAD-TRAILER` mode (ADR112 D3 payload modes), and its Go SDK v2 suite passed in w21/m498 t015; keep the SDK's default checksum unless a call fails, and record which.
- Map S3 error codes to bex's messages: an expired or revoked key (403 `InvalidAccessKeyId` or `ExpiredToken`) says the key is gone and that a very long transfer needs a persistent key (`bex s3 keys create`); `QuotaExceeded` prints the server's message (it names the cap); `SlowDown` and `ServiceUnavailable` are retried by the SDK; `NotImplemented` says bex does not serve that operation.

## Steps

1. Add the dependencies and record the binary-size change of `bex` (before and after, from `go build`) in this task's notes and in ADR112 § Not verified.
2. Replace the `deps` seam that launched another program with a client factory (`newClient(ctx, session) (*s3.Client, error)`), keep `session()` as it is.
3. Add the error mapping and the progress and output helpers every verb will use (`-o json` through `resolveFormat`, progress to stderr and only on a terminal).
