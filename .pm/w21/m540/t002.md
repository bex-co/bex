## Objective

A customer lists buckets and objects, makes and removes buckets, deletes objects and makes a presigned URL with `bex s3`.

## Context

- ADR112 D3 verbs. The listing is `ListObjectsV2` through the SDK paginator. The server lists the workspace's buckets in both regions, the `render-<region>` system buckets included; a name is resolved inside the key's own workspace (`NoSuchBucket` otherwise).
- `ls` with no argument lists the buckets; `ls s3://bucket[/prefix]` lists one level with the `/` delimiter, a `PRE name/` line per common prefix, then date, size and key per object; `--recursive` lists every key without a delimiter, `--human-readable` and `--summarize` as the flag names say.
- `mb s3://bucket [--region oregon|frankfurt]` (a name already owned answers 409 `BucketAlreadyOwnedByYou`, and the command fails with that message). `rb s3://bucket [--force]`: `--force` deletes the objects first; the server refuses a bucket with unfinished multipart uploads (`BucketNotEmpty`), and the message says the sweep aborts them after 7 days.
- `rm s3://bucket/key`, `rm --recursive s3://bucket/prefix` with `--include` and `--exclude` and `--dryrun`, deleting in batches of at most 1,000 with `DeleteObjects`. `presign s3://bucket/key [--expires-in 3600]`: the SDK's presign client; a URL dies with its ephemeral key, twelve hours at most, whatever `--expires-in` says, and the command prints that when the expiry would outlive the key.
- Output lines: `delete: s3://b/k`, `make_bucket: b`, `remove_bucket: b`; `-o json` prints the same results as data.

## Steps

1. Add the five commands and their flags to `s3.go`'s command tree; share a `parseS3URL` helper (bucket, key, prefix; reject a bare path with a message that shows the `s3://` form).
2. Table-driven tests against the t001 fake S3, including a listing of more than 1,000 keys and a delete of more than 1,000.
