## Objective

Run the user's `aws` against bex with the endpoint and an ephemeral key already set and the user's own AWS configuration kept out of it.

## Context

- ADR112 D3 (The command: `bex s3`). `lego/cli` imports no other module; the launcher already runs other tools (`lego/cli/internal/agent/ssh.go`, `lego/cli/internal/code/launch.go`, `lego/cli/internal/desktop/desktop.go`) and passes `ea objects` through to the pinned Render CLI.
- `bex s3 <args>` runs `aws s3 <args>`, `bex s3api <args>` runs `aws s3api <args>`, with `--endpoint-url https://objects.<base domain>` on the command line (the `AWS_ENDPOINT_URL_S3` variable needs a recent CLI and an older one would send the request to AWS), `AWS_ACCESS_KEY_ID` and `AWS_SECRET_ACCESS_KEY` of an ephemeral key minted through the REST route of m498/t003 for the signed-in person in the current workspace (twelve hours; cached in the CLI's state directory with mode 0600; replaced when under one hour remains), `AWS_REGION=oregon` (`--region` overrides), and `AWS_CONFIG_FILE` and `AWS_SHARED_CREDENTIALS_FILE` pointed at files bex owns (the config carries `s3 = addressing_style = path`). The child never sees `AWS_PROFILE` or `AWS_SESSION_TOKEN`.
- A command that outlives its key fails with a 403 the CLI does not retry; a long transfer needs a persistent key. A URL from `bex s3 presign` dies with its ephemeral key whatever `--expires-in` says; the docs say so.
- A missing `aws` prints how to install it and points at `bex s3 env`.

## Steps

1. Add the commands and the environment builder with the isolation rules.
2. Add the key mint and cache.
3. Test the environment the child sees (no profile, no token, the bex-owned config, the endpoint flag) with a fake `aws` that prints it.

## Files

- lego/cli/ (new internal package for the S3 launcher)
- lego/cli/main.go

## Acceptance criteria

- [ ] The fake `aws` sees exactly the documented environment and arguments; the user's `~/.aws` is untouched.
- [ ] An expired cached key is replaced; a missing `aws` gives the install hint.

## Out of scope
