## Objective

Ship the gateway like the static-server: same image, its own Deployment, and a documented way to turn it off.

## Context

- `lego/Dockerfile:44-59` builds each binary (the backend module's binaries are built elsewhere in the file; add objectgw the same way). Model the manifests on `lego/operator/config/staticserver/{deployment,service,pdb}.yaml` and `lego/operator/config/prod/kustomization.yaml`.
- `docs/ADR112-object-storage.md` D4: the kill switch is scaling objectgw to zero replicas in GitOps; a stopped host then gets Traefik's no-backend answer, expected 503 and unverified. D9: the read pair comes from `bex-system/bex-object-storage-read`.

## Steps

1. Add the build line and the objectgw manifests (Deployment, Service, PodDisruptionBudget, NetworkPolicy) with the Secret references.
2. Write `docs/runbooks/objectgw-kill-switch.md`: how to scale to zero, what a visitor sees, how to restore.
3. Measure the real answer for a `pub-` host with no replicas once routed (t006) and replace the expectation in ADR112.
