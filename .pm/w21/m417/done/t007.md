## Objective

Test the behaviors the design promises and the ones an attacker would try.

## Context

- `docs/ADR112-object-storage.md` D11: tests for private, unknown, `Range`, CORS and listing; D7 keys on every path.

## Steps

1. Write end-to-end tests with the fake S3 and the real handlers: a private bucket answers 404, an unknown host 404, a deleted bucket 404, `Range` 206, conditional 304, HEAD, the root and `?list-type=2` never list, CORS allowed, denied and preflight, `nosniff`, cache hit and miss, and `..`, `%2e%2e` and doubled-slash keys.
2. Add a test that disabling `dev-url` stops serving within the cache window.

## Files

- lego/backend/internal/objectgw/*_test.go
- lego/backend/internal/api/*_test.go

## Acceptance criteria

- [ ] Every behavior above has a test that fails without it.

## Out of scope

- Production checks (t008).

## Result

The tests the design promises, with the fake S3 and the real handlers, and bex-api's half over HTTP: private, deleted, unknown, malformed and look-alike hosts are 404 (and a well-formed guess costs one lookup); the root, `?list-type=2`, `..`, `%2e%2e`, `a/../b`, doubled and leading slashes, NUL, backslash and an over-long key never reach Wasabi and never list; another bucket's prefix is unreachable; `Range` (206, suffix, open-ended, past the end 416) and conditional requests on the cached and streamed paths; CORS allowed, denied, wildcard, pattern and preflight; `nosniff`; cache hit and miss and expiry; and `TestDisablingDevURLStopsServingWithinTheCacheWindow`, which drives the gateway against the real verbs over HTTP through enable, disable (still served inside the 30 s window, `404` after it) and delete. bex-api's verbs: bearer required (a prefix or an extension of the right token is refused; an unconfigured mount is 503), the lookup answers only for a public live bucket and identically otherwise, and a malformed egress report is refused whole while a good one reaches the shadow meter. `TestTheGatewayVerbsAreNotOnThePublicMux` pins that neither verb is reachable from the public listener. Run with `-race`.
