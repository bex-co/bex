## Result

Ran `/simplify` as three read-only reviewers (reuse, quality, efficiency) over the milestone's code and applied the findings that were worth it. **Real defects fixed:** a slow reader could hold a place for 30 minutes and 256 of them locked the gateway for everyone (a write deadline that follows the reader, and per-bucket and per-workspace open-response caps); a flood of guessed hosts could make real buckets answer 503 as their lookup entries expired (a separate limiter for renewals); the egress meter's final flush ran before the server had drained, losing the last bytes (the process flushes once after the drain); `SetPublic` refused to turn a bucket private when the hosting domain was gone (disabling never needs it); a 412 was counted as ok (its own result); a failed cache fill was silent (logged); a zero cap would have disabled a limiter (it panics at construction); the transport kept 64 idle connections for 256 requests and bex-api lookups 2 (sized); the egress sum had no index (migration 0275, tested). **Reuse and simplification:** `store.MonthStartUTC`, `core.DecodeLimitedJSON`, one `publichost.NormalizeHost`, one `APIClient` for both calls to bex-api, one `writePlain`, typed result and origin labels, one key validation, an exact-size body read, a pooled copy buffer, the verbs built directly instead of late-bound, a redundant header filter and a redundant dot check removed, and comments that narrated the code or named tasks removed. **Declined, with reasons:** hand-rolled `CachedResolver` over `core.TTLCache` (it needs the two-tier limiter and stale-entry tracking `TTLCache` does not offer); a shared `core.RequireBearer` (a new helper across three packages, beyond this milestone); `serve.UntilShutdown` for two servers (one call per server would lose the fatal-on-serve-error path); a negative cache for missing keys (the per-bucket request cap already bounds it and Wasabi's API calls are free); singleflight on cache fills (bounded by the 32 fill slots); a separate meter kind for cache hits (the gauge is documented as an upper bound). Behavior is unchanged apart from the fixes; lint, `deadcode -test` and the suites pass.
