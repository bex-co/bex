## Objective

Build the read-only gateway binary that serves public bucket objects straight from Wasabi.

## Context

- `docs/ADR112-object-storage.md` D4: GET and HEAD only; `Range` and conditional requests passed to Wasabi; no listing (the root answers 404); a read-only Wasabi identity (`BEX_OBJECT_STORAGE_READ_ACCESS_KEY` and `_SECRET_KEY`); host lookup cached 30 s, misses cached too; a private, deleted or unknown host answers 404.
- Precedent: the static-server (`lego/operator/cmd/staticserver/main.go`, `docs/ADR029-static-sites.md`, `docs/ADR103-security-review-static-rewrite-proxy.md`).
- Keys use the same validation as D7 (reject `..` and its encodings).

## Steps

1. Create `lego/backend/cmd/objectgw/main.go` and `internal/objectgw`: lookup client and cache, handler, Wasabi read with the read-only credential.
2. Return the stored `Content-Type` and `Cache-Control`; answer 405 for other methods; 404 for the root, a private, deleted or unknown host.
3. Test with the fake S3: hit, miss, `Range` 206, conditional 304, HEAD.

## Files

- lego/backend/cmd/objectgw/main.go
- lego/backend/internal/objectgw/ and tests

## Acceptance criteria

- [ ] A public object is served byte-identical, including a `Range` and a conditional request.
- [ ] Private, deleted, unknown, root and `..` keys answer 404; POST answers 405.
