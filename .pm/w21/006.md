# `outcome.cost.sandboxSeconds`: attribute sandbox compute to a session

Why: ADR094 D7 sketches `cost: {modelUSD, sandboxSeconds}`. m260 shipped `modelUSD` only, because there is no honest per-session sandbox figure: sandbox compute is metered per OpenSandbox sandbox in weighted milli-vCPU seconds (`sandbox_meter_states`, `usage_hourly` rows keyed by sandbox id) and every turn runs in a fresh sandbox whose id the session does not keep.

- Decide the unit first: metered weighted seconds (what is billed) or wall-clock seconds the sandbox was running; the ADR example says "seconds" but the bill is weighted.
- Needs a durable session-to-sandbox attribution (for example a `session_id` on `sandbox_meter_states`, set at dispatch) before the meter can be summed per session. Then add `sandboxSeconds` next to `modelUSD` in `agentsessions.Cost` on all three transports and amend ADR094 D7's "As built".
