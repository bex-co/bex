## Objective

Put the S3 surface on `objects.onbex.co` beside Contract B's route, so the production walk can run on the final route before Contract B goes.

## Context

- ADR112 D3 (Host and routing). Today `lego/operator/config/api/ingressroute-objects.yaml` (priority 10000) routes `Host(objects.<domain>) && PathPrefix(/cloudflare/client/v4/)` to bex-api; `scripts/gitops-validate.sh` pins that exact match (around `:3322`) and `routes:1`.
- Add a second IngressRoute for the rest of the host at a lower priority to the `bex-s3` Service; the old route stays until m500. The S3 surface refuses a bucket named `cloudflare` until then. The host is DNS-only, so there is no Cloudflare WAF; Traefik cleans request paths by default, so keys with `//` or dot segments are refused (ADR112 D7).
- Unauthenticated cost: shape check of the key id, a bounded negative cache, secrets read from OpenBao at most once per 15 minutes per replica, and failed authentications rate-limited per client address (an IPv6 address by its /64; 20 a minute, a constant), after which the address's failing requests are refused from the in-memory caches alone (`lego/backend/internal/core/clientip.go` returns the full IPv6 address today).

## Steps

1. Add the route and update `gitops-validate.sh` to pin both.
2. Implement the per-address failed-authentication limiter and its test.
3. Add the D7 refusals (doubled slash, `.` and `..`) on the S3 routes.
