## Objective

Serve the bucket calls and bucket configuration of the S3 API over the existing registry, CORS and lifecycle.

## Context

- ADR112 D1 (regions), D3 (Buckets, Bucket configuration, Errors), D4 and D5. `internal/objectstorage` already has the registry, `ValidateCORS` and `ValidateLifecycle` and the sweep that runs the rules.
- `CreateBucket` writes a row and calls no Wasabi; `LocationConstraint` takes `oregon`, `us-west-1`, `us-west-2` (Oregon) and `frankfurt`, `eu-central-1`, `eu-central-2` (Frankfurt), absent is Oregon, anything else 400 `InvalidLocationConstraint`; a name is unique per workspace (409 `BucketAlreadyOwnedByYou`); 1,000 buckets (`TooManyBuckets`); `ListBuckets` includes the `render-<region>` system buckets; `DeleteBucket` needs an empty bucket and no multipart uploads.
- Stored shape stays what the sweep runs (`lifecycle.go`, `cors.go`): `Days` is `maxAge` seconds (capped at 36,500 days = `MaxLifecycleAgeSeconds`), `Date`, `Status` is `enabled`, `Filter.Prefix`, `AbortIncompleteMultipartUpload`; CORS maps one to one; `ID`s are kept so a Get returns what a Put sent. `Transition`, `NoncurrentVersionExpiration` and tag and size filters answer 501. The bucket-policy calls answer 501.
- A preflight resolves its bucket only from the presigned query's `X-Amz-Credential` key id; an unknown or revoked id, a missing bucket and a refused origin all answer the same 403 with no CORS header; credentials are never allowed.
- Audit verbs: `CreateBucket`, `DeleteBucket`, `GetBucket`, `ListBuckets`, `Get/Set/DeleteBucketCORS`, `Get/Set/DeleteBucketLifecycle`.

## Steps

1. Write the handlers as a thin adapter of the core service.
2. Write the S3-to-stored-shape mapping for lifecycle and CORS with round-trip tests.
3. Write the preflight path.
4. Record the divergences (regions, 501s, the system buckets in `ListBuckets`) for ADR018 (done in m499).

## Files

- lego/backend/internal/objectstorage/
- lego/backend/internal/api/ or the `bex-s3` package

## Acceptance criteria

- [ ] Each call works through stock `aws s3api`; the policy calls answer 501.
- [ ] A lifecycle rule round-trips through `Put` and `Get` unchanged and a `Days` over the cap is refused.
- [ ] The preflight answers as specified for each of its four outcomes.

## Out of scope

- Public-bucket publishing (it is the publish route of t003).
