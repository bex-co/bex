## Objective

Accept the bodies stock clients send by default and verify their integrity before anything is committed to Wasabi.

## Context

- ADR112 D3 (Payload modes, Integrity is verified before the commit). `UNSIGNED-PAYLOAD`, an explicit SHA-256 and `STREAMING-UNSIGNED-PAYLOAD-TRAILER`; the two signed-chunk modes answer 501 (D10).
- The trailer path (botocore's `httpchecksum.py`, AWS's SDK data-integrity page, read 2026-11-19) sends `Transfer-Encoding: chunked` with no `Content-Length`, `x-amz-decoded-content-length`, `Content-Encoding: aws-chunked` and `x-amz-trailer`; the AWS CLI's default algorithm is CRC64NVME, the other SDKs' CRC32.
- Length is `Content-Length`, or `x-amz-decoded-content-length` for `aws-chunked`; 411 `MissingContentLength` is for neither. The `aws-chunked` token is removed from the stored `Content-Encoding`.
- Verify CRC32, CRC32C, CRC64NVME, SHA1, SHA256 trailers, `Content-MD5` and an explicit SHA-256; any other `x-amz-trailer` is 501. Go's `hash/crc64` has no NVMe polynomial, so carry an implementation with the published test vector.
- Withhold the body's last byte from the Wasabi request until the digest verifies; on a mismatch end the upstream request short of its signed `Content-Length`, which Wasabi refuses (ADR112 § Not verified, settled 2026-11-15), so nothing is stored. Answer 400 `BadDigest` (`XAmzContentSHA256Mismatch` for an explicit SHA-256). Echo `x-amz-checksum-*` on puts and parts.

## Steps

1. Write the `aws-chunked` decoder and the length and encoding rules.
2. Write the checksum verifiers (CRC64NVME included) and the held-back-last-byte stream wrapper.
3. Test against bodies built the way botocore and the Go SDK v2 build them, including a wrong trailer and an explicit-hash mismatch over an existing object.

## Acceptance criteria

- [ ] A body with no `Content-Length` and a valid trailer is stored; a wrong checksum stores nothing and leaves the previous object byte-identical.
- [ ] An unknown `x-amz-trailer` answers 501.

## Out of scope

- Signed-chunk payloads (ADR112 D10).
