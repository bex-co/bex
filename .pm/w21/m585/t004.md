## Objective

A table's owner repacks it as Render's guide describes.

## Context

- Render's guide: install the client matching the extension version, run `pg_repack --no-superuser-check --dbname=<EXTERNAL_DATABASE_URL> --table=<TABLE_NAME>`, never through the connection-pool URL; the table needs a primary key or a non-null unique index; free storage of twice the table ([postgresql-pg-repack](https://render.com/docs/postgresql-pg-repack)).
- The image carries pg_repack 1.5.3 on 16+ with the `repack` schema grants (w21/m584 t003). pg_repack's C functions require ownership of the table (`lib/repack.c:120`).

## Steps

1. Gate: as the owner, create a table with a primary key, update it to make dead tuples, run `pg_repack -k --table` with the image's client against the local instance, compare row counts and `pg_relation_size` before and after.
2. Production: same on a disposable 16+ database over its external URL with a 1.5.3 client.
3. Add a sentence to ADR009 (or ADR092) on the client version and the direct URL.
