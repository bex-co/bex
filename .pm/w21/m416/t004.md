## Objective

Serve `wrangler r2 object get|delete --remote`.

## Context

- `docs/ADR112-object-storage.md` D3: a get `HEAD`s first (`10007` when missing) then streams the object back with its stored headers; deadlines extended as for put.
- Wrangler's own behavior for a missing key on delete is read from its source (`packages/wrangler/src/r2`); follow Cloudflare's answer and record the choice in the contract test.

## Steps

1. Add the get and delete handlers.
2. Return `Content-Type`, `Cache-Control`, `Content-Disposition`, `Content-Encoding`, `Content-Language`, `Expires`, `ETag` and `Content-Length`.
3. Test round trips, a missing key, a bucket that is not the caller's, and a key the validator rejects.

## Files

- lego/backend/internal/api/cloudflare_r2_objects.go and tests

## Acceptance criteria

- [ ] A put then get returns identical bytes and the stored headers.
- [ ] A missing key is `10007`; a key with `..` is `10020`.
