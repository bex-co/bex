## Objective

Mount the surface stock wrangler calls and make every answer Cloudflare-shaped, so the later routes only supply results.

## Context

- `docs/ADR112-object-storage.md` D3: routes live under `/cloudflare/client/v4/accounts/{accountId}/r2`; the token is a bex API key sent as `Authorization: Bearer`; `accountId` is the workspace id (`tea-…`, valid under wrangler's `^[A-Za-z0-9_-]+$`).
- Envelope `{success, errors: [{code, message}], messages, result}`; every 2xx carries a body because wrangler fails on a bodiless one.
- Codes: 10002 (401), 10003 (403, also for a workspace the caller cannot see), 10005, 10006, 10007, 10008, 10009, 10020, 10033 (411), 10042 (403), 10058 (429), 10073 (409), 100100 (400).
- These routes are not in Render's OpenAPI, so ADR018's strict Render request gate does not cover them; bex validates its own input.

## Steps

1. Add `internal/api/cloudflare_r2.go`: mount, authentication through the existing bearer middleware, `accountId` to workspace authorization through `Base.AuthorizeWorkspace`, the envelope writer, and the code table.
2. Map the service's typed errors (t002 of m415 and the registry errors) to codes.
3. Answer `10042` for every route when the store is not configured; answer an unknown route under the prefix with a Cloudflare-shaped 404.
4. Test the envelope for success and for each code.

## Files

## Acceptance criteria

- [ ] Every answer is the envelope and every 2xx has a body.
- [ ] Each code in the table is produced by a test.
- [ ] An unconfigured store answers `10042`.

## Out of scope
