# 092 — The charges card's object storage resource row is English in every language

Why: w21/086 translated the object storage category and its three lines, but the row between them is named by bex-api and shows "Object storage" in English under a Chinese, German or Russian category header; the same words also appear twice in a row (category, then resource).

- **Source:** w21/086's production check, 2026-11-15: `bex-canary` with `?lang=zh` reads `对象存储 | $0.00 | Object storage | $0.00 | 出站带宽 …`.
- **Cause:** `lego/backend/internal/usage/service.go` (the block on `store.ResourceKindObjectStorage`) fills an empty `ServiceName` with the literal "Object storage", and `ResourceRow` in `dashboard/src/features/usage/components/charges-card.tsx` prints `resource.serviceName` as it comes. A workspace has one object storage resource whose id is the workspace id, so it has no name of its own.
