## Objective

Serve a sandbox's event timeline as Render's drawer reads it: lifecycle events, command and file-transfer executions, and snapshots, newest first, paged backwards.

## Context

- Render: `sandboxEvents(sandboxId, before, beforeId, limit) { hasMore events }`; each event has `id timestamp outcome label`, plus `lifecycleType trigger` (lifecycle), `summary executionId executionType operation fullCommand exitCode startedAt completedAt` (execution) or its snapshot (README § What Render does).
- bex: executions (`lego/backend/internal/sandbox/executions.go`, GraphQL `sandboxExecutions`), snapshots (`snapshots.go`), and whatever lifecycle record t001 found or settled.

## Steps

1. If t001 found lifecycle transitions are not stored, add the store (a migration with the next free number under `lego/backend/internal/store/migrations/`) and record each transition where it happens: create, running, suspend, resume, error, terminate, with its trigger.
2. Add GraphQL `sandboxEvents` with Render's arguments and a union or interface of the three kinds, merging the sources newest first with a stable `beforeId` tie-break.
3. Authorize as the other sandbox reads.
