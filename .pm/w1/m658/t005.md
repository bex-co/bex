## Objective

Open a sandbox from the list into Render's details drawer, addressable by URL with its tab.

## Context

- Render: README § What Render does (Sandbox details drawer, Events).
- bex: t002's fields, t003's `sandboxEvents`, `sandboxSnapshots` filtered to the source sandbox, `terminateSandbox`.

## Steps

1. The drawer: name and id with copy, status, the tabs Events, Snapshots, Logs (only if t001 kept it) and Details, and the menu with Terminate sandbox. The URL carries the sandbox id and tab; an unknown tab falls back to Events.
2. Events: newest first, "Loading earlier events" on demand, live while the sandbox runs, each kind's row with Render's fields and its links (View snapshot to the Snapshots page drawer).
3. Snapshots: the sandbox's snapshots, with Render's empty texts for a running and an ended sandbox.
4. Details: Render's fields as t002 serves them, the network policy and allowed domains, and Go to snapshot / Go to image.
5. When the open sandbox ends while the list shows only running ones, Render's "Your selected sandbox stopped. Switched to a running one."
6. Eight locales; a pending frame matching the ready drawer at 1440 and 390 px.
