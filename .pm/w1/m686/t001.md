## Objective

Answer Render's query: has this workspace ever created a service.

## Context

- Render's `owner` chunk: `query firstServiceCreationCompleted($ownerId: String!) { firstServiceCreationCompleted(ownerId: $ownerId) }`, a Boolean.
- Backend: GraphQL schema `lego/backend/internal/api/testdata/schema.graphql`; migrations `lego/backend/internal/store/migrations/` (latest 0352).

## Steps

1. Add a durable per-workspace column, set on the first successful service, Postgres or Key Value create from any surface (REST, GraphQL, MCP, Blueprint), and never cleared by deletes.
2. Backfill true for every workspace that has or had a resource or has any project.
3. Serve the query with Render's name and shape, readable by the workspace's members.

## Files

- `lego/backend/internal/store/migrations/` (new migration)
- `lego/backend/internal/workspaces/`
- the GraphQL schema and resolver

## Acceptance criteria

- [ ] A new workspace answers false, true after its first create from any surface, and stays true after the resource is deleted; existing workspaces answer true.
