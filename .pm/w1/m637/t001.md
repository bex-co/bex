## Objective

Fetch every Render per-language version page and turn each into normalized JSON: the current default and the dated creation-date table.

## Context

- Pages: `render.com/docs/{node,python,ruby,bun,uv,poetry}-version` and `/docs/elixir-erlang-versions`. Each serves a `.md` copy, and `/docs/llms.txt` lists exactly these seven.
- Table rows carry one start date each, plus `Before X` and `X and later`. The Erlang page has no history table, only a current default (28.0.2) in its header. Poetry's older rows are not versions (`1.1.x (various)`).
- `scripts/render-changelog-drift.sh` is the shape to follow (fetch, parse, fail closed).

## Steps

1. Take the page list from `llms.txt` (`*-version`, `*-versions`); an eighth page fails the run by name.
2. Fetch each `.md` copy and parse the default and the table; unknown markup fails the run.
3. Emit JSON keyed by page.

## Files

- `scripts/render-version-drift.sh` (or a helper under `scripts/lib/`)

## Acceptance criteria

- [ ] Against today's pages the JSON reproduces the tables read on 2026-11-25 (e.g. Bun 1.4.5 from 2026-11-20, Ruby 3.4.13 from 2026-11-19, uv 0.12.24 from 2026-10-12).
