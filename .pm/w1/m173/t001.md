## Objective

Show on dev-1, with the current operator, whether a free web App with no traffic reaches `Hibernated`, and name the code path that keeps it awake.

## Context

- `spec.idleTTLSeconds` overrides the 15m default (`app_controller.go:2321-2343`), so a 60s window makes the repro quick.
- `runningRequeue` (`app_controller.go:~2958`) stamps last-active and requeues; `recentlyActive` (`activity.go:169-190`) logs `reading service activity failed; keeping the service awake` or `advancing last-active failed; keeping the service awake`.
- `bash scripts/dev-env.sh 1 up` (pre-approved), shared kind/CAPD cluster; the dev operator must run with an activator configured.

## Steps

1. Bring up dev-1 and deploy a free web App (`examples/hello-go`) with `idleTTLSeconds: 60`.
2. Send no traffic; watch `status.phase`, the `app.bex.co/last-active` annotation and operator logs for 5 minutes.
3. Record which log line repeats, the resourceVersion seen by each stamp attempt, and whether any conflict error appears.
