## Objective

After moving a resource into a project from its row, the project page must open on the environment that holds it, so the success toast and the page agree.

## Context

- `environments-panel.tsx:100-104` prefers `environments[0]` over a non-empty Unassigned bucket.
- A row-level move joins the project with no environment, so the resource lands in Unassigned.
- `environments/locales/en.ts:324-326` tells users project-only membership cannot happen — that hint is part of the contradiction.

## Steps

1. Select the environment that actually contains the moved resource; fall back to Unassigned when it is non-empty.
2. Reconcile the create-form hint with the state the move produces (either the move assigns an environment, or the hint stops denying the state).
3. Re-check the Overview → Move to project flow for a service and for a datastore.

- `dashboard/src/features/environments/components/environments-panel.tsx`
