## Objective

Implement the client ADR106 D2 specifies: `POST /v1/agent-sessions/{id}/attach-ticket` (read action), then `GET <streamUrl>` with `X-Bex-Agent-Ticket` and `Accept: text/event-stream`; parse the AI SDK v1 UI-message stream (`data:` JSON parts, `[DONE]`), ignore SSE comment heartbeats; on a drop re-mint (90 s single-use tickets) and reconnect, skipping parts already emitted keyed by `(turn, partIndex)`; on 503 or a missing stream URL fall back to `/transcript` polling, and retry `409 AGENT_SESSION_NOT_ATTACHABLE` while the first sandbox provisions.

## Context

- Design and full CLI spec: `docs/ADR106-cli-cloud-agents-automations.md` (+ `.svg`).
- Shipped group to extend: `lego/cli/internal/agent/` (`agent.go` commands and exit codes, `api.go` REST client, `render.go` text output, `watch.go` polling waits, `types.go` hand-decoded shapes).
- Constraints: the CLI imports no sibling module (thin client, every rule stays in bex-api); never touch the imported Render command tree; `.pm/DO_NOT_DO.md` #APPROVAL-MODE (no permission prompts, no `needs_input`, no agent→user channel).
- Gateway: `lego/backend/internal/sshgateway/agentattach/agentattach.go`; header `agentsessionticket.TicketHeader` = `X-Bex-Agent-Ticket` (`lego/backend/internal/agentsessionticket/ticket.go`).
- Mint: `Service.AttachTicket` (`agentsessions/service.go`), response fields `ticket`, `streamUrl` (`models.go`).
- No WebSocket hop, no second bridge (ADR047 frozen boundary).
