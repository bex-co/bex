# Static sites — CDN-hosted build output (Render `static_site` type)

Split from `w1/m15` (which ships `background_worker` + `cron_job`). Render's `static_site` type builds a repo and serves the output from a CDN with redirects/rewrites + custom response headers — a materially larger effort than the compute service types: it needs a build → object-store/CDN path (not a Deployment), a `publishPath`, and the static-site-only edge rules (`/routes` redirects/rewrites, `/headers`) the parity matrix marks static-site-only. Lower priority for a compute-first PaaS.

Promote to a w1 milestone when static hosting is prioritized; it pulls in the header/redirect/rewrite parity rows (`docs/ADR018-render-parity.md`) too.

Source: split from `w1/m15` during the 2026-07-08 w1 reorg (`/pm`); originally part of inbox note `w1/009` (m13 audit). Goal: pillar 1 (Render parity — service-type breadth).
