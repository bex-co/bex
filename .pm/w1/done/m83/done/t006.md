## Objective

Lifecycle edges per ADR082 D2/D3: suspend keeps the PVC; App deletion GCs it; removing `spec.disk` deletes the PVC (data loss is API-guarded upstream in m84).

## Context

- `parkKubernetes` (`app_controller.go:1722`) scales to 0 — must leave the PVC (and LUKS Secret) alone; resume reattaches wherever the pod lands.
- `deleteStaleChildren` (`app_controller.go:1901`) is the pattern for cleaning up when `spec.disk` is removed: delete PVC + Secret, drop `Recreate` back to default strategy.
- Free-tier auto-hibernate never applies (CEL forbids free-tier disks) — assert, don't assume.

## Steps

1. Extend stale-children handling for disk removal.
2. envtest the three transitions: suspend→resume, disk removal, App delete.
