## Objective

Add the optional `Disk *DiskSpec` field to `AppSpec` with Render-exact validation, per ADR082 D2.

## Context

- `lego/types/v1alpha1/app_types.go` — place after `MaxShutdownDelaySeconds`; shape precedent `*AutoscalingSpec` / `*MaintenanceModeSpec`.
- `DiskSpec{Name string, MountPath string, SizeGB int32}` — `sizeGB` default 10, min 1, max 10000, grow-only.
- CEL: disk ⇒ type in {web_service, private_service, background_worker} ∧ tier != free ∧ replicas ≤ 1 ∧ autoscaling absent/disabled; transition rule `sizeGB >= oldSelf`; mountPath absolute + exact-path denylist (`/`, `/etc`, `/etc/secrets`, `/home`, `/home/render`, `/opt`, `/opt/render`, `/opt/render/project`, `/opt/render/project/src`).
- Codegen runs from `lego/operator/` (`make manifests generate`); output in `zz_generated.deepcopy.go` + `lego/operator/config/crd/bases/app.bex.co_apps.yaml`.

## Steps

1. Add `DiskSpec` + field with kubebuilder markers (defaults, min/max, XValidation rules incl. transition rule with `oldSelf`).
2. `make manifests generate fmt vet` from `lego/operator/`.
3. Unit-test CEL rules via envtest CRD apply (red cases for each refusal) — full matrix lands in t008; here just the happy path compiles.
