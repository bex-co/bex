## Objective

When `spec.disk` is set, the operator creates PVC `disk-<app>` (RWO, `<sizeGB>Gi`, ownerRef → App CR) and projects the Deployment with `Strategy: Recreate`, the volume mounted at `mountPath`, and `cluster-autoscaler.kubernetes.io/safe-to-evict: "false"` (ADR082 D3).

## Context

- `lego/operator/internal/controller/app_controller.go` (`reconcileKubernetes`, ~:1572) and `deployment_projection.go` (`applyDeploymentSpec`; volumes reset at :331-335 — extend, don't fight it).
- KeyValue precedent: `keyvalue_controller.go:566-607` (claim shape, storage class `hcloud-volumes`), but Apps keep the Deployment (ADR082 rejected the StatefulSet).
- No strategy is set anywhere today — disk-less Apps must stay on the implicit RollingUpdate byte-for-byte.
- Build/pre-deploy Jobs must NOT mount the PVC (Render parity: no disk during build/preDeploy).

## Steps

1. PVC create-or-get keyed on the App (immutable size at create; resize is t005), ownerReference for GC.
2. In `applyDeploymentSpec`: when disk set — `Strategy: Recreate`, volume + mount, annotation; when nil — leave everything untouched.
3. Wire the StorageClass name (default `hcloud-volumes`; LUKS class swap is t004).
