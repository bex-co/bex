## Objective

`apply -f FILE|DIR|-` reads YAML or JSON documents in the REST body shape (`name`, `enabled`, `triggers`, `template`; several YAML documents per file; a directory's `*.yaml|*.yml|*.json`). Each is matched by name: missing → create, changed → update with `ifVersion`, unchanged → skip. `--dry-run` prints the plan and a field-level diff and writes nothing. `apply` never deletes. `403 AGENT_AUTOMATION_NOT_CREATOR` is reported with the `take-over` hint. `export <automation>…|--all` prints exactly the fields `apply` accepts (read-only fields dropped), so `export | apply -f -` is a no-op.
