## Objective

Cover the behaviour this milestone shipped and its real failure modes — not the trivially-true parts.

## Context

- t004 already holds the guard tests. This task covers what t004 does not: the pin loader's failure paths and the classification's correctness against a fixture.
- Repo rule: tests must assert real behaviour and failure modes; no tautological or snapshot-everything tests.

## Steps

1. Pin loader: corrupt hash, truncated file, malformed JSON — each fails with a distinguishable error.
2. Classification: a fixture pin plus a fixture tool set exercises all three classes plus the Render-only gap case.
3. `Superset` rule: a tool that removes a Render argument is rejected; one that adds an optional argument is accepted.
4. Drift script: assert the exit code and that the message names the changed tools.
