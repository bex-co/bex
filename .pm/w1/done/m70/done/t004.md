## Objective

Make the classification self-enforcing, so the surface cannot silently regrow or silently break a Render-compatible agent.

## Context

- Mirrors `TestRenderConformance` + `TestConformanceAllowlistEntries` (`lego/backend/internal/api/conformance_test.go`, `conformance_allowlist_test.go`) — the tests that keep the REST surface honest.
- The `internal/id` guard test is the in-repo pattern for "adding a thing without registering it fails the build".

## Steps

1. Test: every registered tool has a class (unclassified ⇒ fail, naming the tool and its file).
2. Test: no `Parity1to1` tool's name or argument names differ from the pin.
3. Test: every `Parity1to1` tool still exists in the pin (catches upstream removal).
4. Test: no `Superset` tool removes or renames a Render argument.
5. Add a stale-checked allowlist escape hatch matching the REST conformance allowlist's shape, so a deliberate, documented divergence is recorded rather than achieved by deleting a test.
