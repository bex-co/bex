## Objective

Replace permissive struct unmarshalling at the Blueprint boundary with a source-preserving front end that rejects duplicate keys, YAML type traps, unknown/misplaced fields, missing required fields, invalid enums, and unsupported registry entries while retaining exact paths and line/column locations.

## Context

- `deploy.go:812-819` currently runs a small dialect check and then `yaml.Unmarshal` into structs; fields outside those structs disappear.
- Render's schema uses `unevaluatedProperties: false`/`additionalProperties: false` and resource-specific required fields.
- Errors must redact manifest values for secret-bearing env entries.

## Steps

1. Parse YAML nodes once, detect duplicate mapping keys, and convert schema-safe values without YAML 1.1 coercion surprises.
2. Validate against the pinned schema plus capability overlay and aggregate independent errors.
3. Map schema/registry failures to stable codes, JSON-style paths, line, and column.
4. Add fixtures for unknown fields at every nesting level, missing `type`/`runtime`, duplicate keys, aliases, invalid values, and redaction.
