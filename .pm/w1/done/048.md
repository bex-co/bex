## Fixed in place this pass (the 6 new findings), with tests

All backend suites (`go test ./...`) + dashboard (2087 tests) + lint green. Uncommitted pending `/ship`.

- **#11 protocol-relative Markdown links (low).** `markdown-renderer.tsx` classified external via `href.startsWith("http")`, so `//host` / `/\host` rendered as internal and navigated the trusted tab off-origin. Moved classification to `dashboard/src/common/lib/external-url.ts` (`classifyHref`): normalize backslashes, resolve against a fixed base, external = http(s) absolute or protocol-relative authority (→ `_blank`+`noopener`), `mailto:`/`tel:` in place, everything else refused. SSR-safe (no `window`, no hydration mismatch). Tests: `external-url.test.ts` + a renderer negative test.
- **#5 SSH gateway pre-auth flood (medium).** `nativessh.Server.Serve` spawned an unbounded goroutine per socket and acquired the session limiter only **after** the handshake + DB key lookups. Added a pre-auth semaphore (`BEX_SSH_MAX_PREAUTH_CONNS`, default 256) acquired before `ssh.NewServerConn`, released the moment the handshake resolves; a full buffer sheds immediately (`bex_ssh_limit_rejected_total{scope="preauth"}`). Test: `TestGatewayPreAuthConnectionCapShedsExcessBeforeHandshake`. **This closes `w4/029` #9** (previously deferred).
- **#7 transcript replay memory (medium).** `agentattach` materialized up to the full 64 MiB transcript per read, no write deadline, ignored write errors — the root cause was `m65/t010` (F10) shipping a read budget equal to the storage quota. Now paged via `afterSeq` (`replayPageBytes`, 4 MiB), per-write deadline via `http.ResponseController` (`defaultSSEWriteTimeout`, 30s), sticky write-error that aborts replay/splice/turn, and a `ctx.Err()` check in the replay loop. Tests: multi-page replay ordering + `agentSSE` sticky-error.
- **#3 webhook queue (high) — closed.** (a) No-op guard: `apps.Scale`/`SetPlan` no longer emit an audit/webhook event when the value is unchanged (the deferred allowed-write audit is simply skipped) — closes the cheap repeatable amplifier. Test `TestScaleNoOpEmitsNoEvent`. (b) `claimLease` was `4×requestTimeout`=60s < worst-case send-pass (~105s), letting the other replica re-claim a still-in-flight row and double-POST; now derived from `ceil(sendBatch/senderConcurrency)+1` waves. (c) `SweepWebhookDeliveries` now also ages out abandoned **pending** rows older than the retention floor (a disabled endpoint's backlog is never claimed/terminalized, so it parked forever) — preserves park-and-resume for a recent disable. Integration assertion added to `store_pg_test.go`. **The deferred remainder shipped 2026-08-17 as `w4/m83`:** a transactional workspace-wide open-notification ceiling (default 10,000, `0` disables), honest watermark advancement on overflow, fair workspace-ranked `SKIP LOCKED` claims, bounded operator evidence, and real-Postgres concurrency/race coverage.
- **#2 CI trust boundary (high).** `deploy.yml` / `app-cluster.yml` / `openbao-restore-drill.yml` exposed `workflow_dispatch` with no ref guard, so a same-repo collaborator could run branch code with prod cluster/SSH/OpenBao secrets. Added a job-level `if: github.ref == 'refs/heads/main'` to each secret-bearing job (the `infra.yml` `production-infra` pattern). **Note:** the authoritative control is GitHub-side protected environments + branch policies — a repo-settings change, not YAML — so this is defense-in-depth; the environment scoping still wants doing in repo settings.
- **#9 client transcript rendering (medium).** `session-conversation-impl.tsx` replayed + rendered the full transcript, unmemoized, no window/virtualization. Added: a render window (`INITIAL_WINDOW`/`WINDOW_STEP` 200, "show earlier messages"), per-message block-building memoized by message identity (WeakMap), `React.memo` on `MessageRow` + `MarkdownRenderer`, and a per-block char cap (`MAX_BLOCK_CHARS` 100k) before Markdown. i18n key `agentSessions.showEarlierMessages` (en+zh).
