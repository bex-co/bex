## Objective

Carry a per-member MFA indicator on `MemberView`, mirroring Render's `user.otpEnabled` in the Team Members query (docs/render-artifacts/team-members.graphql:27), and show it as a badge in the member row — an admin deciding who to trust with `developer` can see who has 2FA.

## Context

- The Kratos-admin MFA lookup already exists: `BEX_KRATOS_ADMIN_URL` powers the owners API's email/MFA fields (`kratos.go` inspects credential contents — the webauthn-stub fix, w4 inbox `020.md` resolution). This task is wiring, not new capability.
- `lego/backend/internal/members/service.go:148-174` — `MemberView`; enrichment happens where `EmailLookup` already runs (w6/m10's pattern: degrade honestly — lookup unwired or per-subject miss ⇒ field omitted/false-y, request still succeeds; docs/ADR024-members.md § Member identity).
- Render also carries `active` and `hasGoogleId`; `active` is presence-of-identity (bex members are always active rows today — surface only if it falls out naturally), `hasGoogleId` maps to Kratos `oidc` credentials (optional stretch).

## Steps

1. Extend the identity-lookup interface the members service injects with the MFA bit (reuse the owners API's existing Kratos-admin reader — one reader, two consumers; do not duplicate the credential-inspection logic).
2. Add `mfaEnabled` to MemberView across REST/GraphQL/MCP (same field name Render's REST owners API uses — check `docs/render-artifacts/owners-api.md` for the canonical casing; GraphQL may keep `otpEnabled` if mirroring the dashboard contract — pick one, note the choice).
3. Dashboard: shield/badge on the member row (`member-row.tsx`), tooltip, i18n'd.

- [ ] A member with TOTP enrolled in Kratos shows `mfaEnabled: true` on all three surfaces; without, `false`.
- [ ] Lookup unwired (`BEX_KRATOS_ADMIN_URL` unset) ⇒ members list still succeeds, field degrades exactly like `email` does today.
- [ ] Badge renders in the member row for the enrolled member on a dev-N stack.

## Out of scope

- Workspace-level MFA *enforcement* (Render pro-gates it; enterprise-surface territory).
