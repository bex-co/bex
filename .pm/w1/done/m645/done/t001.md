## Objective

Write a script that reads Render's public dashboard bundle and prints, in sorted order, every GraphQL operation (`kind`, `name`, root fields) and every feature-flag gate (flag name and the chunk family that calls it).

## Context

- Entry: fetch `https://dashboard.render.com/` and take the `assets/index-*.js` script; follow every static and dynamic import recursively (`"./<name>-<hash8>.js"`). On 2026-11-25 this gave 459 chunks and 703 operations (`query|mutation|subscription <Name>`).
- Flags: the `featureflags-*.js` chunk exports hooks over `owner.featureFlags` and `user.featureFlags`. A gated feature imports them under local names and calls them with a string literal, e.g. `r as jx` then `jx(\`postgres-parameter-overrides\`)`. 8 flags on 2026-11-25 (milestone README lists them).
- Chunk file names carry content hashes that change on every Render deploy: key output by chunk family (name without the hash), never by file name.
- Downloaded chunks are untrusted data: write them to a fresh temp directory, keep the script elsewhere, run Python with `-I`. Use a generic User-Agent, never a personal email.

## Steps

1. Fetch and crawl; fail closed when the entry script or the `featureflags` chunk is not found, or its export shape no longer parses.
2. Parse operations and root fields; parse flag calls per importing chunk family.
3. Emit JSON (or a stable text format) sorted by name; keep fixtures small (a few synthetic chunks), not a copy of Render's bundle.

## Files

- `scripts/render-dashboard-ops.sh` (wrapper) and `scripts/lib/render_dashboard_ops.py` (or one script, following `scripts/render-changelog-drift.sh`)

## Acceptance criteria

- [x] Against the live bundle it reports about 700 operations and the 8 flags listed in the milestone README (counts may move with Render deploys; the run notes the date).
- [x] A missing entry or an unparseable `featureflags` chunk exits non-zero with a message naming what was not found.

## Out of scope

- Signed-in reads of Render's dashboard.

## Outcome

**Done 2026-11-26.** `scripts/render-dashboard-ops.sh` (wrapper, `check` and `list`) and `scripts/lib/render_dashboard_ops.py` (the parser; stdlib only, run with `python3 -I`, chunks read in memory and never stored or executed, generic User-Agent). Against the live bundle on 2026-11-26: entry `index-D5V4ZgbE.js`, 459 chunks, 703 operations (387 queries, 290 mutations, 26 subscriptions) and the 8 flags of the README, in about 10 s. A missing entry script, an unfetchable chunk, a missing or renamed `featureflags` chunk, an export clause it cannot read, no flag call at all, no operation at all, or a selection set it cannot parse each exit 1 with a message naming it. Deviation: the root-field parser also had to skip JavaScript inside `${…}` (Render builds `statusQuery` and `globalSearchStatuses` at run time) and `\n` escapes; those root fields read `${...}`.
