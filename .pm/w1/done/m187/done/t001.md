## Objective

Watch the workload cluster's Nodes. When a guarded node carries CA's `ToBeDeletedByClusterAutoscaler` taint, roll each at-risk App off it with the same evacuation annotation m186 uses. Then requeue until none is at risk or the taint is gone.

## Context

- CA 1.34.5 taints the node `NoSchedule`, sleeps `--node-delete-delay-after-taint`, then drains (`actuator.go:294-296`). The taint key is `ToBeDeletedByClusterAutoscaler` (`utils/taints/taints.go:41`).
- A node is guarded when it is the `status.nodeRef` of a Machine matching `--machine-selector`, so the pool keeps one definition.
- In production, Machines and Nodes are in one cluster; in the mock they are not. The Node watch therefore needs a cache on the workload cluster, added to the manager.

## Steps

1. Factor the evacuation loop out of `hold` so both paths share it.
2. Add a Node controller on a workload-cluster cache (`cluster.New` + `mgr.Add`), filtered to nodes carrying the taint.
3. Add `nodes` list/watch to `config/drain-guard/clusterrole.yaml`.

## Done 2026-10-26

- **Shared evacuation.** `evacuate` holds the loop that `hold` had inline. It skips an App already marked for this node or mid-rollout.
- **Node path.**
  - `ReconcileNode` → `handOver` acts only on a Ready node carrying `ToBeDeletedByClusterAutoscaler` that is the `status.nodeRef` of a Machine matching `--machine-selector` (`guardsNode`).
  - It evacuates the at-risk Apps and rechecks every 5s until none is left. It never cordons.
  - API errors requeue at the same 5s pace, never controller-runtime's backoff.
- **Wiring.**
  - `SetupWithManager(mgr, nodes cache.Cache)` adds the `drain-guard-scale-down` controller, a `source.Kind` on the workload cluster's Node cache filtered by `markedForScaleDown`.
  - `cmd/drain-guard` builds that cache with `cluster.New(workloadCfg)` added to the manager. Pods and Deployments stay uncached.
- **RBAC.** `config/drain-guard/clusterrole.yaml` grants nodes `get, list, watch, patch`; only list and watch are new. The admission policy is unchanged.
- **Tests (`drainguard_test.go`).**
  - `TestScaleDownHandsOverBeforeCAEvicts`: evacuates once, no cordon, stops requeuing once Ready elsewhere.
  - `TestScaleDownLeavesOtherNodesAlone`: not marked, another pool's node, no Machine for the node, NotReady, node gone.
  - `TestScaleDownRetriesAtPaceWhenTheAPIFails`.
  - Mutation check: each of these mutants fails a test:
    - dropping the taint check;
    - dropping the Ready check;
    - dropping the guard;
    - ignoring the nodeRef;
    - backing off on error;
    - requeuing with nothing at risk.
