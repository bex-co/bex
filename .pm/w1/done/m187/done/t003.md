## Objective

Show DoD 1 and 2 on the local CAPD mock, where CA runs on `kind-bex-mgmt` from the same values file.

## Steps

1. Run drain-guard against the mock (as in m186 t004) and give CA the new delay.
2. With two tenant nodes, put a single-instance App on one that CA will consolidate, and run a request loop. Let CA scale the node down. Expect zero failed requests, with the replacement Ready elsewhere before CA's drain.
3. With a replacement that can never become Ready, expect CA to evict and delete the node after its delay.
4. Restore the mock: tenant floor and fixtures.

## Acceptance criteria

- [x] The evidence is recorded in this task: timestamps for taint, replacement Ready, CA drain and node gone, plus the request loop's failure count.
