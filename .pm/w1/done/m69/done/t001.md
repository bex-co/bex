## Objective

Give background callers that hold a workspace name but no request identity a way to make `core.Base`'s workspace/tenant resolution behave exactly as an authenticated member of that workspace would: an internal acting-tenant context value that `resolveWorkspaceUncached` consults **before** the identity check returns empty.

## Context

- `lego/backend/internal/core/workspace.go` — `WithWorkspace` binds only a workspace *name* (`workspaceKey`), never identity.
- `lego/backend/internal/core/base.go:539-545` — `resolveWorkspaceUncached` returns `("", nil)` the moment `IdentityFrom(ctx)` misses, before consulting `WorkspaceFrom`; everything downstream (`Tenant`, `WorkspaceOrDefault`, `TenantNamespace`, scoped matching) keys off that.
- The round-15 finding: `webhook.go:341-347` constructs `core.WithWorkspace(context.Background(), tenantID)` for the Blueprint auto-sync, so the entire apply pipeline runs with `s.Tenant(ctx) == ("", false)`.
- Do **not** widen the exported context API for arbitrary callers: this is a platform-internal mechanism (minted from a durable store row, not caller input).

## Steps

1. Add an unexported-or-internal acting-tenant context key + setter/getter (e.g. `WithActingTenant(ctx, tenantID)` / `ActingTenantFrom(ctx)`) in `internal/core` next to `WithWorkspace`.
2. In `resolveWorkspaceUncached`, consult `ActingTenantFrom(ctx)` before the identity-miss early return: an acting tenant + a bound workspace name resolve to that workspace/tenant tuple (keep the existing identity path authoritative when an identity IS present).
3. Keep behavior byte-identical for every existing caller (no acting tenant in ctx ⇒ unchanged resolution).

## Files

- `lego/backend/internal/core/workspace.go`
- `lego/backend/internal/core/base.go`

## Acceptance criteria

- [ ] `resolveWorkspaceUncached` returns the named workspace's row (tenant id + workspace) when only an acting tenant is present in ctx
- [ ] An identity-bearing context still resolves exactly as before (identity wins / unchanged precedence)
- [ ] No exported-behavior change for callers that never set the acting tenant
