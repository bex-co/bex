## Objective

Bind the git-push Blueprint auto-sync's apply pipeline to the blueprint row's tenant so every created/patched App/Database/KeyValue CR is tenant-labeled, tenant-namespaced, store-managed, and scoped — and make the apply refuse when the tenant cannot be resolved, instead of silently proceeding identity-less.

## Context

- `lego/backend/internal/apps/webhook.go:341-347` — `bgCtx := core.WithWorkspace(context.Background(), tenantID)`; the identity-less context flows through `triggerBlueprintSync` (`blueprint.go:665-675`) → `runSync`/`deployStack` (`blueprint.go:626-638`) → `applyStackServices`/`applyStackDatastores` (`deploy.go:824`, `deploy.go:780`).
- Loss sites when `Tenant(ctx)` is empty: `createNewApp` (`service.go:1671-1687`, bare name/shared ns/no labels; `provisionAppIdentity` `service.go:1732-1772` skips store row + labels + slug), datastore applies (`deploy.go:2757-2763`, `deploy.go:2805-2811`), unscoped display-name matching (`deploy.go:918`, `deploy.go:1032-1043`, `deploy.go:2715-2716`, `deploy.go:2780-2781`), identity-less `GetApp` no-gate (`base.go:1382-1389`), registry creds against `WorkspaceOrDefault("") = default` (`deploy.go:1135`).
- w9/001 already fixed the store-row half via `resolveTenantID` (`blueprint.go:908-921`) — do not regress it; this task fixes the CR/namespace/scoping half.

## Steps

1. In the webhook sync goroutine (or at the top of `triggerBlueprintSync`/`runSync`), stamp the acting tenant (t001 mechanism) from the blueprint row's `TenantID` before any apply work.
2. Add a fail-closed guard on the sync apply path: workspace bound but tenant unresolved ⇒ refuse the sync (surface the refusal in the sync result/log the same way other apply failures surface; never fall through to identity-less behavior).
3. Verify end-to-end that with the binding in place: creates take the tenant branches (labels, `TenantNamespace`, `provisionAppIdentity`), display-name matchers receive `scoped=true`, `fromDatabase`/`fromRegistryCreds` resolve within the blueprint's workspace.
4. Sweep for any other background caller constructing `WithWorkspace` over `context.Background()` for create/patch flows; bind or fail closed there too (the HMAC redeploy path's identity-less patch of repo-matched Apps is documented intentional design — leave its semantics intact).
