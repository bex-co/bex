## Objective

Normalize every remaining production and maintained-dev datastore object to current identity and structured CIDR shapes, then delete the one-time migration scripts and fallback parsers.

## Context

- scripts/postgres-name-migrate.sh and keyvalue-name-migrate.sh backfill immutable typed ids and display names.
- scripts/ipallowlist-normalize.sh and lego/backend/internal/core/cidr.go preserve older flat string entries.
- A non-zero preflight count requires migration and a second zero-count audit before code removal.

## Steps

1. Run migrations in maintained dev environments, validate behavior, then run them against production with before/after inventories.
2. Verify REST, GraphQL, MCP, operator, and official CLI reads use stable ids, display names, and structured allowlist entries.
3. Delete migration scripts, metadata-name fallbacks, and flat-CIDR parsing branches only after zero-count proof.

## Completion evidence

- Production and maintained-local before/after inventories reported zero Databases or Key Values with missing display names, non-typed ids, or malformed allowlist entries. Production's control-plane store also reported zero legacy environment allowlist strings.
- Migration 0053 normalized legacy environment entries and installed `environments_ip_allow_list_structured`. A transaction-isolated production rehearsal proved the up migration preserved descriptions and rejected a legacy write; the down migration removed the guard, and the transaction was rolled back. The deployed store reports schema 53, one structured constraint, and zero legacy entries.
- The unmodified Render CLI v2.21.0 created typed `dpg-` and `red-` fixtures, renamed them without changing ids, and round-tripped description-carrying allowlists through REST, GraphQL, MCP, Kubernetes CRs, and back to the CLI. Both fixtures were deleted and their CR absence verified.
- REST create requests with bare-string allowlist elements returned 400 and created nothing. Server-side dry runs rejected Database and KeyValue CRs without `spec.name`.
- Removed the three one-time migration scripts and tests, metadata-name fallbacks, the generic bare-string decoder, the environment backfiller entrypoint/store methods, and the durable-log legacy id dispatch. Backend/types/operator suites, GitOps validation, script tests, CI, and production rollout passed; the live CLI check additionally fixed current Render `region` request decoding.
