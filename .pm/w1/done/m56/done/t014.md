## Objective

Add durable checks for the supported post-migration state and run the full suites required by the changed platform areas.

## Context

- The meaningful failure modes are an un-restorable backup, a manifest that reintroduces native Barman, a new object born with legacy metadata, an old route recreated, or CI still loading Node 20.

## Steps

1. Add manifest and controller tests asserting plugin-only backup configuration and canonical metadata at creation.
2. Add validation that forbidden deprecated fields, version pins, routes, cleanup jobs, and action runtimes are absent.
3. Run operator, backend, GitOps, Terraform, build, and workflow checks plus the recorded restore drills.
