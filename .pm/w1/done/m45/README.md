## Definition of done

On a dev-N dashboard, pasting each live-verified Render URL shape lands correctly, **and the navigation matches Render's structure for every supported entry**: the global sidebar shows Render's grouping (ungrouped Projects/Blueprints/Env Groups; Integrations: Webhooks, Notifications; Workspace: Usage, Settings — omitted Render entries recorded as non-goals), and a service page swaps to a resource-scoped sidebar (back link; Events; Settings; Monitor: Logs, Metrics; Manage: Environment, Scaling, Plan) instead of the horizontal tab strip. Specifically: `/w/settings` and `/w/{tea-id}/settings` open workspace settings with the context switched to the named workspace (a foreign `tea-id` is refused, never silently shown as the caller's own); `/w/{tea-id}/billing` lands on `/usage` and `/billing/update-plan` opens the change-plan dialog; `/u/{any-id}/settings` lands on account settings; `/d/new`, `/new/database`, `/new/redis`, and `/new/project` each reach a working create surface (no 404s — `/d/new` is broken today); `/webhooks` and `/notifications` render their capability pages; `/login` and `/register` reach the auth pages. `docs/render-artifacts/dashboard-routes.md` records the full captured scheme, and `yarn typecheck && yarn lint && yarn test` stay green.
