## Objective

Meaningful tests for what m148 shipped, with the "restart ships new code" regression first.

## Steps

1. **Backend, with a commit resolver faked to return H while C is live:**
   - REST restart, `restartServer` and MCP `restart_service` produce a release on C;
   - a restart with no live release is refused;
   - an image-backed restart keeps the image.
2. **Backend:** `Trigger(commitId: C)` pins C and sets `autoDeploy = false`. Controls: Deploy latest resolves H, a push pins the pushed SHA, and `config_change` keeps the running commit.
3. **Dashboard:**
   - header and row Restart call the restart verb and share the confirmation;
   - the specific-commit dialog sends `commitId`, shows the auto-deploy notice, and displays a server refusal.
