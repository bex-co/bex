## Objective

Implement t001's design and deploy it in front of (or alongside) the existing Traefik TCP/SNI route for external managed-Postgres.

## Context

- `deploy/gitops/` — wherever the external Postgres TCP routing chart/config lives.
- Must not disturb the existing direct-TLS (PG 17+ `sslnegotiation=direct`) path — both need to keep working per the DoD.

## Steps

1. Deploy the proxy component per t001's design (a new GitOps chart, or config added to an existing one).
2. Wire it into the traffic path ahead of/alongside Traefik's SNI routing so preamble-mode connections are handled correctly while direct-TLS connections are unaffected.

- `lego/operator/cmd/pg-sni-proxy/main.go` — the proxy binary

- `deploy/gitops/overlays/prod/values/traefik.values.yaml` — removed `postgres` from LB exposure
