## Done (2026-09-29, `/loopx w1`)

`examples/ws-silent/` is a gorilla/websocket server. Its `/ws` endpoint receives client frames and writes nothing back; `?mode=send` is the server-sending control; deploying it and connecting no client is the idle control. `GET /stats` counts application and control frames separately, and a `client` subcommand sends periodically without pinging. `go test ./...` asserts each mode: silent writes nothing, send mode writes unprompted, and a ping/pong is counted apart from the application counters. The README records a local run of both connected modes (silent: `clientMessages 3, serverMessages 0, serverPongs 0`) and the live procedure, including the scanner-traffic caveat, the rule of not polling `/stats` inside the measured window, and cleanup. The Docker image builds. m161's live acceptance (t003) stays in m161, which this unblocks.
