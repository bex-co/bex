## Objective

## Steps

1. Add `IPAllowListProxiedNotice` (`common/components/ip-allow-list-proxied-notice.tsx`). It is an amber `Alert` listing the hosts plus the DNS-only fix, and renders nothing for an empty list.
2. Add pluralized `common.ipAllowListProxiedTitle_{one,other}` and `common.ipAllowListProxiedBody_{one,other}`, plus `common.ipAllowListProxiedFix`. zh has only `_other`.
3. Add the field to the `server.graphql`, `ip-allow-list.graphql` and `EnvironmentFields` selections. Run offline codegen from `TestDumpGraphQLSchema` and splice only the feature hunks.
4. Map it in `ServiceView` (optional; null on lists) and `EnvironmentView`. Render it in `ServiceNetworkingPanel` (Settings → Networking) and in `EnvironmentSettingsDialog`.
