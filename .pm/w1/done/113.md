## Resolved 2026-09-28 (`/loopx w1`)

**The gate, stated precisely.** `autoDeployGated` is
`a.Spec.Repo != "" && !a.Spec.AutoDeploy` (`lego/backend/internal/envgroups/service.go:1163`).
So a group write redeploys linked services **except** a repo-backed one whose owner
turned Auto-Deploy off. Image-backed services are deliberately **not** gated — their
`autoDeploy: false` is a default (no branch to watch), not an opt-out, and reading it
as one "would silently strand every image-backed service on stale group values
forever" (that function's own comment).

**And the other half, which the approved refinement warned against overpromising.**
For a gated service the group's Secret refs still land; only `spec.restartedAt` is
left untouched and no deploy row opens (`rollLinked`, `:1176-1180`). So Auto-Deploy
off does **not** prevent the configuration change — it defers the rollout. The new
copy says the service "keeps serving its current release and picks the change up on
its next deploy", which is true in both directions and does not promise prevention.

**Strings corrected, `en` and `zh`:**

**Scope extended by one string beyond the three this note named**, deliberately:
`envGroups.rolloutNote` is the same overpromise in the present tense, and the new
census test below caught it. One string in two locales; recorded rather than
silently widened.

**Why it drifted, and the guard that stops it.** Nothing pinned three of the four
strings — `rolloutNote` was asserted by two `use-env-groups.test.ts` toast
assertions (updated here), and the other three by nothing at all, so they stayed
wrong for as long as the gate had existed. New
`src/features/env-groups/locales/__tests__/redeploy-copy.test.ts` asserts, per
locale: every redeploy-promising string names auto-deploy, none carries the old
absolute phrasing, and none claims auto-deploy off *prevents* the change. Its first
case is a **census** over the `en` catalog — any new string matching `/redeploy/i`
must be added to the list, so the next one cannot escape the assertions. That census
is what found `rolloutNote`.
