## Objective

Collapse the create→adopt(owner-check)→classify Job state machine that `build.EnsureBuild`, `publish.Ensure`, and `predeploy.Ensure` each reimplement into one `execution.EnsureOwnedJob(ctx, cl, job, owned, pkg) (cur *batchv1.Job, created bool, err error)`. Only the ~20-line I/O middle collapses — each package keeps its own `Options`, pure Job constructor, and outcome enum (build's `PhaseWaiting`/`Fault` genuinely differ from publish's).

## Context

- The three bodies: `lego/operator/internal/build/build.go:444-497`, `internal/publish/publish.go:203-231`, `internal/predeploy/predeploy.go:192-224`.
- Shared pieces already in `internal/execution`: `ArtifactIdentity`, `JobHasCondition`, `JobFailureMessage`, `CheckOwner`.
- Error-string prefixes stay per-package via the `pkg` argument (`"build: create job %s: %w"` etc.).
- Naming contract already pinned by `internal/build/jobname_contract_test.go`.
