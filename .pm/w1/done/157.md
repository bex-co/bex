# Cron job rollback: Render's dashboard has no rollback page for one

Why: bex's cron Deploys rows offer Rollback (and, since w1/m646, its Confirm Rollback page), but Render's cron deploy page (`CronJobDeployContainer-*.js`) has no rollback route, so bex may offer a cron action Render's dashboard does not.

- **Evidence:** Render's public dashboard bundle, read 2026-11-26 for w1/m646: `DeployContainer-*.js` holds the `Confirm Rollback` section and the deploy page's Rollback control, and `CronJobDeployContainer-*.js` has neither (no `rollback` string). Render's `POST /services/{id}/rollback` does not say whether a cron job is accepted.
- **Check:** whether Render's API rolls back a cron job (a disposable cron job in a Render workspace bex owns, or the API reference), and whether its cron Deploys list shows Rollback.
- **Then:** if Render offers no cron rollback anywhere, hide bex's cron Rollback in the dashboard and answer the API as Render does; if its API accepts one, keep the verb and record the dashboard difference in `docs/ADR018/deploys.md`.
- **Done when:** ADR018's Rollback row states what Render does for a cron job, and bex's dashboard and API match it.
- **Done 2026-11-26** by `/loopx w1`. Render offers no cron rollback in its dashboard: in its public bundle the cron Deploys rows are drawn with `isRollbackSupported` false and no action (no Cancel either), the cron deploy page (`CronJobDeployContainer`) passes its header no actions, and the cron routes have `deploys/:deployId` but no `/rollback`, so Render's catch-all sends that URL to the cron job's page. Render's API reference documents `POST /services/{serviceId}/rollback` for "a previous deploy of the specified service" with no type limit, and the `rollbackSupportStatus` values name no service type. So bex's cron Deploys rows, Events rows and deploy page no longer offer Rollback (`offersDashboardRollback`), a cron deploy's `/rollback` URL lands on that deploy's page (`redirectCronRollback`), and REST, GraphQL and MCP still roll a cron job back. ADR018 § Rollback, `docs/render-artifacts/cron-dashboard.md` and `rollback-comparison.md` record it. Not tried on a Render cron job, for the reason its Trigger Run was not: a disposable one costs at least $1 a month. bex's cron Deploys rows and deploy page still offer Cancel, which Render's do not; that is outside this note.
