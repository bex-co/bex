# internal/store: queryAll[T] + projector/cpapi sub-packages + delete the Store interface

From the 2026-08-19 refactor review (§3 + §4.3). Two stages, promote as one milestone:

- **`queryAll[T]` generic** (LOW risk, −380): 55 of 57 `rows.Next()` scan loops are the byte-identical 10-line shape (e.g. `store.go:807-823`, `webhooks.go:217-227,306-316,455-465,820-830`); the per-entity `scanT` funcs already exist. pgx v5 ships `CollectRows`, so the helper is ~8 lines. File-by-file; `store_pg_test.go` (3,454 lines) is the net.
- **Package split** (MEDIUM risk, −570): `internal/store` is three packages wearing one name — Postgres persistence, a Kubernetes controller (`reconciler.go` 1,338 + `namespaces.go` 776: **zero** references to `PGStore`), and an HTTP server (`api.go` 819). The ~50-method `Store` interface (`store.go:302-475`) has no consumers outside those in-package files: the reconciler uses 8 methods, namespaces 1, api 11 — yet `fake_test.go`'s 884-line `memStore` must implement all of it. Extract `store/projector` (reconciler + namespaces + reconciler_metrics, own 8/1-method interfaces) and `store/cpapi` (api.go, 11-method interface), then **delete `Store` entirely** and shrink memStore per consumer. Touches `cmd/api/main.go:361-388,926-969,1091-1141` — sequence after w1/070's config split to avoid churning main.go twice.
