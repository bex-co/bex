## Objective

Establish exactly when and why Traefik mints the entrypoint-prefixed `websecure-<router>@kubernetes` sibling alongside `<ns>-<name>-<host>-<path>@kubernetes`, from the deployed Traefik configuration and Traefik's documented Kubernetes-Ingress provider behavior — so t002's resolver fix enumerates the right prefixes by rule, not by copying one prod observation.

## Context

- Observed on prod (w1/m50/t006): for every operator-owned Ingress there are `default-…@kubernetes` (namespace-prefixed only) AND `websecure-default-…@kubernetes` router label values on `traefik_router_responses_bytes_total`; the websecure ones carry the real bytes.
- The Traefik deployment/config lives in `deploy/gitops/` (helm values — entrypoints, TLS, redirections). Questions to answer: which entrypoints exist (`web`, `websecure`, others — e.g. the SNI TCP entrypoints for pg/kv are separate TCP routers, not HTTP); is the sibling created because of the Ingress TLS section, the global `web→websecure` redirection, or annotations the operator sets (check `lego/operator`'s Ingress builder for `router.entrypoints` annotations); can a THIRD variant ever appear (e.g. `web-…` when entrypoints are pinned explicitly)?
- Traefik's provider behavior reference: when an HTTP router is attached to more than one entrypoint with differing TLS, Traefik splits it into per-entrypoint routers named `<entrypoint>-<router>`; confirm against the deployed version's docs/source rather than memory.
- Record the ruling in a doc comment on `core.TraefikRouterNamesForIngress` + a line in ADR023's w1/m50 section (it already documents the miss via `w1/035`).

## Steps

1. Read the Traefik helm values in `deploy/gitops/` (entrypoints, redirections, TLS defaults) and the operator's Ingress construction (annotations, TLS section).
2. Confirm the split-router naming rule for the deployed Traefik major version (docs/changelog); enumerate every prefix that can occur for operator-owned Ingresses.
3. Cross-check against live prod label values (`traefik_router_responses_bytes_total` router label inventory) — every observed prefix must be explained, every predicted prefix observed (or explained why absent).
4. Write the ruling into the resolver's doc comment (t002 lands it) and ADR023.
