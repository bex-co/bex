## Objective

The internal control-plane tenant API on `:8091` fails **open**: `bearer()` is a no-op when
`BEX_CP_TOKEN` is empty, and prod sets that token nowhere — so the API serves unauthenticated in
production. It exposes privilege-granting operations (`POST /v1/tenants` grants OpenFGA
workspace-admin to an arbitrary subject; cross-tenant app create/delete; domain attach). Make it
fail **closed**.

## Context

- `lego/backend/internal/store/api.go:355-359` — `bearer()` returns the handler unwrapped when
  `a.Token == ""` (the constant-time compare from w6/004 at `:365` is dead on this path).
- `lego/backend/cmd/api/main.go:369` — `Token: os.Getenv("BEX_CP_TOKEN")`; no fail-if-empty guard.
  The `:8091` listener starts whenever `BEX_CP_DB_URI` is set.
- `BEX_CP_TOKEN` is set in **no** deployment/config/env file (`lego/operator/config/api/*`,
  `deploy/`, `.env.example`, `.env.template` — all clean on grep).
- `deploy/gitops/base/network-policies.yaml` — `deny-tenant-ingress` admits `bex-system`,
  `traefik`, `monitoring` on **all ports** (the `from` blocks carry no `ports:`), so `:8091` is
  reachable unauthenticated from any pod in those platform namespaces. Not tenant- or
  internet-reachable.
- Secondary: `lego/backend/internal/store/api.go:148` — `createTenant` builds `"user:"+req.Admin`
  with no format validation on `req.Admin`.

## Steps

1. Refuse to serve unauthenticated: when the CP listener is enabled (`BEX_CP_DB_URI` set) and
   `BEX_CP_TOKEN` is empty, fail fatally at startup (`cmd/api/main.go`) — or, if a token is
   genuinely optional in dev, bind the listener to loopback and/or port-scope the NetworkPolicy
   `from` blocks to `:8090` so `:8091` is never reachable cross-pod without a token. Pick fail-fatal
   as the default; document the dev escape hatch.
2. Set `BEX_CP_TOKEN` in `lego/operator/config/api/deployment.yaml` (from a Secret), and mirror the
   name (no value) in `.env.example` + `.env.template` per the repo sync rule.
3. Validate `req.Admin` format in `createTenant` before minting the OpenFGA tuple (reject anything
   that isn't a well-formed subject id).

## Acceptance criteria

- [ ] Starting bex-api with `BEX_CP_DB_URI` set and `BEX_CP_TOKEN` unset either aborts with a clear
      fatal error or the `:8091` listener is unreachable cross-pod (loopback / port-scoped policy).
- [ ] A request to a `:8091` route without the correct bearer returns 401 in prod config.
- [ ] `BEX_CP_TOKEN` appears in the deployment manifest and (name only) in both env templates.
- [ ] `createTenant` rejects a malformed `req.Admin`.

## Out of scope
