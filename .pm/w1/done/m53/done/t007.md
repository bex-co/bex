## Objective

Harden the browser web-shell exec ticket: make single-use hold across gateway replicas, and stop the
ticket from landing in access logs.

## Context

- **L7** `lego/backend/internal/sshgateway/websocket.go:273` (and `server.go:80`) — `usedNonces` is
  a per-process in-memory map; the gateway runs `replicas: 2`, so a captured ticket can be redeemed
  once on **each** replica within its ≤90s TTL. Each redemption still re-authorizes `can_operate`, so
  impact is bounded — but single-use should be global. Move the nonce reuse-guard to the shared
  control-plane DB (the gateway already holds `BEX_CP_DB_URI`), or use sticky sessions.
- **L8** `lego/backend/internal/sshgateway/websocket.go:99` — the ticket travels as a `?ticket=`
  query param (browsers can't set custom WS headers). The gateway doesn't log request URLs, but if
  Traefik (or any intermediary) access-logs query strings, the ticket is captured. Ensure the
  `ssh-shell` IngressRoute does not log query strings, or move the ticket to a
  `Sec-WebSocket-Protocol` subprotocol carrier.

## Steps

1. L7: add a small shared-store nonce table (id + expiry) with an atomic claim-on-first-use, backed
   by `BEX_CP_DB_URI`; fall back to the in-memory guard when the DB URI is unset (dev). Prune expired
   rows.
2. L8: confirm/adjust the `ssh-shell` Traefik IngressRoute + access-log config so query strings are
   not logged; if that can't be guaranteed, carry the ticket via a WS subprotocol instead of the URL.

## Files

- `lego/backend/internal/sshgateway/{websocket.go,server.go}`
- `lego/backend/internal/store/` (nonce table + migration)
- `lego/operator/config/ssh/*` / the `ssh-shell` IngressRoute + Traefik logging config

## Acceptance criteria

- [ ] A ticket redeemed on one replica is rejected on the other (global single-use), test-covered.
- [ ] The web-shell ticket is not present in intermediary access logs (query-string logging off or
      subprotocol carrier).

## Out of scope

- Native `ssh` path (unaffected); ticket TTL/HMAC design (already sound).
