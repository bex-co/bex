## Objective

A tenant can steer the operator into a blind SSRF via the image-signature admission webhook. Three
flaws compound: the registry prefix match lacks a `/` boundary, the operator's shared HTTP client
has no SSRF dial guard, and `Image` is validated nowhere. Fix all three.

## Context

- `lego/operator/internal/webhook/pod_admit.go:60` — `strings.HasPrefix(c.Image, p.registry)` with
  `p.registry` = e.g. `zot.bex-registry.svc:5000` (no trailing slash). So
  `zot.bex-registry.svc:5000.attacker.tld/x:tag` passes the check. Every **other** registry match in
  the operator uses `Registry+"/"` (`app_controller.go:466,605,776,809,2940`) — the webhook is the
  lone deviation.
- `lego/operator/internal/imagecheck/imagecheck.go:81` — `Verify` parses the host out of the image
  ref and issues `GET http(s)://<host>/v2/.../manifests|blobs/...` via `boundedhttp.Shared`.
- `lego/operator/internal/httpclient/httpclient.go:41` — `Shared` uses a bare `net.Dialer` with **no**
  `netutil.SafeDialContext` (the guard the outbound-webhook worker got in w7/m35). Operator has
  in-cluster network position → attacker-chosen host reaches internal services / `169.254.169.254`.
- `lego/types/v1alpha1/app_types.go:153-155` — `Image` has **no** `pattern`/`maxLength` marker
  (unlike `Repo`/`Branch`/`RootDir`); backend only empty-checks `req.Image`
  (`lego/backend/internal/apps/service.go:1855,1940`). No `ValidImage` exists.
- Tenant-triggerable when `BEX_TENANT_SIGNING_KEY_SECRET` is set (pods get `verify-image=enabled`).

## Steps

1. `pod_admit.go`: match `strings.HasPrefix(c.Image, p.registry+"/")` (mirror `registryHosted`).
2. Route the operator's `httpclient` transport through `lego/types/netutil` `SafeDialContext` so
   registry/Prometheus dials refuse loopback/private/link-local/metadata IPs (DNS-rebind covered).
   Keep the existing timeouts/pooling.
3. Add a `ValidImage` reference validator in `lego/backend/internal/store` (host + repo + tag/digest,
   no whitespace/control chars) and enforce it at the create/set-image paths; add
   `+kubebuilder:validation:Pattern`/`:MaxLength` on `App.Spec.Image`, regenerate the CRD
   (`make manifests generate` from `lego/operator/`).
