## Objective

Burn down the operator/manifest defense-in-depth findings: make tenant isolation independent of the
per-App label, harden the admission posture, and harden managed Valkey pods.

## Context

- **L3** `lego/operator/internal/controller/app_controller.go:2673` +
  `deploy/gitops/base/tenant-node-egress.yaml` — the per-App NetworkPolicy and the Cilium
  node/metadata egress-deny both select on `app.bex.co/workspace`. A label-less (hand-applied) App
  gets **neither**, so its pods have no cross-workspace isolation and can reach `169.254.169.254`.
  No namespace-wide default-deny exists in the apps namespace. Requires cluster RBAC to exploit (not
  tenant-reachable), but CR-only Apps exist in prod (`hello-static`). Add a namespace-wide
  default-deny + an all-pods metadata/node `egressDeny` in the apps namespace (as `bex-build`
  already has), so isolation doesn't hinge on a label.
- **L4** `lego/operator/config/webhook/manifests.yaml:41` — signature admission fires only on
  operator-applied `verify-image=enabled` pods; enforcement rests entirely on tenants lacking
  pod-create RBAC. A single RBAC slip re-opens unsigned-image execution. Consider a
  `namespaceSelector`-based fail-closed posture for tenant namespaces.
- **L5** `lego/operator/internal/controller/keyvalue_controller.go:466-493` — managed Valkey
  StatefulSet pods set no securityContext and mount the default SA token. Pinned platform image, not
  tenant-controlled. Apply the same hardening tenant Deployments get: drop ALL caps,
  `allowPrivilegeEscalation:false`, RuntimeDefault seccomp, `automountServiceAccountToken:false`.

## Steps

1. L3: add namespace-wide default-deny + all-pods metadata/node egressDeny for the apps namespace;
   verify tenant reachability matrix still passes (`scripts/verify-tenant-isolation.sh`).
2. L4: evaluate a namespaceSelector fail-closed webhook for tenant namespaces; implement if it
   doesn't break platform pods (weigh against the operator-applied-label model).
3. L5: stamp the securityContext + `automountServiceAccountToken:false` on the Valkey StatefulSet
   pod/containers; regenerate/apply.
