## Objective

The conversation column both session states share: `useChat` + a transport pointed at `api.bex.co/v1/agent-sessions/{id}/stream` (m43 contract), rendering through vendored AI Elements. Terminal sessions = replay + `[DONE]`; running sessions = replay then live. Developable now against a mocked v1 stream (the wire format is fixed by the shipped driver).

## Context

- Contract (ADR047 § D9 target shape + § D3 verbatim-forward): SSE with `x-vercel-ai-ui-message-stream: v1`; parts include `data-acp` (ACP plans/diffs/terminal mapped by the driver, `lego/agent-image/driver/src/session.mjs`); GET = replay+live, POST = live prompt turn; ticket in a header, re-minted per reconnect via `attach-ticket` (90s TTL) through `prepareReconnectToStreamRequest`.
- Version pin: driver is on the AI SDK **v6** line (`acp-ai-provider@0.2.9` + `ai@6.0.237`); dashboard pins `ai@6` + `@ai-sdk/react@3.x`; upgrade only in lockstep.
- AI Elements: shadcn registry, components copied in-repo (React 19 + Tailwind 4 — dashboard matches); hook-agnostic; strip any Next-isms. Candidates: Conversation, Message, Response, Reasoning, Task, Tool, CodeBlock, PromptInput.
- SSR: dynamic-import-in-effect pattern (`web-shell-terminal.tsx` precedent); the transport must only exist client-side.

## Steps

1. Add v6-line packages (exact pins); vendor the selected AI Elements under `src/common/components/ai-elements/`.
2. `lib/transport.ts`: transport with async ticket-header injection + `prepareReconnectToStreamRequest` re-mint via t001's attach hook; injectable fetch for tests (the `EventSourceFactory` precedent).
3. `components/session-conversation.tsx`: `useChat` wiring (`id: sessionId`, `resume` on mount), `dataPartSchemas` for `data-acp`, collapsible Reasoning/Task/Tool/Terminal groups (Devin "Worked/Thought" shape).
4. Mock harness: a test/dev fixture replaying a recorded v1 stream (running + terminal variants) so the column is fully developable before m43 is live.
