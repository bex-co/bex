## Objective

Operator-managed nightly backup for each disk: mount the PVC read-only, stream `tar | gzip | age` to the platform backup store, retain 7 dailies, purge on disk deletion (ADR082 D5).

## Context

- Template: `lego/operator/internal/controller/keyvalue_backup.go` — BackupStore contract, age encryption (`BEX_BACKUP_AGE_PUBLIC_KEY`), digest-pinned busybox, derived work budgets, `keyValueBackupRetention = 7`, purge annotation. Name pattern `dskbak-<app>` (kvbak- precedent, 63-char truncation helper).
- RWO co-mount: while the App pod runs, the backup pod needs required pod-affinity to it (same `kubernetes.io/hostname`); when scaled to 0/suspended, no constraint.
- Streaming (tar straight to upload) avoids the KV pipeline's 2S staging budget where possible; document whichever budget shape ships.
