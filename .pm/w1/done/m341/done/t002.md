## Objective

Resolve the repo (`--repo`, else the `--remote` URL, default `origin`, `github.com/OWNER/REPO` over HTTPS or SSH); print branch, base commit, diffstat and the first 20 untracked files; confirm on a TTY or require `--confirm`; `git push <remote> <commit>:refs/heads/bex-agent/handoff-<8hex>` with the developer's credential; then create the session with `branch` = that ref, the task (words or `-f`) and every `run` flag, `--notes FILE` uploaded as an attachment, idempotency key `handoff:<sha>:<sha256(task)[:16]>`; on a refused create delete the pushed branch and report both outcomes. `--chat`/`--wait`/`--follow` as on `run`. `-o json` prints `{branch, commit, session}`.
