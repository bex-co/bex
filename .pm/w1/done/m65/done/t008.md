## Objective

Close two resource-exhaustion findings on public operator listeners (both CWE-400).

- **F6:** the PG and KV SNI proxies launch a goroutine per accepted socket; after SNI routing the read deadline is cleared, a backend connection is opened before DB auth, and bidirectional copy can idle indefinitely — no global/per-source/per-route limit.
- **F12:** every static-server cache miss buffers an object up to 32 MiB with no singleflight, concurrency gate, or aggregate in-flight byte budget, and the HTTP server has no write/idle timeout.

## Context

- `lego/operator/cmd/pg-sni-proxy/main.go:322-446` — accept loop → `go handleConn`, no admission before backend dial.
- `lego/operator/cmd/kv-sni-proxy/main.go:253-310` — same shape.
- `lego/operator/config/pg-sni-proxy/daemonset.yaml:70`, `.../kv-sni-proxy/daemonset.yaml:58` — constrained pod resources.
- `lego/operator/internal/staticserver/staticserver.go:186-198`, `:319-330`; `internal/staticserver/cache.go:21-55`; `cmd/staticserver/main.go:125-129` — uncoalesced miss fetches; cache budget applies only after fetch; no server timeouts.
- Report: report.md Findings 6 and 12.

## Steps

1. **Proxies:** enforce global + per-source (+ per-route) connection admission before allocating a goroutine / opening a backend connection; reject overload immediately; retain negotiation deadlines and add idle + max-lifetime budgets on routed connections.
2. **Static server:** coalesce fetches per object (singleflight), add global + per-site fetch semaphores plus an aggregate in-flight byte budget, and set write/idle/read-header timeouts with overload rejection; stream/spill large objects where feasible.
