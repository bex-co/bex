## Objective

Close Finding 5 (race-condition, CWE-362): the activator cache stores pointers to Kubernetes App objects and returns them after releasing its lock. Every public request to a sleeping app calls `wakeApp`, which mutates the shared annotations map. Concurrent handlers can trigger a fatal concurrent-map runtime error, crashing the single shared activator replica — an unauthenticated cross-tenant availability hit.

## Context

- `lego/operator/cmd/activator/main.go:119-156` — cache lookup returns a shared pointer; `wakeApp` takes `base := app.DeepCopy()` but then mutates `app.Annotations` (the cache-owned object) directly.
- `lego/operator/cmd/activator/main.go:359-399` — concurrent public handler path.
- `lego/operator/config/activator/deployment.yaml:7` — single replica.
- Report: report.md Finding 5.

## Steps

1. Return an immutable copy from the cache (DeepCopy while holding the read lock) or construct the wake patch exclusively from a private copy — never mutate the cache-owned object.
2. Coalesce wake operations per App (singleflight or a keyed lock) so concurrent requests to the same sleeping app issue one patch.
3. Add a race-enabled concurrent-handler test.
