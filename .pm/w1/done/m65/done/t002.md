## Objective

Close Finding 2 (authorization / IDOR, CWE-639): the GitHub connect callback accepts an arbitrary numeric `installation_id` and treats an App-JWT `GetInstallation` lookup as ownership proof. Because the shared App can see every installation of itself, a workspace admin can bind another customer's installation and mint tokens for its private repositories. Require a GitHub principal proof and a unique installation→workspace binding before persistence.

## Context

- `lego/backend/internal/github/rest.go:85-100` — callback entrypoint (accepts the numeric installation id; `can_manage` on the destination workspace is checked, but nothing binds the id to the caller's GitHub authority).
- `lego/backend/internal/github/service.go:151-170` — `GetInstallation` (App-JWT) result is passed straight into `UpsertGitConnection`.
- `lego/backend/internal/github/client.go:155-174` — App-JWT installation lookup (existence only).
- Report: report.md Finding 2.

## Steps

1. Require a GitHub **user OAuth** principal that is authorized to administer the installation (verify via the user's own token, e.g. list-user-installations / installation admin check) — treat the App-JWT lookup strictly as existence validation, never caller ownership.
2. Bind the pending connect `state` server-side to that GitHub principal + destination workspace and make it single-use.
3. Enforce a unique installation-ownership (or explicit transfer) invariant before `UpsertGitConnection` persists a `(workspace, installation)` row.
4. On failure, reject the callback without mutating either workspace's connection.

## Acceptance criteria

- [ ] Connecting an installation administered by a **different** GitHub user is rejected — asserted by test — with no change to either workspace connection.
- [ ] Pending connect state is workspace + principal bound and single-use.
- [ ] A second workspace cannot silently claim an already-bound installation (unique binding / explicit transfer only).
- [ ] Legitimate connect flow for the caller's own installation still succeeds; backend suite green.
