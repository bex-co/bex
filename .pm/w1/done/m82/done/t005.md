## Objective

Add meaningful tests asserting the behaviors this milestone shipped and their
failure modes. Tests must assert real behavior and fail on the pre-fix code.

## Context

- Behaviors to cover:
  - **t001 (backend):** inviting an email that is already an active member is
    refused with the coded "already a member" error and the member's role is
    **unchanged** — demonstrated red on the pre-fix code (which downgraded an
    Admin to the invited role). Redeeming a pending invite for an existing
    member does not change their role (defense-in-depth). A genuinely new
    invitee still joins with the invited role. Seat usage unaffected by a
    refused invite. Prefer a real-Postgres store test for the
    `redeemInvite`/`ON CONFLICT` path plus a members-service test for the
    invite-time guard.
  - **t002 (dashboard):** the invite dialog blocks/handles `not-an-email`
    (Send disabled or inline hint), and a server-rejected invite surfaces the
    specific reason.

## Steps

1. Write the tests above, each demonstrated red against the pre-fix code where
   feasible.
2. Run the relevant suites (`cd lego/backend && go test ./...`; `dashboard`
   `yarn test` + typecheck).
