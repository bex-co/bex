## Objective

Close Finding 10 (incomplete-cleanup, CWE-459) at root cause and fix the live data bug the scan under-rated: `SetSecretFile` is the only one of seven call sites in `lego/backend/internal/secrets/files.go` that does not canonicalize `service` through `storeServiceName(a, service)`. A `PUT …/secret-files/{name}` addressed by the stable `srv-…` id (or by a store-managed App's tenant-prefixed Kubernetes name) writes to `services/<raw>/files`, which no read, delete, or purge path ever consults — the file materializes into the pod once, then is invisible to `GET`/`LIST`/`DELETE` and survives service deletion, recoverable later by creating a service whose name equals the old id.

## Context

- `lego/backend/internal/secrets/files.go:135-155` — `SetSecretFile`: `AuthorizeApp` → `withTenant` → `readMap(filesPath(service))` with **no** `service = storeServiceName(a, service)`.
- Sibling call sites that do canonicalize: `files.go:64` (List), `:115` (Get), `:172`, `:212`, `:275`, `:319`; plus `secrets/service.go:140,218,267,303,340` and `secrets/batch.go:93`.
- `lego/backend/internal/secrets/service.go:85-93` — `storeServiceName` returns `a.Labels[core.LabelServiceName]` when present, else the caller's token.
- `lego/backend/internal/secrets/purger.go:84-97` — `PurgeApp` purges `storeServiceName(a, a.Name)` only.
- `lego/backend/internal/store/api.go:616-627` — id shape (`srv-<xid>`, DNS-safe, under the 30-char service-name limit ⇒ a later service may legally take that name).
- Report: report.md Finding 10.

## Steps

1. Assign `service = storeServiceName(a, service)` immediately after `AuthorizeApp` in `SetSecretFile`, matching every sibling.
2. Audit the whole `secrets` package for any other post-authorization use of the raw caller token as a storage key; fix the same way (this is a divergence class, not one line).
3. Extend `PurgeApp` to also purge the legacy id-keyed path (`core.LabelAppID`) so paths written before this fix cannot be recovered by a later same-named service.
4. Add regression tests (below) that fail on the pre-fix code.
