## Objective

Close Finding 9 (SSRF, CWE-918): the outbound-webhook client clones `http.DefaultTransport` and replaces only `DialContext`, so `ProxyFromEnvironment` survives. With `HTTP_PROXY`/`HTTPS_PROXY` set in the process environment, `netutil.SafeDialContext` validates the *proxy's* address while the proxy resolves and fetches the tenant-controlled target — the private/link-local/metadata guard is bypassed without ever being consulted.

## Context

- `lego/backend/internal/webhooks/worker.go:186-202` — `defaultClient`: `tr := http.DefaultTransport.(*http.Transport).Clone()`, then only `tr.DialContext` is replaced.
- `lego/types/netutil/ssrf.go:34-95` — `SafeDialContext`, the dial-time destination policy.
- No proxy variable is set in the tracked deployment, so this is latent — but the security policy is implemented at dial time and must not be defeatable by process env.
- Sweep for sibling transports with the same shape (any other `DefaultTransport.Clone()` whose only guard is a custom dialer).
- Report: report.md Finding 9.

## Steps

1. Set `tr.Proxy = nil` on the webhook transport, with a comment naming the invariant (dial-time policy ⇒ no ambient proxy).
2. Grep the backend + operator for other `http.DefaultTransport…Clone()` sites paired with `SafeDialContext` and apply the same treatment where the security policy is dial-time.
3. Add a test that sets `HTTP_PROXY`/`HTTPS_PROXY` and asserts a private-range/metadata webhook target is refused before any proxy connection.
