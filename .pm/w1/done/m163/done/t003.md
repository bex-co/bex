## Objective

A static site whose newest build failed or is still running must still honor suspend (stop serving, bex's suspended response) and resume (serve the last published revision) without waiting for a new successful build.

- `w2/m98` shipped the suspended-web-service response; check which projection a suspended static site uses today.

## Steps

3. Envtest for suspend then resume over a `build_failed` newest release.
