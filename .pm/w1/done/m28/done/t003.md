## Objective

Add a CI workflow that runs `yarn typecheck && yarn lint && yarn test` on every PR and push touching `dashboard/**` — today the dashboard has no CI workflow at all.

## Context

- `dashboard/CLAUDE.md`'s Development commands: `yarn typecheck` (generate-routes + tsc -b), `yarn lint` (typecheck + eslint), `yarn test` (Vitest).
- `yarn codegen` needs `CODEGEN_SESSION_TOKEN` per `dashboard/CLAUDE.md` — but typecheck/lint/test don't regenerate GraphQL codegen from a live bex-api, they run against the already-committed `src/graphql/definitions.ts`, so this workflow needs no bex-api credential.

## Steps

1. Create a new workflow file that checks out, sets up Node + Yarn, installs deps, and runs `yarn typecheck && yarn lint && yarn test` in `dashboard/`.
2. Trigger on `pull_request`/`push` to `main` with `paths: ["dashboard/**", ...]`.
3. Confirm it runs green against current `main`.

## Files

- new `.github/workflows/dashboard-test.yml`

## Acceptance criteria

- [ ] Workflow runs typecheck+lint+test in `dashboard/` and passes against current `main`.

## Out of scope

- `yarn build` as a separate CI check — `deploy.yml`'s Docker build already exercises the production build path; redundant here.
