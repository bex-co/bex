## Objective

Introduce a neutral `ServicePatch` value type (presence-aware optional fields for every PATCH-able service setting) and one `(s *Service) ApplyServicePatch(ctx, id string, p ServicePatch) (AppView, error)` holding the single ordered op table on `core.PatchOps` — the order REST applies today (`rest.go` `patchService`), which MCP's comment already declares canonical.

- REST table: `lego/backend/internal/apps/rest.go:864-942` (19 `addOp` calls + hand-written runner).

- `core.PatchOps` precedent users: `environments/mcp.go:149`, `projects/mcp.go:127`.
- Known divergences to preserve, not resolve: `notificationsToSend` + `autoscaling` (MCP-only today), `repo/image/imageOwnerId` + maintenance-before-plan-on-free-downgrade reorder (REST-only today). Model them as fields the respective adapter simply doesn't fill, with a comment naming each divergence.
