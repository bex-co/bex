## Objective

Enumerate every operator or platform path that deletes a pod while it may still receive traffic. Confirm t001's drain covers each one, or say why a path is exempt. Prove the controls are unchanged.

## Context

- **Probed at filing:** a config-change roll only (m154 README § Evidence).
- **Traced, not probed:**
  - deploy roll;
  - manual Restart (`w6/done/m51` recorded it as a "non-issue" with unrecorded sampling);
  - manual scale-in (`POST …/scale`);
  - autoscaler scale-in;
  - node drain and Cluster Autoscaler consolidation (`docs/ADR004-app-deployment.md` § Rollout headroom);
  - hibernation's scale-to-0 (`shouldAutoHibernate` / `ingressBackend`, `app_controller.go:1942-1951`, `:2314-2323`);
  - suspend;
  - maintenance mode (routing switches while pods keep running).
- **Private services.** In-cluster callers reach private services through the ClusterIP Service and kube-proxy (`applyClusterIPService`, `app_controller.go:2492`), which has the same endpoint-propagation race.
- **Controls:**
  - disk-attached services use `Recreate` (`deployment_projection.go:336-337`), with documented downtime;
  - workers take no inbound traffic;
  - cron and pre-deploy Jobs;
  - static sites (the shared static-server).

## Steps

1. **Enumerate the paths.** Grep the operator for every write that lowers replicas, deletes pods, or changes the pod template. List them with `file:line`, and mark each covered, exempt (with the reason) or needing work.
2. **Probe live** on throwaway services, at ≤ 1 s sampling under constant traffic:
   - a manual Restart;
   - a manual scale 2 → 1 (only if the plan allows it without a purchase; otherwise note it as plan-gated);
   - a private service called in a loop from a sibling web service during a config-change roll.
3. **Check hibernation ordering.** The Ingress must switch to the activator before the last pod's drain starts, so a waking request never waits on a draining pod.
4. **Decide for workers.** Apply the drain uniformly, or skip it because workers have no traffic. Record the choice.
