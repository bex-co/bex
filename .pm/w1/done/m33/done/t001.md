## Objective

Add an optional `PreDeployCommand` field to `AppSpec`, the command to run to completion before a new revision's containers start.

## Context

- `lego/types/v1alpha1/app_types.go` — `AppSpec` currently has no pre-deploy/setup-step concept.
- `docs/ADR006-bex-api.md:124` documents `preDeployCommand` as an ignored bex.yml field today.
- `w6/m21` (build/start command override) added `DockerfilePath`/`StartCommand` — follow the same field-addition pattern (kubebuilder markers, doc comment distinguishing this from `StartCommand`: this runs once before rollout, not as the running process).

## Steps

1. Add `PreDeployCommand string` (optional, shell-word-split like `StartCommand`) to `AppSpec` with a kubebuilder marker and doc comment.
2. Regenerate deepcopy (`make generate` from `lego/operator/`) and CRD yaml (`make manifests`).
