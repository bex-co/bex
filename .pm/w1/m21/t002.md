## Objective

Serve the built static output publicly from the object-store/CDN origin at the app's URL, honoring `publishPath`, plus the static-site-only edge rules: `/routes` redirects/rewrites and `/headers` custom response headers.

## Context

- Traefik fronts app traffic (cert-manager TLS, `*.onbex.co`); serving static content means routing the app host to the object-store origin with the edge rules applied at the proxy.
- `.pm/DO_NOT_DO.md` line 23 parks these edge rules as non-goals **until `w1/012` is promoted** — which it now is, so they are in-scope here.
- Render semantics: redirects (301/302) + rewrites (200 path swap), ordered; custom response headers scoped by path.

## Steps

1. Route the app host(s) to the object-store origin for static sites (Traefik middleware / ingress), serving `publishPath` as the doc root.
2. Implement `/routes` redirects + rewrites (ordered, first-match) at the edge.
3. Implement `/headers` custom response headers scoped by path pattern.

## Files

- `lego/operator/internal/controller/…` (serving/ingress wiring)
- Traefik middleware config as needed

## Acceptance criteria

- [ ] `curl` the app URL returns the built `index.html`; a configured redirect returns 301/302 to the target; a rewrite serves the rewritten path with 200; a configured header appears in the response.
- [ ] SPA fallback (rewrite `/*` → `/index.html`) works.
