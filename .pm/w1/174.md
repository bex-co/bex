# A shell that fails says why, in Render's words: no /bin/sh, a launch failure, or a lost connection

Why: bex's gateway tells every failed exec "unable to start a shell in this image", even a session that ran for an hour and then lost its stream, and the dashboard prints that English text in every language.

- **Found:** `/pm-brainstorm one aspect of render parity to w1` (2026-11-26), item 4, verified before filing.
- **Render:** from its public dashboard bundle (entry `index-D5V4ZgbE.js`, chunk `ServiceShellStarter`).
  - It matches `stat /bin/sh: no such file or directory` and `exec: "/bin/sh": executable file not found` in the stream's status frame. It ends with "This image has no /bin/sh, so the shell can't start." (critical).
  - A `startShell` that answers nothing ends with "The shell couldn't start.".
  - A failed `startShell` call shows "We were unable to launch your shell. Try refreshing the page or manually deploying your service again." with `Error: {message}` under it.
- **bex:**
  - `lego/backend/internal/sshgateway/webshell/websocket.go:461` sends `ws.fail("unable to start a shell in this image")`, with no `reason`, for every executor error that is not a stopped or unready pod, a cancel or a time limit.
  - That includes an API stream that fails after the shell has run for a while: `KubeExecutor.Execute` returns the stream's error whenever it happens (`lego/backend/internal/sshgateway/exec.go:198-222`).
  - The dashboard shows that `message` as-is, in English, under "Connection error" (`dashboard/src/common/components/shell-terminal.tsx:249-256`).
  - Native SSH writes "unable to start /bin/sh in this image" (`nativessh/session.go:191`). w6/m132 t002 saw it for `traefik/whoami`.
- **Do:**
  - The gateway gives that error frame a `reason`:
    - `no_shell` when the error matches Render's two patterns;
    - `stream_lost` when the shell had already written output;
    - `start_failed` otherwise.
  - The dashboard shows Render's sentences for `no_shell` and `start_failed`, and Render's "The shell disconnected." for `stream_lost`, in all eight locales. [w1/m692](m692/README.md) retries `stream_lost`.
  - Native SSH keeps its line.
- **Done when:**
  - Gateway tests drive a fake executor with each pattern, with an error after output and with an error before output.
  - Dashboard tests cover the three sentences.
  - `cd lego/backend && go test ./internal/sshgateway/...` and `dashboard/yarn lint` + `yarn test` pass.
