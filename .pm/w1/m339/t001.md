## Objective

Accept `https://<dashboard>/agents/ags-…` (and the configured dashboard origin) wherever a session id is taken. Add `list --mine --created-by (repeatable, ≤ 20) --automation <automation> --parent <session> --phase --since --until` mapped to the API's `mine`, `createdBy`, `automationId`, `parentSessionId`, `phase`, `createdAfter`, `createdBefore`; `--since/--until` take RFC 3339 or a duration like `24h`/`7d`. Add `run --parent <session>` (`parentSessionId`, ADR102).

## Context

- Design and full CLI spec: `docs/ADR106-cli-cloud-agents-automations.md` (+ `.svg`).
- Shipped group to extend: `lego/cli/internal/agent/` (`agent.go` commands and exit codes, `api.go` REST client, `render.go` text output, `watch.go` polling waits, `types.go` hand-decoded shapes).
- Constraints: the CLI imports no sibling module (thin client, every rule stays in bex-api); never touch the imported Render command tree; `.pm/DO_NOT_DO.md` #APPROVAL-MODE (no permission prompts, no `needs_input`, no agent→user channel).
- List filters parsed in `lego/backend/internal/agentsessions/rest.go` `GET /v1/agent-sessions`.
- `parentSessionId` on create: `service.go` (authorizeParent).
