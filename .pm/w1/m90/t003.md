## Objective

Stop the recents list and the sidebar rail from rendering separators around values that are not there.

## Context

- `session-list.tsx:239-241` emits `{" · "}{s.repo}{" · "}` unconditionally, so a repo-less row renders `Working… · ·`. Confirmed live in `dev-1` on two separate sessions.
- `session-list.tsx:298` has the same shape with repo **and** branch: `{s.repo} · <span className="font-mono">{s.branch}</span> · `.
- The row title already uses the task text, so after t001 it should use the same derived name the header does rather than its own copy of that logic.

## Steps

1. Build the meta line from the non-empty parts and join with the separator, instead of interleaving separators with possibly-empty values.
2. Point the row title at the t001 derived name so the list and the detail header agree.
3. Apply to both call sites, and to `agent-sessions-nav-section.tsx` if it renders the same meta shape.
