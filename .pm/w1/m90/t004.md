## Objective

Make a session tab identifiable when several are open — today every one of them is titled "Session".

## Context

- `/agents/$agentSessionId` sets a static translated title; the browser tab reads `Session ・ bex Dashboard` for every session. Observed in `dev-1`.
- The breadcrumb on the detail route shows only the workspace, so nothing on screen or in the tab strip names the session.
- Other detail routes in this dashboard already title themselves after the resource — follow that existing pattern rather than inventing one.

## Steps

1. Feed the t001 display name into the route's `head`, keeping the ` ・ bex Dashboard` suffix.
2. Keep the static string as the fallback while the session is still loading, so the pending state does not flash an empty title.
3. Add the session to the breadcrumb trail if that matches the convention the other detail routes use.

## Files

- `dashboard/src/routes/agents_.$agentSessionId.tsx`

## Acceptance criteria

- [ ] Two sessions open in two tabs have distinguishable tab titles.
- [ ] The pending state shows the fallback, never an empty or `undefined` title.
- [ ] A test asserts the resolved title for a repo-less and a repo-backed session.

## Out of scope
