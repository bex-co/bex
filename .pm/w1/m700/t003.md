## Objective

Make the main button run the first choice when the service has auto-deploy on, and "Save only" when it is off. An environment group's main button runs its first choice when any linked service that is not suspended has auto-deploy on.

## Context

- Render's `St`: `autoDeploy ? options[0].id : "no-deploy"`. The service page passes `autoDeploy: t.autoDeploy===true`.
- bex's main button is "Save and deploy" for every service (`service-environment-editor.tsx:1192-1253`).
- The service's `autoDeploy` comes from `useServer` (`dashboard/src/features/services/types.ts`).
- The env group page already lists its linked services; read each one's `autoDeploy` and suspended state from what it loads, or add them to its query.
- [w10/m375](../../w10/blocked/m375/README.md) is making the stored `autoDeploy` read what will actually happen. This task reads that value and does not change it.

## Steps

1. Pick the main choice by Render's rule for services and environment groups.
2. Keep the other choices in the menu in Render's order.
