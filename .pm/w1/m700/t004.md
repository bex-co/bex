## Objective

Give the build source's Environment tab Render's two choices. "Save and rebuild" saves the variables and starts one build of the build source.

## Context

- Render: an `ArtifactSource` (its Build Source) gets "Save and rebuild" / "Save only", defaulting to "Save only".
- bex's tab (`dashboard/src/features/build-sources/components/build-source-environment-tab.tsx:110-118`) passes `saveOnly` with the label `buildSources.settingsSaveButton`.
- The backend refuses any mode but Save only for a build source (`lego/backend/internal/secrets/batch.go:114-117`). Its comment says this matches Render, which the bundle contradicts.
- A service's rebuild already saves as Save only and then triggers one deploy, retrying only that step after a partial failure (w4/347). Reuse that shape with the build source's own build trigger ([ADR097](../../../docs/ADR097-build-sources.md)).

## Steps

1. Backend: accept `rebuild` for a build source. Save as Save only, then start one build of the build source, retrying only the build step after a partial failure. Keep refusing `deploy`, and correct the comment.
2. Expose the mode on REST, GraphQL and MCP wherever a build source's environment is saved, with the same errors.
3. Dashboard: "Save and rebuild" and "Save only", with "Save only" as the main button.
4. Amend ADR097 and ADR018's build source row: a build source's environment saves with or without a rebuild, as on Render.

## Files

- `lego/backend/internal/secrets/batch.go` and its tests
- the build source's REST, GraphQL and MCP handlers
- `dashboard/src/features/build-sources/components/build-source-environment-tab.tsx`, `dashboard/src/features/build-sources/locales/en.ts`
- `docs/ADR097-build-sources.md`, `docs/ADR018/`

## Acceptance criteria

- [ ] A backend test saves a build source's environment with `rebuild` and sees one build start; `deploy` is still refused.
- [ ] A dashboard test shows the two choices with "Save only" as the main button.

## Out of scope

- What the build fans out to its linked services, which stays as ADR097 defines it.
