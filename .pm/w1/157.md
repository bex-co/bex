# Cron job rollback: Render's dashboard has no rollback page for one

Why: bex's cron Deploys rows offer Rollback (and, since w1/m646, its Confirm Rollback page), but Render's cron deploy page (`CronJobDeployContainer-*.js`) has no rollback route, so bex may offer a cron action Render's dashboard does not.

- **Evidence:** Render's public dashboard bundle, read 2026-11-26 for w1/m646: `DeployContainer-*.js` holds the `Confirm Rollback` section and the deploy page's Rollback control, and `CronJobDeployContainer-*.js` has neither (no `rollback` string). Render's `POST /services/{id}/rollback` does not say whether a cron job is accepted.
- **Check:** whether Render's API rolls back a cron job (a disposable cron job in a Render workspace bex owns, or the API reference), and whether its cron Deploys list shows Rollback.
- **Then:** if Render offers no cron rollback anywhere, hide bex's cron Rollback in the dashboard and answer the API as Render does; if its API accepts one, keep the verb and record the dashboard difference in `docs/ADR018/deploys.md`.
- **Done when:** ADR018's Rollback row states what Render does for a cron job, and bex's dashboard and API match it.
