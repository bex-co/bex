## Objective

Prove the milestone's definition of done end-to-end: a full roll of bex-api + dashboard under continuous load produces zero user-visible errors, twice in a row.

## Context

- Load shape mirrors the incident: an authenticated API request loop (the GraphQL `project` read + a `setProjectServices` full-replace write, which is idempotent and safe to loop) and repeated full-page dashboard loads (`/project/$projectId` and a service page).
- Run first against dev-1 / the mock cluster; the final evidence run rides a real prod `deploy.yml` roll (or a manual `kubectl rollout restart` of both Deployments on prod at a quiet hour).
- Evidence home: this task's notes + the milestone README at closeout (timestamps, request counts, failure counts, pod transition timeline from `kubectl get events`).

## Steps

1. Script the load loop (curl against the API with the CLI credential; full-page loads with a session cookie or plain `curl -L` on a public page + an authenticated Playwright pass for the loader path).
2. Roll bex-api, then the dashboard, then both together; record failures.
3. Repeat once (two consecutive clean rolls per the DoD).
4. Hold a browser on `/project/$projectId` through a roll; confirm self-recovery without reload.

## Files

- `scripts/` (a small throwaway or committed `roll-verify.sh` — decide by whether it earns a place beside `scripts/*-verify.sh`)
- Evidence in `.pm/w1/m52/` notes

- [ ] Two consecutive rolls of both Deployments under the load loop: zero non-2xx, zero error-page HTML bodies.
- [ ] A browser held open through a roll self-recovers to data with a correct title, no manual reload.
- [ ] Evidence recorded (counts + timeline).
