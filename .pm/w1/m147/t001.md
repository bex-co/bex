## Objective

Make the service bulk patch obey ADR066 #6's contract: the quota is checked inside the CAS mutate, re-checked on every retry, and applied before any write, exactly as its siblings already do.

## Context

- `lego/backend/internal/secrets/batch.go:191-243` (`patchEnvironmentSparse`): the env mutate at `:196-204` and the files mutate at `:212-219`. `:111-177` (`patchEnvironmentCAS`): env applied at `:144`.
- Pattern to copy: `lego/backend/internal/secrets/files.go:178-190` (`quota = err; return false` inside `updateMapCAS`), and `service.go:455-466` (blueprint seeding checks before `storeMap`).
- Env-group sibling that already does it: `lego/backend/internal/envgroups/patch.go:186-189`.
- Live evidence: m147 README § Evidence 2.

## Steps

1. In both mutates of `patchEnvironmentSparse`, after `apply*Patch`, run the matching `*MapWithinQuota(current)`. On error, stash it and return `false` (no write). Surface it the way `applyErr` is surfaced, restoring the env map if the files quota fails after the env write.
2. In `patchEnvironmentCAS`, check `envMapWithinQuota(env)` before the versioned write.
3. The error stays `core.ErrBadRequest`, so REST/GraphQL/MCP map it to 400 / `bad request:` unchanged.
