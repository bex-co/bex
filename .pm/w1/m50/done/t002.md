## Objective

Make the interactive bandwidth reads (`Metrics(BANDWIDTH)` and `MonthToDateBandwidth`) serve data on a churning production cluster: stop erroring the entire window when a source's window-wide health product fails, while leaving the usage-metering rollup's strict gate byte-identical.

## Context

- Today `NewPrometheusRequestSource` (`internal/metrics/source.go:110-129`) and the month-to-date path (`:311-323`) run `egressquery.Health(spec, windowSeconds)` per source and return `egress source X unhealthy` if the product < 1 — all-or-nothing at window scope.
- The sum query (`egressquery.SumRates`, `internal/egressquery/query.go:151-160`) is three `sum(rate(...)) or vector(0)` terms; `rate()`/`increase()` already handle counter resets conservatively (they can lose the pre-reset delta, never invent bytes) — acceptable for a chart, not for billing.
- Candidate shapes (decide in-task, record in the t001 ADR section):
  - **(a) per-bucket gating:** evaluate health at resolution granularity (`Health` terms as range vectors over the step instead of the window) and null out only unhealthy buckets;
  - **(b) degraded-not-fatal:** keep the window-wide check but on failure serve the series anyway and mark the source degraded (pairs with t003);
  - **(c) drop-the-source:** exclude only the unhealthy source's term from the sum and mark it degraded.
  - Shape (b) is the smallest and never blanks the chart; (a) is the most honest. Weigh implementation cost against the DoD (chart renders through a mid-window meter roll AND deploy reset).
- The usage rollup (ADR023 hourly pipeline) must keep calling the strict gate — find its call sites and pin them unchanged with a test (the DoD requires byte-identical rollup numbers).
- One core verb serves REST/GraphQL/MCP — change it once, all three surfaces follow (`internal/api/CLAUDE.md`).

## Steps

1. Split the health usage: a `HealthPolicy` (strict | bestEffort) or two entry points, so the metrics read path and the usage rollup stop sharing one behavior.
2. Implement the chosen shape for `Metrics(BANDWIDTH)` and `MonthToDateBandwidth`; the verb never returns `egress source X unhealthy` to interactive callers.
3. Write the short design note in the t001 ADR section (which shape and why).
4. Unit tests against a fake Prometheus: mid-window `up` gap, mid-window counter reset, healthy window — chart data comes back in all three; rollup path still refuses the first two.
