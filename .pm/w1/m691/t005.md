## Objective

The copy-ready `ssh` command on the Shell page connects to the instance the page shows, as Render's does.

## Context

- `dashboard/src/features/services/components/service-shell-page.tsx:43` builds `ssh ${service.sshAddress}`.
- `sshAddress` is `srv-…@host` (`lego/backend/internal/apps/service.go:1396`).
- The gateway takes a complete instance id as the user ([ADR035](../../../docs/ADR035-ssh.md) step 5).
- Render builds `${serviceId}-${instance}@ssh.${region}.render.com` from the URL's instance.

## Steps

1. Build `ssh {instanceId}@{host}` from the selected instance and the host in `sshAddress`. Keep the bare address while no instance is selected.
2. Keep the gates that already decide whether the command shows: `RequiresSshKey`, and the shell decision's refusal.
