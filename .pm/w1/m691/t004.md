## Objective

When the instance asked for is not there, the Shell says so and names the instance it connected to instead, as Render's does.

## Context

- Render raises the toast in two cases: the URL's instance is not running when the page loads, or the selected instance's `startShell` answers `instance not found`. In both, it selects the first remaining running instance and refetches the list.
- bex refuses a ticket for an instance that has gone as `instance_gone` (`lego/backend/internal/apps/service.go:2016`). The gateway ends a stream whose pod stopped with the same reason (`lego/backend/internal/sshgateway/webshell/websocket.go:450-457`).

## Steps

1. Treat a ticket refusal or start error naming `instance_gone` for the selected instance as Render's `instance not found`. Drop that instance, select the first remaining running one, and refetch.
2. Toast "**{instance} is not available.**" followed by "Now connected to {instance}." when there is one to connect to. Use the info style, with no auto-dismiss.
3. Add the strings in all eight locales.
