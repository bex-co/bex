## Objective

Show the environment's env groups and its inbound IP rules on the settings page, as Render does.

## Context

- Render's Environment Groups card: a searchable table and a New Env Group button.

## Steps

1. Build the Environment Groups card (search, table, New Env Group to the create flow w1/m684 serves).
2. Mount the existing IP-rules editor with its Scale gate.
3. Leave out Render's Dedicated Static IPs card (bex hosts no dedicated IPs) and record that in t009.

## Files

- the new settings route's Environment Groups and Networking cards

## Acceptance criteria

- [x] The env groups in the environment are listed and searchable; IP rules edit as today, gated on Scale.

`EnvironmentEnvGroupsCard` (New Env Group opens the create dialog with the environment chosen until w1/m684) and `EnvironmentNetworkingCard` (the shared IP rules editor; below Scale its reset to allow all). Dedicated IPs are a recorded non-goal, so Render's card has no counterpart (t009).
