## Objective

Fix three small defects found in the live walk:

- The Credentials menu opens with focus on "Disconnect bex-co".
- The agent composer's secondary link goes to a page without the GitHub card.
- The repo list can stay stale after a new account is connected.

## Context

- **Focus (Finding 4).** `dashboard/src/features/git/components/git-credentials-menu.tsx` passes no `onOpenAutoFocus`. Radix FocusScope auto-focuses the first tabbable element but skips links (`removeLinks` in `@radix-ui/react-focus-scope`). Each row's account name and Configure entry are `<a>` elements, so the first control it can focus is the Disconnect button.
- **Settings link (Finding 5).** `dashboard/src/features/agent-sessions/components/new-session-composer.tsx` links "Workspace settings" to `/workspace/settings`. That route (`dashboard/src/routes/workspace.settings.tsx`) has no GitHub card; `ConnectGithubCard` is mounted only on `/settings`.
- **Repo refresh (Finding 7).** The connections query polls (`use-git-connection.ts`, `pollInterval`), but `dashboard/src/features/services/hooks/use-repos.ts` refetches only on window focus. A new account's row can therefore appear while its repos don't.

## Steps

1. Give the Credentials menu an `onOpenAutoFocus` that focuses the panel or the connect action, never a Disconnect button.
2. Point the composer's secondary link at `/settings` with hash `integrations` and relabel it, for example "GitHub settings", in all 8 agent-sessions locales.
3. In the source picker and the Credentials menu, refetch repos whenever the set of connected installation ids changes, in addition to on focus.
