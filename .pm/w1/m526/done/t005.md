## Objective

Every starting point offers one connect action that starts t002's chooser-mode flow. Pages holding unsaved input run the flow in a new tab. "Claim installed account" disappears as a separate button.

## Context

The starting points:

- **Account Settings → Integrations card:** `dashboard/src/features/git/components/connect-github-card.tsx`. The onboarding Getting started checklist links here (`dashboard/src/features/onboarding/components/getting-started-card.tsx:65`, `/settings#integrations`).
- **Source picker, disconnected state:** the "Connect GitHub" button in `dashboard/src/features/services/components/service-source-picker.tsx:109`.
- **Source picker, connected state:** the Credentials menu, `dashboard/src/features/git/components/git-credentials-menu.tsx`.
- **The pages hosting the source picker:**
  - `/services/new` for all five types (`dashboard/src/routes/services.new.tsx:180`);
  - `/blueprints/new` (`dashboard/src/routes/blueprints.new.tsx:381`);
  - Service Settings → Update Source (`dashboard/src/features/services/components/service-source-card.tsx:350`, on `/services/$serviceId/settings`).
- **Agent new-session composer callout:** `dashboard/src/features/agent-sessions/components/new-session-composer.tsx:543`. It connects in the same tab today and has no claim path.
- `dashboard/src/features/git/hooks/use-connect-git.ts` already pre-opens the new tab synchronously so popup blockers don't eat it. `use-claim-git.ts` navigates the current page (Finding 2).

## Steps

1. Add one hook that starts the chooser-mode claim with the selected workspace's `ownerId`. It takes a `newTab` option and pre-opens the tab like `use-connect-git.ts`.
2. Replace the connect and claim buttons in the four components with the single action:
   - Label it "Connect GitHub account" when nothing is connected, and "Connect another account" otherwise.
   - Use a new tab on the source-picker hosts and the agent composer; navigate the same tab on Account Settings.
3. Update all 8 locales of the git and agent-sessions features, and delete the keys this leaves unused (`git.claimButton`, `git.claimHint`, and others), so knip stays clean.
4. The callback still lands on `/settings`, where the chooser lives. The original tab refetches on return (and see t006).
