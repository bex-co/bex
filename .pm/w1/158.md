# The require-2FA and require-Google-login confirmations use Render's words

Why: w1/m647 matched Render's notice, members dialog and reminders word for word, but the confirmation before turning a requirement on, and the refusal when the admin does not meet it, still use w7/m471's and w22/m402's own words, so the same flow reads half Render's and half bex's.

- **Evidence:** [docs/render-artifacts/workspace-2fa-reminders.md § Turning it on](../../docs/render-artifacts/workspace-2fa-reminders.md#turning-it-on) (Render's dashboard bundle, read 2026-11-26). Render: title "Confirm two-factor authentication requirement across team" (Google: "Confirm single sign-on with Google requirement across team"), description "Members who do not have two-factor authentication enabled will **lose access** to the workspace and its resources." (nobody: "Members will need to enable two-factor authentication to access this team and its resources going forward."), heading "N members will be losing access to this workspace", button "Confirm and enforce". bex (`dashboard/src/features/workspaces/locales/en.ts`): "Require two-factor authentication in {workspace}?", its own description, and "Require".
- **Precondition:** Render checks the admin first and opens a dialog ("You do not have two-factor authentication enabled" / "You cannot enforce two-factor authentication for your team until you've enabled it for yourself." + "Go to settings"; Google: "You haven't signed in with Google" + "Sign in with Google") instead of opening the confirmation. bex opens the confirmation and shows its inline refusal (`WORKSPACE_2FA_ADMIN_NOT_ENROLLED`) after Require.
- **Keep:** bex's API key and SSH key lists in the confirmation (bex's gate blocks them; ADR012 §9c records it).
- **Files:** `dashboard/src/features/workspaces/components/workspace-login-requirement-card.tsx`, `login-requirement-impact-list.tsx`, the workspaces locales (8 languages), and the org Security card's confirmation if Render's org settings say otherwise.
- **Done when:** the workspace confirmation's title, description, count heading and button, and the precondition dialog, read as Render's in both requirements, with component tests, and ADR018's two enforcement rows no longer list it.
