## Objective

Cross every `buildFromSource` halt with every runtime transition that needs the Deployment or Ingress write, and record whether the new hold covers it, leaves it unchanged by design, or needs more work.

## Context

- **Halts.**
  - A recorded terminal failure (Build condition, or a legacy Ready marker).
  - A registry-credential wait.
  - The workspace or cluster build cap, including a shed overshoot.
  - A build waiting for capacity or running.
  - A fresh failure pass, which returns an error.
  - A missing repo (`BadSpec`).
- **Transitions.** Wake, auto-hibernate, suspend, resume, manual scale, autoscale, maintenance on or off, custom domains, and the IP allow-list.
- **Neighbours.** A disk restore, a canceled release, a source update pending, and a direct static publish.

## Steps

1. List each halt with its line and what it writes to status.
2. For each pair, name the test or the reasoning that proves the verdict.
3. Record the table in the m157 README.
