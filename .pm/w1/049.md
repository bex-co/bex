# 049 — Security-scan round 7: triage, fixes applied + deferred register

From the codex-security scan `codex-security-bex-5Zrt4l` (revision `bb1b8006`, the post-round-6 tree). 20 findings (2 high, 11 medium, 7 low), triaged same-day with three parallel source-to-sink investigators. **14 are re-reports** of items already fixed-pending-activation, deferred with dispositions, or accepted (both highs included); **6 are new**, of which 5 were fixed in place with tests and 1 deferred. Seventh audit in the ADR028 → m53 → m65 → m66+m67 → m68 → w1/048 lineage.

## Fixed in place this pass, with tests

- **#4 model credential in transcripts (medium — the headline).** The driver redacted the model API key from its local session log but published raw parts to the stream hub, and the gateway persists those bytes verbatim (`AppendAgentSessionTranscript`) — so with a live attacher the durable transcript could carry the key, and the Completer then skips the redacted-log harvest. Fixed at the single publication choke point: `session.ts`'s `publish` now routes through a new fail-closed `credentialManager.redactPart` before the hub, the `onPart` turn mirror, and hence the gateway tee. Fixture leak knob + tests assert no sink (hub history, turn mirror, session log) carries the key.
- **#11 blueprint manifest at `can_view` (medium).** `GetBlueprintByID`/`ListBlueprints` returned the stored manifest verbatim to viewers while `PreviewBlueprint` gates the identical content on `can_view_sensitive` — a read-around of the env-vars sensitivity gate for literal `envVars[].value`. Fixed with a quiet `core.Base.Can` probe (no audit-denial side effect) blanking `Manifest` below the sensitive-read role; metadata stays viewer-readable. Role-split test added.
- **#13 metrics budget bypass (medium) — closes `w4/029` #14.** `MaxQueryHours` was REST-adapter-local; GraphQL and MCP metrics fanned out over unbounded resources × metricTypes × quantiles. Window enforcement moved into the shared service (`Metrics`/`DatastoreMetrics`, mirroring logs' `checkWindow` from w9/004), plus `maxMetricsFanOut` (100 resource×metric pairs) across all three adapters, `maxLatencyQuantiles` (10), and malformed RFC3339 timestamps now 400 instead of silently falling back to the default window. Adapter-parity tests (REST + GraphQL + MCP) assert refusal before any backend read.
- **#9 pre-decode YAML allocation (medium).** The round-4 walk budgets ran only after `yaml.Decode` had materialized the full node graph (~100× amplification; ~200 MB from a 2 MiB body, reachable at `can_view`). Added `blueprintMaxManifestBytes` (512 KiB) checked before decode; `blueprintMaxScalarBytes` lowered to 256 KiB so a single-scalar breach still reports as a scalar breach. At-cap/over-cap tests added.
- **#14 SSRF special-purpose ranges (low → cleanup).** `UnsafeOriginIP` now denies the IANA special-purpose remainder the stdlib predicates miss (0/8 beyond 0.0.0.0, 192.0.0/24, TEST-NETs, 198.18/15, 240/4 incl. broadcast, 2001:db8::/32) **plus** the v6 transition prefixes the scan itself missed (NAT64 64:ff9b::/96, Teredo 2001::/32, 6to4 2002::/16 — each can embed a private v4 target). Deliberately NOT unified with egressmeter's `nonPublicPrefixes`: that list decides what is not billed, this one what may not be dialled.
- **#3 follow-up (no behavior change).** Contributor transcript read is the documented ADR054 boundary (kept), but `AttachTicket` was absent from the role-ladder pins — added to `representativeVerbRelations` (read branch) plus `TestAttachTicketRelationPerAction` pinning both action branches. Note: ADR054 D2's rationale ("attach never reveals credentials") only holds because #4 above is fixed.

## Deferred (1 new)

- **#5 unbounded Blueprint projects/environments (medium → low-medium).** Partially overstated: the action plan DOES run first (it just omits groupings), project lookup is a map not a scan, and the walk budgets cap a request at ~10–12.5k groupings (developer role required). Real residuals: no per-tenant grouping quota, no transaction (mid-loop failure persists partial rows), an unconditional per-grouping ACL write, grouping writes bypass the audit events, and `DisconnectBlueprint` never reclaims orphans. Belongs in the same per-workspace-quota bucket `048.md` deferred for webhooks; precedent for the fix shape is `w7/done/m72/t004` (exports maxItems + active cap). **Materialized 2026-08-16 as `w8/m20`** (transactional grouping writes + per-workspace quota + audit events + disconnect reclaim).
