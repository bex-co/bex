# w1/m49 simplify residuals (webhook pages)

Findings from the m49 `/simplify` pass (2026-07-17) judged not worth applying inside the milestone — each needs a second/third use case or touches files outside the diff. Revisit when the trigger fires.

- **Shared type-to-confirm delete dialog.** Three near-identical shapes now exist: `database-confirm-dialogs.tsx` (name match), `delete-service-card.tsx` (id match + optional dual confirm), `webhook-settings-card.tsx`'s `DeleteWebhookConfirm` (`delete webhook <name>` sudo command). Extract a `@/common/components/` base (input + disabled-gate state) when the next delete flow appears; keep the confirmation-text policy per-caller.
- **Shared long-date formatter.** `webhook-detail-header.tsx` formats `toLocaleDateString(undefined, {year,month:"long",day})` inline; the same shape repeats pre-existing in `workspace-details-card` and `registry-credential-row` (and `usage/lib/period.ts` has the month-year variant). A `formatLongDate()` in `@/common/lib/` would unify — touches files outside the m49 diff, so deferred.
- **Shared field block (Label + helper + Input).** The create page and webhook Settings repeat the `space-y-2` field pattern with differing props (autoFocus/placeholder/inputMode). Two call sites — premature; reconsider if a third webhook form appears.
- **Detail-shell data sharing consistency.** m49's `/webhook/$webhookId` shell shares its `useWebhook` result with child tabs via React context; the services/projects shells instead let each child re-fire its query and lean on Apollo dedup. Both work; pick one convention if a third detail shell arrives.
- **Backend-served event grouping (keys only).** The picker's group/label mapping is deliberately dashboard-side (labels must be i18n'd per language — a backend-served English label can't localize, and Render's grouping is presentation). If the vocabulary outgrows the catalog, the backend could serve group *keys* (`{type, groupKey}`) with labels still translated dashboard-side; today's 17-key vocabulary doesn't warrant the API change.
- **Set-equality / tri-state helpers.** `sameSet()` (webhook-settings-card) and `triState()` (event-picker) are single-use; extract to `@/common/lib/` only when a second hierarchical picker or set-dirty form shows up.
