## Objective

Collapse the service-scoped half of the setter grammar — the largest group — into one patch-shaped tool.

## Context

- Candidates (confirm against t001's mapping): `set_start_command`, `set_build_command`, `set_branch`, `set_root_directory`, `set_dockerfile_path`, `set_health_check_path`, `set_pre_deploy_command`, `set_display_name`, `set_max_shutdown_delay`, `set_auto_deploy`, `set_build_filter`, `set_notify_on_fail`, `set_notifications_to_send`, `set_maintenance_mode`, `set_subdomain_policy`, `set_service_ip_allow_list`, `set_registry_credential`, `set_autoscaling`.
- `internal/apps` holds 58 of the 213 tools; `internal/apps/mcp.go` is 1,207 lines.
- Each setter already delegates to a Service method that REST and GraphQL also call (`internal/api/server.go:18` documents the invariant). The fold is adapter-level: the Service methods do not change.
- `internal/apps/mcp.go:88` is the comment recording that this whole family is a bex invention — update it rather than leaving it describing a grammar that no longer exists.

## Steps

1. Extend `update_service`'s argument struct with one optional argument per folded field, reusing the existing `jsonschema` descriptions so no documentation is lost.
2. Dispatch each present argument to the same Service method the old setter called — no new verbs, no new authorization paths.
3. Preserve per-field behaviour that is not a plain write: a `dockerfilePath` change triggers a fresh build, `set_maintenance_mode` has its own semantics, autoscaling has a disable counterpart.
4. Delete the folded `mcp.AddTool` registrations and their argument structs.
5. Re-run m70's guard test — the folded tools must be gone from the registry and no `Parity1to1` tool may have moved.

## Acceptance criteria

- [ ] Every folded field is settable through `update_service` and reaches the same Service method.
- [ ] Omitting an argument leaves the field unchanged.
- [ ] Build-triggering and disable-path behaviours are preserved.
- [ ] m70's guard test passes; no `Parity1to1` tool changed.
- [ ] `cd lego/backend && go test ./...` green.

## Out of scope

- REST and GraphQL (unchanged by design).
- Datastore / env-group / environment setters (t003).
