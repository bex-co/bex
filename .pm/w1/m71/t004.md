## Objective

Record the removal where this repo already records retired surfaces, so an agent that calls a folded tool name gets a documented answer instead of an unexplained tool-not-found.

## Context

- Precedent: `w1/m55` ("Retire deprecated product compatibility surfaces", done 2026-07-27) recorded its removals in `docs/render-artifacts/deprecated-surface-removal-2026-07-27.md`, with `scripts/platform-deprecations-validate.sh` as the guard.
- These are bex-invented extension names with no Render contract behind them, so a hard removal is defensible — but bex is pre-1.0 and agents may already reference them, so the removal must be *findable*, not silent.
- Decide explicitly: hard removal, or a time-boxed alias that maps the old name onto the new argument. Prefer hard removal with a documented mapping unless there is concrete evidence of an existing caller.

## Steps

1. Record every removed tool name and its replacement call in the deprecation ledger, in the m55 entry's shape.
2. State the decision (hard removal vs alias) and the reason.
3. If aliases are kept, give them an explicit expiry and register them as `Extension` so m70's guard still covers them.
4. Update `docs/ADR025-connect-an-agent.md` if it names any folded tool.
5. Check the dashboard, mobile, `scripts/`, and skills for any hard-coded folded tool name.
