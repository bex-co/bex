## Objective

Cancel semantics are identical on REST `POST …/deploys/{id}/cancel`, GraphQL `cancelDeploy`, MCP and the dashboard dialog, and match Render: "your service continues running its most recent successful deploy (if any), with zero downtime." Any divergence is recorded.

3. **Render and env values.** Record whether Render applies a canceled deploy's saved env values later (its docs don't say), rather than assuming.
