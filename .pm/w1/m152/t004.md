## Objective

The cancel rule holds for every kind of change that opens a `config_change` deploy, and the cancel paths that are correct today keep working.

## Context

- **Change sources:**
  - service env vars and secret files (`lego/backend/internal/secrets/service.go`);
  - environment groups, whose shared Secrets are rewritten for all linked services (`lego/backend/internal/envgroups/service.go:653-657`; see also `w1/092`);
  - start command, health check path, pre-deploy command and plan (`releaseIdentityInput`, `lego/operator/internal/controller/release_identity.go`).
- **Resource types.** Web services were verified in pass 16 (m152 README § Evidence). **Cron jobs were verified in pass 19 (2026-09-14)** on `qa-20260914-cron` (`srv-dak1vca6m8ac739r6210`, `examples/cron-demo`, free, since deleted: `DELETE` 16:28:19Z → `204`, then `GET` → `404`):

  ```text
  16:26:43  POST /v1/cron-jobs/<srv>/runs → crr-r5639d07s033irgmb1e1 → successful; log 16:26:47 "cron-demo: tick"
  16:27:18  PUT /v1/services/<srv>/env-vars/MESSAGE {"value":"should-not-ship"} → 200; dep-dak20p8gsm7s73f64j2g config_change
  16:27:30  POST …/deploys/dep-dak20p8gsm7s73f64j2g/cancel (was build_in_progress) → 200 canceled
  16:27:43  POST /v1/cron-jobs/<srv>/runs → crr-n6hftno0gr0lp3o0ls51 → successful; log 16:27:46 "cron-demo: should-not-ship"
            deploys: dep-dak20p8gsm7s73f64j2g config_change canceled | dep-dak1vca6m8ac739r621g create live
  ```

  The cron pod template reads the same mutable Secrets through `envFromSources` (`reconcileCronJob` → `cronPodSpec`, `lego/operator/internal/controller/app_controller.go:3414`, `:3667-3673`). A canceled change therefore reaches every later cron run, manual or scheduled. Background workers and private services use the same path; that is reasoned, not probed.
- **Controls:** `w6/done/m52` (first-deploy cancel → `Canceled`) and `w6/done/m104` (image-backed cancel restores the image).

## Steps

1. **Change sources.** For each source, live-probe or envtest "change then cancel mid-build", and assert that nothing observable changes. A linked env group must not change for **other** linked services either.
2. **Combined changes.** A code deploy and a config change pending together, then cancel: both are restored.
3. **Controls.** Keep the m52 and m104 cancel paths green, unchanged.
