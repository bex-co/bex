## Objective

Stand up `dashboard/src/features/agent-sessions/` (NOT `sessions/` — taken by Kratos auth artifacts) with the control-plane data layer: GraphQL operations, codegen splice, typed hooks, view mapper. Metadata only — the conversation column is t002's stream, never polled.

## Context

- Shipped GraphQL (`lego/backend/internal/agentsessions/graphql.go`): `agentSessions(ownerId)`, `agentSession(id)`, `createAgentSession`, `steerAgentSession`, `resumeAgentSession`, `cancelAgentSession`; `AgentSession` carries `phase` (creating/running/resuming/redispatching/completed/failed/canceling/canceled — key off `phase`, not the free-text `status`), `headSha`/`prUrl`/`prNumber`, `evidence{...}`, `turns`, `deliveryMode`, `failureReason`, timestamps, mint-only `ticket`/`url`/`expiresAt`. m43 adds `attachAgentSession` (reconnect mint) — add its op when it lands.
- House conventions: per-feature `api/*.graphql` → codegen splice into `src/graphql/definitions.ts` (never wholesale-overwrite; offline recipe in `dashboard/CLAUDE.md`); hooks `cache-first` + `errorPolicy: "all"` + poll + `skipPollWhenHidden`; mutations `no-cache` with typed errors (`use-shell-session.ts` template).

## Steps

1. `api/agent-sessions.graphql`: the six ops (+ attach-ticket once m43 lands); mint fields selected only on mint ops.
2. Codegen splice per the offline recipe.
3. `hooks/use-agent-sessions.ts` / `use-agent-session.ts`: ~5s poll while `phase` non-terminal, 30s terminal; `skip: !authenticated`.
4. `hooks/use-agent-session-mutations.ts`: create/steer/resume/cancel/attach wrappers; 503 → typed `AgentSessionsUnavailableError`; `AGENT_SESSION_*` codes → typed errors with i18n-ready messages (egress errors carry `{reason, entry}`).
5. `types.ts` + `lib/mapper.ts`: `AgentSessionView` with isTerminal/isSteerable/duration helpers.
