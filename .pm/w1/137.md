# Do not bill tenants build minutes for platform-initiated rebuilds

Why: a `deployed_by_render` rebuild (platform-rebuild, e.g. shipping a runtime security patch) is the platform's action, yet it counts against the tenant's build minutes.

Filed 2026-10-24.

- Usage meters build-Job seconds per workspace regardless of trigger (`lego/backend/internal/usage` `queryBuildSeconds`).
- Exempt them — e.g. the operator labels the build Job when the release was opened as `deployed_by_render`, and usage skips labeled Jobs — or credit the affected workspaces after the CVE-2026-111497 rebuild (w1/135).
- Likely more than an hour (operator + usage + tests): promote to a milestone when scheduled.
