## Objective

Upgrade kpack to a maintained release compatible with the upgraded cluster and delete the temporary minimum-version override.

## Context

- deploy/gitops/charts/kpack/kustomization.yaml pins kpack 0.17.2 and overrides KUBERNETES_MIN_VERSION to 1.31.0.
- The manifest comment says the override is removable once the cluster is at least 1.32; the cluster upgrade makes that condition true.

## Steps

1. Review kpack release notes and upgrade manifests to the maintained version supported by the target cluster.
2. Remove KUBERNETES_MIN_VERSION and any workaround-specific patches or comments.
3. Run a clean source build, image publish, deploy, rebuild, and cancellation smoke test.
