## Objective

Establish a read-only production baseline and explicit rollback gates before deleting any migration or backup compatibility path.

## Context

- The research environment could inspect only the local kind/CAPD cluster; it had hand-applied Apps and unlabeled build artifacts that still exercised adoption fallbacks.
- Production must be queried separately without printing kubeconfigs, Secret data, database credentials, or private keys.

## Steps

1. Record Kubernetes, CAPI, CNPG, kpack, and GitHub Action versions and compatibility matrices.
2. Count legacy datastore names/IP shapes, build artifacts without App UID labels, releases without fingerprints, old Traefik routes, and legacy load-balancer targets.
3. Verify current etcd and Postgres backups and document rollback checkpoints for each mutation task.
