## Objective

Delete controller and CI cleanup loops for legacy datastore routes and per-server load-balancer targets after the cloud and cluster inventories are clean.

## Context

- Database and KeyValue controllers still delete older Traefik route shapes during reconciliation.
- .github/workflows/infra.yml runs legacy per-server load-balancer target cleanup on every infrastructure push.
- These are safe to remove only after both Kubernetes objects and Hetzner load-balancer targets report zero legacy instances.

## Steps

1. Inventory and remove remaining legacy Traefik resources through their existing safe cleanup path.
2. Inventory Hetzner load-balancer targets, remove only confirmed legacy per-server attachments, and record the stable node-pool target state.
3. Remove recurring cleanup code/workflow steps and add current-state validation.
