## Objective

Bring all retained build artifacts and releases to the current labels/fingerprints, then remove controller branches that permanently adopt old objects.

## Context

- lego/operator/internal/execution/artifacts.go and internal/build/artifacts.go adopt artifacts missing current App UID ownership labels.
- lego/operator/internal/controller/release_identity.go backfills missing release fingerprints.
- The local cluster observed during research still had three unlabeled build artifacts, so maintained dev state must be migrated as well as production.

## Steps

1. Inventory and patch eligible retained artifacts/releases in maintained dev environments and production.
2. Verify current builds and releases always create the canonical metadata from birth.
3. Delete adoption/backfill branches and add absence guards.
