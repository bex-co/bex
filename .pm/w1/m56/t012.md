## Objective

Remove the repository's dependency on deprecated Node 20 action runtimes by upgrading maintained first-party and third-party actions.

## Context

- Workflows currently use action majors including actions/checkout v4, actions/setup-go v5, and actions/setup-node v4 that emitted Node 20 deprecation annotations.
- Every third-party action upgrade must be reviewed for changed inputs, permissions, artifact formats, and runner requirements rather than changed mechanically.

## Steps

1. Inventory action pins and identify their maintained Node 24-compatible majors from official release notes.
2. Upgrade pins and adjust inputs or permissions only where required.
3. Exercise workflow-equivalent local checks and verify GitHub Actions runs without Node 20 annotations.

## Files

- .github/workflows/
- .github/actions/
- docs/

## Acceptance criteria

- [ ] No workflow invokes an action version backed by deprecated Node 20.
- [ ] Test, build, security scan, image publish, and deploy workflows retain least-required permissions and pass.
- [ ] The successful GitHub runs show no Node 20 deprecation annotation.

## Out of scope

- Replacing GitHub Actions or changing deployment policy.
