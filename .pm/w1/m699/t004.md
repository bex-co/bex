## Objective

Show Render's warning under a matching row while the service's variables are edited, with a **Use Internal URL** button that opens Render's "Review fix" dialog.

## Context

- Render shows it only while editing, and skips secret files, read-only rows, deleted rows and rows with no key. Only the service's editor passes a region, so environment groups never warn. Static sites have no runtime to connect from.
- `service-environment-editor.tsx:157` passes no region today. `EnvironmentEditor` is shared with environment groups (`dashboard/src/features/env-groups/components/env-group-editors.tsx:35`) and the build source's tab.

## Steps

1. Pass the service's region from the service's editor only.
2. Under a matching row, show Render's text, a link to bex's docs on internal and external connections, and **Use Internal URL**.
3. **Use Internal URL** opens "Review fix" with the old and new values. **Update** replaces the value in the draft, and Cancel closes it.

## Files

- `dashboard/src/features/services/components/service-environment-editor.tsx`, a warning component beside it, `dashboard/src/features/services/locales/en.ts`, and their tests
