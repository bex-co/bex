## Objective

Decide whether a value is the external URL of a datastore in the workspace and the service's region, and build the internal URL that replaces it.

## Context

- External hosts: `<id>.<BEX_DB_DOMAIN>` for Postgres (with `-pool`, `-ro-<name>` and `-rp-<name>`), and `<id>.kv.bex.co` for Key Value. The first label carries the id.
- A host has no region, so look the datastore up in the workspace with its non-secret read (`region`, `environmentId`, Key Value's `internalAuth`, t002's internal hosts). Not found means no warning.
- Build the new value from the pasted credentials, never from a connection read.

## Steps

1. Parse a value as a Postgres or Key Value URL on bex's external hosts, and take the datastore id from the host.
2. Look the datastore up, debounced, and require its region to equal the service's.
3. Build the internal URL. Postgres: the matching internal host, the pasted credentials, database and query, without `sslmode=verify-full`. Key Value: `redis://<id>:6379`, keeping the pasted credentials when internal auth is on.
