## Objective

Let bex-api tell the dashboard which providers it may recommend, so the banner never recommends a provider whose delivery has not passed live, or OIDC on an install without the issuer.

## Context

- `BEX_OIDC_ISSUER_URL` turns the issuer on ([ADR116](../../../docs/ADR116-managed-oidc.md)). A self-hosted install without it has no Managed OIDC.
- No provider has passed live yet (w2/m477–m479), so the list starts empty. t007 widens it one provider at a time. It is a temporary rollout step under the repository's allowlist rule, and t007 is its widening task.

## Steps

1. Serve the providers to recommend on GraphQL: none when the issuer is off, otherwise a fixed list in bex-api that starts empty.
2. Test both cases.

## Files

- the backend's OIDC package and GraphQL schema, and their tests
- `docs/ADR116-managed-oidc.md` (note the field beside D8)

## Acceptance criteria

- [ ] A test sees no providers with the issuer off, and the fixed list with it on.
