## Objective

Find long-lived OpenAI, Anthropic, AWS and Google Cloud credentials in an editor's rows exactly as Render does.

## Context

- The patterns and their order are in `docs/render-artifacts/service-environment-page.md` § OIDC recommendation (t001).
- A row is a key and a value, or a secret file's name and contents. Masked values that the editor has not revealed are matched by key name only, as Render's are.

## Steps

1. Write the detection as a pure module that takes the editor's rows and returns the providers found.
2. Table-test it with Render's patterns verbatim: each provider by key name and by value, the Google Cloud JSON in a value and in a secret file, every exclusion, a value's class beating its key name, and the AWS suppression.

## Files

- a new module beside `dashboard/src/features/services/components/service-environment-editor.tsx`, and its test

## Acceptance criteria

- [ ] The table tests cover every pattern and exclusion and pass.
