## Objective

Implement the single harness: `scripts/dev-env.sh <N> {up|down|status}`, covering t001's kept feature set.

## Context

- Repo conventions: `scripts/` holds the shell tooling, `scripts/lib` holds shared helpers, and `*.test.sh` files are the unit-test convention (`install-bex.test.sh`, `bao-init.test.sh`, `ssh-verify.test.sh`), gated by `.github/workflows/scripts.yml`.
- Existing behaviour to preserve: each `dev-N` gets its own Kratos + Hydra + Mailpit in namespace `dev-N-auth`, its own app namespace `dev-N`, reuses the shared cluster's CNPG and bex operators, and runs a locally-built `bex-api` on ports derived from N via `ports.env`.
- `up.sh` must stay idempotent — every workstream README documents it as safe to re-run.
- `BEX_CP_IDENTITY` must stay per-N. Two harnesses sharing the CAPD cluster with the same identity deleted each other's tenant namespaces (`.pm/w3/017.md`, and the mechanism is documented on `ControlPlaneLabel` in `lego/backend/internal/store/reconciler.go`). This is the highest-consequence per-N value in the whole harness.

## Steps

1. Implement `up`, `down`, `status` against t001's kept feature set.
2. Derive every per-N value from N — namespaces, ports, `BEX_CP_IDENTITY`, kubeconfig path — reading `ports.env` where it already exists.
3. Template the static YAML (`db/`, `mailpit/`, `values/`, `rbac-`) with N substituted at apply time rather than keeping ten copies.
4. Keep `up` idempotent; keep `down` scoped so it cannot touch the shared cluster or another workstream's `dev-N`.
5. Implement the override hook t001 chose.
6. Fail loudly on a missing or malformed N rather than defaulting to 1.

## Files

- `scripts/dev-env.sh` (new)
- `scripts/lib/` (shared helpers, if warranted)
- `scripts/dev-env/` (templated manifests)

## Acceptance criteria

- [ ] `up` is idempotent — running twice on a live environment converges and does not error.
- [ ] `down` provably touches only `dev-N`'s own namespaces and processes.
- [ ] `BEX_CP_IDENTITY` is per-N and asserted.
- [ ] A missing/invalid N is a loud failure, never a silent default.
- [ ] Every kept behaviour from t001 is present.

## Out of scope

- Migrating the workstreams (t003).
