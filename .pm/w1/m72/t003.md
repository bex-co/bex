3. Update all ten `wN/README.md` "Local dev environment" sections to the new invocation.
4. Leave a short pointer in each `dev-N/README.md` so a worker landing there is not confused by the missing scripts.
5. Grep the repo for references to `dev-N/up.sh`, `down.sh`, `status.sh` — CLAUDE.md, AGENTS.md, skills, other docs — and update every hit.
