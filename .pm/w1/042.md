# Deferred security-hardening (from w1/m53: L4, L7, L8)

These three w1/m53 LOW items are infra/gateway changes that need a live cluster
(Cilium admission behavior, gateway WebSocket transport, Traefik logging) to
verify safely, so they were deferred rather than shipped untested. Each is LOW
and not tenant-reachable / is bounded by an existing control.

**L4 — namespace fail-closed image-signature admission.**
`lego/operator/config/webhook/manifests.yaml` selects only pods labeled
`app.bex.co/verify-image: enabled` (operator-applied), so enforcement rests on
tenants lacking pod-create RBAC. A `namespaceSelector` fail-closed posture for
tenant namespaces would close a single-RBAC-slip gap — but it risks blocking
legitimate unsigned platform images that run in the apps namespace and needs live
admission testing against every pod that lands there. Do: enumerate every pod
kind in the apps namespace, confirm they're either signed or exempt, then switch
to namespaceSelector fail-closed.

**L7 — cross-replica web-shell ticket single-use.**
`lego/backend/internal/sshgateway/{websocket.go,server.go}` keep the nonce
reuse-guard in a per-process map; with 2 gateway replicas a ticket is redeemable
once per replica within its 90s TTL (each redemption still re-authorizes
`can_operate`). Do: add a shared nonce table (the gateway already holds
`BEX_CP_DB_URI`) with an atomic claim-on-first-use + expiry prune, or use sticky
sessions. Migration + store method + gateway wiring; verify with two replicas.

**L8 — web-shell ticket in the URL query string.**
The dashboard opens `wss://ssh.bex.co/shell?ticket=…`; Traefik's access log keeps
`RequestPath` (`traefik.values.yaml` `accessLog.fields.defaultMode: keep`), so a
captured log line within the 90s TTL yields a single-use ticket. There is no
clean per-route query redaction in Traefik. Do: carry the ticket via a
`Sec-WebSocket-Protocol` subprotocol instead of the URL (gateway `websocket.go`
+ dashboard `web-shell-terminal.tsx`), so it never touches the request line.
