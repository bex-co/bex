# w1/028 — GraphQL `Domain.id` returns the domain name, not the minted `cdm-` id

Sibling of the service deviation w1/m46 closes: `internal/apps/graphql.go`
(the `Domain` type's `id` field) resolves to `DomainView.Name` while domains
mint `cdm-<xid>` ids (ADR020's table). REST's custom-domains surface should be
checked for which shape it serves before flipping — do the same
audit-emit-accept-fallback dance as m46 if it diverges, or record it as a
deliberate deviation in ADR020 § Known deviations if REST is name-shaped too
(domains are addressed by hostname in most Render flows, so name-as-id may be
the honest contract here). Filed during m46 materialization, 2026-07-16.
