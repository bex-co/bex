## Objective

Read the session; require its repo to match the checkout's remote (case-insensitive `owner/repo`, else exit 2); with `--wait` wait for the turn first, else warn that the agent may push more; refuse a dirty tree (exit 2) unless `--stash` (`git stash push -u -m "bex pickup <ags-id>"`); `git fetch <remote> refs/heads/<branch>` then `git switch -c <branch> --track` for a new branch or `git merge --ff-only` for an existing one; refuse a diverged branch with the reconciling commands; exit 1 "the session has not pushed its branch yet" when the ref is missing; print the PR URL. `-o json` prints `{branch, commit, pullRequest}`.
