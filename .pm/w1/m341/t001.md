## Objective

Build the snapshot ADR106 D6 specifies: copy the index to a temporary `GIT_INDEX_FILE`, `git add -A` (or `-u` for `--tracked-only`) against it honoring `.gitignore`, `git write-tree`, `git commit-tree <tree> -p HEAD -m "bex handoff: <title>"`; a clean tree yields HEAD itself. Shell out to the user's `git`; never use a Go git library that could diverge from their config.
