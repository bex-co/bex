## Objective

If t001 shows the OpenSandbox control plane was unavailable during the roll, make it survive a node roll; otherwise record that nothing is needed.

## Context

- `deploy/gitops/charts/opensandbox-controller/values.yaml` `replicaCount: 1`; no PodDisruptionBudget found in the chart.
- Platform rolls drain one node at a time (w1/144).

## Steps

1. Check whether the controller and lifecycle server support more than one replica (leader election for the controller).
2. Add replicas and a PodDisruptionBudget with `maxUnavailable: 1`, or record why not.
3. Run `scripts/gitops-validate.sh`.

## Files

- `deploy/gitops/charts/opensandbox-controller/`, `deploy/gitops/overlays/prod/values/opensandbox-controller.values.yaml`.

## Acceptance criteria

- [ ] A drained node never leaves zero serving replicas, or the README records the reason it cannot.

## Out of scope

- Tenant sandbox pods themselves.
