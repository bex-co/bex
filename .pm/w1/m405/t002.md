## Objective

Before a create is repeated, find any sandbox the earlier attempt left for the same session and dispatch turn, and reuse it if running or remove it if not.

## Context

- `lego/backend/internal/sandbox/service.go` `CreateAgentSessionSandbox` sets `agentsession.BindingLabels(sessionID, repository, branch)` and `LabelDispatchTurn`.
- OpenSandbox's create is not idempotent; a create whose answer was lost may still have made a sandbox.

## Steps

1. Add a lookup of sandboxes by the session and turn labels in the sandbox lifecycle.
2. On a repeat: a running sandbox for this turn is reused; a pending or failed one is removed before the new create.
3. Keep the workspace tenant-key scoping and the egress set-up the first attempt does.

## Files

- `lego/backend/internal/sandbox/service.go`, `lego/backend/internal/sandbox/client.go`, tests.

## Acceptance criteria

- [ ] A test where the first create's answer is lost after the sandbox was made ends with exactly one sandbox for the turn.

## Out of scope

- Sandboxes of other sessions or turns.
