## Objective

Prove DoD 3 on a dev cluster (`scripts/dev-env.sh 1 up` or the local mock cluster).

## Steps

1. Start an agent session and, while its sandbox is being created, restart the lifecycle server (or drain its node).
2. Confirm the session reaches running, exactly one sandbox exists for the turn, and the retry is logged.
3. Record the run in the milestone README.

## Acceptance criteria

- [ ] The session runs and the log shows the retry.

## Out of scope
