## Objective

An Org Owner creates, lists and revokes organization audit-log keys through Render's GraphQL operations; the key's secret is returned once.

## Context

- Workspace keys are Hydra clients bound to a tenant (`lego/backend/internal/apikeys/service.go`: `CreateAPIKey`, `ListAPIKeys`, `RevokeAPIKey`, the binding's `TenantForKey`, `activeKeyQuota`, the `bex.co/created-by` and `bex.co/last-used` metadata). An org key is a new owner kind: bound to an org, never to a workspace, so no workspace key list, quota or teardown counts it.
- Org reads and writes: `lego/backend/internal/workspaces/organizations.go`, `lego/backend/internal/store/organizations.go` (`DissolveOrganization` at the org's end), the org GraphQL in `workspaces/graphql.go`. Ids are minted only through `lego/backend/internal/id` (`id.New(kind)`).
- Render's shapes: `organization(organizationId) { organizationAPITokens { id createdAt label lastUsedAt expiresAt type } }`, `provisionOrganizationAuditLogToken(organizationId, label) { token }`, `revokeOrganizationAPIToken(organizationId, tokenId): Boolean`.

## Steps

1. Store the org binding (a migration under `lego/backend/internal/store/migrations/`, next free number), with the key's org, label, type `AUDIT_LOG` (or the value t001 records), creator and creation time.
2. Service: mint (Owner only, `can_manage` on the org; trimmed non-empty label; the quota t001 settled with its error), list (Owner only; secrets never returned; last-used from the key's stamp), revoke (Owner only; a key of another org answers as not found). Dissolving the org revokes its keys in the same path.
3. GraphQL: the three operations above with Render's argument and field names, and `Organization.organizationAPITokens` resolved only for a caller who may manage the org.
4. Apply t001's lifecycle answers (creator leaves or is demoted, org login requirements).
5. `cd lego/backend && go test ./...`, and `make lint` from `lego/operator/`.

## Files

- `lego/backend/internal/apikeys/` (org key mint, list, revoke), `lego/backend/internal/store/` (binding + migration), `lego/backend/internal/workspaces/graphql.go` or the apikeys GraphQL
- `lego/backend/internal/api/testdata/schema.graphql` (regenerated)

## Acceptance criteria

- [ ] An Owner mints a key and gets its bearer once; the list shows it without a secret; revoke removes it and a second revoke answers not found.
- [ ] A Member, a Guest, a non-member and a workspace key are refused all three operations, and a non-member learns nothing about whether the org exists.
- [ ] Dissolving the org leaves none of its keys working.

## Out of scope
