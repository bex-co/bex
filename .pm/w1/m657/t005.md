## Objective

Render's `orgUserAuthStatus(userID, orgID) { loginMethodStatuses { method signedIn } is2FAEnabled }` answers, for an org member, the login methods t001 listed with whether the member has signed in with each, and whether their account has a second factor.

## Context

- `lego/backend/internal/workspaces/kratos_verification.go` (`KratosIdentities.MFAEnrolled`, `GoogleAccountMatches`) already reads a Kratos identity's second factor and Google link for the enforcement gate; `lego/backend/internal/core/signin.go` names bex's methods (`password`, `oidc:google`, `oidc:github`).
- Org roles and membership: `lego/backend/internal/workspaces/organizations.go`, `store.OrganizationRole`. GraphQL `OrganizationMember` exposes `subject` and `userId`; take the id form the dashboard already holds for a member and say which in the schema description.
- Who may ask: t001's answer for `viewOrgUserAuthStatus` (default: Org Owners).

## Steps

1. A reader that returns one identity's credentials (password set, each oidc provider linked) and its second factor, reusing the Kratos admin client the gate uses; no new Kratos round trip per method.
2. The service: refuse a caller without the permission and a user who is not in the org with the same error, so the answer reveals nothing about strangers; map credentials to Render's method names in t001's order.
3. The GraphQL query with Render's argument names (`userID`, `orgID`) and field names.
4. `cd lego/backend && go test ./...`, and `make lint` from `lego/operator/`.

## Files

- `lego/backend/internal/workspaces/` (the reader and the service method), the org GraphQL
- `lego/backend/internal/api/testdata/schema.graphql` (regenerated)

## Acceptance criteria

- [ ] For a member with a password only, Google only, both, and with and without TOTP, the answer matches the identity.
- [ ] A Member or Guest asking, an Owner asking about someone outside the org, and an unknown user all get the same refusal.
- [ ] A Kratos lookup that fails answers an error, never a status that reads "Not signed in".
