## Objective

Classify every way a service Shell session stops, by Render's rule.

## Context

- The gateway's frames (`lego/backend/internal/sshgateway/webshell/websocket.go`):
  - `exit` carries a code (`:534`).
  - `error` carries a `reason` from `endMessages` (`:229-238`): `revoked`, `suspended`, `ineligible`, `instance_gone`, `timeout` (a gateway release's drain bound, for a service) and `unverified`.
  - An `error` with no reason is a start failure or a lost stream; w1/174 splits those.
  - A socket can also close with no frame at all.
- w1/m691 t004 handles an `instance_gone` refusal: it drops the instance, selects the first running one, and toasts.

## Steps

1. **End for good:**
   - `exit` with a code other than 137 or 143;
   - `revoked`, `suspended` and `ineligible`;
   - the fifth failed try.
2. **Retry:**
   - a close with no frame;
   - `exit` 137 or 143;
   - `instance_gone`, which goes through m691's not-available rule first;
   - `timeout` and `unverified`.
3. A ticket mint that is refused with a non-retryable reason (forbidden, an admin-only refusal, a suspension) ends with that reason, as Render's `startShell` errors do.
4. Note in `shell-page.md` any case Render's code does not decide.
