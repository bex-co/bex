## Objective

The shared image tab runs Render's check and shows Render's states and messages in both places it appears. A service cannot be created, or its image saved, until the image is deployable.

## Context

- `dashboard/src/features/services/components/service-source-picker.tsx` (image tab, `ImageSourceOption`), `registry-credential-select.tsx`, `pages/new-service-page.tsx`, `components/service-source-card.tsx` (Settings), `dashboard/src/common/lib/utils/docker-image.ts` (the syntax check stays first: a malformed path sends no query).
- `dashboard/AGENTS.md`: GraphQL documents, codegen, i18n in all eight locales, pending states that match the ready state.
- The run's lesson: pending frames and one-line messages that were shorter than the ready content failed on production. Reserve the message line while the check is in flight. The longest message, `does_not_exist`, wraps to two lines at 390 px.

## Steps

1. Add the `isDeployableImage` document and a hook. It debounces 800 ms on change, runs at once on paste, runs again when the credential changes, resets on empty, and drops a stale answer for a URL that has since changed.
2. In the field, show a spinner while the check runs, then a check mark or a caution icon. Under it, show Render's message for each code, with and without a credential, and the two success messages. Render links the last words of the platform and size messages to its docs. bex links them to its own page on deploying an image where it has one, and t001 records which page that is.
3. Mark the credential select in error when the check fails with a credential chosen. Follow t001's answer on disabling it for a public image.
4. Gate the create page's Create and Settings' Save on `deployable === true`, keeping the server's own refusal (`serverError`) as before.
5. Add strings for the eight locales, and component tests for each code, the debounce, paste, a credential change and a stale answer.
