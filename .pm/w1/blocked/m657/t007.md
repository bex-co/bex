- **DoD 1 holds.** The Owner minted two keys on GraphQL and one in org Settings → Audit Logs → Audit Log API Keys; each was shown once (the dialog's "API key created" with Done), then listed with its label, Key prefix, Created and Last used (a key used a minute before read `now`; an unused one `Never`).
