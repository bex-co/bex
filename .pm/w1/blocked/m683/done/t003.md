## Objective

Choose Default or Protected as Render's Permissions card does.

## Context

- Render: "Default — For staging and development" and "Protected — Best for production", with the explanation that only admins can delete and suspend resources, move services, and manage database networking; Edit / Cancel / Save.
- Only an Admin may protect an environment (w8/187, w9/106).

## Steps

1. Build the card over the existing ACL mutation.
2. Disable Edit with the role's reason for a non-Admin.

## Files

- the new settings route's Permissions card

## Acceptance criteria

- [x] An Admin switches Default ↔ Protected and the section's protected icon follows; a member who may not change the protection does not see the card, as on Render (amended 2026-11-27 from "a Developer sees Edit disabled", after reading Render's page).

## Result (2026-11-27)

`EnvironmentPermissionsCard`. Render shows the card only to a member who may change the protection (its `updateEnvironmentProtected` level), so a Developer does not see it rather than seeing Edit disabled: the page shows Permissions, Connections and Networking to an Admin only.
