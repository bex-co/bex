## Objective

Close m171 once its definition of done is observed in production, not just in tests.

## Gate

**Deploy + live verify.** This needs the m171 commit shipped and running as the production bex-api and dashboard images (`deploy.yml`). Then a live probe from outside the cluster, using a fixture custom domain whose record is proxied by Cloudflare.

## Steps

1. Confirm the deployed bex-api and dashboard images include the m171 commit.
2. Create a fixture `web_service` with two custom domains: one orange-cloud host in a zone the QA account controls, and one DNS-only host. Verify both claims.
3. Probe each DoD item in the milestone README, recording dated request/response excerpts there under `§ Live verification`:
   - REST PATCH/GET;
   - GraphQL `service(id)` and `setServiceIpAllowList`;
   - MCP `get_service`/`update_service`;
   - clear/open lists;
   - the environment layer through REST, GraphQL and MCP;
   - dashboard screenshots at desktop and narrow-mobile widths, for both the pending and the ready state of Settings.
4. Delete the fixture and restore the DNS records.
5. Close the milestone: move the task to `done/`, mark the row DONE, set `**Status:** done`, move `blocked/m171` → `done/m171`, and check the w1 README box.

## Acceptance criteria

- [ ] Every DoD bullet is observed live and recorded with dates.
- [ ] The fixture is cleaned up.
