## Objective

Header line (`ags-… · repo@branch · model · state · $spent`), the agent's text, one line per tool call, turn boundaries with outcome, PR link and cost (`--reasoning` to show reasoning). An input line under the stream: Enter steers when no turn runs, otherwise queues one message (typing again replaces it, shown as `queued — sends when this turn ends`) and sends it by steer when the turn settles. Ctrl-D, `/quit`, or Ctrl-C on an empty line detach without cancelling. `chat --repo …` without a session creates one with the `run` flags and an idempotency key, then attaches. `--read-only` hides the input line. No TTY → exit 2 pointing to `run --follow`. No permission prompts of any kind (#APPROVAL-MODE).
