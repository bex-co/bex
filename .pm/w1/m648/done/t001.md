## Outcome (2026-11-26)

[docs/render-artifacts/avatars.md](../../../../docs/render-artifacts/avatars.md), from the orchestrator's same-day check of a Render Pro workspace in a headed browser and Render's public bundle. What it corrected in the milestone's premise: a monogram is not a setting but an image (the Edit Monogram dialog draws it into a JPEG and uploads it like a photo, or resets when it is the default), so an owner has one uploaded image or none; the upload is the query `avatarPresignedUpload { url verb }` plus `deleteAvatar`; `AvatarType` is `ACCOUNT | WORKSPACE`, so Render has no organization avatar anyone can set (the organization pages only show members' and workspaces' avatars); the client-side limits are PNG or JPEG and a data URL of at most 20,971,520 characters, and whatever the source the stored image is a 128 × 128 JPEG.
