## Objective

Enforce the gate on every `apps` path that can land a workspace on a non-free compute tier — service create, plan update, and Blueprint deploys that declare a paid plan — and establish the cross-surface refusal shape all later gates reuse: REST `402` in the t001-captured Render dialect, GraphQL error with `extensions.code = PAYMENT_REQUIRED`, MCP tool error that names `create_billing_checkout_session`.

## Context

- Paid = `spec.tier != "free"` (`lego/types/tiers/tiers.yaml` compute ladder; `free` is the default for an absent plan, which must stay ungated).
- Verb inventory: `apps` create (REST `POST /v1/services` `plan`, GraphQL create, MCP `create_web_service`/worker/cron args), plan-change verbs (REST PATCH `serviceDetails.plan`, GraphQL update, MCP `update_*`), and the Blueprint path (`deploy.go` — `bex.yml` `plan:` fields).
- The gate call sits in the service verb after `Authorize`/`AuthorizeApp` (authz first, then payment), on the *target* workspace of the create — a create takes its workspace from request context (backend/CLAUDE.md).
- Only transitions **to** a paid tier gate; free→free, paid→free, and paid→paid-with-card all pass (a bound card is what let it become paid).
- Error mapping: the typed sentinel from t003 maps per surface in the existing error-translation layers (`core.WriteErr` REST mapping, gqlutil, MCP adapter).

## Steps

1. Add a `paidTier(tier) bool` helper against the tiers catalog (free id per family), shared for t005.
2. Call the gate in create + plan-change verbs and in Blueprint deploy validation when any declared service plan is paid.
3. Map `core.ErrPaymentRequired` → REST 402 (t001 dialect), GraphQL `PAYMENT_REQUIRED`, MCP actionable message.
4. Table-driven service tests: free create passes, paid create 402s ungated↔gated, exempt workspaces pass, all three surfaces return the mapped shape.
