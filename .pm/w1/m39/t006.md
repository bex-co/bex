## Objective

Where a major upgrade changed observable behavior (serialization, defaults, error text a feature relies on), pin the new behavior with a real test; if no behavior changed, record that explicitly rather than adding filler tests.

## Acceptance criteria

- [ ] Behavior-changing upgrades pinned by tests, or an explicit "no observable behavior change" record; suites green.
