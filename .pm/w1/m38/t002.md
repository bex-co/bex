## Objective

Before trusting a real drain, disrupt each DB's primary deliberately (cordon its node / delete the primary pod, one cluster at a time) and verify CNPG promotes the replica while the dependent services (Kratos login, Hydra introspection, OpenFGA checks, bex-api store reads/writes) keep answering.

## Steps

1. For each of the four clusters in turn: identify the primary, disrupt it, watch promotion (`kubectl cnpg status` / cluster events).
2. During each disruption, run the cheap probes: a Kratos whoami, a Hydra token introspection, a bex-api authenticated list, an OpenFGA check.
3. Record promotion time + any request failures in the milestone evidence.

## Acceptance criteria

- [ ] All four clusters promote automatically under primary disruption; probes show no sustained outage (brief blips recorded honestly).
