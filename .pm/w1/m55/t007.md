## Objective

Remove the small audited shims whose repository-owned consumers can be migrated in the same change, while retaining deliberate self-hosted and build-namespace fallbacks.

## Context

- lego/types/v1alpha1/groupversion_info.go exports a GroupVersion alias used only by operator tests in this repository; external module consumers require a release note.
- scripts/ssh-dns-cloudflare.sh accepts CF_ZONE_ID while scripts/domain-add.sh still teaches it; standardize on CLOUDFLARE_ZONE_ID before deleting the alias.
- scripts/registry-secrets.sh contains a stale BEX_REGISTRY_PULLER_PASSWORD compatibility comment with no implementation.
- Production enables per-App registry credentials, so the shared BEX_REGISTRY_PULL_SECRET setting is redundant there; the self-hosted code fallback and distinct BEX_REGISTRY_BUILD_PULL_SECRET remain valid.

## Steps

1. Migrate tests from the GroupVersion alias, remove it, and record the public Go API change.
2. Standardize Cloudflare scripts and operational docs on CLOUDFLARE_ZONE_ID; delete CF_ZONE_ID handling.
3. Remove the stale registry comment and redundant production shared-pull setting after manifest validation.
