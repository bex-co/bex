## Objective

Delete the deprecated select_workspace and get_selected_workspace tools and all implicit session fallback once explicit workspaceId is available everywhere.

## Context

- lego/backend/internal/workspaces/mcp.go registers the two deprecated tools.
- lego/backend/internal/core/workspaceselection.go and migration 0044_mcp_workspace_selections implement persistent and storeless session state.
- Applied migration history must remain immutable; remove the live table through a new forward migration rather than deleting or rewriting migration 0044.

## Steps

1. Remove the tools and every SelectedWorkspace or selection-precedence call site.
2. Remove in-memory and PGStore selection methods and add a forward migration that drops mcp_workspace_selections.
3. Remove session-affinity assumptions and update transport, documentation, and tests.

## Acceptance criteria

- [ ] select_workspace and get_selected_workspace are absent from tools/list.
- [ ] No production code reads or writes MCP workspace selection state.
- [ ] A forward migration drops the obsolete table without altering applied migration files.
- [ ] Stateless and multi-replica MCP requests work without session affinity for workspace routing.

## Out of scope

- Removing MCP transport sessions required by the protocol itself.
- Changing dashboard workspace selection.
