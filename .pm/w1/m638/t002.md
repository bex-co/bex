## Objective

Prove a candidate image builds a crate that needs its release, offline, on both architectures.

## Context

- `scripts/go-line-smoke.sh` mounts the source read-only; cargo writes `Cargo.lock` into the source directory, so copy the crate to a writable directory (or ship a lockfile).

## Steps

1. `scripts/rust-line-smoke.sh <image> <release>`: network off, check `rustc --version`, `rustup show active-toolchain`, `cargo build --offline` of a crate with `rust-version = "<release>"`.
2. A `rust-version` newer than the image must fail.

## Files

- `scripts/rust-line-smoke.sh`
- `scripts/rust-line-smoke.test.sh`

## Acceptance criteria

- [ ] The smoke passes on the pinned image for 1.100.0 and fails for 1.100.9.
