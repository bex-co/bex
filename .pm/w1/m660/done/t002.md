## Outcome (2026-11-26)

`RollbackComparison` no longer returns early for a static site:

- **Each side.** A side is the adoption record of the release whose build it serves (`staticBuildGeneration`). That is the release itself, or, for a Rollback or Restart, the release whose publication its adopted selection copied, followed through earlier copies.
- **Fields.** The answer carries env var keys, secret file names, linked groups and the deleted-group count, as a service's does, and nothing else: command, health check, instances and plan stay null.
- **Unavailable.** A missing record, a copy naming no earlier release, or a build record past the window answers a null snapshot.
- **Authorization** is unchanged.
