# Deploy-page log type filter (All / Application / Build)

Render's deploy detail explorer has a type selector — **All logs** (default) / **Application logs** / **Build logs** — verified live 2026-07-17 on dashboard.render.com (`docs/render-artifacts/live-deploy-following.md` § 2026-07-17). bex's deploy log panel deliberately dropped the type dropdown (w9/m1/t003, `dashboard/src/features/deploys/components/deploy-log-panel.tsx` — "a deploy already knows its own window and always wants build+predeploy+app interleaved"); the interleaved default is parity-correct, the missing selector is the gap.

Sub-hour: a three-way client-side filter over the already-merged lines (each `LogLine` carries its `type`; count `predeploy` under Application, matching Render's two buckets), placed in the panel's control row, + i18n keys (`deploys.*`) + a component test. No new queries — filtering the merged array keeps the three legs untouched.
