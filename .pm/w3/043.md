# 043 — A sixth GraphQL timestamp that never calls `TimeField` would still ship

Why: `w7/052` fixed five fields and added `gqlutil.TimeField` so the correct thing is available — but `TestTimeField` pins the **helper's** behavior, not the **schema's**, so a new field that hands a raw `time.Time` to `graphql.String` is exactly as invisible today as the five were.

## What shipped, and what it does and does not cover

`w7/052` (done 2026-09-16) added `gqlutil.TimeField` (`lego/backend/internal/gqlutil/gqlutil.go:77`) and moved `Project.createdAt/updatedAt`, `Environment.createdAt` and `Blueprint.createdAt/updatedAt` onto it. `gqlutil_test.go:248` (`TestTimeField`) asserts the helper emits RFC3339 for `time.Time`, `*time.Time`, zero and non-UTC inputs.

That is the right test for the helper. It cannot fail for a field that never calls it — which is the entire failure mode: `graphql-go` v0.8.1's `coerceString` is `fmt.Sprintf("%v", value)` (`scalars.go:307-314`), so any `time.Time` reaching a `graphql.String` silently renders as Go's `time.String()` layout. Nothing asserts a format invariant across the schema.

The note itself recorded that its own 77-field sweep "got the right answer for the wrong reason" — the search shape it used would not have caught a sixth field. That is the residue.

## Shape

Assert, over the registered schema rather than a hand-maintained list, that every resolved time-shaped field parses as RFC3339. Derivation from the schema is the point: a new type should be covered by default, and an exemption should be an explicit named entry rather than something nobody added.

`lego/backend/internal/api/events_surface_test.go:262,267` is the precedent worth extending — it asserts REST, GraphQL and MCP agree on the same event's timestamp, and it would have caught this class for events.

**Fallback if a schema-derived sweep proves unworkable** against graphql-go's runtime field definitions (the resolver is an opaque func, so a static "does this return `time.Time`" check is not expressible): per-package cross-surface assertions on the affected types plus a lint for `time.Time` returned from a field `Resolve`. Smaller, still a real guard.

**Must not become** a snapshot test that passes on any output.

## Estimate

~60m. A note rather than a milestone: one test, and the five fields it would protect are already fixed — this buys protection against the sixth, not a live defect.
