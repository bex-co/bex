## Objective

Live tail a project view: follow every resource the scope resolves to, with the same labels, as Render's Live tail preset does.

## Context

- `/v1/logs/subscribe` already follows several resources (`rest.go`, one slot per resource); the dashboard tails through it.
- The resolved set can change while tailing (a service created or moved).

## Steps

1. Accept the project scope on the tail path, resolve it with t004's rule, and re-resolve on a bounded interval.
2. Above the resource cap, answer with a message naming the cap rather than silently tailing a subset.
