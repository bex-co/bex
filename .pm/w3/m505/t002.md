## Objective

Persist saved searches and give every project, new and existing, the three default views Render creates: Application Logs, Request Logs and Service Metrics, each with an empty filter document.

## Context

- `lego/backend/internal/id/id.go` (register `SavedSearch = Kind{prefix: "svs", …}`; ids only via `id.New`).
- `lego/backend/internal/projects/` (project create and delete), `lego/backend/internal/store/` migrations.
- The `METRICS` default is created now so w3/m508 only has to list it, as Render keeps one for a project whose UI does not show it.

## Steps

1. Add the `svs` kind and a migration for the saved-search table (project, name, type, filters JSON, timestamps; unique name per project).
2. Create the three defaults in the project-create transaction and backfill them for existing projects in the migration.
3. Delete a project's saved searches with the project.

## Files

- lego/backend/internal/id/id.go
- lego/backend/internal/store/ (migration + queries)
- lego/backend/internal/projects/

## Acceptance criteria

- [ ] A new project has exactly three saved searches with Render's names, types and `{"filters": [], "version": 1}`
- [ ] Existing projects get them from the migration
- [ ] Deleting a project deletes its saved searches
