# Render's dated Node defaults 24.14.1 and 24.21.0 predate the CVE-2026-111497 Brotli fix

Why: since w3/m636 (`41ff57632f`), a native Node service, or another runtime's companion Node, created 2026-04-21 to 2026-10-20 with no version signal builds on Node 24.14.1 or 24.21.0. The Brotli decoder bundled in both lacks the CVE-2026-111497 fix, and w1/135's fleet rebuild had moved every no-signal service off it. Flooring those defaults is the stricter variant of m636's parity choice, so it needs the user's call.

- **Evidence (2026-11-26):** `deploy/native-base/node-brotli/check.js` is Node's own regression from nodejs/node@b5f41529df. It fails on `node:24.14.1-bookworm` and `node:24.21.0-bookworm`, where `zlib.constants.BROTLI_DECODER_ERROR_FORMAT_BLOCK_SWITCH` is undefined. It passes on `node:24.22.1-bookworm`, the 24 line's first fixed release (w1/135).
- **How it surfaced:** the common-image qualification caught it on the exact-default Python case, which m636 had moved to 2026-10-12, where the companion Node is 24.21.0 (run 45874535257). `3c57c4d2f5` moved that case to the 2026-10-21 band and added `TestNativeUtilityExactDefaultCaseHasAFixedNode`. The product's behavior is unchanged.
- **Blast radius (m636 t001):** once production carries `41ff57632f`, at most four Node services and one Go service's companion Node on production. w3/m636's t007 deploys a first-party Node service created before 2026-09-17 and expects `24.14.1 (default)`.
- **Why no gate stops it:** a production build runs `node-check.js` only for the four backported EOL lines (`commonNodeBackport` in `lego/operator/internal/build/nativecommon.go`). A modern line's default patch is trusted to be the fixed one, which held until m636. ADR060's CVE section leaves only patches the user selects explicitly on the official image. A dated default is a choice bex makes on the service's behalf.
- **Options:**
  - (a) Keep Render's exact rows (parity). The user accepts that these services run a Node with a known Brotli out-of-bounds write until they set `NODE_VERSION`.
  - (b) Floor each dated Node default at its line's first CVE-fixed release (24.22.1). The build log then says `24.22.1 (default)` for those services. This is a divergence that ADR018's Runtime row records with the user's sign-off.
  - Either way, the companion Node follows the same table.
- **End state:** the user's choice is in ADR018's Runtime row (`docs/ADR018/services-lifecycle.md`). For (b), `TestNodeDefaultFollowsRendersDatedRows` asserts the floor, and a test fails when a dated Node default would resolve below its line's recorded fixed release.
