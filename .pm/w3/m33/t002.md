## Objective

Implement the first half of the Render CLI's exec handshake: `POST /v1/sandboxes/{sandboxId}/runs/{operation}/token?ownerId=` (operation = `stream`; body carries the command) returning `{ method, uri, token }` (`SandboxConnectResponse`). The CLI then opens `uri` with `token` to stream (t003).

## Context

- Wire shape: [docs/render-artifacts/ea-sandbox.md](../../../../docs/render-artifacts/ea-sandbox.md) §exec (`ExecSandboxStream` in the CLI's `pkg/sandbox/repo.go`).
- Precedent for the short-lived signed token: the Browser Web Shell ticket (`BEX_SHELL_TICKET_SECRET`, HMAC-SHA256, `internal/api` shell-ticket verb, docs/ADR035-ssh.md §Browser Web Shell) — mint a bounded, single-use HMAC token binding sandbox id + workspace + command hash + expiry.
- Authz: authorize `can_operate` against the **sandbox's own workspace** (resolve via the per-workspace key, m32 t006), matching how lifecycle verbs authorize. A caller may only exec into their own sandboxes.
- `uri` must be the browser-reachable stream endpoint (t003), an env like `BEX_SANDBOX_EXEC_WS_URL`/public API origin (mirror `BEX_SHELL_WS_URL`).

## Steps

1. Add the REST route + `Service.ExecToken(ctx, req)` verb (starts with `s.Authorize`/the resource-scoped seam).
2. Mint the HMAC token (new `BEX_SANDBOX_EXEC_SECRET` or reuse the shell-ticket key — decide + document in root CLAUDE.md env table).
3. Return `{method, uri, token}` pointing at the t003 stream endpoint.

## Files

- `lego/backend/internal/sandbox/service.go`, `rest.go`
- `lego/backend/cmd/api/main.go` (wire the secret + stream URL), root `CLAUDE.md` + `.env.example` (new env)

## Acceptance criteria

- [ ] `POST .../runs/stream/token` returns a valid `{method, uri, token}`; unauthorized callers 403; unknown sandbox 404.
- [ ] Token is short-lived, single-use, and binds sandbox+workspace+command.

## Out of scope

- The stream itself (t003).
