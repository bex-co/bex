## Objective

Show Render's almost-full warning at the top of a Postgres database's Info and Plan pages when Render's rule holds.

## Context

- Pages: `dashboard/src/features/databases/pages/database-info-page.tsx` and `dashboard/src/routes/databases.$databaseId.plan.tsx`. The layout hands both the database (`DatabaseDetailProvider`).
- Links: storage the user can grow → Plan at a new `#storage` anchor on the storage control in `database-plan-section.tsx` (Render's `/plan#storage`); a plan whose storage is fixed (`planStorageFixed` in `features/databases/lib/storage.ts`) → Plan at `#plan`. The layout's hash scroll (w3/m641) brings the card into view.
- The warning depends on data, so the pages' pending frames do not draw it (AGENTS.md: pending equals ready where data does not decide).

## Steps

1. Put Render's rule in one pure function beside `storage.ts`, with the constants named.
2. Add the alert component with Render's copy in all eight locales, and render it first on both pages.
3. Add the `#storage` anchor, and teach `features/databases/lib/database-pages.ts` that Render's `/plan#storage` lands there.
