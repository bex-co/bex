## Objective

Every sync bex runs keeps the plan it applied and the commit it read, so its page can show them.

## Context

- `blueprint_syncs.plan_actions` (migration 0187) is written only by `store/blueprint_plans.go` for a planned sync.
- Manual sync, auto-sync on push and the first sync plan through the same appliers (ADR049: 'the diff comes from the same appliers a real sync runs'); find where each path records its `blueprint_syncs` row in `lego/backend/internal/apps/blueprint*.go` and `store/blueprints.go`.
- Deploys store a commit message (migrations 0026, 0040) from the Git read; the Blueprint file read resolves a commit (`discoverBlueprintFile`).

## Steps

1. Add a `commit_message` column (migration with a down) and record it from the Git read on every sync path.
2. Record the applied plan's actions on every path that applies one, in the shape planned syncs already store.
3. Leave rows from before this change as they are (no backfill).
