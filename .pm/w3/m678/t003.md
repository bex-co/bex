## Objective

Give the dashboard one read for a sync's page and the fields the sync card needs.

## Context

- GraphQL `BlueprintSync`, `blueprintSyncs(id, cursor, limit)`, `blueprintPlannedSync(id)` and `BlueprintPlanAction` in `lego/backend/internal/apps/` (schema snapshot `internal/api/testdata/schema.graphql`).
- REST `GET /v1/blueprints/{id}/syncs` and MCP keep Render's shapes (pinned `render-public-api-1.json`); new fields are GraphQL only, as Render's own dashboard reads them over GraphQL.

## Steps

1. Add `blueprintSync(id, syncId)` returning the sync with `commitMessage`, `actions` (with a per-action state derived from the sync's state and its apply results), errors and `requiredManualEnvVars`.
2. Add `commitMessage` to `BlueprintSync` for the list; regenerate the schema snapshot and the dashboard's `graphql/definitions.ts`.
3. Authorize it as `blueprintSyncs` is (the Blueprint's workspace, the same relation).
