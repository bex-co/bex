## Objective

`LogQuery` can say "not these values" for Level, Instance, Method, Status Code, Host and Path, and a store read (history and the live request poll) returns exactly the lines the selecting form would not.

## Context

- `lego/backend/internal/logs/service.go:309`: the structured filters are value sets that only select. `validate` / `normalized` check and normalize them.
- `lego/backend/internal/logs/loki.go`: `lokiSelectorFor` adds `labelMatcher` for level (`storedLevels`), instance, method and status code (`statusClasses`), at `:499`–`:511`. `lokiPipelineFor` (`:589`) filters `request_path` / `request_host` after a `json` stage. `labelMatcher` renders `=` or an anchored `=~`, and a `/…/` value unanchored.
- LogQL: `!=` and `!~` on a stream label also keep streams without the label, so "not info" keeps a line with no level, as DoD 1 asks. The same holds for a label filter after `json`.
- `lego/backend/internal/logs/textprefilter.go:71`: Text Search keeps selecting only (DoD 3). Nothing changes there.
- `pollRequestLogs` (`service.go:1963`) feeds the live request tail from the store through the same selector.

## Steps

1. Add the negated sets to `LogQuery`, for example one `[]string` per field or a per-field negate flag, whichever keeps `validate`, `normalized` and the adapters simplest. Callers outside the package never set them: REST, MCP and GraphQL `resource` reads have no operator.
2. Validate negated values as the selecting ones are validated (wildcards, `/regex/` compiling, status classes, level names), and refuse a field that sets both forms.
3. Render the negated matchers: `!=` / `!~` with the same quoting and anchoring as `labelMatcher` (a shared helper, not a copy). Status classes and stored-level mapping apply before negation.
4. Make `hasFilters`, `hasStoreOnlyFilters` and `requestFilters` count a negated request field as a request filter, so it still narrows the read to request lines.
5. Unit tests on the rendered LogQL for each field, both forms, wildcard and regex values, in the style of `loki_test.go`.
