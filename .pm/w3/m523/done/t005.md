## Objective

The Edit view modal offers Render's `is one of` / `is not one of` on Level, Instance, Method, Status Code, Host and Path, saves `IS_NOT`, and reopens a stored `IS_NOT` row as `is not one of`. A view page reads such a view.

## Context

- `dashboard/src/features/logs/lib/view-filters.ts:141` `viewFieldOperators` returns `["IS", "IS_NOT"]` only for `RESOURCE` and `RESOURCE_TYPE`. Its doc comment names w3/076.
- `dashboard/src/features/logs/components/edit-view-dialog.tsx:339` disables the operator select when a field has one operator. `operatorLabel` (`:417`) already labels `IS_NOT` with `logs.viewOperatorIsNotOneOf` in every locale.
- Tests: `lib/__tests__/view-filters.test.ts`, `components/__tests__/edit-view-dialog.test.tsx`.
- `project-log-viewer.tsx` turns typed `level:` / `instance:` operators into chips. Check that a chip beside a negated view field still answers the API's "the view already filters on …" with its message, as it does for `IS`.

## Steps

1. Offer both operators on the six fields. Keep `ENVIRONMENT`, `TEXT` and `TIME_RANGE` on `IS`, and update the doc comment.
2. Tests: operators per field, a stored `IS_NOT` Level row round-trips through `rowsFromDocument` and the dialog, and saving sends `IS_NOT`.
3. `yarn lint` and `yarn test`.
