## Objective

Every path that reads lines without the store's selector applies the negated sets the same way: an App's pod-log read and live tail, a Postgres or Key Value process log, and the tail's producer routing.

## Context

- `service.go:1258` `compileLevelFilter` builds `levelFilter`, and `keep` (`:874`) applies it per line: the datastore reads and an App tail. A negated level is the inverted match, and an empty level still passes.
- `service.go:734` `keepPod` keeps a pod named in `Instance`. `translateInstanceFilter` (`:2431`) resolves public instance ids to pod names, and an unresolved set becomes `noSuchInstance`, which empties the read. For a negated set, a selector that resolves to nothing must exclude nothing, not everything. `collectPreDeployLogs` (`:2633`) and the follow paths (`:1484`, `:1734`) clone `Instance` as pod selectors.
- A project view's Instance values are project-wide ids (`projectLogInstance`, `ids.ServiceInstanceID`), resolved per resource. A negated instance from one resource must leave the other resources' lines alone.
- `service.go:536` `liveSubscribable` routes request filters to the request producer and `level` to app and request lines. A negated request field routes the same way.
- `datastoreFilters` (`service.go:1242`) admits level and instance on a datastore and refuses request filters. A negated request field is refused the same way, and the project view's `forResource` keeps it off datastores.

## Steps

1. Invert the level matcher for a negated level in `keep`.
2. Teach `keepPod` and the follow paths a negated pod set. Make `translateInstanceFilter` resolve a negated set without the `noSuchInstance` collapse.
3. Route negated request fields in `liveSubscribable` and `datastoreFilters`, so they select and refuse as their selecting forms do.
4. Tests through the existing fakes: an App's pod-log read, an App tail, a Postgres and a Key Value read each with negated level and instance. A request tail with a negated status code and path. An unresolved negated instance that drops nothing.
