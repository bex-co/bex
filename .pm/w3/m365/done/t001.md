## Objective

Turn on GitHub's secret scanning features for `bex-co/bex`, which are free for public repositories and all disabled today.

## Context

- `gh api repos/bex-co/bex -q .security_and_analysis` (2026-11-12): every `secret_scanning*` key is `disabled`. The session's `gh` credential has admin on the repository.
- The only scan today is the post-push gitleaks job in `.github/workflows/deploy.yml`.

## Steps

1. Record the current `security_and_analysis` object in this file.
2. `gh api -X PATCH repos/bex-co/bex --input -` with `{"security_and_analysis":{"secret_scanning":{"status":"enabled"},"secret_scanning_push_protection":{"status":"enabled"},"secret_scanning_non_provider_patterns":{"status":"enabled"},"secret_scanning_validity_checks":{"status":"enabled"}}}`.
3. Re-read the object and record it.
4. Prove push protection: push a throwaway branch whose only change is a file holding a provider's documented sample token format (never a real credential) and confirm the push is refused. Record the refusal text without the token, and confirm the branch does not exist on the remote.

## Result (2026-11-13)

- Before (07:15Z): `secret_scanning`, `secret_scanning_push_protection`, `secret_scanning_non_provider_patterns`, `secret_scanning_validity_checks` and `dependabot_security_updates` all `disabled`.
- `PATCH repos/bex-co/bex` with all four enabled answered 200, but only two took: `secret_scanning: enabled`, `secret_scanning_push_protection: enabled`. Non-provider patterns and validity checks stayed `disabled` on each retry. They need a paid GitHub Secret Protection licence, and `gh api orgs/bex-co -q .plan.name` is `free`. See the milestone's 2026-11-13 decision record.
- Push protection proven: a throwaway root commit holding a checksum-valid but fake GitHub PAT (generated locally, never a real credential, never printed) pushed to `refs/heads/pp-probe-1794554169` was refused with `GH013 … GITHUB PUSH PROTECTION … Push cannot contain secrets … GitHub Personal Access Token`, and `git ls-remote` shows no such branch.
