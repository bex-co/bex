## Objective

Replace the uv cutoff constants with Render's dated uv table, and start Erlang/OTP's 28.0.2 default at Render's 2025-06-12 instead of bex's 2026-11-16.

Render ([elixir-erlang-versions](https://render.com/docs/elixir-erlang-versions)): 28.0.2 for services created from 2025-06-12.
