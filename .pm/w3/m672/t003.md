## Objective

Native builds that select Node 24.14.1 or 24.21.0, whether as a dated default, a companion or an explicit `NODE_VERSION`, copy the repaired donor tree and run the Brotli probe at build time.

## Context

- `nativeRuntimeArtifacts` (`lego/operator/internal/build/nativebases.go`) maps exact upstream identities to donors. `commonNodeQualificationArtifacts` (`nativecommon_node_qualification_test.go`) must list exactly the same map for the families run.
- `commonNodeBackport` (`nativecommon.go`) gates both the probe (`node-check.js`) and `commonRuntimeProvenance` on majors 14/16/18/20. A 24.x is excluded today, and 24.22.1 and later must stay excluded.
- `resolveNativeCompanion` gives a companion the same dated default, so it has to reach the same donor.

## Steps

1. Add both identities to `nativeRuntimeArtifacts` and to `commonNodeQualificationArtifacts`.
2. Make the probe and provenance follow "this version has a reviewed backport donor" rather than the major alone, and keep the tenant-build compile fallback for EOL majors only.
3. Add the qualification cases: a Node service and one companion runtime on each release.
4. Dispatch `native-common-image.yml` with the `families` profile on the new map and record the run. Adopt nothing on a failure.
5. `make test` and `make lint` (from `lego/operator/`).

## Files

- `lego/operator/internal/build/nativebases.go`, `nativecommon.go`, `nativecommon_node_qualification_test.go`, `nativeutility_qualification_test.go`

## Acceptance criteria

- [ ] The generated Dockerfile for a no-signal Node service created 2026-05-01 copies the 24.14.1 donor and runs `node-check.js`. For 2026-10-01 it copies the 24.21.0 donor. For 2026-11-01 (24.22.1) it has neither.
- [ ] A Python service created 2026-10-01 gets the 24.21.0 donor for its companion Node.
- [ ] The families run passes on the new map.

## Out of scope

- Other exact 24.x patches below 24.22.1 (README, out of scope).
