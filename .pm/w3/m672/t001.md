## Objective

`deploy/native-base/node-brotli/patch.sh` rebuilds exactly Node 24.14.1 and 24.21.0 with Node's own 24-line decoder fix, keeping every other version the same, and refuses any other 24.x.

## Context

- The EOL cases swap `deps/brotli/c` for Google's 1.0.10 or 1.1.1 archive and assert that `process.versions.brotli` equals that release. The 24 line bundles 1.2.0. Node fixed it in-tree with `49dff6f57aa7` (decode.c, decode.h) and kept `1.2.0` as the reported version on 24.22.1.
- Official source checksums (nodejs.org `SHASUMS256.txt`, read 2026-11-26):
  - `node-v24.14.1.tar.xz`: `7822507713f202cf2a551899d250259643f477b671706db421a6fb55c4aa0991`
  - `node-v24.21.0.tar.xz`: `a6f54defb6fd7c84f41dba13d61e78e9b4e0961712cf61f29715c05f5ced94fc`
- Node 24 needs GCC 12.2 or newer, so it compiles in the `--common-bookworm` mode (Bookworm's GCC 12), not in the Bullseye EOL stage of `deploy/native-base/Dockerfile`. Final tenant images are Bookworm (the common foundation), so a Bookworm-built binary runs wherever these releases run.
- The node_zlib.cc constant edit is already in the script.

## Steps

1. Vendor `49dff6f57aa7`'s `deps/brotli` diff as a patch file beside the script, with its sha256 checked before it is applied. A GitHub-generated `.diff` is not a stable checksum input, so check in the file.
2. Add 24.14.1 and 24.21.0 cases with their source checksums. Apply the vendored patch to `deps/brotli` instead of replacing `c/`. Expect `process.versions.brotli` to stay `1.2.0`. Make every other 24.x exit as unreviewed.
3. Keep the post-build comparison of node, modules, napi, v8, uv, openssl, zlib and icu, plus the npm check, and record the patch's sha256 in `sources.txt`.
4. Build one of the two releases locally on Bookworm (this host is arm64) and run `check.js` on the result and on the original binary.
5. Add the sources and the 24-line recipe to `node-brotli/README.md`.

## Files

- `deploy/native-base/node-brotli/patch.sh`, a new patch file beside it, `deploy/native-base/node-brotli/README.md`

## Acceptance criteria

- [ ] The rebuilt 24.14.1 or 24.21.0 passes `check.js`, and the original official binary fails it.
- [ ] The version comparison and the npm check pass, and `process.versions.brotli` is `1.2.0`.
- [ ] A 24.x other than the two exits non-zero as unreviewed, and a changed patch file fails its checksum.
