# A refused resource link in an org workspace the caller can join says so, with Render's Join workspace

Why: Render's Access denied page names the workspace a refused resource belongs to and offers Join workspace when it is a public workspace in one of the caller's organizations; bex draws Access denied with the id alone (w3/m706), because bex-api sends no join hint.

Filed by w3/m706 t008 on 2026-11-27, from Render's dashboard bundle read the same day (`Error403-jHswJleF.js`, `errors-Bc7Ku8FH.js`; find the code by these strings).

- **Render:** a refused read's GraphQL error carries `extensions.joinHint.workspaceId`. `Error403` then runs `query joinHintLookup { organizations { id name workspaces(currentMember: false) { id name orgPrivacy } } }` and, when it finds the workspace, adds "It belongs to **`<workspace>`**, a workspace in **`<organization>`** that you can join." with a **Join workspace** button (`joinTeam`, then a reload; a failure toasts "We weren’t able to add you to this workspace. Try again?"), or "It belongs to **`<workspace>`**, a private workspace in **`<organization>`**. Ask an admin for an invite." with Return home. [resource-not-found.md § Access denied](../../docs/render-artifacts/resource-not-found.md#access-denied-error403-jhswjlefjs).
- **bex:** bex-api answers a resource in a workspace the caller is not in with `FORBIDDEN` and no hint (`lego/backend/internal/core/byid.go`, `pickOwner`); `AccessDenied` in `dashboard/src/common/components/resource-not-found.tsx` draws "You don’t have access to `<id>`." with Return home. bex already has org workspaces with `privacy` public or invite-only and a `joinWorkspace` mutation (`lego/backend/internal/members/organizations.go`, `dashboard/src/features/organizations/api/organizations.graphql`).
- **Done when:** a refused by-id read of a resource in an org workspace whose org the caller belongs to carries the workspace id as `extensions.joinHint.workspaceId` on GraphQL (and nothing on REST, which keeps Render's 403 body); the dashboard's Access denied adds Render's paragraph and Join workspace for a public workspace (joining reloads the page onto the resource) or the invite-only wording for a private one; a resource outside the caller's orgs keeps the bare Access denied; tests cover the three cases and the backend hint.
