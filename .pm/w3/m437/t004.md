## Objective

Disclose at install time, so a headless install (an agent in a container with an API key and no `CI` marker) can send after the user was told, instead of never sending (ADR113 G4).

## Context

- Upstream ships a hidden `analytics notice` command "Installers can invoke this command after install or upgrade" (`cmd/analyticsnotice.go`). It prints Render's text, so bex must replace it.
- The hidden `analytics` group also holds `analytics send`, which must stay upstream's. `main.go` `replaceCommand` swaps a root child (`skills` precedent); here only the `notice` child of `analytics` is swapped.
- `scripts/install-bex.sh` (tests: `scripts/install-bex.test.sh`) installs to `~/.local/bin`; `scripts/bex-cli-formula.sh` writes `Formula/bex.rb`, which `.github/workflows/cli-release.yml` pushes to `bex-co/homebrew-tap`.

## Steps

1. Replace the `notice` child of the `analytics` group with a Bex command that prints the t002 text (no TTY requirement) and writes both markers. A second call prints nothing.
2. `install-bex.sh`: after a successful install, run the installed binary's `analytics notice` with the user's `BEX_CLI_CONFIG_DIR` honoured. A failure never fails the install.
3. `bex-cli-formula.sh`: add `caveats` with the same text. Add a test that the generated caveats equal the Go constant (run the built binary's `analytics notice` with a temp config dir and compare).

## Files

- `lego/cli/main.go` (or a new `internal/disclosure` command), `scripts/install-bex.sh`, `scripts/install-bex.test.sh`, `scripts/bex-cli-formula.sh` and its test

## Acceptance criteria

- [ ] `bash scripts/install-bex.test.sh` shows the notice printed and the Bex marker written under a temp `BEX_CLI_CONFIG_DIR`.
- [ ] `bex analytics notice` on a clean `HOME` prints Bex's text and writes both markers; a second call prints nothing; `bex analytics send` is unchanged.
- [ ] The generated formula's caveats match the notice text (test).

## Out of scope

- A Homebrew `post_install` that writes the marker (ADR113 open question; the formula cannot write the user's home).
