2. With a fresh `BEX_CLI_CONFIG_DIR`, inside a pty: run `RENDER_LOG_ANALYTICS=1 bex workspaces -o json` twice. The first prints the Bex notice and sends nothing; the second logs `analytics response: 202 Accepted`.

4. With another fresh directory and no terminal: nothing is sent and no Bex marker exists afterwards.
5. Confirm the two stored events arrived (`bex_api_cli_telemetry_events_total` on production Prometheus, or the CLI usage board as an ops user). Record command, time and outcome lines only (`#NO-ARTIFACTS-IN-GIT`).
