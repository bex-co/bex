# Private-network port discovery: web services' extra listeners, UDP, declared-but-idle ports

Why: w3/m273 ships Render's runtime port discovery for private services and the web `:10000` alias, but ADR089 D3 phase 2 records gaps that still diverge from Render's private network (render.com/docs/private-network: "up to 75 open ports" on any service).

- A web service's extra private listeners (beyond its primary and 10000) are not discovered; `lego/operator/internal/controller/private_ports.go` scans private services only.
- Discovery is TCP connect only; UDP listeners are never found.
- A port the image declares but nothing listens on is still listed in `openPorts`.
- Each scanned listener sees a connect/close about every 2 minutes; check whether Render's scan is observable the same way before tuning.
