## Objective

Accept Render's query grammar wherever its links carry state.

## Context

- Render: `l=[["INSTANCE","<suffix>"]]` (log label filters), `r=<start>,<end>` (window), `eventTypes=` (events), `timeRange=` (metrics); find the encoders by `INSTANCE` and `eventTypes`.
- bex: `features/logs/lib/log-search.ts` (`parseLogSearch` already takes `r` and `t`), `features/metrics/lib/range.ts`, the Events page's filter search.

## Steps

1. Read Render's encoders and list each parameter and value form; record them in `dashboard-routes.md`.
2. Check each against bex's parsers and add what is missing: the `l` label array (instance first, then the labels bex supports), `eventTypes` mapped to bex's event names, `timeRange` on Metrics.
3. Ignore values bex cannot honour, and keep bex's own parameters working.

## Files

- `dashboard/src/features/logs/lib/log-search.ts`, `features/metrics/lib/range.ts`, the Events search parser
- `docs/render-artifacts/dashboard-routes.md`
