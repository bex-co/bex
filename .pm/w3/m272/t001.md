## Objective

Wrap the handler every API test builds so each `/v1` response matching a Render operation is validated (status + body) against the pinned spec with the existing helpers; a violation fails the calling test.

## Context

- `lego/backend/internal/api/server_test.go:187` `buildHandler` (shared by the API test files calling `do()`)
- Existing helpers: `renderSpec.validate` / `validateStatus` in `lego/backend/internal/api/conformance_kin_test.go:68,76`
- `TestRenderConformance` covers only 17 of 124 GET operations (`api/conformance_test.go:307-382`)

## Steps

1. Add a test-only `http.Handler` wrapper that matches the route to a Render operation and validates the recorded response.
2. Install it in `buildHandler`.
3. Report operation id, status and JSON pointer on failure.
