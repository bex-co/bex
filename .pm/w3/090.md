# Log explorer Copy logs writes Render's line format: `timestamp [resource] METHOD STATUS host+path text`

Why: a reader pasting copied logs into a ticket or a script gets Render's machine-readable ISO timestamps from Render, and bex's localized clock, `[instance]` tags and date rows instead.

Read from Render's dashboard bundle by w3/m528 (2026-11-20, `Logs-DOHYAXbe.js`, function `Dn`): Options ▸ Copy logs (`⌘⇧C`) writes each line as `${log.timestamp} ${En(log, {labelValue})}`, the record's own ISO timestamp, then `[resource name]` in a project view, the request's METHOD, STATUS and host+path, then the text with ANSI stripped. There is no instance tag and no date separator line. The toast reads `Copied logs` / `Couldn't copy logs`.

bex today: `logRowsText` (`dashboard/src/features/logs/lib/log-rows.ts`) writes each row as it reads: a date row per day, the dashboard-language clock (or none when timestamps are hidden), `[resource]`, `[instance]`, then the request parts and message. The row menu's Copy log line (w3/m528) already writes Render's `En` part (`logLineText`), so the two can share it.
