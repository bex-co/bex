# A suspended service's header has no actions and Render's suspension notice, on every type

Why: Render's header offers actions only while a service runs and puts a suspension notice with Resume under the facts; since w3/m555 a cron job's header does, but a suspended web service, private service, background worker and static site still show Connect, Resume and Manual Deploy.

- **Render** (bundle 2026-11-22, w3/m555 t001): the Server page passes `actions: state === "Running" && [Connect, Manual Deploy]` and `renderBanners` the suspension banner (`Lr`: "Manually suspended · You are not billed for suspended services. · Resume service" for a user suspension, others for billing, a removed card, crash loops and Render's own).
- **bex:** `dashboard/src/features/services/components/service-detail-header.tsx` keeps `ServiceConnectButton`, `ResumeServiceButton` and `ManualDeployButton` for a suspended non-cron service; `CronSuspendedNotice` (`cron-header-actions.tsx`) is the notice to reuse.
- **Done when** a suspended service of every type shows no header action and the notice (Render's title per suspender, the not-billed line, Resume service), its pending frame reserves the notice at 1440 and 390, the header tests cover each type, and ADR018 says so.
