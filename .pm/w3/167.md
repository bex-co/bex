# An organization the caller is not in reads "Couldn't load the organization / Try again in a moment"; its "Organization not found" state never draws

Why: bex-api answers an org the caller is not in, or one that does not exist, with `ORGANIZATION_NOT_FOUND`, and the org pages have a state for it ("Organization not found. It doesn't exist, or you're not one of its members."), but every org page draws the read-failure card instead, which tells the person to retry something that will never load.

Filed by w3/m705 t007 on 2026-11-28, from the production walk on pin `7d1dce861173` as the QA user: `/org/org-d0000000000000000000/workspaces`, `/members` and `/settings`, and Render's `/organization/<that id>/…` that open them, all drew "Couldn't load the organization / Try again in a moment" at 1440 and 390, on a full load and after a client-side navigation alike. GraphQL `organization(id:)` answered `data.organization: null` with `extensions.code: ORGANIZATION_NOT_FOUND` each time.

- **Cause:** `dashboard/src/features/organizations/lib/organization-route-loader.ts` reads `OrganizationDocument` with `errorPolicy: "all"`, which writes `organization: null` into the Apollo cache. `useOrganization` (`features/organizations/hooks/use-organization.ts`) then reads it `cache-first` (`PRIMED_FETCH_POLICY`): it gets `{ organization: null }` from the cache with no error, so `notFound` (`isNotFoundError(error)`) is false and `OrganizationPageShell` draws `OrganizationUnavailable` with `notFound={false}`.
- **Fix:** let a cached `organization: null` count as not found (the field is null only when bex-api refused it), or keep the loader's refused read out of the cache so the hook's own read carries the code; a transport failure, which leaves no data, still draws the read-failure card.
- **Done when:** an org the caller is not in, or no such org, draws "Organization not found" on Workspaces, Members and Settings on a full load and after a client-side navigation, a failed read still draws "Couldn't load the organization", and a test primes the route loader's cache before the hook reads it.
