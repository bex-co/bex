## Objective

Give the log explorers a range type that can be Live tail, a picker that lists it first, and URL parsing and writing that name it as a range, without changing Metrics.

## Context

- `RangeSelect` (`dashboard/src/features/metrics/components/range-select.tsx`) is shared by Metrics and every log explorer. Its options are `RANGE_PRESETS`, a separator and Custom; it takes a `bound` that disables presets past the plan's window.
- `RangeSelection = RangePreset | CustomRange` and the shared URL keys (`parseRangeSearch`, `rangeFromSearch`, `rangeToSearch`) live in `features/metrics/lib/range.ts`. Metrics must not accept the Live tail value.
- The service tab's URL: `parseLogSearch`, `logRangeFromSearch`, `logFiltersToSearch`, `CLEARED_LOG_SEARCH`, `logSearchEquals` (`features/logs/lib/log-search.ts`), with `live?: 0` beside `range`.
- A datastore tab's URL: `parseDatastoreLogSearch`, `datastoreLogSearchProps` (`features/logs/lib/datastore-log-search.ts`), range keys only.
- A project view's URL: `parseProjectLogSearch`, `projectLogRange`, `projectLogRangeSearch` (`features/logs/lib/project-log-search.ts`), the range as `r`.

## Steps

1. Add a log range type: Live tail, a preset or a custom range (for example `LogRange = LiveTailRange | RangeSelection`, with `isLiveTail`). Keep it in `features/logs/lib/`, so Metrics' types and parsers are untouched.
2. Give `RangeSelect` an opt-in Live tail entry, listed first and followed by a separator, with its own label ("Live tail", in all eight languages). It can be disabled with a reason (its `aria-describedby` pointing at the explorer's note). Metrics does not opt in.
3. Read and write it in the three URL shapes with the spelling t001 recorded. A `live=0` link opens paused on the range it names, and `live` gets an `undefined` tombstone so it leaves the URL on the first write. Write the default range as no key at all, so an unfiltered tab keeps a clean URL.
4. Unit tests for each parser and writer: the Live tail value, `live=0` on a preset, on a custom range and with no range, an unknown value, and Metrics refusing the Live tail value.
