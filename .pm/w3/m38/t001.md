## Objective

Add an internal bex-api verb that mints a per-session GitHub App installation token from the shipped ADR026 integration: scoped to the session's target repo, `contents:write` added (sessions push), and issued only when the session's push target matches `bex-agent/*` — server-side branch confinement at the mint, per ADR047 D2.

## Context

- Existing mint path: `lego/backend/internal/github/client.go` (installation tokens, 1h TTL, `contents:read`+`metadata:read`, minted per deploy in `internal/deploys/service.go`).
- GitHub installation tokens support `repositories` + `permissions` narrowing at mint time; branch-level confinement is bex policy (mint only for `bex-agent/*` session branches) + recommended tenant branch protection — the GitHub token itself cannot express branch scope, so record that honestly.
- Session identity: until w3/m39 lands, key the verb on sandbox/workspace identity (the m39 session record will slot in); keep the signature ready for a session id.

## Steps

1. Extend the github client with a session-token mint (repo narrowing, `contents:write`).
2. Policy check: refuse mints for sessions targeting non-`bex-agent/*` branches; audit-log every mint (actor, workspace, repo, session).
3. Docs note recommending default-branch protection to tenants.
