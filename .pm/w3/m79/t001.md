## Objective

Stand up the two auth/secret backends the agent-session gates and the model-mint handler require, scoped per `dev-N`, and flip the locally-run bex-api off insecure authz onto real OpenFGA.

## Context

- `enabled()` needs `Tuples != nil`, set only when bex-api has `BEX_OPENFGA_URL` (`cmd/api/main.go:611`); the gateway **requires** it with no bypass (`cmd/ssh-gateway/main.go:67`).
- bex-api resolves the OpenFGA store `bex` by name (`internal/authz/authz.go:236`). Seed with `scripts/authz-model.sh` (store + `deploy/gitops/authz/model.json` + bootstrap tuple). CI's pattern: `docker run -d openfga/openfga:latest run` (`.github/workflows/backend-test.yml:75`).
- The model-mint handler is wired only when `BEX_OPENBAO_URL` is set (`cmd/api/main.go:977`); it reads `agent-sessions/<ws>/model-key` (`internal/agentsession/model.go:114`).
- Setting `BEX_OPENFGA_URL` means dropping `BEX_ALLOW_INSECURE_AUTHZ` — authz becomes real, so the dev user must be a workspace member (written by the normal create-workspace flow).

## Steps

1. Run an OpenFGA container on a per-N port (in-memory engine, optional preshared key); seed via `scripts/authz-model.sh` with `OPENFGA_URL`/`OPENFGA_PRESHARED_KEY`.
2. Run an OpenBao dev-mode server (auto-unsealed) on a per-N port; expose `BEX_OPENBAO_URL`. Provide a helper to write the developer's provider key to `agent-sessions/<ws>/model-key` (field `BEX_AGENT_MODEL_API_KEY`).
3. Derive both ports from N (extend the port block); record in `ports.env`.

## Files

- `scripts/dev-env.sh` (per-N ports, service bring-up in the agents path), `scripts/dev-env/` templates as needed.

## Acceptance criteria

- [ ] OpenFGA reachable, store `bex` + model + bootstrap tuple seeded (idempotent re-run).
- [ ] OpenBao reachable and unsealed; a documented one-liner stores the BYO model key at `agent-sessions/<ws>/model-key`.
- [ ] bex-api starts with `BEX_OPENFGA_URL` + `BEX_OPENBAO_URL` set and `BEX_ALLOW_INSECURE_AUTHZ` unset.

## Out of scope

- Production OpenFGA/OpenBao (gitops-owned); OpenBao auto-unseal design (FUTURE-MAYBE).
