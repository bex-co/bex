## Objective

Complete the one unverified m79 path: use developer-supplied GitHub App credentials and an installation on a disposable repository to prove a local delivery session pushes its branch and opens a draft PR.

## Context

- The repo-less real-model path is already green and recorded in the milestone README; this task isolates the external GitHub credential/installation gate instead of leaving completed status and session-smoke work bundled into one partly-open task.
- `.pm/w3/dev-3/.agent/github-app.env` and `github-app.pem` are intentionally absent and gitignored. A normal `gh` user token cannot substitute for the App OAuth and installation-token paths.
- The runbook is `docs/runbooks/agent-sessions-local-dev.md`; the local stack reports `github.connected=false`, `modelKeyReady=true`, and `enabled=true` until these credentials are supplied.

## Steps

1. Stage a real GitHub App ID/slug, OAuth client ID/secret, private key, and installation for a disposable repository in dev-3's gitignored `.agent/` files.
2. Re-run `bash scripts/dev-env.sh 3 agent-up`, connect the workspace to the App installation, and confirm capabilities report `github.connected=true` and `ready=true`.
3. Create a delivery session against the disposable repository; prove the sandbox runs in `<ws>-sandbox`, the branch is pushed, and a draft PR is opened with the expected session metadata.
4. Record only non-secret evidence in the milestone README and update the local-dev runbook if the observed setup differs from it.

## Files

- `.pm/w3/m79/README.md`
- `docs/runbooks/agent-sessions-local-dev.md` (only if the live flow exposes drift)
- `.pm/w3/dev-3/.agent/` (runtime-only, gitignored credentials; never commit or print)

## Acceptance criteria

- [ ] `capabilities` reports `github.connected=true`, `modelKeyReady=true`, and `ready=true` for the local workspace.
- [ ] A local delivery session reaches `completed`, pushes its `bex-agent/*` branch, and opens a draft PR in the disposable repository.
- [ ] The recorded evidence contains no credential values, tokens, or private-key material.

## Out of scope

- Creating or committing a long-lived shared development credential; CI automation for the real-credential smoke.
