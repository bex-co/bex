## Objective

Wire the two cross-boundary links the in-cluster gateway ↔ host bex-api ↔ browser need: the novel in-cluster→host reverse hop for credential/model minting, and the host-reachable port-forwards for exec + attach.

## Context

- The gateway mints git/model credentials by calling bex-api at `BEX_AGENT_CREDENTIAL_API_URL` / `BEX_AGENT_MODEL_CREDENTIAL_API_URL` (`cmd/ssh-gateway/main.go:229,243`), prod-default `http://bex-api.bex-system.svc:8091/…`. Locally bex-api is a **host** process on `BEX_CP_PORT`.
- bex-api dials the gateway only for sandbox-exec (`:8081`, `internal/sandbox/exec.go:163`); the browser hits attach (`:8083`); git/model (`:8082/:8084`) are pod-dialed via cluster DNS and never forwarded.

## Steps

1. Create a Service/ExternalName/Endpoints in the gateway namespace pointing at the OrbStack host (`host.docker.internal` or the host IP the CAPD Docker network can reach) on `BEX_CP_PORT`; set the gateway's two mint URLs to it.
2. Add self-healing `forward` lines for gateway `:8081` and `:8083`; set bex-api `BEX_SANDBOX_EXEC_URL=http://localhost:<pf8081>/sandbox-exec` and `BEX_AGENT_SESSION_GATEWAY_URL=http://localhost:<pf8083>`.
3. Set bex-api `BEX_AGENT_GIT_PROXY_URL` / `BEX_AGENT_MODEL_PROXY_URL` to the gateway **Service DNS** (`http://<gw-svc>.<ns>.svc.cluster.local:8082|8084`) — pod-resolved, host-opaque.

## Files

- `scripts/dev-env.sh` / `scripts/dev-env/` (reverse-hop Service manifest, forwards, URL wiring).

## Acceptance criteria

- [ ] From the gateway pod, `curl <mint-url>/healthz`-equivalent reaches host bex-api `:8091`.
- [ ] `:8081`/`:8083` reachable on localhost; `:8082`/`:8084` are **not** forwarded (in-cluster DNS only).

## Out of scope

- NodePort exposure; TLS on the local hops.

## Completion note

A selectorless Service/EndpointSlice could not traverse the pod-to-OrbStack route. The shipped local-only path is a control-plane-pinned `hostNetwork` TCP proxy in `kube-system`, fronted by the stable `bex-dev-host-api` ClusterIP Service. `status` opens the reverse hop from the OpenSandbox pod, and live model credential minting proved the full request path.
