# 049 — Blueprints empty state and create button use different words than Render

Why: Render's empty Blueprints page reads "You haven't created any Blueprint instances yet." with a **+ New Blueprint Instance** button (logged-in Render workspace, 2026-10-29, `.playwright-mcp/m176-render-blueprints-1440.png`); bex's reads "No blueprints yet" with **New Blueprint** (dev-3, 2026-10-30, `.playwright-mcp/m176-bex-blueprints-empty-1440.png`). Render calls the deployed thing a "Blueprint instance" throughout its dashboard; a user following Render's docs looks for that word. Recorded in ADR018 § bex ahead of Render (w3/m176 t006).

- Align the empty-state title, the header/empty-state create button label (and its `+` icon, as on Env Groups) with Render's wording in en and zh; check the Blueprints list/detail headings for the same term.
- Keep "Generate Blueprint" (bex extension) as is.
- Update the Blueprints route tests that assert the old copy.
