## Objective

Pin what Render returns and shows, then decide which bex surfaces carry the display name vs the slug.

## Steps

1. Render OpenAPI `owner` object (`name`, `email`, `type`), the dashboard switcher/settings, `render workspaces` CLI output.
2. List every bex consumer of `tenants.name` (REST owners, GraphQL `workspace.name`, MCP, dashboard, App/resource naming, CLI launcher) and classify slug vs display.
3. Record the decision in ADR024 (members/workspaces) and ADR018.

## Acceptance criteria

- [x] Decision recorded with the consumer list.

## Done (2026-10-30, loopx w3) — contract, consumers, decision

**Render:** `owner` = `{id, name, email, type, ipAllowList?, twoFactorAuthEnabled?}` (`internal/api/openapi/render-public-api-1.json`); `name` is freeform, no slug field.

**bex today:** `tenants.name` (unique DNS label) is **not** used in any resource name — App CR names, namespaces (`<id>`, `<id>-sandbox`), labels, registry paths, Loki labels and Stripe customer names all use the tenant **id** (`store/reconciler.go:2229`, `TestProjectAppUsesTenantIDNotMutableTenantName`). The "becomes part of App CR names" claims in `workspaces/service.go:45-50`, `store/api.go:611-613`, `docs/ADR020-identifiers.md:66`, `docs/render-artifacts/workspace-lifecycle.md:69` and the dashboard slug help text are stale.

**Consumers of the name** (full inventory by subagent, 2026-10-30): signup/create/finalize/rename writes (`store/store.go:758,841`, `store/workspaces.go:55,159`, `store/workspace_creation.go:87,214`, internal `/v1/tenants`); reads into `WorkspaceView.Name` → GraphQL `Workspace.name`, MCP `list_workspaces`, Render `owner.name` (`workspaces/render.go:65`) and nested `owner.name` on apps/postgres/keyvalue/projects; `?name=` owner filter; CLI selectors (`api/cli_workspace.go:57-82` `X-Bex-Workspace`, `lego/cli/internal/bridge/workspace.go:73-101` `BEX_WORKSPACE` exact match on `owner.name`); delete confirmation phrase; invite preview/accept/email; account-deletion details; ~10 dashboard display sites, the rename form (DNS-label validation) and the create form.

**Decision** (rule: Render parity first; slug kept only where a machine needs a typable key):

| surface | carries |
| --- | --- |
| Render `owner.name` (top-level + nested) | display name |
| GraphQL `Workspace.name`, MCP `list_workspaces.name` | display name; new `slug` field (bex extension) |
| `?name=` owner filter, `BEX_WORKSPACE`, `X-Bex-Workspace` | match display name **or** slug (exact); ambiguity keeps `WORKSPACE_NAME_AMBIGUOUS` |
| rename verbs (REST/GraphQL/MCP/dashboard) | edit the display name (freeform: trimmed, 1–100 chars, not unique) |
| slug | set at create (derived from the display name, editable there), unique DNS label, immutable afterwards (bex extension) |
| delete confirmation phrase | display name (as on Render) |
| invites, emails, account-deletion details, dashboard display | display name |
| signup | display name "<Name>'s Workspace" (email local part when no name); slug stays the id for existing and signup rows |
