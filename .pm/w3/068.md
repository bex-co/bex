# 068 — Render's MCP now ships `run_cron_job` and `cancel_cron_job_run`; bex's tools of the same names take different arguments

Why: an agent written to Render's MCP calls `cancel_cron_job_run` with only a `serviceId`, and `run_cron_job` with `cancelActiveRun`. bex registers both names as extensions that need a `runId` or ignore the flag, so the agent's call fails or does something else. `render-mcp-drift.sh` is red until it is decided.

- **Source:** the w3/m367 closeout, 2026-11-17. `bash scripts/render-mcp-drift.sh` against upstream `render-oss/render-mcp-server` main `a18ef3ee8667` reported `added=[cancel_cron_job_run run_cron_job]`, with nothing removed or changed. The 2026-11-16 15:59Z scheduled `render-schema-drift.yml` run had a green MCP job, so upstream added both after that run. The pin `lego/backend/internal/api/openapi/render-mcp-tools.json` has 48 tools, captured by w3/m367 at `23fb336`.
- **Upstream contract (from the capture):**
  - `run_cron_job`: `serviceId` (required), `workspaceId`, `cancelActiveRun` (boolean). Hints: destructive, not idempotent.
  - `cancel_cron_job_run`: `serviceId` (required), `workspaceId`, and no run id. Hints: destructive, idempotent.
- **bex today (`lego/backend/internal/apps/mcp.go`):**
  - `run_cron_job` (`:728`, `serviceArgs`) always cancels an active run first and has no `cancelActiveRun`.
  - `cancel_cron_job_run` (`:766`, `cronJobRunArgs`) cancels one run by its `crr-` id.
  - Both are described as bex extensions.
- **Steps:**
  1. Read upstream's two handlers for what `cancelActiveRun: false` does while a run is active, and what the cancel does with no active run.
  2. Match them. `run_cron_job` takes `cancelActiveRun`. `cancel_cron_job_run` cancels the active run when given only `serviceId`, and keeps `runId` as an optional bex extension.
  3. Re-capture the pin with `scripts/render-mcp-capture.py`, as the drift script's own instructions say, and set the new sha256 in `render_mcp.go` and the script.
  4. Record round 7's follow-up in ADR018's MCP paragraph.
- **Done when:** `bash scripts/render-mcp-drift.sh` exits 0, and `go test ./internal/api/ -run 'TestMCPParity|TestRenderMCP|TestScopeMatrix'` passes. A test shows `cancel_cron_job_run {serviceId}` canceling the active run, and `run_cron_job` honoring `cancelActiveRun`, both on the same service verbs REST uses. ~1h.
- **Not here:** the Render CLI v2.37.0 drift, which the same day's `render-schema-drift.sh` reports, belongs to w22/m444.
