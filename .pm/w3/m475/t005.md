## Steps

3. Open `render logs -r <same>` interactively, scroll up past the first page (a pty-driven `script`/`expect` session is fine), and confirm older lines load with no error banner.
4. Record the commands and outcomes in the milestone README (no tokens). Clean up any key or session created.
