## Objective

Every response the cache answers from a stored entry carries `Age`: the upstream's Age at store time plus the whole seconds since it was stored, replacing any stored Age.

## Context

- RFC 9111 §4: when a stored response is used without validation, "a cache MUST generate an Age header field"; §5.1 defines it.
- `edgecache.go` `entry` (stored time exists as `expires` only) and `writeEntry`.

## Steps

1. Record the store time and the upstream Age in `entry`.
2. Set `Age` in `writeEntry` and on t001's 304.
3. Unit test with the injected clock (`Config.Now`).

## Record (2026-11-18)

Done. `entry.born` is the store time less the upstream's `Age` (`upstreamAge`: not a count of seconds is 0, too large is 2^31 - 1 per RFC 9111 §1.2.2). `writeEntry` sets one `Age` (whole seconds since `born`) on every HIT and HIT 304, replacing the stored value. A fill is generated by the app for that request, so it passes the upstream's own `Age` through unchanged and adds none (RFC 9111 §5.1). Tests: `TestEveryAnswerFromAStoredPageCarriesItsAge` (injected clock), `TestUpstreamAgeIsWholeSeconds`.
