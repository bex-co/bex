## Objective

Every way a Render sandbox starts or ends keeps the record current.

## Steps

1. Create writes the record with the created view
2. Terminate writes the full current view (rules, name, group) and the end time before the object is deleted
3. The lifetime reaper (`terminateObserved`) ends the record
4. The idle sweeper ends the record of an id OpenSandbox stopped listing (its own `expireTime` deletion) before pruning names, and stops pruning the executions of an ended sandbox
5. The expiry of records ended more than 30 days ago runs on the sweeper's pass
