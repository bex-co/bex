## Objective

A Postgres record per Render sandbox, keyed by its `sbx-` id: the workspace, owner, the public read shape at the time it was written, and when it ended.

## Context

- bex keeps no sandbox table today (`lego/backend/internal/sandbox/byid.go:38`); terminate deletes the OpenSandbox object, so every later read is 404
- Side tables (`sandbox_names`, `sandbox_executions`, `sandbox_group_members`) are pruned once an id stops being listed (`idle.go`)

## Steps

1. Migration: `sandbox_records (sandbox_id pk, workspace_id, owner, view jsonb, created_at, terminated_at)` with an index on `(workspace_id, terminated_at)`
2. Store methods: upsert a live record, end it (stamp `terminated_at` once, writing the view when the row is missing), read one ended record by workspace + id, list a workspace's ended records, find an ended record's workspace by id, and delete records ended more than 30 days ago

## Acceptance criteria

- [ ] A real-Postgres test writes, ends (twice: the first time wins), reads, lists and expires a record
