## Objective

Review the static-server path that proxies a rewrite to a tenant-chosen public URL and write down each attack, whether the code stops it, and the evidence.

## Context

- `lego/operator/internal/staticserver/proxy.go` (+ `proxy_test.go`): any method, `netutil.SafeDialContextFunc` (`lego/types/netutil/ssrf.go`) refuses non-public resolved addresses and dials the checked IP, redirects passed through, loop/hop-marker refusal, 32 MiB request / 64 MiB response / 60 s bounds.
- Validation: `apps.validatePublicRewriteHost` (`lego/backend/internal/apps/service.go`) and the dashboard rule editor (`dashboard/src/features/services/components/static-edge-rule-page.tsx`).
- Shipped by w8/184 on 2026-10-22; `.pm/w8/done/184.md:58` says "a dedicated review sign-off is still owed". The last review round predates it.
- Attacker: any tenant who owns a static site (open signup).

## Steps

1. Cover at least: DNS rebinding / resolve-then-dial TOCTOU; IPv6, IPv4-mapped and literal-encoding bypasses; headers forwarded upstream (Cookie, Authorization, X-Forwarded-*, Host, hop-by-hop); third-party `Set-Cookie` and other response headers landing on the static origin; loop and amplification; size and time limits under slow upstreams; open-proxy abuse (methods, bodies, any public host); whether proxied bytes are metered as the site's bandwidth (`lego/operator/cmd/egress-meter`).
2. For each, record verdict (blocked / finding / accepted) with file:line or a test.
3. Turn every finding into a t002 item.
