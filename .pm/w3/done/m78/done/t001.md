## Objective

Extend the push channel's event projection so the three observed-lifecycle facts the reconciler already produces (`server_available`, `service_suspended`, `service_resumed` — see ADR052 D1's checkpoint edge-trigger) become deliverable push events, alongside the already-projected `server_failed`.

## Context

- `lego/backend/internal/notifications/push_worker.go` `projectPushEvent` (~401–449): under `case store.EventSourceFact`, only `store.EventFactServerFailed` is mapped today (→ `DeliveryEventServerFailed`, title "Service unavailable", `DeliveryUrgencyCritical`).
- `lego/backend/internal/notifications/delivery_policy.go`: `DeliveryEvent*` constants (~43), the policy event vocabulary, and the default policy (~404) — the default event set (`deploy_failed`, `server_failed`, `cron_failed`) must stay unchanged (additive opt-in, no migration).
- `lego/backend/internal/notifications/graphql.go` (~47): the GraphQL delivery-event enum; REST `PATCH /v1/notification-settings/push` validates against the same closed set (`service.go` `UpdatePushSettings`).
- Facts are produced by `RecordObservedServiceState` (`store/event_facts.go:191`) called from `store/reconciler.go:286`; delivery-side webhook mapping already exists (`webhooks/service.go` `factEvents`) — webhooks need no change.
- Urgency/title defaults (from the m78 handoff): `server_available` → "Service recovered", `DeliveryUrgencyImportant` (it closes a Critical page); `service_suspended`/`service_resumed` → Routine.

## Steps

1. Add `DeliveryEventServerAvailable`, `DeliveryEventServiceSuspended`, `DeliveryEventServiceResumed` to `delivery_policy.go`'s vocabulary (policy-selectable, NOT in the default set).
2. Map the three fact types in `projectPushEvent` with the titles/urgencies above; deep-link route = the existing service route (same shape `server_failed` uses).
3. Extend the GraphQL enum and confirm REST validation accepts the new values and rejects unknowns unchanged.
4. Unit tests: projection per fact type; default policy unchanged; policy round-trip with the new events.
