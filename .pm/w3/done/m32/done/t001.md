## Objective

Package the `opensandbox-server` PyPI package (today run only via host `uvx`) into a container image, pushed to the in-cluster Zot — the prerequisite for running the control-plane server in-cluster (ADR042 D1).

- No `opensandbox-server` container image exists today; both start scripts use `uvx --from opensandbox-server`.
- In-cluster Zot: `zot.bex-registry.svc:5000`; push via the `bex-registry-push` pattern (`scripts/registry-secrets.sh`).

## Steps

1. Write `deploy/opensandbox/server.Dockerfile` packaging `opensandbox-server` (+ its deps) on a minimal base.
2. Build + push to Zot; record the image tag.

## Files

- `deploy/opensandbox/server.Dockerfile`
