## Objective

Introduce one internal event-emission point that fires on the write-path transitions Render's outbound webhooks notify on (deploy started/ended, service suspend/resume/restart, manual scale, autoscaling config/start/end, cron-run completion), and have both this milestone's delivery worker and `w3/m7`'s service-events feed consume it — a single instrumentation pass, not two.

## Context

- `w3/m7` (service events feed) is composing deploy transitions (`w2/m5`) + audit log (`w4/m10`) into a per-service read feed at the same time this milestone lands — check its state before duplicating write-path hooks; if `w3/m7` already introduced an internal event abstraction, wire onto it rather than building a second one.
- Deploy lifecycle lives in `lego/backend/internal/deploys/`; suspend/resume/restart and scale mutations live in `lego/backend/internal/apps/`; autoscaling in whatever package `w1/m20` landed; cron-run completion in the cron reconciler path.
- Render's actual event types (verified live from render.com/docs/webhooks 2026-07-12): `build_started`, `build_ended`, `deploy_started`, `deploy_ended`, `server_failed`, `server_available`, `server_restarted`, `service_suspended`, `service_resumed`, `instance_count_changed`, `autoscaling_started`, `autoscaling_ended`, `autoscaling_config_changed`, `cron_job_run_started`, `cron_job_run_ended`. Scope bex's initial set to what already has a bex write-path hook; don't invent hooks for events bex has no equivalent transition for.

## Steps

1. Check `w3/m7`'s current implementation state; align on one shared internal event type/interface if it exists.
2. Define bex's internal domain-event struct: `{type, timestamp, serviceID, serviceName, data}`.
3. Add emission calls at each existing write-path transition (deploy start/end, suspend/resume/restart, scale, autoscaling change, cron run end).
4. Fan the emitted event out to: (a) the webhook delivery queue (this milestone), (b) whatever consumer `w3/m7` needs (if not already wired).

## Files

- `lego/backend/internal/deploys/`, `lego/backend/internal/apps/`, cron reconciler package, autoscaling package
- new shared event-emitter package (or extend `w3/m7`'s if it exists)

## Acceptance criteria

- [ ] Each listed transition emits exactly one internal event.
- [ ] No duplicate instrumentation of the same write path if `w3/m7` already added a hook there.
- [ ] Emission is fire-and-forget from the caller's perspective (doesn't block or fail the underlying write on delivery-queue errors).

## Out of scope

- The delivery worker's retry/backoff logic — t003.
- Render's Postgres/KeyValue-specific event types — deferred, not in this milestone's initial set.
