## Objective

Extend the shared `EmptyState` with an optional primary (and secondary) action, and render the Overview, Blueprints and Env groups empty states through it, so ADR075 D1's actions land in one component instead of three inline blocks.

## Context

- `dashboard/src/common/components/empty-state.tsx:24-28` (`title`, `description`, `iconName`); used by `features/deploys/…` and `features/logs/…`.
- Inline empties: `routes/index.tsx:256-260` (`projects.emptyTitle/Body`), `routes/blueprints.tsx:114-118` (`blueprints.emptyTitle/Body`), `routes/env-groups.tsx:160-165` (`envGroups.emptyTitle/Body`).

## Steps

1. Add an optional `action` (and `secondaryAction`) prop rendering a `Button`/`Link`; existing callers stay unchanged.
2. Replace the three inline empties with `EmptyState`, preserving their current text and layout.

## Files

- `dashboard/src/common/components/empty-state.tsx`
- `dashboard/src/routes/index.tsx`, `routes/blueprints.tsx`, `routes/env-groups.tsx`

## Acceptance criteria

- [ ] Existing `EmptyState` callers render identically (tests unchanged and passing).
- [ ] The three pages render their empty state through `EmptyState` with no visual regression.

## Out of scope

- Wiring the actions (t002).

## Done (2026-10-21)

**Deviation, recorded in ADR075 §D1 + D2 implementation:** the three new-user empties are page-specific inline blocks, not `EmptyState` cards, and their pending skeletons are sized to that markup — so no action slot was added to `EmptyState` (nothing would use it) and the pages were not migrated onto it (that would change their layout). Each action was added inside the existing empty block instead (t002).
