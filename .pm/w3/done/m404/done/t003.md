## Objective

Make sure every `bex agent` path that can outlive 15 minutes goes through the refreshing auth.

## Context

- `lego/cli/internal/agent/stream.go` `streamUntilSettled` mints an attach ticket per reconnect (bearer), then streams with `X-Bex-Agent-Ticket`.
- `watch.go`/`lifecycle.go` wait and poll loops; `chat.go` (line mode, slash commands); automations `runs`/`run --wait` paths.

## Steps

1. List every loop or long-lived call in `lego/cli/internal/agent/` and confirm each request uses the shared `api` (no copied bearer).
2. Check a stream connection that outlives the ticket: the reconnect mints a fresh ticket through the refreshing auth.

## Files

- `lego/cli/internal/agent/*.go` as found.

## Acceptance criteria

- [x] No request in the package carries a bearer captured before the run started.
- [x] A test drives `streamUntilSettled` across a token expiry and a reconnect.

## Out of scope

- Server-side ticket lifetimes.

## Result (2026-11-26)

Every bearer request in `lego/cli/internal/agent/` goes through `api.do`, and so through `login`: session reads, wait and poll loops, chat's steer, queue, stop and cancel, automations and attachments. The stream itself carries only its ticket (`streamOnce`), signed downloads carry no bearer, and `ssh`/`open --desktop` hand off to another program. `TestAStreamOutlivesItsTokenAndReconnectsWithAFreshOne` drives `bex agent logs --follow` through a connection that outlives the token and drops. The reconnect's ticket mint and the session reads carry a refreshed bearer, and no dead one is sent.
