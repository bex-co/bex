# Log Streams — forward logs to external observability tools (Render parity)

Render's "Log Streams" forwards service logs to the customer's own observability stack (Datadog etc., syslog-style endpoint). The other half of w3/001's v0 deferral ("remote-write integrations"). Sensible only after (or alongside) w3/m5 — the shipper deployed there (Alloy/Promtail) is the natural forwarding point; a per-tenant destination needs the control-plane store for config. Park until m5 lands; promote then with the tenant-config question answered.

Source: `/pm-brainstorm for w3` 2026-07-09; w3/001 deferral; Render Log Streams docs.
