## Objective

Translate the service sub-paths whose names or shapes differ, instead of copying them.

## Context

- `common/lib/render-alias.ts` `redirectRenderAlias`; the Postgres and Key Value maps from w3/m641 and m649 are the pattern (`docs/render-artifacts/postgres-dashboard.md:80`).
- Render's `xSe` and its period table `eC` (find by `` window.location.pathname.replace(`/${e}` ``); bex's Metrics window params in `features/metrics/lib/range.ts`.
- Instance names: Render's `:instanceId` is the instance suffix it shows; bex's `?instance=` takes the name bex's Shell lists. Confirm the two match or map them.

## Steps

1. Record Render's full service route table and the period table in `dashboard-routes.md`.
2. Add a per-segment sub-path map: `disks` → `disk`, `metrics/<period>` → `metrics` with the mapped window, `shell/<id>` → `shell?instance=<id>`; leave matching names as they are.
3. Apply it to every service segment (`web`, `worker`, `pserv`, `cron`) and to static sites where a sub-path applies.
