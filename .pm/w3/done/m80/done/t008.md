## Objective

Standing closing task. Lock the milestone's behavior with meaningful tests that assert real failure modes — no snapshot-everything, no tautologies. The three behaviors that must not regress: (1) a 401 classifies as auth-expired and redirects with the correct `next=` (and `aal=aal2` when owed) while a 5xx does not; (2) load-error surfaces render the session-expired card for auth errors and the network card otherwise; (3) the re-auth draft survives the round-trip and clears on save/discard.

## Context

- Dashboard test setup: `dashboard/` (`yarn test`); follow existing patterns for hook/component tests in `dashboard/src/common/hooks/` and `dashboard/src/features/services/`.
- Error-link unit tests can drive a mocked link chain with fabricated 401/503/500 `networkError`s — no live Kratos needed.
- The memo-expiry guard (t004) is testable with an injected `expiresAt` in the past.

## Steps

1. Error-link tests: 401 → invalidate + redirect target assertion (path, `next`, aal); 503/500 → no redirect; already-on-`/auth/*` → no loop.
2. Error-surface tests: auth-shaped error renders "Your session has expired" + Sign-in href; network-shaped renders existing retry card; not-found path unchanged.
3. Session-state tests: stale-`expiresAt` cache miss; `expiresAt` parsed into `SessionState`.
4. `useReauthDraft` tests: save/restore/TTL/clear-on-success, and no restore on a clean visit.
