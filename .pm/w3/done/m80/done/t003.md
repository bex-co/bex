## Objective

Make mid-session expiry rare for active users. Today no session lifespan is configured anywhere, so Ory Kratos's 24h default applies with no sliding extension — an active user is hard-logged-out exactly 24h after login. Configure an explicit policy per OWASP (idle/sliding window + absolute cap, enforced server-side): sessions extend on activity, with a hard absolute maximum.

## Context

- Kratos values (cookie `bex.co`, `SameSite=Lax`, `whoami.required_aal: highest_available` — keep both): `deploy/gitops/base/values/kratos.values.yaml:209-216`; no `session.lifespan` or `earliest_possible_extend` in base or local values.
- Kratos supports sliding sessions natively: `session.lifespan` + `session.earliest_possible_extend` + the session extend admin endpoint; the dashboard's per-navigation `whoami` (`dashboard/src/routes/__root.tsx:20-48`) is the natural activity signal.
- Proposed posture (operator may adjust): lifespan **168h (7d)**, `earliest_possible_extend` set so a session refreshed during normal use keeps sliding, with an absolute cap of **30d** — low-risk B2B band per OWASP; sessions stay stateful/revocable (Settings device panel already lists/revokes: `dashboard/src/common/server-fn/kratos-sessions.ts:42-43`).
- Auth design record: `docs/ADR012-auth.md` §8 documents token TTLs; session lifespan is currently undocumented.

## Steps

1. Add explicit `session.lifespan` + `session.earliest_possible_extend` to `kratos.values.yaml` (base; mirror in local values if the local overlay pins session config).
2. Wire the extension trigger: confirm whether Kratos extends on `whoami` alone at this version or requires the refresh endpoint; if the latter, extend from the dashboard's session fetch server-fn when inside the extend window.
3. Document the chosen idle/absolute posture and rationale in `docs/ADR012-auth.md` (new sessions subsection next to §8's token TTLs).
4. Validate with `scripts/gitops-validate.sh` and confirm Argo sync applies cleanly (values-only change; watch for the m13-class Helm templating traps).

- [ ] ADR012 records the idle/absolute posture.
