# A cron job's `/plan` URL opens a plan picker, as Render's `/cron/<id>/plan` does

Why: w3/m554 left one difference in a cron job's routes. Render still renders a standalone plan picker at `/cron/<id>/plan`; bex lands that URL on the Settings page's Compute section, collapsed.

- **Render** (bundle read 2026-11-22: `index-BR2q8yex.js`'s cron route table maps `plan` to `CronJobUpdatePlan-DTFzWcJp.js`): the cron job's plan cards with Cancel (back to `settings`) and change-plan, which opens the new build; a suspended cron job's `/plan` redirects to `settings`. The cron title map gives it no sidebar title (`"/plan": null`), and the header badge and the upgrade dialog link `settings#compute`, so the page is reached only by URL. Not walked signed in.
- **bex:** `/services/<id>/plan` → `/compute` (`redirectToComputePage`) → `/settings#compute` (`redirectCronCompute`, w3/m554), where Edit opens the same cards (`ComputePlanSection`).
