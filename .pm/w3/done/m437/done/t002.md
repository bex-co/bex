## Objective

Show the Bex disclosure once per machine, where and when Render shows its own: after the command's output, on stderr, only for a notice-eligible command with a terminal on stderr and outside CI.

## Context

- Render's conditions (`cmd/execution.go:28-69`, `internal/analyticsnotice`): every command is notice-eligible except the hidden `analytics` tree and shell completion; `login` and `logout` are notice-eligible though not analytics-eligible; nothing prints without a terminal on stderr or in CI; the run that prints sends nothing.
- Render's copy (`internal/analyticsnotice/notice.go`) names Render as the recipient and links `render.com/docs/cli#usage-telemetry`. That is ADR113 G2.
- `main.go` already has `stderrIsTTY()` and resolves the invoked command with `cmd.RootCmd.Find(os.Args[1:])` (see `opensDashboard`).

## Steps

1. After `cmd.Execute()` returns: if `CI` is not truthy, `disclosure.Disclosed()` is false, stderr is a terminal, and the command is notice-eligible, print the notice to stderr and call `MarkDisclosed()`.
2. Text (one constant, reused by t004): "The bex CLI collects usage data on commands and performance to help improve it. The data goes to Bex, not to Render. It records command names, outcomes, durations and environment signals, never arguments or values. No data has been sent yet. To opt out, set BEX_CLI_DISABLE_ANALYTICS=1 or DO_NOT_TRACK=1. Learn more: https://github.com/bex-co/bex/blob/main/docs/bex-cli.md#cli-usage-telemetry".
3. Opted-out variant: "Telemetry is disabled, so nothing is sent", then how to re-enable it, naming the variable the user actually set (`BEX_CLI_DISABLE_ANALYTICS`, `DO_NOT_TRACK` or `RENDER_CLI_DISABLE_ANALYTICS`), from what t001 recorded before the gate set anything.
4. Render the block like upstream's when stderr supports colour, plain otherwise. Nothing goes to stdout.
5. A command that replaces the process (`bex glm`, `bex edit`, `bex agent ssh`) never returns here, so it stays gated until a later run shows the notice. Leave it that way.

## Acceptance criteria

- [ ] With a terminal on stderr (a pty in the test, or a seam on `stderrIsTTY`) and a clean `HOME`: the first `bex workspaces -o json` prints the Bex notice once on stderr, keeps stdout valid JSON, stores no event and writes the Bex marker; the second run prints nothing and stores one event.
- [ ] `BEX_CLI_DISABLE_ANALYTICS=1` on a clean `HOME` prints the opted-out variant naming `BEX_CLI_DISABLE_ANALYTICS`.
- [ ] `bex __complete …` and `bex analytics send …` never print it.
- [ ] The string "The Render CLI collects" never appears in any run's output.
