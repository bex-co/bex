## Objective

Implement ADR113 D5's gate in the launcher, without patching upstream: a run sends telemetry only when `CI` is truthy or the Bex notice was already shown on this machine, and upstream's own notice never prints.

## Context

- Upstream's gate (render-oss/cli `4fd34231b637`): `internal/analyticsnotice` `ShowIfNeeded`/`CanSend`, called from `cmd/execution.go:28-69`. Its marker is `<state>/analytics/notice-shown`, where `<state>` is `config.StateDir()` (`pkg/config/dirs.go:34`, `$RENDER_CLI_CONFIG_DIR/state`). The bridge maps that to `~/.bex/state` (`lego/cli/internal/bridge/bridge.go` `Apply`, w8/018).
- `config.StateDir()` is exported, so the launcher can resolve the same directory after `bridge.Apply()` instead of re-deriving it.
- Consent: `bridge.go:113-121` maps `BEX_CLI_DISABLE_ANALYTICS` onto `RENDER_CLI_DISABLE_ANALYTICS` unless the latter is set. Upstream reads `RENDER_CLI_DISABLE_ANALYTICS` and `DO_NOT_TRACK` (`pkg/cfg/cfg.go:45-53`); CI is `cfg.IsCI()` (`CI` = `1` or `true`, any case).
- The send subprocess re-executes this binary with `RENDER_CLI_ANALYTICS_SUBPROCESS=1` (`pkg/analytics/subprocess.go`), so `main` and the bridge run again inside it.
- Test harness: `lego/cli/main_test.go` (`telemetryStub`, `telemetryEnv`, `awaitEvents`, `seedNoticeMarker` at ~:697).

## Steps

1. Add a small package (for example `lego/cli/internal/disclosure`) with `Disclosed() bool`, `MarkDisclosed() error` and `EnsureUpstreamMarker() error`. The Bex marker is `<state>/analytics/bex-notice-shown`; both paths come from `config.StateDir()`.
2. In `main.go`, right after `bridge.Apply()`: record which opt-out variables the user set (t002 needs the original values), call `EnsureUpstreamMarker()` best-effort, then, unless `CI` is truthy, `Disclosed()` is true, or this is the send subprocess, set `RENDER_CLI_DISABLE_ANALYTICS=1` for this process only. Never change an opt-out the user set.
3. Do not write the Bex marker here: t002 writes it only when the notice was actually shown.
4. Update `seedNoticeMarker` in `main_test.go` to seed both markers, so the existing telemetry tests keep their meaning.

## Files

- `lego/cli/main.go`, `lego/cli/internal/disclosure/` (new), `lego/cli/main_test.go`

- [ ] With both markers present, `TestBexEmitsTelemetryToBexAPI` and `TestBexOptOutSuppressesTelemetry` pass unchanged in intent.
