## Objective

Add a dedicated Logs tab to managed-Postgres detail with range/search controls,
timestamped lines, loading/empty/error states, and an honest unavailable state
when no log source is configured.

## Acceptance criteria

- [x] The tab is directly linkable and covered by component/route tests for
      data, filters, empty, unauthorized, and degraded states.

## Completion

The Database detail route owns `?tab=logs` and renders a dedicated viewer with
Last hour/6h/24h, observed-instance, and debounced search controls. Component
and route tests cover populated, empty, forbidden, unconfigured-source, generic
error, and direct-link search-state behavior in both supported locales.
