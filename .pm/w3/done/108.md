# Manual Build and Manual Deploy are disabled while a workspace's pipeline minutes are spent, as Render's are

Why: Render disables Manual Build with "You've used up the maximum number of pipeline minutes specified by your spend limit. Learn more."; bex's buttons stay enabled and the build is refused only after the click, because the dashboard cannot read the state.

- **Render** (bundle 2026-11-22, w3/m555 t001): `index-*.js` `Ohe` (a cron job's Manual Build) and `Ude` (a build source's) take `pipelineMinutesExceeded` and wrap the disabled button in `zk`, the popover above, linking the workspace's pipeline minutes page.
- **bex:** the operator refuses such a build and bex-api records `pipeline_minutes_exhausted` (`lego/backend/internal/events/service.go`), but no REST, GraphQL or MCP field says the minutes are spent before a build. `dashboard/src/features/deploys/components/manual-build-button.tsx` and `manual-deploy-button.tsx` gate only on the `deploy` decision.
- **Done when** bex-api exposes whether the acting workspace's pipeline minutes are spent (a field or a `deploy` precondition, on GraphQL and REST), Manual Build and Manual Deploy are disabled with Render's text and link while they are, tests cover both states, and ADR018 says so.
- Filed 2026-11-22 by w3/m555 t008.

**Done 2026-11-25.** Render's bundle re-read the same day (`index-D5V4ZgbE.js`, `hooks-CmQmvx2s.js`): `pipelineMinutesExceeded` comes from the owner's build-plan usage, and its notice `Fk` wraps a cron job's Manual Build (`h_e`), a build source's (`pfe`) and the whole Manual Deploy menu (`sFe`, Restart included), linking "pipeline minutes" to the workspace's Build Pipeline settings and "Learn more" to Render's docs. bex-api now answers `pipelineMinutesExceeded` on the workspace's limits read (REST `GET /v1/owners/{ownerId}/limits`, GraphQL `workspaceLimits`, MCP `get_workspace_limits`): true while an App of the workspace that is not being deleted carries the buildminutes sweeper's current-month mark, the one the operator refuses a build on. The dashboard disables Manual Build, Manual Deploy and a build source's Trigger Build with Render's text and both links while it holds. Not checked on production, where no workspace was out of minutes. ADR018 (gap backlog, workspace limits, cron job rows) and ADR030 §13 record it.
