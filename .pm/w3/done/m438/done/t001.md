## Objective

Add `bex_api_cli_requests_total{client}` so telemetry volume can be compared with the CLI traffic bex-api already sees (ADR113 D6).

## Context

- Origin middleware: `lego/backend/internal/api/httpmetrics.go` (`Middleware`, `surfaceOf`, `OriginMetrics`, registration at ~:200).
- The CLI is recognized by `User-Agent: render-cli/…` (`core.cliUserAgentPrefix`, `lego/backend/internal/core/product_surface.go`); the launcher adds `X-Bex-CLI-Version` (`clitelemetry.BexVersionHeader`).

## Steps

1. Add the counter with one label, `client`: `bex` when the prefix and the release header are present, `render-cli` with the prefix alone. Count REST-surface requests only, excluding `POST /v1/cli-telemetry-events`.
2. Nil-safe like the other observers; register it with the origin metrics.

## Files

- `lego/backend/internal/api/httpmetrics.go` and its test

## Acceptance criteria

- [ ] Tests: prefix + header → `bex`; prefix alone → `render-cli`; a browser UA, GraphQL, MCP and the telemetry route itself → no increment.
- [ ] No identity, path or version becomes a label.

## Result (2026-11-16)

`bex_api_cli_requests_total{client}` in `lego/backend/internal/api/httpmetrics.go`: counted in the origin middleware for REST requests whose User-Agent is the CLI's (`core.IsCLIUserAgent`, now shared with the creation-surface derivation), `client` from `clitelemetry.Client` (the release header present or not), whatever the answer. The telemetry deliveries are left out by method and path (`clitelemetry.IngestRoute`), so a delivery to a missing route is left out too. Both clients are exported at 0 when the process starts. `TestOriginMetricsCountsCLIRequestsByClient` covers launcher and Render CLI (including an unrouted path) as counted, and a browser UA, no UA, a UA that only contains `render-cli/`, GraphQL, MCP, the device-flow route and the telemetry route (with and without the header) as not counted; `TestOriginMetricsExportCLISeriesAtZero` pins the zero export. Removing the route exclusion or the header split makes the test fail.
