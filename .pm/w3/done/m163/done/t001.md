## Objective

Replace the payment wall's "Self-host bex instead" link text with copy that states the real consequence — the account is deleted — and add the strings the confirmation dialog needs.

## Context

- Current strings, `dashboard/src/features/onboarding/locales/en.ts`:
  - `onboarding.paymentSetupSelfHostHint` — "Prefer not to add a card? bex is open source — run it on your own infrastructure for free."
  - `onboarding.paymentSetupSelfHost` — "Self-host bex instead"
- Mirror file: `dashboard/src/features/onboarding/locales/zh.ts`.
- Every string carries a `description` for translators; keep that convention.

## Steps

1. Update the two existing strings and add five for the dialog (title, body, typed-confirmation prompt, destructive confirm, dismiss).
2. Mirror all of them into `zh.ts`.
3. Keep the ADR075 reference in the hint's `description`.

Agreed English copy:

- Hint — "Prefer not to add a card? bex is open source — run it on your own infrastructure, free and unlimited."
- Action — "Delete this account and self-host"
- Dialog title — "Delete this account and self-host?"
- Dialog body — "This permanently deletes your bex account and workspace. You were never charged, and nothing is kept. We'll send you to the self-hosting guide — bex runs free on your own infrastructure, with no limits."
- Prompt — "Type {email} to confirm"
- Confirm — "Delete account and continue"
- Dismiss — "Keep my account"

Agreed Chinese copy:

- Hint — "不想绑卡？bex 是开源的——部署在你自己的基础设施上，免费且无限制。"
- Action — "删除账号并改为自托管"
- Dialog title — "删除账号并改为自托管？"
- Dialog body — "这将永久删除你的 bex 账号和 workspace。我们从未向你收费，也不会保留任何数据。随后会带你去自托管指南——bex 在你自己的基础设施上免费运行，没有任何限制。"
- Prompt — "输入 {email} 以确认"
- Confirm — "删除账号并继续"
- Dismiss — "保留我的账号"

Three deliberate choices worth preserving if the copy is revised later: "You were never charged" answers the wall's single biggest anxiety; "free and unlimited" states self-hosting's full value where the old copy said only "free"; and the action label carries the word "delete" rather than hiding the consequence behind "instead".
