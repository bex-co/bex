## Objective

Ship the session lifecycle surface: `POST /v1/agent-sessions` (create: repo, branch, prompt, agent config), `GET /v1/agent-sessions` + `/{id}`, and cancel — with GraphQL and MCP twins exposing the same fields, semantics, and error shapes. Create provisions the session sandbox from the m37 template image through the existing OpenSandbox lifecycle client (reserved-metadata stamping, `<ws>-sandbox` namespace); cancel terminates it.
