## Objective

A suspended `static_site` currently presents Traefik's default self-signed cert (`CN=TRAEFIK DEFAULT CERT`, i.e. a browser TLS error for visitors) and returns a bare `404 page not found`. The Settings suspend copy meanwhile promises "Its URL and certificates are kept, and you can resume it at any time." Resolve the mismatch: either keep the host served on its managed (Let's Encrypt) cert with a branded "service suspended" page, or — if the maintenance-page route is out of scope for this milestone — correct the dashboard copy so it stops claiming the cert is kept while suspended. Resume must restore normal serving.

## Context

- Verified live 2026-08-21 on `parity-static-site.onbex.co`: while suspended, `openssl s_client` shows `CN=TRAEFIK DEFAULT CERT` and `GET /` returns `404 page not found` (19 bytes); after Resume, `issuer=… Let's Encrypt` and content/rules return.
- Root cause hypothesis: on suspend the operator removes the static host's Ingress backend/route, so Traefik has no cert/route for the host and falls back to its default cert.
- ADR029 already defines a maintenance alias destination: `bex-maintenance-* → bex-activator.bex-system.svc.cluster.local:8888`. A suspended static site could route to it (a compute service's suspend path may already do this — confirm and reuse).
- Settings copy lives in `dashboard/src/features/services/locales/en.ts` ("certificates are kept" / "stop it from serving") + `zh.ts`.

## Steps

1. Reproduce: suspend a `static_site`, capture cert issuer + body; compare with a suspended web service's behavior.
2. Decide (record the choice in the milestone/ADR): (a) route the suspended static host to the maintenance activator so it serves a suspended page on the managed cert, or (b) scope this task to fixing the misleading copy only.
3. Implement the chosen path in the operator reconcile (`lego/operator/internal/controller/` app/static reconcile + `maintenance_mode` handling) and/or the dashboard copy.
4. Verify resume restores serving + rules on the managed cert.

## Acceptance criteria

- [ ] A suspended static site either serves a suspended page over its valid managed cert (no TLS error), or the dashboard no longer claims certs are kept while suspended.
- [ ] Resume restores `200` + edge rules on the Let's Encrypt cert (regression-tested).
- [ ] The decision (maintenance page vs copy-only) is recorded in the milestone README / ADR029.

## Out of scope
