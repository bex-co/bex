## Objective

Expose Render's **Clear build cache & deploy** (`clearCache`) where bex is currently missing it: the dashboard Manual Deploy menu (which today offers only "Deploy latest commit" + "Restart service") and MCP `trigger_deploy`. REST and GraphQL already accept `clearCache`; this closes the two surfaces that don't.

## Context

- Verified live 2026-08-21: the Manual Deploy dropdown has no clear-cache option.
- The MCP gap is already self-documented at `lego/backend/internal/api/mcp_parity.go:120`: "`clearCache` reaches REST and GraphQL but was never wired into the MCP adapter despite ADR018's w2/m30 row — an adapter gap, filed for repair."
- `clearCache` plumbing exists in `lego/backend/internal/deploys/service.go` + `rest.go`.

## Steps

1. Add `clearCache` to the MCP `trigger_deploy` tool args and pass it through to the deploy service; remove/adjust the `mcp_parity.go:120` "filed for repair" note.
2. Add a "Clear build cache & deploy" entry to the dashboard Manual Deploy menu that calls trigger-deploy with `clearCache: true` (localize en + zh).
3. Confirm REST/GraphQL already accept it (no change expected) so all four surfaces agree.
