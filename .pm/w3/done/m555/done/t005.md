## Objective

Move a cron job's manual build to where Render puts it.

## Context

- `dashboard/src/features/deploys/components/deploys-list-page.tsx` (the search field, `deploys.listSearchPlaceholder` "Search…").
- Render's web service Deploys page (2026-09-03 changelog screenshot) and the walked cron job's both read "Search deploys and commits".
- The build verb: the deploy trigger `ManualDeployButton` uses for "Deploy latest commit"; a cron job's deploy is its build.
- Pipeline minutes: bex has the `pipeline_minutes_exhausted` event (`lego/backend/internal/events/service.go`). Disable Manual Build when the dashboard can read that state; otherwise record the gap in the Render parity task.

## Steps

1. For a repo-backed cron job, add a secondary **Manual Build** button beside the search; hide it for an image-backed one.
2. Disabled with the permission reason when the action is refused; on success open the new deploy's detail page.
3. Set the search placeholder to "Search deploys and commits" for every service type, eight languages.
