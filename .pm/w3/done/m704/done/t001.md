## Objective

Give `scripts/lib/render_dashboard_ops.py` a URL inventory beside its operations and flags, so one crawl yields every path Render's dashboard can produce.

## Context

- README § What Render does. `urls-*.js` holds template builders such as `` `/env-group/${e.id}` ``; route objects in the entry and its chunks hold `path:` values, often constants (`path:ri`) or helper calls (`na(':serviceTypeSlug')`), and layouts hold `hrefPatterns`.
- The parser reads chunks as text in memory and never executes them; it fails with a message naming what it could not find rather than reporting every row removed. Keep both properties.
- `inventory()` (line 351) is where operations and flags are collected.

## Steps

1. Collect path literals from the `urls` chunk's builders and from every `path:` and `hrefPatterns` value across chunks; resolve a `path:` that names a constant or a known helper when its literal is in the same chunk, and list the unresolved ones in the output instead of dropping them.
2. Normalize: `${…}` and `:name` segments to `:param`, a trailing `/*` kept as a marker, query strings split off (keep `?plan=` and `?next=` as recorded parameters), duplicates merged.
3. Leave out what is not a dashboard page: asset paths, API and GraphQL endpoints, external origins.
4. Add the URL inventory to `list`'s JSON output and check the count against a hand count of the `urls` chunk.

## Done 2026-11-27

`scripts/lib/render_dashboard_ops.py` § Dashboard URLs: a lexer (strings, template literals, regular expressions, comments), each chunk's top-level declarations, imports and exports, and an evaluator for template literals, `+`, conditionals, arrow-function calls, member access and TypeScript string enums. 385 patterns from 459 chunks (`index-D5V4ZgbE.js`); 159 of the `urls` chunk's 185 declarations build a path (hand count: the other 26 are helpers, bare segments and the docs-origin joiners). Beyond the steps: a non-route `path:` that evaluates to a dashboard path counts as a `link` (the New menu's `/web/new` … `/cron/new`, `/observability#log-streams`), and anything else under that key (form-field paths, locals) is skipped silently; a one-character name inside a function body is treated as a local, not the top-level binding it shadows. 25 route and navigation expressions are listed under `unresolved_urls`.
