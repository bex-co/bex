# Log explorer: Live tail as one of the time ranges, as Render's range picker lists it

Why: Render's explorer has one control for when, its range picker, whose first entry is Live tail; bex has a Live switch beside the range, so a Render user looks for Live tail in the range list and a bex range and Live state can disagree in ways Render's cannot (a custom range with Live on).

Read from Render's dashboard bundle and the capture by w3/m528 (2026-11-20, `docs/render-artifacts/project-observability.md` § The view page): the time range lists Live tail, Last hour … Last 30 days and Custom; `liveMode` is `timeRange === "live"`; New logs in Live Tail sets the range to `live`. w3/m528 mapped Render's relative range onto bex's Live off on a preset range and kept the switch (its t004 scoped the change out).

bex today: `LogFilterBar`'s `LiveToggle` and `RangeSelect` (`dashboard/src/features/logs/components/log-filter-bar.tsx`), the datastore and project viewers' own toolbars, and the URL's `live` key (`lib/log-search.ts`) beside `range`.
