## Objective

Render's Options menu ends with **Theme Settings**, which links to its account settings' Appearance section (`/u/settings#appearance`). bex keeps its theme only in the account menu. bex's account Settings gains an Appearance section with the Dashboard Theme choice, and every explorer's Options ends with a Theme Settings link to it.

## Context

- Render's Appearance (`UserSettings-*.js`): Dashboard Theme (its options, the default marked "(Default)"), Log Explorer Theme and High Contrast Mode. This task builds Dashboard Theme only; t010 files the other two.
- bex's theme: `dashboard/src/common/providers/theme-provider` (`useTheme`: `light`, `dark`, `system`). It is set from `common/components/user-nav.tsx`'s theme submenu (`THEME_LABEL_KEYS`).
- bex's account Settings: `dashboard/src/features/auth/pages/settings-page/index.tsx`. Its sections (`SettingsSection` with `id`) are account, integrations, access, security and danger-zone, with a section rail in `settings-navigation.tsx`. The route skeleton is `AccountSettingsPageSkeleton` (`common/components/route-skeletons.tsx`). Pending and ready must match (`dashboard/AGENTS.md` § Navigation pending states).
- Options: `LogOptionsMenu` in `dashboard/src/features/logs/components/log-explorer.tsx`. The deploy page passes its own `children` (`deploys/components/deploy-log-panel.tsx`).

## Steps

1. Add an Appearance section (`id="appearance"`) after Account, as Render orders it. It offers Dashboard Theme: System (marked the default), Light and Dark. It drives the same `useTheme` state as the account menu, so changing either shows in the other. Add it to the section rail and to the route skeleton.
2. End `LogOptionsMenu` with **Theme Settings** (a settings icon), a link to `/settings#appearance`. Landing there scrolls the section into view.
3. Translate the new strings into all eight languages.
4. Write tests. Cover: the section changes the theme and reflects a change made in the account menu; the Options link's target in a service explorer and in a deploy's log; and the settings skeleton holding the new section, its structural test updated.
