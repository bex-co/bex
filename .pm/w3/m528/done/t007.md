## Objective

On a line with an instance, in the explorer of a service bex can open a Shell for, the row menu offers Render's **SSH into instance**. It opens a new tab on the service's Shell page with that instance selected. When the instance is not running, the item is disabled with Render's tooltip "You can only SSH into running instances. This one is not available."

## Context

- Render: shown when the explorer has `serverInstances`, a `servicePath` and the line has an instance. It links to `${servicePath}/shell/${instance}` (`target="_blank"`) when the instance is among the running server instances, and is disabled with the tooltip otherwise.
- bex's Shell: `routes/services.$serviceId.shell.tsx` → `ServiceShellPage` → `WebShellPanel` (`dashboard/src/features/services/components/web-shell-panel.tsx`). The panel already has Render's "Select an instance" picker over `useServiceInstances(serviceId)`, with "Any ready instance" as the default (`ANY_INSTANCE`). The route has no search state.
- Eligibility: `ServiceShellPage` treats `service.sshAddress` as the signal that a Shell can open (a paid, non-suspended web, private or worker service with the gateway configured).
- Explorers: the service Logs tab has one service. A project view's lines carry their resource. Decide whether a project line offers SSH for its service, and record why. Postgres, Key Value and a deploy's log offer none.

## Steps

1. Give `/services/$serviceId/shell` an `instance` search key (validated, pinned in `search-validators.test.ts`). `WebShellPanel` starts on that instance when it is one of `instances`, and otherwise on Any ready instance.
2. Add **SSH into instance** to the row menu where the explorer knows the service is Shell-eligible. It is enabled when the line's instance is among the service's running instances, and disabled with Render's tooltip otherwise. It is a link that opens in a new tab.
3. Write tests. Cover: the item on an eligible service's line with a running instance (its link names the instance); disabled with the tooltip for an instance that is gone; absent on a Free service, a datastore and a line without an instance; and the Shell page preselecting the instance from the URL.
