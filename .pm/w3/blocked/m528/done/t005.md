## Objective

Every line row gets Render's `LogLineOverflowMenu`: a small "…" button at the row's top right, shown while the row is hovered, under the keyboard's row cursor, or while its menu is open. Its first item is **Copy log line**.

## Context

- `dashboard/src/features/logs/components/log-line-list.tsx`: `LogRow` (memoized, about line 738). The row is `group/row` with `hover:bg-muted/60`, and the keyboard cursor sets `data-active`. The level gutter already uses `group-hover/row` and `group-data-active/row` to show the info mark.
- Render copies `[label] METHOD STATUS host+path` and then the text with ANSI stripped, without the time (`En`), and confirms with "Copied!". Disabled on a blank line.
- `dashboard/src/features/logs/lib/log-rows.ts` `logRowsText` builds Copy logs' text. Reuse its per-line part without the time, so the two cannot drift.
- `useCopyToClipboard` (`dashboard/src/common/hooks/use-copy-to-clipboard`) and the explorer's "Logs copied" toast (`use-log-explorer.ts`).
- A Radix menu in every row would cost each appended row its mount (the reason `LineTime` mounts its tooltip only on hover). Mount the menu only while the row is hovered, active or open.
- The row's measured height must not change when the button appears (virtualized rows, w9/m83).

## Steps

1. Add the "…" button and a `DropdownMenu` to `LogRow`, mounted only while needed, absolutely positioned at the row's top right so the row's layout does not move. It needs an accessible name and must be reachable from the keyboard cursor (for example, a key on the focused list opens the active row's menu). Record the key in `logs.linesKeysHint`.
2. Add **Copy log line**. It copies the line's text as above and confirms with Render's "Copied!", and is disabled for a blank line.
3. Leave room for t006 and t007's items. With no item to show, render no button.
4. Write tests. Cover: no button until hover; the button and menu on hover and on the keyboard cursor; the copied text for an app line, a request line and a project view line with its resource name; a blank line disabled; and the row height unchanged when the button appears.
