## Objective

While a search or a filter narrows an explorer, the row menu offers Render's **View in context**. It opens a new tab on the same explorer with no search or filters, a custom range from 10 minutes before the line to 10 minutes after it, and that line marked and scrolled into view.

## Context

- Render: `hasActiveSearchFilters` = log type not `all`, a search, or a label filter. The link is the explorer URL with the default filters, `contextLogId`, a ±10-minute range and `centeredTimestamp`, opened with `target="_blank"`.
- bex's explorer URLs:
  - The service Logs tab: `dashboard/src/features/logs/lib/log-search.ts` (`range=custom`, `rangeStart`, `rangeEnd`, `live=0`, filters; `CLEARED_LOG_SEARCH`).
  - Postgres and Key Value: `parseDatastoreLogSearch` (`routes/databases.$databaseId.tsx`, `routes/keyvalue.$keyValueId.tsx`).
  - Project views: `parseProjectLogSearch`. A project view's own document filters are the view, not a search. Decide whether its context link drops them, as Render's default filters would, or keeps them, and record why.
  - A deploy's log has no search, so it offers no View in context.
- `dashboard/AGENTS.md`: a route's `validateSearch` returns every key it owns, and each validator is pinned in `src/routes/__tests__/search-validators.test.ts` with `toStrictEqual`.

## Steps

1. Add a context parameter to each explorer route that names the line to mark (its timestamp, plus whatever identifies it among lines with the same timestamp). Validate it and pin it in `search-validators.test.ts`.
2. With that parameter set, the explorer opens on the custom range, with Live off, and with the named line marked (Render highlights it) and scrolled to the middle of the panel. It must not unpin or jump once the reader scrolls.
3. Add **View in context** to the row menu, shown only while the explorer is narrowed, as a link that opens in a new tab.
4. Write tests. Cover: the item hidden without a search or filter and shown with one; the link's search for a service, a Postgres and a project line; and an explorer opened with the parameter marking that line in view.
