## Objective

Make every script that loads `.env` refuse a file readable by group or others, so a copied or newly created `.env` cannot silently sit world-readable again (ADR079 finding 1), and record whether that finding's rotation is still owed.

## Context

- ADR079:30 required revoking/rotating every credential the file held while world-readable and an OpenBao rekey (ADR037); no board item tracked it.
- `scripts/bao-init.sh:34-44` re-applies `0600` only inside `set_env_var`.
- 2026-10-19: `.env` is `-rw-r--r--` in six sibling checkouts (`bex-security`, `bex5`–`bex8`, `bex10`) — other workstreams' checkouts; change them only with the user's OK.
- Loaders that source `.env` include `scripts/agent-snapshot-secret.sh`, `auth-*.sh`, `authz-model.sh`, `bao-*.sh`, `backup-s3-credentials.sh`, `dashboard-env-verify.sh`, `delete-audit.sh`, `dev-env.sh`, `disk-snapshot-secret.sh`, `github-app-secret.sh`, `gh-secrets.sh`, `obs-secrets.sh`, `postgres-*-smoke.sh`, `push-secret.sh` (re-enumerate; this list is the first 20 matches).

## Steps

1. Add one shared loader (e.g. `scripts/lib/env-file.sh`, `load_env_file PATH`) that refuses a file with any group/other permission bit, naming the file and the `chmod 600` fix, then sources it.
2. Route every `.env`-sourcing script through it (enumerate with grep; no script keeps a private `source .env`).
3. Tell the user which sibling checkouts are world-readable and ask whether to `chmod 600` them; ask whether ADR079's rotation + ADR037 rekey happened, and record the answer in ADR079 (dated).

## Acceptance criteria

- [ ] The loader refuses a `0644` and a `0640` fixture with a named error and loads a `0600` fixture; tested in `scripts (test)`.
- [ ] `grep` finds no direct `source`/`.` of `.env` outside the shared loader.
- [ ] ADR079 records the current custody state and whether rotation is owed.

## Out of scope

- Rotating credentials or rekeying OpenBao (operator work if the user decides it is owed).
- Go or dashboard `.env` readers.
