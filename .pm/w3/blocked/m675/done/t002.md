## Objective

Build a Connect popover shared by Postgres and Key Value. It holds the internal URL, then the external URL or Render's note, then the CLI command. It reads the values when opened and is disabled with a reason for a member who cannot see them.

## Context

- Pattern: `ServiceConnectButton` and `ConnectCodeRow` in `features/services/components/service-detail-header.tsx`.
- Values: the reads Info's Connection cards use (`connection-info-panel.tsx`; the Key Value connection card and its `connExternal*` states). Reuse those hooks and queries rather than adding another.
- Gate: `useCapabilities().canViewSensitive`, `reasonKey("can_view_sensitive")`, `PermissionTooltip`.
- The note's link goes to Info's access card (`#access-control` for Postgres, `#networking` for Key Value after m649).

## Steps

1. A `DatastoreConnectMenu` taking the rows, so each datastore passes its own labels ("PSQL Command", "Redis CLI Command").
2. Lazy read on open, with a loading row and an inline error.
3. Locale strings in all eight locales.

- `dashboard/src/features/databases/locales/*.ts`, `dashboard/src/features/keyvalue/locales/*.ts`
