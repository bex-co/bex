## Objective

Run `/simplify` over the code this milestone changed (reuse, simplification, efficiency; behavior-preserving).

## Acceptance criteria

- [ ] Every finding is applied, or recorded as not applicable.

## Result (2026-11-13)

`/simplify` with three reviewers. Applied:

- **Reuse:** the "newest success" fold existed in the operator and in bex-api. It is now `appv1alpha1.NewestSuccessfulRunAt` in `lego/types/v1alpha1/cron.go`, beside the other cron helpers both sides use, and its test moved with it. The backend copy used to return a corrupt recorded value as-is; the shared version drops it, as the operator's did.
- **Reuse:** the migration's run-id backfill reuses 0083's `bex_service_event_id(<job name>)` with the `crr-` prefix, because `id.Derive` hashes only the parts. That replaces hand-rolled bit maths and is 4.6× faster (reviewer's measurement: 60k rows in 1.1 s). The Go-equality test still passes. `cronRunEnded` joins `cronRunStarted` as the shared source-key suffix.
- **Efficiency:**
  - The list query has two shapes, first page and past a cursor, instead of `$2 IS NULL OR …`. A generic plan turned that into a filter, measured at 8.6 ms against 0.15 ms.
  - The cursor lookup says `run_id <> ''`, so a generic plan still uses the partial index (7.3 ms → 0.04 ms).
  - The first page reuses a capped slice of the window instead of cloning it.
- **Quality:**
  - Fact-backed runs format times as RFC3339Nano, as status does for a cancel time, so a canceled run reads the same before and after eviction.
  - `findCronRun` returns early on a window hit.
  - The comments were corrected.
- **Kept:**
  - The run-id cursor, not a keyset cursor. Facts are never deleted, and keeping it leaves the wire format unchanged.
  - `CREATE INDEX` without `CONCURRENTLY`: about 0.5 s per million rows inside the migration.
  - **Upgrade gap:** a success evicted before this operator release is not backfilled into `status.lastSuccessfulRunAt`. It returns with the job's next success. ADR038 records this rather than adding a fact query to every service read.
