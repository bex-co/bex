## Objective

Where the live object is gone, the record answers in Render's shape.

## Steps

1. `Sandbox` gains `terminatedAt` (nullable, as Render's)
2. `Get` and `sandboxOwner` fall back to an ended record in the caller's workspaces, with the same owner/admin boundary as a live sandbox
3. `List`/`listFiltered` append ended records when the status filter names `terminated`
4. `Terminate` of an ended sandbox answers 204
5. `/execs` and `/execs/{id}` read an ended sandbox's history
6. GraphQL `Sandbox.terminatedAt`; MCP `list_sandboxes` follows `listFiltered`

## Acceptance criteria

- [ ] Service and REST tests: GET 200 terminated, list default excludes and `status=terminated` includes, repeat terminate 204, executions listed, a non-owner member still gets 404
