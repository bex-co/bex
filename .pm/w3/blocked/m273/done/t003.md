## Objective

Add a private port 10000 → primary HTTP port mapping on every web service's ClusterIP Service (unless 10000 is already the primary port).

## Context

- Service builder in `lego/operator/internal/controller/`

## Steps

1. Add the alias port.
2. Skip when primary is 10000.

## Files

- lego/operator/internal/controller/

## Acceptance criteria

- [ ] envtest: web Service exposes 10000 targeting the primary port

## Result (2026-11-05)

Every web service's Services answer port 10000 → the primary target (skipped when the primary is 10000; an image-declared 10000 is repointed at the primary, as Render routes it). Tests: `TestWithPrivateNetworkPorts`, envtest "answers a web service's private port 10000".
