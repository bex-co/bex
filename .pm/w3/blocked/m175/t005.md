## Objective

Prove on a running cluster that draining a node or rolling either Deployment costs no requests, then confirm the production rollout.

## Context

- Use the local CAPD mock cluster (`scripts/mock-cluster.sh`, pre-approved); `scripts/mock-cluster.sh scale N` adds platform capacity if needed.
- Probe targets: a published static site, a hibernated free web service (wake path), a never-served service's first-deploy host.

## Steps

1. Start ≤1s probes against all three hosts and record every non-2xx/503-as-designed answer.
2. Drain the node hosting each component's first replica; uncordon; repeat for the second.
3. `kubectl rollout restart` each Deployment.
4. Record results in `docs/drills/<date>-static-activator-drain.md`.
5. After deploy, record production `kubectl get deploy,pdb` for both components and their replica spread.

## Acceptance criteria

- [ ] Zero unexpected probe failures across both drains and both rolls, with probe counts recorded.
- [ ] Production shows 2/2 Ready for each, PDBs present, replicas on different nodes.
