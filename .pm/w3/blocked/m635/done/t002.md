## Objective

Move the Bun 1.4 and Ruby 3.3 / 3.4 / 4.0 lines to the images t001 listed, version fields included, and update every test that hardcodes the old patches.

## Context

- `lego/operator/internal/build/native.go`: Bun 1.4 at line ~243 (`version: "1.4.4"`), Ruby lines at ~220-223. The `version:` field names the patch in build-log lines, so it moves with the digest.
- `lego/operator/internal/build/toolchain-freshness.json`: `committed`, `resolved_at` and `source` per entry.
- Tests that hardcode the old patches (line numbers as of 2026-11-25): `nativeversion_test.go:742,1006,1014,1015,1064,1079`, `nativeinit_test.go:413`, `nativeexact_test.go:355-370,807-812`.
- Side effect: a Ruby service created before `rubyDefaultCutoff` (2026-10-23, `nativeversion.go:293`) or of unknown age follows the 3.4 line's pin, so it moves 3.4.12 → 3.4.13 on its next build. [m636](../../m636/README.md) then gives dated services Render's dated default.
