## Objective

Typing `@` in the composer opens a two-level picker: a category listbox (v1: **Repositories**, **Sessions**) → selecting inserts a typed token (`@repos:` / `@sessions:`) and swaps to that category's item list — fuzzy-filtered as you type, arrow/Enter navigation, a readiness preview footer for repos — and picking embeds a mention chip whose repo becomes the created session's repo.

## Context

- Repo source: the git feature's existing installation repo list (`dashboard/src/features/git/` — the `Repos` query used by service creation; grep `Repos(`). Rows: `name` + `owner` subtitle; readiness = GitHub-App-connected + default branch (model-key presence later).
- Sessions source: t001 hooks `useAgentSessions()` (mention a prior session id in the task text).
- Devin mechanics (evidence `.playwright-mcp/devin-at-{mention,repos}.png`): categories → token insert → fuzzy filter (`@repos:tianpan` matched `android-tianpanco-release`) → preview footer ("Not set up on Devin's machine — Indexing disabled").
- Creating with no `@repo` chip ⇒ inline "pick a repository" nudge anchored at the `@` button; never silently submit.

## Steps

1. Mention popup component (listbox + keyboard nav + fuzzy filter) anchored to the textarea caret; `@` triggers, Escape closes.
2. Category level (Repositories/Sessions) → token insert → item level with the category's data source; repo readiness footer.
3. Chip embed: a removable chip in/above the input; chip.repo → the create mutation's `repo`.
4. The `@` toolbar button opens the same popup.
