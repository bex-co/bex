## Objective

Make the weekly job fail when Render's URLs and the ledger disagree, from the same crawl that checks operations and flags.

## Context

- `scripts/render-dashboard-ops.sh` (`check` / `list`), `read_ledger()` and `check_row()` in `scripts/lib/render_dashboard_ops.py`; the job `render-dashboard-ops` in `.github/workflows/render-schema-drift.yml` (checkout skips `.pm/`, so pointers are not checked against the board there).
- `scripts/render-dashboard-ops.test.sh` serves synthetic bundles; `.github/workflows/scripts.yml` runs it and lists its inputs in `paths` (`scripts/ci_test_inputs.py` checks the list).

## Steps

1. Read the URL table (header `Render URL`) from `dashboard-routes.md`, honouring `RENDER_DASHBOARD_ROUTES_LEDGER` like `RENDER_DASHBOARD_OPS_LEDGER`; reuse `check_row()` for dispositions and pointers.
2. Report a URL with no row, a row whose URL left the bundle, a duplicate row and a malformed row, each with the file and line; exit non-zero on any.
3. Extend the synthetic bundles and the test for each case and for a constant-resolved `path:`.
4. Update the header comments of the script and the workflow job, and `scripts.yml`'s `paths` if the test reads a new file.
