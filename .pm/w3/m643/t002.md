## Objective

The header's "Runs `<command>` <schedule in words>" words every schedule Render words, with Render's words, and shows nothing where Render shows nothing.

## Context

- Render: `AuthContext-*.js` `z`: five space-separated fields, `cron-validator` `isValidCron(s.replace(/\?/g, "*"), { alias: true, allowNthWeekdayOfMonth: true })`, not a day-of-month no listed month has (`R`); then `cronstrue.toString(s)` with default options, first letter lowercased, " UTC" after each AM or PM. w3/m555 t001 read the phrases from cronstrue 2.50.0.
- bex: `describeCronRun` and `cronShape` in `dashboard/src/features/services/lib/cron.ts`; the header falls back to the expression in `CronRunFacts`. bex's validity check is `isValidCron` (robfig's parser, the shared vector table `lego/backend/internal/apps/testdata/cron-schedule-vectors.json`), which accepts what bex-api accepts.
- `*/40 * * * *` fires at :00 and :40, and cronstrue words it "every 40 minutes". bex declines that today on purpose. Under ADR008's parity-first rule the header says what Render's says; keeping the declination is a divergence that stands only with the user's sign-off in ADR018 (file it as its own item if wanted).
- The dashboard speaks en, zh, ko, ja, es, pt, ru and de (`dashboard/src/i18n/config.ts`); cronstrue ships locales for each (`zh_CN`, `ko`, `ja`, `es`, `pt_BR`, `ru`, `de`).

## Steps

1. Add `cronstrue` to the dashboard (pin the version Render's bundle carries, or the nearest), loading only the locales the dashboard speaks.
2. Rewrite `describeCronRun` as Render's `z`: bex's `isValidCron` gate (a schedule bex-api refuses never reaches a saved cron job), then cronstrue in the dashboard language, the first letter lowercased and " UTC" after AM or PM in English; in other languages the UTC marker in that language's words. Remove `cronShape`'s run phrasing and its translation keys if nothing else reads them.
3. Show nothing after the command where Render shows nothing; decide whether the expression fallback stays (Render shows none) and record it.
