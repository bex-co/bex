# Log explorer Options lists Clear logs (`Shift+L`) while the tail is live, as Render's does

Why: Render's Options menu shows the reader that a live tail can be cleared and how; bex has the `Shift+L` shortcut (w3/m509) but no menu item, so a reader who does not know the key cannot find it.

Read from Render's dashboard bundle by w3/m528 (2026-11-20, `Logs-DOHYAXbe.js`, the Options items list): after Order by, while a clear is offered (`onClearLogs`), Options lists **Clear logs** with a `Reset` icon and the `Shift L` key hint, above Display.

bex today: `useClearedLines` (`dashboard/src/features/logs/hooks/use-log-explorer.ts`) offers `clear` only while the tail is live and `useLogExplorer` binds it to `Shift+L`; `LogOptionsMenu` (`components/log-explorer.tsx`) has no item for it. The cleared state's Restore button (`LogClearedState`) brings the lines back.

Done when Options lists Clear logs with its `Shift+L` hint in every explorer while its tail is live (service, Postgres, Key Value, project views), it clears exactly as the shortcut does, it is absent while paused and in a deploy's log, and a test pins both.
