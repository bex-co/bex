## Objective

Add a cluster-internal, HMAC-authenticated **record endpoint** to the isolated ssh-gateway that, given a session's pod/ns/session identity, dials the still-live driver's `GET /stream` (`:8787`), seeds from the store's current max seq, and tees the driver's full-history replay into `agent_session_transcripts` — the non-browser trigger the phase-1 fire-and-forget path is missing (ADR051 "the mechanism").

## Context

- The tee already exists: `lego/backend/internal/sshgateway/agentattach/agentattach.go` — `streamAgentAttach` → `spliceDriverStream` dials `http://<podIP>:8787/stream` and appends each part idempotently by emission ordinal (`store.AppendAgentSessionTranscript`, `ON CONFLICT (session_id, seq) DO NOTHING`). Today the only trigger is a browser `GET`/`POST` carrying an attach ticket.
- The driver retains full `#history` and serves `/stream` until teardown, replaying everything (+ `[DONE]`, hub closed) to any late attacher — `lego/agent-image/driver/src/stream-hub.ts`, `.../main.ts` (stays alive so the Completer can read it).
- Trust primitive to reuse: the sandbox-exec listener's domain-separated HMAC — `BEX_SANDBOX_EXEC_SECRET`, cluster-internal `:8081`, never edge-routed (`lego/backend/cmd/ssh-gateway/main.go`; `internal/sshgateway/sandboxsse`). Resolve seq cursor via `store.AgentSessionTranscriptMaxSeq` so a redispatched turn concatenates instead of colliding.
- Gateway→driver:8787 ingress is already sanctioned by the cluster-wide `sandbox-agent-driver-ingress` Cilium policy.

## Steps

1. Add a record handler (in `agentattach`, or a sibling `agentrecord`) that verifies a signed record ticket/claim (subject/session/pod/ns), authenticated by the `BEX_SANDBOX_EXEC_SECRET` HMAC — internal-only, no edge route, cookies ignored.
2. Seed from `AgentSessionTranscriptMaxSeq(session)`, resolve pod → IP, and reuse `spliceDriverStream`'s dial + per-part idempotent append to drain the whole replay once (no client fan-out needed — this is a recorder, not a viewer).
3. Wire the internal listener/route in `lego/backend/cmd/ssh-gateway/main.go`, gated on `BEX_SANDBOX_EXEC_SECRET` being set (disabled/byte-identical when unset), sharing the process-wide store pool.
4. Keep it byte-transparent (verbatim `data:` parts, ADR047 D3) and safe to call more than once (idempotent).

## Acceptance criteria

- [ ] A signed internal call records a running session's transcript by dialing the driver `/stream` and appending all parts, seeded from the current max seq.
- [ ] Calling it twice is a no-op on the second call (every seq conflicts).
- [ ] The endpoint is cluster-internal only (no Traefik/edge route) and refuses an invalid/absent HMAC.
- [ ] With `BEX_SANDBOX_EXEC_SECRET` unset the listener is not started (byte-identical default).
