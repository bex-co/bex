## Objective

Show a dismissible getting-started card on Overview for a workspace with zero resources, whose items reflect real state from existing queries and link to the action that completes them (ADR075 D2).

## Context

- ADR075:46 order: **Verify your email** (while unverified) → **Add a payment method** (D7) → create first service → deploy a sample → connect GitHub → invite a teammate. Dismissal persists client-side; no backend state, no tour library (`:69`).
- State sources: `features/onboarding/lib/email-verification.ts`; `features/usage/hooks/use-billing-onboarding.ts` (payment readiness); the Overview's existing resource counts (`routes/index.tsx:210-211`); `features/git` (GitHub connections); `features/team` (members).
- "Deploy a sample": no dashboard sample path exists (`parseNewServiceSearch`, `features/services/lib/create-context.ts:103`, has no repo prefill).

## Steps

1. Decide "deploy a sample": add a public-repo prefill to the new-service search (pointing at the repository's `examples/hello-go`) **or** drop the item and amend ADR075 D2 — record the choice and reason here.
2. Build the card: items with done/pending state, each linking to its action; the email item shows only while unverified; the card shows only when the workspace has zero resources and has not been dismissed.
3. Persist dismissal in `localStorage` keyed by workspace id; switching workspaces shows each one's own state.
4. en + zh strings.
