## Done (2026-10-30, loopx w3) — dev-3, fresh account `w3-m176-first-run@dev-3.local`

**Finding:** the Overview pending state previewed the populated layout (3 project cards + a resource table) for every workspace, so a new workspace's checklist card + empty state appeared with a full layout shift (and the page's own first-load skeleton did the same).

**Fix:** `features/onboarding/hooks/use-overview-shape.ts` remembers per workspace (localStorage, ADR075: no backend state) whether Overview last rendered empty or populated; `OverviewPageSkeleton` and the page's first-load state render `OverviewEmptySkeleton` — the getting-started card skeleton (omitted once dismissed) + the empty-state block — for a workspace last seen empty. Both hooks now share `features/onboarding/lib/workspace-local-store.ts` (per-workspace localStorage value with same-tab and cross-tab updates).
