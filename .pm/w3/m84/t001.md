## Objective

Wrap bex-api's public mux (and the `:8091` control-plane mux) with one middleware that records `bex_api_http_request_duration_seconds{surface,route,method,status}`, `bex_api_http_requests_total{…}`, and `bex_api_http_in_flight_requests{surface}` on the existing Prometheus registry, with route labels that are registered patterns and never raw paths.

## Context

- `lego/backend/cmd/api/main.go`: `root := http.NewServeMux()` (~458) → `httpSrv := newHTTPServer(addr, root)` (~463); `metricRegistry := prometheus.NewRegistry()` (~163) served at `GET /metrics` on `internalRoot` (~863); the cp server wraps `internalRoot` (~903). Handlers register with method patterns (`"GET /v1/…"`), so `r.Pattern` is meaningful.
- `surface` derivation: `/v1/` → `rest`, `/graphql` → `graphql`, `/mcp` → `mcp`, OAuth/discovery paths → `auth`, everything on the cp mux → `internal`; unmatched (404) → `route="unmatched"` so scanners cannot inflate cardinality.
- Response-writer wrapper must preserve `http.Flusher`, `http.Hijacker`, and `io.ReaderFrom` (SSE `/v1/logs/subscribe`, MCP SSE, Web Shell WebSocket) — follow `lego/backend/internal/api/gzip.go`.
- Histogram buckets: API-shaped (5ms … 30s) plus a long tail for streams; do not observe streaming requests into the same buckets as unary ones (label `stream="true"` or exclude by pattern — decide and document in the file header).

## Steps

1. Add `lego/backend/internal/api/httpmetrics.go` (`Middleware(reg, surfaceFn) func(http.Handler) http.Handler` + writer wrapper).
2. Wire it around `root` and `internalRoot` in `main.go`; register collectors once (idempotent for tests).
3. Add a cardinality guard test: drive requests through real registered routes with ids and assert every `route` label equals a registered pattern and matches no `(srv|dpg|red|tea|ags|whk)-[a-z0-9]+` segment.
4. Verify `/metrics` locally (dev-3) shows the families with expected labels for REST, GraphQL, MCP, and a 404.
