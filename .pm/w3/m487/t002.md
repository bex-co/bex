## Objective

The sidecar's container name is one constant in `lego/types`, and `podmetrics` excludes that container, so the autoscaler and bex-api's current-usage read count only the service's own container.

## Context

- `lego/types` is the leaf both `operator` and `backend` import (import DAG `operator → types ← backend`; depguard enforces it).
- Today the name is duplicated: `lego/operator/internal/controller/edge_cache.go` and `lego/backend/internal/metrics/service.go:1242` (`edgeCacheContainer = "edge-cache"`).

## Steps

1. Add the constant in `lego/types` (next to `podmetrics` or the App types) and use it in both modules.
2. Make `podmetrics.Parse` skip it.
3. Make t001's autoscaler test pass; run `make test` and backend `go test ./...`.
