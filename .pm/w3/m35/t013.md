## Objective

Prevent a compromised public bex-api Pod from reusing the NamespaceReconciler's cluster-scoped namespace and named-role `bind` permissions against platform namespaces, while preserving automatic tenant namespace reconciliation.

## Context

- Kubernetes RBAC cannot scope a ClusterRole to tenant namespace names that do not exist when the role is installed.
- `bex-api-namespaces` consequently grants namespace mutation, RoleBinding mutation, and `bind` on five tenant ClusterRoles at cluster scope.
- Application code normally targets only `<ws>`/`<ws>-sandbox`, but a compromised Pod can use its ServiceAccount token directly; code-path intent is not an authorization boundary.

## Steps

1. Add fail-closed API-server admission keyed to the exact bex-api ServiceAccount and canonical managed tenant namespace identity.
2. Require the exact managed/PSS Namespace labels, sandbox `default-deny` shape, migration-only legacy-policy deletes, and regime-specific RoleBinding name, ClusterRole, and ServiceAccount mappings; validate stale-binding deletion separately from create/update so migration can revoke even a malformed old grant without admitting its recreation.
3. Reduce RBAC verbs to those the direct client actually uses, then add static GitOps guards plus live impersonated dry-run probes for denied platform/PSS/policy operations and admitted canonical updates.

## Acceptance criteria

- [ ] Impersonated bex-api requests cannot delete/relabel a platform namespace or bind a tenant ClusterRole there, even though raw RBAC grants the dynamic verb.
- [ ] It also cannot downgrade sandbox Pod Security labels or create/update an arbitrary sandbox NetworkPolicy; only exact `default-deny` convergence and deletion of known pre-m35 broad allows pass.
- [ ] Canonical hosting/sandbox namespace updates, exact reconciler RoleBindings, and stale-projection deletes still pass API-server admission.
- [ ] CI fails if the admission policy, fail-closed binding, canonical/PSS check, sandbox policy shape, migration delete branch, exact subject mapping, or reduced object verbs drift.

## Out of scope

- Splitting NamespaceReconciler into a separate binary or ServiceAccount; native admission contains the current architecture without adding another networked component.
