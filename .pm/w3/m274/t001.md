## Objective

Serve `/redis` (list/create), `/redis/{redisId}` (get/patch/delete), `…/connection-info`, `…/suspend`, `…/resume` by delegating to the Key Value handlers and rendering the pinned OpenAPI's `redis` response shapes.

## Context

- Pinned OpenAPI `/redis*` operations; listed in `lego/backend/internal/api/render_operation_coverage_test.go` omissions
- Key Value REST handlers under `lego/backend/internal/keyvalue/`
- Render: https://render.com/docs/blueprint-spec ("`redis` is a deprecated alias for `keyvalue`")

## Steps

1. Mount the routes.
2. Map shapes (field names that differ between `redis` and `keyValue`).
3. Same authz and error shapes as Key Value.
