## Objective

`dashboard/src/common/apollo/retry-link.ts:33-35` retries queries only; a mutation that fails on the network must never read as "did nothing".

## Steps

1. Audit how mutation network errors reach the UI (Apollo error link, per-form handlers, toasts); find any path where the error is swallowed.
2. Make every mutation network error visible with a retry affordance; do not auto-retry non-idempotent mutations. Record the idempotency-key question as a decision in this file (options + recommendation) for the user.

## Acceptance criteria

- [ ] A test simulating a network error on a mutation shows the error UI.
- [ ] `yarn typecheck && yarn lint && yarn test` pass.
