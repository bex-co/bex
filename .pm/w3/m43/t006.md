## Objective

Publish the conversation endpoint under the primary API origin: the platform edge routes `api.bex.co/v1/agent-sessions/{id}/stream` to the **gateway process** (not bex-api), so external developers see one API product with no second origin and no CORS — while the process split stays an internal implementation detail.

## Context

- ADR047 § D9 target shape, "Public origin": deliberate documented exception to "everything on the API origin is served by the bex-api process"; the gateway MUST ignore cookies on this path (Kratos cookies will arrive since it's the api host — ticket is the only credential); preserve/expose `x-vercel-ai-ui-message-stream: v1`. A neutral dedicated origin is the recorded fallback if edge path-routing proves troublesome.
- Edge is Traefik via `deploy/gitops/` (platform infra — GitOps territory, ADR001 boundary: route objects live in gitops, not operator code).
- `BEX_AGENT_SESSION_GATEWAY_URL` (the `url` handed to clients) becomes `https://api.bex.co/v1/agent-sessions` — update env docs + production values.

## Steps

1. Gitops: IngressRoute/route rule matching the stream path on the api host → gateway Service (SSE-friendly: no buffering, adequate timeouts).
2. Gateway: serve the path-shaped route; strip/ignore cookies; assert the edge preserves the v1 header + streaming (no compression/buffering on this route).
3. Docs: CLAUDE.md env rows; ADR047 already records the audit-exception — link the concrete route file.
4. Verify from a browser context: same-origin fetch from the dashboard origin works with zero CORS configuration.

## Files

- `deploy/gitops/**` (route)
- `lego/backend/internal/sshgateway/agent_attach.go` (path + cookie handling)
- `CLAUDE.md`, `.env.example` (mirror any var change)

## Acceptance criteria

- [ ] `curl https://api.bex.co/v1/agent-sessions/{id}/stream` with a ticket streams; the same URL without a ticket is 401/403 even with a valid Kratos cookie attached.
- [ ] v1 header present at the client; SSE frames arrive unbuffered (live-tail latency check).
- [ ] The route file documents the process-exception; `.env.example` mirrors any renamed var.

## Out of scope

- Moving any other gateway listener (shell/SSH stay on their origins).
