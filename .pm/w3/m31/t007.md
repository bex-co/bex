## Objective

Prove the per-tenant-namespace model preserves scale-to-zero + bin-pack economics (ADR043 D4) and the tenant-isolation reachability matrix.

## Context

- ADR043 D4 invariant: per-tenant namespace (logical) + shared tenant node pool (physical); nodes scale to 0 when all tenants sleep.
- `scripts/verify-elastic.sh` (scale up/down, MostAllocated packing), `scripts/verify-tenant-isolation.sh` (reachability matrix).

## Steps

1. Run `verify-tenant-isolation.sh` against per-tenant namespaces (update selectors as needed).
2. Run `verify-elastic.sh`: sleep all tenants → tenant node pool scales to 0; wake → scales back; bin-pack density unchanged.

## Files

- `scripts/verify-tenant-isolation.sh`, `scripts/verify-elastic.sh`

## Acceptance criteria

- [ ] Isolation matrix passes per-namespace.
- [ ] Tenant node pool scales to 0 with all tenants asleep; bin-pack density unchanged vs. shared-namespace baseline.
