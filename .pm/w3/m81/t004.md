## Objective

Prove the implemented lifecycle contract with a disposable static site in a real cluster, measuring deletion timing and checking every tenant surface through the terminal outcome.

## Steps

1. Create and deploy a disposable static site with a route/header and at least one deploy.

3. Record the time to the documented terminal state and verify no dead URL survives in tenant-facing data.
4. Exercise the bounded cleanup-failure path in a controlled non-customer environment.
5. Delete all fixtures and retain only non-secret evidence.
