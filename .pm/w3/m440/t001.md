## Objective

Enforce ADR113's coverage contract rule 3: a Bex-native command that replaces the process cannot ship without `EmitLaunch` and a contract test.

## Context

- Today's call sites: `lego/cli/internal/code/launch.go:120`, `lego/cli/internal/agent/ssh.go:87`, `lego/cli/internal/desktop/desktop.go:85` (all `syscall.Exec`). The upstream hook never sees them because the process is replaced (`lego/cli/internal/telemetry/telemetry.go`).

## Steps

1. Add `lego/cli/telemetry_coverage_test.go`: parse the module's non-test Go files with `go/ast` and find calls to `syscall.Exec` and `unix.Exec`.
2. Keep a reviewed list of allowed files, each naming its contract test. Fail with the file and line of any call site not on the list.

## Acceptance criteria

- [ ] Adding a `syscall.Exec` call in a new file makes `go test ./...` fail with a message that says what to add.
