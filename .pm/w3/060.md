# Postgres SQL and insights on a Creating, Upgrading or Restarting database answer 503 with the reason, not 500

Why: API, CLI and MCP callers get a bare 500 `internal error` during routine lifecycle states that the dashboard already explains (w4/177), so agents get a worse answer than people.

- **Evidence:** `lego/backend/internal/postgres/query.go:205` and `insights.go:519` guard only `db.Spec.Suspended`; `.pm/w4/done/177.md` records "a direct REST query while Creating still answers 500 `internal error`" as out of its scope. The dashboard gate is `sqlConsoleBlock(deriveStatus(database).key)` in `dashboard/src/features/databases/lib/status.ts`.
- **Fix:** classify the non-ready lifecycle states (Creating, Upgrading, Restarting) the same way the suspended case is, `core.ErrUnavailable` with the state named, for `Query` and every insights read (`TopQueries` and its siblings).
- **Tests:** one per surface — REST `POST /v1/postgres/{id}/query` 503, GraphQL `executeDatabaseQuery` field error, MCP `query_render_postgres` `isError` — all with the same message.
