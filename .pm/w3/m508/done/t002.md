## Objective

Read the charts for a whole project or environment in one request, one series per resource (`RESOURCE`) or per status code for requests (`STATUS_CODE`).

## Context

- GraphQL `metrics` already fans out over several `RESOURCE` values (`lego/backend/internal/metrics/graphql.go:346`) within `checkFanOut` (`service.go:445`).
- Per-service plan gates (HTTP requests and latency need Pro) and retention floors apply per resource.

## Steps

1. Accept the project scope and filter document, resolve resources as w3/m505 t004 does, and keep unreadable resources out.
2. Bound the fan-out for large projects and name the bound when exceeded.
