## Objective

Builds run on an environment save, a repo-scoped secret change, a manual request and about every 24 hours, one at a time per repository.

## Context

- The builds table (t003), the sandbox seams (t004) and the driver's build mode (t005).
- Devin: "Only one build runs at a time"; new triggers cancel a queued build.

## Steps

1. Queue a build on each trigger; the daily refresh runs for environments whose newest success is over ~24 h old.
2. Worker: claim → start the builder with the build's secrets (t001) → wait for the driver's status → commit (t004) → record success, or fail with a failure code and the redacted tail.
3. Enforce t002's bounds; the sweeper (t003) fails stale builds and removes leftover builders.
4. Apply retention after each success.
