## Objective

Before builds ship, apply ADR104 D4's constraints to this new trigger of the node-root commit Job and record the review in the security lineage.

## Context

- ADR104 D4: the commit Job mounts `containerd.sock` (node-root equivalent); a user-triggered capture needs a Job spec with nothing caller-chosen, per-sandbox and per-workspace rate limits, size and time bounds, and no privileged Pod left after a failure.
- The user Suspend verb already reaches the Job; builds add environment saves and a daily schedule as triggers.

## Steps

1. Confirm the Job spec takes nothing from the build (image, mounts, arguments) — the controller derives it.
2. Set and test the bounds: one running build per (workspace, repository), a per-workspace daily build cap, the commit timeout, the image size cap, cleanup of a failed capture.
3. Record the review (threats, decisions, residual risk) in the security review lineage (docs/AGENTS.md).

## Out of scope

- Changing the OpenSandbox controller's commit mechanism.

**Done 2026-11-14.** The review is ADR111 § D11, listed in the docs/AGENTS.md security lineage. ADR104 D4's constraints are applied to the new triggers:
- **Nothing caller-chosen.** bex-api pauses only a builder it created; the controller derives the Job.
- **Limits:** one build per repository, two per workspace, and 12 starts per repository per 24 h. Builds share the workspace's live agent sandbox count.
- **Bounds:** 3 h per step (driver) and per build (bex-api); 10 GB and the storage cap, reserved under the workspace storage lock.
- **Cleanup:** the sweeper fails builds that stop heartbeating and terminates their builders, which also drops their pause images.
- **Build principal:** proxy upload-pack only; a mint only for the `building` build's own Pod, repository and build branch; a contents-read token for one repository.
- **Tests:** `agentsession/build_test.go`, `mint_test.go`, `sshgateway/agentcred/build_test.go`, and `sandbox/agent_build_test.go` (including a concurrent storage-cap test).

Residual: a compromised controller is node-root, as for every pause.
