## Objective

Builds run on an environment save, a repo-scoped secret change, a manual request and about every 24 hours, one at a time per repository.

## Context

- The builds table (t003), the sandbox seams (t004) and the driver's build mode (t005).
- Devin: "Only one build runs at a time"; new triggers cancel a queued build.

## Steps

1. Queue a build on each trigger; the daily refresh runs for environments whose newest success is over ~24 h old.
2. Worker: claim → start the builder with the build's secrets (t001) → wait for the driver's status → commit (t004) → record success, or fail with a failure code and the redacted tail.
3. Enforce t002's bounds; the sweeper (t003) fails stale builds and removes leftover builders.
4. Apply retention after each success.

## Out of scope

**Done 2026-11-14.** `agentsessions/repo_environment_builds.go` and `repo_environment_builder.go`:
- **Triggers:** a save that changed the version, a repo-scoped secret set or changed, Build now, and the daily refresh. A stale agent image counts only once the build is 1 h old, in a jittered 20-minute slot out of every 2 h. An internal failure retries after 15 min.
- **Saves never fail** on a build trigger.
- **Worker loop:** claim while a sandbox slot is free, start the builder with the unnamed secrets, poll every 30 s under the Completer's retry window, then commit or fail with the driver's code.
- **Limits:** the 3 h build limit records `build_timeout`; rate-limited triggers get `AGENT_REPO_ENVIRONMENT_BUILD_RATE_LIMITED` with `nextBuildAt`.
- **Cleanup:** retention and environment delete retire images; one replica purges at a time.

Tests are in `repo_environment_builds_test.go` and the pg tests.
