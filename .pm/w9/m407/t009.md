## Steps

1. Declare an environment on the QA repository with a setup step whose effect is observable on disk.
2. Watch the build reach success; start a session: setup does not run, the effect is present, the checkout is at the latest base.
3. Change the environment: a new build starts and the session after it uses the new image; a failing step fails the build and sessions fall back to phase 1.
4. Delete the fixtures and their images; revoke the sessions.
