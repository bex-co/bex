# Creating a project whose environment names the defaults (`unprotected`, isolation off) requires Admin, so Render's Terraform provider cannot create any project with an API key

Why: the provider sends `protectedStatus` and `networkIsolationEnabled: false` for every environment of a `render_project`, and bex treats either field's presence as a protected-environment change that only an Admin may make. A Developer, and so every bex API key, gets 403 for a plain unprotected environment.

- **Found by:** w9/m474, dev-9, 2026-11-18 ([checklist](../../docs/terraform-compatibility-checklist.md), class 2). It stopped 7 provider tests (`TestProject` and the service and datastore tests that share a project fixture).
- **Render:** `internal/provider/project/models.go` `ClientProtectedStatusFromModel` defaults to `unprotected` and the create always carries `networkIsolationEnabled`. Render answers `POST /v1/projects` `{"environments":[{"name":"prod","networkIsolationEnabled":false,"protectedStatus":"protected"}],…}` 201 (`project_cassette.yaml`).
- **bex:** `lego/backend/internal/projects/service.go` (`Create`'s environment loop: `e.ProtectedStatus != "" || e.NetworkIsolationEnabled || e.IPAllowList != nil` → `RelCanManage`) and `internal/environments/service.go` `CreateEnvironmentRequest.hasACL` use the same test. Probe: a Developer key's `POST /v1/projects` with `{"protectedStatus":"unprotected","networkIsolationEnabled":false}` answers `403 FORBIDDEN`.
- **Fix:** require `can_manage` only for a value that differs from the default (`protected`, isolation on, an allow list that restricts something), on project create, environment create and the environment PATCH the provider sends on update. That is w4/355's definition of an ACL-bearing environment for moves (ADR018 Projects & environments row): the seeded allow-all default and `unprotected` are not admin-managed.
- **Done when:** a Developer's `POST /v1/projects` with an `unprotected`, non-isolated environment answers 201, `protected` still answers 403, tests cover REST, GraphQL and MCP, and `TestProject` gets past its first step with a Developer key.
