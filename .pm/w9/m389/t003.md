## Objective

Every log read clamps its start to the workspace plan's window: Hobby 7 days, Pro 14, Scale and Enterprise 30.

## Context

- `lego/backend/internal/logs/loki.go:46` `lokiLookback` (7 days), `:361` `lokiRange` (no plan floor).
- Read paths: REST `/v1/logs`, `/v1/logs/values`, the subscribe WebSocket, GraphQL, MCP `list_logs`, datastore and build logs.
- Plan reader: `core.WorkspacePlanReader` (`lego/backend/internal/core/plan_gate.go:131`).

## Steps

1. Compute the floor from the plan in one place used by every path.
2. A request whose window starts before the floor is clamped to it (never an error unless Render's API is observed to refuse; record which).
3. Keep the default lookback within the floor.

## Files

- `lego/backend/internal/logs/`
- `lego/backend/internal/core/plan_gate.go` (retention per plan)

## Acceptance criteria

- [ ] Tests per plan on each read path: nothing older than the window is returned.
