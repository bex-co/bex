## Objective

coverage-gaming — each test must fail if the fix is reverted.

## Context

Cover, at minimum:

- **Billing bypass (t001):** a workspace in `enforced` (and `recovering`) lifecycle state is refused
  on the Blueprint deploy AND sync path with `ErrBillingEnforced`, and creates no
  Service/Postgres/KeyValue; a good-standing workspace still succeeds. This is the regression test for
  the confirmed finding — it must fail against the pre-fix code.
- **Escaping (t002):** a `"`-bearing value is emitted escaped and cannot terminate the query literal.
- **500 body (t003):** an unmapped store/k8s error yields the generic body (no internal string) while
  a coded error keeps its message.
- **Mint nonce (t004):** replay of a signed mint request is rejected; a fresh nonce succeeds; store
  error fails closed.
- **Hardening sweep (t005):** `ResolveCredentialNames` is workspace-scoped; the nonce in-memory mark
  follows the durable claim.
