## Objective

Close three small accepted hardening notes from the audit in one sweep (none exploitable today; each
tightens a control or documents a deployment invariant).

## Context

Three independent items (audit `REPORT.md` hardening notes 4, 5, 6):

1. **Workspace-scope `registrycreds.ResolveCredentialNames`.** It uses the workspace-unscoped
   `GetRegistryCredentialsByIDs` for display-name enrichment
   (`lego/backend/internal/registrycreds/pullsecret.go:210`). Not exploitable (ids come from
   already-authorized Apps, are opaque `rgc-<xid>`, only the non-secret name is returned, and
   deploy-time materialization independently refuses cross-workspace creds) — but tighten to a
   workspace-scoped lookup for defense-in-depth.
2. **Nonce claim ordering.** `lego/backend/internal/sshgateway/nonce.go:71` records the nonce in the
   in-memory `used` map **before** the durable `ClaimShellNonce`; on a transient DB error the nonce
   is burned in-memory on that replica for its TTL. Fail-closed (only wastes one ticket) — reorder so
   the durable claim succeeds before the in-memory mark, or roll back the in-memory mark on claim
   error.
3. **`BEX_PROXY_PROTOCOL_TRUSTED_CIDRS` narrow-CIDR caveat.** The shipped value is a single `/32` (the
   Hetzner LB). A self-hoster who widened it to the pod CIDR would let tenant pods spoof the PROXY
   client IP and defeat DB `IPAllowList` (still gated by the DB password). Document the
   must-stay-narrow requirement where operators set it (`.env.example` comment + the relevant ADR /
   deployment doc). Deployment/doc concern — no code bug.

## Steps

1. Add a workspace-scoped variant (or pass the workspace filter) to `ResolveCredentialNames`'s lookup;
   keep the returned shape identical.
2. Reorder `nonce.go` so the in-memory mark follows a successful durable claim (or rolls back on
   error); preserve fail-closed behavior.
3. Document the `BEX_PROXY_PROTOCOL_TRUSTED_CIDRS` narrow-CIDR requirement in `.env.example` (comment,
   no value) and the pg/kv SNI-proxy ADR (ADR009 §SNI proxy / ADR021), keeping `.env.example` in sync
   per repo rule.
