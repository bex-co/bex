## Objective

Close the ±30s replay window on the gateway→bex-api `:8091` credential-mint HMAC hop. Unlike the
ticket flavors (which carry a single-use nonce), `agentsession.Verify` accepts any identical signed
`(timestamp, signature, body)` within the clock-skew window, so an on-path attacker on the internal
link could replay a mint request. Add a single-use nonce, reusing the existing guard mechanism.

## Context

- `lego/backend/internal/agentsession/signature.go` — `bex-agent-credential-v1` HMAC, constant-time,
  ±30s skew, **no nonce**. Signs the git-proxy and model-proxy mint hops
  (`InternalMintPath`/`InternalModelMintPath`, bex-api `:8091`).
- The ticket family already has a durable, cross-replica single-use nonce: `hmacticket` +
  `sshgateway.NonceGuard` (`store.ClaimShellNonce`, INSERT…ON CONFLICT). Reuse that mechanism, or the
  same DB-backed pattern, for the mint envelope.
- Impact today is low (requires an on-path position on the internal gateway↔bex-api link; a replay
  re-mints the *same* session-confined credential — no new capability), which is why this is
  defense-in-depth, not the confirmed finding. Recorded in `REPORT.md` hardening note 3.
- Fail-closed on nonce-store error (reject), matching the existing guard.

## Steps

1. Add a nonce field to the mint signature envelope (`signature.go`) and have the gateway generate a
   `crypto/rand` nonce per mint request.
2. On the bex-api side, claim the nonce single-use (reuse `NonceGuard`/`ClaimShellNonce` or an
   equivalent durable claim) before minting; reject a re-seen nonce.
3. Set the nonce-expiry horizon to `timestamp + skew` so the prune window matches the acceptance
   window (no early-prune replay gap — mirror `hmacticket`'s `NonceExpiry`).
4. Keep the change backward-compatible across a rolling deploy (gateway and bex-api ship together;
   confirm no mixed-version window rejects legitimate mints — gate on nonce presence if needed).

## Acceptance criteria

- [ ] A replayed `(timestamp, signature, body, nonce)` mint request within the skew window is
      rejected; a fresh nonce succeeds.
- [ ] Nonce claim is durable/cross-replica and fails closed on store error.
- [ ] Test covers accept-once / reject-replay.

## Out of scope

- Re-architecting the mint transport; the HMAC hop and its network scoping stay as-is.
