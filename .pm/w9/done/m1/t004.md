## Objective

Make every deploy-creating action land on the new deploy's page, matching Render: clicking **Manual Deploy** navigates to `/services/<id>/deploys/<newDeployId>`; a rollback does the same for the rollback deploy; deploy rows on the Events tab become links to their deploy page.

## Context

- `dashboard/src/features/services/hooks/use-trigger-deploy.ts` — the Manual Deploy mutation already returns the new deploy's `id` (`TriggerDeploy` in `src/features/services/api/events.graphql`); today it only toasts + refetches `ServiceEvents`.
- Rollback: `RollbackService` mutation (same file) also returns the new deploy `id`.
- Events tab rows: `src/features/services/` events components render deploy events whose `id` **is** the deploy id (`dep-…`) — wrap the row title in a router `Link`.
- Navigation via TanStack Router's `useNavigate` from the hook's call sites (keep the hook UI-agnostic if it's cleaner — return the id, navigate in the component).

## Steps

1. Surface the new deploy id from `useTriggerDeploy` (and the rollback hook) to callers; navigate to the deploy route on success. Keep the failure toast behavior.
2. Link Events-tab deploy rows to `/services/$serviceId/deploys/$deployId`.
3. `yarn typecheck && yarn lint && yarn test`; click-verify under `yarn dev:local` (Manual Deploy → lands on the in-flight deploy page → status flips to live).

## Files

- `dashboard/src/features/services/hooks/use-trigger-deploy.ts`
- `dashboard/src/features/services/components/manual-deploy-button.tsx`
- Events tab components under `dashboard/src/features/services/components/` (rollback action + event rows)

## Acceptance criteria

- [ ] Manual Deploy click → URL becomes `/services/<id>/deploys/<dep-…>` for the deploy the mutation created.
- [ ] Roll Back to This Deploy → lands on the rollback deploy's page.
- [ ] Events-tab deploy rows navigate to their deploy page.
- [ ] A failed trigger (e.g. cron_job + commitId rejection) still toasts and does NOT navigate.

## Out of scope

- Auto-navigation for webhook/push-triggered deploys (no browser context to navigate).
