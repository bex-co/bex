## Objective

Close the monoculture-fixture blind spot that let w4/052 hide: the live services
parity verifier creates its only web service with `--runtime go`, so it never
exercised the empty-`spec.runtime` (Dockerfile-via-builder) path where the CLI's
partial `services update` broke. Add build-strategy-diverse fixtures and run the
same update leg against each.

## Context

- `scripts/cli-services-parity-verify.sh`: `WEB_ID` is created with
  `--runtime go` (~line 217) and its `services update ... --health-check-path`
  leg (~line 262) therefore always round-trips a runtime that GET returned. The
  `IMAGE_ID` fixture (~line 186) is created without `--runtime` but is only
  update-tested with `--image`, never with a `serviceDetails` field.
- Driven by `scripts/cli-compat.sh` against a live bex-api + the unmodified
  `render-oss/cli`; not part of the CI unit suites (needs the CLI + a cluster),
  so this is defense-in-depth over the t001/t002 backend guards, and its DoD is
  a real run, not just the script edit.

## Steps

1. Add a Dockerfile-via-builder web service fixture created **without**
   `--runtime` (repo + Dockerfile, so `spec.runtime` stays empty) as a new
   verifier leg.
2. Run `services update --health-check-path /healthz` (and one more
   `serviceDetails` field, e.g. `--pre-deploy-command`) against it, asserting the
   value round-trips via raw `GET` — the exact shape that failed in w4/052.
3. Extend the existing image-no-runtime fixture with the same
   `--health-check-path` update leg (or add a dedicated one), so the still-
   unverified image round-trip is actually exercised end to end.
4. Register the new legs in the verifier's leg list / `complete_leg` accounting
   so a skipped leg is a hard failure, and update
   `scripts/cli-services-parity-verify.sh`'s expectations + any leg inventory in
   `docs/cli-compatibility-checklist.md`.
5. Note in the milestone/checklist whether a live run was performed (dev-N or
   prod); if not runnable here, mark the leg added-but-live-pending like prior
   verifier work.
