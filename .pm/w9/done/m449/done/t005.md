## Objective

Record `ChangeEnvironmentProtectionEvent` when an environment's protection changes, `UpdateEnvironmentIsolatedEvent` when its network isolation changes and `UpdateIPAllowListEvent` when its IP list changes; fields a save leaves unchanged record nothing.

## Context

- Render's reference: `ChangeEnvironmentProtectionEvent` (protected access toggled, pinned enum) and `UpdateEnvironmentIsolatedEvent` (isolation setting changed, docs-only, rides the same allowance as m449 t003).
- bex: `environments.SetACL(ctx, id, protectedStatus, networkIsolationEnabled, ipAllowList)` and `Update` (`lego/backend/internal/environments/service.go`) change all three in one call and record a bex-named row; isolation is `core.LabelNetworkIsolation` (w8/m136). `UpdateIPAllowListEvent` already names service, datastore and workspace list changes.

## Steps

1. Compare the old and new values in the verb; record one Render-named row per changed field after the write.
2. Cover REST, GraphQL, MCP and the dashboard's environment settings.

## Files

- `lego/backend/internal/environments/service.go`, `lego/backend/internal/core/audit.go`, `lego/backend/internal/audit/service.go`, tests

## Acceptance criteria

- [x] Toggling only protection records only `ChangeEnvironmentProtectionEvent`; toggling only isolation only `UpdateEnvironmentIsolatedEvent`; a save changing nothing records no `success` row.
