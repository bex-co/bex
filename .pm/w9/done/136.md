# A canceled native build's Managed OIDC tokens stay until the next build ends

Why: w9/124 made a canceled, superseded or timed-out build revoke its per-build NetworkPolicies at once, but its Managed OIDC tokens still outlive it: `endBuildManagedOIDC` ends them only on a succeeded or failed build, so a canceled build leaves both token Secrets (and `status.buildManagedOIDC`, which keeps bex-api minting) until the next build ends or the App is deleted.

- **Found by:** w9/124's worker, 2026-11-19 (a8068e1c7).
- **bex:** `lego/operator/internal/controller/build_managed_oidc.go` `endBuildManagedOIDC` returns early unless `phase` is `build.PhaseSucceeded` or `build.PhaseFailed`; it runs from the observed-build pass in `app_controller.go`, not from `endCanceledBuild` (the cancel settle pass w9/124 fixed for the NetworkPolicies). Its comment bounds the leak: a leftover token expires within the hour, and the next build's end or the App's deletion removes it.
- **Done when:** a canceled, superseded or timed-out build clears `status.buildManagedOIDC` and deletes both the `bex-build` token copy and the App-namespace source Secret on its settle pass, and an envtest beside w9/124's in `build_datastore_reach_envtest_test.go` (or `build_managed_oidc_test.go`) proves it without waiting for a later build; another App's running build keeps its tokens.
- Filed by the `/loopx w9` orchestrator from w9/124's result.

**DONE 2026-11-21.** A settled cancel now ends the canceled build's Managed OIDC tokens on the same pass, as w9/124 ends its build reach. `endCanceledBuild` (`lego/operator/internal/controller/app_controller.go`) joins `revokeBuildManagedOIDC` (`build_managed_oidc.go`, split out of `endBuildManagedOIDC`): it clears `status.buildManagedOIDC` first, so bex-api stops minting, then deletes the `bex-build` copy `bld-<app>-oidc` and the App-namespace `<app>-oidc-build`, both ownership-gated, and returns its errors so the cancel pass retries until it succeeds. That covers a user's cancel, a suspend that ends the rollout and the build of a release a cancel settled below (`stopAbandonedBuild`). The release a cancel leaves running (`survivorInFlight`) never settles there, so it keeps its tokens until its own build ends. A timeout already ended them at its terminal observation (`PhaseFailed`). `build_managed_oidc_envtest_test.go` ("Managed OIDC tokens end with a canceled or settled native build (w9/136)") runs two native Pro builds that set `AWS_ROLE_ARN` in one namespace with minted and copied tokens. It cancels, supersedes then ends, or times out one of them, and checks that its decision and both Secrets are gone on that pass with no later build, while the other App keeps all three. With the `endCanceledBuild` change reverted, the cancel and superseded specs fail and the timeout spec passes either way. ADR116 D12's **End.** paragraph names the new path. The envtests ran with a fail-fast `docker` shim on `PATH`, because Docker Desktop on the dev host was hung; no test in the run needs Docker.
