## Objective

Add meaningful tests for the behavior this milestone shipped, so the entry-chunk diet can't silently regress.

## Context

- The lucide map (t001) is the regression-prone piece: a new `iconName` usage must either exist in the map or fail loudly.
- The locale split (t002/t003) must keep en/zh parity and lazy-load correctness.

## Steps

1. Add a guard test that greps/imports: no `import * as` from `lucide-react` in `dashboard/src`, and every `iconName` literal passed to `EmptyState` app-wide resolves in the static map (fail the suite on an unknown name).
2. Add a test that `extractMessages`/the stripped catalogs still yield every `message` key (parity with the authoring source).
3. Add a test for the lazy-locale loader: after switching to zh, a sampled set of namespaces resolves translated strings (jsdom-level, mock the dynamic import if needed).

## Files

- `dashboard/src/common/components/__tests__/` (icon-map guard)
- `dashboard/src/i18n/__tests__/`
