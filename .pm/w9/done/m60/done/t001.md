## Objective

Stop shipping the full lucide-react barrel (~1,900 icons) in the entry chunk. `EmptyState` is the only consumer of the namespace import, and only 5 icon names are ever passed to it app-wide.

## Context

- `dashboard/src/common/components/empty-state.tsx:1` — `import * as Icons from "lucide-react"`, then dynamically indexes `Icons[iconName]`, which defeats tree-shaking (proof: unused icons like `Banana`/`Sailboat`/`Panda` are present in the built entry chunk).
- The only `iconName` values passed app-wide: `AlertCircle`, `Database`, `DatabaseZap`, `LockKeyhole`, `ScrollText` (grep `iconName=` to re-verify before coding).
- `EmptyState` is imported by ~31 files, hoisting the barrel into the shared entry chunk — route splitting (w5/m67) cannot fix this.

## Steps

1. Re-run the grep for `iconName` usages to confirm the exact icon set.
2. Replace the namespace import with named imports and a `Record<string, LucideIcon>` map; keep the `EmptyState` prop contract unchanged (fall back to a default icon for unknown names).
3. Grep the rest of `dashboard/src` for any other `import * as` from `lucide-react` (or other icon barrels) and fix the same way.
4. `yarn build` and spot-check the entry chunk no longer contains an unused icon identifier (e.g. `Sailboat`).

## Files

- `dashboard/src/common/components/empty-state.tsx`

- [ ] Built entry chunk no longer contains unused lucide icons (spot-check at least 3 known-unused names absent).
