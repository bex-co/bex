## Objective

GraphQL, the dashboard's audit table and its CSV export carry the same actor email, source IP and user agent; the CSV `actor` column is the email, as Render's is.

## Context

- GraphQL `auditLogs` (`lego/backend/internal/audit/graphql.go`) exposes `actor` as the raw subject.
- The dashboard row resolves the subject through the members list (`dashboard/src/features/audit/components/audit-event-row.tsx`), but the CSV writes `event.actor`, the raw subject (`dashboard/src/features/audit/lib/audit-csv.ts`), where Render writes the email. The CSV export shipped in w3/m305.

## Steps

1. Add GraphQL `actorEmail`, `sourceIp`, `userAgent`.
2. Show the source IP and a shortened user agent in the row (full value in a title), in every locale under `dashboard/src/features/audit/locales/`.
3. CSV: `actor` = `actorEmail`, else the `usr-` id; `metadata` includes `source_ip`/`user_agent` when present.
