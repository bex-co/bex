## Objective

Wire the t001 mechanism into the layout/shell routes whose children render behind a guarded `<Outlet/>`, plus the workspace alias route. A dead top-level id redirects to `/` regardless of which child tab the URL named.

## Context

- `dashboard/src/routes/services.$serviceId.tsx` — loader `:33-47`; explicitly separates error (retry Card `:82-111`) from not-found (SearchX Card `:117-142`); the `<Outlet/>` is only reached when the service exists (`:144-158`) — that gate is the 2026-07-09 phantom-service fix and must survive. Redirecting on not-found at the layout covers every child tab (`env`, `settings`, `shell`, `logs`, `metrics`, `scaling`, `plan`, `events`, `deploys.*`) in one place.
- `dashboard/src/routes/project.$projectId.tsx` — layout loader `:14-24` renders a bare `<Outlet/>`; the children branch on `projectResult.state` (`project.$projectId.index.tsx:113-128`, `project.$projectId.settings.tsx:103-113`). Redirect at the **layout loader** so both children shed their not-found branches (their error branches stay).
- `dashboard/src/routes/webhook.$webhookId.tsx` — loader `:21-39`; shell distinguishes `notFound` vs generic error `:90-105`; children `return null` without an endpoint.
- `dashboard/src/routes/w.$.tsx` — `WorkspaceAliasPage` renders the full-screen `NotFoundPage` for a foreign/unknown `tea-` id (`:96-113`); switch that branch to the redirect+toast (the membership check itself stays — no silent fallback to another workspace).

## Steps

1. Pipe each shell loader's `loadRouteResource` result through the t001 redirect helper (target `/`).
2. Replace each shell's settled not-found branch with the t001 client hook; delete the dead not-found JSX. Keep every error/retry branch and the service `<Outlet/>` existence gate intact.
3. In `project.$projectId.{index,settings}.tsx`, drop the now-unreachable `state === "not-found"` branches; keep `state === "error"`.
4. In `w.$.tsx`, redirect+toast on the unknown-workspace branch; loading skeleton unchanged.
5. `yarn typecheck && yarn lint && yarn test`.
