## Objective

Wire the t001 mechanism into the four flat detail routes so a dead id redirects to `/`; delete their now-unreachable inline not-found blocks. Error states keep their existing inline UI.

## Context

- `dashboard/src/routes/databases.$databaseId.tsx` — loader `:44-54`, `showNotFound = !loading && !database` at `:74`, inline block `:131-137`.
- `dashboard/src/routes/keyvalue.$keyValueId.tsx` — loader `:36-46`, `showNotFound` `:65`, inline block `:115-121`.
- `dashboard/src/routes/blueprints.$blueprintId.tsx` — loader `:42-55`, `showNotFound` `:77`, inline block `:112-118`.
- `dashboard/src/routes/env-groups_.$groupId.tsx` — loader `:46-57`, not-found branches `:127-133` and catch-all `!group` `:142-148`; the distinct **error** branch `:134-141` stays.
- Each route also feeds `routeResourceTitle`/`stateTitle` for the `<head>` title — after the redirect the not-found title path becomes moot for these routes but must not break the ready/error titles.

## Steps

1. In each route's loader, pipe the `loadRouteResource` result through the t001 redirect helper (target `/`).
2. In each component, replace the `showNotFound` inline branch with the t001 client hook; remove the dead not-found JSX and any now-unused locale keys (`databases.notFoundTitle`, etc.) if nothing else references them.
3. Keep loading skeletons and error branches byte-identical in behavior.
4. `yarn typecheck && yarn lint && yarn test`.
