## Objective

When the user selects Pro or Scale on `/new/workspace`, show a Payment Method section (Render's create-flow step) that reuses the existing billing onboarding UI. Hobby has no panel. Do **not** charge the $17.50 / $349.30 licensed SKU on create.

## Context

- Render docs: create flow includes "plan type and payment method" then Create Workspace.
- Bex ADR046 already gates **paid resource** intent with `PAYMENT_REQUIRED` + `BillingOnboardingView` (`dashboard/src/features/usage/components/billing-onboarding.tsx`, `useBillingOnboarding`). Stripe Customers are **per workspace** (`bex_workspace=tea-…`).
- Chicken-egg: a brand-new workspace has no `tea-*` yet, so readiness is the **current** workspace's payment method when the gate is on. Document that in the panel copy. After create, ADR046 still applies to paid resources in the new workspace.
- `BEX_REQUIRE_PAYMENT_METHOD` unset/`0` → panel may still *explain* that usage bills separately, but must not block Hobby or paid-plan create (prior behavior).
- Licensed monthly SKU collection is explicitly **not** this task (`docs/ADR030-pricing.md`, Stripe runbook).

## Steps

1. On `/new/workspace`, when selected plan is `pro` or `scale`, render a Payment Method block under the plan cards.
2. If the paid-intent gate is on: reuse `useBillingOnboarding` / `BillingOnboardingView` against the **current** workspace; disable Create until `paymentMethodReady` (or an equivalent documented ready state). Hobby never waits on this.
3. Copy: card is required for paid compute/usage on this plan; the $17.50/$349.30 line is the catalog workspace fee (display), not a Checkout line item in this milestone.
4. Enterprise: same panel as Pro/Scale if treated as paid capability, or follow Hobby if create stays ungated — pick one, test it, do not leave it implicit.

## Acceptance criteria

- [ ] Hobby: no payment gate; Create enabled on a valid slug alone.
- [ ] Pro/Scale + gate on: Create disabled until billing readiness; panel uses existing onboarding, not a new Stripe Price.
- [ ] Gate off: Pro/Scale create still works without a card (byte-identical to today aside from the optional explanatory copy).
- [ ] No new `BillableMeterNames` / licensed Price lookup keys.

## Out of scope

- Subscribing the new workspace to a $17.50/$349.30 Stripe Price.
- Per-user (not per-workspace) Stripe Customer.
- Changing `createWorkspace` GraphQL arguments.
