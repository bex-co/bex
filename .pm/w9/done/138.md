# A Ruby service created since 2026-11-19 with no version signal builds on 3.4.12, but Render's default for it is 3.4.13

Why: Render moved its no-signal Ruby default to 3.4.13 for services created on or after 2026-11-19 ([render.com/docs/ruby-version](https://render.com/docs/ruby-version), read by w9/133's worker 2026-11-20). bex's dated defaults stop at the 2026-11-03 step (3.4.12), so a Ruby service created since then with no `.ruby-version`, Gemfile `ruby`, `Gemfile.lock` `RUBY VERSION`, `.tool-versions` or `RUBY_VERSION` builds on another patch than it would on Render, and its build log names that patch.

- **Found by:** w9/133's worker, 2026-11-20 (993593eeb).
- **bex:** `lego/operator/internal/build/nativeversion.go` dated Ruby defaults (`{renderDefaults20261103, "3.4.12"}`, w4/620); the 3.4 line's reviewed patch and image in `lego/operator/internal/build/native.go` (`ruby:3.4-bookworm@sha256:…`, 3.4.12) and `toolchain-freshness.json`. ADR018's runtime row "Default patches by creation date" (w4/620) records the steps.
- **Done when:** re-read Render's ruby-version page for the exact date and patch; a Ruby service created on or after that date with no version signal builds on 3.4.13 (digest-pinned official image, or the 3.4 line's reviewed patch if the line is refreshed to it), and the log names it; a service created between 2026-11-03 and that date keeps 3.4.12, as Render's table does. Unit tests cover both sides of the new step; ADR018's row and ADR060 name the new step.
- Filed by the `/loopx w9` orchestrator from w9/133's result.

- **Closed 2026-11-21 (`/loopx w9`):** Render's ruby-version page, re-read 2026-11-21, gives 3.4.13 for services created on or after 2026-11-19 and 3.4.12 from 2026-11-03 until then. `exactDefaults` (`lego/operator/internal/build/nativeversion.go`) gains the step `{renderRubyDefault20261119, "3.4.13"}`. It is past the 3.4 line's reviewed 3.4.12, so the resolve phase swaps in `ruby:3.4.13-bookworm`, pinned by digest at build time as the 3.4.4 default is (w8/198), and the log reads `==> Using Ruby 3.4.13 (default)`. Docker Hub's index for that tag is `sha256:a3d6cdfc…`, and its amd64 and arm64 configs carry `RUBY_VERSION=3.4.13` on the bookworm root `@1793827419`, the reviewed 3.4 line's root (registry API, 2026-11-21).
