## Objective

Improve the live login card so empty submit is not a silent no-op and the password input no longer shares `id="password"` with the show-password button when we can override Ory Elements.

## Context

- Live DOM (`hunt2-login-dom.json` / `hunt3.json`): `#identifier` is `type="text"` with **no** `required`; empty submit → `invalid: 0` and no Kratos message. Bad credentials do show an error (path works once values are sent).
- Duplicate ids: both `<input id="password">` and the show-password `<button id="password">` (`duplicateIds: ["password"]`) — invalid HTML, ambiguous `label[for]` / `getElementById`.
- Overrides live in `dashboard/src/common/lib/ory/config.ts` (`oryHideCardLogo` pattern) and `@ory/elements-react` component overrides.
- Provider label "Sign in with github" (lowercase) is Ory/intl — only fix here if an override is already in reach; otherwise leave for inbox `051`.

## Steps

1. Inspect Ory Elements override points for Input / Password / Node; apply the smallest override that (a) avoids duplicate `id` on the toggle button, and (b) improves empty-submit feedback (`required`, `type="email"` on identifier when the node is an email, or a client-side guard before submit).
2. Prefer not forking Ory — if an override is impossible, document the residual in `051` and still land whatever is achievable (e.g. wrapper `onSubmit` check).
3. Add a focused test (DOM or component) that fails on duplicate `id="password"` when our override is mounted, and/or asserts empty submit surfaces feedback.

## Files

- `dashboard/src/common/lib/ory/config.ts` (and any new override module)
- login page if a thin wrapper is needed: `dashboard/src/features/auth/pages/login-page/`
- tests under `dashboard/src/common/lib/ory/__tests__/` or login-page tests

## Acceptance criteria

- [ ] Empty password login submit is no longer a silent no-op (visible validation or identity error).
- [ ] With our overrides mounted, `document.querySelectorAll('#password').length === 1` (or the toggle no longer uses `id="password"`).
- [ ] Successful bad-credential error path unchanged.

## Out of scope

- Full custom login form replacing Ory Elements.
- Changing Kratos identity schema.
- Capitalizing "GitHub" unless the same override pass makes it trivial (else `051`).
