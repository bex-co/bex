## Objective

Add three Pod-bound routes beside the existing spawn route so a running parent session can coordinate its children: wait until one or more finish, send a follow-up to one, and cancel one. Each route is limited to the caller's descendants.

## Context

- ADR102:156: 'The coordinator is woken when a child finishes … **Not built.** An orchestrator uses `wait_agent_sessions`; an in-sandbox parent reads `get_child_session`. Follow-up.'
- Devin (observed 2026-11-06, ADR102:155-156): the coordinator messages running children, terminates them, and is woken when one finishes.
- Existing pieces: spawn route `lego/backend/internal/sshgateway/agentcred/spawn.go:40-127` (Pod authentication, no secret); `agentsessions.Service.Wait` (`wait.go:113`, LISTEN-backed); `Service.Steer` (`service.go:1668`); `Service.Cancel` (`service.go:1419`).
- The orchestrator-side MCP already has `wait_agent_sessions` and `send_agent_session_message` (`agentsessions/mcp.go:25-28`).

## Steps

1. Add `wait`, `message` and `cancel` beside `serveSpawn`, authenticating the source Pod exactly as spawn does.
2. Refuse any session id that is not a descendant of the caller's session (tree from `parentSessionId`/`rootSessionId`).
3. `wait`: reuse `Service.Wait` with a timeout bounded by the caller's remaining turn time; return each child's phase, PR and cost.
4. `message`: re-check the creator's `can_create` before `Steer`, then steer the child with the parent's text.
5. `cancel`: call `Service.Cancel` on the child.
6. No 'needs input' wake: forbidden by DO_NOT_DO #APPROVAL-MODE.

## Files

- `lego/backend/internal/sshgateway/agentcred/spawn.go` (or a sibling `children.go`)
- `lego/backend/internal/agentsession/spawn.go`
- `lego/backend/internal/agentsessions/wait.go`, `service.go`

## Acceptance criteria

- [ ] A parent waits for two children and returns when both end.
- [ ] A parent cannot wait on, message or cancel a session outside its own tree (403-style refusal, tested).
- [ ] A message to a child whose creator lost `can_create` is refused.

## Out of scope

- Waking the parent on 'needs input' (DO_NOT_DO #APPROVAL-MODE).

## Done (2026-11-12)

The spawn URL now takes four more shapes, each Pod-authenticated exactly as spawn is and signed to bex-api as a `spawn-session` envelope with an `op`: `POST …/<child>` messages, `DELETE …/<child>` cancels, `POST …/wait` waits (`agentcred/spawn.go` `spawnRouteFor`, `cmd/ssh-gateway` mux registers POST, GET and DELETE). bex-api's `MessageChildSession`, `CancelChildSession` and `WaitChildSessions` (`agentsessions/spawn.go`) check every named id is a descendant of the verified session (`not_found` otherwise), refuse a parent that records no creator, and then call `Steer`, `Cancel` and `Wait` as the parent's creator, so Steer's own `can_create` check applies; its refusals pass through by code.

- **Wait bound:** at most 20 children and 25 s per call, the same constants on both hops (`agentsession.MaxSpawnWaitChildren`/`MaxSpawnWaitSeconds`, which `agentsessions.Wait` now uses). An omitted timeout is Wait's default of 25 s. That keeps every wait under bex-api's 30 s write timeout, rather than step 3's "remaining turn time": the agent calls again to keep waiting.
- **Wait answer:** each child's `state` plus `settled` and `timedOut`. The phase, PR and cost come from `get_child_session` on a settled child. That avoids one full read per child inside a held request and keeps the answer bounded.
- **Gateway slot:** a wait frees the sandbox's concurrency slot once the Pod check passes, so a 25 s wait never starves git; its context and timeout stay live.
- **Audit:** each call writes an audit row (`agentsessions.MessageChild`/`CancelChild`/`WaitChildren`) naming the child.

Tests: `TestCoordinatorVerbsActOnlyOnDescendants` (real Postgres: wait settles and times out, message relays Steer's refusal, cancel ends the child, outsider/self/unknown ids are `not_found`, stale Pod forbidden, lost `can_create` is `AGENT_SESSION_SPAWN_CREATOR_FORBIDDEN`, no creator is `AGENT_SESSION_SPAWN_NO_CREATOR`); `TestSpawnRouteCoordinatesDescendants` (routes, strict bodies, a read gets through during a wait under a one-slot limit); `TestSpawnEnvelopeCoordinatorOps`; `TestCredentialMuxRoutesEveryChildSessionMethod`.
