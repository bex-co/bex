## Objective

A Billing member's dashboard shows services and their non-sensitive details, but no events, deploy history, metrics or observability views, each with the capability reason instead of an error.

## Context

- `dashboard/src/features/events/`, `features/deploys/`, `features/metrics/`, the service tabs, the project Observability group, metrics event markers.
- The mobile client follows server capabilities (ADR087); no client work.

## Steps

1. Gate each tab, page and widget on the new capability.
2. Check pending and ready states at desktop and narrow-mobile widths.
3. Run `yarn lint` and `yarn test`.

## Acceptance criteria

- [ ] As a Billing member: no events, deploys, metrics or observability views anywhere, with the reason shown. As a Viewer: unchanged.
