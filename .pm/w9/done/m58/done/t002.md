## Objective

Implement the t001 field contract: the internal address (`<slug>:<port>`, from `PlatformSubdomain` + port — the same derivation the operator uses) appears on the service read paths of all three surfaces for web + private services, absent for non-addressable types.

## Context

- One core, thin adapters: derive once in `internal/apps` (service.go read path / render shapes in `render.go:AppView` area), project in `rest.go`/`graphql.go`/`mcp.go` fragments.
- Derivation inputs already on the App: `spec.subdomain`/name (`PlatformSubdomain`), `spec.port` default 3000 — no new operator round-trip needed; but keep it consistent with what m57 made resolvable (single derivation helper, not re-derived per adapter).
- Non-addressable types (worker/cron/static): field omitted, matching `deploy.go:1424`'s addressability rule.
- Legacy slug-less CRs: value falls back to the CR name — still resolvable (their Service is CR-named), still truthful.

## Steps

1. Add the derivation to the apps feature core; unit-test it (web, pserv, worker-omitted, legacy fallback).
2. Project per t001's table into REST/GraphQL/MCP; regenerate GraphQL schema artifacts if touched.
3. `cd lego/backend && go test ./...`; three-surface readback smoke against a dev cluster.
