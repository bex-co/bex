## Done (2026-11-06)

Implemented as ADR099 workspace skills, not separate notes and playbooks. Migration 0204 adds `agent_skills` (`skl-`) and `agent_session_turns.skills`. REST is `/v1/agent-skills[/{id|name}]`; GraphQL has `agentSkills`/`agentSkill` and create/update/delete mutations; MCP has `list_/get_/create_/update_/delete_agent_skill` on `/mcp/cloud-agents`. Reads and invocation need `can_create`, writes need `can_manage`, and writes are audited. Create and steer take `skills: [{name, arguments?}]` (at most 5, in the idempotency fingerprint, recorded per turn). Error codes are AGENT_SKILL_INVALID, LIMIT_EXCEEDED, CONFLICT, NOT_FOUND (404) and SKILLS_UNAVAILABLE (503).
