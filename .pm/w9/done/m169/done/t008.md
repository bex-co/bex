## Objective

Raster thumbnails and the lightbox render broken on production: the dashboard CSP `img-src` (`dashboard/vite.config.ts:356`) only allows self, data: and stripe, so the presigned Wasabi URL is blocked. Allow the configured attachments storage origin.

## Context

- Found by the 2026-11-04 live acceptance (evidence in this README).
- Storage origin: `https://s3.eu-central-2.wasabisys.com` (prod bucket endpoint, path-style).

## Steps

1. Add the storage origin to img-src (prefer a config/env-driven value over a hardcoded host if the CSP is built from config).
2. Keep SVG/HTML download-only behavior unchanged.
3. Test that the CSP header includes the origin.
