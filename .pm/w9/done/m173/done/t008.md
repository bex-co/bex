## Objective

A hung `docker pull moby/buildkit:buildx-stable-1` must not stall the deploy: deploy run 42141509773 (2026-11-06) spent 28 minutes in "pre-pull buildkit image" before any image build started.

## Steps

1. Bound each pull attempt with `timeout` (300 s, three attempts).
2. When the runner host already has the image, refresh it with a 120 s bound and keep the cached copy if the refresh fails.

## Acceptance criteria

- [x] `.github/workflows/deploy.yml` pre-pull step bounds every pull and only fails when no local image exists and all attempts fail.
- [ ] The next three main deploys show the pre-pull step under 5 minutes (checked by t007).
