## Objective

Two small copy bugs on the session detail page:

1. The header always shows plural "turns" even for a single turn (e.g.
   "Duration 34m 51s · 1 turns").
2. The idle-session banner reads as a broken sentence: "This session is idle —
   sending redispatches a new turn on the same branch." — missing a subject
   for "sending" (reads like a template with a dropped word).

## Context

- Turns count:
  `dashboard/src/features/agent-sessions/components/session-detail-header.tsx:210-211`:
  ```jsx
  <span>{t("agentSessions.metaDuration", { duration })}</span>
  <span>{t("agentSessions.metaTurns", { turns: session.turns })}</span>
  ```
  Locale string, `dashboard/src/features/agent-sessions/locales/en.ts:383-384`:
  `"{turns} turns"` — one fixed template, no singular/plural branch. Confirmed
  always "turns" even for `turns: 1` (test fixture at
  `dashboard/src/features/agent-sessions/components/__tests__/session-detail-header.test.tsx:41`
  already uses `turns: 1`).
- Idle banner: `dashboard/src/features/agent-sessions/locales/en.ts:451`:
  `"This session is idle — sending redispatches a new turn on the same
  branch."`

## Steps

1. Add a singular/plural branch for the turns count — i18next supports
   `_plural` suffix keys (`metaTurns_one` / `metaTurns_other`, matching this
   codebase's i18next setup) or an inline ternary at the call site; use
   whatever pattern this codebase already uses elsewhere for pluralization (if
   none exists yet, a simple `turns === 1 ? t("agentSessions.metaTurnsOne") :
   t("agentSessions.metaTurns", { turns })` is acceptable).
2. Reword the idle banner to a grammatical sentence, e.g. "This session is
   idle — sending a message redispatches a new turn on the same branch." (or
   equivalent phrasing that keeps the meaning: a follow-up message will start
   a new turn on the same branch).
3. Check for a `zh` counterpart of both strings
   (`dashboard/src/features/agent-sessions/locales/zh.ts`, if it exists) and
   update in parallel if the same issue applies.
