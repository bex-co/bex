## Objective

`sessionTitle()` returns a session's raw, unbounded `agentConfig.task` string,
which then flows straight into JSX in 4 places across 2 files with only
CSS-level `truncate` (visual ellipsis) — the full text stays in the DOM and,
in two of those places, in `title=`/`tooltip=` attributes that also feed the
accessible name. A session whose task prompt is a multi-thousand-word block of
text (two real production examples exist:
`ags-d9t3jof9kjbc73cq2iv0`, `ags-d9t3imh2dsds73d27o0g`) forces a screen reader
to read the entire text just to identify that row, and bloats every render of
the list.

## Context

- Root helper: `dashboard/src/features/agent-sessions/lib/mapper.ts:118-123`:
  ```
  export function sessionTitle(
    view: Pick<AgentSessionView, "id" | "agentConfig">,
  ): string {
    return view.agentConfig.task || view.id;
  }
  ```
  No length cap.
- Consumers, each duplicating the raw text into both visible text and an
  attribute:
  - `dashboard/src/features/agent-sessions/components/session-list.tsx:224-236`
    (recents row) — `<Link ... title={s.agentConfig.task}>` +
    `<span className="block truncate ...">{sessionTitle(s)}</span>`.
  - `dashboard/src/features/agent-sessions/components/session-list.tsx:282-296`
    (dense/table row) — same pattern.
  - `dashboard/src/common/components/dashboard-layout/agent-sessions-nav-section.tsx:166-182`
    — `const title = sessionTitle(session)`, then
    `<SidebarMenuButton ... tooltip={title} ...>` and
    `<span className="w-full truncate ...">{title}</span>`.

## Steps

1. Add a bounded variant of the title for list-row display — cap
   `sessionTitle()` (or add a new `sessionTitleShort()`) to a sane character
   limit (e.g. ~120-160 chars) with a trailing ellipsis, applied once at the
   source rather than relying on CSS `truncate` to hide the rest.
2. Update all 4 render sites (`session-list.tsx` recents row, `session-list.tsx`
   dense row, `agent-sessions-nav-section.tsx` span + `tooltip`/`title` prop)
   to use the bounded title consistently, so neither the visible text nor the
   `title=`/`tooltip=` attribute ever carries the full raw text.
3. Leave the session **detail page** untouched — the full task text should
   still be visible there (it's the appropriate place for the complete
   prompt), just not duplicated into every list row's accessible name.
