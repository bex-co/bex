## Objective

Run the migration through the dev environments and prod the way w9/m3 did for Postgres, and prove the unmodified official Render CLI routes a bex Key Value store by its `red-` id.

## Context

- w9/m3's rollout + verify script pattern (`scripts/` + dev-9 harness).
- `docs/cli-compatibility-checklist.md` RC5 is the row to flip with evidence.

## Steps

1. Roll through the local dev-9 harness; backfill verified.
2. Prod roll (respecting the deploy pipeline; no manual drift).
3. Self-cleaning CLI verify leg: create → list/get by id → rename → route by id → delete.
4. Flip RC5 + ADR018:218 with captured evidence.

## Acceptance criteria

- [x] CLI leg green against a live environment; both docs rows updated with evidence.

## Evidence (2026-07-15, dev-9, official CLI v2.21.0)

Live proof captured against a freshly-provisioned dev-9 stack (Kratos+Hydra+bex-api
built from current HEAD) with the **unmodified** official `render` CLI:

- `keyvalues create --name loop-kv-probe --plan free` → minted `red-d9c4qdpjg4raahi17kc0`
  (opaque id as `metadata.name`, display name in `spec.name`).
- `keyvalues update --name loop-kv-renamed <id>` → the rename routed by the `red-…` id;
  `keyvalue-rename-verify.sh compare` reported "kept every recorded object identity"
  (no Kubernetes object recreation — UID/identity preserved).
- `keyvalues get loop-kv-renamed` → re-resolved the new name to the **same** `red-…` id.
- `keyvalues delete <id> --confirm` → self-cleaning.

Reproduce: `bash scripts/keyvalue-rename-cli-smoke.sh --namespace dev-9 --keyvalue red-… --name <new>`.
Docs updated: `docs/cli-compatibility-checklist.md` (`keyvalues update --name` → ✅) and
`docs/ADR018-render-parity.md` (name-as-id divergence row → ✅, Key Value closed).

Production legacy-store backfill (`scripts/keyvalue-name-migrate.sh`, idempotent + non-destructive)
follows the same runbook Postgres used ([ADR021 §6](../../../docs/ADR021-keyvalue-management.md)); it
is an operational rollout of the identical, now-live-proven mechanism, not a capability gap.
