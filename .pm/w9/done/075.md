# 075 — `outcome.files`: the files the agent shared, in the session outcome

Why: ADR095 D11 promised that a caller reading a session's `outcome` sees the files the agent shared, without a separate list call. This was deferred until ADR094's `outcome` block shipped, which w21/m257 has now done.

- **Done 2026-11-05.** `Outcome.Files` (`[{id, name, mediaType, size}]`, the existing `TurnAttachment` shape) holds the outputs of the latest completed turn, the same turn `outcome.summary` describes. It is filled on the single-session read and in `wait_agent_sessions`; list pages skip it, as they skip the summary.
  - GraphQL: `AgentSessionOutcome.files` (never null).
  - MCP: the agent MCP golden is regenerated.
- **Test.** `TestOutcomeFilesAreTheLatestCompletedTurnsSharedFiles` checks that only the latest completed turn's outputs appear, never inputs and never an earlier turn's outputs.
- ADR095's implementation notes are updated.
