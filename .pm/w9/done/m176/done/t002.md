## Done (2026-11-06)

- Workspace `approvalMode` (autonomous by default, risky, all) and `approvalBypassAllowed`. Create takes `approvalMode` and `bypassApproval`; a forbidden lowering is refused with 403 AGENT_SESSION_APPROVAL_BYPASS_FORBIDDEN.
- The driver gates ACP `request_permission` against a versioned risky-command table (v2), which normalizes quoting, basenames, wrappers, `bash -c`, `$(…)`, git global options and `rm` targets resolved from the cwd. Ungated calls get `allow_once` and only a "for this session" answer grants `allow_always`. The driver’s own tools are recognized by exact identity.
- An `ask_user` tool and the overlay text exist only for sessions that can pause. Human wait time is excluded from the turn timeout.
- CLI: `bex agent run --approval-mode/--bypass-approval` and `bex agent answer`.
