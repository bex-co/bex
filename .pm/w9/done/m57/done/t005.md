## Objective

- Requires t003: the slug must resolve before the surfaced string names it. The FQDN keeps resolving either way (same Service objects) — this changes only the surfaced string.
- If t001's capture shows Render's pserv `serviceDetails` carries **no** `url` at all, do NOT drop the field here — dropping/renaming REST fields is m58's shape-decision work; this task only makes the value slug-based.
- Stale doc: `docs/ADR006-bex-api.md` §Blueprint ("bare `<name>` resolves because every bex Service is named after its App") — true only for legacy CRs; rewrite per ADR041.
