## Objective

Prove the end state on a running stack: a Contributor member of a Scale workspace on dev-9 is refused every setting change on every surface and the dashboard shows why, while runtime actions work.

## Steps

1. `bash scripts/dev-env.sh 9 up`; create a Scale workspace with a Contributor and a Developer member.
2. As the Contributor: REST, GraphQL and MCP writes of plan, scaling, autoscaling, health check, domains, IP rules, notification override, cron schedule, Postgres and Key Value plan → 403; restart, suspend, resume, cron run → success.
3. Walk the dashboard pages as both members.

## Acceptance criteria

- [ ] Every refused write left the resource unchanged (read back).
- [ ] The Developer's writes all succeed.
- [ ] The record lists the commands and answers (no raw dumps committed).

## Record (2026-11-24)
