## Objective

Every metrics chart flashes the literal "No data in range" empty state during fetch, because the loading flag is dropped on the floor — on the highest-traffic detail tab this reads as broken/empty data. Thread `loading` through and render a chart-shaped shimmer; give the event timeline skeleton rows.

## Context

- `dashboard/src/features/metrics/components/metric-section.tsx:28-33` — branches only on `storeUnavailable`/`unavailable`, ignores `result.loading`; child `SvgLineChart` has no loading concept, so an empty-while-loading series hits `EmptyChart` (`svg-line-chart.tsx:68`, default message "No data in range", `:252-266`).
- The charts have a fixed `HEIGHT` — reuse it for the shimmer so there is no layout shift. The network card mounts multiple `MetricSection`s (`network-metrics-card.tsx:265,316,352`).
- `dashboard/src/features/events/components/event-timeline.tsx:48-52` — bare centered `Loader2` spinner; the Events *tab* already uses skeleton rows (copy that pattern).

## Steps

1. Add a `loading` prop through `MetricSection` → `SvgLineChart` (and the bar-chart sibling if it shares the gap); render a fixed-height shimmer while loading, `EmptyChart` only when resolved-empty.
2. Replace the event-timeline spinner with 2–3 skeleton timeline rows.
3. Verify: throttled-network walk of the Metrics tab — shimmer during fetch, real chart or true empty state after, no layout shift.
