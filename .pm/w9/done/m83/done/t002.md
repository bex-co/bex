## Objective

Virtualize the log viewer's row list so the DOM holds only the visible range, while preserving every existing viewer behavior. Decide the cross-buffer text-selection tradeoff explicitly.

## Context

- `line.spans` is already computed once at ingest (m63) — the virtualized row renderer reads it; no per-frame ANSI re-parse.
- Behaviors that MUST survive (each tested in t005): follow-to-bottom, scroll-up-breaks- follow, jump-to-latest, instance chips, request chips, wrap mode, nowrap mode.
- Known tradeoff to decide: virtualization removes off-screen rows from the DOM, so whole-buffer text selection/copy no longer covers scrolled-away content. Visible-row selection still works. This must be an explicit, documented decision — not incidental.

## Steps

1. Introduce `@tanstack/react-virtual` over the row list (spacer/measure approach) using the t001 harness to verify a rendered range.
2. Re-wire follow/pin: follow-to-bottom scrolls the virtualizer to the last index; a manual scroll-up breaks follow; jump-to-latest re-enables it and scrolls to bottom.
3. Ensure instance chips + request chips + wrap/nowrap still render per row.
4. Handle variable row heights (wrap mode wraps to multiple lines) via measurement.
5. Document the text-selection tradeoff (in-code comment + the milestone README DoD line).
