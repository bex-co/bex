## Objective

Stop `scripts/install-bex.sh` from silently replacing a pre-rename bex desktop `bex` link, and document `bex edit`, the shorthand rule and the cross-repo contract.

## Context

- `scripts/install-bex.sh:109-110` installs with `mv -f` into `${BEX_INSTALL_DIR:-~/.local/bin}`.
- bex desktop's own installer yields to an existing `bex`. After its rename, it migrates only links that point into its own bundle.

## Steps

1. If the target `bex` is a symlink resolving into a `bex*.app` / `Bex*.app`, print a one-line notice before replacing it: "replacing the old bex desktop link; use `bex edit` or `bex-desktop`". Keep the script non-interactive (no prompt).
2. In `docs/bex-cli.md`:
   - add a `bex edit` section covering:
     - the lookup order;
     - the shorthand rule, with examples including `bex docs` vs `bex ./docs`;

     - the telemetry note;
   - link bex-desktop `docs/adrs/ADR002`;
   - list `bex edit` beside `bex code` and `bex upgrade` as a Bex-native command (line 3).
3. `lego/cli/README.md`: add one example to the Use section.
