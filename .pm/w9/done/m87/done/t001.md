## Objective

Thread `canCreate` from the panel into the shared `EnvVarsEditor` the same way `w9/m84` threaded `canReveal`, so a contributor (no `can_create`) sees the env-var **write** controls disabled-with-reason instead of editable controls that 403 on save. This covers both consumers of the shared editor: the service **Environment** tab and the workspace **env-groups** editor.

## Context

- `w9/m84` gated the env-var **reveal** (`can_view_sensitive`) via `useCapabilities`, but left the writes (`SetEnvVar` / delete = `can_create`) ungated — see `.pm/w9/done/048.md`.
- `EnvVarsEditor` is shared by the service Environment tab and the workspace env-groups editor — one thread covers both.
- Controls to gate: the **Add variable** form, and per-row `env-var-row.tsx` **Edit** pencil + **Delete**.
- The relation for writes is `can_create` (same class `w9/m68` moved these onto; `w9/m84` gated four sibling `can_create` controls).
- Pattern: `const { canCreate } = useCapabilities()` + `disabled` / `disabledReason` (EditableFieldRow) or `PermissionTooltip` (plain buttons) — identical to the four controls m84 already ships.

## Steps

1. Locate `EnvVarsEditor` and its two mount sites (service Environment tab, workspace env-groups editor); find where `canReveal` is threaded in from m84 and mirror it with `canCreate`.
2. Gate the Add-variable form submit + inputs with `disabled` + reason when `!canCreate`.
3. Gate `env-var-row.tsx` Edit pencil and Delete (PermissionTooltip / EditableFieldRow `disabledReason`).
4. Confirm the workspace env-groups editor inherits the same gating through the shared component (no second code path).

## Files

- `dashboard/src/features/**/EnvVarsEditor*` (shared editor)
- `dashboard/src/features/**/env-var-row.tsx`
- the service Environment tab + workspace env-groups editor mount sites

## Acceptance criteria

- [x] A contributor (no `can_create`) sees the Add-variable form, per-row Edit, and per-row Delete disabled with an explanatory reason, in **both** the service Environment tab and the env-groups editor.
- [x] An admin sees them enabled and functional (unchanged behavior).
- [x] Reveal gating (`can_view_sensitive`, m84) is untouched.
