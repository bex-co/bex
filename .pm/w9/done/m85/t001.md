## Objective

Make `tsc` type-check `**/*.test.{ts,tsx}`, which are currently excluded, and run that pass in `yarn typecheck` and CI so fixture drift is caught.

## Context

- `dashboard/tsconfig.app.json` excludes `**/*.test.tsx` from `tsc -b`; vitest does not typecheck.
- Prefer a dedicated `tsconfig.test.json` (references the app project, includes test globs, `noEmit`) over widening the app build, so test-only types don't leak into the shipped build graph.

## Steps

1. Add `dashboard/tsconfig.test.json` including the test globs (or extend the app project if cleaner) with `noEmit`.
2. Update the `yarn typecheck` script to run both the app and test projects.
3. Ensure CI's dashboard typecheck step invokes the updated script.

## Files

- `dashboard/tsconfig.test.json` (new) / `dashboard/tsconfig.app.json`
- `dashboard/package.json` (`typecheck` script)
- the CI workflow that typechecks the dashboard

## Acceptance criteria

- [ ] `yarn typecheck` compiles test files (fails on a deliberately-broken fixture)
