## Objective

Wrap bex-api's handler chain in a gzip middleware honoring `Accept-Encoding`, exempting the streaming endpoints where per-event flush latency matters.

## Context

- `lego/backend/internal/api/server.go:851-863` — `Handler()` builds `withSecurityHeaders(withCORS(mux))`; add compression at this seam.
- Streaming paths that must NOT be wrapped (they rely on `http.Flusher` per event): `GET /v1/logs/subscribe` (SSE live tail), the agent-session attach/stream proxies, and the sandbox-exec SSE reverse proxy. Identify them by route or by `Content-Type: text/event-stream` at write time.
- The middleware must preserve `http.Flusher`/`http.Hijacker` passthrough for exempt paths, set `Vary: Accept-Encoding`, and skip already-small responses if trivial to do (optional).
- New Go files carry the Apache-2.0 header from `lego/operator/hack/boilerplate.go.txt`.

## Steps

1. Implement (or adopt a minimal, well-maintained) gzip `http.Handler` wrapper in `internal/api` — prefer a small hand-rolled one over a new dependency unless a stdlib-adjacent option fits; pool `gzip.Writer`s.
2. Exempt SSE: either an explicit route allowlist at wrap time or a response-sniffing writer that disables compression when `text/event-stream` is set. Choose the mechanism that can't silently break a future SSE route (prefer content-type sniffing).
3. Wire into `Handler()`; ensure `Content-Length` is dropped when compressing and `Vary` is set.
4. `cd lego/backend && go build ./... && go test ./...`.
