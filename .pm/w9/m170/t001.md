## Objective

Let the agent hand the user a file (ADR095 D6): `share_file({path, name?, description?})` in `mcp-bex.ts`, posted through the gateway with the session-pod identity like the ADR090 PR verb.

## Context

- In-sandbox MCP: `lego/agent-image/driver/src/mcp-bex.ts` (`open_or_update_draft_pr`, hand-written JSON-RPC, error envelope `structuredContent.error`).
- PR verb path: `sshgateway/agentcred/pullrequest.go`, `agentsession/pullrequest.go` (`InternalPullRequestPath`).

## Steps

1. Add the tool: resolve the path (regular file under /workspace, /tmp or /attachments; no symlink escape), enforce 25 MiB, stream to `POST <proxy>/attachments`.
2. Gateway: authenticate the session pod as for pull-request, forward to an internal bex-api verb.
3. bex-api: run the m168 upload core as `direction: output, created_by: agent`, bound to the current turn; return `{attachmentId,name,mediaType,size}`.
4. Overlay sentence: "To hand the user a file that should not be committed, call share_file."
