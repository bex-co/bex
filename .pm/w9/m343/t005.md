## Objective

The CLI shipped in w1/m338 (ADR106 D7) manages automations from flags and from files in a repo; give it the new field so the CLI does not silently drop or reset it.

## Context

- CLI: `lego/cli/internal/agent/automations.go`, `automations_flags.go`, `automations_apply.go`.
- ADR106 D7 describes the file format; `docs/ADR106-cli-cloud-agents-automations.md`.

## Steps

1. Add `--notify-email always|on_failure|on_success|never` to create/update and `notifications.email` to the file schema.
2. `apply` of a file without the field keeps the server's value (no reset).
3. Show the setting in `get` output; update ADR106 D7's field list.
