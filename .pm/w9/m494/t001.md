## Objective

Define the canonical per-runtime dependency cache directories and deterministic invalidation-key inputs (runtime minor/patch line, target arch, and lockfile presence/hash) in `lego/operator/internal/build/native.go`.

## Context

- `lego/operator/internal/build/native.go:161-168` already configures Render's exact runtime paths: `nativeRubyGems = "/opt/render/project/.gems"`, `nativeGoPath = "/opt/render/project/go"`, `nativeCargoHome = "/opt/render/project/.cargo"`, plus Elixir's `deps`/`_build`.
- Unlike `$XDG_CACHE_HOME` (w9/m493), these directories hold compiled native extensions/binaries that ship into the runtime stage, so restoring a cache built under an older Ruby/Rust/Go/Elixir+OTP toolchain can cause ABI crashes unless the cache key changes when the toolchain changes.
- Node's `node_modules` and `NODE_MODULES_CACHE` remain owned by `w8/blocked/m161`.

## Steps

1. Add a typed per-runtime dependency-cache table in `lego/operator/internal/build/native.go` specifying each runtime's cache paths and toolchain-version key:
   - Ruby: `/opt/render/project/.gems` keyed on Ruby minor + arch (and `Gemfile.lock` when present).
   - Go: `/opt/render/project/go/pkg/mod` keyed on Go minor + arch (`go.sum` when present).
   - Rust: `/opt/render/project/.cargo` (registry/git cache) + optional `target` keyed on Rust version + arch (`Cargo.lock` when present).
   - Elixir: `deps` and `_build` keyed on Elixir + OTP version + arch (`mix.lock` when present).
2. Design the metadata manifest written beside the archive (`deps-cache.meta.json`) so `cache-restore` ignores any archive whose toolchain version or arch does not match the current build.
3. Add unit tests verifying key computation and mismatch invalidation for each runtime.
