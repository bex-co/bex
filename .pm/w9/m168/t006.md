## Objective

Implement ADR095 D4/D5: copy every session input into each fresh sandbox, then present the current turn's files as ACP blocks.

## Context

- Sandbox file transfer: ticket `internal/sandboxfiles/ticket.go` (256 MiB), gateway `internal/sshgateway/sandboxfiles` (stage + atomic mv); dispatch in `runSteerDispatch` / create dispatch (`service.go`).
- Driver: `lego/agent-image/driver/src/acp.ts:576-583` sends text only; `initialize` returns `promptCapabilities`; overlay text lives with ADR090 D2; image dir `/workspace` owned by uid 10001 (`lego/agent-image/Dockerfile:52-63`).
- ACP: every agent MUST accept `text` and `resource_link`; `image {data, mimeType, uri}` requires `promptCapabilities.image`.

## Steps

1. Before the driver turn: stream each input from the store through the sandbox-files upload to `/attachments/<turn>/<att-id>-<name>`, then make the tree read-only (dir 0555, files 0444). Failure → turn fails with `failureReasonCode: ATTACHMENT_COPY_FAILED`, no model call.
2. Pass `{attachments:[{path,name,mediaType,size,turn}]}` to the driver with the prompt; driver adds `resource_link` blocks for this turn's files and an `image` block for png/jpeg/gif/webp ≤ 5 MiB when the agent reports `promptCapabilities.image`; continuation lists earlier files as links.
3. Append the ADR095 overlay paragraph (untrusted data, read-only, outside the repo).
4. Record copy duration in the lifecycle latency instrumentation.
