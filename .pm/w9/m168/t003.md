## Objective

Implement ADR095 D2/D7/D8/D9 in one core used by every adapter.

## Context

- `internal/agentsessions` service pattern; OpenFGA relations: upload = `can_create` on workspace, read/list/content = `can_operate` on the session, unbound readable only by uploader.
- D8 limits (25 MiB/file, 10/turn, 50 files & 250 MiB/session, unbound 24 h) in one `limits.go`; D9 sniff via `http.DetectContentType` + same-family extension refinement; filename sanitizer.

## Steps

1. Upload: stream body → sniff first 512 bytes → hash while streaming to the store; enforce cap on bytes read; write the row only after the object lands; delete partial objects on failure.
2. Presign GET (15 min): inline for png/jpeg/gif/webp, `attachment; filename*=` otherwise; pinned content type.
3. Hourly sweep: delete expired unbound attachments + objects; retry object deletes left by a failed cascade.
4. Session delete cascade purges rows + objects; archive keeps them.

## Files

- lego/backend/internal/agentsessions/attachments.go (new), limits.go
- lego/backend/internal/agentsessions/service.go (Delete cascade)
- lego/backend/cmd/api/main.go (sweep wiring)

## Acceptance criteria

- [ ] Oversized, quota and invalid-name cases return the D8 codes and leave no row/object.
- [ ] Client Content-Type is ignored in favor of sniffing (test with a PNG sent as text/plain and HTML sent as image/png).
- [ ] Delete cascade and sweep proven against the fake store.
