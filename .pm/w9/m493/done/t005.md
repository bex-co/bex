Extraction took 21s.`).
- Every native type (web, private, worker, cron, static) gets it: the recipe is shared. Docker builds and prebuilt images are unaffected (`TestXDGCacheRidesOnlyANativeBuildsS3Cache`). No REST, GraphQL, MCP or dashboard surface changes: `clearCache: "clear"` reaches the archive through the same `stampClearCacheRelease` path as w9/m492's layer cache, on every surface.
