## Objective

Surface clear, Render-familiar build-log lines for cache restore/clear/upload, emit size/hit metrics, and add security/resilience guards against symlinks, path traversal, oversized archives, and corrupt payloads.

## Context

- Render's build logs show cache restore and upload progress (`render.com/docs/deploys`).
- Tenant build commands control every file written under `$XDG_CACHE_HOME`, so archive creation and extraction must resist symlink escape, `..` traversal, special device nodes, and zip/zstd bombs.

## Steps

1. Emit concise user-visible build-log lines in `cache-restore`, `cache-purge`, and `cache-save` (`==> Restoring build cache...`, `==> Build cache cleared`, `==> Uploading build cache...`) and update `native_log_display_test.go` so they display cleanly.
2. Harden archive pack/unpack: strip or refuse symlinks escaping `/opt/render/.cache`, enforce `--no-same-owner`/size cap on unpack, and treat any extraction failure as an empty cache with a log warning rather than a failed build.
3. Extend `bex_build_cache_bytes` / `bex_build_cache_phase_seconds` labels to distinguish `kind="xdg"` from `kind="layer"`.
