## Objective

Stop the sandbox node from overcommitting into a stall.

## Steps

1. Add `system-reserved`, `kube-reserved` and `eviction-hard` to the sandbox pool's KubeadmConfigTemplate (`infra/clusterapi/overlays/hetzner-caph/sandbox-pool.yaml`).
2. Give agent sandbox pods `tolerationSeconds >= 300` for not-ready and unreachable nodes, instead of the cluster's 45 s.
3. Size the pool for the allowed concurrency: either a second node (`replicas: 2`), or a larger type so that two 4 GiB-limit sandboxes fit with reservations.

## Gate

- Needs the user's go-ahead: a second node or a larger type costs money, and reservations roll the production sandbox node, which ends running sandboxes.
