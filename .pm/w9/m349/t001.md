## Objective

Let the completer tell a stalled node from a dead sandbox.

## Steps

1. In `lego/backend/internal/sshgateway/exec.go` `checkTarget` (~58-69), report a pod whose node is NotReady, or that has no Ready condition, as `target_unavailable`. A terminated target stays as it is.
2. `sandboxsse.go:254-257` emits that code instead of "exec failed to start in this sandbox".
3. `lego/backend/internal/sandbox/exec.go:511` maps it to a transient error, never to `core.ErrSandboxesUnavailable`, which reads "sandbox runtime not configured".

## Acceptance criteria

- [ ] With a fake gateway where the pod is Running and its node NotReady, a status read returns the transient error; a terminated pod still returns NotFound (tested).
