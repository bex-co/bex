# The mobile app drops the `agent_automation_paused` push

Why: w9/m343 sends an automation's creator a push when the platform pauses it, but the mobile client accepts only its closed event list, so on iOS and Android that push is silently ignored (web push in the dashboard opens it fine).

- `mobile/src/features/notifications/deep-link.ts:1-20` (`notificationEvents`) has no `agent_automation_paused`, and its `routes` allow only `/services/`, `/databases/`, `/key-values/` and `/sessions/`; a `/automations/aut-…` route fails `routes.some(...)` (`:86`).
- The mobile app has no automations screen. Route the push to the inbox entry (or open `https://dashboard.bex.co/automations/<id>` in the browser), add the event and route pattern, and cover it in `mobile/src/features/notifications/__tests__/deep-link.test.ts`.
- Coordinate with w11 (mobile client) before release.
