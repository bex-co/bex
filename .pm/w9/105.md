# Render's Terraform provider aborts every apply whose configuration names a Render region other than `frankfurt`

Why: bex accepts any Render region and reads back its own, so `terraform apply` of a service, Postgres or Key Value written for Render (`region = "oregon"`) fails with "Provider produced inconsistent result after apply" on bex. On Render the same configuration applies.

- **Found by:** w9/m474's provider acceptance run on dev-9 with production's region mapping (`BEX_REGION=fsn1`), 2026-11-18 ([docs/terraform-compatibility-checklist.md](../../docs/terraform-compatibility-checklist.md), class 1).
- **Render:** `render-oss/terraform-provider-render` `06af456`. `POST /v1/services` with `serviceDetails.region: "oregon"` answers 201 with `region: "oregon"` in every recording. `region` is a required `RequiresReplace` attribute that the provider stores from the response (`internal/provider/types/resource/services.go` `Region`, `webservice/models.go`, `postgres/models.go`, `keyvalue/models.go`).
- **bex:** the same create answers 201 with `region: "frankfurt"` (`lego/backend/internal/resourcemeta/metadata.go` `CheckRequestedRegion` accepts any Render region and places the resource in `BEX_REGION`; `RenderRegion` reads `fsn1` back as `frankfurt`). Terraform core then refuses the new state: `.region: was cty.StringVal("oregon"), but now cty.StringVal("frankfurt")`. 20 of the 47 recorded tests stopped here in run A.
- **Decision needed (user):** ADR049's one-region policy says the request value is never persisted (user decision D1, w8/152) and readback is `frankfurt` (D7, w8/218). Terraform parity needs the readback to echo the region each resource was created with, while placement stays `BEX_REGION`, or ADR018 records that a Terraform configuration must say `frankfurt` on bex. A configuration that says `frankfurt` already applies.
- **Done when:** the decision is recorded in ADR049, and either `TestWebServiceResource_Autoscaling`'s create (`region = "oregon"`) gets past apply on dev-9 with `BEX_REGION=fsn1`, or ADR018's region row records the Terraform consequence with the sign-off.
