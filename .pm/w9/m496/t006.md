## Objective

Let a human mint a key with a chosen grant and change it later, on every surface, refusing any permission the creator's current role does not allow.

## Context

- `lego/backend/internal/apikeys/rest.go` (`POST /v1/api-keys`), `graphql.go` (`createApiKey`), `mcp.go` (`create_api_key`). Render has no public key-mint API (keys are made in the dashboard), so these are bex extensions; keep them additive.
- Render: "Your member role in the selected workspace determines which permissions you can grant an API key"; the gear icon changes an existing key's permissions.
- Minting stays human-only (`AuthorizeMintClass`, I4); editing a grant is mint-class too (I8).

## Steps

1. Accept an optional `permissions` argument on the three create surfaces; omitted means t001's default.
2. Add the change-permissions verb (REST `PATCH /v1/api-keys/{id}`, GraphQL and MCP counterparts), scoped like `RevokeAPIKey` (same workspace, the key's own creator or an Admin, as t001 decides).
3. Validate against the catalog and the creator's current role at the same freshness as a write; refuse an unknown permission or level (400) and one above the role (403), in Render's error shape.
4. Classify the new operations in the scope matrix and the t004 map.
