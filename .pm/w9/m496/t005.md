## Objective

Make the grant bite: a key's request for an operation whose permission it was not granted is refused with Render's 403 shape on REST, GraphQL and MCP, and on every side entry point t001 named, whatever its creator may do.

## Context

- `lego/backend/internal/api/scope_matrix.go` `requireScopeClass` is called by all three surfaces; API keys pass it today through `CapabilityExempt`.
- `lego/backend/internal/core/keyrole.go` `keyCeiling` stays: the grant check is an additional AND (I6).

2. Cover t001's side entry points (log streams, shell and snapshot tickets, the object gateway, any GraphQL nested field that reveals a secret).
3. Keep All keys on the current path so their behavior and cost are unchanged.
