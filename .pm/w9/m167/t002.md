## Objective

Before cobra dispatch, rewrite the call to `bex edit <args…>` when the first argument is path-shaped and exists. This keeps `bex .` working for desktop users without shadowing any command.

## Context

- Pre-dispatch hooks already live in `lego/cli/main.go`: the version, login and postgres-trust interceptions on `os.Args[1:]`.
- Upstream root commands include `docs`, `logs`, `skills`, `init`, `dev`, `ssh`, `services` and others. A bare word must never be taken as a path.

## Steps

1. `isPathShaped(arg)` is true for `.`, `..`, a `./ ../ / ~` prefix, or an argument containing `/`. Strip a trailing `:line[:col]` before the existence check, and expand `~`.
2. Rewrite to the edit path only when all of these hold:
   - `os.Args[1]` is path-shaped;
   - it exists (`os.Stat`);
   - no cobra command is named exactly `os.Args[1]`.

   The remaining args pass through.
3. A path-shaped argument that does not exist errors with "no such path: X (use `bex edit X` to create)". Never create the file.
4. Leave bare `bex`, flags-first invocations (`bex -o json …`) and `__complete` untouched.

## Files

- `lego/cli/main.go`, `lego/cli/internal/desktop/shorthand.go`
