
## Done (2026-11-08)

Create accepts `serviceIds` and `envGroupIds` on REST, GraphQL and MCP. Every link is pre-checked through one `linkableService`, which `LinkBuildSource` also uses, before anything is written. A failed first link deletes the carrier; a later failure returns 409 `BUILD_SOURCE_PARTIALLY_LINKED` with `linkedServiceIds`/`failedServiceId`. Image sources refuse build-time env, as the Render spec says.
