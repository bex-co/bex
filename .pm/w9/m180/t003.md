## Objective

`configureNewImageCompatibility` and `runsContainerPolicy` (`lego/backend/internal/apps/service.go:2608-2646`) read only the service's own `Repo`/`Image`/`Runtime`, so a web or private service linked to a Docker or image build source falls back to port 10000 and no `render-v1` policy (open follow-up from w2/m254 t005). Derive both from the carrier's spec at create, at link and on relink.

## Acceptance criteria

- [ ] Tests: a web service linked to an image source gets the image-port mode and `render-v1`; unlinking returns to its own source's rules.
