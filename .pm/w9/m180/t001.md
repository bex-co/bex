## Objective

`POST /v1/build-sources` (and the GraphQL/MCP create) refuses `serviceIds`/`envGroupIds` with `BUILD_SOURCE_FIELD_UNSUPPORTED` (`lego/backend/internal/apps/build_sources.go:162-164`). Render's create body accepts both. After the carrier is written, link each service through the normal link path, with Render's refusals (start-command rule, no deploy until the deploy API is called), and link each env group. A refused link must not leave a half-created source, or the API must report which links failed the way Render does; check Render's documented behavior first.

## Acceptance criteria

- [ ] Create with `serviceIds` and `envGroupIds` links them on REST, GraphQL and MCP; an invalid service id is refused with Render's error; tests cover both.
