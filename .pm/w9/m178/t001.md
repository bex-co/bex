## Objective

Record the owning agent session on each sandbox meter row: set `session_id` on `sandbox_meter_states` (new migration) when a session dispatch creates a sandbox, and carry it into the hourly usage rows the meter rolls up. Existing rows stay unattributed.

## Acceptance criteria

- [ ] A real-Postgres test shows a dispatched sandbox's meter rows carry the session id, and a query sums one session's weighted milli-vCPU seconds across its turns' sandboxes.
