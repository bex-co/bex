## Objective

Expose the scope on every agent-secret surface and show, on the session view, the names that applied with their source. Values are never returned.

## Context

- REST `GET/PUT/DELETE /v1/agent-secrets[/{name}]` (`lego/backend/internal/agentsessions/rest.go:320-344`); GraphQL `secretNames` on the session (`graphql.go:327`) and the agent-secret fields; MCP tools in `agentsessions/mcp.go`.
- Error shapes follow ADR006/ADR038 (Render's dialect on REST, `extensions.code` on GraphQL, the code prefix on MCP).

## Steps

1. `PUT` accepts `scope` and `repo`; `GET` lists them.
2. The session view gains the applied names with their source on REST, GraphQL and MCP; `secretNames` stays the attached-by-name set.
3. Refuse an unknown scope, or a `repo` scope without a valid repository, with one machine code on every surface.

## Files

- `lego/backend/internal/agentsessions/rest.go`, `graphql.go`, `mcp.go`, `secrets.go`, `models.go`

## Acceptance criteria

- [ ] Each surface reads and writes the same scope; the applied names agree across REST, GraphQL and MCP for one session.
- [ ] No response carries a value.

## Out of scope

- The dashboard (t005).
