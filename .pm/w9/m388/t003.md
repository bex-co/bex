## Objective

Add `WorkspaceIPAllowList` beside `EnvironmentIPAllowList` on the App, Database and KeyValue specs and enforce it as one more chained layer on the HTTP Ingress and the Postgres/Key Value SNI routes.

## Context

- `EnvironmentIPAllowList`: `lego/types/v1alpha1/app_types.go:998-1009`, `database_types.go:199-208`, `keyvalue_types.go:119-128`, identity class in `app_identity.go:112`.
- Enforcement: `lego/operator/internal/controller/app_controller.go`, `lego/operator/internal/sniproxy/allowlist.go`, `cmd/pg-sni-proxy`, `cmd/kv-sni-proxy`.
- Codegen and envtest: `make test` from `lego/operator/` (see `lego/AGENTS.md`).

## Steps

1. Add the field to the three types and regenerate CRDs and deepcopy.
2. Chain a third middleware on HTTP routes and a third check in the SNI proxies; an absent field means no workspace layer.

## Files

- `lego/types/v1alpha1/*_types.go`
- `lego/operator/internal/controller/`
- `lego/operator/internal/sniproxy/allowlist.go`
- `lego/operator/config/crd/` (generated)

## Acceptance criteria

- [ ] envtest: a source allowed by service and environment but not workspace is refused on HTTP and SNI; an absent field changes nothing.
