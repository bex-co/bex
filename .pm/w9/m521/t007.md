## Objective

Check that every surface that shows or uses a Key Value's connection strings agrees with the shipped shapes and with render.com, and file each remaining drift as its own item.

## Steps

1. Walk every surface that serves or uses the strings:
   - REST `/v1/key-value/{id}/connection-info` and `/v1/redis/{id}/connection-info` (`redisCLICommand`);
   - GraphQL `keyValueConnectionInfo`;
   - MCP: Render's MCP server has no credential read, so confirm bex's has none;
   - the dashboard's Connect panel;
   - the CLI's `keyvalues` output and `kv-cli`;
   - a Blueprint `fromService` `connectionString` for a Key Value, which reads the compatibility Secret's `uri`. Check what Render's Blueprint injects.
2. Weigh the difference the milestone left out of scope. Render answers an external string for a store with `ipAllowList: []`, and a private bex store has none. Check ADR018. If it does not record that difference, file it with `/pm add w9`.
3. Record what you checked in ADR018's Key Value row.
