## Objective

On production, a Key Value created public answers the three Render-shaped strings on its first read, and each one connects once the store is available.

## Context

- Sign in with `bash scripts/qa-login.sh`, following `.claude/skills/qa-find-bugs/SKILL.md`. Never read `.env` or `muse.env` yourself.
- The check needs a production pin that carries every commit of t001–t004 (`chore(deploy): pin platform images to <sha>`). Until it does, park with ``pin must carry `<sha>` ``.
- Probe only fixtures you create. Never touch a Key Value you did not create.

## Steps

1. Mint a key and create a public store whose allow list holds only your own `/32`. Read connection info at once on REST `/v1/key-value`, REST `/v1/redis` and GraphQL, and compare each string's shape with the milestone's definition of done.
2. Once the store is available:
   - run the CLI command verbatim and get `PONG`;
   - run `bex kv-cli <id>` and get `PONG`;
   - connect over the external URL;
   - connect over the internal URL from a service in the same workspace, if a free one is at hand. Otherwise record that dev-9 covered it.
3. Delete every fixture and confirm they read 404. Revoke the key and log the QA session out.

- [ ] No fixture or key is left behind, and the session is logged out.
