## Progress (2026-11-06)

- bex-co/bex-desktop `8058754ec2`: while signed in, the context-server store adds `bex-cloud-agents`, an HTTP server at `<api>/mcp/cloud-agents`. The api host is derived from `server_url` (`BEX_API_URL` overrides it). The bearer token is read per request from the signed-in session and is never written to settings or logs. The server is removed on sign-out, and a user-defined server with the same id wins. `cargo test -p bex_auth`, the new store unit tests and the 21 existing `context_server_store` tests pass.
- bex `09bd35564`: `bex-desktop` joined `BEX_OAUTH_PLATFORM_CLIENTS` and `OAUTH_PLATFORM_CLIENTS`. Before this, bex-api refused the desktop's audience-less token under `BEX_OAUTH_REQUIRE_AUDIENCE=1` (`lego/backend/internal/api/auth.go:534-552`).
- **Remaining for acceptance:** once 09bd35564 is deployed, a signed-in desktop build lists the cloud-agents tools. Not yet run: no full desktop build or live sign-in has been done.
