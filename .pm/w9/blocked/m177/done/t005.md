## Objective

Run `/simplify` over the code this milestone changed (behavior-preserving).

## Done (2026-11-06)

`/simplify` over the `bex agent` CLI (6cb507008), with three reviews: reuse, quality and efficiency.

- Bugs fixed:
  - Ctrl-C/SIGTERM now exit 130 instead of 124.
  - `wait --any` always prints valid JSON.
  - Create retries only transient errors (429 included, `Retry-After` honored). `*url.Error` is unwrapped, so bad URLs and failed token refreshes no longer retry.
  - An expired download URL is refreshed once on 403. Name collisions are checked case-insensitively, and files already saved are still printed when a later download fails.
  - Files are finalized without overwriting (`os.Link`), and an oversized answer is refused instead of truncated.
  - `RENDER_OUTPUT` and the terminal check are honored, as on every other command.
- Efficiency: `--follow` backs off while the agent is quiet, and transcript pages use `limit=1000`.
- Quality: shared `turnFlags`/`waitFlags`, one transcript drain, explicit `request.stream`, typed `--state`/`--direction`, dead fields dropped. `desktop.OpenSession` reuses the address it is given.
- Skipped: one REST helper shared by `internal/agent` and `internal/desktop`. It needs a new shared package and one error format on both sides.
