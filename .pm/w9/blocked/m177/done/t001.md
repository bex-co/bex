## Done (2026-11-06)

- Commands: `run`, `send`, `wait` (up to 20 sessions, `--any`), `get`, `list`, `cancel`, `logs` (`--follow`), `files` (`--download`, SHA-256 checked), `open` (bex desktop or the dashboard). `-o json|yaml` prints the API's own response.
- `run` sends one `Idempotency-Key` per invocation and retries 502/503/504 and network errors with it. `--secret` and `--secret-from-env` attach ADR098 secrets; values are never taken on the command line.
- Exit codes: 0 succeeded, 1 CLI/API error, 2 usage, 3 failed, 4 canceled, 5 needs input, 124 `--timeout`.
- Backend contract gaps, filed for this milestone rather than blocking it:
  - There is no REST wait (`wait_agent_sessions` is MCP-only), so the CLI polls with a 2→15 s backoff.
  - The transcript is page-by-page over REST, so `logs --follow` polls every 2 s.
  - The CLI fixture needs a backend twin test, like `lego/backend/internal/agentsessions/cli_contract_test.go`.
