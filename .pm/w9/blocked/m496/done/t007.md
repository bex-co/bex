## Objective

Give the API keys page Render's flow: name, workspace, permissions grouped by area with each area's levels, the All, Read only and Clear all presets, a gear icon that opens the same picker to change an existing key, and a row summary of each key's grant.

## Context

- `dashboard/src/features/api-keys/` (`create-api-key-dialog.tsx`, `api-keys-panel.tsx`, `api-key-row.tsx`, `api-keys-panel-skeleton.tsx`, `locales/` in eight languages).
- The catalog comes from the API (t002), so the dashboard holds no copy of it.
- `dashboard/AGENTS.md` (skeletons must match the ready state; i18n; Playwright output dir).

## Steps

1. Build the picker from the API's catalog: areas, Render's permission names, the levels each offers, and permissions above the viewer's role disabled with the reason.
2. Presets: All (every permission the role allows), Read only (Read on every applicable area), Clear all.
3. Gear-icon edit dialog using the same picker; Save changes calls t006's verb.
4. Row summary (for example "All", "Read only" or the areas granted), and the pending skeleton updated to match.
5. Strings in all eight locales.
