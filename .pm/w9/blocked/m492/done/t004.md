## Objective

Enable `BEX_BUILD_CACHE=s3` permanently for every workspace in the production operator overlay with its sealed Wasabi credential, and emit Prometheus metrics/alerts for build-cache restore/save latency and errors.

## Context

- `lego/operator/config/prod/kustomization.yaml` and `deploy/gitops/` control production operator env vars and secrets.
- `deploy/gitops/base/rules/alerting_rules.yml` and `deploy/gitops/base/values/grafana.values.yaml` hold build-plane alerts and dashboard panels.
- `scripts/gitops-validate.sh` validates rendered manifests and alerts.

## Steps

1. Seal and install the build-cache S3 Secret into `bex-build` (and manager namespace for finalizer cleanup) and set `BEX_BUILD_CACHE=s3` in `lego/operator/config/prod/kustomization.yaml` with no workspace allowlist.
2. Add `bex_build_cache_phase_seconds{phase,outcome}` and `bex_build_cache_bytes` metrics in `lego/operator/internal/controller/build_metrics.go` plus Grafana panels and an error-burst alert in `deploy/gitops/base/rules/alerting_rules.yml`.
3. Run `bash scripts/gitops-validate.sh` and `make test` in `lego/operator/`.

## Result — 2026-11-18

- `lego/operator/config/prod/kustomization.yaml` sets `BEX_BUILD_CACHE=s3` and the four `BEX_BUILD_CACHE_S3_*` values for every workspace, with no allowlist. The Secret it names was installed and verified in t001. An operator image older than this milestone ignores the value (anything but `registry` was off), so the overlay is safe to sync ahead of the pin.
- Metrics: `bex_build_cache_phase_seconds{phase,outcome}` and `bex_build_cache_bytes{phase}`, read once per finished build from each phase's termination log (`build.Signals.CachePhases`); `TestRecordBuildSignalsMetersEachCachePhase`, `TestCachePhaseSignalsReadOnlyOurOwnOutcomes`.
- Alert `BuildCacheStoreErrors` (three S3 cache errors in 30 minutes) with a promtool test that also proves misses stay silent; the Builds dashboard's cache panel now shows the outcome mix and phase p95. `obs-scrape-keep-check.sh` (the `bex_build.*` keep covers both series) and `obs-coverage-check.sh` pass.
- `scripts/gitops-validate.sh`, promtool `check`/`test` and `make test` pass (see t008).
