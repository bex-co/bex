## Objective

Every sandbox consumer — exec handshake, connect-token mint/redeem, stop/get/list, meter, purger, agent-session dispatch, GraphQL, MCP — uses the canonical `sbx-` ID and resolves legacy UUIDs through the t001 resolver.

## Context

- Connect tokens bind workspace + sandbox + execution + command (`lego/backend/internal/sandbox/connect.go`); the exec gateway resolves the token's sandbox (`lego/backend/internal/sshgateway/sandboxsse/`).
- Sibling consumers: `exec.go`, `inventory.go`, `lifetime.go`, `purger.go`, `meter.go`, `agent_dispatch.go`, `graphql.go`, `mcp.go`.

## Steps

1. Enumerate every read of `Sandbox.ID` / `osSandbox.ID` / token-bound sandbox IDs across the package and its callers; route each through the canonical form.
2. Keep cross-sandbox / replay / wrong-operation token refusals intact (existing `connect_test.go` vectors must stay green).
3. Verify the legacy single-step `POST /v1/sandboxes/{id}/exec` path resolves both ID forms.

## Acceptance criteria

- [ ] `exec <sbx-id> -- true` exits 0; `exec <legacy-uuid> -- true` exits 0 (or clean 404, never 500).
- [ ] `stop`/`get`/`list` agree on the canonical ID for one sandbox.
- [ ] `connect_test.go` + `exec_test.go` green unmodified in intent (update only for the new canonical form).

## Out of scope

- Changing token TTL/cipher/HMAC semantics.

## Outcome (2026-09-20)

Every consumer routes through the same resolver. Two places deliberately keep
the SUBSTRATE id, because the platform names things after it: the exec ticket
(`exec.go` now mints on `raw.ID`, not the caller's string — the gateway derives
the pod as `<id>-0`) and the agent-session lifecycle (pod name + the usage
display-name join on `agent_sessions.sandbox_id`), which is why agent-session
creates are deliberately left unstamped. Connect-token mint/redeem and the
stream URI now advertise the canonical id whichever form the caller used; the
meter records the canonical id so a usage row names the sandbox the way the API
does. Existing `connect_test.go`/`exec_test.go` vectors stayed green unmodified.
