## Objective

Keep the evidence. Today Alloy ships only bex-api and controller-manager logs (`deploy/gitops/base/log-shipper.yaml`), so a lost sandbox's own output is gone.

## Steps

1. Add keep rules for `bex-system/bex-ssh-gateway-*`, `opensandbox-system/*` and the tenant `*-sandbox` namespaces' agent sandbox pods. Bound the sandbox stream's rate and line length, and drop lines that look like credentials, as the existing rules do.
2. Check the retention cost against Loki's 21-day retention.

## Acceptance criteria

- [ ] A Loki query for a sandbox id returns that sandbox's driver log on production.

## Done (2026-11-12)

Agent-sandbox pods (`bex.co/agent-session=ags-…` in `*-sandbox` namespaces; tenants' own Render sandboxes excluded) ship through a CRI-file pipeline. It allows 16 KiB lines and 20 lines/s per pod, and its rate limit runs before a credential filter: PEM blocks, cloud and Stripe keys, cookies and raw authorization values are dropped. The gateway and opensandbox-system logs join `platform_pods`. Checked by `scripts/test_log_shipper.py` against real Alloy and by `gitops-validate.sh`.
