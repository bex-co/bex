## Objective

Change `apikeys.Service` so I10 (every role) and I13 hold, with unit tests.

## Context

- `ListAPIKeys` (`lego/backend/internal/apikeys/service.go:546`) filters to `mintedByCaller` only when `Can(ctx, core.RelCanManageKeys)` is false (`:560`).
- `keyRelation` (`:662`) picks `relOwnKeys` for the caller's own key and `core.RelCanManageKeys` otherwise. `RevokeAPIKey` (`:623`) and `UpdateAPIKeyPermissions` (`:717`) make their one `Authorize` with it. `UpdateAPIKeyPermissions` then admits a non-creator Admin through `HoldsFresh(core.RelCanManage, …)` (`:754`).
- `mintedByCaller` (`:682`): a machine caller and a creator-less key own nothing.
- `can_manage_keys` keeps other consumers (`lego/backend/internal/router/service.go`, `members/service.go:489`'s capability probe), so the relation and `model.fga` do not change.

## Steps

1. Add an `allMembers` option to `ListAPIKeys`, either a parameter or a small options struct that the three adapters pass. By default, filter to `mintedByCaller` for every caller. With `allMembers`, make one audited `Authorize(ctx, core.RelCanManage)`, so a non-Admin gets 403, and return every key bound to the workspace.
2. `keyRelation`: another member's key, a creator-less key and an unknown key are decided with `core.RelCanManage` (Admin), not `can_manage_keys`.
3. `UpdateAPIKeyPermissions`: refuse anyone but the key's creator with `KeyEditorForbiddenCode`, Admins included, and reword its message. Keep the "records no creator" 400 for a creator-less key, so its order relative to the 403 stays as tested today.
4. Update the doc comments, then the unit tests in `member_keys_test.go` and `apikeys_test.go` that pin the old Developer and Admin view.

## Acceptance criteria

- [ ] Each of the five roles lists only its own keys by default. An Admin's `allMembers` lists every key, including a creator-less one. A Developer's `allMembers` is 403, audited once against `can_manage`.
- [ ] A Developer revoking or editing another member's key is 403. An Admin revokes it. An Admin editing it is 403 `api_key_permissions_editor_forbidden`. The creator edits and revokes their own.
- [ ] An API key's default list is empty. An Admin's All key passes `allMembers`. A Developer's All key gets 403 for it.
- [ ] `cd lego/backend && go test ./internal/apikeys/...` passes (run `scripts/backend-test-deps.sh up` first).
