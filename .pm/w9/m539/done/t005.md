## Objective

The Account Settings API keys panel matches Render's for every role. An Admin also gets one deliberate switch to the workspace's keys.

## Steps

1. `useApiKeys` takes `allMembers` and passes it to `apiKeys`.
2. For an Admin, the panel shows a two-way switch ("Your keys" / "All members' keys"); it defaults to the caller's own. In the all-members view, every row names its creator. The gear shows only on the caller's own rows. Revoke shows on every row, and its confirmation names the creator when the key is not the caller's.
3. A non-Admin sees no switch. Copy goes in all nine locales.
4. Update the panel's tests and add cases: a Developer sees no switch and only their keys; an Admin switches, sees another's key without a gear, and revokes it.
