## Objective

Signing out records one `LogoutEvent` per workspace, without ever delaying or blocking the sign-out.

## Steps

1. Add a bex extension mutation (for example `recordSignOut`) that records `LogoutEvent` for the caller's session in each of their workspaces.
2. Call it from `dashboard/src/common/lib/ory/logout.ts` just before `createBrowserLogoutFlow`, best effort with a short timeout.
3. Record `LogoutEvent` for the human subject in the CLI's authenticated logout path (`lego/backend/internal/cliauth/service.go`).

## Files

- `lego/backend/internal/api/` or the identity feature package, `lego/backend/internal/cliauth/service.go`, `dashboard/src/common/lib/ory/logout.ts`, tests

## Acceptance criteria

- [ ] A dashboard sign-out records one row per workspace; a failing mutation still signs the user out (test).
