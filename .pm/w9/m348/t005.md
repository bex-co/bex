## Objective

Prove the loop on production as the QA user, on a QA repository the App is installed on.

## Steps

1. Open a same-repository PR on a QA repository. Comment `/bex add a one-line comment to README`.
2. Check: a session starts as the QA member; the App reacts and replies with the link; the session's commit lands on the PR branch.
3. Comment `/bex also fix the typo` and check that it steers the same session. Comment from a fork PR and check that it gets the fork reply.
4. Clean up: close the PR, delete the branch, cancel or archive the sessions. Text evidence only.

## Gate

- The GitHub App must deliver Issue comment, Pull request review and Pull request review comment events (the w9/m344 gate).
