## Objective

Cover the behavior this milestone shipped with tests that assert the real failure modes — not the shape of the code.

## Context

- The allow-list primitive already has a natural table-test seam: `sniproxy.AllowedBy` (`internal/sniproxy/allowlist.go:55-65`) over v4 and v6 sources against v4-only, v6-only, both, and empty prefix sets. The empty-list-is-unrestricted branch is load-bearing and must be pinned.
- The property that actually broke is cross-layer: a source the client-side gate accepts must not be a source the data path silently drops. Whatever t003 chose, there should be one test that would have failed on 2026-09-21.
- Anti-enumeration is a security property and needs its own assertion: an unknown host and a denied source must stay indistinguishable to a source with no route.

## Steps

1. Table-test `AllowedBy` across both address families and all four allow-list shapes.
2. Test the denial path's observable output for a matched route with a non-matching source.
3. Test that the unknown-host path is unchanged.
4. Mutation-spot-check the new assertions.
