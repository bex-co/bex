# 080 — Session page logs React hydration error #418 on load

Why: the agent-session page renders different text on the server and the client, so React throws away the server HTML and re-renders. That costs a visible flash and can mask real errors.

- Seen in the production browser recheck on b8370c30c (2026-11-06) when loading an `/agents/<ags-id>` page. The console shows minified React error #418 (hydration text mismatch).
- Likely candidates are time-relative or locale-formatted text rendered during SSR: durations ("metaDuration"), relative times, and the cost figure, which reads data the server may not have yet. Reproduce with a non-minified dev build to get the mismatching node, then render that text client-only or from the same data on both sides.
- Done when a session page load logs no hydration error at desktop and mobile widths.
