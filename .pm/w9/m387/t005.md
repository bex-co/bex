## Objective

A failing or timed-out setup step ends the turn with a failure that names the step, its exit code (or timeout) and a redacted output tail, on every surface; the agent is not started and no model spend accrues.

## Context

- Session failure codes: `store.AgentSessionFailure` (e.g. `SKILL_COPY_FAILED` in `skills_dispatch.go`).
- Task re-delivery on a later steer (ADR047 § continuity: setup-phase failures).

## Steps

1. Add the failure and map the driver's result onto it.
2. Show it on REST, GraphQL, MCP and the session page.

## Files

- `lego/backend/internal/agentsessions/`
- `lego/agent-image/driver/src/`
- `dashboard/src/features/agent-sessions/`

## Acceptance criteria

- [ ] A failing step yields the code with step name and exit code on all surfaces; a steer after fixing the environment re-runs setup and the task.

## Out of scope

- Automatic retries of setup.
