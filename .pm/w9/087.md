# Edge caching never runs for a web service with image ports

Why: a web service in image-ports mode (`PortModeWebImageV1`) accepts a caching profile, but the operator never starts its cache (`lego/operator/internal/controller/edge_cache.go`, `AppSpec.ServesEdgeCache` requires no image ports). Render offers edge caching on every paid web service, image-backed ones included, so the setting is silently ignored for these services.

- Since w9/m345 such a service records no `edge_cache_enabled` and its purge is refused, so the feed is truthful; the cache itself is still missing.
- Either run the cache sidecar for image-ports services, or refuse the profile on them with Render's wording if Render refuses it there. Verify Render's behaviour first.
