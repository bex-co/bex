## Objective

Confirm, with an operator envtest (and live, once deployed) that canceling an image-backed App's very first deploy — with no prior successful release — now reaches `settleCanceledRelease` and settles to `PhaseCanceled`, matching `w6/m52`'s already-established value for the repo-backed case.

## Context

- This is the exact scenario reproduced live in this milestone's evidence: a fresh Background Worker on Existing Image `nginx:alpine`, crash-looping, canceled while still open. Before t002's fix, `phase` stayed `"Deploying"` forever and the pod kept crash-looping.
- `lego/operator/internal/controller/app_controller.go:565-592` (`settleCanceledRelease`) — the `app.Status.Image == ""` branch is what should now be reached.
- `w6/m52`'s own regression tests (`lego/operator/internal/controller/*_test.go` — grep for `PhaseCanceled` to find them) are the template for the repo-backed case; write the image-backed sibling test the same way.

## Steps
