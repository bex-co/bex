## Objective

Make `Cancel` tell the operator a release was canceled regardless of whether the App is repo-backed or image-backed, so `settleCanceledRelease` becomes reachable for image-backed Apps too.

## Context

- `lego/backend/internal/deploys/service.go:639-707` (`Cancel`). The annotation write (`a.Annotations[appv1alpha1.AnnotationCanceledReleaseGeneration] = strconv.FormatInt(d.Generation, 10)`, line 671) and the `s.Client.Patch(...)` that saves it (line 672) currently sit inside `if a.Spec.Repo != "" { ... }` (line 661), alongside the build-Job delete (line 679-682) and kpack-Image delete (line 688-694).
- `lego/types/v1alpha1/app_types.go:48-53` — the `AnnotationCanceledReleaseGeneration` doc comment currently says "records a **repo-backed** release whose build was explicitly canceled." Update this comment once the annotation covers both kinds — it should no longer claim to be repo-backed-only.
- The operator-side consumer (`lego/operator/internal/controller/release_identity.go:278-282` `canceledReleaseGeneration`, and `prepareAppReleaseDecision` at line 210-218) is already source-kind-agnostic — it only compares generation numbers. No operator-side code change should be needed for the annotation itself to start working for image-backed Apps; t003/t004 will confirm this operator-side behavior end to end.

## Steps

1. Hoist the annotation write + patch (lines 667-674) OUT of the `if a.Spec.Repo != ""` guard so it runs unconditionally for every Cancel call that reaches this point.
2. Keep the build-Job delete (679-682) and kpack-Image delete (688-694) inside their own `if a.Spec.Repo != ""` guard — there is no build artifact to delete for an image source, so this part of the gate is correct and should stay.
3. Update the `AnnotationCanceledReleaseGeneration` doc comment (`app_types.go:48-53`) to drop the "repo-backed" qualifier.
4. Re-read the surrounding comment at `service.go:624-638` (`Cancel`'s own doc comment) and update anything that describes the old repo-only behavior as if it were the only case.
