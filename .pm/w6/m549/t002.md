## Objective

The image checks prove `wormhole` works, not only that it is present.

## Context

- `deploy/native-base/check-tools.py` (the per-tool checks, e.g. `pigz`, `zip`), `deploy/native-base/check.Dockerfile`, `.github/scripts/native-common-qualify.py`
- A CI runner should not depend on the public relay; the `magic-wormhole-mailbox-server` and `magic-wormhole-transit-relay` packages run a local pair.

## Steps

1. Add a check: `wormhole --version`; start a local mailbox and transit relay; send a file whose name has a space and non-ASCII characters; receive it with `--accept-file`; compare sha256.
2. Run it on amd64 and arm64 and on every runtime family the qualification covers.

## Files

- deploy/native-base/check-tools.py and its harness

## Acceptance criteria

- [ ] The check passes on both architectures and fails when wormhole is removed
- [ ] It needs no network beyond the runner
