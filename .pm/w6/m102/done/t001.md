## Objective

Create one reusable component (or a thin wrapper convention) that renders `formatRelativeAge`/`formatRelativeUntil` output with `suppressHydrationWarning` baked in, so no future call site can omit it.

## Context

- `dashboard/src/features/services/lib/format.ts:25-46,51-68` — `formatRelativeAge`/`formatRelativeUntil`, both accept an injectable `now` for tests but default to `Date.now()` in production.
- Existing ad hoc precedent to match: `dashboard/src/features/env-groups/components/env-group-metadata.tsx:50-59` (`<time dateTime={value} suppressHydrationWarning>{formatDateTime(value) ?? value}</time>`, with a comment explaining the SSR/timezone divergence — same shape, different underlying formatter) and `dashboard/src/features/projects/components/resource-table.tsx:219-235` (`<TableCell suppressHydrationWarning>{formatRelativeAge(...)}</TableCell>`).
- `dashboard/src/common/components/` is the shared-component home per `dashboard/CLAUDE.md`'s directory conventions.

## Steps

1. Add a small component, e.g. `common/components/relative-time.tsx`, exporting `<RelativeAge value={iso} />` / `<RelativeUntil value={iso} />` (or a single `<RelativeTime value={iso} direction="age"|"until" />`) that renders a `<time dateTime={value} suppressHydrationWarning>{formatRelativeAge(value) ?? "—"}</time>` internally.
2. Keep `formatRelativeAge`/`formatRelativeUntil` themselves unchanged (their injectable `now` param is still needed for the component's own unit tests) — this wraps them, it doesn't replace them.
3. Write a unit test for the new component mirroring `env-group-metadata`'s test conventions if one exists, asserting the `suppressHydrationWarning` prop is present and the rendered text matches `formatRelativeAge`'s output for a fixed `now`.

## Result

**Done.** New `dashboard/src/common/components/relative-time.tsx` exports `<RelativeAge value={iso} />` and `<RelativeUntil value={iso} />`. Both render

```tsx
<time dateTime={value} className={className} title={title} suppressHydrationWarning>
  {formatRelativeAge(value)}
</time>
```

with the guard and the machine-readable instant baked in, plus three props the call sites actually needed:

- `fallback` (default `"—"`) — rendered bare, with no `<time>`, when `value` is missing or `Date.parse`-unparseable, so `dateTime` never carries a junk value. Covers `api-key-row`'s `"Never used"` and `resource-table`'s `<UnknownValue />`.
- `title` — for `services.$serviceId.events.tsx`, whose relative age carried an exact-timestamp tooltip.
- `as="span"` — for the two webhook call sites that already sit inside a `<time>`. Nested `<time>` is invalid HTML, and `suppressHydrationWarning` reaches only one level deep, so the inner element needs its own guard regardless.

`formatRelativeAge`/`formatRelativeUntil` are untouched in `features/services/lib/format.ts` — the component wraps them, and their injectable `now` still serves their own unit tests. (`common/` importing from `features/services/lib` matches the existing convention, e.g. `common/components/plan-card-grid.tsx`.)

**Test:** `dashboard/src/common/components/__tests__/relative-time.test.tsx`, 7 cases — text parity with the bare formatter, the `dateTime` attribute, the `RelativeUntil` direction, all three fallback paths, the `as="span"` shape, and a real `renderToString`-at-T → `hydrateRoot`-at-T+6s probe across the `"now"` → `"1m"` boundary asserting React raises zero recoverable errors. The last case ships with a **negative control** — the same boundary crossed by a bare `<time>{formatRelativeAge(iso)}</time>` **must** produce a recoverable error — so the test can't silently stop testing anything. Confirmed by temporarily deleting `suppressHydrationWarning` from the component: the guarded case fails, the control passes.
