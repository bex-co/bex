## Objective

Create one reusable component (or a thin wrapper convention) that renders `formatRelativeAge`/`formatRelativeUntil` output with `suppressHydrationWarning` baked in, so no future call site can omit it.

## Context

- `dashboard/src/features/services/lib/format.ts:25-46,51-68` — `formatRelativeAge`/`formatRelativeUntil`, both accept an injectable `now` for tests but default to `Date.now()` in production.
- Existing ad hoc precedent to match: `dashboard/src/features/env-groups/components/env-group-metadata.tsx:50-59` (`<time dateTime={value} suppressHydrationWarning>{formatDateTime(value) ?? value}</time>`, with a comment explaining the SSR/timezone divergence — same shape, different underlying formatter) and `dashboard/src/features/projects/components/resource-table.tsx:219-235` (`<TableCell suppressHydrationWarning>{formatRelativeAge(...)}</TableCell>`).
- `dashboard/src/common/components/` is the shared-component home per `dashboard/CLAUDE.md`'s directory conventions.

## Steps

1. Add a small component, e.g. `common/components/relative-time.tsx`, exporting `<RelativeAge value={iso} />` / `<RelativeUntil value={iso} />` (or a single `<RelativeTime value={iso} direction="age"|"until" />`) that renders a `<time dateTime={value} suppressHydrationWarning>{formatRelativeAge(value) ?? "—"}</time>` internally.
2. Keep `formatRelativeAge`/`formatRelativeUntil` themselves unchanged (their injectable `now` param is still needed for the component's own unit tests) — this wraps them, it doesn't replace them.
3. Write a unit test for the new component mirroring `env-group-metadata`'s test conventions if one exists, asserting the `suppressHydrationWarning` prop is present and the rendered text matches `formatRelativeAge`'s output for a fixed `now`.
