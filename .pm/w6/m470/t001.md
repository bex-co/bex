## Objective

`deploy.yml` can ask, for one SNI proxy, which digest to pin: the current pin when its `/kv-sni-proxy` (or `/pg-sni-proxy`) is byte-identical to the one in the freshly built operator image, and the new digest otherwise. The answer comes from w6/m469's `registry.ImageFileSHA256`, read for production's platform `linux/amd64` whatever the runner's architecture.

## Context

- `registry.ImageFileSHA256(ctx, httpClient, registryHost, repo, digest, step, file)` (`lego/operator/internal/registry/image_file.go`) verifies the manifest, config and layer digests and hashes one file in the layer the build step `step` added. It hard-codes `Platform{OS: "linux", Architecture: runtime.GOARCH}`. Its one caller is `InternalProxyBinaryFromRegistry` (`internal/controller/keyvalue_internal_proxy.go`), which compares an image with the manager's own binary.
- The build steps, as `kvInternalProxyStep` spells its own: `COPY /workspace/kv-sni-proxy /kv-sni-proxy # buildkit` and `COPY /workspace/pg-sni-proxy /pg-sni-proxy # buildkit` (`lego/Dockerfile`).
- The deploy job runs on `ubuntu-24.04-arm`; production images are `linux/amd64` only.
- The SNI binaries do not link `internal/registry` (README § Findings), so this task leaves them byte-identical.

## Steps

1. Give `ImageFileSHA256` an explicit `Platform` argument. The operator's caller passes `registry.Platform{OS: "linux", Architecture: runtime.GOARCH}`, so its behavior is unchanged.
2. Add a small main package under `lego/operator/cmd/` (for example `cmd/proxy-pin`), not built into the image. Inputs: the image repository, the current digest, the candidate digest, the file and the build step (or the file alone, with the step derived the way `lego/Dockerfile` writes it), and the platform. Output on stdout: exactly one digest to pin. A reason line goes to stderr (`kept: /kv-sni-proxy <sha256> unchanged` / `moved: binary changed` / `moved: <error>`).
3. Keep the decision a plain function with an injected hash reader, so a test can pin each branch without a registry: identical → current; different → candidate; either read failing → candidate; current equal to candidate → candidate, with no registry read.
4. Exit non-zero only on bad arguments (not a digest, unknown platform), never on a registry doubt.
