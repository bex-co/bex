## Objective

Deploy each of t001's 20 templates on production with `scripts/render-examples-live.sh`. Bring every failure to an outcome: a filed item, an existing open item, or evidence that Render fails the same way.

## Context

- Production is the reference: the page records the pin the run used (the newest `chore(deploy): pin platform images to <sha>` on `origin/main`).
- Most of the 2 h is waiting on builds. Run the templates one after another, so a shared failure (a node, the registry) is easy to tell apart from a template's own.
- Past real deploys found these classes: ports a private service's image declares (w6/m148), container privileges (w6/m149), a Phoenix app's port detection (w32/037), and runtime version selection (w8/373, w9/133, w8/399, w8/401, w8/307). Check open board items before filing a new one.

## Steps

1. Run every template and record each result line in the t001 table.
2. For each failure, keep the resources with `--keep` if you need them, read the build and deploy logs, and decide:
   - **a bex gap** (Render deploys it; its guide or the template's own history says so): file one inbox note per distinct cause with `/pm add w6 …`, naming the template, the stage, the first error line (other tenants' ids hashed) and what Render does. One note may cover several templates with the same cause.
   - **an existing item**: link it.
   - **Render fails too**: record the evidence (an open issue on the template repo, Render's guide saying a step is manual, a dated Render changelog entry).
3. Delete every kept resource when triage is done.

## Files

- `docs/render-artifacts/render-examples-live.md`
- new w6 inbox notes, through `/pm add`

## Acceptance criteria

- [ ] All 20 rows carry an outcome, the production pin, and for failures the stage and the item or evidence.
- [ ] Each distinct bex-side cause has exactly one board item.
- [ ] `bex-canary` holds none of the run's resources.

## Out of scope

- Fixing the gaps found. Each filed item is drained on its own, and a fix that takes a few lines may ship with its note.
