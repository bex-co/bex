## Objective

The deleted-resource pass meters `egress_bytes` too, from the persisted identity, so the last hour or two of a deleted service's bandwidth are billed as on Render.

## Context

- `usage.retiredAppMeterKinds` meters only instance and build seconds today
- `meterRetiredThrough` closes the streams at the deletion hour + 1
- ADR030 §14 (bandwidth billed above the allowance)

## Steps

1. Add egress to the retired pass using the persisted identity.
2. Keep the same per-source health gating as a live service.
3. Test: a service deleted mid-hour gets its deletion hour's egress row.
