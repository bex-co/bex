## Objective

Make one user-visible mutation produce one audit row. Today assigning a single service writes four identical records and creating one environment writes two.

## Context

Live capture, 2026-08-27, one **Save** in Manage resources with exactly one checkbox newly ticked:

```
aud-da7qe27krsvc73c3m2jg  02:55:04Z  environments.SetServices  metadata.service = tea-…-qa-20260826-webhook-svc
aud-da7qe27krsvc73c3m2j0  02:55:04Z  environments.SetServices  metadata.service = tea-…-qa-20260826-webhook-svc
aud-da7qe27krsvc73c3m2ig  02:55:04Z  environments.SetServices  metadata.service = tea-…-qa-20260826-webhook-svc
aud-da7qe27krsvc73c3m2i0  02:55:04Z  environments.SetServices  metadata.service = tea-…-qa-20260826-webhook-svc
```

and one **Create Environment** click:

```
aud-…  02:54:03Z  environments.CreateWithACL
aud-…  02:54:03Z  environments.CreateWithACL
```

while one **Create Project** click wrote exactly one row.

- All four `SetServices` rows carry the identical action name and the identical single `metadata.service`, so this is not a per-resource-kind fan-out (Services/Databases/Key Value/Env Groups) shedding one row per tab — each is a complete record of the same change. That is an observation, not a diagnosis: **the cause is unverified and this task must establish it before proposing a fix.**
- Candidate call paths to open: the dashboard's Save handler (does it issue one mutation or several?), `environments.Service.SetServices` and its ACL fan-out, and whichever audit sink `CreateWithACL` writes through — the 2× on create suggests the ACL half records separately from the create half.

## Steps

1. Reproduce with one checkbox and count the rows; then reproduce with two checkboxes and count again — whether the multiplier tracks the number of resources, the number of resource kinds, or neither is the diagnostic.
2. Capture the network panel for the Save: how many mutations does the dashboard actually send?
3. Trace from whichever side the count implicates to the audit write, and name the `file:line` that emits the extra rows.
4. Fix so one action ⇒ one row, preserving a genuinely distinct second record if one turns out to be meaningful (e.g. create vs ACL grant are two real events) — in which case make them distinguishable rather than identical, and say so.
