## Objective

Make the dashboard's audit table able to name the object each row acted on, by exposing the target that is already stored — without moving GraphQL onto Render's envelope, which `w4/m26` deliberately declined.

## Context

- `Event.Target` (`lego/backend/internal/audit/service.go:68`) is persisted (`lego/backend/internal/store/audit.go:116`, column `target`) and read back (`service.go:94`), but the GraphQL `AuditLog` type never exposes it. Live introspection returns 13 fields — action, actor, actorMethod, id, metadata, oauthAudience, oauthClientId, oauthScopes, relation, resource, status, targetName, timestamp — and `AuditLogMetadata` has exactly one field, `to`.
- REST already surfaces it: `renderMetadata` (`lego/backend/internal/audit/rest.go:94-101`) does `core.SplitTarget(e.Target)` into `metadata[kind] = name`, live-observed as `"metadata": {"relation": "can_create", "service": "tea-d98210cbbpdc73dcrkvg-qa-20260826-webhook-svc"}`.
- `lego/backend/internal/audit/graphql.go:70-77`'s comment says a null `targetName` lets "the dashboard fall back to the raw id" — impossible today, since the raw id is not a field. Fix the comment along with the schema so the next reader is not misled the same way.
- **Scope guard:** `w4/m26` (done) states GraphQL "deliberately keeps bex's flat dialect for the dashboard". Add a flat scalar field; do not introduce Render's `{kind: name}` metadata map on GraphQL.
- `dashboard/src/features/audit/api/audit.graphql` selects no target today and must start selecting whatever this task adds.

## Steps

1. Add the target to the GraphQL `AuditLog` type as a flat field, keeping the dialect. Decide and record whether it is the raw `"service:tea-…"` string or a split pair, and why.
2. Update `graphql.go`'s `targetName` comment so it describes what the schema actually offers.
3. Select the new field in `dashboard/src/features/audit/api/audit.graphql` and render it in the audit table.
4. **Measure the producer side, do not assume it:** `grep -rn "Target:\|\.Target = " lego/backend/internal --include='*.go' | grep -v _test` — record the exact count and enumerate which verbs set `Target` and which leave it empty. The filing measured only three verbs; that is not the vocabulary. Anything found empty that should not be is t003's shape, filed as its own row.
5. Confirm the authorization framing before exposing anything: the audit log is admin-scoped per workspace (`RelCanManage`), so a reader already holds manage rights over every object it can name. Write that argument down, and check it also holds for rows whose `status` is `denied`.
