# The agent image and the platform builder ship the Go that `lego/go.work` requires

Why: `lego/cli/go.mod` requires `go 1.27.3`, and since 2026-11-05 (`cc2043ca8`) that requirement carries the whole workspace with it, `lego/go.work` included. The agent image still builds on `golang:1.26.10-bookworm` (`lego/agent-image/Dockerfile:3`), and so does the platform builder (`lego/Dockerfile:15`). Every agent session's first `go` command in the bex repo therefore downloads go1.27.3 before it can build. In the w6/m331 t001 replay on the production sandbox node, that download was part of a 137–436 s `go mod download`. It also needs egress to the Go proxy, and it builds with a toolchain the image never pinned.
