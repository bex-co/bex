## Objective

The operator gives each `spec.readReplicas[]` name its own reader by t001's mechanism, and each replica's `internalHost` reaches only that reader.

## Context

- Instances: `databaseInstanceCount` (`lego/operator/internal/controller/database_instances.go:28`) and `cnpgClusterSpec` (`database_controller.go:502`). Readiness and the storage quota use the same instance total (`reconcileDatabaseReadiness`, `:1599`).
- Status: `updateExternalAddressStatus` (`:2078`) sets every replica's `internalHost` to `<id>-ro.<ns>.svc`. `DatabaseReadReplicaStatus` is in `lego/types/v1alpha1/database_types.go:831`.
- Failover: `triggerCNPGSwitchover` (`:2051`) patches `status.targetPrimary` to the first non-primary instance.
- The backend reads the replica statuses (`lego/backend/internal/postgres/service.go:1200`, `:1797`).

## Steps

1. Implement t001's mechanism. Keep each name on the same reader across reconciles: under option A, record the bound instance in the replica's status and rebind only when that instance becomes the primary or disappears.
2. Keep the HA standby out of every replica: it serves no replica URL. Under option A, a planned failover targets the HA standby (an unbound instance) and never a replica's.
3. Set each replica's `internalHost` to its own Service. Leave `<id>-ro` to CNPG.
4. Adding or removing a replica touches only that replica and rolls no primary Pod. Removing the last replica removes what it created.
5. Regenerate CRDs and RBAC (`make manifests`) for any new status field or resource kind.

## Files

- `lego/operator/internal/controller/database_controller.go`, `database_instances.go`, and a new `database_replicas.go` if it reads better

## Acceptance criteria

- [x] envtest: two replicas get two readers bound to distinct non-primary instances, each `internalHost` its own; the HA standby is in neither; the Cluster's pod template is unchanged by adding or removing a replica.
- [x] A unit test: a switchover with HA and replicas targets the HA standby, and a replica whose instance became primary is rebound to a standby.
- [x] `make test` and `make lint` pass.

## Out of scope

- Pooling (t003) and public hostnames (t004).

## Result — 2026-11-18

Done under t001's mechanism (one replica cluster per name, `database_replicas.go`). The envtest `Database read replica clusters` and `TestEachReadReplicaHasItsOwnClusterAndPooler` cover the readers and hosts; `TestSwitchoverTargetsTheHAStandby` the switchover. A replica's instance is never a failover target, so the rebind in the second criterion has nothing to do. `make test` and `make lint` pass.
