## Objective

Repeat t005's checks on production once a deploy carries the milestone.

## Context

- Gate: a pin whose producer contains the milestone's commits (`git log origin/main --grep "pin platform images"`, then `git merge-base --is-ancestor`), as m458 checked.
- Production kubeconfig: `scripts/fetch-app-kubeconfig.sh`, with the control-plane host key pinned per run.
- Probes in `bex-canary` are created and deleted by ID through the API (m458 t005).

## Steps

1. A `basic-4gb` probe with HA, replicas `a` and `b`, 10 GB and pooling.
2. t005's steps 2–4 from a probe pod: 90 server connections on each replica at once; each replica URL reads only its instance; the HA standby serves none.
3. The external direct and pooled URLs of `a` and `b` connect from an allowlisted host and read their own instance.
4. Delete the probe by ID (`GET` answers 404) and the load pod. Record the evidence in ADR009 and ADR018.
