## Objective

The PgBouncer container can actually accept the clients its setting allows.

## Context

- PgBouncer holds a file descriptor per client and per server connection, and its memory grows with connected clients.
- The pooler pod template is `poolerTemplate()`; tenant pods count against the namespace quota ([ADR043](../../../docs/ADR043-tenant-namespace-isolation.md)).

## Steps

1. Read the container's `nofile` limit (`/proc/1/limits`) on dev-6; if it is below about 31,000, raise it the way the cluster allows.
2. Measure memory at 1,000 clients and extrapolate to 30,000; set requests and limits, and check the namespace quota still admits the pooler.
3. Record the figures in ADR009.
