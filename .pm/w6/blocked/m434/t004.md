## Objective

Publish an `@bex-co/muse-code-acp` release that carries the capability.

## Context

- The adapter's `.agents/skills/release/SKILL.md` governs the release. The npm publish runs only in `.github/workflows/publish.yml`; never run `npm publish` locally.
- The adapter is pre-1.0, so a feature means a minor bump: 0.12.0 is expected unless a later release lands first.
- The release needs authorization: "A request only to edit this skill or ship code does not authorize publication". See the milestone's `## Source + Goal linkage`.

## Steps

1. Follow the release skill: version, `CHANGELOG.md`, checks, tag, and the publish dispatch.
2. Verify the publication with `npm view @bex-co/muse-code-acp@<version>` and the packed-install smoke.

## Files

- In the adapter: `package.json`, `package-lock.json`, `CHANGELOG.md`
