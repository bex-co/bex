## Objective

The agent image runs t004's adapter release, and the driver negotiates the capability. The driver's turn stays open across a Muse workflow, and records the workflow's result before it ends.

## Context

- The pin:
  - `lego/backend/internal/agentsession/agent-profiles.json:72` holds `npmPackage: "@bex-co/muse-code-acp@0.11.0"`.
  - `lego/backend/internal/agentsession/profiles_test.go:185` asserts that pin.
  - [ADR108](../../../../docs/ADR108-muse-code-agent.md) names the version in D1 (`:32`).
  - The image build checks the installed version (`lego/agent-image/README.md:54`).
- The capability: `initialize` in `lego/agent-image/driver/src/acp.ts:560-568` sends `clientCapabilities._meta: typedSessionFailureCapabilities`. Add the new key there. A namespaced `_meta` key is harmless to other adapters. Sending it only for the muse profile is the alternative: pick one and say why.
- The fixture `lego/agent-image/driver/fixtures/acp-agent.mjs` already reads `clientCapabilities._meta` (`:191`).
- The turn ends when `provider.prompt()` returns (`lego/agent-image/driver/src/session.ts:345-352`, with `bound.progress()` and `bound.promptSettled()`).
- The turn has three bounds, set in `lego/agent-image/driver/src/config.ts:264-290`: the ceiling, the idle bound (30 min by default) and the tool-call bound (2 h). An in-progress tool call must not count as idle. The ceiling still ends a hold that never settles.

## Steps

1. Bump the pin in `agent-profiles.json`, `profiles_test.go` and ADR108 D1.
2. Negotiate the capability in `acp.ts`, and check that the adapter's initialize answer acknowledges it.
3. Give the fixture a mode for the negotiated capability:
   1. it emits a `workflow` tool call `in_progress` and ends its own turn, keeping the prompt pending;
   2. it later completes the workflow and emits the reporting turn's text;
   3. it then answers the prompt.
4. In `test/muse.test.ts`, add a test that the turn's transcript has the workflow's completion and the reporting text before `finish`. Add a second test that the ceiling cancels a hold that never settles.
5. Run `npm test` in `lego/agent-image/driver` and `go test ./internal/agentsession/...` in `lego/backend`.
