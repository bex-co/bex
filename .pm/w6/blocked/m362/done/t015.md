## Objective

Workspace and account deletion (ADR091 D10.4, `lego/backend/internal/billing/settle.go` `Settler.SettleWorkspace`) settles unbilled agent-model usage with the same charger and export offset, so deletion neither double-bills an already-charged amount nor misses one.

## Acceptance criteria

- [ ] A test deletes a workspace after one threshold charge and settles only the remainder.

## Done 2026-11-13 (already met; no code change)

`Settler.SettleWorkspace` charges the balance by resetting the subscription's billing anchor with `proration_behavior=always_invoice` (`lego/backend/internal/billing/settle.go` ~461-487). The invoice that produces includes the subscription's pending invoice items, so a paid threshold charge's negative net item is deducted there exactly as on a cycle invoice, and every agent-model usage hour is exported to the meter before it (`ExportWorkspace`), so none is missed. The one gap (a declined charge's open invoice beside the settle invoice) is not settle-specific and is filed as w6/125.
