## Objective

A customer sees each threshold charge as its own labelled line ("Agent model charge") beside the monthly invoices, and the month-end invoice explains that charged usage is excluded, so several charges a month never read as double billing.

## Context

- Invoice reads: `lego/backend/internal/billing/read.go` (`finalizedInvoices`); REST/GraphQL billing surfaces; the dashboard's billing views (`dashboard/src/features/usage/components/billing-summary-cards.tsx` and the invoice list).

## Steps

1. Mark threshold invoices in the invoice read model (kind, amount, date) on REST and GraphQL.
2. Show them in the dashboard with their label, and note the exclusion on the cycle invoice; skeletons match.

## Acceptance criteria

- [ ] REST, GraphQL and the dashboard agree on a workspace's charges for a month.

## Done 2026-11-13

`BillingFor` lists the customer's standalone agent-model charge invoices beside the subscription's cycle invoices, newest first, each with `kind` (`cycle` | `agent_model_charge`) on REST and GraphQL (`lego/backend/internal/billing/read.go`, `internal/usage/graphql.go`; the parity test compares `kind`). The dashboard's invoice history badges a charge "Agent model charge" (zh: 智能体模型扣款) and, when the list has one, notes that a month's agent model charges are deducted from that month's invoice. The card renders only with invoices and has no skeleton; the badge sits inline, so row height is unchanged.
