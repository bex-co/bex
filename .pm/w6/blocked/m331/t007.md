## Objective

Every new sandbox is created under a neutral `sandbox` RuntimeClass with handler `bex-sandbox`. The cloud sandbox node maps that handler to runsc, and the AX42-1 maps it to the VMM chosen in t006. Behaviour is unchanged until t010, because the AX42-1 keeps its trial taint.

## Context

- ADR105 § Decision step 2. The OpenSandbox server takes one runtime class for every sandbox (`deploy/opensandbox/sandbox-cluster.toml`, `[secure_runtime]`) and one template (`batchsandbox-template.yaml`). bex-api cannot choose a runtime, so `lego/backend` does not change here.
- `deploy/gitops/base/sandbox-pod-admission.yaml` admits only `runtimeClassName == 'gvisor'` with `nodeSelector bex.co/pool == 'sandbox'`. The AX42-1 carries the same pool label, so only the class check widens.
- Adding the handler to the cloud node is a bootstrap change. Roll the node surge-first (`infra/clusterapi/overlays/hetzner-caph/README.md`).
- RuntimeClass `overhead` comes from t006. It is reserved on the cloud node too, which costs little there.

## Steps

1. Register the `bex-sandbox` handler: on the cloud sandbox bootstrap as runsc, which keeps `overlay2 = "none"`, and on the AX42-1 as the chosen VMM. Roll the cloud node surge-first.
2. Add the `sandbox` RuntimeClass. Give it scheduling `bex.co/pool: sandbox`, the sandbox toleration, and the t006 `overhead`.
3. Widen the admission policy to admit `sandbox` as well as `gvisor`.
4. Check what OpenSandbox does with `secure_runtime.type` beyond the class name. Then switch `k8s_runtime_class` and the template to `sandbox`.
5. Label the cloud sandbox node `bex.co/sandbox-runtime=gvisor`.

## Acceptance criteria

- [ ] A new sandbox runs under `sandbox` on the cloud node and reports the `-gvisor` kernel.
- [ ] A hand-made BatchSandbox that tolerates the trial taint runs under `sandbox` on the AX42-1, reports a guest kernel, and `exec` works.
- [ ] A sandbox-regime Pod with any other runtime class is still rejected.

## Out of scope

- Removing the trial taint (t010).
- Removing the `gvisor` class (t010, once no Pod uses it).
