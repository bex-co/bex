## Objective

CAPH provisions the AX42-1 from a `HetznerBareMetalMachineTemplate` into its own MachineDeployment. The bootstrap installs the same pinned containerd, runc, kubeadm, patched kubelet and kernel that the Cloud snapshot carries, verified against the same digests, because a dedicated server cannot boot a Cloud snapshot.

## Context

- `infra/packer/bex-worker.pkr.hcl` and `infra/packer/README.md`: the pins, the patched kubelet (w4/m200, `bex-kubelet/v<version>-cri-records.N`), and the kernel pin (CVE-2026-98432).
- `sandbox-pool.yaml` asserts `containerd --version` is v2.3.3 from the baked image and gates the join on verified runtimes (w9/074). The bare-metal bootstrap has to install that binary first, and keep the gate.
- Use RAID 1 over the two 512 GB disks (ADR105 § Known limits).
- The `bex-sandbox-unhealthy` MachineHealthCheck deletes and recreates a cloud machine. On one bare-metal host, "recreate" reprovisions the same server. The surge-first rule cannot apply, and the user accepted that exception on 2026-11-11 (ADR105 § Known limits).

## Steps

1. Add `HetznerBareMetalMachineTemplate`, `KubeadmConfigTemplate` and MachineDeployment `bex-sandbox-metal` (replicas 1, not autoscaled), with the RAID 1 install image.
2. In bootstrap, install the packer pins (containerd, runc, kubeadm, the patched kubelet, the kernel) and check each one against its digest. Refuse to join on any mismatch.
3. Extend `scripts/clusterapi-validate.sh` so the metal bootstrap's pins must equal `bex-worker.pkr.hcl`.
4. Add a MachineHealthCheck and remediation for the host: reboot first, then reprovision.
5. Record the single-host exception for `bex-sandbox-metal` under § Changing a machine template in `infra/clusterapi/overlays/hetzner-caph/README.md`.

## Acceptance criteria

- [ ] The machine provisions, and `containerd --version`, `kubelet --version` and `uname -r` match the packer pins.
- [ ] The kubelet's sha256 equals the patched kubelet pin.
- [ ] A changed pin in either file fails `scripts/clusterapi-validate.sh`.
- [ ] The bootstrap gate refuses to join when a digest does not match (`capi-sandbox-bootstrap.test.sh`).
