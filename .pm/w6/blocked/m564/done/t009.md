## Objective

t004's production run (2026-11-23) found that the idle close read the conversation stream as an open editor. Since ADR077 round 17 the gateway's agent attach writes an `ssh_sessions` row for the session id, as an SSH login does, and `AgentSessionSSHActivity` read every row. A session page left open on a sandbox that resume started for an editor keeps a live stream that never ends, so the sandbox stayed up with no SSH connection at all (`deferring teardown, editor SSH open`), for up to the 4-hour cap; and every page view of a finished session moved the idle clock. Only an SSH login is an editor (ADR054 D6, ADR059).

## Context

- `lego/backend/internal/store/sshsessions.go` (`AgentSessionSSHActivity`, read by the Completer's `teardown` and `undelivered`).
- The three writers: `sshgateway/nativessh/server.go`, `sshgateway/webshell/websocket.go`, `sshgateway/agentattach/agentattach.go`.

## Acceptance criteria

- [x] `ssh_sessions.transport` (`ssh`, `web_shell`, `agent_attach`; migration `0339`, default `ssh`) records how each gateway session arrived, and each writer sets it.
- [x] The idle close reads SSH logins only: an open conversation stream does not keep a finished session's sandbox, a page view does not move its idle clock, and an SSH disconnect still does (`TestTheConversationStreamIsNotAnEditorPG`, real Postgres; with the filter reverted its first two cases fail).
- [x] The gateway tests assert each writer's transport. ADR054 D6/D8 and ADR059 say so.

## Out of scope

- The dashboard leaving the stream itself open after the start settles, which still holds one of the person's gateway sessions: w6/171.
