## Objective

A queued `ci_failure` item notes, for each check that also fails on the base branch, "also failing on <base>@<sha>". The steer's prompt tells the agent this failure is not from its change, and that it should leave it unless the task covers it. The turn origin records the note.

## Context

- This follows the proposal's recommendation, not a user decision. Devin "always processes CI failures" (ADR047 D11), so bex keeps steering and adds the note. Dropping such steers would diverge from Devin and needs the user's sign-off.
- The routine automation prompt already tells routine sessions to check origin/main first (2026-11-14). This makes the same fact available to every session.

## Acceptance criteria

- [ ] A steer for a check that also fails on the base branch carries the note in its prompt and its recorded origin.
- [ ] A steer for a check that passes on the base branch is unchanged.

## Done 2026-11-14

For every failing check that also failed on the base's latest commit (by name), the steer adds: "It also fails on `<base>` at `<sha>`, so your change did not cause it: leave it unless your task covers it."
