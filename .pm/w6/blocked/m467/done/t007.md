## Objective

Check that each replica's own hosts read the same on every surface and match Render's contract.

## Steps

1. REST `GET /v1/postgres/{id}` and `/connection-info`, GraphQL and MCP: each replica's `connectionInfo` (internal, external, pooled) and `readReplicaConnectionStrings[]` carry its own hosts, with the same fields and values on all three.
2. The dashboard's connection panel lists each replica's own direct and pooled strings (`dashboard/src/features/databases/`).
3. Compare with Render's `postgresConnectionInfo` and `readReplica` schemas in `lego/backend/internal/api/openapi/render-public-api-1.json`. File any drift as a follow-up.

## Acceptance criteria

- [x] The four surfaces agree for a two-replica pooled database, and any drift is filed.
