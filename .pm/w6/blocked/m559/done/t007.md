## Objective

Make sure the shipped behavior is covered by tests that fail when it breaks:

- the holder is mounted before the template write;
- each fallback lets the rollout go on;
- the holder ends on the same node only after the new pod's mount, and at once on another node;
- an interrupted rollout leaves no holder;
- the holder is never an instance.

Add what t002 and t003 missed, with a mutation spot-check for each.

## Acceptance criteria

- [x] The tests assert real behavior and failure modes, each mutation is recorded here, and `make test`, `make lint` and the backend suite pass.
