## Objective

Before shipping, show with real production images that the command keeps a pin whose SNI binary is byte-identical and moves one whose binary changed, and that the shipping commit's manifests change no DaemonSet.

## Context

- w6/141 hashed `/kv-sni-proxy` out of GHCR: identical in pins `336b647b1`, `5e0fb5ad8` and `fc4fbf28a`, different in `9c79201b4`, `e36296ae8` and `359aee37d`. Each pin commit's `deploy/gitops/base/bex.yaml` names its operator digest.
- The images are public; the command reads them anonymously.

## Steps

1. Run t001's command (`linux/amd64`) for both proxies on `336b647b1`'s digest against `fc4fbf28a`'s: it keeps the current digest. Then `5e0fb5ad8`'s against `e36296ae8`'s: it moves. Record the hashes.
2. Render `config/prod` the way Argo does at the shipping commit (a temp copy with the three `kustomize edit set image` entries from `bex.yaml`) and diff it against the render at `origin/main` before the change: no DaemonSet differs.
3. Run the write-back logic (or its script) against a scratch clone with the command answering "kept", then "moved", and read the resulting diff.
