## Done — 2026-11-16

- **Pin consistency:**
  - `TestToolchainInventoryMatchesCommittedPins` already fails when a digest is edited in one listed file but not another. `toolchain-freshness.py validate` also fails on a pin-site digest the inventory lacks.
  - The gap was CI. Three listed files were outside `operator-test.yml`'s paths: `deploy/cnb-run/Dockerfile`, `deploy/gitops/charts/kpack/platform.yaml` and `deploy/hugo/Dockerfile`. So a push editing only one of them never ran the check.
  - All three are now in both path lists. The new `TestToolchainPinSitesRunThisSuite` reads the inventory and the workflow and fails on any listed file that would not trigger the suite. It failed with exactly those three before the paths were added.
- **Default patches:**
  - The new `TestNodeAndElixirDefaultsAreRendersExactPatch` covers each step: a new service builds on exactly 24.22.1 / 1.18.4, while unknown age, an explicit line, a service created before the step, and a missing tag all keep the reviewed patch.
  - The test also fails if a line's reviewed patch ever equals the default again, since then it would no longer prove anything.
  - `TestExactErlangBuildsOnTheRequestedOTP` now runs with a creation date, so its `ERLANG_VERSION`-only case proves Render's default Elixir 1.18.4 is used.
  - Removing the new `exactDefaults` rows, or the `ERLANG_VERSION` branch, makes these tests fail.
- **Real builds** (`BEX_BUILDKIT_INTEGRATION=1` against the refreshed pins), all passing:
  - `TestNativeGoBuildsCurrentAndOldModules`, `TestNativeImageStartsWithEmptyPATH`, `TestNativeImageRunsPoetry`
  - `TestNativeImageRunsPnpm` (pnpm 10.34.9 on Node v22.23.5 / v24.22.3 / v26.13.1)
  - `TestNativeImageRunsJSToolsBesidePrimaries` (every Ruby, Python, Go, Rust and Elixir line)
  - `TestNativeImageRunsFFmpeg`, `TestNativeNodeServiceDrainsUnderNpm`, `TestNativePythonServiceStopsOnSIGTERM`, `TestNativeImageRunsTheLockedRuby`
  - `TestNativeNodeImageRuntimeEnvironment`, `TestNativeElixirImageMixEnvironment`, `TestNativeRubyImageRailsEnvironment`
