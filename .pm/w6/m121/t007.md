## Objective

Cover the behavior this milestone shipped: the previously blocked verbs are reachable, the header list admits what handlers read, and the origin allowlist is unchanged. Assert real behavior and failure modes — not that a string equals a string.

## Context

- `t004` is the structural drift guard (preflight ⊇ router). This task is the behavioral half: that real requests on the fixed verbs actually complete through the assembled stack.
- The interesting failure modes: a verb advertised but not routed (advertising everything would satisfy a naive superset test), an origin not on the allowlist receiving headers, and `Vary` being clobbered.

## Steps

1. Table-test `OPTIONS` across verbs and route families, asserting the advertised set per route.
2. Test that a non-allowlisted origin receives no CORS headers, and that an empty `BEX_API_CORS_ORIGIN` disables CORS entirely (the `len(allowed) > 0` path).
3. Test `Vary: Origin` and `Vary: Accept-Encoding` coexisting (`e2394e52`'s regression).
4. Test `Idempotency-Key` reaching `webhooks/rest.go:213`'s handler.

## Files

- `lego/backend/internal/api/` tests

## Acceptance criteria

- [ ] `cd lego/backend && go test ./...` passes.
- [ ] Tests fail if the origin allowlist is widened, if `Vary` is clobbered, or if a previously working GET/POST route stops being advertised.
- [ ] No tautological assertions (no test whose only claim is that a literal equals itself).

## Out of scope

- Browser-level end-to-end verification; that is the milestone's DoD, run live rather than in CI.
