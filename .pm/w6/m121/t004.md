## Objective

The defect is drift between two descriptions of the same router, and it went unnoticed because nothing compared them. Add the comparison as a test: enumerate the verbs the mux registers, and assert the preflight advertises a superset. Adding a route on a new verb must fail this test rather than silently 404 browser clients.

## Context

- The test must enumerate **from the router**, not from a list restated in the test file — a restated list is the same failure mode one layer up.
- Go 1.22+ mux patterns are `"VERB /path"`, which is what makes enumeration possible.
- Cover the routes that work today (GET/POST) as well as the ones that do not. They work *because* of the current literal, so a careless "derive it" refactor could drop them and no existing test would notice.
- Same shape for `Allow-Headers`, but against an explicit reviewed allowlist rather than the router — headers are not derivable from route patterns, so the guard there is "the list matches the reviewed constant, and changing it is a deliberate edit".

## Steps

1. Enumerate the registered patterns and extract the verb set.
2. Drive a real `OPTIONS` request through the assembled middleware stack for a sample of routes across verbs, and assert `Allow-Methods` covers each.
3. Assert the non-allowlisted-origin case returns no CORS headers, so the guard cannot be satisfied by advertising everything to everyone.
4. Demonstrate the guard works: temporarily register a throwaway route on a verb outside the set and confirm the test goes red.

## Files

- `lego/backend/internal/api/` — test alongside the existing auth/CORS tests
- `lego/backend/internal/api/auth.go` if the enumeration needs a small exported seam

## Acceptance criteria

- [ ] `cd lego/backend && go test ./internal/api/...` passes after `t001`+`t002`, and fails when a route is added on an unadvertised verb (demonstrated, not asserted).
- [ ] The verb set comes from the router; no second hand-written list of verbs exists in the test.
- [ ] GET and POST routes are covered too, not only the previously broken verbs.
- [ ] The non-allowlisted-origin assertion is present.
