## Objective

No repository check treats the native workflows as byte-pinned, and the docs describe fresh-only qualification.

## Context

- `scripts/github-actions-validate.sh` has three D3 exemptions:
  - ~line 372: checkout check skips `native-base-image.yml` and `native-common-image.yml`, "byte-pinned by w8/m91's D3 custody";
  - ~line 615: bounded-jobs `EXEMPT = {"native-base-image.yml"}`;
  - ~line 675: older action refs kept in `expected_actions` only for `native-base-image.yml`.
- `scripts/ship-gates.sh` gate 5 (lines ~26 and ~157) reads `native-common-qualify.py custody-paths`; `scripts/ship-gates.test.sh:129` copies the helper.
- `deploy/native-common/README.md` lines ~28–30 describe reusing the reviewed 0941 index.
- `scripts/ci_test_inputs.py` and workflow `paths` may list deleted files.

## Steps

1. Drop each D3 exemption. Where dropping one makes the check fail, change `native-base-image.yml` or `native-common-image.yml` to conform (sparse checkout or a `# full-checkout:` reason, job `timeout-minutes`, current reviewed action refs). Do not keep the exemption.
2. Point `ship-gates.sh` gate 5 at what t001 kept (or at the native path regex alone), and drop the "custody" wording. Update `ship-gates.test.sh`.
3. Rewrite the 0941 reuse paragraphs in `deploy/native-common/README.md` to describe fresh-only qualification.
4. Remove deleted files from `scripts/ci_test_inputs.py` and from workflow `paths`, then run `python3 scripts/ci_test_inputs.py`.
