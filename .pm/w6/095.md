# A private service from a prebuilt image publishes only $PORT, not the ports its image declares

Why: Render detects every open port of a private service. On bex, a prebuilt-image `clickhouse/clickhouse-server:23.8` private service published only `PORT`, so a peer's native-protocol connection to 9000 was refused until PORT was moved to 9000 (crypto-price migration, 2026-10-27).

- **Cause:** `configureNewImageCompatibility` (`lego/backend/internal/apps/service.go` ~2528) sets `PortModeImageV1` only when `spec.Type == private_service && spec.Repo != ""`. Prebuilt `spec.Image` private services never get image TCP metadata. The web-service branch already covers `spec.Image`.
- **Evidence:** `srv-dbg4lfdn83uc738uug70` reported `openPorts: [8123]` with `PORT=8123`, then `[9000]` after `PORT=9000`. The Git-built m149 ClickHouse fixture published `[8123, 9000, 9009]`.
- **Fix:** extend the private-service branch to `spec.Image != ""`, with the operator resolving the prebuilt image's config. Test with the ClickHouse image. Existing services need a migration path, or the m148 opt-in.

## Progress — 2026-10-29

- **Implemented:** `configureNewImageCompatibility` stamps `image-v1` (or `image-configured-v1` with an explicit port) on new prebuilt `image:` private services. The operator reads any prebuilt image's config, private or web, anonymously or with the App's bound registry credential, matched to the image's host as kubelet matches it, Docker Hub aliases included. A Basic credential is exchanged at the registry's Bearer realm, and one token now serves the manifest and blob reads. Tests: `TestPrivateImagePortsDefaultForDockerAndPrebuiltPrivateServices`, `TestPrivatePrebuilt*` (ClickHouse `[8123 9000 9009]`, credentialed read, another host's credential never sent, missing Secret named), `TestExchangesForBearer`. ADR004/018/049/089 amended.
- **Also fixed:** web prebuilt images from a private registry previously failed their metadata read (anonymous only).
- **Existing services:** unchanged, per ADR089 ("migrate existing services only through a deliberate operation"). `srv-dbg4lfdn83uc738uug70` keeps `PORT=9000`.
- **Remaining:** after deploy, create a prebuilt `clickhouse/clickhouse-server:23.8` private service as QA, confirm `openPorts` `[8123, 9000, 9009]` and a native-protocol connection to 9000 from a peer, then delete the fixture.
