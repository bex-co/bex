## Objective

A consumer whose environment references another service's port never starts with a wrong value. It waits while the target's primary is unresolved, gets the serving port, and re-rolls when that serving primary changes. A pending candidate's port never leaks in before the candidate serves (ADR089 D4).

## Context

- Precedent for the wait: `fromDatabase` refs become non-optional `SecretKeyRef`s, so the consumer stays Pending until the CNPG Secret exists (`appEnv`, `lego/operator/internal/controller/app_controller.go:4890`).
- The target's published port is `App.ServicePort()` / `ActiveImageNetwork()` (`lego/types/v1alpha1/image_network.go`). It is 0 while discovery is pending, and it follows `ServingNetwork` during replacement.
- The reference shape comes from t001/t005.

## Steps

1. Resolve the reference when building the consumer's pod template: `<slug>:<port>` for `hostport`, `<port>` for `port`, read from the target App in the same namespace.
2. While the target port is 0, keep the consumer unready with a named, user-visible reason (for example `waiting for <target>'s port to be resolved`). Never start it with 3000.
3. Watch/enqueue consumers when a target's serving primary changes, including `SetPort`, a promotion after a port-set change, and a rollback or cancel restoring the old network. The resolved value is part of the consumer's release identity, so a change re-rolls it.
4. Cover suspend/resume and a deleted target, which must give a named failure, not a silent stale value.

## Files

- `lego/operator/internal/controller/app_controller.go` (env build, watches), `release_identity.go`

## Acceptance criteria

- [ ] Envtest: the consumer stays Pending with the named reason until the image-port target promotes, then runs with `<slug>:8123`.
- [ ] Envtest: `SetPort` 3000 → 8080 on a configured target re-rolls the consumer to `<slug>:8080`. A canceled target replacement leaves the consumer on the old value.
- [ ] No consumer reconcile reads a candidate-only port before promotion.
- [ ] `make test` in `lego/operator` passes.

## Out of scope

- User-authored literal URLs: they remain the user's configuration (ADR089 D4).
