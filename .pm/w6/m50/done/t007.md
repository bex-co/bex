## Objective

tautological/snapshot coverage.

## Steps

1. Backend: a real-Postgres integration test proving a failed sync (both the
   `CreateBlueprint` initial-sync path and the shared `runSync` path used by
   manual + webhook auto-sync) persists a non-empty `error_message`, and a
   successful sync leaves it null. Prove it red before t001's fix.
2. Backend: REST/GraphQL/MCP tests confirming the field round-trips.

   `error`-state row and nothing extraneous on a `success` row.

   short queries no longer return unrelated resources, and that an id
   fragment and a `redis`-style exact substring still correctly match. Prove
   red against the un-fixed cmdk default filter first.
