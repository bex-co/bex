## Objective

Make the reconciled Deployment's container `Command`/`Args` reflect `App.Spec.StartCommand` when set, overriding the image's default `ENTRYPOINT`/`CMD`.

## Context

- The operator's Deployment-building code currently lets the image's own `ENTRYPOINT`/`CMD` run as-is; no `Command`/`Args` override exists on the App CRD today.

## Steps

1. When `App.Spec.StartCommand` is set, parse it (shell-word split, e.g. via `shellwords`/`shlex`-equivalent or a simple documented convention) into the container's `Command`/`Args`.
2. Unset `StartCommand` leaves `Command`/`Args` empty (image default), unchanged from today.

## Files

- `lego/operator/internal/controller/app_controller.go`

## Acceptance criteria

- [ ] Setting `StartCommand` on an App changes the running container's process to that command.
- [ ] Unset behaves identically to today.
- [ ] envtest coverage for both states.
