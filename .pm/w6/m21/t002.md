## Objective

Make the in-cluster BuildKit build Job use `App.Spec.DockerfilePath` when set, instead of always defaulting to `<context>/Dockerfile`.

## Context

- `lego/operator/internal/build/build.go:216-264` — the BuildKit Job's `--opt context=<repo>.git#<branch>[:<rootDir>]` construction has no `--opt filename=` override today (defaults to `Dockerfile` at the context root).
- `docs/ADR004-deployment.md` documents the current build-from-git flow.

## Steps

1. When `App.Spec.DockerfilePath` is set, add `--opt filename=<path>` to the buildctl invocation.
2. Validate the path is relative (reject absolute paths / `..` escapes) before passing it through.

## Files

- `lego/operator/internal/build/build.go`

## Acceptance criteria

- [ ] A build with `DockerfilePath: docker/Dockerfile.prod` uses that file instead of the root `Dockerfile`.
- [ ] Unset `DockerfilePath` behaves exactly as today (byte-identical build args).
- [ ] Path traversal attempts are rejected.
