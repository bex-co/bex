## Objective

Cover the idle window, which is what nothing tested.

## Context

- The existing tests cover hibernate (does it park?) and wake (does a request bring it back?). Neither asserts the interval **between** them, which is where this lives — a test that parks and immediately wakes cannot see a service that un-parks on its own a minute later.

## Steps

1. Add an operator test that advances the clock across several TTL periods with no request and asserts the Deployment stays at 0 and `last-active` does not advance — red before t002.
2. Assert no `service_woken` fact is produced across that window.
3. Keep a genuine-wake test as the control, asserting exactly one `service_woken`.
4. Cover explicit suspend across the same window (must stay parked).
5. `make test` (operator) and `cd lego/backend && go test ./...`.
