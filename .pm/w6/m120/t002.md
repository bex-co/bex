## Objective

Apply t001's finding so a parked App stays parked until a request arrives.

## Context

- The bar is not "park harder": a genuine wake must stay fast and reliable. `w6/m116`'s run measured the real path at 15 seconds with the documented `503` + `retry-after: 5` interstitial, and `w6/m94` fixed two races on it. Both must hold after this.
- If t001 finds the annotation is being cleared, the fix is to preserve it — but consider whether the parked state should stop depending on a mutable annotation at all, since that is what makes it fragile.
- Explicit suspend must be untouched: a suspended App is parked for a different reason and stays parked regardless of traffic.
