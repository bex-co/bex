## Objective

`sandboxTemplateRegistry` (`lego/backend/cmd/api/main.go`) registers `agent-4c-8g`: the agent image and driver at the `4c-8g` plan's 4 CPU / 8Gi. The default `agent` template stays 2 CPU / 4Gi, so customers' sessions and their price do not change. Idle suspension and the storage meter key on the agent-session stamp, not the template name, so the new template is treated as an agent sandbox.

## Done when

bex-api on production accepts `agentConfig.template: agent-4c-8g` and the sandbox runs with 4 CPU / 8Gi limits.
