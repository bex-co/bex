## Objective

Prove the outage class is closed the same way it was discovered: put a git-built App onto a **fresh** tenant node (scale up a node or roll one) and verify the image pulls first-try with zero manual configuration — the exact scenario `w1/m26/t007` proved for the pre-auth world and `w1/m36`'s roll broke post-auth.

## Steps

1. Trigger a fresh tenant node (autoscaler scale-up preferred — the real hot path).
2. Schedule/evict a git-built App onto it; watch the pull succeed (`Events`: no `ImagePullBackOff`, no `no basic auth credentials`).
3. Record evidence (node name, pod events, digest) in the milestone.

## Acceptance criteria

- [ ] Fresh-node authenticated pull succeeds first-try with the SA patch absent; evidence captured.
