## Objective

Decide what happens to the historical record. Every App's `instance_seconds` has been written as `Quantity: 0` with `SourceHealth: healthy` for as long as the meter has run; fixing the query forward does not fix that, and "do nothing" is a legitimate answer that must still be a decision, not an omission.

## Context

- `processAppMeterWindowResult` (`lego/backend/internal/usage/service.go:793-844`) upserts a row per App per hour and treats a successful zero as real coverage — so the per-meter cursor has advanced past every one of those windows and will never revisit them.
- Re-metering is bounded by Prometheus retention: cAdvisor series older than the retention window cannot be recovered at any price. Establish the actual retention from `deploy/gitops/base/prometheus.yaml` before choosing.
- The rows feed `estimatedCost` (bex's own estimate) and, via the ADR040 seal-then-emit outbox, Stripe meter events. Rewriting history has a billing consequence in both directions — a backfill that emits meter events for already-sealed windows is not obviously safe.
- `docs/ADR040-billing-metronome.md` owns the seal window and the emitter's retry semantics; read it before proposing any backfill.

## Steps

1. Establish the blast radius in rows and time: how many `usage_hourly` service `instance_seconds` rows exist, over what date range, and how much of that range is still inside Prometheus retention.
2. Enumerate the options and their consequences: (a) leave history as-is and start correct going forward; (b) rewind the per-meter cursor for the recoverable window and re-meter; (c) rewind and re-meter but suppress Stripe meter-event emission for already-sealed windows.
3. Check what a re-meter would do to already-sealed/emitted windows before choosing (b) or (c) — trace the outbox path, do not infer it from the ADR summary.
4. Pick one, implement it, and record the decision and its reasoning in the milestone README including the row/date numbers from step 1.
5. If the answer is (a), say so explicitly in the README rather than leaving it implied.
