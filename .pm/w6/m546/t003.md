## Objective

Every way a Go service runs a process starts in the new directory, as on Render.

## Context

- The start command, pre-deploy Job, cron run and initial deploy hook take the image's `WORKDIR` unless the operator sets `workingDir`; Shell and SSH sessions (`lego/backend` ssh-gateway exec) start where the container does.
- Search `lego/` for `/opt/render/project/src` and `workingDir` to find any hard-coded copy.

## Steps

1. Find every place that sets or assumes the working directory for these processes and move it to the per-service directory.
2. Check the Shell and SSH start directory on dev-6 with a Go fixture.

## Files

- lego/operator/internal/controller (pre-deploy, cron), lego/backend ssh-gateway exec, as found

## Acceptance criteria

- [ ] On dev-6, `pwd` in the start command, a pre-deploy command, a cron run, Shell and SSH prints Render's Go path
- [ ] `make test`, `make lint` and `cd lego/backend && go test ./...` pass

## Out of scope

- Non-Go runtimes
