## Objective

Cover every service type against the auto-sleep path, and cover Resume against a zero-replica service.

## Context

- The existing tests could not see this: they exercise auto-sleep on the type that works (`web_service`) and the type that is excluded (`background_worker`). `private_service` sits between them and was never asserted either way — which is exactly how a predicate that excludes one of two Ingress-less types passed review.
- The five types split three ways at `app_controller.go:1700-1710`: `cron_job` and `static_site` return early, `background_worker` is excluded by the flag, and `web_service`/`private_service` both reach `desiredReplicas`. A table test over all five makes the split explicit instead of leaving the middle case unstated.

## Steps

1. Operator envtest, one case per type: web (sleeps), private (per t001), worker (never), cron and static (never reach the path). Red before t002 for the type that moves.
2. Assert the "wakes on next request" message is only stamped on a type that can be woken.
3. Backend test: Resume on an auto-hibernated service produces t003's decided outcome; Resume on an explicitly suspended service is unchanged.
4. Assert the dashboard renders the idle control only for eligible types.
5. `make test` (operator), `cd lego/backend && go test ./...`, `dashboard/yarn test`.
