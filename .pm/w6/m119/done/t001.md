## Objective

A free `private_service` hibernates and nothing brings it back. Decide which half is wrong: that it sleeps, or that it cannot wake.

## Context

- `.pm/w6/done/m43/done/t002.md:35,55,64` records as settled design that "Only `web_service`/`private_service` have `idleTTLSeconds`-driven auto-sleep", and instructs "leave the free-tier web/private sleeping behavior byte-identical". So this is a mis-drawn line, not an unnoticed type — the eligibility was chosen, the wake path was never checked against it.
- The wake path is the activator, reached as an **Ingress backend** (`app_controller.go:2031`). `EffectiveHosts` returns `nil` for a non-routable type (`types/v1alpha1/app_types.go:848-851`), so a private service has no Ingress — confirmed live in run 46: its platform host returns Traefik's default 404 with no cert, and custom domains are refused with "a private_service has no ingress and cannot have custom domains".
- The two coherent options:
  - **Exclude the type.** Cheapest and consistent with the worker exclusion's own stated reason. Costs the free-tier saving on private services, which ADR003's economics assume across free Apps.
  - **Give it a wake path.** A private service *is* reachable in-cluster through its ClusterIP Service, so a wake could in principle hang off that rather than an Ingress. This is real design work, not a flag flip, and needs its own note about what observes the first in-cluster connection.
- Do not pick "leave it, document it": the dashboard actively offers the control, and `t004` can only fix the copy if the behavior is decided.

## Steps

1. Confirm the unverified premise first: with the Deployment at 0 replicas, is the private service's ClusterIP Service genuinely without endpoints, and does an in-cluster caller get a refused connection rather than a queued one? This hunt had no in-cluster vantage point. The answer decides whether option 2 is even reachable.
2. Check whether anything re-stamps `app.bex.co/last-active` for a private service after the initial Running reconcile (`app_controller.go:2098`). If nothing does, hibernation is permanent by construction and option 1 is the only cheap answer.
3. Decide, and record it in `docs/ADR003-control-plane.md` (the `sleep = free` paragraph) and `docs/ADR007-restart-suspend-and-resume.md`.
4. Note the decision against `w6/m43/t002`'s eligibility statement so the two do not disagree.
