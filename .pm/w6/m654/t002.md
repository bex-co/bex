## Objective

Let the script answer a plan's `requiredManualEnvVars` with values from a file or from flags, then approve, as a user does in Render's Deploy to Render form.

## Context

- The script creates the Blueprint from the repository and approves the planned sync. The approval takes `manualEnvVars` ({serviceType, serviceName, key, value}); a missing key answers `BLUEPRINT_MANUAL_ENV_VARS_MISSING` and an extra one `BLUEPRINT_MANUAL_ENV_VAR_UNKNOWN` (`lego/backend/internal/apps/blueprint_onboarding.go`).
- The script prints only stdout and hashes ids through `scripts/lib/public_log.py`. Values must never be printed.

## Steps

1. Add `--value <service>:<KEY>=<value>` (repeatable) and `--values <file>`, a file of the same lines kept outside the repository.
2. Read the plan's `requiredManualEnvVars`. Answer every one from the values given, and stop at stage `plan` naming each key with no value, before approving.
3. Keep the result line and the cleanup as they are. Never echo a value, even in an error.

## Files

- `scripts/render-examples-live.sh`

## Acceptance criteria

- [ ] A template with a `sync: false` key goes live on production with `--value` given, and stops at `plan` naming the key without it.
- [ ] No value appears in the script's output.
- [ ] `shellcheck scripts/render-examples-live.sh` is clean.
