## Objective

Deploy each of t001's templates with its values on production. Bring every failure to an outcome: a filed item, an existing open item, evidence that Render fails the same way, or "needs a real key".

## Context

- Pin and GitHub budget as in w6/m653 t003: start once [w6/185](../185.md) has shipped, or run at no more than 20 creates an hour if it is parked.
- Match failures to w6/183, w6/184 and w6/186 and to anything w6/m653 filed before filing new ones.
- "Needs a real key" is not a bex gap. It applies only when the process's own output says it refused the placeholder.

## Steps

1. Run each template and record its result line.
2. For each failure, rerun it with `--keep` if you need the logs, then decide:
   - **a bex gap:** file one note per distinct cause with `/pm add w6 …`. A failure in the value path itself (the plan, the approval, or a value that never reaches the process) counts here;
   - **an existing item:** link it;
   - **Render fails too:** record the evidence;
   - **needs a real key:** record the line.
3. Delete every kept resource when triage is done.
