## Objective

The Stripe `build_seconds` meter receives every hourly row. Emit only the part of each hour's quantity that lies beyond the month-to-date allowance, keeping emission idempotent per hour.

## Context

- `lego/backend/internal/store/billing.go:182` `SelectUnemittedUsage`
- `lego/backend/internal/billing/stripe.go:507` (`build_seconds` mapping)
- docs/runbooks/stripe-billing-setup.md:228 (reconciliation report)
- docs/ADR040-billing-metronome.md

## Steps

1. Compute, per workspace and month, the cumulative build seconds before each hour; emit max(0, cumulative after − allowance) − max(0, cumulative before − allowance).
2. Keep the existing local transaction ids so a retried hour emits the same quantity.
3. Update the reconciliation script's expectation; tests including a late-arriving hour.
