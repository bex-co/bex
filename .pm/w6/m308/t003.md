## Objective

Render stops pipeline tasks for the rest of the month when a workspace has used its minutes and has no payment method. Add a sweeper modelled on free instance hours that marks such a workspace's source-built Apps; the operator then refuses new builds and pre-deploy runs, so the deploy ends `build_failed` with "Build Minutes Exhausted". Builds already running finish and running services are untouched.

## Context

- `lego/backend/internal/freehours/freehours.go` (`Sweeper`, `core.Poll`, month-scoped annotation)
- `lego/backend/internal/store/billing.go:81` `PaymentMethodBound`
- operator admission gate `app_controller.go:1105-1130`
- docs/ADR030 §13 "Exhaustion"

## Steps

1. Sweeper: when month-to-date build minutes ≥ allowance and no payment method is bound, set a month-scoped annotation (constant in `lego/types`) on the workspace's source-built Apps; remove it when a payment method is bound or the UTC month turns.
2. Operator: while the annotation names the current month, a new build or pre-deploy dispatch fails the release with a new reason `BuildMinutesExhausted` and the message "Build Minutes Exhausted"; an observing pass is never affected.
3. No enforcement when billing is unwired (self-hosted installs).
4. Tests: sweeper transitions, operator refusal, lift on card and month turn.
