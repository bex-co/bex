## Objective

Let an Enterprise workspace choose how long its sessions' sandboxes stay up after a turn, between 5 and 120 minutes, as Devin lets Enterprise customers choose 5–120. The Completer applies it to sessions people start. Automations still close at harvest.

## Context

- The workspace's agent environment row already holds per-workspace agent defaults: `lego/backend/internal/store/agent_environments.go` (`DefaultTemplate`, `SpendCapOverrideMicroUSD`, …), read by `workspaceEnvironment` in `lego/backend/internal/agentsessions/environment.go`.
- Plan ids: `lego/backend/internal/core/plan_gate.go` (`planEnterprise`).
- Devin: "Enterprise customers can … set a different timeout (between 5 and 120 minutes), which then applies to every session type" ([docs.devin.ai/admin/billing/usage](https://docs.devin.ai/admin/billing/usage), read 2026-11-22). Devin sets it through the account team. bex makes it a workspace setting, so an admin needs no ticket.

## Steps

1. Add a nullable idle-timeout column to the agent environment (migration), unset meaning 5 minutes.
2. Expose it wherever the workspace agent environment is read and written: REST, GraphQL and MCP, with the same field name and the same errors. Refuse a value outside 5–120 minutes, and refuse any value on a non-Enterprise workspace with the plan error the other plan gates use.
3. The Completer reads the workspace's value for a person's session.
4. The dashboard's workspace agent settings show the field on Enterprise only, in every locale.

## Files

- `lego/backend/internal/store/migrations/` (new), `lego/backend/internal/store/agent_environments.go`
- `lego/backend/internal/agentsessions/environment.go`, `rest.go`, `graphql.go`, `mcp.go`, `completion.go`
- `dashboard/src/features/agent-sessions/` (workspace settings), `dashboard/src/features/agent-sessions/locales/`

## Acceptance criteria

- [ ] An Enterprise workspace set to 30 minutes keeps a person's session for 30 minutes; a Pro workspace's write is refused on REST, GraphQL and MCP with the same code; 4 and 121 minutes are refused.
- [ ] The dashboard shows the field on an Enterprise workspace and not on a Pro one, and the e2e or component test covers both.

## Out of scope

- A setting for automations (they close at harvest).
