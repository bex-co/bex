## Objective

The Scaling page tells every service, including a free one, that its instances "are billed accordingly". On the free plan that is false — the rate is exactly zero. Fix the sentence. This does not wait on the policy decision, because the sentence is wrong on free whichever way t001 goes.

## Context

Live capture, free web service, `/services/<id>/scaling`:

```
Scaling — Run multiple instances that are automatically load balanced.
          All instances use the same instance type and are billed accordingly.
  Instances   1 [--------slider--------] 100   [1]   [Save Changes]
```

`lego/backend/internal/pricing/pricing.yaml:40-41` — `- tier: free` / `usdPerSecond: 0.0`.

Note the second-order problem, which is `w6/m110`'s and not this task's to fix: App compute is not metered on **any** plan today, so the sentence is currently misleading on paid plans too. Do not try to solve that here — write copy that is true once m110 lands, i.e. accurate about the plan's rate rather than about whether metering currently works.

## Steps

1. Make the billing sentence plan-aware, or move it out of the always-rendered description into a place where it can be conditioned on the plan's rate being non-zero.
2. If t001 lands a cap first, the slider's bounds should reflect it too — but do not block on that; a wrong sentence over a correct slider is still worth fixing now.
3. `en` and `zh` together.
