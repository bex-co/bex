# 185 — Deploying a public repository's Blueprint fails with "GitHub is rate-limiting bex" after a few dozen creates an hour, across every workspace

Why: a Render template's Deploy button never answers "try again in 15 minutes"; on bex every tenant shares one anonymous GitHub budget, so one busy workspace stops everyone's public-repo creates.

- **Source:** w6/m644 t003 (2026-11-26), the live run of twenty `render-examples` templates ([render-examples-live.md](../../docs/render-artifacts/render-examples-live.md)).
- **Seen:** on production pin `2bd6e1f415d3`, in `bex-canary`, about 25 Blueprint creates from `https://github.com/render-examples/<repo>` between 04:17 and 04:51 UTC (three at a time at most, other QA sessions working too) were followed by `503` `GITHUB_RATE_LIMITED` "GitHub is rate-limiting bex right now. Try again in a few minutes." on every create from 04:51:53 to 05:11:41 (17 refusals of six templates), with `retryAfterSeconds: 857` at 04:57. One create at 04:51:52 answered `400` "bex's GitHub app is not authorized to read this repository" for the public `render-examples/webhook-playground`, which the create at 05:25:38 read without trouble.
- **Where:** a repository with no GitHub App installation is read anonymously (`setTokenAuth` with an empty token, `lego/backend/internal/github/client.go`), and GitHub gives anonymous REST calls 60 requests an hour per source IP, shared by every tenant behind bex-api's egress. w4/528 classified the refusal and named authenticating these reads as an optional follow-up that was never filed. `newAPIError` reads a 403 as a rate limit only when it carries `Retry-After` or `X-Ratelimit-Remaining: 0`; a 403 without them is reported as an installation that is not authorized.
- **Do:**
  1. Read public repositories with a credential whose budget scales (the GitHub App's own token: 5,000 an hour and more per installation), keeping the anonymous read only as a fallback.
  2. Treat GitHub's secondary-limit 403 (its body says "secondary rate limit") as a rate limit, never as "not authorized".
- **Acceptance:**
  - [ ] Forty creates from public `render-examples` repositories within ten minutes on production all plan (delete each Blueprint after its plan; nothing is approved).
  - [ ] A unit test: a 403 with the secondary-limit body and no rate-limit headers maps to `GITHUB_RATE_LIMITED`.
- **Estimate:** ~1h. No customer surface changes beyond fewer refusals, so no Render parity task.
