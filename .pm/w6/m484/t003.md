## Objective

One test projects every long-lived tenant workload the operator writes under operator image A, re-projects it under image B, and fails on any pod-template difference, so the next consumer of the operator's own image cannot roll the fleet again.

## Context

- Consumers of `BackupHelperImage` (`rg -n 'HelperImage' lego/operator/internal/controller`): the health-probe installer and edge-cache sidecar (App Deployments), the Key Value internal proxy (w6/m469), backup and disk-snapshot Jobs, the native resolver in build Jobs.
- Long-lived means Deployments and StatefulSets: web (health check, edge cache, drain), private service, background worker, Key Value and its proxy. Jobs and CronJob templates hold no live connection and are out of scope.

## Steps

1. Build the matrix of tenant workloads with the existing test helpers.
2. Project each under A, re-project under B, compare templates.
3. Confirm the guard fails if t002 is reverted.
