# Suspend Service copy claims a URL for service types that never had one — sibling of w6/029

Why: the suspend-confirmation copy on the service Settings tab is user-facing and factually wrong for 3 of 5 service types, the same trust-eroding pattern already filed against the Delete copy in `w6/029` — and both share one fix.

`services.suspendCardDescription` (`dashboard/src/features/services/locales/en.ts:2463`) — "Suspending your service will shut it down and stop it from serving traffic. Its URL and certificates are kept, and you can resume it at any time." — is rendered unconditionally by `SuspendServiceCard` (`dashboard/src/features/services/components/suspend-service-card.tsx:58-65`) for all 5 service types, via the one shared route `dashboard/src/routes/services.$serviceId.settings.tsx:383` (gated only on `service &&`, no type check).

Only `web_service` and `static_site` actually serve a public URL — same 3 affected types as `w6/029`: `private_service`, `background_worker`, `cron_job` (see that note's citations to `service-type.ts`'s own doc comments).

**Verified live** 2026-08-25 during a `/qa-find-bugs` hunt (dashboard.bex.co): a `qa-20260825-private` Private Service's Settings tab showed this exact "Its URL and certificates are kept" copy despite the service having no public URL — confirmed via GraphQL (`server(id:).url` returns the internal `qa-20260825-private:3000` address, no public domain).

**Fix together with `w6/029`:** both bugs are the same shape (a hardcoded URL claim with no type gate) and the same fix (branch the final clause on the URL-aware predicate `w6/029` already proposes adding to `service-type.ts`) — implementing that predicate once and applying it at both call sites (`DeleteServiceCard`, `SuspendServiceCard`) is cheaper than fixing either alone.

**Blast radius:** one component, one call site, one locale key, same shape as `w6/029` — low risk.

**Dedupe:** not a duplicate of `w6/029` (different component/citation) but shares its root cause; not listed in `.pm/DO_NOT_DO.md`.

Estimate: ~15-20 min if done alongside `w6/029` (shared predicate already exists), ~35-45 min combined if implemented together from scratch.
