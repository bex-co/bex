## Objective

Add `hostedInvoiceUrl` and `invoicePdfUrl` to `billing.Invoice`, taken from Stripe's `hosted_invoice_url` and `invoice_pdf` when an invoice is normalized, and serve them identically on REST (`GET /v1/usage`, the `billing` object), GraphQL (`BillingInvoice`) and MCP (`get_usage`).

## Context

- `lego/backend/internal/billing/read.go`: `Invoice` has only id, status, kind, amounts, currency and period.
- `lego/backend/internal/usage/graphql.go`: `billingInvoiceGQLType`.
- REST and MCP marshal the same struct (ADR006: one core, three adapters).
- Visibility stays w9/m620's `can_view_billing`: members who cannot view billing get no `billing` object today.

## Steps

1. Find where Stripe invoices become `billing.Invoice` and map both URLs; leave a field empty when Stripe gives none.
2. Add both fields to `BillingInvoice`.
3. Confirm the REST and MCP JSON carry them, and update the dashboard's GraphQL documents and types under `dashboard/src/graphql/`.
