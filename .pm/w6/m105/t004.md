## Objective

Run the exact drill `w1/m87`'s t004 ran, but against the real Hetzner production cluster serving
`https://dashboard.bex.co` — closing the specific evidence gap this milestone exists because of (m87's own
drill was recorded as run "on the CAPD cluster").

## Context

- `w1/m87`'s drill sequence (`.pm/w1/done/m87/README.md`): disk-bearing App → `Bound` PVC + LUKS Secret →
  operator's backup CronJob created → a triggered run writes a real object at
  `disks/<ws>/<app>/<timestamp>.tar.gz.age` → disk mutated + restored → pre-snapshot bytes come back →
  detach runs the purge Job → zero objects remain.
- This hunt's fixture pattern: `qa-<yyyymmdd>-` prefixed Existing-Image (`redis:alpine`/`nginx:alpine`)
  Starter-tier service, delete before finishing. A disk requires a paid (non-Free) tier
  (`docs/ADR082-persistent-disks.md` D2).
- The nightly CronJob schedule is `45 2 * * *` UTC (from m87's drill) — waiting for the real nightly run may
  not fit this task's window; triggering it manually (however m87's own drill triggered its run) is the
  practical path within the estimate.

## Steps

1. Create a `qa-<yyyymmdd>-` paid-tier service on production, attach a disk, confirm the PVC is `Bound` and
   the LUKS Secret exists (if cluster access allows; otherwise verify via the dashboard's Disk tab + Metrics
   showing provisioned capacity).
2. Trigger (or wait for) a real snapshot run; confirm a real object lands under the disk's bucket prefix.
3. Query the snapshot three ways and confirm they agree: `GET /v1/disks/{diskId}/snapshots` (REST),
   `diskSnapshots` (GraphQL, the dashboard's own query), `list_disk_snapshots` (MCP).
4. Restore the disk to that snapshot; confirm the restore round-trip returns pre-snapshot bytes (write a
   marker file, snapshot, mutate, restore, confirm the marker is back to its pre-snapshot content).
5. Delete the disk; confirm its snapshot objects are purged (the three-way listing above goes to empty/zero
   across all surfaces).
6. Delete the QA service. Record every command/response as evidence in this task's closeout, mirroring
   `w1/m87`'s own evidence style but stamped "production," not "CAPD cluster."
