## Objective

Prove the completed metadata contract with the unmodified pinned Render CLI in both JSON and human-readable modes, and make the evidence discoverable in the compatibility docs.

## Context

- `.pm/w9/done/m2/verify.sh` and `scripts/cli-compat.sh` are the established isolated CLI compatibility harnesses.
- The original failure was visible in text output as an omitted Workspace line and blank Region line, not merely a JSON schema mismatch.
- Documentation must distinguish a configured truthful field from an omitted unavailable field.

## Steps

1. Extend the self-cleaning harness to create or select one Service, Postgres, and Key Value in a named workspace.
2. Assert JSON owner/region/dashboardUrl/createdAt/updatedAt shapes and text-mode Workspace/Region output.
3. Mutate each resource through a supported verb and prove `updatedAt` advances while `createdAt` does not.
4. Exercise unset region/dashboard configuration and ensure clients degrade cleanly.
5. Update ADR006, ADR018, and the CLI checklist with commands, results, and deliberate omissions.
