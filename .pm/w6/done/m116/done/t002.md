## Objective

Make `app_controller.go` behave the way t001 decided. Under option B this is a real behavior change for every existing free App; under option A it is a no-op here and the work is all in t003.

## Context

- `autoSleepEligible` (`app_controller.go:1638`) is the single predicate: `!app.Spec.Suspended && app.Spec.IdleTTLSeconds > 0 && isFreeApp(app)`.
- It has **exactly 3 callers**, and they are not interchangeable:
  - `shouldAutoHibernate:1642` — should it sleep yet
  - `:2031` — is the activator the Ingress backend (the routing question `w6/m94` split out)
  - `:2098` — is `app.bex.co/last-active` stamped at all
  Under B, all three start firing for Apps that previously never reached them. `:2031` in particular has never run for a `0` App, so it needs a regression test rather than being assumed correct by association.
- `shouldAutoHibernate` returns false when `last-active` is unstamped and lets the next Running reconcile stamp it (`:1646-1648`, `:2100-2102`) — so a newly-eligible App gets a full TTL of grace rather than sleeping immediately. Confirm that still holds for Apps that become eligible because the default changed, not because a user set a value.
- Do **not** disturb explicit suspension: `hibernated()` is reached from `:1867` (auto) and `:2773` (suspend), and ADR007 defines their precedence.

## Steps

1. If B: add the default constant and resolve the effective TTL in one helper, so `autoSleepEligible`, `shouldAutoHibernate` and `idleRequeueAfter` cannot disagree about it. `idleRequeueAfter:1653` reads `app.Spec.IdleTTLSeconds` directly and would otherwise compute a zero-length window.
2. Verify the grace behavior for an App that becomes eligible without any spec change — it must not hibernate on the first reconcile after the operator rolls out.
3. Verify the worker exclusion still holds (`desiredReplicas:1984`, `autoHibernating = !worker && …`) — a worker has no Ingress and could never be woken.
4. Confirm a literal `0` written through the API still round-trips as `0` if t001 kept "off" expressible.
5. Run `make test` from `lego/operator/`.
