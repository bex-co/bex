# The agent sandbox's TMPDIR moves off gVisor's memory-backed /tmp

Why: under gVisor `/tmp` is memory and counts against the sandbox's 8 GiB limit, and Claude Code and Node write their temporary files there. Only Go's work directory was moved (w6/124), and a routine was OOM-killed again on 2026-11-13.

- **Evidence.** Routine transcripts show Claude Code's background-task output under `/tmp/claude-10001/-workspace/<session>/tasks/*.output`. ADR105 records that gVisor keeps `/tmp` in memory. `lego/agent-image/Dockerfile` (~141-144) sets `GOTMPDIR=/var/tmp/go-tmp` but no `TMPDIR`. `rt-flatten-abstractions` (session `ags-dbrhfr0k58is73auo6a0`) failed after 1 h 25 min with `the sandbox ran out of memory (exit 128)`. Its transcript did not survive (w6/m398), so the link to `/tmp` is not proven.
- **Fix.** Set `ENV TMPDIR=/var/tmp` in the agent image. `/var/tmp` is on the rootfs, which the 30Gi ephemeral limit bounds. Then confirm in a sandbox that `node -e 'console.log(require("os").tmpdir())'` prints `/var/tmp` and that Claude Code writes its task output there.
- **Done when:** a routine session's temporary files land under `/var/tmp`, and its memory working set no longer grows with background-task output.

## Done 2026-11-14

- `lego/agent-image/Dockerfile` sets `TMPDIR=/var/tmp` beside `GOTMPDIR`. The driver starts the agent with `{...process.env, ...agentEnv}` (`driver/src/acp.ts` ~371), so Claude Code inherits it, and no sandbox template overrides it.
- **Claude Code follows it.** Its docs (`CLAUDE_CODE_TMPDIR`, env-vars reference): the default temp directory is `os.tmpdir()` on Linux, with `/claude-{uid}/` appended. Node's `os.tmpdir()` returns `TMPDIR` (checked: `TMPDIR=/var/tmp node -e …` prints `/var/tmp`).
- **Not yet seen on production.** The image ships with the next deploy. `w6/blocked/m354/t007.md` records the check: the next routine's sandbox writes its task output under `/var/tmp/claude-10001`.
- **/simplify.** The share-file tool's roots (`driver/src/share-file.ts`, an ergonomics check rather than a security boundary) now include `/var/tmp`, along with the tool description and the gateway's hint (`internal/agentsession/sharefile.go`). Without that, a file the agent made with `mktemp` could no longer be shared without copying it. Driver suite 220/220.
- **Tradeoff, not measured.** Temporary-file I/O now goes through gVisor's gofer (`overlay2=none`) instead of the tmpfs, so many small temp-file operations are slower. In exchange, temp files no longer count against the 8 GiB memory limit.
