## Objective

Add `SetEnvironmentDatabases`/`SetEnvironmentKeyValues` verbs to the Environments service, mirroring the existing `SetEnvironmentServices` full-replace-by-name shape.

## Context

- `lego/backend/internal/environments/service.go` has `SetEnvironmentServices` (full-replace-by-name against `apps.environment_id`).
- Database/KeyValue have no Postgres row, so these new verbs call `postgres.Service.SetEnvironmentID`/`keyvalue.Service.SetEnvironmentID` (from t001) per resource in the replacement set, rather than a SQL update.

## Steps

1. Add `SetEnvironmentDatabases(ctx, environmentID, names []string) error` — diff current vs. desired membership (via label-selector list), assign new members, clear removed ones.
2. Mirror for `SetEnvironmentKeyValues`.
3. Reuse `SetEnvironmentServices`'s validation pattern (names must exist in the environment's project/workspace).

## Files

- `lego/backend/internal/environments/service.go`

## Acceptance criteria

- [ ] Full-replace semantics match `SetEnvironmentServices` (removing a name from the list unassigns it).
- [ ] No partial-failure state left on error (either all changes apply or none do, or errors are reported per-resource).
