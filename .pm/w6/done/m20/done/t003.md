## Objective

## Context

## Steps

1. Add REST endpoints for assigning/listing member databases/keyvalues.
2. Extend the GraphQL Environment type to include `databases`/`keyValues` fields alongside existing `services`.
3. Extend/add MCP tools for the same.

## Files

- `lego/backend/internal/environments/mcp.go`
