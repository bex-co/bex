## Objective

Implement label-selector listing of Databases/KeyValues by `core.LabelEnvironment`, for use by t003's read endpoints.

## Context

- Apps' environment membership is read from the Postgres `apps.environment_id` column; Database/KeyValue have no such row, so listing must go through the k8s API by CR label (mirrors how Project-scoped Database/KeyValue listing already works via `core.LabelProject`).

## Steps

1. Add `ListEnvironmentDatabases(ctx, environmentID)`/`ListEnvironmentKeyValues(ctx, environmentID)` to the respective services, doing a label-selector list against `core.LabelEnvironment=<id>`.
2. Ensure workspace/project scoping is enforced (don't leak cross-tenant resources via a bare label list).

## Files

- `lego/backend/internal/postgres/service.go`
- `lego/backend/internal/keyvalue/service.go`

## Acceptance criteria

- [ ] Listing returns exactly the resources currently labeled with the given environment id, scoped to the caller's workspace.

## Out of scope

- Caching/pagination beyond what existing list verbs already do.
