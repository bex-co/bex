- **Backend, reviewed, not changed:** `projects/service.go` and `environments/service.go` each define a private `conflictOrMapError(err, name)` — same shape, different packages, different message text ("in this workspace" vs. "in this project"). - **Backend, reviewed, not changed:** `keyvalue.ensureKeyValueNameAvailable`/`postgres.ensureDatabaseNameAvailable` remain separately duplicated (list + loop + compare + `NewConflictError`) — pre-existing shape (not introduced by this milestone; only the error-construction line changed), operating on different CRD list types, two call sites. Not touched.
