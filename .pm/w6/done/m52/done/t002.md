## Objective

Give the operator a way to record "canceled, no release yet" as something distinguishable from a genuine failure, and make that value reach bex-api/GraphQL — whatever shape t001 decided (a new Phase value, or exposing the existing Condition Reason/Message).

## Context

- `app.Status.Phase` is the CRD-level field the backend/GraphQL layer reads today (`server.phase`) — see `w6/m52/README.md` for the exact resolver chain.
- `app.Status.Conditions` already carries the correct `Reason: "BuildCanceled"` / `Message` — check whether bex-api's App→Server projection already reads Conditions anywhere, or whether this is new plumbing.
- Changing the CRD type may need `lego/operator/hack/boilerplate.go.txt`-headed codegen (CRD manifests, deepcopy) per `lego/operator/CLAUDE.md` — check what `make manifests`/`make generate` covers.

## Steps

1. Implement whatever t001 decided: either add the new Phase value to the CRD type (with codegen), or thread the Condition Reason/Message through to bex-api's App→Server projection and GraphQL schema.
2. Regenerate CRD manifests/deepcopy if the type changed.
3. Confirm the new signal is queryable via GraphQL (a scratch query is enough at this stage — t003 is what actually sets it correctly).

## Files

- `lego/types/` (CRD type + generated deepcopy)
- `lego/operator/config/crd/` (generated manifests, if the type changed)
- `lego/backend/internal/apps/graphql.go` (Server/App GraphQL projection)

## Implementation (2026-08-24)

`PhaseCanceled AppPhase = "Canceled"` added to `lego/types/v1alpha1/app_types.go` with the kubebuilder enum marker extended (`Pending;Building;Deploying;Running;Hibernated;Canceled;Failed`); `make manifests generate` regenerated `config/crd/bases/app.bex.co_apps.yaml`. No deepcopy change (the phase is a string field).

No new GraphQL plumbing was needed: `AppView.Phase` (`apps/service.go:347`, `json:"phase"`) is a single field that REST serializes, MCP returns, and GraphQL projects (`apps/graphql.go:321`), so the new value reaches all three surfaces from one place — asserted by `TestCanceledPhaseReachesEverySurface` rather than assumed.
