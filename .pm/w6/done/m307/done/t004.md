## Objective

The `builder: buildpack` extension builds through a kpack Image, which creates no Job, so its builds meter nothing.

## Context

- `lego/operator/internal/build/kpack.go`; kpack Images carry `ReleaseBuildLabels` (`lego/operator/internal/build/artifacts.go:192`)
- `lego/backend/internal/usage/service.go` `queryBuildSeconds`

## Steps

1. Read the release's kpack Builds (labels from the Image) and meter each from its pod start (or creation) to its `Succeeded` condition's transition, with t001's failure rule.
2. Exempt platform rebuilds.
3. Tests with unstructured kpack fixtures.

## Files

- lego/backend/internal/usage/service.go
- lego/backend/internal/usage/*_test.go

## Acceptance criteria

- [ ] A succeeded and a failed kpack Build each add their seconds
- [ ] Missing kpack CRDs (self-hosted without kpack) meter zero without error
