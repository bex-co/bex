## Objective

A disk-bearing service's new instance mounts its volume within about 2 s of reaching the node, not up to 10 s. A volume leaving a node is released for detach just as fast.

## Context

- t001: the kubelet mounts an attachable volume only after a node-status sync has reported the volume in use (`reportedInUse`), and the attach/detach controller detaches one only after the old node's sync drops it from `volumesInUse`. Production's kubelets sync every 10 s (`nodeStatusUpdateFrequency: 10s` in `/configz`). That added 1.7–8.6 s on the same node and 1.0–8.1 s before a move's detach.
- `infra/clusterapi/overlays/hetzner-caph/cluster.yaml`: the tenant KubeadmConfigTemplates `bex-tenant-0` (also used by burst and lg), `bex-tenant-build`, `bex-tenant-xl` and `bex-tenant-xxl`, which `scripts/clusterapi-validate.sh` keeps in sync.

## Steps

1. Add `node-status-update-frequency: "2s"` to the four tenant templates' `kubeletExtraArgs`.
2. `bash scripts/clusterapi-validate.sh`.

## Files

- infra/clusterapi/overlays/hetzner-caph/cluster.yaml

## Acceptance criteria

- [x] Every tenant template carries the 2 s sync, and the overlay validates

## Out of scope

- Forcing every tenant machine to roll for this alone. Nodes adopt the setting as Cluster API replaces them. t005 needs only one such node.

## Record (2026-11-21)

Done. The four tenant templates carry `node-status-update-frequency: "2s"`, and `scripts/clusterapi-validate.sh` passes. The kubelet computes status every 2 s but patches the Node only when something changed, or every `nodeStatusReportFrequency` (5 m), so the API load barely moves. The `app-cluster` workflow applies the templates on push. MachineDeployments do not re-roll on an in-place template edit (w5/174), so existing nodes keep 10 s until they are replaced. That was deliberate: a forced roll of every tenant node would Recreate every disk service and other workers' live fixtures for a few seconds of gain. t005 measures on a node that carries 2 s, or rolls `bex-tenant-0` with `rolloutAfter` first if none does by then.
