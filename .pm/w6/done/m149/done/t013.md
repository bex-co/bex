## Objective

Add meaningful tests for the behavior this milestone shipped: real behavior and failure modes, never coverage gaming.

## Steps

1. **Drift guard.** A test fails when the capability set differs between the operator projection (`appSecCtx`), the admission `…Caps` list and ADR089's documented list.
2. **Legacy guard.** A test proves `strict-v1`, `image-v1`, `''`, datastore and platform pod templates stay byte-identical to the pre-milestone golden output.
3. **Failure modes.**
   - Migration refusal states and a failed migration keep the old policy.
   - The down migration refuses while new-policy rows exist.
   - Admission rejects one extra capability and a missing `hostUsers`.
   - Port validation still rejects reserved and out-of-range ports.
4. **Mutation spot-check.** Drop one capability from the projection, then remove the `hostUsers` setting; confirm a test fails each time.

## Acceptance criteria

- [x] All four groups exist and fail when the behavior they guard is broken (mutation spot-check recorded).
- [x] `make test` (operator), `cd lego/backend && go test ./...` and `make lint` pass.
