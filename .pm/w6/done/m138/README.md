## Definition of done

All five roles see exactly the ADR087 navigation matrix (Sessions hidden without confirmed `canOperate`) and detail-section matrix; hidden regions issue **zero** associated requests, including prefetch and restored navigation (assert render + network). The SQL process-list request is removed from the mobile Postgres insights card while capacity/sizes/table-scan cards survive; Logs (HTTP + SSE) never mounts without `canViewLogs`; rollback and the composer require `canCreate`; temporarily blocked authorized actions are disabled with a visible, translated, screen-reader-accessible reason.
