## Objective

Implement the ADR087 top-level navigation matrix: Status/Activity/Notifications for all roles, Sessions only with confirmed `canOperate` — with stable order and route identity for surviving tabs, correct transitions when access changes, and guarded deep links.

## Context

- `mobile/app/` Expo Router routes; validate the actual iOS native-tabs and Android navigator behavior for dynamic tab sets (Expo protected routes remove inaccessible history but don't replace server checks).
- Change the tab set only after a **resolved** workspace/access transition — never because a list is empty, a request is loading, or the network failed. A transport error must not masquerade as a role change.
- If Sessions becomes inaccessible while open: clear content, remove its history entries, return to Status, announce the change (`access.changed`).
- Unknown/foreign/deleted deep link → existing route/ID allowlist + workspace binding + destination permission → generic `access.cannotOpen` with Back to Status; do not echo unverified resource names or distinguish foreign from nonexistent ids.
- `mobile/src/features/notifications/deep-link.ts` — existing subject/workspace/session binding; no auto workspace switch.

## Steps

1. Gate the Sessions tab on confirmed `canOperate`; keep relative order/identity of the rest.
2. Implement the inaccessible-while-open transition (clear, unmount, history removal, redirect, announce, focus destination heading).
3. Extend deep-link validation to include destination permission; route failures to the generic unavailable state.
4. Session screen states: authorized-but-unconfigured shows setup guidance only to `canCreate` callers; a Contributor sees "No sessions yet" with no create CTA.

## Files

- `mobile/app/` (tab layout + guards)
- `mobile/src/features/agent-sessions/sessions-list-screen.tsx`
- `mobile/src/features/notifications/deep-link.ts`

## Acceptance criteria

- [ ] Viewer/Billing never see or mount Sessions; Contributor/Developer/Admin do; verified on both platform bundles.
- [ ] A denied deep link renders generic copy without a network request for the restricted destination's content.
- [ ] Loading/empty/offline never change the tab set (test each).

## Out of scope

- Transcript replay, steering, resume (future ADR048 milestones); any tab beyond the four reference destinations.
