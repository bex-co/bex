## Objective

Extend the DataBoundary lifecycle to access changes inside the same workspace (not just workspace switch/logout), and implement the ADR087 freshness policy: re-evaluate at least every 30 s foregrounded and on every transition; a stale snapshot cannot enable actions or open restricted content.

## Context

- `mobile/src/common/apollo/data-boundary.ts` — key by identity/session, workspace, and a new access generation; add resource identity for target decisions.
- Transition table (ADR087 §Access changes): cold start, A→B switch, foreground/reconnect/return-from-dashboard, same-workspace downgrade (clear affected data/streams/pending controls + history), upgrade (only after affirmative fresh capabilities; no background replay of a refused action), membership removal (clear + verified chooser), auth failure (session-manager contract; a resource 403 is not logout), offline (disable resource actions/new protected navigation; clear logs/transcripts/prompts; non-sensitive snapshots may stay visibly stale).
- Failed refresh → unavailable state, not a role-change announcement. In-flight refresh may preserve the established shell and labeled non-sensitive observations.
- Backend consistency boundary (30 s positive cache, per-replica eviction) means this is a client policy, not a revocation guarantee — assert prompt clearing **after detection**.

## Steps

1. Add the access-generation key + invalidation plumbing to DataBoundary; wire the capability provider's refresh loop (30 s foreground + transition triggers, m136 fresh-evaluation option for recovery).
2. Implement downgrade detection → clear + redirect + announce (reuses t002's transition machinery).
3. Cover upgrade, removal, offline, and failed-refresh branches distinctly.

## Acceptance criteria

- [ ] Integration test: mid-session Contributor→Viewer clears logs/session content, stops streams, cancels pending confirmations, removes inaccessible history — on detection.
- [ ] A snapshot older than 30 s cannot enable an action; in-flight refresh keeps the neutral shell.
- [ ] A transport failure produces `access.unavailable`, never `access.changed`.
