## Objective

Give each bex-api control plane a configurable identity and stamp it onto every tenant namespace that control plane provisions, so a later prune pass can tell its own namespaces from another control plane's. This task only introduces and writes the identity — the prune-side behavior change is `t002`.

## Context

- `lego/backend/internal/store/namespaces.go` — the `NamespaceReconciler`. `managedLabels(workspaceID)` (around `:308`) is the single place every managed object's labels are built; `LabelManagedBy` / `ManagedByValue` / `LabelWorkspace` are defined alongside it.
- The reconciler runs whenever `BEX_CP_DB_URI` is set (see `CLAUDE.md` § Environment variables) and provisions each workspace's `<ws>` and `<ws>-sandbox` namespaces per [`docs/ADR043-tenant-namespace-isolation.md`](../../../docs/ADR043-tenant-namespace-isolation.md).
- Default must be `production` so an unconfigured deployment keeps behaving exactly as today.
- `isManaged` (same file) is the existing guard that keeps the reconciler from clobbering hand-created objects — the identity is an additional axis, not a replacement for it.

## Steps

1. Add a control-plane identity setting (env var, defaulting to `production`) and thread it onto the `NamespaceReconciler`.
2. Add the identity label constant next to `LabelManagedBy` / `LabelWorkspace`.
3. Stamp it in `managedLabels` so every namespace and every managed projection the reconciler owns carries it.
4. Confirm re-reconciling an existing namespace adds the label rather than conflicting (the reconciler already applies labels idempotently — verify, don't assume).
5. Mirror the new variable name into `.env.example` (repo rule: value-less mirror) and document it in `CLAUDE.md`'s bex-api environment table.

## Files

- `lego/backend/internal/store/namespaces.go`
- wherever the reconciler is constructed (bex-api wiring / `cmd/api`)
- `.env.example`
- `CLAUDE.md` (bex-api environment-variable table)

## Acceptance criteria

- [ ] A namespace provisioned by a control plane with no identity configured carries the identity label with value `production`.
- [ ] A namespace provisioned by a control plane with the identity set to `dev-6` carries that value.
- [ ] Re-reconciling a namespace that predates this change adds the label without error and without disturbing its other labels.
- [ ] `.env.example` names the new variable; `CLAUDE.md`'s table documents it including the unset-means-`production` default.
- [ ] `cd lego/backend && go build ./... && go test ./...` green.

## Out of scope

- Changing what `pruneOrphans` deletes — that is `t002`, and until it lands the label is inert.
- Backfilling the label onto namespaces on live production (the reconciler's own next pass does it).
