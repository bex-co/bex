## Objective

Expose t002/t003's `confirm` gate on the MCP surface for suspend only.

## Context

- **No MCP delete tool exists for Postgres or KeyValue, by design** (`.pm/w7/done/m12/t009.md`: "MCP (`delete_service` only — Postgres/KV deliberately have no MCP delete, matching Render)" — Render's own official MCP server ships no delete tool for datastores either). Do not add one as part of this task; the protection guard on `Delete` still exists at the service layer (t002/t003) and is reachable via REST/GraphQL, it's just not MCP-exposed — exactly like Render.
- `suspend_postgres`/`suspend_keyvalue` **do** exist and need the `Confirm` field, mirroring however `apps.mcp.go`'s guarded tools (e.g. `restart_service`/`suspend_service`, if suspend is MCP-guarded there — check) already expose `Confirm`.

## Steps

1. Add an optional `Confirm` input field to `suspend_postgres` (`lego/backend/internal/postgres/mcp.go`) and `suspend_keyvalue` (`lego/backend/internal/keyvalue/mcp.go`).
2. Thread it through to the service call.
