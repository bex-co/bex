## Objective

One test projects every long-lived tenant workload the operator writes under operator image A, re-projects it under image B, and fails on any pod-template difference, so the next consumer of the operator's own image cannot roll the fleet again.

## Context

- Consumers of `BackupHelperImage` (`rg -n 'HelperImage' lego/operator/internal/controller`): the health-probe installer and edge-cache sidecar (App Deployments), the Key Value internal proxy (w6/m469), backup and disk-snapshot Jobs, the native resolver in build Jobs.
- Long-lived means Deployments and StatefulSets: web (health check, edge cache, drain), private service, background worker, Key Value and its proxy. Jobs and CronJob templates hold no live connection and are out of scope.

## Steps

1. Build the matrix of tenant workloads with the existing test helpers.
2. Project each under A, re-project under B, compare templates.
3. Confirm the guard fails if t002 is reverted.

## Done — 2026-11-19

- `TestANewOperatorImageChangesNoLongLivedTenantPodTemplate` (`lego/operator/internal/controller/operator_upgrade_test.go`) runs each workload through the whole reconciler on a fake cluster, first under operator image A and then under B. The App cases are an edge-cached web service with a health check, an edge-cached one with a disk, a paid and a free web service, a private service and a background worker, through `AppReconciler.Reconcile` via `lifecycleFixture`/`serveReleaseOne`. The Key Value case is a starter store through `KeyValueReconciler.Reconcile`, with the same proxy binary under both images.
- It compares every Deployment and StatefulSet in the namespace, so w3/m489's tier `bex-edge-cache-<app>` is covered, and so is any workload the reconcilers start writing later. A setup check asserts which containers of which workloads run the operator's image (the App's installer, the tier's proxy, the store's `internal-proxy`), so the guard cannot pass vacuously. `podTemplateDiff` now names moved container images.
- Red when each hold is reverted (t007), and on `e9890d5ad` (the sidecar era), where both edge-cached cases fail on the moved installer and sidecar images.
- Postgres is not in the guard: its pods are CNPG's, and the `Cluster` takes no operator image (`cnpgOperandImage`).
