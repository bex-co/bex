## Record (2026-11-18)

Done (code and Render docs; the live walk is t006). Surfaces:

- Native SSH (`ssh`, `bex ssh` / `render ssh`): an open session survives a gateway release for up to an hour; a new connection reaches only a new pod (closed listener, `/readyz` 503).
- Dashboard Shell: same; at the bound it ends with `reason: timeout`, which the Shell page already shows as "the session reached its time limit" in the reader's language.
- REST `POST /v1/services/{id}/shell-ticket` and GraphQL `createShellSession`: unchanged. The ticket's `wss://ssh.bex.co/shell` reaches a Ready (new) pod; the nonce lives in Postgres, so a ticket minted just before a release redeems on the new pod.
- MCP: no shell surface.

Render ([render.com/docs/ssh](https://render.com/docs/ssh), read 2026-11-17): maintenance on the infrastructure that enables SSH "gives existing connections one hour before automatically closing them". Matches. No new drift: native SSH still learns no reason when the server ends a session, the known gap ADR035 already records for every end reason.
