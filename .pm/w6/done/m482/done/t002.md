## Objective

The gateway's other listeners stop accepting on SIGTERM and let their in-flight streams finish within the drain bound, instead of a 5 s `Shutdown` that cuts them.

## Context

- `startAuxListener` (`lego/backend/cmd/ssh-gateway/main.go:533-580`) returns a closure that calls `server.Shutdown` with a 5 s timeout. Listeners: sandbox exec (`:8081`), agent git proxy (`:8082`), agent attach (`:8083`), agent model proxy (`:8084`), agent egress proxy (`:8085`).
- Model streams can run for minutes (the ADR062/ADR064 proxy bounds an exchange at 2 h); exec streams are bounded by the gateway session (w32/m381). Hijacked connections (attach, egress `CONNECT` tunnels) are not waited for by `Shutdown`.
- The process must not exit while t001's SSH sessions are draining, and these listeners must not keep it alive past the bound.

## Steps

1. Give `startAuxListener` the drain bound instead of 5 s, and track hijacked connections where a listener hijacks.
2. Run every listener's drain concurrently with t001's, and exit when all are done or the bound passes.

## Files

- lego/backend/cmd/ssh-gateway/main.go
- lego/backend/internal/sshgateway/egressproxy/, agentattach/ (connection tracking, if they hijack)

## Acceptance criteria

- [x] An in-flight model-proxy response started before SIGTERM completes
- [x] No listener accepts after SIGTERM
- [x] The process exits at the bound even if a tunnel is still open

## Out of scope

- Changing the proxies' own per-exchange limits

## Record (2026-11-18)

Done. `startAuxListener` now returns its drain instead of a 5 s shutdown closure: `http.Server.Shutdown(ctx)` (closes the listener, waits for tracked connections) then `Inflight.Wait(ctx)` (every handler still running, hijacked ones included: the Web Shell, egress `CONNECT` tunnels). All drains run concurrently with native SSH's (`drainAll`), within the same bound; at the bound `sessionCtx` ends, which cancels every request context, and after the 10 s grace the process exits even with a tunnel that ignores its context still open (`TestDrainEndsAtTheBoundEvenWithATunnelOpen`). No package under `egressproxy/` or `agentattach/` needed a change: the counting sits in the listener wrapper.
