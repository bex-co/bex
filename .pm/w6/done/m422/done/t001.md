## Objective

`native-common-image.yml` publishes and qualifies only a fresh image. `native-common-qualify.py` keeps only what the fresh path runs.

## Context

- `.github/scripts/native-common-qualify.py`:
  - `plan()` (line ~599) and `initialize()` (line ~635) branch on `mode == "reviewed-candidate"`.
  - The candidate-only code is `CANDIDATE_PATH`/`CANDIDATE_SCHEMA`, `V11_TOOLS`, `V11_SUPPORT_INPUTS`, `D3_LEGACY_0941` with `image_inputs_compatible`, `checkout_packet` … `materialize_evidence`, `evidence_file`/`evidence_json`, `completed_job`, `validate_image_candidate` and `validate_test_candidate` (lines ~100–598).
  - `main()` exposes `checkout-evidence` and `materialize-evidence`.
- `.github/workflows/native-common-image.yml`:
  - the `source` dispatch input (`fresh`/`reviewed-candidate`);
  - three "materialize only complete candidate evidence packets" steps, each with oras setup;
  - the `plan` outputs `ref`/`producer`/`verification`/`receipt_sha256`/`baseline_status`;
  - the `qualify`/`qualify-profile` `if:` reuse branches;
  - the `needs.plan.outputs.source == 'reviewed-candidate' && … || needs.publish.outputs.*` env expressions.
- Fresh family cases already work: `qualify-profile` runs after a fresh `publish` + `qualify`.
- The `sbom` subcommand stays: `lego/operator/internal/build/nativeutility_qualification_test.go:332` runs it.

## Steps

1. Delete the reuse branches in `plan()` and `initialize()`, and the reuse-only fields in `inputs.json` (`candidate_receipt_sha256`, `baseline_status`, `image_approval_inputs_sha256`, `utility_baseline_source`, `utility_jobs`, `previous_baseline_state`).
2. Delete every function and constant that only the candidate path reached. Confirm each with `rg` before deleting.
3. Delete the `checkout-evidence` and `materialize-evidence` subcommands.
4. Decide what `custody-paths` becomes:
   - If `SOURCE_FILES`/`IMAGE_INPUT_PATHS` still feed the fresh `qualification-source.json` inventory, keep the list under a name that says what it is, and update its callers in t003.
   - Otherwise delete it.
5. In the workflow:
   - drop the `source` input;
   - drop the evidence steps, and oras setup where nothing else uses it;
   - drop the reuse outputs and conditions;
   - point the env at `needs.publish.outputs.*`.
6. Delete `.github/native-evidence.json` and `.github/native-common-test-candidate.json`.
