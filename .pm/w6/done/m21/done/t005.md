## Resolution

Both fields now use the same name (`dockerfilePath`/`startCommand`) and semantics
(docker-runtime-only for `dockerfilePath`) across REST, GraphQL, and MCP — matching
render.com's own naming/shape, no deliberate drift. Dashboard check (via an Explore
agent): `startCommand` is set only in the service-create wizard, never editable afterward
in Settings → Build & Deploy; `dockerfilePath` isn't surfaced anywhere in the dashboard.
