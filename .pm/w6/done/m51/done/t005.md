## Findings (2026-08-24)

Reviewed the milestone's own diff for reuse/quality/efficiency and applied three fixes:

- **Triplicated write path.** `apps.patchTracked`, `envgroups.rollLinkedService`, and `secrets.rollApp` each carried the same snapshot → mutate → stamp → patch → open body. Collapsed onto one `rollout.Tracker.Patch`; the three callers are now thin adapters.
- **Dead accessor.** `Snapshot.Rolls()` had no caller — removed.
- **Contained context.** The batch held a `context.Context` in a struct field (with a `nolint`). The flush closure now captures the batched context directly, so the field and the suppression are both gone.

Not changed: `apps.Service` still derives its tracker from the `IntentStore` it already holds rather than taking a `Rollout` field like the other two — deliberate, so a second composition root (`cmd/ssh-gateway`, the workspace purger) cannot build a Service that silently records nothing.

`make lint` clean across all four modules.
