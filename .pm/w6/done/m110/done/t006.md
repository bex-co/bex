## Outcome (2026-08-27)

Reviewed the whole `23c323f9` diff for reuse / quality / efficiency. Three findings applied, all
behavior-preserving; backend + operator suites green after (`internal/{usage,egressquery,metrics,api}`,
`TestPodNameRegexSurvivesGeneratedNameTruncation`).

**Applied:**

1. **Dead condition in `PodNameRegex` (`egressquery/podname.go`).** The guard read
   `truncated <= 0 || len(objectName) > maxGeneratedNameLength`. `truncated <= 0` means
   `len >= 62`, which is wholly subsumed by `len > 58` — the first operand can never decide the
   branch. Reduced to the single meaningful condition, and the comment now states the real reason
   the branch exists (past the cut the truncation lands *inside* the object name, so the pod name is
   not even prefixed by it and no anchored regex built from the full name can match) rather than the
   previous "no room for a suffix", which described the subsumed case.
2. **Redundant `if/else` in the meter switch (`usage/service.go`).** Both the `instance_seconds` and
   `build_seconds` arms wrote `if !identified { quantity, ok = 0, false } else { … }`, but `quantity`
   and `ok` are freshly `var`-declared zero values immediately above the `switch` — the assignment
   restated the zero value. Collapsed each to a single positive `if` with the identity scoped to it.
3. **Magic numbers in the operator's deliberate copy (`controller/autoscale.go`).** The copy spelled
   `63`, `5` and `58` inline while the backend names them. Since the copy exists precisely because
   the operator imports no backend package, its comment asserts "keep the two in step" — so it now
   carries the same three named constants, making the correspondence checkable by eye.

**Skipped, with reasons:**

- **`PodNameRegex`/`PodNameMatcher` live in package `egressquery`.** Pod identity has nothing to do
  with egress, and `metrics`/`usage` now import `egressquery` for it — a genuine naming smell. Moving
  it means a new package plus import churn across four files, which is beyond a behavior-preserving
  simplify pass. Left for a deliberate follow-up if the package grows further.
- **`degradeSourceHealth` copies its input slice.** The one caller owns a freshly built slice, so the
  copy allocates for nothing. Kept: it runs once per meter window (not a hot path) and the copy is
  what makes the helper safe to call on a shared slice later.
