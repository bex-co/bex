# A turn's `completed_at` is re-stamped when its idle sandbox is reaped two hours later

Why: every session's last turn reads about two hours longer than it ran, on GraphQL/REST `TranscriptTurn.completedAt`, the session page and every timing built on it. The 2026-11-13 routine tally reported two-hour CI turns that really took 5 to 38 minutes.

- **Cause.** `store.CompleteAgentSessionTurn` (`lego/backend/internal/store/agentsessions.go` ~616) sets `completed_at=now()` unconditionally. The Completer calls it from `markTurnTranscript` (`internal/agentsessions/completion.go` ~877/885) on every transcript harvest, including the late one when it reaps the idle sandbox. That happens `BEX_AGENT_SANDBOX_IDLE_TTL` (default 2h, `cmd/api/config.go:617`) after the turn ended. `stampTerminalTurn` in the same file already keeps the first value with `COALESCE(completed_at, now())`.
- **Seen on production (2026-11-14).** Session `ags-dbrs194l3h6c73b7q56g` (`rt-simplify-logic`): its turn-1 transcript was stored at 02:12:06, and `completed_at` read 02:12:07 at 02:13, then 04:12:20 later. Every routine turn that was a session's last reads the turn's true length plus about 120 minutes.
  - True durations of the 2026-11-13 CI turns, from their transcripts' storage time: `rt-fix-logic-bugs` 4.8 min (recorded 125.1), `rt-unify-duplicates` 35.1 (155.1), `rt-fix-prod-crashes` 8.9 (128.9), `rt-normalize-abstractions` 12.3 (132.3), `rt-prune-useless-tests` 37.9 (158.1).
- **Fix.**
  1. Keep the first completion: `completed_at = COALESCE(completed_at, now())` in `CompleteAgentSessionTurn`. Add a real-DB regression test: complete a turn, complete it again later, and the time is unchanged.
  2. Repair existing rows. Where a turn's `completed_at` is more than an hour after its first `agent_session_transcripts.created_at`, and the turn has no later row, set it to that time. Do it in a migration, scoped to that condition.
  3. Correct `w6/blocked/m354/t007.md`, which records the two-hour CI turns (Progress 2026-11-14), and say the commit message of `a0c8c6fad` repeats the error.
- **Done when:** a reaped session's last turn keeps its real end time on GraphQL `TranscriptTurn.completedAt` and REST, and the repaired rows read their transcript time.
