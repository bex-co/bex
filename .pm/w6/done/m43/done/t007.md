## Objective

Close the milestone once its definition of done actually holds, not merely
once the code is written.

## Steps

1. Confirm the DoD in `README.md` is genuinely met (re-read it against the
   shipped diff, don't just check tasks off).
2. Set every remaining task's `status: done`.
3. Mark every row `— **DONE**` and set `**Status:** done` in this
   milestone's `README.md`.
4. Move each `tNNN.md` to `w6/m43/done/`.
5. Move the whole `w6/m43/` directory to `w6/done/m43/`.
6. Check `- [x]` for `m43` in `w6/README.md`.

## Acceptance criteria

- [ ] `w6/m43/` no longer exists; `w6/done/m43/` holds the completed
      milestone with every task moved to its `done/` subfolder.
- [ ] `w6/README.md` shows `m43` checked.

## Out of scope

- Any new work — if the DoD isn't met, that's a new task, not this one.
