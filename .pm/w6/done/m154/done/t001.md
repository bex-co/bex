## Objective

Watch the App's dskbak- Jobs. On a Failed Job, set DiskReady False with a SnapshotFailing reason and emit an Event carrying the failed container's termination message (capture via FallbackToLogsOnError, as the build path does). Clear it on the next success. Export the reason from lego/types/v1alpha1/diskbackup.go.

- [ ] envtest: a failed backup Job sets the reason and message; a later success clears it.
