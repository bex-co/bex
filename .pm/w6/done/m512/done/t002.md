## Objective

With `BEX_KV_DRAIN_SECONDS=N`, the first `SIGTERM` starts t001's drain on both listeners with an N-second deadline. The process exits as soon as both listeners have no open stream, and at the latest at N. A second `SIGTERM` or `SIGINT` closes everything at once. With the variable unset, `SIGTERM` closes at once, as today.

## Context

- `lego/operator/cmd/kv-internal-proxy/main.go` (`run`, `internalMode`) and `main_test.go`.
- `--check` mode is unchanged.

## Steps

1. Parse `BEX_KV_DRAIN_SECONDS` as a non-negative integer. A bad value fails closed at startup, as `BEX_KV_MAX_CONNECTIONS` does.
2. Replace `signal.NotifyContext` with handling that tells the first signal from a second one, and feed t001's drain.
3. Add the variable to the operator's env inventory (`lego/operator/AGENTS.md`).

## Acceptance criteria

- [x] A `run` test drives the drain through a cancellable trigger and checks that a held stream outlives it until the deadline, while a new dial is refused.
- [x] An invalid `BEX_KV_DRAIN_SECONDS` fails `run` before any listener opens.
- [x] Unset means close at once, covered by the existing tests unchanged.

## Out of scope

## Result — 2026-11-19

`main` replaces `signal.NotifyContext` with a two-step handler: the first `SIGTERM` or `SIGINT` closes the drain channel, and the second cancels the context. `run(ctx, getenv, check, drain)` reads `BEX_KV_DRAIN_SECONDS` before it opens any listener and gives both listeners the drain. A listener that has drained no longer stops the other one; only an error does. While draining, `run` also starts `kvinternalauth.KeepReserve` (t003). The variable is in `lego/operator/AGENTS.md`'s env inventory. `lego/operator/cmd/kv-internal-proxy/main_test.go`:

- `TestRunDrainsUntilTheDeadline`: with `BEX_KV_DRAIN_SECONDS=1`, the trigger closes both listeners, a held stream still answers `PING`, and `run` returns no earlier than 1 s, closing it.
- `TestRunWithoutDrainSecondsClosesAtOnce`: unset, the trigger closes the held stream at once.
- `TestRunRefusesAnInvalidDrainBeforeListening`: `-1`, `30s` and `x` fail `run`, and the address stays free.
- `TestSIGTERMDrainsAndASecondClosesAtOnce` runs the binary's `main` in a child process. After a real first `SIGTERM` the listener refuses and a held stream is served. A second `SIGTERM` closes it, and the process exits 0.
