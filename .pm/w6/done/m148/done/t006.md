## Objective

A consumer whose environment references another service's port gets the real value as soon as that port is known, and gets the new one whenever the target's **serving** primary changes. A pending candidate's port never leaks in before the candidate serves (ADR089 D4). Every change goes through the tracked patch path, so it opens a normal `config_change` deploy.

## Context

- The reference record is the `app.bex.co/service-refs` annotation written by t005.
- The target's published port is `App.ServicePort()` / `InternalAddress()` (`lego/types/v1alpha1/image_network.go`). It is 0 while discovery is pending, and it follows `ServingNetwork` during replacement.
- `patchFetched` → `patchTracked` (`lego/backend/internal/apps/service.go:4994`, `:5003`) opens a `config_change` deploy row when the release identity moves.
- Loop precedent: `BlueprintRecoverer` (`blueprint_recovery.go`), wired in `cmd/api`. bex-api runs two replicas, so every write must be idempotent and conflict-safe.

## Steps

1. Add `ServiceRefPropagator` in `lego/backend/internal/apps`, a ticker loop wired in `cmd/api/main.go`. Each tick:
   - list Apps carrying the annotation;
   - resolve each ref against the target App in the same namespace;
   - skip when the target is missing or its port is 0, and skip suspended consumers;
   - when the consumer's literal differs, patch it through the tracked path.
2. Patch with optimistic concurrency, so two replicas cannot open two deploys for one change. The losing replica sees the new value on its next read.
3. Log, and make visible, a target that disappears. Keep the last value; never write a guessed port.

## Acceptance criteria

- [ ] Unit test: a pending image-port target → no write. Once `ImageNetwork` resolves → one patch with `<slug>:<primary>`.
- [ ] Unit test: `SetPort` 3000 → 8080 on a configured target → the consumer is patched to `<slug>:8080` with one `config_change` deploy row. An unchanged target → no patch.
- [ ] Unit test: during a replacement, the consumer keeps the serving primary until `ServingNetwork` moves.
- [ ] Two concurrent ticks open at most one deploy.
- [ ] `cd lego/backend && go test ./...` passes.

## Out of scope

- User-authored literal URLs: they remain the user's configuration (ADR089 D4).
- Operator-side resolution (rejected in t001: it would bypass backend-opened deploy history).
