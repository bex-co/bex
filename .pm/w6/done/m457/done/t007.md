## Result — 2026-11-17

Read on production (pin `e36296ae8`) as the QA user, on t005's two probes before they were deleted:

- **The limit matches Render's.** Render documents one connection limit per plan and no separate external cap: Postgres 100 below 8 GB ([creating and connecting](https://render.com/docs/postgresql-creating-connecting), read 2026-11-17), Key Value `starter` 250 ([compute plans](https://render.com/docs/compute-plans)). On production an external client got the plan's figure on both: 96 Postgres sessions (100 less the 3 superuser-reserved slots and one held by another backend), and 250 Key Value clients.
- **The refusal matches Render's.** Render runs stock PostgreSQL and Valkey, and neither page describes another refusal. The client past the limit read PostgreSQL's own SQLSTATE 53300 and Valkey's own `ERR max number of clients reached`, never a dropped connection or a TLS error.
- **REST, GraphQL, MCP, dashboard.** `GET /v1/postgres/{id}/connection-info` and GraphQL `databaseConnectionInfo` returned the same values field for field (the unset pool strings are absent on REST and empty on GraphQL), as did `GET /v1/key-value/{id}/connection-info` and `keyValueConnectionInfo`. MCP `get_postgres` and `get_key_value` return the resource with its `externalHost` and allowlist and no connection string, and none of production's 264 MCP tools mentions a connection count. The dashboard's Connections card showed the same URLs as REST for both, and the Key Value Details card reads "Connection limit 250" (w6/m459), the limit the external client met. This milestone changed no backend or dashboard code (`e2e85ac52`), and nothing on any surface contradicts the external limit.
- **Seen, already filed.** A new public datastore's publicly trusted certificate stalls on Let's Encrypt's weekly limit for `bex.co`: the Postgres URL keeps `sslmode=verify-full` with the private CA, and the Key Value external URL is unreachable until issuance, which every surface states. That is w4/m357 (blocked on a `bex.co` DNS token for a wildcard certificate), not new drift. The edge load balancer's 10,000 is w6/136.
