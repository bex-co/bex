# Dashboard-created Docker private services always pin port 3000 instead of using the image's ports

Why: the create wizard always submits a port, so a Git-built Docker private service created in the dashboard gets `image-configured-v1` with primary 3000, while the same service created over REST, GraphQL, MCP or a Blueprint without a port gets `image-v1` and a primary from its image.

- **Wizard always sends a port.** `dashboard/src/features/services/hooks/use-new-service-form.ts:77` pre-fills `port: "3000"`. `dashboard/src/features/services/lib/create-service-input.ts:159` blocks Submit unless the port parses, and `:233` sends it for every web and private service, so a blank port is impossible.
- **Backend treats any port as explicit.** `lego/backend/internal/apps/service.go:1987,2287` pass `req.Port > 0`; `:2447-2448` then pick `image-configured-v1`. The operator makes `spec.port` the primary and adds it to the image's ports (`lego/operator/internal/controller/image_network.go:76-83`), and readiness is a TCP check on it.
- **Effect.** An image that ignores `$PORT`, such as `examples/multi-port` (`EXPOSE 8123 9000`) or ClickHouse, fails readiness on 3000 when created from the dashboard. Created through a Blueprint, it went live on 8123 (`.pm/w6/done/m148/evidence/README.md` DoD 1), and REST, GraphQL and MCP creates with no port take the same path. Render's private-service form has no port field; it detects the bound port.
- **Copy and docs agree with the old model.** The wizard hint (`dashboard/src/features/services/locales/en.ts:3110-3112`, `zh.ts:3046`) says the container must listen on the typed port. MCP `create_web_service`'s `port` schema says "default 3000" (`lego/backend/internal/apps/mcp.go:209`), which is no longer true for a Git-built Docker private service.
- **Fix.** For `private_service` with a Docker Git source, make the wizard's port optional and blank by default. Send no `port` when blank, and make the hint say ports are read from the image's `EXPOSE` and the field picks the primary. Keep the required, pre-filled field for web services and other private-service sources. Update the MCP `port` description to match. Pin both cases in `create-service-input.test.ts`.

Closed 2026-10-20 inside w6/m148 (same ship as its closeout): the create wizard leaves a Git-built Docker private service's port blank and omits it unless typed (\`portDraft\`/\`portIsValid\`, \`imagePorts\` shape), with image-port copy in en/zh; MCP \`port\` description updated; pinned in \`create-service-input.test.ts\`.
