## Objective

Check the shipped build behavior against render.com and across every surface that shows it: a deploy's statuses and timings on REST, GraphQL, MCP and the dashboard. Render's contract ([build pipeline](https://render.com/docs/build-pipeline)): one active build per service, a newer trigger replaces the queued one, different services build in parallel. File any drift as follow-up work.
