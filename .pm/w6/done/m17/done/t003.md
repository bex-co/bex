## Objective

`List(ownerID)` in `apps/service.go`, `postgres/service.go`, and `keyvalue/service.go` gates a named `ownerId` with `AuthorizeOn(can_view, workspace:<id>)` — OpenFGA only, no `IsMember` check. With `Authz == nil` (authorization off), `List(ctx, "tea-someone-elses")` returns that workspace's resources. Fold this onto `core.WithWorkspace`'s correct membership+OpenFGA mechanism (`resolveWorkspace`), the one `w6/m14` already built and left this older path beside.

## Context

- `w6/013`'s "Also found in the same review" section — the source of this task.
- `core.WithWorkspace` → `resolveWorkspace` — the correct mechanism, checks both membership and OpenFGA.

## Steps

1. Replace `List(ownerID)`'s `AuthorizeOn` call with the `core.WithWorkspace`/`resolveWorkspace` path.
2. Confirm `List` now correctly rejects a non-member's attempt to list another workspace's resources even with `Authz == nil`.
