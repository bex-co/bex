## Objective

Choose the mechanism and its states before coding, and write them into ADR054.

## Context

- `Resume`/`runResume` (`lego/backend/internal/agentsessions/service.go:1683`) set `PhaseResuming` and call `ResumeAgentSessionSandbox` on the existing sandbox id.
- A follow-up's fresh sandbox comes from `dispatch` (`service.go:889`), with `dispatchImage` booting the retained image when one is kept (w10/m491, `retention.go`).
- [ADR054](../../../../../docs/ADR054-open-in-zed.md) D1/D5/D6, [ADR059 § Superseded](../../../../../docs/ADR059-agent-sandbox-hibernation.md#2026-10-25--superseded-hibernation-retired) (why hibernation was retired: slow restore, a mint race, an orphaned `resuming` row).
- Devin: how its IDE behaves for a sleeping session (read docs.devin.ai, record the URL and date).

## Steps

1. Decide: reuse `dispatch` with an "editor" spec that runs no turn, and which phase the session shows while the sandbox is up.
2. Check the ADR059 failure modes do not return (the restore race, an orphaned `resuming` row on a bex-api restart).
3. Record the decision and Devin's behavior in ADR054.

## Result (2026-11-22)

ADR054 D8 records it. Devin: "The Files tab can now be opened while Devin is asleep, and opening Files or Terminal wakes Devin" (docs.devin.ai/release-notes, 2026-10-05, read 2026-11-22), and a preview of a sleeping session restarts its servers (2026-10-16). Decision: `resume` gives the session a sandbox an editor can open and runs no turn. It reuses the turn's sandbox boot (`bootSandbox`, one create with no wait for room) with an editor spec: no prompt, no turn label, `BEX_AGENT_EDITOR=1`, so the driver checks out and reports `ready`. The session reads `resuming` while it starts (a live phase, so the checkout's fetch mints Git credentials and a message waits in the queue), then returns to the phase it was resumed from with the sandbox, marked in `agent_sessions.editor_sandbox_id` (migration 0335). Kept disk first, else a fresh checkout of the branch. ADR059's failure modes: the mint race is the turn's (the driver retries its checkout's Git calls 30 s while the binding lands); a restart cannot orphan a `resuming` row, because the Completer settles a bound one from the driver's status (or after the turn ceiling, or drops a lost sandbox) and returns an unbound one to its finished phase after the start's 15-minute ceiling plus a minute. OpenSandbox's resume of a suspended sandbox was deleted: nothing suspends an agent sandbox since ADR059.
