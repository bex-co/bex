## Objective

Remove the last two frictions on the verification code step: the flow submits
itself the moment the 6th digit lands (no hunting for Continue), and a paste
anywhere on the page — input focused or not, bare code or the whole Kratos
email copied — lands the extracted code in the field and submits.

## Context

- User request 2026-08-21 during the m42 first-run walkthroughs.
- Key finding: Ory Elements routes `code`/`totp_code` nodes through
  **`Node.CodeInput`**, NOT `Node.Input` (input-renderer's `isPinCodeInput`
  branch) — overriding `Input` alone never sees the OTP field.

## Done (implemented + dev-6-verified 2026-08-21)

- `dashboard/src/common/lib/ory/auth-form-overrides.tsx`: `OtpCodeInput`
  registered as `Node.CodeInput` — `inputMode=numeric`,
  `autocomplete=one-time-code` (OS OTP autofill), `maxLength=6`; on a full
  6-digit value it clicks the flow's `method` submit (a real click carries the
  `method=code` submitter pair; "Resend code" is a different node name), one
  auto-submit per value.
- Page-wide `paste` listener: `extractOtp` takes the first run of EXACTLY six
  digits (UUID fragments/durations can't qualify), never hijacks a paste aimed
  at another editable, sanitizes focused pastes of the whole email to just the
  code; writes via the native value setter + `input` event so react-hook-form
  and auto-submit fire.
- Verification page switched from `oryHideCardLogo` to `oryAuthFormOverrides`.
- 10 new unit tests (auto-submit boundaries, dedupe, forwarding, extractOtp,
  paste capture/hijack/no-code cases); full dashboard suite green.
- Live-verified on dev-6 (Playwright): typing the 6th digit → straight to the
  deep link; pasting the full Kratos email onto the page body → code extracted,
  submitted, landed on `/billing`.

## Acceptance criteria

- [x] 6th digit auto-submits; no Continue click needed.
- [x] Paste anywhere with a six-digit code fills + submits; other-editable
      pastes and code-less clipboard text untouched.
- [x] Full dashboard suite + typecheck green; dev-6 browser E2E passed.
