## Objective

Turn `BEX_REQUIRE_PAYMENT_METHOD` from a boolean into a mode (`unset`/`0` = off, `1` = paid-intent-only — today's behavior, byte-identical; `all` = every billable create/plan change requires the `payment_method_bound_at` marker regardless of plan), enforced at the existing single seam so no per-feature wiring is added.

## Context

- The seam already exists: `core.Base.RequirePlanBilling` (`lego/backend/internal/core/base.go:414`) runs the card check only when `PaidPlan(plan)`; `all` mode drops that condition. Call sites (apps/postgres/keyvalue/blueprint) need no changes.
- `cmd/api/main.go:871/885` parses the env as a bool today and feeds both the gate wiring and the emitter's `RequirePaymentMethod` withholding flag.
- The refusal shape stays the existing coded 402/`PAYMENT_REQUIRED` (`core.NewPaymentRequiredError`) — identical across REST/GraphQL/MCP, no new error code (ADR075 D7).
- Repo rule: `.env.example` mirrors `.env` variable names/comments; the CLAUDE.md env table documents only `1` today.

## Steps

1. Introduce a mode type (off / paid-intent / all) parsed in `cmd/api/main.go`; reject unknown values at startup (fail closed, consistent with `BEX_CP_IDENTITY`'s precedent).
2. Thread the mode into `core.Base` so `RequirePlanBilling` checks the marker unconditionally under `all`; keep `RequireBillingMutation` ordering unchanged.
3. Decide + document the emitter interaction: under `all` the emitter's cardless-row withholding is unchanged (rows from pre-flip resources may still be cardless).
4. Update the CLAUDE.md env-table row and `.env.example` comment for the new `all` value.
