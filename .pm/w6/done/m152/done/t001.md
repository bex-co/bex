## Objective

Add GraphQL `diskSnapshotHealth(id)` returning `{state: ok|overdue|unavailable, reason, lastSnapshotAt, dueBy}`, computed from the App's `DiskReady` condition and the snapshot list.

## Acceptance criteria

- [ ] `unavailable` when `DiskReady` is False with a `Snapshot*` reason. The reason is a code, never the operator's prose.
- [ ] `overdue` past the first window's end plus grace, measured from max(last snapshot, disk creation). Snapshots that aren't configured return the existing not-configured error.
- [ ] Authorized like `diskSnapshots`; the scope matrix is updated.
