## Evidence (2026-07-15)

- Render's [public OpenAPI](https://api-docs.render.com/openapi/render-public-api-1.json) defines Environment as `id`, `name`, `projectId`, `databasesIds`, `redisIds`, `serviceIds`, `envGroupIds`, `protectedStatus`, `networkIsolationEnabled`, and optional object-form `ipAllowList`; it has no `ownerId`, `createdAt`, or `updatedAt`.
- Create requires `name`/`projectId` and optionally accepts the ACL triple. List returns `[{environment,cursor}]` and accepts `name`, required `projectId`, created/updated time bounds, `ownerId`, `environmentId`, `cursor`, and `limit` (default 20, 1–100); list-valued parameters are form/explode-false arrays.
- Current bex data can honor name/project/created/owner/environment filters. It cannot evaluate updated-time bounds without an `updatedAt`, so those two return a named 400. Full evidence is pinned in `docs/render-artifacts/protected-environments.md` and ADR032.
