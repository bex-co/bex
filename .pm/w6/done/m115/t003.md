## Objective

Once t002 lands, GraphQL's `name` stops being the immutable workspace-unique name — and that string then has no home on any read surface. Give it one, under a field whose name says what it is.

## Context

- Today the immutable name is readable in exactly one place: GraphQL's `name`. REST has never exposed it (REST's `name` is the label, and `slug` is the host segment).
- **`slug` is not the answer.** `AppView.Slug` is `a.Spec.PlatformSubdomain(a.Name)` (`apps/service.go:846`) and its doc (`service.go:346-353`) says it is the bare name only "when free platform-wide", otherwise `<name>-<4-char suffix>`. On a collided service, `slug` is a string `core.Base.GetApp` cannot resolve, because `GetApp` matches `LabelServiceName` (`core/base.go:1495`), which carries the un-suffixed name.
- This matters beyond tidiness: `core.LabelServiceName` is a live resolution key (`base.go:1453-1495`), so a caller that cannot read the immutable name cannot construct a by-name request even where one is supported.

## Steps

1. Add the field decided in t001 to the shared `renderService` struct so REST and MCP get it in one edit, and to `serviceGQLType`.
2. Populate it from `AppView.Name` — the same value `LabelServiceName` carries.
3. Verify the collision case, which was **not** observed during the hunt that filed this: construct a service whose `slug != name` (a cross-tenant name collision, needing a second workspace) and confirm the new field, not `slug`, is the one that resolves through `GetApp`. If that fixture is impractical, cover it with a unit test over `PlatformSubdomain` + `GetApp` and say so.
4. Check the field against Render's service schema — if Render has no counterpart, record it as a deliberate bex extension in `docs/ADR018-render-parity.md` rather than as a silent addition.

## Acceptance criteria

- [ ] REST, GraphQL and MCP each return the immutable workspace-unique name under the field t001 named, for a renamed service.
- [ ] That value resolves through `core.Base.GetApp` on a service where `slug != name` — demonstrated, not assumed.
- [ ] `slug` is unchanged and still the platform host segment.
- [ ] The field is either Render-compatible or recorded as a bex extension in the parity ledger.

## Out of scope

- Changing how `slug` is minted, or the `PlatformSubdomain` collision suffix.
