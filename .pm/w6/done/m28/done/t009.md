## Objective

Add durable behavior tests that prevent the enriched metadata from regressing into missing fields, fake values, cross-tenant owner leakage, broken CLI shapes, or static timestamps.

## Context

- Core/service tests alone cannot prove REST envelopes and JSON tags consumed by generated clients.
- Owner enrichment adds a cross-package lookup and therefore needs explicit non-default-workspace and authorization tests.
- Optional region/dashboard configuration and legacy objects require negative-path assertions, not snapshots.

## Steps

1. Add table-driven adapter tests for all three resource types and both configured/unconfigured metadata cases.
2. Add REST tests for list/get/create/update envelopes and exact nested owner fields.
3. Prove cross-workspace isolation, legacy omission, missing/deleted owner behavior, and bounded list lookups.
4. Prove mutation advances `updatedAt`, read-only access does not, and times serialize as valid UTC RFC3339 values.
5. Run backend build/tests/lint plus shell syntax and CLI verifier checks.
