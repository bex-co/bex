## Objective

Remove locally retained notification content when the corresponding destination is no longer authorized, and keep unread badges consistent.

## Context

- mergeRemote seeds a map from all local items and never removes an item omitted by the server.
- w6/m137 already filters server inbox rows by destination access; the client needs to consume those semantics and m139's reset generation.

## Steps

1. Connect notification state to the shared access-generation invalidation before affected content can render or be opened.
2. Define successful bounded-page reconciliation versus transport failure and genuine authorization removal; avoid treating every omitted older item as unauthorized.
3. Preserve local read acknowledgments where valid, remove revoked content from persistence, and recompute both in-app and OS unread state.

## Acceptance criteria

- [x] A stored agent-session alert disappears and its badge decrements after confirmed loss of destination access.
- [x] A stale local item cannot be reopened by fabricating an envelope with the current workspace/session.
- [x] Network failure does not masquerade as an authoritative empty inbox, and page limits do not silently erase still-authorized older history.
- [x] Existing local read-state dedupe remains correct.

## Out of scope

- Recalling already delivered OS notifications or exposing more content on lock screens.
- Replacing the server's shared destination policy with client role heuristics.
