## Objective

Add tests that would have caught each bug, and use the fixed build to settle whether `w6/030`'s still-unrooted `/env-groups/<id>` hydration error is actually this milestone's Bug B.

## Context

- `dashboard/src/test/setup.ts:34-38` globally preloads the zh bundle for every test (`i18n.addResourceBundle("zh", "translation", zhResources, true, true)`), which is exactly why no existing test caught Bug A — any test environment already has the zh catalog registered, masking the missing-`ensureLanguage` symptom that only manifests when the catalog genuinely isn't loaded yet.
- Bug B is a concurrency race in a shared module-level singleton — a naive sequential test (call `changeLanguage` twice, assert twice) will not exercise the actual race window; the test needs to simulate genuinely overlapping requests (e.g., two `beforeLoad`/render calls interleaved via `Promise.all` with artificial await points, or whatever seam t002's fix introduces).
- `.pm/w6/030.md` (open inbox note) reports an unroot-caused React #418 on `/env-groups/<id>`, guessing (never confirmed) that timestamp formatting is the cause. Since any page rendered during a language-mismatched request would show the identical generic #418 symptom, it's plausible — but unverified — that this is actually Bug B.
