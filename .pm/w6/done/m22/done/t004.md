## Objective

Grant the manager ServiceAccount permission to create/watch kpack `Image`/`Build` CRs.

## Context

- `lego/operator/cmd/manager/main.go` + kubebuilder RBAC markers (consumed by `make manifests` per root `CLAUDE.md`'s command list) drive the operator's RBAC.

## Steps

1. Add kubebuilder RBAC markers for `kpack.io` `images`/`builds` (get/list/watch/create/update/patch/delete as needed) on the controller reconciling builds.
2. Run `make manifests` to regenerate the RBAC yaml.

## Files

- `lego/operator/internal/build/build.go` (or wherever the reconciling controller's markers live)
- generated RBAC yaml under `lego/operator/config/rbac/`

## Acceptance criteria

- [ ] Manager can create/watch kpack `Image`/`Build` CRs in the build namespace without a permissions error.
- [ ] No broader-than-needed RBAC grant (least privilege, per `w6/m8` precedent).

## Out of scope

- The dispatch logic itself (t002).
