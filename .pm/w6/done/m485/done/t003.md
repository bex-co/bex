## Objective

Tests pin the drain: a held request survives SIGTERM, a request in the withdrawal window is served, the server stops accepting after the window, and it exits as soon as it is idle.

## Context

- `lego/operator/cmd/activator/hold_test.go`, `main_test.go` (the holder's `ready` and `target` are injectable).

## Steps

1. Hold a request on a fake App that turns ready after the signal; assert its response.
2. Assert a request during the window is served and one after it is refused.
3. Assert the drain returns as soon as no request is open.
