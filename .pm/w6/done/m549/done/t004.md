## Objective

Check the definition of done on production once the pin carries the new images.

## Context

- The newest `chore(deploy): pin platform images to <sha>` on `origin/main` must contain the shipping commit; the service must be rebuilt to pick up the new base.

## Steps

1. Create a paid native Go service and a native Node service in `bex-canary`, one with a disk; `wormhole --version` in each Shell.
2. Write 50 MB of random data to the disk; `wormhole send` it from the Shell; receive on a workstation; compare sha256.
3. Send a file from the workstation and receive it onto the disk from the Shell; compare sha256.
4. Delete the fixtures by id.
