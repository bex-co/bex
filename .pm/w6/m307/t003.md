## Objective

Render counts the pre-deploy command against pipeline minutes. bex's pre-deploy Jobs carry `app.bex.co/predeploy`, not `app.bex.co/build`, and run in the App's own namespace, so they meter nothing.

## Context

- `lego/operator/internal/predeploy/predeploy.go:58-66,176-179` (labels `app.bex.co/predeploy`, `app.bex.co/component=predeploy`)
- `lego/backend/internal/usage/service.go:1147-1159` (build query targets `BEX_BUILD_NAMESPACE`)

## Steps

1. Add the App's pre-deploy Jobs (App namespace, `app.bex.co/predeploy=<cr name>`) to the App's `build_seconds`, with the same end-time rules as t001.
2. Exempt platform-opened releases, as for builds.
3. Tests.
