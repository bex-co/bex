## Objective

Pin this milestone's behavior with tests that would have caught the regression: the backend's dead-id contract and the dashboard's redirect-vs-stay-put branches.

## Context

- The regression survived because nothing asserted the **shape** of a dead-id response. `w9/m55` t007 tested the dashboard's redirect-vs-error branches, but with a mocked resource — a backend that returns a zero-value object instead of `null` walks straight past those mocks. That gap is what this task closes.
- Both branches matter: dead id ⇒ `null`/redirect; backend failure ⇒ error/stay put.

## Steps

1. Backend: per resolver (`server`, `service`, `database`, `keyValue`), assert a dead id yields `data.<field> == null` **and** a not-found `errors` entry, and that a store/authz failure yields an error rather than `null`.
2. Backend: assert the REST twins return 404.
3. Dashboard: a route-level test that a settled not-found on the **service** route redirects with the toast, and that an error keeps the inline UI.
4. Add a regression-shaped assertion that an all-empty resource object is never treated as a loaded resource.

## Files

- `lego/backend/internal/apps/*_test.go`, `lego/backend/internal/gqlutil/*_test.go`, the postgres/keyvalue resolver tests
- `dashboard/src/routes/__tests__/`

## Acceptance criteria

- [ ] Each new test fails against the pre-fix code and passes after (state how this was verified).
- [ ] `cd lego/backend && go test ./...`, `make lint`, and `dashboard/` `yarn typecheck && yarn lint && yarn test` all green.

## Out of scope
