## Objective

Run compile stages natively on the ARM64 runner and target `linux/amd64` via `GOARCH`/copied output, so no compiler runs under emulation.

## Context

- `lego/Dockerfile` builder stage has no `--platform=$BUILDPLATFORM` (8 `go build` steps); `dashboard/Dockerfile` and `lego/agent-image/Dockerfile` node build stages likewise.

## Steps

1. Add `FROM --platform=$BUILDPLATFORM` to compile stages; keep runtime stages on the target platform.
2. Confirm the produced binaries are x86-64 (`file`) and images still build from the pinned bases.

## Acceptance criteria

- [ ] Images build for `linux/amd64`; binaries are x86-64; operator image build time drops measurably.
