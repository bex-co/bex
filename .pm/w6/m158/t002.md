## Objective

Reuse layers across runs: `cache-from`/`cache-to: type=registry,mode=max` on ghcr per image, written only from main, plus `RUN --mount=type=cache` for Go module/build and npm caches.

## Acceptance criteria

- [ ] A second run with unchanged inputs shows cached layers for every image and takes a fraction of the first.
- [ ] PR or non-main runs cannot write the cache.
