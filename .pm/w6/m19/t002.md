## Objective

Expose get/set verbs for `protectedStatus`, `networkIsolationEnabled`, and `ipAllowList` on an Environment across REST, GraphQL, and MCP.

## Context

- `lego/backend/internal/environments/{service,rest,graphql,mcp}.go` hold the existing Environment CRUD/assign verbs.
- Follow the existing pattern used for per-datastore `ipAllowList` (`lego/backend/internal/postgres/access.go:48-74`, `GetIPAllowList`/`SetIPAllowList`, exposed via GraphQL `databaseIpAllowList`/`setDatabaseIpAllowList`).

## Steps

1. Add service-layer verbs (`SetProtectedStatus`, `SetNetworkIsolationEnabled`, `SetIPAllowList`) to `environments/service.go`.
2. Wire REST endpoints (PATCH-style) in `environments/rest.go`.
3. Wire GraphQL mutations + include the fields in the Environment query type in `environments/graphql.go`.
4. Wire MCP tool(s) in `environments/mcp.go`.

## Files

- `lego/backend/internal/environments/service.go`
- `lego/backend/internal/environments/rest.go`
- `lego/backend/internal/environments/graphql.go`
- `lego/backend/internal/environments/mcp.go`

## Acceptance criteria

- [ ] Setting each field via REST, GraphQL, and MCP persists and round-trips through get/list.
- [ ] Unauthorized callers (non-members) are rejected consistently with existing Environment verbs.

## Out of scope

- Enforcement logic (t004/t005/t006).
