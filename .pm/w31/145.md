# 145 — MCP datastore mutation tools (`update_key_value`, `suspend_keyvalue`, `resume_keyvalue`, `enable_keyvalue_internal_auth`, `update_postgres`, and Postgres lifecycle/recovery tools) return flat `KeyValueView` / `PostgresView` instead of `renderKeyValue` / `renderPostgres` (`owner`, `options`), contradicting `get_*` / `create_*` / `list_*` and REST
