# 199 — GraphQL `Query.deploys`, GraphQL `Query.webhookDeliveries`, and their REST handlers (`GET /v1/services/{id}/deploys`, `GET /v1/webhooks/{id}/events`) validate filters/timestamps before authorization

Why: `w31/172` tracked pre-authorization timestamp/filter parsing in `deploys/mcp.go:128-138` (`MCP list_deploys`) and `webhooks/mcp.go:115-123` (`MCP list_webhook_deliveries`), but omitted the exact GraphQL and REST handler twins in the same packages: `deploys/graphql.go:250` (`Query.deploys`), `deploys/rest.go:235` (`GET /v1/services/{id}/deploys`), `webhooks/graphql.go:115-122` (`Query.webhookDeliveries`), and `webhooks/rest.go:235` (`GET /v1/webhooks/{id}/events`). Violating `bex-api`'s authz-before-validation contract, unauthorized callers or callers targeting foreign/nonexistent service or webhook IDs receive `400 bad_request` instead of `403 FORBIDDEN` / `404 NOT_FOUND` (and emit no denied audit row).

- **Context:** 2026-11-28, endpoints GraphQL `Query.deploys`, GraphQL `Query.webhookDeliveries`, REST `GET /v1/services/{id}/deploys`, and REST `GET /v1/webhooks/{id}/events`, workspace `bex-canary` (`tea-daif693dqjvc73e7as3g`), nonexistent/foreign probe IDs `srv-00000000000000000000`, `whk-00000000000000000000`, and `tea-00000000000000000000`, run-minted all-permissions API key (revoked after run). - **Expected / actual:**
  - **Expected:** Authorization (`deploys.Service.List` → `AuthorizeApp`; `webhooks.Service.ListDeliveriesFiltered` → workspace/endpoint authorization) runs before filter, limit, and timestamp parsing, so unauthorized or nonexistent targets receive `403 FORBIDDEN` / `404 NOT_FOUND` (and record denied audit rows).
  - **Actual:** Every probe with a malformed timestamp returned `400 bad_request` before authorization ran, while the identical control without the timestamp parameter returned `404 NOT_FOUND` / `403 FORBIDDEN`.
- **Wire evidence:**
  - GraphQL `Query.deploys` with `createdAfter:"not-a-time"` (`rndr-id: 713e4525-f221-9236`) → `bad request: createdAfter must be an RFC3339 timestamp (e.g. 2026-01-02T15:04:05Z)` (Control without `createdAfter`, `rndr-id: b9895884-02c9-bd35` → `NOT_FOUND`).
  - GraphQL `Query.webhookDeliveries` with `sentAfter:"not-a-time"` (`rndr-id: 371fdf8b-8091-8a0b`) → `bad request: sentAfter must be an RFC3339 timestamp (e.g. 2026-01-02T15:04:05Z)` (Control without `sentAfter`, `rndr-id: 5287b98a-3f2d-9f0e` → `FORBIDDEN`).
  - REST `GET /v1/services/srv-00000000000000000000/deploys?createdAfter=not-a-time` (`rndr-id: 9e26c013-1563-194e`) → `400 invalid query parameter "createdAfter"` (Control `rndr-id: a25ca475-3c72-1fb4` → `404 not found`).
  - REST `GET /v1/webhooks/whk-00000000000000000000/events?ownerId=tea-00000000000000000000&sentBefore=not-a-time` (`rndr-id: d4031d28-eb63-4da7`) → `400 invalid query parameter "sentBefore"` (Control `rndr-id: 66eed723-1a49-1a7c` → `403 forbidden`).
- **Attribution:** server (`lego/backend/internal/deploys`, `lego/backend/internal/webhooks`)
- **Root cause:**
  - `lego/backend/internal/deploys/graphql.go:250-254`: `Query.deploys` calls `filterFromArgs(p.Args)` (`:304-329`, which runs `gqlutil.PositiveLimit` and `FilterOf`) before calling `s.List(p.Context, p.Args["serviceId"].(string), filter)`.
  - `lego/backend/internal/deploys/rest.go:235-240`: `GET /v1/services/{id}/deploys` calls `filterFromQuery(r.URL.Query())` (`:193-205`, which runs `core.QueryLimit` and `FilterOf`) before calling `s.List(r.Context(), r.PathValue("id"), filter)`.
  - `lego/backend/internal/webhooks/graphql.go:115-126`: `Query.webhookDeliveries` calls `core.ParseTime("sentAfter", ...)` and `core.ParseTime("sentBefore", ...)` before calling `s.ListDeliveriesFiltered(...)`.
  - `lego/backend/internal/webhooks/rest.go:235-243`: `GET /v1/webhooks/{id}/events` calls `core.QueryTimeWindow(q, "sentBefore", "sentAfter")` before calling `s.ListDeliveriesFiltered(...)`.
- **Fix:**
  - Coordinate with `w31/172` (which covers the MCP twins `deploys/mcp.go:128-138` and `webhooks/mcp.go:115-123`): pass raw filter/timestamp/limit inputs into `deploys.Service.List` and `webhooks.Service.ListDeliveriesFiltered` (or a shared raw-filter struct) and run `FilterOf` / `core.ParseTime` / `core.QueryTimeWindow` / limit validation strictly **after** `s.AuthorizeApp` / endpoint authorization succeeds, matching `events.Service.List`.
  - Surface impact: fixes GraphQL, REST handlers, and MCP through one service-layer validation point.
