# 186 — `registrycreds` validates inputs before authorization across MCP, REST, and GraphQL, and `REST PATCH /v1/registrycredentials/{id}` calls `s.Get` (`RelCanView`) before `s.Update` (`RelCanManage`)

Why: `bex-api`'s authz-before-validation contract requires authorization to run before caller-supplied arguments are validated so unauthorized callers (foreign workspaces, unprivileged roles, or nonexistent IDs) receive `403 FORBIDDEN` / `404 NOT_FOUND` instead of `400 bad_request` (and denied attempts emit denied audit rows). Every `registrycreds` write adapter across MCP, REST, and GraphQL (`create_registry_credential`, `update_registry_credential`, `POST /v1/registrycredentials`, `PATCH /v1/registrycredentials/{id}`, `Mutation.createRegistryCredential`, `Mutation.updateRegistryCredential`) runs `createHost`, `checkRenderRegistry`, and/or `parseExpiresAt` before delegating to `s.Create` / `s.Update` (`core.RelCanManage`, Admin-only), and `GET /v1/registrycredentials` runs `checkRenderRegistry` and `core.QueryTimeWindow` before `ListForCaller` / `s.List`. Worse, when `REST PATCH /v1/registrycredentials/{id}` receives a `registry` field, it authorizes via `s.Get` (`core.RelCanView`, Viewer/Developer) and compares `renderRegistry(current.Host) != *req.Registry` before `s.Update` (`core.RelCanManage`), returning `400` and leaking `current.Host` to non-Admins instead of `403 forbidden`.

- **Attribution:** server (`lego/backend/internal/registrycreds`)
- **Root cause:**
  - `lego/backend/internal/registrycreds/rest.go:170-183` (`POST /v1/registrycredentials`), `lego/backend/internal/registrycreds/graphql.go:145-158` (`createRegistryCredential`), and `lego/backend/internal/registrycreds/mcp.go:102-113` (`create_registry_credential`): all three adapters call `createHost` and `parseExpiresAt` before calling `s.Create`, which authorizes `core.RelCanManage` at `lego/backend/internal/registrycreds/service.go:236`.
  - `lego/backend/internal/registrycreds/rest.go:225-234` (`PATCH /v1/registrycredentials/{id}`), `lego/backend/internal/registrycreds/graphql.go:175-183` (`updateRegistryCredential`), and `lego/backend/internal/registrycreds/mcp.go:125-133` (`update_registry_credential`): all three adapters call `parseExpiresAt` before calling `s.Update`, which scopes and authorizes `core.RelCanManage` at `lego/backend/internal/registrycreds/service.go:313-319`.
  - `lego/backend/internal/registrycreds/rest.go:209-223` (`PATCH /v1/registrycredentials/{id}`): when `req.Registry != nil`, the handler calls `checkRenderRegistry("registry", *req.Registry)` before authz and then invokes `s.Get` (`service.go:197-212`, which checks `core.RelCanView` rather than `core.RelCanManage`) to verify `renderRegistry(current.Host) == *req.Registry`, leaking `current.Host` in a `400` error to non-Admin callers instead of failing `403 forbidden` at `s.Update`, and issuing a redundant authz + store lookup for Admins.
  - `lego/backend/internal/registrycreds/rest.go:132-148` (`GET /v1/registrycredentials`): calls `checkRenderRegistry("type", registry)` and `core.QueryTimeWindow` before `core.ListForCaller(..., s.List)`, diverging from `GET /v1/services` (`apps/rest.go:915-942`) and `GET /v1/postgres` (`postgres/rest.go:197-204`).
- **Fix:**
  - Accept raw `Registry string`, `ExpiresAtRaw string` on `CreateRequest` and `Registry *string`, `ExpiresAtRaw *string` on `UpdateRequest`, and run `createHost`, `checkRenderRegistry`, `renderRegistry(existing.Host) != *req.Registry`, and `parseExpiresAt` inside `s.Create` / `s.Update` immediately **after** `s.Authorize(..., core.RelCanManage)` (and after loading `existing` in `s.Update`), using `core.WithDeferredAllowedWriteAudit` so `400`/`404` refusals do not record false `"allowed"` audit rows.
  - Remove the pre-`s.Update` `s.Get` + registry mismatch block in `lego/backend/internal/registrycreds/rest.go:209-223` so `PATCH /v1/registrycredentials/{id}` authorizes once under `core.RelCanManage` inside `s.Update`.
  - Move `checkRenderRegistry` and both `core.QueryTimeWindow` calls in `lego/backend/internal/registrycreds/rest.go:132-147` below `core.ListForCaller` (`:148`).
