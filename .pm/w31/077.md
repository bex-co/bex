# 077 — `apps.Service.LinkBuildSource(..., dryRun: true)` returns the unchanged pre-link service instead of previewing the linked `buildSourceId` across MCP, REST, and GraphQL

Why: `apps.Service.LinkBuildSource` (`lego/backend/internal/apps/build_sources.go:1124-1126`) short-circuits `if dryRun { return s.view(a), nil }` before applying `linkBuildSourceSpec` or `startCommand` to a copy of `a`, so MCP `link_service_to_build_source(dryRun: true)`, REST `PATCH /v1/services/{id}?dryRun=true` (`buildSourceId`), and GraphQL `linkBuildSource(dryRun: true)` all return the stale pre-link service (`buildSourceId` omitted/`null` and the old `imagePath`/`repo` still set), contradicting `dryrun_test.go:21-22` and sibling `update_service(dryRun: true)` / `ApplyServicePatchDryRun`.

- **Attribution:** server (`lego/backend/internal/apps`)
- **Root cause:**
  - `apps.Service.LinkBuildSource` (`lego/backend/internal/apps/build_sources.go:1124-1126`) merges the `dryRun` check with the already-linked no-op check:
    ```go
    if dryRun || (a.Spec.BuildSource != nil && *a.Spec.BuildSource == *link && existing == start) {
        return s.view(a), nil
    }
    ```
    When `dryRun` is `true`, it returns `s.view(a)` directly instead of applying the link mutation closure (`linkBuildSourceSpec`, `forgetSwitchBackCommands`, and `spec.Command`/`spec.StartCommand = start` from `:1137-1148`) to a deep copy of `a`.
  - `TestBuildSourceLinkAndSwitchBack` (`lego/backend/internal/apps/build_sources_test.go:465-470`) discards the returned `AppView` (`if _, err := svc.LinkBuildSource(..., true)`), checking only that the stored `App` CR was not mutated.
- **Fix:**
  - In `lego/backend/internal/apps/build_sources.go:1124-1151`, extract the spec mutation closure (`applyLink := func(app *appv1alpha1.App) { ... }`):
    - If already identical (`a.Spec.BuildSource != nil && *a.Spec.BuildSource == *link && existing == start`), return `s.view(a), nil`.
    - If `dryRun`, clone `preview := a.DeepCopy()`, run `applyLink(preview)`, and return `s.view(preview), nil` without calling `markSourcePending`, `SetAppBuildSource`, `patchUntracked`, `deleteCloneSecret`, or recording audit events.
    - Otherwise pass `applyLink` to `s.patchUntracked`.
  - Surface impact: MCP `link_service_to_build_source(dryRun: true)`, REST `PATCH /v1/services/{id}?dryRun=true` (`buildSourceId`), and GraphQL `linkBuildSource(dryRun: true)` all return the previewed post-link service (and MCP/REST automatically enrich the previewed `buildSourceId` via `linkedBuildView`).
- **Blast radius:** `lego/backend/internal/apps/build_sources.go` and `lego/backend/internal/apps/build_sources_test.go`. Zero side-effect change; only the returned preview object on `dryRun: true` changes.
