# 220 — Ad-hoc Blueprint `deploy` (`apps.Service.DeployStack` / `MCP deploy` / `REST POST /v1/blueprints/deploy`) bypasses protected-environment Admin enforcement (`PROTECTED_ENVIRONMENT_ADMIN_REQUIRED`) on unmanaged services, datastores, and env groups, and commits partial writes before `403` `maintenanceMode` refusal

Why: `docs/ADR032-environments.md:107` limits Render's protected-environment Blueprint exception to automated push/auto-sync workers marked with `core.WithBlueprintSync` (identity-less), keeping a member's manual sync over REST, GraphQL, or MCP gated. Yet `apps.Service.DeployStack` (`MCP deploy`, `REST POST /v1/blueprints/deploy`, `GQL Mutation.deployStack` / manual sync) matches any existing unmanaged resource in the workspace by name and mutates protected fields without checking `core.BlueprintSync(ctx)` or the protected-environment Admin verbs: (1) `updateStackService` (`lego/backend/internal/apps/deploy.go:4132,4192`) calls `s.requireUnprotected(ctx, existing, "deploy")` — a dead no-op because `core.ProtectedVerbRestricted("deploy")` (`core/confirmation.go:79-86`) returns `false` — letting a non-Admin Developer inject/overwrite `envVars` on a protected service; (2) `patchChangedStackService` (`deploy.go:4445-4535`) commits `persistBlueprintIntent`, `recordBlueprintRedeploy`, and `s.Client.Patch` *before* calling `s.ConfigureMaintenanceMode` at `:4534`, leaving a partial CR/store write and triggered deploy when a non-Admin's mixed `maintenanceMode` update is refused `403 PROTECTED_ENVIRONMENT_ADMIN_REQUIRED`; (3) `applyDatabase` (`deploy.go:4850-4914`) and `applyKeyValue` (`deploy.go:4954-4999`) directly patch `ipAllowList` and `public` on protected datastores without `VerbChangeAccessControl`; and (4) `envgroups.Service.ApplyEnvGroup` (`envgroups/service.go:1692-1762`) and `LinkEnvGroup` (`:1845-1861`) mutate protected environment groups and link groups to protected services without `VerbEnvironmentVariables`.

- **Root cause:**
  - **Dead `"deploy"` guard + service `envVars` bypass (`lego/backend/internal/apps/deploy.go:4132,4192,4459,4516`):** `updateStackService` calls `s.requireUnprotected(ctx, existing, "deploy")` at `:4192`, left over from pre-`w8/187` confirmation phrases. `core.ProtectedVerbRestricted("deploy")` (`lego/backend/internal/core/confirmation.go:79-86`) returns `false`, making `:4192` a dead no-op. `applyBlueprintServiceSpec` (`blueprint_plan.go:343-345`) merges `envVars` directly into `final.Spec.Env`, bypassing `secrets.Service.scope` (`VerbEnvironmentVariables`).
  - **Partial write before `403` `maintenanceMode` refusal (`lego/backend/internal/apps/deploy.go:4409-4535`):** In `patchChangedStackService`, when `actualSpecChanged && !maintenanceOnly` and `maintenanceChanged` is true, lines `:4445-4518` commit `persistBlueprintIntent`, `recordBlueprintRedeploy`, and `s.Client.Patch` (preserving `currentMaintenance` at `:4466`) before `:4534` invokes `s.ConfigureMaintenanceMode` — which checks `requireUnprotected(..., VerbToggleMaintenanceMode)` and returns `403 PROTECTED_ENVIRONMENT_ADMIN_REQUIRED` only after the other changes and deploy have already been persisted.
  - **Datastore `ipAllowList`/`public` bypass (`lego/backend/internal/apps/deploy.go:4850-4914,4954-4999`):** `applyDatabase` and `applyKeyValue` patch `existing.Spec.IPAllowList` and `existing.Spec.Public` directly without checking `core.BlueprintSync(ctx)` or `core.VerbChangeAccessControl`. Note `w4/m594` pinned this in `TestBlueprintSyncChangesAProtectedDatastoresRulesForADeveloper` (`lego/backend/internal/apps/blueprint_datastore_access_test.go:239-272`) by calling `svc.DeployStack(developer, inlineManifest)` directly — conflating an authenticated member's ad-hoc `DeployStack` with an automated push sync (`core.WithBlueprintSync`, `docs/ADR032-environments.md:107`).
  - **Protected environment group `envVars` & `fromGroup` link bypass (`lego/backend/internal/envgroups/service.go:1692-1762,1845-1861`):** `ApplyEnvGroup` and `LinkEnvGroup` authorize only `core.RelCanCreate` and skip `requireGroupAdmin` / `requireEnvironmentAdmin` (`VerbEnvironmentVariables`) even when `!core.BlueprintSync(ctx)`.
- **Fix:**
