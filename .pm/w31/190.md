# 190 — Remaining non-OpenAPI REST write routes (`core.HandleLinksMapped`, `environments/acl`, `secrets/environment`, `envgroups`, `apps/blueprints`, `members`) omit `core.WithStrictJSONDecoding`, silently dropping unknown/misspelled fields and wiping project/environment links on typos

Why: `renderRequestValidator` (`lego/backend/internal/api/render_openapi.go:1028`) only enables `core.WithStrictJSONDecoding` on routes matched in Render's OpenAPI spec; bex-extension REST routes must opt in, and 18 remaining write routes across `core.HandleLinksMapped` (`PUT /v1/{projects,environments}/{id}/*-links`), `environments/rest.go` (`PATCH /v1/environments/{id}/acl`), `secrets/rest.go` (`PATCH /v1/services/{id}/environment`), `envgroups/rest.go` (`POST /v1/env-groups/{id}/clone`, `PATCH /v1/env-groups/{id}/{contents,environment}`, `PUT /v1/env-groups/{id}/env-vars`), `apps/rest.go` (`POST /v1/blueprints/{preview,deploy,generate,{id}/approve,{id}/sync}`), and `members/rest.go` (`POST /v1/invites/{preview,accept}`, `POST /v1/workspaces/{workspaceId}/members`, `PATCH /v1/workspaces/{workspaceId}/members/{subject}`) omit it (and `POST /v1/blueprints/{id}/sync` at `apps/rest.go:1859` discards all decode errors via `_ = core.DecodeJSON`). On full-replace endpoints (`core.HandleLinksMapped`, `PATCH /v1/environments/{id}/acl`, `PUT /v1/env-groups/{id}/env-vars`), a 1-field typo (such as `{"services":["srv-..."]}` instead of `{"serviceIds":["srv-..."]}`) decodes an empty slice and returns `200 OK` while **silently wiping all linked resources, ACL rules, or env-var values** — diverging from MCP and GraphQL, which reject unknown fields immediately.

- **Root cause:**
  - `lego/backend/internal/api/render_openapi.go:1028` only sets `core.WithStrictJSONDecoding` on matched Render OpenAPI operations; the remaining 18 non-OpenAPI bex-extension write handlers decode via plain `core.DecodeBody` / `core.DecodeJSON`:
    - `lego/backend/internal/core/http.go:567` (`HandleLinksMapped` — powers all 7 full-replace link routes: `PUT /v1/environments/{id}/{service,database,keyvalue,env-group}-links` at `environments/rest.go:244-247` and `PUT /v1/projects/{id}/{service,database,keyvalue}-links` at `projects/rest.go:221-223`, normalizing missing fields to `[]string{}` so any misspelled key wipes membership).
    - `lego/backend/internal/environments/rest.go:256` (`PATCH /v1/environments/{id}/acl` — full-replace ACL triple; misspelled `ipAllowList` or `networkIsolationEnabled` silently wipes ACL settings).
    - `lego/backend/internal/secrets/rest.go:80` (`PATCH /v1/services/{id}/environment`).
    - `lego/backend/internal/envgroups/rest.go:156,163,170,181` (`POST /v1/env-groups/{id}/clone`, `PATCH /v1/env-groups/{id}/contents`, `PATCH /v1/env-groups/{id}/environment`, and `PUT /v1/env-groups/{id}/env-vars` — not in Render's OpenAPI spec, so misspelled element fields like `"val"` wipe env-var values to `""`).
    - `lego/backend/internal/apps/rest.go:1718,1790,1808,1832,1859` (`POST /v1/blueprints/{id}/approve`, `POST /v1/blueprints/deploy`, `POST /v1/blueprints/generate`, `POST /v1/blueprints/preview`, `POST /v1/blueprints/{id}/sync`; `:1859` also ignores decode errors completely via `_ = core.DecodeJSON(r, &body)`).
    - `lego/backend/internal/members/rest.go:35,61,76,161` (`POST /v1/invites/preview`, `POST /v1/workspaces/{workspaceId}/members`, `PATCH /v1/workspaces/{workspaceId}/members/{subject}`, `POST /v1/invites/accept`, all of which also discard `err.Error()` into bare `core.ErrBadRequest`).

  - Surface safe field-naming decode errors on `members/rest.go:35,61,76,161` and `apps/rest.go:1808` instead of bare `core.ErrBadRequest`.
