- **Attribution:** server (`lego/backend/internal/projects`, `lego/backend/internal/environments`, `lego/backend/internal/store`)
- **Root cause:**
  - `projects.Service.Rename` (`lego/backend/internal/projects/service.go:580-599`): never checks `if p.Name == name`, unconditionally executing `s.Store.RenameProject` (`lego/backend/internal/store/projects.go:61-72`, `UPDATE projects SET name = $2, updated_at = now()`).
  - `projects.Service.setResourceMembers` (`lego/backend/internal/projects/service.go:806-866`): never tracks whether any resource's `projectID` actually changed in `:846-857`, unconditionally calling `s.Store.TouchProject(ctx, p.ID)` (`:858`) even when zero CRs were patched — and also omits `core.WithDeferredAllowedWriteAudit(ctx)` at `:810`, so both refused calls (`403` unknown ID) and zero-change replays emit `"status": "success"` audit rows (`projects.SetDatabases` / `projects.SetKeyValues`).
  - `store.PGStore.SetProjectServices` (`lego/backend/internal/store/projects.go:240-247`): executes `UPDATE projects SET updated_at = now() WHERE id = $1` unconditionally inside the `placementDiffAround` callback instead of touching `projects.updated_at` only when `len(changes) > 0` (after verifying the project exists).
  - `environments.Service.Rename` (`lego/backend/internal/environments/service.go:931-953`) and `environments.Service.Update` (`:1019-1025`): never check `if e.Name == name`, unconditionally running `s.Store.RenameEnvironment(ctx, e.ID, name)` and emitting `s.RecordAllowedWrite(ctx, "environments.Update", ...)` even when the name did not change.
- **Fix:**
  - In `projects.Service.Rename` (`lego/backend/internal/projects/service.go:580-599`), short-circuit after authorization and `requiredName` validation when `p.Name == name` (returning `s.view(ctx, p)` with zero DB writes and zero allowed-write audit row, coordinated with `w31/122`'s deferred audit).
  - In `projects.Service.setResourceMembers` (`lego/backend/internal/projects/service.go:806-866`), authorize under `core.WithDeferredAllowedWriteAudit(ctx)`, track `changed := false` across the `:846-857` diff loop, call `s.Store.TouchProject` and record the allowed write only when `changed` is true, and return `s.view(ctx, p)` directly otherwise.
  - In `store.PGStore.SetProjectServices` (`lego/backend/internal/store/projects.go:207-252`), touch `projects.updated_at = now()` only when `len(changes) > 0` (keeping the `ErrNotFound` check when the project row does not exist).
  - In `environments.Service.Rename` (`lego/backend/internal/environments/service.go:931-953`) and `environments.Service.Update` (`:1019-1025`), guard `RenameEnvironment` and its `RecordAllowedWrite` behind `if e.Name != name`.
