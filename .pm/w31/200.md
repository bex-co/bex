# 200 — `postgres.FreeExpiresAt` clamps zero `CreationTimestamp` to `FreeExpiryRollout` (`2026-10-27`), returning a stale past `"expiresAt": "2026-11-26T00:00:00Z"` on `dryRun: true` free Postgres creates across MCP, REST, and GraphQL

Why: `postgres.FreeExpiresAt` (`lego/backend/internal/postgres/expiry.go:102-114`) computes a free database's expiry from `d.CreationTimestamp.UTC()` and clamps any timestamp before `FreeExpiryRollout` (`2026-10-27T00:00:00Z`) up to `FreeExpiryRollout`. Because Kubernetes `DryRunCreate` leaves `d.CreationTimestamp` at Go's zero time (`0001-01-01T00:00:00Z`, which is before `2026-10-27`), every `dryRun: true` free Postgres create across MCP `create_postgres`, REST `POST /v1/postgres?dryRun=true`, and GraphQL `Mutation.createDatabase(dryRun: true)` reports `"expiresAt": "2026-11-26T00:00:00Z"` — a date already in the past — instead of previewing `now + 30d` (and leaves `FreeExpirySweeper` exposed to treating any zero-timestamp free `Database` object as already expired).

- **Root cause:**
  - `lego/backend/internal/postgres/expiry.go:102-114`: `FreeExpiresAt(d)` reads `start := d.CreationTimestamp.UTC()` (without checking `d.CreationTimestamp.IsZero()` when `annotationFreeSince` is absent) and then runs `if start.Before(FreeExpiryRollout) { start = FreeExpiryRollout }`, turning `0001-01-01T00:00:00Z` into `2026-10-27T00:00:00Z` and adding 30 days → `2026-11-26T00:00:00Z`.
  - `lego/backend/internal/postgres/service.go:1036-1041`: `CreatePostgres` calls `s.DryRunCreate(ctx, d)` (which does not persist `d` and leaves `d.CreationTimestamp` zero) and returns `s.view(d)`, which calls `FreeExpiresAt(d)` at `service.go:647`.
- **Fix:**
  - In `FreeExpiresAt(d)` (`lego/backend/internal/postgres/expiry.go:102-114`): if `annotationFreeSince` is absent/unparseable and `d.CreationTimestamp.IsZero()`, return `(time.Time{}, false)` instead of clamping zero time to `FreeExpiryRollout` (also ensuring `FreeExpirySweeper.advance` never mistakes a zero-timestamp CR for a database expired on `2026-11-26`).
  - In `postgres.Service.view(d)` (`lego/backend/internal/postgres/service.go:647-650`) — or in `CreatePostgres`'s `if req.DryRun` preview path before calling `s.view(d)` — when `isFreePlan(d.Spec.Plan)` and `d.CreationTimestamp.IsZero()` (an unpersisted dry-run preview), compute the previewed `expiresAt` from `s.Now().UTC()` (clamped to `FreeExpiryRollout` only if `now.Before(FreeExpiryRollout)`), so `expiresAt` previews `now + 30d` across MCP, REST, and GraphQL.
