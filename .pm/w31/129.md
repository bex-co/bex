# 129 — `apps.Service.SetRoutes`, `apps.Service.SetHeaders`, and `apps.Service.MoveRoute` unconditionally patch the App CR (`updatedAt`) and emit `apps.SetRoutes` / `apps.SetHeaders` audit-log rows on no-op updates across MCP, REST, and GraphQL

Why: `apps.Service.SetRoutes` (`lego/backend/internal/apps/service.go:7034-7051`), `apps.Service.SetHeaders` (`:7068-7085`), and `apps.Service.MoveRoute` (`lego/backend/internal/apps/static_rules.go:94-111`, via `editStaticRules` at `:39-52`) unconditionally call `s.recordedPatch` without checking whether `a.Spec.Routes` or `a.Spec.Headers` actually changed — so sending an identical rule list (such as `[]` on a static site with no routes/headers) or moving a route to its existing priority mutates the App CR's `updatedAt` timestamp and emits bogus `"status": "success"` `apps.SetRoutes` / `apps.SetHeaders` audit-log rows across MCP, REST, and GraphQL.

- **Root cause:**
  - `lego/backend/internal/apps/service.go:7034-7051` (`SetRoutes`) and `:7068-7085` (`SetHeaders`): convert `routes`/`headers` with `routesFromViews`/`headersFromViews` inside `s.recordedPatch` without comparing against `a.Spec.Routes` / `a.Spec.Headers` (`slices.Equal`).
  - `lego/backend/internal/apps/static_rules.go:94-111` (`MoveRoute`): passes straight through `editStaticRules` → `s.recordedPatch` even when `routeIndex(a, routeID) == priority`, touching the CR and emitting `apps.SetRoutes` for an unchanged order.
  - Note also sibling `lego/backend/internal/apps/service.go:7302-7322` (`SetAutoscaling`): while it already guards `s.RecordAutoscalingChanged` behind `if autoscalingChanged(from, as)`, it still unconditionally runs `s.patchFetched` (`:7312`) and bumps `updatedAt` even when `reflect.DeepEqual(from, &as)` is true.
- **Fix:**
  - In `SetRoutes` (`apps/service.go:7048`) and `SetHeaders` (`:7082`), compute `next := routesFromViews(routes)` / `headersFromViews(headers)` and return `s.appViewWithEnv(ctx, a), nil` (no patch, no `updatedAt` bump, no audit event) when `slices.Equal(a.Spec.Routes, next)` / `slices.Equal(a.Spec.Headers, next)`.
  - In `MoveRoute` (`apps/static_rules.go:94-111`), short-circuit before patching when `routeIndex(a, routeID) == priority` (after validation confirms the route exists and `priority` is in range).
  - Optionally check `SetAutoscaling` (`apps/service.go:7311-7320`) so a truly identical `AutoscalingSpec` (`from != nil && reflect.DeepEqual(*from, as)`) also skips the no-op CR patch.
