# 022 — Empty agent-session ID (`id: ""`) returns `"authorization service unavailable"` across cloud-agent MCP tools and GraphQL `agentSession` because `validFGAObject` accepts `"type:"`

Why: `validFGAObject` checks only characters inside `id` after splitting `type:id` on `":"`, never checking that `id` is non-empty — so calling any session-scoped cloud-agent MCP tool (or GraphQL `agentSession`) with `id: ""` sends `"agent_session:"` to OpenFGA, whose HTTP 400 rejection is mapped to `core.ErrAuthzUnavailable` (`"authorization service unavailable"`), reporting a 503-class authz outage on trivial empty input.

### `id: ""` on `get_agent_session` and sibling session tools returns `"authorization service unavailable"` instead of `FORBIDDEN`

- **Attribution:** server (`lego/backend/internal/core`)
- **Root cause:**
  - `operableRecord` (`lego/backend/internal/agentsessions/service.go:1641-1644`) authorizes `sessionObject(sessionID)` (`"agent_session:" + sessionID`) via `s.AuthorizeOn` before calling `validateSessionID`, so an empty `sessionID` passes `"agent_session:"` into `checkAuthz` / `checkAuthzFresh` (`lego/backend/internal/core/base.go:1040,1075`).
  - `validFGAObject` (`lego/backend/internal/core/base.go:2678-2689`) splits the object with `_, id, _ := strings.Cut(object, ":")` and checks only each rune in `id`, returning `true` when `id == ""` (or when `typ == ""` or `":"` is missing).
  - OpenFGA rejects `"agent_session:"` with HTTP `400 Bad Request`, which `checkAuthz` / `checkAuthzFresh` (`core/base.go:1044-1046,1079-1081`) logs as `core: authorization unavailable` and returns as `core.ErrAuthzUnavailable` (`"authorization service unavailable"`).
  - Note: `checkAuthz` / `checkAuthzFresh` had a special case only for `object == WorkspaceObject("")` (`core/base.go:1027,1061`), leaving every other OpenFGA object type (such as `agent_session:`) unguarded against an empty ID.
- **Fix:**
  - In `validFGAObject` (`lego/backend/internal/core/base.go:2678-2689`), capture `typ, id, found := strings.Cut(object, ":")` and return `false` when `!found || typ == "" || id == ""` (keeping the existing `WorkspaceObject("")` check above it in `checkAuthz`/`checkAuthzFresh` unchanged so workspace-empty calls still return `400 workspace id is required`).
  - Add unit tests in `lego/backend/internal/core/` covering `validFGAObject("agent_session:")`, `validFGAObject(":id")`, `validFGAObject("no-colon")`, and `checkAuthz`/`checkAuthzFresh` returning `ErrForbidden` (never calling `Authz.Check` / `CheckFresh`) on `"agent_session:"`.
  - Surface impact: fixes MCP (`/mcp` and `/mcp/cloud-agents`), GraphQL, and any REST path reaching `AuthorizeOn` with an empty object ID; no wire breaking change.
- **Blast radius:** `lego/backend/internal/core/base.go` (`validFGAObject`) and its callers `checkAuthz` / `checkAuthzFresh`. Protects all `agent_session:<id>` tools (`get_agent_session`, `get_agent_session_tree`, `get_agent_session_transcript`, `get_agent_session_model_cost`, `get_agent_session_tool_output`, `list_agent_session_attachments`, `list_agent_session_queued_messages`, `update_agent_session`, `set_agent_session_tags`, `archive_agent_session`, `unarchive_agent_session`, `cancel_agent_session`, `delete_agent_session`, `resume_agent_session`, `attach_agent_session`, `send_agent_session_message`, `interrupt_agent_session`, queued-message edits/deletes/moves) and every future non-workspace OpenFGA object type.
