# 018 — `CreateBuildSource` bypasses `image.ownerId` validation when `workspaceId` is omitted on MCP, and `UpdateBuildSource` never validates `image.ownerId` on MCP, REST, or GraphQL

Why: `CreateBuildSource` checks `req.Image.OwnerID != req.OwnerID` only when `req.OwnerID != ""` (`lego/backend/internal/apps/build_sources.go:252`), which is always empty on MCP when `workspaceId` is omitted (`core.NamedWorkspace(ctx) == ""`), and `UpdateBuildSource` (`buildSourcePatch`, `build_sources.go:789-794`) never checks `image.ownerId` at all — so a mismatched or foreign `image.ownerId` silently succeeds on MCP create (default workspace) and on MCP, REST, and GraphQL updates instead of failing with `400 bad request: image.ownerId must be the build source's ownerId`.

- **Attribution:** server (`lego/backend/internal/apps`)
- **Root cause:**
  - `CreateBuildSource` (`lego/backend/internal/apps/build_sources.go:252`):
    ```go
    if req.Image.OwnerID != "" && req.OwnerID != "" && req.Image.OwnerID != req.OwnerID {
    ```
    In `registerBuildSourceTools` (`lego/backend/internal/apps/build_sources_graphql.go:361-365`), MCP `create_build_source` populates `OwnerID: core.NamedWorkspace(ctx)`, which is `""` whenever the caller omits optional `workspaceId`. Because line 252 guards on `req.OwnerID != ""` instead of resolving the acting workspace with `s.Tenant(ctx)`, the check is skipped completely on default-workspace MCP calls (and any other caller that leaves `req.OwnerID` empty).
  - `buildSourcePatch` (`lego/backend/internal/apps/build_sources.go:789-794`):
    ```go
    if img := req.Image; img != nil {
        if img.ImageURL == "" && !imageBacked { ... }
        patch.Image, patch.RegistryCredentialID = opt(img.ImageURL), img.RegistryCredentialID
    }
    ```
    `img.OwnerID` is never inspected on update, so REST `PATCH`, GraphQL `updateBuildSource`, and MCP `update_build_source` all silently accept arbitrary mismatched `image.ownerId` values.
- **Fix:**
  - In `CreateBuildSource` (`lego/backend/internal/apps/build_sources.go:252`), compare `req.Image.OwnerID` against the resolved acting workspace (`tenantID, _ := s.Tenant(ctx); effectiveOwner := cmp.Or(req.OwnerID, tenantID)`): refuse when `req.Image.OwnerID != "" && effectiveOwner != "" && req.Image.OwnerID != effectiveOwner` with `core.ErrBadRequest` (`image.ownerId must be the build source's ownerId`).
  - In `buildSourcePatch` (`lego/backend/internal/apps/build_sources.go:789-794`), check `if owner := a.Labels[core.LabelTenant]; img.OwnerID != "" && owner != "" && img.OwnerID != owner` and return `fmt.Errorf("%w: image.ownerId must be the build source's ownerId", core.ErrBadRequest)` (also covers switching a git build source to an image build source with a mismatched `image.ownerId`).
  - Applies uniformly across MCP, REST, and GraphQL; no change for callers that omit `image.ownerId` or supply the matching workspace ID.
