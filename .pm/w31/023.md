# 023 — MCP `set_sandbox_group_environment` rejects `environmentId: null`, contradicting its own schema description and GraphQL `setSandboxGroupEnvironment`

Why: `set_sandbox_group_environment`'s JSON Schema description explicitly instructs callers to `"omit it or pass null to take the group out of its environment"` (and `w22/m603` specified `null` clears on both GraphQL and MCP), but `setGroupEnvironmentArgs.EnvironmentID` is typed `string` instead of `*string`, so the MCP SDK rejects `{"environmentId": null}` with a type error while GraphQL `setSandboxGroupEnvironment(id, environmentId: null)` succeeds.

- **Root cause:**
