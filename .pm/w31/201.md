# 201 — `router.Service.{Create,Update,Delete}` omit `WithDeferredAllowedWriteAudit`, recording `"status": "success"` audit rows on `403 FORBIDDEN` non-beta, non-session, invalid-name, and not-found refusals

Why: `router.Service.Create` (`lego/backend/internal/router/service.go:166`), `Update` (`:187`), and `Delete` (`:219`) — backing GraphQL `Mutation.createRouterKey`, `Mutation.updateRouterKey`, and `Mutation.deleteRouterKey` — call `s.Authorize(ctx, core.RelCanManageKeys)` without `core.WithDeferredAllowedWriteAudit(ctx)` before `s.requireEnabled(ctx)` (which refuses every workspace outside `BetaWorkspace` with `403 FORBIDDEN`), before name validation (`len(name) == 0 || len(name) > 200`), before `s.call`'s session-only check (`identity.Method != "session"`), and before `Update`/`Delete`'s key-existence and upstream calls. Every refused router mutation on a non-beta workspace (or via an API key, invalid name, unknown key ID, or upstream error) therefore writes a bogus `"status": "success"` (`router.Create`, `router.Update`, `router.Delete`) row into the workspace's audit log.

- **Root cause:**
  - `lego/backend/internal/router/service.go:165-184` (`Create`), `:186-216` (`Update`), and `:218-240` (`Delete`) each call `s.Authorize(ctx, core.RelCanManageKeys)` without `core.WithDeferredAllowedWriteAudit(ctx)` at `:166`, `:187`, and `:219`. Because `RelCanManageKeys` is in `core.writeRelations` (`core/audit.go:1717`), `Authorize` immediately emits an `AuditAllowed` (`"status": "success"`) row before `s.requireEnabled(ctx)`, name-length checks, `s.call`'s `identity.Method != "session"` gate, key-existence checks, or the upstream HTTP mutation run.
- **Fix:**
  - In `router.Service.{Create,Update,Delete}` (`lego/backend/internal/router/service.go:166,187,219`), pass `core.WithDeferredAllowedWriteAudit(ctx)` to `s.Authorize(ctx, core.RelCanManageKeys)` so denied OpenFGA checks still record denied rows while allowed checks emit nothing until the upstream mutation succeeds.
  - After the upstream `s.call` mutation returns `nil` (and `data.Value` succeeds), emit the canonical allowed-write row via `s.RecordAllowedWrite(ctx, "router.Create"|"router.Update"|"router.Delete", core.RelCanManageKeys, tenant, "", "")` (or target `keyID` where non-secret).
  - Surface impact: GraphQL-only (`router` is not exposed on REST or MCP); aligns with every other deferred-write service in `lego/backend/internal/`.
