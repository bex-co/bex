# 176 — `postgres.Service.AcknowledgeUpgrade` and `postgres.Service.ExecuteQuery` (`allowWrites: true`) omit `WithDeferredAllowedWriteAudit`, recording `"status": "success"` audit-log rows on `400`/`404`/`409` refusals across REST and GraphQL

Why: `postgres.Service.AcknowledgeUpgrade` (`lego/backend/internal/postgres/upgrade_run.go:174-202`, added in `w3/m676`) and `postgres.Service.ExecuteQuery` when `allowWrites: true` (`lego/backend/internal/postgres/query.go:160-195`) call `s.fetchLiveDatabase(ctx, core.RelCanCreate, ...)` without `core.WithDeferredAllowedWriteAudit(ctx)` — so calls rejected after authorization (`404 POSTGRES_UPGRADE_RUN_NOT_FOUND`, `409 POSTGRES_UPGRADE_RUN_IN_PROGRESS`, `400 sql is required`, `400` SQL/syntax/timeout errors, `403` protected-environment refusal) and idempotent already-acknowledged no-ops immediately write false `"status": "success"` rows into `/v1/owners/{ownerId}/audit-logs`.
