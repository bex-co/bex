# 057 — `resolveTierForType` and `checkPlan` never reject paid compute plans on `static_site`, so MCP `update_service`, REST `POST`/`PATCH /v1/services`, and GraphQL `createService`/`updateServicePlan` accept `starter`–`pro_max` on static sites

Why: Static sites have no compute plan on Render (`staticSiteDetailsPOST`, `staticSiteDetailsPATCH`, and `staticSiteDetails` in `render-public-api-1.json` define no `plan` field, and bex's Blueprint schema rejects `plan` on `runtime: static`), yet `resolveTierForType` (`lego/backend/internal/apps/service.go:4382-4394`) and `checkPlan` (`lego/backend/internal/apps/settings_check.go:554-587`) only reject `free` on paid-only types and never reject paid compute plans (`starter`, `standard`, `pro`, `pro_plus`, `pro_max`) on `static_site` — allowing callers to set a paid compute plan on a static site, write `spec.tier = starter`, trigger `RequirePlanBilling`, and emit bogus `plan_changed` audit/webhook events.

### Static sites accept paid compute plans (`starter`, `standard`, `pro`, `pro_plus`, `pro_max`) across MCP, REST, and GraphQL

- **Expected / actual:**
  - **Expected:** Matching Render's pinned OpenAPI spec (`lego/backend/internal/api/openapi/render-public-api-1.json`, where `staticSiteDetailsPOST`, `staticSiteDetailsPATCH`, and `staticSiteDetails` have no `plan` property at all), Render's pricing model (static sites run no compute instance and have no compute plan), bex's Blueprint schema (`validate_bex_yml` rejects `plan` on `runtime: static`), and sibling type-applicability guards on `static_site` (`healthCheckPath`, `port`, `maxShutdownDelaySeconds`, `maintenanceMode`, `autoscaling`, `disk`, `startCommand`, `preDeployCommand`), setting a paid compute plan (or changing the plan) on a `static_site` must fail with `400 bad request` naming `static_site` (e.g. `plan is not applicable to a static_site; static sites are always free and have no compute plan`). Omitting `plan` (or passing `plan: "free"` if compatibility callers echo readback `"free"`) remains accepted on create/no-op.
  - **Actual:** All five live create/update endpoints returned `200 OK` with `"type": "static_site"` and `"plan": "starter"` (`serviceDetails.plan: "starter"`), while Blueprint `validate_bex_yml` rejected `plan: starter` with `BLUEPRINT_SCHEMA_INVALID: at '/services/0': additional properties 'plan' not allowed`.

- **Attribution:** server (`lego/backend/internal/apps`)
- **Root cause:**
  - `resolveTierForType` (`lego/backend/internal/apps/service.go:4382-4394`, called by `normalizeTierForType` → `specFromCreate` on `Create`) skips the paid default when `plan == "" && svcType == appv1alpha1.TypeStaticSite`, but when a non-empty paid `plan` is supplied it normalizes it via `normalizeTierOrPlan(plan)` and only checks `paidOnlyServiceType(svcType) && !core.PaidPlan(tier)` — never rejecting `svcType == appv1alpha1.TypeStaticSite && core.PaidPlan(tier)`.
  - `checkPlan` (`lego/backend/internal/apps/settings_check.go:554-587`, called by `SetPlan` and `ApplyServicePatch` / `ApplyServicePatchDryRun`) similarly only checks `paidOnlyServiceType(a.Spec.Type) && !core.PaidPlan(tier)` and never checks `a.Spec.Type == appv1alpha1.TypeStaticSite`.
  - Without `dryRun`, `SetPlan` (`lego/backend/internal/apps/service.go:4934-4987`) persists `spec.tier = starter` on the `static_site` CR, calls `RequirePlanBilling`, and emits a `plan_changed` audit event/webhook (`free → starter`).
- **Fix:**
  - In `resolveTierForType` (`lego/backend/internal/apps/service.go:4382-4394`): when `svcType == appv1alpha1.TypeStaticSite`, reject any paid plan (`core.PaidPlan(tier)`, or any non-empty plan other than `"free"` if readback compatibility requires accepting `"free"` — verify whether `readback_resend_test.go` echoes `"free"` on `static_site`) with `fmt.Errorf("%w: plan is not applicable to a static_site; static sites have no compute plan", core.ErrBadRequest)`.
  - In `checkPlan` (`lego/backend/internal/apps/settings_check.go:554-587`): before tier/billing checks, when `a.Spec.Type == appv1alpha1.TypeStaticSite`, refuse any paid plan (or any plan change away from `"free"`, keeping no-op `"free"` allowed only if `readback_resend_test.go` depends on it) with the same `core.ErrBadRequest` message. Also ensure `errUnknownPlanForType(appv1alpha1.TypeStaticSite, ...)` does not suggest `starter|standard|...` for static sites.
  - Check `apps/readback_resend_test.go` and `apps/plan_default_test.go` so readback-echo and default-tier tests stay consistent.
  - Surface impact: fixes MCP (`update_service`), REST (`POST /v1/services`, `PATCH /v1/services/{id}`), and GraphQL (`createService`, `updateServicePlan`) together through `apps.Service`.
- **Blast radius:** `lego/backend/internal/apps/service.go` (`resolveTierForType`, `errUnknownPlanForType`), `lego/backend/internal/apps/settings_check.go` (`checkPlan`), and `lego/backend/internal/apps/*_test.go`. Affects only `TypeStaticSite` requests that explicitly specify a paid/non-free plan.
