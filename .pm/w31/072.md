# 072 — `apps.Service.UpdateBuildSource` silently ignores empty-string clears on optional Git fields and marks `source-pending` on no-op or rename-only updates across MCP, REST, and GraphQL

Why: `BuildSourceGit` (`lego/backend/internal/apps/build_sources.go:82-93`) declares optional Git settings as non-pointer `string` fields and `buildSourcePatch` (`build_sources.go:768-788`) collapses `""` to `nil` (`opt`), making it impossible to clear `rootDir`, `dockerfilePath`, `dockerContext`, `buildCommand`, or `branch` once set; in addition, `UpdateBuildSource` (`build_sources.go:648-654,691`) checks `name == ""` instead of `name == "" || name == buildSourceName(a)` and calls `markSourcePending` + records `AuditVerbSetSourceAndRegistryCredential` even on a no-op or pure rename.

### `update_build_source` / `PATCH /v1/build-sources/{id}` / GraphQL `updateBuildSource` cannot clear optional Git fields and falsely dirty `source-pending` / `updatedAt` on no-op or rename-only calls

- **Attribution:** server (`lego/backend/internal/apps/{build_sources,build_sources_graphql}.go`)
- **Root cause:**
  - `UpdateBuildSourceRequest` (`lego/backend/internal/apps/build_sources.go:141-145`) reuses `BuildSourceGit` (`build_sources.go:82-93`, whose fields are plain `string`s) for patch input, and `buildSourcePatch` (`build_sources.go:768-788`) converts `""` to `nil` via `opt(v)`, erasing the distinction between "omitted" and "set to empty string".
  - In `UpdateBuildSource` (`lego/backend/internal/apps/build_sources.go:648-654`), the no-op check tests `name == ""` (always false whenever `req.Name != nil`, even if `name == buildSourceName(a)`), and `markSourcePending(ctx, a)` + `AuditVerbSetSourceAndRegistryCredential` (`:652,:691`) run unconditionally whenever `nameChanged` is true, even when `!sourceChanged && equalBuildSettings(probe.Spec, a.Spec)`.
- **Fix:**
  - Introduce a pointer-field patch struct (e.g. `BuildSourceGitPatch` with `*string` for `RepoURL`, `Branch`, `BuildCommand`, `DockerContext`, `DockerfilePath`, `Runtime`, `Region`, `RootDir`, `RegistryCredentialID`, and `*BuildFilterView` for `BuildFilter`) for `UpdateBuildSourceRequest.Git`, wired across MCP (`updateBuildSourceArgs`), REST (`PATCH /v1/build-sources/{id}`), and GraphQL (`updateBuildSource` via `gqlutil.StrPtr`), so `nil` = keep and `""` = clear/restore default (handling `branch: ""` and `dockerfilePath: ""` / `rootDir: ""` / `dockerContext: ""` / `buildCommand: ""` identically to `ServicePatch`).
  - In `UpdateBuildSource` (`apps/build_sources.go:648-693`):
    - Compute `nameChanged := name != "" && name != buildSourceName(a)` and `buildChanged := sourceChanged || !equalBuildSettings(probe.Spec, a.Spec)`.
    - Return early with `s.buildSourceView(ctx, a)` when `!nameChanged && !buildChanged`.
    - Call `s.markSourcePending(ctx, a)` only when `buildChanged` is true, and record `AuditVerbSetDisplayName` (or skip `SetSourceAndRegistryCredential`) when only `nameChanged` is true.
