# 166 — `postgres.normalizeQueryValue` and `queryCellString` corrupt `macaddr`/`macaddr8`/`xml` to base64 strings, leak raw `pgtype` Go structs for `time`/`interval`/`bit`/`varbit`/`tsvector`/`tid`, and double-quote `inet`/`cidr` in GraphQL

Why: `lego/backend/internal/postgres/query_values.go:159-206` (`normalizeQueryValue`) and `query.go:351-369` (`queryRowValues`) omit several built-in PostgreSQL types whose `pgx/v5` (`v5.11.0`) decoded values do not JSON-marshal truthfully: `macaddr`/`macaddr8` decode to `net.HardwareAddr` (a named `[]byte` with `.String()` and no `MarshalJSON`) and `xml` decodes to `[]byte`, causing MCP `query_render_postgres` (a shared Render MCP tool), REST `POST /v1/postgres/{id}/query`, and GraphQL `executeDatabaseQuery` to corrupt human-readable MAC addresses (`08:00:2b:01:02:03`) and XML (`<root>hi</root>`) into base64 strings (`"CAArAQID"`, `"PHJvb3Q+aGk8L3Jvb3Q+"`); meanwhile `time`, `interval`, `bit`/`varbit`, `tsvector`, and `tid` leak raw internal `pgtype.*` Go structs (`{"Microseconds":45296789000,"Valid":true}`, `{"Bytes":"qA==","Len":5,"Valid":true}`, etc.), and `queryCellString` (`lego/backend/internal/postgres/graphql.go:521-543`) wraps `netip.Prefix` (`inet`/`cidr`) in extra literal double quotes (`"\"192.168.1.1/24\""`) in GraphQL SQL console cells.

- **Attribution:** server (`lego/backend/internal/postgres`)
- **Root cause:**
  - `lego/backend/internal/postgres/query_values.go:159-206` (`normalizeQueryValue`) handles only `float64`, `float32`, `pgtype.Numeric`, `pgtype.InfinityModifier`, `[16]byte`, `time.Time`, and `[]any`:
    1. `pgtype.MacaddrCodec` (`macaddr`, `macaddr8`) decodes to `net.HardwareAddr` (whose underlying type is `[]byte`), which implements `fmt.Stringer` (`"08:00:2b:01:02:03"`) but not `json.Marshaler`, so `encoding/json` base64-encodes the raw bytes.
    2. `pgtype.XMLCodec` (`xml` OID 142, `_xml` OID 143) decodes XML text to `[]byte`, making it indistinguishable from binary `bytea` once decoded — so `encoding/json` and `queryCellString`'s `case []byte:` base64-encode the XML document.
    3. `pgtype.Time`, `pgtype.Interval`, `pgtype.Bits`, `pgtype.TSVector`, and `pgtype.TID` have no `MarshalJSON` method, so `encoding/json` serializes their exported Go struct fields (including `"Valid": true`).
  - `lego/backend/internal/postgres/graphql.go:521-543` (`queryCellString`) only unwraps `string`, `[]byte`, and `time.Time` before `json.NewEncoder`, so any `encoding.TextMarshaler` such as `netip.Prefix` (`inet`/`cidr`) is JSON-string-encoded and gains literal surrounding quotes in tabular GraphQL string cells.

  - In `normalizeQueryValue` (`lego/backend/internal/postgres/query_values.go:159-206`):
    - Add `case net.HardwareAddr:` → `v.String()` (preserving nil as nil).
