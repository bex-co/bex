# 211 — `agentsessions.Service.AttachTicket` returns unwrapped `fmt.Errorf` (`500 Internal Server Error`) on invalid `action` across MCP, REST, and GraphQL, and both `AttachTicket` and `CreateShellSession` omit uncached `AuthorizeFreshOn` before minting bearer tickets

Why: `agentsessions.Service.AttachTicket` (`lego/backend/internal/agentsessions/service.go:2344-2346`) rejects an unknown `action` with bare `fmt.Errorf("invalid action: must be 'read' or 'turn'")` without wrapping `core.ErrBadRequest` (and MCP `attach_agent_session` at `lego/backend/internal/agentsessions/mcp.go:352` declares no JSON Schema `enum` on `action`), turning bad caller input into a `500` internal server error across MCP, REST, and GraphQL; in addition, both `AttachTicket` (`service.go:2335`) and `CreateShellSession` (`lego/backend/internal/agentsessions/terminal.go:87`) authorize solely via cached `s.AuthorizeOn` without calling uncached `s.AuthorizeFreshOn` before reading session state and signing bearer stream/shell tickets, diverging from sibling `agentsessions.SSHResolver.ResolveSSHSession` (`ssh.go:65-70`, `codex round-7 F7`).

- **Fix:**

  - In `lego/backend/internal/agentsessions/service.go:2335` (`AttachTicket`), add `if err := s.AuthorizeFreshOn(ctx, relation, sessionObject(sessionID)); err != nil { return View{}, err }` immediately after `s.AuthorizeOn`.
  - In `lego/backend/internal/agentsessions/terminal.go:87` (`CreateShellSession`), add `if err := s.AuthorizeFreshOn(ctx, core.RelCanViewSensitive, sessionObject(sessionID)); err != nil { return ShellSessionView{}, err }` immediately after `s.AuthorizeOn`.
