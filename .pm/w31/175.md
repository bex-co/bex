# 175 — `registrycreds.Service.resolvePullCredential` uses unscoped `GetRegistryCredentialByID` and returns `403` vs `404`, creating a cross-tenant registry-credential existence oracle across MCP, REST, and GraphQL

Why: Unlike `registrycreds.Service.Get` (`lego/backend/internal/registrycreds/service.go:208`) and `registrycreds.Service.IsDeployableImage` (`lego/backend/internal/registrycreds/imagecheck.go:61`), which scope lookups by `workspaceID` and return `404 Not Found` for both nonexistent and foreign-workspace IDs, `registrycreds.Service.resolvePullCredential` (`lego/backend/internal/registrycreds/pullsecret.go:91-100`) calls unscoped `GetRegistryCredentialByID` and returns `404 NOT_FOUND` (`registry credential "<id>" not found`) when the ID does not exist versus `403 FORBIDDEN` (`registry credential "<id>" does not belong to the target workspace`) when it belongs to another workspace — giving any caller with `services: read_write` (even zero `workspaces: read` permission, and even on `dryRun: true`) a cross-tenant existence oracle across MCP `update_service` / `create_web_service` / `create_cron_job` / `create_build_source` / `update_build_source`, REST, and GraphQL.

### `resolvePullCredential` leaks cross-tenant registry credential existence (`403` vs `404`) and is reachable by `services: read_write`-only keys on `dryRun: true`

- **Severity:** major
- **Versions:** deployed pin `d465649ee4` (`546d61ac7343`, active on production during run; zero diff in `lego/backend/internal/registrycreds/pullsecret.go` vs `origin/main` `4dc55fa274`); `serverInfo`: `bex 0.1.0`; negotiated MCP protocol: `2025-06-18`; Render MCP pin: `render-oss/render-mcp-server@a18ef3ee866716933710fa5054323fd5c1ed0eb1`
- **Context:** 2026-11-27, endpoints `/mcp` (`https://api.bex.co/mcp`), REST `/v1/services`, and `/graphql`, workspace `bex-canary` (`tea-daif693dqjvc73e7as3g`), disposable free web service `srv-dc4t82avp92c739idjb0` (deleted and confirmed `404` after run), run-minted `services: read_write`-only scoped API key (zero `workspaces` grant, revoked after run)
- **Repro:**
  ```sh
  # 1. Control — with a services: read_write-only key (no workspaces: read), direct registry
  #    credential listing is refused with api_key_permission_denied:
  python3 scripts/qa-mcp.py --key-file <key-svc-rw.json> call list_registry_credentials '{}'

  # 2. Oracle probe — call update_service (dryRun: true) with a nonexistent rgc-... ID vs
  #    a foreign-workspace rgc-... ID:
  python3 scripts/qa-mcp.py --key-file <key-svc-rw.json> call update_service \
    '{"serviceId":"<srv-id>","registryCredentialId":"rgc-00000000000000000000","dryRun":true}'
  # -> NOT_FOUND: registry credential "rgc-00000000000000000000" not found (pullsecret.go:96)
  # With an rgc-... belonging to another workspace (pullsecret.go:99-100):
  # -> FORBIDDEN: registry credential "<foreign-rgc>" does not belong to the target workspace
  ```
- **Expected / actual:**
  - **Expected:** Matching `registrycreds.Service.Get` (`service.go:208`), `registrycreds.Service.IsDeployableImage` (`imagecheck.go:61`, pinned by commit `8428d9dc67`), and bex's cross-workspace non-disclosure invariant (ADR028 / ADR072 / `TestCrossWorkspaceMCPMatrix`), a `registryCredentialId` that does not exist in `workspaceID` — whether nonexistent or owned by another tenant — must return the identical `404 NOT_FOUND` (`registry credential "<id>" not found`) with zero status or message distinction.
  - **Actual:**
    - Nonexistent `rgc-00000000000000000000` returned `NOT_FOUND: registry credential "rgc-00000000000000000000" not found` even on a `services: read_write`-only key (zero `workspaces: read`) via `update_service(..., dryRun: true)`.
    - In `lego/backend/internal/registrycreds/pullsecret.go:91-100`, `s.Store.GetRegistryCredentialByID(ctx, id)` fetches across all workspaces and branches on `case cred.WorkspaceID != workspaceID:` to return `core.ErrForbidden` (`registry credential "<id>" does not belong to the target workspace`), creating a distinct `403` oracle for every foreign-tenant `rgc-…` ID.
- **Wire evidence:**
  - Control MCP `list_registry_credentials` (`key-svc-rw.json`, `rndr-id: 266007db-daa6-495f`) → `200`, `isError: true`: `"api_key_permission_denied: this API key is not granted the permission this request needs: View registry credentials"`.
  - Probe MCP `update_service` with `registryCredentialId: "rgc-00000000000000000000", dryRun: true` (`key-svc-rw.json`, `rndr-id: ebcad84d-884b-0d64`) → `200`, `isError: true`: `"NOT_FOUND: registry credential \"rgc-00000000000000000000\" not found"`.
  - Source verification of the `403` vs `404` split: `lego/backend/internal/registrycreds/pullsecret.go:91-100` (`GetRegistryCredentialByID` + `case cred.WorkspaceID != workspaceID: core.ErrForbidden`), contrasted with `lego/backend/internal/registrycreds/service.go:208` and `imagecheck.go:61` (`GetRegistryCredential(ctx, workspace, id)` → `404`).
- **Attribution:** server (`lego/backend/internal/registrycreds`)
- **Root cause:**
  - `lego/backend/internal/registrycreds/pullsecret.go:91-100`: `resolvePullCredential` queries `s.Store.GetRegistryCredentialByID(ctx, id)` instead of workspace-scoped `s.Store.GetRegistryCredential(ctx, workspaceID, id)`, then explicitly returns `core.ErrForbidden` ("does not belong to the target workspace") on `cred.WorkspaceID != workspaceID` while returning `core.NotFound` on `store.ErrNotFound`.
  - `w8/done/354.md` explicitly left that pre-existing `403` branch untouched while rewording the `404` branch; meanwhile `imagecheck.go:61` (`w1/m673`, `8428d9dc67`) subsequently adopted workspace-scoped `GetRegistryCredential` so foreign credentials return `404` identically to nonexistent ones.
- **Fix:**
  - In `lego/backend/internal/registrycreds/pullsecret.go:91-100`, replace `s.Store.GetRegistryCredentialByID(ctx, id)` and the `cred.WorkspaceID != workspaceID` `ErrForbidden` branch with workspace-scoped `s.Store.GetRegistryCredential(ctx, workspaceID, id)`, mapping `store.ErrNotFound` to `core.NotFound(fmt.Sprintf("registry credential %q", id))` so nonexistent and foreign-workspace IDs produce the exact same `404 NOT_FOUND` across MCP, REST, and GraphQL (`create_web_service`, `create_cron_job`, `update_service`, `create_build_source`, `update_build_source`, `POST/PATCH /v1/services`, `setImage`, `setRegistryCredential`, and deploy-time pull-secret resolution).
  - Update `lego/backend/internal/registrycreds/pullsecret_test.go` (and any `apps` test asserting `ErrForbidden` on a foreign `registryCredentialId`) to assert `core.ErrNotFound` and indistinguishable error text between unknown and foreign-workspace IDs.
  - Also review whether binding a `registryCredentialId` on a service or build source with a scoped API key should require `core.KeyWorkspaceRegistry` (`workspaces: read`) or remain allowed under `services: read_write` / `build_sources: read_write` (at minimum, removing the `403` branch eliminates the cross-tenant oracle).
- **Blast radius:** `lego/backend/internal/registrycreds/pullsecret.go`, `lego/backend/internal/registrycreds/pullsecret_test.go`, and callers in `lego/backend/internal/apps/` and `lego/backend/internal/deploys/`.
