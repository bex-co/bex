# 112 — `sandbox.NormalizeCredentialDomain` and `sessionegress` host validators accept non-canonical hex/octal/shorthand IPv4 literals (`127.0.0.0x1`, `169.254.169.0xfe`, `0177.0.0.0x1`)

Why: `sandbox.NormalizeCredentialDomain` (`lego/backend/internal/sandbox/credentials_validate.go:126-161`) relies on `net.ParseIP` plus an all-digits TLD check that misses hex final-octet IPv4 literals (`127.0.0.0x1`, `169.254.169.0xfe`, `0177.0.0.0x1`), while `sessionegress.ExtraDestinations` (`lego/backend/internal/sessionegress/policy.go:191-196`), `ModelEndpointHost` (`:286-288`), and `SandboxAllowList` (`lego/backend/internal/sessionegress/sandbox.go:101-106`) rely solely on `net.ParseIP` with no numeric-TLD check at all — allowing non-canonical loopback and cloud-metadata IPv4 literals to pass API validation across MCP, REST, and GraphQL.

### Sandbox credential `domain` and session-egress host allowlists accept non-canonical hex/octal/shorthand IPv4 literals

- **Expected vs Actual:**
  - **Expected:** Per `NormalizeCredentialDomain`'s own contract (`credentials_validate.go:113-114,147`: `"Must be a public multi-label DNS hostname; rejects IP literals ... Reject all-numeric TLDs (catches non-standard numeric IPv4 forms)"`) and `sessionegress`'s host validators (`policy.go:171,191`, `sandbox.go:79,101`: `"IP literals are not supported"`), all non-canonical `inet_aton`/WHATWG-URL IPv4 forms — shorthand (`127.1`), octal (`0177.0.0.1`), hex (`0x7f.0.0.1`, `127.0.0.0x1`, `169.254.169.0xfe`, `0177.0.0.0x1`, `0x7f.0x0.0x0.0x1`), and any hostname with a non-alphabetic/hex-numeric final label — must be rejected with `400` (`SANDBOX_CREDENTIAL_INVALID` / `AGENT_SESSION_EGRESS_ALLOWLIST_INVALID` / `SANDBOX_NETWORK_POLICY_INVALID`) across MCP, REST, and GraphQL.
  - **Actual:** MCP (`127.0.0.0x1`), REST (`169.254.169.0xfe`), and GraphQL (`0177.0.0.0x1`) all returned `200`/`201` and persisted the non-canonical IPv4 literals as credential `domain` values.
- **Evidence:**
  - `POST /mcp` `create_sandbox_group_credential` (`domain: "127.0.0.0x1"`, `rndr-id: 6be6b037-820d-2b46`) → `200`, `{"domain":"127.0.0.0x1","id":"qa-cred-ip",...}`.
  - `POST /v1/sandbox-groups/sbg-dc4a5d4dplss73eg6070/credentials` (`domain: "169.254.169.0xfe"`, `rndr-id: 240db7bc-160a-df11`) → `201`, `{"id":"qa-cred-imds","domain":"169.254.169.0xfe",...}`.
  - `POST /graphql` `createSandboxGroupCredential` (`domain: "0177.0.0.0x1"`, `rndr-id: 75419f70-dc54-5529`) → `200`, `{"data":{"createSandboxGroupCredential":{"domain":"0177.0.0.0x1","id":"qa-cred-oct"}}}`.
- **Root cause (researched):**
  - `lego/backend/internal/sandbox/credentials_validate.go:126-161`: `net.ParseIP` returns `nil` for non-canonical IPv4 forms in Go; `credentialDomainPattern` and `validation.IsDNS1123Subdomain` allow `0x1`/`0xfe` labels; and `isPrivateOrNonPublicCredentialHost` (`:148-160`) only rejects TLDs where every byte is `'0'..'9'`, so a hex-prefixed final octet (`0x1`, `0xfe`) bypasses it completely.
  - `lego/backend/internal/sessionegress/policy.go:191-196` (`ExtraDestinations`, backing `update_agent_environment` `customHosts`), `:286-288` (`ModelEndpointHost`), and `lego/backend/internal/sessionegress/sandbox.go:101-106` (`SandboxAllowList`, backing sandbox `networkPolicy.rules`) do not even have an all-digits TLD check, so `127.1`, `0177.0.0.1`, `127.0.0.0x1`, and `169.254.169.0xfe` all pass `net.ParseIP(host) == nil` and `IsDNS1123Subdomain`.
- **Fix direction:**
  - Extract one shared public-DNS-hostname check (e.g., in `sessionegress` or `netutil`, and coordinate with `w31/105`'s fix for `apps.validatePublicRewriteHost`) that enforces RFC 1123 / RFC 3696 §2 TLD rules and rejects all `inet_aton` / WHATWG-URL IPv4 forms: reject any host whose final label is not an alphabetic DNS TLD (or valid Punycode `xn--...`) — specifically rejecting all-numeric TLDs and hex-literal labels (`0x...`) as well as any host where every dot-separated label parses as a decimal, octal, or hex integer.
  - Apply it uniformly in `sandbox.NormalizeCredentialDomain` (`credentials_validate.go:126-161`), `sessionegress.ExtraDestinations` (`policy.go:191-196`), `sessionegress.ModelEndpointHost` (`policy.go:286-288`), and `sessionegress.SandboxAllowList` (`sandbox.go:101-106`).
  - Surface impact: protects MCP, REST, and GraphQL for sandbox group credentials, agent environment `customHosts`, and sandbox `allow-list` network policies.
- **Blast radius:** `lego/backend/internal/sandbox/credentials_validate.go`, `lego/backend/internal/sessionegress/policy.go`, `lego/backend/internal/sessionegress/sandbox.go`, and their unit tests (`credentials_test.go`, `policy_test.go`, `sandbox_test.go`). Valid public DNS hostnames always have an alphabetic (or `xn--`) TLD per ICANN/RFC 3696, so no legitimate public domain is rejected.
