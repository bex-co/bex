# 130 — `apps.Service.SetPort` unconditionally stamps `spec.restartedAt`, triggers a live `settings_change` deploy, and writes `apps.SetPort` audit rows on no-op same-port updates across MCP, REST, and GraphQL

Why: `apps.Service.SetPort` (`lego/backend/internal/apps/service.go:5993-6017`) only short-circuits clearing an already-unset image port (`!appv1alpha1.IsConfiguredPortMode(mode)` at `:6003`), so sending a service's already-configured port via MCP `update_service`, REST `PATCH /v1/services/{id}`, or GraphQL `setPort` still writes Postgres, bumps `updatedAt`, stamps `spec.restartedAt`, triggers a live `settings_change` rollout on GraphQL (and marks `undeployedChanges` on save-only MCP/REST patches), and emits bogus `apps.SetPort` audit rows.

- **Attribution:** server (`lego/backend/internal/apps`)
- **Root cause:**
  - `lego/backend/internal/apps/service.go:6002-6015`: `SetPort` only checks `if mode == a.Spec.PortMode && port == appv1alpha1.DefaultPort && !appv1alpha1.IsConfiguredPortMode(mode) { return s.view(a), nil }`. When `port` is non-zero and already matches the service's current stored port and `PortMode` (e.g., `port == a.Spec.Port && mode == a.Spec.PortMode`, or `a.Spec.Port == 0 && port == appv1alpha1.DefaultPort && mode == a.Spec.PortMode`), execution falls through to `writeThroughStoreFetched` (`:6006`), stamps `a.Spec.RestartedAt = s.Now().UTC().Format(time.RFC3339)` (`:6010`), rolls the service (under GraphQL) or marks `undeployedChanges` (under save-only REST/MCP), and calls `s.RecordAppConfigChanged(ctx, a, core.AuditVerbSetPort)` (`:6015`).
- **Fix:**
  - In `lego/backend/internal/apps/service.go:6002-6005`, generalize the no-op guard to return `s.view(a), nil` whenever `mode == a.Spec.PortMode` and the effective stored port is unchanged (`port == a.Spec.Port || (a.Spec.Port == 0 && port == appv1alpha1.DefaultPort)`).
  - Verify that transitioning an unconfigured image-port service (`web-image-v1` → `web-image-configured-v1`, or `image-v1` → `image-configured-v1`) STILL writes because `mode != a.Spec.PortMode`.
  - Surface impact: fixes MCP (`update_service`), REST (`PATCH /v1/services/{id}`), and GraphQL (`setPort`) together through the shared `apps.Service.SetPort` verb.
