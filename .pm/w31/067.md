# 067 — `/mcp/cloud-agents` returns tool-execution result `isError: true` instead of JSON-RPC protocol error `-32602` on disallowed and nonexistent tool names

Why: `mcpToolsetMiddleware` (`lego/backend/internal/api/mcp_workspace.go:308-314`, mounted outermost on `/mcp/cloud-agents` at `lego/backend/internal/api/server.go:2455`) intercepts every `tools/call` outside its 41-tool allowlist and returns `mcpCallError(ctx, ...), nil` (a JSON-RPC `200` `result` with `isError: true`) instead of a JSON-RPC `-32602` (`Invalid params`) protocol error, breaking the MCP 2025-06-18 protocol-vs-tool error boundary and diverging from `/mcp` for both out-of-toolset and completely nonexistent tool names.

### Unknown or disallowed `tools/call` names on `/mcp/cloud-agents` return `result.isError: true` instead of JSON-RPC `-32602`

- **Severity:** major
- **Versions:** deployed pin `043827a8e8` (`2bd6e1f415d3`, active on production during run; zero diff in `lego/backend/internal/api/{mcp_workspace,server}.go` vs `origin/main` `83c62b4309`); `serverInfo`: `bex 0.1.0`; negotiated MCP protocol: `2025-06-18`; Render MCP pin: `render-oss/render-mcp-server@a18ef3ee866716933710fa5054323fd5c1ed0eb1`
- **Context:** 2026-11-26, endpoints `/mcp` (`https://api.bex.co/mcp`) and `/mcp/cloud-agents` (`https://api.bex.co/mcp/cloud-agents`), workspace `bex-canary` (`tea-daif693dqjvc73e7as3g`), run-minted all-permissions API key (`57d23571-…`, revoked)
- **Repro:**
  ```sh
  # 1. Control on /mcp — unknown tool returns JSON-RPC protocol error -32602:
  python3 scripts/qa-mcp.py --key-file <key.json> call does_not_exist_r4x9b2 '{}'

  # 2. Bug on /mcp/cloud-agents — identical nonexistent tool name returns JSON-RPC result with isError: true:

  python3 scripts/qa-mcp.py --url https://api.bex.co/mcp/cloud-agents --key-file <key.json> call list_services '{}'
  ```
- **Expected / actual:**
  - **Expected:** Per the MCP 2025-06-18 specification (Tools § Error Handling: unknown tool names are JSON-RPC protocol errors `-32602 Invalid params`, distinct from tool-execution failures `result.isError: true`) and ADR094 D1 ("Both mounts share the auth middleware, rate limiter, workspace binding, scope gate and core error mapping"), calling any tool not exposed on `/mcp/cloud-agents` — whether a nonexistent typo or a `/mcp`-only tool outside the `cloud-agents` toolset — must return a JSON-RPC protocol error with code `-32602` (`"unknown tool \"...\" on this endpoint"` or `"unknown tool \"...\""`), matching `/mcp` (`{"jsonrpc":"2.0","id":…,"error":{"code":-32602,"message":"unknown tool \"...\""}}`), `resources/read` (`-32602`), and `prompts/get` (`-32602`).
  - **Actual:**
    - On `/mcp`, `does_not_exist_r4x9b2` returns JSON-RPC protocol error `{"error":{"code":-32602,"message":"unknown tool \"does_not_exist_r4x9b2\""}}`.
    - On `/mcp/cloud-agents`, both `does_not_exist_r4x9b2` and `list_services` return a JSON-RPC `result` object with `isError: true` (`{"result":{"content":[{"type":"text","text":"unknown tool \"...\" on this endpoint"}],"isError":true}}`).
- **Wire evidence:**
  - Control `POST https://api.bex.co/mcp` (`does_not_exist_r4x9b2`, `rndr-id: 918120d5-f36c-50ca`) → `200`: `{"jsonrpc":"2.0","id":33029408,"error":{"code":-32602,"message":"unknown tool \"does_not_exist_r4x9b2\""}}`.
  - Bug `POST https://api.bex.co/mcp/cloud-agents` (`does_not_exist_r4x9b2`, `rndr-id: 17a32834-1742-6bea`) → `200`: `{"jsonrpc":"2.0","id":411402619,"result":{"content":[{"type":"text","text":"unknown tool \"does_not_exist_r4x9b2\" on this endpoint"}],"isError":true}}`.
  - Bug `POST https://api.bex.co/mcp/cloud-agents` (`list_services`, `rndr-id: a8bf2936-8519-c3e4`) → `200`: `{"jsonrpc":"2.0","id":…,"result":{"content":[{"type":"text","text":"unknown tool \"list_services\" on this endpoint"}],"isError":true}}`.
- **Attribution:** server (`lego/backend/internal/api`)
- **Root cause:**
  - `mcpToolsetMiddleware` (`lego/backend/internal/api/mcp_workspace.go:308-314`) handles `tools/call` names outside `allowed` with:
    ```go
    if _, in := allowed[call.Params.Name]; !in {
        return mcpCallError(ctx, fmt.Errorf("unknown tool %q on this endpoint", call.Params.Name)), nil
    }
    ```
    Returning a `*mcp.CallToolResult` with `nil` error tells `github.com/modelcontextprotocol/go-sdk/mcp` to serialize a JSON-RPC `result` (`isError: true`) rather than a JSON-RPC `error` (`-32602`), whereas `/mcp` lets unknown tool names reach the SDK's dispatcher, which returns `&jsonrpc.Error{Code: jsonrpc.CodeInvalidParams, Message: ...}`.
  - `lego/backend/internal/api/mcp_toolset_test.go:72-90` (`TestCloudAgentsToolsetRefusesToolsOutsideIt`) currently asserts `res.IsError` on `CallTool`, encoding this protocol mismatch.
- **Fix:**
  - In `mcpToolsetMiddleware` (`lego/backend/internal/api/mcp_workspace.go:308-314`), return a JSON-RPC `-32602` error (`nil, &jsonrpc.Error{Code: jsonrpc.CodeInvalidParams, Message: fmt.Sprintf("unknown tool %q on this endpoint", call.Params.Name)}`) instead of `mcpCallError(ctx, ...), nil`. (Verify how `mcpMetricsMiddleware` handles a `nil` result with a `*jsonrpc.Error` — `mcpToolsetMiddleware` is already mounted outermost at `server.go:2455` so out-of-toolset calls intentionally bypass `mcpMetricsMiddleware` and never count as calls.)
  - Update `TestCloudAgentsToolsetRefusesToolsOutsideIt` (`lego/backend/internal/api/mcp_toolset_test.go:72-90`) to assert a JSON-RPC `-32602` error carrying `unknown tool "archive_agent_session" on this endpoint`, and add a wire-level HTTP test asserting both an out-of-toolset tool (`list_services`) and a genuinely nonexistent tool (`does_not_exist`) return `{"error":{"code":-32602,...}}` on `/mcp/cloud-agents`, matching `/mcp`.
  - Surface impact: aligns `/mcp/cloud-agents` (and `api mcp-stdio --toolset cloud-agents`) with `/mcp` and the MCP 2025-06-18 specification; no REST or GraphQL surface exists for MCP toolsets.
- **Blast radius:** `lego/backend/internal/api/mcp_workspace.go`, `lego/backend/internal/api/mcp_toolset_test.go`. Zero impact on allowed `/mcp/cloud-agents` tools or `/mcp`.
