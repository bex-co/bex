# 106 — `webhooks.Service.Update` and `registrycreds.Service.Update` unconditionally write to Postgres and advance `updatedAt` on empty (`{}`) and no-op updates across MCP, REST, and GraphQL

Why: `webhooks.Service.Update` (`lego/backend/internal/webhooks/service.go:959-1020`) and `registrycreds.Service.Update` (`lego/backend/internal/registrycreds/service.go:307-381`) never compare the merged field values against the existing row before calling `s.Store.UpdateWebhookEndpoint` / `s.Store.UpdateRegistryCredential`. As a result, empty `{}` or identical-value patches unconditionally execute an `UPDATE` and bump `updatedAt` on every call across MCP (`update_webhook_endpoint`, `update_registry_credential`), REST (`PATCH /v1/webhooks/{id}`, `PATCH /v1/registrycredentials/{id}`), and GraphQL (`updateWebhookEndpoint`, `updateRegistryCredential`).

- **Attribution:** server (`lego/backend/internal/webhooks`, `lego/backend/internal/registrycreds`)
- **Root cause:**
  - `lego/backend/internal/webhooks/service.go:976-1006`: merges `name`, `dest`, `types`, and `enabled` against `cur`, then unconditionally calls `s.Store.UpdateWebhookEndpoint(...)`, which updates `updated_at = now()` even when all four fields match `cur`.
  - `lego/backend/internal/registrycreds/service.go:323-376`: merges `name`, `username`, and `expiresAt` against `existing`, then unconditionally calls `s.Store.UpdateRegistryCredential(...)` even when `req.Secret == nil` and `name`, `username`, and `expiresAt` are unchanged.
- **Fix:**
  - In `webhooks.Service.Update` (`lego/backend/internal/webhooks/service.go:1005`): after all validation and authorization checks pass, if `name == cur.Name && dest == cur.URL && slices.Equal(types, cur.EventTypes) && enabled == cur.Enabled`, return `toView(cur, s.mayManageWorkspace(ctx, cur.TenantID)), nil` without writing to Postgres.
  - In `registrycreds.Service.Update` (`lego/backend/internal/registrycreds/service.go:363`): after all validation checks pass, if `req.Secret == nil && name == existing.Name && username == existing.Username && timePtrEqual(expiresAt, existing.ExpiresAt)`, return `toView(existing, s.Now()), nil` without writing to Postgres.
  - Surface impact: fixes MCP (`update_webhook_endpoint`, `update_registry_credential`), REST (`PATCH /v1/webhooks/{id}`, `PATCH /v1/registrycredentials/{id}`), and GraphQL (`updateWebhookEndpoint`, `updateRegistryCredential`).
