# 019 — GraphQL `service`, `server`, `services`, and `linkBuildSource` omit `linkedBuildView`, returning `runtime: ""` for build-source-linked services while MCP, REST, and GraphQL `createService` return the build source's runtime

Why: `w3/070` wired `linkedBuildView` into REST service reads, `w3/071` wired it into every MCP service result, and `w2/m612` wired it into GraphQL `createService`, but GraphQL `Query.service`, `Query.server`, `Query.services`, `Mutation.linkBuildSource`, and other GraphQL service-returning mutations still return raw `AppView` without `linkedBuildView` — so GraphQL reads return `runtime: ""` (and blank `buildCommand`/`dockerContext`/`dockerfilePath`), diverging from MCP/REST and hiding the runtime badge and runtime-gated controls in the Dashboard.

### GraphQL `service` / `server` / `services` return `runtime: ""` on a build-source-linked service while MCP and REST return `"image"`

- **Severity:** major
- **Versions:** deployed pin `d8d0713b48` (`9cc529d10432`, active on production during run; zero diff in `lego/backend/internal/apps/{graphql,build_sources_graphql}.go` vs `HEAD` `ac95b51368`); `serverInfo`: `bex 0.1.0`; negotiated MCP protocol: `2025-06-18`; Render MCP pin: `render-oss/render-mcp-server@a18ef3ee866716933710fa5054323fd5c1ed0eb1`
- **Context:** 2026-11-25, endpoints `/mcp` (`https://api.bex.co/mcp`), REST `/v1/services`, and `/graphql` (`https://api.bex.co/graphql`), workspace `bex-canary` (`tea-daif693dqjvc73e7as3g`), run-minted all-permissions API key (revoked); disposable free image web service (`srv-dc3dngh5k4kc73dtagc0`) linked to disposable image Build Source (`bds-dc3dnmtksp0s73b5on20`), both deleted and confirmed `404`

- **Expected / actual:**

  - **Actual:** On `srv-dc3dngh5k4kc73dtagc0` (linked to image Build Source `bds-dc3dnmtksp0s73b5on20`):

- **Attribution:** server (`lego/backend/internal/apps`)
- **Root cause:**
  - `linkBuildSourceSpec` (`lego/backend/internal/apps/build_sources.go:1087-1093`) clears `spec.Runtime`, `spec.BuildCommand`, `spec.DockerContext`, and `spec.DockerfilePath` on the service's `App` CR because the build source carrier holds them.
  - REST (`lego/backend/internal/apps/render.go:765`), MCP (`lego/backend/internal/apps/mcp.go:1228,1245`), and GraphQL `createService` (`lego/backend/internal/apps/graphql.go:1649`) all pass the `AppView` through `s.linkedBuildView(ctx, app, carriers)` (`build_sources.go:1001-1018`) to populate `Runtime`, `BuildCommand`, `DockerContext`, and `DockerfilePath` from the linked build source.
  - GraphQL `Query.services` (`lego/backend/internal/apps/graphql.go:1347-1353`), `Query.server` (`:1355`), `Query.service` (`:1356`), `Mutation.linkBuildSource` (`lego/backend/internal/apps/build_sources_graphql.go:259-268`), and other GraphQL mutations returning `serviceGQLType` call `s.List`/`s.Get`/`s.LinkBuildSource`/etc. directly without `s.linkedBuildView`.
  - Downstream Dashboard impact: `dashboard/src/features/services/components/service-detail-header.tsx:539,954` and `dashboard/src/routes/services.$serviceId.settings.tsx:223,258,273,283` consume `service.runtime` from GraphQL, so an empty `runtime` hides the Runtime badge and misclassifies native vs Docker/image commands on linked services.
- **Fix:**
  - Route GraphQL `Query.services` (paging first, then applying `s.linkedBuildView` with one shared `carriers` map per page so each linked build source is read at most once), `Query.server`, `Query.service`, `Mutation.linkBuildSource`, and every other GraphQL mutation in `lego/backend/internal/apps/graphql.go` returning `serviceGQLType` through `s.linkedBuildView` (or apply `linkedBuildView` at the shared `apps` helper level used by all three adapters, checking that `Service.Get`/`Service.List` callers outside REST/MCP/GraphQL do not break).
  - Verify `dashboard/` components (`service-detail-header.tsx`, `services.$serviceId.settings.tsx`, `service-source-card.tsx`) handle a non-empty `service.runtime` alongside `service.buildSourceId != null` cleanly (especially `settings-sections.ts:66`, which already gates on `Boolean(repo)`).
- **Blast radius:** `lego/backend/internal/apps/graphql.go`, `lego/backend/internal/apps/build_sources_graphql.go`, and tests in `lego/backend/internal/apps/build_sources_test.go` / `build_sources_graphql_test.go`. Affects all GraphQL callers (including the Dashboard and native mobile app) reading or mutating any build-source-linked service.
