# 060 — Scoped `build_sources: read_write` API keys hijack existing services (`serviceIds`), write build-source secrets (`envVars`/`secretFiles`), and link env groups (`envGroupIds`) via `create_build_source` across MCP, REST, and GraphQL

Why: `lego/backend/internal/api/key_permission_ops.go:90,513,1075` maps `MCP create_build_source`, `REST POST /v1/build-sources`, and `GQL Mutation.createBuildSource` solely to `{core.KeyBuildSourcesManage}`, and `apps.Service.CreateBuildSource` (`lego/backend/internal/apps/build_sources.go:207-313`) performs no additional `KeyGrant` checks before writing `envVars`/`secretFiles`, calling `s.EnvGroups.LinkEnvGroup` for `envGroupIds`, and calling `s.LinkBuildSource` for `serviceIds` — letting a `build_sources: read_write`-only key (with zero `services`, `build_source_env`, or `env_groups` permissions) rewire existing workspace services to a new build source, write build-time secrets, and link env groups.

- **Attribution:** server (`lego/backend/internal/apps`)
- **Root cause:**
  - `lego/backend/internal/api/key_permission_ops.go:90,513,1075` checks only `{core.KeyBuildSourcesManage}` at dispatch time before decoding arguments.
  - `apps.Service.CreateBuildSource` (`lego/backend/internal/apps/build_sources.go:207-313`) authorizes workspace `RelCanCreate` and validates the payload, then writes `EnvVars`/`SecretFiles` via `createBuildSourceCarrier` (`:269`), calls `s.EnvGroups.LinkEnvGroup` (`:279`), and calls `s.LinkBuildSource` (`:297`) directly in-process without checking `s.KeyGrant(ctx)` for `core.KeyBuildSourcesEnvSet`, `core.KeyEnvGroupsManage`, or `core.KeyServicesManage`.
- **Fix:**
  - In `apps.Service.CreateBuildSource` (`lego/backend/internal/apps/build_sources.go:215`, immediately after `s.Authorize` and before creating the carrier or touching any service/group):
    - Inspect `s.KeyGrant(ctx)` when `!grant.All` and collect every missing required action:
      - `core.KeyBuildSourcesEnvSet` when `len(req.EnvVars) > 0 || len(req.SecretFiles) > 0`;
      - `core.KeyEnvGroupsManage` when `len(req.EnvGroupIDs) > 0`;
      - `core.KeyServicesManage` when `len(req.ServiceIDs) > 0`.
    - Return `core.NewKeyPermissionDeniedError(missing)` when non-empty.
  - Surface impact: fixes MCP `create_build_source`, REST `POST /v1/build-sources`, and GraphQL `createBuildSource` uniformly from one place; creating a plain build source without those composite fields still works with `build_sources: read_write` alone.
