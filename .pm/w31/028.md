# 028 — `sandbox.Client.Get` sends `GET /sandboxes/` on empty `id` (`""`), returning `"internal error"` on MCP `list_sandbox_executions` / `stop_sandbox` / `suspend_sandbox` and GraphQL sandbox verbs

Why: `resolveSandbox` forwards `""` to `sandbox.Client.Get`, which calls `GET /sandboxes/` (OpenSandbox's collection endpoint), fails JSON decoding with `opensandbox get: bad response` (or non-404 status), and surfaces `"internal error"` (500-class / GraphQL `INTERNAL`) across every sandbox lookup, execution-history, and lifecycle verb instead of `SANDBOX_NOT_FOUND`.

- **Root cause:**
  - `executionsTarget` (`lego/backend/internal/sandbox/executions.go:231`), `lifecycle` (`lego/backend/internal/sandbox/service.go:1956`, shared by `Suspend`, `Resume`, and `Terminate`), and `Get` (`service.go:1850`) all call `s.ownedSandbox(ctx, key, ws, id)` (`service.go:767-784`) → `s.resolveSandbox(ctx, key, id)` (`service.go:747-761`).
  - For `id == ""`, `!isPublicSandboxID("")` is `true`, so `resolveSandbox` calls `s.Client.Get(ctx, key, "")` (`service.go:749`).
  - `Client.Get` (`lego/backend/internal/sandbox/client.go:353-369`) requests `GET "/sandboxes/" + url.PathEscape("")` == `GET /sandboxes/` — OpenSandbox's list endpoint — which returns either a list payload (`s.ID == ""` → `opensandbox get: bad response`) or a non-404 status (`opensandbox get: status %d`).
  - Because that error is not `errOpenSandboxNotFound`, `ownedSandbox` (`service.go:770-773`) returns it unwrapped, surfacing as `"internal error"` on MCP and `INTERNAL` on GraphQL.
- **Fix:**
  - Guard `if id == "" { return osSandbox{}, errOpenSandboxNotFound }` at the top of `Client.Get` (`lego/backend/internal/sandbox/client.go:353`) and `resolveSandbox` (`lego/backend/internal/sandbox/service.go:747`) (keeping `Authorize` in every caller untouched so unauthorized callers still receive `FORBIDDEN`).
  - Verify `orEnded` (`service.go`) returns `sandboxNotFound("")` cleanly when `id == ""` (skipping unnecessary DB lookup when empty or confirming `ErrNotFound` maps to `sandboxNotFound("")`).
  - Surface impact: fixes MCP `list_sandbox_executions`, `stop_sandbox`, `suspend_sandbox`, and `create_sandbox_snapshot`, plus GraphQL `sandbox`, `sandboxExecutions`, `sandboxExecution`, `suspendSandbox`, and `terminateSandbox` together. REST routes with `/{id}` do not match empty path segments.
