# 197 — `REST GET /v1/api-keys` (`apikeys/rest.go:55-61`) parses `?allMembers=` before authorization, returning `400 bad_request` instead of `403 FORBIDDEN` on unauthorized workspaces

Why: `lego/backend/internal/apikeys/rest.go:52-62` (`GET /v1/api-keys`) calls `strconv.ParseBool(q.Get("allMembers"))` and returns `400 bad request: allMembers must be true or false` before delegating to `s.ListAPIKeys(r.Context(), q.Get("ownerId"), allMembers)`, which performs workspace and admin authorization. Violating `bex-api`'s authz-before-validation contract, an unauthorized caller naming a foreign `ownerId` with `?allMembers=bogus` receives `400 bad_request` (and emits no denied audit row) instead of `403 FORBIDDEN`.
