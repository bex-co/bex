# 133 — `apps.Service.SetPublishPath` unconditionally stamps `spec.restartedAt`, triggers a live `settings_change` rebuild/deploy, and writes `apps.SetPublishPath` audit rows on no-op same-`publishPath` updates across MCP, REST, and GraphQL

Why: `apps.Service.SetPublishPath` (`lego/backend/internal/apps/service.go:7091-7105`) never compares `strings.TrimSpace(publishPath)` against `a.Spec.PublishPath`, so sending a static site's already-configured `publishPath` via MCP `update_service`, REST `PATCH /v1/services/{id}`, or GraphQL `setPublishPath` unconditionally stamps `spec.restartedAt`, triggers a brand-new live `settings_change` rebuild/deploy on GraphQL (deactivating the running deploy), bumps `updatedAt`, and writes spurious `apps.SetPublishPath` audit rows on every surface.

- **Root cause:**
  - `lego/backend/internal/apps/service.go:7091-7105`: after `AuthorizeApp(core.WithDeferredAllowedWriteAudit(ctx), ...)` and `checkPublishPath(a, name, publishPath)`, `SetPublishPath` has no equality check against `a.Spec.PublishPath`. It unconditionally calls `s.recordedPatch(ctx, core.AuditVerbSetPublishPath, a, ...)` setting `a.Spec.PublishPath = strings.TrimSpace(publishPath)` and `a.Spec.RestartedAt = s.Now().UTC().Format(time.RFC3339)`. Because `spec.restartedAt` changes, `appv1alpha1.SpecRollsRelease` (`lego/backend/internal/rollout/rollout.go:260`) reports a rolling change: direct GraphQL writes open a new `settings_change` deploy row and rebuild the static site, save-only MCP/REST writes stamp the pending generation annotation, and all three transports bump `updatedAt` and emit `apps.SetPublishPath`.
- **Fix:**
  - In `lego/backend/internal/apps/service.go:7098-7104`, trim `publishPath` once (`trimmed := strings.TrimSpace(publishPath)`), and after `checkPublishPath(a, name, trimmed)` returns `nil`, short-circuit `if trimmed == a.Spec.PublishPath { return s.view(a), nil }` before `s.recordedPatch`.
  - Keep `checkPublishPath` ahead of the short-circuit so invalid or non-`static_site` inputs still return `400 bad_request`.
  - Surface impact: fixes MCP (`update_service`), REST (`PATCH /v1/services/{id}`), and GraphQL (`setPublishPath`) together through the shared `apps.Service.SetPublishPath` verb (`settings.go:444`, `graphql.go:2110`).
