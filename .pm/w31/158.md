# 158 — `agentsessions.Service.PauseAgentAutomation` and `store.SetAgentAutomationPaused` leave stale `nextFireAt`, bump `version`/`updatedAt` on repeated pauses, and erase platform `pausedReason`/`pausedAt` across MCP, REST, and GraphQL

Why: `agentsessions.Service.PauseAgentAutomation` (`lego/backend/internal/agentsessions/automations.go:464-471`) calls `s.Automations.SetAgentAutomationPaused(ctx, row.ID, true, "")` unconditionally without short-circuiting when the automation is already paused/disabled, and `store.SetAgentAutomationPaused` (`lego/backend/internal/store/agentautomations.go:326-343`) neither clears `next_fire_at` nor preserves an existing paused state. As a result, pausing an active automation leaves a stale future `nextFireAt` (contradicting `CreateAgentAutomation(enabled: false)` and `UpdateAgentAutomation(enabled: false)`), repeating `pause_agent_automation` unconditionally bumps `version` and `updatedAt` (contradicting its MCP tool description `"Pausing a paused automation changes nothing."` and `IdempotentHint: true`), and manually pausing a platform-paused automation (`consecutive_failures`, `creator_lost_access`, `template_invalid`) overwrites `paused_reason` and `paused_at` with `NULL`, letting a subsequent `update_agent_automation(enabled: true)` bypass the `CodeAutomationPaused` guard at `automations.go:401-404`.

- **Attribution:** server (`lego/backend/internal/agentsessions` + `lego/backend/internal/store`)
- **Root cause:**
  - `lego/backend/internal/agentsessions/automations.go:464-471`: `PauseAgentAutomation` invokes `s.Automations.SetAgentAutomationPaused(ctx, row.ID, true, "")` unconditionally without checking `if !row.Enabled` first.
  - `lego/backend/internal/store/agentautomations.go:326-343`: `SetAgentAutomationPaused`'s `UPDATE` statement omits `next_fire_at = CASE WHEN $2 THEN NULL ELSE next_fire_at END`, always increments `version = version + 1` and `updated_at = now()`, and unconditionally overwrites `paused_reason = NULLIF($3, '')` and `paused_at = NULL` when `$3 == ""`.
- **Fix:**
  - In `agentsessions.Service.PauseAgentAutomation` (`lego/backend/internal/agentsessions/automations.go:464-471`): if `!row.Enabled` (already manually disabled or platform-paused), return `automationView(row)` immediately without calling `SetAgentAutomationPaused` (preserving `version`, `updatedAt`, and any platform `pausedReason`/`pausedAt`, and honoring `"Pausing a paused automation changes nothing."`).
  - In `PGStore.SetAgentAutomationPaused` (`lego/backend/internal/store/agentautomations.go:330-343`): set `next_fire_at = CASE WHEN $2 THEN NULL ELSE next_fire_at END` so both manual pauses and platform auto-pauses clear `next_fire_at` atomically. (Coordinate with `w31/041` on the resume side.)
