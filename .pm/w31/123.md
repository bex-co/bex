# 123 — `apps.checkCacheProfile` accepts `"no-cache"` on non-web services (`static_site`, `private_service`, `background_worker`, `cron_job`), mutating `updatedAt` and emitting bogus `apps.SetCacheProfile` audit rows across REST and GraphQL

Why: `checkCacheProfile` (`lego/backend/internal/apps/edge_cache.go:58-75`) returns early for `profile == "no-cache"` before checking `a.Spec.Type != appv1alpha1.TypeWebService`, so REST `PATCH /v1/services/{id}` (`serviceDetails.cache.profile: "no-cache"`) and GraphQL `setCacheProfile` accept edge-caching writes on non-web services (where `origin-controlled` is rejected 400), bump the App CR's `updatedAt`, and emit bogus `apps.SetCacheProfile` audit rows (and `SetCacheProfile` also unconditionally patches and audits no-op `"no-cache"` writes on already-`"no-cache"` web services).

- **Root cause:**
  - `checkCacheProfile` (`lego/backend/internal/apps/edge_cache.go:58-75`) short-circuits `if profile == appv1alpha1.CacheProfileNone { return "", nil }` at lines `:65-67` **before** checking `if t := a.Spec.Type; t != "" && t != appv1alpha1.TypeWebService` at lines `:68-70`. Because `servicePatchTable` (`lego/backend/internal/apps/settings.go:315-325`) and `SetCacheProfile` (`edge_cache.go:83-107`) both rely on `checkCacheProfile`, `"no-cache"` passes validation on every non-web service type.
  - `SetCacheProfile` (`edge_cache.go:83-107`) then unconditionally calls `s.patchFetched` (`:95`, which stamps `updatedAt` via `resourcemeta.Touch`) and `s.RecordCacheProfileChanged` (`:105`) even when `a.Spec.CacheProfile == profile` (`"" == ""`).
- **Fix:**
  - Move the `a.Spec.Type != appv1alpha1.TypeWebService` check (`edge_cache.go:68-70`) **above** `if profile == appv1alpha1.CacheProfileNone` (`:65-67`), keeping `freeTier(a.Spec.Tier)` after the `"no-cache"` branch so a free web service can still send `"no-cache"` (e.g., an idempotent Render PATCH payload echoing the readback default `"no-cache"`).
  - In `SetCacheProfile` (`edge_cache.go:83-107`), short-circuit without patching the CR or advancing `updatedAt` when `a.Spec.CacheProfile == profile` (note: check `TestCacheProfileSavesRecordWhetherCachingTurnedOnOrOff` in `lego/backend/internal/apps/edge_cache_test.go:147`, which currently asserts a no-op `no-cache` → `no-cache` save on a paid web service records 1 `AuditVerbSetCacheProfile` row; update that test if no-op writes return early without emitting an audit row, or keep the audit behavior explicitly aligned with `SetPlan`/`SetIdleTTL` conventions).
  - Surface impact: fixes REST `PATCH /v1/services/{id}` (live and `?dryRun=true`) and GraphQL `setCacheProfile` together via the shared `checkCacheProfile`/`SetCacheProfile` path (MCP `update_service` does not currently expose `cacheProfile`).
