# 171 — `apps.Service` Blueprint and Build Source create/update paths omit `core.TrimmedLabel`, accepting and persisting control characters and unbounded lengths across MCP, REST, and GraphQL

Why: Every other free-form resource label across `bex-api` (`services`, `postgres`, `keyvalue`, `projects`, `environments`, `envgroups`, `workspaces`, `organizations`, `apikeys`, `sshkeys`, `webhooks`, `registrycreds`, `sandbox` groups) enforces `core.CheckLabel` / `core.TrimmedLabel` (`lego/backend/internal/core/errors.go:395-425`: no `unicode.IsControl` or `\u2028`/`\u2029` line separators, max `MaxLabelLength = 100` runes, returning `400 DISPLAY_NAME_CONTROL_CHARACTER` / `DISPLAY_NAME_TOO_LONG`). Five `apps.Service` Blueprint and Build Source entry points (`CreatePlannedBlueprint`, `CreateBlueprint`, `UpdateBlueprint`, `CreateBuildSource`, `UpdateBuildSource`) call only `strings.TrimSpace`, accepting and persisting raw newlines, control characters, and 500+ character names across MCP, REST, and GraphQL. Build Sources write `name` directly into `App.Spec.DisplayName` (`build_sources.go:57`), bypassing `checkDisplayName` (`apps/service.go:6400-6406`) and breaking `generate_blueprint` round-trip export (`validate_bex_yml` rejects such names with `RESOURCE_NAME_INVALID`, causing `503 BLUEPRINT_GENERATE_FAILED`).

- **Attribution:** server (`lego/backend/internal/apps`)
- **Root cause:**
  - `lego/backend/internal/apps/blueprint.go:2153-2159` (`UpdateBlueprint`): calls `strings.TrimSpace(*req.Name)` and checks `trimmed == ""`, never calling `core.TrimmedLabel`.
  - `lego/backend/internal/apps/blueprint.go:1435` (`CreateBlueprint`) and `:1579-1598` (`newBlueprintName`): calls `strings.TrimSpace(req.Name)` and never validates non-empty names with `core.TrimmedLabel`.
  - `lego/backend/internal/apps/blueprint_onboarding.go:171-174` (`CreatePlannedBlueprint`): calls `strings.TrimSpace(req.Name)` and checks `req.Name == ""`, never calling `core.TrimmedLabel`.
  - `lego/backend/internal/apps/build_sources.go:216-219` (`CreateBuildSource`) and `:618-627` (`UpdateBuildSource`): call `strings.TrimSpace` and check `== ""`, never calling `core.TrimmedLabel`. On create, `buildSourceCreate.shape` (`build_sources.go:54-58`) assigns `spec.DisplayName = b.name` directly, bypassing `checkDisplayName` (`apps/service.go:6400-6406`).
- **Fix:**
  - Replace bare `strings.TrimSpace` on Blueprint and Build Source names with `core.TrimmedLabel` in all five entry points:
    - `apps/blueprint.go:1435` (`CreateBlueprint`, when non-empty)
    - `apps/blueprint.go:2153-2159` (`UpdateBlueprint`, retaining `name cannot be empty` when `trimmed == ""`)
    - `apps/blueprint_onboarding.go:171-174` (`CreatePlannedBlueprint`, retaining `name is required` when `req.Name == ""`)
    - `apps/build_sources.go:216-219` (`CreateBuildSource`, retaining `name is required` when `req.Name == ""`)
    - `apps/build_sources.go:618-627` (`UpdateBuildSource`, retaining `name cannot be empty` when `name == ""`)
