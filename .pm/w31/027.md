# 027 — `hydraAPIKeys.getAPIKey` sends `GET /admin/clients/` on empty `id` (`""`), returning `"internal error"` on MCP `revoke_api_key` and GraphQL `revokeApiKey` / `updateApiKeyPermissions`

Why: `hydraClientPath("")` builds `"/admin/clients/"` (Hydra's list-all-clients endpoint), so calling `revoke_api_key`, `revokeApiKey`, or `updateApiKeyPermissions` with `id: ""` fetches every OAuth2 client from Hydra, fails JSON struct unmarshaling against the returned array, and surfaces a 500-class `"internal error"` instead of `NOT_FOUND` / `FORBIDDEN`.

### Empty `keyId` / `id` (`""`) on API-key revocation and permission-update verbs hits Hydra's list endpoint and returns `"internal error"`

- **Attribution:** server (`lego/backend/internal/apikeys`)
- **Root cause:**
  - `RevokeAPIKey` (`lego/backend/internal/apikeys/service.go:635`) and `UpdateAPIKeyPermissions` (`:745`) call `s.keyRelation(ctx, id)` (`:672-688`), which calls `s.boundKey(ctx, id)` (`:798`) → `hydraAPIKeys.Get(ctx, id)` (`:1156`) → `h.getAPIKey(ctx, id)` (`:1112-1121`).
  - `hydraClientPath(id)` (`:1105`) returns `"/admin/clients/" + url.PathEscape(id)`. When `id == ""`, that path is `"/admin/clients/"` — Ory Hydra's **list OAuth2 clients** endpoint.
  - `h.do(ctx, http.MethodGet, "/admin/clients/", nil, http.StatusOK, &c)` receives `200 OK` with a JSON array `[...]` of every client in Hydra and fails to decode it into `hydraClient` (a JSON object). Because that decode error is not `core.ErrNotFound`, `keyRelation` (`:680-681`) aborts and returns it directly, surfacing as `"internal error"` on MCP and `INTERNAL` on GraphQL (and causing an unnecessary full Hydra client-list fetch on every empty-id call).
- **Fix:**
  - Guard `if id == "" { return hydraClient{}, core.ErrNotFound }` at the top of `hydraAPIKeys.getAPIKey` (`lego/backend/internal/apikeys/service.go:1112`) and `if id == "" { return core.ErrNotFound }` at the top of `hydraAPIKeys.Delete` (`:1123`) (and `if id == "" { return APIKey{}, core.ErrNotFound }` in `boundKey` `:798` so non-Hydra stores also skip listing).
  - Verify `keyRelation` still returns `core.RelCanManage` on `core.ErrNotFound` so non-admin callers continue receiving `FORBIDDEN` and authorized admins receive `NOT_FOUND` (identical to an unknown UUID), with zero Hydra HTTP requests made.
  - Surface impact: fixes MCP `revoke_api_key` and `update_api_key_permissions`, GraphQL `revokeApiKey` and `updateApiKeyPermissions`, and any internal caller (`KeyOwner`, `KeyCreator`, `Touch`) together. REST `DELETE /v1/api-keys/` does not match `/{id}`, so REST is unaffected.
- **Blast radius:** `lego/backend/internal/apikeys/service.go` (`boundKey`, `hydraAPIKeys.getAPIKey`, `hydraAPIKeys.Delete`) and `lego/backend/internal/apikeys/*_test.go`. Covers all callers of `RevokeAPIKey`, `UpdateAPIKeyPermissions`, `Get`, `Delete`, `Touch`, `KeyOwner`, and `KeyCreator`.
