# 189 — Pre-authorization input validation in `events` (`MCP list_events`), `jobs` (`MCP list_jobs`, `REST GET /v1/services/{id}/jobs`), and `secrets` (`MCP update_environment_variables`) returns `400 bad_request` instead of `403`/`404`

Why: `bex-api`'s authz-before-validation contract requires authorization and target-service resolution to run before validating caller-supplied query filters or body arguments, so unauthorized or foreign-service callers receive `403 FORBIDDEN` / `404 NOT_FOUND` (and record denied audit rows) rather than `400 bad_request`. Three resource-scoped adapter handlers validate inputs before calling into their authorized `Service` methods: `events/mcp.go:125-132` (`list_events` parses `startTime`/`endTime` before `s.List`), `jobs/mcp.go:65-69` and `jobs/rest.go:106-111` (`list_jobs` and `GET /v1/services/{id}/jobs` parse `FilterFromStrings`/`filterFromQuery` before `s.List`), and `secrets/mcp.go:173-175` (`update_environment_variables` rejects `in.EnvVars == nil` before `s.PatchEnvironment`).

- **Attribution:** server (`lego/backend/internal/events`, `lego/backend/internal/jobs`, `lego/backend/internal/secrets`)
- **Root cause:**
  - `lego/backend/internal/events/mcp.go:125-132`: calls `parseListEventsTime("startTime", in.StartTime)` and `parseListEventsTime("endTime", in.EndTime)` before invoking `s.List(ctx, in.ServiceID, filter)`. (REST `GET /v1/services/{id}/events` and GraphQL `serviceEvents` should be checked in the same pass to confirm they do not repeat the pattern.)
  - `lego/backend/internal/jobs/mcp.go:65-69` and `lego/backend/internal/jobs/rest.go:106-111`: call `FilterFromStrings(...)` / `filterFromQuery(r.URL.Query())` before `s.List(ctx, id, filter)` authorizes and loads the service.
  - `lego/backend/internal/secrets/mcp.go:173-175`: checks `if in.EnvVars == nil` and returns `ErrBadRequest` before calling `s.PatchEnvironment` (which runs `s.scopeForWrite(ctx, core.RelCanCreate, service)` at `secrets/batch.go:100`).
- **Fix:**
  - In `events/mcp.go:125-135`, either pass raw `StartTime`/`EndTime` strings into `s.List` (or resolve/authorize the target service first via the same read-scope helper `s.List` uses) before calling `parseListEventsTime`.
  - In `jobs/mcp.go:65-72` and `jobs/rest.go:106-114`, pass the raw filter inputs into `s.List` (or run service authorization/resolution before `FilterFromStrings`/`filterFromQuery`) so `ErrForbidden`/`ErrNotFound` always precedes filter validation.
  - In `secrets/mcp.go:173-180`, move the `in.EnvVars == nil` check after `s.scopeForWrite(ctx, core.RelCanCreate, in.ServiceID)` (with `core.WithDeferredAllowedWriteAudit`) or into a post-authz step in `PatchEnvironment` so Viewers and foreign-service callers receive `403`/`404` (and emit a denied audit row) before `Environment variables are required`.
