# 207 — `GET /v1/key-value` and `GET /v1/redis` parse `suspended` with singular `q.Get`, rejecting comma lists with `400` and silently dropping repeated values

Why: `w1/110` fixed `apps/rest.go:931-936` (`GET /v1/services`) and `postgres/rest.go:119-124` (`GET /v1/postgres`) to parse `suspended` as an array via `core.QueryList(q, "suspended")` (ORing both comma-separated `?suspended=suspended,not_suspended` and repeated `?suspended=suspended&suspended=not_suspended`), noting that a singular `q.Get` silently drops every value after the first and rejects comma lists as invalid enum members. `lego/backend/internal/keyvalue/rest.go:321` (`handleListKeyValues`, mounted on both `GET /v1/key-value` and `GET /v1/redis`) was missed and still calls `core.ParseEnum("suspended", q.Get("suspended"), ...)`, so comma-separated filters fail with `400` and repeated filters silently drop the second value — returning `200 []` and hiding live Key Value instances.
