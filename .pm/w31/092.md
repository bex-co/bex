# 092 — `billing.isCountryCode` checks only `[A-Z]{2}` instead of ISO 3166-1 alpha-2, allowing `update_billing_info` (and REST/GraphQL twins) to persist invalid country codes such as `"XX"` to Stripe

Why: `billing.isCountryCode` (`lego/backend/internal/billing/billing_info.go:240-242`) checks only `len(s) == 2 && 'A' <= s[0] && s[0] <= 'Z' && 'A' <= s[1] && s[1] <= 'Z'`, even though `billing/mcp.go:52` and `billing_info.go:202` promise `"a two-letter ISO 3166-1 country code"` — allowing bogus codes such as `"XX"` to pass validation and be written onto the workspace's Stripe Customer across MCP, REST, and GraphQL.

### `update_billing_info` / `PUT /v1/workspaces/{id}/billing/info` / `setWorkspaceBillingInfo` accept non-ISO two-letter country codes

- **Expected / actual:**

- **Attribution:** server (`lego/backend/internal/billing/billing_info.go`)
- **Root cause:**
  - `lego/backend/internal/billing/billing_info.go:240-242`:
    ```go
    func isCountryCode(s string) bool {
        return len(s) == 2 && 'A' <= s[0] && s[0] <= 'Z' && 'A' <= s[1] && s[1] <= 'Z'
    }
    ```
    checks only ASCII uppercase letters rather than the assigned ISO 3166-1 alpha-2 country code set (which `billing` already maintains statically for `stripeTaxIDTypes` in `lego/backend/internal/billing/tax_id_types.go`).
- **Fix:**
  - Replace the regex-like check in `isCountryCode` (`lego/backend/internal/billing/billing_info.go:240-242`) with a static `iso3166Alpha2` lookup map of officially assigned ISO 3166-1 alpha-2 country codes (matching the `stripeTaxIDTypes` pattern in the same package), returning `BILLING_INFO_INVALID` for unassigned codes like `"XX"`, `"ZZ"`, `"QQ"`.
  - Surface impact: fixes MCP `update_billing_info`, REST `PUT /v1/workspaces/{workspaceId}/billing/info`, and GraphQL `setWorkspaceBillingInfo` together from `normalizeBillingInfo`.
- **Blast radius:** `lego/backend/internal/billing/billing_info.go` and `lego/backend/internal/billing/customer_billing_info_test.go`. Valid ISO 3166-1 alpha-2 country codes remain accepted (case-insensitive, trimmed and uppercased).
