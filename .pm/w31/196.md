# 196 — `api.renderObjects` (`PUT`/`DELETE /v1/objects/...`) omits `WithDeferredAllowedWriteAudit` (recording `"status": "success"` audit rows on `400`/`404` refusals) and omits `core.WithStrictJSONDecoding` on `PUT`

Why: `lego/backend/internal/api/objects_render.go:158-183` (`renderObjects.serve`) authorizes `PUT /v1/objects/{ownerId}/{region}/{key...}` (`AuditVerbPutObject`, `RelCanCreate`) and `DELETE /v1/objects/{ownerId}/{region}/{key...}` (`AuditVerbDeleteObject`, `RelCanCreate`) via `o.base.AuthorizeWorkspaceTargetAs` without `core.WithDeferredAllowedWriteAudit(r.Context())`, so every post-authz refusal — invalid region (`400`), malformed JSON or missing `sizeBytes` (`400`), oversized/quota/invalid-key rejection (`400`/`413`/`429`), or missing object (`404`) — writes a false `"status": "success"` row into `/v1/owners/{ownerId}/audit-logs`. In addition, `PUT /v1/objects/{ownerId}/{region}/{key...}` (`objects_render.go:106`) calls `core.DecodeJSON(r, &req)` without `core.WithStrictJSONDecoding(r.Context())` (and `/v1/objects/...` is outside Render's pinned OpenAPI spec), silently ignoring unknown/misspelled body fields instead of returning `400`.

- **Attribution:** server (`lego/backend/internal/api/objects_render.go`)
- **Root cause:**
  - `lego/backend/internal/api/objects_render.go:158-183` (`serve`): calls `o.base.AuthorizeWorkspaceTargetAs(r.Context(), verb, relation, r.PathValue("ownerId"), renderObjectTarget(r))` unconditionally without `core.WithDeferredAllowedWriteAudit(r.Context())` for write routes (`relation == core.RelCanCreate`, i.e., `PUT` at `:104` and `DELETE` at `:137`). Denied authz must still audit immediately, while allowed write audits must be deferred until `fn` returns `err == nil`.
  - `lego/backend/internal/api/objects_render.go:106`: calls `core.DecodeJSON(r, &req)` without `r = r.WithContext(core.WithStrictJSONDecoding(r.Context()))`.
- **Fix:**
  - In `lego/backend/internal/api/objects_render.go:158-183` (`serve`), for write relations (`relation == core.RelCanCreate`, or via a `deferWriteAudit bool` parameter on `serve`), pass `core.WithDeferredAllowedWriteAudit(r.Context())` into `o.base.AuthorizeWorkspaceTargetAs` and call `o.base.RecordAllowedWrite(r.Context(), workspaceID, verb, relation, renderObjectTarget(r))` only after `ParseRegion` and `fn` succeed.
  - In `lego/backend/internal/api/objects_render.go:106`, wrap `r = r.WithContext(core.WithStrictJSONDecoding(r.Context()))` before `core.DecodeJSON(r, &req)`.
