# 054 — `core.ParseTimeWindow` and `automations_rest.go` echo raw `time.Parse` errors (including caller-supplied values) across MCP, REST, and GraphQL

Why: `core.ParseTimeWindow` (`lego/backend/internal/core/http.go:595-607`) calls `time.Parse` directly and interpolates the raw `*time.ParseError` into the returned error instead of delegating to `core.ParseTime` (`lego/backend/internal/core/pagination.go:177-186`), echoing caller-supplied strings verbatim twice (plus Go's `2006-01-02T15:04:05Z07:00` layout) across 8 log-query surfaces (MCP, REST, GraphQL); `automations_rest.go:49` has the same raw `err.Error()` echo when decoding `runAt`/`endsAt`.

- **Root cause:**
  - `core.ParseTimeWindow` (`lego/backend/internal/core/http.go:595-607`) parses `startTime` and `endTime` with raw `time.Parse(time.RFC3339, ...)` and wraps `err` directly via `fmt.Errorf("%w: startTime: %s", ErrBadRequest, err)` (`:598`, `:603`) instead of calling `ParseTime("startTime", startTime)` and `ParseTime("endTime", endTime)` (`lego/backend/internal/core/pagination.go:177-186`). It is called by 8 surfaces: `postgres/{rest.go:414,graphql.go:577,mcp.go:241}`, `keyvalue/{rest.go:408,graphql.go:168,mcp.go:219}`, and `logs/{rest.go:1017,graphql.go:380}`.
  - `registerAutomationREST`'s `input` helper (`lego/backend/internal/agentsessions/automations_rest.go:44-50`) appends raw `err.Error()` to `"the request body is not a valid automation: "` (`:49`), forwarding Go's `*time.ParseError` (and any `*json.UnmarshalTypeError` / syntax error value details) straight to the caller.
- **Fix:**
  - In `lego/backend/internal/core/http.go:595-607`, replace the two `time.Parse` blocks in `ParseTimeWindow` with calls to `ParseTime("startTime", startTime)` and `ParseTime("endTime", endTime)`.
  - In `lego/backend/internal/agentsessions/automations_rest.go:44-50`, map decode errors via `core.DecodeJSON`-style structured error sanitization (e.g., naming the JSON field path without echoing `*time.ParseError` values or raw Go types, matching `sandbox/snapshots_surfaces.go`'s REST decode error `"invalid request body at /expiresAt"`).
  - Surface impact: aligns all 8 `ParseTimeWindow` callers (MCP, REST, GraphQL) and REST agent-automation create/update with the rest of the backend's `core.ParseTime` / sanitized-decode contract.
- **Blast radius:** `lego/backend/internal/core/http.go` (shared by `postgres`, `keyvalue`, and `logs` REST/GraphQL/MCP log endpoints) and `lego/backend/internal/agentsessions/automations_rest.go`.
