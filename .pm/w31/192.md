# 192 — `github` REST routes validate `installationId`/`chooser` before authorization (returning `400` instead of `403`), and `github.Service.{StartConnect,StartClaim,SelectClaim,Disconnect}` omit `WithDeferredAllowedWriteAudit`

Why: Two contract violations in `lego/backend/internal/github/` match patterns already tracked across sibling packages: (1) `github/rest.go:54-64` (`POST /v1/git/claim`), `:87-92` (`POST /v1/git/claim/selections/{id}`), and `:207-212` (`DELETE /v1/git/connections/{installationId}`) parse and reject `installationId` and `chooser` before calling `s.StartClaim` / `s.SelectClaim` / `s.Disconnect`, so unauthorized callers naming a foreign `ownerId` get `400 bad_request` instead of `403 FORBIDDEN` (emitting no denied audit row); and (2) `github/service.go:219` (`StartConnect`), `:406` (`StartClaim`), `:600` (`SelectClaim`), and `:798` (`Disconnect`) call `s.Authorize(ctx, core.RelCanManage)` without `core.WithDeferredAllowedWriteAudit(ctx)`, so post-authz refusals (`403` expired/unknown selection, `400` out-of-set installation, `409` multiple connections on singular disconnect, `503` unconfigured GitHub/verifier) record bogus `"status": "success"` rows into `/v1/owners/{ownerId}/audit-logs`.

- **Root cause:**
  - Pre-authz validation in `lego/backend/internal/github/rest.go`:
    - `:54-64` (`POST /v1/git/claim`): calls `optionalInstallationID(...)` and `optionalBool(..., "chooser")` before `s.StartClaim`.
    - `:87-92` (`POST /v1/git/claim/selections/{id}`): calls `optionalInstallationID(...)` and checks `installationID == 0` before `s.SelectClaim`.
    - `:207-212` (`DELETE /v1/git/connections/{installationId}`): calls `strconv.ParseInt(...)` before `s.Disconnect`.
  - Missing `WithDeferredAllowedWriteAudit` in `lego/backend/internal/github/service.go`:
    - `:219` (`StartConnect`), `:406` (`StartClaim`), `:600` (`SelectClaim`), and `:798` (`Disconnect`) authorize `core.RelCanManage` without `core.WithDeferredAllowedWriteAudit(ctx)`, emitting the `"success"` audit row before `configured()`, `verifierPreflight()`, `loadSelection()`, `selectionOffers()`, or the multi-connection `ErrConflict` check runs.
- **Fix:**
  - Move `installationId` / `chooser` parsing behind workspace authorization (e.g., pass raw options or authorize on `ownerId` / scoped target before rejecting malformed `installationId` or `chooser` in `github/rest.go` and `github/service.go`).
  - Authorize `StartConnect`, `StartClaim`, `SelectClaim`, and `Disconnect` under `core.WithDeferredAllowedWriteAudit(ctx)` and emit `s.RecordAllowedWrite` only after the transaction/bind/delete succeeds (keeping idempotent no-op `Disconnect` behavior clear and preserving denied audit rows).
  - Surface impact: fixes both REST and GraphQL for deferred audit (they share `github.Service`) and fixes all three REST routes for authz-before-validation.
- **Blast radius:** `lego/backend/internal/github/{rest,service}.go` and `lego/backend/internal/github/*_test.go`. Valid authorized calls return identical responses.
