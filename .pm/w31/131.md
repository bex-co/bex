# 131 — `apps.Service.SetRuntime` / `checkRuntime` accepts empty `runtime: ""`, mutates build-source-linked services to `"docker"`, and restarts on no-op same-runtime writes across REST and GraphQL

Why: `checkRuntime` (`lego/backend/internal/apps/runtime_change.go:34-42`) delegates directly to create-time `resolveBuildStrategy` without checking `runtime == ""` or `a.Spec.BuildSource != nil`, and `SetRuntime` (`:62-82`) only short-circuits `prebuiltImageSource && runtime == "image"` — so REST `PATCH /v1/services/{id}` (`serviceDetails.runtime`) and GraphQL `setRuntime` accept empty `""` (wiping `spec.runtime`/`spec.builder` and triggering a live deploy on prebuilt-image and repo services), accept `"docker"`/`""` on build-source-linked services (overwriting `spec.runtime` and launching a deploy), and trigger unnecessary rebuilds/restarts + `apps.SetRuntime` audit rows when echoing a repo service's current runtime.

- **Attribution:** server (`lego/backend/internal/apps`)
- **Root cause:**
  - `lego/backend/internal/apps/runtime_change.go:34-42`: `checkRuntime` checks only `a.Spec.Type == appv1alpha1.TypeStaticSite` before calling `resolveBuildStrategy(a.Spec.Type, CreateRequest{Repo: a.Spec.Repo, Image: a.Spec.Image, Runtime: runtime, ...})`.
    - `resolveBuildStrategy` (`service.go:4140-4143`) accepts `runtime == ""` as a valid create-time default ("auto"), so empty `""` passes on update and wipes `a.Spec.Runtime` and `a.Spec.Builder`.
    - A build-source-linked service (`a.Spec.BuildSource != nil`) has `a.Spec.Repo == ""` and `a.Spec.Image == ""`, so `resolveBuildStrategy`'s `case "docker":` (`if req.Image != ""` only, `service.go:4147`) accepts `"docker"` on a linked service instead of refusing.
  - `lego/backend/internal/apps/runtime_change.go:74-81`: `SetRuntime` only short-circuits `if prebuiltImageSource(a.Spec) && runtime == "image"`, and otherwise unconditionally calls `recordedPatch` with `a.Spec.RestartedAt = s.Now().UTC().Format(time.RFC3339)` even when `a.Spec.Runtime == runtime && a.Spec.Builder == builder`.
- **Fix:**
  - In `checkRuntime` (`lego/backend/internal/apps/runtime_change.go:34-42`):
    1. Reject `strings.TrimSpace(runtime) == ""` with `core.ErrBadRequest` (e.g., `runtime is required`).
    2. Reject `a.Spec.BuildSource != nil` with `core.ErrBadRequest` (a linked service's runtime is managed by its build source — or allow echoing the linked build source's effective runtime as a no-op if Render Terraform compatibility needs it, while refusing any change).
    3. Also guard `case "docker":` in `checkRuntime` so a service without a repo cannot switch to `"docker"`.
  - In `SetRuntime` (`lego/backend/internal/apps/runtime_change.go:74-81`), return `s.view(a), nil` without patching, stamping `RestartedAt`, or auditing when `a.Spec.Runtime == runtime && a.Spec.Builder == builder` (in addition to `prebuiltImageSource(a.Spec) && runtime == "image"`).
  - Surface impact: fixes REST `PATCH /v1/services/{id}` (live and `?dryRun=true`) and GraphQL `setRuntime` together (MCP `update_service` does not currently expose `runtime`).
