# 108 — `AgentEnvironment.agentDataUse[].acknowledgedBy` leaks raw internal Kratos UUIDs, writes raw Hydra client UUIDs on API-key updates, and is omitted from account-deletion anonymization across MCP, REST, and GraphQL

Why: `agentsessions.Service.UpdateEnvironment` (`lego/backend/internal/agentsessions/environment.go:497`) passes `core.SubjectFrom(ctx)` verbatim into `agentAvailabilityPatch` (`:295`) without resolving an API key's human creator via `s.KeyCreator(ctx)`, `environmentView` (`:876-877`) emits stored `ack.By` verbatim without mapping human subjects through `core.PublicUserIDs` — leaking raw internal Kratos identity UUIDs in violation of `docs/ADR020-identifiers.md` even though dashboard tests expect `usr-…` — and `PGStore.CleanupAccountSubject` (`lego/backend/internal/store/accounts.go:437-452`) never anonymizes `agent_environments.agent_data_use_acks`.

- **Root cause:**
  - `agentsessions.Service.UpdateEnvironment` (`lego/backend/internal/agentsessions/environment.go:497`) calls `agentAvailabilityPatch(current, input, core.SubjectFrom(ctx), &patch)` without resolving attributed API keys through `s.KeyCreator(ctx)`.
  - `agentsessions.Service.environmentView` (`lego/backend/internal/agentsessions/environment.go:868-881`) copies `ack.By` directly into `use.AcknowledgedBy` without translating human subjects through `core.PublicUserIDs` (and `agentsessions.Service` does not yet carry `UserIDs core.UserIDLookup`, as also noted in `w31/096`).
  - `store.PGStore.CleanupAccountSubject` (`lego/backend/internal/store/accounts.go:437-452`) anonymizes `agent_session_attachments`, `agent_skills`, and `agent_skill_versions`, but omits `agent_environments.agent_data_use_acks` (`jsonb` map `{agent: {at, by}}`).
- **Fix:**
  - In `UpdateEnvironment` (`lego/backend/internal/agentsessions/environment.go:497`), resolve the acknowledging actor through the same `s.KeyCreator(ctx)` helper as `w31/040` / `w31/096` (failing closed on lookup errors) so API-key acknowledgements store the creator's human subject rather than a Hydra client UUID.
  - Using `UserIDs core.UserIDLookup` on `agentsessions.Service` (shared with `w31/096`), translate every `ack.By` in `environmentView` (`environment.go:868-881`, passing `ctx`) through `core.PublicUserIDs` so MCP, REST, and GraphQL emit `usr-…` (preserving anonymized deleted-user markers and resolving any legacy API-key UUID via `KeyCreators` if available).
  - In `store.PGStore.CleanupAccountSubject` (`lego/backend/internal/store/accounts.go`), rewrite matching `by` entries inside `agent_environments.agent_data_use_acks` to the anonymized `marker`.
  - Surface impact: aligns `agentDataUse[].acknowledgedBy` across MCP (`get_agent_environment`, `update_agent_environment`), REST (`/v1/agent-environment`), GraphQL (`agentEnvironment`, `updateAgentEnvironment`), and the dashboard Agent Environment UI.
