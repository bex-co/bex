# 101 — `apps.validateMaintenanceMode` accepts literal private, loopback, link-local metadata, and cluster-internal URLs (`169.254.169.254`, `127.0.0.1`, `kubernetes.default.svc`) across MCP, REST, and GraphQL

Why: `apps.validateMaintenanceMode` (`lego/backend/internal/apps/service.go:1000-1032`) rejects the service's own hosts and platform-reserved hosts (`*.onbex.co`, `*.bex.co`), but never runs the literal non-public host check that `validatePublicRewriteHost` enforces right in the same file (`lego/backend/internal/apps/service.go:6660-6684`), letting callers persist `http://169.254.169.254/latest/meta-data/`, `http://127.0.0.1:8090/healthz`, and `http://kubernetes.default.svc/api` as `maintenanceMode.uri` across MCP, REST, and GraphQL — URLs that `bex-activator`'s `SafeDialContext` unconditionally fails with `502 Bad Gateway` only after consuming a shared `fetchSem` slot and triggering DNS lookups.

- **Attribution:** server + operator (`lego/backend/internal/apps`, `lego/operator/cmd/activator`)
- **Root cause:**
  - `lego/backend/internal/apps/service.go:1000-1032` (`validateMaintenanceMode`) and `:1046-1059` (`parseMaintenanceURI`) validate only HTTP(S) scheme, non-empty `u.Hostname()`, absent `u.User`, and loop-guard hosts (`maintenanceHosts`, `reservedHost`, `hostClaimedElsewhere`). Unlike `validatePublicRewriteHost` (`lego/backend/internal/apps/service.go:6660-6684`), it never checks `netutil.UnsafeOriginIP(ip)` or single-label/internal/cluster suffixes.
  - `lego/operator/cmd/activator/main.go:484` uses `netutil.SafeDialContext` at fetch time (so private IPs are blocked from TCP connection and cannot exfiltrate metadata), but `validateCustomPageURL` (`lego/operator/cmd/activator/main.go:684-707`) omits the literal non-public host check — so unvalidated URIs still enter `singleflight`, consume a shared `fetchSem` slot, perform internal DNS resolution on `.svc`/`.cluster.local`, and fail every visitor with `502 Bad Gateway` ("custom maintenance page unavailable") instead of being rejected at config time.
- **Fix:**
  - Extract a shared literal public-host helper from `validatePublicRewriteHost` (`lego/backend/internal/apps/service.go:6660-6684`, or in `lego/types/netutil` so both backend and activator share one rule) rejecting `netutil.UnsafeOriginIP(ip)`, single-label hosts (`localhost`), and internal/cluster suffixes (`.localhost`, `.local`, `.internal`, `.lan`, `.svc`, `.cluster.local`, `.home.arpa`).
  - Call it from `validateMaintenanceMode` (`lego/backend/internal/apps/service.go:1000-1032`) with a clear `400 bad request` (`maintenanceMode.uri must be a publicly accessible URL, not a private, loopback, link-local or cluster-internal address`) and from `validateCustomPageURL` (`lego/operator/cmd/activator/main.go:684-707`) as defense in depth.
