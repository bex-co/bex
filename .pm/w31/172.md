# 172 — `usage` (`get_usage` / `GET /v1/usage` / `Query.usage`), `apps.Service.UpdateBuildSource`, and 4 log/deploy/webhook adapters validate inputs before authorization

Why: `bex-api`'s authz-before-validation contract requires authorization to run before caller-supplied arguments are validated so unauthorized callers (foreign workspaces, unprivileged roles, or nonexistent IDs) receive `403 FORBIDDEN` / `404 NOT_FOUND` instead of `400 bad_request` (and so denied attempts emit denied audit rows). Three surfaces violate this ordering across MCP, REST, and GraphQL: (1) all three `usage` adapters call `ResolvePeriodEnd(period, …)` before `monthToDateAt` (`AuthorizeAs(..., RelCanViewBilling)`), letting foreign-workspace or Contributor/Viewer callers receive `400 period must be a calendar month` instead of `403 FORBIDDEN`; (2) `apps.Service.UpdateBuildSource` checks `req.Git != nil && req.Image != nil` before `buildSourceApp` authorization, returning `400 git and image are mutually exclusive` before `403`/`404` on MCP, REST, and GraphQL; and (3) `deploys`, `webhooks`, `postgres` logs, and `keyvalue` logs parse query timestamps (`FilterOf`, `core.ParseTime`, `core.ParseTimeWindow`) in their adapters before delegating to the authorized service method.

- **Attribution:** server (`lego/backend/internal/usage`, `lego/backend/internal/apps`, `lego/backend/internal/deploys`, `lego/backend/internal/webhooks`, `lego/backend/internal/postgres`, `lego/backend/internal/keyvalue`)
- **Root cause:**
  - `lego/backend/internal/usage/mcp.go:43-47`, `usage/rest.go:105-110`, `usage/graphql.go:337-341`: all three adapters call `ResolvePeriodEnd(period, s.Now().UTC())` before `s.monthToDateAt(ctx, ownerID, asOf)`, which performs `s.AuthorizeAs(ctx, AuditVerbMonthToDate, core.RelCanViewBilling)` at `usage/service.go:293`.
  - `lego/backend/internal/apps/build_sources.go:609-616`: `UpdateBuildSource` checks `if req.Git != nil && req.Image != nil` at `:610-612` before calling `s.buildSourceApp(core.WithDeferredAllowedWriteAudit(ctx), core.RelCanCreate, id)` at `:613`.
  - Adapter-level query parsing before service-layer authorization:
    - `lego/backend/internal/deploys/mcp.go:128-138` (`FilterOf` before `s.List`)
    - `lego/backend/internal/webhooks/mcp.go:115-123` (`core.ParseTime` before `s.ListDeliveriesFiltered`)
    - `lego/backend/internal/postgres/mcp.go:241-245`, `postgres/rest.go:414-418`, `postgres/graphql.go:623-631` (`core.ParseTimeWindow` before `s.QueryDatabaseLogs`)
    - `lego/backend/internal/keyvalue/mcp.go:217-221`, `keyvalue/rest.go:408-413`, `keyvalue/graphql.go:168-176` (`core.ParseTimeWindow` before `s.QueryKeyValueLogs`)
- **Fix:**
  - `usage`: pass the raw `period string` into `s.MonthToDateForPeriod(ctx, ownerID, period)` (or inside `monthToDateAt`) so `s.AuthorizeAs(ctx, AuditVerbMonthToDate, core.RelCanViewBilling)` runs before `ResolvePeriodEnd(period, s.Now().UTC())` across MCP, REST, and GraphQL.
  - `apps/build_sources.go:609-616`: move `if req.Git != nil && req.Image != nil` below `s.buildSourceApp(core.WithDeferredAllowedWriteAudit(ctx), core.RelCanCreate, id)` (the deferred audit context already ensures a `400` refusal writes no `"success"` audit row).
  - `postgres`/`keyvalue`/`deploys`/`webhooks`: accept raw timestamp strings in `DatabaseLogQuery` / `KeyValueLogQuery` (or pass raw strings into the service methods) and parse them immediately after `AuthorizeDatabase` / `AuthorizeKeyValue` / `AuthorizeApp` / endpoint authorization, matching `logs.Service.List` and `events.Service.List`.
