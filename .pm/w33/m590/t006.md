## Objective

Ensure every behavior shipped by `w33/m590` is pinned by a real test that fails if the fix is reverted.

## Context

- Operator build/controller tests (`lego/operator/internal/build/`, `lego/operator/internal/controller/`) and backend tests (`lego/backend/internal/store/`, `lego/backend/internal/events/`, `lego/backend/internal/usage/`).

## Steps

1. Add/verify tests covering:
   - `buildPodFailurePolicy`: `DisruptionTarget=True` ignored first; `buildkit`/`clone` exit `137` fails the Job immediately; `push`/`sign`/`cache-save` exit `137` does NOT classify as tenant.
   - `EnsureBuild` + `buildFailureMessage`: container `OOMKilled` and BuildKit child exit `137` both produce `FaultTenant`, `OOMKilled: true`, memory-limit wording (no `"infrastructure reason"`), `user_failed` metric (no `recordBuildInfraFailure`), and `App.Status` OOM fields.
   - `build_seconds`: OOM-failed build Job is billed (non-zero seconds), while a true `FaultInfra` build Job still bills `0`.
   - `reconciler` + `events`: `build_ended` carries `reason.failure.oomKilled.memoryLimit` on REST, GraphQL and MCP; non-OOM failed builds remain unaffected.
2. Prove key tests are real by temporarily reverting the behavior under test and watching them fail.
3. Record the coverage map in this file and run all affected suites (`make test`, `make lint`, `go test ./...`).
