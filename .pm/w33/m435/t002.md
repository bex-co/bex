## Objective

Move the one-time hook out of the pre-deploy step. Every release, the first included, runs `preDeployCommand` before its rollout; the hook runs once, as its own Job, after the first release is live.

## Context

- `PreDeployStepCommand` (`lego/types/v1alpha1/predeploy.go:28`) returns the hook while `!status.initialDeployHookCompleted`, else the release's `preDeployCommand`. bex-api reads the same function (`lego/backend/internal/store/reconciler.go:2630`).
- `reconcilePreDeploy` (`lego/operator/internal/controller/app_controller.go:7365`) builds and watches the Job; success sets `InitialDeployHookCompleted` at `:7501` and at `:1014`. A failure goes through `failPreDeploy` and fails the deploy.
- The Job builder is `lego/operator/internal/predeploy/predeploy.go`; the step is gated per release generation.
- Execution pods get their network policy from `reconcileExecutionNetworkPolicy`.

## Steps

1. Make `PreDeployStepCommand` return only the release's `preDeployCommand`; add the hook's own selector (hook text, and whether it is still owed).
2. Add a post-rollout phase: once the current release is live and the hook is owed, run the hook as a Job with the release's image, env, secrets and pull secrets, under the execution network policy.
3. Record the hook's run in status (job, generation, state, start and end) separately from `status.preDeploy`, and set `initialDeployHookCompleted` on success.
4. On failure, leave the deploy and the serving release untouched; the next release retries the hook after it goes live. Never re-create a Job that already ended for the same generation, as the pre-deploy step guarantees.
5. Honor the edge cases t001 recorded (suspended, canceled first release, rollback, scale).
6. Regenerate the CRD and RBAC (`make test` from `lego/operator/` runs codegen).

## Acceptance criteria

- [ ] With both commands set, a first release runs the pre-deploy Job before the rollout and the hook Job after the release is live.
- [ ] A second release runs the pre-deploy Job only.
- [ ] A hook that exits non-zero leaves the deploy live and is retried after the next release goes live.
- [ ] `make test` and `make lint` pass from `lego/operator/`.
