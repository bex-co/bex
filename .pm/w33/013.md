# w33/013 — Refresh a private-repo build's GitHub clone token before its 1-hour expiry while a deploy stays open

Why: `deploybudgets.BuildBudget` is 120 minutes while GitHub installation tokens expire after 60 minutes, so a private-repo build queued or disruption-evicted past 1 hour fails `clone` with `Authentication failed` (`ExitTenantError`), blaming tenant git auth for a platform token expiry.

## Context

- `lego/backend/internal/apps/clonesecret.go:74-141` mints a 1-hour GitHub installation token (`lego/backend/internal/github/client.go:152,234`) once at deploy trigger time and writes `<app>-clone`.
- `lego/backend/internal/store/reconciler.go:265` already holds `r.CloneSecrets` (`EnsureCloneSecret`) and reconciles every open deploy (`created`, `queued`, `build_in_progress`).
- `lego/operator/internal/controller/app_controller.go:1322` (`relocateBuildSecret`) already copies `<app>-clone` from the App's namespace into `bex-build` on every reconcile while a build is active/queued, so refreshing `<app>-clone` in `bex-api` needs no operator GitHub credentials and no new auth boundary.

## Steps

1. Stamp a minted-at timestamp annotation (e.g. `app.bex.co/clone-token-minted-at`, RFC3339) in `writeCloneSecret` (`lego/backend/internal/apps/clonesecret.go`) whenever `<app>-clone` is written.
2. In `store.Reconciler` (`lego/backend/internal/store/reconciler.go`), when reconciling an open repo-backed deploy in `created`, `queued` or `build_in_progress` that uses a clone Secret (skipping image-backed and public repos), check the Secret's age (or `ResourceVersion`/minted-at annotation, with a lightweight in-memory or Secret-annotation guard so it does not mint on every tick). If older than 45 minutes (or missing the annotation and the deploy is older than 45 minutes), call `r.CloneSecrets.EnsureCloneSecret` to refresh `<app>-clone`.
3. Verify `app_controller.go:1322` (`relocateBuildSecret` / `copyCloneSecret`) updates the `bex-build` copy when the source Secret's data changes, so any subsequent retry pod's `clone` initContainer mounts the fresh token.
4. Add unit tests covering: fresh token (<45m) is not re-minted; aged token (≥45m) on an open `queued` or `build_in_progress` deploy refreshes `<app>-clone` and updates the annotation; terminal/image/public deploys do not mint; GitHub refresh error is logged and does not crash the reconciler pass.

## Acceptance criteria

- [ ] `<app>-clone` is refreshed proactively before 60 minutes while a private-repo deploy remains `created`/`queued`/`build_in_progress`, and the operator propagates the updated Secret to `bex-build`.
- [ ] `cd lego/backend && go test ./...` and `make test && make lint` (if operator touched) pass.
