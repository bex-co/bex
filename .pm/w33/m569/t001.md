## Objective

A build is succeeded when its image is in the registry: the `push` container (or `sign`, when image signing moves `push` to an init container) has terminated with exit 0. `EnsureBuild` returns `PhaseSucceeded` then, with `FinishedAt` set to that container's `finishedAt`. It no longer waits for `cache-save` and the Job's `Complete` condition. `Complete` stays the fallback for a pod that is already gone.

## Context

- `EnsureBuild` (`lego/operator/internal/build/build.go:794-851`) maps `JobComplete` to `PhaseSucceeded`, with `jobRunWindow` as the run window (`:852-870`).
- `pushContainer = "push"` (`build.go:1105`). With `SignKeySecret` set, `push` becomes an init container and `sign` the regular one (`build.go:1568-1610`). `cache-save` is appended to the regular containers afterwards (`:1619-1621`).
- `listJobPods` (`build.go:1143`) already lists a Job's pods, and `buildQueued` uses it.
- The App reconcile re-reads an in-flight build every 5 s (`buildObserveRequeue`, `lego/operator/internal/controller/app_controller.go:1202`). Build pods live in `bex-build`, so no pod watch maps them to the App (`appPodRequests`, `app_controller.go:8437`). The poll is what notices.
- Dockerfile builds (`dockerfilePush`) and native builds (`nativePushNarration`) share the `push` container. kpack builds (`ensureBuildpack`) are out of this path.

## Steps

1. In `EnsureBuild`, before the queued check, read the Job's pod. If the image's last phase (`sign` when `o.SignKeySecret != ""`, else `push`) is terminated with exit 0, return `PhaseSucceeded` with `StartedAt` from the Job and `FinishedAt` from that container's `finishedAt`.
2. Keep the `JobComplete` and `JobFailed` branches for the cases the pod read cannot settle (no pod, the pod reaped, a failed phase).
3. Make sure a pod whose image phase has not finished still reports `PhaseBuilding`.

## Acceptance criteria

- [ ] A fake pod with `push` terminated 0 and `cache-save` running yields `PhaseSucceeded`, with `FinishedAt` equal to `push`'s `finishedAt`.
- [ ] With signing on, `push` (init) done and `sign` running yields `PhaseBuilding`. `sign` done 0 yields `PhaseSucceeded`.
- [ ] A Job that is `Complete` with no pod left still yields `PhaseSucceeded` from the Job window.
