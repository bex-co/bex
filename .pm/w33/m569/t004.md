## Objective

The build's end reads the same on every surface: REST `GET /v1/deploys` and `/v1/services/{id}/events`, GraphQL, MCP `list_deploys`/`list_events`, `bex deploys list`, and the dashboard deploy page. Each one matches Render's order of `Build successful 🎉` then `Deploying...` with no wait between them.

3. File any surface that still lags as a follow-up note.
