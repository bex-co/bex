## Objective

A private service with no explicit port, no `PORT` and no image port mode is probed by TCP on 10000 only. If its process binds another port, it never goes Ready. That covers a service switched to `redis:7-alpine`, or a native service that binds 6379. While the startup check fails, scan the unready instance as the web detector does, and adopt its lone listener as `status.detectedPort`. Render serves a private service on whatever port it binds.

## Context

- `detectBoundPort` (`lego/operator/internal/controller/port_detect.go`) returns early unless the type is a web service, and it keeps only listeners that answer HTTP (`httpListeners`, w32/037). A private service may speak any protocol, so it must not be filtered to HTTP.
- `detectPrivatePrimary` (`private_ports.go`) already rescues an image-port private service: it takes the same listener in two scans, 3000 if open, else the lowest. Reuse that choice rule rather than writing a third one.
- `App.ServingPort` (`lego/types/v1alpha1/image_network.go`) already prefers `status.detectedPort` for a configured-port spec of any type. `RuntimeOnlyPorts` publishes a private service's other listeners once it is Ready (w3/m273, w3/m276).
- `explicitServingPort` decides when detection never applies: an explicit non-default port, a `PORT` env, or an image port mode.

## Steps

1. Let the bound-port detector run for a private service in configured-port mode. Pick its port with `detectPrivatePrimary`'s rule, with no HTTP filter, and keep the two-scan confirmation and `portDetectGrace`.
2. Keep the stall texts (`DeployReasonHintListening*`, `noOpenPortMessage`) correct for a private service. It has no public route, and its "no open ports" hint stays Render's.
3. Write operator tests: a 6379-only private instance adopts 6379 and goes Ready. Two listeners take 3000 if it is open, else the lowest. An explicit port or `PORT` keeps waiting. An image-port private service still goes through `detectPrivatePrimary`. Web detection is unchanged. Revert the fix and watch the 6379 case fail.
