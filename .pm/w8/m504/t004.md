## Objective

## Steps

1. REST, GraphQL and MCP reads of `port` / `openPorts` for a switched web and a switched private service, before and after the deploy. Check them with the fake-client tests.
2. A Blueprint sync that moves an entry from a native runtime to `runtime: image` goes through the same operator path, with no port mode written. Confirm it with a test or by reading the code.
3. The dashboard Settings port row reads the same value (`SavedPort`).
4. Record any drift as a follow-up note. Do not fix it silently.
