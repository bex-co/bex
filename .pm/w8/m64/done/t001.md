## Done 2026-10-13

`knownServiceEnv` (`lego/backend/internal/apps/deploy.go`) dedupes a source's links by first occurrence, as the initial composer keeps them, and records each known value's provenance (own literal, seed, group). Seed- or group-derived copies are kept as `stateCopies`; `currentStateCopyProblems`, called from `validateBlueprintServices` before any write on both validation and apply, re-derives them for a source that already exists: its current links (`EnvGroupApplier.LinkedGroupNames`, group identity only) then newly declared links appended. The effective value replaces the parse-time guess in place; an existing source's seed (seed-once, possibly edited) or a retained link to a group the file does not declare is a located refusal at the consumer's entry.
