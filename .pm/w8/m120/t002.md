## Objective

When a release is adopted, record its own runtime settings and snapshot its configuration Secrets, so a later save cannot change what that release runs.

## Acceptance criteria

- [ ] A save that lands after adoption leaves the adopted release's record and snapshot unchanged (unit and envtest).
- [ ] A single deploy is unchanged.
