# A Blueprint whose repo is on GitLab or Bitbucket has its render.yaml and commit read from github.com under the same owner/repo

Why: `blueprintRepoToken` (`lego/backend/internal/github/service.go:1562`) takes owner/repo from `ownerRepo`, which drops the host (`service.go:1491`). `resolveBlueprintCommit` (`service.go:1591`) and the content fetch (`service.go:1618`) then call the GitHub API with that pair. So a Blueprint repo `https://gitlab.com/<owner>/<repo>` pins a commit and reads `render.yaml` from `github.com/<owner>/<repo>`: a different repository, possibly another party's, or a 404 that names the wrong host. Render reads a Blueprint from the repo it was given.

- **Source:** follow-up from the w8/343 worker (`c5f5e4915`, `7954674a1`), 2026-11-20. Found by code reading while fixing non-GitHub repo validation; **not reproduced live**.
- **Severity:** major if reproduced. A Blueprint sync applies a configuration from a repository the user never named.
- **Fix direction:**
  - Make the Blueprint fetch host-aware. A github.com repo keeps today's path.
  - A public GitLab or Bitbucket repo fetches over public git transport: `resolvePublicGitCommit`, which already exists for github.com fallbacks, plus a raw read of `render.yaml` at that commit.
  - Any other host, or a private one that can't be reached, answers a 400 that names the host. It never falls through to github.com.
  - Check what Render supports for GitLab and Bitbucket Blueprints before choosing between "fetch" and "refuse". Its docs cover GitLab and Bitbucket repos for Blueprints.
- **Done when:**
  - A unit test shows a gitlab.com Blueprint URL never calls the GitHub client with its owner/repo.
  - A live dry run of a Blueprint pointing at a public GitLab repo either reads that repo's `render.yaml` at its pinned commit or is refused with the host named.
  - A github.com control is unchanged.
- **Blast radius:** every caller of `blueprintRepoToken` (`service.go:1592`, `1618`), and any other `ownerRepo` user that then calls the GitHub API. Grep them in the same change.
- **Estimate:** ~1h.
