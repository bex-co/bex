## Objective

Keep native platform helpers working while handing the user build command its exact configured PATH, for both mutable env storage and Blueprint literals.

## Context

- [Finding](finding.md): two native CLI builds fail; changing only PATH recovers the same commit.
- `native.go:235–242` exports PATH before later `base64` calls. `:290–295` installs literal PATH into the preparation container, which also affects its relative shell and codec tools.

## Steps

1. Preserve the user's literal PATH without replacing the preparer's own tool lookup; keep values in the existing preparation transport.
2. Make RUN decoding independent of application PATH, or install the final user PATH after decoding all records.
3. Retain exact bytes, omitted/empty behavior, last-wins and literal-over-Secret precedence. Keep image-default PATH when no user PATH exists.
