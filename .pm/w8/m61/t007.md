## Objective

Accepted empty application PATH must reach the authored absolute Node start command, with all configured bytes intact, after a successful native build.

## Context

- [Two native failures and causal controls](evidence/live-node-sweep216/README.md). Render reaches update_failed; Bex is captured stalled with the same startup failure, then superseded by the owned recovery control.
- Source-pinned Node image metadata on Linux amd64 and arm64: ENTRYPOINT docker-entrypoint.sh, copied to /usr/local/bin. The actual deployed artifact config/SHA is not inspected.
- nativeDockerfile at lego/operator/internal/build/native.go:234 replaces CMD but retains this entrypoint; appContainer at lego/operator/internal/controller/deployment_projection.go:245 preserves native image launch. Current generated RUN tests pass for empty PATH and miss this boundary.

## Steps

1. Remove the inherited-relative-entrypoint dependency for native-generated images, evaluating an explicit empty ENTRYPOINT before the authored absolute CMD. Preserve user PATH exactly, including empty; add no reserved-name refusal or launcher rewrite.
2. Audit the one generator/serving consumer, all six native toolchains and web/private/worker/cron/static consumers. Preserve buildpack and opaque Docker image launch contracts, pre-deploy/one-off commands and cache/release identity.
3. Repeat fresh Free Node PATH= journeys through published/current Bex and the unmodified pin. Both must reach Live/HTTP200 with build and runtime PATH still empty, matching marker/file hashes and unchanged absolute commands. Full-PATH recovery is a control, not acceptance.
4. Run omitted/normal/narrow, literal-over-stored and image-level entrypoint regressions, then required checks and exact-owned cleanup.

## Acceptance criteria

- [ ] Inherited toolchain entrypoints cannot stop the authored native command solely because user PATH is empty.
- [ ] Both unchanged clients reach Live/HTTP200 with PATH still empty and exact marker/file bytes.
- [ ] Native siblings and opaque Docker/buildpack launch behavior are checked without a global environment rewrite.
- [ ] The runtime regression fails on the current inherited-entrypoint implementation and passes the correction; local helper checks alone are insufficient.
- [ ] Every owned resource is reconciled and remaining hosted/surface limits are explicit.
