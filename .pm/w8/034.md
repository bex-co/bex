# 034 — A service rename accepts control characters, unbounded length and another service's `srv-` id as the display name

Why: rename is the one free-form name path, and it takes anything. A newline in a name breaks the `bex services -o text` table and every other one-line rendering. A 1,000-character name is stored as is. A name equal to another service's id (`srv-…`) puts two rows in the list that both "look like" that service. Ids still resolve correctly (by-id beats by-name), but the list becomes misleading, and in a shared workspace that is an easy way to confuse a teammate.

Live, 2026-09-27, production `4a0422577`, `bex v0.2.1` (pin v2.27.0), human device login, workspace `bex-canary`. Found by the `/qa-find-bugs-cli` sweep 56. Fixtures: free crons A `srv-dasjis3ncejs739qitcg` and B `srv-dasjisi1pbgc73a24kag` (both deleted).

```text
$ bex services update B --name "$(printf 'qa56line1\nline2')"   → exit 0, stored 'qa56line1\nline2'
$ bex services -o text
qa56line1                                                  Cron Job       srv-dasjisi1pbgc73a24kag
line2                                                                     ← table row split
$ bex services update B --name "<1000 × n>"                     → exit 0, stored in full
$ bex services update B --name "  spaced  "                     → stored 'spaced' (trimmed: correct)
$ bex services update B --name srv-dasjis3ncejs739qitcg         → exit 0: B is now named with A's id
$ bex deploys list srv-dasjis3ncejs739qitcg                     → A's deploys (id wins, safe)
```

## Mechanism

`lego/backend/internal/apps/service.go` `SetDisplayName` (`:4203-4232`) trims whitespace but applies no content or length rule. Create is strict (DNS label, 1–30 chars), so the display name is the only unconstrained name.

## Fix

In `SetDisplayName` (and every rename surface: REST `PATCH name`, GraphQL `setDisplayName`, MCP `update_service(name)`, dashboard Settings), refuse:

- control characters (`unicode.IsControl`, including `\n`, `\r`, `\t`),
- names longer than a bound (pick one, e.g. 100 characters; confirm Render's limit in the parity check),
- a name matching the typed-id shape of any resource kind (`^(srv|dpg|red|evm|prj|tea|dep|…)-[a-z0-9]{20}$`).

Each gets a named 400. Coordinate with `w8/m47` (rename uniqueness), which touches the same function.

## Acceptance

- [ ] Renames containing a newline, over the bound, or shaped like `srv-<20>` → exit 1 with a named error. `"  spaced  "` still trims and succeeds.
- [ ] Unit test over the three refusals on the shared rename path.
