## Objective

Add `generateValue` to the env-var write verb in `internal/secrets`: when true (and no explicit value given), mint a cryptographically random value server-side and store it in OpenBao exactly like a user-supplied one. Match Render's field semantics (their OpenAPI: `generateValue` on env-var input; base64-ish random string).

- `lego/backend/internal/secrets/` — env-vars verbs are OpenBao-backed (`docs/ADR013-secrets.md`); 503 without `BEX_OPENBAO_URL`.

- An explicit `value` alongside `generateValue: true` must be rejected or resolved per Render's documented behavior — check, don't invent.

## Steps

1. Extend the write request type + validation; mint via `crypto/rand`.
2. Return the minted value in the write response (the caller must be able to see what was generated), stored thereafter like any env var.
