## Objective

Say where a refused source goes and why, so the next change to the proxies keeps the refusal and its security property.

## Context

- ADR021 § IP allowlist says the proxy checks the source "before dialing the store" (`docs/ADR021-keyvalue-management.md:50`). § 3 describes the pass-through.
- The operator guide's `kv-sni-proxy` rows and its "Internal Key Value proxy" section list the proxy's env vars (`lego/operator/AGENTS.md`).

## Steps

1. ADR021 § IP allowlist: a refused source on a known name is answered by the store's own proxy, with the store's certificate, with Render's text for each command, and its connection never reaches Valkey. An unknown name is still dropped. Record the held-template choice (t002) and the degraded path.
2. `lego/operator/AGENTS.md`: the new env var in the internal proxy section, and the refusal in the `kv-sni-proxy` row.
3. Run `npx prettier@3.4.2 --write` on both files from the repository root, and `bash scripts/docs-links-validate.sh`.
