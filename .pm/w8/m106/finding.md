# The documented Hugo static-site build cannot find Hugo

**Severity: major. Attribution: native static-build tool supply.** Both published Bex0.3.2 and unchanged pinned Render2.27.0/a764810a7682 create fresh Free static sites through unchanged captured POST201/exit0, then their first builds fail `hugo: command not found`. Adding only a Hugo package-install line makes both replacements Live. Six HTTP200 checks verify actual generated indexes, proof artifacts and theme stylesheets. [Results](evidence/cli-sweep431/results.json), [complete native records](evidence/cli-sweep431/complete-native-staged-Hugo-failures-controls-and-cleanup.json).

[Render's Hugo quickstart](https://render.com/docs/deploy-hugo) links the tested sample and prescribes `hugo --gc --minify` with publish directory `public`. This establishes static build availability. Hugo is not listed in the general [all-native tools table](https://render.com/docs/native-runtimes#tools-and-utilities), so this finding makes no compute-runtime availability promise. Render hosting was not tested.
