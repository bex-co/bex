## Objective

Decide which PostgreSQL role attributes the owner and each Render-style default credential carry. `CREATEDB` is required by Render's "Adding multiple databases to a single instance". For `CREATEROLE`, read Render's credentials page ("Users created directly with the `CREATE USER` command are not managed by Render") and choose the parity-sufficient rule; file any stricter or looser variant as a follow-up. Also decide what a retired (tombstoned) user keeps. Record the rule in ADR009 and in ADR018's Postgres row, with Render's sentences quoted.

## Acceptance criteria

- [ ] ADR009 and ADR018 state the attributes of the owner, a default credential, an auxiliary user and a retired user.
- [ ] A kind or docker spike shows CNPG applying the chosen `spec.managed.roles` attributes to an existing role without a restart.
