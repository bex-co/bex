## Objective

Add a clusterwide Cilium policy that drops ingress from any workspace-labeled tenant pod to a free-plan web pod, so a free web service is reachable only through the public edge, as on Render.

## Context

- `deploy/gitops/base/tenant-node-egress.yaml:126-146` (`deny-free-plan-smtp-egress`, the free-plan precedent)
- `lego/operator/internal/execution/security.go` (`LabelFreePlan`), `lego/operator/internal/controller/container_policy.go:28-58`
- Per-App policy: `lego/operator/internal/controller/app_controller.go:6564` `reconcileNetworkPolicy` (same-workspace allow)
- `scripts/gitops-validate.sh` (m127 guard)

## Steps

1. Confirm a free web pod carries `app.bex.co/free-plan: "true"` and a selector that distinguishes web from other types (add a type label only if none exists).
2. Write `deny-free-plan-private-ingress`: `endpointSelector` free-plan web; `ingressDeny` `fromEndpoints` with `app.bex.co/workspace` Exists in any namespace (`k8s:io.kubernetes.pod.namespace` unconstrained); `enableDefaultDeny.ingress: false`.
3. Check on the pinned Cilium (kind) that Traefik, the activator and kubelet probes still reach the pod and that the per-App allow does not override the deny.
4. Inventory live free web Apps receiving same-workspace traffic before rollout (Hubble or flow logs); record the count in the milestone README.
5. Add the gitops-validate guard.

## Files

- `deploy/gitops/base/tenant-node-egress.yaml` (or a sibling ingress file)
- `scripts/gitops-validate.sh`

## Acceptance criteria

- [ ] On kind: a tenant pod's connect to a free web pod's ClusterIP times out; Traefik → pod returns 200; the activator wakes a sleeping free pod.
- [ ] A paid web pod is still reachable from the same tenant pod.
- [ ] gitops-validate fails if the policy is removed or its selector changes.

## Out of scope

- Changing Postgres/Key Value reachability.
