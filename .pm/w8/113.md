- operator/internal/build/native.go:262–270 emits the generated image and authored build RUN. Its nonstatic tail:279–284 adds only PORT/entrypoint/CMD, with no Python Gunicorn defaults. - [Gunicorn26.2.0 config](https://github.com/benoitc/gunicorn/blob/26.2.0/gunicorn/config.py) consumes GUNICORN_CMD_ARGS at79–82; defaults accesslog to None at1323–1334 and preload_app to false at1018–1030. [The real logger](https://github.com/benoitc/gunicorn/blob/26.2.0/gunicorn/glogging.py#L331) skips access output when disabled and sends enabled dash output to stdout. Gunicorn itself derives its default bind from PORT. No launcher request rewrite is warranted.
- backend/internal/logs/service.go:45–55 distinguishes app-container output from edge request logs; QueryLogs:548–623 reads the durable or pod source. The working observer/startup output and all control access lines prove the application log path works. This finding does not claim missing edge request logs or lost ingestion.
