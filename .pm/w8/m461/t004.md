## Objective

REST, GraphQL, MCP and the dashboard agree on a switched service's runtime, commands and deploy behavior, and those match an image-created service and Render's image-backed service contract.

## Steps

1. Diff `GET /v1/services/<id>` for a switched service against an image-created service on the same image, ignoring IDs, names and timestamps.
2. Check GraphQL `service { runtime builder startCommand buildCommand }`, MCP `get_service`, and the dashboard Settings page for the same service.
3. Record the Render evidence in ADR018's runtime row: Render's docs don't say whether a Git-backed service can switch to an image, and an image-backed service reads `runtime: image` with an optional Docker Command. Record bex's switch as an extension and file any drift as follow-up work.
