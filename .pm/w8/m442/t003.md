## Objective

Render's sandbox build create now says its `name` "Can't start with `sbb-`, the prefix reserved for build IDs." `validateImageName` accepts such a name, so a later `buildName` lookup could collide with a build ID. Refuse it.

## Context

- `lego/backend/internal/sandbox/images.go:381-388` (`validateImageName`): 1–255 characters, no surrounding spaces, no control characters.
- Sandbox create resolves `buildId` (an `sbb-` ID) or `buildName` (`sandbox/rest.go:61-64`).

## Steps

1. Refuse a name with the prefix `sbb-` (case as Render's pattern, `^sbb-`) with the existing `CodeSandboxImageInvalid` 400 and a message naming the reserved prefix.
2. Keep names that merely contain `sbb-`.
