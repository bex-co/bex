resource resolver only handles service/postgres/keyvalue kinds
(`lego/backend/internal/apps/blueprint.go` ~852-876), so env-var groups a
blueprint creates never appear in `resources[]` — Render's wire shape includes
`environment_group` entries. Related: an env-group-only stack suppresses the
action plan entirely (`blueprint_state_plan.go:35`), so such a blueprint
previews as "no actions" despite creating groups.

make env-group creates count as plan actions. Sub-hour; touches the resolver +
plan + one test each. Verify current line numbers first — m19/m20 reworked
