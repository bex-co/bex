## Objective

Run an end-to-end traffic matrix on the production-equivalent Cilium path and prove each byte class lands once on the intended resource while excluded traffic lands nowhere.

## Context

- Unit tests cannot prove eBPF hook placement, Cilium coexistence, LB/proxy routing, or actual Prometheus labels.
- The local CAPD app cluster uses Calico, so this validation needs a dedicated Cilium fixture or controlled live rollout.
- Evidence must avoid committing tenant identifiers or raw traffic.

## Steps

1. Generate bounded HTTP, WebSocket, direct TCP/UDP, private-service, Postgres, and Key Value traffic.
2. Restart pods and meter/proxy processes, then verify deltas and recovery.
3. Record only aggregate expected/observed ranges, resets, and coverage status.

## Acceptance criteria

- [ ] Included paths increase exactly one resource's expected source within a documented tolerance.
- [ ] Same-workspace/private, control-plane, DNS-to-cluster, dropped, and backup paths do not increase tenant egress.
- [ ] Restart/reset tests produce no negative, duplicated, or silently missing hourly usage.

## Out of scope

- A 28-day cap-data audit.
