## Objective

Query and sum the correct independent sources for each resource kind while preserving `m11`'s successful-zero, failure, retry, and gap-free cursor contract.

## Context

- App egress is router responses plus direct public traffic; Postgres and Key Value egress are their public proxy responses.
- A missing required source is failure, not zero; non-applicable sources are explicit N/A.
- Deploying the new composition invalidates HTTP-only bandwidth observations for cap selection.

## Steps

1. Implement per-resource source composition and reject partial successful sums.
2. Persist successful zero rows for Database and Key Value egress and give each an independent cursor.
3. Update usage docs, pricing descriptions, and `w8/001` with the exact new evidence origin after rollout.
