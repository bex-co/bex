# Keep Python 3.14.10 as the no-signal default, a signed-off divergence for the Brotli fix?

Why: w8/217 shipped the parity-first default (AGENTS.md: "Never park parity work on an optional decision. Ship the parity-sufficient choice, and file stricter or looser variants as separate follow-ups"). A native Python service created on or after 2026-10-23 with no version signal now builds on Render's exact default 3.14.8 (`pythonDefaultVersion`, `lego/operator/internal/build/nativeversion.go`), from the official `python:3.14.8-bookworm` image pinned by digest at build time. That image is no longer rebuilt upstream, so it still ships the vulnerable system `libbrotli1 1.0.9-2+b6` (CVE-2026-111497). `63fd10231` refreshed the 3.14 line to 3.14.10 (`libbrotli1 1.0.9-2+deb12u1`) to remove it (w1/136). The native build takes its interpreter from the toolchain image, so 3.14.8 cannot sit on the refreshed base layers without a bespoke image.

Severity: **minor** (system `libbrotli1` is reached only by code that decompresses through the system library; CPython itself does not link it). Attribution: platform build (native default resolution). Estimate: ~20m once decided. Filed 2026-10-29 from w8/217.

## Evidence

```text
docker buildx imagetools inspect python:3.14.8-bookworm  (2026-10-29)
  index digest sha256:d971782704801eedcce987f5a3aa473500e255094e86400e2078a74652973b74
  SBOM (linux/amd64): libbrotli1@1.0.9-2+b6          (unfixed; DLA-4855-1 fix is 1.0.9-2+deb12u1)
python:3.14-bookworm@sha256:a8cf203c… (reviewed 3.14 line, 3.14.10): libbrotli1 1.0.9-2+deb12u1 (w1/136 evidence)
```

## Decision needed

1. **Keep exact 3.14.8 (current, shipped by w8/217):** Render-identical; new no-signal Python services run on the frozen 3.14.8 image without the Brotli fix. Whether Render's own 3.14.8 runtime carries a patched Brotli is unverified.
2. **Revert the default to 3.14.10:** drop `pythonDefaultVersion` from `exactDefaults`, record the divergence in ADR018 with the security reason and the user's sign-off, and amend w8/174's acceptance text (`Python 3.14.8` → the 3.14 line's reviewed patch).
3. **Bespoke 3.14.8 on the refreshed base:** build and publish a bex-owned 3.14.8 image on the patched bookworm base (or add an `--only-upgrade libbrotli1` layer to the frozen image). Parity and the fix, at the cost of a maintained image; w1/136 already declined per-build apt upgrades.

## Acceptance

- Option 1: close this note with the user's answer recorded. Option 2: a new no-signal Python service logs `Python 3.14.10`, ADR018 carries the signed-off divergence, and `TestPythonDefaultIsRendersExactPatch` is replaced by a test that the default keeps the reviewed patch. Option 3: the default image's SBOM lists `libbrotli1 1.0.9-2+deb12u1` and `python --version` prints `Python 3.14.8`.
