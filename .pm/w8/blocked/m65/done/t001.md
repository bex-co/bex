## Done 2026-10-13

- **Installed:** `deploy/gitops/base/cnpg-operator.yaml` pins the mirrored chart `cloudnative-pg 0.29.0` (`deploy/helm-artifacts.lock`), whose `appVersion` is **operator 1.30.0** (chart index, created 2026-06-29). The live instance-manager identity was not read from the cluster.
- **Fix:** upstream PR [#11131](https://github.com/cloudnative-pg/cloudnative-pg/pull/11131) ("fix(logging): stop sampling logs of the pods' processes", merged 2026-07-28, labels `release-1.28`, `release-1.30`) is in `v1.30.0...v1.30.1` (GitHub compare). **Target: chart `0.29.1` / operator 1.30.1** (2026-09-23), a same-minor patch release, so no CRD/API-major migration is expected.
- **Rollout risk (why this needs a decision):** the repo does not enable CNPG's in-place instance-manager updates (`ENABLE_INSTANCE_MANAGER_INPLACE_UPDATES` absent from `deploy/`), so an operator upgrade rolls every managed Cluster's pods to the new instance manager — the control-plane database and every tenant Postgres, including single-instance Free ones that have no replica to fail over to. The pin is also an immutable GHCR mirror digest that only the credentialed `scripts/helm-artifact.sh mirror` step in `deploy.yml` produces.
