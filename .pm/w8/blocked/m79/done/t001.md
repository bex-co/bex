# Implement bounded automatic Brotli for static responses

## Objective

Make eligible static assets negotiate Brotli and preserve HTTP representation semantics.

## Context

[Finding](../finding.md) and [durable evidence](../evidence/cli-sweep326/README.md). Functional CLI QA found a minor Render static-compression gap; no implementation is included.

## Steps

1. Trace all three serveObject callers and choose a bounded encoding/cache strategy within existing budgets.
2. Implement Accept-Encoding negotiation and useful-size/MIME selection, preserving identity, authored encoding and no-transform.
3. Preserve framing, validators, HEAD/ranges/preconditions, revision isolation and existing custom headers.

## Files

- lego/operator/internal/staticserver/staticserver.go
- lego/operator/internal/staticserver/cache.go
- lego/operator/internal/staticserver/s3origin.go

## Acceptance criteria

- [x] The three failing real-Handler Brotli cases encode and decode to exact original content; identity and precompressed controls remain correct.
- [x] Memory/CPU/cache behavior is bounded and no identity payload is mislabeled.

## Out of scope

Paid fixtures, CDN/purge infrastructure, unrelated API compression, CLI forks, security reviews and any mutation of baseline resources.

Done 2026-10-15 (agent worktree, integrated by worker8): new `lego/operator/internal/staticserver/encoding.go` hooked into `serveObject`, so direct file/index, rewrite target and SPA fallback all choose identity or `br` before http.ServeContent (304/412/Range/HEAD apply to the bytes sent). Eligible: text-like types (text/JS/JSON/XML/SVG/wasm/uncompressed fonts), 1 KiB–8 MiB, no authored Content-Encoding and no `Cache-Control: no-transform`; `br` only when Accept-Encoding gives it (or `*`) q>0; `Vary: Accept-Encoding` merged; exact Content-Length; strong ETags sent weak on br; authored precompressed bodies byte-for-byte. Encoded once per revision key into the existing per-site/global cache budget, quality 5 / 1 MiB window, ≤2 concurrent encodes (one per site) leased from the live-body budget; incompressible assets remembered; budget pressure falls back to identity 200. Dependency: github.com/andybalholm/brotli v1.2.6 (MIT, pure Go, no cgo) in lego/operator/go.mod — stdlib and klauspost/compress have no Brotli encoder.
