## Objective

Add comprehensive multi-instance real-Postgres integration tests covering every acceptance criterion and failure mode of the shared rate limiter and shared log-subscription caps, and verify the full backend suite and linter pass.

## Context

- Standing closing task per `.claude/skills/pm/SKILL.md`.
- `w8/417` requires: "A test with two limiter instances sharing the store: 400 GETs across both in a minute succeed, and the 401st is refused, with `RateLimit-Remaining` consistent across instances."
- Also cover the other Render rows, sandbox classes, GraphQL/MCP refunds, deploy hooks, fail-open store outage, and two `logs.Service` instances sharing subscription caps.

## Steps

1. Add multi-instance real-Postgres tests (in `lego/backend/internal/api/` and `lego/backend/internal/logs/`, skipping cleanly only when `BEX_TEST_PG_URI` is unset and failing under `BEX_TEST_REQUIRE_DEPS=1`, matching existing `*_pg_test.go` conventions):
   - Two `api.Server` (or `api.RateLimiter` + `RenderRateLimits`) instances sharing one `*store.PGStore` on a controlled clock: 400 Render `GET` requests spread across both instances within a minute succeed with `RateLimit-Limit: 400` and `RateLimit-Remaining` stepping `399, 398, …, 0`, and the 401st request on either instance returns 429 with `Retry-After` and `RateLimit-Remaining: 0`.
   - Two instances sharing the per-service deploy row (REST deploy + deploy hook across instances: 10 succeed, 11th returns 429) and the hourly service-create row (20 succeed across both, 21st returns 429).
   - Two instances sharing sandbox rate classes (e.g. 100 creates across both succeed, 101st refuses).
   - Multi-bucket refusal leaves the caller's row untouched when the workspace bucket refuses; MCP/GraphQL refund returns the general token in Postgres.
   - Simulated Postgres failure falls back to the in-process limiter (no 500s) and still enforces the local bound.
   - Two `logs.Service` instances sharing one `*store.PGStore`: per-subject, per-workspace, and global caps enforce one total across both instances; closing a stream frees its slot on the other instance; an expired lease is reclaimed.
2. Mutation-check the key tests (verify that disconnecting the shared store breaks the cross-instance 400/401st test and the cross-instance SSE cap test).
3. Run the full real-DB backend suite (`scripts/backend-test-deps.sh` + `BEX_TEST_REQUIRE_DEPS=1 go test -p 1 ./...`) and `make lint` from `lego/operator/`.
4. Record the DoD → test map in `.pm/w8/m579/README.md`.
