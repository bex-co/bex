## Outcome (2026-10-16)

Dispositions: every native runtime and line (Python 3.10–3.14, Node 22/24/26, Ruby, Elixir, Go, Rust) and static sites get the same step, matching Render's tools table (all native runtimes, build + runtime); the source root is irrelevant to the supplier. Shared consumers: `nativeDockerfile` is the sole generator (build.go → nativeBuildPreparer); the resolve phase's FROM rewrite and companion inserts keep it. Dockerfile/image sources and datastores untouched. Layering: the copy to `/` creates no parent directory, so the layer is byte-reproducible — one ~110 MB compressed (~226 MB uncompressed) layer per architecture shared by every native image, stored once in the registry and pulled once per node (a `/usr/local/bin` destination produced a new blob per cold build; verified and pinned by a test). Each cold build still fetches the pin from Docker Hub, like its base. Executed on linux/arm64 locally; amd64 is the pinned index's other manifest, unexecuted here.
