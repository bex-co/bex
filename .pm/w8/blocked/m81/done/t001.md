## Outcome (2026-10-16)

`ResolveNativeUV` (nativeversion.go) opts a native Python build in on a regular-file `uv.lock` in the service's root directory and takes `UV_VERSION` (exact release) or Render's default 0.12.10; `addNativeUV` (nativeresolve.go) installs exactly `uv==<version>` into `/opt/bex/uv` on the selected Python right after the FROM (before source/build, after Poetry's step) and links `/usr/local/bin/uv` + `uvx`, so build, pre-deploy and runtime find it with no app installer or PATH change. Narrated `==> Using uv 0.12.10 (from uv.lock)`. Poetry and uv share `nativePythonToolInstall` (Poetry's step is byte-identical); provenance follows m72's exact-PyPI-release convention (ADR060 D7).
