# Forward stdin to noninteractive psql imports

Why: A successful CLI CSV import currently writes no rows because the child receives EOF instead of the caller's data, misleading automation about completion.

**Severity:** major. **Status:** blocked — upstream patch prepared 2026-10-16; needs the user's authorization to submit upstream. **Estimate:** 55m active work: explicit reader/caller10m, real-child regression controls20m, native replay15m, shared-call/adoption review10m. ## Cause and repair

The pinned `cmd/psql.go:94–109` validates noninteractive arguments, calls `views.ExecutePSQLNonInteractive` at103 and prints PSQLResult unchanged. Its sole production helper is `pkg/tui/views/psql.go:45–95`: it resolves the database/connection, builds the actual external psql command at75–80, attaches stdout and stderr at82–84, and runs at86, without setting `cmd.Stdin`. Go's [exec.Cmd contract](https://pkg.go.dev/os/exec#Cmd) gives an unassigned stdin a null-device source. PostgreSQL's [psql COPY contract](https://www.postgresql.org/docs/18/app-psql.html) makes pstdin read psql's stdin even with a command source. Immediate EOF explains the successful zero-row import. This is an upstream client I/O defect, not a Bex API request or database repair.

Pass Cobra `cmd.InOrStdin()` explicitly as an `io.Reader` into ExecutePSQLNonInteractive and assign it to the external child's Stdin before Run. Preserve stdout-only PSQLResult and JSON/YAML/text schemas, existing error handling, argv/connection/CA handling and cancellation. Coordinate the signature with the separately prepared diagnostic-writer patch in [blocked079](079.md). Avoid process-global stdin replacement, launcher interception or a second CLI implementation.

The same helper remains unconnected in released upstream2.29.0/af9bdd180e90ab9d1e971d73185687fed9ef08d8 and current upstream main afeb8c0d2e5faea3f534f3ff021e62b5a7e2f14c, inspected as source only. A pin bump to that release alone is not a demonstrated repair. No product fix, upstream patch, external issue/PR/message, Bex pin change or release was made in this sweep.
