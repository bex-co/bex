## Objective

A static site that serves a publication applies its service, environment and workspace IP rules within seconds of a save, whatever state its newest release is in: building, publishing, stuck or failed. This is w32/m419's guarantee for web services over failed image deploys, extended to static sites. Production let a client outside `203.0.113.0/24` read the site with 200 for about 36 minutes after the rule was saved (07:22:31 → 07:58:14, including after the deploy failed at 07:42:07).

## Context

- The static host's routing and IP middleware converge in `convergeStaticRouting` (`app_controller.go:5029`), reached only at the end of `reconcileStaticSite`.
- w32/m419's web-service path (ADR018 inbound IP allowlist row) shows how a rule reaches the serving release ahead of the rollout.
- Workspace and environment layers: w9/m388.

## Steps

1. Converge the static host's routing, including the IP middleware, on every pass once a publication is active, before any branch that can return early on an unsettled or failed release.
2. Cover a failed first release that still serves, not only a stuck one.

- `lego/operator/internal/controller/app_controller.go` (static routing)
