## Outcome (2026-10-19)

Counted inventory:

- **Pinned types:** one gate, `releaseInFlight` through `pinnableSourceRelease`.
  - Native and Docker web and private services, and workers, record `activeRevision` in `markRunning`.
  - Cron records it when it reconciles the CronJob.
  - A source-built static site records it on publish. It is now pinned through `Publishing`, so SA publishes before SB, as Wait describes.
  - Prebuilt images, suspended apps and direct static publish never pin. The finding's prebuilt-image control is unchanged.
- **Overlapping triggers:** `services update`, `deploys create`, git push, env/env-group/secret-file changes, Blueprint sync and deploy hooks all enter through the stamped release generation, so there is one operator path.
- **`activeRevision` readers:**
  - `deploys/rollback_config.go` `servingDeploy` now finds the served release;
  - `apps/service.go` `Revision` and the dashboard's current revision display it;
  - operator `successfulReleaseGeneration` / `releaseHasServed` are now accurate for cancel and failed-rollout restores.
- **Controls:**
  - m117's six cancel envtests and the w5/m114 suspend envtest pass;
  - the w2/018 queued replacement is unchanged (`TestCreateDeployKeepsActiveAndQueuesLatestOverlap`);
  - build failure keeps `build_failed` precedence (w6/m100), which is checked before the new branches.

ADR060 §D1a carries the "rolled out means served" note.
