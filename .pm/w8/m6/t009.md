## Objective

Once all other tasks are complete and the milestone's definition of done actually holds, close the milestone.

## Context

- See `.claude/commands/pm.md` § Closeout for the exact move sequence.

## Steps

1. Verify the DoD: a user can pick a past month on the dashboard Usage page and see correct totals matching REST `?period=`; GraphQL/REST/MCP all accept the same `period` shape.
2. Set every remaining task's `status: done`, move each `tNNN.md` to `w8/m6/done/`.
3. Mark every row `— **DONE**` and set `**Status:** done` in `w8/m6/README.md`.
4. Move the whole `w8/m6/` directory to `w8/done/m6/`.
5. Check `- [x]` for m6 in `w8/README.md`.
