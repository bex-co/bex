- **Keep 512 KiB (recommended):** change the handler's 413 text, code comments, the 026 note and ADR049 to say 512 KiB, and record it as a divergence from Render's 10 MiB in ADR018. Consider lowering the route's widened body cap to match.

Acceptance: a 600 KiB Blueprint and a 3 MiB one get the same named limit, in the same wording, on the validate route, and the docs state that limit.
