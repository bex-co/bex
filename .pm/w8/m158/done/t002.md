## Objective

bex-api writes one `server_failed` fact per recorded exit, keyed by instance and restart count, with the reason code (`non_zero_exit` and the exit code, `oom_killed`, or an early-exit code for status 0), the instance and the finish time. The sampled outage adds no `server_failed` of its own when an exit was recorded for the service inside it, and keeps its `server_available`.
