## Boundary and scoped correction

- Pinned [`cmd/ssh.go:119–125`](https://github.com/render-oss/cli/blob/a764810a768202704e7206eb7b87a47211fcd98e/cmd/ssh.go#L119) builds a fresh SSHInput with the selected Project and EnvironmentIDs, leaving ServiceIDOrName empty. It calls uppercase **InteractiveSSHView**, the direct execution-view constructor at42–44.
- The correct chooser dispatcher, lowercase **interactiveSSHView**, has the empty-selector branch at53–76. That branch creates NewServiceList and uses `getServiceListInput:98–112`, retaining this project's nonempty environment scope and supported web/private/worker type restriction.
- `pkg/tui/views/ssh.go:33–38` always constructs an ExecModel. Its `loadDataSSH:140–149` resolves ServiceIDOrName through `getServiceFromIDOrName:107–137`; the latter sets `Name: &client.NameParam{idOrName}` at119–121 and does not consume Project/EnvironmentIDs. Here that is a one-element empty-name selector.
- `pkg/service/repo.go:27–36` adds the selected workspace, and the actual generated `pkg/client/client_gen.go:20410–20447` serializes the empty selector as `name=`. The [actual-pin builder probe](evidence/091/builder-probe.go.txt), [module](evidence/091/go.mod.txt), [checksums](evidence/091/go.sum.txt), and [three outputs](evidence/091/builder.json) preserve empty, nonempty and omitted name inputs without sending HTTP.
- [Separate API diagnosis](evidence/091/diagnostic-wire.json) sends that generated empty-name shape: `GET /v1/services?name=&ownerId=tea-daif693dqjvc73e7as3g&limit=100` returns400 and complete `{error,id,message}` naming `name`. Regardless of how a server treats an empty name, the project action should return a chooser and should not attempt connection preparation.

Change **only this project callback's dispatch** to the existing lowercase chooser dispatcher. Preserve selected Project/EnvironmentIDs for the scoped list, and nil clearing for the unfiltered list. Keep direct service/instance arguments and the services palette's intentional direct-service SSH action on their existing paths. No server filter relaxation, request rewriting, launcher fork, new SSH transport or dashboard/GraphQL/MCP field is needed.
