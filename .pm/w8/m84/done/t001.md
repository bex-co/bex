## Outcome (2026-10-16)

Every Database reconcile applies an owned `postgresql.cnpg.io/v1` Database child `<db>-app` (`database_extensions.go`) adopting the application database (its recorded name and owner; restores copy the source's) with `extensions: [{name: vector, ensure: present}]`, `ensure: present`, `databaseReclaimPolicy: retain` and no pinned version. CNPG installs vector as superuser, so the owner's `CREATE EXTENSION IF NOT EXISTS vector` becomes a no-op. The verdict projects onto a new `ExtensionsReady` condition (Pending/Applied/ApplyFailed — failure read regardless of generation since CNPG bumps observedGeneration only on success; ApplyError on a write error; ReservedDatabaseName for a PostgreSQL-owned name, which gets no child). The child never fails the Database. Watched via `Owns` (resourceVersion), RBAC (`config/rbac/role.yaml`, day-to-day read role) and the operator object-namespace admission policy cover `databases`.
