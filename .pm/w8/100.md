## Native reproduction

```sh
bex blueprints validate .pm/w8/evidence/100/root-pool-reference.yaml --confirm -o json
bex blueprints validate .pm/w8/evidence/100/project-second-pool-reference.yaml --confirm -o json
```

Each file declares a Free database with pooling absent, and a Free image web caller whose environment variable uses `fromDatabase.property: connectionPoolString`. Repeat using the isolated unmodified pinned Render client against Bex. The reference is correctly refused (exit1, valid:false), but its error `path` ends in `services[0].connectionPool`. That property is absent from the service, and is not a service-schema field. Line/column fall back to the service header instead of the known env entry.
