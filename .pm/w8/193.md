# Restrict environment-variable, secret-file and shell access to Admins in a protected environment

Why: Render's projects documentation lists "view or modify environment variables and secret files" and "use shell access" among the actions only Admins may perform in a protected environment ([render.com/docs/projects](https://render.com/docs/projects)). w8/187 replaced bex's typed-phrase gate with Render's Admin rule for delete, suspend, resume and maintenance-mode-on, but env-var and secret-file reads and writes (the `secrets` package) and SSH/shell access (the ssh-gateway) still allow any member who may use them elsewhere. A Developer can read a protected service's secrets on bex and not on Render. Under ADR008 § Render parity first this is an open gap, recorded in ADR032 § Protected environments follow Render's role rule.

**Severity:** minor (protected environments are opt-in and all current workspaces are first-party). **Attribution:** server (`secrets` env-var/secret-file verbs, ssh-gateway authorization). **Estimate:** 2h. **Source:** w8/187 (2026-10-22).

## Fix

1. Give `secrets.Service` the same protection lookup apps/postgres/keyvalue use (`core.EnvironmentProtectionStore` through the App's `LabelEnvironment`) and, for a member of a protected environment, require `core.AuthorizeAppFresh(ctx, core.RelCanManage, app)` on the env-var and secret-file list/get/set/delete verbs and on the environment-group link verbs that change a protected service's variables.
2. Do the same in the ssh-gateway session authorization for `srv-` targets in a protected environment.
3. Keep turning maintenance mode off open (it restores availability), as Render documents only "toggle maintenance mode" — decide against a capture, since bex gates only the "on" direction today.

## Acceptance

- Unit: a non-admin gets 403 on each variable/file verb and on an SSH session for a protected member; an admin and a member of an unprotected environment are unaffected.
- Live: as a Developer, `GET /v1/services/<protected>/env-vars` is 403; as the owner it is 200.
