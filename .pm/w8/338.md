# Settings → Port shows a detected port as if it were configured

Why: a service whose port bex detected shows that port in Settings → Port as a saved value, with a hint that bex injects it as `$PORT`. In fact `PORT` stays 10000, and an image-created service on the same image shows the row blank ("From the image").

- **Found by:** w8/m504 t004, in the Render parity walk on 2026-11-19. It applies to a native service whose process binds another port (w8/177), and to a web or private service switched from a native build to a prebuilt image (w8/m504).
- **Evidence:**
  - `ServicePortRow` (`dashboard/src/features/services/components/service-port-row.tsx`) shows `configuredPort` unless `imagePorts && !portConfigured`.
  - For a configured-port spec, `configuredPort` is `App.SavedPort` → `servingPort(spec)`, which returns `status.detectedPort` (`lego/types/v1alpha1/image_network.go`).
  - The hint `services.settingsPortHint` says "bex routes traffic to it and injects it as $PORT". `processPort` keeps `PORT` at 10000 for a detected port (`lego/operator/internal/controller/port_detect.go`, w8/267).
  - Saving the value shown turns the detected port into an explicit one. The service then no longer follows its process when the port moves, for example after a rollback to a native release that binds 10000.
- **Render:** a web or private service has no Port setting. `PORT` defaults to 10000, and Render routes to the port it detects ([render.com/docs/web-services#port-binding](https://render.com/docs/web-services#port-binding)). The row is a bex extension, so this is a presentation fix, not a contract change.
- **End state:**
  - When a service's serving port was detected (configured-port mode, no explicit port, no `PORT`, `status.detectedPort` set), Settings → Port says so. For example, the field is blank with a "Detected: 80" placeholder, and the hint says `PORT` stays 10000.
  - GraphQL tells the dashboard that the port was detected, for example with `portDetected`.
  - A dashboard test covers the detected row and the configured row.
