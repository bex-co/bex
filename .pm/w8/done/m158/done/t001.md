## Objective

On a pass over a release that is serving, read each current-revision pod's app container: when it has restarted, record its last termination (instance, restart count, exit code, whether it was an out-of-memory kill, finish time) in `App.status.instanceExits`. Keep the newest ten, and write status only when the list changes. A rollout that is failing keeps reporting through `status.rolloutFailure`.

## Files

- `lego/types/v1alpha1/app_types.go` (status field, CRD, deep copy)
- `lego/operator/internal/controller/`

## Acceptance criteria

- [x] A unit test covers a non-zero exit, an out-of-memory kill, an exit with status 0, a second restart of the same instance, and the bound.
- [x] A steady-state pass with nothing new writes no status.
