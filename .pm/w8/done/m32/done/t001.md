## Objective

In the New Service wizard, stop offering the "Existing Image" (Docker) source when the selected service type is `static_site`, so the Source selector for a static site shows only GitHub and Public Git URL.

## Context

- `dashboard/src/routes/services.new.tsx:135-142` passes `image={{…}}` to `ServiceSourcePicker` unconditionally.
- `ServiceSourcePicker` renders the image tab whenever the `image` prop is present: `dashboard/src/features/services/components/service-source-picker.tsx:150` (grid width `:139`, tab union `:24`, docstring `:48-51` — "its presence is what decides whether that tab exists").
- The correct pattern already exists in the Blueprint caller, which omits `image`: `dashboard/src/routes/blueprints.new.tsx:162`.
- Service-type enum: `dashboard/src/features/services/lib/create-context.ts:4-10` (`SERVICE_TYPES`).

## Steps

1. In `services.new.tsx`, pass `image` to `ServiceSourcePicker` only when `form.serviceType !== "static_site"` (e.g. `image={form.serviceType === "static_site" ? undefined : {…}}`), mirroring `blueprints.new.tsx:162`.
2. Confirm the picker already handles an absent `image` prop (two-tab layout) — no picker change should be needed; if the grid/columns assume three tabs, verify `service-source-picker.tsx:139` degrades correctly.
3. If the wizard defaults `form.tab` to `"image"`, ensure switching to Static Site resets it to a valid Git source so no stale image state persists.

## Files

- `dashboard/src/routes/services.new.tsx`
- (verify only) `dashboard/src/features/services/components/service-source-picker.tsx`

## Acceptance criteria

- [x] `/services/new?type=static_site` shows only GitHub + Public Git URL in the Source selector; no "Existing Image" tab, no "Docker Image" field.
- [x] `/services/new?type=web_service` (and private/worker/cron) still show all three tabs including "Existing Image".
- [x] Switching Service Type from Web Service (with Existing Image selected) to Static Site clears the image source and does not leave a "Docker Image" field visible.

- The submit-gate/payload hardening (t002) and the settings-page "Update Source" card (t004).
