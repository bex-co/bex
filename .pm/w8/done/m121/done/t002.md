## Outcome (2026-10-19)

On the adoption pass, `recordAdoptedRelease` also stores the release's whole `AppSpec` as JSON in its release record, under the operator-internal key `adoptedSpec` (`release_view.go`). `persistRuntimeConfigRecord` merges that key, so the later pod-template record keeps it. `adoptedReleaseSpec` reads it back. bex-api reads only the template and `ReleaseRecordSpec` keys, so its record handling is unchanged.
