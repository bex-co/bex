## Outcome (2026-10-17)

Done. Render's Hugo quickstart (render.com/docs/deploy-hugo) uses build `hugo --gc --minify` and publish `public`. Render documents no Hugo version selection and doesn't list Hugo in its native tools table, so the version was inferred from Render's Debian 12 environment and the quickstart's own requirements.

No API, CLI or dashboard field changes. ADR029 records the limits:
- A theme needing a newer Hugo must fetch it in the build command.
- There is no `HUGO_VERSION`.
- Hugo Modules need Go, which the Node image lacks.
