## Outcome (2026-10-17)

Done. Every native static build now carries Hugo **0.111.3 extended** before its source and authored command (`lego/operator/internal/build/nativehugo.go`, wired in `nativeDockerfile`):
- The official linux tarball for the build platform (`TARGETARCH` amd64/arm64) is checked against its pinned sha256 before only the `hugo` binary is extracted into `/usr/local/bin`.
- Extended links only glibc, libstdc++ and libgcc, all present in every bookworm toolchain image (checked with `ldd` on node:24).

The version is Debian 12's. The quickstart's pinned Ananke theme calls `resources.ToCSS`, which later Hugo removed: Hugo 0.167.0 fails the quickstart (`can't evaluate field ToCSS`), and 0.111.3 builds it. The Debian 0.111.3 control is therefore the release that matches Render's Debian 12 environment, not a blind adoption of it.

The official Docker image is Alpine/musl, so it was not used.
