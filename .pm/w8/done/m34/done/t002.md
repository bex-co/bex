## Objective

Make the rename safe for everything already written under the old spellings: stored `service_event_facts` and audit rows carrying `disk_attached`/`disk_detached` must still render on all surfaces and match the renamed `?type=` filter, and webhook endpoints whose subscribed-type filters store the old spellings must keep receiving the renamed events.

## Context

- Choose the mechanism deliberately and record it: a one-time data migration (rewrite stored type strings + stored subscription filters — bounded: two spellings, `w6/068` sized the rename cost as small) or a read-time alias map (old ⇄ new treated as one type at query/delivery time). A migration leaves no permanent aliasing code; prefer it unless row volume or immutability rules (webhook attempt history is immutable — `w8/m25`) argue otherwise. Immutable delivered-attempt payloads are historical evidence and must NOT be rewritten — only live projection/filter state may move.
- Event storage/query: `lego/backend/internal/store/` (event facts + audit events); webhook subscription filters: `lego/backend/internal/webhooks/`.
- Migrations live in the backend's numbered migration set (see `lego/backend/internal/store/` migrations directory).

## Steps

1. Inventory every place an event-type string is persisted: event facts, audit rows, webhook endpoint filters, webhook attempt payloads (immutable — excluded), notification state.
2. Pick migration vs aliasing per store; implement; document the choice in the milestone README on completion.
3. Prove: a pre-rename fixture row renders and filters under the new spelling; an endpoint subscribed to `disk_attached` receives a newly emitted `disk_created`.

## Files

- `lego/backend/internal/store/` (migration or alias helpers)
- `lego/backend/internal/webhooks/` (subscription-filter handling)
- Real-Postgres tests alongside (`TestPGStore` family)

## Acceptance criteria

- [ ] Pre-rename rows render on REST/GraphQL/MCP and match `?type=disk_created`/`disk_deleted` filters.
- [ ] An endpoint subscribed under an old spelling receives renamed events (test-proven).
- [ ] Immutable webhook attempt history is byte-unchanged.
