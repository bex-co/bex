The same common base supplies rsync. `install.sh` installs Debian's `rsync`, and the SPDX attestation of `sha256:4b809600…` lists `rsync` `3.5.0+ds1-0+deb12u1` (a Debian 12 security update; `rsync  version 3.5.0  protocol version 32`) with every library its package depends on: `libacl1` `2.3.1-3`, `liblz4-1` `1.9.4-1`, `libpopt0` `1.19+dfsg-1`, `libssl3` `3.0.22-1~deb12u2`, `libxxhash0` `0.8.1-1`, `libzstd1` `1.5.4+dfsg2-5` and `zlib1g` `1:1.2.13.dfsg-1`.

- **Delivery.** The same distribution install as jq (t001), with no separate supplier or framework. `/usr/bin/rsync` and its libraries sit outside `/usr/local`, so it is present at build, pre-deploy and runtime.
- **Behavior proved** (t006, t007): the original `rsync -a --delete --exclude='*.tmp'` copy of Unicode and space-named files, byte for byte, excluding the own draft and deleting own stale output, at build and on every runtime request; plus modes, times, symlinks, empty directories, excluded-file protection, itemized dry runs and trailing-slash semantics in the maintained cohort.
