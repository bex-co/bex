## Objective

## Steps

1. Verify the DoD: a workspace with a managed Postgres and/or Key Value instance sees `instance_seconds` rows for them identically across `GET /v1/usage`, GraphQL `usage`, MCP `get_usage`, and the dashboard Usage page.
2. Set every remaining task's `status: done`, move each `tNNN.md` to `w8/m5/done/`.
3. Mark every row `— **DONE**` and set `**Status:** done` in `w8/m5/README.md`.
4. Move the whole `w8/m5/` directory to `w8/done/m5/`.
5. Check `- [x]` for m5 in `w8/README.md`.
