## Outcome (2026-10-17)

Done. Render says a static site "automatically attempts to detect and install" its dependencies. Its `SKIP_INSTALL_DEPS` entry reads "skip running `yarn`/`npm install` during build" (render.com/docs/environment-variables). bex now runs Yarn for a Yarn Classic project as Render does.

REST, GraphQL, MCP, Blueprint and the dashboard all reach the one operator step through the App's build command, publish path and env. The change is wholly in the generated build, so no field, error or output shape changes, and both native clients are untouched. ADR029 records the remaining divergences:
- pnpm, Bun and Yarn 2+ are not installed automatically.
- A failed install does not fail the build.
