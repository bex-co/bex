## Outcome (2026-10-17)

Done. `nativeStaticInstallScript` (`lego/operator/internal/build/nativestaticdeps.go`) now runs `yarn install --production=false --non-interactive` when Yarn Classic is the project's only package-manager signal. That means a `yarn.lock` without Yarn 2+'s `__metadata` block, and/or `packageManager: yarn@1…`. It uses the image's Yarn 1.22.22 in the same pre-command step, root directory and effective env, and the bare authored command then finds its dependencies. Command bytes and the npm path are unchanged. Frozen mode is not imposed, because Render runs plain `yarn`.

Real-image gate: the locked fixture installs `cross-env` with the lockfile's `cross-spawn` 7.0.3 (a fresh resolution takes a later 7.x), keeps `yarn.lock` byte-identical, and a bare `yarn build` publishes. The same cases fail on the pre-fix script.
