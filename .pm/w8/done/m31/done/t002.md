## Objective

Mount `GitCredentialsMenu` in the header of `ServiceSourcePicker`'s GitHub tab so
the in-place credentials control appears everywhere the picker is used —
`/services/new`, create-Blueprint, and the Settings→Update Source dialog. Wire
refetch-on-focus and refetch-after-connect/disconnect so a newly-granted
account's repos appear in place, and keep the source-picker skeleton shape
parity.

## Context

- Insertion point: `dashboard/src/features/services/components/service-source-picker.tsx`
  — the GitHub `TabsContent` header. The picker already groups repos by account
  (`repoGroups`, `showAccountHeadings`) and shows a Connect button in the fully
  disconnected state; the menu goes in the tab header alongside the repo search.
- The picker is shared by create-service (`routes/services.new.tsx`),
  create-Blueprint, and the Settings→Update Source dialog (`w5/m76`), so one edit
  covers all three surfaces.
- `use-git-connection.ts`'s query is `cache-and-network` and Apollo-normalized on
  the `gitConnections` document, so the menu and the picker read one cache entry;
  a `refetch()` on window focus (the connect flow returns via a new tab) updates
  both. `useRepos()` must also refetch so the new account's repos list without a
  manual reload.
- The GitHub install callback still redirects to `/settings` (backend
  `rest.go:237`); returning to a background `/services/new` tab is handled by the
  focus refetch, not by a callback-target change. `git_error` callback-failure
  copy stays owned by the Settings card (out of scope here).
- Skeleton parity: `dashboard/CLAUDE.md` "Navigation pending states" —
  the source-picker area's pending skeleton must still match the ready layout
  after adding the header control.

## Steps

1. Render `GitCredentialsMenu` in the GitHub tab header of `ServiceSourcePicker`.
2. Add a window-focus listener that refetches `gitConnections` and `repos` (the
   connect flow opens a new tab; focus is the return signal).
3. Ensure disconnect/connect from the menu refreshes the repo list in place.
4. Verify skeleton shape parity at desktop and narrow-mobile widths.

## Files

- `dashboard/src/features/services/components/service-source-picker.tsx`
- `dashboard/src/features/services/hooks/use-repos.ts` (expose/return `refetch`
  if not already)
