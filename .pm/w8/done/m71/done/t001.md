## Done 2026-10-15

`ResolveNativeBun` (`lego/operator/internal/build/nativeversion.go`) is an opt-in companion selector using Render's precedence: `BUN_VERSION` → `.bun-version` → a `bun.lock`/`bun.lockb` lockfile (default line). It has no effect without an opt-in. Requests are mapped to a line like this:

- **plain version:** onto its major.minor line, so `BUN_VERSION=1.3.4` → the 1.3 line's 1.3.14 (a recorded patch divergence, like the primary lines);
- **bare major:** onto that major's newest line;
- **`latest`:** onto the newest line;
- **semver range:** onto the highest satisfying line;
- **anything else:** fails with the existing tenant `UnsupportedVersionError`, naming the supported lines.

The reviewed lines are `nativeBun` 1.2 (1.2.23) and **1.3** (1.3.14), both multi-arch `oven/bun` indexes pinned by digest and inventoried in `toolchain-freshness.json` (`native-bun-1-2`, `native-bun`; `validate` passes). Primary-language selection is unchanged and independent.
