## Closed — 2026-11-19 (loopx session)

- **Render's contract.** [render.com/docs/native-runtimes](https://render.com/docs/native-runtimes) lists `webpack` as available both during builds and at runtime, on Debian 12 "bookworm", names no version and does not mention `webpack-cli` (read 2026-11-19). bex supplies npm's current `webpack` and the CLI the lock carries (t001). Which versions Render ships is unverified, and no Render-hosted comparison was run.
- **Webpack's contract.** The [CLI reference](https://webpack.js.org/api/cli/) documents the options exercised: an entry operand, `--mode`, `--target`, `--output-path`, `--output-filename`, `--output-chunk-filename`, `--json`, `--env`, `--config` discovery of `webpack.config.mjs`, `--devtool` and `--cache-type`. The maintained checks run each (t005).
- **ADR060.** The D7 m101 row records the packages and the minimizer, the private Node, the behaviors accepted and the limits. Each limit is the same under a global `npm install -g webpack webpack-cli`, the sweep 422 control, checked on the same pinned `node:24-bookworm`:
  - `webpack --version` from webpack-cli 7.2.3 lists only the calling project's packages, so outside a project with its own webpack it prints an empty list and exits 0. The statistics' `version` names the compiler, and the frozen validator reads that.
  - The platform install is not on Node's module path, so a configuration that calls `require('webpack')` (for a built-in plugin) fails with `Cannot find module 'webpack'` and needs the project's own webpack.
  - Only `webpack` is supplied; a global install also links a `webpack-cli` command.
  - No dev server: `webpack serve` asks to install `webpack-dev-server` and, with no terminal, returns without installing anything (t005).
  - Loaders, plugin collections and browser targets are not separately accepted.
- **No surface change.** Webpack arrives through the image every native build already uses. REST, GraphQL, MCP, Blueprint and the dashboard keep their schemas, fields and error shapes, and no selector, toggle or launcher change was added.
