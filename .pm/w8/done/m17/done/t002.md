## Objective

Implement t001's design: after N consecutive sample failures on an autoscaling-enabled Database, emit the durable Warning signal; reset the counter on a successful sample. Cover it with envtest/unit tests including the benign first-reconcile case staying quiet.

## Context

- `lego/operator/internal/controller/database_autoscale.go` — the `DiskUsageReader` error branch.
- Event RBAC (`create;patch;update`) already present in `role.yaml` from m14.
- Existing test seams: `TestDatabaseDiskAutoscaleDecision`, `TestPrometheusDatabaseDiskUsageReaderChoosesFullestPVC`.

## Steps

1. Implement the signal + debounce per t001.
2. Tests: N-1 failures → no signal; N failures → signal; success resets; first-reconcile no-PVC stays quiet.
3. `cd lego/operator && make test` (runs manifests/generate/fmt/vet first).

## Files

- `lego/operator/internal/controller/database_autoscale.go`

## Acceptance criteria

- [x] `kubectl describe database` shows the Warning after a sustained sample outage in an envtest-simulated flow; tests fail if the signal or reset regresses.
- [x] `make test` passes.

Production verification on 2026-07-16 used the disposable `dev-8-m17/m17-sample-proof` Database. It persisted counts 1→2 with no Event, emitted exactly one `Warning DiskAutoscalingSampleUnavailable` at count 3, stayed capped without duplicate Events on count 4, and cleared the annotation when autoscaling was disabled. The namespace was deleted afterward.
