## Objective

## Steps

1. Add local endpoint search over name, destination, and human event labels.
2. Show latest status and exact/relative send time without an N+1 query.
3. Limit visible chips and add an accessible “Show N more” disclosure.

## Acceptance criteria

- [ ] Search filters immediately and has a clear no-match state.
- [ ] Latest attempt status/time is accurate for success, failure, retrying, and never-sent endpoints.
- [ ] Large subscriptions do not flood or destabilize the row layout.
- [ ] List data is batched/paged without per-row requests.
