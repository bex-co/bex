## Outcome (2026-10-17)

Done. In the resolve phase, a native static build whose generated recipe carries the dependency install step, and whose root has a regular `Gemfile`, gets a Ruby companion. The line comes from a Ruby service's precedence: `Gemfile.lock` `RUBY VERSION`, then `.ruby-version`, `.tool-versions`, the Gemfile's `ruby`. A Ruby no reviewed line serves is left out with a log line rather than failing. The Gemfile need not be the site's: a mobile app's CocoaPods Gemfile pins its own Ruby. The companion is one `COPY --link` of that line's pinned `/usr/local`, which carries ruby, gem, bundle, the stdlib and the headers. It also sets Render's Bundler layout, as Ruby services have it (w8/117): `BUNDLE_PATH`/`BUNDLE_BIN` in `/opt/render/project/.gems`, beside the published source, with a committed `.bundle/config` still honored. `LANG=C.UTF-8` is set as well.

The two images' `/usr/local` trees share no file (compared for Ruby 3.3/4.0 against Node 22/24/26). Both are bookworm, so Ruby's shared libraries are already present. The narration names the chosen Ruby.

The quickstart's `.ruby-version` 3.3.5 selects 3.3.12.
