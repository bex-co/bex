## Outcome (2026-10-17)

Done. The install step runs `bundle install` when the root has a `Gemfile`, after any JavaScript install, under the step's extended PATH. It keeps a current `Gemfile.lock`; frozen/deployment mode is not imposed.

`SKIP_INSTALL_DEPS=true` skips both installs. If Bundler is missing, a line says so. A failed install keeps the existing announce-and-continue behavior.

The npm/Yarn paths are unchanged; the script was only restructured into functions.
