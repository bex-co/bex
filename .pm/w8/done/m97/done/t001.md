## Closed — 2026-11-19 (loopx session)

The adopted common base (w8/m91 t007/t008) is the supplier. `deploy/native-base/install.sh` installs Debian's `ghostscript` with `--no-install-recommends`, which pulls its normal closure. The SPDX attestation of `sha256:4b809600…` (production's `nativeCommonBase` since pin `938c5cb36b49`, and at pin `dff52c596d13`), fetched again from the registry on 2026-11-19, lists `ghostscript`, `libgs10`, `libgs10-common` and `libgs-common` `10.0.0~dfsg-11+deb12u8`, `fonts-urw-base35` `20200910-7`, `poppler-data` `0.4.12-1`, and the codec and driver libraries `libijs-0.35`, `libjbig2dec0`, `libpaper1`, `liblcms2-2`, `libopenjp2-7`, `libidn12` and `libcups2`. That is Debian 12's package, the base Render names for its native runtimes.

- **What travels together.** The `gs` program (10.00.0) and its helper scripts (`ps2pdf`, `pdf2ps`, `eps2eps`, `ps2ascii` and the rest), `libgs.so.10`, `/usr/share/ghostscript/10.00.0/Resource` (`Init`, `Font`, `CMap`, `ColorSpace` and the other resource categories), `iccprofiles`, the Debian `Fontmap` under `/etc/ghostscript` and `/var/lib/ghostscript`, and the URW Base35 fonts that the `Resource/Font` entries point at. Nothing is copied by hand: no bare executable, `.so` symlink or donor root filesystem.
- **Phases.** `/usr/bin`, `/usr/lib` and `/usr/share` are outside the primary's `/usr/local` copy, so the program and its resources are present before source and authored commands at build, pre-deploy and runtime (t002).
- **Environment.** Nothing sets `GS_LIB`, `GS_FONTPATH`, `GS_OPTIONS` or a locale for Ghostscript, so authored values keep their meaning. An authored `GS_LIB` directory is searched (t005).
- **Identity.** A changed package is a new image digest, so a reviewed pin change is re-qualified by a families run. The common image's `toolchain-freshness.json` entry and the ADR060 D7 table inventory it. `check-tools.py` renders a PostScript page with `gs` at every publication.
- **Not chosen.** Trixie or a newer upstream Ghostscript: the user's 2026-10-29 decision put every utility on the one Bookworm image as distribution packages. Render names no Ghostscript version, so the version is not asserted to match Render's.
