## Closed — 2026-11-19 (loopx session)

Audited on main; the chain is the one w8/m94 and w8/m95 t002 traced. The changes since (w9/m493's `$XDG_CACHE_HOME` build cache, w9/m494's per-toolchain dependency directories) do not touch the base, the tools or their resource paths.

- **One recipe chain.** `nativeDockerfile` (`native.go`) has one caller, the native build Job's preparer environment. `cmd/native-resolve` ends with `applyNativeCommonBase` (`nativeresolve.go` → `nativebases.go`), so every native web service, private service, worker, cron job and static-site build starts from the common image, whatever the primary (Node, Python, Ruby, Elixir, Go, Rust) and its companions.
- **Phases.** Build, pre-deploy and runtime run one image: the pre-deploy Job runs the image the build produced. A static site's image is only its publish Job's extract source, so it gets `gs` at build only, which is all a static site has.
- **Resolution.** `applyNativeCommonBase` re-copies only `/usr/local` from the selected primary, then runs `ldconfig`. `gs` is `/usr/bin/gs`, its library `/usr/lib/<triplet>/libgs.so.10`, its resources under `/usr/share/ghostscript/10.00.0` and the fonts under `/usr/share/fonts`, so no primary shadows them; the original `shutil.which('gs')` found `/usr/bin/gs` on production (t006). No `GS_*` variable or `LD_LIBRARY_PATH` is set, so an authored `PATH`, `GS_LIB` or locale keeps its meaning.
- **Cache.** The base is digest-pinned. Tenant source and environment changes do not touch its layers; a package change is a new digest that misses the cache. Ghostscript keeps no cache under `$XDG_CACHE_HOME`.
- **Exclusions.** Dockerfile, prebuilt-image and buildpack services never enter this recipe. A static site with no build command builds no native image.
- **Neighbors kept.** FFmpeg, Pandoc, SQLite, libvips, the PostgreSQL clients, native-init and the companion and package-manager steps are unchanged; m97 changes no product code.
- **Exercised versus source-only.**
  - Production (t006): build and runtime, Python 3.13, both CLIs, on `4b809600…`.
  - Maintained cohort: the frozen m97 program on the Python 3.13 primary at build and on a network-off runtime (`python313-original`); the Ghostscript checks at the Node compute build, its network-off runtime and the static build; and the `missing-ghostscript` omission on the Python primary (t005).
  - Families runs on the same digest: the other primaries, companions, native-init and static.
  - Not executed: a hosted pre-deploy run (Free refuses `preDeployCommand`, as Render does) and ARM64 (D3).
