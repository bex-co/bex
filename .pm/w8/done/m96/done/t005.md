## Closed — 2026-11-19 (loopx session)

Every `native-common-image.yml` utility cohort (`TestNativeUtilityGeneratedImages`) runs these real-image checks on the image it publishes:

- **The original Django app** (already maintained). `python313-original` runs the frozen m96 program on the Python 3.13 primary. At build it installs Django 5.2.18 from the prepared wheels, and `compilemessages` compiles the original French PO to a 461-byte GNU MO whose Unicode, `python-format` and 0/1/2/5 plural translations equal the frozen reference, read by Django and independently by Python's `gettext`. Three HTTP requests on a `--network none` runtime repeat the translations and a fresh external `msgfmt` compilation, and the frozen oracle parses the downloaded catalog on its own.
- **Extraction and merge** (already maintained). `utility-check.py` extracts Python strings with `xgettext`, merges them with `msgmerge`, deduplicates with `msguniq`, compiles with `msgfmt --check-format` and requires a c-format mismatch to be refused.
- **New, the m96 PO through the other GNU programs** in `utility-check.py`, at the `node-compute` build and network-off runtime and at the `node-static` build:
  - `msgfmt --check --statistics` on the original PO reports exactly `3 translated messages`;
  - `msgunfmt` turns the MO back into a PO that `msgcmp` accepts and that compiles to the identical MO bytes;
  - `xgettext` extracts an AppStream metainfo file's translatable `name` and `summary`, but not its `id`, which only the packaged ITS rules in `/usr/share/gettext-0.21/its` can tell apart;
  - `msginit --locale=fr` writes French's `nplurals=2; plural=(n > 1)` header;
  - `envsubst` substitutes only the listed variables, with Unicode values;
  - the C library's lookup through `gettext` and `ngettext` with `TEXTDOMAINDIR` and `LANGUAGE=fr` returns the French strings under `LC_ALL=C.UTF-8`, and the English source under `LC_ALL=C`;
  - a PO with an unterminated string is refused with `broken.po:3: end-of-line within string`, and a mismatched python-format placeholder with `argument 'name' doesn't exist in 'msgstr'`.
- **New, `missing-gettext` omission control.** On the Python 3.13 primary, a test-only layer removes only the four programs the original probe locates (`msgfmt`, `msgmerge`, `msguniq`, `xgettext`), and checks that `msgunfmt`, `envsubst` and the ITS data remain. The original m96 build must then fail on Django's `Can't find msgfmt. Make sure you have GNU gettext tools 0.19 or newer installed.` after the layer's ready line.
- **How this was checked before shipping.** The host is arm64 and the adopted image is amd64-only, so the generated-image gate cannot run here. The checks ran on a `python:3.13-bookworm` arm64 replica with the identical `gettext`/`gettext-base` 0.21-12, `libc6` 2.36-9+deb12u14, no `locales` package and only `C.utf8`, with no network. The third worker re-ran all of them on 2026-11-19 against the block as restored onto `main`:
  - both gettext blocks of `utility-check.py` passed under Debian's `/usr/bin/python3` 3.11, before and after the mutations;
  - each of 14 mutations failed its assertion: `C` in place of `C.UTF-8` for the lookup, the ITS directory removed (`xgettext` then writes no catalog), a valid string in `broken.po`, a matching placeholder in `named.po`, `msginit --locale=ja`, `$KEEP` added to `envsubst`'s list, a changed round-trip translation, and each of `msgunfmt`, `msgcmp`, `msginit`, `envsubst`, `gettext` and `ngettext` removed;
  - the original m96 build and its three network-off runtime requests passed through `original-cases.py`;
  - the omission command, taken from the Go source, ran as a `RUN --network=none` layer and printed its ready line after `msgunfmt` and `envsubst` answered; the original build then failed with Django's `CommandError` above, and its before-probe passed the frozen `valid_before` validator (all four locators null), matching the historical failure;
  - the push of this change re-runs the amd64 utility cohort through `native-common-image.yml`; that run is the amd64 proof.
- **Unit and package checks.** The operator's `make test` (codegen, `go vet`, `gofmt` and every package, including `TestNativeOriginalReplayHTTPOracles`, `TestNativeUtilityOmissionsHaveRemovalLayers` and the omission-evidence tests) and `make lint` over all four modules.
