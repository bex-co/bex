## Closed — 2026-11-19 (loopx session)

Audited on main at `5a85568ae`. The chain is the one w8/m94 t002 and w8/m95 t002 traced. Since then, w9/m493 and w9/m494 added an `$XDG_CACHE_HOME` cache mount and dependency-directory caches to the build `RUN`, and w32/m424 changed port defaults; none touches `/usr/bin` or `/usr/share`.

- **One recipe chain.** `nativeDockerfile` has one caller, `nativeBuildPreparer`, which every `BuilderNative` build Job runs. `applyNativeCommonBase` (`nativebases.go`) moves the final stage onto the common image, so every native web service, private service, worker, cron job and static-site build starts from it, whatever the primary (Node, Python, Ruby, Elixir, Go, Rust) and its companions.
- **Phases.** Build, pre-deploy and runtime run one image: the pre-deploy Job runs the image the build produced. A static site's image is only its publish Job's extract source, so it gets the programs at build only, which is all a static site has.
- **Program and data resolution.** `applyNativeCommonBase` re-copies only `/usr/local` from the selected primary and then runs `ldconfig`. The gettext programs live in `/usr/bin`, their ITS data in `/usr/share/gettext-0.21`, their libraries in `/usr/lib/<triplet>`, so no primary shadows them. Django's `find_command('msgfmt')` found `/usr/bin/msgfmt` at build and runtime on production (t006). No `TEXTDOMAINDIR`, `LANGUAGE`, `LC_*` or `GETTEXT*` variable is set, so authored values keep their meaning; a primary's own `LANG=C.UTF-8` (Python's official image) is kept as before.
- **Cache.** The base is digest-pinned. Tenant source and environment changes do not touch its layers, and a package change is a new digest that misses the cache.
- **Exclusions.** Dockerfile, prebuilt-image and buildpack services never enter this recipe. A static site with no build command builds no native image.
- **Neighbors kept.** FFmpeg, Pandoc, SQLite, libvips, the PostgreSQL clients, native-init and the companion and package-manager steps are unchanged; m96 changes no product code.
- **Exercised versus source-only.**
  - Production (t006): build and network-attached runtime, Python 3.13, both CLIs, on `sha256:4b809600…`.
  - Maintained cohort: the frozen m96 program on the Python 3.13 primary at build and on a network-off runtime (`python313-original`), and the GNU tool checks at the Node compute build, its network-off runtime and the static build (t005).
  - Families runs on the same digest: the other primaries, companions, native-init and static.
  - Not executed: a hosted pre-deploy run (Free refuses `preDeployCommand`, as Render does) and ARM64 (D3).
