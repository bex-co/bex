## Objective

Add an optional `DisplayName` field to `AppSpec`, distinct from the immutable k8s object `Name`.

## Context

- `lego/types/v1alpha1/app_types.go:507-512` — `App` embeds `metav1.ObjectMeta` directly; `Name` is the immutable, DNS-safe k8s object name, baked into the `<name>-tls` cert secret (`:263`) and the `Subdomain` fallback (`:274-283`).
- `Subdomain` is the existing precedent for separating a routing-facing field from `Name` — mirror that pattern's doc-comment style.

## Steps

1. Add `DisplayName string` (optional, no DNS-safety constraint — free-form human label) to `AppSpec` with a kubebuilder marker and doc comment explaining it is distinct from `Name`.
2. Regenerate deepcopy (`make generate` from `lego/operator/`) and CRD yaml (`make manifests`).
