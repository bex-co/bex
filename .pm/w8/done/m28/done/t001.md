## Objective

Make the default `/agents` view a prompt workspace: one heading, a centered composer, and a labeled Start control that shares vocabulary with “Starting the sandbox…”.

## Context

- Today `routes/agents.tsx` stacks `PageHeader` (“Agent sessions” + the sandbox/PR subtitle), `ComposerSection` (“What should the agent work on?” + left-aligned `max-w-3xl` box), and `SessionListSection`.
- `NewSessionComposer` submits with a round `ArrowUp` whose accessible name is already “Start session” (`agentSessions.submit`) — the visible UI looks like send-chat.
- Copy in `locales/{en,zh}.ts` repeats the same sentence in subtitle, placeholder, and empty body.

## Steps

1. On the default view (no `archived` / `phase` search), drop `PageHeader`. Keep a list-mode title for `?archived=true` / `all` so those URLs still feel like a list.
2. Center the composer (~40rem), give the editor more min-height, keep the existing focus-within ring.
3. Replace the round arrow with a labeled button using `agentSessions.submit` / `agentSessions.submitting` (“Start session” / “Starting…”). Disable while `isSubmitting`.
4. Keep a single prompt heading (or fold it into the placeholder). Cut the page subtitle from the default view; do not leave three paraphrases of “describe a task and @-mention a repo.”
5. Configuration trigger copy: retitle toward **Advanced** (locale key; zh too). Do not move fields in this task.
