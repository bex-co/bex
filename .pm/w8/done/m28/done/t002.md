## Objective

Put the two choices people actually make — which agent, which repo — on the composer toolbar, and fail closed with a Connect GitHub CTA when the workspace has no installation repos.

## Context

- Agent (claude/gemini/codex) lives in the Configuration popover (`configuration-fields.tsx`) next to branch, model, endpoint, and egress. Default is Claude; most people never open the popover.
- Repo is required (`onSubmit` nudges at `@` if missing) but only as an inline mention. `useRepos()` already loads the GitHub App catalog; empty state is buried in the mention picker (“No repositories — connect GitHub in workspace settings first.”).
- Workspace settings live at `/workspace/settings`; the service create wizard already has a GitHub App install CTA to copy, not reinvent.

## Steps

1. Add a compact agent `<Select>` on the composer toolbar bound to the existing form `agent` field. Leave branch / model / endpoint / egress in Configuration (now Advanced).
2. Show a persistent repo chip from `composerDocument.repo` (full name). Empty → button that calls `editorRef.openMention()` with copy like “Add repository”. Selecting a repo still replaces the prior mention (existing `insertMention` behavior).
3. When `!reposLoading && repos.length === 0`, render a Connect GitHub callout **instead of** (or overlaying) the writable editor — do not let them write a prompt into a wall. Link to `/workspace/settings` and/or the existing GitHub App install URL the wizard uses.
4. Keep the `@` button. If they submit without a repo while repos exist, highlight the chip/`@` control, not only the 12px tooltip.
5. Create mutation args stay `agent` + `repo` as today.
