## Objective

Finish the first-run and loading surfaces: mention nodes look like chips, the keyboard contract is visible, empty/loading/error match the new page shape, and first-run example prompts insert into the composer.

## Context

- TipTap mention nodes are unstyled default spans (`data-type="mention"`). No composer-specific CSS in `dashboard/src/style.css`.
- Enter submits, Shift+Enter newlines (`inline-mention-editor.tsx`) — undocumented in the UI.
- Default empty is `empty-state.tsx`: dashed border + Bot + copy that repeats the composer.
- In-list loading is `<Skeleton className="h-40 w-full" />`. Route pending uses shared `ListPageSkeleton` (title + **card grid**) — wrong shape for this page.
- Example chips are first-run only (no sessions yet) and must go through `t()`.

## Steps

1. Style repo vs session mention nodes as chips (Tailwind on the mention renderHTML / a node view). Keep them atomic (existing insert/replace behavior).
2. One muted hint under the composer: Enter to start, Shift+Enter for a new line, `@` for a repo.
3. Default empty: no dashed Bot card. Composer remains the CTA; at most one quiet line (“Sessions you start will show up here.”). Keep distinct archived / filtered empties.
4. Add 2 example prompt chips, visible only when the workspace has zero sessions and repos exist. Clicking inserts the text and opens `@`. Dismiss/hide after the first session exists (derive from `useAgentSessions`, no new backend flag).
5. Route `pendingComponent`: a composer + recents skeleton, not `ListPageSkeleton`. In-list loading: 4–5 recents-shaped rows.
6. List error: one sentence + Retry, same voice as `createErrorTitle`.
