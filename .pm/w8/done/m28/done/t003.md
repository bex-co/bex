## Objective

Replace the default-view five-column sessions table with full-row recents that speak the sidebar’s human status language, and remove the ten-value phase filter from `/agents`.

## Context

- `session-list.tsx` is a `Table` (Task / Phase / PR / Created / archive). Phase chips expose `creating` / `redispatching` / `hibernating` / ….
- The rail (`agent-sessions-nav-section.tsx`) already maps status via `agentSessionStatusPhraseKey` (“Working…”, “PR is ready”).
- Membership tabs say **Current**; the rail heading says **Recent**. Archive exists as tabs + sidebar footer + per-row icon.
- `?phase=` is validated in `agents.tsx` `validateSearch` and passed into `useAgentSessions`. Keep URL compatibility (ignore unknown/legacy `phase` or still honor it if linked) but do not offer the dropdown on the default view.
- Archived (`?archived=true`) and All (`?archived=all`) may keep a denser list — people are hunting there.

## Steps

1. Default view: render recents as block rows — title (`sessionTitle`), subline (status phrase · repo · relative age), PR number as a trailing link when `prUrl` exists, entire row is the `Link` to `/agents/$agentSessionId`. Archive stays a trailing control that does not swallow navigation (same `stopPropagation` as today).
2. Remove the **Filter by phase** `<Select>` from `SessionListSection`. Do not invent Working/Done/Failed buckets in this milestone.
3. Unify membership copy: pick **Recent** (matches the rail) or **Current** — one word in tabs, rail, and empty states. Update en+zh.
4. Keep Current / Archived / All (or equivalent) as the membership switch; sidebar Archived footer stays the deep link to `?archived=true`.
5. Whole-row click target; overflow `…` is optional if archive-only still fits. Do not add Delete here unless it already exists on the list (it lives on detail today).
6. One-rail invariant tests must still pass — no new `<aside>`.
