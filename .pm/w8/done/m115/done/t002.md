## Objective

Blast-radius verification for t001's attribution change: every pre-existing request-line shape keeps its labels, and no shape can be steered into another tenant's history.

## Context

- The pipeline already carries three hard-won attribution cases, each a prior silent-emptiness bug: tenant namespaces (`tea-<xid>`, ADR043), static sites (ExternalName alias, w4/m113), platform edge hosts (fixed bounded pairs, w5/053). t001 must not regress any of them.
- The query pins namespace AND app to the caller's resolved values, so a mislabeled line hides rather than leaks — preserve that; this task proves the new path cannot mint a (namespace, app) pair the caller does not own, including lines with forged `RequestHost` values aimed at another tenant's hostname.

## Steps

1. Extend the t001 fixture set: routed compute 200, static-site 200, app-generated 404, IPAllowList 403 (web), IPAllowList 403 (static), platform-host 5xx, unknown-host line, spoofed-Host line naming a different tenant's subdomain.
2. Assert post-pipeline labels for each: allowed pairs only, spoofed/unknown lines dropped or attributed solely by their true ingress.
3. Assert drop-counter reasons stay meaningful (`not_an_access_line` vs `not_a_tenant_app`).

## Files

- `deploy/gitops/base/log-shipper.yaml` (tests/fixtures beside the maintained harness)

## Acceptance criteria

- [x] Every fixture's labels match the pre-change baseline except the newly-attributed 403 shapes.
- [x] The spoofed-Host fixture cannot produce a line under the victim App's labels.

## Out of scope

- bex-api query changes (none expected).

## Evidence — 2026-10-18

- The actual-Alloy `RequestLogAttributionTest` retains compute 200, app-origin 404, legacy static ExternalName alias 200, platform API 503, web/static/default allowlist 403s, and an empty ServiceName refusal with exact expected labels.
- A victim-tenant hostname and a platform hostname on a true tenant ingress both remain in the true ingress's namespace/App stream. An unknown host, a namespace suffix collision, and a missing ingress name remain dropped. Exact Loki drop counters assert two operational lines as `not_an_access_line` and three unattributable access lines as `not_a_tenant_app`.
- The pre-fix fixture run lost the six new refusal cases; the fixed run and complete 11-test shipper suite passed. Existing Go log-reader/access-field guards passed unchanged.
