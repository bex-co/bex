## Objective

Verify the real CLI journey and an owned local runtime so schema-valid Blueprint env literals reach their intended process values.

## Context

- [Reproduction, mechanism and scope](finding.md).
- [Observable milestone outcome](README.md).

## Steps

1. Use worker8's isolated dev-8 stack, an explicit free plan and a ledger-owned fixture; inspect quota and cleanup paths first.
2. Drive both Bex and unmodified pinned Render against that API with numeric and quote-only manifests. Compare JSON exit/status and a meaningful invalid-value control.
3. Apply an owned local web/group fixture and assert the process sees the expected string; repeat an unchanged sync. Delete children/parents by recorded IDs and verify absence.

## Acceptance criteria

- [ ] Both clients validate numeric input with exit0/validtrue; quoted controls still pass.
- [ ] An actual owned process reports the expected string and repeated sync causes no env-induced deploy.
- [ ] All created fixtures/children are absence-verified; skipped live surfaces are explicit.

## Out of scope

- New CLI flags, a CLI fork, global numeric stringification or unsupported Blueprint features.

## Outcome (2026-10-09)

Production, deploy pinned to `a668150912f4` (includes the fix). Released Bex v0.3.2 (embeds the pinned Render v2.27.0), isolated config, QA human device login, workspace bex-canary. The baseline was the same 6 services before and after. Fixtures were deleted, URLs return 404, and the CLI session was logged out and the browser session revoked. `bex blueprints validate numeric.yaml --confirm -o json` with `QA_MARKER` and env-group `ANSWER` set to `47`, `47.5`, `1e3` and quoted `"47"`: all four exit 0 with `valid:true`, `envGroups:[qa-20261009-m53-eg]`, `services:[qa-20261009-m53-bp]`, `totalActions:2` (previously exit 1 with the bexEnvVar decode error). **Limits:** validate only. No runtime fixture was created, so the process-string and second-sync no-diff checks rest on the unit tests (`TestBlueprintEnvValueAcceptsNumbers` asserts the exact spec.Env strings). The unmodified Render binary was not rerun.
