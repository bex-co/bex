## Outcome (2026-10-18)

Done.
- **`scanGroups` (new):** one helper, `scanGroups` (`lego/backend/internal/envgroups/service.go`), now lists and reads every group id's metadata with a bounded fan-out (`errgroup`, limit 8). It uses a plain group, so a failed read never cancels readMeta's lazy ownership migration or audit. Results stay in id order, and `ErrNotFound` is still skipped.
- **All scans go through it:** list, environment membership, name lookup, the Blueprint name map, the create/rename uniqueness sweep, the quota and the workspace purger. The legacy-union locator loop in `listGroupIDs` uses the same fan-out.
- **Slow-scan logging:** a scan over 2 s logs how many ids it listed and how many had metadata, so further growth is visible before it reaches the edge timeout.
- **Empty projects skip the scans:** `environments.List` returns `[]` for a project with no environments without running the member scans. All three bex projects are in that case.
