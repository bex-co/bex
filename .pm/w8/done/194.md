# Static-site responses carry no `Strict-Transport-Security` or `X-Content-Type-Options: nosniff`; Render's static sites send both on every file

Why: Render's static sites tell browsers to use HTTPS only (`strict-transport-security: max-age=315360000; includeSubdomains; preload`) and not to MIME-sniff (`x-content-type-options: nosniff`). bex sends neither on a successful static response, so a site moved from Render loses both protections without any change on the owner's side.

Severity: minor (security headers / parity). Source: `/qa-find-bugs-cli` loop sweep 64af, 2026-10-23 UTC, bex v0.3.3, pin Render CLI v2.27.0 `a764810a7682`, `https://api.bex.co/v1/`, `bex-canary`, human device login.

## Evidence

Owned fixture `srv-dbdbssfvlr1c73fj1av0` (`qa-20261022-64af-site`, free static site, deleted by ID afterwards):

```text
$ curl -sD - -o /dev/null https://qa-20261022-64af-site.onbex.co/big.js
HTTP/2 200
cache-control: public, max-age=0, must-revalidate
content-type: text/javascript
etag: "iGcV5AUegn9P4hXfMFOvPw"
vary: Accept-Encoding
```

`/` and `/data.json` likewise have no HSTS and no `nosniff`.

Render, 2026-10-23 (`https://create-react-app.onrender.com/`, `/static/js/1.13eeb203.chunk.js`, `/manifest.json`, all `200`):

```text
cache-control: public, max-age=0, s-maxage=300
strict-transport-security: max-age=315360000; includeSubdomains; preload
x-content-type-options: nosniff
vary: Accept-Encoding
```

Render's 404 for a miss carries `nosniff` but no HSTS. Render **web services** (`django.onrender.com`, `rails.onrender.com`) send no HSTS, so this is a static-site default only. Their `nosniff` comes from the app frameworks, not Render.

## Root cause

`lego/operator/internal/staticserver/staticserver.go:484-492` (`serveObject`) sets `Content-Type`, `Cache-Control` and `ETag`, then applies the site's custom headers. The only `nosniff` is on the custom 404 page path (`staticserver.go:441`). No HSTS anywhere in the static server.

## Fix

In `serveObject`, before `applyHeaders` (so a saved custom header still wins, w4/272 precedence): set `Strict-Transport-Security: max-age=315360000; includeSubdomains; preload` and `X-Content-Type-Options: nosniff`. Keep `nosniff` on the 404 paths; add no HSTS to error responses (as Render). Update ADR029's default-headers list and ADR018's static row.

## Blast radius

Every static-site success response on every host in every workspace. Custom domains: Render's behavior there is not captured (no Render custom-domain static site observed). Apply the same headers (the site is HTTPS-only either way, and m118 redirects HTTP), and note it as unverified. Custom header rules can override both.

## Acceptance

- Unit: `serveObject` emits both headers on 200/206/304. A custom `Strict-Transport-Security` rule replaces the default. A miss emits `nosniff` without HSTS.
- Live after the operator deploy: a fresh owned free static site's `/`, an asset and a 206 range response carry both headers. Delete by ID with a 404 proof.
