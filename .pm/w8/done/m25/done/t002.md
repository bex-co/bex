## Objective

Make the multi-replica dispatcher append one immutable attempt per send while scheduling retries and terminal state on the logical notification.

## Context

- `lego/backend/internal/webhooks/worker.go`
- `lego/backend/internal/store/webhooks.go`
- Eight total attempts and the existing backoff/auto-disable contract remain unchanged.

## Steps

1. Separate claim/schedule state from attempt evidence insertion.
2. Append outcome atomically and schedule or close the parent exactly once.
3. Update sweeps, endpoint deletion, and retention for both tables.

## Files

- `lego/backend/internal/webhooks/worker.go`

## Acceptance criteria

- [ ] Two workers cannot send the same scheduled attempt twice.
- [ ] Each network exchange produces exactly one immutable attempt.
- [ ] Backoff, notices, exhaustion disable, payload bytes, and signature vectors remain correct.
- [ ] Retention never orphans payloads, parents, or attempts.
