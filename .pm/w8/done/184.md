# A static-site rewrite cannot proxy to another site (`/api/* → https://api.example.com/api/*`): bex refuses any non-local rewrite destination, where Render serves the external URL's content at the original path

Why: [Render's redirects-and-rewrites docs](https://render.com/docs/redirects-rewrites) say "Destination can be either a path or a full, publicly accessible URL", and a rewrite "serves the content from the rule's destination at the original path". Render staff recommend `/api/* → https://<backend>.onrender.com/api/*` as the way for a static frontend to reach its API without CORS or an nginx service ([community thread](https://community.render.com/t/how-to-proxy-network-calls-for-spa-static-site/667); [rewrite to internal URLs](https://community.render.com/t/rewrite-rules-that-target-internal-urls/2940): only public URLs, no internal addresses). Bex refuses every rewrite whose destination is not a local path, on REST, GraphQL, MCP, the dashboard and Blueprints. A Render project using that pattern fails `bex blueprints validate` and cannot be configured. w8/162 (done) opened external targets for redirects and explicitly kept rewrites "local-only"; ADR018's header/redirect row records that as a divergence with no user sign-off.

**Severity:** major (blocks the standard static-frontend-plus-API layout; the workaround is CORS on the API or a separate proxy service). **Attribution:** server (route validation) plus static-server (rewrite execution). **Estimate:** 3h (SSRF-safe fetch path). **Source:** `/qa-find-bugs-cli` sweep 1316, 2026-10-22 ([evidence](evidence/cli-sweep1300/README.md#sweep-1316--external-rewrites)).

## Reproduction

Production `https://api.bex.co/v1/`, pin `efdd8e2ff06b`, `bex-canary`, HEAD-built pinned CLI, no fixtures. `bex blueprints validate rw.yaml -o json` on a free static site with:

```yaml
routes:
  - type: rewrite
    source: /api/*
    destination: https://httpbin.org/anything/*
  - type: redirect
    source: /old
    destination: https://example.com/new
```

→ exit 1, `services[0].routes[0].destination`: `service "qa1316-rewrite": routes[0].destination must be a path starting with /`. The external redirect in the same file is accepted (w8/162).

## Expected

A rewrite to an absolute `http(s)` URL is accepted when the URL is publicly routable. At request time, the static-server fetches the expanded destination (with `*` substitution as for local rewrites) and returns its status, headers and body at the original path, without redirecting the browser. Render's documented limits apply: rules never apply where a file exists, and the root path cannot be rewritten. Destinations that are not public stay refused, at validation for literal hosts and at fetch time after DNS resolution. That covers private, loopback, link-local, metadata and cluster-internal addresses, including bex's own internal service names, which matches Render's "no internal addresses".

## Root cause

- `lego/backend/internal/apps/service.go:5266–5297` (`validateRoutes`): only `t == "redirect"` may take an `http(s)` destination (`validateExternalRedirect`). Anything else must be a local `/` path with no host ("rewrite, which bex would have to fetch, stays local-only (w8/162)").
- `lego/operator/internal/staticserver/staticserver.go:332` and `:678` (`expandDest(…, allowAbsolute)`): the rewrite branch serves only stored objects.

## Fix

1. Validation: allow an absolute `http(s)` rewrite destination using the same parser as `validateExternalRedirect`. Refuse literal non-public hosts and IPs.
2. Static-server: add a bounded reverse-proxy path for external rewrites:
   - resolve the host, refuse non-public addresses after resolution (DNS-rebinding safe: dial the checked IP);
   - forward method, body and safe request headers, setting `X-Forwarded-Host` and `-Proto` as Render does;
   - apply timeouts and response-size limits from the existing static budgets;
   - do not follow redirects (pass them through);
   - egress through the platform's normal egress path.
   Reuse the existing SSRF-guarded external fetcher: the activator already serves a custom maintenance page from an external URL through `validateCustomPageURL` and `fetchOrigin`, with a per-URI singleflight, a TTL cache and size caps (`lego/operator/cmd/activator/main.go:367–450`). Extract it into a shared package rather than writing a second one.
3. Keep the site's custom headers applying to the proxied response as they do to local objects.
4. Update ADR029, ADR018 and ADR056 #11, the security note on open redirects, which is unaffected for rewrites. Get a security review sign-off for the fetch path in the same milestone; it is not a reason to keep the gap.

## Blast radius

Static-site route validation on every surface, and the shared static-server request path for sites whose rules contain an external rewrite. Sites without such rules are unaffected.

## Acceptance

- Unit: validation accepts `https://api.example.com/*` and refuses `http://10.0.0.1/*`, `http://169.254.169.254/*`, `http://localhost/*` and `http://<svc>.<ns>.svc/*`. The proxy refuses a public hostname that resolves to a private IP.
- Live after deploy: a free static site with `/api/* → https://<owned bex web service>.onbex.co/*` returns that service's body at `/api/x`, while the browser URL stays on the static site. Delete fixtures by ID with 404 proofs.

## Dedupe

`git grep -i 'local-only|external rewrite|rewrite.*proxy' .pm`: w8/162 (done) kept rewrites local deliberately. No open item reopens it.

**Done 2026-10-22:** `staticserver/proxy.go` — a rewrite to a public http(s) URL is proxied by the static server (any method; `netutil.SafeDialContextFunc` refuses every non-public resolved address and dials the checked IP; redirects passed through; loop/hop-marker refusal; 32 MiB request / 64 MiB response / 60 s bounds; file wins and root not rewritten). `apps.validatePublicRewriteHost` + dashboard row validator accept public hosts and refuse non-public literals.
