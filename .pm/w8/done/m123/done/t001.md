## Objective

A Yaegi-loadable Traefik middleware plugin that removes caller-supplied client-identity headers and sets `True-Client-IP` to the real client address, keeping genuine Cloudflare headers only when the TCP peer is a Cloudflare edge.

## Context

- Existing local plugin to mirror: `deploy/gitops/charts/traefik-plugins/websocketegress/` (`go.mod`, `.traefik.yml`, plugin + test).
- Cloudflare ranges: `lego/backend/internal/core/proxiedhosts.go` `cloudflareRanges` (fetched 2026-10-02).

## Steps

1. Create `clientipheaders/{go.mod,.traefik.yml,clientipheaders.go,clientipheaders_test.go}` per the milestone's Design.
2. Parse `RemoteAddr` with `net.SplitHostPort` + `netip.ParseAddr` (unmap). If it does not parse, treat the peer as untrusted and leave `True-Client-IP` absent.

## Files

- `deploy/gitops/charts/traefik-plugins/clientipheaders/*`

## Acceptance criteria

- [ ] Unit tests: forged headers from a non-Cloudflare peer → `CF-*`/`X-Client-IP` gone, `True-Client-IP` = peer; Cloudflare peer with a valid `CF-Connecting-IP` → `CF-*` kept, `True-Client-IP` = that value; Cloudflare peer with a garbage `CF-Connecting-IP` → treated as untrusted.
