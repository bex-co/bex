## Objective

Databases provisioned before w2/m25 gain query insights: the operator reconciles the `pg_stat_statements` extension onto existing CNPG clusters (spec update ± `CREATE EXTENSION` on the primary) so their Top Queries list stops degrading to empty forever.

## Context

- Degradation point: `lego/backend/internal/postgres/insights.go:257` (graceful empty, never self-heals).
- Seam: w2/m25's parameter-override write path — the operator already reconciles CNPG parameter overrides; ride it, don't invent a new mechanism.
- CNPG applies `shared_preload_libraries` changes with a rolling restart — confirm the plan's disruption story (single-instance plans restart; note it).

## Steps

1. Make the operator's Database reconcile converge the extension config for clusters missing it.
2. Verify on a pre-m25 cluster (dev-N or prod) that Top Queries populates after reconcile.
3. Note the restart behavior in ADR009.

## Acceptance criteria

- [x] A cluster created without the extension gains it via reconcile alone; insights Top Queries returns rows
- [x] No-op on clusters that already have it (idempotent, no restart churn)
