## Closed — 2026-11-19 (loopx session)

The adopted common base (w8/m91 t007/t008) is the supplier. The `node-tools` stage of `deploy/native-common/Dockerfile` runs `npm ci --ignore-scripts` on `deploy/native-base/package.json` and `package-lock.json`, an integrity-locked graph, into `/opt/bex/native-node-tools`, and copies that stage's Node there. `/usr/bin/tsc` is a two-line wrapper that execs the package's `bin/tsc` on that Node. The SPDX attestation of `sha256:4b809600…` (production's `nativeCommonBase` at pin `dff52c596d13`), fetched again from the registry on 2026-11-19, lists `typescript` `7.0.2`, `@typescript/typescript-linux-x64` `7.0.2` with its `lib/tsc` (Go module `github.com/microsoft/typescript-go`), and the private `node` `24.22.3`.

- **The reviewed release.** 7.0.2 is npm's `latest` on 2026-11-19 (7.1.0 is still `beta`), and the lock's `sha512` integrity equals the registry's. It was not adopted from the sweep 420 control unexamined. 7.0 is the native compiler, so the JavaScript package alone does not compile anything. npm installs the one platform package whose `os` and `cpu` match, and that package carries the executable and the standard-library declarations (`lib.*.d.ts`).
- **What travels together.** The wrapper, the private Node, `typescript` and its platform package. Nothing is downloaded at build or run time, and no donor root filesystem is copied.
- **Phases.** `/usr/bin` and `/opt/bex` are outside the primary's `/usr/local` copy, so `tsc` is present before source and authored commands at build, pre-deploy and runtime (t002). Both production builds and every runtime request reported `Version 7.0.2` (t006).
- **Environment.** bex sets no TypeScript variable. The wrapper runs its own Node, so the app's `NODE_VERSION`, `node` and `npm` are untouched, and a project's own compiler still runs first from an npm script (t005).
- **Identity.** A changed lock or Node is a new image digest, which a families run re-qualifies. The image's SPDX attestation lists both packages and the ADR060 D7 table records them; `toolchain-freshness.json` tracks the image digest, not the npm lock. Every `native-common-image.yml` run's utility cohort compiles TypeScript and rejects a type error on the image it publishes (t005).
