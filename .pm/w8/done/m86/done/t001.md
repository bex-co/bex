## Outcome (2026-10-16)

Native Node static builds now carry a bex-owned step (`nativestaticdeps.go`, `/opt/bex/install-deps`, invoked with `/bin/bash` between the env loader and the exact authored command in the build RUN): skip on `SKIP_INSTALL_DEPS=true`, no `package.json` or a root publish path; another manager's lockfile/`packageManager` left to the build command with a log line; otherwise `npm install --include=dev --no-audit --no-fund` (lock or no lock; devDependencies under NODE_ENV=production). A failed automatic install is announced and non-fatal so sites installing in their own command keep working. Builtin-only checks; the step alone extends PATH with image dirs. `Options.StaticPublishPath` carries the publish path from the App.
