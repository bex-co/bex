## Objective

Rewrite user-visible cobra Short/Long (and remaining Example edge cases) so common help text says Bex instead of Render, without corrupting Blueprint filenames or API-shaped terms that must stay `render.yaml`.

## Context

- Upstream Short/Long are full of "on Render", "Render CLI", "Render Dashboard", "Render Postgres", "Render Key Value", "Render agent skills".
- Blind `Render` → `Bex` breaks **`render.yaml`** (canonical Blueprint contract, ADR049).
- Prefer targeted replacements: `Render CLI` → `bex CLI`, `on Render` → `on Bex`, `Render Dashboard` → `Bex dashboard`, `` `render `` → `` `bex ``, "to Render" / "of Render" carefully.
- Product phrases like "Render Postgres" / "Render Key Value" may become "Bex Postgres" / "Bex Key Value" or stay as-is if rewriting sounds wrong — pick one consistent policy and document it in t004.
- Workflows help is Render-product copy and workflows are a bex non-goal; still apply the same safe string rules (do not hide the command tree in this milestone).

## Steps

1. Extend the branding walk to Short/Long with an allowlisted/safe replacer (unit-test the replacer on fixtures including `render.yaml`, `Render CLI`, `on Render`).
2. Apply to every command under `RootCmd` after Use/examples overlay.
3. Spot-check `bex services --help`, `bex login --help`, `bex postgres --help`, `bex skills --help`, `bex workflows --help`.
4. Do **not** replace `RunE` bodies or attempt stderr rewriting.

## Files

- `lego/cli/internal/branding/` (replacer + walk)
- tests for the replacer (may land fully in t006; at least keep the function testable)

## Acceptance criteria

- [ ] Representative `--help` Short/Long no longer lead with "Render CLI" / "on Render" where the safe map applies.
- [ ] Any string containing `render.yaml` is unchanged.
- [ ] No command `RunE` is replaced; no fork.

## Out of scope

- Hard-coded `fmt`/TUI strings inside upstream packages (`Complete login in the Render Dashboard`, `run \`render login\``, logout success copy).
- Hiding `workflows` / `skills` as a product cut.
