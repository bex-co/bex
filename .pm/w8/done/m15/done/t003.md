## Objective

Build a disposable prototype that counts App packets sent to public destinations at the pod boundary, then prove the chosen eBPF attachment and map lifecycle survive pod churn, agent restart, counter reset, and node restart without silent loss or reuse.

## Context

- Hubble flows carry identities but not byte length; cAdvisor transmit bytes have no destination class.
- Cilium 1.19.5 policy statistics are a bounded LRU diagnostic map and do not provide durable resource attribution.
- The production path is Cilium; local CAPD is Calico, so the prototype needs a focused Cilium fixture rather than pretending the existing mock validates it.

## Steps

1. Compare cgroup-skb and TC attachment on a disposable Cilium node and select the least invasive stable hook.
2. Count IPv4 and IPv6 bytes against explicit public/private LPM sets.
3. Exercise pod deletion/recreation, runtime-id reuse, agent restart, map reset, and node restart.

## Acceptance criteria

- [x] The prototype distinguishes public from same-cluster/private destinations for TCP and UDP.
- [x] Every reset/loss condition is detectable and has a defined delta rule.
- [x] The selected hook coexists with Cilium without replacing its programs.
