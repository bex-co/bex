## Objective

Give the service layer one pair of conversions and use them wherever a service's list is saved or read. Saving: an explicitly empty list becomes the single `core.DenyAllCIDR` entry; a list holding only the allow-all ranges becomes no rule; anything else is saved as written. Reading: the deny-all entry alone reads `[]`; no stored rule on a publicly routable type reads `core.UnrestrictedAllowList`; anything else reads as stored.

## Acceptance criteria

- [x] Unit tests pin the three saved states and the three read states, and that reading then saving changes nothing.
- [x] A private service, worker or cron job still reads no list.
