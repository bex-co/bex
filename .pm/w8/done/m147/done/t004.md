Callers (`rg "liveSubscribable|narrowLiveTypes|FollowLogs|followAll"`):

| Caller | Outcome |
| --- | --- |
| `rest.go` `logsSubscribe` pre-slot loop, per resource | narrows each App resource, refuses a filter its type cannot carry (400), then a request-only App tail without a store (503); datastores keep `datastoreFilters` |
| `service.go` `followLogs` (via `FollowLogs`, `followAll` for SSE/NDJSON and WebSocket) | narrows before the plan rule, compiles the App level filter, re-checks `liveSubscribable` (idempotent) |

| GraphQL `logs`, MCP `list_logs` | no live tail; unchanged |

Kinds: web, private, worker, cron and static App tails share one path (no kind branch in `followLogs`); a static site's request lines come from the same store poll. Postgres and Key Value tails are unchanged (`TestSubscribeTailsManagedDatastores`, `postgres_level_test.go`); an App + Key Value subscription under `level=warning` streams each resource's matching lines (new case), and an HTTP filter beside a datastore is still its 400.
