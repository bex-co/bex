## Closed — 2026-11-16 (loopx session)

- **Removed:** the per-language supplied-base mode, which no production pin used once the common base was adopted. That covers `nativeSuppliedBases`, `suppliedNativeImage`, `nativeLine.matchesProvenance`, `NativeChoice.imageSuite`, and the supplied branch of `pinNativePrimary`. That branch fell back to the reviewed image when an exact image's environment could not be read. Common mode instead fails with `read selected native primary environment`, covered by `TestCommonMetadataFailureNeverSubstitutesAnotherRuntime`.
- **Simplified:** `applyNativeSuppliedBase` and its single-caller `transplantNativePrimary` are now one function, `applyNativeCommonBase`. Without a common base the recipe keeps the selected official image; the official-image route stays for the supplier-removed control and the qualification controls.
- **Tests:**
  - Supplied-only tests are deleted.
  - Coverage that applies to the common base moved to `TestCommonBaseRefusesUnreviewedInputs`: a mutable base is refused, and an exact primary environment that is empty, has an invalid name, or contains a newline is refused. It also has a valid-environment control.
  - The official-image half of the backport test remains as `TestPlatformBackportKeepsOfficialExactLookup`.
  - The utility cohort and every generated-image gate now require `BEX_NATIVE_TEST_COMMON_IMAGE` (`nativeUtilityCommonImage`). The historical `BEX_NATIVE_TEST_NODE_IMAGE`/`PYTHON313_IMAGE` supplier inputs are gone; no workflow set them.
- `/simplify` found nothing else.
