## Closed — 2026-11-16 (loopx session)

Audited on main at `885d692b2`; production pin `7aaa8700befa` (common image `sha256:5d6b8139…`).

- **One recipe chain.** `nativeDockerfile` (`native.go:320`) has one caller, `nativeBuildPreparer` (`native.go:531`). `build.go:1487` adds it to every `BuilderNative` build Job, followed by the resolver container (`build.go:1488`). `cmd/native-resolve` calls `ResolveNativeBuildExact` (`nativeresolve.go:65`), which pins the primary (`pinNativePrimary`) and finishes with `applyNativeCommonBase` (`nativeresolve.go:166`). Every native web service, private service, worker, cron job and static-site build therefore ends on the common image, whatever the primary (Node, Python, Ruby, Elixir, Go, Rust, plus the Bun, Node, Ruby and Poetry companions).
- **Build, pre-deploy and runtime use one image.**
  - The service runs the image the build produced.
  - The pre-deploy Job (`app_controller.go:2887` → `reconcilePreDeploy`) runs that same `image`, with the pod's `appEnv` and `platformEnv`, its secret files and its `envFrom`.
  - `psql`, `pg_dump` and `pg_restore` are on the default `PATH` in all three.
  - A static site's image is only its publish Job's extract source, so the clients exist at its build phase only, as on Render.
- **Image boundaries.**
  - The clients and `libpq5` are Debian packages under `/usr`. The selected primary is copied into `/usr/local` after the old tree is removed, then `ldconfig` runs.
  - No `LD_LIBRARY_PATH` or other loader override exists, so no language library is shadowed.
  - Literal image environment is restored with escaping (`TestCommonFoundationPreservesDefaultAndExactSelections`).
  - Dockerfile, image and buildpack services never enter this recipe (builder selection, `app_controller.go:1764`–`1822`). A static site with no build command never builds a native image.
- **Phases exercised on production (t006):** build and runtime, through both CLIs. The live `psql`/`pg_dump`/`pg_restore` round trip ran against a PostgreSQL 18.6 server at build and at runtime.
- **Not executed:**
  - A hosted pre-deploy run. Free refuses `preDeployCommand` (Render's rule, `settings_check.go:67`), and these fixtures are Free only. The Job runs the identical image digest, so it holds the same binaries. The 2026-10-30 dev-8 Job proof above ran the controller's PodTemplate.
  - ARM64. D3 limits production qualification to linux/amd64, and the ARM64 common variant gets light local checks only.
  - Non-Node primaries on production. Families run 43883107194 covers them on the same digest: 36 cases, including static, native-init, Python, Ruby, Elixir and Go/Rust.
