## Closed — 2026-11-16 (loopx session)

Audited on main at `0b372d347`; production pin `7aaa8700befa` (common image `sha256:5d6b8139…`).

- **One recipe chain.** `nativeDockerfile` (`native.go:320`) has one caller, `nativeBuildPreparer` (`native.go:531`), which `build.go:1487` adds to every `BuilderNative` build Job. `cmd/native-resolve` calls `ResolveNativeBuildExact` (`nativeresolve.go:65`), which ends with `applyNativeCommonBase` (`nativeresolve.go:166`, `nativebases.go:113`). Every native web service, private service, worker, cron job and static-site build ends on the common image, whatever the primary: Node, Python, Ruby, Elixir, Go and Rust, plus their companions.
- **Phases.**
  - Build, pre-deploy and runtime run one image. The pre-deploy Job (`app_controller.go:2887` → `reconcilePreDeploy`, `app_controller.go:7361`) runs the image the build produced, so `pandoc` and its data are there in all three.
  - A static site's image is only the publish Job's extract source (`native.go:211`), so Pandoc exists at its build only. Render lists `pandoc` as available at build and runtime, which a static site has no runtime to use.
- **Data and libraries.** `pandoc` reads `/usr/share/pandoc/data` for every Markdown read, not only for templates: with that directory gone, even a fragment conversion exits 97 (`Could not find data file …/abbreviations`), checked on Debian 12 arm64 with the identical package. The data and every library are distribution packages under `/usr`. The selected primary is copied into `/usr/local` and `ldconfig` runs. No `LD_LIBRARY_PATH` or other loader override exists, so no runtime library shadows `liblua5.3` or `libgmp`. No Pandoc environment variable is set, so an authored `PATH` or `XDG_DATA_HOME` keeps its meaning.
- **Cache.** The base is digest-pinned. Tenant source and environment changes do not touch its layers, and a package change is a new digest that misses the cache.
- **Exclusions.** Dockerfile, prebuilt-image and buildpack services never enter this recipe (builder selection, `app_controller.go`). A static site with no build command never builds a native image.
- **Neighbors kept.** FFmpeg, the PostgreSQL clients and the companion and package-manager steps are unchanged; m93 changes no product code.
- **Exercised versus source-only.**
  - Production (t006): build and runtime, Node 24, both CLIs.
  - Maintained cohort on `5d6b8139`/`4b809600`: compute build and network-off runtime on Node 24. Static build and the omission control run from this milestone's commit on (t005).
  - Families runs on the same digests: the other primaries, companions, native-init and static.
  - Not executed: a hosted pre-deploy run (Free refuses `preDeployCommand`, Render's rule, `settings_check.go:67`) and ARM64 (D3).
