## Closed — 2026-11-16 (loopx session)

Maintained real-image checks, run by every `native-common-image.yml` utility cohort (`TestNativeUtilityGeneratedImages`) on the image it publishes:

- **Original conversion** (already maintained). `node-compute` runs the frozen m93 program: the UTF-8 Markdown document converts at build, and again on three HTTP requests at runtime with `--network none`. The exact source, document, program and HTML hashes pass, and the output is parsed independently.
- **New, `utility-check.py`** (runs at the `node-compute` build and network-off runtime and at the `node-static` build):
  - a UTF-8 Markdown table, link and heading become a standalone HTML5 page through the packaged `pandoc-data` template and a Lua filter (`pandoc.text.upper`) on the packaged `liblua5.3`;
  - an independent `html.parser` pass checks the title, headings, table cells, link text, the exact `href` and `charset=utf-8`;
  - an unknown reader and a failing Lua filter both exit non-zero.
- **New, `missing-pandoc` omission control.** A test-only layer removes only `/usr/bin/pandoc`, checks that no other `pandoc` is on `PATH` and that `/usr/share/pandoc/data` survived, then runs the original m93 build, which must fail with `pandoc: command not found` after the layer's ready line. The original probe records `ENOENT` first, which is the historical failure.
- **How this was checked before shipping.** The host is arm64 and the adopted image is amd64-only, so the generated-image gate cannot run here. On Debian 12 arm64 with the identical `pandoc` 2.17.1.1-2~deb12u1:
  - the new block passed;
  - it failed with `templates` removed (exit 97) and with `liblua5.3.so.0` removed (exit 127);
  - on `node:24-bookworm`, the original m93 build passed with Pandoc, and after the omission layer it printed the ready line, then `pandoc: command not found`.
  - The push of this change re-runs the amd64 utility cohort through `native-common-image.yml`, which publishes and qualifies a fresh image; that run is the amd64 proof.
- **Unit and package checks.** `go test ./internal/build/` (including `TestNativeOriginalReplayHTTPOracles` and the omission-evidence tests), `go vet`, `gofmt` and `golangci-lint` on the package.
- **Bounds.**
  - ARM64 is out of scope (D3).
  - Pre-deploy runs the same image; no hosted pre-deploy (Free refuses it).
  - Formats beyond Markdown, HTML and the Lua filter, PDF engines and remote fetches are not covered.
