The resolve phase (bex's own image, `BEX_NATIVE_INIT`) stages it into `/native/init` with the release mtime, and buildctl gets it as the `bex-init` named context. The Node serving tail is `COPY --link --from=bex-init /native-init /` + `ENTRYPOINT ["/native-init"]` after the build RUN, with the CMD bytes unchanged. With no resolver image, the generated image keeps `ENTRYPOINT []` and no context/env. A missing binary fails the resolve phase (exit 1), not the tenant.
