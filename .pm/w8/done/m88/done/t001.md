## Objective

Implement termination forwarding and descendant lifetime so normal native npm shutdown can finish its active work. [Finding](../finding.md).

## Steps

1. Start the exact command as an owned process group; forward SIGTERM/SIGINT and wait/reap terminating descendants even when an npm ancestor exits.
2. Preserve normal command exit/errors, argv/cwd/environment and all three standard streams; coordinate launch/exit/signal races with real processes.
3. Use the included passing local mechanism only as a control; produce maintained Go behavior and deterministic process tests.

2026-10-16: done — `lego/operator/cmd/native-init` (the filed `cmd/native-start` name was not used). It runs the exact command (own process group unless PID 1), forwards TERM/INT/QUIT/HUP/USR1/USR2/WINCH, exits at once with the command's status (127/126/128+n) when it exits on its own, and after a TERM/INT/QUIT-triggered exit signals what is left (kill(-1) as PID 1, the group otherwise) and reaps until nothing remains. Every signal is followed by a reap. `main_test.go` exercises real processes, run on macOS and on Linux in the pinned Go image (3×): argv/stdio/env/cwd, statuses, forwarding, the npm shape, an unrequested exit and an uncooperative leftover. Not covered: a signal landing before `signal.Notify` in the microseconds after exec (as PID 1 it would be ignored and kubelet's SIGKILL ends the pod).
