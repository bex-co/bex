# 075 — Clones inherit fields forbidden by the requested service type

Why: static → web and web → cron clones fail on flags the user never supplied, although direct creation of each requested free service works.

Severity: **minor**. Attribution: **upstream Render CLI**, shared by Bex and unmodified Render. Estimate: **~1h** to prepare an upstream applicability fix and regression cases for this shared default merge. Upstream acceptance, a Bex dependency refresh and a CLI release are separate prerequisites; this note does not authorize external submission, shipping or a CLI fork. Source: user-requested functional `$qa-find-bugs-cli` loop in w8, 2026-10-09 UTC. Goal: dependable hosting configuration reuse (ADR008 / ADR018).

## Producer → consumer and fix

- Bex correctly returns the static publish path: `lego/backend/internal/apps/render.go:419`, `renderServiceDetails`. Keep that field; removing it would break static reads and same-type clones. REST get/list and MCP use this shared projection; GraphQL's flat publish-path field is unrelated to the CLI merge.
- Pinned `pkg/service/clone.go:202–207` reads static `PublishPath`; `applyBaseDefaults:217–220` honors the caller's type override. `applyAdditionalCloneDefaults:271–279` then copies `PublishDirectory` **without checking the resulting type**.
- Pinned `pkg/types/service/servicecreate.go:282–285` correctly restricts that field to `static_site`. `cmd/servicecreate.go:139–147` merges then validates; request construction and POST occur only afterward, at `:158–162`. **Live HTTP mutation traffic was not intercepted.** The local-validation attribution is supported by this command trace and the actual pinned builder probe, not a claimed live no-POST capture.
- The same missing destination-type check affects web defaults: `pkg/service/clone.go:151–164` extracts the correct health/start/instance/shutdown/maintenance fields. `applyAdditionalCloneDefaults:275–277` and `applyServiceTypeDefaults:292–298` inherit them unconditionally. `pkg/types/service/servicecreate.go:277–300,312–320` then correctly rejects incompatible flags. Bex's producer (`lego/backend/internal/apps/render.go:422,449–459`) must keep these correct web fields, including the schema-required disabled maintenance block.
- **Fix:** inherit each type-specific source default only if the resolved destination supports it. Use the same applicability rules as `validateFlagsForType`, including the other type-specific default helpers, rather than fixing only the first publish/health error or retrying after validation. Preserve caller-supplied incompatible flags so validation still refuses them. Keep same-type inheritance, compatible fields and explicit overrides unchanged. Make this change upstream; do not strip correct Bex response fields or weaken server validation.

One production caller of `ServiceFromAPI` was found (`cmd/servicecreate.go:176`); service creation is noninteractive. The inherited field affects **four nonstatic target types**: web, private, worker and cron. The latter three were reproduced through the pinned merge/validate/build pipeline **offline only**, with no paid production requests. Static → static constructs a request containing the publish path; removing only the implicit publish field makes static → web construct its valid request. Counterfactual inputs are diagnostics, not product fixes or live acceptance.

## Acceptance and limits

- With the same captured static source, each of the four nonstatic target types validates and builds a request without an inherited publish directory. A caller-supplied `--publish-directory` still fails for every nonstatic type.
- Same-type static clone retains `publishPath`; repo, branch, root override, auto-deploy and supported target settings retain precedence. Re-run fresh free static → web through Bex and unmodified Render: create exits 0, latest deploy Live, marker HTTP 200, then exact cleanup. Direct-create controls remain valid.
- Web → cron no longer inherits health/start/instance/shutdown/maintenance settings; both clients create the requested free cron, which reaches Live and produces its own scheduled marker. Same-type web retains those five fields. Explicit incompatible flags remain refusals. Cover private/worker and other affected target combinations through the pinned merge/validate/build pipeline without paid live fixtures.
- Re-run the private [probe](evidence/075/probe.go.txt) with [go.mod](evidence/075/go.mod.txt) and [go.sum](evidence/075/go.sum.txt), copying them to ordinary filenames and placing both captured `source-*.json` files beside them; `GOWORK=off GOTOOLCHAIN=go1.27.0 go run -mod=mod .`.
