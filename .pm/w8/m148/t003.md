## Objective

List every network fetch bex adds to native builds (not the user's own `npm install` etc.): URL host, which builds hit it, and whether it can move to bex-controlled supply. Move any GitHub-hosted one the same way as t001, or file a follow-up.

## Context

- `rg -n "ADD --checksum|https://" lego/operator/internal/build/*.go`: `nativehugo.go`, `nativepnpm.go` (registry.npmjs.org, legacy pnpm on every Node build), `nativecommon_erlang.go:151` (OTP URL in the base image Dockerfile), Docker Hub helper images.

## Acceptance criteria

- [x] The inventory is recorded in this task, with a verdict per fetch.
- [x] No remaining per-build `github.com` fetch, or a filed follow-up for each.

## Done — 2026-11-10

Every network fetch a native build makes that the tenant did not write (`rg -n "ADD --checksum|https://|FROM " lego/operator/internal/build/native*.go`). A native build's Dockerfile is generated whole, so each of these is bex's:

| Fetch | Source | Builds that hit it | Verdict |
| --- | --- | --- | --- |

No per-build `github.com` fetch remains once t001's pin lands. No follow-up filed: npm and the image registries are already hard dependencies of the builds that use them.
