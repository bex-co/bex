## Objective

Build a reusable `GitCredentialsMenu` popover that mirrors Render's `/web/new`
"Credentials (N)" dropdown: a trigger showing the connected-account count, and a
panel listing every connected GitHub account/org with its repo count, an
"Open in GitHub" external link, a "Configure in GitHub" grants link, and a
per-account Disconnect (confirm) — plus a "Connect another account" action and
the ADR075 claim fallback. It composes the existing git hooks; it adds no
GraphQL. This is the standalone component; t002 mounts it.

## Context

- Backend surface already ships (ADR075 / w5/m74): `gitConnections`
  (`accountLogin`, `installationId`, `createdAt`, `installUrl`), `connectGit`,
  `disconnectGit(installationId)`, `claimGit`, `repos` (annotated with
  `accountLogin`/`installationId`). See `dashboard/src/features/git/api/git.graphql`.
- Existing hooks to reuse: `dashboard/src/features/git/hooks/use-git-connection.ts`
  (`useGitConnections` → full list; `useGitConnection` → singular view),
  `use-connect-git.ts`, `use-disconnect-git.ts`, `use-claim-git.ts`.
- The full management UX already exists in Settings —
  `dashboard/src/features/git/components/connect-github-card.tsx` — reuse its
  list/disconnect/claim logic and unavailable/error handling as the reference.
- Repo counts per account: `useRepos()`
  (`dashboard/src/features/services/hooks/use-repos.ts`) returns repos carrying
  `accountLogin`/`installationId`; count per `installationId`.
- "Open in GitHub" per account → `https://github.com/<accountLogin>`;
  "Configure in GitHub" → the connection's `installUrl`.
- Popover primitive: `dashboard/src/common/components/ui/` (Popover/DropdownMenu);
  confirm via `dashboard/src/common/components/confirm-dialog.tsx`.
- Connect-in-a-new-tab: the shared `use-connect-git.ts` does
  `window.location.href = url` (loses the create form). This menu must open the
  install in a **new tab** — add a new-tab connect action (a small variant/hook,
  or a `mode` on the existing hook) that does `window.open(url, "_blank")` after
  the `connectGit` mutation; do not change the Settings card's behavior.

## Steps

1. Add a new-tab connect action (variant of `use-connect-git` or a `mode` param)
   that fires `connectGit` (ownerId-scoped per ADR075 §6) and opens `installUrl`
   in a new tab.
2. Build `GitCredentialsMenu` (`dashboard/src/features/git/components/`): trigger
   "Credentials ({count})"; panel with account rows (login, repo count,
   Open-in-GitHub, Configure-in-GitHub, Disconnect+confirm), a Connect-another
   action, and the claim fallback.
3. Handle the three edge states from the Settings card: unavailable (no GitHub
   App / 503), error, and loading; and the disconnected (zero connections) state.
4. Add en + zh i18n keys under the `git.*` namespace
   (`dashboard/src/features/git/locales/{en,zh}.ts`).
