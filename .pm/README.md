Before proposing or materializing roadmap work, read [`DO_NOT_DO.md`](./DO_NOT_DO.md) and treat it as a hard constraint.

Every `wN` worker is general-purpose and may take work anywhere in the bex project. A workstream directory records scheduling and history only; it does not define a permanent mission, specialty, component boundary, or ownership claim.
