## Objective

Implement the accepted native sign-in, restore, refresh/revocation, and logout lifecycle with secrets confined to OS-protected storage.

## Context

- Use system browser and verified deep/app links; bind state, nonce, PKCE verifier, issuer/resource, redirect, and token audience.
- Never log or persist credentials in AsyncStorage, Apollo persistence, crash reports, or WebView state.

## Steps

1. Add auth adapter, secure storage, redirect validation, expiry/refresh, and logout revocation.
2. Fail closed on cancellation, issuer mismatch, replay, storage unavailability, or offline expiry.

- `mobile/src/features/auth/**`
- `mobile/app/auth/**`
- `mobile/app.json`

## Acceptance criteria

- [ ] Real iOS/Android sign-in, restart restoration, expiry, and logout work without browser-readable/plaintext credentials.
