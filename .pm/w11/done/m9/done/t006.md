## Objective

Verify the drawer composes existing Render-compatible workspace/current-user semantics without creating cross-surface drift, and record why the native navigation treatment is a bex extension.

## Context

- Workspaces come from the existing GraphQL `workspaces` projection while current user intentionally comes from Render REST `GET /v1/users`; logout uses the existing OAuth revoke route.
- Render has no official mobile app per ADR048, so drawer placement/gesture behavior cannot be a mobile Render-parity requirement.
- The PM standing parity rule still applies because this is a tenant-facing surface and any semantic mismatch must be filed rather than hidden in UI composition.

## Steps

1. Verify workspace id/name/plan/role and current-user name/email match their existing REST/GraphQL/dashboard/CLI semantics for the same OAuth caller.
2. Verify workspace selection remains client context rather than a new mutation and logout preserves the existing revoke/error contract.
3. Confirm no GraphQL/MCP current-user work is warranted—the endpoint's documented REST-only decision remains valid—or file concrete drift if evidence changed.
4. Amend ADR048 or the closest mobile evidence note with the drawer's Beancount provenance, global-control rationale, and deliberate lack of desktop configuration actions.

## Files

- `docs/ADR048-mobile.md` or a focused `mobile/e2e/` evidence note
- `docs/ADR018-render-parity.md` (only if an existing semantic claim changes)
- `.pm/w11/NNN.md` (only for a concrete discovered follow-up)

## Acceptance criteria

- [ ] Same-caller workspace/current-user fields are evidence-backed against existing platform surfaces with no silent shape/authorization drift.
- [ ] The record distinguishes Render API compatibility from the Beancount-inspired native navigation extension.
- [ ] The audit confirms no forbidden mobile configuration/dangerous action and no unnecessary GraphQL/MCP addition.
- [ ] Any real mismatch is captured as separate concrete follow-up work rather than silently expanded into m9.

## Out of scope

- A broad Render dashboard walk or treating absent official Render mobile UI as a parity defect.
