## Objective

Finish the drawer's fixed personal section with identity status and a deliberate logout action that reuses the reviewed local-first session teardown on every route.

## Context

- `SessionManager.signOut()` captures the current token, starts best-effort feature cleanup/revocation, clears protected local session state and the Apollo identity boundary first, then settles remote cleanup.
- The current Status header exposes an unlabeled-state icon that calls `signOut()` immediately; every other route lacks logout.
- Beancount confirms logout with a native alert before invoking its one auth action.

## Steps

1. Add a fixed drawer footer with avatar/fallback, personal name/email or translated status, retry affordance for a failed status read, and a destructive Logout row.
2. Require a localized native confirmation before calling `useAuth().signOut()`; guard double taps while logout is pending.
3. Close the drawer and let the existing auth guard redirect after local teardown; report no false failure when remote revocation alone fails.
4. Remove the page-local Status logout icon/imports so workspace/account actions have one global owner.
