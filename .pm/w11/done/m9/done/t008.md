## Objective

Lock down the drawer's behavioral and security boundaries with focused unit/component tests plus iOS and Android interaction evidence, avoiding static snapshots and duplicated lower-layer auth tests.

## Context

- m2 already tests PKCE, credential storage, refresh races, local-first logout, workspace invalidation, and invalid deep links; m9 must test the new orchestration atop those contracts.
- Highest-risk regressions are stale profile/workspace responses after a boundary change, gesture theft, missing global access on nested routes, and a logout UI that bypasses confirmation or double-submits.

## Steps

1. Test drawer state transitions, interrupted animations, backdrop/back/button/swipe dismissal, horizontal-swipe ownership, and reduced-motion behavior at pure/helper boundaries where possible.
2. Test workspace ordering/selected metadata, no-op and successful switch dismissal, retry states, and absence of old-workspace UI after reset.
3. Test current-user response validation, timeout/abort/offline/unavailable states, identity-bound late-response suppression, and no persistence/logging.
4. Test logout cancel/confirm/double-tap/local-first failure behavior and removal of Status-page duplicates.
5. Run the full mobile checks and record focused simulator/device interaction on both platform bundles.

- `mobile/src/components/app-drawer/__tests__/**` (new)

## Acceptance criteria

- [ ] Tests fail on stale identity/workspace display, unsafe sheet dismissal timing, gesture ownership regressions, logout bypass/double-submit, and missing drawer access from a nested route.
- [ ] Tests assert real state/actions/accessibility output rather than snapshotting the entire drawer tree.
- [ ] Current-user fixtures and failure messages contain no real personal data, tokens, or raw OAuth subjects.
- [ ] `yarn format:check`, `yarn typecheck`, `yarn lint`, `yarn test:unit`, `yarn expo:check`, `yarn bundle:ios`, and `yarn bundle:android` pass.
- [ ] iOS and Android evidence covers button/swipe open, switch, profile state, cancel/confirm logout, back/dismissal, rotation, and a chart/pager gesture non-regression.

## Out of scope

- Repeating PKCE cryptography tests or gaming coverage with snapshots/tautologies.
