## Objective

Create one drawer instance around the existing authenticated Tabs so every tab and nested detail route can open the same stationary side menu without changing route identities or remounting tab state.

## Context

- `mobile/app/(app)/_layout.tsx` currently renders `WorkspaceProvider` directly around `Tabs`; this is the narrow shared mount for a drawer provider.
- The Beancount reference uses `LedgerDrawerProvider` + context, a stationary menu layer, translated app content, a header button, backdrop close, Android BackHandler, and edge swipe.
- Expo Router SDK 57 has an official Drawer navigator, but adopting it here would add Reanimated/Worklets and require nesting/moving the established tab/detail route tree. The drawer contains context/actions, not peer destination routes, so a wrapper is the smaller architecture.
- `mobile/src/common/horizontal-swipe-owner.ts` and `GestureHandlerRootView` already exist from the source client.

## Steps

1. Adapt the reference drawer/provider/header-button structure under a bex-owned `components/app-drawer/` module, using current theme and translation primitives.
2. Wrap `WorkspaceTabs` once inside the authenticated `WorkspaceProvider`, keeping Tabs and hidden detail routes unchanged.
3. Add a consistent menu trigger to the app's screen header pattern without duplicating one drawer per route.
4. Preserve tap-backdrop, programmatic open/close, interrupted-animation generation guards, and Android back behavior.

## Acceptance criteria

- [ ] Exactly one drawer instance wraps all authenticated tabs and nested detail routes.
- [ ] Button, backdrop, left-edge swipe, leftward close swipe, and Android back open/close the same drawer state.
- [ ] Switching tabs, following a deep link, or opening a nested detail does not remount or duplicate the drawer and existing route URLs remain valid.
- [ ] No Reanimated/Worklets/navigation-tree dependency is added unless implementation evidence disproves the settled wrapper approach and the milestone record is amended first.

## Out of scope

- Replacing bottom tabs, adding new top-level routes, or porting Beancount analytics/ledger domain code.
