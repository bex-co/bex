## Objective

Show cron run history and expose only existing run-now and current-run cancel actions with safe-action conventions.

## Context

- Reuse dashboard cron contracts/hooks and m4 confirmation/idempotency behavior.
- Render-compatible run-now cancels an active run and starts one replacement; it is not an active-run rejection.

## Steps

1. Reject run-now server-side while the cron service is suspended without writing run/cancel intent.
2. Add pagination/status/timing/general-service-log links plus capability-aware run/cancel and convergence.

## Files

- `lego/backend/internal/apps/**`
- `mobile/src/features/cron/**`

## Acceptance criteria

- [x] A suspended cron run-now returns conflict and writes no run/cancel intent; an active run is cancel-and-replaced by one confirmed request.
- [x] Double taps are single-flighted; an ambiguous timeout forces history refresh before a new confirmation or retry.
- [x] Terminal runs, authorization, billing conflict, convergence timeout, paging, and empty history are tested.
- [x] Mobile selects only opaque run id/status/timestamps; mechanism name, schedule, command, shell, and configuration mutations remain absent.

## Out of scope

- Schedule/build-command editing or cron shell.
