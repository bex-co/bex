## Interim live-verifier coverage (2026-08-16)

`scripts/agent-session-verify.sh` now exercises the m7 protocol instead of only
the older generic attach flow. Its explicit `BEX_LIVE_VERIFY=1` run proves:

- distinct read/turn tickets, wrong-action refusal, single-use nonce refusal,
  exact session binding, and a strictly increasing `afterSeq` replay;
- one AI SDK-shaped live POST with a stable idempotency key, a durable user turn,
  monotonic assistant bounds, and an identical retry that creates neither a
  second turn nor new transcript IDs;
- a real ACP permission pause with only advertised one-shot choices. Auto mode
  selects only `allow_once`; manual mode leaves the driver paused for the signed-
  in mobile client and fails if it chooses anything other than that exact
  one-shot continuation;

  `agent_needs_decision` inbox row whose resource and deep link are the same
  generated session before permitting a response.

walkthrough: tap the real inbox item, render/respond to the typed decision,
background/foreground during streaming, verify cursor recovery/no duplication,
and inspect completion/fallback. `bash -n` and diff checks are green.
