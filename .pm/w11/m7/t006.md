## Implementation evidence (2026-08-16)

- REST, GraphQL, and MCP were audited against the shared `agentsessions.Service`:
  durable conversation/cursor reads, typed decision list/respond, prompt-turn
  idempotency, and `read`/`turn` attach minting all delegate to the same core
  authorization, validation, and coded-error paths. The stream remains the
  intentional REST-only byte transport; GraphQL/MCP expose its ticket mint.
- Dashboard parity now includes a fail-closed pending-decision dock with
  optimistic-version responses, server-declared one-shot permission actions,
  safe declared-field forms, secret-shaped schema rejection, and credential-free
  HTTPS external elicitation. It replaces ordinary steering while a decision is
  pending or the decision state cannot be read. English and Chinese copy and
  focused behavior/failure tests were added.
- `ADR018`, `ADR047`, and `ADR048` record the shared cursor, ticket, idempotency,
  decision, client recovery, and phase-1 fallback boundaries. Dashboard
  typecheck/lint, all 310 Vitest files (2125 tests), and the production client +
  SSR build pass.
- Offline codegen still hits the repository's existing GraphQL 17/codegen
  introspection visitor bug (`InputValueDefinition.directives` is absent and
  codegen calls `.find`). The feature operations therefore use the existing
  typed hand-splice pattern and were reconciled directly against the backend
  schema dump; fixing the generator dependency mismatch is separate tooling
  work, not a wire-contract divergence.

This task stays open on the board because its declared dependency chain
