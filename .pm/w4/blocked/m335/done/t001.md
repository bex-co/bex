## Objective

Keep each side's CPU and memory targets on the audit row, and record nothing when a save changes nothing.

## Result

- **2026-11-11 (loopx w4):** done. Migration `0231_audit_autoscaling_targets` adds `autoscaling_cpu_from/_to` and `autoscaling_memory_from/_to`. `core.AuditEvent` gains the four fields, and `RecordAutoscalingChanged` now takes each side's `AutoscalingSpec` (nil when disabled). `SetAutoscaling` records no event when the requested config equals the enabled one. The write still runs, so a service being deleted still answers 404. `DeleteAutoscaling` records the config it removed. The feed and the by-id lookup read the columns through `AuditChanges` (`store/events.go`), whose verbs now include `apps.SetAutoscaling` and `apps.DeleteAutoscaling`.
