## Objective

Factor the load-then-authorize-on-owner resolution into one helper used by every by-id verb. Add a guard test that drives each registered by-id route with a resource in a non-default workspace and fails when any returns 403/404. Model it on the existing scope-matrix guard tests.

## Outcome (2026-10-04)

Done:
- **Shared resolver:** `core.Base.ScopeByID`, used by every fixed family.
- **Guard:** `internal/api/byid_resolution_guard_test.go` `TestEveryByIDRouteResolvesItsOwnWorkspace`. It enumerates every live REST route with a path id (188 routes, 23 families), fails on an unclassified family, and fails when a classified family's package stops referencing its resolver. Both failure modes were confirmed by mutation.
- **Deviation:** this is a classification and mechanism guard, not a route-driving behavioral one. The behavioral coverage lives in each family's own tests (t006).
