## Objective

Confirm the live request-log behavior is one behavior on every surface that exposes it.

## Steps

1. REST subscribe dialects (WebSocket for Render CLI v2+, SSE, NDJSON) all ride `followAll`/`followLogs` — verify no dialect re-checks the old refusal.
2. GraphQL and MCP expose no log tail — record that, and that their historical reads are unchanged.
3. Render comparison: Render's log stream (`render logs --tail`, websocket protocol) carries request logs live; note any field-shape drift of streamed request entries vs history entries and file follow-ups instead of silently diverging.
4. Record the outcome in ADR018 if the ledger tracks the log-stream row it changes; check ADR010's "tail reads pod logs" line and amend it to name the second producer.

## Acceptance criteria

- [ ] Every subscribe dialect accepts and streams `type=request` identically.
- [ ] ADR010/ADR018 wording matches the shipped behavior.

## Out of scope
