## Objective

Make t001's proven producer available through the existing reproducible node-image workflow, with auditable source/patch/binary pins and a documented rollback.

## Steps

1. Integrate the demonstrated supported upstream release, or the narrow patched kubelet dependency build, into the existing snapshot workflow and Packer inputs. Do not introduce a parallel undocumented node-install path.
2. Lock the source revision, patch checksum, binary checksum and applicable version/architecture. Existing Packer worker images install amd64 Kubernetes packages; prove the exact supported target rather than assuming the dashboard API client's version identifies the node.
3. Verify baked and non-baked node-template install paths and current-node rollover retain the corrected artifact. Account for control-plane nodes if workloads can execute there; no blanket claim from one worker.
4. Require one worker/canary to provision and serve a fixture through the ordinary pod API before broad adoption, following the existing Packer runbook. Record artifact identity and rollback to the prior pin.
5. Update source/runtime version validation so a stock kubelet replacement cannot silently discard the remedy.
