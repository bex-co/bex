## Two traced causes and bounded fix

`dashboard/src/common/components/route-skeletons.tsx:2132–2137` chooses `EditableMetadataSkeleton rows={10}` and `CardSkeleton rows={2}` for these two regions.

`EditableMetadataSkeleton:426–446` has no name-editor lead. It creates ten grid rows with 46px minimum height on mobile and 60px at desktop, and turns every third value into a 36px control placeholder. Ready `DatabaseMetadataCard` explicitly supplies `DatabaseNameRow` as the lead (`database-metadata-card.tsx:46–49`). `MetadataList` renders that lead in a separate `mb-4 border-b pb-4` wrapper above its ordinary label/value grid (`metadata-list.tsx:33–56`). `database-name-row.tsx:27–45` supplies the static hint and disabled name input/pencil through `EditableFieldRow`. In this PostgreSQL 18 fixture, the Version value is plain text because no upgrade target exists; the placeholder's arbitrary control pattern does not describe it.

Connections uses the generic two-text-bar card (`detail-skeletons.tsx:113–134`). Ready `ConnectionInfoPanel:41–70` has a title, description, and Reveal action while `info` is absent. Its default masked state is the target; the revealed password/URL layout is not.

The independently traced sibling uses `EditableMetadataSkeleton rows={8}` at `route-skeletons.tsx:2212`; ready `KeyValueMetadataCard:40–45` supplies `KeyValueNameRow` as the same `MetadataList` lead. `key-value-name-row.tsx:23–43` supplies the static hint and name editor through `EditableFieldRow`. The private fixture has seven ready facts; a representative pending row count alone is not the defect. Key Value Connections instead uses `ReservedCardSkeleton` at `route-skeletons.tsx:2215–2217`, whose generic header/body block omits the description/action. Ready `keyvalue/components/connection-info-panel.tsx:43–70` supplies those two regions. This producer is distinct from the Postgres Connections placeholder.

The actual Card primitives were inspected: `ui/card.tsx` gives Card its padding/gap, CardHeader two auto rows with a 4px gap, and CardTitle `leading-none`. The measured ready title is 16px plus that header gap, whereas the pending title placeholder is 20px. This is native DOM/CSS geometry, not a chart/router library layout inference.

**Target:** correct the shared metadata preview for its two verified callers, and replace the two Connections call sites with faithful masked previews using the existing Card/field primitives. Details needs the separate Name label, static hint wrapping, full-width disabled-input geometry, pencil-action slot, divider, and the facts grid's real padding/spacing. Connections needs its title, static description region with the same responsive wrapping, and a 36px Reveal-button placeholder. Use known translated static labels/help to preserve wrapping if useful; keep entity values as inert placeholders. Never instantiate mutation hooks with a fabricated datastore just to reuse a ready editor, or expose connection values before the read/reveal.

Match the two cards' measured bounds at both widths instead of offsetting lower sections with compensating margins. Reserve representative optional fact rows without inventing resolved public/HA/status values; cover the public-host and older-version upgrade-control shapes in implementation verification. Preserve the outer grid, right/compact navigation, parent header, deferred panels, and other route regions.
