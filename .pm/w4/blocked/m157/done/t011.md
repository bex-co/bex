## Objective

Preserve PostgreSQL JSON/JSONB numeric tokens and scalar identity before the generic any decode rounds or erases them. A bounded query-local codec using owned RawMessage values is demonstrated in json-finding.md; cover scalar and native-array elements in text/binary formats, preserve dimensions, and retain existing GraphQL string/null and REST/MCP native JSON schemas.

## Context

- [JSON evidence and researched fix](../json-finding.md) — continuous functional QA pass 51, 2026-10-10.
- Existing m157 typed-value work and m158 exact MCP serialization remain separate prerequisites and regression contracts.

## Steps

1. Implement the bounded lossless JSON conversion on ephemeral query connections, including JSON/JSONB array ElementType codecs.
2. Preserve SQL NULL, quoted JSON strings, JSON null and exact numeric tokens through the existing adapters.
3. Keep raw and encoded budgets, row truncation and existing execution behavior; avoid global pool or serializer changes.

- [x] The captured object and JSONB[] number keep 9007199254740993 and the complete decimal digits.
- [x] The top-level JSON-null GraphQL cell is string null; the quoted JSON string remains quoted; actual SQL NULL stays nullable.

## Out of scope

Global driver forks or pool changes, schema/type metadata redesign, SQL policy changes, unrelated product work, and production table/data writes.
