# Free datastore storage written before w4/427 still prices: October's Free Postgres/Key Value rows carry no tier, and their Stripe events were already sent

Why: w4/427 makes new Free storage rows $0, but every row written before its rollout (2026-10-28 04:15Z) has no tier, so the current month's estimate still charges Free storage. For any collected Hobby workspace, those `storage_gb_hours` events already reached Stripe and will invoice at month end.

Severity: minor (cents per datastore, but a "Free" resource still shows a charge for this month, and real invoices may carry it). Estimate: ~45m. Source: live `/qa-find-bugs w4` loop run 4513, 2026-10-28 UTC (`muse.env`, Hobby workspace `tea-daif693dqjvc73e7as3g`, production pin `d368e383fcb1`, which contains `dd525ed52`).

## Evidence

- `/billing` → Charges → Expand all, read at 04:21Z on the new pin: **Postgres $0.02**. The Free `qa-20261017-64552e-pg14` (`dpg-db9r654flioc739mcpbg`, "Free: 1 of 1") is still **$0.01**, unchanged from run c5dd before the fix.
- `dd525ed52` (w4/427): "Storage usage rows now carry the datastore's plan … each meter has its own forward cursor, so no window already written is re-keyed" (`lego/backend/internal/usage/service.go` `processDatastoreMeterWindow`). `pricing.Sheet.rateFor` returns $0 only when `tier == "free"`, so an untiered historical row keeps `storage.usdPerGBSecond`.
- w4/427 left its "Unverified: check Stripe meter events for `storage_gb_hours` against Free datastores before deciding on credits" item open.

## Fix

- Backfill the tier on existing `storage_gb_seconds` rows from the datastore's plan for the window (plan history if it exists; otherwise the current plan, for datastores that have only ever been Free), at least for the current billing period. Or price an untiered storage row with the datastore's recorded plan at read time.
- For collected workspaces, find the `storage_gb_hours` meter events already sent for Free datastores this period, and cancel or credit them before the October invoices finalize. Record the decision in w4/427's ADR030 note.
- Test: an untiered historical storage row for a Free Postgres prices at $0 after the backfill. A paid one keeps its charge.

## Unverified

- Whether new (post-04:15Z) hourly storage rows for this Free Postgres are priced at $0. Only the month-to-date total was readable, and the first new windows had not closed. Re-read the line after a few hours.
- Whether any collected Hobby workspace holds a Free datastore this month.
