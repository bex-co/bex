## Objective

After suspend → resume, a free Postgres reads `available` while its external data path stays dead (`SSL error: unexpected eof`) for 6+ minutes across 4 consecutive probes. Make `available` mean the data path is up — or report the transitional state honestly.

## Context

- Live repro 2026-09-17, fixture `dpg-daloivd2r12c73cnghbg` (free, deleted after the sweep):
  - Pre-suspend: `bex psql -c 'SELECT 1'` exits 0 (with `PGSSLROOTCERT` provisioned per t001).
  - Suspend (direct `POST /v1/postgres/{id}/suspend`, empty body — the CLI needs `--confirm`, previewed without it) → `202 suspended`; resume via `bex postgres resume --confirm` → converges to `available` in ~70s.
  - Then 4 consecutive `bex psql` failures over ~6 min: `SSL error: unexpected eof while reading` (server `2a01:4f8:c01e:3d1f::1:5432`).
  - Ruled out: allow-list intact (`162.224.81.143/32` still present); egress IP unchanged (the CLI's own gate still resolves the same address, and clearing the list moves the failure to the client-side gate, proving the server was being reached).
- Cause UNVERIFIED (needs server-side evidence: pg-sni-proxy logs for DENY vs NO-BACKEND on these handshakes, CNPG cluster wake state after resume). Candidates: proxy route not re-registered on wake; backend still starting while status is already `available`; stale `ExternalHost`/certificate. Do not guess — pull the proxy/operator evidence first.
- Related: two isolated first-connection EOFs also preceded the first successful psql earlier in the sweep (then self-healed). If the same mechanism, one fix covers both; if not, split it.

## Steps

1. Reproduce on demand (create → psql-ok → suspend → resume → psql) and capture proxy-side verdict per handshake (denied vs unrouted vs backend-refused) plus CNPG pod/endpoint state across the resume window.
2. Fix the layer at fault: re-register/retain the proxy route across suspend-resume, and/or hold status out of `available` until the first backend handshake succeeds (a readiness probe, not optimism).
3. Add a regression that suspends, resumes, waits for `available`, and asserts a real query succeeds within the DoD budget.
