## Objective

Show on a real meter that capacity rows equal plan GB × seconds, and that no Key Value storage is billed.

## Steps

1. **dev-4:** bring the stack up (`bash scripts/dev-env.sh 4 up`) and create a paid Postgres and a Key Value (disposable). After an hour closes, read `GET /v1/usage`.
   - The Postgres has a capacity row of storageGB × seconds and a used-bytes row.
   - The Key Value's storage is shown at $0.
   - The emitter's dry path sends `storage_gb_hours` for the capacity only.
2. **Production:** once the deploy pin carries the shipped commits, sign in as the QA user (`bash scripts/qa-login.sh`). In `bex-canary`, create the same pair (disposable) and read the usage API and the Billing page after an hour closes. Then delete both.
3. Write the conclusion into this task: the numbers, the commands, and no raw dumps.

## Acceptance criteria

- [ ] The capacity row equals storageGB × seconds held on both environments.
- [ ] No billed Key Value storage line appears on either environment.
