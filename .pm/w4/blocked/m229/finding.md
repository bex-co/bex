## Cause and target

- `blueprint_plan.go:354–359` also applies a Blueprint-inherited Git source whenever this narrowed field set contains neither repo nor image and the current service is prebuilt. Thus probing **name only** still invokes applyBlueprintRepo, clears the old image and changes the source. `:178–190` implements that legitimate full-apply source transition. The unrelated scalar's equality cannot save its probe.
- The overlay-only actual-source diagnostic constructs minimal matching scalar state and records all twelve probes. Every probe changes Repo/Image; even name-only reports true. A same-image name-only control reports unchanged. No product source file or fix was created. The diagnostic deliberately asserts the faulty premise; it must not be copied as a passing expectation for repaired behavior.

The renderer is faithfully showing a producer error, so filtering a few names in the UI is insufficient.
