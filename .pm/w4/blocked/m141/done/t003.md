## Objective

Give each Rollback (and Cancel) row control an accessible name that identifies its deploy, for example "Roll back to 80b423b (dep-…79s7g)", matching `w4/084`/`w4/150`. At filing, two rows exposed identical `button "Rollback"`.

## Result (2026-09-27)

Row controls carry `aria-label` "Roll back to <short-sha> (<deploy-id>)" and "Cancel deploy <short-sha> (<deploy-id>)" (the deploy id alone when there is no commit), en + zh.
