## Objective

Find every operator path that assumes a native image holds only its Root Directory, starting with the disk mount mapping, and make it right for the whole-repository image without moving an existing service's disk.

## Context

- `movedDiskMount` (`lego/operator/internal/controller/disk.go:184`) remaps a native service's disk mount that lies outside its Root Directory, and flags a mount that would hide the source (`hides`); it was written for an image that holds only the Root Directory ([ADR082](../../../docs/ADR082-persistent-disks.md)).
- Callers of `build.NativeSourceDir` and `build.NativeWorkdir` across `lego/operator/`.

## Steps

1. List every caller of `NativeSourceDir` / `NativeWorkdir` and say for each whether the wider image changes its answer.
2. Re-derive `movedDiskMount`: a disk must never hide the service's own source, and a service that already has a disk keeps the same in-container mount path on its next deploy. If the mapping must change, it changes only for disks created afterwards, and ADR082 says so.
3. Add tests for an existing disk mounted outside the Root Directory, one mounted inside it, and one at an ancestor of it.

## Files

- `lego/operator/internal/controller/disk.go` and its tests
- `docs/ADR082-persistent-disks.md` if the rule changes

## Acceptance criteria

- [x] An existing native service with a disk keeps its mount path across the change (test).
- [x] No mount hides the Root Directory's source (test).
- [x] ADR082 states the rule that holds after this task.

## Result (2026-11-25)

Callers of `NativeSourceDir` / `NativeWorkdir` and whether the wider image changes their answer:

- `controller/disk.go` `movedDiskMount`: no. It maps a disk against `NativeSourceDir`, which is still the image's last `WORKDIR`, so every mount path is the same before and after (`TestNativeImageWorkdirIsNativeSourceDir` pins that for every runtime, two repository forms and six root directories).
- `cmd/native-resolve` (`BEX_NATIVE_PROJECT_DIR` = `nativeSourceDir`, version files read from the checkout's Root Directory): no.
- `nativeversion.go` narration, `nativePythonVenv`, `nativeSourceLink`, the secret-file links, the static publish check and the publish Job's extract (all relative to the last `WORKDIR`): no.
- `depscache.go` `nativeSourceDependencyDirs` (Rust `target`, Elixir `deps`/`_build` in the working directory): no.

`movedDiskMount` needed no change. Its tests already cover a disk outside the Root Directory, one inside it and one at an ancestor of it (`TestMovedDiskMountIsTheOldPathInTheRootDirectory`), and an existing service's Deployment mounting it (`TestServingDeploymentMountsAnEarlierDiskInTheRootDirectory`); all pass unchanged. A mount the operator adds still never covers the Root Directory (`hides`). What changed is that a pre-w6/m558 disk's path outside the Root Directory can now sit on a repository directory and hide it, as any disk over a repository directory does on Render; ADR082 § Whole repository says so.
