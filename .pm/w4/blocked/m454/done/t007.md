## Objective

Add meaningful tests for the behavior this milestone shipped: grant and revoke rows per workspace, the Hydra check that refuses a forged grant, remembered consents and platform clients recording nothing, idempotent retries, and the consent and revoke never failing on an audit write. Tests assert real behavior and failure modes.

## Acceptance criteria

- [x] Backend (real DB) and dashboard tests cover the shipped behavior and fail when it regresses.

## Done (2026-11-16)

- `internal/oauthgrant/access_test.go`: one row per workspace from Hydra's newest consent (its scopes, not the union), derived ids stable across a retry, and nothing recorded for a forged report, a consent older than the window or dated ahead of it, or a `skip_consent` client; Hydra or the membership read failing records nothing; a revocation names the client, records nothing for a client Hydra does not know, and records without the name when Hydra cannot answer.
- `internal/cliauth/access_test.go`: the grant route admits only a member's session (no identity, an API key, a human OAuth token and a non-human session are 403), answers 204/404/503 by the recorder's verdict, refuses a bad body; the revocation is audited only after its marker moved and answers 204 when the audit fails.
