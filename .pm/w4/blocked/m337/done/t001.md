## Objective

Record what a rename and a custom-domain change name.

## Result

- **2026-11-11 (loopx w4):** done. Migration `0232_audit_display_name_domain` adds `display_name_from`, `display_name_to` and `domain`. `core.AuditEvent` gains the three fields. `RecordDisplayNameChanged` records a rename's label on each side, using the service's own name (`core.AppPublicName`) on a side with no label. A label change that shows the same name is no rename and records nothing. A create under a free-form name and a Blueprint's first label go through `labelNewService`, which records no rename. `RecordDomainEffect` takes the hostname. A delete records one row per host that went away, so deleting an apex also names the `www.` sibling it takes with it. The feed and the by-id lookup read the columns through `AuditChanges`, whose verbs now include the rename and the three domain verbs.
