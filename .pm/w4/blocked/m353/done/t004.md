## Objective

Add tests that assert this milestone's behavior and its failure modes. No trivial or snapshot-everything tests.

## Acceptance criteria

- [ ] `health-probe drain`: a pass sleeps, and fail, refused, timeout and bad arguments each return at once with exit 0.
- [ ] Projection: the preStop's check arguments always equal the liveness probe's, for path, port and Host, the "can never disagree" invariant of `healthCheckHandler`.
- [ ] Regressions:
  - workers and disk-attached services carry no preStop;
  - `terminationGracePeriodSeconds` stays drain + `maxShutdownDelaySeconds`;
  - a stored template without the new preStop is not rewritten on operator upgrade.

## Outcome (2026-11-14)

Done.

- `lego/operator/cmd/health-probe/main_test.go` `TestDrainWaitsOnlyForAPassingInstance`: HTTP and TCP passes sleep the 60 s (recorded through a seam). A 500, a refused connection, a timeout, a refused TCP connection, a missing `--seconds`, a missing check, an unknown check and a bad flag each return at once without draining.
- `lego/operator/internal/controller/health_probe_drain_test.go` covers four things:
  - `TestDrainRunsTheLivenessCheckFirst`: the preStop's check equals the liveness probe's (path, port and Host for a path, `tcp --port` without one), for web and private services. It also asserts the helper is installed and the grace is drain + 30.
  - `TestHealthProbeCheckArgsFollowTheProbe`: a kubelet HTTP probe maps to the no-redirect check with the same path, port and Host. Unrunnable shapes (foreign exec, named port, none) fall back to the sleep.
  - `TestHealthCheckedDrainOnlyWhereADrainApplies`: workers and disk-attached services carry no preStop, and a worker gets no installer. An operator without an image keeps the sleep.
  - `TestHealthCheckedDrainIsAdoptedOnTheNextRollNotOnUpgrade`: a stored sleep (path service) and a stored helper-free TCP pod are not rewritten on upgrade. The next roll adopts the checked drain and the installer, then re-projects unchanged.
- The existing drain and grace regressions (`TestTrafficServingPodsDrainBeforeSIGTERM`, `TestWorkersAndDiskAttachedServicesDoNotDrain`, `TestDrainLengthIsAdoptedLazilyFromTheOldDrain`, the envtest shutdown cases) still pass. `TestNoRedirectProbeOnlyWhereItApplies` now expects the installer on a TCP-checked service.
