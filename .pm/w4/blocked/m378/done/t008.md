## Objective

`get_metrics` answers with the object Render's server marshals. Its `data` arrays are the same time-series the REST metrics endpoints return.

## Context

- Shapes: [README § Round 296 extension](../README.md#round-296-extension--get_metrics-has-bexs-shape-too-2026-11-13-13521358-utc-pin-5de3d5bcce8e).
- Today `getMetricsResult{Series []MetricSeries}` (`lego/backend/internal/metrics/mcp.go:73-79`) goes out through the typed path.
- The REST adapters already render Render's `labels[{field, value}]`, `unit` and `values`. Reuse that renderer.

## Steps

1. Build `{resourceId, timeRange: {start, end}, metrics: [{type: <Render metric type>, data: <REST time-series>}]}`, grouping the series by requested metric type.
2. For more than one `resourceId` (bex's extension), say how the result is shaped: one object per resource, or the first. Keep Render's single-resource call exact.
3. Map the core's `code` label to `statusCode`, and the other core label names to REST's, exactly as REST does.
4. Correct the tool description so "Render-shaped" is true.

## Acceptance criteria

- [x] A test decodes the MCP text and checks every `data` item against the REST handler's output for the same fixture.

## Outcome (2026-11-14)

- `get_metrics` answers Render's `MetricsResponse`: `{resourceId, timeRange: {start?, end?} (the call's own bounds, RFC3339Nano, omitted when not passed), metrics: [{type: <requested spelling>, data: <REST series>}]}`, through `mcputil.RenderText` (no `structuredContent`).
- `renderStatusCodeLabel` (metrics/render.go) is the one `code` → `statusCode` mapping for REST and MCP; bex's `metric` label is no longer added.
- Multi-id: bex's legacy `resource` array answers a JSON array with one `MetricsResponse` per resource; Render's single `resourceId` call answers the one object.
- The description now says what it returns. `get_datastore_metrics` (bex-only) keeps `{series}` (`datastoreMetricsResult`).
- Tests: `TestMCPGetMetricsIsRendersMetricsResponse` (data equals `GET /v1/metrics/cpu|memory`), `TestMCPGetMetricsStatusCodeBreakdownIsRESTs`, `TestMCPGetMetricsLegacyResourceArrayAnswersOnePerResource`, `TestMCPGetMetricsWireIsRendersText`.
