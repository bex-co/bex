# Static sites are served from a global CDN, as Render's are, or ADR018 records the single-region origin with the user's sign-off

Why: Render parity. Render promises every static site "a blazing-fast, reliable, and secure global CDN" that caches "on network edges around the world". bex serves each static site from one origin in one Hetzner location, so a visitor far from it pays origin latency for every asset, and no ADR018 row says so.

- **Render (read 2026-11-27):** [static-sites](https://render.com/docs/static-sites) § Global CDN; [multi-service-architecture](https://render.com/docs/multi-service-architecture): "Render static sites are served by a globally distributed CDN"; [render-vs-heroku-comparison](https://render.com/docs/render-vs-heroku-comparison) and [migrate-mongodb-static-hosting-to-render](https://render.com/docs/migrate-mongodb-static-hosting-to-render) say the same.
- **bex:** a static site is served by the in-cluster static server behind Traefik ([ADR029](../../../docs/ADR029-static-sites.md)), and every tenant host resolves to the one Hetzner load balancer (`infra/terraform/main.tf`). ADR018 § Services & lifecycle: Static site is ✅ and does not mention delivery; the Edge caching row records "not a global CDN" for web services, with no sign-off. `w21/126` covers DDoS protection and the Cloudflare decision, not CDN delivery, and `w4/736` only the `cf-cache-status` header.
- **Do:** decide with the user between putting a CDN in front of static-site hosts (the same decision `w21/126` asks about Cloudflare would cover it) and recording the single-region origin as a signed-off divergence in the Static site and Edge caching rows. Until then, add the divergence to both rows as unsigned, so the ledger stops reading ✅.
- **End state:** a static site's first byte from a distant region comes from an edge near it, or ADR018's Static site row records the single-region origin with the user's sign-off.
- **Size:** the ledger half about 20m; the CDN itself is a milestone.
- **Source:** w4/m688 t002, full reads of four Render docs pages, 2026-11-27.

## Worked (2026-11-27, `/loopx w4`)

- **Premise re-checked:** Render's [static-sites](https://render.com/docs/static-sites) § Global CDN still reads "Render serves your site over a blazing-fast, reliable, and secure global CDN" and "We cache your content on network edges around the world" (read 2026-11-27). `sveltekit-static.onrender.com` resolves through `gcp-us-west1-1.origin.onrender.com.cdn.cloudflare.net` and answered `cf-ray …-SJC`, `cf-cache-status: EXPIRED`, from the data center nearest the client. A `*.onbex.co` host resolves to `49.12.20.236`, the one `lb11` in `fsn1` (`infra/terraform/main.tf`), and bex's `cf-ray` ends in `FRA` for every visitor (`defaultColo`, `deploy/gitops/charts/traefik-plugins/clientipheaders/clientipheaders.go`).
- **The ledger half, shipped:** [ADR018 § Services & lifecycle](../../../docs/ADR018/services-lifecycle.md) Static site row ✅ → ◐ on every column, with the single-region origin recorded as unsigned (Render's claim, both hosts' evidence, what a distant visitor pays, and the decision that closes it). The Edge caching row ✅ → ◐ (MCP stays `—`): its three 2026-11-19 differences were never signed off, and difference (1) now points at this note.

## Parked (2026-11-27, `/loopx w4`)

- **Gate (the user):** choose one. (a) Sign the single-region origin off: a worker records the sign-off, its date and the user's words in the Static site row (and difference (1) of the Edge caching row) and closes this note. (b) Approve a paid CDN in front of static-site hosts, and a worker files the milestone.
- **Why it is not a worker's call:** a CDN for every static site needs spend only the user can approve. Cloudflare already holds `onbex.co` for DNS only, and [ADR093](../../../docs/ADR093-onbex-wildcard-tls.md) says bex calls it to renew, never to serve. Fronting custom domains with it needs Cloudflare for SaaS (100 hostnames included, then $0.10 each a month), and wildcard custom domains and apex proxying need Enterprise (`w21/126`'s read, 2026-11-24). The Cloudflare Enterprise approval that `w21/126` (b) asks for would cover this one too. A self-run edge in Hetzner's other locations would need servers and geo-steered DNS, which also costs money.
- **What milestone (b) must carry:** proxied static-site hosts and custom domains (including apex and wildcard), purge on every successful deploy as Render does, the static server's `cf-cache-status` (w4/m703 t004) moved to the CDN, and bandwidth metering for edge-served bytes, since a cached hit never reaches Traefik, whose response bytes are what bex counts today (`lego/backend/internal/metrics/bandwidth_sources.go`).
