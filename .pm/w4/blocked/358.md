# A Blueprint `ipAllowList` can restart and empty a Persistence Off Key Value without the confirmation

Why: w4/m233 made a Key Value's first external-access enable the only restart left, and made REST, GraphQL and MCP refuse it on a running Persistence Off store unless `confirm` carries `sudo clear key value <name>`. A Blueprint sync reaches the same change by another road. A nonempty `ipAllowList` on a private store sets `spec.public` through `ApplyBlueprintKeyValueSpec` and a direct `Client.Patch`, never through `updateKeyValue`. The first enable then adds the TLS listener, restarts the store and deletes every key, and nothing asks first.

- **Source:** `w4/m233` t001 writer audit, 2026-10-19 (loopx w4). Reasoned from code, not probed live.
- **Path:**
  - `lego/backend/internal/apps/blueprint_plan.go:587-590` `ApplyBlueprintKeyValueSpec` flips `Public` when `ipAllowList` is present.
  - `apps/deploy.go:3838-3845` patches the CR directly.
  - Reached from REST `POST /v1/blueprints`, `/v1/blueprints/deploy` and `/v1/blueprints/{id}/sync`, GraphQL `createBlueprint`/`syncBlueprint`, MCP `deploy`/`create_blueprint`/`sync_blueprint`, and `BlueprintAutoSyncWorker` (no human in the loop).
- **Decision needed:** a Blueprint has no `confirm` channel. Options:
  - The plan refuses that change with a named error pointing at the Networking card or API, where the confirmation exists.
  - The plan lists it as a destructive change and requires an explicit apply flag.
  - Accept and document it.

  Whichever is chosen, the auto-sync worker must not take it unattended.
- **Related, same audit:**
  - Allowlist and `public` changes are outside `protectedKeyValuePatchVerb` (`keyvalue/protection.go:35-50`), so a protected environment's store takes its one remaining restart without the protected phrase. The m233 restart phrase still applies to Persistence Off stores.
  - GraphQL and MCP create with an `ipAllowList` but no `public` make a private store, while REST create infers public from a nonempty list (documented in ADR021 as the create default, so this is recorded, not a bug).
- **Estimate:** 45m once decided.
