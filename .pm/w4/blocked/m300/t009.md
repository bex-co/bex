## Objective

In Recent Runs, the row toggle of a run that ended `canceled` with no `startedAt` says the run never started. Today it says "not started yet", which describes a run still waiting. A pending run with no `startedAt` keeps "not started yet". Neither name ever contains the `crr-` id.

## Context

- **Live, round 81 of the `/qa-find-bugs w4` loop, 2026-11-11** (`bex-canary`; production runs `348bd77a5`, which contains this milestone's `d4d105415`). On `qa-20261111-cr81` (`srv-dbq0s52p92ls73cjjfn0`, deleted afterwards), a trigger at 06:48:11Z replaced a running run. `DELETE /v1/cron-jobs/srv-dbq0s52p92ls73cjjfn0/runs` then canceled the replacement before its Job started.
  - `GET …/runs` read `{"id":"crr-9qiacn9v5s1dlq39e0f1","status":"canceled","finishedAt":"2026-11-11T06:48:27.309940155Z"}`.
  - After a reload, the Events tab's Recent Runs rendered `row "— Run details, not started yet (row 1) — Canceled"`.
- **The cause.** `dashboard/src/features/services/components/cron-runs-section.tsx:256-263` picks `services.cronRunDetailToggleNotStarted` whenever `run.startedAt` is empty, whatever the status. The message is at `dashboard/src/features/services/locales/en.ts:3184-3187` (zh `zh.ts:3120-3123`), and its description says it is for "a just-triggered pending run".
- **Same round, recorded for t008's replay.** The deploy gate this milestone waited for has passed; production runs `d4d105415`.
  - **P1:** `POST` +330 ms → `200 {"id":"crr-lq305qd7tqfb76u7s733","status":"pending"}`. `GET …/runs/crr-lq305…` at +540 ms → `200 pending`. `?limit=1` at +745 ms lists it first. GraphQL `cronJobRun(serviceId, runId)` at +1042 ms → `pending` with `startedAt: null`. `startedAt` 06:49:59Z appeared by +4.5 s, and the run ended `successful`.
  - **P2:** `POST` +473 ms → `crr-0rgefo7osddub0123mq3`, then `DELETE …/runs` at +741 ms → `204`. `GET` at +941 ms → `canceled` with `finishedAt`, still `canceled` 20 s later. The run has no log line and no `cron_job_run_started`.
  - **P3:** two `POST`s by +1005 ms → A `crr-trv603s0gk1bgvngvmil`, B `crr-m3mggmrr8eh674kbgk4g`. A read `canceled` at +1365 ms. B started 07:06:49Z and ended `successful` once. The list holds both.
  - **Not replayed:** P2 via `POST …/runs/X/cancel` and GraphQL `cancelCronJobRun`, P3's "eleven runs later", P4 at 1440 and 390 px, and the adjacent classes.

## Steps

1. Add `services.cronRunDetailToggleNeverStarted` in en ("Run details, never started (row {n})") and zh.
2. In `cron-runs-section.tsx`, use it when `startedAt` is empty and the status is not in `ACTIVE_STATUSES`. Keep `…NotStarted` for an active run.
