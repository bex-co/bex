## Result

- **2026-11-11 (loopx w4):** done. 25 codes: the health-check stall by target (GET or TCP), state (waiting or failed) and liveness restarts (8, built from `ProbeStallWaiting`/`ProbeStallFailed`, so `TerminalStallText` still turns one into the other), `rollout_deadline_exceeded`, five pre-deploy verdicts (`pre_deploy_window_exceeded` {minutes}, `_out_of_memory` {code}, `_exited` {code}, `_failed`, `_could_not_launch`), `build_never_started` {cause}, `build_abandoned`, `deploy_abandoned`, and eight cancel reasons (`canceled_suspended`, `superseded_by_newer_release`, `superseded_by` {deploy}, `canceled_by_restart` {deploy}, `canceled_along_with` {deploy}, `canceled_along_with_newer`, `restart_service_gone`, `restart_wait_timed_out` {wait}). The probe templates end in `{hint}`, which matches nothing or an appended sentence, so the port hints the operator adds on scanning passes keep the code. Every parameter but a path, a cause and a hint is one token, and the template that fixes the most text is tried first, so a parameter cannot swallow another template's text.
