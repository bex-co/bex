## Objective

Give already-persisted incompatible managed App references a bounded, idempotent repair path that cannot erase concurrent valid placement or adopt foreign resources.

## Context

- The new writer prevents future drift but captured rows stay projectB/environmentA until explicit reassignment.
- ListDesiredApps joins inherited rules by environment_id alone, and current committed reads expose that source.
- ADR032/w1m56 retired RepairDriftedEnvironmentIDs and environments-backfill at c5d31d1c6. Do not reintroduce old pre-m28 migration behavior or datastore clobber residue handling.

## Steps

1. Inventory only demonstrably incompatible source pairs using both parent-project and tenant ownership; define dry-run output/limits without secret values. Establish the maintained projection/repair boundary and an explicit implementation choice.
2. Conditionally clear the observed incompatible reference and inherited projection with stable App/tenant identity; retry/interruption must preserve a later valid assignment. Do not blindly clear every null/missing/foreign reference.
3. Native PG plus controlled CR/projector fixtures show old drift, post-repair null environment, unchanged own configuration/allowlists, and a second no-op pass.
4. Verify cancellation/partial failure and bounded fair work. Record production data count/repair as an unperformed operational gate unless the authorized implementation run actually executes it on a known scope.

## Resolution (2026-10-10)

Chosen boundary: there is no automatic sweep (per the finding). Existing (B, A/Stage) drift is repaired by the next explicit membership write naming the service, which is now conditional on the environment not belonging to the project. It reports a truthful (B,Stage)→(B,nil) diff, so the inherited CR layer is cleared too, and a second pass is a no-op (native PG case in the same regression). The projector re-derives LabelEnvironment from SQL. Production inventory/re-save of drifted projects remains an unperformed operator step and is recorded in ADR032.
