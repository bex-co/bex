# 646 — The zh dashboard calls Secret Files two names: 20 messages say 密钥文件 ("key file") and 6 say 机密文件, both on the service's own Environment page

Why: a Chinese-speaking user reads two different terms for the same thing. The Environment page, the new-service form and the env-group pages each mix them. The service's Environment page describes itself as managing "环境变量、机密文件和已关联的环境组", then heads the section "密钥文件" with the button "添加密钥文件". The new-service form says "添加机密文件". 密钥 also means a cryptographic key, so "密钥文件" reads as a key file, not an arbitrary secret file such as `.npmrc`, `.env` or a certificate.
