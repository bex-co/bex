## Objective

Select the new identity in the shared Logs operation and regenerate types. Preserve embedded query-scoped Apollo log data with an explicit LogEntry keyFields:false policy in the shared CSR/SSR cache; the new id would otherwise activate default normalization. Carry history and SSE payload IDs into LogLine and prefer them for record keys. Keep a documented compatible fallback for genuinely ID-less legacy shapes, without allowing a millisecond collision to override distinct authoritative IDs. Reuse the SSE JSON id field; outer SSE id/Last-Event-ID remains the timestamp resume cursor.
