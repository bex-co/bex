# A new stable Go release reaches native Go builds within about a day, as on Render

Why: Render's changelog of 2026-04-16 ("Automatic Go version updates") moves its native Go to the latest stable Go 1.x, "usually within 24 hours of a new release". bex's Go line moves when someone commits a reviewed digest bump after a weekly freshness issue, so a new Go release can take a week or more to reach a build. Found by w4/m553 t002 on 2026-11-22 ([disposition table](../../docs/render-artifacts/render-changelog.md)).

- **bex:** `lego/operator/internal/build/native.go` pins one Go line (`golang:1.27-bookworm@sha256:…`, w5/m144) and says it tracks Go's latest stable. `.github/workflows/build-toolchain-freshness.yml` runs on Thursdays and opens a tracking issue when a digest moves. `scripts/image-pin-validate.sh` requires every image to stay digest-pinned.
- **End state:** a new stable Go 1.x release (a new patch or a new minor line) is in the native Go builder within about a day, with nobody's action, and the image stays digest-pinned with its checks run before it ships. A test or the freshness self-test covers the new release being picked up.
