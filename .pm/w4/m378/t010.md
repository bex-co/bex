## Objective

The six datastore tools return the same objects REST returns, which are Render's `keyValueDetail`/`postgresDetail`.

## Context

- [README § Round 298 extension](README.md#round-298-extension--datastore-tools-return-bexs-flat-views-2026-11-13-14221430-utc-pin-5de3d5bcce8e).
- MCP returns `KeyValueView`/`PostgresView` (`lego/backend/internal/keyvalue/mcp.go:109-140`, `lego/backend/internal/postgres/mcp.go:108-140`).
- REST maps through `renderKeyValue` (`keyvalue/rest.go:45-…`) and Postgres's equivalent REST mapper.

## Steps

1. Route each tool's result through the REST mapper, including the owner lookup REST does.
2. Keep bex's additive keys (`public`, `internalAuth`, `externalAccessRestarts`, `blueprintId`, `projectId`) only where ADR018 records them as extensions. Otherwise drop them.
3. Cover the list items (t001's arrays) with the same mapper.
