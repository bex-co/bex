## Objective

`scripts/auth-oauth21-e2e.sh` hid both bugs: it registers with `audience` (`:293`) and authorizes with `audience=` (`:447`), which no real MCP client does. Make one leg behave like a real client: register without `audience` (and without `scope`, as the SDK v1 does), authorize with `resource=` only, and expect `/mcp` to accept the token.

## Context

- `scripts/auth-oauth21-e2e.sh:278-293`, `:447`, `:516`.
- w31/001 changes the same script to read `registration_endpoint` from metadata; build on it.

## Steps

1. Add (or convert) a leg that mirrors the MCP SDK: discovery → DCR without `audience` → authorize with `resource=$RESOURCE` → consent → token → `/mcp`.
2. Keep the existing `audience=` leg for platform clients.
3. Run the script locally.
