## Objective

Expose the audit trail to workspace admins: `GET /v1/audit-events` (newest-first, filterable by `resource`, `startTime`/`endTime`, `limit`) and a matching GraphQL `auditEvents` query — gated on the OpenFGA manage scope (`can_manage`), 403 for everyone else, 503 store-less.

## Context

- Render's REST spec has no audit endpoint (dashboard-only feature there), so the REST shape is bex's own under Render's vocabulary conventions — document that, per the established "bex's own, documented" precedent (env-var mutations).
- Follow the feature-package layout: this likely becomes a small `internal/audit` feature package with `service.go` + `rest.go` + `graphql.go` fragments composed in `server.go`.
- Scope reads to the caller's workspace (tenant column from t002) so w1/m9 enforcement applies automatically.
