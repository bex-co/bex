## Objective

Persist audit events in the control-plane store: an `audit_events` migration (id, tenant, caller, verb, resource, outcome, at — indexed by tenant + time), a store-backed `AuditSink`, and a documented retention cap so the table can't grow unbounded.

## Context

- The store (`lego/backend/internal/store`, w1/m2) already runs embedded migrations; follow its migration conventions.
- Tenant column keys to the caller's workspace (`tea-…` id) so w1/m9's scoping applies to audit reads too; pre-m9 rows carry the default workspace.
- Retention: simplest credible mechanism (e.g. delete-older-than-N-days on write, or a periodic sweep in the projector loop) — pick one, document it in the migration/README.

## Steps

1. Migration for `audit_events` + indexes.
2. Store `AuditSink` implementation; wire it in the composition root when `BEX_CP_DB_URI` is set (no-op otherwise).
3. Retention sweep + a knob if warranted (default value documented).
