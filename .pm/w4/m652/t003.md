## Objective

Prove on `.pm/w4/dev-4/` that a service created with a disk mounts it on its first deploy, with no second deploy or Recreate restart.

## Context

- `bash scripts/dev-env.sh 4 up` brings up dev-4 (pre-approved; AGENTS.md).

## Steps

1. From the create page, create a paid web service with a 1 GB disk at `/var/data`.
2. Check that the first deploy mounts it: write a file there through the service (or its shell) and read it back.
3. Restart the service and read the file again.
4. Check `GET /v1/services/{id}/deploys` lists exactly one deploy before the restart, and that the service's events show no Recreate for adding the disk.
