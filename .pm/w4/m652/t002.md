## Objective

Add an Add Disk control to the create page's Advanced section that sends t001's argument, reusing the Disk page's mount path field and size options.

## Context

- Render: "You can do so during service creation (click *Advanced* at the bottom of the creation form), or any time _after_ creation from your service's *Disk* page" (render.com/docs/disks, read 2026-11-25).
- bex's after-create disk UI: `dashboard/src/routes/services.$serviceId.disk.tsx`, `dashboard/src/features/services/components/disk-section.tsx`, `dashboard/src/features/services/hooks/use-disks.ts`.
- w4/m651 adds Health Check Path and Pre-Deploy Command to the same `CreateAdvanced` section (`dashboard/src/features/services/pages/new-service-page.tsx`); build on its layout.
- Locales: `dashboard/src/features/services/locales/{de,en,es,ja,ko,pt,ru,zh}.ts`.

## Steps

1. Add the control, hidden for a static site and a cron job, and disabled on Free with the reason the Disk page gives.
2. State, as the Disk page does, that a service with a disk runs one instance and has no zero-downtime deploys.
3. Send `disk` from `create-service-input.ts` only when the control is filled in; drop it when the type or plan stops allowing it.
4. Add the strings in all eight locales, and component and builder tests.
