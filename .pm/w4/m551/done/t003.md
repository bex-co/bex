## Objective

Implement ADR009's two GraphQL fields over one core verb.

## Context

- Postgres GraphQL: `lego/backend/internal/postgres/graphql.go`; service create: the shared create path in `lego/backend/internal/apps/` (the one REST `POST /v1/services`, GraphQL and MCP use).
- Render has no REST or MCP surface for admin apps (a dashboard feature), so none is added.

## Steps

1. Add the catalog (from t001) and `postgresAdminApps(databaseId)`, answering each app's deployed service (found by the link label) or none.
2. Add `deployPostgresAdminApp(databaseId, app, credentials)`: authorize per ADR009, generate missing credentials per t001, create the web service through the shared path with its env vars, the internal connection, the explicit port, and the database's region/project/environment; audit it as a service create.
3. Refuse a second app of the same kind for one database with Render's behavior from t001.
