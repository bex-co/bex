# An image service's Credential dropdown lists only the credentials for the image's registry, as Render's does

Why: Render parity. On Render's image forms the Credential dropdown holds only the credentials whose registry matches the image URL, so a person picking a credential for a GHCR image is not offered their Docker Hub one. bex lists every credential, and choosing one for another registry is refused only at create (`400` image-host mismatch).

- **Render:** read from its public dashboard bundle on 2026-11-26 ([registry-credential-dialog.md](../../docs/render-artifacts/registry-credential-dialog.md) § The Credential dropdown). The image forms pass the parsed image's registry (`parsedRegistryType`) and the dropdown keeps `credentials.filter(c => !type || c.registryType === type)`. The parser maps `*pkg.dev*` to Google Artifact, `*dkr.ecr*` to AWS ECR, `docker.io` to Docker, `ghcr.io` to GitHub and any host containing `gitlab` to GitLab. An image on any other host shows every credential. The settings and Docker-build dropdowns pass no type.
- **bex:** `RegistryCredentialSelect` (`dashboard/src/features/services/components/registry-credential-select.tsx`) lists every credential on every page. Each credential's registry is already on the view (`RegistryCredentialView.registry`, w4/m670), and `registryForHost` (`dashboard/src/features/registry-credentials/lib/registries.ts`) is bex-api's `renderRegistry`.
- **Do:** give the select an optional image URL. On the create page's Existing Image source, keep the credentials whose registry is the image host's (a credential for a self-hosted host matches only that host), and keep the current selection listed even when it no longer matches. Leave Settings → Image, the Docker-build and the Build Source dropdowns unfiltered, as Render does. Add tests for a GHCR image, a Docker Hub image, a self-hosted image and an unparsed host.
- **End state:** typing `ghcr.io/acme/web:1` on the create page leaves only GitHub credentials (and Add credential) in the dropdown; `registry.example.com/web:1` shows every credential.
- **Size:** about 45m, too small for a milestone.
- **Source:** w4/m670 t005's parity check, 2026-11-26.
