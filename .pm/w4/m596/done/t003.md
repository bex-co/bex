## Objective

Mount Render's `suspend-sandbox` and take it out of `renderOperationOmissions`.

## Context

- Render, live OpenAPI of 2026-11-23: "Suspend the running sandbox with the provided ID. Returns HTTP 202 after the sandbox starts suspending, or if it is already `suspending` or `suspended`. Retrieve the sandbox until its status is `suspended`. Open commands and connections end. The next connection resumes the sandbox." The 202 has no body. A sandbox that is not `running`, `suspending` or `suspended` answers 409 `sandbox_not_running`.
- bex:
  - `sandbox.Service.Suspend` (`lego/backend/internal/sandbox/service.go:1878`) suspends through `lifecycle` (`:1931`), which needs `can_operate` and runs `beforeSuspend`.
  - It is mounted only as the bex extension `POST /v1/sandboxes/{id}/pause`, which answers 204 (`lego/backend/internal/sandbox/rest.go:226-229`, `lifecycleREST`).
  - Nothing in the repository calls `/pause` apart from its route tables (`sandbox/ratelimit.go:113`, `api/scope_matrix_ops.go:1082`, `api/key_permission_ops.go:1110`).
  - `sandbox_not_running` is already `sandbox.CodeSandboxNotRunning` (`sandbox/records.go:46-66`).
  - The idle suspender (`sandbox/idle.go`, w2/m278) suspends the same way.
- GraphQL and MCP have no sandbox suspend today. Render's MCP has no sandbox tools ([ADR104](../../../docs/ADR104-sandbox-render-parity.md)).

## Steps

1. Mount `POST /v1/sandboxes/{id}/suspend` with Render's statuses:
   - 202 with no body when the sandbox starts suspending, or when it is already suspending or suspended (idempotent);
   - 409 `sandbox_not_running` for any other state (pending, terminated, errored);
   - 404 for an unknown or another workspace's sandbox.
2. Add the route to the rate-limit, scope-matrix and key-permission tables, with the same class and permission as `/pause`.
3. Decide `/pause`: keep it as a bex alias with its own 204, or retire it now that Render's verb exists. Record the choice in ADR104.
4. Add GraphQL `suspendSandbox` and MCP `suspend_sandbox` beside the existing sandbox verbs, so the capability is reachable on every surface. If the dashboard shows sandboxes, add its Suspend action.
5. Remove `suspend-sandbox` from `renderOperationOmissions`.

## Acceptance criteria

- [ ] A running sandbox's suspend answers 202 with no body, and the sandbox reads `suspending` or `suspended`. A repeat answers 202.
- [ ] A terminated sandbox answers 409 with `"code": "sandbox_not_running"`. An unknown id answers 404.
- [ ] The response validates against the pin, and the operation coverage test counts the operation as served.
