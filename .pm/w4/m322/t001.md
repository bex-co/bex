## Objective

One selector picks every pod a cron App's runs create: scheduled and manual, at every service name length up to 30. It picks no other App's pod. Metrics (cpu, memory, instance-count, limit history) and the usage meter keep reading the same selector.

## Context

- **The selector.** `egressquery.PodNameMatcher`/`PodNameRegex` (`lego/backend/internal/egressquery/podname.go:69-94`) match `<obj>-[a-z0-9]+-[a-z0-9]{5}` or `<obj>-[a-z0-9]{62-len(obj)}`.
- **The live pod names this misses** (round 81):
  - manual run: `tea-daif693dqjvc73e7as3g-qa-20261111-cr81-run-1c18537e-wkvfv`, from Job `ManualCronRunJobName` = `<app>-run-<8 hex>` (`lego/types/v1alpha1/cron.go:39-42`);
  - 30-character name, scheduled run: hostname `tea-daif693dqjvc73e7as3g-qa-20261111-cr-5cb8a9072637-29906350-q`, from `FitCronJob` (`lego/types/k8sname/k8sname.go:64-68`, `MaxCronJob` 52).
- **Labels exist, but aren't exported.** Run pods carry the App's labels from the template (`lego/operator/internal/controller/app_controller.go:4988` for CronJob Jobs, `:5284` for manual-run Jobs). kube-state-metrics exports only `nodes=[bex.co/pool]` labels (`deploy/gitops/base/prometheus.yaml:108`).
- **The Job name is a run's identity.** `ManualCronRunJobName` is shared by the backend (`lego/backend/internal/apps/service.go:1348`, `:4154`) and the operator (`app_controller.go:5246`, `:5545`). It derives the run's `crr-` id (w4/m300).

## Steps

1. **Choose the mechanism and record why** in `podname.go`'s doc and ADR010's selector section.
   - Preferred: an identity join, either a kube-state-metrics `metricLabelsAllowlist` entry for the App id label joined `on(namespace, pod)`, or a `kube_pod_owner` ownership join.
   - Alternative: rename both Job kinds into `PodNameRegex`'s shapes, and teach the regex the hashed `FitCronJob` prefix.
   - Rejected: a bare `<obj>-run-[0-9a-f]{8}-[a-z0-9]{5}` alternative, which also matches a sibling App `<name>-run`'s Deployment pods.
2. **Implement it** so `PodNameMatcher`'s callers (`metrics/source.go:288`, `:453`; `usage/service.go:1246-1248`) all pick it up. A cron-only path is acceptable if Deployment Apps keep the name selector.
3. **If renaming,** state how a run triggered during a backend/operator skew keeps one `crr-` id, and keep m300's tests green.
