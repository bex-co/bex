## Objective

`Create` gates on `can_create` because a session sandbox receives the workspace's reusable BYO model key. `Steer` did the same thing under `can_operate`. Raise it, which requires `can_create` to exist on the `agent_session` type.

## Context

- `lego/backend/internal/agentsessions/service.go` — `Create` carries a `SECURITY (codex #1)` comment whose rationale ("the credential entered the sandbox at create time, authorized by a developer") does not cover `Steer`: `Steer` reloads the same key via `s.modelAPIKey`, takes a caller-supplied prompt and egress allowlist, and dispatches a **fresh** sandbox.
- `deploy/gitops/authz/model.fga` — the `agent_session` type defined only `can_view` and `can_operate`, so gating on `can_create` against the session object needed a new inherited relation (and the regenerated `model.json`).
- Deploy ordering matters: `scripts/authz-model.sh` must apply the new model before the new bex-api image serves traffic, or every `Steer` fails on an undefined relation.

## Acceptance criteria

- [x] `agent_session` inherits `can_create` from its workspace in both `model.fga` and `model.json`.
- [x] `Steer` authorizes `core.RelCanCreate` on the session object (not the caller's default workspace).
- [x] `representativeVerbRelations` pins `*agentsessions.Service.Steer` to `can_create`.
- [x] Deploy ordering verified: model application precedes the rollout.

## Resolution (2026-08-09)

Added `define can_create: can_create from workspace` to `agent_session`. The `fga` CLI is not installed locally, so `model.json` was hand-edited to mirror the `tupleToUserset` shape the other inherited relations use; the drift gate (`scripts/gitops-validate.sh`, and `gitops.yml` which does install the CLI) compares under `yq 'sort_keys(..)'`, so structural equivalence is what it checks. Confirmed `deploy.yml` runs `scripts/authz-model.sh` at step 4d (line ~686) before the `rollout restart` (~line 738), so the relation exists before the code that checks it. Backend suite green.

**Behavior change:** contributors can no longer steer a session (they can still view/cancel). Lifecycle verbs that touch no fresh credential — resume, cancel, read — deliberately stay `can_operate`.
