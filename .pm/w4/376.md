# 376 — The Free Postgres create form offers an editable disk size and says "between 1 and 1 GB"

Why: Free Postgres storage is fixed at 1 GB (ADR018, `w8/m50`), yet the create dialog presents Disk size as an editable number. Any other value is refused with "Enter a whole number between 1 and 1 GB.", which is wrong English for a fixed size and teaches nothing.

**Severity:** minor. **Estimate:** ~20m. **Source:** live `/qa-find-bugs w4` loop run c7a1, 2026-10-20 UTC, `muse.env`, workspace `bex-canary`. No database was created; the workspace's Free Postgres slot was already used. Evidence: `.playwright-mcp/qa-databases-c7a1-1.png` (local, 1024 px).

## Repro

`/new/database` → Instance type stays at the default `Free — 256 MB RAM, 0.1 CPU, 1 GB · $0.00/month`. **Disk size (GB)** is enabled with placeholder `1`. Type `5`: the field reads `[invalid]` with "Enter a whole number between 1 and 1 GB." Any value other than 1 gives the same message.

## Root cause

`dashboard/src/features/databases/components/create-database-dialog.tsx:122-132` sets `diskFloor = selectedPlan.storageGB` and `diskCeiling = selectedPlan.maxStorageGB`, which are both 1 on Free. The input is disabled only when the ceiling is unknown (`:348`), and the error formats `databases.fieldDiskError` ("Enter a whole number between {min} and {max} GB.", `dashboard/src/features/databases/locales/en.ts:222-226`) with min = max.

## Fix (target behavior)

- When `storageGB === maxStorageGB`, the field is read-only, showing the fixed size, with a hint such as "Free databases have a fixed 1 GB disk." The range message is never produced, and the create request sends no `diskSizeGB` (the server default applies, as today when blank).
- Paid plans keep the editable range and the existing message.
- Apply the same rule wherever a fixed-size plan meets the field, for example the plan/disk editor on a Free database's detail page, if it shows one. Verify that.

## Acceptance

- A dialog test: Free renders a non-editable 1 GB disk and never shows the range error. A paid plan shows the editable field with min/max and the error out of range.
- en/zh copy is added.
- Dashboard `yarn lint` and `yarn test` pass.
