## Cause, consumer and bounded work

- `dashboard/src/common/root-route/root-component.tsx:17–24,54–64` intentionally preserves DashboardLayout across chrome routes. `common/components/dashboard-layout/index.tsx:43–47` contains the **one production SidebarProvider and DashboardHeader JSX mount**.
- `common/components/ui/sidebar.tsx:81,132–135,257` owns openMobile, toggles it manually and passes it as the Sheet's controlled open predicate. Production search for openMobile/setOpenMobile finds no navigation reset. Desktop open/collapse and width are separate state.
- `common/components/dashboard-layout/sidebar-nav-groups.tsx:60` renders ordinary TanStack Links. Exhaustive production JSX search finds **three** shared renderer mounts: DashboardSidebar at139 and183 (project/default groups), ServiceSidebar at64. Its links navigate without closing the drawer. Global/default, project and service rails use the same persistent provider; agent-session rail extensions are source-inspected, not live-tested here.
- `common/components/dashboard-layout/dashboard-header.tsx:24–29` already consumes isMobile/openMobile and shows the header trigger only when the drawer is closed. Make this existing router-aware header observe the committed current href, retaining a previous-href reference to avoid a mount-time write. On an actual href change, call **setOpenMobile(false)**. Do not call desktop setOpen or add a router dependency to the generic Sidebar primitive.
- `common/components/ui/sheet.tsx:9–10` passes props into Radix Dialog.Root. Actual installed **@radix-ui/react-dialog 1.1.15**, `dist/index.mjs:23–52,130–145`, defaults modal true and uses controlled state; its modal content calls hideOthers and traps focus while open. Actual **react-use-controllable-state 1.2.2** `dist/index.mjs:5–15,28–39` reads a supplied prop and delegates requested changes to onChange. Navigation is not a dialog-dismiss request. The app must change the correct controlled predicate; removing the overlay or modality would leave the actual navigation-state defect.
