## Objective

Meaningful tests for the shipped behavior.

## Acceptance criteria

- [ ] **Tests:**
  - A served release's outage reads `Running`, with `undeployedChangesApplying=false`.
  - A rollout, a pre-deploy step and a wake still read `Deploying`.
  - A requested deploy still reads applying.
  - `server_failed` and `server_available` still fire.
- [ ] The tests fail if the served-release check is removed.
- [ ] Operator `make test`, backend `go test ./...` with `BEX_TEST_REQUIRE_DEPS=1`, and dashboard `yarn lint` and `yarn test`, pass.
