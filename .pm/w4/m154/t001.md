## Objective

Keep literal characters captured from a request path inside the destination path instead of turning them into query or fragment delimiters.

## Context

See [finding.md](finding.md) for the observed failing and passing probes, pinned Go implementation, caller counts and limits.

## Steps

1. Separate the configured destination's URL components from the decoded wildcard capture before expansion. Preserve both :splat and trailing /\* aliases.
2. Serialize path captures with correct escaping, including ?, #, %, spaces and Unicode, while retaining intended literal destination query/fragment components and path separators.
3. Retain the final local-target guard, object-before-rule precedence and first-match behavior. Do not replace the shared decoded request path globally.

## Files

- `lego/operator/internal/staticserver/staticserver.go`

## Acceptance criteria

- [ ] GET/HEAD /qa-jump/a%3Fb.yaml and /qa-jump/a%23b.yaml produce /docs/a%3Fb.yaml and /docs/a%23b.yaml respectively under both tested destination aliases; the browser keeps the filename in its path.
