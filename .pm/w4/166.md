# Five MCP tools fail without `workspaceId`, and the error exposes bex's internal OpenFGA URL and store id

Why: an agent that calls `list_projects`, `list_workspace_members`, `list_workspace_invites`, `get_workspace_seat_usage` or `get_workspace_limits` without an explicit workspace gets `authorization service unavailable` instead of its default workspace's data. Every sibling tool (`list_services`, `list_postgres_instances`, `list_env_groups`, `list_api_keys`, …) resolves the default. The error text also hands the caller an in-cluster service URL and the OpenFGA store id, because the raw client error is wrapped into a sentinel that counts as public.

Found live in `/qa-find-bugs` pass 245 on 2026-09-27 (w4-targeted, `muse.env` credentials) against the deployed `4a0422577`. Read-only: in-page MCP session at `https://api.bex.co/mcp` (`initialize` → `notifications/initialized` → `tools/call`). The QA user is admin of three workspaces; the selected one is `bex` (`tea-d98210cbbpdc73dcrkvg`).

REST `GET /v1/projects` requires `ownerId` (400 naming it), and GraphQL `projects(ownerId: String!)` requires it, so the missing-workspace path is MCP-only.

## Mechanism

1. **Empty workspace reaches OpenFGA.** Each MCP handler passes `core.NamedWorkspace(ctx)`, which is `""` when the call names no workspace (`internal/core/workspace.go:63`). The contract there is that "the domain layer still resolves" it. These five domain methods do not; they build the check object straight from the argument:
   - `projects.Service.List` `internal/projects/service.go:325` (and `Create` l.362 / l.379, reached by `create_project`)
   - `members.Service.List` l.477, `SeatUsage` l.526, `ListInvites` l.592 (and the mutating siblings at l.619, l.626, l.708, l.875, l.881, l.1053, l.1059, l.1312)
   - `workspaces.Service.ResourceLimits` (→ l.598/l.824)

   `core.WorkspaceObject("")` is `"workspace:"`, which OpenFGA rejects with 400.
2. **The 400 becomes a leaked 503.** `core.Base.checkAuthz` (`internal/core/base.go:795`) returns `fmt.Errorf("%w: %v", ErrAuthzUnavailable, err)`. `ErrAuthzUnavailable` is a public sentinel, so `core.MCPError` (`errors.go:253`), `WriteErr` (`http.go:302`) and the GraphQL sanitizer all pass the whole string through, OpenFGA's URL and store id included. This happens on **any** OpenFGA client error, on all three surfaces, not only this one.

## Fix

Target: a workspace-scoped verb with no named workspace acts on the caller's resolved workspace, exactly as `list_services` does. An OpenFGA failure reads `authorization service unavailable` with no internal detail.

- Resolve before authorizing: in the five read methods and their mutating siblings, replace an empty `workspaceID` with `s.WorkspaceOrDefault(ctx)` / `Tenant(ctx)` (`internal/core/base.go:957-973`), or reject `""` with a named 400. Never build `WorkspaceObject("")`. Better, make `WorkspaceObject("")` (or `checkAuthz`) refuse an empty id with `ErrBadRequest` so a future caller cannot reach OpenFGA with it.
- Redact: `checkAuthz` logs the client error and returns the bare `ErrAuthzUnavailable`. Grep the other `%w: %v` wraps of public sentinels for the same leak.
- Tests: an MCP test calling each of the five tools with `{}` returns the default workspace's data. A `checkAuthz` test with a failing checker asserts the returned message has no `http://` or store id.
- Blast radius: the `WorkspaceObject(workspaceID)` call sites listed above (projects ×3, members ×12, workspaces ×2, environments l.464, audit l.228) and every `core.NamedWorkspace(ctx)` MCP caller (≈50, `grep -rn 'core.NamedWorkspace(ctx)' internal`). The 22 passing tools need a regression test too, because they pass today only because their domain methods resolve.

Unverified: the mutating tools (`create_project`, `invite_workspace_member`, `change_member_role`, `remove_workspace_member`, …) were not called; they reach the same check code. `environments` l.464 and `audit` l.228 were not reached by a probe, since `list_environments` requires `projectId`.

Render: n/a (bex MCP extension). Its official MCP resolves the selected workspace for every call.
