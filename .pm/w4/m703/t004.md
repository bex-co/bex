## Objective

Every answer the static server sends carries a `CF-Cache-Status` that its own cache state supports, in Render's vocabulary: one status for an object served from the pod's cache, one for an object fetched from the origin, and the statuses t003 captured for the rest (`BYPASS` for a missing file and a route redirect).

## Context

- `lego/operator/internal/staticserver/staticserver.go`: `get` returns a cached object, or fetches it through one flight per key and caches it, including a confirmed miss. It does not tell its caller which happened. `serveObject`, `serveNotFound`, `serveBareNotFound`, `serveRedirect`, `serveOtherMethod`, `serveOriginError` and `proxy.go`'s `serveExternalRewrite` write the answers. `encoding.go` derives compressed variants from the cached object.
- A revision's objects are immutable, so a cached object never expires. Render's `EXPIRED` comes from Cloudflare revalidating an answer older than `s-maxage=300`; the static server sends the same `Cache-Control` (`defaultCacheControl`).
- `appv1alpha1.ReservedStaticHeader` decides which header names a static site's rule may not set.

## Steps

1. Choose the mapping, and record it for t005: `HIT` for a cache hit, `MISS` for an origin fetch, unless t003 shows a closer one. A request that waited on another's fetch counts as that fetch. `HEAD`, `304` and `206` read as the object they answer for.
2. Report the cache outcome from `get` to the code that writes each answer, without changing what is cached or how flights collapse.
3. Set the header on every answer, the `404.html` page and the suspended site's `404` included. Make it reserved, so a header rule cannot set it, as Cloudflare overwrites an origin's.
4. Tests in `staticserver` for each answer kind, and the static site's Traefik gate (`static_site_traefik_test.go`) asserts a miss then a hit through the deployed edge.

## Files

- `lego/operator/internal/staticserver/staticserver.go`, `encoding.go`, `proxy.go`, and their tests
- `lego/types/v1alpha1` (the reserved header list), if the header becomes reserved there
- `lego/operator/internal/controller/static_site_traefik_test.go`

## Acceptance criteria

- [ ] A first `GET` of an object on a pod reads the origin status and the next reads `HIT`; a missing file's `404` and a route redirect read `BYPASS`.
- [ ] A header rule naming `CF-Cache-Status` does not change it.
- [ ] `make test` and `make lint` pass.
