# 235 — Static rule fields collapse to a few characters on mobile

Why: users need enough visible space to review and edit header names, values and redirect paths on a narrow screen.

- **Severity:** minor. At 390×844, Header Name/Value inputs are **38px** wide and redirect Source/Destination inputs are **54px** wide. Only about two or four characters fit after input padding. Values save correctly; no data loss, incorrect response rule or page overflow was observed.
- **Estimate:** 55m: local table sizing 15m, shared callers/skeleton review 10m, browser/draft controls 25m, live replay/cleanup 5m. Keep as an inbox fix.
- **Source:** user-requested functional qa-find-bugs loop, 2026-10-10 UTC pass a50, muse profile, workspace `tea-d98210cbbpdc73dcrkvg`, research HEAD `8afd13646`. Filing only.
- **Goal linkage:** [ADR029 static-site management](../../docs/ADR029-static-sites.md), [ADR018 parity](../../docs/ADR018-render-parity.md) and usable dashboard editing. This corrects the existing dedicated rule forms without changing their API or serving semantics.

## Reproduction

Create an owned Free static site from public repo `https://github.com/bex-co/bex`, branch main, root directory `examples/static-site`, Publish Directory `.`, empty Build Command and Auto-deploy off. This pass used **qa-20261010-loop-a50-static**, `srv-db51re4b8ulc73efu46g`.

1. Wait for its first deploy to become Live and its public root to return HTTP 200. Open **Headers**.
2. Add and save `/* / X-QA-A50 / global-first`, `/qa-a50/* / x-qa-a50 / specific-last`, and `/render.yaml / X-QA-A50 / yaml-last`. Set the viewport to **390×844**.
3. Header Path inputs are 144px, but each Name and Value input is **38px** including borders; client width is 36px with **12px padding on each side**, leaving **12px** of text space. The Name column title wraps as “Nam” / “e”. The table/container is 316px and has no horizontal overflow to reveal wider fields.
4. Fresh-load that page. At **11:17:19.593Z**, the same saved values and widths repeat. At 1440×1000 the same Name/Value inputs are **307px**. Return to mobile and focus Value: its width remains 38px. Change the first value to `global-mobile-save` and Save headers: the full literal round-trips.
5. Open **Redirects/Rewrites** with a saved rewrite `/qa-a50/special.css → /index.html` followed by redirect `/qa-a50/* → /render.yaml?which=second`. At **11:18:35.386Z**, Source and Destination are **54px** each, leaving 28px after padding. The Destination heading splits across lines.
6. Fresh-load that page at **11:19:30.499Z**: same 54px fields. At desktop the same Source/Destination fields are **323px**. Values and rules remain exact.

Both forms were independently traced and measured. This is ordinary populated-form geometry, not a missing label, loading placeholder or clipped API value.

## Cause and bounded target

**Headers:** `dashboard/src/features/services/components/static-site-section.tsx:368–424` renders a full-width table, with Path fixed at `w-40` and actions at `w-10`.
