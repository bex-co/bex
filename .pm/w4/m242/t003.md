## Objective

The create-service body's `envVars` accepts Render's `{key, generateValue: true}` and mints the value with `core.GenerateValue()` (base64, 256-bit), the same as the env-var endpoints. `value` together with `generateValue` → `400` "provide exactly one of value or generateValue", matching `core/environmentpatch.go:60`.

## Context

- `lego/backend/internal/apps/rest.go:203`, `render.go:32-48` (`envVarInput`, `toEnvVars`); MCP `mcp.go:202`, `:317`, `:536`.
- Generated values belong in the service's Secret like other env values. They must never land in the App CR spec or in any log.
- GraphQL `createService` input: check whether it shares `gqlutil.EnvVarInputType` (which already has `generateValue` for `setEnvVars`).

## Acceptance criteria

- [ ] REST create with a generated key → `201`, and `GET …/env-vars/<key>` returns a 44-char value.
- [ ] Both-fields and neither-field requests → `400`.
- [ ] MCP create tools are decided against the pinned Render MCP schema: accepted, or recorded in ADR018 as not offered upstream.
