# 472 — A build's `buildRun` omits Render's `commitUrl`, so API clients cannot link a build to its commit

Why: Render's build object carries `buildRun.commitUrl` next to `commitId`, so a CLI or CI integration can link straight to the commit. bex already computes commit URLs for events, but returns none for builds.

- **Source / severity / estimate:** live `/qa-find-bugs w4` loop, round 9, 2026-11-04 12:32 UTC (`muse.env`, `bex-canary`, pin `9d4e3a138783`); **minor** (Render API parity); ~20m.
- **Probe:** for a git build source (`github.com/bex-co/bex`, `examples/hello-go`, docker; fixture deleted), `GET /v1/build-sources/<bds-…>/builds` → `{"build":{"id":"bld-…","buildSourceId":"bds-…","buildRun":{"id":"dep-…","status":"succeeded","buildStartedAt":"…","buildFinishedAt":"…","runtime":"docker","commitId":"bdbdfa45cb4e01ca875739f1fd23c8ebf7046f70"},…}}`. There is no `commitUrl`.
- **Render contract:** pinned `render-public-api-1.json`, `POST /build-sources/{buildSourceId}/builds` 201 schema: `buildRun.properties` = `id, status, buildStartedAt, buildFinishedAt, runtime, commitId, commitUrl`.
- **Root cause:** `lego/backend/internal/deploys/build_sources.go:45-52` `BuildRunView` has no `CommitURL` field, and `buildView` (`:176-177`) fills only `CommitID`. Events already build the commit URL (`events/service.go:1234` `ev.Details.CommitURL = r.CommitURL`; REST `events/rest.go:108`, GraphQL `events/graphql.go:175`).
- **Fix:** add `CommitURL string \`json:"commitUrl,omitempty"\`` to `BuildRunView`, filled from the same commit-URL source events use (the deploy row's commit info). Expose it on GraphQL `build`/`builds` and the MCP build tools, which return the same view. Omit it when the repo host cannot form a URL, as events do.
- **Tests:** a build view for a GitHub source includes `commitUrl = https://github.com/<owner>/<repo>/commit/<sha>`; an image-source build still has no `buildRun`; and the existing response-conformance test keeps passing.
- **Dedupe:** `grep -rl commitUrl .pm` → only w4/m147's finding (an event, done). w2/m254 and w2/m262 cover build sources but not this field. No DO_NOT_DO item applies.
