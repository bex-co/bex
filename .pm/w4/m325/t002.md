## Objective

Every read of a `type=request` line returns t001's Render-shaped summary instead of Traefik's record: REST `GET /v1/logs`, GraphQL `logs`, MCP `list_logs` and the live tail.

## Context

- **The read path.** It only trims terminators today: `canonicalHistoryMessage` at `lego/backend/internal/logs/loki.go:765-771`.
- **The stored JSON is load-bearing** and must stay as shipped:
  - the path and host filters parse it (`loki.go:555-566`);
  - request metrics and latency parse it (`lego/backend/internal/metrics/lokisource.go:160-164`, `latency_ns="Duration"`);
  - the shipper attributes lines with `ServiceName` and `KubernetesIngressName`.
- **The live record, round 89:** `{"DownstreamStatus":503,"Duration":8384760,"KubernetesIngressName":…,"KubernetesIngressNamespace":…,"RequestHost":"qa-20261111-lg89.onbex.co","RequestMethod":"GET","RequestPath":"/qa89-err","ServiceName":…,"downstream_Rndr-Id":…,"level":"info","msg":"","origin_Rndr-Id":…,"request_Rndr-Id":…,"time":"2026-11-11T08:55:49Z"}`.

## Steps

1. Add a request-line formatter: parse the record, then emit t001's format.
   - Response time is `Duration` / 1e6 ms.
   - The request id is `Rndr-Id`, taken from `request_Rndr-Id`, else `downstream_`.
   - Leave out the attribution and duplicate keys.
2. Apply it wherever a `type=request` message leaves the logs service: history, the live poll and the deploy page's leg.
3. A non-access-record line passes through unchanged.

## Files

- `lego/backend/internal/logs/loki.go`
- the live-tail path in `lego/backend/internal/logs`
- tests
