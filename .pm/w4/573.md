# 573 — The Chinese dashboard switches between the formal 您 and the informal 你 for "you", even within one flow, and the Suspend card mistranslates "stop it from serving traffic"

Why: a Chinese user suspending a service reads "您可以随时恢复" in the Settings card and then "你可以随时恢复" in the confirmation dialog. One product voice should address the user one way. The card's "停止流量服务" also doesn't say what the English says.

- **Source / severity / estimate:** live `/qa-find-bugs w4` loop, round 111, 2026-11-11 14:22–14:27 UTC (`muse.env`, workspace `bex-canary`; production runs the code of `7ca0227aa477`). **Minor** (copy). ~40m.
- **Fixture:** Free image web service `qa-20261111-r111-sus` (`srv-dbq7khg2gues73d7p5b0`, `docker.io/traefik/whoami:v1.10.1`), suspended and resumed through the zh dashboard. Deleted afterwards (DELETE 204, then GET 404).
- **Probe** (`?lang=zh`):
  - Settings → 暂停服务 card: `text: 暂停服务将关闭它并停止流量服务。服务的 URL 和证书将保留，您可以随时恢复。`
  - Its 暂停 button opens `alertdialog "暂停 qa-20261111-r111-sus？"` with `paragraph: 服务将缩容至零并停止处理流量。其 URL 与证书会保留，你可以随时恢复。`
  - The suspend itself was correct: the toast read `正在暂停 qa-20261111-r111-sus……`; the URL answered `503 x-render-routing: suspend` "This service is suspended."; Events showed `suspender_added`, `service_suspended`, and after 恢复, `suspender_removed` and `service_resumed`; the URL answered 200 again.
- **Root cause:**
  - There is no register rule for zh. Across every `zh.ts` locale file, 您 appears 59 times, in 14 files, and 你 121 times: `grep -rho '您'` / `grep -rho '你'` over `dashboard/src --include='zh.ts'`.
  - Per file containing 您 (您/你): `auth` 20/15, `onboarding` 7/1, `services` 6/24, `usage` 5/0, `databases` 4/5, `connected-agents` 4/0, `blueprints` 3/1, `common` 2/2, `ssh-keys` 2/1, `sessions` 2/0, and 1/0 each in `api-keys`, `registry-credentials` and `sandbox-groups`. `keyvalue` is 1/5.
  - The suspend pair: `services.suspendCardDescription` and `services.suspendCardDescriptionNoUrl` (`dashboard/src/features/services/locales/zh.ts:3227-3236`) use 您. `services.confirmSuspendBody*` (`:362-380`) and the Key Value suspend confirmation (`keyvalue/locales/zh.ts:496`) use 你.
  - `suspendCardDescription` renders en "…shut it down and stop it from serving traffic" (`en.ts:3293-3295`) as "停止流量服务", which reads as "stop the traffic service".
- **Fix (target behavior):**
  - **Use 你 everywhere in zh**, the majority form and the one the confirmation dialogs already use. Rewrite the 59 您 occurrences in the 14 files, keeping each meaning.
  - **Suspend card:** "暂停服务会将其关闭并停止处理流量。服务的 URL 和证书会保留，你可以随时恢复。" The no-URL variant: "暂停服务会将其关闭并停止运行，你可以随时恢复。"
  - **Guard:** a test beside `dashboard/src/i18n/__tests__/locale-parity.test.ts` fails when any `zh.ts` message contains 您.
  - **Unaffected:** Ory Elements' own strings (upstream), and the en locale.
- **Unverified:** whether any 您 string is quoted from a legal or billing text that must keep the formal form. Check `usage` and `auth` while rewriting.
- **Render:** n/a. Render has no Chinese UI.
- **Dedupe:**
  - `grep -rl '您' .pm` finds nothing.
  - `dashboard/AGENTS.md` § Internationalization sets no zh register.
  - Not deploy lag: `zh.ts:3229` is unchanged on `origin/main`.
- **DoD (live):** with `?lang=zh` on an owned Free web service:
  - Settings → 暂停服务 reads "暂停服务会将其关闭并停止处理流量。服务的 URL 和证书会保留，你可以随时恢复。";
  - the 暂停 dialog still reads "…你可以随时恢复。";
  - `grep -c '您'` over every `dashboard/src/**/zh.ts` is 0, and the new test passes in `yarn test`.
