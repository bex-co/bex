## Objective

Add one helper in `lego/backend/internal/rollout` that, inside a locked App patch, writes `Spec.ReleaseConfig{Generation: a.Generation+1, Image: <served image>}` for an image-backed service (`Spec.Image != ""`, `Spec.Repo == ""`, not a static site, not suspended) whose live release runs an image other than the saved one.

## Context

- `Tracker.ServedRelease` (`rollout/rollout.go:76`) returns the newest Live row; its `ResolvedImage` is the `repo@sha256:…` digest Restart selects.
- See the milestone README's "Trap" note: selecting a digest when the service serves its saved tag can flip `undeployedChangesReason` to `image_override`.
- The secrets path (`selectServedBuild`) and the env-group path (`rollLinkedService`) both call it.

## Steps

1. Write the helper (e.g. `(*Tracker).SelectServedImage(ctx, a) error`). A missing history (`ErrNoDeployHistory`) or no live row is a no-op, never an error.
2. Unit-test it: an override is served → selected; the saved tag is served → nothing selected; no history → nothing; a suspended service → nothing.

## Files

- `lego/backend/internal/rollout/rollout.go` (or a new file there)

## Acceptance criteria

- [ ] The helper selects the override digest and leaves a saved-tag service's spec untouched.
- [ ] `cd lego/backend && go test ./internal/rollout/...` passes.

## Out of scope

- Git-backed services (already covered by `servedArtifact`).
