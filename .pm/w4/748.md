# bex publishes a shared responsibility model and a penetration testing policy, as Render does, and the repository has a SECURITY.md

Why: Render parity. Render's security and HIPAA docs rest on a shared responsibility page, and its penetration testing page lets customers test their own services without asking while forbidding tests of the platform, other tenants and denial of service. A bex customer cannot tell whether testing their own service is allowed, what bex secures and what they must, or where the repository takes a vulnerability report.

- **Render (read 2026-11-27):** [shared-responsibility-model](https://render.com/docs/shared-responsibility-model) splits Render's duties (infrastructure, patching, network, availability, breach transparency) from the customer's (their code, access, data); [penetration-testing](https://render.com/docs/penetration-testing): "customers are welcome to carry out security assessments or penetration tests of their own Render-hosted services without prior approval", with the forbidden targets and a vulnerability disclosure program.
- **bex:** `bex.co/docs/shared-responsibility-model` and `bex.co/docs/penetration-testing` answer 404, and bex.co's terms of service neither allow testing your own services nor name denial-of-service tests. `bex.co/.well-known/security.txt` names a contact, and GitHub private vulnerability reporting is on, but the repository has no `SECURITY.md`. bex already does most of the platform side Render lists (kernel and runtime patching, `platform-rebuild.yml`, the private network, status.bex.co).
- **Do:** add `SECURITY.md` in this repository naming the report channels. Draft both pages from what bex does today, with the policy wording for the user to approve, and publish them on bex.co's docs, which live in the site repository (pushing there needs the user's permission, as `w4/730` does).
- **End state:** `SECURITY.md` is on `main`, and `bex.co/docs/shared-responsibility-model` and `bex.co/docs/penetration-testing` answer 200 with the user-approved wording.
- **Size:** about 1h, the site push gated on the user.
- **Source:** w4/m688 t002, full reads of Render's shared-responsibility-model and penetration-testing pages, 2026-11-27.
