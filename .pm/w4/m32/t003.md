## Objective

Environments that already had non-empty rules before m28 have members carrying no layer at all — their rules are silently unenforced on Apps until the environment's next incidental write. Ship an idempotent one-shot sweep (the `scripts/ipallowlist-normalize.sh` shape: clusterless-testable, safe to re-run) that re-runs the member fan-out for every environment, and optionally drops a datastore's own `spec.ipAllowList` when it is byte-identical to its environment's list — provably the pre-m28 clobber's residue (harmless double-enforcement, but confusing to read).

## Context

- `.pm/w4/done/025.md` item 3. m28 migrated empty-list environments seeded-open but did not backfill members of environments that already had rules.
- `scripts/ipallowlist-normalize.sh` + its 16-assertion clusterless harness (w4/m29) is the established one-shot-sweep pattern — reuse its shape (dry-run mode, assertion harness, recorded prod run).
- Fan-out entry points: `lego/backend/internal/environments/service.go` (member stamp), `lego/backend/internal/postgres/service.go` / `lego/backend/internal/keyvalue/service.go` (datastore lists).

## Steps

1. Write the sweep: enumerate environments, re-run the m28 member fan-out for each (Apps + datastores), idempotently.
2. Add the optional residue-drop: datastore whose own `spec.ipAllowList` is byte-identical to its environment's list ⇒ drop the datastore's own copy (keep only the environment layer). Guard with a dry-run flag.
3. Clusterless assertion harness mirroring `ipallowlist-normalize`'s: pre-m28-shaped fixtures ⇒ post-sweep state asserted; second run asserted a no-op.
4. Run against prod (or record the m28-closeout pattern if no cluster this session) and note the result in the script header or milestone README.

## Files

- new `scripts/` sweep script + harness (follow `ipallowlist-normalize.sh` naming)
- `lego/backend/internal/environments/service.go` (expose/reuse the fan-out if the sweep drives it through the API/store rather than raw SQL)

## Acceptance criteria

- [ ] After the sweep, a member App of a pre-m28 ruled environment carries `spec.environmentIPAllowList` matching the environment.
- [ ] Byte-identical datastore residue lists are dropped only when identical; differing lists untouched.
- [ ] Second run is a no-op (harness-asserted).

## Out of scope

- Workspace-level IP-rule layer (explicit m28 deferral — needs user re-open).
