## Objective

No tenant-facing deploy or event surface prints a cluster-internal registry host (`zot.bex-registry.svc:5000`, any `*.svc` / `*.cluster.local`). Git builds keep their commit identity (and digest if shown, minus the internal host); user-supplied images pass through byte-identical. The stored deploy image does not change — redaction happens once, at the read-projection boundary.

## Context

- Finding 2 in [finding.md](finding.md): deploy rows on the Events tab and in REST read `zot.bex-registry.svc:5000/<workspace>/<workspace>-<service>:gen-2@sha256:…`.
- Projection sites: `lego/backend/internal/deploys/rest.go:134-135` (`image.ref`), `lego/backend/internal/events/service.go:901,1003` → `events/rest.go:95,191`, `events/graphql.go:81`. Internal hosts are already enumerated at `lego/backend/internal/store/image.go:88-97` (`trustedImageRegistry`).
- The same stored ref feeds rollback ("run this deploy's image") and operator/status paths — those keep the raw value.

## Steps

1. Grep every reader of the deploy row's `Image` and of `Details.Image` across REST/GraphQL/MCP/dashboard; record the count and which are tenant-facing.
2. Add one projection helper (near `store/image.go`'s registry knowledge) that maps an internal-registry ref to its tenant-facing form and leaves external refs untouched; apply it at the tenant-facing readers from step 1.
3. Confirm the dashboard Events and deploy-detail rendering needs no compensating change (it should just stop receiving the internal host).

## Files

- `lego/backend/internal/store/image.go` (helper home, or the seam step 1 justifies)
- `lego/backend/internal/deploys/rest.go`
- `lego/backend/internal/events/service.go`, `lego/backend/internal/events/rest.go`, `lego/backend/internal/events/graphql.go`
- MCP deploy/event projections if step 1 finds separate ones

## Acceptance criteria

- [ ] For a git-built service, `GET /v1/services/<id>/deploys/<deployId>` and `GET /v1/services/<id>/events` bodies contain no `.svc` / `.cluster.local` substring; the Events tab shows none.
- [ ] An image-backed service's user image reads back byte-identical on REST, GraphQL, MCP and the dashboard.
- [ ] Rollback to a git-built deploy still runs that deploy's exact image (stored ref untouched).
- [ ] Backend `go test ./...` passes for the touched packages (real-DB gate where it applies).

## Out of scope

- Renaming the internal registry or its repository layout.
- Historical rows: projection is at read time, so no data migration.
