## Objective

Check the change is consistent across every surface the environment save is exposed on, and record any divergence from Render rather than leaving it implicit.

## Context

- The CAS protocol is a bex extension — Render's environment update has no caller-supplied revision — so this is an additive surface and ADR018 should say what it adds and why.
- The dashboard Environment editor is the primary consumer (`w1/m147` names it as the GraphQL mutation's caller). How it currently handles the conflict error matters: if it surfaces a toast, users have been told saves failed that succeeded.

## Steps

1. Diff the patch result shape across REST, GraphQL and MCP after t003.
2. Read the dashboard's handling of `ENVIRONMENT_REVISION_CONFLICT` and confirm it now reflects the real outcome.
3. Record the CAS extension in ADR018 if it is not already there.
