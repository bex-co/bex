## Objective

Write down, from live requests, the headers a Render web service receives and the headers Render's edge answers with, so the rest of the milestone matches a record rather than memory.

## Context

- Captured 2026-11-27 01:58 UTC from `https://httpbin.onrender.com/headers` (a public app on Render, the same echo [ADR022](../../../docs/ADR022-tenant-isolation.md) cites): the app received `cdn-loop: cloudflare; loops=1`, `cf-connecting-ip: <client>`, `cf-ipcountry: US`, `cf-ray: a60d86a06ea867d9-CMH`, `cf-visitor: {"scheme":"https"}`, `rndr-id`, `true-client-ip`, `x-forwarded-for: <client>, <cloudflare edge>, <internal hop>`, `x-forwarded-proto: https`, `x-request-start`, and `accept-encoding: gzip, br` for a curl that sent none.
- Render's answer carried `server: cloudflare`, `cf-ray`, `cf-cache-status: DYNAMIC` (on a service with no edge caching), `rndr-id`, `x-render-origin-server` and `alt-svc: h3`.
- A public request carrying its own `CF-Connecting-IP: 203.0.113.9` got `403`, `content-type: text/plain; charset=UTF-8`, `content-length: 17`, body `error code: 1000`, with `server: cloudflare` and a `cf-ray`. Forged `CF-IPCountry: KP` and `CF-Ray` were overwritten (`US`, a fresh ray).
- Render's [uptime-best-practices](https://render.com/docs/uptime-best-practices): "Render includes this header in the request it sends along to your service" (`CF-Ray`), and every request should be logged with it. Render's [PocketBase article](https://render.com/articles/host-pocketbase-on-render) sets `settings.trustedProxy.headers = ["CF-Connecting-IP"]` and says private-network requests bypass Cloudflare.

## Steps

1. Repeat the captures above (web service request and response, a forged `CF-Connecting-IP`, forged `CF-IPCountry`/`CF-Ray`), plus a Render static site's response headers and an `http://` request.
2. Record each header with its exact shape (`CF-Ray` is 16 lowercase hex, `-`, a three-letter data-center code), what Cloudflare does with a caller's value, and the 403's full response.
3. Note what is left for later decisions: `server: cloudflare` (a vendor name bex's edge is not), `accept-encoding` normalization, `alt-svc: h3` (already a signed-off difference, `docs/ADR018/deploys.md`).
