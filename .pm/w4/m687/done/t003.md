## Objective

Set `CF-IPCountry` on requests from a non-Cloudflare peer to the client address's ISO 3166-1 alpha-2 country, `XX` when it is unknown, as Cloudflare does for a Render app.

## Context

- The plugin runs under Traefik's Yaegi interpreter, which loads only the standard library and the plugin's own sources, so a lookup must be plain Go over a table the Traefik pods can read.
- Recommended source: DB-IP's "IP to Country Lite" (CC BY 4.0, monthly, IPv4 and IPv6), which needs an attribution line in bex's public docs. MaxMind GeoLite2 needs an account and an EULA.
- No table file may be committed if it is over 1 MiB (`scripts/repo-artifact-guard.sh`): fetch it at build or start time, or keep a compact form under the limit.

## Steps

1. Choose where the table lives (a file mounted into the Traefik pods and refreshed monthly, or a compact embedded form) and record the choice in ADR022.
2. Implement the lookup (sorted ranges, binary search) for IPv4 and IPv6, `XX` for an address in no range.
3. Measure the lookup's cost per request under Yaegi; if it adds more than about 50 µs at p99, move the lookup out of the interpreted path and record why.
4. Keep a trusted Cloudflare peer's own `CF-IPCountry`.

## Files

- `deploy/gitops/charts/traefik-plugins/clientipheaders/clientipheaders.go`
- the Traefik chart values or the table's refresh job under `deploy/gitops/`
- `docs/ADR022-tenant-isolation.md`

## Acceptance criteria

- [ ] A request from a known German, US and IPv6 address reads `DE`, `US` and its country; an unallocated address reads `XX`.
- [ ] The measured per-request cost is recorded, and the table refreshes without a Traefik release.

## Out of scope

- `T1` (Tor) and other Cloudflare special codes.

**Done 2026-11-27:** the plugin downloads DB-IP's monthly table itself (`country.go`; 4.6 MB gzipped, too large for a ConfigMap or the repository), at start and every 24 hours until the month's table loads, falling back to the previous month; `XX` until it loads, and a failed download keeps the loaded table. Recorded in ADR022. Measured under Yaegi v0.16.1 with the 2026-11 table: about 4 s of background parsing, a lookup about 6 µs at p50 and 20 µs at p99 (a first version with a function call per comparison read 51 µs at p99 and was rewritten). In Traefik v3.7.17 itself the table loaded from DB-IP and PROXY-protocol clients read `DE` (46.4.0.1, 2a01:4f8::1), `US` (8.8.8.8), `JP` (2001:200::1), `AU` (1.1.1.1) and `XX` (198.51.100.20). Attribution is in the repository README.
