# Chinese sidebar keeps English navigation and resize labels

Why: the primary navigation controls and mobile drawer announcements ignore the selected Chinese language while the navigation links around them are translated.

**Severity:** minor localization defect. **Estimate:** 35m. Functional `$qa-find-bugs w4`, a595, 2026-10-15 UTC; source checked on synced main `b0b4d70fc`. Filing only.

## Reproduction and controls

1. Avatar → Language → 中文. Reload the dashboard or an owned project at 390px. The navigation toggle remains **button "Toggle Sidebar"** alongside Chinese Search/New controls.
2. Open that button. At **14:57:10.281Z**, `<html lang="zh">` and Chinese navigation links were present, but the accessibility tree was **dialog "Sidebar"**, heading **Sidebar**, description **Displays the mobile sidebar.**, and button **Toggle Sidebar**.
3. Close with Escape and change to 1440px. At **14:57:57.735Z**, the desktop toggle still had the English name; the vertical separator had **aria-label="Resize sidebar"** and title **Drag to resize · double-click to toggle**.

**Passing control:** after restoring English at **14:59:30.897Z**, these same labels are appropriate. Two native toggle clicks changed the sidebar from expanded/256px to collapsed/48px and back to expanded/256px. The separator retained its vertical role and value 256. This is untranslated control text, not failed navigation or resizing. The actual drag/keyboard behavior was not retested live in this pass.

[Durable native accessibility trees, DOM attributes, English control, caller census and cleanup](evidence/310-311-shared-control-labels.json). `.playwright-mcp/qa-localization-a595-sidebar-mobile.png` is supplementary; accessible text survives in the durable artifact. No screen-reader audio behavior is claimed.

## Cause and bounded fix

The five strings are literal text in `dashboard/src/common/components/ui/sidebar.tsx`:

| Producer | Lines | Current text |
| --- | --- | --- |
| Sidebar mobile Sheet header | 271–272 | Sidebar; Displays the mobile sidebar. |
| SidebarTrigger | 355 | Toggle Sidebar |
| SidebarRail | 479, 484 | Resize sidebar; Drag to resize · double-click to toggle |

These primitives never translate their text. `SidebarBrand` already uses `useTranslations` for the neighboring home link, which explains the mixed-language result. Use that same hook in the three owning functions and common en/zh catalog entries for the five strings. Call hooks before Sidebar's viewport branches. Suggested Chinese targets: **侧边栏**, **显示移动端侧边栏。**, **切换侧边栏**, **调整侧边栏宽度**, and **拖动调整宽度 · 双击展开或收起**. Keep the current English messages.

This is a global string change within the shared sidebar primitives. Preserve callbacks, keyboard shortcuts, cookies, persisted width, mobile open state, separator role/orientation/value attributes, IDs, focus and animation. Do not add a language-specific drawer, duplicate the shell or change layout geometry.
