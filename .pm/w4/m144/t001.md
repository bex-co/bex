## Objective

Restore the existing metrics source with a measured, bounded startup and runtime memory budget.

## Context

See [finding.md](finding.md) for the reproduced source outage, complete API probes, caller inventory and evidence limits.

## Steps

1. Measure replay/steady-state/query memory and required series cardinality against the retained data; check available platform capacity and account for simultaneous workloads.
2. Adjust the owning production Helm values/overlay; preserve the volume, WAL, required scrape jobs and rules. Document the selected headroom and any measured source reduction.
3. Roll out through the authorized platform workflow and verify replay completion, readiness and actual query recovery. Observe a restart with existing data; do not infer recovery from empty storage.
