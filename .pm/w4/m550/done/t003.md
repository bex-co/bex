## Objective

Add Render's Suspend and Resume to the shared selection toolbar, acting on every selected service.

## Context

- Per-service mutations: `SuspendService($id, $confirm)` and `ResumeService($id)` in `dashboard/src/features/services/api/services.graphql`, driven by `dashboard/src/features/services/hooks/use-service-lifecycle.ts`.
- t001 records which kinds Render's toolbar acts on, its confirmation and its outcome copy. If Render's dashboard calls a batch operation, mirror it in GraphQL (`lego/backend/internal/apps/graphql.go`) over the same per-service core verb, with the same authorization and audit per service; otherwise call the existing mutation once per service.

## Steps

1. Add Suspend and Resume to the toolbar's action menu, offered for the kinds t001 records.
2. Show Render's confirmation (t001); on confirm, run the action for each selected service, in parallel with a small bound.
3. Report each row's outcome: succeeded rows refresh their status badge; failed rows stay selected and show why (the mutation's message). A service already in the target state is a no-op, as t001 records Render treating it.
4. Add the strings to every locale.

## Files

- the shared toolbar from t002
- `dashboard/src/features/services/hooks/use-service-lifecycle.ts`
- `dashboard/src/features/projects/locales/*.ts`
- `lego/backend/internal/apps/graphql.go` only if t001 finds a batch operation

## Acceptance criteria

- [x] Selecting a running web service, a suspended worker and a static site and choosing Suspend leaves all three suspended; Resume brings back both that were running before (as t001 records for a mixed selection).
- [x] A service whose suspend fails stays selected with its error; the others complete.

## Out of scope

- Bulk delete (Render documents none).
