# `GET /v1/services?suspended=` refuses every value, and `?env=` is accepted but ignored

Why: a Render-shaped client can't filter services by suspension at all. The OpenAPI gate admits only Render's `suspended`/`not_suspended`, and the handler then refuses both because it wants `true`/`false`, so every value returns 400. `?env=node` validates but filters nothing, which silently returns the wrong list. `w2/m52` shipped both filters as done; its unit test drives the bare mux, which skips the gate, so it passed.

Found live in `/qa-find-bugs` pass 242 on 2026-09-27 (w4-targeted, `muse.env` credentials) against the deployed `4a0422577`. Read-only: in-page `fetch` from `dashboard.bex.co`, `ownerId=tea-d98210cbbpdc73dcrkvg`, which has 5 web services (4 `runtime: docker`, 1 `node`; none suspended).

| `GET /v1/services?ownerId=…&` | result |
| --- | --- |
| `suspended=true` / `suspended=false` | **400** `suspended must be one of suspended\|not_suspended` (the OpenAPI gate) ❌ |
| `suspended=suspended` / `suspended=not_suspended` | **400** `bad request: unknown suspended "suspended" (want true\|false)` (the handler) ❌ |
| `env=node` | 200, **5** services, 4 of them `docker` ❌ (want 1) |
| `env=bogus` | 400 `env must be one of docker\|elixir\|…\|image` (so the gate knows the param) |
| control: `GET /v1/postgres?suspended=suspended` | 200 ✅; `suspended=true` → 400 naming `suspended\|not_suspended` ✅ |
| control: `type=`, `name=` (repeated), `limit`, `createdAfter` on services | narrow correctly ✅ |

## Mechanism

- Render's own spec, embedded at `lego/backend/internal/api/openapi/render-public-api-1.json`, declares `/services` `suspended` as `array<enum suspended|not_suspended>` (the same as `/postgres`) and `env` as `array<enum docker|…|image>`.
- `lego/backend/internal/api/render_openapi.go` validates query params against that spec (enum error text at l.618). So `true`/`false` never reach the handler.
- `lego/backend/internal/apps/rest.go:689` `core.ParseEnum("suspended", …, "true", "false")`: the handler takes a boolean vocabulary that Render never had. The comment above it says "Render's boolean string filter", which is wrong. `postgres/rest.go:95` and `keyvalue/rest.go:240` use `core.RenderSuspended`/`RenderNotSuspended`.
- The `apps/rest.go` list handler (l.672–712) never reads `env` (or `region`, `includePreviews`). The gate admits them because they are in the Render operation, and the handler then drops them.
- `apps_test.go:1494` pins `?suspended=true|false` against the handler mux alone, so the gate/handler contradiction is untested.
- `docs/ADR018-render-parity.md:63` and `:344` record `?suspended=true|false` as the shipped parity, so the ledger is wrong too.

## Fix

Target: `/v1/services` takes Render's vocabulary, the same as `/v1/postgres`.

- `suspended`: repeatable `suspended`/`not_suspended` (OR'd), via `core.RenderSuspended`/`RenderNotSuspended`. `true`/`false` stays a 400 at the gate (Render never accepted it).
- `env` filters on the service runtime (`env` is Render's deprecated alias for `runtime`), OR'd across values. A static site has no runtime, so it never matches a runtime filter.
- `region`: all bex services report `fsn1`, so decide whether a Render region filter matches everything or nothing, and document it in ADR018. Do not leave it silently ignored.
- Correct ADR018 l.63 and l.344.
- Tests: exercise the list through the **gated** server (`internal/api`), not the bare mux, for `suspended=suspended`, `suspended=not_suspended`, both together, and `env=node`.
- Blast radius: add a test that fails for any `list-*` operation that has a Render query param the gate admits but the handler never reads, unless it is listed as a documented omission (e.g. `includePreviews`). Run it across services, postgres, key-value, env-groups, projects, environments, blueprints, deploys and custom domains.

GraphQL (introspected in pass 244): `services(ownerId, cursor, limit)` has no `suspended`/`env` arguments, so nothing is silently dropped there, and the dashboard is unaffected. Unverified: MCP `list_services` filter arguments.

Render: `GET /v1/services?suspended=suspended` filters to suspended services (per Render's own OpenAPI, embedded above).

Estimate: ~45m.
