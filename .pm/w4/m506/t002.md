## Objective

Each read replica's status says whether it is syncing and since when it stopped, from t001's signal, with hysteresis so a short hiccup does not flip it.

## Context

- `DatabaseReadReplicaStatus` (`lego/types/v1alpha1/database_types.go:832`).
- `lego/operator/internal/controller/database_controller.go` reconciles the replica clusters.

## Steps

1. Add the stale state to `DatabaseReadReplicaStatus`; regenerate (`make manifests generate`).
2. Set it from t001's signal after the threshold; clear it on recovery.
3. envtest: stale after the threshold, not before; recovery clears; initial sync and failover never set it.
