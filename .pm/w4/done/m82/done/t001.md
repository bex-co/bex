## Resolution (2026-08-16)

`lego/operator/cmd/staticserver/main.go`'s `newServer` set `ReadHeaderTimeout`/`WriteTimeout`/`IdleTimeout` from an earlier finding-12 pass but never `ReadTimeout` — a declared-but-withheld request body could still pin a goroutine on Go's unread-body drain on the shared single-replica server. Added `readTimeout = 30 * time.Second` and wired it into `newServer`. `TestServerTimeoutsConfigured` (`main_test.go`) now also asserts `srv.ReadTimeout > 0`. `go test ./cmd/staticserver/...` green.

## Objective

Close `029.md` finding #16: the static server accepts GET/HEAD only, so an unbounded request-read phase serves no purpose and only exposes a slow-body DoS lever.
