## Objective

Make the environment contract enforceable, so the next projection added to the operator cannot quietly re-open this.

## Context

- The strongest form is an assertion on the *whole* set, not on the absence of one prefix: a test that says "these keys and no others", which fails when anything new appears.
- `server_defaults_envtest_test.go` already establishes the pattern of re-deriving behavior from a live API server rather than restating constants; the same envtest can show the pod template's resolved `enableServiceLinks`.

## Steps

1. Envtest: an App Deployment's pod template has `enableServiceLinks: false`, and a converged reconcile still issues no write.
2. A whole-set assertion on the container environment for a service with known variables — exact set equality, not a `grep -v`.
3. The same for the tenant-code pods t003 flipped (cron, build, pre-deploy).
4. A guard that fails when a new `corev1.PodSpec{}` site appears in the operator without a decision — count-based or inventory-based, matching how the repo already guards route and verb inventories.
5. Show the key tests failing against pre-fix code.
