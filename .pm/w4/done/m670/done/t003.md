## Objective

Give `RegistryCredentialSelect` an Add credential entry that opens the dialog over the current page and, on success, refreshes the list and selects the new credential, so every page that uses the select (create page, Settings → Image, Build Source create and settings) gains it at once.

## Context

- `dashboard/src/features/services/components/registry-credential-select.tsx` (the Manage link at `:87-93`); callers listed in the milestone README.
- The dialog opens from its own `DialogTrigger` (`create-registry-credential-dialog.tsx:95-99`) and reports `onCreated`; it needs a controlled `open` so a select item can open it.
- Keep or drop the Manage link according to t001.
- Members who may not create credentials do not see the entry; use the gate the Workspace Settings panel uses.

## Steps

1. Make the dialog controllable (`open`, `onOpenChange`) and pass the created credential to `onCreated`.
2. Add the entry to the select; open the dialog and select the new credential on success.
3. Test it on the create page and in Settings → Image.
