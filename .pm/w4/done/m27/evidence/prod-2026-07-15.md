## Two verifier fixes surfaced by production (committed with this closeout)

1. **Login-page selector ambiguity** — production's login page renders GitHub social login (ADR012 §10), so the browser helper's bare `button[type="submit"]` matched two buttons; it now clicks `button[name="method"][value="password"]` specifically (`scripts/render-cli-auth-browser.cjs`).
2. **Multi-replica logout probe** — production runs 2 bex-api replicas; each caches positive introspections for `core.PositiveTTL` (30s) and only the replica serving the logout invalidates synchronously, so the immediate 401 probe could hit the other replica's still-warm cache. Hydra-side revocation is immediate; the E2E now polls up to 40s for the 401 (`scripts/render-cli-auth-e2e.sh`) — the same documented bounded-staleness window API-key revocation has (w4/m13).
