## Objective

Make the flip safe and prove it end-to-end: seed the relation tuples that keep the platform operable (`bex-bootstrap` → `admin` of `tenant:default`) at deploy time, then extend the E2E to show a seeded identity passing, an unseeded fresh key getting 403, and the unset-env regression staying allow-all.

## Context

- Seeding belongs with the other out-of-band deploy steps: extend `scripts/authz-model.sh` (or a sibling `authz-seed.sh`) to write the tuple idempotently (`POST /stores/{id}/write` with duplicate-tolerant handling); deploy.yml runs it right after the model apply.

- Mock-cluster quirks: pin OpenFGA to the control-plane node like everything else (docs/auth.md local notes).
