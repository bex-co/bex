## Objective

Make accepted query-bearing and encoded local rewrite destinations resolve the same object as a direct request to that destination.

## Context

See [finding.md](finding.md) for the observed failing and passing probes, pinned Go implementation, caller counts and limits.

## Steps

1. Parse the configured local destination before combining it with decoded captures; use its decoded path exactly once for the object key, with query/fragment excluded from the key.
2. Preserve literal reserved characters originating from captures: do not parse the final expanded decoded string as a new URL, which would recreate the redirect defect for rewrites.
3. Define malformed-target write refusal and a bounded runtime failure for invalid direct CR input. Keep S3-only serving, revision scoping, canonical path normalization and existing error classes.
