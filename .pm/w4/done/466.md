# 466 — A deploy's Rollback control is named "Roll back to dep-…", which doesn't contain its visible label "Rollback"

Why: a voice-control user who says "click Rollback" cannot activate the button, because its accessible name ("Roll back to dep-…") doesn't contain the visible word. WCAG 2.5.3 Label in Name asks that the name start with the visible label.

- **Source / severity / estimate:** live `/qa-find-bugs w4` loop, 2026-11-04 10:05 UTC (`muse.env`, `bex-canary`, pin `fb6098dd2e37`); **minor** (accessibility); ~20m.
- **Probe (Playwright, owned fixture `qa-20261104-whoami`, `srv-dblg4gn73ids73e34da0`, deleted afterwards):** on `/services/<id>/deploys` and `/services/<id>/deploys/<dep-id>`, `getByRole('button', {name: 'Rollback'})` times out after 30 s. The aria snapshot shows `button "Roll back to dep-dblg4gn73ids73e34dag": Rollback`.
  - A scan of 10 pages (deploys, deploy detail, settings, env, logs, events, metrics, `/`, `/env-groups`, `/blueprints`) for elements whose `aria-label` does not contain their visible text found only this control as a real violation. The other hits were comboboxes showing their current value, which 2.5.3 allows.
  - **Control:** the row's Cancel button is named "Cancel deploy {target}", which contains "Cancel", so it passes.
- **Root cause:** `dashboard/src/features/deploys/components/deploy-actions.tsx:293` sets `aria-label={t("services.eventsRollbackAria", { target })}`. The message is "Roll back to {target}" (`features/services/locales/en.ts:4806`, `zh.ts:4695`), while the visible text is `services.eventsRollback` = "Rollback" (`en.ts:4775`). w4/m141 added the per-row target so two rows don't read as two identical buttons, and that part stays.
- **Fix:** change the message to "Rollback to {target}", and check that the zh message starts with the zh visible label. Update the assertions that match `/^Roll back to /`: `deploy-actions.test.tsx` (13 sites, including the exact `"Roll back to 80b423b (dep-1)"` at `:569`), `routes/__tests__/services.$serviceId.events.test.tsx:270,297`, `capabilities/__tests__/resource-action-freshness.test.tsx:226` and `confirm-through-refresh.test.tsx:381`. Add one test asserting that the accessible name starts with the visible text.
- **Render:** Render's deploy rows label the action "Rollback".
- **Dedupe:** no `.pm` item mentions label-in-name or 2.5.3. `git log -S"Roll back to {target}"` → `f0479fa66` (w4/m141) is the only change. No DO_NOT_DO item applies.
