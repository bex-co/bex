## Objective

Keep the wider context's cost bounded and its contents safe: measure image size and build time, keep layer-cache reuse, keep `.git` out of the image, and leave secret files where they are today.

## Context

- Secret files are copied into the build context (`lego/operator/internal/build/dockerinputs.go`, the copy loop before `dockerContextDir`; [ADR013](../../../../../docs/ADR013-secrets.md)).
- Build pipeline and cache design: [ADR060](../../../../../docs/ADR060-build-worker-reliability-and-performance.md).

## Steps

1. Build t005's fixtures before and after t002 on dev-4 and record image size and build time in this milestone's README.
2. Check that a change outside the Root Directory still reuses the dependency layers where it did before, or record what it costs.
3. Check that the image has no `.git` and that each secret file is readable at the same paths as before.

## Files

- `lego/operator/internal/build/` and its tests
- `.pm/w4/m650/README.md` (measurements)

## Acceptance criteria

- [x] Size and time before and after are recorded.
- [x] No `.git` in a native image (test).
- [x] Secret files keep their paths (test).

## Result (2026-11-25)

Measured on the local BuildKit harness, not dev-4: the local cluster cannot build natively (README § Record). Numbers are in the README.

- Layer cache: the steps before `COPY . .` (toolchain, tools, defaults) are reused as before. The `COPY . .` layer now changes on a commit outside the Root Directory too; the build command's step reruns on every release anyway (`nativeReleaseRevision`), so nothing else is lost. The dependency directories' key is the Dockerfile up to the first `COPY . .`, so it still ignores source changes, but its text changed for a service with a Root Directory: each such service rebuilds its kept dependency directories once after the change (ADR060 D7, whole repository).
- No `.git`: `TestNativePreparerWritesTheDockerfilesIgnoreFile`, and the real image in `TestNativeImageReadsTheWholeRepository` has neither the checkout's `.git` nor a submodule's `.git` file.
- Secret files: in the real Go image the build command reads `/etc/secrets/api.env`, and the file is linked at `<repo>/cmd/api/api.env`, the Root Directory, and not at the repository root (`TestNativeImageReadsTheWholeRepository`).
