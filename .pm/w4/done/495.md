# 495 — The Billing page's "Partial data" caveat keeps its explanation in a hover-only `title`, so keyboard and screen-reader users never learn what is incomplete

Why: w4/048 added the caveat so nobody reads a degraded estimate as authoritative. The part that matters ("may undercount… complete only through 2026-11-01… degraded sources: …") lives only in a `title` on a non-focusable span, so only mouse users who hover can read it.

- **Source / severity / estimate:** live `/qa-find-bugs w4` loop, round 74, 2026-11-05 14:10 UTC (`muse.env`, `bex-canary`, pin `c8bbc07cbeeb`); **minor** (accessibility); ~15m.
- **Probe:** `/usage` redirects to `/billing`. Under **Charges**, the visible text is just `Partial data`. Its element carries `title="This estimate may undercount usage. Complete only through 2026-11-01. Degraded metering sources: direct, http, instance, postgres, websocket."` and has no `aria-describedby`. The span is not focusable, and the `ariaSnapshot` exposes only `Partial data`.
- **Root cause:** `dashboard/src/features/usage/components/charges-card.tsx:232-258` `CoverageCaveat` joins the explanation into `title={parts.join(" ")}` on a plain `<span>`.
- **Fix (target behavior):** the explanation is visible text, or at least announced and reachable by keyboard. For example, render the sentences under the label (one small line), or make the label a focusable disclosure. Either way the `ariaSnapshot` must contain the "complete only through …" and degraded-sources text. Keep the en/zh keys (`usage.coveragePartial*`). Extend the component test to assert the accessible text.
- **Blast radius:** one component. The other `title=` uses in `features/usage` (`charges-card.tsx:149`, `resource-caps.tsx:101`) are worth the same check, but were not exercised this round.
- **Render:** n/a (bex's own caveat).
- **Dedupe:** w4/048 (done) introduced the caveat as a tooltip. `grep -ril "Complete only through" .pm` finds only 048. No DO_NOT_DO item applies.

Closed 2026-11-05: `CoverageCaveat` renders the explanation as a visible line under the label (no hover-only `title`); `charges-card.test.tsx` asserts the visible text.
