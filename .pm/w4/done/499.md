# 499 — Every env var and secret file row's Reveal/Hide button has the same accessible name

Why: with several variables, a screen-reader user hears a list of identical "Reveal" buttons and cannot tell which value each one exposes. The Copy button beside each one already names its row.

**Severity:** minor (a11y) · **Estimate:** 15m · **Worker:** worker4 · **Status:** todo

- **Source:** live `/qa-find-bugs w4`, production, 2026-11-05 17:39–17:45 UTC, round 88. Workspace `bex-canary`. Prod pin `cc3c51e12952`; research on main `14f32e549`.
