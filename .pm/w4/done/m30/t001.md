## Objective

Move the environments partial-update merge out of the REST adapter into a service-layer `Update(ctx, id, patch)` verb taking an `EnvironmentPatch` (pointer fields for name + the ACL triple), owning the read-modify-write merge and the `""→unprotected` pre-migration default, following the `postgres.UpdatePostgres`/`PostgresPatch` precedent.

## Context

- `lego/backend/internal/environments/rest.go:229-296` — the PATCH handler currently does: optional `Rename`, then Get-if-needed, merge pointer overrides over the current triple (defaulting empty `protectedStatus` to `unprotected`), then full-replace `SetACL`.
- `lego/backend/internal/environments/service.go` — `Rename`, `SetACL`, `applyACL`, `validateACL` already exist; `CreateWithACL` (w6/m33) is the shape precedent for a composed core verb.
- Collapsing the composed calls also removes the duplicate authorize/fetch round-trips the adapter sequence incurs (`Rename` + `Get` + `SetACL` each authorize independently).

## Steps

1. Define `EnvironmentPatch` (pointer name + pointer ACL fields) and `Update` in `service.go`; one authorize, one fetch, merge, validate, apply.
2. Thin the REST PATCH handler to decode + call `Update` + render.
3. Keep behavior byte-identical for existing callers (same validation errors, same empty-body 400).
