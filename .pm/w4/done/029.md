## Rate-limit identity behind Traefik (report #10) — the widest of these

## Two findings triaged as NOT code bugs

- **#5 agent GitHub token branch scope — accepted with mitigation.** `MintSessionInstallationToken` requests `contents: write` scoped to one repo; GitHub installation tokens genuinely cannot encode a ref scope, and `docs/ADR047-cloud-coding-agent-sessions.md:99-107` already says so. The branch check in `agentsession/mint.go` is an intent check, not confinement. The compensating control is a repository ruleset restricting the App to `bex-agent/*` with no bypass — verify it exists, don't patch Go.
- **#6 bex-api cluster-wide CR writes — partly valid, narrow slice actionable.** The RBAC and automount claims are correct, but `bex-api-app-admission.yaml` plus `AppReconciler.canonicalNamespace` already confine Apps to `tea-*` or `default`. ~~The real delta: **`databases` and `keyvalues` have no admission policy and no reconciler namespace guard** (`canonicalNamespace` exists only in `app_controller.go`), so those two CRs can be planted in any namespace including platform ones. Mirror the App policy for them.~~ **DONE (already, confirmed 2026-08-16):** a shared `canonicalNamespace` now lives in `database_controller.go:249` (called `:539`) and is reused by `keyvalue_controller.go:656`; the admission policy's `resources` list already covers `apps`/`databases`/`keyvalues` (`bex-api-app-admission.yaml:28`). The report's "minimal tenant-aware projector" rewrite is an ADR-level item, not this.
