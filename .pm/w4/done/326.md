## Cause and bounded correction

- `lego/backend/internal/envgroups/service.go:135–137` declares `SecretFileView.Content` as a string with `json:"content,omitempty"`. `GetEnvGroupFile` at `:1109–1130` checks map membership separately and returns the correct empty string for an existing file. The JSON tag then removes it.
- REST `rest.go:177–178` returns that view directly. `internal/core/http.go:365–372,236–239` passes it to `encoding/json`; no response projection restores field presence.
- The **three production consumers** of GetEnvGroupFile are REST, GraphQL (`graphql.go:229`) and MCP (`mcp.go:258`), verified by exhaustive production grep. GraphQL's explicit resolver `graphql.go:39–44` returns the string directly, explaining the passing native read. The dashboard's content query at `features/env-groups/api/env-groups.graphql:63–67` is consumed by `hooks/use-env-groups.ts:604–609`; it already receives the correct empty string.
- MCP `get_env_group_secret_file` at `mcp.go:254–259` returns the same view as its typed output. The pinned **go-sdk v1.6.1** was opened: `mcp/server.go:370–391` marshals the output, validates/applies schema defaults, and uses that JSON for both structured content and its text result. `mcp/tool.go:69–104` preserves the marshalled object subject to actual schema defaults. The current field has no content default. This is the independently traced MCP serialization path, not a claimed live MCP observation.

Use a dedicated content-bearing response with `name` and a string `content` **without omitempty**, projected from the successful read at the REST GET and MCP get-tool adapters. The domain read can retain its current return type and GraphQL resolver. The existing SDK can infer/validate the new read output schema; an empty string is a valid string. Update any required generated schema expectations through their normal workflow.

Do not remove omitempty globally from SecretFileView: group metadata is assembled with names-only views (`service.go:2231–2234`), and **SetEnvGroupFile deliberately returns only Name** (`:1085`). A global tag change would conflate masked metadata with a revealed empty file and alter create-input/acknowledgement shapes. Scope the read representation to the two JSON adapters; preserve input omission, native create/clone/patch behavior and existing service-file responses.
