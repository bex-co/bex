## Objective

Prove, with a test, that both `internal/environments.Service.Get` and `internal/projects.Service.Get` return `core.ErrForbidden` (403) — not `core.ErrNotFound` (404) — when the caller probes an id that belongs to a **different** tenant, matching the established `apps` precedent. Today this behavior is structurally implied by the fetch-then-`AuthorizeOn` shape of `requireEnvironment`/`requireProject` (`lego/backend/internal/environments/service.go:629-643`, mirrored in `internal/projects/service.go`), but it is unverified: `environments_test.go` only has a blanket-deny test (`TestVerbsDenyWhenUnauthorized`, lines 276-287), and `internal/projects` has zero test files at all.

## Context

- `lego/backend/internal/apps/apps_test.go:246` — `TestGetCrossTenantIsForbiddenNotNotFound`, the pattern to mirror.
- `lego/backend/internal/core/base.go:351-367` — `checkAuthz`, maps denial to `ErrForbidden`.
- `lego/backend/internal/core/http.go:50-68` — `ErrForbidden` → 403, `ErrNotFound` → 404.
- `lego/backend/internal/environments/service.go:629-643` — `requireEnvironment`: global fetch, then `AuthorizeOn` against the row's own tenant.
- `lego/backend/internal/projects/service.go:162-172` (approx, `Get`) — same shape, no blanket `s.Authorize` first.
- `docs/ADR012-auth.md:191` — "403-before-404 is preserved" is the documented invariant this pins.

## Steps

1. In `internal/environments`, add a test creating two tenants, an environment (and its parent project) in tenant A, then calling `Get` as tenant B — assert `errors.Is(err, core.ErrForbidden)`, not `core.ErrNotFound`.
2. In `internal/projects` (new `projects_test.go` — none exists yet), add the equivalent test for `projects.Service.Get`.
3. Also assert the genuinely-nonexistent-id case still returns `core.ErrNotFound` for both, so the test pins both halves of the split, not just one.
4. Run `cd lego/backend && go test ./internal/environments/... ./internal/projects/...` — confirm green (the behavior should already be correct; this task is coverage, not necessarily a fix — if either fails, note the actual bug for t002/t003 to absorb rather than silently patching outside the recorded scope).
