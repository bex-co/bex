Production pin `21762a1df1fb` carried 0284 and not 0283, so production's `schema_migrations` read 284. - **Every write fails.** `insertAuditEvent` (`audit.go:150-180`) inserts both columns for every row, and both `Record` (`:129`) and `RecordAll` (`:136`) go through it.
