## Objective

Change the Blueprint plan so that a file applying `numInstances` without a `scaling` block sets the service's manual instance count and leaves its autoscaling settings untouched, as Render's spec says.

## Context

- `lego/backend/internal/apps/blueprint_plan.go:463-483`: the `applies("scaling")` branch owns autoscaling; the `else if applies("numInstances") && !present("scaling")` branch at `:480` calls `turnOffAutoscaling(dst)` then sets `dst.Replicas`.
- A manual count is ignored while autoscaling is on (w4/m364), so storing it is safe.

## Steps

1. Drop `turnOffAutoscaling(dst)` from the `numInstances` branch and keep `dst.Replicas = want.Replicas`.
2. Make sure the plan reports no autoscaling change for that service, so no `autoscaling_config_changed` event is written.
3. Update the comment above the branch.

## Files

- `lego/backend/internal/apps/blueprint_plan.go` and its tests

## Acceptance criteria

- [x] An autoscaled service synced from a file with `numInstances: 3` and no `scaling` keeps `autoscaling.enabled` and its range, and its manual count reads 3 (test).
- [x] No `autoscaling_config_changed` fact is recorded for it (test).

## Out of scope

- Removing a previously declared `scaling` block (`:467-469`), which Render does not document.
