# In a protected environment suspend, resume, delete, maintenance mode and Shell answer a bare `FORBIDDEN`, while every other Admin-only verb is coded

Why: a client should tell "only an Admin may do this here" from any other refusal by one code, as the dashboard's raced-403 path and every API caller do for placement, credentials, IP rules and environment groups since w4/m594. Found by w4/m594 t007 on 2026-11-23.

- **Today:** `core.RequireEnvironmentAdmin` (`lego/backend/internal/core/confirmation.go`) returns the fresh workspace-manage check's bare `ErrForbidden` for `suspend`, `resume`, `delete`, `take offline` and `shell`, through `requireUnprotected` in `apps/protection.go`, `postgres/protection.go` and `keyvalue/protection.go`. Placement answers `PROTECTED_ENVIRONMENT_ADMIN_REQUIRED` (w3/m281), and since w4/m594 so do datastore credentials, IP rules, environment groups and a protected service's environment variables (`core.RequireEnvironmentAdminCoded`, `core.ProtectedAdminError`).
- **End state:** every restricted verb's non-Admin refusal is the coded `403` with `params.environmentId` on GraphQL, MCP and bex-native REST (Render's operations keep Render's codes, w8/411): `requireUnprotected` in all three packages uses the coded gate and `RequireEnvironmentAdminCoded` folds into `RequireEnvironmentAdmin`. The dashboard's lifecycle, Delete, maintenance-mode and Shell paths read a raced coded `403` as _This action is limited to admins._ (`adminOnlyErrorMessage`, `dashboard/src/features/capabilities/lib/admin-only.ts`). Pairs with w4/724–w4/726, which gate those controls before the click. Tests per verb that the code reaches GraphQL and MCP.
