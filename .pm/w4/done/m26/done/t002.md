## Resolution (2026-07-15)

Aligned REST to the captured schema: `event` replaces `action` (1:1 verb→Render-enum mapping for the unambiguous lifecycle/rename/ip-allow-list verbs, `<feature>.<Verb>` passthrough otherwise); `actor` became Render's `{type: user|rest_api|system, id}` object (`session`→user, `oauth2`→rest_api, else system; email omitted — the row stores only the subject); `status` speaks the closed `success|error` enum with the denial preserved as `metadata.outcome: "denied"`; `metadata` is the required always-present string map carrying the audited target keyed by kind (via new `core.SplitTarget`) + the maintenance `to` flag; the store limit cap rose 200→1000 (Render's audit-specific bound). `Event.Target` now flows through the shared view. GraphQL deliberately keeps bex's flat dialect (`actor` string, `action`, `status: denied`) for the dashboard — Render has no public GraphQL.
