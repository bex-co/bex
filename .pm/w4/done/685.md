# 685 — At phone width, Account Settings' API Keys and SSH Public Keys tables squeeze the Name column to 28 px: names stack one or two characters per line, and a two-key table is 874 px tall

Why: a key's name is how its owner tells keys apart before revoking one. At 390 px each name stacks into a 1–2-character column ("b / e / x / - / c / a / n …"), and the header "Name" stacks too.

- **Source / severity / estimate:** live `/qa-find-bugs w4` round 493, 2026-11-16 07:15–07:25 UTC, pin `3c6654df60a2`, `/settings` as the `bex-canary` admin. **Minor:** nothing is lost and the actions work, but the table is unreadable. ~45m.
- **Probe** (390×844, signed in, `/settings`, after `networkidle` + 3 s; widths read from `getBoundingClientRect`):
  - **API Keys:**
    - Columns: Name 28, Client ID 240, Created 44, Created by 149, Last used 44, Actions 16 px.
    - The table is 558 px wide inside a 316 px scroll container.
    - Rows are 437 px (`bex-canary-probes-m96`) and 357 px (`bex-canary-probes`), so the card is 1092 px.
  - **SSH Public Keys:**
    - Columns: Name 28, Fingerprint 288, Created 45 px.
    - The table is 413 px in 316, and the one row (`tp-ms-fish`) is 197 px.
  - **Controls that hold:** Active sessions (Device 256 px, rows 39–53 px) and Team on `/workspace/settings` (Member 128 px).
  - **Scan:** the same "crushed cell" check over 14 pages found only the three cells above. The pages were `/`, `/settings`, `/workspace/settings`, `/env-groups`, `/blueprints`, `/webhooks`, `/billing`, a web service's overview, deploys, events, env, settings and scaling, and a Key Value.
- **Cause:**
  - The body sets `[overflow-wrap:anywhere]` (`dashboard/src/common/root-route/shell-component.tsx:39`). Every `th` and `td` inherits it: live, the SSH table's header and cells compute `overflow-wrap: anywhere`.
  - Unlike `break-word`, `anywhere` counts a break between any two characters when it computes min-content width, so a word's min-content is one glyph.
  - When the card is narrower than the table, auto table layout gives each column its min-content width. Cells that cannot shrink keep their width:
    - API Keys' Client ID: `flex max-w-[14rem]` with a `truncate` code element (`features/api-keys/components/api-key-row.tsx:27-28`).
    - API Keys' dates: `whitespace-nowrap` (`:39`, `:45`).
    - SSH Public Keys' Fingerprint: `max-w-72 truncate` (`features/ssh-keys/components/ssh-keys-panel.tsx:191-192`).
  - So Name drops to one glyph plus `p-2`.
  - The API key Name cell's own `break-all` (`api-key-row.tsx:23`) does the same by itself.
  - `TableHead` and `TableCell` set no wrap rule (`common/components/ui/table.tsx:70`, `:83`).
  - [w1/133](../../w1/done/133.md) met the same body rule in a flex header, and fixed only that header (`features/metrics/components/metric-section.tsx:97-99`).
- **Fix:**
  - Table cells break words only where a word is wider than the whole table container.
  - Set `[overflow-wrap:break-word]` on the `TableHead` and `TableCell` base classes. A column's min-content then becomes its longest unbreakable run, which breaks at spaces and hyphens. The table widens, and the existing `overflow-x-auto` container (`ui/table.tsx:9`) scrolls it.
  - Replace `break-all` with `break-words` in the cells that set it:
    - `api-key-row.tsx:23`
    - `features/registry-credentials/components/registry-credential-row.tsx:31` and `:37`
    - `features/services/components/custom-domains-section.tsx:246`
    - the Team skeleton's `team-panel-skeleton.tsx:63`
- **Blast radius:**
  - 32 non-test files import `ui/table`, so the base-class change is global.
  - Keep the tables that look right today unchanged at 390 and 1440, and pin them with tests: Active sessions, Team, Deploys, Events, Env groups and Webhooks.
- **Unverified (not opened this round):**
  - registry credential and custom-domain rows (`bex-canary` has no registry credentials);
  - 360 and 375 px widths;
  - zh column headers.
- **Render:** n/a (not compared).
- **Done when:**
  - On production at 390, API Keys and SSH Public Keys show each name broken only at its hyphens, the header "Name" on one line, and the table scrolling sideways inside its card.
  - The 14-page scan finds no crushed cell.
  - The control tables keep their widths.
  - Dashboard `yarn lint` and `yarn test` pass.
