## Objective

Make RelativeAge and RelativeUntil advance with the current client clock on an otherwise unchanged visible page, retaining their current compact formatting and exact source instants.

## Context

The two fresh cron repros and complete API controls are in finding.md. RelativeTime calls format(value) only on render; unchanged Apollo polls do not supply a clock. Existing useNow already supplies a one-minute clock to the advancing deploy-list control.

## Steps

1. Choose the smallest shared clock arrangement that updates compact relative labels at least once per minute without per-row intervals or extra API requests. Reuse the existing clock behavior where it fits.
2. Keep exact datetime/title and custom fallback/as=span behavior. Preserve SSR hydration guards and a safe initial render before query data settles.
3. Keep background poll loading behavior intact; do not enable network-status rerenders as a clock substitute. Record the chosen cadence and unmount/hidden-resume behavior for t005.
