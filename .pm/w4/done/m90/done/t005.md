## Objective

Make the multi-step creation flow recover cleanly across redirects, refreshes, cancellations, and local/test environments, with a pending skeleton that matches the final page.

## Context

- Redirect-capable payment methods and SCA can leave the page before finalization; a return URL must carry only an opaque attempt id and resume by server read.
- `WorkspaceCreatePageSkeleton` currently previews slug + plan cards only, violating the repo rule once billing email/payment regions are added.
- `dashboard/scripts/local-bex.mjs` needs deterministic fixtures for worker browser checks without real Stripe; the real Stripe test-mode path is still required for final evidence.
- Abandoned attempts and Customers must not accumulate indefinitely or appear in the switcher.

## Steps

1. Add sanitized return/search-state parsing and resume/poll/finalize behavior; handle success, cancel, expired attempt, recoverable provider lag, and permanent failure without duplicate submission.
2. Add an explicit start-over path that retires the old attempt and preserves safe form fields where appropriate.
3. Wire bounded local/provider cleanup into an existing worker/admin cadence with metrics for expired attempts and cleanup failures.
4. Update `WorkspaceCreatePageSkeleton` and its manifest/tests to match the ready page at desktop and narrow mobile breakpoints.
5. Extend local-bex and isolated dev-4 configuration so required/optional/off modes and success/cancel/retry UI can be exercised without embedding secrets.

## Acceptance criteria

- [x] Refresh/back/redirect return resumes the same authorized attempt and never asks the user to create a duplicate workspace.
- [x] Cancel and expiry explain that no workspace was created and offer a working retry/start-over action.
- [x] Cleanup is bounded, observable, idempotent, and cannot delete a finalized workspace's Customer/contract.
- [x] Pending and ready screenshots have matching outer bounds, headings, sections, plan grid, Payment Method region, and footer at desktop and 390px mobile.
- [x] Local-bex can deterministically show all payment-policy and retry states with no Stripe secret.
