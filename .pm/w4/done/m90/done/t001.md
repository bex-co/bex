## Objective

Give billing email and pre-payment workspace creation durable, subject-bound state without inserting a usable tenant before its required payment method is verified.

## Context

- `tenants` has no billing-email column; Stripe Customer creation in `lego/backend/internal/billing/stripe.go` uses only the `tea-*` as its name.
- The billing mapping tables foreign-key `tenants(id)`, so a Stripe Customer created before the tenant cannot be parked there.
- A separate short-lived create-attempt row is safer than a `pending` tenant: every existing tenant list/read/resource path otherwise has to learn that pending tenants are invisible and unusable.
- The attempt must bind the authenticated subject, reserved `tea-*`, normalized name/plan, billing email, provider correlation, expiry, and terminal/finalized state. Provider ids remain server-only.

## Steps

1. Add the next paired migration for `tenants.billing_email` and a bounded `workspace_creation_attempts` table with the necessary uniqueness, ownership, expiry, and finalization fields.
2. Add store types/verbs to create, load-for-subject, advance, finalize, and expire attempts. Mint the reserved workspace id only through `internal/id`.
3. Make finalization insert the tenant with its reserved id, billing email, and owner membership exactly once in one Postgres transaction; retain the existing plan/name/cap invariants.
4. Define deterministic conflict/retry behavior and ensure subject/account deletion cannot strand reusable attempts.

## Acceptance criteria

- [x] A workspace carries a normalized non-empty billing email after creation.
- [x] No pending attempt appears in `ListTenantsForSubject` or any tenant-backed resource API.
- [x] The same subject can resume an unexpired attempt; another subject receives not-found/forbidden without learning its contents.
- [x] Concurrent finalizers yield one tenant and one owner membership.
- [x] Expired/abandoned attempts can be claimed for bounded cleanup without touching completed workspaces.
- [x] Up/down migration and real-Postgres race coverage pass.
