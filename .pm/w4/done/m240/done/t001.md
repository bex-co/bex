## Objective

Make the static server match `:name` source segments and substitute them into the destination, so Render's documented placeholder rules fire.

## Context

- `lego/operator/internal/staticserver/staticserver.go:721-738` `matchPattern` (exact, `/*`, trailing `/foo/*` only).
- `staticserver.go:749-790` `expandDest` (`:splat` and trailing `/*` only; escape-once rules from w4/m154).
- Callers: `matchRoutes` at `staticserver.go:317` (GET/HEAD miss) and `:949` (non-GET external rewrite).
- [finding.md](finding.md) has the live probe and Render's examples.

## Steps

1. Return a capture set (splat + named segments) from the matcher. A `:name` segment matches one non-empty segment and may precede a trailing `/*`.
2. In `expandDest`, replace each declared `:name` in the decoded destination path. Keep the `:splat`/`/*` behavior and the size bounds; count every capture toward `maxExpandedRoutePathBytes`.
3. A destination `:name` the source does not declare stays literal at runtime (writers refuse it in t002; a direct CR write must not panic).
