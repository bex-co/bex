## Objective

Check the change against Render on every surface it touches, and walk the other verbs Render reserves to Admins in a protected environment.

## Steps

1. GraphQL `serverActions`, `databaseActions` and `keyValueActions`, and the dashboard: confirm the projection and the verbs agree on REST, GraphQL and MCP. REST and MCP have no projection; their verbs' refusals are unchanged.
2. Compare with Render: render.com/docs/projects, and its dashboard bundle's per-service Suspend and Resume copy if it differs from the bulk toolbar's _This action is limited to admins._ (`docs/render-artifacts/service-list-bulk-actions.md`).
3. Walk the remaining restricted verbs (`core.ProtectedVerbRestricted`) for a Developer in a protected environment: Delete (gated on `can_create` in the dashboard), maintenance mode on, and Shell. File each one that reads as allowed and then answers 403 as its own note. w4/720 already covers datastore passwords, IP rules and environment groups.
4. Update ADR018's Suspend / Resume row so the per-resource controls are named alongside the bulk path.

## Acceptance criteria

- [x] ADR018 and ADR032 describe what shipped, and each drift found is filed or fixed.
