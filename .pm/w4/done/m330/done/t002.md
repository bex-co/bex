## Objective

Remove the restart from the API texts and from what bex-api records.

## Result

- **2026-11-11 (loopx w4):** done. GraphQL `setKeyValueMaxmemoryPolicy` and MCP `update_key_value` (tool and `maxmemoryPolicy` argument) say the change applies to the running store without a restart. `markRestartFree` marks a policy-only write, so the status stays `available`. `recordUpdateEffects` records `key_value_config_restart` for a persistence change only; a policy change alone is the generic `keyvalue.UpdateKeyValue` row (Render's config-restart event is a restart record, `{message, reason}`).
