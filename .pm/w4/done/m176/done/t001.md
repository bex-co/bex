## Objective

`Trigger` with `ImageURL`/`CommitID` and every `Rollback` on a protected member require `ProtectedConfirmation("repoint", name)`; a bare `Trigger` stays exempt.

## Context

- `lego/backend/internal/deploys/service.go:509-522` (`Trigger`), `:1025-1045` (`Rollback`).
- Phrase and guard: `lego/backend/internal/apps/protection.go` (`ProtectedConfirmation`, `requireUnprotected`); shared core: `lego/backend/internal/core/confirmation.go:86` (`RequireEnvironmentConfirmation`), as used by `postgres/protection.go:35` and `keyvalue/protection.go:56`.
- `confirm` plumbing: `core.WithConfirm` on the request context; REST `?confirm=`, GraphQL `confirm` arg, MCP `confirm` field.

## Steps

1. Resolve the App's environment protection inside `deploys` through the core helper (or a small `apps`-owned predicate injected into `deploys`), so all four guards share one predicate. Fail closed on lookup errors.
2. Call it in `Trigger` only when an override is present, and in `Rollback` unconditionally, after authorization and before any write.
3. Accept `confirm` on REST `POST /v1/services/{id}/deploys` and `/rollback`, the GraphQL mutations and the MCP tools.
4. Grep every `Trigger`/`Rollback` caller (webhook, deploy hook, blueprint sync) and record which reach an override.

## Acceptance criteria

- [x] The DoD's override-deploy and rollback probes refuse without the phrase and succeed with it; a bare trigger is unchanged.
- [x] An unprotected service needs no phrase.

## Out of scope

- Changing ADR032's exemption list beyond adding these verbs (t003).

Done 2026-10-05:

- `deploys.Service.Protection` is apps' guard via `apps.Service.ProtectionGuard()` (wired in `api/server.go`), so it shares the predicate and the `repoint` phrase.
- `Trigger` calls it only with `imageUrl`/`commitId`, after authorization and before billing/writes.
- `Rollback` calls it after the suspended/billing/target checks.
- A lookup failure refuses.
- `confirm` is threaded on REST `?confirm=` (validator admits it on `create-deploy`/`rollback-deploy`, and on `update-service`, whose refusal named a parameter the validator rejected), GraphQL `triggerDeploy`/`rollbackService` and MCP `trigger_deploy`/`rollback_deploy`.

**Caller grep:**

- Webhook auto-deploy (apps' redeploy) and env-group rebuild (`api/server.go:852`, `TriggerParams{}`) carry no override.
- **The deploy hook does** (`deployhook.go:381`, `?ref=`/`?imgURL=` via `triggerFetched`). It is kept exempt deliberately, as a secret URL for automation (ADR032).
