## Resolution (2026-07-15) — done

`suspenders` now reads `["user"]` while suspended and `[]` otherwise on all three surfaces. One deviation from the slug pattern, deliberately: no new `AppView` field — unlike slug (new data), suspenders is a pure derivation of the existing `Suspended` bool, so each adapter derives it via one shared `apps.suspenders()` helper (`render.go`'s `renderService` — REST **and** MCP inherit it through `toRenderService`, which already declared the field but hardcoded `[]` — plus a `graphql.go` list field). Always an array, never `null`, never a faked enum value bex has no source for (`admin`/`billing`/`parent_service`/…). Parity test: `TestSuspendersPresentOnAllThreeSurfaces` (clone of the slug test, both suspended states). ADR018 Suspend/Resume row updated. No dashboard change (it consumes the `suspended` enum, not `suspenders`).
