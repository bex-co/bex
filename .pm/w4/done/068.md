**Logs filters (journey 7's logs half).** On `beancount-forum` (`srv-d9nqg9dcavls73fp8m2g`, read-only, pre-existing) and on the fixture:

- **Search narrows.** With `message-bus` in the search box, all 13 rendered lines contained it and **zero** contained `discourse-presence`, which was present before filtering.
- **A no-match search is honest**: 0 lines plus "No matching logs — No logs match these filters." — which is distinct from "no logs at all".
- **Type filter narrows, with a real control case.** `All logs` → 13 Traefik request records; `Application logs` → 0 lines; `Request logs` → 13 records. An empty Application view on a live Discourse forum looks like a broken filter, so it was checked against a service whose stdout is known: the fixture's `Application logs` showed exactly its two `hello-go listening on 3000: "OK"` lines (one per deploy, tagged `[kb5ac]` and `[uefrr]`) and no request noise. The filter is correct; the forum simply writes no stdout in that window.
- Range presets are Render-shaped (`Last 30 minutes` → `Last 30 days` + `Custom…`), filter state rides the URL (`?type=request`), and selecting a structured filter says so: **"Live tail is off — request-log and structured filters can't be tailed."**

**Free-tier sleep → wake (journey 15), measured to the second.** Last request 14:06:47 → `service_hibernated` at **14:21:47**, phase `Hibernated` — exactly the 15-minute `defaultIdleTTL` (`lego/operator/internal/controller/app_controller.go:1910`). First request after that returned `503 {"error":"service hibernated","retryAfter":5}` in 0.58s with `Retry-After: 5`, and the **next** request ~6s later returned `200 OK`. The advertised "wake on the next request" holds, with the wake costing ~6s.

## Three candidates that dissolved — do not re-chase

1. **"Application logs is empty, so the type filter is broken."** It is not: the control case above proves the filter returns real stdout for a service that emits it.
2. **"A sleeping service answers raw JSON instead of an interstitial."** The activator **content-negotiates** — `cmd/activator/main.go:198-231`: an explicit non-zero `text/html` range gets `wakePage` (HTML); a client sending no `Accept` or only `*/*` gets the JSON body, and the comment states that intent ("API clients … keep the historical JSON response instead of unexpectedly receiving a document"). The JSON was correct for `curl`'s `*/*`. **The HTML page itself was not observed** — re-hibernating costs another 15 minutes — so if someone wants the browser path confirmed, that is the one gap here.
3. **"'Idle timeout: Platform default' never says it means 15 minutes."** Deliberate. `dashboard/src/features/services/lib/idle-timeout.ts:6-13`: `0` "means the platform default idle window, which the operator resolves to a real value (15 min for free services, w6/m116) — **distinct from the explicit '15 min' preset in that it follows whatever the platform default is, rather than pinning a number**." Labelling it "Platform default (15 min)" would undercut the distinction and go stale if the default moved. `w4/044` (done) covered this control's accessible name, a separate concern.
