## Objective

Converge interrupted env-var/secret-file saves to a coherent committed state and reject late writes from a superseded operation.

## Context

- A save writes multiple OpenBao paths and Kubernetes Secrets before releasing its content revision.
- A timeout or process restart can interrupt any boundary, including compensation or claim release.

## Steps

1. Integrate phase advancement and ownership checks into the save/compensation path, including Kubernetes conditional-write boundaries.
2. Add a bounded recovery pass on the appropriate existing service/startup seam that resumes or restores operations according to durable evidence.
3. Prevent stale owners from finalizing or overwriting newer state, preserve acknowledged commits, and record a truthful terminal or repair-required result when safe automatic recovery is impossible.

## Files

- `lego/backend/internal/envgroups/patch.go`
- `lego/backend/internal/envgroups/revision.go`
- `lego/backend/internal/envgroups/recovery.go (new if needed)`

## Acceptance criteria

- [ ] Termination at each write boundary and recovery by a second instance yields matching source maps, projection Secrets, metadata, and revision.
- [ ] An active operation cannot be stolen, and a paused stale writer is refused after ownership changes.
- [ ] Recovery preserves acknowledged saves and generated values; ordinary errors expose no secret data.

## Out of scope

- Unrelated platform recovery workers.
- Changing existing save_only/deploy/rebuild intent or billing.
