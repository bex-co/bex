# The Postgres and Key Value plan pickers show no price, so a paid datastore is chosen blind

Why: the service picker prices every tier ("$4.90/month" … "$315.00/month"), and so does the public `bex.co/pricing` page. The Postgres and Key Value create forms show only RAM/CPU/disk, so a customer picks "Basic 1GB" ($14.00/mo) or Key Value "Standard" ($21.00/mo) without being told it costs anything. It is the one purchase decision in the dashboard that is not priced at the point of choice.

Found live in `/qa-find-bugs` pass 206 on 2026-09-26 (w4-targeted, `muse.env` credentials). Read-only against the deployed `726042a28`; nothing was created or submitted.

| Surface | Prices shown |
| --- | --- |
| `/services/new` plan cards | `$0.00/month`, `$4.90/month`, `$17.50/month`, `$59.50/month`, `$122.50/month`, `$157.50/month`, `$315.00/month` ✅ |
| `bex.co/pricing` | Postgres `Free $0 · Basic 256 MB $4.90 · Basic 1 GB $14.00`; Key Value `Free $0 · Starter $7.00 · Standard $21.00` ✅ |
| `/?new=database` → **Instance type** options | `Free — 256 MB RAM, 0.1 CPU, 1 GB` · `Basic 256MB — 256 MB RAM, 0.1 CPU, 1 GB` · `Basic 1GB — 1 GB RAM, 0.5 CPU, 5 GB` ❌ no price |
| `/keyvalue/new` → **Instance type** radios | `Free 128 MB RAM · 0.1 CPU` · `Starter 256 MB RAM · 0.1 CPU` · `Standard 1 GB RAM · 0.5 CPU` ❌ no price |
| GraphQL `{instanceTypes{id monthlyUsd}}` | `monthlyUsd` per tier (`"4.90"` … `"315.00"`) ✅ |
| GraphQL `databaseInstanceTypes` / `keyValueInstanceTypes` (introspected field set) | `cpu id memory name storageGB`, with **no `monthlyUsd` field** ❌ |

The dashboard cannot show a price it is never sent.

## Mechanism

- `lego/backend/internal/apps/service.go:1321`: the service `InstanceTypes` fills `MonthlyUSD` from `pricing.Default.InstanceMonthlyUSD(id, store.ResourceKindService)`.
- That helper (`lego/backend/internal/pricing/monthly.go:32`) already handles `store.ResourceKindPostgres` and `store.ResourceKindKeyValue`, from the same `pricing.yaml` rows that `bex.co/pricing` and billing use (`postgres basic-256mb` $4.90, `basic-1gb` $14.00; `keyvalue starter`/`standard`).
- `lego/backend/internal/postgres/tiers.go:46` and `lego/backend/internal/keyvalue/tiers.go:45` build their instance-type lists without calling it. Their GraphQL types (`postgres/graphql.go` `DatabaseInstanceType`, `keyvalue/graphql.go:121` `keyValueInstanceTypes`) therefore declare no price field.

## Fix

1. Add `MonthlyUSD` to `DatabaseInstanceType` and `KeyValueInstanceType`, filled from `pricing.Default.InstanceMonthlyUSD(id, store.ResourceKindPostgres|ResourceKindKeyValue)`, and expose it as `monthlyUsd` (String, same `"0.00"` formatting as the service type). This keeps one price sheet, with no dashboard-side copy (the same rule `apps/service.go:1310` states for compute).
2. Render the price in every datastore picker with the service picker's `/month` formatting:
   - `dashboard/src/features/databases/components/create-database-dialog.tsx` and `dashboard/src/routes/keyvalue.new.tsx`: the create forms probed above.
   - `features/databases/components/database-plan-section.tsx` and `features/keyvalue/components/key-value-plan-section.tsx`: the plan-change pickers on an existing datastore (same hooks, `use-database-instance-types.ts` / `use-key-value-instance-types.ts`).
3. Tests:
   - Backend: each datastore list's `monthlyUsd` equals `pricing.Default.InstanceMonthlyUSD` for every tier, and free is `"0.00"`.
   - Dashboard: each picker renders the fetched price for a paid tier, and renders no fabricated price when the field is absent.

## Done (2026-09-27)

- **Backend:** `DatabaseInstanceType` and `KeyValueInstanceType` now carry `MonthlyUSD`, filled from `pricing.Default.InstanceMonthlyUSD(id, ResourceKindPostgres|ResourceKindKeyValue)`: the one price sheet `bex.co/pricing` and billing read, with no dashboard-side copy. It is exposed as GraphQL `monthlyUsd` on both types ("" for an unlisted tier). Tests: every tier equals the sheet, Postgres free/basic-1gb = `0.00`/`14.00`, and Key Value free/starter/standard = `0.00`/`7.00`/`21.00`.
- **Dashboard:** both instance-type queries select `monthlyUsd` (codegen from a fresh schema dump) and the view types carry it. The three `PlanCardGrid` pickers (Key Value create, Key Value plan change, Postgres plan change) now render the existing `common.pricePerMonth` label. The Postgres create dialog's options append " · $14.00/month". Both plan-change confirms add "The new plan costs $7.00/month." (en + zh). An unlisted tier shows no price.
- Tests: the Key Value plan-section card price and confirm price, the Postgres create option price, and fixtures updated. Backend postgres/keyvalue/api tests + golangci-lint and dashboard `yarn lint` + `yarn test` (448 files / 3728 tests) are green.
