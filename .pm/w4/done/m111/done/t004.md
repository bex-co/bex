## Result, 2026-09-18 — applied

Two duplications the milestone would otherwise have created were graduated
instead, in the same diff:

- **`ScopeSelect` is now shared.** It was private to `env-group-actions.tsx`
  (Move + Clone). Rather than re-implement the picker in the create dialog, it
  moved to `dashboard/src/features/env-groups/components/scope-select.tsx` and
  all three dialogs render the one component — so the option set and its labels
  cannot drift between minting a group and relocating one.
- **The scope-compatibility rule is now one function.** `linked-services-card.tsx`
  had `isCompatible` inline (`serviceEnvironmentById.get(id) ?? null ===
  group.environmentId`), and the create dialog needed the identical predicate.
  Both now call `serviceMatchesScope` / `serviceMatchesGroupScope` from the new
  `dashboard/src/features/env-groups/lib/scope.ts`, which also owns
  `WORKSPACE_SCOPE` and the `scopeValue`/`scopeEnvironmentId` sentinel
  conversions the Select needs (a lib file, not the component file, because
  `react-refresh/only-export-components` forbids non-component exports there).

Behavior-identical: the dashboard suite (3510 tests), typecheck and lint are
green before and after.
