## Objective

Render's apps are "automatically configured to connect to your database". pgAdmin takes no connection URL, so register the server for it; PgHero needs `pg_stat_statements` for its query pages.

## Steps

1. For pgAdmin, add a secret file `servers.json` (one server: the database's internal host, port, database and user) and a passfile, and point `PGADMIN_SERVER_JSON_FILE` (and the server's `PassFile`) at them, unless t001 shows Render does it differently.
2. For PgHero, confirm `pg_stat_statements` is preloaded and created on bex databases (the Postgres observability top-queries already read it); if a database lacks the extension, PgHero's other pages still work and the dialog says what is missing, as t001 records Render saying.

- the admin-app file from t003
