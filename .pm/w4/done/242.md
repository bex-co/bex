## Cause and bounded work

- `dashboard/src/features/env-groups/components/new-env-group-dialog.tsx:108` uses the shared grid dialog without a bounded column. The form returns sibling grid items, including the Linked Services section and footer.
- That component's service grid at **577**, row at **581**, and Label at **593–603** contribute name and immutable ID side by side. `common/components/ui/label.tsx:14` supplies `flex items-center gap-2`; `block` on the child spans does not stack flex items. The label's `min-w-0` alone does not bound the containing implicit auto grid track.
- `common/components/ui/dialog.tsx:63` supplies grid, padding and frame cap without an explicit column. The live computed track is 391.922px. The [CSS Grid automatic minimum rules](https://www.w3.org/TR/css-grid-1/#min-size-auto) explain its intrinsic contribution. The pinned Tailwind **4.1.18** code at `dashboard/node_modules/tailwindcss/dist/chunk-CT46QCH7.mjs` was opened: `grid` sets display only, `grid-cols` sets grid-template-columns, and `flex-col` sets direction. No Radix or API defect is asserted.

**Browser-only prototype, restored:** setting this dialog's column to `minmax(0,1fr)` reduced the track to308 but still left scrollWidth399. Additionally stacking the local service labels, bounding label width and child max-width, produced **356/356**, track308 and Create right349. Removing those temporary styles restored **356/440**. A grid-only fix is insufficient for the observed rows.
