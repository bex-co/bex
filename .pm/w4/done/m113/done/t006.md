## Objective

Hold the t001–t004 behavior with tests that fail if any leg regresses to the empty state — builder-level for the PromQL selectors, config-level for the shipper, verb-level for the surfaces.

## Context

Each of t001–t004 ships its own unit coverage; this task is the cross-leg net: a static App must never again silently read empty on requests while bandwidth works, and a compute App must never pick up the static selectors.

## Fix shape

- Metrics verb tests (extend `lego/backend/internal/metrics/*_test.go`, no new files): a static-type App fixture asserting the requests/latency/filter queries carry the router scope (assert on the built query / injected-source request, not on live Prometheus); a web-service fixture asserting today's service-scoped queries byte-identical.
- The bandwidth-static test already passing stays the untouched control (assert it in the same run so a shared refactor can't break it silently).
- Shipper coverage lives in t004; this task only cross-checks that `logs-verify.sh` (or its successor) covers a static `ServiceName` — file a follow-up instead of expanding scope if the script can't express it.
- Mutation spot-check per repo convention: break one selector and watch the suite fail (the useless-tests routine's bar).

## Result, 2026-09-18

Cross-leg net added to `internal/metrics/metrics_test.go` (extended, no new
file):

- `TestStaticSiteRequestMetricsSelectRouterSeries` — for both
  `http_requests` and `http_latency`: the service resolves the App's routers
  for a static request read (not only for bandwidth), marks the read
  router-scoped, and the built query selects `traefik_router_*` anchored to
  `router=~"^(default-site-site-onbex-co@kubernetes)$"` with no
  `traefik_service_` left in it.
- `TestComputeRequestMetricsKeepTheServiceSelector` — the compute query is
  byte-identical to today's, and no Ingress list is performed for it.
- `TestStaticSiteWithoutRoutersBuildsNoQuery` — the anti-leak rule, on both
  metrics and on filter discovery.
- `TestStaticSiteStatusCodeDiscoveryUsesRouterSeries` — discovery reads the
  same router series the chart does, returns the observed codes, and leaves
  `INSTANCE` honestly empty.
- `TestBandwidthMetricResolvesExactIngressRouters` (pre-existing) runs in the
  same package as the untouched control.

**Mutation spot-check** (the useless-tests bar): making `routerScopedRequests`
return `false` fails 7 assertions across the new tests; restoring it returns
the package to green.

Shipper coverage lives in t004 and is likewise config-reading, not a copy.
`scripts/logs-verify.sh` still exercises `APP_NS=default` only; extending it to
a static fixture needs a live cluster, so it is deliberately NOT expanded here
— the Go-level guard over the real ConfigMap is the durable one, and
`scripts/request-logs-liveness.sh` remains the out-of-band probe.

Gates: `cd lego/backend && go test ./...` green (all packages), `make lint` 0
issues across all four modules, `bash scripts/gitops-validate.sh` PASS.
