## Objective

## Context

[UUID evidence and root cause](uuid-finding.md) includes fresh-page UI reproduction, full raw adapter probes, pinned driver types and positive controls.

## Steps

2. Test native UUID and UUID[] through the real decoding path; include NULL, bytea and integer-array controls. Cover writable RETURNING locally, not through production table writes.
3. Include these SELECTs in t003 live parity and t005 regression coverage; preserve special numeric/temporal results and encoded budgets.
