## Objective

A restart selects the running release's recorded shutdown delay, port and pre-deploy command; a rollback selects the target's. A record without them falls back to the saved spec and is logged, as the existing image-only fallback is.

## Context

- `deploys/rollback_config.go:44-70` (`targetReleaseConfig`) builds `ReleaseConfigReference` from the record; `ReleaseConfigReference` is at `lego/types/v1alpha1/releasesnapshots.go:161`.
- Render's Restart (render.com/docs/deploys § Restarting a service): "the new instance always uses the exact same Git commit and configuration as the running instance at the time of the restart."
- Render's rollback page does not cover these three fields; selecting the target's recorded values follows the rule ADR004 already applies to the start command and health path.

## Steps

1. Carry the three values through `ReleaseConfigReference` and have the operator project them onto the release instead of the saved spec.
2. Decide from Render's Restart text whether a restart runs a pre-deploy command at all; if Render's pages do not say, keep bex's current choice and record it as unverified.
3. Envtest: save port 9000 without deploying, restart → still the old port; normal deploy → 9000.

## Done (2026-11-16)

- bex-api `targetReleaseConfig` copies the record's `runtime` into `spec.releaseConfig.runtime` and logs when the record predates it. The operator copies the selection's value into the new release's record (`ensureSelectedReleaseConfig`), and `projectRuntimeApp` applies it to the template (shutdown delay). `App.RuntimeSpec` gives the serving port (`releaseRuntimeSpec` in Reconcile, image networks, `explicitServingPort`), `ServingPort`/`ConfiguredImagePort` and `PreDeployStepCommand`. A port mode applies only within its family (configured or image ports).
- Pre-deploy on Restart: Render's deploys page (read 2026-11-16) does not say whether a restart runs it. bex already ran a pre-deploy step on Restart, and that choice stays; it now runs the running release's command. A rollback runs the target's command. Both are recorded in ADR004/ADR018 as bex's unverified choice.
- Envtest: after saving port 9000, a 40 s delay and `echo two`, the Restart runs `echo one` on port 3000 with the old grace. The next deploy runs `echo two` on 9000 with grace +10. A rollback to generation 1 runs `echo one` on 3000 while saved reads stay 9000.
