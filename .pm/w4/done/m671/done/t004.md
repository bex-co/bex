## Objective

Prove the check end to end with an image that really disappears: push a small image to `ttl.sh/<random>:1h`, deploy it, and wait for it to expire.

## Context

- `ttl.sh` is an anonymous registry whose tags expire after the tag's duration.
- `bash scripts/dev-env.sh 4 up`; production as the QA user in a fixture workspace from `scripts/lib/first_party_workspaces.txt`.
- Shorten the interval for the walk with an operator flag or environment variable if t002 adds one; record the setting used.

## Steps

1. Deploy the `ttl.sh` image to a web service and check it serves.
2. After expiry, read `ImageAvailable`, the event on REST, GraphQL and MCP, the webhook delivery and the email (Mailpit on dev-4).
3. Push the tag again, read the recovery, then delete the service. Record the walk in the milestone README.
