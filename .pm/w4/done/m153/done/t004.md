## Objective

Align API/runtime state and persistence copy with the safe transition, retaining explicit bex/Render differences.

## Context

REST/GraphQL/MCP currently agree on desired mode and available while the runtime keyspace is stale. UI promises data kept for every save. Render warns about transitions involving Off, and free persistence is deliberately different in bex.

## Steps

1. Replay the complete three-surface reads/writes and verify state distinguishes acceptance, conversion, failure and completion without breaking Render-compatible wire forms.
2. Compare current official Render persistence behavior; preserve bex's documented durable Free default. Make en/zh copy accurately distinguish durable transitions from intentional Off data loss and required restart.
3. Update ADR021/ADR018 runtime-transition notes and references to the restore precedent. Record unobserved Render UI behavior explicitly.
