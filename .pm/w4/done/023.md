# Auth-gate introspection concurrency + unmetered public device routes

← filed by `w4/m27/t007`'s simplify pass 2026-07-15 (real findings judged too subtle/design-laden for an inline closing-task fix on the freshly production-verified auth gate).

1. **`revocationMu.RLock()` held across the Hydra introspection round trip** (`internal/api/auth.go`, `introspectUpstream`). `sync.RWMutex` blocks new readers once a writer is pending, so one `invalidate` (CLI logout — rare but caller-triggerable at will) arriving while any cache-miss introspection is in flight stalls every new cache-miss introspection process-wide for up to the 5s client timeout. Proposed shape: an atomic revocation epoch — snapshot before the upstream call, run the HTTP round trip lock-free, and under one short lock `Put` only if the epoch is unchanged; `invalidate` bumps the epoch inside its delete critical section. Preserves the "an older in-flight positive result cannot resurrect a revoked entry" invariant while dropping lock hold time from network-RTT to a map write; also lets the singleflight closure return the identity directly, removing `introspect`'s second cache lookup. Needs focused concurrency review + the existing cache-invalidation race tests extended — not a drive-by edit on the hottest path in the binary.

2. **The three public device-flow routes are unmetered upstream amplification** (`internal/cliauth`, `POST /v1/device-grant|device-token|token/refresh/`). They mount outside the rate limiter (which keys on resolved `Identity` — anonymous callers would all share one bucket), and each anonymous hit costs one full Hydra round trip; the official CLI legitimately polls `/v1/device-token` during login. A fix needs an IP-keyed token bucket (or Hydra-side limits) — a design decision, not a cleanup.

Also noted, declined with reasons recorded in `done/m27/done/t007.md`: `Identity.Human` derivability, `RevokeHandler` conjunct collapse (defensive explicitness on a security path), bootstrap/E2E script cosmetics (the scripts are freshly captured production evidence — cosmetic rewrites would invalidate the verified state without re-running the browser ceremony), `core.NewOryClient(timeout)` consolidation (codebase-wide, predates the diff).
