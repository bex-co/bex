## Objective

Retain and select the exact successful static publication independently of current saved output settings.

## Context

See [the researched finding](../finding.md) for the exact failing rollback, same-target control, source trace and live-unverified branches.

## Steps

1. Capture actual prefix, layout and stored release generation after successful publication; reuse existing immutable release bookkeeping where appropriate.
2. Introduce an internal static-publication selection that supports both image-backed and direct targets; do not rely on image-required runtime references for prefix-only targets.
3. Select the named target's retained metadata in Service.Rollback without changing saved settings or non-static selection.
4. Define provable legacy target resolution and a named pre-dispatch unavailable-artifact refusal.
