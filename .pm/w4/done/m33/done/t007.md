## Resolution (2026-08-15)

Cross-surface consistency holds. `Steer` (t002) and the postgres user verbs (`DeleteUser`, t005) each have a single `service.go` implementation behind one relation, with thin REST/GraphQL/MCP fragments — `TestAuthzGuardsEveryVerb` + `TestFetchByNameUsesTheVerbsOwnRelation` pin the relation; error shape stays Render-dialect on REST and native on GraphQL/MCP by construction. The device-flow change (t004) is dashboard-only. No new drift from render.com.
