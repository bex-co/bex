## Objective

Expand a `*` anywhere in a route destination to the string the source's `*` captured, keeping the existing `:splat` and `:name` expansion and its size limit.

## Context

- `lego/operator/internal/staticserver/staticserver.go:1022-1047`: `trailing` handles only a destination ending in `/*`; `maxExpandedRoutePathBytes` bounds the result.

## Steps

1. Replace the trailing-only branch with an expansion of each `*` in the destination.
2. Keep the size check before writing.

## Files

- `lego/operator/internal/staticserver/staticserver.go` and its tests

## Acceptance criteria

- [x] `/old-*` → `/new-*` sends `/old-page` to `/new-page`; `/*` → `/*/index.html` rewrites `/docs` to `/docs/index.html` (test).
- [x] An expansion over the size limit is refused as today (test).

## Out of scope

- External destinations' query handling (w8/184).

## Result

2026-11-27: `substituteCaptures` expands each `*` in the destination path: the nth `*` takes the source's nth capture (the last past the source's count), `:splat` the first. The size bound is computed before writing, as before. `TestRouteDestinationWildcardExpandsInPlace`, `TestRouteDestinationWildcardKeepsTheExpansionBudget` and `TestRouteWildcardRulesServeLikeRender` (HTTP: `/old-page` 301s to `/new-page`, `/guides/intro` serves `intro/index.html`).
