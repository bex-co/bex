# Expose the active project resource-type filter

Why: customers using assistive technology cannot discover which resource type is active because selection exists only in button styling.

**Status:** done — a889, 2026-10-17, passes the remaining native390px Space and fresh1440px URL-kind accessibility-tree replay, with search and other activation controls. **Severity:** minor. **Estimate:**45m. Ordinary functional QA a834, 2026-10-17 UTC, research main b9acddc64073e9b3284766e412001869da90add7. Filing only. Supports ADR008's dependable dashboard and ADR018's project-management surface.
