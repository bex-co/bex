# w4/199 — BLOCKER: deploys red since `d1e4c9315` (w4/m172): non-member by-id reads now 404, but ADR072 #8 and the w6/m24 e2e test require 403

Why: every deploy of `main` since the m172 commit fails `test-backend`, so the already-merged fixes for w4/m172, w4/196 and w4/m173 (and anything after) cannot reach production.

Evidence (2026-10-05 UTC, GitHub Actions `deploy.yml`):

- `d1e4c9315` (05:05) **failure** and `44a612e8d` (05:15) **failure**, both in `test-backend / backend`. `e2510371c` (05:26) was in progress at 05:30 with the same test in tree.
- The failing test is the same in both runs: `TestEnvGroupReadSideOwnerIDTargetingE2E` (`lego/backend/internal/api/envgroups_ownerid_e2e_test.go`). Failures quoted from the run log:
  - `:150` — `erin GET /v1/env-groups/evg-…: 404, want 403`
  - `:157` — `erin reveal bravo's TOKEN: 404, want 403`
- Production is still on pin `8f58b933d748`.

Cause:

- `d1e4c9315` (`core.Base.ScopeByID`) makes a non-member's by-id read answer **404**, "the same 404 as missing".
- That came from w4/m172's Definition of done, "Adjacent classes: a non-member's id returns the same 404 as a nonexistent id on every family". That bullet was **wrong**: `docs/ADR072-security-review-round7.md:18` finding #8 records the deliberate decision "all-denied name sweeps collapse to 404; **typed-id 403 stays**".
- The w6/m24 e2e test (`c798a3dee`) pins exactly that typed-id 403.

Fix (pick one, then make CI green):

1. **Recommended:** keep ADR072 #8. In `ScopeByID`, answer a typed-id non-member with **403** (the resource exists in a workspace the caller doesn't belong to); keep 404 for genuinely missing ids. Leave the w6/m24 test as-is and update any m172 tests that asserted 404 for non-members.
2. Or deliberately reverse ADR072 #8: amend the ADR with the rationale, then update `envgroups_ownerid_e2e_test.go:150,157` and every other typed-id 403 assertion to 404 in the same change.

Also: correct w4/m172's README "Adjacent classes" bullet to the chosen rule (done for option 1 in this filing), and re-run the deploy so w4/m172, w4/196 and w4/m173 reach production.

Severity: blocker (deploy pipeline). Estimate: ~30m.
