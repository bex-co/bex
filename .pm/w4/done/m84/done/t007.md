## Objective

Prove that no supported path serves an unverified hostname and that migration, races, verification, projection, and user surfaces converge correctly.

## Context

The dangerous failures are cross-layer: a database row is pending while a CR/Ingress serves it, a stale DNS result promotes a replacement row, or Blueprint/create bypasses direct-add checks. Coverage must include real Postgres, fake resolver, reconciler, adapters, and dashboard behavior rather than only one service unit test.

## Steps

1. Add migration and real-Postgres tests for backfill, uniqueness, idempotency, and concurrent claim/promotion.
2. Add apps/reconciler tests for add/create/Blueprint/delete, wrong/correct TXT, stale verification, and verified-only projection.
3. Add REST/GraphQL/MCP contract tests and dashboard hook/component tests for instructions and state transitions.
4. Run backend, operator/types, and dashboard suites plus lint in proportion to changed modules.

## Files

- `lego/backend/internal/store/{migrate_test.go,store_pg_test.go,reconciler_test.go}`
- `lego/backend/internal/apps/domains_test.go`
- `lego/backend/internal/apps/domains_test.go` (cross-surface contract cases)
- `dashboard/src/features/services/components/__tests__/custom-domains-section.test.tsx`
- new/updated custom-domain hook tests

## Acceptance criteria

- [ ] A regression that includes pending rows in desired hosts fails a test.
- [ ] All write paths are covered; wrong/stale proof cannot promote.
- [ ] Existing domains survive migration as active and verified.
- [ ] Cross-surface fields/errors and dashboard copy/interaction are pinned.
- [ ] Relevant Go and dashboard test/lint suites pass.

## Out of scope

- Live registrar automation; a fake authoritative resolver is sufficient for deterministic CI.
