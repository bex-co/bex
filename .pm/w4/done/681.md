# 681 — A Postgres's Access control grows 58 px when its credentials load: the Credentials list has no row placeholder, so the pending frame omits the default credential row

Why: the dashboard rule ([AGENTS.md](../../AGENTS.md), "Dashboard preloading skeletons must match their post-loading contents") asks a pending state to keep the ready panel's regions at stable heights. Every Postgres has at least its default credential, so the ready list's first row is known in advance.

- **Source / severity / estimate:** the w4/m315 t003 live re-check, 2026-11-16 06:20–06:30 UTC, pin `971a79648213`, workspace `bex-canary`, a public Free Postgres (`qa-20261115-m315-pg2`, deleted afterwards). **Minor** (layout shift below the allowlist; nothing is lost). ~30m.
- **Probe:** reload `/d/<id>#access-control` with the batched GraphQL request that carries `DatabaseIpAllowList` and `DatabaseCredentials` held 8 s. At 1440 the Access control card is 670 px pending and 728 px ready; at 390 it is 926 → 984 px. The IP allowlist section is identical in both frames (348 / 496 px, two rule-row placeholders → the two rule rows, after w4/m315 t008). The whole 58 px is the Credentials section: pending it draws the heading, hint and the "New default credential" row with an empty list; ready adds the `<username> Default` row (50 px + gap). Without the hold the same jump happens at ~3.5–4.2 s.
- **Cause:** `CredentialsSection` maps `access.credentials` straight into the `<ul>` (`dashboard/src/features/databases/components/access-control-panel.tsx:157-158`), and `useAccessControl` maps a missing `credentialsQuery.data` to `[]` (`dashboard/src/features/databases/hooks/use-access-control.ts:72`), with no pending flag for the credentials read (only `allowListPending`, `:191-192`).
- **Fix:** expose `credentialsPending` (first read in flight, no data) from `useAccessControl`, and draw one credential-row placeholder at the ready `<li>`'s geometry (bordered row, username + badge skeleton, delete-button skeleton) while it is pending. Test it next to t008's `access-control-panel.test.tsx` cases.
- **Done when:** on production, the same held reload shows the same Access control card height pending and ready at 1440 and 390, with one credential-row placeholder where the default credential lands; dashboard `yarn lint` and `yarn test` pass.
