- **Source / estimate:** follow-up from w4/m378 (2026-11-14). **Minor** (parity). ~20m.
- **Fix:** check whether the MCP pin test already flags it; accept the argument (bex has no previews, per `DO_NOT_DO.md`, so it filters nothing) or record the divergence in ADR018.
- **DoD:** `list_services {"includePreviews":true}` is accepted and returns the same list.

- **Closed 2026-11-14 (/loopx w4):** the pin did flag it, as an accepted divergence (`mcpAcceptedDivergences["list_services"]`, `lego/backend/internal/api/mcp_parity.go:102` before this change), but the premise held: a call carrying `includePreviews` was refused by input validation. `list_services` now takes an optional boolean `includePreviews` (Render's type) and lists the same services either way, since bex has no previews (`.pm/DO_NOT_DO.md`); the accepted divergence is removed and the tool counts as `Parity1to1` (15 1:1, 2 Divergent).
