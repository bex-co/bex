## Repro (production, pin `a3f66521f93d`)

Static site from `https://github.com/bex-co/bex`, branch `main`, `rootDir: examples/static-site`, `publishPath: .`, build command `mkdir -p blog && printf "blog-v8p1\n" > blog/index.html`. It reached Live, then:

```

GET /blog        -> 200  body: <!doctype html> <html lang="en"> …   (root index.html)
```

## Root cause (unchanged since the original filing; line numbers re-read on `main`)

- `lookupPath` (`lego/operator/internal/staticserver/staticserver.go:456-460`) defaults to `index.html` only for `/` or a path ending in `/`, so `/blog` misses as the object `blog`.
- `spaFallback` (`:466+`) then serves the root `index.html` for any extensionless miss, without checking `<path>/index.html` first.
- The rewrite branch's `h.fetch(fallbackPath)` has the same gap.

## Fix, acceptance, unverified

These are unchanged from the original filing; see `.pm/w4/done/377.md` from "## Fix (target behavior)" to the end of "## Unverified":

- `/blog` with `blog/index.html` → 301 `/blog/`, with the query preserved and `/blog/*` headers applied.
- A rewrite to a directory → 200 with the directory's index.
- The SPA fallback, 404 for extension-bearing misses, cache keys and error classes stay unchanged.
