# Environment-group scopes hide the parent project of same-named environments
Why: a workspace can contain several environments named Production; customers need the project name to choose and verify where shared configuration belongs.

- **Source / severity / estimate:** continuous live `qa-find-bugs`, user-selected w4, 2026-10-08 cycle 8; **minor**, 55m. ADR008 pillar 1, ADR032 environments, ADR006 / ADR018 dashboard contracts. Filing only.
- **Repro:** in the QA workspace create projects `qa-20261008-c8-project-a-a8f1` and `qa-20261008-c8-project-b-a8f1`, each with an environment named `qa-c8-shared-a8f1`. On `/env-groups`, New Environment Group → Environment presents two identical options. Choose the first and create `qa-20261008-c8-group-a8f1`; the API places it in A. Manage → Move group again shows both identical options; choose the second, and the API moves it to B while the selected label and Group Metadata remain the same bare name. After a fresh load, Manage → Clone group, workspace bex, waits for the scope index and again offers both identical names; choosing the first creates `qa-20261008-c8-clone-a8f1` in A. A fresh collection load shows the original in B and clone in A with identical Environment cells. A fresh original-detail Move dialog at 390×844 reproduces both identical visible and accessible option names; desktop is 1440×1000. No project title or aria-label disambiguates them.
- **Expected / actual:** the workspace-wide options, selected scope and saved scope displays identify **Project / Environment**. Actual labels contain only the environment name. IDs and mutations work; this is ambiguous presentation, with no observed data loss, permission bypass or incorrect backend assignment. The sweep chose by ordinal using independently verified IDs; that is not a reasonable customer workflow.
- **Root cause:** `dashboard/src/features/env-groups/components/scope-select.tsx:44` iterates the workspace environment array but `:46` renders only `environment.name`; its props (`:19`) do not receive projects. These are three traced presentation paths, not a claim that metadata is rendered by ScopeSelect.
