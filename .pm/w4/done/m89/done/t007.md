## Objective

Lock the distinctions this milestone introduces so they cannot collapse back into one 503.

## Context

- The original bug is a _collapse_: many causes, one message. The regression test must therefore assert that two different causes render **different** copy — asserting each one in isolation would still pass if they were merged again.
- The state bug is a _false negative_: failure copy during a healthy phase. Assert absence, not just presence.

## Steps

1. Backend: a test per cause group asserting its code, including one asserting two distinct groups do not share a code.
2. Dashboard: assert not-configured and dependency-unavailable render different text.
3. Assert no failure copy renders in `Creating`.
4. Assert the send button label across states.

## Files

- `lego/backend/internal/agentsessions/*_test.go`
- `dashboard/src/features/agent-sessions/components/__tests__/`

## Acceptance criteria

- [ ] A test fails if two cause groups are given the same code or copy.
- [ ] A test fails if failure copy reappears during `Creating`.
- [ ] Verified by actually reverting each fix and seeing the matching test go red.
