## Objective

Stop returning one undifferentiated 503 for seventeen different causes, so a caller can tell a misconfiguration from a transient fault.

## Context

- `lego/backend/internal/agentsessions/service.go` returns `core.ErrAgentSessionsUnavailable` from **17** sites. They span at least four genuinely different situations:
  - **not configured** — `enabled()` / `modelProxyEnabled()` / `ticketEnabled()` are false because `BEX_AGENT_SESSION_GATEWAY_URL`, `BEX_AGENT_SESSION_IMAGE` or `BEX_SHELL_TICKET_SECRET` is unset. This is the only one the current copy describes.
  - **dependency unavailable** — e.g. `establish agent session authorization: %v` when OpenFGA cannot be reached.
  - **workspace not ready** — `read agent session model key: %v`.
  - **snapshot store unavailable** — `prepare snapshot restore` / `delete session snapshot`.
- Existing agent-session codes (`AGENT_SESSION_INPUT_INVALID`, `_NOT_FOUND`, `_NOT_RESUMABLE`) show the established naming and the ADR006 dialect to follow.

## Steps

1. Enumerate all 17 sites and group them by cause; write the grouping down in the milestone as the reviewed decision.
2. Add coded errors per group — keep 503 for the retryable ones and pick the honest status for the rest.
3. Convert each site to its group's code, preserving the existing wrapped detail for logs.
4. Keep `ErrAgentSessionsUnavailable` working as the not-configured case so nothing silently changes meaning.

## Files

- `lego/backend/internal/agentsessions/service.go`
- `lego/backend/internal/core/errors.go`

## Acceptance criteria

- [ ] Every one of the 17 sites returns a code naming its cause.
- [ ] A retryable fault is distinguishable from a permanent misconfiguration by code alone.
- [ ] Detail stays in logs; no internal path or dependency hostname leaks into the client-visible message.
- [ ] Existing agent-session tests still pass.
