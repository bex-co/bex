## Objective

Selecting either Connect remedy dismisses the menu, preserves its intended destination, and releases modal focus/pointer restrictions before the destination becomes interactive.

## Context

`SshUnavailable` renders a plain TanStack Link inside an uncontrolled Radix modal menu. The header survives service-tab navigation. The Link navigates, but no menu-item selection closes the Root; both remedy targets retain the modal overlay.

## Steps

1. Use the existing menu selection primitive for the remedy Link (for example `DropdownMenuItem asChild`) or an equally scoped explicit close handler. Verify actual TanStack Link event composition and Radix selection, including the hash destination. Do not disable modality globally or remount the persistent service layout.
2. Check both plan and resume targets in a real client-router component test: navigation alone is insufficient; the old menu must close, the destination must become accessible, and the body lock must be released.
3. Retain sensible focus behavior during pending navigation and after the ready state. Preserve Copy internal address/SSH command interactions; copying should not accidentally become navigation. Put same-destination, modifier-click and paid CTA cases into t003 verification rather than assuming a pathname-only effect handles them.
