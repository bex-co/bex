## Objective

Both fixes in this milestone change shared code with several callers, and in both cases some callers behave correctly **today** — which means they are correct because of current behavior and need regression coverage too, not just the broken ones. Enumerate the callers, cover every one, and prove the guarantees that must survive.

## Context

`rollout.Tracker.record` (`lego/backend/internal/rollout/rollout.go:161`) is the single writer of the empty `CommitInfo`. Its callers, from `grep -rn "Rollout.Patch\|Rollout.Open\|patchTracked" lego/backend/internal`:

If the fix lands inside `PGStore.CreateDeploy` instead, the caller set widens to every `CreateDeploy` call site — `deploys/service.go:569`, `apps/service.go:2908`, `apps/deploy.go:2861`, `rollout.go:161` — each of which passes a **resolved** commit today and must keep winning over any inherited one. Enumerate whichever set the chosen layer implies; do not assume.

### t001's guarantees that must not regress

From `.pm/w1/done/m67/done/t002.md`, the criteria that exist to stop Ory amplification:

- a flood of unique invalid bearers from one source is shed, with upstream introspection call count asserted bounded;
- the same flood behind a trusted proxy keys on the forwarded client IP, not the proxy's;
- oversized credentials are refused before any upstream call;
- rate-limit response shapes stay Render-compatible.

These are the control cases: they pass today and must still pass. The criterion that does **not** hold today — "a valid caller's requests are unaffected" — is what t001 fixes and what needs a new test.

## Steps

1. Write one test per `rollout.Tracker` caller asserting the commit it records. Include the callers that are already fine under the chosen design, so a later refactor cannot quietly drop the inheritance for one path.
2. Write the image-backed control: same call sites, no repo, still no commit.
3. Write the valid-caller concurrency test for t001 (N concurrent authenticated requests, all admitted) and keep it deterministic — drive the admission bound directly rather than racing real goroutines against wall-clock, or the test will be the next flake.
4. Re-run `w1/m67`'s existing admission tests unchanged and record that they pass.
5. Add a test that an admission shed and a rate-limit shed are distinguishable on the wire (the t001 step-4 contract the dashboard keys on in t003), so the two cannot silently re-converge.
