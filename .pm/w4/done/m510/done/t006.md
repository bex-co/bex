## Objective

Prove the definition of done on dev-4 with real build sources, a real failed pull and a webhook receiver.

## Context

- `bash scripts/dev-env.sh 4 up`; `scripts/webhooks-verify.sh` for the receiver.
- A pull failure can be induced by deleting the build's image from the build registry before a deploy of that build; find the least invasive way and record it.
- Evidence is text in this task's Outcome (`.pm/DO_NOT_DO.md` #NO-ARTIFACTS-IN-GIT).

## Steps

1. Create two build sources and a web service; link, relink and unlink it; read the events on REST, GraphQL and MCP and the webhook deliveries.
2. Change the service's repository branch as a control (`source_changed`).
3. Deploy a build whose image cannot be pulled; read `artifact_fetch_failed` and confirm no `image_pull_failed`.
4. Delete every fixture and record the evidence.
