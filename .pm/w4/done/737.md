# Cloudflare's published edge ranges are watched by nothing, though the edge trusts Cloudflare's headers by them

Why: The edge keeps Cloudflare's `CF-Connecting-IP`, `CF-IPCountry` and `CF-Ray` only from an address in `cloudflareRanges`. If Cloudflare adds a range, every request through it to `bex.co`, `api.bex.co`, `dashboard.bex.co` and a tenant's own Cloudflare-proxied custom domain reads the edge's address as the client. If w4/m687 t004 restores Render's refusal of a `CF-Connecting-IP` from outside Cloudflare, those requests are refused `403` instead.

- **Today:** `deploy/gitops/charts/traefik-plugins/clientipheaders/clientipheaders.go` `cloudflareRanges` and `lego/backend/internal/core/proxiedhosts.go` were fetched 2026-10-02 from `https://www.cloudflare.com/ips-v4` and `/ips-v6`. `scripts/gitops-validate.sh` checks that the two copies agree, never that they match Cloudflare's list. They matched it on 2026-11-27 (checked by hand for w4/m687).
- **Do:** add a scheduled job, as `render-version-drift.yml` does for Render's version pages, that fetches both lists and fails, naming each added or removed range and both files, when they differ from the plugin's. Register its window with `ci-schedule-drift`'s script.
- **End state:** a range added to Cloudflare's list turns the job red within a day, and the job is green today.
- **Size:** about 45m.
- **Source:** w4/m687 t007, 2026-11-27.

**Done 2026-11-27 (`/loopx w4`):** the daily `.github/workflows/cloudflare-ranges-drift.yml` (04:37 UTC) runs `scripts/cloudflare-ranges-drift.sh`, which fetches `https://www.cloudflare.com/ips-v4` and `/ips-v6` and fails, naming each range Cloudflare added (`added by Cloudflare, missing here:`) or removed (`removed by Cloudflare, still trusted here:`) and both files, when either `cloudflareRanges` copy differs; a body that is not a CIDR list, an empty or unreachable list, or a renamed block fails with exit 2 instead of passing. Its window (40 h) is registered in `scripts/ci-schedule-drift.sh`, its self-test `scripts/cloudflare-ranges-drift.test.sh` (network-free, 18 cases, run against the committed Go files) runs in `scripts.yml`, and ADR022 names the job. Green today: Cloudflare's 15 IPv4 and 7 IPv6 ranges equal both copies (run by hand 2026-11-27). Reproduce: `bash scripts/cloudflare-ranges-drift.sh`.
