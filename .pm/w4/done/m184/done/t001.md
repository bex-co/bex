## Objective

Add an App status field (sibling of `undeployedChanges`) that is true only while a newer release is in flight (not canceled, not failed) and its configuration equals the saved configuration: compare against the in-flight release's record, or, before the record exists, a normal deploy that will snapshot the saved values. Restart (preserve group values) and rollback selections never carry saved settings.
