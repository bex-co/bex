## Root and concrete repair

`lego/operator/internal/build/native.go:89–91,111–113,243–269` selects the reviewed Go/Rust images and generates the native image. `nativepnpm.go:42–46` installs the primary-Node tools only for runtime node. In `nativeresolve.go:83–91,114–119`, the JS companion allowlist contains **ruby and python**, so Go and Rust receive no Node/npm/Yarn/pnpm layer before their authored builds. Both live executions and the Go exact-image execution agree with that code.

Extend existing companion eligibility to **Go and Rust** and reuse `addNativeJSTools/nativeJSToolLines` (`nativeresolve.go:133–146`) before source/build. Keep primary Go/Rust and their paths intact; copy the selected reviewed Node line and its npm, the existing Yarn1.22.22 supplier, and reviewed pnpm10.34.6. Reuse existing NODE_VERSION → .node-version → .nvmrc → package engines precedence and deterministic refusal rules rather than an installer, a new runtime, or a Go-version selector. This changes previously ignored Go/Rust-side Node-version signals; document that behavior as m77 does. Preserve Rust's existing rustup `RUSTUP_TOOLCHAIN` and rust-toolchain handling.

The predicate can express both runtimes without an API/schema change. Reviewed Go, Rust and Node bases are Bookworm images; prove the copied tools actually execute beside each primary compiler, including at runtime, rather than accepting generated-text assertions alone. Preserve exact authored PATH/env handling, command quoting, optional Bun, primary compiler behavior and stable/changed cache inputs. Keep Elixir unchanged until separately probed; Rust is now included because of a692's two failures and Live control.

The current regression guard explicitly forbids the needed repair: `nativeversion_test.go:510–522` asserts Go/Rust/Elixir do not gain `/usr/local/bin/node`. Replace the Go/Rust expectations with companion execution/selection coverage and retain the untouched Elixir control. Extend the existing real-image gate `native_test.go:1056` (`TestNativeImageRunsJSToolsBesideRubyAndPython`) to cover Go and Rust and retain its Ruby/Python controls.
