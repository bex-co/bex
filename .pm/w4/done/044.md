# 044 — Give Settings' Idle timeout dropdown an accessible name

Why: keyboard and screen-reader users can change this hosting setting, but the combobox does not identify which setting it controls.

Severity: **minor**. Estimate: **20m**. Source: repeated live `$qa-find-bugs w4` hunt, 2026-09-05, second run. Goal: accessible hosting configuration (ADR008); lifecycle context: `docs/ADR004-app-deployment.md` and `dashboard/src/features/services/lib/idle-timeout.ts`.

## Reproduction and durable evidence

1. Open a free web service's Settings page. Tested twice, including a full reload, at `https://dashboard.bex.co/services/srv-dae9jip88i5c7399e9a0/settings` (`qa-20260905-redeploy`, created for this run in `tian-personal`).
2. Inspect the real accessibility tree. The visible Idle timeout heading is followed by `combobox: Platform default`, without a name. In the same page, the neighboring controls are `combobox "Auto-Deploy"` and `combobox "Service Notifications"`.
3. Select `15 min`, then reload. The value persists, but the combobox remains unnamed. This is a labeling defect, not a failed save.

Repeatable browser probe (signed-in session; no credential output):

```js
const control = page
  .getByRole("combobox")
  .filter({ hasText: "Platform default" });
await control.ariaSnapshot(); // '- combobox: Platform default'
await control.evaluate((e) => ({
  text: e.textContent,
  ariaLabel: e.getAttribute("aria-label"),
  ariaLabelledby: e.getAttribute("aria-labelledby"),
  id: e.id,
  labels: [...(e.labels || [])].map((l) => l.textContent),
}));
```

Complete result: `{"text":"Platform default","ariaLabel":null,"ariaLabelledby":null,"id":"","labels":[]}`. After selecting the preset, substitute `15 min` in the locator; ARIA remains `- combobox: 15 min`.

Persistence control: POST `https://api.bex.co/graphql`, JSON body `{"query":"query { service(id:\"srv-dae9jip88i5c7399e9a0\"){id idleTTLSeconds} }"}`, browser credentials included. HTTP 200, complete response: `{"data":{"service":{"id":"srv-dae9jip88i5c7399e9a0","idleTTLSeconds":900}}}`.

Screenshot: `.playwright-mcp/qa-idle-timeout-2.png` (verified present; gitignored local evidence, so the replayable ARIA/DOM capture above is the durable evidence). No console errors; inspected GraphQL requests returned 200. The fixture is deleted at hunt closeout; recreate a prefixed free web service to repeat.

## Root cause and fix

`dashboard/src/features/services/components/idle-timeout-row.tsx:54-57` renders the heading as an unassociated `div`; `:92-94` renders `SelectTrigger` without an accessible-name prop. Add `aria-label={t("services.settingsIdleTimeout")}` to that trigger, reusing the existing en/zh key. Expected tree: `combobox "Idle timeout": Platform default` (or the selected duration), including while disabled during save.

The shared wrapper `dashboard/src/common/components/ui/select.tsx:25-43` forwards trigger props. Installed `@radix-ui/react-select` **2.2.6**, `dist/index.mjs:169-185`, renders `Primitive.button` with `role="combobox"` and spreads `triggerProps`; it does not derive the name from the selected value. The fix can reach the actual button without changing the shared primitive. The working neighbors pass their labels through `EditableFieldRow` (`editable-field-row.tsx:225,247`); their names are independently confirmed in the DOM and ARIA capture.

Blast radius: exhaustive `rg 'IdleTimeoutRow' dashboard/src --glob '*.tsx'` finds **one production mount**, `dashboard/src/routes/services.$serviceId.settings.tsx:167`; remaining occurrences are its declaration/interface, imports, comments, and tests. Apply the label locally. `autoSleepEligibleType` restricts the row to public web services; paid web services render an always-on notice, and private/worker/cron/static render no row. Postgres/Key Value do not mount this App settings component. No REST/GraphQL/MCP semantics change; those remain the persistence contract. Unauthenticated/forbidden/error handling stays on the existing route and mutation paths.

Acceptance: repeat the live steps and find the control by role **and name** before and after changing its value. Strengthen the existing free/null-plan assertions in `components/__tests__/idle-timeout-row.test.tsx` to require the name; retain paid-plan and four ineligible-type cases. Unverified live: Chinese locale, paid and non-web variants, and an actual screen-reader session; verify these during implementation. Render: configurable idle timeout is a bex extension; this finding concerns its accessibility, not an upstream feature gap.
