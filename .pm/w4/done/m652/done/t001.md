## Objective

Give GraphQL `createService` a `disk` argument (name, mount path, size in GB) that creates the service with its disk in one write, validated and refused exactly as REST's `serviceDetails.disk` is.

## Context

- REST create takes `serviceDetails.disk` (`lego/backend/internal/apps/rest.go:309`, Render's `serviceDisk` schema `serviceDiskReq` at `:327`), checked by `validateCreateDisk(svcType, tier, replicas, autoscaling, disk)` (`lego/backend/internal/apps/disks.go:798`).
- GraphQL `createService` (`lego/backend/internal/apps/graphql.go:1574`) has no disk argument.
- Render: disks attach to "web services, private services, and background workers" (render.com/docs/service-types), on paid instance types, one instance, no zero-downtime deploys ([ADR082](../../../../../docs/ADR082-persistent-disks.md)).

## Steps

1. Add a `DiskInput` argument and pass it through the same create path REST uses, calling `validateCreateDisk`.
2. Return REST's error codes as GraphQL errors for a static site, a cron job, a Free plan, more than one instance and autoscaling.
3. Add resolver tests for each refusal and for a successful create that reads the disk back.

## Files

- `lego/backend/internal/apps/graphql.go`
- `lego/backend/internal/apps/service.go` if the create path needs the disk passed down
- their tests

## Acceptance criteria

- [x] `createService(disk:)` creates a paid web service, private service or worker with its disk, and `server { disk }` reads it back (test).
- [x] Each refusal answers the code REST answers for the same input (test).

## Out of scope

- MCP: Render's `create_web_service` has no disk argument, so bex's MCP create tools stay as they are.

## Result

Done 2026-11-26: `createService(disk: ServiceDiskInput)` (`graphql.go`, `gqlServiceDiskInput` in `disks.go`) reaches `Create` through `validateCreateDisk`. Pinned by `TestGraphQLCreateServiceAttachesADisk`, `TestGraphQLCreateServiceDiskDefaultsItsSize`, `TestGraphQLCreateServiceRefusesADiskAsRESTDoes` (`disk_create_graphql_test.go`) and the `disk.*` rows of `TestCreateWireFieldsReachTheRequest`. Autoscaling cannot be sent to GraphQL's `createService`, so its refusal is REST's alone.
