## Objective

Write the hand-rolled installer (godownloader is deprecated; hand-written is current practice): detect OS (darwin/linux) and arch (arm64/amd64), resolve the newest bex-cli/v* release via the GitHub API (list releases, filter tag prefix — /releases/latest is unreliable in the monorepo), download the platform archive + checksums.txt, verify sha256 (shasum -a 256 on macOS, sha256sum on Linux), install to ~/.local/bin (BEX_INSTALL_DIR override) with a PATH hint. BEX_VERSION pins a version; a base-URL override enables offline tests. Document the curl one-liner in cli/README.md and docs/bex-cli.md.
