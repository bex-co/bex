## Objective

Compare the result with render.com's Blueprint sync preview and file any drift as follow-up.

## Result (2026-09-26)

Only the dashboard's headline now counts non-noop actions, and it derives that from the same `actions`. Render's Blueprint sync preview lists per-resource changes before confirm, and the dashboard now does too. No drift filed.
