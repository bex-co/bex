## Objective

`scripts/pty-signal-echo-probe.py` also checks the two gaps a tenant notices first, so the sandbox CI check and the live check (t009) cover them:

- the input flush on Ctrl-C, with and without `noflsh`;
- VKILL's erase.

## Context

- The probe (`scripts/pty-signal-echo-probe.py`, w4/m545) runs w4/m545's five signal-echo cases natively, under runsc, or in a bex sandbox. It prints one line per case and exits 1 when any case differs from Linux.
- `scripts/sandbox-runsc-pty-check.sh` and `.github/workflows/sandbox-runsc-pty.yml` run the pool's install item from `infra/clusterapi/overlays/hetzner-caph/sandbox-pool.yaml` (its URL and pinned digests). The probe then runs natively and under the installed runsc, so a gVisor bump that loses the fix turns the check red before the pool rolls onto it.
- The new cases read what the foreground process gets, not only the screen:
  - The flush case types `abc`, Ctrl-C, Enter at a process that ignores SIGINT and reads one line. It expects `\n`, and `abc\n` under `noflsh`.
  - The VKILL case types `abc`, Ctrl-U, `def`, Enter and expects `def\n`, with the native echo bytes.
