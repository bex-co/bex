## Objective

A credential the operator writes is accepted by the running registry within seconds, with no zot restart, so the build and rollout gates clear on their first probe.

## Context

- ADR022 § Credential activation records that zot `v2.1.18` did not reload htpasswd or `accessControl` on a Kubernetes Secret's atomic symlink swap, and that SIGHUP stops the server. The pin is now `v2.1.22`.
- The gates are `app_controller.go:1122-1134` (build) and `deployRegistryGate` `:2928-2935` (rollout); the activation logic is `lego/operator/internal/registry/verify.go`.

## Steps

1. Check the options at the pinned version and choose one that needs no restart:
   - zot's own config and htpasswd file watching, fed by a regular-file write (an operator-written file on a volume, not a symlinked Secret);
   - zot API keys or a bearer-token service;
   - one credential per workspace rather than per App, with its ACL in config that reloads.
2. Implement it. Keep repository isolation as `scripts/verify-per-app-registry-isolation.sh` asserts it: App A's credential gets 401 on App B's repository.
3. Keep the probe gate. Keep the bounce only as a last-resort fallback that alerts when it fires, or remove it if t001 shows it disrupts in-flight pushes.
4. Amend ADR022 § Credential activation with the new mechanism and the round 180 evidence.

## Acceptance criteria

- [x] On the mock cluster, six services created within 30 s all start their builds within 60 s, and no zot pod restarts.
- [x] The isolation script passes.

## Outcome (2026-11-14)

Option 1 chosen (zot's own file watching), and none of the other two was needed.

- **zot reloads by itself.** zot `v2.1.22` fingerprint-polls htpasswd and config every second, so it picks up a kubelet Secret symlink swap. Upstream tests `TestHTPasswdWatcherAtomicReplace` and `TestConfigReloaderKubernetesConfigMapUpdate` pass at that tag. `v2.1.18` reacted to `Write` only.
- **The nudge closes the kubelet gap.** Every credential write merge-patches `bex.co/registry-credentials-written` on pod `zot-0`. RBAC adds `pods: patch` with `resourceNames: [zot-0]`. The kubelet then re-projects the Secrets at once instead of at its periodic sync.
- **The gate stays.** It re-probes every 3 s and re-nudges at most every 5 s.
- **The restart is kept only as a last resort.** It fires 3 min after the write, logs an error, and increments `bex_registry_activation_restarts_total`, which the new alert `RegistryCredentialActivationRestarted` watches. The alert has a promtool test, the series is in the scrape keep-list, and a dashboard panel graphs it.
- **ADR022 § Credential activation is amended.**

Acceptance:

- "Six services start builds within 60 s with no restart" is shown at the registry level on the mock cluster (all six active within 4.9 s, no restart). It was not shown with operator-created services; t005 replays that on production.
- `scripts/verify-per-app-registry-isolation.sh` was not run live, because the mock cluster runs the old operator. Isolation under hot reload was checked directly (`403`) and in `verify_reload_test.go`.
