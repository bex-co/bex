## Objective

Add meaningful tests for the behavior this milestone shipped.

## Steps

1. Operator: a newly written credential is accepted on the first probe with no bounce. Concurrent new Apps each clear the gate without waiting on a cooldown.
2. Isolation: one App's credential is refused on another App's repository, and a revoked credential is refused, without a restart.
3. The fallback path, if kept, fires only when activation fails, and is observable.

## Acceptance criteria

- [x] Each test fails on the current bounce-based activation where it should, and passes after the change.

## Outcome (2026-11-14)

`lego/operator/internal/registry/verify_reload_test.go` runs against `projectedZot`, a zot model that serves only what the kubelet last projected, where a nudge triggers the projection. It covers:

- **First probe:** a new credential is accepted on its first probe, with one nudge and no restart.
- **Concurrency:** six concurrent new Apps all clear the gate on their first probe.
- **Isolation:** A's credential gets `403` on B's repository.
- **Revocation:** a revoked credential is refused, with no restart.
- **Fallback:** the restart fires only past the grace, re-nudges are rate-limited, and the counter rises by exactly one.
- **Failed nudge:** a nudge that fails never fails the write.

`per_app_registry_envtest_test.go` now asserts that a pending credential does not restart zot inside the grace, and that only past the grace does it fall back to a restart.

Mutation check: removing the nudge from `recordWrite` fails the first-probe, concurrency and revocation tests. The old restart-based code also fails them (no nudge, and revocation deleted the pod).
