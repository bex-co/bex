## Objective

Prove the definition of done on the local kind/CAPD cluster with a real Machine deletion and a probe running through it.

## Context

- `bash scripts/mock-cluster.sh` brings up `tenant-0` (`bex-tenant-0`) as a MachineDeployment (`scripts/mock-cluster.sh:171`); `bash scripts/mock-cluster.sh operator` deploys the operator built from the tree. drain-guard ships in `deploy/gitops/base/`.

- Evidence is text in this task's Outcome, no dumps in git (`.pm/DO_NOT_DO.md` #NO-ARTIFACTS-IN-GIT).

## Steps

1. Create a single-instance web service on a `bex-tenant-0` node and a webhook subscribed to the pair; start an HTTP probe against it.
2. Delete that node's Machine; wait for the handover and the drain.
3. Read the pair on REST list and retrieve, GraphQL and MCP; confirm the webhook deliveries and the probe's non-2xx count.
4. Repeat with a disk-attached service (expect no events) and, if the cluster autoscaler can be made to remove a node, with a scale-down (expect `node_consolidation`); otherwise rely on t001's envtest for that path and say so.
5. Delete every fixture and record the evidence.
