## Objective

When an App's Deployment pod template gains a new `drain-guard.bex.co/evacuated-from` value, the App reconciler records a platform-redeploy transition on the App's status: an id, the node, the trigger, the time it started, and the time it ended once the rollout of that template completed. A re-read or an operator restart records no second transition.

## Context

- drain-guard (w1/m186, w1/m187) sets the annotation on the pod template of each App whose only Ready pods are on a node about to go (`lego/operator/internal/drainguard/drainguard.go:77` `EvacuatedFromAnnotation`, `evacuate` at `:265`). The annotation stays after the roll, like `kubectl rollout restart`'s (`docs/runbooks/drain-guard.md`).
- Two paths reach it: a deleted guarded `bex-tenant-0` Machine (drain-guard cordons the node) and a Cluster Autoscaler scale-down (the node carries the `ToBeDeletedByClusterAutoscaler` taint). Recommended trigger values: `node_replacement` and `node_consolidation`. Render's trigger vocabulary is uncaptured (`w10/blocked/002`), so these are bex's choice.
- The operator already reads Nodes through its cached client (`nodeLossMessage`, `lego/operator/internal/controller/app_controller.go:6497-6560`).
- Pattern to follow: the autoscaling transition (`AutoscalingStatus`, `lego/types/v1alpha1/app_types.go:1815`; `TransitionID` built in `lego/operator/internal/controller/autoscale.go:404`).
- A disk-attached service rolls with `Recreate` and drain-guard releases it at once (ADR004 § Node rolls), so it is not a zero-downtime redeploy and records nothing.

## Steps

1. Add a platform-redeploy transition to `AppStatus` (`lego/types/v1alpha1/app_types.go`) and regenerate (`make manifests generate` in `lego/operator/`).
2. In the App reconciler, start a transition when the pod template's annotation value differs from the last recorded one; key it on the node and the Deployment generation that carried the change. Read the node's taints at that moment for the trigger.
3. End it when the Deployment's rollout of that generation has completed (updated and available replicas at the desired count, no old ReplicaSet pods), or when the old pod is gone because the hold expired; an outage in the latter case stays reported by `server_failed`/`server_available` as today.
4. Skip Apps whose Deployment uses `Recreate`.
5. envtest: annotation set → started with the trigger; rollout complete → ended; operator restart mid-transition → the same transition, no new one; `Recreate` → none.
