**Fix shipped 2026-10-05 (w5 drain, `fix(deps): clear the dashboard's critical seroval advisory (w4/208)`); open until the next `deploy.yml` run passes the gate and pins images.**

- **Cause:** the only critical is `seroval` 1.5.6 under `solid-js` 1.9.11, which reaches the tree only through `@tanstack/devtools`. Every `solid-js` release, 1.9.15 included, pins `seroval ~1.5`, and all of 1.5.x is in the critical range, so no TanStack or Solid bump can clear it. TanStack's own packages already used `seroval` 1.6.2.
- **Fix:** `resolutions` pin `seroval` and `seroval-plugins` to `^1.6.8`, which clears the critical and the `<=1.6.2` high on TanStack's SSR path, and raise `undici` from `^7.29.0` (still vulnerable) to `^7.29.1`. In-range lockfile refreshes cover `@fastify/busboy`, `brace-expansion`, `prosemirror-view`, `source-map-js` and `@graphql-tools/executor-legacy-ws`.
- **Verified locally with CI's yarn 4.17.0:** `yarn npm audit --all --recursive --severity critical` reports no suggestions. `yarn typecheck && yarn lint && yarn test` pass (4156 tests), and so does `yarn build`. The built server renders `/auth/login` and `/terms` with the seroval dehydration payload, and the client hydrates in Chromium with zero console errors.
- **Still reported at HIGH (report-only):** `braces <=3.0.3` has no patched release yet (via `micromatch`). `@graphql-tools/utils <=12.0.0` is pinned `^11.2.0` by the dev-only `@graphql-codegen/*` toolchain, so clearing it needs a codegen major bump. Neither ships in the bundle.
