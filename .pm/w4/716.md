# A log line's time card lacks Render's From previous and From start, its copy buttons and its millisecond timestamp

Why: Render's log explorer answers "how long since the line before?" and "how long into this deploy?" from the time's hover card, and copies each value in one click. bex's card has neither, so a reader subtracts two clock times by hand. Found by w4/m552 t001 on 2026-11-22, from Render's public dashboard bundle ([capture § Line detail view](../../docs/render-artifacts/project-observability.md#line-detail-view-read-2026-11-22-w4m552)).

- **Render** (`Logs-*.js`, `TimestampTooltipContent`, shown by `LogLineTimestamp` on hovering a line's time): a `dl` whose values each sit in a copy button named `Copy <label>`. The rows are:
  - the local zone's abbreviation (`Local` when it has none), showing `MMM D hh:mm:ss A` and copying `YYYY-MM-DDTHH:mm:ss.SSSZ`;
  - **UTC**, left out when the local zone is UTC, copying the ISO string;
  - **Timestamp**, in Unix **milliseconds**;
  - **From previous**, the gap since the line before, on every line but the first;
  - **From start**, the time since the explorer's `startedAt`, which only a deploy's or a build's log passes (`new Date(deploy.createdAt)`).

  The gaps use Render's duration format: under 100 ms `42ms`, under a minute tenths of a second (`1.2s`), then `3m 4s`, `2h 5m`, `1d 3h`, dropping a zero second part (`3m`).
- **bex:** `LineTime` (`dashboard/src/features/logs/components/log-line-list.tsx`) opens the shared `InstantTooltip` (`dashboard/src/common/components/instant-tooltip.tsx`). It shows Local, UTC and Timestamp, the last in Unix **seconds** (`formatInstantDetails`, `dashboard/src/common/lib/format/format-instant.ts`). Its values are `select-all` text with no copy button, and it has no From previous or From start. ADR018's "Log explorer display and shortcuts" row records the gap and points here.
- **Scope:** only a log line's card. Other timestamps keep `InstantTooltip` unless Render's same card is found behind them.
- **End state:** hovering a line's time (or the keyboard row cursor on it) in every explorer shows Render's rows, labels and order, From previous on every line but the first, and From start only on a deploy's log. Each value copies Render's string. A test covers the gap format at each boundary (99 ms, 100 ms, 59.9 s, 60 s, 1 h, 1 d) and the omitted UTC row when the zone is UTC.
