## Objective

Make the verbs that change *what a service runs* refuse on a protected environment member without the confirmation phrase, and give them a `confirm` argument so the phrase can be supplied.

## Context

- This is the verb the hunt caught: `setImage` on a protected member returned success and the service ended up `Running` on the new image at `rev-6`.
- All three forms land in `SetSourceAndRegistryCredential` (`lego/backend/internal/apps/service.go:3561`), whose own comment already classifies the operation: _"repointing a service at a new repo or image chooses the executable the operator runs with the service identity — create-like, so gate on can_create (developer and up), not the lifecycle-oriented can_operate."_ The authorization is already elevated; only the protected-environment confirmation is missing.
- The guard call is one line in the shape the other three sites use: `if err := s.requireUnprotected(ctx, a, "<verb>"); err != nil { return … }`, after the App is fetched and before `resolveSourcePatch`.
- The phrase is per-verb by design (`protection.go:51-54`), so pick the verb word deliberately — `"update source"` reads better in `sudo update source service <name>` than `"setImage"`, and it must be stable because callers type it.
- The confirm travels on the context (`core.WithConfirm` / `core.ConfirmFrom`), not as a service-method parameter — ADR032 explains this is because these verbs are reached through REST/GraphQL/MCP forwarding helpers with a fixed `func(ctx, name string)` shape. The adapter is what needs the new argument.

## Steps

1. Add `requireUnprotected` to `SetSourceAndRegistryCredential` with the verb word chosen in t001.
2. Add a `confirm` argument to the adapters: GraphQL `setImage`/`setRepo`/`setRegistryCredential`, the REST source-patch route, and the MCP tool — mirroring exactly how `suspendService(id, confirm)` does it today.
3. Thread it onto the context with `core.WithConfirm` at the adapter boundary, the same way the suspend path does.
4. Confirm the unprotected path is byte-identical: no new required argument, no behavior change.

## Files

- `lego/backend/internal/apps/service.go` (`SetSourceAndRegistryCredential`)
- `lego/backend/internal/apps/graphql.go`, `rest.go`, `mcp.go`

## Acceptance criteria

- [ ] `setImage` on a protected member is refused with the named error and the exact phrase.
- [ ] Passing the phrase proceeds and the image changes.
- [ ] The same holds for the repo and registry-credential forms of the same verb.
- [ ] A service in an unprotected environment, or in none, is unaffected and needs no confirmation.

## Out of scope

- The settings verbs (t003) and the dashboard (t004).
