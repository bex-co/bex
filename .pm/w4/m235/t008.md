## Objective

The Definition of done says `404 page not found` never appears between the create `201` and the first `200`. On the live pin carrying t001–t006 it still does, for the first ~2.5 s: the host has no route until the operator's first reconcile writes the Ingress and Traefik loads it. A poll every 3 s from the 201 (the DoD's own method) usually lands in that window.

## Context

Live `/qa-find-bugs w4` loop run 8a59, 2026-10-27 UTC (`muse.env`, `bex-canary`, pin `b4726243e74f`; m235's `f4e383710` is in the pin). A Free image web service `ghcr.io/nginxinc/nginx-unprivileged:stable-alpine` was created with `POST /v1/services`, then its host was polled every 0.5 s from the 201:

```text
+0.6s  404  "404 page not found"          (Traefik, no route)
+3.2s  503  Retry-After: 10  "This service's first deploy is in progress. Try again in a few seconds."
+12.6s 200  nginx welcome page
```

A second fixture created a minute earlier showed the same `404 → 503 → 200` sequence on 8 s polling. Both fixtures (`srv-dbg2k6ln83uc738uuaqg`, `srv-dbg2kgtn83uc738uuatg`) were deleted (`GET` → 404).

Mechanism: `routeFirstDeploy` / `writeFirstRoute` (`lego/operator/internal/controller/app_controller.go:3023-3045`) run in the operator's reconcile, so the route exists only after the App CR is reconciled and Traefik's Kubernetes provider has loaded the new Ingress. Until then Traefik has no router for the host. The static-site path (t003, "route at creation") was not re-probed this run.

## Steps

1. Make the host answered from the instant create returns. Options, roughly in order of preference:
   - a lowest-priority catch-all router for `*.<platform domain>` to the activator. The activator resolves the App by host, answers the t001 first-deploy `503` for an App that exists and never served, and a bex-branded `404` for an unknown host;
   - or have the backend's create write the first route (the activator Ingress) synchronously before returning `201`.
2. Make sure the catch-all can never shadow a real route (strictly lower priority than every App Ingress) and never wakes or touches an App.
3. Re-run the DoD with a sub-second poll as well as the 3 s one.

## Files

- `lego/operator/internal/controller/app_controller.go` (first route) and/or the activator's host lookup
- platform Traefik values or a static IngressRoute for the catch-all (`deploy/gitops/…`), if that option is chosen

## Acceptance criteria

- [ ] Live: a new Free image web service and a static site, polled every 0.5 s from the `201`, never answer `404 page not found` before their first `200`; every pre-200 answer is the t001 first-deploy response.
- [ ] An unknown `*.onbex.co` host answers a bex-branded 404, not Traefik's raw text (if the catch-all route is chosen).
- [ ] Existing services' routing is unchanged (catch-all priority test).
