## Root cause and fix

`lego/operator/internal/controller/app_controller.go:3155-3161` makes `prefix + appName` when it fits 63 characters, otherwise truncates the app component and appends eight SHA-256 hex characters. The three callers are static `:3149`, maintenance `:3232`, and activator `:3261`. `reconcilePlatformAlias` (`:3207`) applies exact App owner/labels and the fixed target. `reconcileActivatorAlias` returns the admission error at `:3255`.

`deploy/gitops/base/operator-alias-admission.yaml:40-70` requires literal full names for all three purposes, including `object.metadata.name == 'bex-activator-' + variables.app`. For this fixture the App name has 53 characters; the computed alias is exactly the failure's `bex-activator-tea-d98210cbbpdc73dcrkvg-qa-20260909-ad2-e071258f` (63 chars). The short control App has 43 chars and its full alias has 57 chars, so the existing expression admits it.

Align admission's accepted name shapes with the bounded constructor. Keep the existing short-name equality. For long names admit only the constructor's purpose-specific prefix, exact truncated App prefix, separator and eight lowercase hex suffix shape, only when the unshortened name would exceed 63. CEL's available functions must be checked before claiming it can recompute SHA-256; the security boundary remains trusted operator identity + exact App controller ownership + labels + fixed ExternalName target/port, not secrecy of the suffix. Do not remove the policy, broaden fixed targets, relabel the App to fit, rename existing aliases, or restore an overlength Service name. Include a real admission test with the actual constructor output so independent fake-client tests cannot miss this again.
