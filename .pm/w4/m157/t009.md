## Objective

Return nested JSON arrays for native multidimensional PostgreSQL array cells, matching PostgreSQL to_json shape, then apply the milestone's scalar normalization recursively before encoded-result budgeting. An array matrix must not become indistinguishable from a flat list.

## Context

[array-finding.md](array-finding.md) contains two fresh dashboard reproductions, REST/MCP probes, 3D/text/null controls and a local proof using pinned pgx v5.10.0. The default ArrayCodec.DecodeValue chooses an any slice whose reflect scanner discards dimensions. Post-processing rows.Values alone is too late.

## Steps

1. Pass/access the actual query connection's type map and each field's DataTypeOID, Format and RawValues after existing raw-byte budget checks. Recognize registered ArrayCodec fields by codec type, not a short hardcoded OID list or a SQL-text heuristic.
2. Decode array cells using the existing pgtype.Array[any] scan target (Map.Scan or its planned equivalent) to retain dimensions and element order. Preserve non-array and unknown-codec paths. Do not copy/fork pgx's generic Values implementation or register global replacement codecs merely for this executor.
3. Reconstruct nested slices from dimension lengths, with checked cardinality/lengths and bounded allocation. SQL NULL remains null, a non-null empty array remains [], and one dimension remains a flat list. JSON array indexing stays ordinal; do not invent a bounds wrapper or promise preservation of PostgreSQL custom lower-bound metadata in this task.
4. Normalize each scalar through the shared numeric/temporal/UUID conversion. Apply the encoded JSON budget to the final nested shape. Handle decoder errors using existing safe query failure mapping; keep auth, read-only and writable confirmations, timeout and row caps.
5. Coordinate t003/t005 verification with m158 for exact MCP numbers. This change cannot fix MCP's later numeric coercion.

## Acceptance criteria

- [ ] Native matrix/cube/text-null arrays match the captured PostgreSQL JSON controls across surfaces.
- [ ] Empty/NULL/flat arrays and bytea retain their observed representations.
- [ ] The raw-to-shaped decoding path uses field metadata, stays bounded and runs before final encoded-size accounting.
- [ ] Existing typed-value normalization applies at leaves without flattening nesting or misclassifying bytea as an SQL array.

## Out of scope
