# Additional `@` mention types in the /agents composer (files, secrets, …)

Filed by w4/m36/t004 (universal `@` search) as the "future mention-type candidates" follow-up.

m36 made the composer `@` picker universal over the two v1 types (`repos`, `sessions`) and left the registry (`dashboard/src/features/agent-sessions/lib/mention.ts` — `MentionCategory` union + `MENTION_CATEGORIES` + `CATEGORY_META`) deliberately at two. Devin ships seven mention types (Repos, Files, Macros/Knowledge, Playbooks, Skills, Secrets, Sessions — docs.devin.ai/get-started/first-run).

Candidates worth considering, each gated on the underlying data existing in bex:

- **Files** — needs a per-repo file index the composer can query (Devin's `@file_name`). No such index today; the agent session clones the repo in-sandbox. Largest lift.
- **Secrets** — the tenant env-vars store (OpenBao, ADR013) is already a bex surface; referencing a secret name as context is plausible and low-data-lift.
- **Env groups / services** — bex-native context the agent might want.

Mechanism is ready: adding a type = extend the `MentionCategory` union + `MENTION_CATEGORIES` + `CATEGORY_META` + a `MentionSource` field + a source query; the universal ranking, grouping headers, and `mentionOptionGroup` already fan out over whatever kinds exist. Not scoped/committed — promote to a milestone only on explicit product intent, since each type needs a real data source, not just a picker row.
