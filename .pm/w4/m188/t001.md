## Objective

Make the two relative-time formatters consume the active request/component translator and supply it from the shared wrapper. Keep exact instants, the bounded clock, fallbacks and hydration guards.

## Context

- [Current finding, root causes, complete requests and scope](finding.md).
- Two minor presentation defects; current API instants, validation and runtime behavior are correct in the exercised cases.
- Discovery fixtures are deleted; any live acceptance uses new owned qa-prefixed Free resources.

## Steps

1. Add common.\* messages for past-age units and future countdown units. English preserves current compact output; Chinese uses 刚刚 / N分钟 / N小时 / N天 / N个月 / N年 and 现在 / N分钟后 / N小时后 / N天后.
2. Inject the hook/request translator rather than importing an ambient i18next singleton; do not change time parsing, bucket arithmetic or schedule semantics.
3. Keep hooks unconditional before the existing missing/invalid-value return; preserve fallback nodes, dateTime, title, as=time/span and suppressHydrationWarning.
