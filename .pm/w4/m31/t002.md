## Objective

Bound anonymous abuse of the three credential-less device-flow routes — each hit today costs a full Hydra round trip with no metering — without breaking the official Render CLI's legitimate login polling.

## Context

- Routes: `POST /v1/device-grant`, `POST /v1/device-token`, `POST /v1/token/refresh/` (`lego/backend/internal/cliauth/service.go:79-81`), mounted outside the auth gate by design (`internal/api/CLAUDE.md` always-public inventory) and therefore outside the identity-keyed rate limiter (anonymous callers would all share one bucket).
- Design decision recorded in `w4/023`: an IP-keyed token bucket in bex-api vs Hydra-side limits. Decide and record the choice + rationale in this task's op log; the IP-keyed bucket is the default expectation (self-contained, no Hydra config dependency).
- The official CLI polls `/v1/device-token` during login (interval per RFC 8628 `interval`, default 5s) — limits must comfortably admit a real ceremony, including a slow human authorizing in the browser.
- 429 bodies on these routes stay OAuth-dialect via `writeOAuthError` (`slow_down` is the RFC 8628 signal the CLI understands on the token route), never the Render REST error shape.
- Respect the replica-local-state FUTURE-MAYBE boundary: a per-replica bucket is acceptable at one replica; note it alongside the existing deploy-hook limiter entry if the shape matches.

## Steps

1. Add an IP-keyed token bucket (reuse/extend the existing limiter machinery if its shape fits) wrapping only these three handlers.
2. Pick limits generous for a real ceremony, tight for a flood; make them env-tunable following the `BEX_RATE_LIMIT` naming family and document in CLAUDE.md's env table + `.env.example`/`.env.template` sync rule.
3. Return `slow_down` (device-token) / OAuth-shaped 429s; never touch Hydra before the bucket check.

## Files

- `lego/backend/internal/cliauth/service.go` (+ a small limiter file in `cliauth` or shared)
- `CLAUDE.md` env table, `.env.example`, `.env.template` (if a knob is added)

## Acceptance criteria

- [ ] A flood from one IP is shed before any Hydra call; a second IP is unaffected.
- [ ] A simulated full device ceremony at the CLI's polling cadence completes unthrottled.
- [ ] 429/`slow_down` bodies are OAuth-dialect on all three routes.

## Out of scope

- Rate limiting any other always-public route (webhooks, deploy hooks have their own credentials/limits).
- Durable/shared bucket state (FUTURE-MAYBE, single-replica today).
