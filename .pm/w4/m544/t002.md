## Objective

Give the TypeScript driver the Go resolver without a TypeScript port that could drift: a tiny static binary, `lego/backend/cmd/agent-toolchain`, importing `lego/types/toolchains`, built in an agent-image stage and called by the driver.

## Context

- The agent image already ships backend-owned files (`agent-profiles.json`, `lego/agent-image/Dockerfile` ~:30, :83, :311).
- Inputs: a directory (the checkout root) and the environment (`PYTHON_VERSION`, `BEX_AGENT_SESSION_CREATED_AT`). Output: JSON `{line, version, exact, source, narration}` or a named error.

## Steps

1. Write the command and its tests.
2. Add a build stage to `lego/agent-image/Dockerfile` and copy the binary to a fixed path.

## Files
