## Objective

Render honors a fully qualified `PYTHON_VERSION` exactly. When the requested patch is not the baked one (e.g. `3.11.9` against the baked 3.11.18), fetch that patch's official image layer by digest into `/opt/bex-python/<version>`, and when the fetch fails, fall back to the line's baked patch and say so, as the native build does (ADR060's exact-patch pattern).

## Context

- Docker Hub is in the session egress registries catalog (`lego/backend/internal/sessionegress/policy.go` ~:614-626); the in-cluster registry is probably unreachable from a sandbox (private addresses are denied, ADR047).
- A fetched version's `pip` scripts point at `/usr/local/bin/python3.X`; its shims must run `python -m pip` instead.
- Honor `HTTPS_PROXY` and the session's network tier.

## Steps

1. Resolve the exact image digest (from `types/toolchains` or the registry), pull the Python layer only, unpack, and verify `python --version`.
2. On failure, select the baked patch and narrate the fallback with the reason.

## Files

- `lego/agent-image/driver/src/python-select.ts` (+ a fetch helper), tests with an offline fixture registry

## Acceptance criteria

- [x] With a fixture registry, `PYTHON_VERSION=3.11.9` yields 3.11.9 and `python -m pip --version` works.
- [x] With the registry unreachable, the session gets 3.11.18 and the transcript names the fallback and why.

## Out of scope

- Caching fetched patches across sessions.

## Outcome

Done 2026-11-20. `driver/src/python-fetch.ts` fetches an exact patch's official image through `curl` (the session's proxy applies): token, index, the platform manifest, then the top layers (at most four) until the one carrying `python3.X`, each checked against its digest, extracted from that layer up, assembled into `/opt/bex-python/<version>` and verified with `--version`, all within 5 minutes; it never leaves a partial prefix. A prefix already there (a snapshot that fetched it) is reused. On failure the line's baked patch runs and the step adds `==> Could not fetch <image> (<reason>); using the reviewed Python 3.X build, <patch>`. Tests: a fixture registry (3.11.9 fetched, the base layer never downloaded, no work directory left, no second download) and an unreachable one (the named fallback).
