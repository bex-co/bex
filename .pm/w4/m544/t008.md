## Objective

Check the shipped behavior against both reference products and file any drift as follow-up work.

## Context

- Render ([python-version](https://render.com/docs/python-version)): `PYTHON_VERSION` must be fully qualified (3.7.3+), then a root `.python-version` (patch optional → latest patch), then a dated default (3.14.10 since 2026-11-03); uv only with `uv.lock` ([uv-version](https://render.com/docs/uv-version)).
- Devin (the reference for agent surfaces, ADR047): no automatic selection; a blueprint's `initialize` uses `actions/setup-python` with `python-version`, and its PATH carries into later steps and maintenance.
- The selection is visible on the session surfaces (transcript, REST/GraphQL/MCP session reads, dashboard session view): check each shows the same step.
