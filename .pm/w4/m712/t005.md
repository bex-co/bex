## Objective

Prove the boundary in envtest and on production. A `frankfurt` and an `oregon` resource in the same workspace cannot reach each other privately, two `frankfurt` ones can, and no pod restarted.

## Context

- `make verify-tenant-isolation` checks NetworkPolicy reachability (ADR041 notes it).
- `bex-canary` is a first-party workspace. Disposable resources there are created and deleted by id, with a 404 proof, and marked `(disposable)` on the board.

## Steps

1. Add envtest cases for the policy set across region, environment, isolation and pod kind.
2. Deploy to production. In `bex-canary`, create these resources (disposable):
   - two private services in `frankfurt`;
   - one private service in `oregon`;
   - a Key Value instance in `frankfurt`.
3. Check reachability by internal address, by pod IP and by Key Value internal URL, from each service. Compare pod UIDs from before and after the operator upgrade on one existing first-party service.
4. Delete the disposable resources and record the 404s.
