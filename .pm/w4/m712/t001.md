## Objective

Before anything is enforced, learn whether any workspace would lose private traffic it uses, and write the design t002–t004 build. If cross-region private traffic is in use, stop and ask the user.

## Context

- Production can be read with `bash scripts/fetch-app-kubeconfig.sh <path outside the repo>`. Use it read-only.
- Each App, Database and KeyValue CR carries `app.bex.co/region` when it was created with a Render region. Without that annotation, the resource reads back the platform alias (`resourcemeta.Config.ResourceRegion`, `lego/backend/internal/resourcemeta/metadata.go:178-185`).
- Possible signs of cross-region private use:
  - env vars or secret files on a service that name another resource's internal hostname or internal URL, where that resource reads back a different region;
  - linked datastore URLs (`fromDatabase` / `fromService` in Blueprints).
  - Cilium flow logs, where available.
- Today's policy set: `allowNetworkPolicies`, `sameNamespaceNetworkPolicy` and `environmentIsolationPolicies` (`lego/backend/internal/store/namespaces.go:891-1013`).
- Restarting nothing:
  - A pod template change rolls every service (w4/m342's finding).
  - `LabelNetworkIsolation` reaches App pods "only as an in-place relabel, never through a pod template" (`lego/backend/internal/core/base.go:282-284`), through `relabelPodsInPlace` (`lego/operator/internal/controller/environment_network_policy.go:114`). Key Value and Postgres pods are relabelled in place too (`keyvalue_isolation.go`, `datastore_priority.go`).
- The board is public: record counts and hashed or neutral names only, never tenant names.

## Steps

1. Count the workspaces whose resources read back more than one region, and their resources by region.
2. In those workspaces, look for the signs of cross-region private use above, and count them.
3. Write the design in this milestone's README:
   - The label key and value.
   - How a pod with no label counts: as the platform alias, the region an unstamped resource reads back.
   - How the policies select region × environment. Kubernetes ORs peers in one rule but ANDs the expressions in one selector.
   - How the label reaches running pods without a rollout, and new pods from creation.
4. If step 2 finds cross-region private use, write the counts and the options into the milestone's README, move the milestone to `blocked/` for the user's decision, and stop. Otherwise continue.
