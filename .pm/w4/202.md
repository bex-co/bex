# Failed health-check deploy's final failureReason still says "the rollout is waiting"

Why: a deploy that already gave up is reported in the present tense ("so the rollout is waiting") on its `update_failed` record forever, which reads as if bex is still trying.

- **Severity:** minor (copy).
- **Repro (loop40, 2026-10-05, pin `f837cec46294`):** owned Free image service `qa-20261005-l40-acl` (deleted afterwards). Set `healthCheckPath` to `/slow?wait=10s` (traefik/whoami answers after 10s, beyond the 5s probe timeout). Deploy `dep-db1obj8ti8qc73bltc20` started 11:11:13Z and settled `update_failed` at 11:26:13Z, which is correct (900s budget; the old pod served 200 throughout). Its `failureReason` reads: _"the container is running but its startup health check has not succeeded, so the rollout is waiting: GET /slow?wait=10s on port 8080. Check that the path returns …"_.
- **Expected:** the terminal reason states the outcome, for example _"the startup health check never succeeded within 15 minutes (GET /slow?wait=10s on port 8080), so the deploy failed and the previous release kept serving. Check that the path …"_. The in-flight `stallReason` wording can stay as it is.
- **Root cause:** `lego/operator/internal/controller/app_controller.go:4932-4934` (`probeStallMessage`) builds the in-flight message. `settleFailedRollout` (`:3157-3169`) reuses it verbatim as the terminal reason, either through `stuckPodMessage` or through `lastStallDiagnosis` (`:3180-3187`, w8/039).
- **Fix:** at settle time, rewrite a `reasonHealthCheckFailing` message into the terminal form; keep the Reason wire value unchanged (it is a contract, `:4950`). Check the other stall kinds that `lastStallDiagnosis` carries (CrashLoopBackOff, ImagePullBackOff, InvalidImageName, CreateContainerConfigError) for the same present-tense wording.
- **Blast radius:** every surface that renders `failureReason` (REST/GraphQL/MCP deploy, dashboard deploy page, deploy-failed notifications/webhooks). The text is user-visible only; there is no logic on it, so update tests that pin the exact string.
- **Unverified:** the crash-loop and image-pull terminal messages; the notification email body.
- **Render:** Render reports a timed-out health check as a failed deploy in the past tense.
- **Estimate:** ~30m.
