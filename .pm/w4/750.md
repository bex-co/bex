# Every native service last built before the Ghostscript-fixed common image is rebuilt, or its owner is told the cutoff, as Render did for Upload2Shell

Why: Render parity and security. Render patched the Ghostscript its native runtime ships and told customers to redeploy any service not deployed since 2026-11-20 20:00 UTC. bex's common image carried the vulnerable package until 2026-11-21, and a native service built before then still runs it, with no rebuild and no notice.

- **Render (read 2026-11-27):** [advisory-upload2shell](https://render.com/docs/advisory-upload2shell): "check whether your service has deployed successfully at least once since November 20, 2026 20:00 UTC … If not, redeploy".
- **bex:** the common image ships Ghostscript (`deploy/native-base/install.sh`). Its image's SBOM shows `10.0.0~dfsg-11+deb12u8` in the pin from `71914199f9` (2026-11-16) and the fixed `deb12u9` (Debian DLA-4914-1) from `0f4ab445b0` (2026-11-21) on (`lego/operator/internal/build/nativebases.go`). The last `platform-rebuild.yml` run was 2026-11-19T08:08Z, before the fix. [ADR060](../../docs/ADR060-build-worker-reliability-and-performance.md) still records `deb12u8`.
- **Do:** find when production first ran a pin carrying `0f4ab445b0`, list the native services whose current image predates it, and run `platform-rebuild.yml` for them (or all). Correct ADR060's version line. Tell the owners through the advisory practice of `w4/749`.
- **End state:** no running native service's image carries Ghostscript `deb12u8`, checked from the images' SBOMs or `dpkg -s ghostscript` over SSH on a sample, and ADR060 names `deb12u9`.
- **Size:** about 45m.
- **Source:** w4/m688 t002, a full read of Render's advisory-upload2shell page, 2026-11-27.
