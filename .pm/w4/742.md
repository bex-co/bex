# Static sites are served from a global CDN, as Render's are, or ADR018 records the single-region origin with the user's sign-off

Why: Render parity. Render promises every static site "a blazing-fast, reliable, and secure global CDN" that caches "on network edges around the world". bex serves each static site from one origin in one Hetzner location, so a visitor far from it pays origin latency for every asset, and no ADR018 row says so.

- **Render (read 2026-11-27):** [static-sites](https://render.com/docs/static-sites) § Global CDN; [multi-service-architecture](https://render.com/docs/multi-service-architecture): "Render static sites are served by a globally distributed CDN"; [render-vs-heroku-comparison](https://render.com/docs/render-vs-heroku-comparison) and [migrate-mongodb-static-hosting-to-render](https://render.com/docs/migrate-mongodb-static-hosting-to-render) say the same.
- **bex:** a static site is served by the in-cluster static server behind Traefik ([ADR029](../../docs/ADR029-static-sites.md)), and every tenant host resolves to the one Hetzner load balancer (`infra/terraform/main.tf`). ADR018 § Services & lifecycle: Static site is ✅ and does not mention delivery; the Edge caching row records "not a global CDN" for web services, with no sign-off. `w21/126` covers DDoS protection and the Cloudflare decision, not CDN delivery, and `w4/736` only the `cf-cache-status` header.
- **Do:** decide with the user between putting a CDN in front of static-site hosts (the same decision `w21/126` asks about Cloudflare would cover it) and recording the single-region origin as a signed-off divergence in the Static site and Edge caching rows. Until then, add the divergence to both rows as unsigned, so the ledger stops reading ✅.
- **End state:** a static site's first byte from a distant region comes from an edge near it, or ADR018's Static site row records the single-region origin with the user's sign-off.
- **Size:** the ledger half about 20m; the CDN itself is a milestone.
- **Source:** w4/m688 t002, full reads of four Render docs pages, 2026-11-27.
