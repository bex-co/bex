## Context

- `claude plugin validate [--strict] [--profile directory] <path>` (Claude Code 2.1.322) validates a plugin or marketplace manifest and its skills, agents and commands.
- `.github/workflows/cli-test.yml` paths need `plugins/**` and `.claude-plugin/**`; `scripts/ci_test_inputs.py` checks workflow paths.
- `scripts/skill-layout-validate.sh` only reads `.claude/skills` and `.agents/skills`, so it needs no change.

## Steps

1. Run `claude plugin validate --strict` on the marketplace and the plugin in `cli-test.yml`.
2. Add the paths; run `python3 scripts/ci_test_inputs.py`.
