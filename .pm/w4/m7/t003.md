## Objective

Flip the two switches the values file has been carrying TODOs for: `courier.enabled: true` with the SMTP URI delivered via the `kratos` Secret key `smtpConnectionURI` (t001 — values carry only a non-secret placeholder in `courier.smtp.connection_uri` to gate the env injection), and `selfservice.flows.verification.enabled: true` **in both the base and the local overlay values** (the overlay re-declares `enabled: false` and Argo merges valueFiles later-wins). Locally the Mailpit URI comes from the local `auth-secrets.sh` run, not overlay values.

## Context

- `deploy/gitops/base/values/kratos.values.yaml` — the `recovery` block (enabled, with the "can't deliver until courier.smtp lands" comment), `verification` block (`enabled: false`), and `courier` block (`enabled: false`); line numbers drifted after the m9/m19 edits, cite blocks not lines.
- **Precondition (2026-07-11):** the m19 sweep pins kratos/hydra deployments+jobs and the CNPG auth DBs to `bex.co/pool=platform` — a label no CAPD mock node carries, so step 3's sync leaves the substrate Pending on a fresh mock. Blocked on the `w1` inbox note on mock pool-labels (mock node labeling or a local-overlay nodeSelector sweep — which also matches the docs/auth.md local control-plane-pin quirk); alternatively verify against prod.

Without a `statefulSet:` block the courier lands on the untainted tenant pool in prod and dies with tenant scale-downs.
- Local overlay values layering: `deploy/gitops/overlays/local/values/` (per docs/auth.md §4); its kratos values re-declare `verification.enabled: false` — must be flipped there too.
