# Chinese repository selectors retain English guidance and clear labels

Why: a Chinese user choosing a repository or branch should receive translated empty-state guidance and a translated name for the clear action.

**Severity:** minor. **Estimate:** 35m. Functional `$qa-find-bugs`, read-only a606, 2026-10-15, user-selected w4. Research HEAD `e84ee60cc55cc44f4eb3b47ee62a3df38b4f406d`; no product fix. Goal: ADR008 usable hosting, ADR049 Blueprint creation and `dashboard/AGENTS.md:174–186`'s en/zh contract.

## Reproduction and controls

1. With document language **zh**, open `/blueprints/new` at 390×844, choose **公开 Git URL**, and enter public repo `https://github.com/bex-co/bex`.
2. Type `qa-a606-missing-branch` in **分支**. At **16:51:38.866Z**, the popup shows **No results found Press Enter to use "qa-a606-missing-branch"** and the clear button is named **Clear input**. The surrounding form and input name are Chinese.
3. Independently reload at **1440×1000**, retain Chinese, and repeat with `qa-a606-fresh-branch`. The same strings appear at **16:52:18.619Z**.
4. Click Clear input: the value becomes empty and focus stays on the input. Choose the real **main** suggestion: the input becomes main and the popup closes. No Deploy Blueprint action is taken.
5. Restore English and reload. At **16:54:14.936Z**, document language is en and the same English copy is appropriate.

[Durable evidence](evidence/312-313-shared-search-labels.json) records these native interactions, relevant accessibility trees, complete caller census and baseline reconciliation. The invalid branch text is deliberate input for exercising the empty picker; no invalid deployment was requested.

## Root cause and bounded fix

`dashboard/src/common/components/ui/combobox.tsx` owns untranslated strings:

- **48:** default placeholder Select an option.
- **49:** default empty text No results found.
- **223:** clear button `aria-label="Clear input"`.
- **248–251:** custom-value hint Press Enter to use the interpolated input.

Use `useTranslations` with common en/zh entries for these defaults and the custom-value hint/clear action. Preserve explicit `placeholder` and `emptyText` overrides and existing falsy-fallback semantics. Keep the typed value literal through ordinary text interpolation. Localize the placeholder as a source-established neighboring fallback; no production default-placeholder failure was observed because the concrete callers provide placeholders.

This is independent of cmdk's English Suggestions name, owned by [312](312.md). An upstream cmdk patch cannot translate these application-authored strings.

Exhaustive production census finds **3 Combobox render sites in 3 files**, yielding **4 concrete contexts**:

1. `routes/blueprints.new.tsx:275`: branch; translated placeholder/input label, no emptyText override.
2. `features/services/components/service-source-card.tsx:227`: source-edit branch; supplies **translated emptyText** at 233. This caller's empty text is source-established as overridden, not a live passing-control claim; keep its override.
3. `features/services/components/editable-field-row.tsx:234`: generic wrapper. Among **22 EditableFieldRow sites in 15 files**, exactly **2** pass `comboboxOptions`: `build-deploy-section.tsx:345` (repository) and **363** (branch). Keep the other 20 rows' existing select/input behavior.

The shared service Settings surface reaches web/private/worker/cron/static according to its source/build gates, including canonical static Settings and legacy `/web`, `/pserv`, `/worker`, `/cron`, `/static` aliases through the existing redirects. Datastore editors do not add another Combobox render site. No REST/GraphQL/MCP change is required.
