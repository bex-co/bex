# A `POST` to a path under a static site's local redirect rule answers `301`, where Render answers a bare `200`, and the rule's `301` lacks Render's `vary: Accept-Encoding`

Why: Render parity. A form or webhook that posts to a path a site redirects to another of its own paths reads `200` on Render and a `301` on bex, so its client follows a redirect it never gets on Render.

- **Render (captured 2026-11-28 ~01:05 UTC with `curl`):** `vue.onrender.com`'s local rule `/* → /index.html` answers `GET /no-such-path-m703` with `301` `location: /index.html`, `cf-cache-status: BYPASS` and `vary: Accept-Encoding`, but a `POST` to the same path, and to `/`, answers a bare `200` with `cf-cache-status: DYNAMIC`, as an `OPTIONS` to `/deep/x` does (w8/319's answer). A rule to a full URL still redirects every method: `POST https://wc3v.onrender.com/maps/X/map.jpg` answers `301` to `https://cdn.wc3v.com/maps/X/map.jpg`, as w8/324 captured, and its `GET` `301` also carries `vary: Accept-Encoding`.
- **bex (production pin `7d1dce861173`, static site `loopx-w4-m703-static` (disposable) in `bex-canary`, rule `/old → /index.html`, deleted after the walk):** `POST /old` answers `301` `location: /index.html` (`cf-cache-status: DYNAMIC`, correct); `GET /old` answers `301` `cf-cache-status: BYPASS` with no `vary`. `serveOtherMethod` (`lego/operator/internal/staticserver/staticserver.go`) sends every non-`GET` request a matched redirect rule covers to `serveRedirect`, local or not (w8/324 generalized from `wc3v`'s full-URL rules).
- **Do:** first capture which property decides it on Render: a local destination, or `vue`'s catch-all `/*` source (a Render site with a local, non-catch-all redirect rule answers it; a disposable Render static site works). Then answer `POST`, `PUT`, `DELETE`, `PATCH` and `OPTIONS` under that kind of rule with w8/319's bare `200`, and keep the `301` for the rest. Give every redirect rule's `GET`/`HEAD` `301` Render's `Vary: Accept-Encoding`. Record both in ADR029 and in ADR018's "Static site" row (`docs/ADR018/services-lifecycle.md`).
- **End state:** on a static site with Render's kind of rule, `curl -X POST` to a covered path answers `200` with `content-length: 0` and `cf-cache-status: DYNAMIC`, `GET` answers the `301` with `vary: Accept-Encoding`, and static-server tests cover both.
- **Size:** about 45m, plus the capture.
- **Source:** w4/m703 t006's parity walk, 2026-11-28.
