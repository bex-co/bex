# 380 — A static site's Suspend confirmation says it "scales to zero"

Why: a static site has no instances to scale (the shared static-server serves it), yet its Suspend confirmation reuses the web-service sentence "The service scales to zero and stops serving traffic." The sibling `w4/172` fixed the same reuse for cron jobs and gave private services and workers their own sentence. Static sites were left on the web wording.

**Severity:** minor (copy). **Estimate:** ~15m. **Source:** live `/qa-find-bugs w4` loop run g7b5, 2026-10-20 UTC, `muse.env`, workspace `bex-canary`. Fixtures (`qa-20261020-g7b5-static` `srv-dbbhqahq56vc73bn8ccg`, `qa-20261020-g7b5-web`) were deleted in-run; the session was revoked.

## Probe

- Static site → Settings → **Suspend** opens the confirmation: "Suspend qa-20261020-g7b5-static? | The service scales to zero and stops serving traffic. Its URL and certificates are kept, and you can resume it at any time."
- Behavior is correct: while suspended, `GET https://qa-20261020-g7b5-static.onbex.co/some/path` → `503 This service is suspended.`, `Retry-After: 3600`, `Cache-Control: no-store`. Resume (07:51:37Z) served 200 by the first poll (07:51:45Z).
- Only the copy is wrong.

## Root cause

`dashboard/src/features/services/components/service-row-actions.tsx:57-81` selects `services.confirmSuspendBody` for every type with a public host, and switches only to `confirmSuspendBodyNoUrl` (private/worker) or `suspendCronDescription` (cron). The `services.confirmSuspendBody` copy is in `dashboard/src/features/services/locales/en.ts:369-374`. The Settings card (`suspend-service-card.tsx:160`) uses the same selection.

## Fix (target behavior)

- Static sites get their own sentence, for example "The site stops serving and answers 503 while suspended. Its URL and certificates are kept, and you can resume it at any time."
- It is used by both the row-actions confirmation and the Settings card, en and zh.
- Web services keep "scales to zero".

## Acceptance

- A component test: static → the static sentence, web → unchanged, cron/private/worker → unchanged.
- Dashboard `yarn lint`/`yarn test` pass.
