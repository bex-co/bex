## Objective

Add a reproducible end-to-end proof using the pinned, unmodified Render CLI with `RENDER_API_KEY` unset and an isolated `RENDER_CLI_CONFIG_PATH`.

## Steps

1. Start from an empty CLI config and complete `render login` through a real browser.
2. Prove `render services` sees the human's workspace.
3. Force the stored access-token expiry and prove the next command refreshes automatically.
4. Log out and prove both the old access token and refresh token/chain are unusable.
5. Repeat with a second user and prove the first user's logout does not affect it; prove the fixed client remains.

## Files

- a focused auth/CLI E2E script under `scripts/`
- `.pm/w3/dev-3/` harness wiring
- `.pm/w9/m4/t003.md` coordination
- sanitized evidence under this milestone

## Acceptance criteria

- [ ] The full flow is one documented, repeatable green run against local auth and production; evidence records CLI commit + bex digest without credentials.
- [ ] The test fails if refresh is disabled, logout only removes local config, the shared client is deleted, or one user's revocation affects another.

## Out of scope

- Forking or patching the CLI.
- Treating `RENDER_API_KEY` as proof of browser login.
