## Objective

Browsers that cached the HTML shell under a real chunk URL keep it for a year (`immutable`), and chunks whose content is unchanged keep their name across builds (`vendor-react-v-sG7it2.js` was 27 days old at the edge). One release must therefore move every asset to a new URL, so no poisoned entry is ever requested again.

## Steps

1. Change the asset directory or prefix once, in the same release as t001, for example `build.assetsDir` (`dashboard/vite.config.ts:412`, today `"assets"`) to a new name. Move t001's 404/immutable handling to the new prefix, and keep answering the old `/assets/*` prefix with 404 `no-store`.
2. Update anything that names `/assets/`: CSP, tests, docs and the route rules.
3. Note in the README that there is no Cloudflare purge (the deploy token is DNS-only, `.github/workflows/deploy.yml:702-706`). Edge copies of HTML under old URLs simply stop being requested.

## Acceptance criteria

- [ ] After the release, the live `index-*` entry and all its chunks are under the new prefix.
- [ ] A browser that had HTML cached under an old chunk URL loads every service page.
- [ ] `/assets/<old chunk>` answers 404 `no-store`.

## Out of scope

- Repeating the move on later releases. t001 keeps new poisoning from happening.

## Outcome (2026-11-14)

- `build.assetsDir` is now `ASSETS_DIR = "_assets"` (`dashboard/server/security-headers.ts`). `/static/` was avoided because it is the static-site route. The immutable rule moved to `/_assets/**`; `/assets/**` has no rule and is answered by the miss handler, `404 no-store`, for every path.
- Updated the error-page test fixtures and the `vite.config.ts` sourcemap comment. Nothing else names `/assets/` (CSP is origin-based; no docs or deploy file did).
- No Cloudflare purge exists (the deploy token is DNS-only, `.github/workflows/deploy.yml:702-706`); edge and browser copies under `/assets/` simply stop being requested. Noted in the milestone README.
- The live acceptance (the live `index-*` under `/_assets/`, a poisoned browser recovering) is t006's production replay.
