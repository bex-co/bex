Why: customers using Chinese still encounter English chart descriptions and “No data in range,” although the surrounding Metrics controls and event markers use their selected language.

**Severity:** minor. **Estimate:** 45m. Source: continuous functional `$qa-find-bugs w4`, a434, 2026-10-14 UTC. Goal: the usable hosting dashboard under ADR008 and the repository's requirement that user-facing strings use `useTranslations`. Filing only; no product changes.

## Cause and bounded fix

There are three independently traced literals:

- `dashboard/src/features/metrics/components/svg-line-chart.tsx:105` writes the English template directly to the SVG's `role="img"` accessible name.
- `svg-bar-chart.tsx:104` does the same for a bar chart.
- `svg-line-chart.tsx:252–267` defaults `EmptyChart.message` to `"No data in range"` and renders it directly. `SvgLineChart:68` and `SvgBarChart:78` call that default when there are no points. The Network card's latency chart (`network-metrics-card.tsx:363`) is one live example; `MetricSection:39–79` already distinguishes loading/errors from settled children, so this is not a swallowed-error fix.

All three literal families exist in original commit `fde064959`. No inspected subsequent symbol commit localizes them; the live behavior agrees with current source. This is an uncovered chart translation gap.

**Target:** translate the two chart image names and the default empty-window message using the existing Metrics catalog. English names must use native singular/plural forms, including “1 data point”; Chinese gets its `_other` form. Pass numeric `count: frames.length`, preserving today's union-of-sample-times count, rather than substituting series count, tick count, or request volume. Preserve `role="img"`, focus/keyboard behavior, and the actual numeric data.

Put `useTranslations` before any conditional chart return so empty→populated transitions obey React's hook rules. Resolve the default message inside `EmptyChart` only when the caller omitted `message`; explicit translated overrides, including an explicit empty string, must retain their current behavior. Keep pending geometry and the loading, no-limit, percentage-unavailable, throttled, source-unavailable, and generic-error distinctions.

The layer can express this directly: `EmptyChart` accepts `message?: string`, and SVG `aria-label` accepts the translated string. The neighboring `chart-event-markers.tsx:78` already uses `t("metrics.eventMarkersLabel")` and is observed as `服务事件`. `use-translations.ts:20–56` passes numeric plural counts through to i18next. Installed `react-i18next` **17.0.8** subscribes to language changes (`dist/commonjs/useTranslation.js:53–99`, default `bindI18n: "languageChanged"`); installed i18next **26.3.4** selects plural keys for numeric counts (`dist/cjs/i18next.js:598–605,817–842`). The configured `{count}` interpolation and catalog-before-switch sequence are in `i18n/init.ts:25–29,130–133`. Reuse them; no translation-framework or global language-loader change is needed.
