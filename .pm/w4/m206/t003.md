## Objective

Make the serial full-replace group move report a consistent or explicit recoverable outcome; reconcile actual source/target placement before another write and remove selections that have left the canonical source.

## Context

- setResourceMembers mutates each group then returns immediately on a later failure.
- Desktop timed out with a split and one source row/Selected:2; mobile timed out but eventually moved both.

## Steps

1. Define owned compensation or explicit partial-outcome handling that survives a superseding writer without overwriting it.
2. On an uncertain mutation result, read source and target after older active reads settle; mark reconciliation pending and block another Move until authoritative state resolves.
3. Prune only departed canonical membership IDs on ready data; preserve hidden-by-search selections and give a failed placement read a read-only retry.

## Acceptance criteria

- [ ] Settled normal move has both target IDs, empty source and no source selection.
- [ ] A failure after the first write is not presented as unchanged placement; remaining selections match ready canonical membership.
- [ ] The observed filtered-select-all control continues selecting both after clearing search.
