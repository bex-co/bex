# Team table: every role picker is an unnamed combobox and every row's delete control is just "Remove"

Why: on the workspace Team list a screen-reader or voice-control user hears "combobox, Admin" and "Remove, button" once per member, with no member named. Changing or removing the wrong person is one misstep away. `w4/084` fixed this exact shape for `RevokeIconButton` callers, and this row uses plain `Button`/`Select` instead, so it was never in that sweep.

Found live, `/qa-find-bugs` pass 175, 2026-09-26 (w4-targeted, `muse.env` credentials), `/workspace/settings#team`, read-only (nothing was changed).

- **Accessibility tree at filing** (`page.locator('main').ariaSnapshot()`), three members:
  - `row "puncsky@gmail.com You Owner …"` → `combobox [disabled]: Admin`, `button "Remove" [disabled]`
  - `row "onlyif2009@gmail.com …"` → `combobox: Admin`, `button "Remove"`
  - `row "puncsky+viewer@gmail.com …"` → `combobox: Viewer`, `button "Remove"`
- **Root cause:** `dashboard/src/features/team/components/member-row.tsx:119` renders the role `SelectTrigger` with no `aria-label`/`aria-labelledby`. `:145` and `:159` give both Remove variants `aria-label={t("team.remove")}`, a bare verb.
- **Sibling found in pass 184 (2026-09-26):** the environment group page's Linked Services list renders each row's control as `button "Unlink"` (`dashboard/src/features/env-groups/components/linked-services-card.tsx:150`, `envGroups.unlinkButton`), with no service named. Clicking it redeploys that service immediately, with no confirmation (live: `QA_GRP` vanished from the running process about 13s later). Same fix: "Unlink <service name>".
- **Fix:** name both controls after the member, as `w4/084` did, for example "Role for onlyif2009@gmail.com" and "Remove onlyif2009@gmail.com" (en + zh), and extend `w4/084`'s guard test to cover this component. The disabled owner row should keep its existing permission explanation.
- **Checked and correct:** "Leave workspace" is disabled for the owner, and its reason ("You own this workspace, so you cannot leave it. Transferring ownership is not available yet.") is reachable by both hover and keyboard via `PermissionTooltip`'s focusable wrapper with `aria-describedby`. That is the accessible pattern `w4/143`'s SSH hint should adopt instead of `title=`.

Estimate: ~20m (both surfaces).
