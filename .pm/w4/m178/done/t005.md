## Completion (2026-10-11, rerun)

The new test is `move-refreshes-source-environment.test.tsx`, built from:

- a real `ApolloClient`/`InMemoryCache`;
- a real Router;
- the real `EnvironmentsPanel` and `EnvironmentCard` rows and counts, with polling disabled;
- a scripted server with single-valued membership.

It runs eight cases:

- Move for service, Postgres and Key Value.
- Remove for service, Postgres and Key Value.
- Mutation refusal.
- Refresh rejection.

The cases also cover menu unmount, unrelated members, the unrelated project's watcher, exactly one write, and no Project read on Remove.

A pre-write `Environments` read is held and released newest-first:

- **On the old hook:** 7 of 8 cases fail.
- **With the settle step removed:** the three Move cases fail.
- **With only `queryDeduplication:false` removed:** the suite still passes. That option is defensive and follows the rename pattern.

The unit tests now assert the source Environments read for Move and Remove, and no read for an ungrouped move. Dashboard `yarn lint` passed, and `yarn test` passed 492 files and 4528 tests.
