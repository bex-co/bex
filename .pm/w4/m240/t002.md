## Objective

A rule whose destination names a placeholder its source does not declare, or whose source repeats a name, is refused with `400` naming the rule index and token, on every writer.

## Context

- `lego/backend/internal/apps/service.go:5295` `validateRoutes`, shared by REST `PUT/POST/PATCH …/routes`, GraphQL `setStaticRoutes` and MCP `update_static_routes`.
- The Blueprint `routes:` apply path: find its validator and confirm it reaches `validateRoutes`, or add the same check.

## Steps

1. Parse source `:name` segments with the same grammar as t001; keep the backend and operator parsers in step with a shared-vector or drift-guard test (the module DAG forbids importing the operator from the backend).
2. Refuse undeclared destination tokens and duplicate source names, e.g. `routes[0].destination references :y, which routes[0].source does not declare`.
3. Decide how already-stored rules that now fail behave on read — reads must not break and existing sites keep serving — and record the choice here and in ADR029 (t003).

## Files

- `lego/backend/internal/apps/service.go` and its tests; the Blueprint routes validator.

## Acceptance criteria

- [ ] REST, GraphQL, MCP and Blueprint tests each refuse `/a/:x` → `/b/:y` and `/a/:x/:x`, and accept Render's two doc examples.
- [ ] `cd lego/backend && go test ./...` and lint pass.

## Out of scope

- Runtime matching (t001).
