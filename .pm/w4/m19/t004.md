## Objective

The public platform host becomes `<spec.subdomain>.<BEX_BASE_DOMAIN>` instead of `<app.Name>.<BEX_BASE_DOMAIN>`, so the globally-unique slug from t002 — not the per-workspace name — owns the URL axis, and two same-named Apps can never emit Ingresses claiming the same host.

## Context

- Host derivation: `effectiveHosts` at `lego/operator/internal/controller/app_controller.go:1058` (`fmt.Sprintf("%s.%s", app.Name, baseDomain)` at `:1069`); static-site mirror at `lego/operator/internal/staticserver/resolver.go:134-135`.
- `Status.URL`/`Status.URLs` written at `app_controller.go:473/493/523-526` from `effectiveHosts(...)`.
- The operator is mechanism-only and DB-free — it must read the slug from the CR spec (t002), never from the store.
- Backward compatibility: Apps without `spec.subdomain` (pre-migration CRs, direct `kubectl apply` like `examples/whoami-app.yaml`) must keep working — fall back to `app.Name`.

## Steps

1. `effectiveHosts`: prefer `spec.subdomain` when set, fall back to `app.Name`; same in `staticserver/resolver.go`.
2. Verify Ingress/cert host, status URL, and the custom-domain DNS-target derivation (`BEX_BASE_DOMAIN` surface, docs/ADR005) all flow from `effectiveHosts` and pick up the slug.
3. Controller tests: slug set → host uses slug; unset → unchanged legacy host; static-site resolver same.
4. `make test` from `lego/operator/`.

## Implementation notes (2026-07-13)

- Both `effectiveHosts` copies (controller + staticserver) prefer
  `spec.Subdomain`, falling back to `app.Name` — Ingress/status URL and the
  static-site resolver stay agreed since they share the same fallback rule.
- Also fixed `apps.Service.platformHost` (`lego/backend/internal/apps/domains.go`)
  — the custom-domain DNS-instructions surface (docs/ADR005) had its own
  independent `app.Name + "." + BaseDomain` computation that would have kept
  pointing tenants at the wrong (potentially colliding) CNAME target; it now
  prefers `spec.Subdomain` too.
- New tests: `hosts_test.go` cases in both operator packages (`controller`,
  `staticserver`) covering slug-set and slug-unset.
