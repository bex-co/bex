# A webhook's filtered delivery list says "No deliveries yet — trigger a deploy" while the Failed tab holds eight

Why: selecting **Successful** (or narrowing the Sent after/before range) on a webhook that has delivered, but only failed, tells the user nothing has ever been sent and to go trigger a deploy. That is a dishonest empty state on the very screen used to debug a broken endpoint.

Found live, `/qa-find-bugs` pass 168, 2026-09-25 (w4-targeted, `muse.env` credentials), webhooks (journey 14's notification half). Fixtures: webhook `qa-20260925-hook` (`whk-darmc6uuag9c73eddc90` → `https://example.com/qa-bex-hook`, the 8 Deploy-family events) and static site `qa-20260925-hooksite` (`srv-darmclmuag9c73eddcdg`), whose first deploy fired the events. Both were deleted the same pass.

- **Repro:** webhook → Activity. The **All** tab lists 7–8 attempts, each `Failed · HTTP 405`, with attempt 1 and retry attempt 2 rows. Click **Successful**.
- **Actual:** "**No deliveries yet** — Trigger a subscribed event — a deploy, for example — to see it here." Clicking **Failed** immediately shows 8 rows.
- **Root cause:** `dashboard/src/features/webhooks/components/webhook-deliveries-card.tsx:194-199` renders `webhooks.historyEmptyTitle`/`historyEmptyBody` whenever the *filtered* `deliveries` array is empty, regardless of the active status tab or date range.
- **Fix:** distinguish the filtered-empty state ("No successful deliveries" / "No deliveries in this range", with a clear-filters action) from the true first-run state, which is shown only when no filter is active. The same distinction exists elsewhere in the dashboard (the Logs tab's "No logs match these filters"). en + zh.
- **Checked and correct this pass:** creation shows the signing secret once. Every attempt is its own row with the attempt number, retries land (attempt 2), the status and HTTP code match reality (`example.com` answers POST with 405), the response button expands the request payload and endpoint response inline, and the event link returns the event JSON.

Estimate: ~20m.
