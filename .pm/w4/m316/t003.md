## Objective

Enumerate every Key Value write that changes the Valkey pod template, and so restarts a running Persistence Off store and empties it. Confirm each one now warns or asks for the phrase.

## Context

- **Pod-template inputs:** `valkeyArgs` (`lego/operator/internal/controller/keyvalue_controller.go:227-253`) takes the persistence mode, maxmemory policy, and the plan's memory budget. The plan also sets the container resources (w4/m263 cites `kvResources`). Version upgrades and anything else that touches the template are to be checked.
- **Already guarded:**
  - persistence-mode change (typed phrase);
  - first external-access enable (m233, `requireRestartConfirmation`);
  - Blueprint `ipAllowList` (w4/358);
  - plan change (m263: copy plus the dashboard phrase).

## Steps

1. List every spec field that feeds the pod template, and every writer of each field across REST, GraphQL, MCP, Blueprint and the dashboard.
2. For each pair, record whether it warns or asks on a running Off store. File anything still silent as a follow-up.
3. Add regression tests for the writers that already behaved correctly (plan, persistence, external access), so this fix cannot loosen them.
