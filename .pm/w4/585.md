# 585 — Static sites have HTTP request logs on bex; Render has none — keep them with a recorded sign-off, or drop them

Why: Render says "Render does not emit logs for static sites" (render.com/docs/logging), and a live `type=request` read of a Render static site returned no lines on 2026-11-11 (w4/m325, `docs/render-artifacts/request-logs.md`). bex ships and serves request lines for static sites (w4/m113's static-server attribution, `TestShipperAttributesStaticSiteRequestLines`). Under the parity rule a divergence stands only with the user's sign-off in ADR018, and this one has none.

- **Source / severity / estimate:** w4/m325 t004 and the `/simplify` review, 2026-11-11. **Minor** (a superset). ~20m either way.
- **Options:**
  - (a) Keep them as a Bex extension, recorded in ADR018's Request row with the user's sign-off.
  - (b) Drop static-site request lines from the read path, or in the shipper. Then make the Logs tab's Request type unavailable on a static site.
- **Parity-sufficient default if no sign-off is given:** (b).
- **Dedupe:** w4/m113 (done) added the static-site attribution; no open item questions it.
