# 540 — Every custom domain's DNS panel names its verify button just "Re-check"

Why: with an apex+www pair, the Custom Domains table has two buttons a screen reader announces only as "Re-check", while every other per-domain control in the same rows names its domain.

- **Source / severity / estimate:** live `/qa-find-bugs w4` loop, round 6, 2026-11-10 08:58 UTC (`muse.env`, workspace `bex-canary`, pin `4630a48a765e`). Fixture: the service and throwaway pair from [w4/539](539.md), all removed. **Minor** (accessibility). ~15m.
- **Probe:** the button names in each table row, read from the accessibility tree:

  | row | buttons |
  | --- | --- |
  | `qa20261110-bexqa-nx.com` | "Show DNS setup for qa20261110-bexqa-nx.com", "Actions for qa20261110-bexqa-nx.com" |
  | its DNS row | **"Re-check"**, "Copy ALIAS host for qa20261110-bexqa-nx.com", "Copy ALIAS target for …", "Copy A host for … (49.12.20.236)", "Copy A target for … (49.12.20.236)" |
  | `www.qa20261110-bexqa-nx.com` | "Show DNS setup for www…", "Actions for www…" |
  | its DNS row | **"Re-check"**, "Copy CNAME host for www…", "Copy CNAME target for www…" |

- **Root cause:**
  - `dashboard/src/features/services/components/custom-domains-section.tsx:425-433` (`DnsInstructions`) renders `<Button …>{t("services.domainRecheck")}</Button>` ("Re-check", `features/services/locales/en.ts:1774-1777`) with no `aria-label`, although `domain` is in scope.
  - The row's other controls use `services.domainActionsMenu` ("Actions for {domain}", `en.ts:1621`) and `services.domainDnsToggle` ("Show DNS setup for {domain}", `en.ts:1722`).
- **Fix:** add `aria-label` "Re-check {domain}" under a new key, in en and zh, leaving the visible text unchanged. The busy state keeps the name.
- **Dedupe:**
  - [w4/537](537.md) (the env-groups-panel Link/Unlink) and w4/150 cover other components.
  - w4/353 only mentions the Re-check toasts.
  - No open item.
- **DoD** (live): with an apex+www pair, the accessibility tree lists `button "Re-check <apex>"` and `button "Re-check www.<apex>"`, and the zh locale names them too.
