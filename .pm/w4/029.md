# codex-security round-4: P2/P3 register

Filed 2026-08-09 from the triage of `codex-security-bex-JOJ6g5` (scan of `e815388e`). All 16 findings were verified against the code; the six P0/P1 items became **w4/m33**. These ten are the remainder — each is real, none is urgent. Several are one-liners and could be grouped into a chores milestone; #6 and the OpenFGA outbox are design-sized.

## Rate-limit identity behind Traefik (report #10) — the widest of these

`callerKey` (`lego/backend/internal/api/ratelimit.go:92`) and `cliauth`'s limiter (`internal/cliauth/ratelimit.go:81`) both key on `r.RemoteAddr`, and nothing in `lego/backend` reads `X-Forwarded-For`. Traefik is the TCP peer for every public request, so three "per-source" budgets are actually **global**: device flow 30/min, deploy-hook lookup 60/min, webhooks 600/min. The device one is the sharp edge — anyone can hold `render login` broken platform-wide at 30 req/min, turning an anti-abuse control into the DoS lever. Fix: trust forwarded addresses only from an explicit trusted-proxy CIDR, keep a separate global ceiling.

**Same root cause, not in the report:** `lego/operator/config/ssh/ingressroutetcp.yaml` sets no `proxyProtocol`, and `nativessh/server.go:207` records `conn.RemoteAddr()` into `ssh_sessions.remote_address` — so every SSH audit row stores Traefik's pod IP and the ADR035 audit trail cannot attribute a session to a source.

## The rest

- **#13 Blueprint path (one-liner).** `approvedBlueprintPath` is called only at `blueprint.go:85` (create/preview). `UpdateBlueprint` (`:700`) persists any nonempty path, and `runSync` fetches it with the workspace installation token. Validate at the storage and fetch boundaries, not in discovery.
- **#14 Metrics budgets.** REST calls `checkQueryRange`; GraphQL (`graphql.go:282`) and MCP (`mcp.go:20-83`) do not, and all three loop over uncapped `resources` × `metricTypes` × `quantiles`. Move range + cardinality + work-product checks into the shared service entry point.
- **#12 Registry-credential delete ≠ revoke.** `registrycreds.Service.Delete` removes the row and the OpenBao value only. The derived per-App `<app>-registry-pull` Secrets carry username/password/auth in plaintext, have no ownerRef by design, and are reaped only on **App** delete (`apps/pullsecret.go:113`). Deleting after a suspected leak leaves the copies live. Refuse deletion while bindings exist, or clear bindings + Secrets first.
- **#16 Static server `ReadTimeout`.** `cmd/staticserver/main.go` sets ReadHeader/Write/Idle but no `ReadTimeout`; GET/HEAD handlers never reject bodies, so a declared-but-withheld body can pin a goroutine on the single-replica server. Mechanism depends on Go's unread-body drain and Traefik sits in front — verify before investing. One-line fix regardless.
- **#9 SSH pre-auth cap.** `nativessh/server.go:164` starts a goroutine per accepted socket; the session limiter is acquired only after handshake + key auth + authorization. The 10s handshake deadline bounds it but caps no concurrency. Add a pre-auth semaphore.
- **#11 Deploy-hook token in the URL path.** `deploy/gitops/base/values/traefik.values.yaml` keeps `RequestPath` (`defaultMode: keep`, headers dropped) — the comment says so explicitly — so every hook invocation writes a reusable credential into edge logs. Redact the route or move the capability into an Authorization header behind a non-secret id.
- **#15 Mobile push after account switch.** `registration-controller.ts:100` disables the local preference before the fallible remote unregister; a failure leaves the server row owned by the old subject while `inspectAndRepair` refuses to re-register. Low practical impact — push is release-gated per ADR052 — fix during mobile hardening.

## Two findings triaged as NOT code bugs

- **#5 agent GitHub token branch scope — accepted with mitigation.** `MintSessionInstallationToken` requests `contents: write` scoped to one repo; GitHub installation tokens genuinely cannot encode a ref scope, and `docs/ADR047-cloud-coding-agent-sessions.md:99-107` already says so. The branch check in `agentsession/mint.go` is an intent check, not confinement. The compensating control is a repository ruleset restricting the App to `bex-agent/*` with no bypass — verify it exists, don't patch Go.
- **#6 bex-api cluster-wide CR writes — partly valid, narrow slice actionable.** The RBAC and automount claims are correct, but `bex-api-app-admission.yaml` plus `AppReconciler.canonicalNamespace` already confine Apps to `tea-*` or `default`. The real delta: **`databases` and `keyvalues` have no admission policy and no reconciler namespace guard** (`canonicalNamespace` exists only in `app_controller.go`), so those two CRs can be planted in any namespace including platform ones. Mirror the App policy for them. The report's "minimal tenant-aware projector" rewrite is an ADR-level item, not this.
