## Objective

List every workflow job that holds production credentials and what it prints to its log, so the redaction covers all of them.

## Context

- Jobs that run `scripts/fetch-app-kubeconfig.sh`, use a `production-*` environment, or read `HCLOUD_TOKEN`, `BEX_SSH_PRIVATE_KEY` or a production database DSN.
- Known printers: `.github/workflows/cluster-diagnose.yml` (12 `kubectl` reads, including `get pods -A -o wide`, `describe nodes` and `describe pod`) and `.github/workflows/app-cluster.yml` (2).
- The repository is public: run logs and artifacts are readable by anyone.

## Steps

1. `grep -l` the workflows for the markers above.
2. For each job, read its most recent run log (`gh run view <id> --log`) and note which tenant data appears: namespaces (`tea-…`, `<ws>-sandbox`), workspace or service ids, service names in pod names, node names and IPs, event messages, image references.
3. Record the table (job, what it prints, tenant data yes/no, run ids carrying it) under `## Findings` in this milestone's README.
