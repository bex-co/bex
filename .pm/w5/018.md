# Metrics page needs an event timeline

Live Render overlays a filterable event timeline above application metrics so a
deploy or lifecycle change can be correlated with chart movement. bex has the
metrics and Events surfaces separately but no correlation strip on Metrics.

Add the service-event timeline to Metrics using the existing events query and
time window. Keep request-metric host/path functionality out of this note; it
is already owned by `w3/m18`.

Acceptance: Metrics displays events within the selected range, offers the
equivalent event filtering, and tests cover range/filter propagation and empty
states without duplicating event-fetch logic.
