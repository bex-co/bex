## Objective

Tests that need an external dependency skip locally with a hint but fail under CI, so a CI job can never silently stop running them.

## Context

- 59 backend test files skip unless `BEX_TEST_DB_URI` and `BEX_TEST_OPENFGA_URL` are set (e.g. `lego/backend/internal/api/envgroups_ownerid_e2e_test.go:52`).
- `lego/backend/internal/usage/instance_seconds_query_test.go:50-53` skips without promtool; `lego/operator/internal/controller/keyvalue_persistence_engine_test.go:36-37` skips without `BEX_TEST_VALKEY=1`.
- GitHub Actions sets `CI=true`. The module DAG is operator→types←backend, so each module gets its own small helper; types is the CRD contract, not a home for test helpers.

## Steps

1. Add `testenv.Require(t, name, available, hint)` in `lego/backend/internal/testenv` and `lego/operator/internal/testenv`. It calls `t.Skipf` locally and `t.Fatalf` when `CI` is set, unless the dependency is listed in `BEX_TEST_ALLOW_SKIP`.
2. Unit-test both branches.
