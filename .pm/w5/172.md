# A Blueprint `dockerContext: /` means the repository root, as on Render

Why: Render's `minio` template sets `dockerContext: /` (the repository root). bex refuses it ("dockerContext must be a relative path with no '..' components"), so the template fails on bex.

- Treat a leading `/` as repository-root-relative: `/` becomes `.` and `/sub` becomes `sub`. Keep refusing `..`. Apply the same rule to `dockerfilePath` and `rootDir` if Render accepts it there.
- Guard: `knownBlueprintGaps` lists `"dockerContext must be a relative path"` for this note. Remove it when this ships.
