## Objective

Write down the navigation convention this milestone establishes, so the next contributor adding a contextual dashboard surface extends `DashboardSidebar` instead of mounting another `<aside>` — the mistake that produced this milestone.

## Context

- `docs/ADR047-cloud-coding-agent-sessions.md` § D9 ("Dashboard session surface: one render layer, two swappable data sources", line ~165) is the governing record; `agents.tsx`'s docstring already cites "ADR047 D9". The header's decision log should note the correction alongside the existing D9 entries.
- The convention has three parts worth stating explicitly:
  1. **One rail, always.** A page never renders a second sidebar landmark; contextual navigation is a branch inside `DashboardSidebar`.
  2. **Two branch flavors, and when to use each.** `ProjectSidebar`/`ServiceSidebar` **replace** the nav (deep hierarchical context with a back link); the agents branch **augments** it (a peer working-set list under the global nav). Devin does the augmenting flavor throughout — its rail keeps global nav above a per-section `Recent` slot.
  3. **The contextual list is section-scoped**, not global: sessions appear on `/agents*` only, mirroring Devin's slot showing sessions on session routes, pull requests on `/review`, and nothing on `/automations` / `/wiki`.
- Devin evidence to cite: `.playwright-mcp/devin-home.png`, `devin-review.png`, `devin-automations.png`, `devin-collapsed.png`, `devin-recent-menu.png` (captured 2026-08-07).
- Devin affordances deliberately **not** ported (t002) — session folders, the Filter control, row archive — should be named here as unshipped-capability gaps, not as drift. File a `w5/NNN` inbox note only if one looks genuinely wanted; do not create milestones for them.

## Steps

1. Amend ADR047 D9 with the one-rail convention and the two branch flavors, dated 2026-08-07, citing the user directive and the Devin evidence.

3. If `dashboard/CLAUDE.md` documents layout conventions, add a one-line pointer there — that file is what a dashboard contributor reads first.
