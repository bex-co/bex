## Objective

Lock the tightened behavior-hint guarantees with targeted unit/guard tests in `internal/mcputil` and `internal/api`, and update `docs/ADR018-render-parity.md`.

## Context

- Keeping explicit tests on `mcputil.DefaultAnnotations` and on key fixed extension tools prevents future verb-default edits from silently reverting `verify_custom_domain` or `archive_agent_session` back to `DestructiveHint: true`.

## Steps

1. Add tests in `lego/backend/internal/mcputil/mcputil_test.go` covering `DefaultAnnotations` across read, create, and default write verbs and verifying non-nil `DestructiveHint`/`OpenWorldHint` pointers.
2. Add assertions in `lego/backend/internal/api/mcp_parity_test.go` verifying:
   - Every tool on `Server.MCPServer()` sets explicit non-nil `DestructiveHint` and `OpenWorldHint` pointers.
   - `verify_custom_domain`, `archive_agent_session`, `unarchive_agent_session`, `attach_agent_session`, and `wait_agent_sessions` carry their expected non-destructive/idempotent hints.
3. Update `docs/ADR018-render-parity.md` § Types and behavior hints to note that all four hints (`readOnlyHint`, `destructiveHint`, `idempotentHint`, `openWorldHint`) are now guarded against `render-mcp-tools.json`.
4. Run `npx prettier@3.4.2 --write docs/ADR018-render-parity.md` and `bash scripts/docs-links-validate.sh`.
