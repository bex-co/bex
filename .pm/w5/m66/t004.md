## Objective

Standing cross-surface check, re-scoped for this plane: Render has **no** agent-session conversation API to compare against (bex extension, ADR047 D9), so instead verify the part-shape change is consistent across every **consumer** of the driver's UI-message stream — dashboard **and** mobile (w11) — and that the byte-transparency contract still holds end to end. Confirm the REST/GraphQL/MCP agent-session field shapes are unchanged (no accidental surface drift).

## Context

- Consumers of the driver stream: dashboard agent-session feature (t003), mobile (`w11`, e.g. `w11/m7`), and any AI-SDK client (D3 promise: "any Vercel AI SDK client consumes a session natively").
- Byte-transparency chain that must stay intact: driver `x-vercel-ai-ui-message-stream: v1` → gateway `agentattach.go` (verbatim splice/tee) → bex-api attach-ticket surface → edge routing. None of these change in this milestone.
- REST/GraphQL/MCP agent-session verbs (`Create`/`Resume`/`Steer`/`AttachTicket`/`Get`/`List`, `agentsessions/{rest,graphql,mcp}.go`) — field shapes/semantics unchanged; this task confirms that, it does not modify them.

## Steps

1. Confirm the mobile client renders the new typed parts (or file a scoped w11 follow-up if it still hard-codes the `data-acp` shape — do not silently diverge).
2. Verify the gateway still forwards verbatim and the transcript tee/store + ADR051 Completer log-harvest persist the new parts unchanged (no gateway/bex-api code change needed).
3. Diff the REST/GraphQL/MCP agent-session responses before/after to confirm no field/semantic drift.
4. Record any consumer that lags (mobile) as an explicit follow-up note rather than leaving it inconsistent.

## Files

- Read-only verification across `lego/backend/internal/agentsessions/`, `lego/backend/internal/sshgateway/agentattach/`, `dashboard/`, `w11` mobile client; new follow-up note only if a consumer lags.

## Acceptance criteria

- [ ] Dashboard and mobile both render the new typed parts, or a lagging consumer is filed as a scoped follow-up (not silently diverged).
- [ ] Byte-transparency verified intact: `x-vercel-ai-ui-message-stream: v1` preserved; gateway/transcript/Completer unchanged.
- [ ] REST/GraphQL/MCP agent-session field shapes confirmed unchanged.

## Out of scope

- Any render.com parity comparison (no equivalent API exists).
- Implementing a full mobile refactor if one is needed (file it to w11).
