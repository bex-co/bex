## Objective

Under Wait, a restart no longer supersedes the in-flight deploy: it queues and, when it runs, restarts whatever release is serving at that moment (the newly deployed one if it succeeded).

## Context

- `lego/backend/internal/deploys/service.go` (`Restart`, `restartSelectedRelease`)
- the w8/m121 Wait queue for ordinary deploys

## Steps

1. Reuse the Wait queue for restarts.
2. Defer release selection to dispatch time.
3. Keep Override behavior for Override-policy workspaces.

## Files

- `lego/backend/internal/deploys/service.go`
- `lego/backend/internal/deploys/rollback_config.go`

## Acceptance criteria

- [x] Under Wait, no deploy row is closed "Canceled by restart"
- [x] The restart runs on the release that is serving when it dispatches
