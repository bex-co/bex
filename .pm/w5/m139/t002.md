## Objective

`/v1/logs/subscribe` (WebSocket, SSE and NDJSON) streams a managed Postgres or Key Value resource's logs live by following its pods' logs, applying the same instance, text and level filters and the same per-line parsing as the historical datastore read.

## Context

- `lego/backend/internal/logs/rest.go:195-223` — the subscribe handler authorizes each resource, then calls `unsupportedLiveResource` before any streaming header or 101 (the pinned CLI reads a closed socket as a finished tail — w8/083).
- `lego/backend/internal/logs/service.go:136-179` — `PodLogStream`/`PodLogsFollow`, the followed pod-log producer the app tail already uses.
- `lego/backend/internal/datastorelogs/logs.go` — the direct-pod historical read (`Collect`, `readPod`, `parseLine`) and how datastore pods/containers are selected; the tail must select the same pods and drop the same CNPG chatter.
- `acquireSubscription` enforces the subscription limit; a datastore tail counts like any other.

## Steps

1. Replace `unsupportedLiveResource` with a datastore producer: resolve the resource's pods (all instances, or the `instance` filter), follow each with `PodLogsFollow`, parse with `datastorelogs.ParseLine`, filter text/level, and fan in to the existing stream writers.
2. Handle pods that come and go mid-tail (a replica added, a failover restart) the way the app tail does, without ending the stream.
3. Keep the refusal ordering: authorization first, then any named refusal, then the upgrade.

## Files

- lego/backend/internal/logs/rest.go
- lego/backend/internal/logs/service.go
- lego/backend/internal/datastorelogs/logs.go

## Acceptance criteria

- [ ] A subscription to an authorized `dpg-`/`red-` resource streams lines written after it opened, over WebSocket and SSE.
- [ ] An unauthorized or unknown datastore id is refused identically to the historical query, before streaming starts.
- [ ] `instance`, `text` and (from t001) `level` narrow the live stream exactly as they narrow the historical query.

## Out of scope

- Store-only structured filters, which have no live producer for pod lines (ADR010).
