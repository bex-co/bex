## Objective

Live Render offers Export beside the Environment variable/file controls; bex's Environment tab supports editing, secret files, and group links but has no export action. Add a safe export of the current service environment that never exposes masked/unavailable secret values as if they were recoverable.

## Context

- Absorbed from `w5/017` (dashboard walk — Environment, 2026-07-15).
- Reuse the existing secret-service semantics; provide a clear degraded/error state (e.g. OpenBao unavailable ⇒ no partial export that silently omits values).

## Steps

1. Add the Export action (download/copy) with a deterministic, documented format.
2. Wire the masked-value rule: values the UI can't reveal are never emitted as placeholders that look real.
3. Tests: format determinism, masked-value handling, degraded state.

## Files

- dashboard/src/features/services/ (Environment tab components/hooks)
- affected tests

## Acceptance criteria

- [ ] Environment page has an Export action with a deterministic format pinned by tests.
- [ ] Secrets never leak through a fallback or stale client cache; masked values are handled explicitly.
