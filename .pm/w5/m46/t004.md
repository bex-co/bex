## Objective

Turn the successful negative control, shim handoff, and real SQL runs into reproducible, credential-safe evidence and update the CLI ledger only to the level actually proven.

## Context

- `docs/cli-compatibility-checklist.md` currently leaves `pgcli [id|name]` unchecked solely because the interactive-only guard fires in its non-TTY sweep.
- The checklist pins Render CLI v2.21.0 and distinguishes real bex gaps from environment limitations.
- Evidence must be sufficient to rerun the proof but must not include a raw terminal recording, bearer token, password, or connection URI.

## Steps

1. Document the source-level execution contract, PTY method, pinned versions, non-production prerequisites, redaction rules, exact safe probe, id/name outcomes, negative control, and cleanup proof.
2. Add the new verifier invocation to `scripts/cli-compat.sh`'s documented command surface.
3. Change the checklist row to `[x]` only after both real id/name SQL runs pass; otherwise retain `[ ]` and record the exact remaining gate.
4. Inspect ADR018 for stale CLI claims and update only claims directly changed by this proof.
