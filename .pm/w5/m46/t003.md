## Objective

Replace the contract shim with a real installed `pgcli` and prove the complete interactive session against a disposable public bex Postgres, including a harmless query, clean exit, and unconditional fixture cleanup.

## Context

- The shim proves the official CLI's resolution and exec contract but cannot prove a real `pgcli` accepts the emitted URI or completes the TLS/database handshake.
- The live probe must run only against a non-production environment with the public Postgres SNI path configured as documented in `docs/ADR009-postgresql-management.md`.
- The safe query is `SELECT 1 AS bex_pgcli_probe;`; the PTY driver can wait for the redacted column/value marker and then send `\q`.
- Database credentials, connection strings, access tokens, and the raw interactive screen must never be captured as durable evidence.

## Steps

1. Preflight and record the pinned `pgcli` version and the disposable database's Ready/public/allow-listed state without printing sensitive connection info.
2. Run the id form through the PTY, send the probe query, require the expected value, send `\q`, and require a zero child/CLI exit.
3. Repeat by exact database name and confirm the same immutable database handled the session.
4. Use an EXIT trap to delete a verifier-created database and every temporary config/shim/transcript on success, failure, interruption, or timeout; confirm the resource is gone.

## Files

- `scripts/pgcli-compat-verify.sh`
- `scripts/render-cli-pty.py`
- `docs/render-artifacts/pgcli-cli.md` (evidence seed)

## Acceptance criteria

- [ ] Real `pgcli` executes `SELECT 1 AS bex_pgcli_probe;` successfully through `render pgcli` by id and by name.
- [ ] Both runs exit cleanly after `\q`; a TLS, authentication, IP allow-list, or missing-external-host failure is named and is not graded as success.
- [ ] Cleanup runs on every exit path and proves a verifier-created Database no longer exists.
- [ ] Durable output contains versions, redacted resource identity, pass/fail markers, and cleanup result only—never credentials or raw PTY bytes.

## Out of scope

- Mutating application data, performance testing, persistent fixtures, or accepting a shim-only result as full compatibility.
