# Service root should land on deploy history

Live Render opens a service at its deploy history; Events is a separate tab.
bex currently redirects the service root to Events even though its Deploys page
is already complete.

Change the default service-detail redirect to Deploys and update route tests and
the stale source comment. Preserve direct `/events` links.

Acceptance: opening `/services/<id>` lands on Deploys, Events remains directly
reachable, and redirect/navigation tests pin both routes.
