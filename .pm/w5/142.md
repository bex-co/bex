# Each new service with domains lists every App on the platform during a Blueprint apply

Why: `hostClaimIndex` (`lego/backend/internal/apps/domains.go`) lists every App on the platform with no filter, to index host claims. A Blueprint apply builds it once in the preflight and again for each new service that declares domains (`deploy.go`), which makes it the heaviest list in an apply. bex-api's client is uncached.

- **Where:** `hostClaimIndex` in `domains.go`, and its callers on the create path in `deploy.go`, around the per-service domain checks.
- **Fix:** build the index once per request, invalidating it when the apply claims a host. Better, find a narrower query than every App, such as one keyed by host label.
- **Test:** an apply creating two services with domains builds the index once.
