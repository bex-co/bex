## Objective

Expose a read-only `credits` block — `{available, currency, grants: [{remaining, expiresAt}]}` — on the billing service payload (alongside readiness/invoice preview), sourced from Stripe `credit_balance_summary` + `credit_grants`, degrading by omission on any Stripe read failure, fanned out identically to REST, GraphQL, and MCP.

## Context

- Billing feature: `lego/backend/internal/billing/` (service + `stripe.go` client + `contracts.go` + rest/graphql/mcp fragments). One core, three thin adapters (`lego/backend/CLAUDE.md`).
- Stripe reads: `GET /v1/billing/credit_balance_summary?customer=…` (available balance) and `GET /v1/billing/credit_grants` filtered by customer (per-grant remaining + `expires_at`). stripe-go v86.
- **Display truth caveat (recorded 2026-08-17):** `create_preview` may not reflect credit grants under flexible billing mode — the block must be computed from the credit APIs, never derived from the invoice preview.
- Degrade pattern to copy: the invoice-preview read (Stripe failure ⇒ field omitted, estimate-only unaffected).
- Runtime restricted key needs one **read** permission added (credit balance/grants read); writes stay with ADR071's future dedicated credit key. Runbook §2's permission inventory (`docs/runbooks/stripe-billing-setup.md`) records it.
- Authorization: same relation as the existing billing readiness verb (workspace billing admin); no new relation.

## Steps

1. Add the credit read calls to the Stripe client (bounded, cached like the invoice preview; TTL on the order of the existing preview cache).
2. Extend the billing service payload + the three adapter fragments with the `credits` block (omitted when unavailable — absent, not zeroed).
3. Unit tests against the stub Stripe API (`BEX_STRIPE_API_URL` test pattern): populated, empty-balance, read-failure-omits, permission-denied-omits.
4. Amend runbook §2's table with the credit read row + why runtime write stays excluded.
5. Operator step (out-of-band, note in the task result): add the read permission to the live runtime key in the Stripe Dashboard.
