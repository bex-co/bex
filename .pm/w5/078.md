Why: TanStack sets `match.search = {...raw, ...validated}` (`router-core/dist/esm/router.js:688-691`). The validator omits an invalid `type` instead of returning `undefined`, so the raw value survives and every reader of `Route.useSearch()` needs its own guard; w4/182 added one.

Source: Last-24h code review, 2026-10-05 (user handed all fixes to w5). Follow-up to `1d331d334` (w4/182).
