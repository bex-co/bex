## Objective

Create a composed-server conformance suite in `lego/backend/internal/api/` that invokes all 28 shared Render tools through `Server.MCPServer()` (with middleware, workspace binding, and real JSON-RPC transport) and checks every answer with `rendertest.AssertRenderMCPResult`, plus a coverage guard guaranteeing zero shared tools are missed and zero `form: "object"` tools lack a `type`.

## Context

- Currently, `rendertest.AssertRenderMCPResult` is called only in scattered per-package unit tests that bypass `Server.MCPServer()` middleware, and nothing verifies that all 28 shared tools in `render-mcp-results.json` are actually exercised on the composed server.
- Mirroring `w5/m581`'s REST conformance coverage guard (`TestMain` coverage census over all served operations), a composed MCP suite prevents a future shared tool from shipping without end-to-end result-shape validation.

## Steps

1. Add a composed-server test file in `lego/backend/internal/api/` (e.g., `mcp_result_conformance_test.go`) building an in-process `Server` (using the existing fake/in-memory fixtures used by `internal/api` tests) and connecting a real MCP client via `mcp.NewInMemoryTransports()` to `srv.MCPServer()`.
2. Exercise all 28 shared tools recorded in `render-mcp-results.json` (covering both non-empty and empty/queued branches where `emptyText` applies: `list_key_value`, `list_postgres_instances`, `trigger_deploy` live & queued, `update_blueprint` changed & no-op, `list_deploys` & `list_events` cursor suffix, `query_render_postgres` array of row objects), asserting each through `rendertest.AssertRenderMCPResult`.
3. Add a coverage assertion verifying:
   - Every tool in `render-mcp-results.json` was exercised in the suite (`untested == 0`).
   - Every `form: "object"` tool in `render-mcp-results.json` has a non-empty `Type` (`untyped == 0`), so future `render-mcp-capture.py` runs cannot reintroduce bare `{"form": "object"}` blind spots.
4. Run `cd lego/backend && go test -v ./internal/api -run TestMCPResultConformance` (and full `./internal/api/...`).

## Files

## Acceptance criteria

- [ ] All 28 shared tools in `render-mcp-results.json` are invoked through `Server.MCPServer()` and pass `rendertest.AssertRenderMCPResult`.
- [ ] A guard fails if any shared tool in `render-mcp-results.json` is not covered by the composed suite or if any `form: "object"` tool lacks a `type`.
- [ ] `cd lego/backend && go test ./internal/api/...` passes.

## Out of scope

- Exercising the 261 bex-only extension tools (not in `render-mcp-results.json`).
