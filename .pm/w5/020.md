# Project resources need search and type filters

Live Render's project/environment resource table has search plus
All/Services/Env Groups filters. bex's project page supports grouping and
resource management but becomes scan-only as the resource count grows.

Add URL-owned search and type filters to the project/environment resource view,
using the resource categories the page actually supports. Do not invent
unsupported resource families.

Acceptance: search and All/Services/Env Groups filtering compose, survive
refresh, remain scoped to the selected environment, and have accessible
no-match states and tests.
