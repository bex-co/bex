# Logs page needs a URL-owned time range

Live Render's Logs page exposes a time-range selector. bex supports bounded log
queries but the dashboard has no user control for the range, and the chosen
window cannot be deep-linked or restored.

Add a compact range selector backed by URL search state, apply it consistently
to the history query, and keep live tail behavior explicit. This does not own
the backend host/path work already tracked by `w3/m18`.

Acceptance: a user can choose at least the current Render-relevant recent
windows, refresh/share the URL without losing the selection, and the query uses
the selected bounds with tests for parsing/defaults.
