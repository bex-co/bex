## Objective

Add a danger-zone section to the service Settings tab with a delete action gated by a type-to-confirm dialog (the user must type the exact service name to enable the confirm button).

## Context

- Follow the type-to-confirm pattern `w6/m3/t004` establishes for workspace delete.
- Service Settings tab lives under `dashboard/src/features/services/components/` (see `instance-type-picker.tsx` for the existing Settings-tab component style).

## Steps

1. Add a `DangerZone` component: destructive-styled section, "Delete service" button opens a confirm dialog.
2. Dialog requires typing the service's `name` exactly; confirm button stays disabled until it matches.
3. On confirm, call `useDeleteService` (t001); show a loading state on the button while in flight.

## Files
