## Objective

Every Ready=False reason the Key Value controller writes becomes a `Reason*` constant beside `ReasonConnectionSecretRebuilding` in `lego/types/v1alpha1/keyvalue_types.go`, and the operator uses the constants.

## Context

- `kvFail` callers in `lego/operator/internal/controller/keyvalue_controller.go`, `keyvalue_persistence.go` and `keyvalue_persistence_live.go` pass literal reasons: `SecretFailed`, `ServiceFailed`, `StatefulSetFailed`, `StatefulSetReadFailed`, `CredentialSecretFailed`, `SecretRecreateFailed`, `PVCResizeFailed`, `PVCReadFailed`, `BackupCronJobFailed`, `BackupNetworkPolicyFailed`, and `appv1alpha1.ReasonNetworkPolicyFailed`.
- w5/079 did the same for the Database reasons (commit `a177fa9a0`).

## Acceptance criteria

- [x] Every reason the Key Value controller writes, including non-`kvFail` Ready=False reasons, is a constant; `grep` finds no literal reason in the controller.
- [x] `make test` passes.

## Result (2026-10-07)

- `lego/types/v1alpha1/keyvalue_types.go` declares the Key Value's Ready reasons in two groups.
  - Converging: `Provisioning`, `PodUnready`, `PersistenceTransition`, `WaitingForPVC`, `WaitingForPVCBinding`.
  - Failed, twenty in all:
    - 11 from `kvFail`;
    - `TLSIssuerMissing`, `CertificateFailed`, `CertificateCleanupFailed` from the TLS step;
    - `StorageClassMissing`, `StorageClassNotFound`, `StorageClassNotExpandable`, `StorageBlockedByQuota` from the storage gate;
    - `PersistenceTransitionFailed`, `PersistenceSourceUnknown` from the persistence handoff.
- The note listed 11. The inventory found the storage, TLS and persistence reasons too.
- **The operator:**
  - The Key Value controller files use the constants. The local `reasonKVCertificateFailed` is gone.
  - The App controller's disk condition and its `ServiceFailed` now use the shared ones as well. The values are identical, so behaviour doesn't change.
  - The one remaining literal, `StorageProvisioned`, is the storage condition's ready reason, never a Ready reason.
- `make test`: 25 packages pass.
