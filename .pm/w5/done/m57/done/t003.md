## Objective

Render's static-site Settings page has no Region row; bex shows a read-only Region row for all types (added platform-wide in w5/m52). Hide it for static-typed services to match Render. Non-static types keep the Region row.

## Context

- Render static Settings sections (live capture 2026-07-28): General(Name), Build, Deploy, Custom Domains, PR Previews, Networking, Notifications, Delete/suspend — **no Region**.
- bex renders the read-only Region row unconditionally in `dashboard/src/routes/services.$serviceId.settings.tsx` (~lines 88-97); w5/m52 added it to match Render's _web-service_ settings. Static sites are region-agnostic (served from the object store via the shared static-server, docs/ADR029-static-sites.md), so Render omits it.

## Steps

1. Gate the Region row on `!isStaticSite(service)` (helper in `dashboard/src/features/services/lib/service-type.ts`).
2. Verify web/worker/pserv/cron still show the Region row.

## Files

- `dashboard/src/routes/services.$serviceId.settings.tsx`
