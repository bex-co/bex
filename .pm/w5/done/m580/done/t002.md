## Objective

Inspect every served Render list endpoint outside the 9-operation subset in `list_query_contract_test.go` and the 4 endpoints fixed in `t001`, fixing any remaining unread query parameters, scalar-vs-array mismatches, or missing `explode=false` comma splitting.

## Context

- `lego/backend/internal/api/render_list_paging_test.go` lists all 30 served Render list operations; `list_query_contract_test.go` currently checks only 9.
- The remaining 17 unguarded lists include `list-blueprint-syncs`, `list-builds-in-build-source`, `list-disks`, `list-owners`, `list-owner-audit-logs`, `list-organization-audit-logs`, `list-registry-credentials`, `get-env-vars-for-service`, `list-secret-files-for-service`, `get-env-vars-for-build-source`, `list-secret-files-for-build-source`, `list-logs`, `list-logs-values`, `list-redis`, `list-headers`, `list-routes`, `list-webhooks`, `list-webhook-events`, `list-sandbox-groups`, `list-sandbox-builds`, `list-sandbox-snapshots`, `list-sandboxes`, and `list-sandbox-executions`.

## Steps

1. Compare every query parameter declared in `lego/backend/internal/api/openapi/render-public-api-1.json` (plus `renderQueryExtensions`) for each unguarded list operation against its REST handler.
2. Verify array parameters (`explode=false` and `explode=true`), time-window filters, cursor/limit parsing, and `name` raw-comma splitting (`core.QueryNameList` where `explode=false`).
3. Fix every silent ignore or arity mismatch found; record genuine non-goal omissions (e.g., `list-build-sources` `includePreviews`, `list-logs`/`list-logs-values` Workflows `task`/`taskRun`) with explicit rationale.
4. Add targeted handler tests for every fix made.
