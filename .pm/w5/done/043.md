# 043 — Systematic initial-JS attribution pass: shrink the ~5.5 MB client entry chunk

Surfaced 2026-08-16 while implementing `w5/m67`. m67 confirmed (by measurement) that a route file's exported page component gets **eagerly bundled into the client entry chunk** rather than code-split, and banked the 4 zero-risk drops (entry 1,312 → 1,176 kB gzip, −10.4 %). But it also found the effect is **graph-dependent**, not mechanical: `services.$serviceId.scaling` was already its own chunk despite its export, while `agents`/`databases` were pinned into the entry — so you cannot tell which of the ~21 remaining exported route pages (or which vendor libs) actually weigh on the entry without **attributing it**. After m67 the entry is still **~5.5 MB raw / ~1.18 MB gzip** (`index-*.js` from `yarn build`).

The lever is **entry attribution + splitting**, on two fronts: (a) the remaining 21 exported route pages that m67 left (allowlisted in `no-new-route-component-export.test.ts`) — move the graph-pinned ones into feature modules so they leave the entry; (b) heavy libraries only needed on specific routes, lazy-loaded rather than sitting in the entry/shared graph:

- `@xterm/*` (~290 kB, already a chunk — confirm it's not also pinned into the entry) — only the service Shell / web-shell.
- `@tiptap/*` — only the agent-session composer (`inline-mention-editor`).
- `ai` / `@ai-sdk/react` (`session-conversation-impl` ~500 kB chunk) — only agent-session views.
- `@ory/elements-react` (`use-ory-flow` ~205 kB) — only auth pages.
- Markdown stack (`react-markdown` + `remark-*` + `rehype-*`) — only where prose renders.

Work (a real milestone, > 1h): run a bundle analyzer (e.g. `rollup-plugin-visualizer`) against `.output/public`, attribute the 5.9 MB entry, then ensure the heavy libs are route-lazy (dynamic `import()` / lazy route components) and split vendor into a cacheable chunk group. Add a bundle-size budget/CI check so the entry can't silently regrow. Measure entry gzip before/after — target a materially smaller initial payload. This is the genuine "faster first load" win m67's title promised.
