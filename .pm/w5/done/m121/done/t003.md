## Objective

The backend and operator compute a host's TLS Secret name with the same function.

## Context

- The backend's `tlsSecretForHost` (`domains.go`) truncates names at 253; the operator's `tlsSecretName` (`lego/operator/internal/controller/app_controller.go:4790`) hashes them. A host long enough to exceed 253 together with the app name and `-tls-` stays "pending" in the backend after issuance. The backend's doc comment says it is "mirroring the operator's naming convention".

## Steps

1. Move the naming into `lego/types/v1alpha1`, used by both; keep the legacy index-0 `<app>-tls` rule.

## Files

- lego/types/v1alpha1/ (secret names)
- lego/backend/internal/apps/domains.go
- lego/operator/internal/controller/app_controller.go

## Acceptance criteria

- [ ] Both call the same function, and a long-host test shows the host verified once its Secret exists.
