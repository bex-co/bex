## Objective

Add live tail: subscribe to bex-api's `GET /v1/logs/subscribe` SSE stream (authenticated by the Kratos session), append new lines to the panel in real time, with pause/resume, autoscroll, and a capped in-memory buffer. Document the deliberate SSE-vs-WebSocket divergence from Render in the data-layer code.

## Context

- bex-api SSE endpoint (`docs/bex-api.md`, `docs/observability.md`): `GET /v1/logs/subscribe?resource=<id>` streams new lines over Server-Sent Events — bex's deliberate choice where Render upgrades to a WebSocket; same "stream new lines live" contract.
- Auth: the same Kratos session the dashboard already uses; SSE requests must carry it.
- Buffer: cap the retained lines to avoid unbounded memory on a long-lived tail.

## Steps

1. Add a `useLiveLogs` hook wrapping `EventSource` (or a fetch-based SSE reader if credentials require it) against `/v1/logs/subscribe`.
2. Merge streamed lines into the panel above the historical query results; dedupe against the last historical page.
3. Implement pause/resume (close/reopen the stream), autoscroll-on-new-line (disabled when the user scrolls up), and a capped ring buffer.
4. Add a code comment documenting the SSE-vs-WebSocket divergence and why (bex's no-dependency choice).
