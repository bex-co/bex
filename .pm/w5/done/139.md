# A sandbox file transfer revoked mid-stream answers 503, not the exec stream's 403

Why: when access is revoked during a sandbox file upload or download, the gateway answers `sandbox file operation failed` (503), as for any outage. The exec stream answers the same revocation with 403 "access was revoked during this exec", logs it and counts it as revoked. So a caller cannot tell revoked access from a failure, and the two transports disagree.

- **Where:** `lego/backend/internal/sshgateway/sandboxfiles/sandboxfiles.go`. `sshgateway.WithRevalidation` cancels the transfer's context, so `execute` returns `context.Canceled`, and `writeError` answers it as unclassified. Compare `lego/backend/internal/sshgateway/sandboxsse/sandboxsse.go`, which tells revocation (`execCtx.Err() != nil && timedCtx.Err() == nil`) from the client or the cap.
- **Fix:** distinguish a revoked transfer from the timeout and the client's own cancel the way sandboxsse does. Answer 403 with a fixed sentence, and log it with the sandbox id.
- **Test:** `TestUploadRevocationStopsBodyAndDoesNotPublish` (and a download twin) answers 403, not merely non-204.
- Found by w5/131's quality review (2026-10-07). It predates w5/131, which changed only the 503's text from "context canceled".

## Result (2026-10-07)

- **Answer:** `sandboxfiles` classifies a transfer the revalidation watchdog ended as `sandboxsse` does. The watchdog's context was canceled while the request's timed context is still live. Such a transfer answers `access was revoked during this transfer` (403), is logged with the sandbox's id and subject, and counts the session as `revoked`. An upload's body closed mid-read surfaces as an archive error rather than `Canceled`, and is classified the same way. A download revoked after its first byte is still aborted but is logged and counted.
- **Review fix:** a first cut flagged any failed watchdog check. A check still in flight when the transfer timed out, or when its client left, fails only because its own context ended, so those were answered and counted as revoked. The classification now reads the contexts, and a regression covers both cases.
- **Tests:** `TestUploadRevocationStopsBodyAndDoesNotPublish` now requires 403 and the sentence. `TestDownloadRevocationAnswersForbidden` covers revoked before the first byte (403, counted), revoked while streaming (aborted, counted), timed out mid-check (504, not counted) and left by its client mid-check (not 403, not counted). Five mutants fail them, including the shipped code and the flag's misreading. The package passes under `-race`.
- **Docs:** ADR006's sandbox-transfer bullet.
- **Gates:** `go test ./internal/sshgateway/...`; `make lint`.
