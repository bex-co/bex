## Objective

The user can ask for a PR: the new-session composer gains an "Open a draft PR when done" control, **default off**, wired to t001's `openPr` create field. Without it the opt-in backend flag would be unreachable from the primary surface.

## Context

- `dashboard/src/features/agent-sessions/components/new-session-composer.tsx` + `configuration-fields.tsx` — the create form and its per-session configuration block (agent/model/repo/branch pickers live here; the toggle belongs alongside).
- The `createAgentSession` mutation needs the new field spliced into `src/graphql/definitions.ts` (offline codegen reconcile, per `dashboard/CLAUDE.md`).
- New locale keys (en + zh) for the label/help text.

## Steps

1. Add the default-off toggle to the composer's configuration fields; pass `openPr` through the create mutation.
2. Splice the mutation field into `definitions.ts` offline; add locale keys.
3. Extend the composer test: default submit sends `openPr: false`/omits it; toggled submit sends `true`.

## Files

- `dashboard/src/features/agent-sessions/components/{new-session-composer,configuration-fields}.tsx` (+ `__tests__/`)
