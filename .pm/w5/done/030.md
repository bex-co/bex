# 030 — Datastore Logs viewers: align range presets with the shared m56 ladder

**Filed:** 2026-07-30, during w5/m61's already-satisfied closeout. **Type:** minor consistency polish (non-blocking, low priority).

The datastore Logs viewers (`features/databases/components/postgres-log-viewer.tsx`, `features/keyvalue/components/key-value-log-viewer.tsx`) expose only a **1h / 6h / 24h** range select, while the service **Logs tab** and the **Metrics** page share the richer m56 range ladder (`30m … 30d` + Custom, via `features/metrics/components/range-select.tsx`). This predates m56 and is a small cross-surface inconsistency, not a functional gap — the datastore panels work and are store-gated.

**If picked up (~30m):** swap the datastore viewers' hand-rolled 1h/6h/24h `Select` for the shared `RangeSelect` component (or its preset set), mapping the range to the existing `usePostgresLogs`/`useKeyValueLogs` start/end variables, and update the viewers' tests. Keep the datastore default at its current window. Purely a consistency improvement; no backend change (the `logs` verb already accepts arbitrary start/end).

Not a blocker for any milestone — the datastore Logs panels already meet their DoD (w5/m61 closed already-satisfied).
