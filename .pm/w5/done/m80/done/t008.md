## Objective

Add meaningful tests for the behavior this milestone shipped: the bounded turn timeout, the model-proxy terminal-auth fast-fail, the failed-session short reclaim grace, and `failureReason` completeness across classes. Tests must assert real behavior and failure modes, not tautologies.

## Context

- Backend suites run against real Postgres + OpenFGA in CI (`lego/backend`); the model proxy and completer have existing table-driven tests (`modelproxy_test.go`, `completion_test.go`).
- Dashboard suite (`dashboard/yarn test`) covers the agent-session mapper/callout.

## Steps

1. Model proxy: assert a post-mint 401/403 fast-fails the session (terminal) while 429/5xx still relay and the create-race `mintWithRetry` path is unchanged.
2. Completer: assert a failed session with no open SSH reclaims on the short grace, a completed session keeps the full grace, and an open-SSH session is never reclaimed.
3. Driver/config: assert the turn-timeout default is the sane bound (not 4h) and remains overridable/positive-integer-validated; assert a timed-out turn converges to `failed` with a timeout reason.
4. `failureReason`: assert every terminal-failure class (capacity, auth, timeout) yields a non-empty reason across REST/GraphQL/MCP and that the dashboard mapper/callout renders it (no blank card).
