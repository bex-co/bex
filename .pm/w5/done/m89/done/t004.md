## Objective

Add accessible instance selection and raw/MIN/MAX/AVG controls to the Application Metrics card using the shared backend contract.

## Context

- ApplicationMetricsCard currently exposes only Percentage/Total.
- useMetrics owns query wiring and shares the route's live window; the new controls should reuse it.
- Metric legends should carry m87's public IDs and stable colors as selection changes.

## Steps

1. Add instance selection and aggregate controls at the card scope, keeping their request wiring in the existing metrics hook.
2. Render authoritative results from the backend and preserve percentage/total, limit, target, and event-marker behavior.
3. Keep loading/error/empty behavior honest while selections change; reuse the shared polling/window rather than adding a timer.
