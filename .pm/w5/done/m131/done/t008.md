## Objective

Env-group link and unlink also rewrite `spec.filesFromSecrets`, adding or removing the group's own files Secret, from the App they read. Patch it under the lock, so a stale link cannot drop the service's own `<service>-files` reference a secrets write just set. Cover the rolling path and the auto-deploy-gated one, which must not stamp a release.

## Context

- `lego/backend/internal/envgroups/service.go` `rollLinkedService` (the unlocked `Rollout.Patch`) and `rollLinked`'s gated path (a plain `MergeFrom`). Found by the m131 Simplify review.

## Acceptance criteria

- [ ] A link whose patch loses the race to a write that adds `<service>-files` keeps both references, on a rolling service and on one whose auto-deploy is off.
