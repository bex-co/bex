## Objective

`finalizeEnvironmentPatch` patches with an optimistic lock. On a conflict it re-reads the App, re-runs the projections and the reference staging against it, and patches again. It compensates the store only when the write finally fails.

## Context

- `lego/backend/internal/secrets/batch.go` `finalizeEnvironmentPatch`. It patches with `MergeFrom(txn.originalApp)` and compensates on any error, including a conflict.

## Steps

1. Wrap the projection, staging and patch in a bounded retry keyed on conflicts.
2. Each attempt uses the re-read App as both its base and its original.

## Files

- `lego/backend/internal/secrets/batch.go`

## Acceptance criteria

- [ ] A batch that empties the files map and loses the App race does not remove the reference a later files write added.
- [ ] A save-only batch still stages, and a deploying one still rolls.

## Out of scope

- The env CAS path's own revision check.
