# Authenticate anonymous Docker Hub reads with a platform account

Why: every tenant's anonymous Docker Hub metadata reads and pulls leave bex through a few shared egress IPs, so they share one anonymous quota. Since `e3e0f9eea` a 429 no longer fails the deploy — it waits and retries (w5/176) — but a busy platform can keep every public `docker.io` deploy waiting. Render has the same 429 failure mode and the same remedies, so this is hardening, not parity.

- **Shape:**
  - A platform Docker Hub credential (operator env, e.g. `BEX_DOCKERHUB_PULL_SECRET`) used for `docker.io` metadata reads only when the App has no workspace credential for Docker Hub (`externalImageAuthHeader`), and for the native build resolver (`build.NewDockerHubResolver`).
  - Kubelet pulls: either a platform pull secret bound alongside the workspace one, or a Zot `sync` on-demand mirror of `registry-1.docker.io` (authenticated upstream) wired through `/etc/containerd/certs.d/docker.io/hosts.toml` in every node pool. A mirror must not cache mutable tags past their upstream digest, because Render pulls fresh on every deploy.
  - The w5/171 metadata-endpoint deny stays in place either way.
- **Size:** more than 1 hour across the operator, infra node bootstraps and GitOps; promote on unblock.

**BLOCKED (2026-11-04):** needs a platform Docker Hub account and access token from the user (a paid plan for no pull limit, or confirmation that the free authenticated limit is enough), plus a choice between a platform pull secret and an authenticated Zot mirror. The parity behavior (automatic retry, workspace credentials) is already live.

**Retired to FUTURE-MAYBE — 2026-11-05 (user decision D4, `/unblock w5`).** Render parity is already live: a 429 retries instead of failing (w5/176, `e3e0f9eea`), and workspaces can add their own Docker Hub registry credentials, which is Render's own remedy. A platform account is hardening, not parity. Deferred with a trigger; no account or token was requested. The shape above (a Zot authenticated mirror or a platform pull secret, with the w5/171 deny kept) remains the starting point when it is promoted.
