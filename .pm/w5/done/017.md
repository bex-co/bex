# Service Environment needs Export

Live Render offers Export beside the Environment variable/file controls. bex's
Environment tab supports editing, secret files, and group links but has no
equivalent export action.

Add a safe export of the current service environment in the dashboard. It must
not expose masked/unavailable secret values as if they were recoverable; reuse
the existing secret-service semantics and provide a clear degraded/error state.

Acceptance: the Environment page has an Export action, the downloaded/copied
format is deterministic and documented in tests, and secrets never leak through
a fallback or stale client cache.

Source: [dashboard walk — Environment](../../docs/render-artifacts/dashboard-walk/services.md#page-by-page-verdicts),
2026-07-15. Estimate: 30m.
