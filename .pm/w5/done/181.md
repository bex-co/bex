- w4/532 (`70b9e2dbc`) already resolves the default branch for the legacy create and preview through `s.blueprintBranch` (`blueprint.go:2346`). Reuse it in `CreatePlannedBlueprint`, keeping `main` only when no GitHub lookup is available.
- Remove the matching divergence sentence in `docs/ADR049-render-yaml-parity.md` (§ onboarding "Divergences"), and drop "(default main)" from MCP `create_blueprint`'s `branch` description.
- Test: a create with no branch against a repo whose default is `trunk` plans `trunk` on REST and MCP.
