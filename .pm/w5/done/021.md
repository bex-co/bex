# Logs: compact, clickable instance slugs

Implemented 2026-07-17 as a sub-hour Render-parity correction.

- Service application-log rows abbreviate a Kubernetes pod such as
  `web-6f7d8f9c4b-bv612` to Render's compact `[bv612]` presentation.
- Clicking the slug applies the exact full pod name as the existing instance
  filter, so GraphQL/SSE filtering and the shareable `?instance=` URL remain
  lossless.
- Hover text and the translated accessible label retain the full instance.
- Focused interaction tests plus the complete dashboard typecheck, lint, and
  1,357-test suite pass.

Source: user-requested comparison against Render's live Logs page and Render's
official logging contract, which specifies that clicking an instance ID adds it
as a search filter. Kept out of `m41` because that open milestone owns populated
Project overview parity, not Logs.
