## Objective

Give every Key Value a `bex` ACL user with full access for platform clients, with a password tenants can never read.

## Context

- The tenant password lives in the auth Secret's `password` key and is revealed through the `lego/backend/internal/keyvalue/` connection-info endpoints.
- Rule shape: `--user bex on >$(VALKEY_ADMIN_PASSWORD) ~* &* +@all`.

## Steps

1. Generate a platform password (a separate Secret key or Secret) on create, and backfill it for existing Key Values in reconcile.
2. Add the `bex` user rule to the server args.
3. Confirm no REST/GraphQL/MCP reveal or connection string returns the platform password.

## Files

- lego/operator/internal/controller/keyvalue_controller.go
- The Key Value auth Secret builder
- lego/backend/internal/keyvalue/ (reveal paths; read-only check)

## Acceptance criteria

- [x] New and existing Key Values have the `bex` user after reconcile.
- [x] A test shows no API response contains the platform password.

- Work owned by other w5 items in the 2026-10-05 queue.
