## Objective

Quantify the win: record initial-JS and per-route-chunk sizes before and after the export removal, so the DoD's "measurably smaller" claim is backed by numbers.

## Context

- `yarn build` (Vite) emits the chunk manifest; the initial/entry bundle plus shared vendor chunks are what load before first paint.
- Baseline = the tree at HEAD before t001 (capture from `git stash`/a clean build if t001 already landed, or from the pre-change build output).

## Steps

1. Build the pre-t001 tree and capture entry + shared chunk sizes (and the count of eagerly-bundled page bodies).
2. Build the post-t001 tree and capture the same.
3. Record the delta (initial JS bytes saved, new per-route chunks) in the milestone `README.md` DoD.

## Files

- `dashboard/` build output (no source change)
- `.pm/w5/m67/README.md` (record the numbers)

## Acceptance criteria

- [ ] Before/after initial-JS sizes recorded with a concrete byte/percentage delta.
- [ ] The delta is a reduction (or the milestone is re-evaluated if it isn't).

## Out of scope

- Adding a bundle-size CI budget (a possible follow-up note, not this milestone).
