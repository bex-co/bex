## Objective

Prove the full Environments dashboard flow works end to end against a real (or mock) cluster, including the ADR032 auto-join-project behavior on assignment.

## Context

- `scripts/mock-cluster.sh` for a local CAPD cluster; `docs/ADR032-environments.md` for the auto-join contract.
- Existing precedent: `scripts/environments-verify.sh` (backend-only, `w1/m32`) — this task is the dashboard-driven equivalent, via Playwright or manual click-through.

## Steps

1. Stand up (or reuse) the mock cluster; deploy a Project with 2+ services.
2. Click through: create an Environment, assign a service to it (confirm it auto-joins the parent Project if not already a member), rename the Environment, delete it (confirm services return to Ungrouped, not deleted).
3. Record the run (screenshot or notes) in the milestone README's Definition of done section.

- [ ] Full create → assign → rename → delete cycle verified against a live/mock cluster with no console errors.
