## Objective

Produce a repeatable baseline for the direct-ACP conversation hot path and turn the Vercel review into explicit implementation constraints. Measure operations rather than guessing: per-part gateway store transactions, driver log opens/writes, frame serialization, first-part forwarding, terminal flush, and Completer recovery.

## Context

- `w5/m66` already chose and implemented direct `@agentclientprotocol/sdk`; this task must not reopen that completed decision.
- `lego/backend/internal/sshgateway/agentattach/agentattach.go` currently awaits `AppendAgentSessionTranscript` before `sse.frame`.
- `lego/backend/internal/store/agentsessions.go` takes a transaction-scoped advisory lock and queries `max(seq)` for each append call.
- `lego/agent-image/driver/src/session.ts` calls `appendFile` for each UI-message part; `stream-hub.ts` frames the same part repeatedly.
- Vercel harness packages remain experimental, AI SDK v7-based, and sandbox-owning; bex retains its in-pod driver and platform boundaries.

## Steps

1. Add a deterministic fixture/benchmark around a representative stream of text, reasoning, tool, plan, diff, and terminal parts.
2. Count store append transactions, log-open/write operations, frame encodes, and ordering/flush events; record elapsed timings as diagnostic evidence, not brittle pass/fail thresholds.
3. Record invariants that later tasks must preserve: AI SDK v6 marker, direct ACP stdio, redaction-before-publication, quota/truncation, replay order, terminal flush, and ADR051 harvest recovery.
4. Update ADR047/ADR051 with the adoption boundary and a pointer to the measured hot path.
