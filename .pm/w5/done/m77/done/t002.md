## Objective

Adopt the useful `createACP` lesson—a small declarative runtime profile—inside the existing bex stack. Replace duplicated profile conditionals with one non-secret, release-locked manifest consumed and validated by the backend and in-pod driver.

## Context

- Profile facts are currently split between `agentsessions/service.go` (`agentAdapters`), `driver/src/config.ts` (`modelProxyRoutes` and command allowlist), `internal/agentsession/model.go`, and Docker executable checks.
- The manifest may contain only reviewed static facts: public profile id, executable, args, bootstrap env, credential env, proxy base-URL env/suffix, and authentication/permission metadata.
- Tenant input must remain a profile id, never an executable path or arbitrary environment.
- Backend and agent image ship in lockstep, so one embedded/copied release artifact can safely define the contract.

## Steps

1. Define a versioned JSON schema/manifest in a location both the Go release and agent-image build can consume without runtime network installation.
2. Embed and validate it in the backend; use it for profile resolution and driver environment rendering.
3. Load and validate the same artifact in the driver; remove command/routing switch duplication while preserving the closed executable allowlist.
4. Make the image build verify every manifest executable and pin every package exactly.
5. Fail startup/build tests on duplicate ids, missing routing fields, unsafe paths/env names, undeclared executables, or backend/driver drift.

## Files

- `lego/backend/internal/agentsession/`
- `lego/backend/internal/agentsessions/service.go`
- `lego/agent-image/driver/src/config.ts`
- `lego/agent-image/Dockerfile`
- related backend and driver tests

## Acceptance criteria

- [x] One release-locked manifest supplies all shared runtime/profile routing facts.
- [x] Unknown profile ids, arbitrary commands/args/env, and incomplete proxy routing fail closed.
- [x] Claude, Codex, and Gemini resolve to the same executable, args, auth, credential, and base-URL behavior as before.
- [x] Agent image build verifies all declared binaries and exact package pins.
- [x] No dynamic package installation or Vercel harness dependency is introduced.

## Out of scope

- Changing the public profile catalog or adding a new agent.
- Moving credential authority out of the gateway model proxy.
