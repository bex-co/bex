## Objective

Add a small reusable runner that lets automation execute an unmodified interactive Render CLI command with a real controlling pseudo-terminal while retaining strict timeouts and never emitting the raw terminal byte stream.

## Context

- `cli/pkg/command/outputresolver.go` selects interactive output only when stdin, stdout, and stderr are TTYs, `TERM` is not `dumb`, `CI` is false, and `RENDER_OUTPUT` does not force another format.
- `cli/pkg/command/inputs.go` rejects `pgcli` before parsing when the resolved format is non-interactive.
- Passing `--output interactive` to ordinary pipes is not enough: Bubble Tea still needs a terminal. The runner must allocate a controlling PTY for all three streams.
- `scripts/ssh-verify.sh` demonstrates bounded, redacting interactive verification, but its official-CLI leg currently requires a human-owned TTY rather than creating one headlessly.

## Steps

1. Implement a standard-library PTY driver with an explicit terminal size, deadline, child-exit propagation, and marker-based input/output expectations.
2. Sanitize the child environment: use `TERM=xterm-256color`, unset `CI` and `RENDER_OUTPUT`, and isolate `RENDER_CLI_CONFIG_PATH` in a temporary directory.
3. Keep terminal bytes in memory only long enough to match bounded non-secret markers; on failure report the missed marker/state, never the raw transcript.
4. Add a non-TTY control proving the official guard still fires and a PTY control proving execution reaches a harmless sentinel child.

## Files

- `scripts/render-cli-pty.test.sh` (new)

## Acceptance criteria

- [x] The child sees TTY-backed stdin, stdout, and stderr and Bubble Tea starts without a human terminal.
- [x] The runner times out and terminates a hung child without hanging CI or leaving descendants behind.
- [x] Exit status and named marker failures are reported without printing raw ANSI output or environment values.
- [x] A piped `render pgcli` control stops at the official interactive-only error, while the PTY control reaches its sentinel.

## Out of scope

- Modifying `render-oss/cli`, implementing Postgres-specific resolution, or connecting to a database.
