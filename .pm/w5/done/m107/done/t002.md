## Objective

Use existing release records and snapshots to select runtime configuration without restoring it into saved state.

## Context

- restoreTargetConfig currently calls Environment.RestoreEnvironment; Rollback with RollbackOptions then overwrites App.spec.startCommand.
- Release snapshots and pod-template records already exist in types and operator.

## Steps

1. Trace the saved state and release state owners, then select the smallest release-scoped representation consistent with the researched matrix.
2. Replace saved-environment/start-command restoration with selection of target runtime inputs.
3. Preserve row-first dispatch, secret isolation, linked-group semantics and safe failure behavior; regenerate types/CRDs only if the representation changes.
