## Objective

Takeover dialogs branch on error codes and render fully localized text.

## Context

- `dashboard/src/features/blueprints/lib/views.ts:226` `isTakeoverOnlyConflict` substring-matches messages, although the GraphQL validation error carries a `code` (`lego/backend/internal/apps/graphql.go:894`, `errorDetails` at `:987`).
- `features/blueprints/lib/takeover.ts:107-111` interpolates server text into en and zh sentences. Kinds arrive as "service", "database", "key value" or raw `key_value`, and the owner can be the literal "another blueprint" (`apps/blueprint_ownership.go`).
- `protected-confirmation.ts` has dead branches ("is managed by blueprint", "already tracks"); `takeover.ts` catches those by code first.
- The dialog state is two variables that are always set together.

## Steps

1. Select `errorDetails{code}` and branch on codes.
2. Map kinds to localized labels, and render the owner from structured fields.
3. Delete the dead branches and use one `BlueprintConfirmationRequired | null` state.
