# Deploy logs: compact, clickable instance slugs

Implemented 2026-07-17 as a sub-hour Render-parity correction extending
`w5/done/021` from the service Logs tab to per-deploy logs.

- Deploy-detail application-log rows abbreviate a Kubernetes pod such as
  `eden-cms-v2-6f7d8f9c4b-bv612` to Render's compact `[bv612]` presentation.
- Clicking the slug applies the exact full pod name as a client-side instance
  filter without refetching the deploy's bounded log window.
- A visible, translated filter chip retains the full instance name and lets the
  user clear the filter; hover text and the accessible label stay lossless.
- Focused interaction coverage asserts abbreviation, exact filtering, and
  clearing. The complete dashboard typecheck, lint, and 1,369-test suite pass.

Source: user-requested comparison against Render's live Logs page, applied to
the bex deploy detail page. Kept out of a milestone because the existing shared
log-row behavior made this a bounded deploy-panel wiring change under one hour.
