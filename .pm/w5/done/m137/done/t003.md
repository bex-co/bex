## Objective

Verification happens without the tenant: a bounded background sweep in bex-api re-checks unverified claims on an interval and promotes + projects + kicks exactly as a successful manual Verify does today. Manual Verify becomes an immediate trigger of the same path (Render: automatic, manual "usually unnecessary").

## Context

- Today only `VerifyDomain` (`lego/backend/internal/apps/domains.go`) promotes, and it is per-request authorized. The sweep is a system actor: it needs a cross-App pending-claims read the store does not have yet (`ListDomainClaims` is per-app) and must promote through the same `PromoteDomainClaim` → `projectDomainClaims` → `Kick` sequence, with the `custom_domain_verified` audit/event recorded once at promotion (w4/m122 placement — never on a failed check).
- Attempt metadata (`RecordDomainVerificationAttempt`) already exists for bounding/observability; the sweep should pace per-claim checks (interval + attempt count) so a never-configured domain is not hammered forever at full rate, and stay bounded in claims per tick.
- Wiring follows bex-api's existing background-worker patterns in `lego/backend/internal/api` (start/stop with the server; disabled in storeless mode, which has no pending rows).

## Steps

1. Add the store read for pending claims across apps (bounded, oldest/attempt-aware ordering).
2. Extract one `checkAndPromoteClaim` core path used by both `VerifyDomain` (authorized, returns the fresh view to GraphQL/MCP) and the sweep (system, no caller). Authorization stays at the verb boundary, not in the shared path.
3. Wire the sweep loop with a documented interval and per-tick bound; record attempts on failures only as today.

## Acceptance criteria

- [ ] A test claim whose (fake) DNS flips to pointed is promoted by the sweep alone — App spec gains the host, one verified event exists, and no `VerifyDomain` call was made.
- [ ] A never-pointed claim stays unverified across many ticks with bounded attempt growth; a deleted/recreated row is not promoted by a stale tick.
- [ ] Manual Verify and the sweep racing promote exactly once.
