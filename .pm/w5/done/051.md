# Source-update toasts describe a Root Directory change

Why: confirming the wrong setting after a source save makes users doubt whether their repository or image edit was applied.

The live m76 closeout on 2026-09-05 showed "Root Directory updated." after a successful Source repo/branch or image save. `use-set-repo.ts` and `use-set-image.ts` both pass `services.buildDeploySuccess` / `services.buildDeployError` into `useFieldMutation`, but those translations describe only root-directory changes. Give source updates their own English/Chinese success and fallback-error keys. Keep `serverRefusalReason` first so an inaccessible-repo validation error still tells the user what to fix. Verify both source hooks use the new copy; do not alter actual Root Directory toasts.
