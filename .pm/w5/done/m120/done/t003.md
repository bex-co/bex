## Objective

Link sets hold `srv-` ids, so names can't alias across services.

## Context

- The link write path in `envgroups/service.go` stores the caller's identifier as given.

## Steps

1. Store ids at link time.
2. Add a one-time migration that resolves name entries to ids within the group's workspace, and drops and logs dangling ones.
3. Read paths render names from ids.

## Files

- lego/backend/internal/envgroups/service.go
- A migration or startup backfill

## Acceptance criteria

- [ ] Links survive a rename, a new same-name service isn't linked, and a migration test covers name→id and dangling entries.
