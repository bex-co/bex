## Objective

Audit `/static/$serviceId/events`, `/env`, and `/metrics` one route at a time using the shared service components without compute-only placeholder drift.

## Context

- These routes are thin static-tree adapters around shared pages; route-specific loading must preserve the static sidebar and exclusions.

## Steps

1. Delay the parent resource and each child query independently.
2. Fix wrong-tree navigation, blank adapters, and misleading empty states.

## Files

- `dashboard/src/routes/static.$serviceId.{events,env,metrics}.tsx`
- shared event/env/metric tests

## Acceptance criteria

- [ ] All three URLs show static-context, final-shape skeletons.
- [ ] No compute-only control or “no data” claim flashes while loading.

## Shared shape-parity gate

- [ ] At desktop and narrow-mobile widths, every rendering route this task owns has pending-versus-ready evidence showing the same outer bounds, padding, max-width, responsive columns, heading/action slots, tabs, and always-present major content regions with stable heights. A shared skeleton is acceptable only when that geometry actually matches; routes explicitly classified as redirects or server-only render no skeleton.

## Out of scope

- Shared query semantics.
