## Objective

## Acceptance criteria

- [ ] At desktop and narrow-mobile widths, every rendering route this task owns has pending-versus-ready evidence showing the same outer bounds, padding, max-width, responsive columns, heading/action slots, tabs, and always-present major content regions with stable heights.
