## Objective

Move the Percentage/Total toggle from the page-level bar into the Application Metrics card header (Render renders it as tabs at the top of the card), and add Render's section affordances: Memory and CPU sections carry a `Limit` link to `/services/<id>/plan` showing the configured limit (e.g. "512 MB", "0.5 CPU") when known, and Total Instances carries a `Manage scaling` link to `/services/<id>/scaling`.

- Route state: `percentage` currently lives in `routes/services.$serviceId.metrics.tsx` and is passed to the card — move the state (or just the control) into the card.

4. Verify on dev-5: tabs switch percentage/total; links navigate to the Plan and Scaling tabs.
