## Objective

Replace the six inline range buttons on the Metrics toolbar with one Render-style dropdown, and adopt Render's preset list: Last 30 min / Last hour / Last 4 hours / **Last 12 hours (default)** / Last 24 hours / Last 2 days / Last 7 days / Last 14 days. After this task the page-level bar holds only time controls (plus the event-timeline controls t002 restyles) — Percentage/Total, quantile, and Status Code leave the bar in t003/t004.

## Context

- Captured live 2026-07-17: Render's toolbar is `[filter-events icon] [Last 12 hours ▾] … [show-event-timeline icon]`. Its dropdown lists 30 min, hour, 4h, 12h (selected default), 24h, 2 days, 7 days, 14 days, 30 days (disabled — plan-gated), Custom. "30 days" and "Custom" are excluded scope (milestone README).
- bex today: `metrics-filters.tsx` renders all six presets as inline buttons; `lib/range.ts` presets are 30m/1h/3h/6h/12h/1d with `DEFAULT_RANGE_PRESET = 1h`.
- `RangePreset` ids scale `resolutionSeconds` with span (~120 points/series — keep that invariant when adding 4h/24h/2d/7d/14d and dropping 3h/6h/1d).
- **Shared consumers:** the Logs tab uses the same presets (`features/logs/components/log-filter-bar.tsx`, `log-viewer.tsx`, `features/logs/lib/log-search.ts`, `routes/services.$serviceId.logs.tsx` — w5/m36's time range) and parses preset ids from the URL via `parseRangePreset`. Old `3h`/`6h`/`1d` URL values must degrade to the default, never crash. The Scaling page passes a bare `RangeWindow` (no preset id) and is unaffected.
- Ranges beyond Prometheus retention just show the retained window (existing `range.ts` comment) — 7d/14d need no backend change.
- `BEX_MAX_QUERY_HOURS` defaults to 720h — 14 days (336h) stays inside it.

## Steps

1. Update `RANGE_PRESETS` in `dashboard/src/features/metrics/lib/range.ts` to ids `30m|1h|4h|12h|24h|2d|7d|14d` with proportionate `resolutionSeconds`; set `DEFAULT_RANGE_PRESET` to `12h`.
2. In `metrics-filters.tsx`, swap the button row for a single Select/dropdown (shadcn `Select`, label = current preset), updating `RANGE_LABEL_KEYS` + `features/metrics/locales/{en,zh}.ts` for the new preset labels.
3. Sweep Logs-side fallout: label keys, default handling, and `parseRangePreset` of retired ids (degrade to default).
4. Verify against dev-5 (or `yarn dev:local`): both Metrics and Logs render the new dropdown, default Last 12 hours on Metrics.
