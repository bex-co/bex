## Objective

A create or `spawn_session` naming a `bex-agent/*` branch that another unfinished, unarchived session in the workspace holds on the same repository is refused, so one session's sandbox cannot push to another session's branch and re-sync its pull request.

## Context

- `lego/backend/internal/agentsessions/service.go` (create validation: `agentsession.ValidateBranch`, ADR094 D3's `bex-agent/<id>` default).
- `lego/backend/internal/agentsessions/spawn.go:107` passes `req.Branch` into `CreateRequest`.
- `lego/backend/internal/store/agentsessions.go` `CreateAgentSession` (the insert; a check belongs in its transaction, or a partial unique index over unfinished rows).

## Steps

1. Refuse, in the store's create transaction (so two concurrent creates cannot both pass), a branch another unfinished, unarchived session in the workspace holds on the same repository.
2. Map it to 409 `AGENT_SESSION_BRANCH_IN_USE` naming the branch, on every surface.
3. Leave an omitted branch and a branch held only by finished or archived sessions accepted.

## Acceptance criteria

- [x] Real-Postgres test: a second create (and a spawn) on a held branch is refused; after the holder finishes, the same branch is accepted; two concurrent creates on one branch yield one session.

## Outcome (2026-11-13)

`store.lockUnheldBranch` (in `CreateAgentSession`, only when a branch is named) takes a per-workspace advisory lock on repo+branch and refuses while a session in the workspace is working on it, archived or not; for a spawned child, also while any non-canceled, unarchived session could still push to it. A person's or automation's create may reuse a finished session's branch (an automation's next run does; the first draft refused it, caught by /simplify). The check runs after the insert (excluding the new row), so a retry with the same idempotency key fails on its key and replays before it could be refused for the branch; the service maps the refusal to 409 `AGENT_SESSION_BRANCH_IN_USE`. Store fixtures that put several sessions on one branch now take the default branch. Per workspace, so it neither leaks another tenant's branch nor lets one squat it. Test: `agentsessions.TestOneSessionAtWorkPerBranch` (real Postgres).
