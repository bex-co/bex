## Objective

A fresh agent generation with prior durable turns is primed before the user's prompt: rung 2 (bounded transcript-derived preamble) when history exists, rung 3 (prefix `agent_config.task`) when no prior turn ever reached the agent. Cold prompts to sessions with history become impossible.

## Context

- ADR047 D3 continuity amendment (2026-08-30) defines the ladder; ADR051 §"Transcript as the agent re-priming source" defines what rung 2 may draw from (prompts + assistant text from the harvested transcript; tool noise elided; newest-first under an explicit byte budget).
- Driver: `lego/agent-image/driver/src/` (`session.ts` owns turn prompts; `delivery.ts` `ensureRepo` shows the resume path). The driver learns "prior turns existed" and fetches replay material — decide the seam: env injected by bex-api at dispatch (e.g. serialized recent context) vs. driver-side fetch through the attach/replay boundary; prefer whatever keeps the sandbox's egress surface unchanged.
- Rung 3 trigger: prior turns exist but none produced transcript parts / reached the agent (the `ags-da9mh5vj596c73en5eq0` shape — all turns died at setup).
- The preamble must be marked (ADR051) so the tee/replay does not re-render it as fresh conversation.

## Acceptance criteria

- [x] Steer/resume onto a fresh generation with real history: agent receives preamble + prompt; a context-dependent prompt is answerable.
- [x] Resume of a setup-failed session: prompt arrives prefixed with the original task.
- [x] Preamble byte budget enforced; marked parts excluded from replay rendering.
