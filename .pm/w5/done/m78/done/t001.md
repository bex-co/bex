## Objective

Stop showing `GitHubEmptyCallout` ("Connect GitHub to start") when the user is creating a **chat-only** agent session that does not require a connected repository.

## Context

- `dashboard/src/features/agent-sessions/components/new-session-composer.tsx:92-93,212` — `noRepos` is `repos.length === 0` after load; the callout renders whenever there are zero repos, even though repo-less create is valid (QA confirmed chat-only sessions work when env is correct).
- Capabilities already expose GitHub readiness separately (`agentSessionCapabilities`); the callout should align with "this session needs a repo" not "you have no repos at all".

## Steps

1. Derive `needsRepo` from composer mode / selected delivery (repo chip, capabilities, or explicit repo field) — not from `repos.length === 0` alone.
2. Show `GitHubEmptyCallout` only when `needsRepo && noRepos`.
3. Keep example prompts gated on `!noRepos` only if they assume a repo context; otherwise gate on `needsRepo`.
