## Objective

Serve the stored code as `failureReasonCode` beside `failureReason` on REST, GraphQL and MCP.

## Context

- `lego/backend/internal/agentsessions/models.go` `View.FailureReason` (`json:"failureReason,omitempty"`); the view is built in `service.go` and exposed by `rest.go`, `graphql.go` (`gqlutil.StrField`) and `mcp.go`.

## Steps

1. Add `FailureReasonCode` to `View` (`omitempty`) and fill it from the record.
2. Add the GraphQL field (nullable string) with a description naming the codes.
3. Pin all three surfaces in one cross-surface test: a capacity failure carries the code; another failure and a healthy session omit it (GraphQL null).
