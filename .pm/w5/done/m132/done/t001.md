## Objective

Add `agent_sessions.failure_reason_code` and write it in the same statement as `failure_reason`. The capacity branch of `agentsessions.dispatch` records `sandbox.CodeSandboxCapacityLimit`. Every other write of the reason records an empty code or the code it already carries.

## Context

- Writers of `failure_reason` in `lego/backend/internal/store/`:
  - `AbandonAgentDispatch` (`agentdispatch.go`) sets it; the capacity sentence arrives here through `agentsessions.abandonDispatch`.
  - `SetAgentSessionFailure` and `FinalizeAgentSession` (`agentsessions.go`) set it. The snapshot reaper's unclaim (`completion.go`, `FinalizeAgentSession(..., claimed.FailureReason)`) re-finalizes with the claimed row's reason and must keep its code.
  - Steer's redispatch, `RecordAgentSessionDispatch` and `ExpireHibernatedAgentSession` clear or replace it.
- Before w5/m80 (9724686a7), `setLifecycleIfActive` wrote the capacity sentence to `status` through `SetAgentSessionLifecycle`, so old rows may hold it there instead.
- Migrations live in `lego/backend/internal/store/migrations/`; the next number is 0144.

## Steps

1. Migration 0144: add the column (`text NOT NULL DEFAULT ''`) and backfill failed rows whose `failure_reason` or `status` is `sandbox capacity reached`. Add a down migration.
2. Add `FailureReasonCode` to `store.AgentSession`, its column list and its scan.
3. Carry the code through each writer listed above, by changing each signature or passing one failure value, whichever reads better at the call sites. Update the interfaces and fakes.
4. `agentsessions.dispatch` passes `sandbox.CodeSandboxCapacityLimit` with `sandbox.CapacityFailureReason`.

## Acceptance criteria

- [ ] A capacity dispatch failure stores the code with the sentence, in one write.
- [ ] A redispatch, a successful dispatch record and a hibernation expiry leave no stale code.
- [ ] The reaper's unclaim keeps a failed session's code.
- [ ] The backfill codes old capacity failures from either column and leaves every other row empty (real-Postgres test).

## Out of scope

- Codes for the other failure sentences.
