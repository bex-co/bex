# w5/046 — live multi-account GitHub install walk (ADR078 / m74)

Deferred from `w5/m74` closeout: the one DoD element that can't be automated — a
real browser + GitHub App install of a **second** account (e.g. org `bex-co` + a
personal account) onto one workspace, then confirming the grouped repo picker and
per-installation token minting on production.

Everything else is covered by tests: the full migration chain (0001→0090) runs
against ephemeral Postgres in `backend-test.yml` (locally verified up/down + the
down-guard), `git_connections` multi-connection store methods, owner-scoped
resolution, quota, per-installation disconnect, and the dashboard flow.

Do this on a real Hetzner/dev environment with `BEX_GITHUB_APP_*` configured. The
original incident (installation 154851602 on `puncsky`) is the natural test case:
connect it alongside the existing `bex-co` org from **dashboard Settings**, then
open `services/new` and confirm both accounts' repos show grouped.
