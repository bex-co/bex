# Post-add DNS/CNAME instructions for custom domains

After adding a custom domain, show the DNS record the user must create (Render displays the CNAME target + verification state, and re-checks until the cert issues). bex's Custom Domains section (w1/m11.5) currently adds the domain and shows Verified/Certificate status, but gives no guidance on _what DNS record to point at the service_ — the user has to know to CNAME to the platform host.

Needs: the platform CNAME target surfaced from the backend (App URL / ingress host), a small instructions panel in the add flow or per-row expansion, and copy-to-clipboard. Verify against Render's live add-domain flow first (capture per the m7/m11.5 pattern).

Source: split out of w1/m11.5 (custom-domains dashboard) on 2026-07-09 — the add/list/delete + status half shipped there; DNS instructions were explicitly out of scope. Mechanism (per-host cert issuance) already works; this is a UX/guidance gap only.
