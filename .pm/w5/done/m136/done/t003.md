## Objective

An address the mail server rejects for good (a `*textproto.Error` with a 5xx code, wrapped by `mailer.SMTP.Send`) is logged and treated as reached-or-skipped, not retried. No notice is claimed past a fixed attempt cap.

## Context

- `internal/mailer/mailer.go` wraps `smtp.SendMail`'s error with `%w`.
- `ClaimBillingNotifications` has no cap. The backoff is `workerBackoff` (max 128m).

## Steps

1. A permanent-rejection classifier, used by `notifyBilling`.
2. Claim only rows with `attempt_count < cap`. The row keeps `last_error`, so an operator can see why it stopped.

## Files

- `lego/backend/internal/notifications/service.go`, `internal/store/billing_lifecycle.go`, tests.

## Acceptance criteria

- [ ] A 5xx rejection is not retried, and a notice at the cap is never claimed again.

## Out of scope

- Bounce handling via webhooks.
