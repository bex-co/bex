## Objective

Extend the Render-compatible REST surface: service reads emit `autoDeployTrigger: "commit"|"off"` derived from the boolean (`autoDeploy` true → `commit`), create/PATCH accept the field (`commit`→true, `off`→false), and when both `autoDeploy` and `autoDeployTrigger` arrive, the trigger wins (Render's documented precedence). `checksPass` returns a Render-shaped 400 validation error stating bex doesn't integrate CI checks. Storage stays the existing boolean — no CRD change.
