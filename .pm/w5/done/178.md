# `BUN_VERSION=canary` builds, as on Render

Why: since 2026-10-16 Render builds Bun canary releases from `BUN_VERSION=canary` or a `.bun-version` of `canary`; on bex the same service fails its build with `unsupported BUN_VERSION=canary`.

- `bunRequest` (`lego/operator/internal/build/nativeversion.go:302`) knows `latest`, plain versions and semver ranges; `canary` falls through to `highestSatisfying("canary")`, which fails, and `unsupported` (`:369`) names it.
- Bun lines are digest-pinned in `lego/operator/internal/build/native.go:143-145`; canary moves daily, so it cannot join that table.
- Fix: resolve `canary` (env or `.bun-version`) to `oven/bun:canary` at build time, pin the digest resolved for that build and print it in the build log; no build cache reuse across canary digests; the freshness check ignores it.
- Test: resolver unit tests for `canary`/`CANARY` from env and file; a build-plan test that the image is digest-pinned.
- Render parity: check Render's changelog entry (render.com/changelog, 2026-10-16) and the native-runtime docs for any other accepted spelling; no API surface changes.
- Estimate ~1h; promote to a milestone if the digest-resolution policy needs more than one task.
- Source: `/pm-brainstorm w5` 2026-11-05 item 5.

**Done 2026-11-05:** `BUN_VERSION=canary` and `.bun-version` `canary` (any case) are accepted. The request resolves to the reviewed default Bun line with `Exact=canary`, so no choice ever carries an unpinned image. The native-resolve phase then pins it with the existing exact-version path (`pinExactVersion` → `ResolveTag("oven/bun", "canary")`), and the build log narrates `==> Bun canary is oven/bun:canary@sha256:…`. If the registry can't be reached, or the tag doesn't exist, the build keeps the reviewed 1.4 image and says so. An unsupported request now names `canary` among the supported values. Tests cover the resolver rows, the pinned success, the registry-error fallback and the missing-tag fallback. ADR060's Bun row is updated. A live canary build is not performed here; the first tenant build that uses it does that.
