# 183 — The workspace audit log names neither a rename's names, a custom domain, nor the env group a link changed, though the audit rows now carry them

Why: the audit log is where an owner asks "who renamed this service, and from what" or "who removed that domain". Since w4/m337 and w4/m328 the rows record those facts and the service Events feed shows them. The audit log still reads only `{"service": "srv-…"}`.

- **Source / severity / estimate:** `/pm-brainstorm for 残留问题 for w5` (2026-11-12), item 3; residual of w4/m337 (its t006 parity record) and w4/m328. **Minor.** ~45m–1h.
- **Root cause:**
  - `lego/backend/internal/audit/rest.go` `renderMetadata` writes only the target, `targetName`, the role pair, revoked keys and OAuth facts.
  - `lego/backend/internal/store/audit.go:191` `auditColumns` reads none of `display_name_from`, `display_name_to`, `domain`, `env_group_id`, `env_group_name`.
- **Fix (target behavior):**
  - Read those columns into the audit row.
  - Add metadata keys: `from`/`to` on `UpdateServiceNameEvent`; `domain` on the custom-domain events; `envGroupId`/`envGroupName` on the env-group link events.
  - The same keys appear in the CSV export, and the dashboard's Audit Log shows them.
- **Render parity:** Render's audit-log `metadata` is a free string map (`additionalProperties: string`; `docs/render-artifacts/audit-logs-api.md`). Its metadata for `UpdateServiceNameEvent` was never captured. A read-only GET of the reference account on 2026-11-12 found only `ViewEnvVarValuesEvent` in its window, and the second owner's plan has no audit logs. The new keys are therefore additive bex metadata. Record them in ADR018's audit-log row, and adopt Render's key names if a later capture shows them.
- **Tests:** a real-Postgres round trip of a rename, a domain add and an env-group link through the audit-log list and the CSV export.
- **Dedupe:** w4/m321 t011 (blocked) names the resource on create and delete rows and decides `relation`; this note touches neither. w4/m337 and w4/m328 (shipped) record the facts.

- **2026-11-12 (loopx w5):** done. The workspace audit log reads `display_name_from`/`_to`, `domain` and `env_group_id`/`_name` (`store/audit.go` `auditColumns`, `scanAuditRow`).
