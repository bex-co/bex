## Objective

A missing resource answers its code on REST, GraphQL and MCP, with the same status and message as today.

## Context

- `core.ErrNotFound` is a bare sentinel. `core.NotFound(resource)` names the resource, and `errors.Is(err, ErrNotFound)` holds for both.
- `NewNotFoundError(code, …)` refusals already carry their own codes, and must keep them.

## Steps

1. Give `core.ErrNotFound` and `core.NotFound` a code, keeping `errors.Is` identity and every specific code.
2. Pin it in `api/refusal_codes_test.go` on all three surfaces.

## Files

- `lego/backend/internal/core/errors.go`
- `lego/backend/internal/api/refusal_codes_test.go`
