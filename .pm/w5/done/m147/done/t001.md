## Objective

Render (render.com/docs/environment-variables): set for web and private services created after December 8 2025, runtime only, "based on the CPU count for the service's compute plan" (`1` on 0.5 CPU, `2` on 2 CPU), so bex uses `max(1, ceil(cpu))` from `lego/types/tiers/tiers.yaml`. Decide and record: services created after this ships (recommended, mirroring Render's cutoff and leaving running services' memory alone) or all.
