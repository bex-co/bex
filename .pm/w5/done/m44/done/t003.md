## Objective

Replace immediate row mutations on the service Environment Variables card with Render's explicit masked view mode and one local draft entered via Edit. Add/update/delete operations stay local until a footer save action; Cancel restores the exact server snapshot.

## Context

- Current `EnvVarsEditor` and `EnvVarRow` save each row immediately and are also reused by environment groups; preserve the group editor's behavior unless deliberately factored into separate service-specific components.
- The draft should retain opaque unchanged entries rather than reveal or copy their values. Only Show, editing an existing value, export, or an explicit replacement may request sensitive material.
- Render permits key edits within the draft. Represent a rename as delete-old + set-new without exposing the old value unless the value itself changes.

## Steps

1. Introduce typed draft rows and dirty/diff derivation under `features/services`.
2. Render masked, reveal-on-demand read rows with Export + Edit actions.
3. In edit mode render editable keys/values, staged delete, Add variable, validation, dirty summary, save-action slot, and global Cancel.
4. Preserve focus, Escape behavior, stable row identity, pagination completion, error states, and refetch reconciliation.

## Acceptance criteria

- [ ] View mode exposes no mutation controls and reveals only the requested row.
- [ ] Edit mode can stage multiple adds, updates, renames, and deletes without a network write.
- [ ] Cancel restores the original rows and masks; unchanged opaque values survive save without reveal.
- [ ] Invalid/duplicate keys block commit with row-local accessible errors.
