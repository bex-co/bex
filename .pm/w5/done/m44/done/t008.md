## Objective

Make the finished Environment workflow operable and verifiable at desktop and 390px mobile: no crushed headers or horizontal page overflow, complete keyboard/focus behavior, English/Chinese copy, and a local stub whose query shapes match Apollo without environment-feature warnings.

## Context

- The captured 390px bex baseline crushes the Environment Variables title/description into a few characters per line; the opened add form overflows far beyond the viewport.
- Render stacks card actions below copy at the same width and contains its tables.
- `local-bex` currently emits Apollo missing-field errors for `envVars` and `secretFiles`, so the Environment tab cannot be a trustworthy browser oracle.

## Steps

1. Make page/card headers and action groups wrap or stack at narrow breakpoints; use contained horizontal scrolling or mobile row layouts only inside cards.
2. Audit names, descriptions, focus return, menu/dialog state, touch targets, error association, and reduced-motion/loading behavior.
3. Add every new string to services/env-groups English and Chinese resources.
4. Extend `local-bex` with non-secret env/file fixtures, correct paged GraphQL shapes, reveal/batch mutation behavior, all save modes, and deterministic failure toggles.
5. Browser-walk desktop and 390px view/edit/import/upload/save/cancel/link paths with no feature console errors.
