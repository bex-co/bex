## Objective

Add meaningful behavior and failure-mode coverage for everything the milestone ships, then run the complete backend and dashboard gates. Tests must protect secret preservation, rollout count, staged cancellation, parsers/uploads, partial failures, and narrow-screen usability rather than snapshotting implementation detail.

## Context

- Backend risk: partial cross-store writes, duplicate rollouts, accidental deletion of omitted masked values, and secret leakage in errors/events.
- Frontend risk: an import or rename silently overwrites another key, Cancel leaves mutations behind, retry duplicates a successful patch, or responsive actions overflow again.

## Steps

1. Add Core/adapter tests for mixed patch, all modes, generation, authorization, unavailable store, compensation, redaction, and exactly-zero/one rollout.
2. Add pure tests for draft diffs, dotenv parsing, export, generation, file validation, and save-phase retry state.
3. Add component tests for view/edit/cancel, menus/dialogs, reveal boundaries, upload/import, group create/link, errors, keyboard/focus, and mobile classes/overflow guard.
4. Run backend and dashboard full suites plus typecheck/lint; browser-run the local fixture at desktop and 390px.

## Acceptance criteria

- [ ] Tests fail on value loss, secret leakage, duplicate rollout, write-before-save, broken Cancel, invalid import/upload, and mobile overflow regressions.
- [ ] `cd lego/backend && go test ./...` passes.
- [ ] `cd dashboard && yarn typecheck && yarn lint && yarn test` passes.
- [ ] Browser evidence covers success and at least one save-success/deploy-failure recovery path.

## Out of scope

- Tautological snapshots or coverage-only branches.
