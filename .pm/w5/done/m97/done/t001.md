## Objective

Add the storage and the plumbing: a closed `surface` on `product_activity_events`, a `Surface` field on `core.ProductActivity`, and a request-context carrier the API middleware sets so `Base.ObserveProductActivity` can fill it without every call site changing.

## Context

- Gate satisfied: v1 (`0114`/`0115`, `store/product_analytics.go`, `apps/product_analytics.go`, `core/product_activity.go`) shipped as `a99e13750`, pinned for deploy by `ba00f3c98`. Confirm the migrations are actually applied in the environment you test against; take the **next free migration number at implementation time**.
- `core.Base.ObserveProductActivity` already normalizes `ActorType`; add `Surface` there, defaulting to `unknown`.
- `api/httpmetrics.go` middleware knows the surface per request (closed set); add a `core.WithSurface(ctx, s)` / `core.SurfaceFrom(ctx)` pair set by that middleware (or the existing identity middleware — pick the one that runs for every product request, including the internal Blueprint sync path which is not an HTTP request).
- Rollback/deletion semantics of v1 (failed-creation rollback removes provisional events in the same transaction) must be unaffected.

## Steps

1. Migration: `ALTER TABLE product_activity_events ADD COLUMN surface text NOT NULL DEFAULT 'unknown' CHECK (surface IN ('dashboard','cli','mcp','api','blueprint','unknown'))` (+ down).
2. `core.ProductActivity.Surface`; `ObserveProductActivity` fills it from `SurfaceFrom(ctx)` and clamps anything outside the set to `unknown`; store insert includes it.
3. Context carrier + middleware wiring; unit tests for clamp and default.
