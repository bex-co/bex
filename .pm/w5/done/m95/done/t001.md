## Objective

Give the sandbox create and terminate paths first-party, bounded-label Prometheus series on the control-plane registry, mirroring the agent-session `CompletionMetrics` shape (nil-safe, constructor takes a `prometheus.Registerer`).

## Context

- `lego/backend/internal/sandbox/service.go`: `Create` (~line 335) → `createResolved` → `s.Client.Create(...)` (~line 395; `sandboxCapacityError()` on the capacity branch) → `sandboxFromOpenSandbox(raw, workspace)`; `Terminate` (~line 930). Authorization (`s.Authorize`), `ErrSandboxesUnavailable`, unknown plan/template are pre-provisioning outcomes.
- Pattern: `lego/backend/internal/agentsessions/completion_metrics.go:88-135` (`NewCompletionMetrics(reg)`, `observeProvision`); registry wiring `cmd/api/main.go:170`.
- Label discipline (ADR088 § origin-side telemetry): closed sets only — `outcome ∈ {succeeded, failed, capacity, unavailable, rejected}`; no plan/template/workspace labels.
- `Create` returns after the runtime create call; whether the returned state is already Running is decided by `sandboxFromOpenSandbox`. Name the histogram for what it measures (create-call wall-clock), not "time to Running", unless the service itself observes Running.

## Steps

1. Add `sandbox/metrics.go`: `Metrics` struct with `createTotal` (CounterVec), `createSeconds` (HistogramVec, buckets `{1,2,5,10,20,30,60,120,300}` like the sibling), `terminateTotal` (CounterVec); `NewMetrics(reg)`; nil-safe observe helpers.
2. Instrument `createResolved` around the runtime call and the outcome classification; instrument `Terminate`; wire `sandbox.NewMetrics(metricRegistry)` where the sandbox `Service` is constructed in `cmd/api/main.go`.
3. Unit tests with `prometheus/testutil`: each outcome increments exactly one series; pre-provisioning errors (denied, bad request, disabled) increment nothing; nil metrics is a no-op.
