## Objective

Stand up a `features/env-groups/` feature whose hooks cover the full env-group contract at the **workspace** level (not scoped to a single service), reusing the existing service-scoped `use-env-groups.ts` logic where possible: list all groups, get one, create/delete, edit vars, set/delete a secret file, and link/unlink a service.

## Context

- Backend contract (GraphQL): `envGroups`/`envGroup` queries + `createEnvGroup`/`deleteEnvGroup`/`setEnvGroupVars`/`setEnvGroupSecretFile`/`deleteEnvGroupSecretFile`/`linkEnvGroup`/`unlinkEnvGroup` mutations (`lego/backend/internal/envgroups`, docs/ADR018-render-parity.md "Environment groups" row).
- Existing UI: `dashboard/src/features/services/hooks/use-env-groups.ts` + `components/env-groups-panel.tsx` are today mounted only inside `routes/services.$serviceId.env.tsx` (the service Environment tab).
- The GraphQL documents/types live in `dashboard/src/graphql/definitions.ts` — see [[dashboard-offline-codegen-drift]] (splice per-feature, never full-codegen).

## Steps

1. Create `dashboard/src/features/env-groups/` (hooks + types + locales dirs), moving/promoting the reusable pieces of `features/services/hooks/use-env-groups.ts` so both the service tab and the new page share them.
2. Add a `useEnvGroups()` list hook and a `useEnvGroup(id)` detail hook; confirm `envGroups`/`envGroup` documents exist in `definitions.ts` (splice if missing).
3. Wire mutation hooks: create/delete group, setVars, set/delete secret file, link/unlink service — returning busy/error state consistent with existing feature hooks.

## Files

- `dashboard/src/features/env-groups/**` (new)
- `dashboard/src/features/services/hooks/use-env-groups.ts` (promote shared logic)
- `dashboard/src/graphql/definitions.ts` (splice any missing documents)

## Acceptance criteria

- [ ] `useEnvGroups()` returns the workspace's groups (var/file counts + linked-service ids); `useEnvGroup(id)` returns one group's full detail.
- [ ] Create/delete/setVars/setSecretFile/deleteSecretFile/link/unlink hooks compile and are covered by the service Environment tab's existing usage without regression.

## Out of scope

- The list/detail pages themselves (t002/t003) and the create dialog (t004).
