Inject the runtime set on the app container (and cron and pre-deploy where Render sets them), computed from the selected release like m147's WEB_CONCURRENCY so held/rolled-back releases stay consistent, and yielding to any literal or envFrom key the service sets.

- `lego/operator/internal/controller/web_concurrency.go` is the yielding pattern
- `appEnv` keeps PORT last
