## Objective

Build one shared settings-row component implementing Render's edit-in-place pattern: label + description on the left; on the right an always-rendered input (text variant and select variant) that is disabled by default with a pencil Edit button beside it. Clicking the pencil enables and focuses the input and replaces the pencil with Cancel + "Save changes" buttons, Save staying disabled until the draft differs from the current value. Cancel (and Escape) restores the value and returns to the disabled state. Support an optional confirm-dialog hook invoked before save for fields that trigger a rebuild, an optional input prefix slot (used by m51's root-dir prompt prefix), and busy/saving state.

## Context

- Current anti-pattern to replace: each row is bespoke with `editing` state that swaps plain text for an `Input` — e.g. `dashboard/src/features/services/components/display-name-row.tsx` renders the value as a `<div>` until Edit is clicked.
- Verified Render behavior (live, 2026-07-27): the Name textbox stays in the DOM, becomes active on pencil click, `Save changes` renders `[disabled]` until dirty, Cancel restores.
- shadcn `Input`, `Button`, `Select` primitives live under `dashboard/src/common/components/ui/`.
- i18n via `useTranslations` (`dashboard/src/common/hooks/use-translations`); add en/zh strings for shared labels (Cancel, Save changes).

## Steps

1. Create `editable-field-row.tsx` (text + select variants, shared chrome) under `dashboard/src/features/services/components/`.
2. Props: label, description, value, placeholder, optional prefix, optional `confirm` callback (returns a promise/boolean), `onSave`, busy, disabled-reason (e.g. feature unavailable), select options for the select variant.
3. Implement focus management (enable → focus + select), Escape-to-cancel, dirty tracking, and a11y (input keeps its label association in both states).
4. Unit-test the state machine (disabled → editing → save/cancel, dirty gating, confirm hook ordering).

## Acceptance criteria

- [ ] Input is present and visibly disabled before Edit is clicked; value readable.
- [ ] Pencil click enables + focuses the same input; Cancel + "Save changes" replace the pencil; Save disabled until the draft differs.
- [ ] Cancel and Escape restore the original value and disabled state without saving.
- [ ] Confirm-hook (rebuild dialog) runs before `onSave` and can abort the save.
- [ ] Select variant behaves identically with a disabled select.
