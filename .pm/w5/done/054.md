# Alert→panel coverage drift guard for the obs dashboards

Why: ADR088 §6's rule is "every alert gets a panel", but nothing enforces it — the §6 review triage (item 4, 2026-09-08) showed the claim can drift from reality silently (e.g. `WebhookDeliveryAdmissionPressure` had no panel until the same triage), and a hand-audit goes stale on the next alert.

Add a mechanical check to `scripts/gitops-validate.sh` (or a sibling script it calls): extract every alert rule's backing series from `deploy/gitops/base/prometheus.yaml` and fail closed unless each appears in at least one dashboard JSON in `deploy/gitops/base/values/grafana.values.yaml` (allow an explicit, commented waiver list for alerts whose series is intentionally panel-less). Output the alert→dashboard/panel map so the audit the reviewer asked for is generated, not hand-maintained.
