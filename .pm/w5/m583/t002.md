## Objective

Audit the other 11 unemitted values of `components.schemas.errorCode` in the pinned Render OpenAPI spec, enforce Render's `build_source_region_mismatch` on `POST /v1/services` and `PATCH /v1/services/{id}` (plus GraphQL/MCP) when linking a git-backed build source in a different declared Render region, and wire any other applicable error code found.

## Context

- The 11 remaining unemitted `errorCode` values at `3854adf442` are: `build_source_region_mismatch`, `multiple_regions`, `snapshot_plan_mismatch`, `sandbox_group_suspended`, `preauth_consent_required`, `preauth_declined`, `preauth_attempt_spent`, `preauth_no_payment_method`, `preauth_unavailable`, `cursor_origin_receipt_expired`, and `cursor_origin_receipt_invalid`.
- Render's pinned OpenAPI for both `POST /services` and `PATCH /services/{serviceId}` documents: `400 with code: build_source_region_mismatch if buildSourceId names a git-backed Build Source in a different region than the service.`
- Since `w9/105`, services and build sources both carry a declared Render region (`resourcemeta` / `AppView.Region` / `BuildSourceGit.Region`), defaulting to `BEX_REGION`'s Render alias when omitted.
- Recommendation under `ADR008 § Render parity first` (not a user decision): compare effective Render regions on git-backed build sources at service create (`buildSourceId`) and `LinkBuildSource` (`PATCH buildSourceId`, GraphQL `linkBuildSource`, MCP `link_service_to_build_source`), refusing a mismatch with `400 build_source_region_mismatch` (image-backed build sources are region-independent per Render's description).

## Steps

1. Inspect `lego/backend/internal/apps/build_sources.go` (`LinkBuildSource`, `createBuildSourceCarrier`, `CreateBuildSource` `serviceIds` linking) and `apps/service.go` (`Create` with `buildSourceId`) to determine effective Render region for both the git-backed build source and the service.
2. When a git-backed build source and service resolve to different Render regions, return `core.NewBadRequestError("build_source_region_mismatch", …)` consistently across REST, GraphQL, and MCP.
3. Audit `multiple_regions`, `snapshot_plan_mismatch` (runtime snapshots, pending `w2/m322`), `sandbox_group_suspended` (bex has no suspended sandbox-group state), `preauth_*`, and `cursor_origin_receipt_*`: wire any that already correspond to an enforced bex refusal, and record exact N/A rationale for the rest for `t003`.
4. Add unit and composed-server tests verifying `build_source_region_mismatch` on both `POST /v1/services` and `PATCH /v1/services/{id}` (and verifying matching regions and image-backed build sources still succeed).

- [ ] Linking a git-backed build source with the same region, or an image-backed build source, succeeds.
- [ ] Every remaining unemitted `errorCode` has a verified disposition (emitted or N/A reason).
