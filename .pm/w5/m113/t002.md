## Objective

`availabilityEdgeAt` uses a lower bound that only availability changes move, so a phase-only write can't hide the Ready transition.

## Context

- `availabilityEdgeAt(transition, previousChangedAt, observed)` (`store/event_facts.go:474`) accepts the transition only if it is after `previousChangedAt`, the checkpoint's `updated_at` (read at `:351` and `:365`).
- The checkpoint UPDATE (`event_facts.go:403-409`) moves `updated_at` whenever phase, availability or suspended changes.
- `healthy_transition_at` is the reference `rejectStaleUnhealthy` already orders against.
- The comment "Nothing reads updated_at" (`event_facts.go:391`) has been false since w4/196.

## Steps

1. Bound failure edges by `healthy_transition_at`, or add an `availability_changed_at` column that only availability changes move (new migration with the next free number).
2. Rewrite the comment to state the invariant.
3. Leave the recovery edge and the anti-flap debounce unchanged.
