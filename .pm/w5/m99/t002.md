## Objective

Stop the deferred-teardown reaper from permanently abandoning a sandbox whose teardown failed for longer than its scan window.

## Context

- `Completer.reapIdleSandboxes` (`lego/backend/internal/agentsessions/completion.go:319-328`) computes `since := c.now().Add(-(2*c.sshGraceTTL() + c.idleTTL()))` and passes it to `ListTerminalAgentSessionsWithSandbox`.
- `ListTerminalAgentSessionsWithSandbox` (`lego/backend/internal/store/agentsessions.go:481-497`) filters `phase = ANY($1) AND sandbox_id <> '' AND updated_at >= $2`.
- Shipped defaults make that window **8h30m**: `defaultSSHGraceTTL = 4 * time.Hour` (`completion.go:217`) and `BEX_AGENT_SANDBOX_IDLE_TTL` defaulting to `30 * time.Minute` (`cmd/api/config.go`).
- A failing teardown does not advance `updated_at`, so the row slides out of the window and is never retried. The store comment at `agentsessions.go:474-480` justifies the bound with "skips pre-feature history (whose sandboxes are long gone)" — the assumption this task removes.

## Steps

1. Make the eligibility decision per row (is this session terminal and past its own idle grace?) instead of pre-filtering the scan by `now`-relative recency.
2. Keep the scan cheap without capping age: an index on `(phase, sandbox_id)` limited to `sandbox_id <> ''`, or a partial index, so the working set stays small without an `updated_at` floor.
3. If a bound must remain for cost reasons, drive it from a durable per-row attempt counter/next-attempt timestamp that the failure path advances, so retries back off but never stop.

## Files

- `lego/backend/internal/agentsessions/completion.go`
- `lego/backend/internal/store/agentsessions.go`
- a new migration under `lego/backend/internal/store/migrations/` if an index is added

## Acceptance criteria

- [ ] A test with a terminal session holding a `sandbox_id` and `updated_at` **30 days** in the past is reaped on the next tick; the same test fails on `main`.
- [ ] Repeated teardown failures are retried indefinitely with backoff, proven by a test that fails the client N times and asserts the N+1th attempt still happens.
- [ ] The scan's cost is bounded by the number of sessions holding a sandbox, not by history size — asserted against a table seeded with many terminal rows that hold no sandbox.

## Out of scope

- The hibernation retention sweep (`defaultRetentionTTL`, ADR059 D5).
- Changing the idle-grace semantics themselves (ADR059 D2 / ADR054 D6).
