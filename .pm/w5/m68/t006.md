## Objective

Add meaningful tests for the loader-prefetch behavior: the loader primes the cache and the component reads warm without a second fetch.

## Context

- Assert real behavior: a route's loader populates the Apollo cache and the mounted component renders data without issuing a duplicate query.
- Cover the cause-aware fetch policy (network-only on entry, cache-first on `stay`) so a regression to always-refetch is caught.

## Steps

1. Add a test that invokes a covered route's loader and asserts the primary query is cached.
2. Add/extend a render test asserting the warm component renders data without a second network call.
3. Cover the `stay` cache-first path (tab switch / search-param change doesn't refetch).

## Files

- `dashboard/src/routes/__tests__/*` and/or feature-level tests for the covered routes.

## Acceptance criteria

- [ ] Loader-primes-cache test passes and fails if the loader is removed.
- [ ] Warm-render-no-refetch test passes.
- [ ] `yarn test` green.
