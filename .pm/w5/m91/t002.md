## Objective

Keep the user’s selected IDs until an explicit reset instead of pruning them into all-instances mode.

## Context

- See [milestone scope and evidence](README.md); this corrects a specific incomplete m89 criterion.
- Use isolated dev-5 for live verification and read cascading instructions before implementation.

## Steps

1. Replace destructive discovery pruning with explicit all-versus-selected state.
2. Retain selections and labels across refresh gaps and window changes; do not let empty inventory remove query intent.
3. Provide an explicit return-to-all action and define resource-navigation reset so choices cannot accidentally cross service boundaries.

## Acceptance criteria

- [ ] Discovery empty/error states never remove the active INSTANCE filter.
- [ ] A selected historical instance remains selected when it has no samples in the new window.
- [ ] Only an explicit all action or deliberate resource-navigation reset clears selection.
