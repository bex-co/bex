## Objective

Check that the main mutation paths (service create/update, deploy trigger, Blueprint apply) honor context cancellation so a timed-out request does not keep writing, and that a retry after a timeout does not apply the change twice.

## Context

- `lego/backend/internal/apps/`, `internal/deploys/`

## Steps

1. Trace ctx through the main mutation paths.
2. Fix any path that ignores cancellation.

## Files

- `lego/backend/internal/apps/`
- `lego/backend/internal/deploys/`

## Acceptance criteria

- [ ] A cancelled mutation leaves no partial write, or the write is idempotent on retry
