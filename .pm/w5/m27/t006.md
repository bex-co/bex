## Objective

End-to-end verify the Blueprints surface against the mock cluster: deploy a repo-backed `bex.yml`, confirm the blueprint appears in the list, view its manifest, run a sync, and run a validate.

## Context

- Local cluster: `bash scripts/mock-cluster.sh`; `scripts/app-apply.sh <bex.yml>` / MCP `deploy` auto-registers a blueprint when the deploy includes a `repo`.
- Blueprints auto-register on every repo-backed `deploy` (docs/ADR018-render-parity.md).

## Steps

1. Stand up / reuse the mock cluster and run the dashboard.
2. Deploy a repo-backed `bex.yml` (a multi-service stack form exercises `databases:` + `fromDatabase`).
3. Confirm the blueprint lists → open detail → view manifest → run Sync (idempotent) → run Validate (dry-run, per-entry errors on a deliberately-broken manifest).
