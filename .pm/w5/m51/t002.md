## Objective

Render Render's prompt-prefix affordance inside the three command inputs on every service type that shows them: a non-editable `<rootDir>/ $` prefix when `spec.rootDir` is set (e.g. `backend/ $`), plain `$` when unset, updating live when Root Directory changes. Applies to Build Command, Pre-Deploy Command, and Start/Docker Command.

## Context

- Render reference (live 2026-07-27, root dir `backend`): all three command textboxes render a literal `backend/ $` prefix inside the field.
- Precedent already in-tree: the static-site section carries root-dir prefixes since w5/m48 — generalize that treatment instead of duplicating it.
- m50/t001's `EditableFieldRow` has a prefix slot for exactly this.

## Steps

1. Extract/reuse the w5/m48 prefix rendering as a shared helper (rootDir → prefix string).
2. Thread it through the three command rows in `build-deploy-section.tsx` (and keep static-site behavior identical).
3. Verify the prefix is presentation-only — saved values never include it.

## Files

- `dashboard/src/features/services/components/build-deploy-section.tsx`
- `dashboard/src/features/services/components/static-site-section.tsx` (reuse, no behavior change)
- tests under `__tests__/`

## Acceptance criteria

- [ ] With rootDir `backend`, all three command inputs show `backend/ $`; clearing rootDir switches them to `$` without reload.
- [ ] Saved command values are unaffected by the prefix.
- [ ] Static-site rows unchanged in behavior.

## Out of scope
