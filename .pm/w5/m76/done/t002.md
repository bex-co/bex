## Objective

Add a **Source** card to the service Settings page mirroring Render's: it displays the current backing source (`owner/repo` + branch, or image ref) and an **Edit** button opening a dialog to pick a different connected-account repo (reusing the account-grouped `ServiceSourcePicker`), change the branch (`useRepoBranches` combobox with free-text fallback), or switch to a container image (image ref + registry credential select) — saving PATCHes the service and shows Render's semantics honestly: "changes are not deployed automatically; the next deploy uses the new source."

## Context

- Page: `dashboard/src/routes/services.$serviceId.settings.tsx` + `features/services/components/` (see `build-deploy-section.tsx` for the existing Settings-card pattern and where Branch currently surfaces).
- Reuse: `ServiceSourcePicker` (m74 account-grouped, ADR078 §6 workspace-scoped), `useRepoBranches`, `RegistryCredentialSelect`; the update mutation should ride the existing service-update GraphQL operation (extend its document with repo/branch/image if the fields aren't yet selected — offline codegen via schema dump).
- Type immutability: never offer a type change (milestone constraint).
- Locale strings en+zh; every string through `t()`.

## Steps

1. Source card (display + Edit) with the three edit modes; confirm dialog copy includes the no-auto-deploy note.
2. Wire the mutation; optimistic/refetch behavior consistent with the other Settings cards.
3. Update/extend the settings-page tests' mocks; `yarn typecheck && yarn lint && yarn test`.

## Files

- `dashboard/src/features/services/components/` (new `source-card.tsx` or extension of build-deploy-section), `routes/services.$serviceId.settings.tsx`, `src/graphql/definitions.ts`, locales

## Acceptance criteria

- [ ] Repo-backed service: card shows repo+branch; Edit can re-point repo (grouped picker), change branch, or switch to image.
- [ ] Image-backed service: card shows image; Edit can re-point image or switch to a repo.
- [ ] Save PATCHes without triggering a deploy; the no-auto-deploy note is visible in the dialog.
- [ ] `yarn typecheck`, `yarn lint`, `yarn test` green.
