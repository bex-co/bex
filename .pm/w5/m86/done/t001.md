## Objective

Deploy Grafana as an Argo CD Application in the `monitoring` namespace alongside the backends it reads, with Prometheus and Loki datasources plus a starter platform dashboard provisioned as code — zero click-ops state (ADR087 §1).

## Context

- Pattern to follow: `deploy/gitops/base/prometheus.yaml`, `deploy/gitops/base/loki.yaml` (Argo CD Application + Helm chart, `monitoring` namespace), values files under `deploy/gitops/base/values/` (see `hydra.values.yaml`).
- In-cluster datasource URLs: Prometheus and Loki services in `monitoring` (read their manifests for exact service names/ports).
- Break-glass local admin credentials come from a Secret (SealedSecret in prod per ADR016) — reference by name, never a value in git.
- Tenant pods are already denied from `monitoring` by `network-policies.yaml`; confirm Grafana needs no new policy exception beyond Traefik ingress reachability.

## Steps

1. Add `deploy/gitops/base/grafana.yaml` (Argo CD Application, official Grafana chart, pinned version, `monitoring` namespace) + `deploy/gitops/base/values/grafana.values.yaml`.
2. Provision datasources (Prometheus + Loki, in-cluster URLs) and a starter "platform availability" dashboard as code (dashboards provider + committed JSON); disable sign-up; admin password from the named Secret.
3. Register `grafana.yaml` in `deploy/gitops/base/kustomization.yaml` with a one-line comment matching neighbors.
4. Run `scripts/gitops-validate.sh` (and any kustomize build check the repo uses) to confirm the tree renders.

## Files

- `deploy/gitops/base/grafana.yaml` (new)
- `deploy/gitops/base/values/grafana.values.yaml` (new)
- `deploy/gitops/base/kustomization.yaml`

## Acceptance criteria

- [ ] `kustomize build deploy/gitops/base` (or the repo's validate script) passes with the new Application
- [ ] Datasources + starter dashboard are file-provisioned, no runtime configuration required
- [ ] No secret value in git; admin credentials referenced by Secret name only

- The full six-dashboard set (starter only; grow post-milestone)
