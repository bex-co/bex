## Objective

Give prod Grafana its public address `obs.bex.co` (letsencrypt-prod TLS) and generic-OAuth OIDC config against `https://oauth.bex.co`; keep the local overlay admin-only with no public host (ADR087 §2/§5).

## Context

- Overlay pattern: `deploy/gitops/overlays/prod/kustomization.yaml` + `overlays/prod/values/*.values.yaml`; hostname/TLS precedent in `deploy/gitops/base/values/hydra.values.yaml` (issuer + ingress + `cert-manager.io/cluster-issuer: letsencrypt-prod`).
- OIDC client details come from t003: confidential client, redirect `https://obs.bex.co/login/generic_oauth`, scopes `openid profile email`, PKCE S256 (`use_pkce`) — the consent gate refuses auth-code flows without S256 (`hydra-consent.ts` `pkceSatisfied`).
- Role mapping: `role_attribute_path` over the `ops_role` claim (t005), `role_attribute_strict: true`, `allow_sign_up: true` (org user auto-created; admission is gated upstream at consent). Short token/session lifetimes per ADR087 §4.
- Client secret via Secret/SealedSecret reference, name-only in git.

## Steps

1. Prod overlay: ingress host `obs.bex.co` + TLS, `[auth.generic_oauth]` settings (issuer discovery, PKCE, scopes, role mapping strict, short lifetimes), disable the login form except break-glass admin.
2. Local overlay: exclude OIDC + public ingress — admin-only, same reduced shape as other local components.
3. Validate both overlays render (`scripts/gitops-validate.sh` / kustomize build).

## Files

- `deploy/gitops/overlays/prod/kustomization.yaml`

## Acceptance criteria

- [ ] Prod overlay renders Grafana with `obs.bex.co` ingress + letsencrypt-prod and strict OIDC role mapping
- [ ] Local overlay renders Grafana with no OIDC and no public host
- [ ] `role_attribute_strict` is on — an id_token without `ops_role` cannot log in even if minted
