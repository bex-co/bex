## Objective

Close the `len(have) == 0` and `want.Enum` blind spots in `mcp_parity.go` / `mcp_parity_test.go`, and add an automated schema-hygiene guard in `mcp_schema_test.go` so leaked tag directives and missing enum/union schemas cannot regress.

## Context

- `lego/backend/internal/api/mcp_parity.go:155-171` (`mcpArgTypeMismatches`):
  - Currently skips `len(have) == 0`, letting `any`-typed fields emit `{}` and silently pass `TestMCPArgumentTypesMatchUpstream`.
  - Never inspects `want.Enum`, even though `render-mcp-tools.json` already pins `enum` for all 21 shared-tool arguments.
- `lego/backend/internal/api/mcp_schema_test.go` currently checks only for inferred `[]byte` arrays (`TestMCPSchemasHaveNoByteArrays`).

## Steps

1. Update `mcpArgTypeMismatches` in `lego/backend/internal/api/mcp_parity.go` so that when `want.Type != ""` and `len(have) == 0` (the property exists on bex's tool with no `"type"` / `"anyOf"` type), it is reported as a mismatch instead of silently skipped. Support reading types from both `"type"` (string or string array) and `"anyOf"`/`"oneOf"` branches in `jsonSchemaTypes` (`mcp_parity_test.go`).
2. Add enum parity comparison (`mcpArgEnumMismatches` or in `TestMCPArgumentTypesMatchUpstream` / a dedicated `TestMCPArgumentEnumsMatchUpstream`) that inspects every shared tool argument with `len(want.Enum) > 0`:
   - Fails if bex's schema property omits `"enum"`.
   - Fails if any value in `want.Enum` is missing from bex's emitted `"enum"` (`bexEnum ⊇ upstreamEnum`).
   - Supports an explicit `mcpAcceptedEnumDivergences` map (empty initially, stale-checked so it cannot rot).
3. Add a guard in `lego/backend/internal/api/mcp_schema_test.go` (e.g. `TestMCPSchemasHaveNoLeakedTagDirectives`) walking every registered tool's input/output schema descriptions and failing on leaked `jsonschema` directive tokens (`required,`, `,enum=`, `enum=`, `omitempty,`).
4. Add unit tests for `mcpArgTypeMismatches` (including empty `have` failing) and enum mismatch helpers in `mcp_parity_test.go`.

## Files

- `lego/backend/internal/api/mcp_parity.go`
- `lego/backend/internal/api/mcp_parity_test.go`

## Acceptance criteria

- [ ] `TestMCPArgumentTypesMatchUpstream` fails if a shared tool argument has an empty schema `{}` when upstream declares a type.
- [ ] `TestMCPArgumentEnumsMatchUpstream` (or extended guard) asserts all 21 pinned upstream enum arguments emit `"enum"` containing every pinned upstream value.
- [ ] `TestMCPSchemasHaveNoLeakedTagDirectives` passes across all registered tools and fails if `,enum=` or `required,` is reintroduced.
- [ ] `cd lego/backend && go test ./internal/api/...` passes.

## Out of scope
