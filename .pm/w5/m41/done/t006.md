## Objective

Add the populated Render Project's checkbox selection and bulk Move operating flow, using t001's verified target semantics and bex's existing full-replace membership verbs.

## Context

- Render shows a leading checkbox per row and a selected-count toolbar with Move.
- bex has per-row Move-to-project and an Environment-level Manage resources dialog, but no table selection or selection-scoped Move action.
- Backend Environment membership is full-replace per kind (`setEnvironmentServices`, `setEnvironmentDatabases`, `setEnvironmentKeyValues`, `setEnvironmentEnvGroups`). Selection may span kinds, so failures must not be reported as a total success.

## Steps

1. Add accessible row and select-visible-all checkboxes with stable `kind:id` identity; selection follows the t001 pagination/filter rules.
2. Show an accurate selected count and enable Move only for an eligible nonempty selection.
3. Implement the evidence-backed target picker. Reuse existing Environment/project hooks and full-replace mutations rather than inventing client-only membership state.
4. Reconcile mixed-kind operations carefully: deduplicate ids, avoid dropping unselected members, refetch canonical membership, and surface partial failures truthfully.
5. Clear or retain selection after filter/environment changes and mutation results exactly as t001 records; keyboard and screen-reader interaction must be complete.
6. Keep per-row actions and Manage resources available for one-off and full-environment workflows.

## Acceptance criteria

- [ ] Visible rows can be selected individually or as an eligible visible set with an accurate count.
- [ ] Move updates the verified target membership without dropping unrelated resources.
- [ ] Mixed-kind and partial-failure behavior is truthful and canonical state is refetched.
- [ ] Filtering, switching Environment, retrying, and keyboard use cannot leave ghost selections or a false success state.

## Out of scope

- Bulk delete or bulk lifecycle actions.
- A new membership model; use the existing Project/Environment contracts.
