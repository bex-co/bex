## Objective

Add meaningful regression coverage for the populated Project behavior shipped by this milestone.

## Steps

1. Backend tests: Service GraphQL region configured/unconfigured and metadata consistency with existing updatedAt/runtime sources.
2. Projection/table tests: every resource kind, honest missing metadata, distinct created/updated values, aligned responsive columns.
3. Route/component tests: selected Environment default/URL/unknown id, search/type composition and category counts, back/forward/refresh, unassigned and empty states.
4. Create-context tests: selected Project/Environment initialization, stale/mismatched values, manual override, submitted mutation variables.
5. Bulk-Move tests: individual/select-all, filter/switch selection lifecycle, mixed kinds, unrelated-member preservation, success, failure, and partial failure/refetch.
6. Run backend tests appropriate to the GraphQL change plus dashboard codegen, lint, typecheck, tests, and production build.
