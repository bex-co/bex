## Objective

Mount Render's `create-postgres-user` (`POST /postgres/{id}/credentials`, today a 404) on a Core verb that creates the managed role and makes it the default, returning Render's credential shape. `GET …/credentials` reports the real default. `DELETE …/credentials/{username}` refuses the current default by name and, for the original owner, revokes its login instead of dropping it.

## Steps

1. Add the Core verb (create + promote) reusing `CreateUser`'s Secret issuance.

3. Implement the default-refusal and owner-deactivation delete rules.
