## Objective

Give the `Database` CRD a default-user pointer (empty = the create-time owner) and a record that the original owner's login was revoked. The operator grants each managed user the owner role's privileges (CNPG managed role `inRoles: [<owner>]`) so a promoted default can use every existing object, and sets the original owner to `login: false` when it is "deleted" — never dropping it, so the objects it owns survive.

## Context

- `lego/types/v1alpha1/database_types.go` (`Spec.Users`, `DeletedUsers`, `EffectiveDatabaseUser`)
- `lego/operator/internal/controller/database_controller.go`, `spec_projection.go` (managed roles)
- Render docs (render.com/docs/postgresql-credentials): every added user becomes the default; the default cannot be deleted; deleting the original user revokes its login.

## Steps

1. Add the default-user field and the original-owner-deactivated marker with CEL validation (default must be the owner or a member of `spec.users`).
2. Project `inRoles` and `login: false` into the CNPG Cluster's managed roles.
3. Regenerate CRDs (`make test` from `lego/operator/`).
