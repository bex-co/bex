## Objective

Internal/external connection strings, `psqlCommand` and the Blueprint `fromDatabase` user/password/connectionString resolution read the default user's Secret, so a rotation reaches linked services on their next Blueprint sync, as Render documents.

## Context

- `lego/backend/internal/postgres/` connection-info
- Blueprint compiler `fromDatabase` → SecretKeyRef (`lego/backend/internal/apps/` blueprint code)
- Render: "Whenever the default user changes, these environment variables update their value on the next Blueprint sync."

## Steps

1. Point connection-info at the default user's Secret.
2. Point `fromDatabase` resolution at it; verify a sync rewrites the reference.
3. Keep services that hold a literal copied URL unaffected (they keep working until the old user is deleted).

## Files

- `lego/backend/internal/postgres/`
- `lego/backend/internal/apps/` (Blueprint `fromDatabase`)

## Acceptance criteria

- [ ] connection-info returns the new default's credentials after rotation
- [ ] A Blueprint sync after rotation re-points `fromDatabase` env vars
