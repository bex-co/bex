## Objective

Close and ship the milestone only when its observable definition of done holds.

## Context

- Follow /pm status/move rules and /loopx /ship sequencing; source changes from different milestones ship separately.

## Steps

1. Verify every task, the live evidence and the cleanup against the definition of done.
2. Via /pm, mark completed tasks done, move task files to done/, synchronize the table and status, move the milestone to w5/done, and check the workstream checkbox.
3. Format Markdown and validate board paths and dependencies, then invoke /ship for the milestone's changes. If shipping fails, record the run-level block without claiming shipment.

## Files

- .pm/w5/m111/
- .pm/w5/README.md

## Acceptance criteria

- [ ] The definition of done is real, all task statuses and moves agree, and no old-path stub remains.
- [ ] The milestone has a recorded successful commit/push, or a truthful run-level ship checkpoint without a shipment claim.

## Out of scope

- New work discovered during closeout; file it as a w5 inbox note.
