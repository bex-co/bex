# Decide whether tenant request logs should drop the access-log fields nothing reads

Why: w5/076 made the Traefik access-log fields an allowlist but kept every field tenants already see, since ADR010 chose "losing nothing a tenant may see"; the review behind w5/076 proposed keeping only the fields something reads, which would change what tenants see, so it needs a product decision first.

- **Decision needed (user):** keep today's 32 fields, or trim to what a reader or a tenant needs. The w5/076 proposal kept 9: the shipper's `ServiceName`, `KubernetesIngressName`, `RequestMethod`, `DownstreamStatus` and `RequestHost`; bex-api's `RequestPath` and `Duration`; and `StartUTC` and `ClientHost` for tenants. Candidates to also keep, which Render's request logs show: response size (`DownstreamContentSize`) and protocol (`RequestProtocol`).
- **If trimmed:** edit `deploy/gitops/base/values/traefik.values.yaml` and `tenantAccessLogFields` in `lego/backend/internal/logs/access_log_fields_test.go`, and update ADR010's "every kept field intact" sentence. The Docker check in w5/076's closure (Traefik v3.7.5 with the chart-rendered flags) shows the result before deploy.
- **Size:** about 20 minutes once decided.
