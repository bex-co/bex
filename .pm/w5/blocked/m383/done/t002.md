## Objective

An imported manifest holds only layers bex copied: a layer with `urls` would make containerd on the sandbox node fetch from those URLs over the host network.

## Context

- `lego/backend/internal/sandbox/images.go` `copy` (`desc.Image()`, `remote.Write`), the manifest reads capped in round 24.

## Steps

1. Before the write, read the source manifest's layer descriptors; refuse any with non-empty `URLs` or a non-distributable media type, naming the digest.

## Acceptance criteria

- [x] Test: a manifest with a foreign layer is refused before any registry write; an ordinary manifest imports.

## Outcome (2026-11-13)

`foreignBlob` refuses a manifest whose config or any layer carries download URLs, or a non-distributable layer, before any registry write, naming the blob. The copy also writes only the image the check saw (`copy` compares the image digest), since a registry labels a manifest by header. Tests: `TestImportRefusesSourcesItWouldNotCopy`, `TestCopyWritesOnlyTheCheckedImage`.
