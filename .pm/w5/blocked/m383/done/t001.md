## Objective

An import never reads from the sandbox registry itself: a source on that host could have its layers mounted across repositories with the sink's credential, linking another tenant's layer by digest.

## Context

- `lego/backend/internal/sandbox/images.go` `resolveSource`, `registryHost`, `copy` (`remote.Write`).

## Steps

1. In `resolveSource`, refuse a reference whose registry host is the sandbox registry's host (case-insensitive, with and without the port) as an invalid source, before any read.

## Acceptance criteria

- [x] Test: a source on the sink's host is refused and nothing is written; another host is unaffected.

## Outcome (2026-11-13)

`resolveSource` refuses a source whose registry is the sandbox registry's host (case-insensitive, same or implicit port) before any read; in production the registry is in-cluster and behind the source dial guard as well. Test: `TestImportRefusesSourcesItWouldNotCopy`.
