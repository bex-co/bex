## Objective

A workspace with a slow source cannot hold every import slot on a replica and starve other tenants.

## Context

- `lego/backend/internal/sandbox/images.go` `slots()` (`importWorkers = 2`), `run`.

## Steps

1. Acquire a per-workspace slot (one per replica) before a shared slot, so a workspace's queued imports wait on its own slot without holding a shared one.

## Acceptance criteria

- [x] Test: with one workspace's import blocked in a slot and more of its imports queued, another workspace's import runs.

## Outcome (2026-11-13)

`workspaceSlots` gives each workspace one import slot per replica, taken before a shared slot in `Images.run`; entries go when no import holds or waits for them. Test: `TestWorkspaceImportSlotsAreFair` (race detector).
