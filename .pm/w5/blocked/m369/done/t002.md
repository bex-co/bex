## Objective

The control plane records an App's terminal deploy transitions (`live`, `build_failed`, `update_failed`, `pre_deploy_failed`, `canceled` by the cluster) within a few seconds of the operator writing them, not on the next resync (w4/624's target behavior).

## Context

- w4/624 (now `w4/done/624.md`): timeline, root cause and blast radius. The same pass marks a successful deploy `live`, so success is late too.
- bex-api's controller-runtime client is uncached (`lego/backend/cmd/api/main.go:248`); `srv.Apps.Kick = rec.Kick` (`:1561`). RBAC already grants `get`/`list`/`watch` on `apps.app.bex.co` cluster-wide (`lego/operator/config/api/rbac.yaml:21-23`).
- The fields `recordDeploy` reads: phase, build and release conditions, `status.build`, `status.releaseStart`, observed generation (`lego/backend/internal/store/reconciler.go`, `recordDeploy` and `releaseDispatchStart`).
- bex-api runs two replicas: check how they share `ReconcileOnce` before adding a trigger to each.

## Steps

1. Start a watch on `apps.app.bex.co` across namespaces (a status-only comparison of old and new objects; reconnect with backoff; a restart counter).
2. Kick the reconciler only when one of the fields above changes; ignore metadata-only and spec-only updates.
3. Keep the 30 s resync unchanged as the level-triggered backstop.
4. If t001's baseline shows a full pass is costly, reconcile only the changed App on a watch kick; otherwise record why the full pass is fine.
5. Ensure a busy cluster cannot turn every status write into back-to-back full passes (`Kick` coalesces; confirm with t001's kick counter).

## Files

- `lego/backend/cmd/api/main.go`, `lego/backend/internal/store/reconciler.go` (or a new watch file beside it)

## Acceptance criteria

- [ ] With the resync stubbed to 10 minutes, an operator-side status write of a failed build turns the deploy row `build_failed` and writes `deploy_ended` within 5 s; with the watch disabled it waits for the tick (control).
- [ ] A watch error or disconnect still converges through the resync.
- [ ] Two bex-api replicas do not double-write a transition.

## Out of scope

- Operator-side reconcile latency (w5/m370).
