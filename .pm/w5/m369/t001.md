## Objective

## Context

## Steps

1. Add `bex_controlplane_reconcile_pass_seconds` (histogram) and `bex_controlplane_reconcile_kicks_total{source}` (`api`, `watch`, `resync`; a closed set) beside the existing control-plane metric.

3. On dev-5 (`bash scripts/dev-env.sh 5 up`), create about 50 Apps and read p50/p95 pass time; record it in the milestone README under `## Findings`.
