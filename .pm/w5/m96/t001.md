## Objective

Create the first-party production fixture the probes need: a `bex-canary` workspace excluded from billing, one free `web_service` built from `examples/hello-go`, and one workspace-scoped API key. This is the user-authorized step (see the milestone README § Authorization); do not proceed without that authorization in place.

## Context

- Fixture spec: `docs/ADR088-platform-observability-ui.md` § "Scheduled probes and the canary fixture" (free plan on purpose — the probe's own request wakes it, exercising the activator).
- Billing exclusion: ADR040 § Mode A (`tenants.billing_excluded=true`, line ~88). The admin path is `lego/backend/internal/billing/admin.go` `OverrideBilling` → `store.SetBillingException(..., store.BillingExcluded, true, actor, reason, now)`; use whatever ops surface exposes it (internal `:8091` listener / ops role), otherwise the documented direct `UPDATE tenants SET billing_excluded = true WHERE id = '<tea-…>'` on the control-plane CNPG primary — record which path was used.
- Creation surfaces: dashboard `/new/workspace` (collects billing email; Hobby plan) or GraphQL `createWorkspace`; service via `POST /v1/services` (public repo `bex-co/bex`, root dir `examples/hello-go`, free plan) or the dashboard wizard; key via `POST /v1/api-keys` in that workspace.
- Never print the key or `.env`; capture ids only.

## Steps

1. Create the workspace; record the `tea-…` id; apply billing exclusion; verify with the read path (`estimatedCost` still visible, no Stripe customer created).
2. Deploy the hello-go free web service; wait for Ready; record `srv-…` and the assigned `https://….onbex.co` URL; confirm it hibernates and wakes on request.
3. Mint the workspace-scoped API key; store it only in `.env` under `BEX_CANARY_API_KEY`.
