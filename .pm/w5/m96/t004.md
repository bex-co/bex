## Objective

Prove each probe can fail — a probe that cannot fail reports safety (ADR088's load-bearing property). For each credentialed probe, break one input deliberately, confirm the tracking issue opens, restore, and confirm the next green run closes it.

## Context

- Issue labels per ADR088 probe table: `tenant-view-down`, `deploy-canary-down`, `tenant-isolation-down`, `sandbox-isolation-down`.
- Cheapest safe breaks: point `BEX_CANARY_SERVICE_ID` at a nonexistent id (tenant-view); an intentionally wrong `BEX_CANARY_WORKSPACE_ID` (deploy canary aborts before creating anything, per its own guard); for the isolation matrix, use the script's documented negative-control switch if one exists — otherwise record that its red path was proven by its own negative-control step and cite the log line.
- Restore in the same session; never leave production variables broken.

## Steps

1. For each probe: set the broken value → dispatch → confirm the issue opened (number recorded) → restore → dispatch → confirm the issue auto-closed.
2. Record issue numbers and run ids in ADR088 and m83's Evidence.
