## Objective

Let bex-api mint a gateway credential for `muse` sessions from a bex-owned Meta key, pinned to the contributor model, independent of any workspace key.

## Context

- `lego/backend/internal/agentsession/devroute.go`: `routeFor`, `PinnedAgent` (claude only), `platformRouteCovers`, `PlatformRouteServes`, `PlatformModelKeyReady`, `PlatformPinnedModel`; `OpenRouterHost`.
- `lego/backend/internal/agentsession/model.go`: the mint injects the platform key only when `host == OpenRouterHost`; a workspace key wins over the platform route.
- Config: `lego/backend/cmd/api/config.go` (`BEX_AGENT_PLATFORM_MODEL_*`), `scripts/agent-platform-model-secret.sh`, env inventory in `lego/backend/AGENTS.md`.

## Steps

1. Make the platform route per profile: `claude` keeps its OpenRouter route; `muse` uses host `api.meta.ai`, Bearer, the new `BEX_AGENT_PLATFORM_META_KEY`, and pin `muse-spark-1.3-contributor`.
2. For `muse`, ignore the workspace key entirely (no BYO path), and report readiness from the Meta route only.
3. Refuse any other model at create with `AGENT_SESSION_MODEL_PINNED`.
4. Wire the secret: `.env` `META_MODEL_API_KEY` → production secret → bex-api env; update `.env.example` and `lego/backend/AGENTS.md`.
