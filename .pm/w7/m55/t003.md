## Objective

Cover the other two surfaces with the same enumerated non-member deny guarantee: every GraphQL query/mutation and every MCP tool, invoked as the workspace-A caller against the workspace-B resource, must be denied. MCP currently has **zero** dedicated cross-workspace tests; GraphQL relies on the assumption that resolvers always delegate to the swept service verbs — this task turns that assumption into an enforced invariant.

## Context

- GraphQL resolvers and the MCP tool registry live in `lego/backend/internal/` (resolvers beside the services; MCP tools registered per-service like `RegisterREST`).
- Enumerate resolvers/tools mechanically from their registries (schema introspection for GraphQL; the tool registry for MCP) with the same completeness-guard pattern as t002.
- Fixture + checker from t001.

## Steps

1. Enumerate GraphQL queries/mutations from the schema; invoke each with workspace-B-targeting arguments as the workspace-A caller; assert authorization error, never data.
2. Enumerate MCP tools from the registry; same invocation and assertion.
3. Completeness guards for both: a new resolver/tool must join the matrix or fail the test; document principled exclusions (e.g. whoami-style caller-scoped verbs) in-test.

## Files

- `lego/backend/internal/api/crossworkspace_matrix_test.go` or sibling `crossworkspace_graphql_test.go` / `crossworkspace_mcp_test.go`

## Acceptance criteria

- [ ] Every GraphQL mutation/query and MCP tool with a workspace-scoped target is asserted-denied for a non-member or justified-excluded.
- [ ] Adding an uncovered resolver/tool fails CI.

## Out of scope

- Dashboard UI (a pure GraphQL client — covered transitively); live-FGA E2E (t004).
