## Objective

The milestone ships tests, so the meaningful coverage task is proving the guard actually guards: seed each authz-regression class the matrix claims to catch and verify the suite turns red. A matrix that passes on today's correct code but would also pass on broken code is tautological — this task is the anti-tautology check.

## Context

- Regression classes to seed (temporarily, one at a time, each reverted): (1) a verb whose `Authorize*` call is removed; (2) a verb authorizing the caller's own workspace object instead of the target's (confused deputy); (3) a REST route rebound to skip its verb's authz path; (4) an MCP tool with the workspace check dropped; (5) for the E2E: an FGA model relaxation making a relation public.
- Each seed is a local, uncommitted mutation; record the red-run evidence (test name + failure line) in this task file or the milestone README when done.

## Steps

1. Apply each seeded regression; run the matrix; confirm the specific failing assertion; revert.
2. Where a class is awkward to seed by hand, add a permanent in-suite self-test instead (e.g. the completeness guard tested against a fake unregistered route).
3. Fill any coverage hole the seeding reveals.

## Files

- `lego/backend/internal/api/` matrix tests (assertions added as needed)

## Acceptance criteria

- [ ] All five regression classes demonstrably fail the suite (evidence recorded).
- [ ] Any hole found during seeding is closed.
