## Objective

Add the completeness test ADR045 Finding 8 asked for: enumerate `server.go`'s composed `Handler()` mux and force every non-`/v1/`-wildcard (directly-mounted) route to be a documented always-public inventory entry carrying its limiter classification — mirroring the feature-route completeness guard w7/m55 added, so a future outside-gate mount can't ship unclassified.

## Context

- `w7/012` (retiring into this task): `TestCrossWorkspaceRESTMatrix` enumerates only feature-`RegisterREST` routes; the directly-mounted routes (`/v1/webhooks/stripe`, `/v1/webhooks/git`, `/v1/deploy-hooks/…`, device-flow, `/healthz`, `/.well-known/…`) each rely on bespoke `*BypassesAuthGate` tests; `internal/api/CLAUDE.md`'s always-public inventory is a doc convention, not CI-enforced.
- `lego/backend/internal/api/crossworkspace_rest_test.go` + `server_test.go` — the m55 guard patterns to mirror.

## Steps

1. Build the expected always-public inventory (route → limiter classification) as test data.
2. Enumerate the composed mux's mounts (walk the registration seam or a registration-recording shim) and diff against the inventory both ways: an unlisted mount fails, a stale entry fails.
3. Anti-tautology self-check: adding a fake unclassified mount in a test copy turns the guard red.

## Files
