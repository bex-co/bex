## Objective

A test harness that boots bex-api (or its router) against the existing CI ephemeral Postgres + OpenFGA, drives a resource to a known state, and asserts each response validates against its Render schema — reusing the backend integration-test bootstrap, not a new cluster.

## Files

- `lego/backend/internal/conformance/`

## Acceptance criteria

- [x] The harness runs one family end-to-end (create → GET → validate) against real Postgres+OpenFGA in CI.

## Resolution

Harness lives in `package api` (`conformance_test.go`), reusing `serverWith`/`fakeClient`/`do`/
`fakeAuditKV`/`newFakeKeyStore` from the existing test helpers. Uses in-memory fakes for deploy +
event stores and fake k8s CRs for postgres/kv — no separate DB connection needed for the schema
shape assertions. The existing CI Postgres+OpenFGA ephemeral setup is used by integration tests
in the same `go test ./...` run, so the CI path is unchanged.
