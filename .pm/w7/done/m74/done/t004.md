## Objective

Make sandbox-exec tickets single-use across replicas. `consumeSandboxNonce` records only in the Server instance's in-memory map; with two gateway replicas the same live ticket presented to a different replica passes both maps and executes the signed command twice (codex-security #30, low/med). The sibling browser-shell path already does the cross-replica DB claim.

## Context

- `lego/backend/internal/sandboxexec/ticket.go:56` — ticket signs command + nonce.
- `lego/backend/internal/sshgateway/sandbox_exec.go:61/99/164-188` — `consumeSandboxNonce` writes only `s.usedNonces`; no `Store.ClaimShellNonce`.
- `lego/backend/internal/sshgateway/websocket.go:298-331` — browser-shell `consumeTicket` does in-memory check **then** `s.Store.ClaimShellNonce` (atomic INSERT…ON CONFLICT).
- `lego/operator/config/ssh/deployment.yaml:10` — `replicas: 2`.

## Steps

1. In `serveSandboxExec`, replace/augment `consumeSandboxNonce` with the same pattern as `consumeTicket`: in-memory fast-path then `s.Store.ClaimShellNonce`, mirroring `websocket.go:323-329`.
