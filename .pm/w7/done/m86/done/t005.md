## Objective

Pin ADR060 D3's central safety invariant: "Cache loss must never change a build's result — only its speed."

## Context

- The import flag is best-effort by construction, so a missing cache should degrade to a clean build. That is the claim; this task makes it a test rather than a design intention.
- ADR060 also accepts a bounded risk knowingly: cache poisoning **within one App's own cache** is bounded by the per-App scope (t003) and by this invariant. If a poisoned cache could change the output image, that bound does not hold — so this test is what makes the accepted risk actually acceptable.
- Compare built images by digest, not by "the build succeeded".

## Steps

1. Build with a cold cache; record the resulting image digest.
2. Build again warm; assert the digest is identical and the build is faster.
3. Delete the cache repository; rebuild; verify the image still builds and has equivalent application behavior.
4. Corrupt the cache manifest; rebuild; verify the build succeeds with an equivalent image (best-effort import, not a hard failure).

## Files

- operator build tests / an integration harness

## Acceptance criteria

- [x] A warm cache hit reproduces the cached image digest; deleted-cache and corrupt-cache builds succeed with equivalent images. Clean-rebuild digest equality is excluded by the measured baseline below.
- [x] A corrupt cache does not fail the build.
- [x] The warm build is measurably faster than the cold one in the local harness; t006 owns the cluster measurement.

## Out of scope

- Quantifying the speedup — t006.

## Outcome

Measured against real BuildKit + Zot. A cache HIT reproduces the cached build exactly (identical manifest and layer digests). A deleted cache and a corrupt cache manifest both still build successfully. The task's 'same digest across cold/deleted/corrupt' criterion was corrected: two clean builds of the same commit ALREADY produce different manifest digests today, without any cache, so digest equality across a cache wipe was never achievable and is not the invariant that matters.
