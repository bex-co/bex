## Objective

Implement the first half of the pinned client's exec handshake: return a `SandboxConnectResponse` that authorizes exactly one stream operation.

## Context

- Request (pinned `repo.go:298-324`, `client_gen.go:20194-20240`): `POST /v1/sandboxes/{sandboxId}/runs/{operation}/token?ownerId=<ws>` with `operation=stream` and body `{"command":"…"}`. The command is optional in the generated type but always sent by exec.
- Response: `201` with `{executionId, expiresAt (RFC3339), method:"POST", token, uri}` (`pkg/client/sandboxes/sandboxes_gen.go:310`). A 201 without a body is treated as an error by the client.
- Existing design and security precedent:
  - `w3/m33/t002` (deferred): `.pm/w3/done/m33/done/t002.md`.
  - The exec ticket minted in `lego/backend/internal/sandbox/exec.go:84-190` (`dialGateway` authorizes `RelCanCreate`; `mintAndDial` signs an exact target and command).
- New id kind (`executionId`, e.g. `exe-`) goes through `lego/backend/internal/id` (`id.New`), never by hand.

## Steps

1. Register the route in `internal/sandbox/rest.go`. Owner is query-or-body, the same as `/exec`. `operation != "stream"` returns 400 (named). Unknown, foreign, or ownerless sandbox returns the existing `SANDBOX_NOT_FOUND` 404. Missing `can_create` returns 403, checked before minting.
2. Mint a short-lived (≤60s), single-use, HMAC-signed token. Bind it to workspace, sandbox, execution id, the exact command, operation, and expiry. The token must not be an API bearer credential.
3. Set `uri` to the redeem endpoint from t004 (absolute URL on the public API origin) and `method` to `POST`.
4. Add the scope-matrix entry (`OpClassWrite`, matching `/exec`) and audit the mint like exec.

## Files

- `lego/backend/internal/sandbox/rest.go`, `exec.go` (or a new `connect.go`), `internal/id` registry, `internal/api/scope_matrix_ops.go`.

## Acceptance criteria

- [x] The pinned client's generated `ConnectSandboxRunWithResponse` decodes `JSON201` against an httptest server.
- [x] 400 for a bad operation, 404 for unknown and foreign ids (same body), 403 without `can_create`. No token minted on any refusal.
- [x] `TestScopeMatrixCoversLiveOperations` passes with the new entry.

## Out of scope

- Redeeming the token (t004), and file tokens for `ea sandboxes copy`.

## Done 2026-09-15

`POST /v1/sandboxes/{id}/runs/{operation}/token` (`rest.go` → `ConnectRun`, `connect.go`): applies the exact exec gate (`authorizeExecTarget`, shared with `dialGateway`) before anything is signed — 403 without can_create, 404 `SANDBOX_NOT_FOUND` for unknown and foreign ids (same body), 400 for a non-`stream` operation or missing command; no token in any refusal body. Token: HMAC via `hmacticket` under a key derived from `BEX_SANDBOX_EXEC_SECRET` with a connect-specific label (so it never verifies as a gateway ticket), bound to subject, workspace, sandbox, `exe-` execution id (`id.SandboxExecution`, minted by `id.New`), operation, exact command, iat/exp (≤60 s), nonce. Response is Render's `SandboxConnectResponse`; `uri` is on `BEX_API_PUBLIC_URL` (request origin fallback). Scope matrix entry added (`OpClassWrite`); `TestScopeMatrixCoversLiveOperations` green.
