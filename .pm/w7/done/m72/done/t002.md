## Objective

Stop the activator from doing a cluster-wide App `List` + linear scan on every unauthenticated request (codex-security #7, medium). Replace it with a maintained host→App mapping and bound the public handler's concurrency.

## Context

- `lego/operator/cmd/activator/main.go:90-121` — `newHandler` routes every non-`/healthz` request through `findAppByHost`.
- `lego/operator/cmd/activator/main.go:318-332` — `findAppByHost` does `c.List(ctx, &list)` (cluster-wide, no selector) then linear `appHosts(app)` scan; no cache, no coalescing, no rate limit.
- `lego/operator/config/activator/role.yaml` — cluster-scoped list/watch; `deployment.yaml` — single replica, no resources.

## Steps

1. Feed an in-memory host→App index from a `Watch`/informer (the role already grants watch); refresh on add/update/delete.
2. `findAppByHost` reads the index (O(1)) instead of List+scan.
3. Add bounded concurrency / an IP rate-limit on the public handler so an unknown-host flood is cheap.

## Files

- `lego/operator/cmd/activator/main.go`
- `lego/operator/config/activator/deployment.yaml` (resources if needed).

## Acceptance criteria

- [ ] Steady-state requests do not trigger a kube `List`.
- [ ] An unknown-host flood is bounded (429/backpressure), not amplified into apiserver load.
