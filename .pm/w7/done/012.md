# w7/012 — No completeness guard for directly-mounted (outside-gate) routes

**Source:** w7/m57 audit (ADR045 Finding 8), 2026-07-30. **Severity:** low.

`TestCrossWorkspaceRESTMatrix` (`lego/backend/internal/api/crossworkspace_rest_test.go`) auto-enumerates only routes registered via feature `RegisterREST(mux)`. The directly-mounted public routes in `server.go`'s `Handler()` (`/v1/webhooks/stripe`, `/v1/webhooks/git`, `/v1/deploy-hooks/…`, device-flow) are outside that sweep and each rely on a bespoke `*BypassesAuthGate` test; the always-public inventory in `internal/api/CLAUDE.md` is a doc convention, not CI-enforced. A future directly-mounted public route would trip no completeness guard.

**Fix when picked up:** add a completeness test that enumerates `server.go`'s composed `Handler()` mux and forces every non-`/v1/`-wildcard mount to be a documented always-public entry — mirroring the feature-route completeness guard w7/m55 added.
