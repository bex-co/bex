## Objective

Periodically reconcile active/grace/enforced workspaces against authoritative Stripe Subscription and invoice state so missed webhooks cannot strand billing state.

## Context

- ADR040 explicitly lists a polling backstop as residual work.
- Polling must be bounded, cached, rate-limit aware, and inactive when Stripe is disabled.

## Steps

1. Select only workspaces whose billing state needs convergence.
2. Read authoritative Stripe state with bounded concurrency, retry/backoff, and metrics.
3. Feed differences through the same normalized transition path as webhooks.

## Files

- `lego/backend/internal/billing/reconciler.go`
- `lego/backend/cmd/api/main.go`
- `lego/backend/internal/store/`

## Acceptance criteria

- [x] A deliberately dropped webhook is repaired by polling.
- [x] Polling does no Stripe traffic when billing is disabled.
- [x] Rate limits/outages degrade with metrics and retry rather than request-path failures.

## Out of scope

- Replacing webhooks with polling.
