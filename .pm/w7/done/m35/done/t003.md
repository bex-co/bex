## Objective

Prove the guard: a test battery that a webhook (and the activator fetch) targeting each dangerous class is blocked, and a public destination still delivers.

## Context

- Cases: `http://169.254.169.254/latest/meta-data/` (cloud metadata), `http://10.0.0.5/`, `http://192.168.1.1/`, `http://127.0.0.1/`, `http://[::1]/`, a hostname that DNS-resolves to a private IP (rebind), and a public URL that 302-redirects to a private one (must not follow). Positive control: a public test server delivers.
- Test the guard at the helper level (fast, hermetic) AND at the worker level (the delivery path actually refuses).

## Acceptance criteria

- [x] Every dangerous class blocked at both levels; public delivery + non-followed-redirect asserted; suite green.

## Out of scope

- Load/timing tests.
