## Objective

Add the transactional-outbox column that lets the emitter (t005) track which sealed rows have shipped to Metronome, exactly-once, without a separate table. The emitter selects `emitted_at IS NULL` sealed rows and stamps `emitted_at` after a successful ingest.

## Context

- `docs/ADR040-billing-metronome.md` §4 (outbox via `emitted_at`).
- Migrations dir: `lego/backend/internal/store/migrations/` — latest is `0022`; add the next number.
- `usage_hourly` PK: `(resource_kind, service_id, kind, tier, window_start)` — must not change. Read paths (`GET /v1/usage`, GraphQL, MCP) must be untouched.
- Column is nullable so existing rows read as "not yet emitted"; the epoch floor (t005) prevents the emitter from trying to ship all historical rows.

## Steps

1. Add `NNNN_usage_emitted_at.up.sql` / `.down.sql`: `ALTER TABLE usage_hourly ADD COLUMN emitted_at timestamptz;` (down: drop column).
2. Confirm the migration is picked up by the store's embedded-migration loader.
3. Verify no existing query selects `*` in a way that breaks (add the column explicitly only where the emitter needs it).
