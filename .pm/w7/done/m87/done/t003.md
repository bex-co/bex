## Objective

Thread the environment revision into native BuildKit execution so a changed effective environment reruns the relevant build step while unchanged inputs retain cache reuse.

## Context

- The operator currently passes RuntimeEnvSecret, BuildEnv, and BuildCache into build.Options; nativeDockerfile's secret-consuming RUN has no cache invalidator.
- w7/m86 keeps output-registry credentials outside the tenant-executing BuildKit container and treats cache transport as best-effort.

## Steps

1. Pass the revision through the existing native build options and preparer into a non-secret cache-key input consumed by the environment-dependent instruction.
2. Keep the native command and byte-preserving decoder intact, including static-site extract images and all supported native toolchains.
3. Check that cache-disabled jobs, Dockerfile/kpack behavior, release selection, and the existing credential boundary retain their documented contracts.
