## Objective

Make convergence a standing invariant rather than a one-time fix, so the next projection change cannot silently reintroduce the loop.

## Context

- This is the durable half of the milestone. `w9/m57` fixed the Service instance in July and the Deployment instance survived until 2026-08-17 precisely because nothing generalized the check.
- The invariant should be a shared helper applied to every owning controller, not a copy-pasted assertion per controller — the copy-paste version rots the same way.
- Exemptions from t003 must be **explicit and enumerated** in the invariant, so an exemption is a visible decision rather than a silent gap.
- `w7`'s guard precedents: `m7`/`m30` CI structural guards, `m58`'s universal fail-closed guard with a single-sourced helper, `m60`'s completeness census with anti-tautology self-tests in both directions.

## Steps

1. Extract the two-reconcile assertion into a shared test helper covering every owning controller.
2. Enumerate t003's exemptions explicitly in one place.
3. Add an anti-tautology self-test: reintroduce a known churn (e.g. drop `SuccessThreshold` again) and prove the invariant turns red.
4. Make sure it runs in the CI-enforced `make test` path.

## Files

- `lego/operator/internal/controller/` shared test helper + envtests

- [x] One helper covers App, Database and KeyValue owners.

## Result

`reconcile_convergence_envtest_test.go` holds one `divergence()` helper used by all three
owners. It settles the reconciler, snapshots every owned object it can find, runs one more
pass, and returns **both** halves of the definition of done: every write the pass issued
(via a `writeRecorder` client wrapper) and every owned object whose `resourceVersion`
moved.

The oracle is the client, not `resourceVersion` — deliberately. t001 measured that a
redundant PUT leaves `resourceVersion` untouched, because the API server re-defaults the
incoming object and skips the etcd write, so an RV-only assertion would have passed
against the very bug this file exists to catch. Counting requests is the
`OperationResultNone` the DoD asks for; the RV snapshot rides along as the independent
second half.

Shapes covered, each asserting the kinds it must own so a shape that silently stops
producing an object cannot pass vacuously: App web (HTTP probes), App TCP-probe, App
routed (Ingress + all three Traefik middlewares + a projected secret-files volume), App
worker, App cron; KeyValue with and without backups (the backup CronJob); Database (CNPG
Cluster).

**Anti-tautology, both directions.** `turns red when a projection stops writing the server
defaults` re-runs the reconciler's own Deployment `CreateOrUpdate` with the pre-w7/m84
projection — six times, dropping one default family each time — and proves the recorder
sees the PUT every time. The kind-coverage assertion was likewise checked by demanding a
kind the shape does not own and watching it fail.
