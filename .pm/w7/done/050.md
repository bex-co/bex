## Journey 9 — static site, create → serve → redirect rule

Fixture: `qa-20260915-927d1b-static` (`srv-dakuoeob3bfc73eq7vng`), static site from the public repo, root `examples/static-site`, publish dir `.`, auto-deploy off.

- Created and **Live at `rev-1` inside 75 seconds**; `https://qa-20260915-927d1b-static.onbex.co/` served the example's `index.html` (200, 1548 B).
- Bare `/static/<id>` lands on **Events**, not Deploys as web services do — deliberate, `static.$serviceId.index.tsx:4-8` records it as Render parity (`w5/m57`), shared with the `/services` resolver. Not a defect.
- All eight static tabs (index, deploys, env, events, metrics, redirects, headers, settings) render with no console errors and no 4xx/5xx.
- A redirect/rewrite rule saved from the UI: `setStaticRoutes` → `200 {routes:[{source:"/qa-old",destination:"/qa-new",type:"rewrite"}]}`.
- **Wire check was inconclusive by construction and is not evidence either way:** every extensionless path (`/qa-old`, `/qa-new`, `/definitely-missing-qa`, `/`) returns the same 200 index payload, which is ADR018's **accepted** extensionless-miss divergence that `w4/094` already verified live with a proper control. A discriminating check needs extensioned paths; `w4/093` proved rules take effect on the wire on 2026-09-14, so this run adds nothing there.
- **One observation raised and then settled (2026-09-15, fourth sweep).** During this sweep, extensioned paths (`/index.html`, `/qa-old.html`, `/missing-qa.html`) each answered `404` — but those probes raced this run's own deletion of the fixture, so they proved nothing. Re-run against a second, still-live static fixture (`qa-20260915-46a941-st2`, `srv-dakv5mgdp28s73ek2gl0`), the behavior is correct and there is no defect:

  ```text
  /              200  1548B  text/html
  /index.html    200  1548B  text/html   (byte-identical to /)
  /missing.html  404    10B
  ```

  So the static server serves a real file by its exact path, 404s a missing extensioned path, and only the extensionless miss falls back to the index — exactly ADR018's accepted divergence.

## The canary's root cause, found by falsifying my own note (thirty-second sweep)
