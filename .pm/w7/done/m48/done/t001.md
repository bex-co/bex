## Objective

Bind each billable customer to the rate card so Metronome actually rates their exported usage into invoices. A customer without a contract has usage but no priced invoice; this task creates the contract that starts billing.

## Context

- `docs/ADR040-billing-metronome.md` §2, §7 (per-workspace charging = a Metronome contract, not a bex env gate).
- Builds on m47/t004 (customers exist) + m47/t001 (rate card exists).
- `POST /v1/contracts/create` binds `customer_id` → rate card + billing period; `start = billing start` (usage before start is not rated).
- Comped tenants (ADR040 §7): Mode A skips the contract entirely (`billing_excluded`); Mode B creates the contract then attaches a 100% credit / non-collectible flag.

## Steps

1. Add contract provisioning to the billing package: ensure a contract per non-excluded customer (idempotent), start = configurable billing start.
2. Support the comped path (Mode B): 100% discount / credit application + non-collectible marking as a distinct call.
3. Persist/track contract identity so it is not re-created each cycle.
4. Unit-test idempotency + the comped path.
