## Objective

Add production Prometheus alert rules and operator annotations for billing conditions that require action before invoices become unreliable.

## Context

- Stamp ambiguity older than Stripe's identifier window must stop blind retries.
- Alerts must distinguish a disabled test sandbox from an unhealthy enabled sandbox.

## Steps

1. Add warning/critical rules for backlog age, permanent 4xx, stamp ambiguity, duplicates, invoice-read degradation, and webhook/signature drift.
2. Link each alert to one concrete runbook action.
3. Validate rules with promtool and synthetic metric fixtures.
