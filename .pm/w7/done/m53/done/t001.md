## Objective

Build a repeatable reconciliation harness that accounts for selected `usage_hourly` rows from local outbox state through Stripe test-mode meter aggregation and rated invoice lines.

## Context

- ADR040 acknowledges bounded identifier deduplication rather than strict cross-system exactly-once delivery.
- Reconciliation must compare normalized units for per-tier instance seconds, GiB egress, build seconds, and GB-hours storage.

## Steps

1. Query a bounded workspace/period from Postgres without exposing credentials.
2. Read the corresponding Stripe meter summaries and invoice line quantities/amounts.
3. Report exact matches, expected rounding, missing rows, duplicates, and ambiguous old retries with a failing exit status.

## Files

- `scripts/stripe-billing-reconcile.sh`
- `lego/backend/internal/billing/`
- `docs/runbooks/stripe-billing-setup.md`

## Acceptance criteria

- [x] The harness reports every paid dimension and unit conversion separately.
- [x] Mismatch/ambiguity produces a clear non-zero result without blind replay.
- [x] It refuses live keys by default and never prints secret values.

## Out of scope

- Automatic financial adjustments.
