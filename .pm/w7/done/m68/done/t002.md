## Objective

The KeyValue reconciler owns a nightly backup CronJob per paid-plan instance: trigger `BGSAVE`, wait for completion, upload the RDB gzip'd to `s3://…/keyvalue/<id>/<RFC3339-utc>.rdb.gz`, prune to the 7 most recent.

## Context

- Reconciler: `lego/operator/internal/controller/keyvalue_controller.go` (StatefulSet + Secrets + Services already owned there; ADR021).
- Snapshot correctness: `BGSAVE` via `valkey-cli` (auth from the instance's `<id>-auth` Secret), then poll `LASTSAVE` until it advances before copying `dump.rdb` — never copy a mid-write file. Copy path: exec into the pod or mount-free `--rdb` remote dump (`valkey-cli --rdb`) from the Job pod — prefer `--rdb` (no shared volume, no exec RBAC).
- Naming: RFC3339 UTC timestamps (lexicographic = chronological); prune keeps last 7 — the Job does its own pruning like the etcd/OpenBao backup CronJobs (`deploy/gitops/` patterns, ADR011/ADR015).
- Plan gating: paid plans only (`spec.plan` != free tier; plan set at `lego/types/v1alpha1/keyvalue_types.go:55`); Free stays PVC-only.
- Schedule: stagger from the platform backups (etcd 03:15, OpenBao 03:45, bex-db 04:00) — e.g. 03:30 + per-instance jitter/offset so N instances don't thundering-herd.

## Steps

1. Reconcile the CronJob (owned, deterministic name e.g. `kvbak-<id>`) when the env contract is set AND the plan qualifies; delete it when either stops holding.
2. Job spec: valkey-cli BGSAVE/LASTSAVE (or `--rdb`) → gzip → S3 upload → prune; credentials from `BEX_KV_BACKUP_S3_SECRET`; resource limits + securityContext per the platform-pod hardening baseline (w7/m58).
3. Verify live on a paid dev instance: snapshot lands, prune works at 8th run (can force with a tight test schedule).

## Files

- `lego/operator/internal/controller/keyvalue_controller.go`
- `lego/operator/config/rbac/` (CronJob create/own if not already granted)

## Acceptance criteria

- [x] Paid instance ⇒ CronJob exists; Free ⇒ none; env unset ⇒ none anywhere.
- [x] A run produces a valid loadable RDB in the bucket under `keyvalue/<id>/`; 8th snapshot prunes to 7.
- [x] Snapshot taken via BGSAVE/LASTSAVE (or `--rdb`) — no raw copy of a live `dump.rdb` without the save barrier.
