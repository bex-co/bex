## Objective

The standing coverage task. The milestone's value is entirely in defaults, so the tests must pin *values and consequences*, not merely that probes exist. Assert real failure modes: the shapes that were broken before must be shapes a regression would trip on.

## Context

Each definition-of-done item needs a test that would have failed before m80:

1. **404 root deploys** — unset path yields `TCPSocket`, so a service whose root is not 2xx/3xx becomes Ready. This is the case that was impossible before.
2. **No flapping** — every probe carries `TimeoutSeconds: 5`.
3. **Slow boot survives** — `startupProbe` budget = 15 min, and it equals `progressDeadlineSeconds` and `DeployGateTimeout`. Assert the equality, not three separate literals; a test that hardcodes `900` three times would pass while the timers drift.
4. **Explicit stays strict** — a set path still yields HTTP requiring 2xx/3xx.

## Steps

1. Add the operator-side cases (envtest/unit in `app_controller_test.go` and the projection tests).
2. Add the backend-side case pinning `DeployGateTimeout`.
3. Add the cross-module agreement check for the three timers — if a single shared constant is impossible across modules, assert it in whichever module can see both and say so in a comment.
4. Confirm the worker/cron no-probe invariant is still covered.
5. Avoid tautologies: no test should assert a constant against itself.
