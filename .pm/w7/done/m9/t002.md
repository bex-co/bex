## Objective

## Context

- `lego/backend/internal/postgres/` and the KeyValue equivalent — their create handlers.
- Count the workspace's *current* resources (not a separate counter table — query existing store/CR state) against t001's cap for its plan.

## Steps

1. Add a cap check before each create path commits, counting the workspace's current resources of that kind.
2. Return a clean 4xx (403 or 429, pick consistent with existing error-shape conventions) with a message indicating the limit and current count.
3. Apply to services, Postgres, and KeyValue creates.
