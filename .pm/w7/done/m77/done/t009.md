### Outcome (2026-08-08)

**Naming.** `AppNamespace` always computed "the workspace's hosting namespace", not something App-specific, so it is now `TenantNamespace` with `AppNamespace` kept as a one-line alias — App call sites still read naturally, and no diff noise was spent renaming dozens of unrelated lines.

**Extracted.** The credential projection was written twice (Database → ObjectStore consumer, KeyValue → CronJob consumer) with identical bodies; it is now one `projectBackupCredential` free function taking a client, which both reconcilers call. Real duplication, cleanly removable.

**Deliberately left alone.** `findDatabase`/`findKeyValue` are near-identical ~25-line siblings. Collapsing them needs either Go generics over `client.Object`+`client.ObjectList` (two type parameters with pointer constraints) or an interface with extraction callbacks — both harder to read than the pair, for no behavioral gain. This also matches the house pattern the file already sets: `AuthorizeDatabase`/`AuthorizeKeyValue` are the same shape and the code calls them "siblings" on purpose. Likewise `secretClient()` on the two reconcilers stays duplicated at 5 lines each, mirroring `AppReconciler.buildPlaneClient`.

One prealloc lint hit in a test I wrote was fixed at the source.
