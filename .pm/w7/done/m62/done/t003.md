## Objective

Investigate-first (the `009`→m55 branch pattern): the static-site publish Job's extract initContainer pulls the just-built tenant image with the wildcard-read `bex-registry-pull` (`bex-builder`) credential. Determine whether the per-App repo-scoped `reg-pull-<name>` mirror (w7/m36 machinery, mirrored into `BEX_BUILD_NAMESPACE` for the push/sign phases under `BEX_REGISTRY_NS`) is still present/reachable when the publish Job runs; if yes, switch the extract initContainer's `imagePullSecret` to it (wildcard fallback unchanged for dev/`BEX_REGISTRY_NS`-unset); if no (e.g. the mirror is cleaned up post-build), record an evidence-backed disposition on ADR045 Finding 7 with the revisit trigger.
