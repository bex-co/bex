## Objective

Add tests for the behavior this milestone shipped where t002–t005 left gaps. They must assert real behavior and failure modes.

## Steps

1. Cover the OR of the org and workspace settings as a table: each of the four combinations, for both requirements, on a workspace in an org and a standalone one.
2. Cover the failure modes: the store read failing (fail closed, `ErrAuthzUnavailable`), an org deleted by a downgrade while a requirement is on (the workspaces fall back to their own settings), a workspace moved into an enforcing org by the support transfer, and a Guest in an enforcing org.
3. Prove each new regression test is real: revert the behavior it guards and watch it fail.

## Acceptance criteria

- [x] The new tests fail without the behavior they guard, and `cd lego/backend && go test ./...` and `dashboard/yarn test` pass.
