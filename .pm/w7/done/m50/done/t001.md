## Objective

Document and automate the Stripe-side meters, prices, comp coupon, webhook, and least-privilege runtime key required by the direct Billing integration.

## Context

- `internal/pricing/pricing.yaml` remains the rate source of truth.
- Runtime credentials must be restricted keys stored out of band; setup credentials are separate.
- Webhook requests must be signature-verified before any event is processed.

## Steps

1. Make `scripts/stripe-billing-setup.py` idempotently provision the complete catalog and comp coupon.
2. Add a runbook with test/live separation, restricted-key permissions, webhook creation, verification, and rollback.
3. Ensure no credential value is written to git or logs.

## Files

- `scripts/stripe-billing-setup.py`
- `docs/runbooks/stripe-billing-setup.md`

## Acceptance criteria

- [ ] Re-running the setup script creates no duplicate active meters, prices, products, or coupons.
- [ ] The runbook lists the minimum runtime key permissions and webhook-signing-secret custody.
- [ ] Test mode is the documented default before live activation.

## Out of scope

- Automated tax registration or payment-method collection UX.
