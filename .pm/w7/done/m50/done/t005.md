## Objective

Create one idempotent multi-item metered Stripe Subscription per billable workspace and implement Mode B comping with a perpetual 100%-off coupon.

## Context

- Mode A remains `billing_excluded` and never reaches customer/subscription provisioning.
- Every active price lookup key generated by the setup script must be attached exactly once.
- Subscription creation and comp application must tolerate process restarts.

## Steps

1. Resolve all required price lookup keys and validate the complete catalog.
2. List-before-create subscriptions tagged with the workspace metadata.
3. Apply the configured comp coupon idempotently.

## Files

- `lego/backend/internal/billing/contracts.go`
- `lego/backend/internal/billing/stripe_test.go`

## Acceptance criteria

- [ ] Existing subscriptions are reused after restart.
- [ ] Missing/duplicate price lookup keys fail before creating a partial contract.
- [ ] Reapplying a comp leaves one effective 100%-off discount.

## Out of scope

- Customer self-service Checkout or Portal UX.
