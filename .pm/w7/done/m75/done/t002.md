## Objective

Stop new sandbox nodes from installing the gVisor security boundary (`runsc` + containerd shim) from the mutable `release/latest` URL as root with no integrity check (codex-security #18, low).

## Context

- `infra/clusterapi/overlays/hetzner-caph/sandbox-pool.yaml:196/206-208/225` — `GVURL="https://storage.googleapis.com/gvisor/releases/release/latest/${ARCH}"`; `wget` runsc + shim, `cp` to `/usr/local/bin`, register runtime, restart containerd; runs as root in `preKubeadmCommands`.

## Steps

1. Pin to a concrete gVisor release (e.g. `release-20260801.0`).
2. Fetch the published SHA256 checksums file and verify each binary before `cp`/`chmod`.

## Files

- `infra/clusterapi/overlays/hetzner-caph/sandbox-pool.yaml`

## Acceptance criteria

- [ ] `release/latest` replaced with a pinned release; binaries checksum-verified before install.

## Out of scope
