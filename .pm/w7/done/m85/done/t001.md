## Objective

Pin the one user-facing image in the tree that is still built from a floating tag.

## Context

- `dashboard/Dockerfile:2` (`FROM node:22-alpine AS builder`) and `:45` (`FROM node:22-alpine`) are both unpinned. `lego/Dockerfile` pinned both of its FROMs long ago (`golang:1.25@sha256:…`, `gcr.io/distroless/static:nonroot@sha256:…`), so this is the outlier.
- The dashboard is the SSR image users actually reach, which makes it the highest-value single line in this milestone.
- Pin format used elsewhere in the repo: `name:tag@sha256:…` — keep the human-readable tag **and** the digest, so a reader can see the version without resolving the hash.
- Resolve the digest for the multi-arch manifest, not one platform's image, or arm64 developer builds break against an amd64-only pin.

## Steps

1. Resolve the current `node:22-alpine` multi-arch manifest digest.
2. Pin both FROMs as `node:22-alpine@sha256:…`.
3. Verify the dashboard image still builds on both architectures the repo cares about.

## Files

- `dashboard/Dockerfile`

## Acceptance criteria

- [x] Both FROMs carry a digest alongside the readable tag.
- [x] The digest is the multi-arch manifest digest, not a single-platform one.
- [x] The dashboard image builds unchanged.

## Out of scope

- Upgrading the Node major version — pin what is running, do not bundle an upgrade.

## Outcome (2026-08-21)

**Already closed before this milestone ran** — `dashboard/Dockerfile`'s two FROMs were pinned to `node:22-alpine@sha256:c610fcdf…` by commit `9081fbdb` ("fix(security): close repository audit findings"). Verified rather than assumed: that digest is what `node:22-alpine` resolves to as the multi-arch manifest today, and `scripts/image-pin-validate.sh --verify-digests` confirms the registry serves it. No dashboard change was needed, so the "builds unchanged" criterion is trivially met — the file was not touched.

The lasting work is that `scripts/image-pin-validate.sh` now covers every tracked Dockerfile's `FROM` and `--from=`, so this cannot silently regress (t005).
