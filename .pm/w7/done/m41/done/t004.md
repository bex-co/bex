## Objective

Add Included/Ignored Paths (Build Filters) to the Advanced section of the
static site create wizard, matching Render's create form which shows them there.
Currently the create wizard has no build filter UI for any service type; this
adds it specifically for static sites.

## Context

- `dashboard/src/routes/services.new.tsx`
  - No `buildFilter` state or UI anywhere in the create wizard
  - The Advanced accordion (around lines 1166–1188) contains Auto-Deploy + Env Vars + Secret Files
  - After t002: `createService` GraphQL mutation accepts `buildFilter: {paths, ignoredPaths}` and `use-create-service.ts` threads it through
- `dashboard/src/features/services/components/build-deploy-section.tsx` lines 479–546: the `BuildFilterEditor` subcomponent (post-create, stateful `setBuildFilter`) — its path-list UI (glob inputs, add/remove buttons) is the model; the create-wizard version is stateless (controlled by parent state, no mutation)
- Render's Advanced section for static sites shows: **Build Filters** (Included Paths + Ignored Paths text inputs) → **Auto-Deploy** → env vars

## Steps

1. Add state to the create wizard:
   ```ts
   const [buildFilterPaths, setBuildFilterPaths] = useState<string[]>([]);
   const [buildFilterIgnored, setBuildFilterIgnored] = useState<string[]>([]);
   ```
2. Add a reusable (or inline) glob-list editor in the Advanced section for `isStaticType && isGitSource` — two `GlobListInput` editors (Included Paths, Ignored Paths) following the same add/remove chip pattern used by `BuildFilterEditor`. Keep it as a controlled component; no mutation (filters are submitted with the create payload).
3. Add locale keys `services.buildFilterCreateLabel`, `services.buildFilterCreateHint` (or reuse existing `services.buildFilterLabel`/`services.buildFilterHint` keys from `build-deploy-section.tsx` if they fit the create context).
4. Thread the value into the create payload in `handleSubmit`:
   ```ts
   buildFilter: isGitSource && isStaticType && (buildFilterPaths.length || buildFilterIgnored.length)
     ? { paths: buildFilterPaths, ignoredPaths: buildFilterIgnored }
     : undefined
   ```
5. Wire `use-create-service.ts` to accept and forward `buildFilter` (t002 adds it to the mutation; this task adds it to the hook's input type and the variables call).

## Acceptance criteria

- [ ] When creating a `static_site` from git, the Advanced section shows "Build Filters" with Included Paths and Ignored Paths glob editors (add/remove entries)
- [ ] Submitting with filters configured sends `buildFilter: {paths, ignoredPaths}` in the `createService` payload
- [ ] A subsequent `server { buildFilter }` query for the new service returns the configured values
- [ ] Submitting with no filters configured sends no `buildFilter` (field absent)
