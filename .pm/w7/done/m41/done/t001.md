## Objective

Remove the `!isStaticType` guard that hides the build command input for static
sites and fix the create payload so the user-entered value is sent.

## Context

- `dashboard/src/routes/services.new.tsx`
  - Line 460: `const [buildCommand, setBuildCommand] = useState(RUNTIME_COMMANDS.node.build);` — state already exists
  - Line 939: `{!isStaticType ? (<> runtime picker, build command, start command sections </>) : null}` — entire block hidden for static sites
  - Lines 618–621: `buildCommand: isGitSource && !isStaticType && runtime !== "docker" ? buildCommand.trim() : undefined` — payload drops it for static sites
- Static sites do not need the runtime picker or start command, but DO need a build command (e.g., `npm run build` to produce the publishPath directory)
- Render's create form shows Build Command as a standalone labeled input above Publish Directory, not bundled with the runtime/start-command block

## Steps

1. Add a separate `buildCommand` state for static sites (or reuse the existing one with a different initial value — `""` makes sense for static, not `RUNTIME_COMMANDS.node.build`).
2. For `isStaticType && isGitSource`, render a standalone Build Command `<Input>` field (labeled `t("services.buildCommandLabel")`), placed immediately above the Publish Directory input (lines 1121–1139).
3. Fix the payload: change lines 618–621 so `buildCommand` is sent for static sites too — `isGitSource ? buildCommand.trim() || undefined : undefined` (omit only when empty, not when static).
4. Add locale keys `services.buildCommandLabel`, `services.buildCommandHint` to `src/features/services/locales/{en,zh}.ts`.
5. Guard: only show the field when `isGitSource` (image-backed static sites have no build step).

- [ ] Creating a `static_site` from a git repo shows a "Build Command" input above "Publish Directory"
- [ ] Submitting the form with a build command sends it in the GraphQL `createService` call (`buildCommand` variable)
- [ ] Submitting with an empty build command sends `undefined` (no field), not an empty string
- [ ] Image-backed static sites see no build command field
- [ ] Runtime picker, start command, and Docker-specific fields remain hidden for static sites
