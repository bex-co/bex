## Objective

On App deletion, delete the app's image repository contents from the in-cluster Zot registry (OCI distribution API: list tags → delete manifests) so tenant images don't accumulate forever, and make sure Zot's garbage collection actually reclaims the blobs.

## Context

- `lego/operator/internal/build/build.go` — derive the app's repo name exactly as the build push does (from `BEX_REGISTRY`/`BEX_KPACK_REGISTRY` + app identity); the teardown must compute the same repo.
- Zot supports `DELETE /v2/<repo>/manifests/<digest>` when `allowDelete` is on; blob reclamation needs GC enabled in Zot's config — check/extend `deploy/gitops/` zot config (registry deployment) for `gc: true` + delete permissions.
- Authn: Zot denies anonymous ops when registry auth is on (w7/m8); reuse the push credential (`BEX_REGISTRY_PUSH_SECRET` docker-config) for the delete calls, and handle the unauthenticated dev default too.
- Registers as a teardown func in the t002 finalizer hook; idempotent (repo/tag already gone ⇒ success), and registry-unreachable should requeue, not silently drop.
- Only relevant for repo-built Apps (prebuilt `image:` Apps push nothing — skip).

## Steps

1. Small Zot client in the operator (list tags, resolve digest, delete manifest) honoring the push secret.
2. Register as a t002 teardown func for Apps that ever built (has build status/revision evidence).
3. Enable/verify `allowDelete` + GC in the gitops Zot config.
4. Test with a fake registry HTTP server: tags listed, manifests deleted, 404 tolerated.

## Files

- `lego/operator/internal/build/` (zot client + teardown func)
- `lego/operator/internal/controller/app_controller.go` (registration)
- `deploy/gitops/` (zot config: delete + gc)

## Acceptance criteria

- [ ] After deleting a repo-built App, `GET /v2/<repo>/tags/list` on Zot returns no tags (or 404).
- [ ] Works authenticated (push secret set) and unauthenticated (dev default); prebuilt-image Apps skip cleanly.
- [ ] Zot GC is enabled so deleted manifests' blobs are reclaimed.

## Out of scope

- Registry-wide orphan sweeps for Apps deleted before this shipped (one-shot manual cleanup, note in docs if needed).
