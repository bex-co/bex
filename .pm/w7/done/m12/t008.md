## Objective

Prove "delete really deletes" end-to-end on the mock cluster with a repeatable audit script: create the full spread of resources, delete each via its public verb, and assert zero leftovers of every artifact class this milestone closed.

## Context

- Mock cluster: `bash scripts/mock-cluster.sh` (see memory note on CAPD quirks); off-cluster harness pattern: `scripts/secrets-verify.sh` (host bex-api + operator, OpenBao SA-token auth) — reuse its scaffolding.

- Leftover checks after each delete: build ns Jobs/kpack Images, Zot `/v2/<repo>/tags/list`, static bucket `<appID>/` prefix, OpenBao env-var path, `<app>-env` + TLS Secrets, PVCs, CNPG backup disposition per t007's decision, CR gone, REST GET returns 404.
