## Objective

Build the reusable core of the matrix: a two-workspace fixture (caller is a member of workspace A; the target resource is owned by workspace B) plus a reflection-based sweep over every service verb that asserts the non-member caller is denied. Unlike the existing deny-all sweep, the checker must be **allow-own / deny-other** — it grants every relation on workspace A's objects and denies workspace B's — so a verb that authorizes the wrong workspace's object (confused deputy) fails the test instead of passing it.

## Context

- `lego/backend/internal/api/server_test.go:1012` — `TestAuthzGuardsEveryVerb`, the existing reflection sweep; reuse its verb-enumeration mechanics but replace the deny-all checker.
- `lego/backend/internal/api/relationguard_test.go:133` — `TestFetchByNameUsesTheVerbsOwnRelation`, the relation-consistency guard; a sibling pattern, not a replacement.
- Authorization seams: `core.Base.Authorize`, `AuthorizeApp`/`AuthorizeDatabase`/`AuthorizeKeyValue`, `AuthorizeOn`/`AuthorizeOnTarget` (`lego/backend/internal/core/`).
- The checker fake must distinguish objects by owning workspace, so fixtures need resources (App/Database/KeyValue/project/env-group/…) stamped with workspace B ownership while the caller identity resolves to workspace A.

## Steps

1. Build the two-workspace fixture: identities, workspace A membership, and one owned resource per resource kind in workspace B.
2. Implement the allow-own/deny-other authz fake keyed on the FGA object id's workspace.
3. Write the reflection sweep: every service verb invoked as the workspace-A caller against the workspace-B resource must return `ErrForbidden`/not-found — never success.
4. Add a completeness guard: the sweep enumerates verbs mechanically (as `TestAuthzGuardsEveryVerb` does) so a new verb is swept automatically; document any principled exclusions in-test.

## Acceptance criteria

- [ ] Every enumerated service verb denies the workspace-A caller access to the workspace-B resource.
- [ ] A verb hand-modified to authorize the caller's own workspace object (instead of the target's) fails the sweep — verified once locally, then reverted.
- [ ] The sweep's verb list is derived mechanically, not hand-maintained.
