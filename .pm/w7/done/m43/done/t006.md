## Objective

Add meaningful tests for the behavior this milestone shipped: the Scaling
page's mutual-exclusion composition, the Manual Scaling card's draft/save
mechanics, the Recent Metrics section's data/empty states, and the
Settings-page stepper removal.

## Context

- Existing patterns: `dashboard/src/routes/__tests__/services.$serviceId.settings.test.tsx`
  (section presence by service type, hooks mocked),
  `dashboard/src/features/services/components/__tests__/` (component suites).
- `useScaleService`, `useAutoscaling`, and the metrics query hook are the
  Apollo clients to mock.

## Steps

1. **Scaling page composition test** (new `services.$serviceId.scaling.test.tsx`
   or extend an existing route suite): autoscaling off ⇒ Manual Scaling card
   present; autoscaling on ⇒ hidden; Recent Metrics present in both; cron/
   static ⇒ no manual card.
2. **Manual Scaling card test**: draft change enables Save; Save calls
   `scaleService(id, n)`; Save disabled when draft equals live count; input
   clamped to 1–100.
3. **Recent Metrics test**: renders the three blocks from mocked series;
   empty series ⇒ "No data captured…" state; "View all metrics" link targets
   the Metrics tab.
4. **Settings test update**: assert the Instance count stepper is gone from
   the Settings page (update the existing w5/m16 assertions).
5. **Autoscaling card test updates** (t003): slider max 100, default 60,
   disable messaging.
6. `yarn test` (dashboard) green.
