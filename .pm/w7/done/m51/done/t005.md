## Objective

Create short-lived Customer Portal sessions for an authorized workspace admin to manage test payment methods and inspect Stripe-hosted invoices.

## Context

- Portal configuration is an operator-owned Stripe object; runtime only creates sessions for the resolved Customer.
- The return URL must be constrained to the trusted dashboard origin.

## Steps

1. Add the narrow Stripe Portal session client call and required restricted-key permission.
2. Resolve the Customer from workspace identity and validate the return origin.
3. Document the test-mode Portal configuration and disabled-state behavior.

## Files

- `lego/backend/internal/billing/sessions.go`
- `docs/runbooks/stripe-billing-setup.md`
- `scripts/stripe-billing-secret.sh`

## Acceptance criteria

- [ ] A workspace admin receives a Portal URL for only that workspace's Customer.
- [ ] Untrusted return URLs and missing Customers fail closed.
- [ ] The runtime key retains only the additional minimum Portal permission.

## Out of scope

- A custom payment-method or invoice-management UI.
