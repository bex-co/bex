## Objective

Move the direct Stripe integration to the current supported Stripe SDK and API contract before adding Checkout and Portal calls, keeping the test webhook endpoint version aligned with stripe-go.

## Context

- `lego/backend/go.mod` currently carries stripe-go v82 and ADR040 pins the older webhook API version.
- Checkout sessions created on the current API must carry a randomized `integration_identifier`; the upgrade must preserve meter, invoice, and webhook behavior.

## Steps

1. Upgrade stripe-go and resolve compile-time API changes in `internal/billing`.
2. Update the setup/runbook webhook version and recreate or update the test endpoint deliberately.
3. Re-run the existing real sandbox smoke with the dedicated `rk_test_*` key.
