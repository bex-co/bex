## Objective

Stop App finalization from deleting arbitrary named Secrets in `bex-build`. `reclaimAppExecution` builds `knownBuildSecretNames` from App-controlled fields and calls `deleteAndWait` on each name in the build namespace without reading or validating the target's ownership labels — so creating an App with a victim Secret's name and deleting it removes another tenant's/platform's credential (codex-security #5, medium).

## Context

- `lego/operator/internal/controller/app_controller.go` `reclaimAppExecution` (~:3060/:3131-3137) iterates `knownBuildSecretNames(app)` (~:3244, built from `CloneSecret`/`ExternalRegistryPullSecret`/`EnvFromSecrets`/`FilesFromSecrets`) and `deleteAndWait`s each in the build ns.
- `ReclaimAppArtifacts` filters by App UID — mirror that pattern here: Get the target, verify ownership labels, skip+log on mismatch.

## Steps

1. Before each `deleteAndWait`, `Get` the target Secret and verify its ownership labels match the App being deleted (`labelApp == app.Name` + workspace).
2. Skip + structured-log on mismatch (do not delete foreign/platform Secrets).
3. Tolerate NotFound (already gone) as today.

## Acceptance criteria

- [ ] A non-owned same-named Secret survives an App's finalizer.
- [ ] Only Secrets owned by the deleted App are removed.
