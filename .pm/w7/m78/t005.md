## Objective

Pin the invariant so this class cannot come back: a web service that reaches the Deployment apply ends with routing, or with an explicit named failure — never silently unroutable.

## Context

- The operator has envtest coverage (`make test` from `lego/operator/`, `suite_test.go` and the `*_envtest_test.go` files) — the right level for a reconcile-ordering invariant.
- A test that only covers the one branch t001 found would miss the next reordering. Prefer an invariant over the specific instance, in the spirit of the existing structural-guard tests (`rbac_test.go`, `hardening_test.go`).

## Steps

1. Add a regression test for the specific t001 branch, failing against pre-fix code.
2. Add the invariant test: inject a failure at each best-effort step and assert routing still converges.
3. Assert the negative too — a genuinely blocking failure must still block, and must still be visible.
4. Confirm each test fails for its own reason.
