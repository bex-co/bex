## Objective

Consolidate the per-plane and cross-cutting findings into a single ADR028-format security-review register in `docs/`, with the frozen scope map, one severity + evidence + disposition per finding, and a follow-up register that becomes w7's next work queue. This is the milestone's deliverable.

## Context

- Format precedent: `docs/ADR028-security-review.md` (evidence-backed findings with severity, remediation status, follow-up register) and `docs/ADR039-operator-audit-and-platform-reuse.md`. Next free ADR number is expected to be ADR045 (confirm at write time — highest today is ADR044).
- Three dispositions only, per the DoD: **fixed in place** (trivial — the fix lands in this milestone, gets a t008 regression test), **owned follow-up** (filed as a real `.pm` board item — inbox note or milestone via a `/pm` hand-off), or **accepted risk** (explicit record with rationale, the `w7/008` / FUTURE-MAYBE pattern).
- Zero-findings on a plane is valid **only** with the t001–t005 sweep evidence showing the plane was probed; the register must show *what was checked*, not just *what was found*.
- Trivial fixes made during t002–t005 are recorded here as fixed-in-place; anything non-trivial is a follow-up, never silently fixed under this audit milestone.

## Steps

1. Assemble the register: §Scope (t001 map incl. exclusions + owners), §Findings (per plane, severity + evidence + disposition), §Follow-up register (owned items with pointers), §Accepted risks.
2. For each fixed-in-place finding, apply the trivial fix now (deeper fixes → follow-up) and note the commit/diff; hand each owned follow-up to `/pm` (inbox note or milestone) and cite its path in the register.
3. Record accepted risks with rationale + trigger-to-revisit (the `w7/008` pattern).
4. Cross-reference the register from `docs/ADR028-security-review.md`'s lineage note so the audit chain stays discoverable.
5. `npx prettier@3.4.2 --write "**/*.md"`.

## Acceptance criteria

- [ ] The register exists in `docs/` with §Scope (incl. exclusions + owners), §Findings, §Follow-up register, §Accepted risks.
- [ ] Every finding has exactly one disposition; fixed-in-place ones name their diff, owned ones cite a `.pm` path, accepted ones state rationale + trigger.
- [ ] Each plane shows probe evidence even where findings are zero.
- [ ] The ADR028 lineage note references the new register; prettier is clean.

## Out of scope

- Regression tests for fixed-in-place findings (t008).
