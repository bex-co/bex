## Objective

The dashboard shows Render's graphs where Render shows them: five more on a Postgres, Disk Activity on a Key Value, and Disk Activity and Disk Operations on a service's Disk page.

## Context

- `dashboard/src/features/metrics/components/datastore-metrics-panel.tsx` renders the datastore graphs; it is used by the database and Key Value detail pages and by `dashboard/src/features/services/components/disk-section.tsx`. Skeletons live in `dashboard/src/common/components/route-skeletons.tsx`.
- The metrics feature has eight locale files (`dashboard/src/features/metrics/locales/`).
- Render's names: Network Activity, Transaction Volume, Lock-Delayed Queries, Disk Activity, Disk Operations. Replication Lag already shows only with a replica.
- Root `AGENTS.md`: a loading skeleton must match the ready state's geometry.

## Steps

1. Add the graphs with Render's names. Network Activity, Disk Activity and Disk Operations each draw two series (in and out, read and written).
2. Lock-Delayed Queries without the log store shows the existing "needs the log store" state, not an error.
3. Key Value gets Disk Activity; a service's Disk page gets Disk Activity and Disk Operations beside its usage chart.
4. Update the skeletons so pending and ready states match at desktop and narrow-mobile widths, and compare them side by side.
5. Add the strings to every metrics locale file.
6. Component tests: the graphs per kind; the two-series graphs; the store-unavailable state; empty data.
