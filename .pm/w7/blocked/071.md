Facts checked on 2026-11-17:

- **Render's HIPAA-enabled workspaces** (render.com/docs/hipaa-compliance):
  - They run "services and datastores on access-restricted hosts", and enabling one redeploys everything onto those hosts.
  - They need Scale or Enterprise, one workspace per plan, and a BAA the admin signs before enabling.
  - "An additional 20% fee applies to all usage (compute, storage, etc.)".
  - Enabling is irreversible. Free instances, Workflows and Singapore are excluded.
- **Render's private links** (render.com/docs/private-link):
  - They are outbound-only AWS PrivateLink connections to a VPC endpoint service in the same AWS region, such as Snowflake, MongoDB Atlas or the customer's own VPC.
  - They need Pro or higher and cost $30 a month for up to 3 links, plus $0.03 per GB.
- **bex today:** bex runs on Hetzner (`fsn1`) and has no AWS VPC.
- **No sign-off on record:** `docs/render-artifacts/dashboard-routes.md` says the sidebar's Networking group is omitted with "both entries non-goals" (w1/m45). That is an agent's reading. The user never signed off on private links, so correct that line once the user decides.
