## Objective

Make sure the shipped behavior is pinned by tests that fail when it breaks, not by tests that only add coverage.

## Steps

1. Check the matrix: each principal kind (session, OAuth token, API key, SSH key) × each sign-in method × each setting combination (neither, 2FA only, Google only, both) gives the expected answer.
2. Check the Kratos hook endpoint's decisions: email change, unlink, unrelated profile edits, a member of no enforcing workspace, and an unreachable store.
3. Revert one guard at a time (plan gate, lock-out, exemption, fail-closed) and confirm a test fails each time.

## Acceptance criteria

- [x] Every guard has a test that fails without it, and the backend and dashboard suites pass.
