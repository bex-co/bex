## Objective

Keep all tenants within Meta's per-key limit for `muse-spark-1.3-contributor` (150 RPM / 3,000,000 TPM) and fail clearly when it is hit.

## Context

- One bex key serves every workspace's `muse` sessions, so the limit is platform-wide.
- m390/t001 measured requests and tokens per typical turn (or left it pending for t005).

## Steps

1. Add a platform cap on concurrently running `muse` sessions (env-configurable, default sized from t001), enforced at create with a typed refusal.
2. Map an upstream 429 from Meta to a failed turn with a readable reason code instead of an opaque error.

- [ ] Tests: the cap refuses the next create with the typed code and admits again once a session ends; a Meta 429 yields the named failure reason.
