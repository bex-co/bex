## Walk (2026-11-17)

Walked on real infrastructure rather than `dev-7`'s browser (the Playwright MCP server did not connect in this session): `TestOrganizationsE2E` and `TestOrganizationDowngradePreconditionsE2E` (`lego/backend/internal/api/organizations_e2e_test.go`) drive bex-api's own REST mux, GraphQL schema and MCP registry over a real Postgres and a real OpenFGA as an Owner, a Member, a Guest and a non-member, and `TestOrganizationModelOnRealOpenFGA` checks every org and workspace relation for each.

- **Same fields on GraphQL and MCP:** `get_organization` returns `OrganizationView`, whose JSON names are the GraphQL `Organization` fields (`id`, `name`, `plan`, `primaryWorkspaceId`, `viewerRole`, `createdAt`, `workspaces { id name slug plan privacy primary viewerIsMember }`); the e2e reads the same org through both. Org member tools return `OrganizationMemberView`, the GraphQL `OrganizationMember` fields.
- **Same refusals:** `ORGANIZATION_NOT_FOUND` for an unknown org and for one the caller is not in (GraphQL and MCP), `ORGANIZATION_BILLING_LIMIT` on GraphQL, MCP and REST `PATCH /v1/owners/{ownerId}/members/{userId}` (409), `ORGANIZATION_GUEST_SINGLE_WORKSPACE`, `ORGANIZATION_PLAN_ON_PRIMARY`, `ORGANIZATION_DOWNGRADE_BLOCKED` with `preconditions`, `ORGANIZATION_PRIMARY_HAS_WORKSPACES`, `FORBIDDEN` for a Member creating an org workspace.
- **REST adds no non-Render field:** `GET /v1/organizations/{orgId}/audit-logs` answers the owner route's `auditLogWithCursor` rows through the same `toAuditLogList` (Render's `auditLog` plus the `resource` and `actorDeleted` extras the workspace route already carries); `GET /v1/owners` and `GET /v1/owners/{ownerId}` are unchanged (the schema golden and the owners tests did not move).
- **Render's documented behavior** (`docs/render-artifacts/organizations.md`): matched, except where bex has no SSO (a Guest is made by an Owner, ADR115 D4) and the items filed below.
