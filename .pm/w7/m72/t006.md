## Objective

Bound tenant-controlled build/publish disk usage so a malicious repo/Dockerfile/image cannot fill the tenant node filesystem, trigger disk pressure/evictions, and disrupt co-tenant workloads (codex-security #3, medium). w7/m2 added pod securityContext + CPU/memory limits but not ephemeral storage.

## Context

- `lego/operator/internal/publish/publish.go:244/278-281/328/400` — `outVolume` EmptyDir no SizeLimit; `modestResources()` same gap.

3. (If ADR043 namespace quotas are on) confirm aggregate ephemeral-storage `ResourceQuota` covers it.
