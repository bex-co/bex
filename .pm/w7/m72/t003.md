## Objective

Stop the static server from `io.ReadAll`-ing a tenant-published S3 object fully into memory before the cache-size check, which lets one large object OOM the single-replica shared server and take down every tenant's static site (codex-security #10, medium).

## Context

- `lego/operator/internal/staticserver/s3origin.go:90-111` — `Get` calls `GetObject` with a tenant-derived key then `drain(out.Body)`.
- `lego/operator/internal/staticserver/staticserver.go:307-311` — `drain` is `io.ReadAll(rc)`; no `LimitReader`, no `ContentLength` bound.
- `lego/operator/internal/staticserver/cache.go:21/48-54` — budget checked only in `put`, after allocation.

## Steps

1. In `Get`, reject when `out.ContentLength` exceeds a hard ceiling; otherwise wrap with `io.LimitReader(out.Body, maxObjectBytes+1)` and treat the +1 overflow as "too large".
2. Stream into the cache rather than allocating the full body first where feasible.

- [ ] An object above the cap is rejected without an unbounded allocation.
- [ ] Legit objects still served/cached.
