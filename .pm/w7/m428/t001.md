## Objective

A push whose head commit message contains any of Render's six skip phrases opens no deploy and records `commit_ignored`, on the commit path and the checks-pass path.

## Context

- `commitHasSkipPhrase` (`lego/backend/internal/apps/webhook.go:1122-1124`) checks `[skip render]` and `[render skip]` only. It gates the checks-pass path at `:1045` and the push path at `:1077`, where `recordCommitIgnored` writes the event with `store.EventReasonSkipPhrase`.
- Render (render.com/docs/deploys § Skipping an auto-deploy, read 2026-11-16): the phrase is `[skip render]` or `[render skip]`, and `render` may be replaced with `deploy` or `cd`.

## Steps

1. Re-read Render's section and note whether it says anything about letter case or about which commit of a push is read. Keep bex's current matching (head commit) unless the page says otherwise.
2. Extend the list to the six phrases.
3. Table test: each phrase on the push path and the checks-pass path; a phrase inside a longer message; near-misses such as `[skip-render]` and `skip render` without brackets do not match.
4. Leave Blueprint auto-sync unchanged: Render documents skip phrases for service auto-deploys only.
5. Update any bex document or dashboard hint that lists the phrases, and add a note under ADR018 § Deploys.
