## Context

The Render CLI `psql` flow (`render-oss/cli` `cmd/psql.go` → `pkg/tui/views/psql.go`):

1. `getPostgresFromIDOrName` — `GetPostgres(id)` first, else `ListPostgres(name=…)` (ambiguous name ⇒ error).
2. `getUserIP()` — caller's public IP from `https://api.ipify.org`.
3. `hasAccessToPostgres(pg, userIP)` — **client-side** check: iterates `pg.IpAllowList` as CIDRs; if the IP isn't contained, aborts with `"IP address (%s) not in allow list for %s"` **before spawning psql**. An empty allowlist matches nothing ⇒ refusal.
4. `GetPostgresConnectionInfo(pg.Id)` → uses `connectionInfo.ExternalConnectionString` (always external, never internal).
5. Spawns `psql <ExternalConnectionString> -c <command>`.

bex-api side (research-confirmed, this task re-verifies against current HEAD):

- Resolve by id + name: `GET /v1/postgres/{id}` and `GET /v1/postgres?name=` (filters on `p.Name` AND `p.ID`, `lego/backend/internal/postgres/rest.go:118`).
- `GET /v1/postgres/{id}/connection-info` → `PostgresConnectionInfo()` (`internal/postgres/service.go:558`) emits `externalConnectionString` **only when** `d.Status.ExternalHost != ""` (`omitempty` otherwise).
- `ExternalHost` is set only when `db.Spec.Public && BEX_DB_DOMAIN != ""` (`operator/internal/controller/database_controller.go:800`).
- IP allowlist enforced at the pg-sni-proxy TCP layer (Traefik `MiddlewareTCP`); empty ⇒ open.
