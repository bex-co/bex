## Objective

- Base dev-9 deliberately does not run `BEX_DB_DOMAIN` / the SSH gateway / external datastore connect (`docs/cli-compatibility-checklist.md:15`), which is exactly why the row is `[~]` today. Acceptance needs a wired env: a dev supplement that brings up the pg-sni-proxy + sets `BEX_DB_DOMAIN` (the `w6/m38` / `pgcli` Postgres supplements are the precedent), or production per ADR009 (edge TCP `5432 → 31056` listener already exists).

4.
