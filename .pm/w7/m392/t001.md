## Objective

Store which agent profiles a workspace allows, and the admin's acknowledgement for Muse, on the existing agent environment.

## Context

- The agent environment update is REST `PATCH /v1/agent-environment`, GraphQL `updateAgentEnvironment`, MCP `update_agent_environment` (admin-only; ADR091 D5/D7 fields such as `agentModelMonthlySpendCapUsd` and `modelApiKey` live there).
- Profile ids come from `lego/backend/internal/agentsession/agent-profiles.json`.

## Steps

1. Migration: per-workspace enabled profiles (default: every profile except `muse`) and `museDataUseAcknowledgedAt` / `…By`.
2. Read and update fields on REST, GraphQL and MCP; reject unknown ids; enabling `muse` requires `acknowledgeMuseDataUse: true` in the same request; audit the change.

## Files

- `lego/backend/internal/store/*` (migration + queries), `lego/backend/internal/agentsessions/*` (agent environment service), the REST/GraphQL/MCP handlers and schema for the agent environment, `dashboard/src/**/agent-environment*.graphql`

## Acceptance criteria

- [ ] Tests: defaults; admin can change, non-admin gets 403; unknown id refused; Muse without acknowledgement refused; acknowledgement stored with subject and time.

## Out of scope

- Enforcement (t002) and UI (t003).
