## Objective

Make a disabled agent unusable everywhere a session can start, and invisible in what clients are offered.

## Context

- Session starts: `createAgentSession` (REST/GraphQL/MCP), automation runs (ADR101 scheduler), child spawns (ADR102 `spawn_session`), PR takeover intake.
- Capabilities: `Capabilities()` in `lego/backend/internal/agentsessions/service.go` sets `caps.Agents = agentProfiles()`.

## Steps

1. Refuse each start path with `AGENT_SESSION_AGENT_DISABLED` when the profile is disabled; keep steering existing sessions allowed.
2. Filter `caps.Agents` by the workspace's enabled list (and, for `muse`, by route availability from m390/t003).

## Files

- `lego/backend/internal/agentsessions/service.go`, automation and spawn entry points under `lego/backend/internal/agentsessions/`

## Acceptance criteria

- [ ] Tests: each start path refused with the typed code; steering an existing session still works; capabilities omit a disabled agent.
