## Objective

Cover the isolation, retention and gate-off properties, which are the ones a reviewer cannot verify by reading.

## Context

- t005 already covers the cache-loss invariant; this task covers the rest.
- The highest-risk untested property is **cross-workspace cache isolation** — a leak there is a confidentiality breach, not a performance regression.
- The second is the retention interaction, which only manifests after N builds and would otherwise be found in production.

## Steps

1. Test the gate: unset `BEX_BUILD_CACHE` produces a byte-identical Job spec.
2. Test cross-workspace denial on the `-cache` repository (both `BEX_REGISTRY_NS` set and unset).
3. Test the retention interaction with enough pushes to trigger a naive-policy eviction.
4. Confirm `make test` and the backend suite are green.

- `lego/operator/internal/build/build_test.go`, controller tests

## Acceptance criteria

- [ ] Gate-off byte-identity is asserted, not assumed.
- [ ] Cross-workspace cache access is denied under both credential modes.
- [ ] Retention interaction is proven by a test that would fail under a shared policy.
- [ ] No trivial or tautological tests; suites green.
