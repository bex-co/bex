## Objective

Make the dashboard behave like Devin's sidebar. The agent session list opens on the non-archived sessions the viewer started, with a toggle to everyone's. Every row and the session header say who started the session, and the header can replace the session's tags.

## Context

- List: `dashboard/src/features/agent-sessions/components/session-list.tsx`, `agents-panel.tsx`, `hooks/use-agent-sessions.ts`, `api/agent-sessions.graphql`.
- Header: `components/session-detail-header.tsx` (automation starter line at :479).
- Creator labels: `useWorkspaceSubjectLabel` (used by `agent-environment/components/agent-skill-history.tsx:48`). The viewer's own ids come from the `WorkspaceMembers` roster's `isSelf` row (`agent-automations/hooks/use-automation-viewer.ts`).
- Locales: `features/agent-sessions/locales/{en,zh}.ts`.
- Skeleton rule: `dashboard/AGENTS.md` (the pending state must match the loaded layout at desktop and narrow-mobile widths).

## Steps

1. GraphQL documents: request `createdBy`, pass `mine` to the list query, and add the `setAgentSessionTags` mutation; run codegen.
2. List: a "Mine / All" control defaulting to Mine, remembered per viewer in localStorage. Show the creator label on each row (omit it under Mine, where it is always the viewer).
3. Header: "Started by <name>" for sessions a person started. Automation sessions keep "Started by automation <name>" and add the person it runs as; child sessions show their creator too.
4. Tag editor in the header: a chip input that replaces the whole set through the mutation, disabled for archived sessions if t003 refuses those, with an optimistic update and an error toast.
5. Update the skeletons for the new control and creator line; compare pending and ready states side by side at desktop and about 390px.
