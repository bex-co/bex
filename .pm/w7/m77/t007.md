## Objective

Execute t001's cutover plan against hetzner-prod so the real tenants stop depending on hand-built reconcile artifacts, and prove the platform path now does what a human did by hand on 2026-08-08.

## Context

- Affected production tenants (workspace `tea-d98210cbbpdc73dcrkvg`): `tianpan-forum` and `blockeden-forum` (currently running **only** because of manual artifacts), plus `beancount-forum` (`srv-d9nqg9dcavls73fp8m2g`) and `beancount-cms-v2`, whose datastores also live in `default`.
- Manual artifacts to retire, per tenant, from the incident report §7:
  1. Hand-copied `dpg-<id>-app` + `red-<id>` Secrets in the tenant namespace, with a hand-patched `host` key set to the FQDN.
  2. A hand-written `CiliumNetworkPolicy` allowing the forum pods egress to `app.bex.co/keyvalue=<red-id>:6379` and `cnpg.io/cluster=<dpg-id>:5432`.
  3. A hand-made traefik `Ingress` for `<svc>.onbex.co` with cert-manager `letsencrypt-prod` (this one belongs to `w7/m78` — remove it only once m78's fix produces the Ingress).
- These are live forums serving real data at `https://tianpan-forum.onbex.co/forum/` and `https://blockeden-forum.onbex.co/forum/` — downtime is a real user impact, and the Postgres holds real content.
- Do not commit or print `.env` / `*.kubeconfig` contents (repo rule).

## Steps

1. Take a verified backup of each affected tenant's Postgres before touching anything, and confirm it is restorable — not merely that a backup object exists.
2. Execute [`docs/runbooks/datastore-namespace-cutover.md`](../../../docs/runbooks/datastore-namespace-cutover.md) one tenant at a time, starting with a tenant that is not a live forum if one exists. Rehearse the whole procedure on a scratch workspace first — the runbook requires it.
3. After each tenant: confirm the pod mounts platform-created Secrets (not the hand-copied ones), reaches Postgres and Valkey, and serves its site.
4. Remove the manual artifacts for that tenant and confirm nothing regresses — the removal is the proof the platform path works.
5. Record the executed cutover, per-tenant results, and any deviation from the plan.
