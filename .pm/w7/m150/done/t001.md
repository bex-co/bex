## Done 2026-09-17

Contract pinned from the client itself, not from help output — the distinction the first acceptance line insists on, and it mattered: reading the real code corrected a documented claim.

**`lego/cli/testdata/sandbox-file-contract.json`** records the handshake, and **`TestPinnedSandboxFileTransportMatchesBexContract`** (`lego/cli/sandbox_contract_test.go`) drives the real pinned `pkg/sandbox.Service` against it, so a pin bump that moves the transport fails here before bex-api is built against a stale contract. Sibling of the exec contract `w7/m147` established.

Measured from `pkg/sandbox/files.go`, `pkg/sandbox/repo.go` and `pkg/client/client_gen.go` at `v1.1.3-0.20260909214233-a764810a7682`:

- **Mint:** `POST /v1/sandboxes/{id}/files/{operation}/token`, `operation` ∈ {`upload`,`download`} as a **path segment**, `ownerId` and `path` as form-style **query parameters**, and **no request body**.
- **`docs/render-artifacts/ea-sandbox.md` was wrong and is corrected**: it documented a `{ "path": "…" }` request body. The pinned client sends none — verified by an assertion, not by reading.
- **Transfer:** bex chooses the method; the client issues the transfer with whatever `method` the connect response returns, under `Authorization: Bearer {token}`.
- **Body shape:** a **single file streams raw**; only a **directory** is tar + gzip with `Content-Length: -1`. The previous checklist wording ("the tar/octet body") blurred the two. Measured — the test's uploaded body is byte-identical to the source file.
- **Archive policy:** traversal components (`.`, `..`, `/`, empty) rejected; escaping symlink targets rejected; non-regular non-symlink entries skipped rather than aborting; dir/regular/symlink/hardlink handled; a **truncated archive must not read as success** (the client wraps the body in a `terminatedReader` and relies on the gzip trailer, which an identity `x-tar` lacks).
- **Non-goals recorded:** `ea sandbox-groups` stays ungraded by choice; App SSH restrictions unchanged.

`docs/cli-compatibility-checklist.md` now cites the fixture and the test rather than restating prose. Verified: `go test ./...` green across `lego/cli` (7 packages).
