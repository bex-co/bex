## Objective

Prove the full loop end to end for every store using **only the scripts**: take (or wait for) a fresh backup, restore it with the store's script, verify a known marker/row, tear down the throwaway — the user's "actually try backup and recover and ensure they work" ask.

## Context

- Stores and scripts: etcd (t001), OpenBao (t002), `bex-db` + one tenant Database (t003; plus one auth DB if w7/m67 has landed), KeyValue (t004; against a paid dev instance, or prod if w7/m68 has landed).
- "Fresh backup" means the drill first confirms the newest snapshot/base-backup postdates a marker write where feasible (e.g. write a marker row/key, trigger or await the scheduled backup, then restore and find the marker) — this catches a backup pipeline that runs but captures nothing, which one-shot restore drills of old snapshots cannot.
- Precedent drill records: `drills/2026-07-14-*`, `drills/2026-07-28-barman-plugin-pitr.md` — same evidence format (commands, timings, verification output, teardown proof).
- Any ad-hoc command needed mid-drill is a script bug: fix the script, re-run, and note it in the drill record.

## Steps

1. Per store: marker write (where the store allows) → fresh backup confirmed → scripted restore → marker verified → scripted/verified teardown.
2. Record one drill file with per-store sections + timings (these become the RTO evidence `w7/016` will cite).

## Files

- `drills/<date>-scripted-restore-e2e.md` (new)
- `scripts/restore-*.sh` (fixes surfaced by the drill)

## Acceptance criteria

- [ ] Every store restored via its script with zero ad-hoc intervention (or the intervention folded back into the script and re-run clean).
- [ ] Marker-based freshness verified for at least bex-db and KeyValue (stores where a marker write is cheap and safe).
- [ ] All throwaways torn down; drill record committed with timings.
