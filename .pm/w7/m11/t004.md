## Objective

Prove the check works live: a correctly cosign-signed tenant image admits normally; a tampered or unsigned image is cleanly rejected with an explanatory error/event, not a silent failure or an opaque 500-style admission error.

## Steps

1. With signing enabled, deploy a normally-built (signed) tenant image — confirm it admits.
2. Attempt to deploy an unsigned image (or a signed image swapped for a different digest) — confirm admission rejects it, and the rejection reason is visible (kubectl describe / events).

## Acceptance criteria

- [ ] A signed image admits.
- [ ] A tampered/unsigned image is rejected with a clear, visible reason.
