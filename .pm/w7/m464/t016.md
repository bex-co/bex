## Objective

Make sure the org's rules are pinned by tests that assert real behavior and failure modes, not by snapshots.

## Steps

1. Check the coverage the earlier tasks left. Add whatever is missing:
   - every refusal code on every surface;
   - the backfill on a database seeded like production;
   - authz property tests across Owner, Member, Guest and non-member, for every org and workspace relation;

- [ ] Each rule in the definition of done has a named test that fails when the rule is removed.
- [ ] `cd lego/backend && go test ./...`, `make lint`, `yarn lint` and `yarn test` pass.
