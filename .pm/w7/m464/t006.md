## Objective

Let an org grow to any number of workspaces at no additional plan fee, as on Render ("An org can contain unlimited workspaces at no additional cost"). Implement:

- An Owner creates a workspace in the org, Public or Invite-only, with Invite-only as the default.
- A Member adds themselves to a Public workspace.
- An Owner adds themselves to any org workspace as admin.
- A workspace admin changes its privacy.
- Deleting a secondary workspace works as today. The primary cannot be deleted while it has secondaries.
- Support (an operator) moves an existing standalone workspace into an org, as Render support does.

## Context

- Workspace create: GraphQL `prepareWorkspaceCreation` / `finalizeWorkspaceCreation` / `createWorkspace` (`workspaces/graphql.go:213-259`), `Service.Create` (`service.go:1065`), and the paid-create payment step (w9/m88, `billing/workspace_creation.go`).
- t001's artifact records whether Render asks an org workspace for its own payment method. Each Render workspace keeps its own Billing page and invoices.
- Render (render.com/docs/organizations): "Org Owners can create workspaces from the org's Workspaces page". Public: "any org member can add themselves". Invite-only: "only workspace admins can invite members". "New workspaces are invite-only by default". "Existing workspaces can be transferred into an org by contacting Render support".
- An operator-only command already exists as a bex-api subcommand: `lego/backend/cmd/api/revoke_oauth_grant.go`.
- Per-user caps: `store.LimitsFor(plan).MaxWorkspacesPerUser` is unlimited on paid plans (render.com/docs/team-members), so org workspaces need no new cap.

## Steps

1. Create in an org: take `organizationId` and `privacy` on the create verbs (GraphQL and MCP). Require `can_create_workspace`. The new workspace takes the org's plan. Payment follows t001's finding: no plan-fee step, and a payment method only if Render asks for one. Make the creator its admin.
2. Join:
   - `joinWorkspace(id)`: a Member on a Public workspace joins with the role t001 recorded;
   - `joinWorkspaceAsAdmin(id)`: an Owner joins any org workspace as admin.

   Both go on GraphQL and MCP.
3. Privacy: `setWorkspacePrivacy(id, public|invite_only)`, gated by `can_manage`.
4. Delete: refuse deleting the primary while secondaries exist, with a named code.
5. Support transfer: add a bex-api subcommand `move-workspace-to-organization`, modelled on `revoke-oauth-grant`. It attaches a standalone workspace to an org, sets its plan to the org's and writes its tuples, and refuses a workspace that is already in an org. Document it in a runbook line in the ADR.
