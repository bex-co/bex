## Objective

Let a `muse` session's model requests through the gateway model proxy to Meta's inference endpoint, and nothing else on that origin.

## Context

- `allowedProviderOperation` in `lego/backend/internal/sshgateway/modelproxy/modelproxy.go` is the confused-deputy boundary per host.
- `ResolveAuthScheme` (`lego/backend/internal/agentsession/model.go`) falls through to `AuthSchemeBearer` for an unknown host, which is Meta's scheme.

## Steps

1. Add `api.meta.ai`: `POST`, JSON, path `/v1/responses`, empty query (widen only if the t001 ADR shows Muse needs another inference path).
2. Pin the Bearer scheme for `api.meta.ai` explicitly rather than by fall-through.

## Files

- `lego/backend/internal/sshgateway/modelproxy/modelproxy.go`, `lego/backend/internal/agentsession/model.go`, `lego/backend/internal/sshgateway/modelproxy/modelproxy_test.go`

## Acceptance criteria

- [ ] Tests: `/v1/responses` is forwarded with the injected Bearer key; `/v1/models`, `/v1/files`, GET, non-JSON and any query are refused; a foreign Pod is refused.

## Out of scope

- Model pinning and usage metering (m391).
