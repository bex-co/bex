## Objective

Enforce the setting at the one point the 2FA requirement already uses, so every surface refuses the same way and none can drift.

## Context

- `core.Base.requireTwoFactor` (`lego/backend/internal/core/twofactor.go`) calls `core.TwoFactorGate.Check` after every positive OpenFGA decision. `WithTwoFactorExempt` marks the reads a blocked member still needs. `CheckTwoFactor` covers workspace configuration.
- `twofactor.Gate` (`internal/twofactor/gate.go`) resolves the principal: a session, a human token, or an API key's creator. It caches the setting and the facts for 60 s and fails closed.
- The SSH gateway asks bex-api over an HMAC verb (`internal/agentsession/two_factor.go`, `internal/sshgateway/twofactor.go`) for native SSH, the web shell, agent attach and sandbox exec and files. `cmd/ssh-gateway/twofactor_test.go` covers it.
- `internal/api/twofactor_surfaces_test.go` proves one refusal on every surface.

## Steps

1. Extend the gate so one `Check` answers both requirements. A workspace that requires neither still costs no lookup. A caller who fails both gets one refusal, in an order t001 fixes.
2. Refuse with 403 `WORKSPACE_GOOGLE_LOGIN_REQUIRED` and the workspace id when the caller's sign-in (from t003) is not Google. An API key or SSH key fails when it was not created in a Google session, unless t001's exemption applies.
3. Carry the answer through the SSH gateway verb, so every SSH path refuses a non-Google key in an enforcing workspace.
4. Count refusals in the existing metric under a new closed reason.
5. Extend `twofactor_surfaces_test.go` and the gateway tests to the new requirement.

## Files

- `lego/backend/internal/twofactor/gate.go`, `internal/core/twofactor.go`, `internal/agentsession/two_factor.go`, `internal/sshgateway/twofactor.go`, `cmd/api/main.go`, and the tests named above

## Acceptance criteria

- [ ] In an enforcing workspace, a password-session member, a token from a password session, and an API key and SSH key created in one all get the coded 403 on REST, GraphQL, MCP and SSH. The same callers signed in with Google pass.
- [ ] The exempt reads still answer a blocked member: the workspaces list, `currentUser` and leave.
- [ ] A lookup that cannot answer fails closed. A workspace that requires neither setting makes no lookup.
