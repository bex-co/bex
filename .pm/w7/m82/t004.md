## Objective

Make the push phase survive the transient registry failures t002 now classifies as retryable, and close the standing `--dest-tls-verify=false` finding while the same lines are open.

## Context

- `lego/operator/internal/build/build.go:537` — `pushArgs := []string{"copy", "--dest-tls-verify=false"}`, unconditional, with **no** `--retry-times`. ADR060 D4 wants whole-blob retry (`--retry-times 3`), not chunked-upload resume: resume paths are where registries historically corrupt uploads.
- The unconditional TLS flag is `.pm/w1/046.md` **F11** — inert against the in-cluster HTTP Zot, wrong the moment `BEX_REGISTRY` names a TLS registry. The register lives in w1; note the strike there when this lands.
- ADR060 D4 also wants the operator-managed `zot-config` to pin `gcDelay` above the worst-case push duration (≥ the 30-minute build deadline) and Zot's `scrub` extension enabled. A recent upstream untagged-manifest GC default flip is exactly the kind of change that would eat an in-flight push.
- Zot remains a single-replica accepted SPOF; the push metrics here are its tripwire, not a fix.

## Steps

1. Add `--retry-times 3` to the skopeo push.
2. Condition `--dest-tls-verify` on the registry scheme (or an explicitly allowlisted dev endpoint) so an HTTPS `BEX_REGISTRY` is verified.
3. Pin `gcDelay` ≥ the build deadline in the operator-managed `zot-config` and enable the `scrub` extension.
4. Add `bex_build_push_seconds` and `bex_build_push_errors_total`.
5. Note the F11 strike in `.pm/w1/046.md`.

## Acceptance criteria

- [ ] Push retries transient failures up to three times; a deterministic push failure still fails once.
- [ ] An HTTPS registry URL results in TLS verification being **on**; the in-cluster HTTP Zot path is byte-identical to today.
- [ ] `gcDelay` ≥ the build deadline and `scrub` enabled, asserted by a test or CI guard rather than by inspection.
- [ ] Push latency and push errors are queryable series.

## Out of scope

- Zot HA or a pull-through cache tier — ADR060 D4 keeps single-replica as an accepted SPOF with these metrics as the tripwire.
