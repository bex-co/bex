## Objective

A user looking for logical replication on bex learns what Render's page tells them: it is off by default, it needs a Pro workspace and 10 GB, it is enabled on request with the database id, role, schemas and the all-tables choice, and afterwards they run `CREATE PUBLICATION … FOR TABLE` themselves and connect subscribers to the external URL (never the pooler).
