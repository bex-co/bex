## Objective

Populate `INSTANCE` filter discovery from Prometheus cAdvisor series observed during `[Start, End]` merged with live pods, so instances replaced by deploys, restarts, crashes, or scale-ins remain discoverable for historical windows.

## Context

- `lego/backend/internal/metrics/service.go:1408-1420` currently lists only live `OwnAppPods(ctx, app)` and ignores `[Start, End]`.
- `lego/backend/internal/metrics/source.go` already queries Prometheus `/api/v1/label/<name>/values` and cAdvisor pod selectors (`container_cpu_usage_seconds_total` / `instancePods` for datastores).
- Static sites have no pods and must stay empty (`w4/m113`).

## Steps

1. Add a bounded Prometheus instance-discovery source (or extend `MetricsFilterValuesSource` / add `InstanceFilterValuesSource`) querying `/api/v1/label/pod/values` with `start`/`end` and the exact same namespace + pod selector used by `cpu`/`memory` (`container!="",container!="POD"`, `AppNotBefore` respected; `instancePods` for Postgres/Key Value).
2. In `MetricsFilters` for `filterFieldInstance`, union Prometheus-observed pods over `[Start, End]` with live pods (`OwnAppPods` for compute services; none for static sites), project each to its canonical public instance ID (`ids.ServiceInstanceID`), deduplicate, and sort deterministically.
3. Wire the production source in `lego/backend/internal/api/server.go` whenever `BEX_PROM_URL` is configured, falling back gracefully to live pods when Prometheus is unwired.

## Files

- `lego/backend/internal/metrics/source.go`
- `lego/backend/internal/metrics/service.go`
- `lego/backend/internal/api/server.go`

## Acceptance criteria

- [ ] A pod that ran during `[Start, End]` and was terminated before `now` is returned by `/v1/metrics/filters/application` and GraphQL `metricsFilters(outputFilters: ["INSTANCE"])`.
- [ ] A static site still returns `[]` for `INSTANCE`.
- [ ] Datastore IDs (`dpg-`/`red-`) return canonical instance IDs for their primary, standby, and read-replica pods.

## Out of scope

- HTTP host and statusCode discovery (t003).
