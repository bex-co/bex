## Objective

Implement the backend source and shared `metrics.Service` verb that derives HTTP path filter suggestions from the most recent 5,000 matching Traefik request log lines in Loki, matching Render's documented `GET /metrics/filters/path` behavior.

## Context

- `lego/backend/internal/api/openapi/render-public-api-1.json` (`list-path-filter-values`): _"The path suggestions are based on the most recent 5000 log lines as filtered by the provided filters"_, example `"/user/*"`, accepting `startTime`, `endTime`, repeatable `resource`/`service`, `host`, `statusCode`, and `path`.
- `deploy/gitops/base/values/traefik.values.yaml:180-185`: Traefik access logs carry `RequestHost`, `RequestPath`, and `DownstreamStatus` (shipped with `type="request"`, `status` label).
- `lego/backend/internal/metrics/lokisource.go` already queries Loki's `/loki/api/v1/query_range` and builds safe `%q`-escaped LogQL selectors; `lego/backend/internal/metrics/retention.go` enforces the workspace plan's metrics retention floor.
- `lego/backend/internal/api/server.go` wires `metrics.Service` sources from `BEX_LOKI_URL`.

## Steps

1. Define `PathFilterSuggestionsSource`, `PathFilterSuggestionsRequest`, and `PathFilterSuggestionsQuery` in `lego/backend/internal/metrics/` (supporting multiple resources, `[Start, End]` defaulting to `now-1h..now` and clamped to workspace plan retention, `Hosts []string`, `StatusCodes []string`, and `Paths []string`).
2. Implement `NewLokiPathFilterSuggestionsSource(base, hc)` querying Loki's `/loki/api/v1/query_range` with `direction=backward`, `limit=5000`, and safe `%q`-escaped matchers (`namespace`, `app`, `type="request"`, optional `status=~`, `request_host`, and `request_path` prefix/wildcard filter), extracting distinct `RequestPath` values (bounded and deterministically ordered, e.g. by frequency descending then lexicographically).
3. Implement `Service.PathFilterSuggestions(ctx, q)` enforcing `checkWindow`, `checkFanOut`, per-resource `AuthorizeApp(ctx, core.RelCanView, ...)`, retention clamping, and `core.ErrLogStoreUnavailable` when the Loki source is nil.
4. Wire `NewLokiPathFilterSuggestionsSource` in `lego/backend/internal/api/server.go` whenever `BEX_LOKI_URL` is configured.

## Files

- `lego/backend/internal/metrics/service.go`
- `lego/backend/internal/metrics/lokisource.go`
- `lego/backend/internal/api/server.go`

## Acceptance criteria

- [ ] `PathFilterSuggestions` authorizes every requested resource ID (`403`/`404` on unauthorized/unknown resources) and enforces `MaxQueryHours`, `checkFanOut`, and plan retention clamping.
- [ ] The Loki source queries at most 5,000 most-recent matching request log lines, respects `host`, `statusCode`, and `path` filters, and returns deduplicated, bounded suggestions without leaking another tenant's paths.
- [ ] With Loki unwired (`nil`), `PathFilterSuggestions` returns `core.ErrLogStoreUnavailable` (503) instead of a silent empty list.
