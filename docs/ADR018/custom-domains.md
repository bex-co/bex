# Custom domains

This is the Custom domains part of the [Render parity matrix](../ADR018-render-parity.md) (ADR018), moved out of it on 2026-11-23 (w10/m607) to keep the ledger under the 1 MiB blob limit. The matrix's legend, method and evidence sources apply here. Amend these rows in this file, not in ADR018.

**REST list filters (w4/165):** Projects honor exact `name` matches (OR across repeated values) plus `createdBefore`/`createdAfter` and `updatedBefore`/`updatedAfter`; custom domains honor the same name matching plus the creation window. Filtering precedes cursor pagination and malformed RFC3339 values return a named 400. Managed custom-domain creation times come from the durable claim row. Storeless legacy hosts have no recorded creation timestamp and pass creation windows through, matching the shared missing-timestamp policy rather than inventing a time from the parent App. These name/time arguments belong to the REST contract; Render's introspected GraphQL project/custom-domain queries and the existing MCP tools do not expose them. Gated regression coverage: `TestGatedProjectAndDomainListFilters`.
