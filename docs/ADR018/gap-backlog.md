Every Postgres create adapter resolves omission to Render's reachable-by-default database: an omitted `public` on REST, GraphQL, MCP and the dashboard, and an omitted `ipAllowList` in a Blueprint (w2/038, w8/157, w4/553), while `/v1/key-value` publishes only when a nonempty `ipAllowList` enables external access, as Render keeps a new Key Value private.
