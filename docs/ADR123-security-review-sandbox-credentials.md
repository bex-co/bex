# ADR123: Security review — sandbox group credential brokering

- **Status**: Accepted (2026-11-21, `w2/m536` t001)
- **Trigger**: `w2/m532`–`m535` implemented [ADR122](ADR122-sandbox-credential-brokering.md): write-only OpenBao-backed sandbox group credentials across REST, GraphQL, MCP, and the dashboard, an internal `:8091` control-plane lookup route, a Pod-bound outbound HTTPS selective-MITM broker (`:8086`) inside `bex-ssh-gateway`, and sandbox Pod CA/proxy wiring + Cilium egress/ingress policies. An outbound TLS-intercepting secret broker introduces cross-tenant identity, SSRF, HTTP smuggling, secret custody, and RBAC attack surfaces that must pass adversarial review before production sign-off.
- **Lineage**: Focused review following [ADR103](ADR103-security-review-static-rewrite-proxy.md) (static rewrite proxy), [ADR062](ADR062-sandbox-credential-vault.md) (agent credential vault), and [ADR117](ADR117-security-review-api-key-roles.md)–[ADR121](ADR121-security-review-key-postgres-logins.md) (scoped API keys and creator ceilings).

## Scope

Audited every layer of the sandbox group credential control plane, secret store, internal lookup, gateway broker, Pod wiring, and cluster admission/egress manifests:

- **Control plane & validation**: `lego/backend/internal/sandbox/credentials.go`, `credentials_validate.go`, `credentials_vault.go`, `credentials_rest.go`, `credentials_surfaces.go`, `broker_cp.go`, `broker_wiring.go`, `service.go`, `idle.go`, `lifetime.go`, `admission.go`.
- **Persistence & custody**: `lego/backend/internal/store/sandbox_credentials.go` (migration `0318_sandbox_group_credentials`), `lego/backend/internal/sandbox/purger.go`, `groups.go`.
- **Authz & API keys**: `lego/backend/internal/api/key_permission_ops.go`, `scope_matrix_ops.go`, `core.Base.Authorize` / `keyCeiling`.
- **Data-plane broker**: `lego/backend/internal/sshgateway/sandboxbroker/{broker,pod,ssrf,match,inject,ca}.go`, `lego/backend/internal/sshgateway/proxyutil.go`, `metrics.go`, `lego/backend/cmd/ssh-gateway/main.go`.
- **Cluster manifests & policies**: `deploy/gitops/base/sandbox-pod-admission.yaml`, `deploy/gitops/base/tenant-node-egress.yaml`, `lego/operator/config/certmanager/certificate.yaml`, `lego/operator/config/ssh/{deployment,networkpolicy,service}.yaml`, `lego/operator/config/api/deployment.yaml`, `scripts/gitops-validate.sh`.

## Findings fixed in this review

| ID | Severity | Attack class | Finding | Fix & regression test |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **F1** | **High** | #2 SSRF | `sshgateway.BlockedEgressAddr` checked `netip.Prefix.Contains(addr)` without rejecting IPv6 zone IDs (`addr.Zone() != ""`). In Go's `net/netip`, `Prefix.Contains` always returns `false` for any zoned IPv6 address, so `CONNECT [::1%lo]:443` or `CONNECT [fe80::1%eth0]:443` bypassed all deny prefixes in both `sandboxbroker` and `egressproxy` and could dial loopback/link-local addresses on `bex-ssh-gateway`. | Reject `addr.Zone() != ""` in `lego/backend/internal/sshgateway/proxyutil.go` (`BlockedEgressAddr`). Regression tests: `TestSSRFGuard` (zoned IPv6 literals & `BlockedEgressAddr` assertions in `sandboxbroker/broker_test.go`). |
| **F2** | **High** | #1 Cross-group / cross-workspace IP reuse | `KubeSandboxPodResolver` (`pod.go`) verified `pod.Status.PodIP == sourceIP && pod.DeletionTimestamp == nil` in both the hint-cache fast path and namespace scan, but did not check `pod.Status.Phase == corev1.PodRunning` or `!pod.Spec.HostNetwork`. In Kubernetes, an exited Pod (`Succeeded`/`Failed`) retains `Status.PodIP` with `DeletionTimestamp == nil` even after Cilium recycles that IP to another group, workspace, or agent-session Pod; a warm hint hit returned the exited Pod's identity. Additionally, `scanNamespaces` ignored transient apiserver errors (other than `NotFound`/`Forbidden`), risking partial-scan misattribution. | Added `isLivePodAtIP` requiring `DeletionTimestamp == nil && Status.Phase == corev1.PodRunning && !Spec.HostNetwork && Status.PodIP == sourceIP` on both paths, and failed closed (`ErrPodForbidden`) on transient apiserver list errors during `scanNamespaces`. Regression test: `TestKubeSandboxPodResolverRejectsNonRunningHostNetworkAndTransientErrors` (`sandboxbroker/broker_test.go`). |
| **F3** | **Medium** | #4 Request / path smuggling | `handleMITMRequest` matched `paths` patterns against Go's decoded & cleaned `URL.Path` while forwarding the unnormalized raw URI (`EscapedPath()`). Sending `GET /v1/admin/..%2fsafe/ok` or `GET /v1/admin/../safe/ok` matched `/v1/safe/*` and injected the secret while forwarding `/v1/admin/..%2fsafe/ok` or `/v1/admin/../safe/ok` upstream; sending `/v1/safe/foo%2fbar` could split segments differently between broker and upstream. `handleMITMRequest` also did not reject nested `CONNECT` or opaque URIs, nor clear `outURL.User` / `Fragment` on absolute-URI requests. | Rejected nested `CONNECT` (`405`), opaque URIs (`400`), and non-canonical paths containing literal or `%2e`-encoded dot segments, backslashes (`\`/`%5c`), or `//` (`400`) in `broker.go`; cleared `outURL.User` and `outURL.Fragment`; required path-restricted credentials to match both decoded `URL.Path` and `URL.EscapedPath()` (`matchCredentialPaths` in `match.go`). Regression test: `TestBrokerMITMPathSmugglingAndRequestHardening` (`sandboxbroker/e2e_test.go`). |
| **F4** | **Medium** | #1 & #6 Label tampering | `bex-sandbox-pods` (`deploy/gitops/base/sandbox-pod-admission.yaml`) permitted `UPDATE` to set `bex.co/sandbox-group` whenever `oldObject.metadata.labels['bex.co/sandbox-group'] == ''`, and did not freeze `bex.co/agent-session`, `bex.co/sandbox-id`, `bex.co/workspace`, or `bex.co/egress` on Pod `UPDATE`. A compromised OpenSandbox controller/server could strip `bex.co/agent-session` and attach `bex.co/sandbox-group` + `bex.co/sandbox-id` + `bex.co/egress: allow-all` to a running agent-session Pod, or flip a `deny-all` Pod to `allow-all`. | Removed the `oldObject == ''` loophole (pre-m535 resume backfills patch the suspended `BatchSandbox` CR, so every Pod has its final labels at `CREATE`) and locked all five labels (`bex.co/sandbox-group`, `bex.co/sandbox-id`, `bex.co/workspace`, `bex.co/agent-session`, `bex.co/egress`) immutable on Pod `UPDATE`. Pinned in `scripts/gitops-validate.sh`. |
| **F5** | **Low** | #5 Header / cookie injection | `ValidateCredentialInjection` blocked `\r`, `\n`, `\x00` (and `;` for cookies) in rendered `header`/`cookie` values, but allowed non-CRLF ASCII control characters (`0x01`–`0x08`, `0x0b`, `0x0c`, `0x0e`–`0x1f`, `0x7f`), which violate RFC 9110 §5.5 / RFC 6265 §4.1.1 and can trigger parser differentials or runtime `RoundTrip` errors. | Rejected all ASCII control characters (`(b < 0x20 && b != '\t') |  | b == 0x7f`for`header`; `b < 0x20 |  | b == 0x7f |  | b == ';'`for`cookie`) in `credentials_validate.go`. Regression tests in `sandbox/credentials_test.go`. |

## Attack-class audit matrix (all 8 classes)

| # | Attack class | Verdict | Evidence & controls |
| --- | --- | --- | --- |
| 1 | Cross-sandbox-group & cross-workspace credential theft via Pod IP spoofing, label tampering, or agent-session Pod calling broker | **Blocked (after F2 & F4)** | Direct TCP `RemoteAddr` IP only (`Proxy-Authorization` ignored); `KubeSandboxPodResolver` requires `Phase == PodRunning`, `DeletionTimestamp == nil`, `!HostNetwork`, `app.bex.co/regime=sandbox`, `namespace == <ws>-sandbox`, `bex.co/sandbox-id` (`sbx-*`), `bex.co/sandbox-group` (`sbg-*`), `bex.co/agent-session` absent, unambiguous single match, and fails closed on transient apiserver errors (F2); `bex-sandbox-pods` enforces strict `UPDATE` immutability across all five identity/egress labels (F4); Cilium `sandbox-credential-broker-gateway-ingress` explicitly denies non-sandbox, `agent-session`, missing-`sandbox-group`, and host/world peers on `:8086`; `:8091` `BrokerLookupResolver` re-verifies `sandbox_group_members`, non-deleting `sandbox_groups`, non-terminated/unexpired `sandbox_records`, and rejects `AgentSession: true` over HMAC+single-use-nonce auth (`broker_cp_test.go`, `broker_test.go`, `e2e_test.go`). |
| 2 | SSRF & DNS rebinding via credential `domain` or `CONNECT` target | **Blocked (after F1)** | `NormalizeCredentialDomain` forbids IP literals, ports, wildcards, schemes, paths, single-label names, numeric TLDs, and private/cluster suffixes (`credentials_validate.go`). `SSRFGuard.ResolveAndCheck` resolves DNS once with trailing dot, unmaps IPv4-mapped IPv6, rejects zoned IPv6 (F1), rejects if _any_ returned IP hits `deniedEgressPrefixes` (loopback, RFC1918, CGNAT, `169.254.0.0/16`, IPv6 ULA/link-local/NAT64/Teredo/6to4) or `DenyPrefixes`, and dials the verified `AddrPort` directly (`broker_test.go`, `e2e_test.go`). |
| 3 | Cross-host HTTP 3xx redirect secret leakage | **Blocked** | `handleMITMRequest` calls `http.Transport.RoundTrip` directly (never `http.Client.Do`), returning 3xx responses verbatim without following redirects. Verified end-to-end against `redirect-target.example.com` (`e2e_test.go`). |
| 4 | `Host`/SNI mismatch smuggling & HTTP request/path smuggling | **Blocked (after F3)** | TLS `GetConfigForClient` rejects non-matching SNI and mints exact-host ECDSA P-256 leaves only; `handleMITMRequest` rejects `Host` or absolute-URI host mismatches (`421`), multi/non-chunked `Transfer-Encoding` (`400`), nested `CONNECT` (`405`), opaque URIs (`400`), ambiguous/dot-segment/backslash/`//` paths (`400`, F3); strips `outURL.User`/`Fragment` and hop-by-hop + `Connection`-nominated headers via `sshgateway.RemoveHopHeaders` before injection; matches path-restricted credentials against both decoded and escaped paths (`e2e_test.go`). |
| 5 | Forbidden header injection & CRLF/control-char injection via `${SECRET}` or `name` | **Blocked (after F5)** | `ValidateCredentialInjection` runs both on write (`credentials.go`) and at runtime injection (`inject.go`, defense in depth). Rejects `Host`, `Connection`, `Keep-Alive`, `Proxy-*`, `TE`, `Trailer`, `Transfer-Encoding`, `Upgrade`, `Content-Length`, `X-Forwarded-*`, `Forwarded`, `Via`, non-token header/cookie names, `basic` with `name`, and ASCII CTLs (F5) / semicolons (cookie). `basic` base64-encodes; `query` uses `url.Values.Encode()` (`credentials_test.go`, `inject_test.go`). |
| 6 | `allow-list` bypass via brokered domain & `deny-all` bypass via broker port | **Blocked (after F4)** | Five layers: `BrokerConfig.Inject` skips `deny-all` and `SessionOnly` Pods; Cilium `sandbox-credential-broker-egress` & `sandbox-credential-broker-gateway-ingress` select only `bex.co/egress In [allow-all, allow-list]` without `agent-session` and with `sandbox-group`; `bex-sandbox-pods` freezes `bex.co/egress` on `UPDATE` (F4); `broker.go` enforces `policyAllowsConnect` before DNS/dial and again per keep-alive MITM request (`AllowsDestination` enforces exact or single-label `*.` match on `:443` only, never IP literals); `BrokerLookupResolver` defaults absent/unknown policy to `deny-all` (`wiring_e2e_test.go`, `e2e_test.go`, `gitops-validate.sh`). |
| 7 | OpenBao secret leakage via responses, errors, Postgres, audit logs, gateway logs, Prometheus, or snapshots | **Blocked** | Write-only OpenBao KV v2 under `tenants/data/<ws>/sandbox-groups/<sbg>/credentials/<sha256(id)>/<secretRef>` (`secretRef` = group-salted HMAC-SHA256, domain-separated from config fingerprint). No response type (REST/GraphQL/MCP) has a secret field; Postgres stores metadata, byte counts, and `secret_ref` only; vault errors wrap via `core.HideCause`; `BrokerCredential.String`/`GoString` redact `Value`; `scrubErrorCause` strips `*url.Error.URL`; Prometheus metrics use closed-cardinality labels only; `ValidatePublicBrokerCAPEM` rejects any PEM containing a private key block; sandbox env/entrypoint/snapshots carry only the public CA cert (`sandbox_credentials_e2e_test.go`, `broker_wiring_test.go`, `e2e_test.go`). |
| 8 | Privilege escalation: Developer PATCH, scoped API keys, narrowed/revoked keys, demoted Admin | **Blocked** | Single `s.Authorize` gate per verb (`core.RelCanView` for reads; `core.RelCanCreate` for Developer PATCH of `injection`/`methods`/`paths`/`enabled` only; `core.RelCanManage` for create, delete, restore, and any PATCH supplying `domain` or `value` across REST/GraphQL/MCP). Write verbs run uncached OpenFGA checks + creator `keyCeiling` (`core/base.go`), so demoting an Admin immediately revokes Admin-only credential writes on their existing API key. `key_permission_ops.go` enforces `KeySandboxesHistory` (read) and `KeySandboxesCredentials` (write) across all 21 REST/GraphQL/MCP operations; `scope_matrix_ops.go` enforces `bex.read`/`bex.write`. Foreign groups answer `404 SANDBOX_GROUP_NOT_FOUND` (`credentials_surfaces_test.go`, `sandbox_credentials_e2e_test.go`). |

## Accepted residuals

- **Up to 5-second broker lookup cache window (`BrokerLookupMaxCacheTTL = 5s`)**: disabling, deleting, updating, or restoring a credential cuts off injection in `bex-ssh-gateway` within at most 5 seconds (even on reused HTTP/1.1 keep-alive connections). Accepted trade-off to bound `:8091` lookup and OpenBao read load; matches ADR122 D6.
- **`HTTPS_PROXY` + Sandbox Broker CA vs transparent TCP-443 interception**: clients inside a sandbox that ignore `HTTPS_PROXY` or pin an upstream public root CA bypass the broker (they cannot steal secrets — they simply do not receive them, and remain confined by Cilium `networkPolicy`). Recorded in [ADR018](ADR018-render-parity.md) and [ADR104](ADR104-sandbox-render-parity.md) awaiting user sign-off.
- **Developer 1-bit character oracle via `basic`/`cookie` PATCH validation**: a Developer authorized to update `injection` on an existing credential can probe whether the stored secret contains `:` (by switching to `type: basic`) or `;` (by switching to `type: cookie`). Inherent to Render's documented split RBAC where Developers manage `injection` settings while `value` stays write-only.
- **Post-commit OpenBao eviction cleanup is best-effort**: if OpenBao is transiently unreachable immediately after a Postgres commit that evicts an older version past current + 3 prior configs, the orphaned secret entry stays unreadable by the broker (no DB row points to it) and is swept on subsequent credential/group/workspace delete (`DeleteCredentialPrefix` / `DeleteGroupPrefix` / `DeleteWorkspacePrefix` list and delete by KV prefix).
