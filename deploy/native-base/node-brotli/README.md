# Brotli backport for existing Node lines

`patch.sh` rebuilds the exact four EOL Node releases currently reviewed in `native.go`, replacing only the bundled Brotli C tree with Google's matching security release and exposing the new format-error constant. It replaces `/usr/local/bin/node`, preserves npm, and refuses an unreviewed old Node patch. It does nothing on other language images or supported Node lines. Run it on the official image before installing the shared native utilities, with that image's compiler, Python, and system libraries. Node 14's Bullseye Python 3.9 is supported by its configure script; the reviewed Node 16/18/20 sources support Bookworm Python 3.11.

Sources reviewed 2026-10-29:

- [Google's decoder fix](https://github.com/google/brotli/commit/0ed4268a4401abcb4472096340477cf4af7d1a2b), released as [1.0.10](https://github.com/google/brotli/releases/tag/v1.0.10) and [1.1.1](https://github.com/google/brotli/releases/tag/v1.1.1). Node 14/16 bundle 1.0.9; Node 18/20 bundle 1.1.0. The fixed archives are locked by SHA-256 in the script.
- Official Node source checksums: [14.21.3](https://nodejs.org/dist/v14.21.3/SHASUMS256.txt), [16.20.2](https://nodejs.org/dist/v16.20.2/SHASUMS256.txt), [18.20.8](https://nodejs.org/dist/v18.20.8/SHASUMS256.txt), [20.20.2](https://nodejs.org/dist/v20.20.2/SHASUMS256.txt).
- Node's [companion fix and regression](https://github.com/nodejs/node/commit/b5f41529df78a8af7b395abd6a97d2dcb6c52c61) supplies the malformed block-switch input used by `check.js`. Both synchronous and one-byte streaming decoders must reject it with error -17; ordinary compressed input must still round-trip.

Each candidate must compile and pass these checks on both amd64 and arm64 before adoption. Compilation also compares the original Node version, module ABI, N-API, V8, libuv, OpenSSL, zlib and ICU versions and verifies npm's version is unchanged. Its source record remains inside the image under `/usr/share/bex-node-brotli/sources.txt`; the shared image security gate installs and runs the network-free decoder probe separately. Copy only `patch.sh` into the compilation layer, so changing a probe does not invalidate an expensive Node rebuild. The malformed probe emits about 16 MiB before the expected error and caps output at 64 MiB. A system-package update alone cannot repair the statically bundled Node decoder. This backport addresses this Brotli issue; it does not claim all security issues in EOL Node have been repaired.

The whitelist covers the four reviewed image releases, not every historical exact patch a tenant can request. An exact-primary overlay copied from an unpatched official image can replace the repaired executable. Adopting these images must preserve the patched path for matching reviewed versions and explicitly account for other exact versions; never claim those are repaired by this recipe.
